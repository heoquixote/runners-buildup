## 현실에서는 σ를 모른다

[지난 레슨](#/l/st-04-1)에서는 모표준편차 σ를 안다고 가정하고 신뢰구간을 만들었습니다. 하지만 현실에서 모평균을 모르는데 모표준편차만 알고 있는 경우는 거의 없습니다. 그래서 σ 자리에 **표본 표준편차 s**(n − 1로 나눈 것)를 넣어 표준오차를 추정합니다.

> 추정한 SE = s ÷ √n

문제는 s도 표본에서 계산한 값이라 **함께 흔들린다**는 것입니다. 표본이 작을수록 s가 우연히 작게 나와서 구간이 실제보다 좁아질 위험이 커집니다. 이 추가 불확실성을 반영해 1.96보다 조금 더 큰 배수를 쓰는데, 그 배수를 주는 분포가 **t분포**입니다.

## t분포: 꼬리가 조금 더 두꺼운 종

::figure{src="content/img/stats/st04-t-vs-normal.svg" alt="표준정규분포 곡선과 자유도 4인 t분포 곡선을 겹친 그림. t분포가 가운데는 조금 낮고 양쪽 꼬리는 더 두껍다. 95% 경계가 정규는 ±1.96, t(4)는 ±2.78" caption="t분포는 정규분포와 닮았지만 꼬리가 더 두꺼워서, 같은 95%를 남기려면 더 멀리(더 큰 배수)까지 가야 합니다. 자유도가 커질수록 정규분포와 같아집니다."}

t분포는 정규분포처럼 좌우 대칭인 종 모양이지만 **꼬리가 더 두껍습니다.** 모양은 **자유도**(degrees of freedom, df) 하나로 정해지는데, 평균의 신뢰구간에서는 **df = n − 1**입니다. 자유도가 작으면(표본이 작으면) 꼬리가 두껍고, 자유도가 커지면 정규분포와 거의 같아집니다.

95% 구간에 쓰는 배수를 자유도별로 비교해 봅니다. `stats.t.ppf(0.975, df)`가 t분포에서 가운데 95%를 남기는 경계입니다.

```run
from scipy import stats

for df in [4, 29, 200]:
    print(f"자유도 {df}: t 배수 {stats.t.ppf(0.975, df):.3f}  (정규 1.960)")
```

자유도 4(표본 5개)면 2.776으로 1.96보다 훨씬 크고, 자유도 29(표본 30개)면 2.045, 자유도 200이면 1.972로 거의 1.96입니다. **표본이 작을수록 더 넓게 팔을 벌리라**는 뜻입니다. 표본이 수백 개면 t를 쓰든 정규를 쓰든 결과가 거의 같지만, 언제나 t를 쓰는 편이 안전합니다.

## 평균의 신뢰구간: 식당 팁

식당 계산서 244장의 팁 평균에 대한 95% 신뢰구간을 구해 봅니다. 먼저 재료 세 가지(평균, 표본 표준편차, 표준오차)를 구합니다.

```run
import numpy as np
import pandas as pd

tip = pd.read_csv("tips.csv")["tip"]
mean, s, n = tip.mean(), tip.std(), len(tip)
print("평균:", round(mean, 3), "/ s:", round(s, 3), "/ SE:", round(s / np.sqrt(n), 4))
```

평균 2.998달러, 표본 표준편차 1.384달러, 표준오차 0.0886달러입니다. 이제 `stats.t.interval`로 구간을 구합니다. 신뢰수준, 자유도, 중심(`loc`), 표준오차(`scale`)를 넣습니다.

```run
import numpy as np
import pandas as pd
from scipy import stats

tip = pd.read_csv("tips.csv")["tip"]
se = tip.std() / np.sqrt(len(tip))
print("95% CI:", np.round(stats.t.interval(0.95, len(tip) - 1, loc=tip.mean(), scale=se), 3))
```

95% 신뢰구간은 2.824 ~ 3.173달러입니다. 손으로도 계산해 봅니다. 배수만 1.96 대신 t 배수를 쓰면 됩니다.

```run
import numpy as np
import pandas as pd
from scipy import stats

tip = pd.read_csv("tips.csv")["tip"]
t_mult = stats.t.ppf(0.975, len(tip) - 1)
half = t_mult * tip.std() / np.sqrt(len(tip))
print("t 배수:", round(t_mult, 4), "/ 구간:", round(tip.mean() - half, 3), "~", round(tip.mean() + half, 3))
```

t 배수 1.9698로, 함수 결과와 똑같은 2.824 ~ 3.173달러가 나옵니다. 자유도 243이면 t 배수가 1.96과 거의 같습니다.

## 표본이 작으면 t가 중요하다

금요일 계산서는 19장뿐입니다. 이럴 때 1.96을 쓰면 구간이 얼마나 좁게(위험하게) 나오는지 비교해 봅니다.

```run
import numpy as np
import pandas as pd
from scipy import stats

fri = pd.read_csv("tips.csv").query("day == 'Fri'")["tip"]
se = fri.std() / np.sqrt(len(fri))
print("n =", len(fri), "/ t 배수:", round(stats.t.ppf(0.975, len(fri) - 1), 3))
print("정규로 만든 폭:", round(2 * 1.96 * se, 3), "/ t로 만든 폭:", round(2 * stats.t.ppf(0.975, len(fri) - 1) * se, 3))
```

n = 19면 t 배수가 2.101입니다. 1.96으로 만든 구간은 t로 만든 구간보다 7%쯤 좁습니다. 겉으로는 더 정밀해 보이지만, 실제로는 참값을 놓칠 확률이 5%보다 커집니다.

## 비율의 신뢰구간

생존율, 합격률, 불량률 같은 **비율**도 신뢰구간을 만들 수 있습니다. 0과 1로 된 데이터의 평균이 비율이므로, 비율도 일종의 평균이고 중심극한정리가 그대로 적용됩니다. 비율 p̂의 표준오차는 다음 공식으로 구합니다.

> 비율의 SE = √( p̂ × (1 − p̂) ÷ n )

표본이 충분히 크면(대략 성공 · 실패가 각각 10개 이상) 정규분포 배수 1.96을 씁니다. 타이타닉 승객의 생존율에 대한 95% 신뢰구간을 구해 봅니다.

```run
import numpy as np
import pandas as pd

surv = pd.read_csv("titanic.csv")["survived"]
p, n = surv.mean(), len(surv)
se = np.sqrt(p * (1 - p) / n)
print("생존율:", round(p, 3), "/ 95% CI:", round(p - 1.96 * se, 3), "~", round(p + 1.96 * se, 3))
```

생존율 0.384, 95% 신뢰구간은 0.352 ~ 0.416입니다. 이 891명이 당시 승객 전체에서 무작위로 뽑힌 표본이라고 본다면, 전체 승객의 생존율은 35~42% 사이쯤이라고 말할 수 있습니다.

## 그룹별 구간 비교하기

성별로 나눠서 생존율의 신뢰구간을 각각 구해 봅니다.

```run
import numpy as np
import pandas as pd

df = pd.read_csv("titanic.csv")
for sex, g in df.groupby("sex"):
    p, n = g["survived"].mean(), len(g); se = np.sqrt(p * (1 - p) / n)
    print(f"{sex}: n = {n}, 생존율 {p:.3f}, 95% CI {p - 1.96 * se:.3f} ~ {p + 1.96 * se:.3f}")
```

여성은 0.694 ~ 0.790, 남성은 0.157 ~ 0.221입니다. 두 구간이 전혀 겹치지 않고 아주 멀리 떨어져 있으니, 성별에 따른 생존율 차이가 우연이라고 보기는 어렵습니다.

> 두 구간이 **겹치지 않으면** 차이가 있다고 볼 근거가 강합니다. 하지만 **조금 겹친다고** 해서 차이가 없다는 뜻은 아닙니다. 두 그룹의 차이를 정확히 판단하려면 차이 자체의 신뢰구간이나 가설검정([DAY 07](#/l/st-05-3))을 써야 합니다.

## 보고하는 법

신뢰구간은 숫자 세 개(추정값, 아래 끝, 위 끝)와 표본 수를 함께 적습니다.

> 평균 팁은 **3.00달러**(95% CI 2.82 ~ 3.17달러, n = 244)였다.
> 승객 생존율은 **38.4%**(95% CI 35.2 ~ 41.6%, n = 891)였다.

이렇게 쓰면 읽는 사람이 "평균이 대략 이 정도이고, 오차는 이 정도"라는 것을 한눈에 알 수 있습니다. 평균만 덩그러니 적는 것보다 훨씬 정직한 보고입니다. 보고 방법은 [DAY 11](#/l/st-10-2)에서 더 자세히 다룹니다.

## 정리

- σ를 모르면 표본 표준편차 s로 SE를 추정하고, 그만큼 커진 불확실성을 **t분포**로 반영한다.
- t분포는 꼬리가 두꺼운 종 모양, 자유도 n − 1. 표본이 작을수록 배수가 커지고, 크면 정규분포(1.96)와 같아진다.
- 평균의 CI: `stats.t.interval(0.95, n - 1, loc=평균, scale=s/√n)`.
- 비율의 CI: p̂ ± 1.96 × √(p̂(1 − p̂) ÷ n).
- 보고할 때는 추정값 · 신뢰구간 · 표본 수를 함께 적는다.
