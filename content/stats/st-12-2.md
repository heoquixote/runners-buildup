## 평균만큼 중요한 흩어짐

품질 현장에서는 평균보다 **흩어짐(산포)** 이 더 중요한 경우가 많습니다. 평균이 규격 한가운데에 있어도 흩어짐이 크면 불량이 나오기 때문입니다. 그래서 이런 질문이 자주 나옵니다.

- 이 설비의 흔들림이 허용 기준(σ₀)보다 큰가? → **1표본 카이제곱 분산 검정**
- 정비 후 흔들림이 줄었나? (두 그룹) → **F검정**
- 세 라인의 흔들림이 같은가? (여러 그룹) → **바틀렛 검정** 또는 **레빈 검정**

평균 검정이 "차이 ÷ 표준오차"였다면, 분산 검정은 **두 분산의 비율**로 비교합니다. 흩어짐은 빼기보다 나누기로 비교하는 것이 자연스럽기 때문입니다.

## 1표본 분산 검정: 흔들림이 기준보다 큰가

정규분포에서 n개를 뽑아 표본분산 s²를 구하면, 아래 값은 자유도 n − 1인 **카이제곱 분포**를 따릅니다.

`χ² = (n − 1) × s² ÷ σ₀²`

s²가 σ₀²와 같으면 χ²는 대략 자유도(n − 1) 근처에 오고, s²가 크면 χ²도 커집니다. 토크의 표준편차 허용 기준이 σ₀ = 10Nm라고 할 때, 오늘 설비 25대의 흔들림이 기준을 넘는지 봅니다. "더 큰가"만 궁금하므로 단측 검정입니다.

```run
import numpy as np
import pandas as pd
from scipy import stats

df = pd.read_csv("ai4i2020.csv")
s = df.iloc[5000:6000].sample(25, random_state=0)["torque"]
n, sigma0 = len(s), 10.0
chi2 = (n - 1) * s.var() / sigma0 ** 2
print("sample std:", round(s.std(), 2), "Nm")
print("chi2 =", round(chi2, 2), "with df", n - 1, "(expected about", n - 1, "if sigma = 10)")
print("one-sided p =", round(stats.chi2.sf(chi2, n - 1), 4))
lo, hi = np.sqrt((n - 1) * s.var() / stats.chi2.ppf([0.975, 0.025], n - 1))
print(f"95% CI for sigma: {lo:.2f} ~ {hi:.2f} Nm")
```

- 표본 표준편차는 12.26Nm로 기준(10)보다 큽니다. χ² = 36.10으로 기대값 24보다 크지만, 단측 p = 0.054로 5% 기준에 아슬아슬하게 못 미칩니다.
- σ의 95% 신뢰구간은 9.58 ~ 17.06Nm입니다. 구간이 기준값 10을 포함하므로 "기준을 넘었다"고 단정할 수 없습니다. 25대로는 흩어짐을 정확히 재기 어렵다는 뜻이기도 합니다.

평균의 신뢰구간과 달리 **좌우가 대칭이 아닙니다**(12.26에서 아래로 2.7, 위로 4.8). 카이제곱 분포가 오른쪽으로 꼬리가 긴 비대칭 분포이기 때문입니다.

## F검정: 두 그룹의 흔들림 비교

두 그룹의 표본분산 비율은 **F분포**를 따릅니다. F분포는 자유도가 두 개(분자 n₁ − 1, 분모 n₂ − 1)입니다. [ANOVA](#/l/st-06-2)의 F와 같은 분포입니다. ANOVA도 "그룹 간 분산 ÷ 그룹 안 분산"이라는 분산의 비율이었습니다.

`F = s₁² ÷ s₂²`

분산이 같으면 F는 1 근처에 옵니다. 공정 온도의 흔들림이 처음 기간(1 ~ 1,000번째 기록)과 나중 기간(2,001 ~ 3,000번째 기록)에 달라졌는지, 각각 20대씩 뽑아 비교합니다.

```run
import pandas as pd
from scipy import stats

df = pd.read_csv("ai4i2020.csv")
a = df.iloc[0:1000].sample(20, random_state=0)["process_temp"]
b = df.iloc[2000:3000].sample(20, random_state=0)["process_temp"]
F = a.var() / b.var()
dfa, dfb = len(a) - 1, len(b) - 1
p = 2 * min(stats.f.sf(F, dfa, dfb), stats.f.cdf(F, dfa, dfb))
print("std:", round(a.std(), 3), "vs", round(b.std(), 3))
print("F =", round(F, 2), ", two-sided p =", round(p, 5))
```

표준편차 1.025K와 0.418K, F = 6.02(분산이 6배), p = 0.0003입니다. 나중 기간의 흔들림이 확실히 작습니다. 사이파이에는 F검정 함수가 따로 없어서, F분포의 꼬리 넓이(`stats.f.sf`, `stats.f.cdf`)로 직접 계산했습니다. 양측이므로 작은 쪽 꼬리에 2를 곱합니다.

## 여러 그룹: 바틀렛 vs 레빈

그룹이 셋 이상이면 **바틀렛 검정**(`stats.bartlett`)이나 **레빈 검정**(`stats.levene`)을 씁니다. 둘 다 귀무가설은 "모든 그룹의 분산이 같다"입니다. 결정적인 차이는 **정규성에 얼마나 민감한가**입니다.

| 검정 | 원리 | 정규분포일 때 | 정규가 아닐 때 |
| --- | --- | --- | --- |
| F검정 · 바틀렛 | 분산 자체를 비교 | 가장 민감(검정력 높음) | 치우침 · 이상치를 "분산 차이"로 오인 |
| 레빈 | 각 값이 그룹 중심에서 떨어진 **거리**로 ANOVA | 조금 덜 민감 | 잘 버팀 |

요일별 팁의 흩어짐을 두 검정으로 비교해 봅니다. 팁은 오른쪽으로 꼬리가 긴 분포였습니다([가정 확인과 비모수 검정](#/l/st-06-3)).

```run
import pandas as pd
from scipy import stats

df = pd.read_csv("tips.csv")
groups = [df[df["day"] == d]["tip"] for d in ["Thur", "Fri", "Sat", "Sun"]]
print("std by day:", [float(round(g.std(), 2)) for g in groups])
print("skew by day:", [float(round(stats.skew(g), 2)) for g in groups])
print("Bartlett p =", round(stats.bartlett(*groups).pvalue, 4))
print("Levene p   =", round(stats.levene(*groups).pvalue, 4))
```

바틀렛은 p = 0.012로 "분산이 다르다", 레빈은 p = 0.647로 "다르다고 볼 근거 없음"입니다. 정반대입니다. 토요일 팁은 표준편차가 1.63으로 크고, 왜도가 큰 몇 건(아주 큰 팁)이 있습니다. 바틀렛은 이 **꼬리**를 분산 차이로 받아들였고, 거리로 비교하는 레빈은 흔들리지 않았습니다. 데이터가 정규에 가깝다는 확신이 없으면 **레빈을 기본**으로 씁니다.

:::tip 알아 두면 좋아요 · 레빈 검정의 속
레빈 검정은 각 값을 |값 − 그룹 중심|(중심에서 떨어진 거리)으로 바꾼 뒤, 그 거리로 **일원 ANOVA**를 합니다. 흩어짐이 큰 그룹은 거리의 평균이 크기 때문입니다. 중심으로 평균을 쓰면 원래 레빈, 중앙값을 쓰면 **브라운-포사이스** 검정이라고 부릅니다. 사이파이의 `stats.levene`은 기본값이 `center="median"`이라 사실 브라운-포사이스이고, 이상치에 더 강합니다.
:::

## 실무 예제: 등급별로 흔들림이 다른가

AI4I의 세 제품 등급(L · M · H)에서 토크 · 회전수 · 공정 온도의 흔들림이 같은지 한 번에 확인합니다.

```run
import pandas as pd
from scipy import stats

df = pd.read_csv("ai4i2020.csv")
for col in ["torque", "rpm", "process_temp"]:
    groups = [df[df["type"] == t][col].astype(float) for t in ["L", "M", "H"]]   # rpm is int: use float
    stds = [float(round(g.std(), 2)) for g in groups]
    print(f"{col:>12}: std L/M/H {stds}, Bartlett p {stats.bartlett(*groups).pvalue:.3f}, Levene p {stats.levene(*groups).pvalue:.3f}")
```

세 변수 모두 두 검정의 p-value가 0.23 이상입니다. 등급에 따라 흔들림이 다르다고 볼 근거가 없으므로, 등급별 평균 비교에 [ANOVA](#/l/st-06-2)를 그대로 써도 등분산 가정은 문제없습니다.

## 자주 하는 실수

| 실수 | 무슨 일이 생기나 | 바로잡기 |
| --- | --- | --- |
| 치우친 데이터에 바틀렛 · F검정 | 정규성 위반을 분산 차이로 착각 (팁: 0.012 vs 0.647) | 레빈(브라운-포사이스) |
| 분산 검정 결과로 t검정 종류를 기계적으로 고름 | 검정을 두 번 하면서 오류가 쌓임 | 처음부터 Welch t검정 |
| 25개로 σ를 정밀하게 판단 | 분산의 신뢰구간은 생각보다 넓음 (9.6 ~ 17.1) | 신뢰구간을 함께 보고, 표본을 늘림 |
| F를 큰 분산 ÷ 작은 분산으로 고정하고 양측 p를 안 곱함 | p-value가 절반으로 작아짐 | 양측이면 작은 쪽 꼬리 × 2 |

## 정리

- 흩어짐은 **비율**로 비교합니다. 1표본: χ² = (n − 1)s²/σ₀², 두 그룹: F = s₁²/s₂², 여러 그룹: 바틀렛 · 레빈.
- 토크 25대의 흔들림(12.26)은 기준 10을 넘는다고 단정하기 어려웠습니다(p = 0.054, σ 신뢰구간 9.58 ~ 17.06).
- 공정 온도 흔들림은 두 기간에 6배 차이가 났습니다(F = 6.02, p = 0.0003).
- 바틀렛 · F검정은 정규성에 민감합니다. 요일별 팁에서 바틀렛 0.012, 레빈 0.647로 결론이 갈렸습니다. 정규성이 의심되면 **레빈**을 씁니다.
