## "비 올 확률 70%"는 무슨 뜻일까

일기예보에서 "내일 비 올 확률 70%"라고 하면, 우리는 우산을 챙깁니다. 그런데 70%라는 숫자는 정확히 무슨 뜻일까요? 내일은 한 번뿐이고, 비는 오거나 안 오거나 둘 중 하나인데요.

가장 이해하기 쉬운 해석은 이렇습니다. **"오늘 같은 날씨가 100번 있었다면, 그다음 날 비가 온 것이 70번쯤이었다."** 확률은 **같은 일을 아주 많이 반복했을 때 그 일이 일어나는 비율**입니다. 이번 레슨에서는 이 생각을 파이썬으로 직접 확인해 봅니다. 통계의 나머지 내용(분포, 검정, 신뢰구간)이 모두 이 확률 위에 서 있습니다.

## 실험 · 결과 · 표본공간 · 사건

확률을 말하려면 먼저 이름 네 개를 정리해야 합니다. 주사위 한 번 던지기로 봅시다.

| 이름 | 뜻 | 주사위 예 |
| --- | --- | --- |
| **실험**(시행) | 결과가 우연히 정해지는 행동 | 주사위를 한 번 던진다 |
| **결과** | 실험에서 나올 수 있는 하나하나 | 1, 2, 3, 4, 5, 6 중 하나 |
| **표본공간** | 가능한 결과 전체의 모음 | {1, 2, 3, 4, 5, 6} |
| **사건** | 표본공간 중 우리가 관심 있는 일부 | "짝수가 나온다" = {2, 4, 6} |

::figure{src="content/img/stats/st09-sample-space.svg" alt="1부터 6까지 적힌 표본공간 사각형 안에 짝수 사건 A(2, 4, 6)와 4 이상 사건 B(4, 5, 6)가 원으로 겹쳐 그려져 있고, 겹친 부분은 4와 6" caption="표본공간(사각형) 안에서 사건은 결과들의 묶음입니다. A와 B가 겹친 부분 {4, 6}이 'A 그리고 B', 둘을 합친 부분 {2, 4, 5, 6}이 'A 또는 B'입니다."}

## 확률의 정의: 경우의 수로 세기

모든 결과가 똑같이 나올 법하다면(공정한 주사위처럼), 확률은 이렇게 셉니다.

> P(사건) = 사건에 속한 결과의 수 ÷ 전체 결과의 수

"짝수가 나올 확률"은 결과 6개 중 3개(2, 4, 6)가 해당하니 3 ÷ 6 = 0.5입니다. P는 Probability(확률)의 첫 글자입니다.

```run
space = [1, 2, 3, 4, 5, 6]
even = [x for x in space if x % 2 == 0]
print("짝수 사건:", even, "/ 확률:", len(even) / len(space))
```

확률에는 늘 지켜지는 규칙 세 가지가 있습니다.

1. 모든 확률은 **0 이상 1 이하**입니다. 0은 절대 안 일어남, 1은 반드시 일어남.
2. 표본공간 전체의 확률은 **1**입니다. 주사위를 던지면 1~6 중 무언가는 반드시 나옵니다.
3. 어떤 사건이 **일어나지 않을 확률**은 1 − (일어날 확률)입니다. 짝수가 안 나올 확률 = 1 − 0.5 = 0.5. 이것을 **여사건**의 확률이라고 합니다.

## 시뮬레이션: 컴퓨터에게 던지게 하기

경우의 수로 세기 어려운 문제도 많습니다. 그럴 때는 컴퓨터로 실험을 **아주 많이 반복**해서 비율을 보는 방법을 씁니다. 이것을 **시뮬레이션**이라고 합니다.

NumPy의 난수 생성기 `rng`로 주사위를 던집니다. `rng.integers(1, 7, size=10)`은 1 이상 7 미만의 정수를 10개 뽑습니다. `default_rng(0)`의 0은 **시드**(seed)라는 출발 번호로, 같은 시드를 쓰면 언제 실행해도 같은 "우연"이 나옵니다. 그래서 이 레슨의 숫자와 여러분 화면의 숫자가 같게 나옵니다.

```run
import numpy as np

rng = np.random.default_rng(0)
rolls = rng.integers(1, 7, size=10)
print("10번 던진 결과:", rolls)
```

이 10번 중 짝수의 비율을 세어 봅니다. `rolls % 2 == 0`은 짝수면 True, 아니면 False인 배열이고, True를 1로 세서 평균을 내면 비율이 됩니다.

```run
import numpy as np

rng = np.random.default_rng(0)
rolls = rng.integers(1, 7, size=10)
print("짝수 비율 (10번):", (rolls % 2 == 0).mean())
```

10번 중 짝수가 6번, 비율 0.6입니다. 이론값 0.5와 0.1이나 차이가 납니다. 10번은 너무 적어서 우연이 크게 작용합니다. 이번엔 10,000번 던져 봅니다.

```run
import numpy as np

rng = np.random.default_rng(0)
rolls = rng.integers(1, 7, size=10_000)
print("짝수 비율 (10,000번):", (rolls % 2 == 0).mean())
```

10,000번 던지니 짝수 비율이 0.5019로 0.5에 아주 가까워졌습니다.

## 큰 수의 법칙

이처럼 **같은 실험을 많이 반복할수록, 사건이 일어난 비율은 진짜 확률에 점점 가까워집니다.** 이것을 **큰 수의 법칙**이라고 합니다. 확률을 "많이 반복했을 때의 비율"로 해석할 수 있는 근거가 바로 이 법칙입니다.

::figure{src="content/img/stats/st09-lln.svg" alt="가로축은 던진 횟수(로그 눈금), 세로축은 짝수 비율. 처음에는 0.2에서 0.8 사이를 크게 오르내리다가 횟수가 늘수록 0.5 선에 붙는 곡선" caption="큰 수의 법칙: 처음 몇 번은 비율이 크게 흔들리지만, 던질수록 진짜 확률(0.5) 근처로 모입니다."}

던질 때마다 "지금까지의 짝수 비율"을 계산해 그래프로 그려 봅니다. `np.cumsum`은 누적 합(지금까지 짝수가 몇 번 나왔나)이고, 그것을 지금까지 던진 횟수로 나누면 누적 비율이 됩니다.

```run
import matplotlib.pyplot as plt
import numpy as np

rng = np.random.default_rng(0)
even = rng.integers(1, 7, size=2000) % 2 == 0
ratio = np.cumsum(even) / np.arange(1, 2001)
plt.plot(ratio); plt.axhline(0.5, color="gray"); plt.xlabel("number of rolls"); plt.show()
print("20번째:", round(ratio[19], 3), "/ 200번째:", round(ratio[199], 3), "/ 2000번째:", round(ratio[1999], 3))
```

20번째까지의 비율은 0.75, 200번째는 0.485, 2,000번째는 0.518입니다. 앞부분에서는 선이 크게 출렁이지만, 오른쪽으로 갈수록 0.5 선에 달라붙습니다.

> 큰 수의 법칙은 "많이 하면 결국 평균으로 돌아온다"는 뜻이지, "앞에서 홀수가 많이 나왔으니 이제 짝수가 나올 차례"라는 뜻이 아닙니다. 주사위는 앞의 결과를 기억하지 않습니다. 이 착각을 **도박사의 오류**라고 부릅니다.

직접 해 보세요: 위 셀의 시드 `0`을 다른 숫자로 바꿔 보세요. 앞부분의 출렁임 모양은 매번 다르지만, 끝에서는 늘 0.5 근처로 모입니다.

## "또는"과 "그리고"

사건 두 개를 함께 생각할 때가 많습니다. 주사위에서 A = "짝수", B = "4 이상"이라고 하면,

- **A 그리고 B** (곱사건): 짝수이면서 4 이상 = {4, 6} → 확률 2/6
- **A 또는 B** (합사건): 짝수이거나 4 이상 = {2, 4, 5, 6} → 확률 4/6

"또는"의 확률은 P(A) + P(B) − P(A 그리고 B)로 셉니다. 겹친 부분 {4, 6}을 두 번 세지 않으려고 한 번 빼는 것입니다: 3/6 + 3/6 − 2/6 = 4/6.

두 사건이 서로 영향을 주지 않을 때 **독립**이라고 하고, 이때는 "그리고"의 확률을 **곱해서** 구합니다. 동전 두 개를 던져 둘 다 앞면일 확률은 0.5 × 0.5 = 0.25입니다. 시뮬레이션으로 확인해 봅니다.

```run
import numpy as np

rng = np.random.default_rng(1)
coin1 = rng.integers(0, 2, size=10_000)
coin2 = rng.integers(0, 2, size=10_000)
print("둘 다 앞면(1) 비율:", ((coin1 == 1) & (coin2 == 1)).mean(), "/ 이론값: 0.25")
```

10,000번 시뮬레이션에서 0.2582로, 이론값 0.25와 거의 같습니다.

## 데이터 속의 확률: 상대도수

실제 데이터에서는 "모든 결과가 똑같이 나올 법하다"는 가정을 할 수 없습니다. 이때는 데이터에서 그 일이 일어난 **비율**(상대도수)을 확률의 추정값으로 씁니다. 타이타닉 승객 중 무작위로 한 명을 골랐을 때 생존자일 확률은?

```run
import pandas as pd

df = pd.read_csv("titanic.csv")
print("생존자 수:", df["survived"].sum(), "/ 전체:", len(df))
print("P(생존) =", round(df["survived"].mean(), 3))
```

891명 중 342명이 생존해서 P(생존) = 0.384입니다. 0과 1로 된 열의 평균이 곧 1의 비율이라는 점도 기억해 두세요. 다음 레슨에서는 "여성일 때 생존할 확률"처럼 **조건이 붙은 확률**을 이 데이터로 계산합니다.

## 실무 예제: "적어도 한 대는 고장"일 확률

설비 한 대가 고장 날 확률이 3.39%라고 합시다(설비 데이터의 전체 고장률). 설비가 서로 영향을 주지 않는다면(독립), 여러 대에 대한 확률은 곱셈으로 구합니다.

- 3대 모두 정상일 확률 = 0.9661 × 0.9661 × 0.9661
- **적어도 한 대는 고장**일 확률 = 1 − (모두 정상일 확률)

"적어도 하나"는 경우가 너무 많아서(1대 고장, 2대 고장, …) 직접 세기 어렵습니다. 그래서 반대 사건(**여사건**, 하나도 고장 나지 않음)을 구해 1에서 빼는 것이 요령입니다.

```run
p = 0.0339
for n in [3, 10, 30]:
    print(f"{n}대: 모두 정상 {(1 - p) ** n:.3f} / 적어도 한 대 고장 {1 - (1 - p) ** n:.3f}")
```

한 대씩 보면 고장은 드문 일(3.39%)이지만, 10대를 운영하면 적어도 한 대가 고장 날 확률이 29.2%, 30대면 64.5%입니다. "고장률 3%면 신경 안 써도 된다"는 판단이 설비 수가 늘어나면 틀리게 되는 이유입니다. 시뮬레이션으로도 확인해 봅니다. 10대짜리 공장을 10,000번 돌립니다.

```run
import numpy as np

rng = np.random.default_rng(0)
broken = rng.random((10000, 10)) < 0.0339
print("적어도 한 대 고장인 공장 비율:", broken.any(axis=1).mean())
```

0.287로, 계산값 0.292와 거의 같습니다. `rng.random((10000, 10))`은 공장 10,000개 × 설비 10대의 표를 만들고, `.any(axis=1)`은 행마다 "하나라도 True인가"를 확인합니다.

## 자주 하는 실수

1. **"이번엔 될 차례"라고 생각한다(도박사의 오류).** 동전을 다섯 번 던져 모두 앞면이 나와도 여섯 번째 뒷면 확률은 0.5입니다. 큰 수의 법칙은 앞의 결과를 메워 주는 법칙이 아닙니다.
2. **독립이 아닌데 곱한다.** 같은 전원에 물린 설비는 정전이 나면 함께 멈춥니다. 서로 영향을 주는 사건의 확률을 곱하면 위험을 크게 낮춰 잡게 됩니다.
3. **"또는"을 그냥 더한다.** 두 사건이 겹치면 겹친 부분을 한 번 빼야 합니다: P(A 또는 B) = P(A) + P(B) − P(A 그리고 B).

## 정리

- 확률은 **같은 실험을 아주 많이 반복했을 때 그 일이 일어나는 비율**이다.
- 실험 · 결과 · **표본공간**(가능한 결과 전체) · **사건**(관심 있는 결과 묶음).
- 확률 규칙: 0~1, 전체는 1, 일어나지 않을 확률 = 1 − P.
- **큰 수의 법칙**: 많이 반복할수록 비율이 진짜 확률에 가까워진다. 그래서 시뮬레이션으로 확률을 근사할 수 있다.
- **독립**인 두 사건이 함께 일어날 확률은 곱한다. 데이터에서는 상대도수가 확률의 추정값이다.
