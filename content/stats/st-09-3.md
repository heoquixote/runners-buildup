## 전부 검사할 수 없을 때

부품 500개가 든 로트(lot)가 입고됐습니다. 500개를 모두 검사하면 시간과 비용이 많이 들고, 파괴 검사라면 검사한 부품은 쓸 수도 없습니다. 그래서 현장에서는 **일부만 뽑아 검사하고 로트 전체를 받을지 정합니다.** 이것을 **샘플링 검사**(acceptance sampling)라고 합니다.

규칙은 보통 이렇게 정합니다.

> 로트에서 **n개**를 뽑아 검사하고, 불량이 **c개 이하**면 로트를 합격시킨다.

예를 들어 "20개를 뽑아 불량이 1개 이하면 합격"입니다. 이 레슨에서는 [st-09-1](#/l/st-09-1)의 확률과 [st-02-2](#/l/st-02-2)의 이항분포로 "이 규칙이면 불량률 5%인 로트가 몇 % 확률로 합격하나"를 계산합니다. 품질 담당자가 검사 규칙을 정하고 설명할 때 쓰는 계산입니다.

## 합격 확률: 이항분포로 계산

로트의 불량률이 p일 때, 20개를 뽑아 불량이 0개 또는 1개 나올 확률이 곧 **합격 확률**입니다. 로트가 충분히 크면 매번 뽑을 때 불량일 확률이 p로 거의 같으니 이항분포를 씁니다.

```run
from scipy import stats

n, c = 20, 1
p = 0.05
print("불량 0개:", round(stats.binom.pmf(0, n, p), 4))
print("불량 1개:", round(stats.binom.pmf(1, n, p), 4))
print("합격 확률 (c 이하):", round(stats.binom.cdf(c, n, p), 4))
```

불량률 5%인 로트에서 20개를 뽑으면 불량 0개일 확률이 35.8%, 1개일 확률이 37.7%이고, 둘을 더한 **73.6%**가 합격 확률입니다. `binom.cdf(c, n, p)`는 "c개 이하"의 확률을 한 번에 더해 줍니다. 불량이 20개 중 1개꼴로 섞인 로트를 4번 중 3번쯤은 그냥 받는다는 뜻입니다. 생각보다 높지 않나요?

## 정확하게는: 초기하분포

엄밀히 말하면 검사한 부품을 다시 넣지 않으므로(비복원추출), 하나 뽑을 때마다 남은 로트의 불량 비율이 조금씩 바뀝니다. 이 경우의 정확한 분포가 **초기하분포**(`stats.hypergeom`)입니다. 로트 크기 N, 로트 안 불량 수 D, 뽑는 수 n을 넣습니다.

```run
from scipy import stats

N, n, c = 500, 20, 1
for p in [0.01, 0.02, 0.05, 0.10]:
    D = int(N * p)
    print(f"불량률 {p:.0%}: 이항 {stats.binom.cdf(c, n, p):.4f}  초기하 {stats.hypergeom.cdf(c, N, D, n):.4f}")
```

두 값이 소수 둘째 자리까지 거의 같습니다. 뽑는 수가 로트 크기의 10%보다 작으면(여기서는 20/500 = 4%) 이항분포로 계산해도 충분합니다. 로트가 작고 많이 뽑을 때만 초기하분포를 씁니다.

## 시뮬레이션으로 확인

불량 25개(5%)가 섞인 500개 로트를 만들고, 20개를 비복원추출로 뽑는 검사를 1만 번 해 봅니다.

```run
import numpy as np

rng = np.random.default_rng(0)
lot = np.array([1] * 25 + [0] * 475)          # 1 = 불량
passed = [rng.choice(lot, size=20, replace=False).sum() <= 1 for _ in range(10000)]
print("합격 비율:", np.mean(passed))
```

1만 번 중 73.4%가 합격했습니다. 초기하분포로 계산한 73.6%와 거의 같습니다. [큰 수의 법칙](#/l/st-09-1)대로 반복이 많으면 상대도수가 확률에 가까워집니다.

## OC 곡선: 검사 규칙의 성적표

불량률을 0%부터 20%까지 바꿔 가며 합격 확률을 그리면, 그 검사 규칙이 어떤 로트를 받고 어떤 로트를 거르는지 한눈에 보입니다. 이 그래프를 **OC 곡선**(operating characteristic curve, 검사 특성 곡선)이라고 합니다.

```run
import numpy as np
import matplotlib.pyplot as plt
from scipy import stats

p = np.linspace(0, 0.20, 101)
fig, ax = plt.subplots(figsize=(6, 3.5))
for n, c in [(20, 1), (50, 2), (80, 3)]:
    ax.plot(p * 100, stats.binom.cdf(c, n, p), label=f"n={n}, c={c}")
ax.set_xlabel("Lot defect rate (%)")
ax.set_ylabel("P(accept)")
ax.set_title("OC curves: larger samples separate good and bad lots")
ax.legend()
for n, c in [(20, 1), (50, 2), (80, 3)]:
    print(f"n={n}, c={c}: 불량 1% 합격 {stats.binom.cdf(c, n, 0.01):.3f} / 불량 8% 합격 {stats.binom.cdf(c, n, 0.08):.3f}")
```

이상적인 검사라면 좋은 로트(불량 1%)는 100% 받고 나쁜 로트(불량 8%)는 0% 받는, 절벽 모양이어야 합니다. 20개 검사는 곡선이 완만해서 불량 8% 로트도 51.7% 확률로 받습니다. 80개를 뽑아 3개 이하로 바꾸면 좋은 로트는 99.1% 받으면서 나쁜 로트는 10.9%만 받습니다. **더 많이 검사할수록 곡선이 가팔라지고, 좋은 로트와 나쁜 로트를 더 잘 가릅니다.**

## 생산자 위험과 소비자 위험

OC 곡선의 두 끝에는 이름이 있습니다. [st-05-2](#/l/st-05-2)의 1종 · 2종 오류와 같은 구조입니다.

| 위험 | 뜻 | 누구 손해 | 검정에 비유하면 |
| --- | --- | --- | --- |
| 생산자 위험 (α) | 좋은 로트가 불합격 | 납품한 회사 | 1종 오류 |
| 소비자 위험 (β) | 나쁜 로트가 합격 | 받은 회사 | 2종 오류 |

n = 80, c = 3 규칙이면 불량 1% 로트의 생산자 위험은 1 − 0.991 = 0.9%, 불량 8% 로트의 소비자 위험은 10.9%입니다. 두 회사가 "좋은 로트는 몇 %, 나쁜 로트는 몇 %"를 먼저 합의하고, 두 위험을 함께 만족하는 n과 c를 찾는 것이 검사 규칙 설계입니다. 실무에서는 KS Q ISO 2859 같은 표준 샘플링 표에서 고르는 경우가 많은데, 그 표의 숫자도 이 계산으로 만들어진 것입니다.

## 실무 예제: "불량 0개면 합격" 규칙은 엄격할까

c = 0, 즉 "한 개라도 나오면 불합격" 규칙은 엄격해 보입니다. 정말 그런지 n = 20으로 계산해 봅니다.

```run
from scipy import stats

n = 20
for p in [0.01, 0.05, 0.10]:
    print(f"불량률 {p:.0%}: c=0 합격 {stats.binom.cdf(0, n, p):.3f} / c=1 합격 {stats.binom.cdf(1, n, p):.3f}")
```

c = 0으로 바꾸면 나쁜 로트(10%)의 합격 확률은 12.2%로 줄지만, 좋은 로트(1%)의 합격 확률도 81.8%로 떨어집니다. 좋은 로트 5개 중 1개가 억울하게 반품되는 셈입니다. 규칙이 엄격해 보여도 **표본이 작으면 좋은 로트와 나쁜 로트를 잘 가르지 못합니다.** 둘 다 잡으려면 c를 줄이는 것이 아니라 n을 늘려야 합니다.

## 자주 하는 실수

- "샘플에서 불량이 안 나왔으니 로트 불량률은 0%": 20개 중 0개여도 불량률 5% 로트일 확률이 충분히 있습니다([st-04-2](#/l/st-04-2)의 "고장이 0건이면" 참고).
- 로트 크기에 비례해 뽑아야 한다는 생각: 합격 확률은 로트 크기보다 **뽑는 수 n**에 거의 달려 있습니다. 500개 로트든 5,000개 로트든 20개를 뽑으면 OC 곡선이 거의 같습니다.
- 무작위로 뽑지 않기: 맨 위 상자에서만 꺼내면 [편향된 표본](#/l/st-03-1)이 되어 이 계산이 모두 틀어집니다.

## 정리

- 샘플링 검사: n개를 뽑아 불량 c개 이하면 합격. 합격 확률은 `binom.cdf(c, n, p)`.
- 로트가 작고 많이 뽑을 때는 초기하분포(`hypergeom`)가 정확하고, 뽑는 비율이 10% 미만이면 이항분포로 충분하다.
- OC 곡선은 불량률별 합격 확률이다. n이 클수록 가팔라져 좋은 로트와 나쁜 로트를 잘 가른다.
- 생산자 위험(좋은 로트 불합격)과 소비자 위험(나쁜 로트 합격)은 1종 · 2종 오류와 같은 구조다.
