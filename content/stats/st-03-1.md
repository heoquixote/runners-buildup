## 하나의 표본, 하나의 평균

공정에서 30개를 뽑아 평균을 내면 하나의 숫자가 나옵니다. 내일 또 30개를 뽑으면 조금 다른 평균이 나옵니다. 이 **표본평균들이 이루는 분포**가 표본분포입니다.

## 표준오차

표본평균의 표준편차를 표준오차(SE)라고 합니다.

SE = σ / √n

표본을 4배로 늘려야 SE가 절반이 됩니다. 측정 횟수를 정할 때 이 관계로 비용과 정밀도를 저울질합니다.

```run
import numpy as np

sigma = 0.08
for n in [4, 16, 64]:
    print(f"n={n:>3}  SE={sigma / np.sqrt(n):.3f}")
```

## 중심극한정리를 눈으로 확인하기

설비 정지 간격처럼 한쪽으로 치우친(지수분포) 데이터도, 크기 30인 표본의 평균을 여러 번 모으면 종 모양에 가까워집니다. 시드를 고정해 난수를 재현합니다.

```run
import numpy as np

rng = np.random.default_rng(0)
raw = rng.exponential(scale=10, size=5000)              # 원래 데이터: 치우침
means = rng.exponential(scale=10, size=(5000, 30)).mean(axis=1)   # 표본평균 5000개

def skew(x):
    return float(np.mean(((x - x.mean()) / x.std()) ** 3))

print("원 데이터   평균", round(raw.mean(), 2), "왜도", round(skew(raw), 2))
print("표본평균들  평균", round(means.mean(), 2), "왜도", round(skew(means), 2))
print("표본평균 표준편차", round(means.std(ddof=1), 3), "이론 SE", round(10 / np.sqrt(30), 3))
```

> 왜도(치우침 정도)가 2 근처에서 0.4 정도로 줄어듭니다. 표본평균의 표준편차는 이론값 σ/√n과 거의 같습니다.
