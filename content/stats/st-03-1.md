## 라면 맛을 확인하는 방법

라면 공장에서 오늘 만든 라면 10만 봉지가 맛이 괜찮은지 확인하려고 합니다. 10만 봉지를 다 끓여 먹어 보면 확실하겠지만, 그러면 팔 라면이 하나도 남지 않습니다. 그래서 몇십 봉지만 골라서 맛을 봅니다. 이렇게 모집단에서 일부를 골라내는 일을 **표본추출**(sampling)이라고 합니다.

전부를 보지 않는 이유는 여러 가지입니다.

- **비용 · 시간**: 전국 고등학생 수십만 명에게 설문하기는 너무 비쌉니다.
- **파괴 검사**: 라면 맛, 자동차 충돌 시험처럼 검사하면 제품이 사라집니다.
- **불가능**: 앞으로 태어날 고객, 내일 생산될 제품은 아직 볼 수 없습니다.

그런데 **어떻게** 고르느냐에 따라 결과가 크게 달라집니다. 이번 레슨에서는 좋은 표본과 나쁜 표본의 차이를 직접 확인합니다.

## 편향과 흔들림: 과녁으로 이해하기

표본으로 구한 숫자가 참값에서 벗어나는 이유는 두 가지입니다.

::figure{src="content/img/stats/st03-bias-target.svg" alt="과녁 네 개: 왼쪽 위는 화살이 가운데에 모여 있음(편향 작음, 흔들림 작음), 오른쪽 위는 한쪽 구석에 모여 있음(편향 큼, 흔들림 작음), 왼쪽 아래는 가운데 주변에 넓게 흩어짐(편향 작음, 흔들림 큼), 오른쪽 아래는 한쪽에 넓게 흩어짐(둘 다 큼)" caption="편향은 화살이 한쪽으로 꾸준히 빗나가는 것, 흔들림은 화살이 넓게 흩어지는 것입니다. 표본을 키우면 흔들림은 줄지만 편향은 그대로입니다."}

- **흔들림**(무작위 오차): 표본을 뽑을 때마다 우연히 조금씩 다르게 나오는 것. 과녁 가운데 주변에 화살이 흩어지는 모습입니다. 표본을 크게 하면 줄어듭니다.
- **편향**(bias, 치우침): 뽑는 방법 자체가 잘못되어 숫자가 **한쪽으로 꾸준히** 빗나가는 것. 과녁 한쪽 구석을 계속 맞히는 모습입니다. 표본을 아무리 크게 해도 **줄어들지 않습니다.**

## 실험: 타이타닉을 모집단으로

타이타닉 승객 891명을 **모집단 전체**라고 생각하고, 여기서 표본을 뽑아 생존율을 추정하는 실험을 합니다. 모집단 전체를 갖고 있으니 참값과 비교할 수 있습니다. 먼저 참값(모수)입니다.

```run
import pandas as pd

df = pd.read_csv("titanic.csv")
print("모집단 생존율(참값):", round(df["survived"].mean(), 3))
```

참값은 0.384입니다. 실제 조사에서는 이 값을 모르고, 표본으로 짐작해야 합니다.

## 단순 무작위 추출

가장 기본이 되는 방법은 **단순 무작위 추출**입니다. 모집단의 모든 사람이 **똑같은 확률로** 뽑히도록 고르는 방법으로, 891명의 이름을 종이에 써서 상자에 넣고 눈을 감고 100장 뽑는 것과 같습니다. pandas에서는 `df.sample(개수)`가 이 일을 합니다.

```run
import pandas as pd

df = pd.read_csv("titanic.csv")
sample = df.sample(100, random_state=1)
print("무작위 100명의 생존율:", sample["survived"].mean())
```

0.39로 참값 0.384와 아주 가깝습니다. 하지만 무작위 추출에도 흔들림은 있습니다. 직접 해 보세요: `random_state`를 0, 2, 4로 바꿔 보세요.

```run
import pandas as pd

df = pd.read_csv("titanic.csv")
for seed in [0, 2, 4]:
    print(seed, df.sample(100, random_state=seed)["survived"].mean())
```

0.43, 0.42, 0.29처럼 뽑을 때마다 다릅니다. 이것이 **흔들림**입니다. 하지만 평균적으로는 참값 0.384 주변에 흩어지고, 한쪽으로만 치우치지는 않습니다. 이 흔들림이 얼마나 큰지는 [다음 레슨](#/l/st-03-2)에서 정확히 재 봅니다.

## 편향된 표본: 1등석에서만 물어본다면

이번엔 조사원이 편하다는 이유로 **1등석 승객 근처에서만** 100명을 인터뷰했다고 해 봅시다.

```run
import pandas as pd

df = pd.read_csv("titanic.csv")
first = df[df["pclass"] == 1]
print("1등석에서만 100명:", first.sample(100, random_state=0)["survived"].mean())
```

0.55로 참값 0.384보다 훨씬 높습니다. 1등석 승객은 구명보트에 가까운 갑판 위층에 묵어서 생존율이 높았기 때문입니다. "그럼 표본을 늘리면 나아지지 않을까?" 200명으로 늘려 봅니다.

```run
import pandas as pd

df = pd.read_csv("titanic.csv")
first = df[df["pclass"] == 1]
print("1등석에서만 200명:", round(first.sample(200, random_state=0)["survived"].mean(), 3))
```

0.64로 오히려 더 멀어졌습니다. 1등석 안에서 표본이 커질수록 결과는 **1등석의 생존율(0.63)**에 다가갈 뿐, 전체 생존율(0.384)에는 절대 다가가지 않습니다. **편향은 표본 크기로 고쳐지지 않습니다.** 뽑는 방법을 고쳐야 합니다.

## 자주 만나는 편향 세 가지

| 편향 | 어떻게 생기나 | 예 |
| --- | --- | --- |
| **선택 편향** | 뽑기 쉬운 사람만 뽑힘 | 학원가 앞에서만 "하루 공부 시간" 설문 → 실제보다 높게 나옴 |
| **무응답 편향** | 대답하는 사람과 안 하는 사람이 다름 | 만족도 설문에 아주 만족하거나 아주 불만인 사람만 응답 |
| **생존자 편향** | 살아남은 것만 보고 판단 | 성공한 창업자 인터뷰만 보고 "대학을 그만두면 성공한다" |

생존자 편향에는 유명한 이야기가 있습니다. 2차 세계대전 때 미군은 돌아온 폭격기의 총알 자국을 조사해서, 구멍이 많은 날개와 꼬리에 철판을 덧대려고 했습니다. 그때 통계학자 아브라함 왈드(Abraham Wald)가 반대했습니다. "돌아온 비행기는 날개에 맞아도 **돌아올 수 있었던** 비행기입니다. 엔진에 맞은 비행기는 돌아오지 못해서 여기 없는 겁니다. 구멍이 **없는** 엔진을 보강해야 합니다."

데이터가 **어떻게 모였는지**를 묻지 않으면, 아무리 꼼꼼히 계산해도 틀린 결론이 나옵니다.

## 층화 추출: 무리별 비율 맞추기

무작위로 뽑아도 운이 나쁘면 한 무리가 너무 많이 뽑힐 수 있습니다. 앞에서 `random_state=0`으로 뽑은 100명을 등급별로 나눠 보면,

```run
import pandas as pd

df = pd.read_csv("titanic.csv")
print("모집단:", df["pclass"].value_counts(normalize=True).sort_index().round(2).to_dict())
print("무작위 100명:", df.sample(100, random_state=0)["pclass"].value_counts(normalize=True).sort_index().to_dict())
```

모집단에서 1등석은 24%인데, 이 표본에는 34%나 들어 있습니다. 그래서 생존율이 0.43으로 높게 나왔던 것입니다.

이럴 때 **층화 추출**(stratified sampling)을 씁니다. 모집단을 미리 무리(층)로 나누고, **각 무리에서 모집단 비율만큼** 따로 무작위로 뽑는 방법입니다. 1등석 24%, 2등석 21%, 3등석 55%를 그대로 맞춰서 뽑습니다.

```run
import pandas as pd

df = pd.read_csv("titanic.csv")
strat = df.groupby("pclass").sample(frac=100 / 891, random_state=0)
print("층화 100명:", strat["pclass"].value_counts(normalize=True).sort_index().to_dict())
```

등급 비율이 모집단과 똑같이 0.24, 0.21, 0.55로 맞춰졌습니다. 층화 추출은 결과에 큰 영향을 주는 무리(여기서는 등급)의 비율을 고정해 주므로, 같은 표본 크기로도 흔들림이 조금 더 작아집니다. 1,000번 반복해서 비교해 봅니다.

```run
import numpy as np
import pandas as pd

df = pd.read_csv("titanic.csv")
simple = [df.sample(100, random_state=s)["survived"].mean() for s in range(1000)]
strat = [df.groupby("pclass").sample(frac=100 / 891, random_state=s)["survived"].mean() for s in range(1000)]
print("흔들림(표준편차) 단순:", round(np.std(simple), 4), "/ 층화:", round(np.std(strat), 4))
```

단순 무작위 추출은 0.0463, 층화 추출은 0.0432로 흔들림이 조금 줄었습니다. 머신러닝에서 데이터를 학습용 · 시험용으로 나눌 때 `stratify=y`를 주는 것([ml-01](#/l/ml-01-1))도 같은 아이디어입니다.

## 자주 하는 오해

- **"데이터가 많으니 편향은 괜찮다."** 아닙니다. 1등석 200명 실험처럼, 쏠린 방법으로 모은 데이터는 많을수록 틀린 값을 더 확신하게 만들 뿐입니다.
- **"무작위로 뽑았으니 표본 숫자가 곧 정답이다."** 아닙니다. 무작위 표본도 흔들립니다. 그래서 "얼마나 흔들리는지"를 함께 말해야 하고, 그 방법이 [신뢰구간](#/l/st-04-1)입니다.

## 정리

- 표본으로 구한 숫자가 빗나가는 이유는 **흔들림**(표본을 키우면 줄어듦)과 **편향**(뽑는 방법의 문제, 표본을 키워도 안 줄어듦) 두 가지.
- **단순 무작위 추출**은 모두에게 같은 기회를 줘서 편향을 막는다.
- 선택 편향 · 무응답 편향 · 생존자 편향: 데이터가 **어떻게 모였는지**부터 묻자.
- **층화 추출**은 중요한 무리의 비율을 모집단과 맞춰 흔들림을 줄인다.
