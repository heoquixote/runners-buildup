## 법정에서 배우는 가설검정

재판에서 피고인은 **무죄로 추정**하고 시작합니다. 검사는 증거를 내놓고, 판사는 "이 사람이 정말 무죄라면, 이런 증거가 나올 수 있을까?"를 따집니다. 무죄라고 보기에는 증거가 너무 강하면 유죄를 선고하고, 증거가 부족하면 무죄를 선고합니다. 여기서 "무죄 선고"는 "결백이 증명되었다"는 뜻이 아니라 "**유죄라고 할 만큼 증거가 충분하지 않다**"는 뜻입니다.

통계의 **가설검정**(hypothesis test)이 정확히 이 구조입니다. [DAY 01](#/l/st-00-1)에서 남겨 둔 질문, "토요일과 일요일의 팁 차이(0.26달러)는 진짜 차이일까, 그냥 흔들림일까?"에 답하는 방법이 바로 가설검정입니다.

## 귀무가설과 대립가설

가설검정은 두 가설을 세우는 것으로 시작합니다.

| 이름 | 뜻 | 법정 비유 | 예 |
| --- | --- | --- | --- |
| **귀무가설** H₀ | 차이 · 효과가 **없다** (기본값, 지루한 쪽) | 무죄 추정 | 동전은 공정하다 (앞면 확률 0.5) |
| **대립가설** H₁ | 차이 · 효과가 **있다** (보이고 싶은 쪽) | 유죄 | 동전은 공정하지 않다 |

"귀무(歸無)"는 "없음으로 돌아간다"는 뜻입니다. 가설검정은 귀무가설이 맞다고 **일단 가정**하고, 그 가정 아래에서 지금 데이터가 얼마나 이상한지를 따집니다.

::figure{src="content/img/stats/st05-test-steps.svg" alt="가설검정 4단계 흐름도: 1 가설 세우기(H0 차이 없음), 2 데이터에서 통계량 계산, 3 H0가 맞는 세상에서 이런 값이 얼마나 드문지 p-value 계산, 4 p-value와 유의수준 비교해 판단" caption="가설검정 4단계. 핵심은 3단계, 'H₀가 맞는 세상'을 상상해서 지금 결과가 얼마나 드문지 재는 것입니다."}

## 예제: 이 동전은 공정할까

친구가 동전을 100번 던졌더니 앞면이 **61번** 나왔습니다. 공정한 동전이라면 50번쯤 나와야 하는데, 61번은 좀 많아 보입니다. 이 동전이 조작되었다고 말할 수 있을까요?

1. **가설**: H₀ "공정한 동전이다(앞면 확률 0.5)", H₁ "공정하지 않다"
2. **통계량**: 100번 중 앞면 수 = 61

3단계를 위해 **H₀가 맞는 세상**, 즉 공정한 동전을 컴퓨터로 만들어 100번 던져 봅니다. `rng.binomial(100, 0.5)`는 [이항분포](#/l/st-02-2)에서 하나를 뽑는 함수로, 공정한 동전 100번의 앞면 수를 줍니다.

```run
import numpy as np

rng = np.random.default_rng(0)
print("공정한 동전 100번의 앞면 수:", rng.binomial(100, 0.5))
```

51번이 나왔습니다. 이번엔 이 실험(100번 던지기)을 **10,000세트** 반복해서, 공정한 동전이라면 앞면 수가 어떻게 퍼지는지 봅니다.

```run
import matplotlib.pyplot as plt
import numpy as np

rng = np.random.default_rng(0)
heads = rng.binomial(100, 0.5, size=10_000)
plt.hist(heads, bins=range(30, 72)); plt.axvline(61, color="red"); plt.xlabel("heads in 100 tosses"); plt.show()
print("가장 적게:", heads.min(), "/ 가장 많이:", heads.max())
```

공정한 동전이라도 앞면 수는 50을 중심으로 대략 35~65 사이에서 오르내립니다. 빨간 선(61)은 오른쪽 꼬리 쪽에 있습니다. 그렇다면 공정한 동전에서 61번 **이상**이 나오는 경우는 10,000세트 중 몇 %일까요?

```run
import numpy as np

rng = np.random.default_rng(0)
heads = rng.binomial(100, 0.5, size=10_000)
print("61번 이상 나온 비율:", (heads >= 61).mean())
```

1.82%입니다. 공정한 동전이라면 100번 던져서 앞면이 61번 이상 나오는 일은 100번 중 2번도 안 되는 드문 일입니다.

## p-value: H₀ 세상에서 얼마나 드문가

방금 구한 숫자가 바로 **p-value**(유의확률)입니다.

> **p-value** = 귀무가설이 맞다고 가정했을 때, **지금 관측한 것만큼 또는 그보다 더 극단적인** 결과가 나올 확률

p-value가 작을수록 "H₀가 맞는 세상에서는 보기 드문 일이 일어났다", 즉 H₀를 의심할 이유가 크다는 뜻입니다.

한 가지 더 따져야 합니다. 대립가설은 "공정하지 **않다**"였지 "앞면이 **더 많다**"가 아니었습니다. 앞면이 39번 이하로 너무 **적게** 나와도 똑같이 공정하지 않다는 증거입니다. 그래서 양쪽 꼬리를 모두 셉니다. 50에서 11 이상 떨어진 경우(39 이하 또는 61 이상)입니다. 이것을 **양측 검정**이라고 합니다.

```run
import numpy as np

rng = np.random.default_rng(0)
heads = rng.binomial(100, 0.5, size=10_000)
print("양측 p-value (|앞면 - 50| >= 11):", (abs(heads - 50) >= 11).mean())
```

양측 p-value는 약 0.037입니다. 시뮬레이션 없이 정확한 값을 계산해 주는 함수도 있습니다. `stats.binomtest(성공 수, 시행 수, 확률)`입니다.

```run
from scipy import stats

print("binomtest p-value:", round(stats.binomtest(61, 100, 0.5).pvalue, 4))
```

정확한 양측 p-value는 0.0352로, 시뮬레이션 결과와 거의 같습니다.

## 유의수준과 판단

p-value가 "얼마나 작아야" H₀를 버릴까요? 이 기준을 데이터를 보기 **전에** 미리 정해 두는데, 이것을 **유의수준** α(알파)라고 합니다. 대부분의 분야에서 **α = 0.05**를 씁니다.

| 결과 | 판단 | 쓰는 문장 |
| --- | --- | --- |
| p-value < α | 귀무가설을 **기각한다** | "통계적으로 유의한 차이가 있다" |
| p-value ≥ α | 귀무가설을 **기각하지 못한다** | "유의한 차이를 확인하지 못했다" |

동전 예에서 p = 0.035 < 0.05이므로 "공정한 동전이라는 가설을 기각한다. 이 동전은 공정하지 않다고 볼 근거가 있다"고 판단합니다.

직접 해 보세요: 앞면이 **55번** 나왔다면 어떨까요? 아래 셀의 숫자를 바꿔 보세요.

```run
from scipy import stats

heads = 55
p = stats.binomtest(heads, 100, 0.5).pvalue
print("앞면", heads, "번 → p-value", round(p, 4), "→", "기각" if p < 0.05 else "기각하지 못함")
```

55번이면 p-value가 0.368로 0.05보다 훨씬 큽니다. 공정한 동전에서도 37% 정도는 이 정도 치우침이 나오니, 이것만으로 조작을 의심할 수는 없습니다. "기각하지 못함"입니다.

## p-value에 대한 오해 세 가지

p-value는 통계에서 가장 많이 잘못 해석되는 숫자입니다.

1. **"p = 0.035니까 H₀가 맞을 확률이 3.5%다."** ❌ p-value는 "H₀가 맞다고 **가정했을 때** 이런 데이터가 나올 확률"입니다. 가설이 맞을 확률이 아닙니다. [베이즈 정리](#/l/st-09-2)에서 본 "P(A | B) ≠ P(B | A)"와 같은 함정입니다.
2. **"p-value가 작을수록 효과가 크다."** ❌ p-value는 표본 크기에 크게 좌우됩니다. 표본이 아주 크면 아주 작은 차이도 p-value가 작게 나옵니다. 효과의 크기는 차이 자체와 신뢰구간으로 따로 말해야 합니다([DAY 10](#/l/st-08-2)).
3. **"기각하지 못했으니 차이가 없다는 게 증명되었다."** ❌ 법정의 무죄 선고처럼, "차이가 있다고 할 증거가 부족하다"는 뜻일 뿐입니다. 표본이 작아서 못 잡았을 수도 있습니다([다음 레슨](#/l/st-05-2)).

## 실데이터: 토요일 vs 일요일 팁, 순열 검정

이제 처음 질문으로 돌아갑니다. 토요일 계산서 87장과 일요일 76장의 평균 팁 차이는 0.26달러였습니다.

- H₀: 요일은 팁과 관계없다 (차이는 우연)
- H₁: 요일에 따라 평균 팁이 다르다

H₀가 맞다면 "토요일", "일요일"이라는 이름표는 아무 의미가 없으니, **이름표를 마구 섞어서 다시 붙여도** 비슷한 차이가 나와야 합니다. 이름표를 섞어 차이를 구하는 일을 5,000번 반복하면 "H₀ 세상의 차이 분포"를 만들 수 있습니다. 이 방법을 **순열 검정**(permutation test)이라고 합니다. 먼저 실제 차이를 구합니다.

```run
import pandas as pd

df = pd.read_csv("tips.csv").query("day in ['Sat', 'Sun']")
g = df.groupby("day")["tip"].mean()
print("일요일 - 토요일:", round(g["Sun"] - g["Sat"], 3), "달러")
```

이제 이름표를 섞어서, 섞은 차이가 실제 차이(0.262)만큼 또는 더 크게 벌어지는 비율을 셉니다.

```run
import numpy as np
import pandas as pd

df = pd.read_csv("tips.csv").query("day in ['Sat', 'Sun']")
tip, sun, rng = df["tip"].to_numpy(), (df["day"] == "Sun").to_numpy(), np.random.default_rng(0)
diffs = np.array([tip[s].mean() - tip[~s].mean() for s in (rng.permutation(sun) for _ in range(5000))])
print("순열 검정 p-value:", (abs(diffs) >= 0.262).mean())
```

p-value는 약 0.26입니다. 요일과 팁이 아무 관계가 없더라도, 이름표를 아무렇게나 붙였을 때 이 정도 차이는 4번에 1번꼴로 나온다는 뜻입니다. 0.05보다 훨씬 크므로 **귀무가설을 기각하지 못합니다.** "이 데이터로는 토요일과 일요일 팁이 다르다고 말할 근거가 부족하다"가 결론입니다. 차이가 **없다**는 것을 증명한 것은 아니라는 점도 함께 기억하세요.

## 실무 예제: 진짜 차이가 있어도 "기각하지 못함"이 나온다

설비 10,000대 전체를 보면 고장 설비는 정상 설비보다 공구를 평균 37분 더 썼습니다([대표값: 평균 · 중앙값 · 최빈값](#/l/st-01-1)). 이 차이는 진짜로 있는 차이입니다. 그런데 현실에서 고장 설비 30대, 정상 설비 30대만 조사했다면 검정은 무엇이라고 답할까요? 같은 순열 검정을 해 봅니다.

```run
import pandas as pd

df = pd.read_csv("ai4i2020.csv")
fail = df.query("failure == 1")["tool_wear"].sample(30, random_state=0)
ok = df.query("failure == 0")["tool_wear"].sample(30, random_state=0)
print("고장 30대:", round(fail.mean(), 1), "분 / 정상 30대:", round(ok.mean(), 1), "분 / 차이:", round(fail.mean() - ok.mean(), 1), "분")
```

30대씩 뽑은 표본에서도 차이가 35.3분으로 크게 나왔습니다. 이름표를 5,000번 섞어 p-value를 구합니다.

```run
import numpy as np
import pandas as pd

df = pd.read_csv("ai4i2020.csv")
x = np.concatenate([df.query("failure == 1")["tool_wear"].sample(30, random_state=0), df.query("failure == 0")["tool_wear"].sample(30, random_state=0)])
lab, rng = np.array([1] * 30 + [0] * 30), np.random.default_rng(0)
diffs = np.array([x[p == 1].mean() - x[p == 0].mean() for p in (rng.permutation(lab) for _ in range(5000))])
print("p-value:", (abs(diffs) >= 35.33).mean())
```

p-value는 0.062로 0.05보다 큽니다. 규칙대로라면 "귀무가설을 기각하지 못한다"입니다. 하지만 우리는 전체 데이터를 알고 있어서 **진짜 차이가 있다**는 것을 압니다. 공구 사용 시간은 0 ~ 250분으로 아주 넓게 퍼져 있어서(표준편차 약 64분), 30대씩으로는 35분 차이도 흔들림에 묻힐 수 있었던 것입니다.

그래서 이 결과는 이렇게 보고해야 합니다.

> 고장 설비의 공구 사용 시간이 35분 길었지만(30대 vs 30대), 이 표본 크기로는 우연과 구분할 만큼 확실하지 않았다(p = 0.06). 더 많은 설비로 확인이 필요하다.

"차이가 없다"고 쓰면 틀린 보고입니다. 표본이 작으면 진짜 차이도 놓칠 수 있다는 것, 이것이 다음 레슨의 **2종 오류와 검정력** 이야기입니다.

## 자주 하는 실수

1. **p = 0.06을 "효과 없음"으로, p = 0.04를 "효과 있음"으로 정반대로 해석한다.** 두 결과의 증거 강도는 거의 같습니다. 0.05는 판단을 위한 선일 뿐, 그 양쪽이 질적으로 다른 세상은 아닙니다.
2. **결과를 본 뒤 α를 바꾼다.** p = 0.07이 나오자 "α = 0.1로 하자"고 바꾸면 검정의 의미가 사라집니다. α는 데이터를 보기 전에 정합니다.
3. **p-value만 적고 차이의 크기를 빠뜨린다.** "유의했다(p < 0.05)"만으로는 차이가 1분인지 35분인지 알 수 없습니다.

## 정리

- 가설검정은 **귀무가설 H₀(차이 없음)을 일단 가정**하고, 그 아래에서 지금 데이터가 얼마나 드문지 따진다.
- **p-value** = H₀가 맞을 때 지금만큼 또는 더 극단적인 결과가 나올 확률.
- 미리 정한 **유의수준 α**(보통 0.05)보다 p-value가 작으면 H₀를 **기각**, 크면 **기각하지 못함**.
- 방향을 따지지 않으면 양쪽 꼬리를 모두 세는 **양측 검정**.
- p-value는 H₀가 맞을 확률도, 효과의 크기도 아니다. 기각하지 못함 ≠ 차이 없음 증명.
