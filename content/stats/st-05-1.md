## 가설검정의 뼈대

1. **귀무가설 H0**: 차이가 없다 (평균이 30분이다, 개선 전후가 같다)
2. **대립가설 H1**: 차이가 있다 (또는 크다 / 작다)
3. H0가 맞다고 가정했을 때 지금 데이터만큼 극단적인 결과가 나올 확률 = **p-value**
4. p-value < 유의수준(보통 0.05)이면 H0를 기각

## 세 가지 t검정

| 상황 | 함수 |
| --- | --- |
| 한 집단 평균 vs 기준값 | `stats.ttest_1samp(x, 기준값)` |
| 서로 다른 두 집단 | `stats.ttest_ind(a, b, equal_var=False)` |
| 같은 대상의 전후 · 두 측정 | `stats.ttest_rel(전, 후)` |

```run
import numpy as np
from scipy import stats

before = np.array([42.1, 43.5, 41.8, 44.2, 42.9, 43.1])
after = np.array([40.8, 41.5, 40.2, 42.0, 41.1, 40.6])
res = stats.ttest_ind(before, after, equal_var=False)
print("Welch t =", round(res.statistic, 3), "p =", f"{res.pvalue:.5f}")
print("기각" if res.pvalue < 0.05 else "기각 못 함")
```

## 대응표본이면 대응표본으로

같은 시편을 두 측정기로 쟀다면 시편끼리의 차이는 빼고 봐야 합니다. 독립 2표본으로 검정하면 그 차이가 잡음으로 섞여 p-value가 커집니다.

```run
import numpy as np
from scipy import stats

a = np.array([10.02, 9.98, 10.05, 10.01, 9.97, 10.03])
b = a + np.array([0.02, 0.01, 0.03, 0.01, 0.03, 0.02])
print("독립으로 잘못 검정 p =", round(stats.ttest_ind(a, b).pvalue, 4))
print("대응표본 p          =", f"{stats.ttest_rel(b, a).pvalue:.5f}")
```

## 단측검정

"개선 후가 **더 짧다**"처럼 방향이 정해진 질문은 `alternative`로 지정합니다. 첫 번째 인자 기준으로 `'greater'`, `'less'`.

```run
import numpy as np
from scipy import stats

mins = np.array([31, 35, 29, 38, 33, 30, 36, 34, 28, 37])
print("양측 p", round(stats.ttest_1samp(mins, 30).pvalue, 4))
print("단측 p (30보다 크다)", round(stats.ttest_1samp(mins, 30, alternative="greater").pvalue, 4))
```

> p-value가 크다고 "차이가 없다"가 증명되는 것은 아닙니다. 표본이 작으면 실제 차이를 놓칠 수 있습니다(제2종 오류, 검정력).
