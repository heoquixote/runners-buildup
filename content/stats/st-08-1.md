## A/B 테스트의 뼈대

1. **가설**: 새 버튼(B)이 기존(A)보다 구매 전환율이 높다
2. **무작위 배정**: 방문자를 무작위로 A/B에 나눠 다른 조건을 같게 만든다
3. **표본 수를 먼저 정한다**: 검출하고 싶은 최소 효과와 검정력으로 계산
4. **끝까지 모은 뒤 한 번 판정**: p-value, 신뢰구간, 효과 크기

공정 변경 전후 비교도 같은 틀입니다. 다만 공정은 시간에 따라 원자재·설비 상태가 바뀌므로 가능하면 **같은 기간에 나란히** 돌려 비교합니다.

## 두 비율 비교

전환율, 불량률처럼 비율을 비교할 때는 2표본 비율 z검정을 씁니다.

- 합동 비율 p̄ = (x₁ + x₂) / (n₁ + n₂)
- z = (p̂₁ − p̂₂) / √(p̄(1 − p̄)(1/n₁ + 1/n₂))
- 양측 p-value = 2 · P(Z > |z|)

```run
import numpy as np
from scipy import stats

conv_a, n_a = 120, 2400
conv_b, n_b = 156, 2400
p_a, p_b = conv_a / n_a, conv_b / n_b
pp = (conv_a + conv_b) / (n_a + n_b)
z = (p_b - p_a) / np.sqrt(pp * (1 - pp) * (1 / n_a + 1 / n_b))
print("A", p_a, " B", p_b, " lift", round((p_b - p_a) / p_a, 3))
print("z =", round(z, 3), " p =", round(2 * stats.norm.sf(abs(z)), 4))
se = np.sqrt(p_a * (1 - p_a) / n_a + p_b * (1 - p_b) / n_b)
print("95% CI of diff:", round(p_b - p_a - 1.96 * se, 4), "~", round(p_b - p_a + 1.96 * se, 4))
```

p-value보다 **신뢰구간**이 더 많은 것을 알려 줍니다. 차이가 0.2%p~2.8%p 사이라면, 0.2%p 상승도 사업적으로 의미가 있는지 함께 판단해야 합니다.

## 두 가지 오류와 검정력

| | 실제로 차이 없음 | 실제로 차이 있음 |
| --- | --- | --- |
| 유의하다고 판정 | 1종 오류 α (거짓 경보) | 검정력 1 − β |
| 유의하지 않다고 판정 | 옳은 판단 | 2종 오류 β (놓침) |

표본이 작으면 실제 차이가 있어도 놓치기 쉽습니다. 아래는 실제 평균 차이가 0.05mm(σ = 0.1)일 때 집단당 표본 수에 따른 검정력입니다.

```run
import numpy as np
from scipy import stats

delta, sigma = 0.05, 0.1
z_a = stats.norm.ppf(0.975)
for n in [10, 30, 63, 100]:
    se = sigma * np.sqrt(2 / n)
    power = stats.norm.cdf(delta / se - z_a)
    print(f"n = {n:>3} per group -> power {power:.2f}")
```

## 표본 수는 실험 전에

필요한 표본 수 n은 효과 크기 δ의 제곱에 반비례합니다. 효과를 절반 크기로 잡아내려면 표본이 4배 필요합니다.

```run
import numpy as np
from scipy import stats

def n_per_group(p1, p2, alpha=0.05, power=0.8):
    z_a, z_b = stats.norm.ppf(1 - alpha / 2), stats.norm.ppf(power)
    pbar = (p1 + p2) / 2
    n = (z_a * np.sqrt(2 * pbar * (1 - pbar)) + z_b * np.sqrt(p1 * (1 - p1) + p2 * (1 - p2))) ** 2 / (p2 - p1) ** 2
    return int(np.ceil(n))

for p2 in [0.07, 0.06, 0.055]:
    print(f"5% -> {p2:.1%}: {n_per_group(0.05, p2):,} per group")
```

> 실험 도중 매일 p-value를 보다가 0.05 아래로 내려간 날 멈추면, 실제 효과가 없어도 "유의"가 나올 확률이 5%보다 훨씬 커집니다. 정한 표본 수를 다 모은 뒤 판정하세요.
