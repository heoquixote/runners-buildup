## 여러 개씩 잴 때와 불량을 셀 때

[지난 레슨](#/l/st-11-1)의 I-MR 관리도는 값을 하나씩 잴 때 썼습니다. 현장에서는 두 가지 경우가 더 흔합니다.

| 상황 | 관리도 | 찍는 값 |
| --- | --- | --- |
| 한 시간마다 부품 **5개씩** 뽑아 치수를 잰다 | **X̄-R 관리도** | 5개의 평균(X̄)과 범위(R) |
| 하루마다 검사해서 **불량 개수**를 센다 | **p 관리도** | 그날의 불량률 |

치수처럼 숫자로 재는 값을 **계량값**, 불량 · 양품처럼 세는 값을 **계수값**이라고 합니다. 계량값은 X̄-R, 계수값은 p 관리도를 씁니다.

## X̄-R 관리도: 묶음(부분군)으로 보기

한 번에 뽑는 5개를 **부분군**(subgroup)이라고 합니다. 부분군 하나에서 두 가지를 계산합니다.

- **X̄**(엑스바): 5개의 평균. 공정의 **중심**이 옮겨 갔는지 본다
- **R**: 5개 중 최댓값 − 최솟값. 공정의 **흔들림**이 커졌는지 본다

평균을 쓰면 [중심극한정리](#/l/st-03-3) 덕분에 X̄가 정규분포에 가까워지고, 흔들림도 √5배 줄어 작은 이동도 잘 잡힙니다. 관리한계는 표준 상수표의 값을 씁니다. 부분군 크기 5일 때 상수는 다음과 같습니다.

| 관리도 | 중심선 | 관리한계 |
| --- | --- | --- |
| X̄ 관리도 | X̄의 평균 | X̄의 평균 ± **0.577** × R 평균 |
| R 관리도 | R 평균 | 하한 **0** × R 평균, 상한 **2.114** × R 평균 |

0.577, 0.000, 2.114는 부분군 크기마다 정해진 상수(A₂, D₃, D₄)입니다. 원리는 I-MR과 같아서 "R 평균으로 σ를 추정하고 ±3σ를 만든다"를 미리 계산해 둔 숫자입니다.

25시간 동안 매시간 5개씩 잰 축 지름(mm) 데이터입니다.

```run
import numpy as np

rng = np.random.default_rng(5)
X = rng.normal(25.0, 0.1, (25, 5))     # 25개 부분군 × 5개
X[17] += 0.25                          # 18번째 시간에 무슨 일이 생겼다고 가정

xbar = X.mean(axis=1)
r = X.max(axis=1) - X.min(axis=1)
xbb, rbar = xbar.mean(), r.mean()
print("X̄ 중심선:", round(xbb, 4), "/ 한계:", round(xbb - 0.577 * rbar, 4), "~", round(xbb + 0.577 * rbar, 4))
print("R 중심선:", round(rbar, 4), "/ 상한:", round(2.114 * rbar, 4))
```

[2차원 집계와 표준화](#/l/da-02-2)에서 배운 `axis=1`로 부분군(행)마다 평균과 범위를 구했습니다. X̄ 관리한계는 24.871 ~ 25.113, R 관리 상한은 0.443입니다.

```run
import numpy as np
import matplotlib.pyplot as plt

rng = np.random.default_rng(5)
X = rng.normal(25.0, 0.1, (25, 5))
X[17] += 0.25
xbar = X.mean(axis=1)
r = X.max(axis=1) - X.min(axis=1)
xbb, rbar = xbar.mean(), r.mean()
idx = np.arange(1, 26)

fig, (ax1, ax2) = plt.subplots(2, 1, figsize=(7, 5), sharex=True)
ax1.plot(idx, xbar, marker="o")
for y in [xbb - 0.577 * rbar, xbb, xbb + 0.577 * rbar]:
    ax1.axhline(y, color="gray", linestyle="--")
ax1.set_ylabel("X-bar (mm)")
ax1.set_title("X-bar and R chart (subgroup size 5)")
ax2.plot(idx, r, marker="o", color="darkorange")
for y in [rbar, 2.114 * rbar]:
    ax2.axhline(y, color="gray", linestyle="--")
ax2.set_ylabel("Range (mm)")
ax2.set_xlabel("Hour")
fig.tight_layout()

print("X̄ 한계 밖:", (np.where((xbar > xbb + 0.577 * rbar) | (xbar < xbb - 0.577 * rbar))[0] + 1).tolist())
print("R 한계 밖:", (np.where(r > 2.114 * rbar)[0] + 1).tolist())
```

X̄ 관리도에서 18번째 시간이 상한을 넘었고, R 관리도에는 신호가 없습니다. "5개가 **다 함께** 커졌다(중심 이동)"는 뜻이지 "들쭉날쭉해졌다(흔들림 증가)"는 뜻이 아닙니다. 그 시간에 설정값이 바뀌었는지, 원료가 바뀌었는지부터 찾습니다. 두 관리도를 함께 보면 원인의 종류가 좁혀집니다.

| X̄ 신호 | R 신호 | 의심 |
| --- | --- | --- |
| 있음 | 없음 | 중심이 옮겨 감 (설정, 원료, 지그) |
| 없음 | 있음 | 흔들림이 커짐 (설비 진동, 체결 풀림, 작업자 교대) |
| 있음 | 있음 | 둘 다. R부터 안정시킨 뒤 X̄를 다시 본다 |

## p 관리도: 불량률을 관리하기

매일 400개씩 검사해서 불량 개수를 센다면, 그날의 불량률 p를 찍습니다. 불량 개수는 [이항분포](#/l/st-02-2)를 따르므로 불량률의 표준편차는 √(p̄(1 − p̄)/n)이고, 관리한계는

> p̄ ± 3 × √(p̄ × (1 − p̄) ÷ n)

입니다. 하한이 음수가 나오면 0으로 둡니다. 설비 데이터 1만 건을 순서대로 400건씩 25묶음으로 나눠, 묶음마다 고장률을 찍어 봅니다.

```run
import numpy as np
import pandas as pd

df = pd.read_csv("ai4i2020.csv")
block = np.arange(len(df)) // 400                 # 0~24번 묶음
p = df.groupby(block)["failure"].mean()

pbar, n = df["failure"].mean(), 400
se = np.sqrt(pbar * (1 - pbar) / n)
ucl, lcl = pbar + 3 * se, max(0, pbar - 3 * se)
print("p̄:", round(pbar, 4), "/ 한계:", round(lcl, 4), "~", round(ucl, 4))
print("한계 밖 묶음:", (np.where(p > ucl)[0] + 1).tolist(), p[p > ucl].round(4).tolist())
```

평균 고장률 3.39%, 관리 상한 6.1%인데 11번째와 12번째 묶음(4,001 ~ 4,800번째 기록)의 고장률이 14.75%, 15.25%로 상한의 두 배가 넘습니다. 그 구간에 무슨 일이 있었는지 다른 열을 봅니다.

```run
import numpy as np
import pandas as pd

df = pd.read_csv("ai4i2020.csv")
df["temp_gap"] = df["process_temp"] - df["air_temp"]     # 공정 온도 − 공기 온도
block = np.arange(len(df)) // 400
gap = df.groupby(block)["temp_gap"].mean().round(2)
print("전체 평균 온도 차:", round(df["temp_gap"].mean(), 2))
print("묶음 10~13:", gap.iloc[9:13].tolist())
```

평소 공정 온도와 공기 온도의 차이는 10K인데, 문제 구간인 11 · 12번 묶음은 8.46K, 8.08K로 줄어 있습니다. 앞뒤 묶음(8.98K)도 평소보다 낮아, 이 무렵 온도 차가 줄었다가 회복된 흐름이 보입니다. 공기 온도가 올라 설비 열이 잘 빠지지 못한 것입니다. 이 데이터에는 실제로 "온도 차가 작으면 열 방출 고장"이라는 고장 유형이 들어 있습니다. 관리도가 **언제** 문제가 생겼는지 짚어 주면, 그 시점의 다른 기록에서 **왜**를 찾습니다.

> 관리한계를 정할 때 이상 구간까지 넣어 계산했습니다. 원래는 원인을 확인한 뒤 11 · 12번 묶음을 빼고 다시 계산합니다. 빼고 계산하면 p̄는 2.38%, 상한은 4.67%로 더 좁아집니다.

## 자주 하는 실수

- 부분군 안에 성격이 다른 것을 섞기: 서로 다른 설비 두 대의 부품을 한 부분군에 넣으면 R이 커져 한계가 넓어지고 신호를 놓칩니다. 부분군은 "같은 조건에서 짧은 시간 안에" 뽑습니다.
- X̄만 보고 R을 안 보기: 흔들림이 커지는 것도 중요한 이상 신호입니다.
- 검사 수가 날마다 다른데 같은 한계 쓰기: p 관리도의 n이 바뀌면 한계도 날마다 다시 계산합니다(검사가 적은 날은 한계가 넓어짐).

## 정리

- 계량값을 여러 개씩 재면 X̄-R 관리도, 불량을 세면 p 관리도.
- X̄ 관리도는 중심 이동을, R 관리도는 흔들림 증가를 잡는다. 둘을 함께 보면 원인이 좁혀진다.
- 부분군 크기 5의 상수: X̄ 한계 ± 0.577 × R 평균, R 상한 2.114 × R 평균.
- p 관리도 한계는 p̄ ± 3√(p̄(1 − p̄)/n). 신호가 난 시점의 다른 기록에서 원인을 찾는다.
