## 공식이 없는 숫자의 신뢰구간

[지난 레슨](#/l/st-04-2)에서 평균과 비율의 신뢰구간을 공식으로 구했습니다. "평균 ± t 배수 × 표준오차"였습니다. 그런데 실무에서는 평균 말고 다른 숫자를 보고할 때가 많습니다.

- 요금처럼 한쪽으로 크게 치우친 데이터는 평균보다 **중앙값**을 보고합니다
- 품질에서는 "상위 10% 토크"처럼 **분위수**를 봅니다
- 두 그룹의 **중앙값 차이**를 말하고 싶을 때도 있습니다

이런 숫자들은 표준오차 공식이 복잡하거나 아예 없습니다. 이때 쓰는 방법이 **부트스트랩**(bootstrap)입니다. 공식 대신 컴퓨터로 표본을 수천 번 다시 뽑아서, 그 숫자가 얼마나 흔들리는지 직접 봅니다.

## 아이디어: 표본을 모집단처럼 쓴다

[표본평균의 분포와 표준오차](#/l/st-03-2)에서는 모집단에서 표본을 여러 번 뽑아 표본평균이 얼마나 흔들리는지 봤습니다. 현실에서는 모집단이 없고 표본 하나뿐입니다. 부트스트랩은 **가진 표본을 모집단 대신** 놓고 거기서 다시 뽑습니다.

1. 표본 n개에서 **복원추출**로 n개를 뽑는다 (같은 값이 여러 번 뽑힐 수 있음)
2. 뽑은 묶음으로 원하는 숫자(중앙값 등)를 계산한다
3. 1~2를 수천 번 반복해 숫자들의 분포를 만든다
4. 그 분포의 가운데 95%(2.5% ~ 97.5% 지점)를 신뢰구간으로 쓴다

복원추출은 주머니에서 공을 꺼내 기록하고 **다시 넣은 뒤** 또 꺼내는 방식입니다. 그래서 다시 뽑은 묶음마다 어떤 값은 두 번, 어떤 값은 0번 들어가 조금씩 다른 표본이 됩니다.

```run
import numpy as np

x = np.array([1.01, 1.66, 3.50, 3.31, 3.61])
rng = np.random.default_rng(0)
for i in range(3):
    print(np.sort(rng.choice(x, size=len(x), replace=True)))
```

값 5개에서 5개를 복원추출했더니 묶음마다 겹치는 값과 빠진 값이 다릅니다. `replace=True`가 복원추출이라는 뜻입니다.

## 먼저 평균으로 확인하기

부트스트랩이 믿을 만한지, 공식이 있는 평균으로 먼저 비교해 봅니다. 팁 244건으로 2,000번 다시 뽑아 평균을 구합니다.

```run
import numpy as np
import pandas as pd

tip = pd.read_csv("tips.csv")["tip"].to_numpy()
rng = np.random.default_rng(0)
means = np.array([rng.choice(tip, size=len(tip), replace=True).mean() for _ in range(2000)])

print("부트스트랩 SE:", round(means.std(ddof=1), 4))
print("95% 구간:", np.percentile(means, [2.5, 97.5]).round(3))
```

부트스트랩 표준오차 0.0876은 지난 레슨에서 공식으로 구한 0.0886과 거의 같고, 구간 2.833~3.176도 t 구간 2.824~3.173과 거의 겹칩니다. 공식이 있는 경우에 같은 답을 내니, 공식이 없는 경우에도 믿고 쓸 수 있습니다.

## 중앙값의 신뢰구간: 타이타닉 요금

타이타닉 요금은 평균 32.2, 중앙값 14.45로 차이가 큽니다. 몇몇 비싼 표가 평균을 끌어올렸기 때문입니다([대표값: 평균 · 중앙값 · 최빈값](#/l/st-01-1)). 이럴 때 보고하는 중앙값의 신뢰구간을 구해 봅니다.

```run
import numpy as np
import pandas as pd

fare = pd.read_csv("titanic.csv")["fare"].to_numpy()
rng = np.random.default_rng(0)
meds = np.array([np.median(rng.choice(fare, size=len(fare), replace=True)) for _ in range(2000)])

print("표본 중앙값:", round(np.median(fare), 2))
print("95% 구간:", np.percentile(meds, [2.5, 97.5]).round(2))
```

> 해석: 승객 요금의 중앙값은 14.45이고, 95% 부트스트랩 신뢰구간은 13.0 ~ 15.5다.

평균을 보고했다면 "평균 32.2"라는, 대부분 승객과 동떨어진 숫자를 말할 뻔했습니다. 무엇을 보고할지는 데이터 모양으로 정하고, 그 숫자가 무엇이든 부트스트랩으로 구간을 붙일 수 있습니다.

## 실무 예제: 상위 10% 토크의 신뢰구간

설비 50대만 측정해서 "토크 상위 10% 경계(90번째 백분위수)"를 보고해야 한다고 해 봅시다. 설비 1만 대 데이터에서 50대를 뽑아 표본으로 씁니다.

```run
import numpy as np
import pandas as pd

df = pd.read_csv("ai4i2020.csv")
x = df.sample(50, random_state=1)["torque"].to_numpy()
rng = np.random.default_rng(0)
p90 = np.array([np.quantile(rng.choice(x, size=len(x), replace=True), 0.9) for _ in range(2000)])

print("표본 P90:", round(np.quantile(x, 0.9), 2))
print("95% 구간:", np.percentile(p90, [2.5, 97.5]).round(2))
print("전체 1만 대 P90:", round(df["torque"].quantile(0.9), 2))
```

표본 50대의 P90은 50.57이고 95% 구간은 46.49 ~ 53.62입니다. 폭이 7 가까이 됩니다. 실제 1만 대의 P90(52.6)은 이 구간 안에 있습니다. 꼬리 쪽 분위수는 그 근처 값이 몇 개 안 돼서 평균보다 훨씬 많이 흔들립니다. **50대로 상한 규격을 정하기에는 불확실성이 크다**는 판단을 숫자로 할 수 있습니다.

## 두 그룹의 차이에도 쓴다

점심과 저녁의 팁 **중앙값 차이**에도 구간을 붙일 수 있습니다. 두 그룹을 **각각** 복원추출해 차이를 계산하는 일을 반복합니다.

```run
import numpy as np
import pandas as pd

df = pd.read_csv("tips.csv")
dinner = df[df["time"] == "Dinner"]["tip"].to_numpy()
lunch = df[df["time"] == "Lunch"]["tip"].to_numpy()
rng = np.random.default_rng(0)
diffs = np.array([np.median(rng.choice(dinner, len(dinner))) - np.median(rng.choice(lunch, len(lunch)))
                  for _ in range(2000)])

print("중앙값 차이:", np.median(dinner) - np.median(lunch))
print("95% 구간:", np.percentile(diffs, [2.5, 97.5]).round(2))
```

`rng.choice`는 `replace`를 생략하면 복원추출이 기본입니다. 저녁 팁 중앙값이 점심보다 0.75달러 높고, 95% 구간은 0.23 ~ 1.01입니다. 구간에 0이 들어 있지 않으니 "저녁 팁이 더 높다"고 말할 근거가 됩니다. t검정([세 가지 t검정](#/l/st-05-3))이 평균을 비교했다면, 부트스트랩은 중앙값처럼 원하는 숫자로 같은 판단을 하게 해 줍니다.

## 자주 하는 실수

| 실수 | 바로잡기 |
| --- | --- |
| 비복원추출(`replace=False`)로 다시 뽑기 | 그러면 매번 원래 표본과 같은 값들이 됩니다. 반드시 복원추출 |
| 반복 횟수 100번 | 구간 끝(2.5%, 97.5%)이 불안정합니다. 최소 1,000번, 보고용은 2,000번 이상 |
| 표본이 아주 작은데(10개 미만) 부트스트랩 | 표본에 없는 값은 절대 나오지 않아서 구간이 너무 좁아집니다 |
| 편향된 표본에 부트스트랩 | 부트스트랩은 **흔들림**만 보여 줍니다. 표본이 한쪽으로 치우쳤다면([표본 뽑기와 편향](#/l/st-03-1)) 구간도 같이 치우칩니다 |
| 시드를 고정하지 않기 | 실행할 때마다 구간 끝자리가 바뀝니다. 보고서에는 시드와 반복 횟수를 적습니다 |

## 정리

- 부트스트랩: 가진 표본에서 복원추출을 수천 번 반복해 숫자의 흔들림을 직접 본다.
- 평균에서는 공식과 같은 답을 내고, 중앙값 · 분위수 · 차이처럼 공식이 없는 숫자에도 쓸 수 있다.
- 구간은 반복 결과의 2.5% ~ 97.5% 백분위수로 만든다(백분위수 방법).
- 표본이 작거나 편향되어 있으면 부트스트랩도 구해 주지 못한다.
