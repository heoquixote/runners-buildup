## 대응 데이터의 검정 모음

같은 대상을 두 번 이상 재면 **대응(paired)** 데이터가 됩니다. [세 가지 t검정](#/l/st-05-3)의 대응 t검정과 [윌콕슨 부호순위 검정](#/l/st-06-3)이 그 예였습니다. 이번 레슨은 대응 데이터에서 나머지 빈칸을 채웁니다.

| 결과의 종류 | 두 번 측정 | 세 번 이상 측정 |
| --- | --- | --- |
| 숫자 (정규에 가까움) | 대응 t검정 | 반복측정 ANOVA |
| 숫자 (치우침 · 순위) | 윌콕슨 부호순위, **부호검정** | **프리드먼 검정** |
| 범주 (예/아니오) | **McNemar 검정** | 코크란 Q 검정 |

굵게 쓴 세 가지를 배웁니다. 공통 원리는 하나입니다. **대상마다의 차이(변화)만 본다.** 대상끼리의 원래 차이(어떤 설비는 원래 진동이 크다)는 비교에서 빼 버리기 때문에, 독립 그룹 검정보다 훨씬 예민하게 변화를 잡습니다.

## McNemar 검정: 같은 대상의 예/아니오가 바뀌었나

머신러닝에서 바로 쓰이는 예로 시작합니다. 타이타닉 시험용 승객 223명에게 **로지스틱 회귀**와 **랜덤포레스트**가 각각 맞혔는지(O/X)를 기록합니다. 같은 승객을 두 모델이 판정했으니 대응 데이터입니다.

```run
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression
from sklearn.ensemble import RandomForestClassifier

df = pd.read_csv("titanic.csv")
df["female"] = (df["sex"] == "female").astype(int)
df["age"] = df["age"].fillna(df["age"].median())
X = df[["pclass", "female", "age", "sibsp", "parch", "fare"]]
y = df["survived"]
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.25, random_state=0, stratify=y)
logit_ok = make_pipeline(StandardScaler(), LogisticRegression()).fit(X_train, y_train).predict(X_test) == y_test
forest_ok = RandomForestClassifier(300, min_samples_leaf=3, random_state=0).fit(X_train, y_train).predict(X_test) == y_test
print("accuracy: logistic", round(logit_ok.mean(), 3), "/ forest", round(forest_ok.mean(), 3))
print(pd.crosstab(logit_ok.rename("logistic correct"), forest_ok.rename("forest correct")))
```

| | 숲 X | 숲 O |
| --- | --- | --- |
| 로지스틱 X | 30 | **20** |
| 로지스틱 O | **10** | 163 |

정확도는 로지스틱 0.776, 숲 0.821로 4.5%p 차이입니다. 숲이 더 좋은 모델일까요?

McNemar의 아이디어는 **둘 다 맞힌 163명, 둘 다 틀린 30명은 두 모델의 차이에 대해 아무것도 말해 주지 않는다**는 것입니다. 차이는 **판정이 갈린 30명**(굵은 칸)에서만 나옵니다. 숲만 맞힌 승객 20명, 로지스틱만 맞힌 승객 10명입니다. 두 모델의 실력이 같다면 갈린 승객은 반반(15 대 15)으로 나뉘어야 합니다.

`χ² = (|b − c| − 1)² ÷ (b + c)`  (b, c = 판정이 갈린 두 칸, −1은 연속성 보정)

갈린 사람 수가 적을 때는 "30명 중 10명 이하가 한쪽일 확률"을 이항분포로 정확히 계산합니다.

```run
from scipy import stats

b, c = 10, 20   # logistic only correct, forest only correct
chi2 = (abs(b - c) - 1) ** 2 / (b + c)
print("McNemar chi2 =", round(chi2, 2), ", p =", round(stats.chi2.sf(chi2, 1), 4))
print("exact McNemar (binomial) p =", round(stats.binomtest(b, b + c, 0.5).pvalue, 4))
```

χ² = 2.70, p = 0.100이고, 정확한 이항검정도 p = 0.099입니다. **정확도 4.5%p 차이는 시험용 223명으로는 우연과 구별되지 않습니다.** 판정이 갈린 승객이 30명뿐이라서입니다. 모델 비교표에서 정확도 몇 %p 차이로 "숲이 낫다"고 단정하기 전에 McNemar로 확인하는 습관이 필요합니다.

:::tip 알아 두면 좋아요 · 왜 독립 2비율 검정을 쓰면 안 될까
두 정확도 0.776과 0.821을 [2비율 z검정](#/l/st-12-1)으로 비교하면, 두 비율이 **서로 다른 223명씩**에서 나왔다고 가정하게 됩니다. 실제로는 같은 223명이라 두 결과가 강하게 연결돼 있습니다(193명은 판정이 같음). 연결을 무시하면 흔들림을 잘못 계산합니다. 교육 전후 합격률, 같은 부품을 두 검사원이 판정한 결과, 같은 환자의 두 진단법 비교가 모두 McNemar 상황입니다.
:::

## 부호검정: 방향만 센다

정비 전후 설비 10대의 소음(dB)입니다. 한 대는 측정기 오류로 값이 크게 튀었습니다.

```run
import numpy as np
from scipy import stats

before = np.array([72.1, 70.4, 75.3, 71.8, 69.9, 73.2, 74.0, 70.8, 71.5, 72.6])
after = np.array([70.3, 69.8, 73.1, 71.9, 68.2, 71.0, 72.2, 69.9, 70.1, 95.0])  # last one: sensor glitch?
diff = after - before
n_down = (diff < 0).sum()
print("differences:", diff.round(1))
print("machines got quieter:", n_down, "of", len(diff))
print("sign test p =", round(stats.binomtest(n_down, len(diff), 0.5).pvalue, 4))
print("Wilcoxon p  =", round(stats.wilcoxon(before, after).pvalue, 4))
print("paired t p  =", round(stats.ttest_rel(before, after).pvalue, 4))
```

**부호검정**은 차이의 크기를 버리고 **+인지 −인지**만 셉니다. 정비 효과가 없다면 조용해질 확률은 반반이므로, "10대 중 몇 대가 조용해졌나"는 이항분포 B(10, 0.5)를 따릅니다.

- 10대 중 8대가 조용해졌고(1대는 +0.1, 1대는 +22.4), 부호검정 p = 0.109입니다.
- 윌콕슨(순위 사용)은 p = 0.106으로 비슷하고, 대응 t검정(평균 사용)은 p = 0.688입니다.
- 이상치 +22.4 하나가 평균 차이를 거꾸로 뒤집고(평균 +1.0dB) 표준편차를 부풀려서 t검정은 아무것도 잡지 못했습니다. 부호검정은 22.4도 그냥 "+1개"로 세서 흔들리지 않습니다.

이 데이터는 10대뿐이라 어느 검정도 5% 기준을 넘지 못했지만, 부호검정이 가장 이상치에 강하다는 것은 분명합니다. 대신 크기 정보를 모두 버려서 **검정력은 가장 낮습니다.** 차이가 "좋아졌다 / 나빠졌다"로만 기록된 데이터(설문의 개선 여부 등)에 특히 알맞습니다.

| 검정 | 쓰는 정보 | 이상치 | 검정력 (가정이 맞을 때) |
| --- | --- | --- | --- |
| 대응 t | 차이의 값 | 약함 | 가장 높음 |
| 윌콕슨 부호순위 | 차이의 순위 + 부호 | 강함 | 중간 |
| 부호검정 | 차이의 부호만 | 가장 강함 | 가장 낮음 |

## 프리드먼 검정: 같은 대상, 세 조건 이상

같은 대상을 세 가지 이상 조건에서 잰 데이터입니다. 대표 예가 **교차검증 점수 비교**입니다. 10-fold 교차검증에서 같은 10개 조각(fold)으로 네 모델을 평가하면, 조각이 "대상"이고 모델이 "조건"입니다. 조각마다 난이도가 다르니(어떤 조각은 다들 점수가 낮음) 대응 구조를 살려야 합니다.

```run
import pandas as pd
from scipy import stats
from sklearn.model_selection import StratifiedKFold, cross_val_score
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression
from sklearn.tree import DecisionTreeClassifier
from sklearn.ensemble import RandomForestClassifier
from sklearn.neighbors import KNeighborsClassifier

df = pd.read_csv("titanic.csv")
df["female"] = (df["sex"] == "female").astype(int)
df["age"] = df["age"].fillna(df["age"].median())
X = df[["pclass", "female", "age", "sibsp", "parch", "fare"]]
y = df["survived"]
cv = StratifiedKFold(10, shuffle=True, random_state=0)
models = {"logistic": make_pipeline(StandardScaler(), LogisticRegression()),
          "tree": DecisionTreeClassifier(max_depth=4, random_state=0),
          "forest": RandomForestClassifier(300, min_samples_leaf=3, random_state=0),
          "knn": make_pipeline(StandardScaler(), KNeighborsClassifier(15))}
scores = pd.DataFrame({name: cross_val_score(m, X, y, cv=cv) for name, m in models.items()})
print(scores.round(3))
print("mean:", scores.mean().round(3).to_dict())
print("mean rank (1 = best):", scores.rank(axis=1, ascending=False).mean().to_dict())
res = stats.friedmanchisquare(*[scores[c] for c in scores])
print("Friedman chi2 =", round(res.statistic, 2), ", p =", round(res.pvalue, 4))
```

프리드먼 검정은 **조각마다** 네 모델에 1 ~ 4등 순위를 매긴 뒤, 모델별 평균 순위가 고르게 2.5 근처인지 봅니다. 차이가 없다면 어떤 모델도 늘 1등이거나 늘 꼴찌일 수 없기 때문입니다.

- 평균 순위는 숲 1.45, 트리 2.15, KNN 2.85, 로지스틱 3.55입니다.
- 프리드먼 χ² = 15.98, p = 0.0011로 "네 모델의 성능이 모두 같지는 않다"고 판단합니다.

ANOVA 뒤에 사후검정을 했듯이, 프리드먼이 유의하면 **어느 쌍**이 다른지 봅니다. 쌍마다 윌콕슨 부호순위 검정을 하고, 여러 번 검정했으니 p-value를 보정합니다.

```run
import itertools
import pandas as pd
from scipy import stats
from sklearn.model_selection import StratifiedKFold, cross_val_score
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression
from sklearn.tree import DecisionTreeClassifier
from sklearn.ensemble import RandomForestClassifier
from sklearn.neighbors import KNeighborsClassifier

df = pd.read_csv("titanic.csv")
df["female"] = (df["sex"] == "female").astype(int)
df["age"] = df["age"].fillna(df["age"].median())
X = df[["pclass", "female", "age", "sibsp", "parch", "fare"]]
y = df["survived"]
cv = StratifiedKFold(10, shuffle=True, random_state=0)
models = {"logistic": make_pipeline(StandardScaler(), LogisticRegression()),
          "tree": DecisionTreeClassifier(max_depth=4, random_state=0),
          "forest": RandomForestClassifier(300, min_samples_leaf=3, random_state=0),
          "knn": make_pipeline(StandardScaler(), KNeighborsClassifier(15))}
scores = pd.DataFrame({name: cross_val_score(m, X, y, cv=cv) for name, m in models.items()})
pairs = list(itertools.combinations(scores.columns, 2))
for a, b in pairs:
    p = stats.wilcoxon(scores[a], scores[b]).pvalue
    print(f"{a:>8} vs {b:<8}: p {p:.4f}, Bonferroni p {min(1, p * len(pairs)):.4f}")
```

쌍이 6개라 Bonferroni 보정은 p-value에 6을 곱합니다. 보정 후에도 5% 아래로 남는 것은 **숲 vs 로지스틱(0.012)** 하나뿐입니다. 트리 vs 로지스틱(보정 전 0.011)은 보정 후 0.067로 올라갑니다. 보정 방법은 [여러 번 검정할 때](#/l/st-12-6)에서 자세히 배웁니다.

:::tip 알아 두면 좋아요 · 교차검증 점수 비교의 한계
교차검증의 조각들은 학습 데이터를 서로 많이 공유해서 완전히 독립이 아닙니다. 그래서 조각 점수로 한 검정은 p-value가 실제보다 조금 작게 나오는 경향이 있습니다. 결론을 "숲이 로지스틱보다 확실히 낫다"보다는 "숲이 일관되게 앞선다(10조각 평균 순위 1.45)"처럼 조심스럽게 쓰고, 최종 결론은 따로 떼어 둔 시험용 데이터로 확인합니다.
:::

## 자주 하는 실수

| 실수 | 무슨 일이 생기나 | 바로잡기 |
| --- | --- | --- |
| 같은 시험용으로 잰 두 모델 정확도를 2비율 z검정 | 대응을 무시해 흔들림을 잘못 계산 | McNemar |
| 정확도 표만 보고 "4.5%p 높으니 더 좋은 모델" | 갈린 사례가 30건이면 우연일 수 있음 (p = 0.10) | McNemar로 확인, 표본을 늘림 |
| 조각별 점수를 일원 ANOVA · 크루스칼로 비교 | 조각 난이도 차이가 잡음으로 섞여 검정력 손해 | 대응 구조를 살린 프리드먼 |
| 프리드먼 뒤 쌍 비교를 보정 없이 | 헛발견이 쌓임 | Bonferroni · Holm 보정 |

## 정리

- 대응 검정은 **대상마다의 변화만** 봅니다. 그래서 대상 간 원래 차이를 빼고 예민하게 비교합니다.
- **McNemar**: 판정이 갈린 칸(b, c)만 비교합니다. 로지스틱 vs 숲은 정확도 4.5%p 차이였지만 갈린 30건이 10 대 20이라 p = 0.10이었습니다.
- **부호검정**: 차이의 +/−만 세는 이항검정입니다. 이상치에 가장 강하고 검정력은 가장 낮습니다.
- **프리드먼**: 대상(조각)마다 조건(모델)에 순위를 매겨 비교합니다. 네 모델 χ² = 15.98, p = 0.0011. 유의하면 쌍별 윌콕슨 + 보정으로 어디가 다른지 봅니다.
