## 아이스크림이 물놀이 사고를 일으킨다?

어느 해 여름, 한 도시의 데이터를 보니 **아이스크림 판매량이 많은 날일수록 물놀이 사고도 많았습니다.** 상관계수가 0.8이 넘습니다. 그럼 아이스크림 판매를 금지하면 사고가 줄어들까요?

물론 아닙니다. 두 숫자 모두 **더운 날씨** 때문에 함께 올라간 것입니다. 더우면 아이스크림을 많이 사 먹고, 더우면 물놀이를 많이 가니까요. 아이스크림과 사고 사이에는 아무런 원인 관계가 없습니다.

이번 트랙에서 계속 "상관은 인과가 아니다"라고 말했습니다. 이번 레슨에서는 그 말이 정확히 무슨 뜻인지, 그리고 실제 데이터에서 숫자는 맞는데 결론이 거꾸로 뒤집히는 **심슨의 역설**을 직접 확인합니다.

## 함께 움직이는 세 가지 다른 이유

두 변수 X와 Y가 함께 움직일 때, X가 Y의 원인이라는 것 말고도 적어도 세 가지 다른 설명이 있습니다.

::figure{src="content/img/stats/st10-confounder.svg" alt="교란변수 삼각형: 위 꼭짓점 '더운 날씨'에서 아래 왼쪽 '아이스크림 판매'와 아래 오른쪽 '물놀이 사고'로 각각 화살표가 내려가고, 아래 두 꼭짓점 사이에는 점선과 물음표로 '상관은 있지만 원인 아님'이 표시된 그림" caption="숨은 공통 원인(교란변수)이 두 변수를 동시에 움직이면, 둘 사이에 원인 관계가 없어도 강한 상관이 나타납니다."}

| 이유 | 설명 | 예 |
| --- | --- | --- |
| **교란변수** (숨은 공통 원인) | 제3의 변수가 X와 Y를 동시에 움직임 | 더위 → 아이스크림, 더위 → 물놀이 사고 |
| **역인과** (방향이 반대) | 사실은 Y가 X의 원인 | "소방차가 많이 출동한 화재일수록 피해가 크다" → 피해가 커서 소방차가 많이 온 것 |
| **우연** | 비교를 많이 하다 보면 아무 관계 없는 것끼리도 맞아떨어짐 | 어느 나라 치즈 소비량과 침대 시트에 엉켜 사망한 사람 수 |

그리고 이것들을 다 걸러 내고 남았을 때 비로소 **X가 Y의 원인**일 가능성을 이야기할 수 있습니다.

## 실데이터 ①: 펭귄 부리의 길이와 깊이

[st-07-1](#/l/st-07-1)의 상관 행렬에서 펭귄의 부리 길이와 부리 깊이(두께)의 상관이 −0.24였습니다. "부리가 길수록 얇다"는 뜻일까요? 다시 계산해 봅니다.

```run
import pandas as pd

df = pd.read_csv("penguins.csv").dropna(subset=["bill_length_mm", "bill_depth_mm"])
print("전체 상관계수:", round(df["bill_length_mm"].corr(df["bill_depth_mm"]), 3))
```

펭귄 342마리 전체로 보면 r = −0.235, 약한 **음의** 상관입니다. 이번엔 **종별로 나눠서** 상관계수를 구해 봅니다.

```run
import pandas as pd

df = pd.read_csv("penguins.csv").dropna(subset=["bill_length_mm", "bill_depth_mm"])
for sp, g in df.groupby("species"):
    print(f"{sp:10s} r = {g['bill_length_mm'].corr(g['bill_depth_mm']):.3f}")
```

Adelie 0.391, Chinstrap 0.654, Gentoo 0.643. **세 종 모두 양의 상관**입니다. 같은 종 안에서는 부리가 길수록 **두껍습니다.** 몸집이 큰 펭귄일수록 부리가 길고 두꺼운 것이니 자연스러운 결과입니다. 그런데 셋을 합쳤더니 부호가 **음수로 뒤집혔습니다.**

## 그림으로 보는 심슨의 역설

종별로 색을 칠한 산점도 위에, 전체 데이터로 구한 회귀직선(검은색)을 그려 봅니다.

```run
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd

df = pd.read_csv("penguins.csv").dropna(subset=["bill_length_mm", "bill_depth_mm"])
for sp, g in df.groupby("species"):
    plt.scatter(g["bill_length_mm"], g["bill_depth_mm"], s=10, label=sp)
b, a = np.polyfit(df["bill_length_mm"], df["bill_depth_mm"], 1)
plt.plot([32, 60], [a + b * 32, a + b * 60], color="black"); plt.legend(); plt.xlabel("bill length"); plt.ylabel("bill depth"); plt.show()
print("전체 직선의 기울기:", round(b, 3))
```

색깔별로 보면 세 무리 모두 오른쪽 위로 올라가는 띠인데, 무리 전체를 관통하는 검은 직선은 오른쪽 아래로 내려갑니다(기울기 −0.085). 이유는 종마다 **위치가 다르기** 때문입니다. Adelie는 부리가 짧고 두꺼운(왼쪽 위) 무리, Gentoo는 부리가 길고 얇은(오른쪽 아래) 무리입니다. 무리를 섞으면 "왼쪽 위 무리 → 오른쪽 아래 무리" 방향의 차이가 무리 안의 관계를 덮어 버립니다.

::figure{src="content/img/stats/st10-simpson.svg" alt="세 개의 점 무리가 왼쪽 위, 가운데, 오른쪽 아래로 놓여 있고, 각 무리 안에는 오른쪽 위로 올라가는 짧은 선이 그려져 있다. 세 무리 전체를 관통하는 긴 점선은 오른쪽 아래로 내려간다" caption="심슨의 역설: 그룹 안에서는 모두 +인 관계가, 그룹을 합치면 −로 뒤집힐 수 있습니다. 그룹(종)이 x와 y 모두에 영향을 주는 교란변수이기 때문입니다."}

이처럼 **그룹별로 나눠 본 결론과 합쳐서 본 결론이 정반대가 되는 현상**을 **심슨의 역설**(Simpson's paradox)이라고 합니다. 여기서 종(species)은 부리 길이와 부리 깊이 모두에 영향을 주는 **교란변수**입니다. 무엇이 "진짜" 관계일까요? 종이 다른 펭귄을 섞어서 비교하는 것은 의미가 없으니, 이 경우에는 **종 안에서의 관계(양의 상관)**가 우리가 알고 싶은 관계입니다.

## 실데이터 ②: 비싼 표가 생존의 원인일까

타이타닉에서 요금(`fare`)과 생존(`survived`)의 상관을 봅니다.

```run
import pandas as pd

df = pd.read_csv("titanic.csv")
print("요금 · 생존 상관계수:", round(df["fare"].corr(df["survived"]), 3))
```

r = 0.257로 양의 상관입니다. 비싼 표를 산 승객이 더 많이 살아남았습니다. 그렇다면 "같은 3등석이라도 돈을 더 냈으면 살 확률이 높아졌을까?" 등급별로 나눠 봅니다.

```run
import pandas as pd

df = pd.read_csv("titanic.csv")
for pc, g in df.groupby("pclass"):
    print(f"{pc}등석: 평균 요금 {g['fare'].mean():6.1f} / 생존율 {g['survived'].mean():.3f} / 등급 안 상관 {g['fare'].corr(g['survived']):.3f}")
```

1등석은 평균 요금 84.2에 생존율 0.630, 3등석은 13.7에 0.242입니다. 그런데 **같은 등급 안에서** 요금과 생존의 상관은 1등석 0.191, 2등석 0.099, 3등석 0.001로 크게 약해지고, 3등석에서는 아예 사라집니다. 요금 자체가 생존을 높인 것이 아니라, **객실 등급**이 요금(1등석은 비쌈)과 생존(1등석은 구명보트가 있는 갑판 가까이에 있었음) 모두에 영향을 준 교란변수였던 것입니다.

직접 해 보세요: 탑승 항구(`embarked`)별 생존율을 구해 보면 C(Cherbourg) 항구가 0.554로 가장 높습니다. 그럼 C 항구에서 탄 것이 생존에 도움이 된 걸까요? 아래 셀로 항구별 등급 구성을 확인해 보세요.

```run
import pandas as pd

df = pd.read_csv("titanic.csv")
print(df.groupby("embarked")["survived"].mean().round(3))
print(pd.crosstab(df["embarked"], df["pclass"], normalize="index").round(2))
```

C 항구 승객은 51%가 1등석이었고, Q 항구는 94%가 3등석이었습니다. 항구별 생존율 차이의 상당 부분은 항구가 아니라 **누가 그 항구에서 탔는지**(등급 구성)로 설명됩니다.

## 인과를 말하려면

그렇다면 "X가 Y의 원인이다"라고 말하려면 어떻게 해야 할까요?

1. **무작위 실험**: 가장 강력한 방법입니다. [A/B 테스트](#/l/st-08-1)처럼 X를 무작위로 배정하면 교란변수가 두 그룹에 고르게 섞여서, 남는 차이는 X 때문이라고 말할 수 있습니다.
2. **층별로 나눠 보기**: 실험을 할 수 없다면(타이타닉을 다시 띄울 수는 없으니까요), 의심되는 교란변수(종, 등급)로 데이터를 나눠서 관계가 그대로인지 확인합니다. 지금 레슨에서 한 방법입니다.
3. **여러 변수를 함께 고려한 모델**: 다중회귀처럼 교란변수를 함께 넣어 "다른 조건이 같을 때"의 관계를 봅니다([ml-02](#/l/ml-02-1)). 다만 우리가 재지 않은 교란변수는 여전히 숨어 있을 수 있습니다.

## 상관을 발견했을 때의 체크리스트

데이터에서 "X와 Y가 함께 움직인다"는 결과를 봤다면, 결론을 내리기 전에 네 가지를 물어보세요.

1. **숨은 변수**: X와 Y를 동시에 움직일 만한 제3의 변수는 없나? 그 변수로 나눠 보면 관계가 유지되나?
2. **방향**: 혹시 Y가 X의 원인은 아닐까?
3. **우연**: 수많은 조합 중에 우연히 맞아떨어진 것은 아닐까? 다른 데이터에서도 재현되나?
4. **선택 편향**: 데이터가 모인 방식 때문에 생긴 관계는 아닐까? ([생존자 편향](#/l/st-03-1))

## 실무 예제: 혼자 탄 승객은 왜 덜 살아남았나

타이타닉에서 혼자 탄 승객(`alone`)과 일행과 함께 탄 승객의 생존율을 비교합니다.

```run
import pandas as pd

df = pd.read_csv("titanic.csv")
print(df.groupby("alone")["survived"].mean().round(3))
```

혼자 탄 승객은 30.4%, 일행이 있는 승객은 50.6%가 생존했습니다. "혼자면 도와줄 사람이 없어서 덜 살아남았다"는 이야기가 그럴듯하게 들립니다. 그런데 혼자 탄 승객은 누구였을까요? 성별 구성을 봅니다.

```run
import pandas as pd

df = pd.read_csv("titanic.csv")
print(pd.crosstab(df["alone"], df["sex"], normalize="index").round(2))
print(df.groupby(["sex", "alone"])["survived"].mean().unstack().round(2))
```

혼자 탄 승객의 77%가 남성이었고, 일행이 있는 승객은 47%만 남성이었습니다. 성별로 나눠서 다시 보면, **남성**은 혼자일 때 16%, 일행이 있을 때 27%로 혼자가 낮지만, **여성**은 혼자일 때 79%, 일행이 있을 때 71%로 오히려 혼자가 높습니다. 전체에서 본 20%p 차이의 상당 부분은 "혼자 = 대부분 남성"이라는 구성 차이에서 나온 것입니다. 성별이 혼자 여부와 생존 모두에 영향을 준 **교란변수**입니다.

이 분석에서 끝이 아닙니다. 등급(`pclass`)도 혼자 여부, 생존과 관련이 있을 수 있습니다. 교란변수 후보는 하나씩 나눠서 확인하고, 여러 개를 함께 다루려면 [다중회귀나 로지스틱 회귀](#/l/ml-02-1)를 씁니다.

## 자주 하는 실수

1. **그럴듯한 이야기를 먼저 만들고 데이터를 끼워 맞춘다.** "혼자라서 도움을 못 받았다"는 이야기는 데이터를 성별로 나누기 전까지만 그럴듯했습니다.
2. **층을 너무 잘게 나눈다.** 성별 × 등급 × 나이대 × 혼자 여부로 나누면 칸마다 몇 명밖에 남지 않아 비율이 크게 흔들립니다. 칸마다 인원수를 함께 봅니다.
3. **교란변수를 통제했다고 인과가 증명되었다고 말한다.** 잰 변수만 통제할 수 있습니다. 재지 않은 교란변수는 여전히 남아 있을 수 있습니다.

## 정리

- 상관이 있어도 **교란변수**(숨은 공통 원인), **역인과**, **우연** 때문일 수 있다.
- **심슨의 역설**: 그룹별 관계와 전체 관계가 반대로 나올 수 있다(펭귄 부리: 종 안에서는 +, 전체는 −).
- 교란변수가 의심되면 **그 변수로 나눠서** 관계가 유지되는지 확인한다(타이타닉 요금 → 등급별로 보면 관계가 약해짐).
- 인과를 말하는 가장 확실한 방법은 **무작위 실험**이다.
