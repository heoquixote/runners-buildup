## 관계에도 검정이 필요하다

[공분산과 상관계수](#/l/st-07-1)에서 r을 계산하고 [회귀 결과 읽기와 진단](#/l/st-07-3)에서 기울기의 p-value를 봤습니다. 이번 레슨은 "관계"를 검정하는 방법을 한자리에 모읍니다.

1. 상관계수 r이 0과 다른가? (**피어슨 상관 검정**)과 r의 신뢰구간
2. 직선이 아니어도 한 방향으로 움직이는 관계는? (**스피어만 · 켄달** 순위상관)
3. 회귀모형 전체가 의미 있는가? (**회귀 F검정**)

## 피어슨 상관 검정: r도 표본에 따라 흔들린다

설비 30대만 뽑아 공구 마모 시간과 토크의 상관을 보면 r = 0.20이 나옵니다. 약하지만 양의 관계가 있는 것일까요? 귀무가설 "모집단 상관 ρ = 0" 아래에서 아래 값은 자유도 n − 2인 t분포를 따릅니다.

`t = r × √(n − 2) ÷ √(1 − r²)`

r이 크거나 표본이 클수록 t가 커집니다. 직접 계산하고 `stats.pearsonr`과 비교합니다.

```run
import numpy as np
import pandas as pd
from scipy import stats

df = pd.read_csv("ai4i2020.csv")
s = df.sample(30, random_state=0)
res = stats.pearsonr(s["tool_wear"], s["torque"])
r, n = res.statistic, len(s)
t = r * np.sqrt(n - 2) / np.sqrt(1 - r ** 2)
print("r =", round(r, 3), ", t =", round(t, 3), ", p (by hand) =", round(2 * stats.t.sf(abs(t), n - 2), 4), ", p (pearsonr) =", round(res.pvalue, 4))
ci = res.confidence_interval()
print(f"95% CI for rho: {ci.low:.3f} ~ {ci.high:.3f}")
print("all 10,000 machines: r =", round(stats.pearsonr(df["tool_wear"], df["torque"]).statistic, 4))
```

- 30대에서 r = 0.20이지만 p = 0.289로 0과 다르다고 할 수 없습니다.
- 신뢰구간이 −0.17 ~ 0.52로 넓습니다. 30개로는 "음의 약한 관계"부터 "꽤 강한 양의 관계"까지 모두 가능하다는 뜻입니다.
- 실제로 1만 대 전체의 상관은 r = −0.003, 사실상 0입니다. 30대의 0.20은 우연이었습니다.

r의 신뢰구간은 r을 **피셔 z 변환**(z = ½ ln((1 + r)/(1 − r)))으로 정규분포에 가깝게 편 뒤 구간을 구하고 다시 되돌립니다. 그래서 구간이 r을 중심으로 대칭이 아닙니다.

## 표본이 크면: 유의하지만 쓸모없는 상관

반대 경우도 있습니다. 1만 대 전체에서 공기 온도와 회전수의 상관을 봅니다.

```run
import pandas as pd
from scipy import stats

df = pd.read_csv("ai4i2020.csv")
res = stats.pearsonr(df["air_temp"], df["rpm"])
print("n =", len(df), ", r =", round(res.statistic, 4), ", r^2 =", round(res.statistic ** 2, 5), ", p =", round(res.pvalue, 4))
```

r = 0.023, p = 0.023으로 "유의"합니다. 하지만 r² = 0.0005, 즉 공기 온도는 회전수 흔들림의 **0.05%** 를 설명합니다. 표본이 1만 개면 0.02 같은 미세한 상관도 0과 구별되기 때문입니다. 상관 검정의 p-value는 "0인가 아닌가"만 답하므로, **r의 크기와 신뢰구간**을 함께 보고 실질적인 의미를 판단합니다.

| | 30대, 마모 vs 토크 | 1만 대, 공기 온도 vs 회전수 |
| --- | --- | --- |
| r | 0.20 | 0.023 |
| p | 0.289 (유의하지 않음) | 0.023 (유의함) |
| 실제 의미 | 판단할 정보가 부족 | 관계가 있긴 하지만 무시할 만큼 작음 |

## 순위상관: 스피어만과 켄달

피어슨 r은 **직선** 관계의 세기만 잽니다. 회전수와 토크처럼 휘어진 관계([다항회귀](#/l/ml-02-7)에서 본 반비례 모양)는 한 방향으로 확실히 움직여도 r이 덜 크게 나옵니다. 이럴 때 값 대신 **순위**로 상관을 봅니다.

- **스피어만 ρ**: 두 변수를 각각 순위로 바꾼 뒤 피어슨 r을 계산합니다. "한쪽이 커질 때 다른 쪽이 꾸준히 커지는(작아지는)가"를 잽니다. 직선이 아니어도 **단조**(한 방향) 관계면 ±1에 가까워집니다.
- **켄달 τ**: 모든 두 대씩 짝을 지어, 두 변수의 순서가 **같은 방향인 짝(일치)** 과 **반대 방향인 짝(불일치)** 을 셉니다. τ = (일치 − 불일치) ÷ 전체 짝 수.

```run
import pandas as pd
from scipy import stats

df = pd.read_csv("ai4i2020.csv")
x, y = df["rpm"], df["torque"]
pear, spear, kend = stats.pearsonr(x, y).statistic, stats.spearmanr(x, y).statistic, stats.kendalltau(x, y).statistic
print(f"Pearson r {pear:.3f} | Spearman rho {spear:.3f} | Kendall tau {kend:.3f}")
print(f"share of machine pairs moving in opposite directions: {(1 - kend) / 2:.3f}")
```

- 피어슨 −0.875, 스피어만 **−0.916**입니다. 휘어진 관계라서 순위로 본 스피어만이 관계의 세기를 더 잘 잡습니다.
- 켄달 τ = −0.757은 "설비 두 대를 아무렇게나 골랐을 때 87.9%의 짝에서 회전수가 빠른 쪽이 토크가 작다"는 뜻으로 바로 읽힙니다. 켄달 τ는 값의 크기가 스피어만보다 작게 나오는 것이 보통이라, 두 값을 서로 비교하지 않습니다.

| | 피어슨 r | 스피어만 ρ | 켄달 τ |
| --- | --- | --- | --- |
| 재는 것 | 직선 관계 | 단조 관계 (순위) | 순서가 일치하는 짝의 비율 |
| 이상치 | 약함 | 강함 | 강함 |
| 알맞은 데이터 | 연속 · 정규에 가까움 | 순서형, 치우친 값, 휘어진 관계 | 표본이 작거나 같은 순위가 많을 때 |
| 해석 | r² = 설명된 분산 비율 | 순위끼리의 r | (1 + τ)/2 = 순서 일치 확률 |

## 회귀 F검정: 모형 전체가 의미 있나

회귀 결과에는 계수마다의 t검정과 별도로 **모형 전체의 F검정**이 나옵니다. 귀무가설은 "모든 기울기가 0이다", 즉 "x들이 y를 전혀 설명하지 못한다"입니다.

`F = (R² ÷ k) ÷ ((1 − R²) ÷ (n − k − 1))`  (k = x의 개수)

설명된 몫(R²)과 설명되지 않은 몫(1 − R²)을 각자의 자유도로 나눠 비교하는, [ANOVA](#/l/st-06-2)와 같은 신호 ÷ 잡음 구조입니다.

```run
import pandas as pd
import statsmodels.formula.api as smf

df = pd.read_csv("tips.csv")
simple = smf.ols("tip ~ total_bill", data=df).fit()
print("simple: F =", round(simple.fvalue, 2), ", t^2 =", round(simple.tvalues["total_bill"] ** 2, 2), ", p =", f"{simple.f_pvalue:.1e}")
multi = smf.ols("tip ~ total_bill + size", data=df).fit()
r2, k, n = multi.rsquared, 2, len(df)
print("multiple: R^2 =", round(r2, 3), ", F =", round(multi.fvalue, 2), ", by hand =", round((r2 / k) / ((1 - r2) / (n - k - 1)), 2))
print(multi.pvalues.round(4))
```

- 단순회귀(계산 금액 하나)에서는 **F = t² = 203.36**입니다. x가 하나면 "모형 전체가 의미 있나"와 "그 기울기가 0이 아닌가"가 같은 질문입니다.
- 다중회귀(계산 금액 + 인원)는 R² = 0.468, F = 105.95로, 공식으로 계산한 값과 같습니다. 모형 전체는 확실히 의미 있습니다.
- 개별 계수의 p-value를 보면 계산 금액은 매우 강하고(p ≈ 0), 인원은 p = 0.025로 약합니다. **F검정이 유의해도 모든 변수가 유의한 것은 아닙니다.** F는 "적어도 하나는 0이 아니다"라는 뜻입니다.

## 자주 하는 실수

| 실수 | 무슨 일이 생기나 | 바로잡기 |
| --- | --- | --- |
| p < 0.05인 상관을 "강한 관계"로 보고 | r = 0.023도 1만 개면 유의 | r, r², 신뢰구간을 함께 |
| 30개로 구한 r = 0.20을 믿고 판단 | 신뢰구간이 −0.17 ~ 0.52 | 표본을 늘리거나 구간을 보고 |
| 휘어진 관계에 피어슨만 봄 | 관계의 세기를 과소평가 | 산점도를 보고 스피어만 |
| F검정 유의 → "모든 변수가 중요" | F는 적어도 하나가 0이 아니라는 뜻 | 계수별 t검정과 신뢰구간 |
| 상관이 유의하니 원인이라고 해석 | 교란변수 가능성 | [상관과 인과, 심슨의 역설](#/l/st-10-1) |

## 정리

- **피어슨 상관 검정**: t = r√(n − 2)/√(1 − r²). 30대의 r = 0.20은 p = 0.289, 신뢰구간 −0.17 ~ 0.52였고 실제 상관은 0이었습니다.
- 표본이 크면 r = 0.023도 유의합니다(p = 0.023, r² = 0.05%). p-value보다 **r의 크기와 신뢰구간**을 봅니다.
- **스피어만**은 순위의 피어슨 r(단조 관계), **켄달**은 순서 일치 짝의 비율입니다. 회전수 · 토크는 피어슨 −0.875, 스피어만 −0.916, 켄달 −0.757이었습니다.
- **회귀 F검정**은 "모든 기울기 = 0"을 검정합니다. 단순회귀에서는 F = t²(203.36)이고, F가 유의해도 개별 변수는 따로 확인합니다.
