## 가장 유명한 곡선

고등학교 남학생의 키, 같은 기계로 만든 과자 봉지의 무게, 측정할 때마다 생기는 작은 오차. 이런 값들의 히스토그램을 그리면 놀랍게도 비슷한 모양이 나옵니다. 가운데가 가장 높고, 양쪽으로 갈수록 대칭으로 낮아지는 **종 모양**입니다. 이 모양의 확률분포를 **정규분포**(normal distribution)라고 합니다.

정규분포가 이렇게 자주 나오는 이유는 **작은 영향이 아주 많이 더해진 값**이 이 모양이 되기 때문입니다. 키는 유전자 수천 개, 먹은 음식, 잠잔 시간 같은 수많은 작은 요인이 더해진 결과입니다. 이 성질은 [DAY 05의 중심극한정리](#/l/st-03-3)에서 다시 만납니다.

## 평균과 표준편차 두 숫자로 정해진다

정규분포는 단 두 숫자로 모양이 완전히 정해집니다.

- **평균 μ**(뮤): 종의 **가운데 위치**
- **표준편차 σ**(시그마): 종의 **넓이** (클수록 납작하고 넓게 퍼짐)

N(μ, σ²)라고 쓰기도 합니다. `scipy.stats`에서는 `stats.norm(loc=평균, scale=표준편차)`로 만듭니다. 평균은 같고 표준편차가 다른 두 곡선을 그려 봅니다.

```run
import matplotlib.pyplot as plt
import numpy as np
from scipy import stats

x = np.linspace(140, 200, 200)
plt.plot(x, stats.norm(170, 6).pdf(x), label="sd 6"); plt.plot(x, stats.norm(170, 10).pdf(x), label="sd 10")
plt.legend(); plt.show()
print("두 곡선 아래 넓이:", round(stats.norm(170, 6).cdf(200) - stats.norm(170, 6).cdf(140), 4))
```

두 곡선 모두 170에서 가장 높지만, 표준편차가 10인 곡선이 더 납작하고 넓습니다. 곡선 아래 넓이는 언제나 1(100%)이라서, 넓게 퍼지면 그만큼 키가 낮아집니다. `pdf`는 곡선의 높이(확률밀도)를 주는 메서드입니다.

## 68 - 95 - 99.7 규칙

정규분포에는 꼭 외워 둘 만한 규칙이 있습니다.

::figure{src="content/img/stats/st02-normal-rule.svg" alt="정규분포 곡선 아래에 평균 ±1 표준편차 구간 68%, ±2 표준편차 구간 95%, ±3 표준편차 구간 99.7%가 겹친 띠로 표시된 그림" caption="평균에서 표준편차 1개 안에 약 68%, 2개 안에 약 95%, 3개 안에 약 99.7%가 들어갑니다."}

- 평균 ± 1σ 안에 약 **68%**
- 평균 ± 2σ 안에 약 **95%**
- 평균 ± 3σ 안에 약 **99.7%**

키가 N(170, 6²)를 따른다면, 164~176cm 사이에 약 68%, 158~182cm 사이에 약 95%가 있습니다. 170 ± 3 × 6 = 152~188cm 밖에 있는 사람은 1,000명 중 3명 정도뿐입니다. [st-01-3](#/l/st-01-3)의 "|z| > 3이면 이상치 후보" 규칙이 여기서 나왔습니다.

정규분포에서 난수 10,000개를 뽑아 규칙이 맞는지 확인해 봅니다. `rng.normal(평균, 표준편차, 개수)`로 뽑습니다.

```run
import numpy as np

rng = np.random.default_rng(0)
z = rng.normal(0, 1, 10_000)
print("±1σ:", (abs(z) < 1).mean(), "/ ±2σ:", (abs(z) < 2).mean(), "/ ±3σ:", (abs(z) < 3).mean())
```

0.6823, 0.9545, 0.9977로 규칙과 거의 같습니다.

## 표준화: 모든 정규분포를 하나로

[st-01-3](#/l/st-01-3)에서 배운 **z점수** z = (x − μ) ÷ σ를 기억하나요? 정규분포를 따르는 값을 z점수로 바꾸면, 원래 평균과 표준편차가 무엇이든 **평균 0, 표준편차 1인 정규분포**가 됩니다. 이것을 **표준정규분포**라고 합니다.

그래서 "키 182cm"와 "몸무게 5,800g"처럼 단위가 전혀 다른 값도 z점수로 바꾸면 같은 곡선 위에서 비교할 수 있습니다.

```run
height, mu, sigma = 182, 170, 6
z = (height - mu) / sigma
print("182cm의 z점수:", z)
```

182cm는 z = 2.0, 평균보다 표준편차 두 개만큼 큰 키입니다. 68-95-99.7 규칙에 따르면 ±2σ 밖은 약 5%이고 위쪽은 그 절반이니, 182cm보다 큰 사람은 약 2.5%쯤 됩니다.

## cdf: x 이하일 확률

정규분포의 확률은 곡선 아래 넓이이고, `cdf(x)`는 **x보다 왼쪽 넓이**, 즉 x 이하일 확률을 줍니다. 키 180cm 이하인 사람의 비율은?

```run
from scipy import stats

height = stats.norm(loc=170, scale=6)
print("180cm 이하:", round(height.cdf(180), 4))
print("180cm 초과:", round(height.sf(180), 4))
```

180cm 이하가 95.2%, 초과가 4.8%입니다. 반에 30명이 있다면 180cm 넘는 친구는 한두 명쯤 있겠네요.

**구간의 확률**은 오른쪽 끝 cdf에서 왼쪽 끝 cdf를 빼서 구합니다. 165~175cm 사이 비율은?

```run
from scipy import stats

height = stats.norm(loc=170, scale=6)
print("165~175cm:", round(height.cdf(175) - height.cdf(165), 4))
```

약 59.5%입니다. 175 이하 넓이에서 165 이하 넓이를 빼면 그 사이 넓이만 남습니다.

## ppf: 확률 → 경계값

거꾸로 "**상위 5%**에 들려면 키가 몇 cm 이상이어야 하나?"를 묻는다면 확률에서 값을 찾아야 합니다. 이때 cdf의 반대 함수인 `ppf`를 씁니다. 상위 5%의 경계는 아래에서 95%인 지점이니 `ppf(0.95)`입니다.

```run
from scipy import stats

height = stats.norm(loc=170, scale=6)
print("상위 5% 경계:", round(height.ppf(0.95), 1), "cm")
print("표준정규 ppf(0.975):", round(stats.norm.ppf(0.975), 3))
```

179.9cm 이상이면 상위 5%입니다. 두 번째 줄의 **1.96**은 아주 중요한 숫자입니다. 표준정규분포에서 가운데 95%를 남기는 경계(양쪽 꼬리 2.5%씩)로, [DAY 06 신뢰구간](#/l/st-04-1)에서 "± 1.96 × 표준오차"로 다시 나옵니다.

## 실제 데이터는 정말 정규분포일까

설비 데이터의 공기 온도(`air_temp`, 단위 K)가 정규분포에 가까운지 봅시다. 먼저 평균과 표준편차를 구합니다.

```run
import pandas as pd

temp = pd.read_csv("ai4i2020.csv")["air_temp"]
print("평균:", round(temp.mean(), 2), "/ 표준편차:", round(temp.std(), 2))
```

평균 300.0K, 표준편차 2.0K입니다. 이 두 숫자로 만든 정규 곡선을 히스토그램 위에 겹쳐 봅니다. `density=True`는 막대 높이를 곡선과 같은 밀도 단위로 맞춰 줍니다.

```run
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
from scipy import stats

temp = pd.read_csv("ai4i2020.csv")["air_temp"]
x = np.linspace(294, 306, 200)
plt.hist(temp, bins=30, density=True); plt.plot(x, stats.norm(temp.mean(), temp.std()).pdf(x)); plt.show()
print("왜도:", round(temp.skew(), 2), "/ 첨도:", round(temp.kurt(), 2))
```

가운데가 높고 좌우가 비슷한 모양이라 정규 곡선과 대체로 겹치지만, 히스토그램이 곡선보다 조금 더 평평합니다(첨도 −0.84, 꼬리가 얇음). 실제 데이터가 이론 분포와 **완벽히** 같은 경우는 거의 없습니다. 그래서 정규분포로 계산한 확률이 실제와 얼마나 맞는지 확인해 봐야 합니다.

```run
import pandas as pd
from scipy import stats

temp = pd.read_csv("ai4i2020.csv")["air_temp"]
model = stats.norm(temp.mean(), temp.std())
print("303K 초과 - 정규 계산:", round(model.sf(303), 3), "/ 실제 비율:", round((temp > 303).mean(), 3))
```

정규분포로 계산하면 303K 초과가 6.7%, 실제 비율은 7.5%입니다. 완벽하진 않지만 "대략 7% 정도"라는 판단에는 충분히 쓸 만합니다.

직접 해 보세요: 위 셀을 `titanic.csv`의 `fare`(요금)로 바꾸고, `sf(303)` 대신 `cdf(0)`(요금이 0 미만일 확률)을 계산해 보세요. 정규분포는 요금이 음수일 확률이 26%라고 답합니다. 요금은 음수가 될 수 없으니 터무니없는 답이지요. 오른쪽 꼬리가 긴 데이터([st-01-4](#/l/st-01-4))에 정규분포를 그대로 쓰면 이렇게 크게 틀립니다. **정규분포를 쓰기 전에는 항상 히스토그램부터 그려 보세요.**

## 실무 예제: 규격을 벗어날 비율 예측하기

공정 온도(`process_temp`)의 관리 규격이 306.5K ~ 313.0K라고 합시다. 정규분포 모델로 규격 밖 비율을 예측하고, 실제 비율과 비교합니다.

```run
import pandas as pd
from scipy import stats

pt = pd.read_csv("ai4i2020.csv")["process_temp"]
model = stats.norm(pt.mean(), pt.std())
print("예측:", round(model.cdf(306.5) + model.sf(313.0), 4), "/ 실제:", round(((pt < 306.5) | (pt > 313.0)).mean(), 4))
```

정규분포 모델은 3.09%, 실제는 2.86%가 규격을 벗어났습니다. 아래쪽(`cdf(306.5)`)과 위쪽(`sf(313.0)`)을 따로 구해 더했다는 점에 주목하세요. 이렇게 평균과 표준편차 두 숫자만 알면 "공정 조건을 이렇게 바꾸면 불량이 몇 %쯤 될까?"를 미리 계산할 수 있습니다.

직접 해 보세요: 공정 온도의 평균을 1K 낮출 수 있다면(`pt.mean() - 1`) 규격 밖 비율이 어떻게 변할까요? 평균이 규격 가운데(309.75K)에 가까워질수록 양쪽 꼬리가 모두 규격 안으로 들어옵니다.

## 자주 하는 실수

1. **치우친 데이터에 정규분포를 쓴다.** 요금, 대기 시간처럼 꼬리가 긴 데이터는 정규분포가 꼬리 확률을 크게 틀립니다. 히스토그램을 먼저 그리세요.
2. **한쪽 꼬리만 계산한다.** 규격 밖 비율, "평균에서 2σ 넘게 벗어난 비율"처럼 양쪽이 모두 해당하는 질문은 두 꼬리를 더해야 합니다.
3. **pdf 값을 확률로 읽는다.** `pdf(x)`는 곡선의 높이(밀도)이지 "딱 x일 확률"이 아닙니다. 확률은 항상 구간의 넓이(cdf의 차이)로 구합니다.

## 정리

- **정규분포**는 평균 μ(가운데)와 표준편차 σ(넓이) 두 숫자로 정해지는 종 모양 분포.
- **68 - 95 - 99.7 규칙**: 평균 ± 1σ, 2σ, 3σ 안에 각각 약 68%, 95%, 99.7%.
- **표준화**(z점수)하면 모든 정규분포가 평균 0, 표준편차 1인 표준정규분포가 된다.
- `cdf(x)`는 x 이하 확률, 구간 확률은 cdf의 차이, `ppf(q)`는 확률 q에 해당하는 경계값. 표준정규의 `ppf(0.975)` = 1.96.
- 실제 데이터가 정규에 가까운지는 히스토그램과 정규 곡선을 겹쳐서 먼저 확인한다.
