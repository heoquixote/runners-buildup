## 상관에서 예측으로

[지난 레슨](#/l/st-07-1)에서 펭귄의 지느러미 길이와 몸무게의 상관계수가 0.87로 강한 양의 관계라는 것을 확인했습니다. 그렇다면 한 걸음 더 나아가 봅시다. **지느러미 길이만 재면 몸무게를 예측할 수 있을까?** 펭귄을 저울에 올리기는 어렵지만, 사진으로 지느러미 길이는 잴 수 있다면 쓸모가 있겠지요.

상관계수는 "얼마나 함께 움직이나"를 숫자 하나로 말할 뿐, 예측하는 식을 주지는 않습니다. 산점도에 **직선을 하나 그어서** x로 y를 예측하는 방법이 **회귀분석**(regression)이고, x가 하나뿐일 때를 **단순선형회귀**라고 합니다.

## 직선의 식: 절편과 기울기

중학교 때 배운 일차함수와 같습니다.

> ŷ = a + b × x

- **ŷ**(와이 햇): 직선이 **예측한** y 값. 실제 y와 구분하려고 모자(^)를 씌웁니다.
- **a**(절편, intercept): x = 0일 때 직선의 높이
- **b**(기울기, slope): x가 1 늘 때 ŷ가 얼마나 변하나

실제 값과 예측값의 차이를 **잔차**(residual)라고 합니다.

> 잔차 = 실제 y − 예측 ŷ

점이 직선보다 위에 있으면 잔차가 +, 아래에 있으면 −입니다. 좋은 직선이란 잔차가 전체적으로 작은 직선이겠지요.

## 최소제곱법: 가장 잘 맞는 직선 고르기

::figure{src="content/img/stats/st07-least-squares.svg" alt="산점도 위에 직선 하나가 그어져 있고, 각 점에서 직선까지 세로 막대(잔차)가 그려져 있으며, 각 잔차를 한 변으로 하는 정사각형이 칠해져 있다. 최소제곱 직선은 이 정사각형 넓이의 합이 가장 작은 직선" caption="잔차(세로 막대)를 한 변으로 하는 정사각형을 그리면, 최소제곱 직선은 이 정사각형들의 넓이 합이 가장 작아지는 직선입니다."}

산점도 위에 그을 수 있는 직선은 무수히 많습니다. 그중 어떤 직선이 "가장 잘 맞는" 걸까요? 통계에서 가장 많이 쓰는 기준은 이렇습니다.

> **잔차를 제곱해서 모두 더한 값(잔차 제곱합)이 가장 작은 직선**

이 방법을 **최소제곱법**(least squares)이라고 합니다. 제곱하는 이유는 [분산](#/l/st-01-2)과 같습니다. 잔차의 +와 −가 상쇄되지 않게 하고, 크게 빗나간 점에 더 큰 벌점을 주기 위해서입니다. 직선이 움직일 때 잔차 제곱(사각형)들의 넓이가 어떻게 변하는지 영상으로 보면 바로 이해됩니다.

## 직접 직선을 대 보기

아무 직선 두 개를 골라 잔차 제곱합을 비교해 봅니다. 직선 A는 ŷ = −5,000 + 45x, 직선 B는 ŷ = −6,000 + 50x입니다.

```run
import pandas as pd

df = pd.read_csv("penguins.csv").dropna(subset=["flipper_length_mm", "body_mass_g"])
x, y = df["flipper_length_mm"], df["body_mass_g"]
for a, b in [(-5000, 45), (-6000, 50)]:
    print(f"직선 ŷ = {a} + {b}x → 잔차 제곱합 {((y - (a + b * x)) ** 2).sum():,.0f}")
```

직선 A는 63,152,825, 직선 B는 61,183,750으로 B가 조금 더 잘 맞습니다. 하지만 이것이 최선일까요?

직접 해 보세요: 위 셀의 숫자들을 바꿔 가며 잔차 제곱합을 더 작게 만들어 보세요. 손으로 찾기는 꽤 어렵습니다. 다행히 최소제곱 직선의 a와 b는 공식으로 한 번에 계산됩니다.

## stats.linregress: 최소제곱 직선 구하기

`stats.linregress(x, y)`가 최소제곱 직선의 기울기와 절편을 바로 계산해 줍니다.

```run
import pandas as pd
from scipy import stats

df = pd.read_csv("penguins.csv").dropna(subset=["flipper_length_mm", "body_mass_g"])
res = stats.linregress(df["flipper_length_mm"], df["body_mass_g"])
print("기울기 b:", round(res.slope, 2), "/ 절편 a:", round(res.intercept, 1))
```

최소제곱 직선은 **ŷ = −5,780.8 + 49.69 × x**입니다. 이 직선의 잔차 제곱합도 확인해 봅니다.

```run
import pandas as pd
from scipy import stats

df = pd.read_csv("penguins.csv").dropna(subset=["flipper_length_mm", "body_mass_g"])
x, y = df["flipper_length_mm"], df["body_mass_g"]
res = stats.linregress(x, y)
print(f"최소제곱 직선의 잔차 제곱합: {((y - (res.intercept + res.slope * x)) ** 2).sum():,.0f}")
```

52,854,796으로, 앞에서 대 본 두 직선보다 확실히 작습니다. 어떤 직선을 그어도 이보다 작게 만들 수는 없습니다.

## 기울기 해석: 단위를 붙여 말하기

기울기 49.69는 이렇게 읽습니다.

> **지느러미가 1mm 길면, 몸무게는 평균적으로 약 49.7g 더 나간다.**

해석할 때 꼭 지켜야 할 세 가지가 있습니다.

1. **단위를 붙인다**: "49.7"이 아니라 "1mm당 49.7g". x를 cm로 재면 기울기는 497이 됩니다.
2. **"평균적으로"를 붙인다**: 모든 펭귄이 정확히 그렇다는 뜻이 아니라, 직선이 요약한 경향입니다.
3. **"늘리면"이 아니라 "~인 펭귄은"**: 이 데이터는 관찰한 것이지 실험한 것이 아닙니다. 펭귄의 지느러미를 1mm 늘린다고 몸무게가 늘지는 않습니다. 회귀 기울기도 [상관](#/l/st-07-1)처럼 인과를 말해 주지 않습니다.

## 절편 해석의 함정

절편 −5,780.8은 "지느러미 길이가 0mm인 펭귄의 몸무게는 −5,781g"이라는 뜻입니다. 말이 안 되지요. 지느러미가 0mm인 펭귄도, 몸무게가 음수인 펭귄도 없습니다. 데이터의 지느러미 길이는 172~231mm 사이에만 있으니, x = 0은 데이터에서 아주 멀리 떨어진 곳입니다.

절편은 직선을 올바른 높이에 놓기 위한 숫자일 뿐, x = 0이 의미 있는 범위 안에 있을 때만 해석합니다.

## 기울기와 상관계수의 관계

기울기는 상관계수와 이런 관계가 있습니다.

> b = r × (y의 표준편차 ÷ x의 표준편차)

상관계수 r이 "표준편차 단위"의 기울기라면, b는 그것을 원래 단위로 되돌린 것입니다. 확인해 봅니다.

```run
import pandas as pd
from scipy import stats

df = pd.read_csv("penguins.csv").dropna(subset=["flipper_length_mm", "body_mass_g"])
x, y = df["flipper_length_mm"], df["body_mass_g"]
r = stats.pearsonr(x, y).statistic
print("r × sy / sx =", round(r * y.std() / x.std(), 2))
```

49.69로 `linregress`의 기울기와 같습니다. 그래서 r = 0이면 기울기도 0(수평선)이 되고, r의 부호와 기울기의 부호는 항상 같습니다.

## 예측하기

이제 직선으로 몸무게를 예측합니다. 지느러미 200mm, 220mm인 펭귄이라면?

```run
import pandas as pd
from scipy import stats

df = pd.read_csv("penguins.csv").dropna(subset=["flipper_length_mm", "body_mass_g"])
res = stats.linregress(df["flipper_length_mm"], df["body_mass_g"])
for f in [200, 220]:
    print(f"지느러미 {f}mm → 예측 몸무게 {res.intercept + res.slope * f:,.0f}g")
```

200mm면 약 4,156g, 220mm면 약 5,150g입니다. 20mm 차이에 49.69 × 20 ≈ 994g 차이가 납니다.

실제 펭귄 몇 마리의 잔차도 봅니다.

```run
import pandas as pd
from scipy import stats

df = pd.read_csv("penguins.csv").dropna(subset=["flipper_length_mm", "body_mass_g"])
res = stats.linregress(df["flipper_length_mm"], df["body_mass_g"])
df["pred"] = res.intercept + res.slope * df["flipper_length_mm"]
print(df[["flipper_length_mm", "body_mass_g", "pred"]].assign(resid=df["body_mass_g"] - df["pred"]).head(4).round(0))
```

첫 번째 펭귄(지느러미 181mm, 3,750g)은 직선이 3,212g으로 예측해서 잔차가 +538g, 직선보다 꽤 무겁습니다. 이런 잔차들을 모아 보면 직선이 데이터에 잘 맞는지 진단할 수 있는데, [다음 레슨](#/l/st-07-3)에서 다룹니다.

마지막으로 산점도 위에 회귀직선을 그려 봅니다.

```run
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
from scipy import stats

df = pd.read_csv("penguins.csv").dropna(subset=["flipper_length_mm", "body_mass_g"])
res = stats.linregress(df["flipper_length_mm"], df["body_mass_g"])
xs = np.array([170, 235])
plt.scatter(df["flipper_length_mm"], df["body_mass_g"], s=10); plt.plot(xs, res.intercept + res.slope * xs, color="C1"); plt.show()
print(f"ŷ = {res.intercept:.1f} + {res.slope:.2f} × flipper")
```

직선이 점들의 띠 한가운데를 지나갑니다.

## 정리

- **단순선형회귀**: ŷ = a + b × x. 잔차 = 실제 − 예측.
- **최소제곱법**: 잔차 제곱합이 가장 작은 직선. `stats.linregress(x, y)` → `slope`, `intercept`.
- 기울기는 "**x가 1 단위 큰 경우 y가 평균적으로 b만큼 크다**"로, 단위를 붙여 해석한다. 인과는 아니다.
- 절편은 x = 0이 의미 있는 범위일 때만 해석한다.
- 기울기 b = r × (sy ÷ sx).
