## 하늘이 흐리다는 정보가 생기면

아무 정보 없이 "내일 비가 올까?"라고 물으면 30% 정도라고 답할 수 있습니다. 그런데 "지금 하늘에 먹구름이 잔뜩 꼈다"는 정보를 들으면 확률이 확 올라가겠지요. 이처럼 **어떤 조건(정보)이 주어졌을 때의 확률**을 **조건부확률**이라고 합니다.

조건부확률은 통계와 머신러닝 곳곳에 나옵니다. "여성일 때 생존할 확률", "검사에서 양성이 나왔을 때 실제로 병이 있을 확률", "이 단어가 들어 있을 때 스팸일 확률" 모두 조건부확률입니다. 이번 레슨에서는 타이타닉 데이터로 조건부확률을 계산하고, 직관을 자주 배신하는 **베이즈 정리**를 배웁니다.

## 출발점: 전체 생존 확률

[지난 레슨](#/l/st-09-1)에서 승객 891명 중 아무나 한 명을 골랐을 때 생존자일 확률을 구했습니다.

```run
import pandas as pd

df = pd.read_csv("titanic.csv")
print("P(생존) =", round(df["survived"].mean(), 3))
```

P(생존) = 0.384입니다. 이번에는 성별이라는 정보를 추가해 봅니다. 두 범주형 변수를 함께 세는 표를 **교차표**(crosstab)라고 합니다. `margins=True`를 주면 행과 열의 합계(All)도 붙습니다.

```run
import pandas as pd

df = pd.read_csv("titanic.csv")
print(pd.crosstab(df["sex"], df["survived"], margins=True))
```

여성 314명 중 233명이 생존(1)했고, 남성 577명 중 109명이 생존했습니다.

## 조건부확률: 분모를 바꾸는 계산

"여성일 때 생존할 확률"은 이렇게 씁니다.

> P(생존 | 여성)

세로 막대 `|` 뒤에 오는 것이 **조건**입니다. "여성이라는 걸 이미 알 때"라고 읽습니다. 계산은 간단합니다. **조건에 해당하는 사람들만 남겨 놓고, 그 안에서 비율을 구하면** 됩니다.

::figure{src="content/img/stats/st09-conditional.svg" alt="성별과 생존 여부로 나눈 2행 2열 표에서, 여성 행만 강조해 잘라 낸 뒤 그 안에서 생존자 233명을 여성 314명으로 나누는 그림" caption="조건부확률은 분모를 바꾸는 계산입니다. 전체 891명이 아니라 조건(여성)에 맞는 314명만 분모로 씁니다."}

```run
import pandas as pd

df = pd.read_csv("titanic.csv")
female = df[df["sex"] == "female"]
print("P(생존 | 여성) =", round(female["survived"].mean(), 3))
print("P(생존 | 남성) =", round(df[df["sex"] == "male"]["survived"].mean(), 3))
```

여성의 생존 확률은 0.742(233 ÷ 314), 남성은 0.189(109 ÷ 577)입니다. 전체 생존 확률 0.384와 비교하면, 성별 정보가 생존 확률을 크게 바꿔 놓았습니다. 실제로 타이타닉에서는 "여성과 아이 먼저"라는 원칙에 따라 구명보트를 탔습니다.

## 뒤집으면 다른 확률이 된다

이번엔 반대로 물어봅시다. **생존자 중에서** 여성의 비율은?

```run
import pandas as pd

df = pd.read_csv("titanic.csv")
survivors = df[df["survived"] == 1]
print("P(여성 | 생존) =", round((survivors["sex"] == "female").mean(), 3))
```

P(여성 | 생존) = 0.681(233 ÷ 342)입니다. P(생존 | 여성) = 0.742와 다른 숫자입니다. 분자는 똑같이 233명(여성이면서 생존)이지만, **분모가 다르기 때문**입니다(여성 314명 vs 생존자 342명).

**P(A | B)와 P(B | A)는 다른 확률입니다.** 너무 당연해 보이지만, 실제로는 이 둘을 헷갈려서 큰 실수가 자주 일어납니다. 예를 들어 "폐암 환자의 대부분은 흡연자다"(P(흡연 | 폐암)가 높다)와 "흡연자의 대부분은 폐암에 걸린다"(P(폐암 | 흡연))는 전혀 다른 문장입니다.

pandas에서는 `normalize="index"`를 주면 각 행 안에서의 비율, 즉 행을 조건으로 한 조건부확률표를 한 번에 만들 수 있습니다.

```run
import pandas as pd

df = pd.read_csv("titanic.csv")
print(pd.crosstab(df["sex"], df["survived"], normalize="index").round(3))
```

각 행의 합이 1이 됩니다. female 행의 1 열(0.742)이 P(생존 | 여성)입니다.

## 독립: 조건이 아무것도 바꾸지 못할 때

조건을 알아도 확률이 그대로라면, 즉 P(A | B) = P(A)라면 A와 B는 **독립**입니다. [지난 레슨](#/l/st-09-1)의 동전 두 개가 그랬습니다. 첫 번째 동전이 앞면이라는 걸 알아도 두 번째 동전의 확률은 여전히 0.5입니다.

타이타닉에서 객실 등급과 생존은 독립일까요? 등급별 생존 확률을 봅니다.

```run
import pandas as pd

df = pd.read_csv("titanic.csv")
print(df.groupby("pclass")["survived"].mean().round(3))
```

1등석 0.630, 2등석 0.473, 3등석 0.242로 전체 생존 확률(0.384)과 크게 다릅니다. 등급은 생존과 **독립이 아닙니다**. 등급을 알면 생존 가능성에 대한 예측이 달라집니다. 이렇게 "관련이 있는지 없는지"를 데이터로 엄밀하게 판단하는 방법(카이제곱 검정)을 [카이제곱 검정: 범주끼리 관련이 있을까](#/l/st-06-1)에서 배웁니다.

## 베이즈 정리: 검사가 양성이면 정말 병일까

이제 조건부확률의 진짜 함정을 봅시다. 어떤 병을 진단하는 검사가 있습니다.

- 이 병에 걸린 사람은 전체의 **1%**입니다.
- 병이 있는 사람이 검사하면 **90%**가 양성이 나옵니다.
- 병이 없는 사람도 **5%**는 양성이 나옵니다(잘못된 양성).

어떤 사람이 검사에서 **양성**이 나왔습니다. 이 사람이 진짜 병에 걸렸을 확률은 얼마일까요? 많은 사람이 "90%쯤"이라고 답하는데, 정답은 훨씬 낮습니다.

## 10,000명으로 바꿔 세면 쉽다

확률 대신 **사람 수**로 바꿔 세면 헷갈리지 않습니다. 이 방법을 **자연빈도**라고 합니다. 10,000명이 검사를 받는다고 생각해 봅시다.

::figure{src="content/img/stats/st09-bayes-tree.svg" alt="10,000명이 병 있음 100명과 병 없음 9,900명으로 나뉘고, 병 있음 100명 중 90명이 양성, 병 없음 9,900명 중 495명이 양성. 양성 585명 중 진짜 환자는 90명" caption="양성 판정을 받은 585명 중 진짜 환자는 90명뿐입니다. 병 없는 사람이 워낙 많아서, 그 5%만 잘못 양성이 나와도 진짜 환자 수를 크게 넘어섭니다."}

```run
sick, healthy = 10_000 * 0.01, 10_000 * 0.99      # 병 있음 100명, 병 없음 9,900명
pos_sick, pos_healthy = sick * 0.90, healthy * 0.05  # 그중 양성이 나온 사람
print("양성:", pos_sick + pos_healthy, "명 중 진짜 환자", pos_sick, "명")
print("P(병 | 양성) =", round(pos_sick / (pos_sick + pos_healthy), 3))
```

양성이 나온 585명 중 진짜 환자는 90명뿐입니다. **P(병 | 양성) = 0.154**, 겨우 15.4%입니다. 검사가 "90%나 잡아낸다"는 사실, 즉 P(양성 | 병) = 0.9를 P(병 | 양성)으로 착각하면 크게 틀립니다. 바로 앞에서 본 "뒤집으면 다른 확률"의 실제 예입니다.

이렇게 직관이 틀리는 가장 큰 이유는 **원래 병에 걸린 사람이 1%로 아주 드물다**는 사실을 잊기 때문입니다. 이것을 **기저율 무시**라고 부릅니다.

## 베이즈 정리 공식

위 계산을 식으로 정리한 것이 **베이즈 정리**입니다.

> P(병 | 양성) = P(양성 | 병) × P(병) ÷ P(양성)

말로 풀면 이렇습니다. 처음에 갖고 있던 믿음(**사전확률**, 병일 확률 1%)에, 새 증거(양성)가 병일 때 얼마나 잘 나오는지를 곱하고, 그 증거가 전체적으로 얼마나 흔한지로 나눠서, 새 믿음(**사후확률**, 15.4%)으로 고칩니다. 증거를 볼 때마다 믿음을 조금씩 고쳐 나가는 방법입니다.

```run
p_sick, p_pos_sick, p_pos_healthy = 0.01, 0.90, 0.05
p_pos = p_pos_sick * p_sick + p_pos_healthy * (1 - p_sick)
print("P(양성) =", round(p_pos, 4))
print("P(병 | 양성) =", round(p_pos_sick * p_sick / p_pos, 3))
```

공식으로 계산해도 0.154로 같습니다. 분모 P(양성) = 0.0585는 "진짜 환자가 양성"(0.009)과 "건강한데 양성"(0.0495)을 더한 값으로, 자연빈도의 585명 ÷ 10,000명과 같습니다.

직접 해 보세요: 위 셀의 `p_sick`을 `0.10`(병이 흔한 경우)으로 바꿔 보세요. 같은 검사인데도 양성일 때 진짜 병일 확률이 0.667로 크게 올라갑니다. 병원에서 증상이 있는 사람만 검사하는 이유가 여기에 있습니다. 증상이 있는 사람들 안에서는 사전확률이 훨씬 높으니까요.

## 실무 예제: 품질 등급과 고장

설비 데이터에서 품질 등급(`type`)과 고장(`failure`)의 교차표를 만들고, 두 방향의 조건부확률을 모두 구해 봅니다. `normalize="index"`는 행마다, `normalize="columns"`는 열마다 비율을 냅니다.

```run
import pandas as pd

df = pd.read_csv("ai4i2020.csv")
print(pd.crosstab(df["type"], df["failure"], normalize="index").round(4))
```

이 표는 **P(고장 | 등급)**입니다. L등급은 3.92%, M등급은 2.77%, H등급은 2.09%가 고장 났습니다. 전체 고장률 3.39%와 비교하면 L등급에서 고장이 더 잦습니다. 등급이 고장 확률을 바꾸므로, 등급과 고장은 **독립이 아닙니다.** 이번엔 방향을 뒤집어 봅니다.

```run
import pandas as pd

df = pd.read_csv("ai4i2020.csv")
print(pd.crosstab(df["type"], df["failure"], normalize="columns").round(3))
```

이 표는 **P(등급 | 고장)**입니다. 고장 난 설비(1 열)의 69.3%가 L등급입니다. 이 숫자만 보고 "고장의 70%가 L등급이니 L등급이 아주 위험하다"고 말하면 과장입니다. 원래 설비의 60%가 L등급이었기 때문입니다(정상 설비 열에서도 L이 59.7%). 고장 설비 중 L 비율(69.3%)이 전체 중 L 비율(60%)보다 **조금** 높은 정도이고, 등급별 고장률로 보면 3.92% 대 2.09%로 약 1.9배 차이입니다.

> 보고서에서 "고장의 ○○%가 △△에서 나왔다"는 문장을 보면, 그 △△가 원래 전체에서 몇 %였는지(기저율)를 꼭 함께 확인하세요.

## 자주 하는 실수

1. **P(A | B)와 P(B | A)를 바꿔 말한다.** "고장 설비의 69%가 L등급"을 "L등급 설비의 69%가 고장"으로 옮기면 완전히 다른 (틀린) 말이 됩니다.
2. **기저율을 무시한다.** 드문 병의 양성 판정, 드문 불량의 알람처럼 사전확률이 작으면 정확한 검사도 양성 대부분이 헛경보일 수 있습니다.
3. **칸 인원이 적은 조건부확률을 믿는다.** H등급 고장은 21건뿐입니다. 이런 비율은 몇 건만 달라져도 크게 바뀌니 인원수를 함께 적습니다.

## 정리

- **조건부확률** P(A | B)는 B인 경우만 남겨 놓고 그 안에서 A의 비율. 분모를 바꾸는 계산이다.
- **P(A | B)와 P(B | A)는 다르다.** 분자는 같아도 분모가 다르다.
- P(A | B) = P(A)이면 A와 B는 **독립**. 타이타닉에서 성별·등급은 생존과 독립이 아니다.
- **베이즈 정리**는 사전확률을 증거로 고쳐 사후확률을 만든다. 드문 일(기저율이 낮은 일)은 정확한 검사로도 양성 중 진짜가 적을 수 있다. 헷갈리면 10,000명으로 바꿔 세자.
