## 검정은 세 가지 질문으로 고른다

통계 트랙에서 검정을 스무 가지 넘게 배웠습니다. 이름을 다 외울 필요는 없습니다. 아래 세 가지 질문에 답하면 쓸 검정이 거의 정해집니다.

1. **결과 변수가 어떤 종류인가?** 연속형(무게, 시간)인지, 범주형(불량/정상, 생존/사망)인지. 연속형이면 정규분포에 가까운지, 치우쳤거나 순서형(1~5점)인지도 봅니다.
2. **그룹이 몇 개인가?** 기준값 하나와 비교하는지, 두 그룹인지, 세 그룹 이상인지. 그룹이 아니라 두 변수의 관계를 보는 경우도 있습니다.
3. **독립인가, 대응인가?** 서로 다른 사람(설비)인지, 같은 사람(설비)을 여러 번 잰 것인지.

::figure{src="content/img/stats/st12-test-map.svg" alt="검정 고르기 지도. 열은 데이터 종류(연속형·정규에 가까움 / 연속형·치우침 또는 순서형 / 범주형), 행은 그룹 구조(1그룹 vs 기준값, 2그룹 독립, 2그룹 대응, 3그룹 이상 독립, 3그룹 이상 대응, 두 변수의 관계). 예: 2그룹 독립·정규는 Welch t, 치우침은 맨-휘트니 U, 범주형은 2비율 z·카이제곱. 3그룹 이상 대응은 반복측정 ANOVA, 프리드먼, 코크런 Q." caption="열(데이터 종류)과 행(그룹 구조)이 만나는 칸이 쓸 검정입니다. 가운데 열은 왼쪽 열의 비모수 버전입니다."}

가운데 열(비모수 검정)은 값 대신 **순위**를 쓰기 때문에 정규성 가정이 필요 없고 이상치에 강합니다. 대신 데이터가 정말 정규분포에 가까우면 왼쪽 열보다 검정력이 조금 낮습니다. 그래서 "정규에 가까우면 왼쪽, 아니면 가운데"가 기본 규칙입니다.

반복측정 ANOVA와 코크런 Q는 지도의 빈칸을 채우려고 이름만 넣었습니다. 같은 대상을 세 번 이상 잰 연속값(정규), 같은 대상을 세 번 이상 잰 예/아니오 값에 쓰는 검정이라는 것만 기억해 두면 됩니다.

:::tip 지도로 고르기 어려운 경우
- **결과가 여러 요인에 함께 달려 있다** (온도, 압력, 작업자…): 검정을 여러 번 하지 말고 [회귀](#/l/st-07-2)나 이원 ANOVA처럼 한 모형에 함께 넣습니다.
- **예/아니오 결과를 여러 변수로 설명한다**: 카이제곱을 변수마다 하는 대신 로지스틱 회귀를 씁니다.
- **표본이 아주 작다** (칸마다 5 미만): 카이제곱 대신 피셔 정확 검정, t 대신 순열 검정이나 부트스트랩을 씁니다.
:::

## p-value만으로는 부족하다: 효과 크기

검정은 "차이가 **있는가**"에 답합니다. 실무에서 더 궁금한 것은 "차이가 **얼마나 큰가**"입니다. 이것을 재는 값이 **효과 크기**(effect size)입니다.

p-value는 효과 크기와 표본 수가 함께 만든 결과입니다. 같은 효과라도 표본이 크면 p가 작아집니다. AI4I에서 고장 설비와 정상 설비의 공구 마모 시간을 비교하되, 표본 크기만 바꿔 봅니다. 효과 크기는 두 평균의 차이를 표준편차로 나눈 **Cohen's d**를 씁니다.

`d = (평균₁ − 평균₂) ÷ 합동 표준편차`

```run
import numpy as np
import pandas as pd
from scipy import stats

df = pd.read_csv("ai4i2020.csv")

def cohen_d(a, b):
    na, nb = len(a), len(b)
    sp = np.sqrt(((na - 1) * a.var() + (nb - 1) * b.var()) / (na + nb - 2))   # pooled SD
    return (a.mean() - b.mean()) / sp

for n in [300, 1000, 10000]:
    s = df.sample(n, random_state=4) if n < len(df) else df
    a, b = s.loc[s["failure"] == 1, "tool_wear"], s.loc[s["failure"] == 0, "tool_wear"]
    p = stats.ttest_ind(a, b, equal_var=False).pvalue
    print(f"n = {n:>5} (failed {len(a):>3}) | d = {cohen_d(a, b):.2f} | p = {p:.2g}")
```

| 표본 수 | 고장 설비 | d | p |
| --- | --- | --- | --- |
| 300 | 9 | 0.65 | 0.10 (유의하지 않음) |
| 1,000 | 32 | 0.41 | 0.042 |
| 10,000 | 339 | 0.59 | 1.9 × 10⁻¹⁸ |

- d는 0.4 ~ 0.65 근처에서 움직이지만, p는 0.10에서 10⁻¹⁸까지 내려갑니다. **p는 표본 수에 따라 크게 바뀌고, 효과 크기는 "차이의 크기" 자체를 잽니다.**
- d = 0.59는 "고장 설비의 마모 시간이 표준편차의 약 0.6배만큼 길다"는 뜻입니다. 단위(분)에 상관없이 다른 변수와 비교할 수 있습니다.
- 고장 설비가 9대뿐인 n = 300에서는 d도 흔들립니다. 효과 크기에도 신뢰구간이 필요한 이유입니다.

## 효과 크기 가족

검정마다 짝이 되는 효과 크기가 있습니다. 같은 데이터로 하나씩 계산합니다.

| 검정 | 효과 크기 | 뜻 |
| --- | --- | --- |
| t검정 (두 평균) | **Cohen's d** | 평균 차이가 표준편차 몇 배인가 |
| ANOVA | **η²** (에타 제곱) | 전체 흩어짐 중 그룹 차이가 설명하는 비율 |
| 카이제곱 | **크래머 V** | 두 범주 변수의 관련 정도 (0 ~ 1) |
| 상관 · 회귀 | **r, R²** | 직선 관계의 세기, 설명된 분산 비율 |
| 맨-휘트니 | **순위이연 상관 r** | 한 그룹이 다른 그룹보다 큰 쪽에 몰린 정도 |
| 2 × 2 표 | **오즈비 (OR) · 위험비 (RR)** | 한 그룹에서 사건이 몇 배 잘 일어나는가 |

### η²와 크래머 V: 유의 여부와 크기를 함께 보기

`η² = 그룹 간 제곱합 ÷ 전체 제곱합`,  `V = √(χ² ÷ (n × (min(행, 열) − 1)))`

```run
import numpy as np
import pandas as pd
from scipy import stats

def eta_squared(y, g):
    grand = y.mean()
    ss_between = sum(len(v) * (v.mean() - grand) ** 2 for _, v in y.groupby(g))
    return ss_between / ((y - grand) ** 2).sum()

pg = pd.read_csv("penguins.csv").dropna()
tips = pd.read_csv("tips.csv")
p1 = stats.f_oneway(*[v for _, v in pg.groupby("species")["body_mass_g"]]).pvalue
p2 = stats.f_oneway(*[v for _, v in tips.groupby("day")["tip"]]).pvalue
print(f"penguin body mass by species: eta^2 = {eta_squared(pg['body_mass_g'], pg['species']):.3f}, p = {p1:.1e}")
print(f"tip by day:                   eta^2 = {eta_squared(tips['tip'], tips['day']):.3f}, p = {p2:.3f}")

ti = pd.read_csv("titanic.csv")
ai = pd.read_csv("ai4i2020.csv")
for name, tab in [("titanic sex x survived", pd.crosstab(ti["sex"], ti["survived"])),
                  ("AI4I type x failure   ", pd.crosstab(ai["type"], ai["failure"]))]:
    p = stats.chi2_contingency(tab)[1]
    print(f"{name}: Cramer's V = {stats.contingency.association(tab, method='cramer'):.3f}, p = {p:.1e}")
```

- 펭귄 몸무게의 **67%** 가 종 차이로 설명됩니다(η² = 0.674). 아주 큰 효과입니다.
- 요일별 팁은 η² = 0.020, p = 0.17입니다. 차이가 있다는 증거도 없고, 있더라도 2% 수준입니다.
- 타이타닉 성별과 생존은 V = 0.543으로 강한 관련입니다.
- AI4I 등급과 고장은 p = 0.001로 **유의하지만** V = 0.037로 아주 약합니다. 1만 대라서 작은 관련도 잡힌 것입니다. "등급이 고장을 좌우한다"고 말하기에는 부족합니다.

### 순위이연 상관과 오즈비: 바로 읽히는 효과 크기

```run
import pandas as pd
from scipy import stats

ai = pd.read_csv("ai4i2020.csv")
a, b = ai.loc[ai["failure"] == 1, "tool_wear"], ai.loc[ai["failure"] == 0, "tool_wear"]
u = stats.mannwhitneyu(a, b)
cl = u.statistic / (len(a) * len(b))          # P(random failed machine > random normal machine)
print(f"Mann-Whitney p = {u.pvalue:.1e} | P(failed > normal) = {cl:.3f} | rank-biserial r = {2 * cl - 1:.3f}")

ti = pd.read_csv("titanic.csv")
tab = pd.crosstab(ti["sex"], ti["survived"]).loc[["female", "male"], [1, 0]]
print(tab)
risk = tab[1] / tab.sum(axis=1)
print(f"survival rate: female {risk['female']:.3f}, male {risk['male']:.3f} -> risk ratio {risk['female'] / risk['male']:.2f}")
res = stats.contingency.odds_ratio(tab.values)
ci = res.confidence_interval()
print(f"odds ratio {res.statistic:.1f} (95% CI {ci.low:.1f} ~ {ci.high:.1f})")
```

- 고장 설비 하나, 정상 설비 하나를 아무렇게나 골랐을 때 고장 설비의 마모 시간이 더 길 확률이 **66.2%** 입니다(차이가 없으면 50%). 순위이연 상관 r = 2 × 0.662 − 1 = **0.324**입니다. "확률"로 바로 말할 수 있어서 보고서에 쓰기 좋습니다.
- 타이타닉 여성 생존율 74.2%, 남성 18.9%로 **위험비 RR = 3.93**, 여성이 3.9배 더 살아남았습니다.
- **오즈비 OR = 12.3**(95% CI 8.8 ~ 17.4)입니다. 오즈는 "생존 ÷ 사망"(여성 233 ÷ 81 = 2.88, 남성 109 ÷ 468 = 0.23)이고, 그 비율이 12배라는 뜻입니다.

:::tip 오즈비와 위험비를 헷갈리지 않기
같은 표에서 RR은 3.9, OR은 12.3입니다. 사건이 흔하면(여기서 생존율 38%) OR이 RR보다 훨씬 크게 나옵니다. "여성이 12배 더 살아남았다"고 쓰면 틀립니다. 12배는 **오즈**의 비율입니다. 사건이 드물면(10% 미만) 두 값이 비슷해집니다. 로지스틱 회귀의 계수를 exp로 바꾼 값이 바로 OR이라서, 보고서에서 자주 만납니다.
:::

## 크다, 작다의 기준

자주 쓰이는 기준(Cohen이 제안한 관례)입니다. **분야마다 다르니 참고용**으로만 씁니다.

| 효과 크기 | 작음 | 중간 | 큼 | 이번 레슨의 예 |
| --- | --- | --- | --- | --- |
| Cohen's d | 0.2 | 0.5 | 0.8 | 마모 0.59 (중간) |
| η² | 0.01 | 0.06 | 0.14 | 펭귄 0.674 (큼), 팁 0.020 (작음) |
| r · 순위이연 r | 0.1 | 0.3 | 0.5 | 마모 순위이연 0.324 (중간) |
| 크래머 V (2 × 2) | 0.1 | 0.3 | 0.5 | 타이타닉 0.543 (큼), AI4I 0.037 (거의 없음) |
| 오즈비 | 약 1.7 | 약 3.5 | 약 6.7 | 타이타닉 12.3 (매우 큼) |

기준표보다 중요한 것은 **현장의 단위로 다시 말하기**입니다. "d = 0.59"보다 "고장 설비의 공구 마모 시간이 평균 37분 더 길다(144분 vs 107분)"가 의사결정에 쓰입니다. 품질 현장이라면 규격 폭과, 매출이라면 금액과 비교합니다.

## 정리

- 검정은 **결과 변수의 종류, 그룹 수, 독립/대응** 세 질문으로 고릅니다. 정규에 가까우면 모수 검정, 치우쳤거나 순서형이면 순위 기반 비모수 검정입니다.
- p-value는 표본 수에 크게 좌우됩니다. 마모 시간의 d는 0.4 ~ 0.65로 비슷했지만 p는 0.10에서 10⁻¹⁸까지 바뀌었습니다.
- 효과 크기 가족: **d**(평균 차이 ÷ 표준편차), **η²**(그룹이 설명하는 비율), **크래머 V**(범주 관련), **r**(관계), **순위이연 r**(우월 확률), **OR · RR**(몇 배).
- AI4I 등급과 고장처럼 **유의하지만 아주 약한** 관련(V = 0.037)이 흔합니다. 효과 크기와 현장 단위로 다시 판단합니다.
