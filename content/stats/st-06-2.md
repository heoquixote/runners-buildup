## 세 반을 비교하고 싶을 때

1반, 2반, 3반의 수학 평균이 같은지 알고 싶습니다. [t검정](#/l/st-05-3)은 두 그룹을 비교하니까, 1반 vs 2반, 1반 vs 3반, 2반 vs 3반으로 **세 번** 검정하면 될까요?

[1종 오류와 검정력](#/l/st-05-2)에서 배운 함정이 여기서 나옵니다. 검정을 여러 번 하면 헛경보가 쌓입니다. 세 반이 실제로 똑같더라도, 세 번 중 하나라도 "유의하다"가 나올 확률은 5%가 아닙니다.

```run
print("t검정 3번 중 적어도 한 번 헛경보:", round(1 - 0.95 ** 3, 3))
print("10개 그룹이면 비교 45번:", round(1 - 0.95 ** 45, 3))
```

세 번만 해도 14.3%, 그룹이 10개(쌍 45개)면 90%입니다. 그래서 세 그룹 이상의 평균은 **한 번의 검정으로** 비교하는 방법이 필요합니다. 그것이 **분산분석**(ANOVA, ANalysis Of VAriance)입니다.

- H₀: 모든 그룹의 모평균이 같다
- H₁: 적어도 한 그룹의 모평균이 다르다

## ANOVA의 아이디어: 그룹 사이 vs 그룹 안

이름은 "분산"분석인데 비교하는 건 평균입니다. 평균이 다른지를 **흩어짐 두 가지를 비교해서** 판단하기 때문입니다.

::figure{src="content/img/stats/st06-anova-idea.svg" alt="두 개의 패널. 왼쪽: 세 그룹의 점들이 서로 멀리 떨어진 평균선 주위에 좁게 모여 있어 F가 크다. 오른쪽: 세 그룹의 평균선은 비슷하고 점들이 넓게 퍼져 서로 겹쳐 F가 작다" caption="그룹 평균끼리의 거리(사이 흩어짐)가 그룹 안의 흩어짐보다 훨씬 크면 F가 커지고, 평균이 다르다고 볼 근거가 됩니다."}

- **그룹 사이 흩어짐**: 그룹 평균들이 전체 평균에서 얼마나 떨어져 있나 (신호)
- **그룹 안 흩어짐**: 각 그룹 안에서 값들이 얼마나 퍼져 있나 (잡음)

> F = 그룹 사이 흩어짐 ÷ 그룹 안 흩어짐

[t 통계량](#/l/st-05-3)처럼 **신호 ÷ 잡음**입니다. 그룹 평균이 정말 같다면 사이 흩어짐도 우연한 흔들림 정도라서 F ≈ 1 근처가 나옵니다. F가 1보다 훨씬 크면 평균이 다르다는 증거입니다.

## 실데이터: 펭귄 세 종의 몸무게

펭귄 세 종(Adelie, Chinstrap, Gentoo)의 평균 몸무게를 비교합니다.

```run
import pandas as pd

df = pd.read_csv("penguins.csv").dropna(subset=["body_mass_g"])
print(df.groupby("species")["body_mass_g"].agg(["count", "mean", "std"]).round(0))
```

Adelie 3,701g, Chinstrap 3,733g은 비슷하고, Gentoo는 5,076g으로 훨씬 무겁습니다. 그룹 안 표준편차는 380~500g 정도입니다. `stats.f_oneway(그룹1, 그룹2, 그룹3)`으로 검정합니다.

```run
import pandas as pd
from scipy import stats

df = pd.read_csv("penguins.csv").dropna(subset=["body_mass_g"])
groups = [g["body_mass_g"] for _, g in df.groupby("species")]
res = stats.f_oneway(*groups)
print("F =", round(res.statistic, 1), "/ p-value =", f"{res.pvalue:.1e}")
```

F = 343.6, p-value = 2.9e-82입니다. 그룹 사이 흩어짐이 그룹 안 흩어짐의 343배나 됩니다. **H₀를 기각**하고, 세 종의 평균 몸무게가 모두 같지는 않다고 결론 내립니다. `*groups`는 리스트 안의 그룹 세 개를 풀어서 함수에 따로따로 넣어 주는 문법입니다.

## F를 직접 계산해 보기

F가 정말 "사이 ÷ 안"인지 직접 계산해 봅니다. 사이 흩어짐은 그룹 평균과 전체 평균의 차이를 제곱해 그룹 크기만큼 더한 것, 안 흩어짐은 각 값과 자기 그룹 평균의 차이를 제곱해 더한 것입니다. 각각 자유도(그룹 수 − 1, 전체 수 − 그룹 수)로 나눠 평균을 맞춥니다.

```run
import pandas as pd

df = pd.read_csv("penguins.csv").dropna(subset=["body_mass_g"])
m, g = df["body_mass_g"].mean(), df.groupby("species")["body_mass_g"]
between = (g.count() * (g.mean() - m) ** 2).sum() / (3 - 1)
within = ((df["body_mass_g"] - g.transform("mean")) ** 2).sum() / (len(df) - 3)
print("사이:", round(between), "/ 안:", round(within), "/ F =", round(between / within, 1))
```

사이 흩어짐 73,432,107, 안 흩어짐 213,698, 나누면 F = 343.6으로 `f_oneway`와 같습니다. `transform("mean")`은 각 행에 자기 그룹의 평균을 붙여 주는 함수입니다.

## "차이 없음" 사례: 요일별 팁

이번엔 요일별(목 · 금 · 토 · 일) 평균 팁을 비교해 봅니다.

```run
import pandas as pd

df = pd.read_csv("tips.csv")
print(df.groupby("day")["tip"].agg(["count", "mean"]).round(2))
```

평균 팁은 2.73 ~ 3.26달러로 요일마다 조금씩 다릅니다. ANOVA로 검정합니다.

```run
import pandas as pd
from scipy import stats

df = pd.read_csv("tips.csv")
res = stats.f_oneway(*[g["tip"] for _, g in df.groupby("day")])
print("F =", round(res.statistic, 2), "/ p-value =", round(res.pvalue, 3))
```

F = 1.67, p-value = 0.174로 0.05보다 큽니다. **H₀를 기각하지 못합니다.** 요일 사이의 평균 차이(최대 0.53달러)가 계산서마다 팁이 흔들리는 정도(표준편차 약 1.4달러)에 비하면 작아서, 우연으로 설명할 수 있다는 뜻입니다. [DAY 07](#/l/st-05-1)에서 토요일 · 일요일만 비교했을 때와 같은 결론입니다.

## 사후검정: 어느 그룹이 다른가

펭귄 ANOVA는 "모두 같지는 않다"고 말해 줬지만, **어느 종과 어느 종이 다른지**는 말해 주지 않습니다. Gentoo만 다른 걸까요, 셋 다 서로 다른 걸까요? ANOVA가 유의할 때 이어서 하는 검정을 **사후검정**(post-hoc test)이라고 합니다.

가장 많이 쓰는 **Tukey HSD**는 모든 쌍을 비교하되, 비교를 여러 번 하면서 헛경보가 쌓이지 않도록 기준을 조정해 줍니다. `stats.tukey_hsd`로 계산하고, 결과의 p-value를 종 이름이 붙은 표로 봅니다.

```run
import pandas as pd
from scipy import stats

df = pd.read_csv("penguins.csv").dropna(subset=["body_mass_g"])
names, groups = zip(*[(k, g["body_mass_g"]) for k, g in df.groupby("species")])
res = stats.tukey_hsd(*groups)
print(pd.DataFrame(res.pvalue, index=names, columns=names).round(3))
```

Adelie와 Chinstrap 사이의 p-value는 0.881로 **차이가 없고**, Gentoo는 다른 두 종과 p-value 0.000으로 **확실히 다릅니다.** ANOVA가 유의하다고 해서 모든 그룹이 서로 다른 것은 아니라는 점을 꼭 기억하세요.

## 효과 크기: 차이가 얼마나 큰가 (η²)

ANOVA의 p-value도 "평균이 다르다"까지만 말합니다. 차이가 얼마나 큰지는 **에타제곱**(η², eta squared)으로 봅니다. 전체 흩어짐 중에서 그룹 사이 흩어짐이 차지하는 비율입니다. 회귀의 [R²](#/l/st-07-3)와 같은 생각입니다.

> η² = 그룹 사이 제곱합 ÷ 전체 제곱합

```run
import pandas as pd

df = pd.read_csv("penguins.csv").dropna(subset=["body_mass_g"])
gm = df["body_mass_g"].mean()
between = sum(len(g) * (g.mean() - gm) ** 2 for _, g in df.groupby("species")["body_mass_g"])
print("η² =", round(between / ((df["body_mass_g"] - gm) ** 2).sum(), 3))
```

η² = 0.67입니다. 펭귄 몸무게 흩어짐의 67%가 **종의 차이**로 설명된다는 뜻입니다. 아주 큰 효과입니다. 대략 0.01은 작은 효과, 0.06은 중간, 0.14 이상은 큰 효과로 읽습니다.

## 실무 예제: 등급별로 공구를 다르게 썼을까

설비 데이터에서 품질 등급(L · M · H)에 따라 공구 사용 시간이 다른지 ANOVA로 확인합니다.

```run
import pandas as pd
from scipy import stats

df = pd.read_csv("ai4i2020.csv")
print(df.groupby("type")["tool_wear"].mean().round(1).to_dict())
print("p =", round(stats.f_oneway(*[g for _, g in df.groupby("type")["tool_wear"]]).pvalue, 3))
```

세 등급의 평균이 107 ~ 108분으로 거의 같고, p = 0.711로 차이가 없다는 귀무가설을 기각하지 못합니다. 이 결과는 오히려 반가운 결과입니다. 등급별 고장률을 비교할 때([조건부확률과 베이즈 정리](#/l/st-09-2)) 공구 사용 시간이 등급마다 달랐다면, 고장률 차이가 등급 때문인지 공구 사용 시간 때문인지 구분할 수 없었을 것입니다. "비교하려는 그룹이 다른 조건에서는 비슷한가?"를 확인할 때도 ANOVA를 씁니다.

## 자주 하는 실수

1. **ANOVA가 유의하다고 "모든 그룹이 서로 다르다"고 말한다.** ANOVA는 "적어도 한 그룹이 다르다"까지만 말합니다. 어느 쌍인지는 사후검정으로 확인합니다.
2. **t검정을 여러 번 해서 세 그룹 이상을 비교한다.** 쌍마다 t검정을 하면 헛경보가 쌓입니다. 먼저 ANOVA, 그다음 보정된 사후검정을 씁니다.
3. **p-value만 보고하고 η²를 빠뜨린다.** 그룹이 크면 아주 작은 차이도 유의해집니다.

## ANOVA의 가정과 대안

ANOVA가 정확하려면 세 가지 가정이 대략 맞아야 합니다.

1. **독립**: 각 값이 서로 영향을 주지 않는다 (같은 펭귄을 두 번 세지 않음)
2. **정규성**: 각 그룹의 값이 정규분포에 가깝다 (그룹이 크면 [중심극한정리](#/l/st-03-3) 덕분에 덜 중요)
3. **등분산**: 그룹마다 흩어짐(분산)이 비슷하다

값이 많이 치우쳤거나 이상치가 많으면, 값 대신 **순위**로 비교하는 **Kruskal-Wallis 검정**(`stats.kruskal`)을 대안으로 씁니다. 순위를 쓰면 아주 큰 값도 "1등"일 뿐이라 이상치에 덜 흔들립니다.

```run
import pandas as pd
from scipy import stats

df = pd.read_csv("penguins.csv").dropna(subset=["body_mass_g"])
res = stats.kruskal(*[g["body_mass_g"] for _, g in df.groupby("species")])
print("Kruskal-Wallis p-value:", f"{res.pvalue:.1e}")
```

펭귄 몸무게는 Kruskal-Wallis로도 p-value가 5.6e-48로 결론이 같습니다.

직접 해 보세요: 위 셀을 `tips.csv`의 요일(`day`)별 `tip`으로 바꿔 보세요. Kruskal-Wallis p-value가 0.036으로, ANOVA(0.174)와 결론이 달라집니다. 팁은 오른쪽으로 치우치고 큰 값이 섞여 있어서, 평균을 비교하는 ANOVA와 순위를 비교하는 Kruskal-Wallis가 서로 다른 것을 보고 있기 때문입니다. 이런 경우에는 결과를 보고 마음에 드는 검정을 고르면 안 되고, **데이터 모양을 보고 검정을 먼저 정한 뒤** 그 결과를 따라야 합니다. 그리고 "두 방법의 결론이 엇갈릴 만큼 차이가 크지 않다"는 사실 자체를 함께 보고하는 것이 정직합니다.

## 정리

- 세 그룹 이상을 t검정 여러 번으로 비교하면 헛경보가 쌓인다. **ANOVA**로 한 번에 검정한다.
- F = 그룹 사이 흩어짐 ÷ 그룹 안 흩어짐 (신호 ÷ 잡음). scipy: `stats.f_oneway`.
- ANOVA가 유의하면 "적어도 하나는 다르다"까지만. 어느 쌍이 다른지는 **사후검정**(Tukey HSD, `stats.tukey_hsd`).
- 가정(독립 · 정규 · 등분산)이 크게 어긋나면 순위 기반 **Kruskal-Wallis**(`stats.kruskal`).
- 차이가 유의해도 실제 크기(Gentoo가 약 1,350g 무거움)를 함께 보고한다.
