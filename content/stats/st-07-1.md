## 함께 움직이는 두 값

키가 큰 친구는 대체로 몸무게도 많이 나갑니다. 공부 시간이 긴 학생은 대체로 성적이 높습니다. 기온이 높은 날은 아이스크림이 많이 팔립니다. 이처럼 **한 값이 커질 때 다른 값도 함께 커지거나 작아지는** 관계를 숫자 하나로 나타내는 방법을 배웁니다.

지금까지는 변수 하나(몸무게만, 팁만)를 요약하거나 그룹끼리 비교했습니다. 이번 DAY부터는 **수치형 변수 두 개의 관계**를 봅니다.

## 먼저 그려 본다: 산점도

두 변수의 관계는 언제나 **산점도**(scatter plot)부터 그립니다. 펭귄의 지느러미 길이(x)와 몸무게(y)를 봅니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("penguins.csv").dropna(subset=["flipper_length_mm", "body_mass_g"])
plt.scatter(df["flipper_length_mm"], df["body_mass_g"], s=10)
plt.xlabel("flipper length (mm)"); plt.ylabel("body mass (g)"); plt.show()
print("펭귄 수:", len(df))
```

점들이 왼쪽 아래에서 오른쪽 위로 길게 늘어서 있습니다. 지느러미가 긴 펭귄일수록 무겁습니다. 이런 관계를 **양의 관계**라고 합니다. 반대로 한쪽이 커질 때 다른 쪽이 작아지면 **음의 관계**입니다. 이 관계의 방향과 강도를 숫자로 나타내 봅시다.

## 공분산: 편차끼리 곱하기

[분산](#/l/st-01-2)을 구할 때 편차(값 − 평균)를 제곱했습니다. 두 변수의 관계를 보려면 **x의 편차와 y의 편차를 곱합니다.**

::figure{src="content/img/stats/st07-covariance-quadrants.svg" alt="산점도를 x 평균선과 y 평균선으로 네 칸으로 나눈 그림. 오른쪽 위와 왼쪽 아래 칸은 편차 곱이 양수(+), 왼쪽 위와 오른쪽 아래 칸은 음수(−). 점 대부분이 +칸에 있으면 공분산이 양수" caption="평균선 두 개로 네 칸을 나누면, 오른쪽 위·왼쪽 아래 점은 편차 곱이 +, 나머지 두 칸은 −입니다. 점들이 어느 칸에 많이 모였는지가 공분산의 부호를 정합니다."}

- x도 평균보다 크고 y도 평균보다 크면(오른쪽 위): (+) × (+) = **+**
- x도 y도 평균보다 작으면(왼쪽 아래): (−) × (−) = **+**
- 한쪽만 크면(왼쪽 위, 오른쪽 아래): **−**

이 곱을 평균 낸 것이 **공분산**(covariance)입니다. 점들이 대부분 + 칸에 있으면 공분산이 양수(양의 관계), − 칸에 많으면 음수(음의 관계), 고르게 퍼져 있으면 0 근처입니다.

```run
import numpy as np
import pandas as pd

df = pd.read_csv("penguins.csv").dropna(subset=["flipper_length_mm", "body_mass_g"])
x, y = df["flipper_length_mm"], df["body_mass_g"]
print("편차 곱의 평균:", round(((x - x.mean()) * (y - y.mean())).mean(), 1))
print("np.cov (n-1):", round(np.cov(x, y)[0, 1], 1))
```

공분산은 약 9,800으로 양수입니다. 양의 관계라는 것은 알겠는데, 9,800은 큰 걸까요 작은 걸까요? `np.cov`는 표본이라 n − 1로 나눠서 직접 계산한 값과 조금 다릅니다.

## 공분산의 약점: 단위에 따라 크기가 변한다

지느러미 길이를 mm 대신 **cm**로 바꿔서 공분산을 다시 구해 봅니다. 관계는 하나도 바뀌지 않았습니다.

```run
import numpy as np
import pandas as pd

df = pd.read_csv("penguins.csv").dropna(subset=["flipper_length_mm", "body_mass_g"])
print("mm, g :", round(np.cov(df["flipper_length_mm"], df["body_mass_g"])[0, 1], 1))
print("cm, g :", round(np.cov(df["flipper_length_mm"] / 10, df["body_mass_g"])[0, 1], 1))
print("mm, kg:", round(np.cov(df["flipper_length_mm"], df["body_mass_g"] / 1000)[0, 1], 2))
```

같은 관계인데 단위만 바꿔도 9,824 → 982 → 9.82로 바뀝니다. 공분산은 **방향(부호)**은 알려 주지만 **강도**를 비교하기에는 쓸 수 없습니다.

## 상관계수 r: 단위를 없앤 공분산

해결책은 [z점수](#/l/st-01-3)처럼 표준화하는 것입니다. 공분산을 두 변수의 표준편차로 나누면 단위가 사라지고, 값이 항상 **−1 ~ 1** 사이에 들어옵니다. 이것이 **피어슨 상관계수** r입니다.

> r = 공분산 ÷ (x의 표준편차 × y의 표준편차)

```run
import numpy as np
import pandas as pd
from scipy import stats

df = pd.read_csv("penguins.csv").dropna(subset=["flipper_length_mm", "body_mass_g"])
print("np.corrcoef:", round(np.corrcoef(df["flipper_length_mm"], df["body_mass_g"])[0, 1], 3))
res = stats.pearsonr(df["flipper_length_mm"], df["body_mass_g"])
print("stats.pearsonr: r =", round(res.statistic, 3), "/ p-value =", f"{res.pvalue:.1e}")
```

r = 0.871입니다. mm로 재든 cm로 재든 이 값은 똑같습니다. `stats.pearsonr`은 r과 함께 "r = 0"(관계 없음)이라는 귀무가설의 p-value도 줍니다(4.4e-107, 관계가 우연이 아님).

## r 읽는 법

| r | 해석 | 산점도 모습 |
| --- | --- | --- |
| 1 | 완벽한 양의 직선 | 점이 오른쪽 위로 향하는 직선 위에 딱 놓임 |
| 0.7 ~ 0.9 | 강한 양의 관계 | 오른쪽 위로 뚜렷한 띠 (펭귄 0.87) |
| 0.3 ~ 0.7 | 중간 정도 | 경향은 보이지만 퍼짐이 큼 |
| 0 ~ 0.3 | 약하거나 거의 없음 | 둥근 구름 |
| 음수 | 같은 강도의 음의 관계 | 오른쪽 아래로 향함 |

이 기준은 분야마다 조금씩 다릅니다. 사람의 행동을 다루는 데이터에서는 0.3도 의미 있는 관계로 보는 반면, 물리 측정에서는 0.9도 낮다고 볼 수 있습니다.

## 함정 ①: r은 직선 관계만 잰다

공을 위로 던졌을 때 시간(x)과 높이(y)처럼 올라갔다 내려오는 관계를 생각해 봅시다. y = x² 같은 U자 관계입니다. x만 알면 y가 정확히 정해지는 아주 강한 관계인데, r은 얼마일까요?

```run
import numpy as np
from scipy import stats

x = np.arange(-5, 6)
y = x ** 2
print("U자 관계의 r:", round(stats.pearsonr(x, y).statistic, 3))
```

r = 0.0입니다. 왼쪽 절반은 음의 관계, 오른쪽 절반은 양의 관계라서 서로 상쇄되었습니다. **r ≈ 0은 "직선 관계가 없다"는 뜻이지, "아무 관계가 없다"는 뜻이 아닙니다.** 그래서 r을 계산하기 전에 반드시 산점도를 그려야 합니다.

## 함정 ②: 이상치 하나가 r을 뒤집는다

공부 시간(x)과 점수(y) 10명의 데이터에서, 마지막 학생의 점수를 입력 실수로 −20점이라고 잘못 적었다고 해 봅시다.

```run
import numpy as np
from scipy import stats

hours = np.arange(1, 11)
score = np.array([2, 4, 5, 4, 5, 7, 8, 9, 10, -20])     # 마지막 값이 입력 실수
print("피어슨 r:", round(stats.pearsonr(hours, score).statistic, 3))
print("스피어만 r:", round(stats.spearmanr(hours, score).statistic, 3))
```

나머지 9명은 뚜렷한 양의 관계인데, 이상치 하나 때문에 피어슨 r이 −0.261로 **음수가 되어 버렸습니다.**

**스피어만 상관계수**는 값 대신 **순위**(1등, 2등, …)로 상관을 계산합니다. −20은 그냥 "꼴찌"일 뿐이라 얼마나 극단적인지는 반영되지 않아서, 0.421로 덜 흔들립니다. 또 스피어만은 "꾸준히 증가하기만 하면" 곡선이어도 1에 가까워집니다. 이상치가 걱정되거나 관계가 곡선이면 스피어만을 함께 보세요.

## 상관 행렬: 여러 변수를 한 번에

변수가 여러 개면 `df.corr()`로 모든 쌍의 상관계수를 표 하나로 볼 수 있습니다. 이 표를 **상관 행렬**이라고 하고, 색으로 칠하면 히트맵이 됩니다([상관계수와 히트맵 읽기](#/l/da-15-3)).

```run
import pandas as pd

df = pd.read_csv("penguins.csv")
cols = {"bill_length_mm": "bill_len", "bill_depth_mm": "bill_dep", "flipper_length_mm": "flipper", "body_mass_g": "mass"}
print(df[list(cols)].rename(columns=cols).corr().round(2))
```

지느러미 · 몸무게(0.87)가 가장 강하고, 부리 길이 · 몸무게(0.60)도 꽤 강합니다. 그런데 부리 길이 · 부리 깊이는 −0.24로 음수입니다. "부리가 길수록 얇다"는 걸까요? 이 숫자에는 큰 함정이 숨어 있는데, [DAY 11 심슨의 역설](#/l/st-10-1)에서 파헤칩니다.

## 실무 예제: 설비 변수들의 상관 행렬

설비 데이터의 변수 여섯 개로 상관 행렬을 만듭니다. 고장(`failure`)은 0 · 1 값이지만 상관계수를 구할 수 있습니다(이 경우 "고장 쪽에서 값이 얼마나 큰가"를 잽니다).

```run
import pandas as pd

df = pd.read_csv("ai4i2020.csv")
print(df[["air_temp", "process_temp", "rpm", "torque", "tool_wear", "failure"]].corr().round(2))
```

눈에 띄는 짝이 두 개 있습니다.

- **회전 속도 · 토크 −0.88**: 아주 강한 음의 상관입니다. 모터의 출력(≈ 토크 × 회전 속도)이 거의 일정하게 운전되기 때문에, 빨리 돌면 힘이 작고 천천히 돌면 힘이 큽니다. 물리 법칙이 만든 상관입니다.
- **공기 온도 · 공정 온도 0.88**: 공정 온도가 공기 온도에 열이 더해진 값이라 함께 움직입니다.

반면 고장과의 상관은 토크 0.19, 공구 사용 시간 0.11처럼 모두 약합니다. 그렇다고 "고장과 관계없다"는 뜻은 아닙니다. 고장은 드물고(3.4%) 0 · 1 값이라 r이 작게 나오기 쉽고, 토크가 **아주 높을 때만** 고장이 몰리는 것 같은 관계는 r 하나로 잘 드러나지 않습니다. [위치와 이상치: 사분위수 · 상자그림 · z점수](#/l/st-01-3)에서 토크 이상치의 91%가 고장이었던 것을 떠올리세요.

같은 짝을 피어슨과 스피어만으로 비교해 봅니다.

```run
import pandas as pd
from scipy import stats

df = pd.read_csv("ai4i2020.csv")
print("피어슨:", round(stats.pearsonr(df["rpm"], df["torque"]).statistic, 3), "/ 스피어만:", round(stats.spearmanr(df["rpm"], df["torque"]).statistic, 3))
```

스피어만(−0.916)이 피어슨(−0.875)보다 강하게 나옵니다. 순위로 보면 거의 완벽하게 "한쪽이 크면 다른 쪽은 작은데", 직선으로 보면 조금 덜 맞는다는 뜻입니다. 관계가 **휘어 있다**는 신호입니다. 이 휘어짐이 회귀에서 어떤 문제를 일으키는지 [회귀 결과 읽기와 진단](#/l/st-07-3)에서 확인합니다.

## 자주 하는 실수

1. **상관 행렬에서 가장 큰 숫자만 보고 "원인"을 찾았다고 한다.** 상관은 함께 움직인다는 것까지만 말합니다.
2. **r이 작다고 관계가 없다고 한다.** 곡선 관계, 일부 구간에서만 나타나는 관계, 드문 사건과의 관계는 r이 작게 나옵니다. 반드시 그림을 함께 봅니다.
3. **같은 것을 두 번 잰 변수의 높은 상관에 놀란다.** 공기 온도와 공정 온도처럼 정의상 묶인 변수는 상관이 높은 것이 당연합니다. 이런 짝은 모델에 함께 넣을 때 주의가 필요합니다([선형 · 로지스틱 회귀](#/l/ml-02-1)).

## 앤스컴 콰르텟: 숫자가 같아도 그림은 다르다

통계학자 앤스컴(Francis Anscombe)이 1973년에 만든 데이터 네 세트가 있습니다. 네 세트 모두 x와 y의 평균, 표준편차, 상관계수가 **거의 똑같습니다.**

```run
import matplotlib.pyplot as plt
import numpy as np

x = [10, 8, 13, 9, 11, 14, 6, 4, 12, 7, 5]
sets = {"I": (x, [8.04, 6.95, 7.58, 8.81, 8.33, 9.96, 7.24, 4.26, 10.84, 4.82, 5.68]),
        "II": (x, [9.14, 8.14, 8.74, 8.77, 9.26, 8.10, 6.13, 3.10, 9.13, 7.26, 4.74]),
        "III": (x, [7.46, 6.77, 12.74, 7.11, 7.81, 8.84, 6.08, 5.39, 8.15, 6.42, 5.73]),
        "IV": ([8, 8, 8, 8, 8, 8, 8, 19, 8, 8, 8], [6.58, 5.76, 7.71, 8.84, 8.47, 7.04, 5.25, 12.50, 5.56, 7.91, 6.89])}
fig, axes = plt.subplots(1, 4, figsize=(12, 2.6))
for ax, (name, (a, b)) in zip(axes, sets.items()):
    ax.scatter(a, b); ax.set_title(f"{name}: r = {np.corrcoef(a, b)[0, 1]:.3f}")
plt.show()
print({k: round(float(np.mean(b)), 2) for k, (a, b) in sets.items()})
```

네 세트 모두 r = 0.816, y 평균 7.50으로 숫자로는 구별되지 않습니다. 그런데 그림은 전혀 다릅니다. I은 평범한 직선 관계, II는 곡선, III은 직선 위의 이상치 하나, IV는 x가 거의 다 8인데 점 하나가 r을 만들어 냈습니다. **숫자 요약만 보고 판단하지 말고, 반드시 그려 보세요.**

## 데이터사우루스: 공룡도 숨을 수 있다

**데이터 소개 · 데이터사우루스 더즌** (`datasaurus.csv`)

점 142개짜리 데이터 **13세트**를 한 표에 이어 붙인 **1,846행**입니다(datasauRus, MIT). 2017년 연구자들이 "요약 통계는 같은데 모양은 전혀 다른" 데이터를 컴퓨터로 만들어 낸 것입니다. **한 행 = 점 하나**입니다.

| 컬럼 | 뜻 | 자료형 | 예시 |
| --- | --- | --- | --- |
| `dataset` | 세트 이름 | 글자 | dino, star, circle |
| `x` | 점의 가로 위치 | 소수 | 55.3846 |
| `y` | 점의 세로 위치 | 소수 | 97.1795 |

빈칸은 없습니다. 세트를 구분하려면 `dataset` 열로 묶습니다.

앤스컴의 네 세트는 손으로 만든 작은 데이터였습니다. 2017년에는 연구자들이 컴퓨터로 이 생각을 훨씬 극단적으로 밀어붙였습니다. **데이터사우루스 더즌**(Datasaurus Dozen)은 점 142개짜리 데이터 13세트로, 그중 하나는 점을 이으면 공룡 모양(`dino`)이 됩니다. 먼저 세트별 요약 통계부터 봅니다.

```run
import pandas as pd

df = pd.read_csv("datasaurus.csv")
print(df["dataset"].nunique(), "sets,", len(df[df["dataset"] == "dino"]), "points each")
summary = df.groupby("dataset").agg(x_mean=("x", "mean"), y_mean=("y", "mean"), x_std=("x", "std"), y_std=("y", "std"))
summary["r"] = df.groupby("dataset").apply(lambda g: g["x"].corr(g["y"]), include_groups=False)
print(summary.round(2))
```

13세트 모두 x 평균 54.26~54.27, y 평균 47.83~47.84, 표준편차 16.77 · 26.94 안팎, 상관계수 −0.06 ~ −0.07로 소수 둘째 자리까지 거의 같습니다. 숫자만 보면 "같은 데이터를 13번 뽑았다"고 생각하기 쉽습니다. 이제 그려 봅니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("datasaurus.csv")
g = sns.relplot(data=df, x="x", y="y", col="dataset", col_wrap=5, height=1.8, s=8)
```

## 정리

- 두 수치형 변수의 관계는 **산점도**부터 그린다.
- **공분산**은 편차 곱의 평균. 부호(방향)는 알려 주지만 단위에 따라 크기가 변한다.
- **피어슨 상관계수 r** = 공분산 ÷ (두 표준편차의 곱). −1 ~ 1, 단위와 무관. `stats.pearsonr`.
- r은 **직선 관계만** 잰다(곡선이면 0일 수 있음). **이상치 하나**에 크게 흔들린다 → 순위 기반 **스피어만**(`stats.spearmanr`).
- 같은 r이라도 그림은 전혀 다를 수 있다(앤스컴 콰르텟, 데이터사우루스). 상관은 인과가 아니다([상관과 인과, 심슨의 역설](#/l/st-10-1)).
