## 통계에서 가장 고마운 정리

[지난 레슨](#/l/st-03-2)에서 표본평균들의 히스토그램(표본분포)을 그렸을 때, 혹시 모양이 눈에 들어왔나요? 가운데가 높고 양쪽이 낮은 **종 모양**이었습니다. 그런데 공구 마모 시간 모집단 자체는 0~250분 사이에 거의 고르게 퍼진, 종 모양과는 거리가 먼 분포였습니다.

이것은 우연이 아닙니다. **모집단이 어떤 모양이든, 표본평균의 분포는 표본이 커질수록 정규분포에 가까워집니다.** 이것을 **중심극한정리**(Central Limit Theorem, CLT)라고 합니다. 이번 레슨에서는 아주 심하게 치우친 모집단으로 이 정리를 직접 확인하고, 왜 이 정리가 통계 전체를 떠받치는지 봅니다.

## 아주 치우친 모집단: 타이타닉 요금

[분포의 모양: 히스토그램 · 왜도 · 첨도](#/l/st-01-4)에서 본 타이타닉 요금은 왜도 4.79로 오른쪽 꼬리가 아주 긴 분포였습니다. 정규분포와는 정반대 모양입니다. 이 891명을 모집단으로 씁니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

fare = pd.read_csv("titanic.csv")["fare"]
plt.hist(fare, bins=40); plt.xlabel("fare (population)"); plt.show()
print("모평균:", round(fare.mean(), 2), "/ 왜도:", round(fare.skew(), 2))
```

모평균 32.20, 대부분 0~50에 몰리고 500 근처까지 꼬리가 늘어진 모양입니다.

## 실험: n = 2와 n = 30

이 모집단에서 **2명**씩 뽑아 평균 요금을 구하는 일을 2,000번 반복하고, 표본평균 2,000개의 히스토그램을 그립니다.

```run
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd

fare = pd.read_csv("titanic.csv")["fare"]
rng = np.random.default_rng(0)
means = [rng.choice(fare, 2).mean() for _ in range(2000)]
plt.hist(means, bins=40); plt.xlabel("sample mean (n=2)"); plt.show()
print("표본평균의 왜도:", round(pd.Series(means).skew(), 2))
```

2명의 평균은 모집단처럼 여전히 오른쪽으로 치우쳐 있습니다(왜도 3.17). 두 명 중 한 명만 비싼 표를 사도 평균이 확 커지니까요. 이번엔 **30명**씩 뽑아 봅니다.

```run
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd

fare = pd.read_csv("titanic.csv")["fare"]
rng = np.random.default_rng(0)
means = [rng.choice(fare, 30).mean() for _ in range(2000)]
plt.hist(means, bins=40); plt.xlabel("sample mean (n=30)"); plt.show()
print("표본평균의 왜도:", round(pd.Series(means).skew(), 2))
```

30명의 평균은 32 근처를 중심으로 훨씬 종 모양에 가까워졌습니다(왜도 0.93). 오른쪽 꼬리가 아직 조금 남아 있지만, 모집단의 극단적인 모양과는 완전히 다릅니다. 30명을 모으면 비싼 표 몇 장과 싼 표 여러 장이 섞이면서 극단값이 서로 상쇄되기 때문입니다.

## 표본 크기를 키워 가며 보기

n = 2, 5, 30, 100을 한 번에 나란히 그려 봅니다.

::figure{src="content/img/stats/st03-clt.svg" alt="네 개의 히스토그램이 나란히 있다. 왼쪽 n=1(모집단)은 극단적으로 오른쪽 꼬리가 길고, n=5는 꼬리가 줄고, n=30은 거의 종 모양, n=100은 좁고 대칭인 종 모양" caption="표본 크기 n이 커질수록 표본평균의 분포는 ① 종 모양에 가까워지고 ② 폭이 좁아집니다. 중심은 언제나 모평균입니다."}

```run
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd

fare = pd.read_csv("titanic.csv")["fare"]
fig, axes = plt.subplots(1, 4, figsize=(12, 2.5))
for ax, n in zip(axes, [2, 5, 30, 100]):
    rng = np.random.default_rng(0)
    ax.hist([rng.choice(fare, n).mean() for _ in range(2000)], bins=30); ax.set_title(f"n = {n}")
plt.show()
print("그림 4개: 왼쪽부터 n = 2, 5, 30, 100")
```

n이 커질수록 두 가지 변화가 동시에 일어납니다. 모양은 **종 모양**에 가까워지고, 폭은 **좁아집니다**(표준오차 σ ÷ √n이 줄어서). 모양 변화를 숫자로도 확인해 봅니다. 왜도가 0에 가까울수록 좌우 대칭입니다.

```run
import numpy as np
import pandas as pd

fare = pd.read_csv("titanic.csv")["fare"]
for n in [2, 5, 30, 100]:
    rng = np.random.default_rng(0)
    print("n =", n, "→ 표본평균의 왜도:", round(pd.Series([rng.choice(fare, n).mean() for _ in range(2000)]).skew(), 2))
```

모집단 왜도 4.79가 n = 2에서 3.17, n = 5에서 2.08, n = 30에서 0.93, n = 100에서 0.47로 줄어듭니다.

직접 해 보세요: 위 셀의 `[2, 5, 30, 100]`에 `300`을 추가해 보세요. 왜도가 더 0에 가까워집니다.

## 중심극한정리 한 문장

> 서로 독립인 값을 **충분히 많이** 모아 평균을 내면, 원래 값들이 어떤 분포를 따르든 그 평균은 **정규분포**에 가까워진다. 이 정규분포의 중심은 모평균 μ, 표준편차는 σ ÷ √n이다.

[정규분포와 표준화](#/l/st-02-3)에서 "작은 영향이 아주 많이 더해진 값은 정규분포가 된다"고 했던 것이 바로 이 정리입니다. 키가 정규분포에 가까운 것도 수많은 작은 요인이 더해진 결과이기 때문입니다.

**얼마나 커야 "충분히"일까요?** 흔히 n ≥ 30이면 된다고 말합니다. 모집단이 대칭에 가까우면 10~20개로도 충분하지만, 타이타닉 요금처럼 꼬리가 아주 긴 모집단은 30개로도 왜도가 0.93이나 남았습니다. "30"은 법칙이 아니라 대략적인 기준입니다. 데이터가 많이 치우쳤다면 더 큰 표본이 필요합니다.

## 흔한 오해: 데이터가 정규분포가 되는 게 아니다

중심극한정리는 **표본평균의 분포**에 대한 이야기입니다. 표본을 크게 뽑는다고 **표본 안의 데이터 자체**가 정규분포가 되지는 않습니다. 30명 표본 하나의 요금 분포를 봅시다.

```run
import numpy as np
import pandas as pd

fare = pd.read_csv("titanic.csv")["fare"]
rng = np.random.default_rng(0)
one_sample = pd.Series(rng.choice(fare, 30))
print("표본 하나(30명) 안의 요금 왜도:", round(one_sample.skew(), 2))
```

표본 하나 안의 요금은 여전히 왜도 2.00으로 오른쪽에 치우쳐 있습니다. 표본 안의 데이터는 언제나 모집단을 닮습니다. 종 모양이 되는 것은 **그런 표본을 여러 번 뽑아 얻은 평균들**입니다.

## 왜 이 정리가 고마운가

모집단의 분포를 모르더라도, 표본평균에 대해서는 **정규분포 계산**([정규분포와 표준화](#/l/st-02-3)의 cdf · ppf)을 쓸 수 있게 됩니다. 예를 들어 "30명을 무작위로 뽑았을 때 평균 요금이 40을 넘을 확률"을 시뮬레이션 없이 정규분포로 계산해 봅니다. 평균은 모평균, 표준편차는 표준오차 σ ÷ √30을 씁니다.

```run
import numpy as np
import pandas as pd
from scipy import stats

fare = pd.read_csv("titanic.csv")["fare"]
se = fare.std(ddof=0) / np.sqrt(30)
print("정규분포 계산:", round(stats.norm(fare.mean(), se).sf(40), 3))
```

정규분포로 계산하면 0.195입니다. 시뮬레이션으로도 확인해 봅니다.

```run
import numpy as np
import pandas as pd

fare = pd.read_csv("titanic.csv")["fare"]
rng = np.random.default_rng(0)
means = np.array([rng.choice(fare, 30).mean() for _ in range(2000)])
print("시뮬레이션:", (means > 40).mean())
```

시뮬레이션 결과 0.192로, 정규분포 계산과 거의 같습니다. 모집단은 극단적으로 치우쳤는데도 표본평균에 대해서는 정규분포 계산이 잘 맞습니다.

## 실무 예제: 고장률(비율)에도 통한다

중심극한정리는 평균에 대한 정리인데, **비율도 평균**입니다. 고장 = 1, 정상 = 0으로 적으면 고장률은 0과 1의 평균이니까요. 설비 200대를 뽑아 고장률을 구하는 일을 2,000번 반복합니다.

```run
import numpy as np
import pandas as pd

fail = pd.read_csv("ai4i2020.csv")["failure"]
rng = np.random.default_rng(0)
rates = np.array([rng.choice(fail, 200).mean() for _ in range(2000)])
print("평균:", round(rates.mean(), 4), "/ 흔들림:", round(rates.std(), 4), "/ 공식 √(p(1−p)/n):", round(np.sqrt(0.0339 * 0.9661 / 200), 4))
```

모집단은 0과 1 두 값뿐인, 전혀 종 모양이 아닌 분포입니다. 그래도 200대 고장률들의 평균은 0.034로 참값과 같고, 흔들림 0.0129는 공식 √(p(1 − p) ÷ n) = 0.0128과 거의 같습니다. 이 공식이 [비율의 신뢰구간](#/l/st-04-2)에 그대로 쓰입니다.

단, 고장처럼 **드문 사건**은 n이 작으면 정규분포에 가까워지지 않습니다. 20대만 뽑으면 2,000번 중 절반 정도가 고장률 0%로 나와 왼쪽 끝에 몰립니다. 비율에서는 "고장 수(np)와 정상 수(n(1 − p))가 모두 10개 이상"을 대략적인 기준으로 씁니다. 고장률 3.39%라면 n이 약 300대는 넘어야 합니다.

## 정리

- **중심극한정리**: 모집단이 어떤 모양이든, 표본평균의 분포는 n이 커질수록 정규분포에 가까워진다. 중심은 μ, 표준편차는 σ ÷ √n.
- n ≥ 30은 대략적인 기준. 모집단 꼬리가 길수록 더 큰 n이 필요하다.
- 정규분포가 되는 것은 **표본평균들**이지, 표본 안의 데이터가 아니다.
- 그래서 표본평균에는 정규분포 계산을 쓸 수 있고, 이것이 신뢰구간과 가설검정의 바탕이 된다.
