## 검정을 많이 하면 헛발견이 쌓인다

[1종 오류 · 2종 오류 · 검정력](#/l/st-05-2)에서 "검정을 여러 번 하면 헛경보가 쌓인다"는 **다중비교 문제**를 봤습니다. 유의수준 5%는 "차이가 없을 때 20번에 1번은 우연히 유의하게 나온다"는 뜻입니다. 그러면 차이가 전혀 없는 검정을 20번 하면 **적어도 하나** 유의하게 나올 확률은 얼마일까요?

`P(적어도 하나 헛발견) = 1 − (1 − α)^m = 1 − 0.95²⁰ ≈ 0.64`

64%입니다. 실제로 그런지 시뮬레이션으로 확인합니다. 같은 정규분포에서 두 그룹(20개씩)을 뽑아 t검정하기를 20번, 이것을 2,000번 반복합니다.

```run
import numpy as np
from scipy import stats

rng = np.random.default_rng(1)
any_hit = 0
for _ in range(2000):
    ps = [stats.ttest_ind(rng.normal(size=20), rng.normal(size=20)).pvalue for _ in range(20)]
    any_hit += min(ps) < 0.05
print("simulated P(at least one p < 0.05 in 20 null tests):", any_hit / 2000)
print("formula 1 - 0.95^20:", round(1 - 0.95 ** 20, 3))
```

시뮬레이션 0.655, 공식 0.642입니다. 차이가 하나도 없는데도 열에 여섯 번 넘게 "유의한 발견"이 나옵니다. 변수 20개를 다 비교해 보고 유의한 것만 보고하면 이런 일이 생깁니다.

## 두 가지 목표: FWER과 FDR

보정 방법은 무엇을 지키고 싶은지에 따라 두 갈래입니다.

| 목표 | 뜻 | 대표 방법 | 알맞은 상황 |
| --- | --- | --- | --- |
| **FWER** (가족 단위 오류율) | 헛발견이 **하나라도** 나올 확률을 α 이하로 | Bonferroni, Holm | 확인 단계, 하나만 틀려도 큰일 (신약 승인, 품질 판정) |
| **FDR** (거짓 발견 비율) | "유의하다"고 한 것 중 헛발견의 **비율**을 α 이하로 | Benjamini-Hochberg (BH) | 탐색 단계, 후보를 넓게 뽑고 나중에 확인 (유전자 · 변수 선별) |

FWER은 엄격하고, FDR은 너그럽습니다. 100개를 "유의하다"고 했을 때 FDR 5%는 그중 5개 정도는 헛발견이어도 괜찮다는 약속입니다.

## Bonferroni: 가장 단순한 보정

검정 m개를 하면 각 검정의 기준을 **α / m**로 낮춥니다. 같은 말로, p-value에 m을 곱해(1을 넘으면 1) 0.05와 비교합니다.

- 20개 검정이면 0.05 / 20 = 0.0025보다 작아야 유의합니다.
- 왜 되나: 각 검정의 헛발견 확률이 α/m이면, m개 중 하나라도 헛발견일 확률은 많아야 m × α/m = α입니다.

단순하고 어떤 상황에서도 성립하지만, 검정이 많으면 너무 엄격해서 진짜 차이도 놓치기 쉽습니다(검정력 손실).

## Holm: Bonferroni를 단계적으로

Holm 방법은 Bonferroni와 같은 FWER을 지키면서 **항상 같거나 더 많이** 발견합니다.

1. p-value를 작은 것부터 줄 세운다: p(1) ≤ p(2) ≤ … ≤ p(m)
2. 가장 작은 p(1)을 α/m와 비교한다. 통과하면 다음으로.
3. p(2)는 α/(m − 1), p(3)은 α/(m − 2)… 기준이 **조금씩 느슨해진다**.
4. 처음으로 통과하지 못한 곳에서 멈추고, 그 뒤는 모두 유의하지 않다고 본다.

이미 하나를 "진짜"로 인정했다면, 남은 검정은 m − 1개뿐이니 기준을 그만큼 풀어 줘도 된다는 논리입니다.

## Benjamini-Hochberg: 비율을 관리한다

BH 방법은 FDR을 α 이하로 지킵니다.

1. p-value를 작은 것부터 줄 세운다.
2. k번째 p-value를 **(k / m) × α**와 비교한다.
3. 이 조건을 만족하는 **가장 큰 k**를 찾고, 1등부터 k등까지를 모두 유의하다고 본다.

Holm과 반대로 **아래(큰 p)에서부터** 찾기 때문에, 중간에 기준을 못 넘는 것이 있어도 그 뒤에서 통과하면 앞의 것들이 함께 살아납니다.

## 손으로 비교하기: p-value 8개

검정 8개의 p-value가 0.001, 0.006, 0.008, 0.020, 0.031, 0.044, 0.30, 0.62로 나왔다고 합시다. 보정하지 않으면 6개가 유의합니다.

```run
import numpy as np

p = np.array([0.001, 0.006, 0.008, 0.020, 0.031, 0.044, 0.30, 0.62])   # already sorted
m, alpha = len(p), 0.05
k = np.arange(1, m + 1)
bonf = p <= alpha / m
holm_ok = p <= alpha / (m - k + 1)
holm = np.cumprod(holm_ok).astype(bool)            # stop at the first failure
bh_ok = p <= k / m * alpha
bh = k <= (k[bh_ok].max() if bh_ok.any() else 0)   # everything up to the largest passing k
print(" k  p      Bonf(α/m) Holm(α/(m-k+1)) BH(kα/m)")
for i in range(m):
    print(f"{k[i]:>2}  {p[i]:.3f}  {alpha / m:.4f} {'O' if bonf[i] else '.'}   {alpha / (m - k[i] + 1):.4f} {'O' if holm[i] else '.'}      {k[i] / m * alpha:.4f} {'O' if bh[i] else '.'}")
print("discoveries -> Bonferroni:", bonf.sum(), "| Holm:", holm.sum(), "| BH:", bh.sum())
```

| 방법 | 발견 수 | 이유 |
| --- | --- | --- |
| 보정 없음 | 6 | 0.05보다 작은 것 전부 |
| Bonferroni | 2 | 모두 0.00625와 비교 |
| Holm | 3 | 3번째(0.008)는 0.05/6 = 0.0083을 통과, 4번째(0.020)는 0.01에서 멈춤 |
| BH | 5 | 5번째(0.031)가 5/8 × 0.05 = 0.03125를 통과 |

같은 p-value에서 2개, 3개, 5개로 결론이 다릅니다. 엄격함의 순서는 **Bonferroni > Holm > BH**입니다.

## 도구로 한 번에: 보정된 p-value

사이파이의 `stats.false_discovery_control`은 BH 보정 p-value를, statsmodels의 `multipletests`는 여러 방법의 보정 p-value를 한 번에 줍니다. 보정된 p-value는 그대로 0.05와 비교하면 됩니다.

```run
import numpy as np
from scipy import stats
from statsmodels.stats.multitest import multipletests

p = np.array([0.001, 0.006, 0.008, 0.020, 0.031, 0.044, 0.30, 0.62])
print("BH (scipy):      ", stats.false_discovery_control(p).round(3))
for method in ["bonferroni", "holm", "fdr_bh"]:
    reject, p_adj, _, _ = multipletests(p, alpha=0.05, method=method)
    print(f"{method:>10}: adjusted {p_adj.round(3)}, significant {reject.sum()}")
```

Bonferroni의 보정 p-value는 원래 p에 8을 곱한 값입니다(0.006 → 0.048). Holm과 BH의 보정 p-value는 순위에 따라 곱하는 수가 달라지고, 순서가 뒤집히지 않도록 다듬은 값입니다.

## 실무 예제: 진짜 신호 5개 + 가짜 신호 20개

AI4I 설비 3,000대에서, 고장 난 설비와 정상 설비의 평균을 25개 변수에 대해 비교합니다. 5개는 진짜 센서 값이고, 20개는 **아무 의미 없는 난수**(noise) 열을 일부러 넣은 것입니다.

```run
import numpy as np
import pandas as pd
from scipy import stats
from statsmodels.stats.multitest import multipletests

df = pd.read_csv("ai4i2020.csv").sample(3000, random_state=2)
rng = np.random.default_rng(2)
for i in range(20):
    df[f"noise{i:02d}"] = rng.normal(size=len(df))
cols = ["air_temp", "process_temp", "rpm", "torque", "tool_wear"] + [f"noise{i:02d}" for i in range(20)]
failed = df["failure"] == 1
p = pd.Series([stats.ttest_ind(df.loc[failed, c], df.loc[~failed, c], equal_var=False).pvalue for c in cols], index=cols)
print("raw p < 0.05:", list(p[p < 0.05].index))
for method in ["bonferroni", "holm", "fdr_bh"]:
    reject = multipletests(p, alpha=0.05, method=method)[0]
    print(f"{method:>10}:", list(p.index[reject]))
```

- 보정 없이 보면 6개가 유의합니다. 그중 **noise09(p = 0.018), noise06(p = 0.034) 두 개는 난수**입니다. 보고서에 "noise09가 고장과 관련 있다"고 쓰면 헛발견입니다.
- Bonferroni · Holm · BH 모두 토크 · 공기 온도 · 공구 마모 세 개만 남기고, 난수 두 개를 걸러 냈습니다.
- 공정 온도(p = 0.032)도 보정 후 탈락했습니다. 실제로 약한 관련이 있을 수 있지만, 25개를 뒤진 상황에서는 이 정도 증거로는 난수와 구별되지 않습니다. 이런 변수는 "다음 데이터에서 다시 확인할 후보"로 남깁니다.

## 언제 보정하고, 언제 안 해도 되나

| 상황 | 보정 |
| --- | --- |
| 변수 · 그룹 · 지표를 여러 개 뒤져서 유의한 것을 찾음 | 필요 (탐색이면 BH, 확인이면 Holm) |
| ANOVA 뒤 모든 쌍 비교 | 필요 (Tukey HSD 또는 Holm) |
| A/B 테스트에서 지표 여러 개를 봄 | 주 지표 하나는 미리 정해 보정 없이, 나머지는 보정 |
| 실험 전에 미리 정한 **하나의** 가설만 검정 | 불필요 |
| 서로 다른 연구 질문들 | 질문마다 따로 판단 |

가장 좋은 방법은 **검정할 것을 미리 적어 두는 것**입니다. 검정 수를 줄일수록 보정에 따른 검정력 손실도 줄어듭니다.

## 자주 하는 실수

| 실수 | 무슨 일이 생기나 | 바로잡기 |
| --- | --- | --- |
| 25개를 검정하고 유의한 것만 보고 | 난수도 "발견"됨 (noise09, noise06) | 검정한 개수를 밝히고 보정 |
| 탐색 단계에서 Bonferroni만 고집 | 진짜 신호까지 대부분 버림 | 탐색은 BH, 확인은 Holm |
| 보정 후 탈락 = "관련 없음"으로 단정 | 증거가 부족할 뿐 | "확인 필요한 후보"로 기록 |
| 결과를 보고 나서 보정 방법을 고름 | 원하는 결론에 맞추는 셈 | 분석 전에 방법을 정함 |

## 정리

- 차이가 없는 검정도 20번 하면 64%의 확률로 하나는 "유의"합니다. 이것이 **다중비교 문제**입니다.
- **FWER**(헛발견이 하나라도 나올 확률)을 지키는 Bonferroni(α/m), Holm(단계적으로 느슨해지는 기준)과, **FDR**(발견 중 헛발견 비율)을 지키는 BH(kα/m)가 있습니다. 엄격함은 Bonferroni > Holm > BH입니다.
- p-value 8개 예에서 발견 수는 보정 없음 6, Bonferroni 2, Holm 3, BH 5였습니다.
- AI4I 실무 예제에서 보정은 난수 열 2개를 걸러 내고 진짜 센서 3개를 남겼습니다. 검정할 것은 미리 정하고, 검정한 개수를 함께 보고합니다.
