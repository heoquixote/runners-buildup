## 요인이 둘일 때

[분산분석(ANOVA)과 사후검정](#/l/st-06-2)은 요인 **하나**(펭귄 종)로 나눈 그룹들의 평균을 비교했습니다. 그런데 현실의 결과는 보통 여러 요인이 함께 만듭니다. 펭귄 몸무게는 종에 따라서도, 성별에 따라서도 다릅니다. 공정 불량률은 설비와 원료 로트에 따라 함께 달라집니다. 요인 두 개를 한 번에 분석하는 것이 **이원분산분석(two-way ANOVA)** 이고, 이때 처음 등장하는 중요한 개념이 **교호작용(interaction)** 입니다.

## 이원분산분석이 묻는 세 가지

종(3) × 성별(2)이면 그룹이 6칸입니다. 이원분산분석은 이 6칸의 평균을 보고 세 가지를 동시에 검정합니다.

| 효과 | 묻는 것 | 귀무가설 |
| --- | --- | --- |
| 주효과 A (종) | 성별을 고르게 섞어 봤을 때, 종에 따라 평균이 다른가 | 종별 평균이 모두 같다 |
| 주효과 B (성별) | 종을 고르게 섞어 봤을 때, 성별에 따라 평균이 다른가 | 성별 평균이 같다 |
| 교호작용 A × B | **성별 차이의 크기가 종마다 다른가** | 성별 차이가 모든 종에서 같다 |

교호작용은 "한 요인의 효과가 다른 요인의 수준에 따라 달라진다"는 뜻입니다. 약의 효과가 나이대마다 다르다, 온도를 올렸을 때의 불량률 변화가 원료마다 다르다 같은 것입니다.

## 교호작용은 그래프로 먼저 본다

교호작용 그래프는 가로축에 한 요인, 선마다 다른 요인을 두고 칸별 평균을 잇습니다.

::figure{src="content/img/stats/st12-interaction.svg" alt="세 그림: 두 선이 평행하면 교호작용 없음, 기울기가 다르면 교호작용 있음, 두 선이 엇갈리면 강한 교호작용" caption="선이 평행하면 교호작용이 없고, 간격이 달라지거나 엇갈리면 교호작용이 있습니다."}

- **평행**: B의 효과(두 선의 간격)가 A의 어느 수준에서나 같다. 교호작용 없음.
- **간격이 다름**: B의 효과가 A의 수준에 따라 커지거나 작아진다.
- **엇갈림**: A 수준 1에서는 B = 1이 높은데, 수준 2에서는 B = 2가 높다. 효과의 **방향**까지 바뀐다.

펭귄 몸무게를 그려 봅니다.

```run
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv("penguins.csv").dropna()
table = df.groupby(["species", "sex"])["body_mass_g"].mean().unstack().round(0)
print(table)
print("male - female gap:", (table["MALE"] - table["FEMALE"]).to_dict())
fig, ax = plt.subplots(figsize=(5, 3.4))
for sex in ["FEMALE", "MALE"]:
    ax.plot(table.index, table[sex], marker="o", label=sex)
ax.set_ylabel("mean body mass (g)"); ax.set_title("Interaction plot: species x sex"); ax.legend()
plt.tight_layout(); plt.show()
```

수컷이 암컷보다 무거운 것은 세 종 모두 같지만, 차이의 크기가 다릅니다. Adelie 674g, Chinstrap 412g, Gentoo 805g입니다. 선이 완전히 평행하지 않으니 교호작용이 있을 수 있습니다. 이 정도 차이가 우연인지 검정으로 확인합니다.

## statsmodels로 이원분산분석

이원분산분석은 **statsmodels**의 회귀식 문법으로 합니다. `y ~ C(A) * C(B)`라고 쓰면 주효과 A, 주효과 B, 교호작용 A:B를 모두 넣으라는 뜻입니다. `C( )`는 그 열을 범주로 다루라는 표시입니다.

```run
import pandas as pd
import statsmodels.formula.api as smf
from statsmodels.stats.anova import anova_lm

df = pd.read_csv("penguins.csv").dropna()
model = smf.ols("body_mass_g ~ C(species) * C(sex)", data=df).fit()
table = anova_lm(model, typ=2)
table["eta_sq_partial"] = table["sum_sq"] / (table["sum_sq"] + table.loc["Residual", "sum_sq"])
table.loc["Residual", "eta_sq_partial"] = float("nan")
print(table.round(4))
```

| 효과 | 자유도 | F | p | 부분 η² |
| --- | --- | --- | --- | --- |
| 종 | 2 | 749.0 | 거의 0 | 0.821 |
| 성별 | 1 | 387.5 | 거의 0 | 0.542 |
| 종 × 성별 | 2 | 8.76 | 0.0002 | 0.051 |
| 잔차 | 327 | | | |

- 종과 성별의 주효과는 모두 아주 큽니다.
- **교호작용도 유의합니다**(p = 0.0002). "수컷이 얼마나 더 무거운가"가 종에 따라 다르다는 것이 우연이 아닙니다.
- 다만 부분 η² = 0.051로, 주효과에 비하면 작은 효과입니다. 수컷이 무겁다는 큰 그림은 세 종 모두 같고, 그 차이의 크기가 조금씩 다를 뿐입니다.

## 원리 한 걸음 더: 제곱합을 네 조각으로 나눈다

[일원분산분석](#/l/st-06-2)은 전체 흩어짐(SST)을 "그룹 간"과 "그룹 안"으로 나눴습니다. 이원분산분석은 그룹 간 부분을 다시 셋으로 나눕니다.

`SST = SS(A) + SS(B) + SS(A × B) + SS(잔차)`

각 효과의 F는 일원분산분석과 같은 모양입니다.

`F = (SS(효과) ÷ 자유도(효과)) ÷ (SS(잔차) ÷ 자유도(잔차))`

자유도는 A가 (수준 수 − 1) = 2, B가 1, 교호작용은 두 자유도를 곱한 2 × 1 = 2, 잔차는 (전체 개수 − 칸 수) = 333 − 6 = 327입니다. 교호작용 F = (1,676,557 ÷ 2) ÷ (31,302,630 ÷ 327) = 8.76으로, 표의 값과 같습니다.

**부분 η²** 는 "그 효과의 SS ÷ (그 효과의 SS + 잔차 SS)"로, 다른 효과를 빼고 봤을 때 그 효과가 설명하는 비율입니다. 일원분산분석의 η²를 요인이 여러 개일 때로 넓힌 것입니다.

:::tip 알아 두면 좋아요 · typ=2? 칸마다 개수가 다를 때
칸마다 개수가 같으면(균형 설계) 제곱합을 나누는 방법이 하나로 정해집니다. 개수가 다르면(불균형) 요인끼리 정보가 겹쳐서 나누는 방법이 여러 가지가 됩니다. `typ=1`은 식에 쓴 순서대로 차례로 빼서 순서에 따라 결과가 바뀝니다. `typ=2`는 교호작용이 없다고 볼 때 주효과를 공정하게 재고, `typ=3`은 교호작용이 있어도 주효과를 따로 잽니다(이때는 범주 코딩을 `C(A, Sum)`으로 바꿔야 합니다). 처음에는 `typ=2`를 쓰고, 교호작용이 크게 유의하면 주효과 대신 **칸별 평균**을 해석합니다.
:::

## 엇갈리는 교호작용: 주효과만 보면 놓친다

팁 비율(팁 ÷ 계산 금액 × 100)을 손님 성별과 흡연석 여부로 나눠 봅니다.

```run
import pandas as pd
import statsmodels.formula.api as smf
from statsmodels.stats.anova import anova_lm

df = pd.read_csv("tips.csv")
df["pct"] = df["tip"] / df["total_bill"] * 100
print(df.groupby(["sex", "smoker"])["pct"].mean().unstack().round(2))
model = smf.ols("pct ~ C(sex) * C(smoker)", data=df).fit()
print(anova_lm(model, typ=2).round(4))
```

| | 비흡연 | 흡연 |
| --- | --- | --- |
| 여성 | 15.69% | **18.22%** |
| 남성 | 16.07% | 15.28% |

- 성별의 주효과(p = 0.277), 흡연의 주효과(p = 0.628)는 둘 다 유의하지 않습니다.
- 그런데 **교호작용은 p = 0.049**로 경계선에서 유의합니다. 여성은 흡연석에서 팁 비율이 2.5%p 높고, 남성은 오히려 0.8%p 낮습니다. 효과의 방향이 엇갈려서 평균을 내면 서로 지워졌습니다.

성별만, 흡연만 따로 비교했다면 "아무 차이 없음"으로 끝났을 데이터입니다. 요인을 함께 넣어야 보이는 관계가 있다는 것이 이원분산분석의 가장 큰 가치입니다. 다만 p = 0.049는 아슬아슬하고, 흡연 여성은 33명뿐이라 다른 데이터에서 다시 확인해야 할 **가설 후보**로 보고합니다([여러 번 검정할 때](#/l/st-12-6)).

## 교호작용이 유의하면 해석이 달라진다

| 상황 | 해석하는 법 |
| --- | --- |
| 교호작용 없음 | 주효과를 그대로 해석: "수컷이 평균 ○○g 무겁다" |
| 교호작용 있음 (같은 방향) | 주효과 + "그 크기가 종마다 다르다" (칸별 차이를 보고) |
| 교호작용 있음 (엇갈림) | 주효과는 해석하지 않고, **칸별로** 나눠 말한다: "여성은 흡연석에서 높고, 남성은 차이가 없다" |

## 실무 예제: 제품 등급 × 공구 상태별 고장률

AI4I에서 공구 사용 시간이 150분을 넘으면 "오래된 공구"로 나눠, 제품 등급(L · M · H)과 함께 고장률을 봅니다. 고장 여부(0/1)의 평균이 곧 고장률입니다.

```run
import numpy as np
import pandas as pd
import statsmodels.formula.api as smf
from statsmodels.stats.anova import anova_lm

df = pd.read_csv("ai4i2020.csv")
df["wear"] = np.where(df["tool_wear"] > 150, "old", "new")
print((df.groupby(["type", "wear"])["failure"].mean().unstack() * 100).round(2))
model = smf.ols("failure ~ C(type) * C(wear)", data=df).fit()
print(anova_lm(model, typ=2).round(5))
```

오래된 공구에서 고장률이 크게 오르는데(주효과 F = 95.3), 그 증가 폭이 등급마다 다릅니다(교호작용 p = 0.00004). 표를 보면 L 등급은 새 공구 2.31%에서 오래된 공구 7.55%로 5.2%p 뛰지만, M 등급은 1.6%p, H 등급은 1.8%p만 오릅니다. "공구 교체 주기를 등급별로 다르게 잡자"는 근거가 됩니다.

고장 여부처럼 0/1인 결과에 ANOVA를 쓰는 것은 대략적인 탐색용입니다. 정식 분석에서는 로지스틱 회귀를 씁니다([로지스틱 회귀: 확률로 분류하기](#/l/ml-02-5)).

## 자주 하는 실수

| 실수 | 무슨 일이 생기나 | 바로잡기 |
| --- | --- | --- |
| 요인마다 일원분산분석을 따로 함 | 엇갈리는 교호작용을 놓침 (팁: 둘 다 "차이 없음") | 두 요인을 함께 넣고 교호작용 확인 |
| 교호작용이 유의한데 주효과만 보고 | "흡연은 효과 없음"처럼 틀린 결론 | 칸별 평균으로 나눠 해석 |
| 칸 하나에 몇 명뿐인데 교호작용 결론 | 우연히 엇갈려 보일 수 있음 | 칸별 개수 확인, 재현 확인 |
| 같은 대상을 여러 번 잰 데이터에 일반 이원분산분석 | 관측이 독립이 아님 | 반복측정 ANOVA 또는 [프리드먼](#/l/st-12-5) |

## 정리

- **이원분산분석**은 두 요인의 주효과와 **교호작용**(한 요인의 효과가 다른 요인에 따라 달라지는 것)을 함께 검정합니다. 제곱합 = SS(A) + SS(B) + SS(A × B) + SS(잔차).
- 펭귄: 종 · 성별 주효과가 크고, 교호작용도 유의(p = 0.0002, 부분 η² 0.051). 수컷이 무거운 정도가 종마다 다릅니다(412 ~ 805g).
- 팁: 주효과는 둘 다 유의하지 않았지만 교호작용은 p = 0.049. 엇갈리는 효과는 함께 넣어야 보입니다.
- 교호작용이 유의하면 주효과보다 **칸별 평균**을 해석합니다. 그래프 먼저, 검정은 확인용입니다.
