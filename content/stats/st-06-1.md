## 데이터 종류에 따라 검정이 다르다

t검정은 **두 집단의 평균**을 비교합니다. 그런데 현장 질문은 이런 것도 많습니다.

| 질문 | 데이터 | 검정 |
| --- | --- | --- |
| 요일별 불량이 고르게 나오나? | 범주 하나의 빈도 | 카이제곱 **적합도** `stats.chisquare` |
| 라인과 불량 유형은 관계가 있나? | 범주 두 개의 교차표 | 카이제곱 **독립성** `stats.chi2_contingency` |
| 설비 세 대의 평균 두께가 같나? | 세 집단 이상의 연속값 | **일원분산분석(ANOVA)** `stats.f_oneway` |

## 카이제곱: 관측과 기대의 차이

H0가 맞다면 나왔어야 할 빈도(기대 빈도 E)와 실제 빈도(관측 O)의 차이를 모두 더합니다.

χ² = Σ (O − E)² / E

차이가 클수록 χ²가 커지고 p-value가 작아집니다. 자유도는 적합도에서 (범주 수 − 1), 독립성에서 (행 − 1) × (열 − 1)입니다.

```run
import numpy as np
from scipy import stats

obs = np.array([18, 22, 25, 20, 35])          # Mon..Fri defects
exp = np.full(5, obs.sum() / 5)
print("expected", exp)
print("chi2 by hand", round(((obs - exp) ** 2 / exp).sum(), 3))
res = stats.chisquare(obs)
print("chisquare", round(res.statistic, 3), "p =", round(res.pvalue, 4))
```

금요일이 35건으로 많아 보여도 p ≈ 0.12라 "요일과 무관하다"는 가설을 기각하지 못합니다. 한 주 데이터 120건으로는 이 정도 차이는 우연으로도 흔히 나옵니다.

## 독립성 검정: 교차표부터

두 범주 변수는 `pd.crosstab`으로 교차표를 만든 뒤 `chi2_contingency`에 넣습니다. 결과의 `expected_freq`가 "두 변수가 독립이라면" 기대되는 표입니다.

```run
import pandas as pd
from scipy import stats

df = pd.DataFrame({
    "line": ["A"] * 50 + ["B"] * 50 + ["C"] * 50,
    "type": ["scratch"] * 20 + ["size"] * 20 + ["func"] * 10
          + ["scratch"] * 15 + ["size"] * 25 + ["func"] * 10
          + ["scratch"] * 30 + ["size"] * 10 + ["func"] * 10,
})
table = pd.crosstab(df["line"], df["type"])
print(table)
res = stats.chi2_contingency(table)
print("p =", round(res.pvalue, 4), " dof =", res.dof)
print(pd.DataFrame(res.expected_freq, index=table.index, columns=table.columns).round(1))
```

> 기대 빈도가 5보다 작은 칸이 많으면 카이제곱 근사가 맞지 않습니다. 범주를 합치거나 `stats.fisher_exact`(2×2)를 씁니다. 2×2 표에서는 `chi2_contingency`가 기본으로 연속성 보정(Yates)을 합니다.

## ANOVA: 세 집단 이상의 평균

세 설비를 쌍마다 t검정(A-B, A-C, B-C)하면 검정을 3번 하는 셈이라 우연히 하나쯤 유의하게 나올 확률이 커집니다. ANOVA는 "모든 평균이 같다"를 **한 번에** 검정합니다.

F = (집단 **사이** 흩어짐) / (집단 **안** 흩어짐)

집단 평균끼리 멀리 떨어져 있을수록, 집단 안 값들이 촘촘할수록 F가 커집니다.

```run
import numpy as np
from scipy import stats

a = np.array([10.02, 10.05, 9.98, 10.01, 10.04, 10.00])
b = np.array([10.08, 10.11, 10.06, 10.12, 10.09, 10.07])
c = np.array([10.01, 9.99, 10.03, 10.00, 10.02, 9.98])
res = stats.f_oneway(a, b, c)
print("F =", round(res.statistic, 2), " p =", f"{res.pvalue:.2e}")
print(stats.tukey_hsd(a, b, c))
```

ANOVA의 p-value가 작으면 "적어도 하나는 다르다"까지만 말할 수 있습니다. 어느 쌍이 다른지는 **사후검정** Tukey HSD로 봅니다. 위 결과에서는 B만 A·C와 다르고, A와 C는 차이가 없습니다.

> ANOVA는 집단마다 분산이 비슷하고 대략 정규분포라고 가정합니다. 분포가 크게 치우쳤거나 이상치가 있으면 순위 기반의 `stats.kruskal`을 함께 확인하세요.
