## 평균을 낼 수 없는 데이터

지금까지 배운 t검정은 **평균**을 비교했습니다. 그런데 "성별과 생존 여부는 관련이 있을까?"처럼 두 변수가 모두 **범주형**이면 평균을 낼 수 없습니다. 성별의 평균, 생존 여부의 평균 같은 건 의미가 없으니까요([척도](#/l/st-00-2)).

범주형 데이터는 **개수를 세서 표로** 정리합니다. [조건부확률](#/l/st-09-2)에서 만든 **교차표**가 그것입니다. 이번 레슨에서는 이 교차표를 보고 "두 범주형 변수가 서로 관련이 있는가(독립이 아닌가)"를 검정하는 **카이제곱 검정**(chi-square test)을 배웁니다. 카이(χ)는 그리스 문자입니다.

## 관측도수: 실제로 센 표

타이타닉 승객의 성별과 생존 여부 교차표를 다시 만듭니다. 실제로 센 이 숫자들을 **관측도수**(observed frequency)라고 합니다.

```run
import pandas as pd

df = pd.read_csv("titanic.csv")
print(pd.crosstab(df["sex"], df["survived"], margins=True))
```

여성 314명 중 233명, 남성 577명 중 109명이 생존했습니다. 가설을 세웁니다.

- H₀: 성별과 생존은 **관련이 없다** (독립이다)
- H₁: 성별과 생존은 관련이 있다

## 기대도수: 관련이 없다면 이랬을 표

[가설검정](#/l/st-05-1)의 핵심은 "H₀가 맞는 세상"을 상상하는 것이었습니다. 성별과 생존이 **아무 관련이 없다면**, 표는 어떻게 생겼을까요?

전체 생존율은 342 ÷ 891 = 38.4%입니다. 성별과 관련이 없다면 여성도 남성도 똑같이 38.4%가 살아남았어야 합니다. 그러면 여성 314명 중 생존자는 314 × 0.384 = 120.5명이 "기대"됩니다. 이렇게 **H₀가 맞을 때 기대되는 개수**를 **기대도수**(expected frequency)라고 합니다. 칸마다 공식은 같습니다.

> 기대도수 = (그 행의 합계 × 그 열의 합계) ÷ 전체 합계

::figure{src="content/img/stats/st06-observed-expected.svg" alt="왼쪽은 관측표(여성 사망 81, 생존 233, 남성 사망 468, 생존 109), 오른쪽은 기대표(여성 사망 193.5, 생존 120.5, 남성 사망 355.5, 생존 221.5). 여성 생존 칸은 관측 233이 기대 120.5보다 훨씬 많아 강조" caption="관련이 없다면 여성 생존자는 120.5명쯤이어야 하는데 실제로는 233명이었습니다. 이 어긋남을 모든 칸에서 모아 점수를 매기는 것이 카이제곱 통계량입니다."}

```run
import numpy as np
import pandas as pd

df = pd.read_csv("titanic.csv")
ct = pd.crosstab(df["sex"], df["survived"])
expected = np.outer(ct.sum(axis=1), ct.sum(axis=0)) / ct.to_numpy().sum()
print("기대도수:\n", expected.round(1))
```

관련이 없었다면 여성 생존자는 120.5명, 남성 생존자는 221.5명이어야 합니다. 실제로는 여성 233명, 남성 109명이었습니다. 표가 기대와 크게 어긋납니다. `np.outer`는 행 합계와 열 합계를 칸마다 곱해 주는 함수입니다.

## 카이제곱 통계량: 어긋남 점수

관측과 기대가 얼마나 어긋났는지를 숫자 하나로 모읍니다. 칸마다 (관측 − 기대)²을 기대로 나누고 모두 더합니다.

> χ² = Σ (관측 − 기대)² ÷ 기대

제곱하는 이유는 [분산](#/l/st-01-2)처럼 +와 −가 상쇄되지 않게 하려는 것이고, 기대로 나누는 이유는 "기대가 큰 칸에서 10명 차이"보다 "기대가 작은 칸에서 10명 차이"가 더 놀라운 일이기 때문입니다. 관련이 없다면 이 값은 작고, 어긋날수록 커집니다.

```run
import numpy as np
import pandas as pd

df = pd.read_csv("titanic.csv")
ct = pd.crosstab(df["sex"], df["survived"])
expected = np.outer(ct.sum(axis=1), ct.sum(axis=0)) / ct.to_numpy().sum()
print("카이제곱 통계량:", round(((ct.to_numpy() - expected) ** 2 / expected).sum(), 2))
```

카이제곱 통계량은 263.05입니다. 이 값이 얼마나 큰 건지는 H₀ 아래에서 이 통계량이 따르는 **카이제곱분포**와 비교해서 p-value로 판단합니다.

## scipy로 한 번에: chi2_contingency

`stats.chi2_contingency(교차표)`가 기대도수, 통계량, 자유도, p-value를 한 번에 계산해 줍니다.

```run
import pandas as pd
from scipy import stats

df = pd.read_csv("titanic.csv")
res = stats.chi2_contingency(pd.crosstab(df["sex"], df["survived"]))
print("χ² =", round(res.statistic, 2), "/ 자유도 =", res.dof, "/ p-value =", f"{res.pvalue:.1e}")
```

p-value가 1.2e-58로 0에 한없이 가깝습니다. 성별과 생존이 관련 없다면 이런 표는 사실상 나올 수 없습니다. **H₀를 기각**하고, 성별과 생존은 관련이 있다고 결론 내립니다.

통계량이 260.72로 직접 계산한 263.05와 조금 다른 이유는, 2 × 2 표일 때 scipy가 작은 표본에서의 오차를 줄이는 **연속성 보정**(Yates 보정)을 자동으로 하기 때문입니다. `correction=False`를 주면 직접 계산한 값과 같아집니다. 표본이 클 때는 결론이 거의 달라지지 않습니다.

## 자유도: 표의 크기

카이제곱 검정의 **자유도**는 표의 크기로 정해집니다.

> 자유도 = (행의 수 − 1) × (열의 수 − 1)

성별 2 × 생존 2 표면 (2 − 1) × (2 − 1) = 1입니다. 행 합계와 열 합계가 정해져 있으면, 2 × 2 표에서는 한 칸만 정하면 나머지 세 칸이 자동으로 정해지기 때문입니다. "자유롭게 정할 수 있는 칸의 수"라고 생각하면 됩니다.

객실 등급(3개) × 생존(2개)이라면 자유도는 (3 − 1) × (2 − 1) = 2입니다.

```run
import pandas as pd
from scipy import stats

df = pd.read_csv("titanic.csv")
res = stats.chi2_contingency(pd.crosstab(df["pclass"], df["survived"]))
print("χ² =", round(res.statistic, 2), "/ 자유도 =", res.dof, "/ p-value =", f"{res.pvalue:.1e}")
```

χ² = 102.89, 자유도 2, p-value = 4.5e-23입니다. 객실 등급도 생존과 강하게 관련이 있습니다.

직접 해 보세요: `"pclass"`를 `"embarked"`(탑승 항구: C, Q, S)로 바꿔 보세요. 항구도 생존과 관련이 있을까요? 결과가 유의하게 나와도 "항구가 생존의 원인"이라고 말할 수 있는지 생각해 보세요. (힌트: 어느 항구에서 1등석 승객이 많이 탔을까요? [DAY 11](#/l/st-10-1)에서 다룹니다.)

## 적합도 검정: 기대한 비율대로 나왔나

카이제곱 검정에는 다른 쓰임도 있습니다. **변수 하나**가 우리가 기대한 비율대로 나왔는지 보는 **적합도 검정**(goodness-of-fit test)입니다. 예를 들어 주사위를 600번 던져서 각 눈이 나온 횟수가 공정한 주사위(각 100번씩 기대)와 맞는지 검정합니다.

```run
from scipy import stats

counts = [80, 95, 110, 90, 105, 120]    # 1 ~ 6이 나온 횟수 (합 600)
res = stats.chisquare(counts)            # 기대 비율을 안 주면 모두 같다고 가정
print("χ² =", res.statistic, "/ p-value =", round(res.pvalue, 4))
```

1이 80번, 6이 120번으로 꽤 들쭉날쭉해 보이지만 p-value는 0.062로 0.05보다 큽니다. 공정한 주사위라도 600번 던지면 이 정도 들쭉날쭉함은 6%쯤 나올 수 있으니, 이것만으로는 "조작된 주사위"라고 말할 수 없습니다(기각하지 못함).

## 실무 예제: 유의하지만 약한 관련

설비 데이터에서 품질 등급(`type`)과 고장(`failure`)이 관련 있는지 카이제곱 검정을 해 봅니다.

```run
import pandas as pd
from scipy import stats

df = pd.read_csv("ai4i2020.csv")
res = stats.chi2_contingency(pd.crosstab(df["type"], df["failure"]))
print("χ² =", round(res.statistic, 2), "/ 자유도 =", res.dof, "/ p =", round(res.pvalue, 4))
```

p = 0.001로 유의합니다. 등급과 고장은 "관련이 있다"고 볼 근거가 있습니다. 그런데 관련이 **얼마나 강한지**는 p-value로 알 수 없습니다. 카이제곱의 효과 크기로는 **크래머 V**(Cramér's V)를 씁니다. 0이면 전혀 관련 없음, 1이면 완벽한 관련입니다.

```run
import pandas as pd
from scipy import stats

df, tt = pd.read_csv("ai4i2020.csv"), pd.read_csv("titanic.csv")
print("등급 × 고장 V:", round(stats.contingency.association(pd.crosstab(df["type"], df["failure"])), 3))
print("성별 × 생존 V:", round(stats.contingency.association(pd.crosstab(tt["sex"], tt["survived"])), 3))
```

등급 × 고장의 V는 0.037로 아주 약하고, 타이타닉의 성별 × 생존은 0.543으로 강합니다. 등급별 고장률이 2.1% ~ 3.9%로 다르긴 하지만, 10,000대나 되는 표본이 작은 차이까지 유의하게 만든 것입니다. **"유의하다"와 "강하게 관련 있다"는 다른 말**입니다.

| 크래머 V | 대략적인 해석 |
| --- | --- |
| 0.1 미만 | 매우 약함 |
| 0.1 ~ 0.3 | 약함 |
| 0.3 ~ 0.5 | 중간 |
| 0.5 이상 | 강함 |

## 쓸 때 주의할 점

1. **기대도수가 너무 작으면 부정확합니다.** 기대도수가 5보다 작은 칸이 많으면(대략 20% 이상) 카이제곱 근사가 맞지 않습니다. 이럴 때는 범주를 합치거나, 2 × 2 표라면 `stats.fisher_exact`(피셔의 정확 검정)를 씁니다.
2. **비율이 아니라 개수를 넣어야 합니다.** 교차표에 %를 넣으면 표본 크기 정보가 사라져서 엉뚱한 결과가 나옵니다.
3. **관련이 있다 ≠ 원인이다.** 카이제곱 검정은 "함께 움직인다"는 것만 말해 줍니다. 원인인지는 다른 근거가 필요합니다([DAY 11](#/l/st-10-1)).
4. **관련의 크기는 따로 봐야 합니다.** p-value가 아주 작다고 관련이 아주 강한 것은 아닙니다. 조건부 비율(여성 74% vs 남성 19%)처럼 실제 차이를 함께 보고하세요.

## 정리

- **카이제곱 검정**은 범주형 × 범주형 교차표에서 두 변수가 관련이 있는지(독립이 아닌지) 검정한다.
- **기대도수** = 행 합계 × 열 합계 ÷ 전체 = 관련이 없다면 기대되는 개수.
- χ² = Σ (관측 − 기대)² ÷ 기대. 클수록 "관련 없음"과 어긋난다.
- 자유도 = (행 − 1) × (열 − 1). scipy: `stats.chi2_contingency(교차표)`.
- 변수 하나가 기대 비율을 따르는지는 **적합도 검정** `stats.chisquare`.
