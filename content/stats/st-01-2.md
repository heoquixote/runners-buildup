## 평균이 같으면 같은 데이터일까

두 택배 회사가 있습니다. 둘 다 "평균 배송 기간 3일"이라고 광고합니다. 그런데 A사는 늘 2~4일 사이에 도착하고, B사는 어떤 날은 하루 만에, 어떤 날은 6일이 걸립니다. 내일 꼭 받아야 하는 물건이라면 어느 회사를 고르겠어요?

평균은 같아도 **값이 얼마나 퍼져 있는지**가 다르면 전혀 다른 데이터입니다. 이 퍼진 정도를 **흩어짐**(산포도, dispersion)이라고 합니다. 이번 레슨에서는 범위 · 분산 · 표준편차 · 변동계수를 차례로 배웁니다.

::figure{src="content/img/stats/st01-spread.svg" alt="평균 3일 선을 중심으로 A사 점들은 좁게, B사 점들은 넓게 퍼져 있고, 각 점에서 평균까지 편차 화살표가 그려진 그림" caption="두 회사의 평균(가운데 선)은 같지만, 점들이 평균에서 떨어진 거리(편차)는 B사가 훨씬 큽니다."}

```run
import numpy as np

a = np.array([3, 2, 4, 3, 3, 4, 2, 3])
b = np.array([1, 6, 2, 5, 1, 3, 6, 0])
print("A 평균:", a.mean(), "/ B 평균:", b.mean())
```

두 회사 모두 평균은 3.0일입니다. 평균만 보면 두 회사는 구별되지 않습니다.

## 범위: 가장 큰 값 − 가장 작은 값

가장 쉬운 흩어짐은 **범위**(range)입니다. 최댓값에서 최솟값을 빼면 됩니다.

```run
import numpy as np

a = np.array([3, 2, 4, 3, 3, 4, 2, 3])
b = np.array([1, 6, 2, 5, 1, 3, 6, 0])
print("A 범위:", a.max() - a.min(), "/ B 범위:", b.max() - b.min())
```

A사는 2일, B사는 6일입니다. 벌써 차이가 보이지요. 하지만 범위는 **양 끝 두 값만** 봅니다. 한 번만 유난히 늦게 와도 범위가 확 커지고, 가운데 값들이 어떻게 퍼져 있는지는 알려 주지 않습니다. 그래서 모든 값을 반영하는 지표가 필요합니다.

## 편차: 평균에서 얼마나 떨어졌나

각 값에서 평균을 뺀 것을 **편차**(deviation)라고 합니다. 평균보다 크면 +, 작으면 −입니다. 흩어짐을 재려면 편차들을 모아서 "보통 얼마나 떨어져 있나"를 구하면 될 것 같습니다. 그런데 편차를 그냥 더하면 문제가 생깁니다.

```run
import numpy as np

b = np.array([1, 6, 2, 5, 1, 3, 6, 0])
dev = b - b.mean()
print("편차:", dev)
print("편차의 합:", dev.sum())
```

편차의 합은 0.0입니다. 평균은 시소의 균형점이라서 + 편차와 − 편차가 **항상 정확히 상쇄**되기 때문입니다. 어떤 데이터든 편차의 합은 늘 0이라서 흩어짐을 잴 수 없습니다. 그래서 부호를 없애려고 **제곱**을 합니다.

## 분산: 편차 제곱의 평균

**분산**(variance)은 편차를 제곱해서 평균 낸 값입니다. 제곱하면 음수가 사라지고, 평균에서 멀리 떨어진 값일수록 훨씬 크게 반영됩니다.

```run
import numpy as np

b = np.array([1, 6, 2, 5, 1, 3, 6, 0])
dev = b - b.mean()
print("직접 계산:", (dev ** 2).mean())
print("np.var  :", np.var(b))
```

B사의 분산은 5.0입니다. 그런데 이 5.0의 단위는 무엇일까요? 편차(일)를 제곱했으니 **일²(일의 제곱)**입니다. "배송 기간이 5 제곱일만큼 흩어져 있다"는 말은 머릿속에 그려지지 않습니다.

## 표준편차: 원래 단위로 돌아오기

분산에 제곱근(√)을 씌우면 원래 단위로 돌아옵니다. 이것이 **표준편차**(standard deviation, std)입니다. "값들이 평균에서 **보통 이 정도** 떨어져 있다"로 읽으면 됩니다.

```run
import numpy as np

a = np.array([3, 2, 4, 3, 3, 4, 2, 3])
b = np.array([1, 6, 2, 5, 1, 3, 6, 0])
print("A 표준편차:", round(np.std(a), 2), "일")
print("B 표준편차:", round(np.std(b), 2), "일")
```

A사는 평균 3일에서 보통 0.71일 정도 벗어나고, B사는 보통 2.24일 정도 벗어납니다. 평균이 같은 두 회사의 차이가 숫자 하나로 드러났습니다.

## 표본이면 n − 1로 나눈다

위에서는 편차 제곱을 **n**(값의 개수)으로 나눴습니다. 그런데 손에 든 데이터가 모집단 전체가 아니라 **표본**이라면, 통계에서는 **n − 1**로 나눕니다.

이유를 간단히 말하면, 표본의 편차는 "표본 자신의 평균"에서 잰 거리라서 진짜 모평균에서 잰 거리보다 조금 작게 나오는 경향이 있습니다. 표본평균은 늘 표본 한가운데에 있으니까요. 나누는 수를 하나 줄여서 그만큼 보정해 주는 것입니다. 이렇게 구한 값을 **표본 표준편차**라고 하고, 실제 분석에서는 거의 항상 이것을 씁니다.

| 함수 | 나누는 수 | 언제 |
| --- | --- | --- |
| `np.std(x)` | n (`ddof=0`, NumPy 기본값) | 모집단 전체를 가진 경우 |
| `np.std(x, ddof=1)` | n − 1 | 표본으로 모집단을 짐작할 때 (대부분) |
| `df["열"].std()` | n − 1 (pandas 기본값) | 표본 표준편차 |

`ddof`는 "빼는 개수"(delta degrees of freedom)라는 뜻입니다. NumPy와 pandas의 기본값이 다르다는 점을 꼭 기억하세요.

```run
import numpy as np
import pandas as pd

b = np.array([1, 6, 2, 5, 1, 3, 6, 0])
print("np.std (n):    ", round(np.std(b), 3))
print("np.std (n-1):  ", round(np.std(b, ddof=1), 3))
print("pandas .std(): ", round(pd.Series(b).std(), 3))
```

같은 데이터인데 NumPy 기본값은 2.236, n − 1로 나누면 2.390입니다. pandas는 처음부터 2.390을 줍니다. 값이 8개뿐이라 차이가 꽤 나지만, 데이터가 수백 개면 차이는 거의 사라집니다.

## 실데이터: 펭귄 세 종의 몸무게

남극 펭귄 데이터(`penguins.csv`)로 종마다 몸무게(g)의 평균과 표준편차를 봅니다. `agg`로 여러 요약을 한 번에 구할 수 있습니다.

```run
import pandas as pd

df = pd.read_csv("penguins.csv").dropna()
print(df.groupby("species")["body_mass_g"].agg(["mean", "std"]).round(0))
```

Adelie와 Chinstrap은 평균이 약 3,700g으로 비슷하고 표준편차도 380~460g 정도입니다. Gentoo는 평균 5,092g으로 훨씬 무겁고 표준편차도 501g으로 조금 큽니다. "Adelie 펭귄은 보통 3,706g ± 459g 정도"처럼 평균과 표준편차를 함께 말하면 데이터의 모습이 훨씬 또렷해집니다.

## 단위가 다르면: 변동계수

이번엔 펭귄의 몸무게(g)와 지느러미 길이(mm) 중 어느 쪽이 더 들쭉날쭉한지 비교해 봅시다. 표준편차를 바로 비교하면 될까요?

```run
import pandas as pd

df = pd.read_csv("penguins.csv").dropna()
print("몸무게 std:", round(df["body_mass_g"].std(), 1), "g")
print("지느러미 std:", round(df["flipper_length_mm"].std(), 1), "mm")
```

몸무게 표준편차는 805.2g, 지느러미는 14.0mm입니다. 숫자만 보면 몸무게가 57배나 더 흩어진 것 같지만, g과 mm는 단위가 달라서 비교할 수 없습니다. 몸무게 단위를 kg으로 바꾸면 0.8이 되니까요.

이럴 때 **변동계수**(CV, coefficient of variation)를 씁니다. 표준편차를 평균으로 나눈 값으로, "평균에 비해 몇 % 정도 흩어져 있나"를 말해 줍니다. 단위가 나눗셈으로 사라지기 때문에 서로 다른 변수끼리 비교할 수 있습니다.

```run
import pandas as pd

df = pd.read_csv("penguins.csv").dropna()
for col in ["body_mass_g", "flipper_length_mm"]:
    print(col, "CV =", round(df[col].std() / df[col].mean(), 3))
```

몸무게의 CV는 0.191(평균의 약 19%), 지느러미는 0.070(약 7%)입니다. 평균 대비로 보면 몸무게가 약 2.7배 더 들쭉날쭉합니다.

직접 해 보세요: 공장 설비 데이터(`ai4i2020.csv`)에서 공기 온도(`air_temp`), 회전 속도(`rpm`), 토크(`torque`)의 CV를 비교해 보세요. 어느 값이 가장 안정적일까요?

```run
import pandas as pd

df = pd.read_csv("ai4i2020.csv")
for col in ["air_temp", "rpm", "torque"]:
    print(col, "CV =", round(df[col].std() / df[col].mean(), 3))
```

공기 온도의 CV는 0.007로 거의 흔들리지 않고, 회전 속도는 0.117, 토크는 0.249로 가장 들쭉날쭉합니다. 단, 공기 온도는 켈빈(K) 단위라 평균이 300으로 커서 CV가 작게 나온 면도 있습니다. 평균이 0에 가깝거나, 0이 "없음"을 뜻하지 않는 값(섭씨온도처럼 등간척도)에는 CV를 쓰지 않는 것이 원칙입니다.

## 실무 예제: 평균은 같고 흩어짐도 같을까

공장에서는 평균보다 **흩어짐**이 품질을 좌우하는 경우가 많습니다. 평균 두께가 규격에 딱 맞아도, 들쭉날쭉하면 규격을 벗어나는 제품이 생기니까요. 설비 데이터에서 품질 등급(`type`)별 토크(Nm)의 평균과 표준편차를 봅니다.

```run
import pandas as pd

df = pd.read_csv("ai4i2020.csv")
print(df.groupby("type")["torque"].agg(["count", "mean", "std"]).round(2))
```

세 등급 모두 평균 약 40Nm, 표준편차 약 10Nm로 거의 같습니다. "등급에 따라 토크 조건이 다르지 않다"는 뜻입니다. 이렇게 그룹별 평균과 표준편차를 나란히 놓는 표는 보고서에서 가장 자주 쓰는 형태입니다.

표준편차가 감으로 와닿지 않는다면, **평균 ± 2 × 표준편차 안에 값이 몇 %나 들어가는지** 세어 보세요.

```run
import pandas as pd

t = pd.read_csv("ai4i2020.csv")["torque"]
m, s = t.mean(), t.std()
print(f"평균 {m:.1f}, 표준편차 {s:.1f} → {m - 2 * s:.1f} ~ {m + 2 * s:.1f} 안의 비율: {((t - m).abs() <= 2 * s).mean():.1%}")
```

토크의 95.3%가 20.0 ~ 59.9Nm 안에 들어갑니다. 값이 종 모양으로 퍼져 있으면 평균 ± 2σ 안에 약 95%가 들어간다는 규칙이 있는데([정규분포](#/l/st-02-3)), 실제 데이터에서도 거의 맞습니다. 그래서 "토크는 보통 40 ± 10Nm, 대부분 20 ~ 60Nm 사이"처럼 말할 수 있습니다.

## 자주 하는 실수

1. **표준편차를 "좋다·나쁘다"로 절대 해석한다.** 표준편차 2가 큰지 작은지는 평균과 단위, 목적에 따라 다릅니다.
2. **이상치가 많은 데이터에 표준편차 하나만 쓴다.** 표준편차도 평균처럼 극단값에 크게 흔들립니다. 이런 데이터에는 가운데 50%의 폭인 IQR이 더 안정적입니다([위치와 이상치: 사분위수 · 상자그림 · z점수](#/l/st-01-3)).
3. **단위가 다른 변수의 표준편차를 그대로 비교한다.** 변동계수나 표준화([z점수](#/l/st-01-3))를 쓰세요.

## 정리

- **범위**는 쉽지만 양 끝 두 값만 본다.
- 편차의 합은 늘 0이라서 제곱해 평균 낸 것이 **분산**, 그 제곱근이 **표준편차**(원래 단위, "보통 이만큼 떨어져 있다").
- 표본이면 n − 1로 나눈다. NumPy 기본값(`ddof=0`)과 pandas 기본값(n − 1)이 다르다.
- 단위나 크기가 다른 변수끼리는 **변동계수**(표준편차 ÷ 평균)로 비교한다.
