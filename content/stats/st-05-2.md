## 화재경보기의 두 가지 실수

화재경보기는 두 가지 방식으로 틀릴 수 있습니다.

1. **불이 안 났는데 울린다.** 생선 굽는 연기에 경보가 울려서 모두 밖으로 대피했습니다. 귀찮지만 큰일은 아닙니다.
2. **불이 났는데 안 울린다.** 이건 훨씬 위험합니다.

경보기를 아주 예민하게 만들면 2번 실수는 줄지만 1번 실수(헛경보)가 늘어납니다. 둔하게 만들면 반대입니다. 두 실수를 동시에 0으로 만들 수는 없습니다.

[지난 레슨](#/l/st-05-1)에서 배운 가설검정도 똑같이 두 가지 방식으로 틀릴 수 있습니다. 검정 결과는 "기각" 아니면 "기각하지 못함"인데, 진실은 우리가 모르는 채로 정해져 있으니까요.

## 판단의 네 가지 경우

::figure{src="content/img/stats/st05-error-table.svg" alt="2행 2열 표. 열은 실제(차이 없음, 차이 있음), 행은 판단(기각, 기각하지 못함). 차이 없음·기각 칸은 1종 오류(α), 차이 있음·기각하지 못함 칸은 2종 오류(β), 나머지 두 칸은 올바른 판단이고 차이 있음·기각 칸은 검정력(1 − β)" caption="검정의 판단과 실제가 어긋나는 두 칸이 1종 오류와 2종 오류입니다. 진짜 차이를 제대로 잡아내는 칸이 검정력입니다."}

| | 실제로 **차이 없음** (H₀ 참) | 실제로 **차이 있음** (H₀ 거짓) |
| --- | --- | --- |
| **기각한다** ("차이 있다") | ❌ **1종 오류** (헛경보), 확률 α | ⭕ 올바른 발견, 확률 **검정력** = 1 − β |
| **기각하지 못한다** | ⭕ 올바른 판단 | ❌ **2종 오류** (놓침), 확률 β |

- **1종 오류**(Type I error): 없는 차이를 있다고 말하는 실수. "효과 없는 약을 효과 있다고 판정"
- **2종 오류**(Type II error): 있는 차이를 놓치는 실수. "효과 있는 약을 효과 없다고 판정"
- **검정력**(power) = 1 − β: 진짜 차이가 있을 때 그것을 **잡아낼 확률**. 경보기가 진짜 불에 울릴 확률입니다.

## 1종 오류의 확률은 α

유의수준 α = 0.05로 정했다는 것은 "H₀가 참일 때 잘못 기각할 확률(1종 오류)을 5%로 허용하겠다"는 뜻입니다. 정말 그런지 시뮬레이션으로 확인해 봅니다.

**차이가 전혀 없는** 두 반이 있습니다. 둘 다 시험 점수가 평균 50점, 표준편차 10점인 같은 분포에서 나옵니다. 각 반에서 20명씩 뽑아 두 반 평균을 비교하는 t검정([다음 레슨](#/l/st-05-3)에서 자세히 배웁니다)을 1,000번 반복하고, p < 0.05로 "차이 있다"고 잘못 판단한 비율을 셉니다. `rng.normal(50, 10, (1000, 20))`은 20명짜리 반을 1,000개 한꺼번에 만듭니다.

```run
import numpy as np
from scipy import stats

rng = np.random.default_rng(0)
a, b = rng.normal(50, 10, (1000, 20)), rng.normal(50, 10, (1000, 20))
p = stats.ttest_ind(a, b, axis=1).pvalue
print("차이가 없는데 '차이 있다'고 판단한 비율:", (p < 0.05).mean())
```

0.056으로, 약속한 5% 근처입니다. 진짜 차이가 없어도 검정을 100번 하면 5번쯤은 "유의하다"는 결과가 나옵니다. **이것은 검정의 실수가 아니라, α = 0.05를 고른 순간 받아들인 대가입니다.**

## 검정력: 진짜 차이를 잡아낼 확률

이번엔 새 공부법을 쓴 반의 평균이 **진짜로 5점 높은**(55점) 상황을 만듭니다. 차이가 실제로 있으니 기각하는 것이 정답입니다. 20명씩 비교하면 1,000번 중 몇 번이나 차이를 잡아낼까요?

```run
import numpy as np
from scipy import stats

rng = np.random.default_rng(0)
a, b = rng.normal(50, 10, (1000, 20)), rng.normal(55, 10, (1000, 20))
p = stats.ttest_ind(a, b, axis=1).pvalue
print("진짜 차이를 잡아낸 비율(검정력):", (p < 0.05).mean())
```

검정력은 0.329, 겨우 33%입니다. 새 공부법이 진짜로 5점을 올려 주는데도, 한 반 20명으로 비교하면 3번 중 2번은 "차이를 확인하지 못했다"는 결론이 나옵니다(2종 오류 β = 0.67). [지난 레슨](#/l/st-05-1)에서 "기각하지 못함 ≠ 차이 없음"이라고 한 이유가 바로 이것입니다.

## 두 분포가 겹치는 정도

왜 이렇게 놓치는 걸까요? 그림으로 보면 이해가 쉽습니다.

::figure{src="content/img/stats/st05-power-curves.svg" alt="두 개의 종 모양 곡선. 왼쪽은 H0가 맞을 때 평균 차이의 분포, 오른쪽은 실제 차이가 있을 때의 분포. 기각 경계선 오른쪽, 왼쪽 곡선의 꼬리는 α, 경계선 왼쪽 오른쪽 곡선 부분은 β, 경계선 오른쪽 오른쪽 곡선 부분은 검정력. 아래 그림은 표본이 커져 두 곡선이 좁아지고 덜 겹친다" caption="두 곡선이 많이 겹칠수록 놓치는 부분(β)이 큽니다. 표본을 키우면 곡선이 좁아져 겹침이 줄고 검정력이 올라갑니다."}

- 왼쪽 곡선: 차이가 없을 때(H₀) 표본에서 나올 수 있는 평균 차이의 분포
- 오른쪽 곡선: 진짜 차이(5점)가 있을 때 나올 수 있는 평균 차이의 분포
- 세로선: 기각 경계(α로 정함). 오른쪽에 떨어지면 "차이 있다"

두 곡선이 많이 겹치면, 진짜 차이가 있어도 표본 차이가 경계선 왼쪽에 떨어져서 놓치게 됩니다. 곡선의 폭은 [표준오차](#/l/st-03-2)이므로, **표본을 키우면 곡선이 좁아져서 겹침이 줄고 검정력이 올라갑니다.**

## 표본을 키우면 검정력이 오른다

같은 5점 차이를 한 반 20명, 50명, 100명으로 비교해 봅니다.

```run
import numpy as np
from scipy import stats

for n in [20, 50, 100]:
    rng = np.random.default_rng(0)
    p = stats.ttest_ind(rng.normal(50, 10, (1000, n)), rng.normal(55, 10, (1000, n)), axis=1).pvalue
    print(f"한 반 {n}명 → 검정력 {(p < 0.05).mean():.3f}")
```

20명이면 0.329, 50명이면 0.689, 100명이면 0.931입니다. 보통 실험을 설계할 때는 검정력이 **80% 이상**이 되도록 표본 수를 정합니다. 이 예라면 한 반에 60~70명 정도가 필요합니다. 표본 수를 계산하는 방법은 [DAY 10](#/l/st-08-2)에서 배웁니다.

검정력은 **차이의 크기**에도 달려 있습니다. 차이가 클수록 두 곡선이 멀리 떨어져서 잡아내기 쉽습니다.

직접 해 보세요: 아래 셀의 `diff`를 2, 5, 10으로 바꿔 보세요(한 반 50명 고정).

```run
import numpy as np
from scipy import stats

diff = 2
rng = np.random.default_rng(0)
p = stats.ttest_ind(rng.normal(50, 10, (1000, 50)), rng.normal(50 + diff, 10, (1000, 50)), axis=1).pvalue
print(f"차이 {diff}점, 한 반 50명 → 검정력 {(p < 0.05).mean():.3f}")
```

차이가 2점이면 검정력 0.159, 5점이면 0.689, 10점이면 1.000입니다. 작은 차이를 잡으려면 훨씬 많은 표본이 필요합니다.

## α와 β는 시소

그럼 α를 0.01로 엄격하게 낮추면 어떨까요? 헛경보(1종 오류)는 줄지만, 기각 경계선이 오른쪽으로 밀리면서 놓치는 경우(2종 오류)가 늘어납니다.

```run
import numpy as np
from scipy import stats

rng = np.random.default_rng(0)
p = stats.ttest_ind(rng.normal(50, 10, (1000, 50)), rng.normal(55, 10, (1000, 50)), axis=1).pvalue
print("α = 0.05 검정력:", (p < 0.05).mean(), "/ α = 0.01 검정력:", (p < 0.01).mean())
```

같은 데이터에서 α = 0.05면 검정력 0.689, α = 0.01이면 0.450으로 떨어집니다. 화재경보기처럼 **두 실수 중 어느 쪽이 더 큰 손해인지**를 따져서 α를 정해야 합니다.

| 상황 | 더 무서운 실수 | 선택 |
| --- | --- | --- |
| 새 약 승인 | 효과 없는 약을 승인 (1종) | α를 낮게 (0.01) |
| 암 1차 검진 | 환자를 놓침 (2종) | 민감하게, 이후 정밀 검사로 확인 |
| 웹사이트 버튼 색 테스트 | 둘 다 손해가 작음 | 관례대로 α = 0.05, 검정력 80% |

## 검정을 여러 번 하면 헛경보가 쌓인다

마지막으로 꼭 기억할 함정이 있습니다. 검정 한 번의 헛경보 확률은 5%지만, **검정을 여러 번 하면** 그중 하나라도 헛경보가 날 확률은 빠르게 커집니다. 차이가 전혀 없는 비교를 20번 한다면?

```run
print("20번 검정 중 적어도 한 번 헛경보:", round(1 - 0.95 ** 20, 3))
```

64%입니다. 시험 점수를 과목 20개로 나눠 비교하면, 아무 차이가 없어도 "수학에서 유의한 차이 발견!" 같은 결과가 하나쯤 나올 가능성이 높습니다. 이것을 **다중비교 문제**라고 하고, [ANOVA](#/l/st-06-2)와 [A/B 테스트](#/l/st-08-2)에서 대처법을 배웁니다.

## 실무 예제: 몇 대씩 조사해야 고장 신호를 잡을까

고장 설비는 정상 설비보다 토크가 평균 약 10Nm 높습니다(전체 데이터 기준). 이 진짜 차이를 그룹당 k대씩 조사해서 t검정으로 잡아낼 확률(검정력)을 시뮬레이션으로 구합니다. 각 k마다 1,000번 실험합니다.

```run
import numpy as np
import pandas as pd
from scipy import stats

df = pd.read_csv("ai4i2020.csv")
f, o, rng = df.query("failure == 1")["torque"].to_numpy(), df.query("failure == 0")["torque"].to_numpy(), np.random.default_rng(0)
for k in [5, 10, 20, 40]:
    print(f"그룹당 {k}대: 검정력 {np.mean([stats.ttest_ind(rng.choice(f, k), rng.choice(o, k), equal_var=False).pvalue < 0.05 for _ in range(1000)]):.2f}")
```

그룹당 5대면 검정력이 0.32로, 진짜 차이를 세 번 중 두 번은 놓칩니다. 20대면 0.66, 40대면 0.91입니다. 실무에서 흔히 목표로 하는 검정력 80%를 넘기려면 그룹당 30대 이상이 필요하다는 것을 **조사를 시작하기 전에** 알 수 있습니다.

이런 계산을 미리 하지 않고 5대씩만 조사한 뒤 "유의한 차이가 없었으니 토크는 고장과 관계없다"고 결론 내렸다면, 중요한 원인을 놓친 2종 오류가 됩니다.

## 자주 하는 실수

1. **검정력을 따지지 않고 "차이 없음"을 결론으로 쓴다.** 표본이 작은 연구의 "유의하지 않음"은 거의 정보가 없습니다.
2. **실험이 끝난 뒤 검정력을 계산해 변명한다.** 검정력은 표본 수를 정하기 위해 **실험 전에** 계산하는 것입니다.
3. **1종 오류만 걱정한다.** 안전 점검, 불량 검출처럼 놓치는 것이 더 비싼 상황에서는 β(놓칠 확률)를 줄이는 쪽이 더 중요할 수 있습니다.

## 정리

- **1종 오류**: 없는 차이를 있다고 판단(헛경보), 확률 α. **2종 오류**: 있는 차이를 놓침, 확률 β.
- **검정력** = 1 − β = 진짜 차이를 잡아낼 확률. 보통 80% 이상을 목표로 한다.
- 검정력은 **표본 크기**가 클수록, **차이**가 클수록, α가 클수록 높아진다.
- α와 β는 시소. 어느 실수가 더 큰 손해인지 따져서 정한다.
- 검정을 여러 번 하면 헛경보가 쌓인다(**다중비교**).
