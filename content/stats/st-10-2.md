## 분석의 마지막 단계는 "말하기"

분석을 아무리 잘해도, 결과를 읽는 사람이 오해하면 소용이 없습니다. 통계 결과는 대부분 통계를 배우지 않은 사람(선생님, 사장님, 팀원, 고객)이 읽습니다. 이번 마지막 레슨에서는 지금까지 배운 숫자들을 **정직하고 알아듣기 쉬운 문장**으로 바꾸는 법을 배웁니다.

먼저 나쁜 보고의 예를 봅시다.

> ❌ "저녁 손님과 점심 손님의 계산 금액을 t검정했더니 p = 0.002로 유의했습니다!"

틀린 말은 없지만, 읽는 사람은 아무것도 알 수 없습니다. 몇 명을 비교했는지, 얼마나 차이가 났는지, 그 차이를 얼마나 믿을 수 있는지, 그래서 무엇을 하라는 건지가 빠져 있습니다. 같은 결과를 이렇게 바꿔 봅시다.

> ⭕ "저녁 계산서(176건)의 평균 금액은 20.80달러로 점심(68건) 17.17달러보다 3.63달러(21%) 높았습니다(95% CI 1.33 ~ 5.93달러, Welch t검정 p = 0.002). 저녁 메뉴의 단가를 기준으로 매출 계획을 세울 때 이 차이를 반영할 만합니다. 다만 이 데이터는 한 식당, 한 시기의 기록이므로 다른 매장에 그대로 적용하기는 어렵습니다."

## 결과 보고에 꼭 들어갈 다섯 가지

::figure{src="content/img/stats/st10-report-frame.svg" alt="보고 문단의 네 칸 틀: 1 무엇을 봤나(대상·표본 수), 2 얼마나 다른가(요약값과 차이, 효과 크기), 3 얼마나 확실한가(신뢰구간, p-value), 4 그래서 무엇을(해석·한계·행동)" caption="좋은 보고 문단은 '무엇을 봤나 → 얼마나 다른가 → 얼마나 확실한가 → 그래서 무엇을'의 네 칸을 채웁니다."}

| 항목 | 왜 필요한가 | 예 |
| --- | --- | --- |
| **표본 수** (n) | 결과가 몇 개의 데이터에서 나왔는지 | 저녁 176건, 점심 68건 |
| **요약값** | 각 그룹이 어땠는지 (치우쳤으면 중앙값도) | 평균 20.80 vs 17.17달러 |
| **효과 크기** | 차이가 얼마나 큰지, 단위와 함께 | +3.63달러 (+21%) |
| **신뢰구간** | 그 차이를 얼마나 믿을 수 있는지 | 95% CI 1.33 ~ 5.93달러 |
| **p-value** | 우연으로 설명될 수 있는지 | p = 0.002 |

p-value만 적는 것은 다섯 개 중 하나만 적는 것입니다. [DAY 10](#/l/st-08-2)에서 본 것처럼 p-value는 효과의 크기를 말해 주지 않습니다.

## 직접 만들어 보기: 재료 모으기

위 보고 문장의 숫자들을 직접 계산해 봅니다. 먼저 그룹별 표본 수, 평균, 중앙값입니다.

```run
import pandas as pd

df = pd.read_csv("tips.csv")
print(df.groupby("time")["total_bill"].agg(["count", "mean", "median"]).round(2))
```

저녁 176건 평균 20.80달러(중앙값 18.39), 점심 68건 평균 17.17달러(중앙값 15.96)입니다. 평균과 중앙값이 같은 방향으로 차이 나니, 몇몇 큰 계산서 때문에 생긴 차이는 아닙니다.

다음은 차이와 Welch t검정입니다. scipy의 t검정 결과에는 `confidence_interval()`이 있어서 **차이의 신뢰구간**도 바로 구할 수 있습니다.

```run
import pandas as pd
from scipy import stats

df = pd.read_csv("tips.csv")
dinner, lunch = df.query("time == 'Dinner'")["total_bill"], df.query("time == 'Lunch'")["total_bill"]
res = stats.ttest_ind(dinner, lunch, equal_var=False)
ci = res.confidence_interval(0.95)
print(f"차이 {dinner.mean() - lunch.mean():.2f}달러, 95% CI {ci.low:.2f} ~ {ci.high:.2f}, p = {res.pvalue:.3f}")
```

차이 3.63달러, 95% 신뢰구간 1.33 ~ 5.93달러, p = 0.002입니다. 재료가 다 모였습니다.

## 보고 문장을 코드로 만들기

숫자를 손으로 옮겨 적다 보면 실수가 생깁니다. f-string으로 계산 결과에서 바로 문장을 만들면 숫자가 바뀌어도 문장이 자동으로 따라옵니다.

```run
import pandas as pd
from scipy import stats

df = pd.read_csv("tips.csv")
d, l = df.query("time == 'Dinner'")["total_bill"], df.query("time == 'Lunch'")["total_bill"]
res = stats.ttest_ind(d, l, equal_var=False); ci = res.confidence_interval(); diff = d.mean() - l.mean()
print(f"저녁({len(d)}건) 평균 {d.mean():.2f}달러, 점심({len(l)}건) {l.mean():.2f}달러로 저녁이 {diff:.2f}달러({diff / l.mean():.0%}) 높았다 (95% CI {ci.low:.2f} ~ {ci.high:.2f}달러, p = {res.pvalue:.3f}).")
```

이렇게 만든 문장은 그대로 보고서에 붙일 수 있습니다.

## 유의하지 않은 결과도 정직하게

결과가 유의하지 않을 때도 보고해야 합니다. "아무것도 안 나왔다"가 아니라 **"이만큼의 차이까지는 배제할 수 있다"**는 정보가 있기 때문입니다. 흡연 여부에 따라 팁 비율(팁 ÷ 계산 금액 × 100)이 다른지 봅니다.

```run
import pandas as pd
from scipy import stats

df = pd.read_csv("tips.csv").assign(rate=lambda x: x["tip"] / x["total_bill"] * 100)
yes, no = df.query("smoker == 'Yes'")["rate"], df.query("smoker == 'No'")["rate"]
res = stats.ttest_ind(yes, no, equal_var=False); ci = res.confidence_interval()
print(f"흡연 {len(yes)}건 {yes.mean():.2f}% / 비흡연 {len(no)}건 {no.mean():.2f}% / 차이 95% CI {ci.low:.2f} ~ {ci.high:.2f}%p / p = {res.pvalue:.2f}")
```

흡연 손님 16.32%, 비흡연 손님 15.93%로 차이는 0.39%p, p = 0.68입니다. 이렇게 보고합니다.

> "흡연 여부에 따른 팁 비율 차이는 확인되지 않았습니다(흡연 93건 16.3% vs 비흡연 151건 15.9%, 차이 95% CI −1.5 ~ +2.2%p, p = 0.68). 이 데이터로는 두 그룹의 차이가 있더라도 대략 ±2%p 이내일 것으로 보입니다."

"차이가 없다"고 단정하지 않고, 신뢰구간으로 **차이가 있다면 어느 정도까지일지**를 알려 주는 것이 핵심입니다.

## 관측과 해석을 나눠 쓰기

보고서에서 가장 흔한 실수는 **본 것**과 **생각한 것**을 섞어 쓰는 것입니다.

| 관측 (데이터가 말하는 것) | 해석 (분석가의 판단) |
| --- | --- |
| 저녁 계산서 평균이 점심보다 3.63달러 높았다 | 저녁에는 술이나 코스 요리를 주문하는 경우가 많아서일 수 있다 |
| 1등석 승객의 생존율이 3등석의 2.6배였다 | 구명보트와 가까운 객실 위치가 영향을 줬을 것이다 |

관측은 숫자로 확인할 수 있지만, 해석은 데이터 밖의 지식이 들어간 추측입니다. 두 가지를 다른 문단(또는 "결과"와 "해석" 제목)으로 나누면 읽는 사람이 무엇을 믿고 무엇을 검토해야 할지 알 수 있습니다.

## 한계를 쓰는 것은 약점이 아니다

좋은 보고서는 결론이 **어디까지 통하는지**를 스스로 밝힙니다. [DAY 01](#/l/st-00-1)의 세 문장 중 마지막 두 문장입니다.

- **표본의 범위**: "한 식당, 몇 달 동안의 기록이다" ([표본과 편향](#/l/st-03-1))
- **인과가 아님**: "관찰 데이터라서 원인이라고 말할 수는 없다" ([상관과 인과](#/l/st-10-1))
- **측정 방법**: "팁은 카드 결제분만 기록되었다"
- **분석 선택**: "이상치 3건을 제외했다. 포함해도 결론은 같았다"

한계를 숨기면 나중에 누군가 발견했을 때 결과 전체의 신뢰를 잃습니다. 먼저 밝히면 오히려 신뢰를 얻습니다.

## 그래프 하나로 보여 주기: 오차 막대

보고서에 그래프를 하나만 넣는다면, 평균과 **신뢰구간을 오차 막대로** 함께 그린 그래프가 좋습니다. 막대 끝만 보여 주는 그래프보다 "얼마나 확실한지"가 한눈에 보입니다.

```run
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
from scipy import stats

df = pd.read_csv("tips.csv")
g = df.groupby("day")["total_bill"]; mean, se, n = g.mean(), g.sem(), g.count()
half = stats.t.ppf(0.975, n - 1) * se
plt.errorbar(mean.index, mean, yerr=half, fmt="o", capsize=5); plt.ylabel("mean total bill (95% CI)"); plt.show()
print((mean - half).round(1).to_dict(), (mean + half).round(1).to_dict())
```

요일별 평균 계산 금액과 95% 신뢰구간입니다. 금요일(Fri)은 표본이 19건뿐이라 구간이 가장 넓고, 토 · 일요일 구간은 서로 많이 겹칩니다. 숫자 표보다 "어느 요일이 확실히 다르고, 어느 요일은 구별이 안 되는지"가 훨씬 빨리 읽힙니다. `g.sem()`은 그룹별 [표준오차](#/l/st-03-2)입니다.

## 실무 예제: 제조 보고서 한 문단 완성하기

설비 데이터로 "공구를 200분 이상 쓴 설비는 고장이 더 잦은가"를 보고하는 문단을 처음부터 만들어 봅니다. 먼저 재료(표본 수, 요약값, 차이, 신뢰구간, p-value)를 모읍니다.

```run
import numpy as np
import pandas as pd
from scipy import stats

df = pd.read_csv("ai4i2020.csv")
hi, lo = df.query("tool_wear >= 200")["failure"], df.query("tool_wear < 200")["failure"]
d, se = hi.mean() - lo.mean(), np.sqrt(hi.mean() * (1 - hi.mean()) / len(hi) + lo.mean() * (1 - lo.mean()) / len(lo))
print(len(hi), len(lo), round(hi.mean() * 100, 1), round(lo.mean() * 100, 1), round(d * 100, 1), round((d - 1.96 * se) * 100, 1), round((d + 1.96 * se) * 100, 1), round(hi.mean() / lo.mean(), 1))
```

숫자가 한 줄로 나왔습니다. 200분 이상 801대, 미만 9,199대, 고장률 15.4% 대 2.3%, 차이 13.0%p(95% CI 10.5 ~ 15.5%p), 고장률 비 6.5배입니다. p-value는 카이제곱 검정으로 구합니다.

```run
import pandas as pd
from scipy import stats

df = pd.read_csv("ai4i2020.csv")
print(f"p = {stats.chi2_contingency(pd.crosstab(df['tool_wear'] >= 200, df['failure'])).pvalue:.1e}")
```

p는 10⁻⁸⁴ 수준이라 "p < 0.001"로 적습니다. 이제 네 칸 틀에 맞춰 씁니다.

> **무엇을 봤나** 설비 10,000대를 공구 사용 시간 200분 기준으로 나눠 고장률을 비교했다(200분 이상 801대, 미만 9,199대).
> **얼마나 다른가** 200분 이상 그룹의 고장률은 15.4%로, 미만 그룹(2.3%)보다 13.0%p 높았다(약 6.5배).
> **얼마나 확실한가** 차이의 95% 신뢰구간은 10.5 ~ 15.5%p였다(카이제곱 검정 p < 0.001).
> **그래서 무엇을** 공구 교체 기준을 200분 전후로 검토할 근거가 된다. 다만 관찰 데이터이므로, 공구 사용 시간이 긴 설비가 다른 조건(토크, 회전 속도)에서도 달랐는지 확인이 필요하다. 200분이라는 기준도 임의로 정한 것이라, 다른 기준(180분, 220분)에서도 결과가 비슷한지 함께 보고하는 것이 좋다.

마지막 칸의 "다만"이 보고서의 신뢰를 높입니다. 읽는 사람이 물어볼 질문을 먼저 답해 두는 것입니다.

## 자주 하는 실수

1. **배수만 강조한다.** "6.5배 증가!"는 강렬하지만, 기준값(2.3%)과 절대 차이(13.0%p)가 없으면 규모를 판단할 수 없습니다. 둘을 함께 씁니다.
2. **기준을 결과가 가장 좋게 나오는 값으로 고르고 숨긴다.** 180, 190, 200, 210분을 다 해 보고 가장 극적인 것만 보고하면 다중비교와 같은 문제가 생깁니다. 기준을 어떻게 정했는지 적습니다.
3. **분석에서 뺀 데이터를 적지 않는다.** 결측치, 이상치, 제외한 기간을 밝히지 않으면 같은 결과를 아무도 재현할 수 없습니다.

## 정리

- 보고에 꼭 넣을 다섯 가지: **표본 수 · 요약값 · 효과 크기 · 신뢰구간 · p-value**.
- 보고 문단 틀: 무엇을 봤나 → 얼마나 다른가 → 얼마나 확실한가 → 그래서 무엇을.
- 유의하지 않은 결과도 신뢰구간과 함께 보고한다. "차이 없음"이라고 단정하지 않는다.
- **관측과 해석을 나누고, 한계를 먼저 밝힌다.**
- 그래프는 평균 + 신뢰구간 오차 막대, 숫자는 단위 · %p · 반올림 규칙을 지킨다.
