## 실험은 몇 명으로 해야 할까

[지난 레슨](#/l/st-08-1)에서 A/B 테스트는 "표본 수를 미리 정하라"고 했습니다. 그럼 몇 명이 적당할까요?

- **너무 적으면**: 진짜 효과가 있어도 놓칩니다. [1종 오류 · 2종 오류 · 검정력](#/l/st-05-2)에서 봤듯이 한 반 20명으로는 5점 차이를 3번 중 2번 놓쳤습니다(검정력 33%). 실험에 들인 시간과 비용이 헛수고가 됩니다.
- **너무 많으면**: 결론을 낼 수 있는 시점을 한참 지나서까지 사용자 절반에게 더 나쁜 버전을 보여 주는 셈이고, 시간도 낭비입니다.

필요한 표본 수는 감으로 정하지 않고 **계산**합니다. 이번 레슨에서는 표본 수를 계산하는 법과, 실험 결과를 실제 결정으로 바꾸는 법을 배웁니다.

## 표본 수를 정하는 네 가지 재료

| 재료 | 뜻 | 예 |
| --- | --- | --- |
| **기준 전환율** p₁ | 지금(A) 전환율. 과거 데이터로 안다 | 4% |
| **검출할 최소 차이** | 이 정도는 올라야 바꿀 가치가 있다 | +1%p (→ 5%) |
| **유의수준** α | 헛경보(1종 오류) 허용치 | 0.05 |
| **검정력** 1 − β | 진짜 차이를 잡아낼 확률 | 0.8 (80%) |

이 네 가지가 정해지면 그룹당 필요한 표본 수 n이 하나로 정해집니다. 두 비율을 비교할 때 쓰는 공식을 함수로 만들어 둡니다. 공식을 외울 필요는 없고, **어떤 재료가 들어가는지**만 보세요. `norm.ppf`로 α와 검정력에 해당하는 z 배수를 구하고, 두 비율의 흩어짐을 차이의 제곱으로 나눕니다.

```run
import numpy as np
from scipy import stats

def n_per_group(p1, p2, alpha=0.05, power=0.8):
    za, zb, pbar = stats.norm.ppf(1 - alpha / 2), stats.norm.ppf(power), (p1 + p2) / 2
    return int(np.ceil((za * np.sqrt(2 * pbar * (1 - pbar)) + zb * np.sqrt(p1 * (1 - p1) + p2 * (1 - p2))) ** 2 / (p2 - p1) ** 2))

print("4% → 5% 를 잡으려면 그룹당:", n_per_group(0.04, 0.05), "명")
```

전환율 4%를 5%로 올리는 효과를 80% 확률로 잡아내려면 **그룹당 6,745명**, 두 그룹 합쳐 약 13,500명이 필요합니다. 하루 방문자가 1,000명이라면 2주쯤 실험해야 한다는 계산이 나옵니다.

## 작은 차이를 잡으려면 훨씬 많이

이번엔 4% → **4.5%**, 차이를 절반(0.5%p)으로 줄여 봅니다.

```run
import numpy as np
from scipy import stats

def n_per_group(p1, p2, alpha=0.05, power=0.8):
    za, zb, pbar = stats.norm.ppf(1 - alpha / 2), stats.norm.ppf(power), (p1 + p2) / 2
    return int(np.ceil((za * np.sqrt(2 * pbar * (1 - pbar)) + zb * np.sqrt(p1 * (1 - p1) + p2 * (1 - p2))) ** 2 / (p2 - p1) ** 2))

print("4% → 4.5%:", n_per_group(0.04, 0.045), "명 / 4% → 5.5%:", n_per_group(0.04, 0.055), "명")
```

차이가 0.5%p면 그룹당 25,551명으로, 1%p일 때(6,745명)의 약 **3.8배**입니다. 차이가 1.5%p면 3,156명으로 줄어듭니다. 공식에서 차이가 분모에 **제곱**으로 들어가기 때문에 **차이를 절반으로 줄이면 필요한 표본은 약 4배**가 됩니다. [표준오차](#/l/st-03-2)에서 본 "4배로 늘려야 절반" 관계와 같은 이야기입니다.

::figure{src="content/img/stats/st08-sample-size.svg" alt="가로축은 검출할 차이(%p), 세로축은 그룹당 필요한 표본 수. 차이가 0.5%p일 때 약 25,500명, 1%p일 때 약 6,700명, 1.5%p일 때 약 3,200명, 2%p일 때 약 1,860명으로 차이가 작아질수록 가파르게 치솟는 곡선" caption="검출할 차이가 작아질수록 필요한 표본 수는 가파르게 늘어납니다. '아주 작은 개선도 놓치지 않겠다'는 목표는 그만큼 비쌉니다."}

그래서 "최소 의미 있는 차이"를 정하는 것이 중요합니다. 0.1%p 개선까지 잡으려고 하면 수십만 명이 필요하지만, 그 정도 개선은 애초에 바꿀 가치가 없을 수도 있습니다.

직접 해 보세요: 위 셀에서 기준 전환율을 `0.10`(10%)으로 바꾸고 `0.11`과 비교해 보세요. 같은 1%p 차이인데 필요한 표본 수가 어떻게 달라지나요? 그리고 `power=0.9`를 넣어 검정력을 90%로 높이면요?

## 시뮬레이션으로 검정력 확인하기

계산한 6,745명이 정말 검정력 80%를 주는지 확인해 봅니다. 실제로 A 4%, B 5%인 실험을 2,000번 시뮬레이션하고, 유의하게 나온 비율을 셉니다. `rng.binomial(n, p, 2000)`은 n명 중 구매자 수를 2,000번 뽑습니다.

```run
import numpy as np

n, rng = 6745, np.random.default_rng(0)
a, b = rng.binomial(n, 0.04, 2000), rng.binomial(n, 0.05, 2000)
p = (a + b) / (2 * n); z = (b - a) / n / np.sqrt(p * (1 - p) * 2 / n)
print("유의하게 나온 비율(검정력):", (abs(z) > 1.96).mean())
```

0.81로, 설계한 대로 약 80%입니다. 거꾸로 말하면 효과가 진짜 있어도 5번 중 1번은 놓친다는 뜻입니다. 이 실험에서 "유의하지 않음"이 나왔다고 B가 효과 없다고 단정할 수 없는 이유입니다.

## 유의하다 ≠ 중요하다

반대 상황도 있습니다. 표본이 **아주 크면** 아주 작은 차이도 유의하게 나옵니다. 그룹당 100만 명이 방문한 대형 서비스에서, 전환율이 4.0% → 4.1%(0.1%p)로 바뀌었다고 해 봅시다.

```run
from scipy import stats

n = 1_000_000
table = [[40_000, n - 40_000], [41_000, n - 41_000]]
print("p-value:", f"{stats.chi2_contingency(table).pvalue:.4f}")
```

p-value = 0.0003으로 아주 유의합니다. 하지만 0.1%p 개선이 새 디자인을 만들고 유지하는 비용보다 가치가 있을까요? 그건 통계가 아니라 **실무적인 판단**입니다. p-value는 "우연이 아니다"를 말할 뿐, "중요하다"를 말해 주지 않습니다.

| 구분 | 질문 | 답하는 도구 |
| --- | --- | --- |
| **통계적 유의성** | 이 차이가 우연이 아닌가? | p-value |
| **효과 크기** | 차이가 얼마나 큰가? | 차이(%p), 신뢰구간 |
| **실무적 중요성** | 이 차이가 비용을 들일 가치가 있나? | 매출 · 비용 계산, 도메인 판단 |

그래서 결과를 보고할 때는 p-value만 적지 말고 **차이와 그 신뢰구간**을 반드시 함께 적습니다([보고하는 법](#/l/st-10-2)).

## 지표를 여러 개 보면: 다중비교

A/B 테스트에서 주 지표(구매 전환율) 하나만 보면 좋겠지만, 실제로는 클릭률, 체류 시간, 재방문율, 장바구니 담기 등 여러 지표를 함께 봅니다. 지표 20개를 각각 α = 0.05로 검정하면, 아무 효과가 없어도 [하나쯤은 유의하게 나올 확률이 64%](#/l/st-05-2)입니다. "구매는 안 늘었지만 장바구니 담기가 유의하게 늘었다!"는 이런 헛경보일 수 있습니다.

대처법은 두 가지입니다.

1. **주 지표 하나를 미리 정하고**, 나머지는 참고 지표로만 본다.
2. 여러 지표로 판단해야 한다면 기준을 엄격하게 바꾼다. 가장 간단한 방법이 **본페로니 보정**으로, α를 검정 횟수로 나눕니다.

```run
alpha, m = 0.05, 5
print(f"지표 {m}개를 함께 판단 → 각 지표의 기준 p < {alpha / m}")
```

지표 5개라면 각 지표는 p < 0.01이어야 유의하다고 봅니다. 엄격한 만큼 검정력은 떨어지므로, 처음부터 주 지표를 하나로 좁히는 것이 가장 좋습니다.

## 결과를 결정으로 바꾸기

실험이 끝나면 아래 표처럼 판단합니다.

| 유의한가? | 차이(신뢰구간)가 의미 있는 크기인가? | 결정 |
| --- | --- | --- |
| 유의함 | 신뢰구간 전체가 의미 있는 크기 이상 | **적용한다** |
| 유의함 | 신뢰구간이 아주 작은 효과까지 포함 | 비용 대비 효과를 따져 결정, 필요하면 추가 실험 |
| 유의하지 않음 | 신뢰구간이 넓다 (큰 효과 가능성도 있음) | **판단 보류**, 표본 부족. 더 모으거나 재설계 |
| 유의하지 않음 | 신뢰구간이 좁고 0 근처 | 효과가 있어도 아주 작다. **적용하지 않는다** |

[지난 레슨](#/l/st-08-1)의 버튼 실험(차이 1.5%p, 95% CI 0.18 ~ 2.82%p)이라면 두 번째 줄에 해당합니다. 유의하지만 효과가 거의 없을 가능성(0.18%p)도 남아 있으니, 새 디자인을 적용하는 비용이 크다면 표본을 더 모아 구간을 좁혀 보는 것도 방법입니다.

## 실무 예제: 실험 기간 계산하기

필요한 표본 수가 정해지면 **실험 기간**도 계산할 수 있습니다. 두 그룹 합쳐 필요한 인원을 하루 방문자로 나누면 됩니다.

```run
import numpy as np
from scipy import stats

def n_per_group(p1, p2, alpha=0.05, power=0.8):
    za, zb, pbar = stats.norm.ppf(1 - alpha / 2), stats.norm.ppf(power), (p1 + p2) / 2
    return int(np.ceil((za * np.sqrt(2 * pbar * (1 - pbar)) + zb * np.sqrt(p1 * (1 - p1) + p2 * (1 - p2))) ** 2 / (p2 - p1) ** 2))

n = n_per_group(0.04, 0.05)
for daily in [500, 1000, 3000]:
    print(f"하루 {daily:,}명 → {int(np.ceil(2 * n / daily))}일")
```

4% → 5%를 잡는 실험은 하루 방문자가 500명이면 27일, 1,000명이면 14일, 3,000명이면 5일이 걸립니다. 단, 3,000명이라 5일이면 된다고 해도 **최소 1주일**은 돌리는 것이 좋습니다. 요일마다 사용자가 다르기 때문입니다(주말 손님과 평일 손님).

반대로 계산이 "79일"처럼 너무 길게 나오면 실험 설계를 바꿀 때입니다. 검출할 차이를 키우거나(정말 0.4%p 개선을 잡아야 하나?), 더 자주 일어나는 지표(구매 대신 장바구니 담기)를 주 지표로 쓰는 방법이 있습니다.

## 자주 하는 실수

1. **표본 수를 "느낌상 충분해 보일 때까지"로 정한다.** 이것은 몰래 들여다보기와 같아서 헛경보가 늘어납니다. 시작 전에 계산합니다.
2. **기준 전환율을 너무 낙관적으로 잡는다.** p₁이 실제보다 높으면 필요한 n이 작게 계산되어 검정력이 모자랍니다. 최근 데이터로 기준값을 정합니다.
3. **상대 차이로 표본 수를 계산하고 절대 차이로 착각한다.** "10% 개선"이 4% → 4.4%(+0.4%p)인지 4% → 14%인지 계산 전에 분명히 적습니다.

## 정리

- 표본 수는 **기준 전환율 · 검출할 최소 차이 · α · 검정력** 네 재료로 계산한다.
- 검출할 차이를 절반으로 줄이면 필요한 표본은 약 **4배**.
- 표본이 아주 크면 사소한 차이도 유의하다. **유의성 ≠ 중요성**. 차이와 신뢰구간을 함께 보고, 실무 가치는 따로 판단한다.
- 지표를 여러 개 보면 헛경보가 쌓인다. **주 지표 하나**를 미리 정하거나 본페로니 보정(α ÷ 검정 수).
