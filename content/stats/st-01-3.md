## 성적표의 "상위 10%"

성적표에 "상위 10%"라고 적혀 있으면, 100명을 점수순으로 줄 세웠을 때 내 위에 10명쯤 있다는 뜻입니다. 이렇게 **줄에서의 위치**로 값을 말하는 것을 **백분위수**(percentile)라고 합니다. "아래에서 90% 지점"이 곧 상위 10%입니다.

평균과 표준편차가 "얼마나 큰가, 얼마나 흩어졌나"를 말한다면, 이번 레슨의 도구들은 "**이 값은 줄의 어디쯤에 서 있나, 혹시 혼자 너무 멀리 떨어져 있지 않나**"를 말해 줍니다.

```run
import numpy as np
import pandas as pd

df = pd.read_csv("titanic.csv")
print(np.percentile(df["age"].dropna(), [10, 50, 90]))
```

타이타닉 승객 나이의 10% 지점은 14살, 50% 지점(= 중앙값)은 28살, 90% 지점은 50살입니다. "승객 열 명 중 한 명은 14살 이하였다"고 읽으면 됩니다.

## 사분위수와 IQR

백분위수 중에서 25%, 50%, 75% 지점은 특별한 이름이 있습니다. 데이터를 네 등분하는 경계라서 **사분위수**(quartile)라고 부릅니다.

- **Q1** (제1사분위수): 아래에서 25% 지점
- **Q2** (제2사분위수): 50% 지점 = 중앙값
- **Q3** (제3사분위수): 아래에서 75% 지점
- **IQR** (사분위 범위) = Q3 − Q1: **가운데 50%** 값들이 퍼진 폭

IQR은 양 끝 25%씩을 빼고 가운데만 보기 때문에, 극단값이 아무리 커도 거의 흔들리지 않습니다. 범위(최댓값 − 최솟값)의 약점을 보완한 흩어짐 지표입니다.

```run
import numpy as np
import pandas as pd

df = pd.read_csv("titanic.csv")
q1, q3 = np.percentile(df["fare"], [25, 75])
print("Q1:", q1, "/ Q3:", q3, "/ IQR:", round(q3 - q1, 2))
```

요금의 Q1은 7.91, Q3은 31.0, IQR은 23.09입니다. 승객의 가운데 절반은 7.91~31.0 사이의 요금을 냈다는 뜻입니다.

## 상자그림과 1.5 × IQR 규칙

[데이터 시각화 트랙 da-09-3](#/l/da-09-3)에서 그린 **상자그림**(box plot)이 바로 이 숫자들로 만들어집니다.

::figure{src="content/img/stats/st01-boxplot-rule.svg" alt="상자그림의 구조: 상자의 왼쪽 끝 Q1, 가운데 선 중앙값, 오른쪽 끝 Q3. 상자 양쪽으로 1.5배 IQR까지 수염이 뻗고, 그 밖의 점은 이상치" caption="상자 = 가운데 50%(IQR). 수염은 상자 끝에서 1.5 × IQR까지만 뻗고, 그 밖에 있는 값은 점으로 따로 찍혀 '이상치 후보'가 됩니다."}

상자그림이 쓰는 이상치 기준은 이렇습니다.

> 아래 경계 = Q1 − 1.5 × IQR, 위 경계 = Q3 + 1.5 × IQR
> 이 두 경계 밖의 값을 **이상치**(outlier) 후보로 본다.

1.5라는 숫자는 수학적으로 꼭 맞는 값이 아니라, 통계학자 존 튜키(John Tukey)가 "대부분의 데이터에서 적당히 드문 값만 걸러지는" 기준으로 정한 관례입니다. 요금 데이터에 적용해 봅니다.

```run
import numpy as np
import pandas as pd

df = pd.read_csv("titanic.csv")
q1, q3 = np.percentile(df["fare"], [25, 75])
iqr = q3 - q1
print("아래 경계:", round(q1 - 1.5 * iqr, 2), "/ 위 경계:", round(q3 + 1.5 * iqr, 2))
```

위 경계는 65.63입니다. 아래 경계는 −26.72로 요금은 음수가 될 수 없으니, 아래쪽 이상치는 없습니다. 위 경계를 넘는 승객은 몇 명일까요?

```run
import numpy as np
import pandas as pd

df = pd.read_csv("titanic.csv")
q1, q3 = np.percentile(df["fare"], [25, 75])
high = q3 + 1.5 * (q3 - q1)
print("이상치 후보:", (df["fare"] > high).sum(), "명 /", len(df), "명")
```

891명 중 116명(13%)이 "이상치 후보"로 걸렸습니다. 열 명 중 한 명 넘게 이상치라니, 뭔가 이상하지요? 이들은 입력 실수가 아니라 **비싼 1등석 표를 산 실제 승객**입니다. 요금처럼 오른쪽 꼬리가 긴 데이터에서는 1.5 × IQR 규칙이 정상적인 큰 값까지 많이 걸러 냅니다. "이상치 후보"는 **확인해 볼 대상**이지, 곧바로 지울 대상이 아닙니다.

직접 해 보세요: `1.5`를 `3`으로 바꾸면 "아주 심한" 이상치만 남습니다. 몇 명으로 줄어드는지 확인해 보세요.

```run
import numpy as np
import pandas as pd

df = pd.read_csv("titanic.csv")
q1, q3 = np.percentile(df["fare"], [25, 75])
k = 3
print("k =", k, "→ 이상치 후보:", (df["fare"] > q3 + k * (q3 - q1)).sum(), "명")
```

k = 3으로 늘리면 53명으로 줄어듭니다. 기준을 어떻게 정하느냐에 따라 이상치 수가 크게 바뀐다는 것을 기억하세요.

## describe(): 다섯 숫자 요약을 한 번에

pandas의 `describe()`는 개수, 평균, 표준편차, 최솟값, Q1(25%), 중앙값(50%), Q3(75%), 최댓값을 한 번에 보여 줍니다. 데이터를 처음 받으면 가장 먼저 실행해 볼 만한 한 줄입니다.

```run
import pandas as pd

df = pd.read_csv("titanic.csv")
print(df["fare"].describe().round(2))
```

평균(32.20)이 중앙값(14.45)보다 훨씬 크고, 최댓값(512.33)이 Q3(31.00)의 16배가 넘습니다. 숫자만 보고도 "오른쪽 꼬리가 아주 긴 데이터"라는 것을 알 수 있습니다.

## z점수: 표준편차 몇 개만큼 떨어졌나

국어 시험에서 80점, 수학 시험에서 70점을 받았습니다. 어느 과목을 더 잘 본 걸까요? 점수만 보면 국어지만, 국어 평균이 85점이고 수학 평균이 55점이었다면 이야기가 달라집니다.

이럴 때 쓰는 것이 **z점수**(표준점수)입니다.

> z = (값 − 평균) ÷ 표준편차

"평균에서 **표준편차 몇 개만큼** 떨어져 있나"를 나타냅니다. z = 0이면 딱 평균, z = 2면 평균보다 표준편차 두 개만큼 위, z = −1이면 표준편차 하나만큼 아래입니다. 단위가 사라지기 때문에 서로 다른 시험, 서로 다른 변수끼리도 비교할 수 있습니다.

::figure{src="content/img/stats/st01-zscore.svg" alt="종 모양 곡선 아래에 z = -3부터 3까지 눈금이 있고, z = 0이 평균, z = 2 오른쪽은 아주 드문 영역으로 칠해진 그림" caption="z점수는 '평균에서 표준편차 몇 칸 떨어졌나'입니다. 종 모양 데이터라면 |z| > 2인 값은 드물고, |z| > 3인 값은 아주 드뭅니다."}

```run
kor, kor_mean, kor_std = 80, 85, 5
math, math_mean, math_std = 70, 55, 10
print("국어 z:", (kor - kor_mean) / kor_std)
print("수학 z:", (math - math_mean) / math_std)
```

국어는 z = −1.0(평균보다 표준편차 하나만큼 아래), 수학은 z = 1.5(표준편차 1.5개만큼 위)입니다. 점수는 국어가 높지만, 반 친구들 사이에서의 위치로 보면 **수학을 훨씬 잘 봤습니다.**

실데이터에서도 z점수로 "가장 튀는 값"을 찾을 수 있습니다. 식당 계산 금액에서 z점수가 가장 큰 계산서를 찾아봅니다.

```run
import pandas as pd

df = pd.read_csv("tips.csv")
z = (df["total_bill"] - df["total_bill"].mean()) / df["total_bill"].std()
print("가장 큰 z:", round(z.max(), 2), "/ 그 금액:", df["total_bill"][z.idxmax()])
```

50.81달러짜리 계산서가 z = 3.48로, 평균보다 표준편차 3.5개만큼 위에 있습니다.

## |z| > 3 규칙과 그 한계

값이 종 모양으로 퍼져 있다면 |z| > 3인 값은 1,000개 중 3개 정도밖에 나오지 않습니다([정규분포](#/l/st-02-3)에서 확인합니다). 그래서 "|z| > 3이면 이상치 후보"라는 규칙도 많이 씁니다. IQR 규칙과 비교해 봅시다.

```run
import numpy as np
import pandas as pd

df = pd.read_csv("titanic.csv")
z = (df["fare"] - df["fare"].mean()) / df["fare"].std()
q1, q3 = np.percentile(df["fare"], [25, 75])
print("|z| > 3:", (z.abs() > 3).sum(), "명 / IQR 규칙:", (df["fare"] > q3 + 1.5 * (q3 - q1)).sum(), "명")
```

같은 요금 데이터에서 z 규칙은 20명, IQR 규칙은 116명을 골라냈습니다. 왜 이렇게 다를까요? z점수는 **평균과 표준편차로** 계산하는데, 꼬리가 긴 데이터에서는 그 큰 값들이 평균과 표준편차를 이미 끌어올려 놓았습니다(표준편차 49.69). 그래서 큰 값이 상대적으로 덜 튀어 보입니다. 반대로 IQR은 가운데 50%만 보고 경계를 정하니 큰 값이 더 많이 걸립니다.

| 규칙 | 기준 | 잘 맞는 데이터 | 약점 |
| --- | --- | --- | --- |
| \|z\| > 3 | 평균 · 표준편차 | 종 모양(대칭) 데이터 | 이상치가 평균 · 표준편차를 끌어올려 자기 자신을 숨김 |
| 1.5 × IQR | 사분위수 | 치우친 데이터, 이상치가 섞인 데이터 | 꼬리가 긴 데이터에서는 정상 값도 많이 걸림 |

## 이상치를 만나면: 지우기 전에 이유부터

이상치를 찾았다고 바로 지우면 안 됩니다. 먼저 **왜 튀는지** 확인하세요.

1. **입력·측정 실수**: 나이 250살, 키 1,700cm처럼 불가능한 값 → 고치거나 빈 값으로 처리
2. **진짜 드문 값**: 1등석 요금, 대형 주문 → 지우면 현실을 왜곡함. 그대로 두고 중앙값·IQR처럼 튼튼한 요약을 쓰거나, 따로 분석
3. **다른 무리가 섞인 값**: 단체 손님 계산서, 다른 공장 제품 → 무리를 나눠서 분석

어떤 처리를 했든 보고서에 "몇 개를 어떤 기준으로 어떻게 처리했는지"를 꼭 적습니다.

## 정리

- **백분위수**는 줄에서의 위치, **사분위수**(Q1 · 중앙값 · Q3)는 데이터를 네 등분하는 경계.
- **IQR** = Q3 − Q1은 가운데 50%의 폭이라 이상치에 강하다. 상자그림의 상자가 IQR, 수염 밖이 **1.5 × IQR 이상치 후보**.
- **z점수** = (값 − 평균) ÷ 표준편차. 단위가 다른 값끼리도 "평균에서 몇 칸 떨어졌나"로 비교할 수 있다.
- 이상치 규칙은 기준에 따라 결과가 크게 달라진다. 이상치는 지우기 전에 이유부터 확인한다.
