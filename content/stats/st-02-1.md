## 결과에 숫자 붙이기

동전 두 개를 던지면 결과는 (앞, 앞), (앞, 뒤), (뒤, 앞), (뒤, 뒤) 네 가지입니다. 그런데 우리가 정말 궁금한 건 "어떤 모양으로 나왔나"보다 "**앞면이 몇 개 나왔나**"인 경우가 많습니다. 이렇게 우연한 실험의 결과마다 **숫자를 하나씩 붙인 것**을 **확률변수**(random variable)라고 합니다. 보통 대문자 X로 씁니다.

- 동전 두 개를 던져 나온 앞면 수: X = 0, 1, 2
- 주사위를 던져 나온 눈: X = 1 ~ 6
- 오늘 식당에 온 손님 팀의 인원 수: X = 1, 2, 3, …
- 오늘 고장 난 설비 대수, 내일 최고 기온

## 확률분포: 값마다 확률을 적은 표

확률변수가 가질 수 있는 값마다 그 확률을 적어 놓은 것을 **확률분포**(probability distribution)라고 합니다. 동전 두 개의 앞면 수 X라면 결과 네 개가 똑같이 나올 법하므로,

| X (앞면 수) | 0 | 1 | 2 |
| --- | --- | --- | --- |
| 해당 결과 | 뒤뒤 | 앞뒤, 뒤앞 | 앞앞 |
| 확률 P(X = x) | 1/4 | 2/4 | 1/4 |

확률을 모두 더하면 반드시 1이 됩니다. 파이썬 딕셔너리로 표를 만들어 봅니다.

```run
dist = {0: 1/4, 1: 2/4, 2: 1/4}
print("확률분포:", dist)
print("확률의 합:", sum(dist.values()))
```

[지난 레슨](#/l/st-09-1)에서 배운 시뮬레이션으로 이 표가 맞는지 확인해 봅니다. 동전 두 개(0 또는 1)를 10,000번 던져 합을 구하고, 각 값의 비율을 셉니다.

```run
import numpy as np

rng = np.random.default_rng(0)
x = rng.integers(0, 2, size=(10_000, 2)).sum(axis=1)
print("앞면 수 0, 1, 2의 비율:", np.bincount(x) / len(x))
```

시뮬레이션 비율이 [0.2432, 0.5119, 0.2449]로 표의 0.25, 0.5, 0.25와 거의 같습니다. `np.bincount`는 0, 1, 2가 각각 몇 번 나왔는지 세어 주는 함수입니다.

## 이산형과 연속형

확률변수는 값의 성격에 따라 두 가지로 나뉩니다.

| 종류 | 값의 모양 | 예 | 확률을 나타내는 방법 |
| --- | --- | --- | --- |
| **이산형** | 하나, 둘 **셀 수 있는** 값 | 앞면 수, 불량 개수, 손님 수 | 값마다 확률 (막대그래프) |
| **연속형** | 자로 **재는** 값, 사이사이 값이 끝없이 있음 | 키, 몸무게, 시간, 온도 | 구간의 넓이 (곡선 아래 면적) |

이산형부터 자세히 보고, 연속형은 레슨 끝에서 다룹니다.

## pmf와 cdf: "딱 그 값"과 "그 값 이하"

이산형 확률분포에서 자주 묻는 질문은 두 종류입니다.

- **"딱 k일 확률"**: P(X = k). 이것을 주는 함수를 **pmf**(확률질량함수, probability mass function)라고 합니다.
- **"k 이하일 확률"**: P(X ≤ k). 이것을 주는 함수를 **cdf**(누적분포함수, cumulative distribution function)라고 합니다.

::figure{src="content/img/stats/st02-pmf-cdf.svg" alt="왼쪽: 값 0, 1, 2에 높이 0.25, 0.5, 0.25인 막대(pmf). 오른쪽: 같은 값에서 0.25, 0.75, 1.0으로 한 계단씩 올라가는 계단 그래프(cdf)" caption="pmf는 각 값의 막대 높이, cdf는 왼쪽부터 막대를 차곡차곡 쌓아 올린 계단입니다. cdf의 마지막 계단은 항상 1입니다."}

cdf는 pmf를 왼쪽부터 차례로 더해 가면(누적 합) 만들어집니다.

```run
import numpy as np

pmf = np.array([0.25, 0.5, 0.25])   # X = 0, 1, 2
cdf = np.cumsum(pmf)
print("pmf:", pmf, "/ cdf:", cdf)
```

cdf는 [0.25, 0.75, 1.0]입니다. "앞면이 1개 이하일 확률" P(X ≤ 1) = 0.75 = P(X = 0) + P(X = 1)입니다. 반대로 "앞면이 1개보다 많을 확률" P(X > 1)은 1 − cdf(1) = 0.25입니다. 이 "1 − cdf"를 **sf**(생존함수, survival function)라고 부르는데, 다음 레슨에서 자주 씁니다.

## 기댓값: 오래 반복했을 때의 평균

확률변수의 **기댓값**(expected value, E[X])은 "이 실험을 아주 많이 반복하면 평균적으로 얼마가 나오나"입니다. 값 × 확률을 모두 더해서 구합니다.

> E[X] = Σ (값 × 그 값의 확률)

동전 두 개의 앞면 수라면 0 × 0.25 + 1 × 0.5 + 2 × 0.25 = 1입니다. 동전 두 개를 던지면 평균적으로 앞면이 1개 나온다는, 직관과 맞는 결과입니다.

```run
import numpy as np

values = np.array([0, 1, 2])
pmf = np.array([0.25, 0.5, 0.25])
print("기댓값:", (values * pmf).sum())
```

기댓값은 1.0입니다. 시뮬레이션 평균과도 비교해 봅니다. 큰 수의 법칙에 따라 많이 반복한 평균은 기댓값에 가까워져야 합니다.

```run
import numpy as np

rng = np.random.default_rng(0)
x = rng.integers(0, 2, size=(10_000, 2)).sum(axis=1)
print("시뮬레이션 평균:", x.mean())
```

10,000번 반복한 평균이 1.0017로 기댓값 1.0과 거의 같습니다. 복권이나 게임에서 "한 번 할 때 평균적으로 얼마를 따거나 잃나"를 계산할 때도 기댓값을 씁니다.

### 원리 한 걸음 더: 확률분포의 분산

기댓값이 "가운데"라면, 그 가운데에서 얼마나 흩어지는지는 **분산**(Var[X])입니다. [기술통계의 분산](#/l/st-01-2)과 같은 생각인데, 행마다 1/n로 평균 내는 대신 **확률로 가중 평균**합니다.

> Var[X] = Σ (값 − E[X])² × 그 값의 확률,  표준편차 = √Var[X]

동전 두 개라면 (0 − 1)² × 0.25 + (1 − 1)² × 0.5 + (2 − 1)² × 0.25 = 0.5입니다.

```run
import numpy as np

rng = np.random.default_rng(0)
values = np.array([0, 1, 2])
pmf = np.array([0.25, 0.5, 0.25])
mean = (values * pmf).sum()
var = ((values - mean) ** 2 * pmf).sum()
x = rng.integers(0, 2, size=(10_000, 2)).sum(axis=1)
print("Var by formula:", var, "| SD:", round(float(np.sqrt(var)), 3))
print("simulation var:", round(float(x.var()), 4))
```

공식으로 0.5, 시뮬레이션으로 0.488입니다. 이 두 공식(기댓값, 분산)은 뒤에서 계속 쓰입니다. 이항분포의 평균 np와 분산 np(1 − p), 표본평균의 표준오차 σ ÷ √n이 모두 여기서 출발합니다.

## 실제 데이터의 확률분포

실제 데이터에서는 값마다의 **비율**(상대도수)이 확률분포 역할을 합니다. 식당 손님 팀의 인원 수(`size`)를 봅니다. `value_counts(normalize=True)`는 각 값의 비율을 줍니다.

```run
import pandas as pd

df = pd.read_csv("tips.csv")
print(df["size"].value_counts(normalize=True).sort_index().round(3))
```

2명이 0.639로 가장 많고, 3명 0.156, 4명 0.152 순입니다. 이 표가 "아무 팀이나 한 팀 골랐을 때 인원 수"의 확률분포입니다. 이 분포로 기댓값을 구하면 무엇이 나올까요?

```run
import pandas as pd

df = pd.read_csv("tips.csv")
p = df["size"].value_counts(normalize=True)
print("값 × 비율의 합:", round((p.index * p).sum(), 3), "/ 평균:", round(df["size"].mean(), 3))
```

둘 다 2.57명으로 같습니다. 데이터의 확률분포로 구한 기댓값은 그냥 **평균**입니다. 기댓값은 "확률분포의 평균"이라고 기억하면 됩니다.

## 실무 예제: 100대 묶음마다 고장 몇 대

설비 데이터를 기록된 순서대로 100대씩 묶으면 묶음이 100개 생깁니다. 묶음마다 고장 대수를 세고, 그 값들의 확률분포(상대도수)를 만들어 봅니다. `reshape(100, 100)`은 10,000개 값을 100행 × 100열 표로 접습니다. 한 행이 한 묶음입니다.

```run
import pandas as pd

fail = pd.read_csv("ai4i2020.csv")["failure"].to_numpy()
per_batch = pd.Series(fail.reshape(100, 100).sum(axis=1))
print(per_batch.value_counts(normalize=True).sort_index().round(2).to_dict())
```

고장 0대인 묶음이 6%, 1대 24%, 2대 25%, 3대 21%이고, 드물게 12대, 18대처럼 많이 나온 묶음도 있습니다. 이 분포의 기댓값을 계산해 봅니다.

```run
import pandas as pd

fail = pd.read_csv("ai4i2020.csv")["failure"].to_numpy()
per_batch = pd.Series(fail.reshape(100, 100).sum(axis=1))
p = per_batch.value_counts(normalize=True)
print("기댓값:", round((p.index * p).sum(), 2), "/ 가장 흔한 값:", per_batch.mode()[0], "/ 중앙값:", per_batch.median())
```

기댓값은 3.39대로, 전체 고장률 3.39% × 100대와 같습니다. 그런데 가장 흔한 값은 2대, 중앙값도 2대입니다. **기댓값은 "가장 자주 나오는 값"이 아닙니다.** 고장이 많이 몰린 몇몇 묶음이 기댓값을 끌어올렸기 때문입니다. "한 묶음에서 보통 몇 대가 고장 나나?"라고 물으면 2대, "100묶음을 돌리면 고장이 모두 몇 대쯤 나오나?"라고 물으면 3.39 × 100 = 339대가 답입니다.

## 자주 하는 실수

1. **기댓값을 "다음번에 나올 값"으로 말한다.** 주사위 기댓값 3.5는 한 번 던져서 절대 나오지 않습니다. 기댓값은 오래 반복했을 때의 평균입니다.
2. **확률의 합이 1인지 확인하지 않는다.** 직접 만든 확률표는 반드시 합을 확인하세요. 빠진 값이 있거나 비율 계산이 틀렸다는 신호입니다.
3. **연속형 변수에 pmf를 쓴다.** 무게, 온도처럼 재는 값은 "딱 그 값"의 확률이 0이라서 구간 확률(cdf의 차이)로 말해야 합니다.

## 연속형: 딱 그 값의 확률은 0

몸무게처럼 재는 값은 4,000g, 4,000.1g, 4,000.01g… 사이사이 값이 끝없이 있습니다. 그래서 몸무게가 **정확히** 4,000.000…g일 확률은 0입니다. 연속형에서는 "딱 그 값" 대신 **구간**의 확률을 묻습니다. "3,500g 이상 4,500g 이하일 확률"처럼요.

펭귄 몸무게에서 구간별 비율을 세어 봅니다.

```run
import pandas as pd

mass = pd.read_csv("penguins.csv")["body_mass_g"].dropna()
print("3,500 ~ 4,500g 비율:", round(mass.between(3500, 4500).mean(), 3))
print("정확히 4,000.5g 비율:", (mass == 4000.5).mean())
```

3,500~4,500g 사이에 45.6%가 들어가고, 정확히 4,000.5g인 펭귄은 하나도 없습니다(0.0).

연속형 확률분포는 막대 대신 **곡선**(확률밀도함수, pdf)으로 그리고, 곡선 아래 **넓이**가 그 구간의 확률입니다. 곡선 아래 전체 넓이는 1입니다. 대표적인 연속형 분포인 정규분포를 [정규분포와 표준화](#/l/st-02-3)에서 배웁니다.

## scipy.stats: 분포마다 같은 메서드

앞으로는 분포의 확률을 직접 더하지 않고 `scipy.stats`를 씁니다. 어떤 분포든 **같은 이름의 메서드**를 쓴다는 점이 편리합니다.

| 메서드 | 묻는 것 | 예 (불량 수 X) |
| --- | --- | --- |
| `pmf(k)` / `pdf(x)` | 딱 k일 확률 / 곡선 높이(연속형) | 불량이 딱 2개일 확률 |
| `cdf(k)` | k **이하**일 확률 | 불량이 2개 이하일 확률 |
| `sf(k)` | k **초과**일 확률 (= 1 − cdf) | 불량이 2개보다 많을 확률 |
| `ppf(q)` | cdf의 반대: 아래에서 q 비율이 되는 경계값 | 하위 95%가 되는 불량 수 |
| `rvs(size=n)` | 이 분포에서 난수 n개 뽑기 | 시뮬레이션용 |

메서드 목록은 [scipy.stats 문서](https://docs.scipy.org/doc/scipy/reference/stats.html)에서 분포마다 볼 수 있습니다.

## 정리

- **확률변수** X는 우연한 결과에 붙인 숫자, **확률분포**는 값마다의 확률표(합은 1).
- 이산형(셀 수 있음)은 값마다 확률, 연속형(잴 수 있음)은 구간의 넓이로 확률을 말한다. 연속형에서 "딱 그 값"의 확률은 0.
- **pmf**는 딱 k, **cdf**는 k 이하, **sf**는 k 초과.
- **기댓값**은 값 × 확률의 합 = 아주 많이 반복했을 때의 평균.
