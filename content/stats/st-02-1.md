## 어떤 분포를 고를까

| 상황 | 분포 | scipy |
| --- | --- | --- |
| n개 중 불량(성공) 개수, 확률 p 고정 | 이항분포 | `stats.binom(n, p)` |
| 단위 시간·면적당 발생 건수, 평균 μ | 포아송분포 | `stats.poisson(mu)` |
| 키·무게·두께 같은 연속 측정값 | 정규분포 | `stats.norm(loc, scale)` |

## 네 가지 메서드

- `pmf(k)`: 정확히 k일 확률 (이산 분포)
- `cdf(x)`: x **이하**일 확률
- `sf(x)`: x **초과**일 확률 = 1 − cdf(x)
- `ppf(q)`: 하위 q가 되는 지점 (cdf의 역함수)

```run
from scipy import stats

lot = stats.binom(50, 0.02)   # 불량률 2%, 50개 검사
print("불량 0개", round(lot.pmf(0), 4))
print("불량 2개 이하", round(lot.cdf(2), 4))
print("불량 3개 이상", round(lot.sf(2), 4))   # 3개 이상 = 2개 초과
```

> "k개 이상"을 `sf(k)`로 쓰는 실수가 가장 흔합니다. 이산 분포에서 sf(k)는 k를 포함하지 않습니다.

## 포아송: 드물게 일어나는 사건의 개수

```run
from scipy import stats

calls = stats.poisson(3)      # 시간당 평균 3건
for k in range(7):
    print(k, "건", round(calls.pmf(k), 3))
print("5건 이상", round(calls.sf(4), 4))
```

## 정규분포: 규격 이탈 비율과 기준점

```run
from scipy import stats

w = stats.norm(loc=500, scale=2)    # 평균 500g, 표준편차 2g
print("496g 미만", round(w.cdf(496), 4))
print("±2σ 안", round(w.cdf(504) - w.cdf(496), 4))
print("상위 5% 기준", round(w.ppf(0.95), 2))
```

68–95–99.7 규칙(±1σ, ±2σ, ±3σ에 각각 약 68%, 95%, 99.7%)은 머릿속 검산용으로 외워 두면 좋습니다.
