## 모든 검정의 공통 모양: 신호 ÷ 잡음

새 검정이 많아 보여도 뼈대는 같습니다. [t 통계량](#/l/st-05-3)에서 본 것처럼, 검정통계량은 대부분 이런 모양입니다.

`검정통계량 = (관찰한 값 − 귀무가설이 말하는 값) ÷ 그 값이 우연히 흔들리는 크기(표준오차)`

통계량이 0에서 멀수록 "우연이라고 보기 어렵다"는 뜻이고, 그 통계량이 귀무가설 아래에서 따르는 분포(정규, t, 카이제곱, F)에서 꼬리 넓이를 구한 것이 p-value입니다. 검정마다 다른 것은 **무엇을 비교하느냐**와 **그때 표준오차를 어떻게 계산하느냐** 두 가지뿐입니다.

## z검정: 모집단 표준편차 σ를 알 때

t검정은 표본에서 구한 표준편차 s로 표준오차를 계산했습니다. 그런데 공정처럼 **오랫동안 쌓인 기록**이 있어서 흔들림 σ를 이미 안다면, s 대신 σ를 씁니다. 이것이 **z검정**입니다.

`z = (표본평균 − μ₀) ÷ (σ / √n)`

σ는 추정한 값이 아니라 알려진 값이라서 표본이 작아도 통계량이 **표준정규분포**를 따릅니다. t분포처럼 꼬리가 두껍지 않으므로, 같은 유의수준 5%(양측)에서 기준선이 t보다 조금 낮습니다.

| 분포 | 양측 5% 기준선 |
| --- | --- |
| 표준정규 (z) | 1.960 |
| t, 자유도 14 | 2.145 |
| t, 자유도 29 | 2.045 |

예제를 봅니다. AI4I 공정 온도는 오랜 기록상 평균 310.0K, 표준편차 1.48K라고 합시다. 어느 날 설비 15대의 공정 온도를 쟀더니 평균이 조금 높게 나왔습니다. 평소보다 뜨거워졌다고 말할 수 있을까요?

```run
import numpy as np
import pandas as pd
from scipy import stats

df = pd.read_csv("ai4i2020.csv")
today = df.iloc[4000:5000].sample(15, random_state=1)["process_temp"]
mu0, sigma = 310.0, 1.48
z = (today.mean() - mu0) / (sigma / np.sqrt(len(today)))
p = 2 * stats.norm.sf(abs(z))
print("today mean:", round(today.mean(), 2), "K, n =", len(today))
print("z =", round(z, 2), ", p =", round(p, 4))
```

표본평균 311.03K, z = 2.70, p = 0.0068입니다. 평소 흔들림(σ/√15 = 0.38K)의 2.7배만큼 높으니 우연으로 보기 어렵습니다. 공정 온도가 올랐다고 판단합니다.

`stats.norm.sf(z)`는 표준정규분포에서 z보다 클 확률(오른쪽 꼬리)이고, 양측이라 2를 곱했습니다.

## z와 t, 언제 무엇을 쓰나

교과서의 규칙은 간단합니다. **σ를 알면 z, 모르면 t**입니다. 실무에서 σ를 정말로 아는 경우는 드물어서 평균 비교는 대부분 t검정을 씁니다. 그런데 z검정이 **기본**으로 쓰이는 곳이 있습니다. 바로 **비율** 검정입니다. 비율은 평균과 달리, 귀무가설이 비율 p₀를 정하면 흔들림도 √(p₀(1 − p₀)/n)으로 **함께 정해지기** 때문입니다.

:::tip 알아 두면 좋아요 · 'σ를 안다'는 가정이 틀리면
위 예제와 같은 방법으로 다른 날(3,000 ~ 4,000번째 행)의 15대를 뽑으면 표본평균 310.57K에서 z검정은 p = 0.13으로 "차이 없음", 같은 데이터의 t검정은 p = 0.0045로 "차이 있음"이 나옵니다. 그날 15대의 표준편차가 0.66K로, 기록상 σ(1.48K)보다 훨씬 작았기 때문입니다. 기록상 σ에는 계절 · 날짜에 따른 큰 흔들림까지 섞여 있어서, 하루 안의 흔들림에 쓰기에는 너무 큽니다. **어떤 σ를 쓰느냐가 결론을 바꿉니다.** 기록상 σ를 쓸 때는 그 σ가 지금 비교하려는 상황과 같은 조건에서 구한 것인지 먼저 확인합니다.
:::

## 1비율 z검정: 불량률이 목표를 넘었나

AI4I 1만 대 중 고장은 339대(3.39%)입니다. 관리 목표가 "고장률 3% 이하"라면, 3.39%는 목표를 넘은 것일까요, 우연한 흔들림일까요?

`z = (p̂ − p₀) ÷ √(p₀(1 − p₀) / n)`

분모에 **귀무가설의 비율 p₀**를 쓴다는 점이 핵심입니다. "귀무가설이 맞다면 비율이 이만큼 흔들린다"를 계산하는 것이기 때문입니다.

```run
import numpy as np
import pandas as pd
from scipy import stats

df = pd.read_csv("ai4i2020.csv")
x, n, p0 = df["failure"].sum(), len(df), 0.03
p_hat = x / n
z = (p_hat - p0) / np.sqrt(p0 * (1 - p0) / n)
print(f"failures {x} / {n} = {p_hat:.4f}")
print("z =", round(z, 3), ", two-sided p =", round(2 * stats.norm.sf(abs(z)), 4))
print("exact binomial test p =", round(stats.binomtest(x, n, p0).pvalue, 4))
```

z = 2.29, p = 0.022입니다. 정확한 [이항검정](#/l/st-05-1)(`binomtest`)도 p = 0.024로 거의 같습니다. 1만 대나 되니 0.39%p 차이도 우연으로 보기 어렵습니다.

z 근사는 **np₀ ≥ 10이고 n(1 − p₀) ≥ 10**일 때 믿을 만합니다. 여기서는 np₀ = 300이라 충분합니다. 불량이 몇 개 안 되는 작은 표본(예: 50개 중 2개)이면 z 대신 이항검정을 씁니다.

## 2비율 z검정: 두 그룹의 비율이 다른가

AI4I 제품 등급별 고장률을 비교합니다. L 등급은 6,000대 중 235대(3.92%), M 등급은 2,997대 중 83대(2.77%)입니다.

귀무가설("두 비율이 같다") 아래에서는 두 그룹을 합친 **공통 비율** p̄로 흔들림을 계산합니다.

`z = (p̂₁ − p̂₂) ÷ √(p̄(1 − p̄)(1/n₁ + 1/n₂))`,  p̄ = (x₁ + x₂) / (n₁ + n₂)

```run
import numpy as np
import pandas as pd
from scipy import stats

df = pd.read_csv("ai4i2020.csv")
L, M = df[df["type"] == "L"]["failure"], df[df["type"] == "M"]["failure"]
x1, n1, x2, n2 = L.sum(), len(L), M.sum(), len(M)
pool = (x1 + x2) / (n1 + n2)
z = (x1 / n1 - x2 / n2) / np.sqrt(pool * (1 - pool) * (1 / n1 + 1 / n2))
print(f"L: {x1}/{n1} = {x1 / n1:.4f},  M: {x2}/{n2} = {x2 / n2:.4f}")
print("z =", round(z, 3), ", p =", round(2 * stats.norm.sf(abs(z)), 4), ", z^2 =", round(z ** 2, 3))
chi2, p, dof, _ = stats.chi2_contingency([[x1, n1 - x1], [x2, n2 - x2]], correction=False)
print("chi-square (no correction) =", round(chi2, 3), ", p =", round(p, 4))
```

- z = 2.78, p = 0.0055입니다. L 등급의 고장률이 M 등급보다 높다고 판단합니다.
- **z² = 7.715가 카이제곱 통계량(7.715)과 정확히 같고, p-value도 같습니다.** 2 × 2 표의 카이제곱 검정과 2비율 z검정은 같은 검정을 다른 모양으로 쓴 것입니다. [A/B 테스트](#/l/st-08-1)에서 두 전환율을 카이제곱으로 비교한 것도 그래서입니다.

`chi2_contingency`는 기본값으로 **연속성 보정**(Yates)을 해서 통계량을 조금 줄입니다(7.382, p = 0.0066). 표본이 클 때는 차이가 작고, 작을 때는 보정한 쪽이 더 보수적입니다. z와 맞춰 보려고 여기서는 `correction=False`를 썼습니다.

## 검정과 함께 보고할 것: 차이의 신뢰구간

p-value는 "차이가 있다"만 말해 줍니다. **얼마나** 다른지는 차이의 신뢰구간으로 보고합니다. 신뢰구간에서는 공통 비율이 아니라 **각 그룹의 비율**로 표준오차를 계산합니다(귀무가설을 가정하지 않기 때문입니다).

```run
import numpy as np
import pandas as pd

df = pd.read_csv("ai4i2020.csv")
L, M = df[df["type"] == "L"]["failure"], df[df["type"] == "M"]["failure"]
p1, n1, p2, n2 = L.mean(), len(L), M.mean(), len(M)
diff = p1 - p2
se = np.sqrt(p1 * (1 - p1) / n1 + p2 * (1 - p2) / n2)
print(f"difference {diff:.4f}, 95% CI ({diff - 1.96 * se:.4f}, {diff + 1.96 * se:.4f})")
print(f"relative risk L/M = {p1 / p2:.2f}")
```

차이는 1.15%p, 95% 신뢰구간은 0.38%p ~ 1.91%p입니다. 상대적으로는 L 등급이 M 등급보다 약 1.41배 자주 고장 납니다. 보고할 때는 "L 등급 고장률 3.92%, M 등급 2.77%, 차이 1.15%p(95% CI 0.38 ~ 1.91%p, p = 0.005)"처럼 씁니다.

## 자주 하는 실수

| 실수 | 무슨 일이 생기나 | 바로잡기 |
| --- | --- | --- |
| 표본 표준편차 s를 넣고 "z검정"이라고 부름 | 표본이 작으면 p-value가 너무 작게 나옴 | σ를 모르면 t검정 |
| 1비율 검정의 분모에 p̂를 씀 | 귀무가설 아래의 흔들림이 아님 | 검정은 p₀, 신뢰구간은 p̂ |
| 불량 2개 / 50개에 z 근사 | 정규 근사가 맞지 않음 | np₀ ≥ 10 확인, 아니면 `binomtest` |
| 같은 대상을 전후로 잰 비율에 2비율 z검정 | 두 그룹이 독립이 아님 | [McNemar 검정](#/l/st-12-5) |

## 정리

- 검정통계량은 대부분 **(관찰값 − 귀무가설 값) ÷ 표준오차**입니다. 검정마다 다른 것은 비교 대상과 표준오차 계산법뿐입니다.
- **z검정**은 σ를 알 때 평균을 비교합니다. 실무에서는 비율 검정에서 주로 씁니다. 어떤 σ를 쓰느냐가 결론을 바꿀 수 있습니다.
- **1비율 z검정**: 고장률 3.39% vs 목표 3%, z = 2.29, p = 0.022(이항검정 0.024). 분모는 p₀로 계산합니다.
- **2비율 z검정**: L 3.92% vs M 2.77%, z = 2.78, p = 0.0055. z² = 2 × 2 카이제곱 통계량입니다. 차이의 신뢰구간(0.38 ~ 1.91%p)을 함께 보고합니다.
