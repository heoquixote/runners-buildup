## 평균을 비교하는 세 가지 상황

평균에 대한 질문은 크게 세 가지 모양으로 나옵니다.

1. **기준값과 비교**: "이 과자 봉지의 평균 무게가 표시된 100g과 다를까?"
2. **서로 다른 두 그룹 비교**: "점심 손님과 저녁 손님의 평균 계산 금액이 다를까?"
3. **같은 대상의 전과 후 비교**: "같은 학생들이 특강을 듣기 전과 후에 점수가 달라졌을까?"

세 질문 모두 [t분포](#/l/st-04-2)를 쓰는 **t검정**으로 답하지만, 상황마다 쓰는 함수가 다릅니다. 이번 레슨에서는 세 가지 t검정을 고르는 법과 쓰는 법을 배웁니다.

## t 통계량: 신호 ÷ 잡음

세 가지 t검정은 모두 같은 아이디어로 만들어집니다.

> t = (관측한 차이) ÷ (그 차이의 표준오차)

시끄러운 교실에서 친구 목소리를 알아듣는 것과 같습니다. 목소리(신호, 차이)가 크고 주변 소음(잡음, 표준오차)이 작을수록 잘 들립니다. t가 2라면 "차이가 우연한 흔들림의 두 배"라는 뜻이고, 대략 |t| > 2면 p-value가 0.05보다 작아집니다.

::figure{src="content/img/stats/st05-ttest-chooser.svg" alt="t검정 선택 순서도. 질문 1: 기준값 하나와 비교하나? 예이면 1표본 t검정 ttest_1samp. 아니면 질문 2: 같은 대상을 두 번 쟀나? 예이면 대응 t검정 ttest_rel, 아니면 독립 2표본 t검정 ttest_ind(equal_var=False)" caption="t검정 고르기: 기준값과 비교하면 1표본, 같은 대상을 두 번 쟀으면 대응, 서로 다른 두 그룹이면 독립 2표본(Welch)."}

## ① 1표본 t검정: 기준값과 비교

남극 펭귄 연구 자료에 "이 지역 펭귄의 평균 몸무게는 4,000g"이라고 적혀 있습니다. 우리가 잰 342마리의 평균은 이 기준과 다를까요?

- H₀: 모평균 = 4,000g
- H₁: 모평균 ≠ 4,000g

```run
import pandas as pd

mass = pd.read_csv("penguins.csv")["body_mass_g"].dropna()
print("표본평균:", round(mass.mean(), 1), "g / 기준과의 차이:", round(mass.mean() - 4000, 1), "g")
```

표본평균은 4,201.8g으로 기준보다 201.8g 무겁습니다. 이 차이가 우연한 흔들림으로 설명될 수 있는지 `stats.ttest_1samp(데이터, 기준값)`으로 검정합니다.

```run
import pandas as pd
from scipy import stats

mass = pd.read_csv("penguins.csv")["body_mass_g"].dropna()
res = stats.ttest_1samp(mass, 4000)
print("t =", round(res.statistic, 3), "/ p-value =", f"{res.pvalue:.1e}")
```

t = 4.65, p-value는 4.7e-06(0.0000047)입니다. 차이가 표준오차의 4.65배라서, 모평균이 정말 4,000g이라면 이런 표본은 거의 나오지 않습니다. 유의수준 0.05에서 **H₀를 기각**합니다. "이 펭귄들의 평균 몸무게는 4,000g보다 무겁다고 볼 근거가 있다"고 결론 내립니다.

> `4.7e-06`은 4.7 × 10⁻⁶, 즉 0.0000047을 짧게 쓴 표기입니다. p-value가 아주 작을 때 자주 보입니다.

## ② 독립 2표본 t검정: 서로 다른 두 그룹

식당에서 점심 손님과 저녁 손님의 평균 계산 금액을 비교합니다. 점심 손님과 저녁 손님은 서로 다른 사람들이므로 **독립인 두 그룹**입니다.

```run
import pandas as pd

df = pd.read_csv("tips.csv")
print(df.groupby("time")["total_bill"].agg(["count", "mean", "std"]).round(2))
```

저녁(176건)은 평균 20.80달러, 점심(68건)은 17.17달러로 저녁이 3.63달러 높습니다. 표준편차도 저녁(9.14)과 점심(7.71)이 다릅니다.

`stats.ttest_ind(그룹1, 그룹2)`로 검정합니다. 여기서 `equal_var=False`를 꼭 넣는 습관을 들이세요. 두 그룹의 흩어짐(분산)이 같다고 가정하지 않는 **Welch t검정**으로, 분산이 실제로 같을 때도 손해가 거의 없고 다를 때는 훨씬 정확합니다.

```run
import pandas as pd
from scipy import stats

df = pd.read_csv("tips.csv")
dinner, lunch = df.query("time == 'Dinner'")["total_bill"], df.query("time == 'Lunch'")["total_bill"]
res = stats.ttest_ind(dinner, lunch, equal_var=False)
print("t =", round(res.statistic, 3), "/ p-value =", round(res.pvalue, 4))
```

t = 3.12, p-value = 0.0022입니다. 0.05보다 훨씬 작으니 **H₀를 기각**합니다. 저녁 손님의 평균 계산 금액이 점심보다 높다고 볼 근거가 있습니다.

## ③ 대응 t검정: 같은 대상을 두 번

학생 8명이 수학 특강을 듣기 **전**과 **후**에 같은 난이도의 시험을 봤습니다.

| 학생 | A | B | C | D | E | F | G | H |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 전 | 62 | 70 | 55 | 81 | 68 | 74 | 59 | 66 |
| 후 | 66 | 73 | 57 | 86 | 70 | 79 | 60 | 70 |

같은 학생을 두 번 쟀으므로 두 줄은 **짝**(대응)이 있습니다. 이럴 때는 학생마다 **차이(후 − 전)**를 먼저 구하는 것이 핵심입니다.

```run
import numpy as np

before = np.array([62, 70, 55, 81, 68, 74, 59, 66])
after = np.array([66, 73, 57, 86, 70, 79, 60, 70])
print("학생별 차이:", after - before, "/ 평균 차이:", (after - before).mean())
```

8명 모두 점수가 1~5점 올랐고, 평균 3.25점 올랐습니다. `stats.ttest_rel(후, 전)`은 이 차이들의 평균이 0인지 검정합니다.

```run
import numpy as np
from scipy import stats

before = np.array([62, 70, 55, 81, 68, 74, 59, 66])
after = np.array([66, 73, 57, 86, 70, 79, 60, 70])
print("대응 t검정 p-value:", round(stats.ttest_rel(after, before).pvalue, 5))
```

p-value = 0.00046으로 아주 작습니다. 특강 후 점수가 올랐다고 볼 근거가 강합니다.

## 대응을 무시하면 차이를 놓친다

같은 데이터를 실수로 **독립 2표본** t검정에 넣으면 어떻게 될까요?

```run
import numpy as np
from scipy import stats

before = np.array([62, 70, 55, 81, 68, 74, 59, 66])
after = np.array([66, 73, 57, 86, 70, 79, 60, 70])
print("(잘못) 독립 t검정 p-value:", round(stats.ttest_ind(after, before, equal_var=False).pvalue, 3))
```

p-value가 0.48로 커져서 "차이를 확인하지 못함"이 됩니다. 왜 이렇게 달라질까요? 학생들의 실력 차이(55점 ~ 81점, 26점 폭)가 특강 효과(3점)보다 훨씬 큽니다. 독립 검정은 이 학생 간 차이를 모두 "잡음"으로 취급해서 3점이라는 신호가 묻혀 버립니다. 대응 검정은 학생마다 자기 자신과 비교하므로 학생 간 차이가 사라지고, 신호가 또렷해집니다.

**같은 대상을 두 번 쟀다면 반드시 대응 t검정**을 쓰세요. 실험을 설계할 때도, 가능하면 같은 대상을 전후로 재는 편이 적은 표본으로 효과를 잡아내기 쉽습니다.

## 실무 예제: 고장 설비의 토크는 정말 더 높을까

설비 데이터 전체로 고장 설비(339대)와 정상 설비(9,661대)의 토크를 Welch t검정으로 비교합니다. 그룹 크기와 흩어짐이 크게 다르니 `equal_var=False`가 맞습니다. 결과에서 p-value뿐 아니라 **차이의 신뢰구간**도 함께 뽑습니다.

```run
import pandas as pd
from scipy import stats

df = pd.read_csv("ai4i2020.csv")
f, o = df.query("failure == 1")["torque"], df.query("failure == 0")["torque"]
res = stats.ttest_ind(f, o, equal_var=False); ci = res.confidence_interval(0.95)
print(f"차이 {f.mean() - o.mean():.2f}Nm, 95% CI {ci.low:.2f} ~ {ci.high:.2f}, t = {res.statistic:.1f}, p = {res.pvalue:.1e}")
```

고장 설비의 토크가 평균 10.54Nm 높고(95% CI 8.78 ~ 12.30Nm), p-value는 3.6 × 10⁻²⁷로 매우 작습니다. 그런데 "얼마나 큰 차이인가"는 p-value가 알려 주지 않습니다. 차이를 두 그룹의 표준편차로 나눈 **효과 크기**(Cohen's d)를 함께 봅니다.

```run
import numpy as np
import pandas as pd

df = pd.read_csv("ai4i2020.csv")
f, o = df.query("failure == 1")["torque"], df.query("failure == 0")["torque"]
print("Cohen's d =", round((f.mean() - o.mean()) / np.sqrt((f.var() + o.var()) / 2), 2))
```

d = 0.79입니다. 흔히 0.2는 작은 효과, 0.5는 중간, 0.8은 큰 효과로 읽습니다. 고장 설비의 토크는 "평균에서 표준편차 0.8개 정도 위"에 있는 셈이라, 토크가 고장과 꽤 강하게 관련된 변수라고 말할 수 있습니다. 보고서에는 이렇게 씁니다.

> 고장 설비(n = 339)의 평균 토크는 정상 설비(n = 9,661)보다 10.5Nm 높았다(95% CI 8.8 ~ 12.3Nm, Welch t검정 p < 0.001, d = 0.79).

## 자주 하는 실수

1. **같은 대상을 두 번 쟀는데 독립 검정을 쓴다.** 전 · 후 측정은 대응 검정입니다. 독립 검정을 쓰면 개인차가 잡음으로 들어가 차이를 놓칩니다.
2. **그룹 크기가 크게 다른데 equal_var=True(기본 Student t)를 쓴다.** 분산이 다르면 결과가 틀어질 수 있습니다. 기본으로 Welch를 쓰세요.
3. **p-value가 아주 작다고 효과가 크다고 말한다.** 표본이 10,000개면 아주 작은 차이도 p가 작아집니다. 차이, 신뢰구간, 효과 크기를 함께 적습니다.

## 단측 검정: 방향을 미리 정했을 때

지금까지는 "다른가?"(≠)를 묻는 **양측 검정**이었습니다. 그런데 데이터를 보기 **전부터** "저녁이 점심보다 **많을** 것이다"처럼 방향이 분명한 가설을 세웠다면, 한쪽 꼬리만 보는 **단측 검정**을 쓸 수 있습니다. `alternative="greater"`(첫 그룹이 더 크다) 또는 `"less"`(더 작다)를 줍니다.

```run
import pandas as pd
from scipy import stats

df = pd.read_csv("tips.csv")
dinner, lunch = df.query("time == 'Dinner'")["total_bill"], df.query("time == 'Lunch'")["total_bill"]
print("양측:", round(stats.ttest_ind(dinner, lunch, equal_var=False).pvalue, 4))
print("단측(저녁 > 점심):", round(stats.ttest_ind(dinner, lunch, equal_var=False, alternative="greater").pvalue, 4))
```

단측 p-value(0.0011)는 양측(0.0022)의 정확히 절반입니다. 한쪽 꼬리만 세기 때문입니다.

> 단측 검정은 p-value를 절반으로 줄여 주기 때문에, 결과를 **본 뒤에** "유의하게 나오도록" 단측으로 바꾸고 싶은 유혹이 생깁니다. 이것은 반칙입니다. 방향은 반드시 데이터를 보기 전에 정해야 하고, 확신이 없으면 양측을 쓰세요.

직접 해 보세요: 1표본 t검정 셀에서 기준값 `4000`을 `4150`, `4200`으로 바꿔 보세요. 기준값이 표본평균(4,201.8g)에 가까워질수록 p-value가 어떻게 변하나요?

## 정리

| 상황 | 검정 | scipy |
| --- | --- | --- |
| 평균이 기준값과 다른가 | 1표본 t검정 | `stats.ttest_1samp(x, 기준값)` |
| 서로 다른 두 그룹의 평균 비교 | 독립 2표본 (Welch) | `stats.ttest_ind(a, b, equal_var=False)` |
| 같은 대상의 전 · 후 비교 | 대응 t검정 | `stats.ttest_rel(후, 전)` |
| 방향을 미리 정함 | 단측 | `alternative="greater"` 또는 `"less"` |

- t = 차이 ÷ 차이의 표준오차 = 신호 ÷ 잡음.
- 같은 대상을 두 번 쟀다면 반드시 대응 검정. 독립 검정을 쓰면 차이를 놓칠 수 있다.
- 단측 검정은 데이터를 보기 전에 방향을 정했을 때만.
