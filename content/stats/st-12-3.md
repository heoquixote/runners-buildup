## 정규성, 왜 이렇게 자주 확인할까

t검정 · ANOVA · 회귀의 p-value, 관리도의 3σ 한계, 공정능력지수는 모두 **정규분포**를 바탕으로 계산합니다. 그래서 분석 전에 "이 데이터가 정규분포에 가까운가"를 자주 묻습니다. [가정 확인과 비모수 검정](#/l/st-06-3)에서는 히스토그램과 샤피로-윌크 검정을 썼습니다. 이번 레슨에서는 실무에서 가장 많이 쓰는 그림인 **Q-Q 플롯**을 제대로 읽는 법과, 다른 정규성 검정 두 가지(**KS**, **앤더슨-달링**)를 배우고, 정규성 검정을 **언제 믿지 말아야 하는지**까지 정리합니다.

## Q-Q 플롯: 정규분포와 줄 세워 비교하기

Q-Q 플롯은 데이터를 작은 값부터 줄 세운 뒤, "정규분포에서 같은 개수를 뽑았다면 같은 순서에 올 값(이론 분위수)"과 짝지어 점을 찍습니다.

- 100개 중 5번째로 작은 값은 하위 5% 근처이므로, 정규분포의 하위 5% 값(z = −1.64)과 짝이 됩니다.
- 50번째 값은 한가운데라 z = 0과 짝이 됩니다.

데이터가 정규분포라면 모든 짝이 비례해서 **점이 직선 위에** 늘어섭니다. 직선에서 벗어나는 **모양**이 분포가 어떻게 다른지 알려 줍니다.

::figure{src="content/img/stats/st12-qq-patterns.svg" alt="Q-Q 플롯 네 가지: 정규면 직선, 오른쪽 꼬리가 길면 아래로 볼록, 꼬리가 두꺼우면 뒤집은 S자, 꼬리가 얇으면 S자" caption="Q-Q 플롯은 가운데보다 양 끝을 봅니다. 끝이 직선 위로 휘면 그쪽 꼬리가 길고, 아래로 휘면 짧습니다."}

| 모양 | 뜻 | 예 |
| --- | --- | --- |
| 직선 | 정규분포에 가까움 | 키, 측정 오차 |
| 아래로 볼록 (양 끝이 위로) | 오른쪽 꼬리가 김 (양의 왜도) | 소득, 팁, 대기 시간 |
| 뒤집은 S자 (왼쪽 끝은 아래, 오른쪽 끝은 위) | 양쪽 꼬리가 두꺼움 (이상치가 잦음) | 주가 수익률 |
| S자 (양 끝이 직선 안쪽으로) | 양쪽 꼬리가 얇음 | 균등분포, 사용 시간처럼 범위가 정해진 값 |

실제 데이터 세 가지를 그려 봅니다. `stats.probplot`이 이론 분위수와 정렬된 값을 계산하고 직선까지 그려 줍니다.

```run
import pandas as pd
import matplotlib.pyplot as plt
from scipy import stats

peng = pd.read_csv("penguins.csv").dropna()
tips = pd.read_csv("tips.csv")
ai4i = pd.read_csv("ai4i2020.csv").sample(200, random_state=0)
data = {"Gentoo body mass": peng[peng["species"] == "Gentoo"]["body_mass_g"],
        "tip": tips["tip"],
        "tool wear (200 machines)": ai4i["tool_wear"]}
fig, axes = plt.subplots(1, 3, figsize=(10, 3.2))
for ax, (name, x) in zip(axes, data.items()):
    stats.probplot(x, dist="norm", plot=ax)
    ax.set_title(name, fontsize=10)
    print(f"{name:>24}: skew {stats.skew(x):5.2f}, excess kurtosis {stats.kurtosis(x):5.2f}")
plt.tight_layout(); plt.show()
```

- **Gentoo 몸무게**: 점이 직선을 잘 따릅니다. 왜도 0.04, 첨도 −0.76으로 정규에 가깝습니다.
- **팁**: 오른쪽 끝이 직선 위로 크게 휘어 올라갑니다. 왜도 1.46, 오른쪽 꼬리가 긴 분포입니다.
- **공구 마모 시간**: 양 끝이 직선 안쪽으로 들어오는 S자입니다. 첨도 −1.14로 꼬리가 얇습니다. 공구는 0분부터 약 250분 사이에서 고르게 쓰이다가 교체되기 때문에, 균등분포에 가까운 모양입니다.

첨도(`stats.kurtosis`)는 정규분포를 0으로 맞춘 **초과 첨도**입니다. 양수면 꼬리가 두껍고, 음수면 얇습니다.

## 숫자로 확인하는 정규성 검정 세 가지

세 검정 모두 귀무가설은 "데이터가 정규분포에서 나왔다"입니다. 차이는 **무엇을 비교하느냐**입니다.

| 검정 | 비교하는 것 | 특징 |
| --- | --- | --- |
| 샤피로-윌크 `stats.shapiro` | Q-Q 플롯이 얼마나 직선에 가까운가 | 대부분의 상황에서 검정력이 가장 높음 |
| 콜모고로프-스미르노프(KS) `stats.kstest` | 누적분포(CDF)끼리의 **가장 큰 차이** 하나 | 가운데 차이에 민감, 꼬리에 둔감 |
| 앤더슨-달링 `stats.anderson` | 누적분포 차이를 **꼬리에 가중치**를 더 줘서 합산 | 꼬리(이상치, 극단값) 차이에 민감 |

KS 검정의 통계량은 그림으로 이해하면 쉽습니다. 데이터의 누적 비율 계단(경험적 누적분포)과 정규분포의 누적곡선을 겹쳐 그렸을 때, **세로로 가장 크게 벌어진 거리** D가 통계량입니다.

```run
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from scipy import stats

x = pd.read_csv("tips.csv")["tip"]
z = np.sort((x - x.mean()) / x.std())
ecdf = np.arange(1, len(z) + 1) / len(z)
res = stats.kstest(z, "norm")
fig, ax = plt.subplots(figsize=(5.5, 3.4))
ax.step(z, ecdf, where="post", label="data (empirical CDF)")
grid = np.linspace(-3, 4, 300)
ax.plot(grid, stats.norm.cdf(grid), label="normal CDF")
ax.set_title(f"KS statistic D = {res.statistic:.3f}"); ax.legend()
plt.tight_layout(); plt.show()
print("KS D =", round(res.statistic, 3), ", p =", round(res.pvalue, 4))
```

팁 데이터는 D = 0.102, p = 0.012입니다. 가장 크게 벌어진 곳은 평균보다 조금 큰 약 3.5달러 근처로, 데이터 계단이 정규 곡선보다 0.10 위에 있습니다. 3.5달러 이하 팁이 정규분포가 예상하는 것보다 10%p 더 많다는 뜻입니다. 작은 팁이 몰려 있고, 대신 오른쪽으로 긴 꼬리가 있는 모양입니다.

## KS 검정의 함정: 평균과 표준편차를 데이터에서 구하면

위 코드는 데이터의 평균과 표준편차로 표준화한 뒤 표준정규분포와 비교했습니다. 그런데 KS 검정의 p-value는 **비교할 분포가 미리 정해져 있을 때**를 가정합니다. 데이터에서 평균 · 표준편차를 구해 맞춰 놓으면 정규 곡선이 데이터 쪽으로 미리 다가와 있어서, D가 작게 나오고 p-value는 **너무 커집니다**(정규가 아닌 것을 놓침). 이를 바로잡은 것이 **릴리포스(Lilliefors) 검정**입니다.

```run
import pandas as pd
from scipy import stats
from statsmodels.stats.diagnostic import lilliefors

ai4i = pd.read_csv("ai4i2020.csv").sample(200, random_state=0)
for name, x in [("tool wear", ai4i["tool_wear"]), ("air temp", ai4i["air_temp"])]:
    z = (x - x.mean()) / x.std()
    ad = stats.anderson(x, dist="norm")
    print(f"{name:>9}: naive KS p {stats.kstest(z, 'norm').pvalue:.3f} | Lilliefors p {lilliefors(x)[1]:.3f} | "
          f"Shapiro p {stats.shapiro(x).pvalue:.4f} | Anderson A2 {ad.statistic:.2f} (5% critical {ad.critical_values[2]:.2f})")
```

| 설비 200대 | 단순 KS | 릴리포스 | 샤피로 | 앤더슨-달링 (5% 기준 0.77) |
| --- | --- | --- | --- | --- |
| 공구 마모 | 0.195 (정규?) | 0.008 | 0.0000 | 1.98 → 기각 |
| 공기 온도 | 0.347 (정규?) | 0.040 | 0.0006 | 1.36 → 기각 |

단순 KS는 두 변수 모두 "정규성을 기각할 수 없다"고 했지만, 릴리포스 · 샤피로 · 앤더슨-달링은 모두 정규가 아니라고 판단했습니다. 공구 마모처럼 **꼬리가 얇은** 분포를 단순 KS는 거의 잡지 못합니다. 정규성을 볼 때 KS를 쓴다면 반드시 릴리포스 보정판을 씁니다.

앤더슨-달링은 p-value 대신 **통계량과 기준값**을 줍니다. 통계량(A²)이 5% 기준값보다 크면 5% 유의수준에서 정규성을 기각합니다.

## 정규성 검정의 진짜 함정: 표본 크기

정규성 검정도 검정이라서 **표본이 크면 아주 작은 어긋남도 잡아냅니다.** 같은 공기 온도 데이터를 20개, 100개, 1,000개, 5,000개 뽑아 샤피로 검정을 해 봅니다.

```run
import pandas as pd
from scipy import stats

air = pd.read_csv("ai4i2020.csv")["air_temp"]
for n in [20, 100, 1000, 5000]:
    print(f"n = {n:>4}: Shapiro p = {stats.shapiro(air.sample(n, random_state=1)).pvalue:.4f}")
```

같은 분포인데 n = 20이면 p = 0.38(정규로 보임), n = 100이면 0.018, n = 1,000부터는 0.0000입니다. 공기 온도의 분포 모양은 그대로인데 판단이 바뀐 것은 **표본 크기 때문**입니다.

그래서 실무 규칙은 이렇습니다.

1. **그림(Q-Q 플롯, 히스토그램)을 먼저** 본다. 검정은 보조.
2. 표본이 크면(그룹당 30 ~ 50 이상) 평균 비교는 [중심극한정리](#/l/st-03-3) 덕분에 정규성에 크게 흔들리지 않는다. 검정 p가 작아도 Q-Q 플롯이 크게 휘지 않았다면 t검정 · ANOVA를 써도 된다.
3. 표본이 작은데 Q-Q 플롯 끝이 크게 휘었다면 [비모수 검정](#/l/st-06-3)이나 변환(로그 등)을 쓴다.
4. **정규성이 결과에 직접 들어가는 분석**(관리도 한계, 공정능력지수, 개별 값의 예측구간)은 표본이 커도 정규성을 꼼꼼히 확인한다. 평균이 아니라 개별 값의 꼬리를 쓰기 때문이다.

## 자주 하는 실수

| 실수 | 무슨 일이 생기나 | 바로잡기 |
| --- | --- | --- |
| 데이터로 평균 · 표준편차를 구해 KS 검정 | p-value가 너무 커서 비정규를 놓침 (공구 마모 0.195) | 릴리포스(`lilliefors`) 또는 샤피로 |
| 1만 개 데이터에 샤피로 p < 0.05 → "정규 아님, t검정 금지" | 사소한 어긋남에 과잉 반응 | Q-Q 플롯과 표본 크기를 함께 판단 |
| 20개 데이터에 p = 0.38 → "정규분포 확인" | 검정력이 낮아 못 잡은 것일 수 있음 | "기각하지 못함"은 "정규임"이 아니다 |
| Q-Q 플롯 가운데만 봄 | 꼬리의 어긋남을 놓침 | 양 끝 점들을 본다 |

## 정리

- **Q-Q 플롯**은 정렬한 데이터와 정규분포 분위수를 짝지은 그림입니다. 직선이면 정규, 끝이 위로 휘면 그쪽 꼬리가 길고, S자면 꼬리가 얇습니다.
- **샤피로**는 검정력이 가장 높고, **KS**는 누적분포의 최대 차이, **앤더슨-달링**은 꼬리에 가중치를 둡니다. 평균 · 표준편차를 데이터에서 구했다면 KS 대신 **릴리포스**를 씁니다.
- 정규성 검정은 표본 크기에 크게 좌우됩니다. 같은 공기 온도가 n = 20에서 p = 0.38, n = 1,000에서 0.0000이었습니다. **그림 먼저, 검정은 보조**입니다.
