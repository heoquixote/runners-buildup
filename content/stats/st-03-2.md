## 표본평균도 흔들린다

반 친구 30명 중 5명을 무작위로 뽑아 평균 키를 재면 168cm가 나왔다고 해 봅시다. 다른 5명을 뽑으면? 171cm가 나올 수도, 165cm가 나올 수도 있습니다. [지난 레슨](#/l/st-03-1)에서 봤듯이 무작위 표본도 뽑을 때마다 결과가 **흔들립니다**.

그렇다면 표본평균은 **얼마나** 흔들릴까요? 이 질문에 답할 수 있어야 "표본평균 168cm"라는 숫자를 얼마나 믿을지 정할 수 있습니다. 이번 레슨의 답은 놀랍도록 간단한 공식 하나로 정리됩니다.

## 실험 무대: 설비 10,000대의 공구 마모

설비 데이터(`ai4i2020.csv`)의 공구 마모 시간(`tool_wear`, 분)을 **모집단**으로 씁니다. 10,000대 전체를 갖고 있으니 모평균과 모표준편차를 알 수 있습니다. 모집단 전체이므로 표준편차는 n으로 나눕니다(`ddof=0`, [st-01-2](#/l/st-01-2)).

```run
import pandas as pd

wear = pd.read_csv("ai4i2020.csv")["tool_wear"]
print("모평균 μ:", round(wear.mean(), 2), "/ 모표준편차 σ:", round(wear.std(ddof=0), 2))
```

모평균 μ = 107.95분, 모표준편차 σ = 63.65분입니다. 실제 조사라면 이 값을 모르는 상태에서 설비 30대만 골라 평균을 낼 것입니다.

```run
import numpy as np
import pandas as pd

wear = pd.read_csv("ai4i2020.csv")["tool_wear"]
rng = np.random.default_rng(0)
print("30대 표본평균:", round(rng.choice(wear, 30).mean(), 1))
```

`rng.choice(wear, 30)`은 10,000개 중에서 30개를 무작위로 고릅니다. 이번 표본평균은 110.0분으로 모평균 107.95분과 2분쯤 차이가 납니다. 다섯 번 더 뽑아 봅니다.

```run
import numpy as np
import pandas as pd

wear = pd.read_csv("ai4i2020.csv")["tool_wear"]
rng = np.random.default_rng(1)
print([float(round(rng.choice(wear, 30).mean(), 1)) for _ in range(5)])
```

106.6, 115.4, 98.4, 133.0, 101.4분입니다. 가장 작은 값과 가장 큰 값이 35분 가까이 차이 납니다. 같은 모집단에서 같은 크기로 뽑았는데 표본평균이 이만큼 오르내립니다.

## 표본분포: 표본평균들의 분포

이 실험을 1,000번 반복해서 표본평균 1,000개를 모으고, 그 1,000개의 히스토그램을 그려 봅시다. 이렇게 **통계량(여기서는 표본평균)이 표본마다 어떻게 퍼지는지**를 나타낸 분포를 **표본분포**(sampling distribution)라고 합니다.

::figure{src="content/img/stats/st03-sampling-dist.svg" alt="왼쪽 모집단 상자에서 화살표로 표본 1, 표본 2, 표본 3 … 표본 1000이 나오고, 각 표본의 평균 값 하나씩이 오른쪽 히스토그램의 벽돌로 쌓이는 흐름도" caption="표본 하나에서 평균 하나가 나옵니다. 이것을 1,000번 반복해 평균 1,000개를 쌓은 히스토그램이 표본분포입니다."}

헷갈리기 쉬운 점은 히스토그램의 **벽돌 하나가 설비 한 대가 아니라 표본 하나(설비 30대의 평균)**라는 것입니다.

```run
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd

wear = pd.read_csv("ai4i2020.csv")["tool_wear"]
rng = np.random.default_rng(0)
means = np.array([rng.choice(wear, 30).mean() for _ in range(1000)])
plt.hist(means, bins=30); plt.xlabel("sample mean (n=30)"); plt.show()
print("표본평균들의 평균:", round(means.mean(), 2), "/ 표준편차:", round(means.std(), 2))
```

두 가지를 확인할 수 있습니다.

1. **표본평균들의 평균은 108.17분으로 모평균 107.95분과 거의 같습니다.** 표본평균은 한 번 한 번은 빗나가도, 평균적으로는 참값을 정확히 겨냥합니다(편향이 없음).
2. **표본평균들은 표준편차 11.12분 정도로 흩어집니다.** 설비 한 대 한 대의 흩어짐(σ = 63.65분)보다 훨씬 좁습니다. 30대의 평균을 내면서 큰 값과 작은 값이 서로 상쇄되기 때문입니다.

## 표준오차: 표본평균의 흔들림 크기

표본평균들의 표준편차, 즉 **표본평균이 보통 얼마나 흔들리는지**를 **표준오차**(standard error, SE)라고 합니다. 매번 1,000번씩 시뮬레이션하지 않아도 공식으로 바로 구할 수 있습니다.

> SE = σ ÷ √n

모표준편차를 표본 크기의 제곱근으로 나눈 값입니다. 공식으로 계산한 값과 시뮬레이션 값을 비교해 봅니다.

```run
import numpy as np
import pandas as pd

wear = pd.read_csv("ai4i2020.csv")["tool_wear"]
sigma = wear.std(ddof=0)
print("공식 σ/√30:", round(sigma / np.sqrt(30), 2))
```

공식으로 구한 표준오차는 11.62분으로, 시뮬레이션의 11.12분과 거의 같습니다. 이 공식 덕분에 표본 하나만 갖고도 "내 표본평균이 보통 ±11.6분 정도는 흔들릴 수 있다"고 말할 수 있습니다.

## n을 4배로 하면 흔들림은 절반

공식에 √n이 들어 있다는 것이 중요합니다. 표본 크기를 10, 40, 160대로 4배씩 늘리며 표준오차를 비교해 봅니다.

```run
import numpy as np
import pandas as pd

wear = pd.read_csv("ai4i2020.csv")["tool_wear"]
for n in [10, 40, 160]:
    print("n =", n, "→ SE =", round(wear.std(ddof=0) / np.sqrt(n), 2))
```

n = 10일 때 20.13분, 40일 때 10.06분, 160일 때 5.03분입니다. **표본을 4배로 늘려야 흔들림이 절반으로 줄어듭니다.** 정확도를 두 배로 높이려면 비용이 네 배 드는 셈이라, 실제 조사에서는 "얼마나 정확해야 하나"와 "얼마나 쓸 수 있나" 사이에서 표본 크기를 정합니다([DAY 10](#/l/st-08-2)).

직접 해 보세요: 위 셀의 `[10, 40, 160]`을 `[100, 400, 2500]`으로 바꿔 보세요. 2,500대면 표준오차가 약 1.3분까지 줄어듭니다.

## 표준편차와 표준오차는 다르다

이름이 비슷해서 가장 많이 헷갈리는 두 개념입니다.

| | 표준편차 (SD) | 표준오차 (SE) |
| --- | --- | --- |
| 무엇의 흩어짐? | **값 하나하나** | **표본평균** (표본을 여러 번 뽑았을 때) |
| 질문 | 설비 한 대의 마모 시간은 보통 얼마나 다른가? | 30대 평균은 보통 얼마나 빗나가나? |
| n을 키우면? | 거의 그대로 (데이터 자체의 성질) | 줄어든다 (√n에 반비례) |
| 이 예에서 | 63.65분 | 11.62분 (n = 30) |

보고서에서 "평균 ± 숫자"를 볼 때는 그 숫자가 SD인지 SE인지 꼭 확인하세요. 데이터가 얼마나 다양한지를 말하려면 SD, 평균을 얼마나 믿을지를 말하려면 SE입니다.

## 현실에서는: 표본 하나로 SE 추정하기

실제 조사에서는 모표준편차 σ를 모릅니다. 그래서 표본의 표준편차 s(n − 1로 나눈 것)로 대신 계산합니다. `scipy.stats.sem`이 이 계산을 한 번에 해 줍니다(sem = standard error of the mean).

```run
import numpy as np
import pandas as pd
from scipy import stats

wear = pd.read_csv("ai4i2020.csv")["tool_wear"]
sample = wear.sample(30, random_state=0)
print("직접 s/√n:", round(sample.std(ddof=1) / np.sqrt(30), 2), "/ stats.sem:", round(stats.sem(sample), 2))
```

표본 30대 하나만으로 추정한 표준오차는 11.67분입니다. 참값(11.62분)과 완전히 같지는 않지만, "평균이 ±10분 남짓 흔들릴 수 있다"는 감을 잡기엔 충분합니다. 이 추정된 SE가 [신뢰구간](#/l/st-04-1)과 [t검정](#/l/st-05-3)의 재료가 됩니다.

## 실무 예제: 몇 대를 재야 할까

표준오차 공식을 거꾸로 쓰면 **필요한 표본 수**를 구할 수 있습니다. "공구 사용 시간 평균을 ±5분 정도의 흔들림(SE ≤ 5)으로 알고 싶다"면,

> SE = σ ÷ √n ≤ 5 → n ≥ (σ ÷ 5)²

σ는 과거 데이터나 예비 조사로 짐작합니다. 설비 데이터의 표준편차를 써 봅니다.

```run
import numpy as np
import pandas as pd

sigma = pd.read_csv("ai4i2020.csv")["tool_wear"].std(ddof=0)
print("σ =", round(sigma, 1), "→ 필요한 n =", int(np.ceil((sigma / 5) ** 2)))
```

σ가 63.7분이니 163대를 재면 됩니다. 정말 그런지 163대씩 2,000번 뽑아 평균들의 표준편차를 확인합니다.

```run
import numpy as np
import pandas as pd

wear = pd.read_csv("ai4i2020.csv")["tool_wear"]
rng = np.random.default_rng(0)
print("163대 평균의 흔들림:", round(np.std([rng.choice(wear, 163).mean() for _ in range(2000)]), 2))
```

4.97분으로, 목표한 5분 안에 들어옵니다. 흔들림을 절반(2.5분)으로 줄이고 싶다면 n은 4배인 약 650대가 필요합니다. 점검 비용과 원하는 정밀도 사이에서 표본 수를 정하는 것이 실무의 일입니다.

## 자주 하는 실수

1. **보고서에 SE를 적어 놓고 "데이터가 이만큼 흩어져 있다"고 설명한다.** SE는 평균의 흔들림입니다. 값 하나하나의 흩어짐은 표준편차입니다.
2. **SE가 작으니 데이터가 정확하다고 생각한다.** SE는 표본이 크면 얼마든지 작아집니다. 편향된 표본이라면 SE가 아무리 작아도 엉뚱한 값을 정밀하게 맞히는 것입니다.
3. **모집단 크기가 중요하다고 생각한다.** 모집단이 표본보다 훨씬 크면, SE는 모집단 크기(10만이든 1억이든)가 아니라 표본 크기 n으로 정해집니다.

## 정리

- 표본평균도 표본마다 흔들리는 값이다. 그 분포를 **표본분포**라고 한다.
- 표본분포의 중심은 **모평균**(편향 없음), 흩어짐은 **표준오차 SE = σ ÷ √n**.
- 표본을 **4배**로 늘려야 표준오차가 **절반**이 된다.
- **표준편차**는 값 하나하나의 흩어짐, **표준오차**는 평균의 흔들림. 현실에서는 s ÷ √n(`stats.sem`)으로 추정한다.
