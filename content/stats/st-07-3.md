## 직선을 그었다고 끝이 아니다

[지난 레슨](#/l/st-07-2)에서 펭귄의 지느러미 길이로 몸무게를 예측하는 직선 ŷ = −5,780.8 + 49.69x를 구했습니다. 그런데 최소제곱법은 **어떤 데이터에도** 직선을 그어 줍니다. 점들이 U자로 휘어 있어도, 아무 관계가 없는 구름이어도 "가장 잘 맞는 직선"은 항상 나옵니다.

그래서 직선을 구한 다음에는 반드시 물어야 합니다. **"이 직선을 믿어도 되나?"** 이번 레슨에서는 회귀 결과를 읽고 진단하는 네 가지 도구를 배웁니다: R², 기울기의 p-value와 신뢰구간, 잔차 그래프, 그리고 외삽 주의.

`stats.linregress`의 결과에는 이미 이 재료들이 들어 있습니다.

```run
import pandas as pd
from scipy import stats

df = pd.read_csv("penguins.csv").dropna(subset=["flipper_length_mm", "body_mass_g"])
res = stats.linregress(df["flipper_length_mm"], df["body_mass_g"])
print("R² =", round(res.rvalue ** 2, 3), "/ 기울기 p-value =", f"{res.pvalue:.1e}", "/ 기울기 표준오차 =", round(res.stderr, 2))
```

R² = 0.759, 기울기 p-value = 4.4e-107, 기울기 표준오차 = 1.52입니다. 하나씩 뜻을 알아봅니다.

## R²: 직선이 설명하는 비율

펭귄 몸무게는 2,700g부터 6,300g까지 다양합니다. 이 다양함(흩어짐) 중에서 **지느러미 길이로 설명되는 부분은 몇 %일까요?** 이것이 **R²**(결정계수)입니다.

::figure{src="content/img/stats/st07-r-squared.svg" alt="두 개의 막대. 위 막대는 전체 흩어짐(평균에서 잰 제곱합) 100%. 아래 막대는 그중 직선이 설명한 부분 76%와 직선이 설명하지 못하고 잔차로 남은 부분 24%로 나뉘어 있다" caption="R²는 y의 전체 흩어짐 중에서 직선이 설명한 비율입니다. 나머지는 잔차로 남은, 직선이 설명하지 못한 부분입니다."}

- **전체 흩어짐**: 몸무게가 평균에서 떨어진 거리의 제곱합. x를 전혀 모를 때 우리가 가진 "모름"의 크기입니다.
- **남은 흩어짐**: 직선으로 예측한 뒤에도 남는 잔차의 제곱합. x를 알고도 여전히 남은 "모름"입니다.

> R² = 1 − (남은 흩어짐 ÷ 전체 흩어짐)

직접 계산해 봅니다.

```run
import pandas as pd
from scipy import stats

df = pd.read_csv("penguins.csv").dropna(subset=["flipper_length_mm", "body_mass_g"])
x, y = df["flipper_length_mm"], df["body_mass_g"]
res = stats.linregress(x, y)
total, left = ((y - y.mean()) ** 2).sum(), ((y - (res.intercept + res.slope * x)) ** 2).sum()
print(f"전체 {total:,.0f} / 남은 {left:,.0f} / R² = {1 - left / total:.3f}")
```

전체 흩어짐 219,307,697 중에서 직선을 쓴 뒤에 남은 것은 52,854,796입니다. R² = 0.759, 즉 **몸무게 흩어짐의 약 76%를 지느러미 길이 하나로 설명**한다는 뜻입니다. 나머지 24%는 종, 성별, 먹이 같은 다른 요인들 몫입니다.

단순선형회귀에서는 R²가 상관계수 r의 제곱과 같습니다(0.871² = 0.759). R²는 0~1 사이이고, 1이면 모든 점이 직선 위에 딱 놓인 것, 0이면 직선이 평균선보다 나을 게 없다는 것입니다.

> R²가 높다고 "좋은 모델"인 것은 아닙니다. 앞으로 볼 곡선 패턴처럼 직선이 틀린 모양이어도 R²가 꽤 높게 나올 수 있습니다. R²는 잔차 그래프와 함께 봐야 합니다.

## 기울기의 p-value와 신뢰구간

`linregress`의 p-value는 "**기울기 = 0**"이라는 귀무가설의 검정 결과입니다. 기울기가 0이면 x가 변해도 y가 변하지 않는다는 뜻, 즉 관계가 없다는 뜻이니까요. p-value 4.4e-107은 "관계가 없다면 이런 데이터는 사실상 나올 수 없다"는 뜻입니다.

기울기에도 [신뢰구간](#/l/st-04-2)을 만들 수 있습니다. 기울기 ± t 배수 × 기울기의 표준오차입니다. 자유도는 n − 2를 씁니다(직선의 숫자 두 개 a, b를 데이터에서 추정했으므로).

```run
import pandas as pd
from scipy import stats

df = pd.read_csv("penguins.csv").dropna(subset=["flipper_length_mm", "body_mass_g"])
res = stats.linregress(df["flipper_length_mm"], df["body_mass_g"])
t_mult = stats.t.ppf(0.975, len(df) - 2)
print(f"기울기 95% CI: {res.slope - t_mult * res.stderr:.1f} ~ {res.slope + t_mult * res.stderr:.1f} g/mm")
```

기울기의 95% 신뢰구간은 46.7 ~ 52.7g/mm입니다. "지느러미 1mm당 몸무게는 약 47~53g 차이 난다"고 범위로 보고할 수 있습니다. 구간에 0이 들어 있지 않으니 p-value와 같은 결론(관계 있음)입니다.

## 잔차 그래프: 패턴이 없어야 좋다

회귀 진단에서 가장 중요한 도구는 **잔차 그래프**입니다. 가로축에 x(또는 예측값), 세로축에 잔차를 찍습니다. 직선이 데이터의 모양을 잘 잡았다면, 남은 잔차는 **0 주위에 아무 패턴 없이** 고르게 흩어져야 합니다.

::figure{src="content/img/stats/st07-residual-patterns.svg" alt="잔차 그래프 세 칸. 첫째 칸: 점들이 0선 주위에 고르게 띠 모양으로 흩어짐(좋음). 둘째 칸: 점들이 U자 곡선을 그림(직선이 맞지 않음, 곡선 관계). 셋째 칸: 왼쪽은 좁고 오른쪽으로 갈수록 넓게 퍼지는 깔때기 모양(흩어짐이 일정하지 않음)" caption="좋은 잔차는 0 주위의 고른 띠입니다. U자 곡선이 보이면 직선이 맞지 않는 것이고, 깔때기 모양이면 x가 클수록 예측이 불안정한 것입니다."}

| 잔차 모양 | 뜻 | 대처 |
| --- | --- | --- |
| 0 주위 고른 띠 | 직선이 적절함 | 그대로 사용 |
| U자, 곡선 | 관계가 직선이 아님 | x², 로그 변환 등 곡선 모델 |
| 깔때기 (점점 넓어짐) | x가 클수록 흩어짐이 커짐 | 로그 변환, 예측 오차를 x에 따라 다르게 보고 |
| 혼자 멀리 떨어진 점 | 이상치 · 영향점 | 원인 확인([위치와 이상치: 사분위수 · 상자그림 · z점수](#/l/st-01-3)) |

펭귄 회귀의 잔차 그래프를 그려 봅니다.

```run
import matplotlib.pyplot as plt
import pandas as pd
from scipy import stats

df = pd.read_csv("penguins.csv").dropna(subset=["flipper_length_mm", "body_mass_g"])
res = stats.linregress(df["flipper_length_mm"], df["body_mass_g"])
resid = df["body_mass_g"] - (res.intercept + res.slope * df["flipper_length_mm"])
plt.scatter(df["flipper_length_mm"], resid, s=10); plt.axhline(0, color="gray"); plt.ylabel("residual (g)"); plt.show()
print("잔차 표준편차:", round(resid.std()), "g")
```

잔차가 0 주위에 대체로 고르게 흩어져 있습니다. 뚜렷한 곡선이나 깔때기는 보이지 않으니 직선 모델이 적절하다고 볼 수 있습니다. 잔차의 표준편차는 394g으로, "이 직선으로 예측하면 보통 ±400g 정도 빗나간다"는 뜻입니다.

## 깔때기 잔차: 계산 금액과 팁

이번엔 식당 데이터에서 계산 금액(x)으로 팁(y)을 예측하는 직선을 구하고, 잔차를 봅니다.

```run
import matplotlib.pyplot as plt
import pandas as pd
from scipy import stats

df = pd.read_csv("tips.csv")
res = stats.linregress(df["total_bill"], df["tip"])
resid = df["tip"] - (res.intercept + res.slope * df["total_bill"])
plt.scatter(df["total_bill"], resid, s=10); plt.axhline(0, color="gray"); plt.xlabel("total bill"); plt.show()
print(f"ŷ = {res.intercept:.2f} + {res.slope:.3f}x / R² = {res.rvalue ** 2:.3f}")
```

직선은 ŷ = 0.92 + 0.105x로, "계산 금액이 1달러 크면 팁이 평균 약 0.105달러(10.5%) 많다"는 상식적인 결과입니다. 그런데 잔차 그래프는 왼쪽(작은 금액)에서 좁고 오른쪽(큰 금액)으로 갈수록 넓게 퍼지는 **깔때기** 모양입니다. 숫자로 확인해 봅니다.

```run
import pandas as pd
from scipy import stats

df = pd.read_csv("tips.csv")
res = stats.linregress(df["total_bill"], df["tip"])
resid = df["tip"] - (res.intercept + res.slope * df["total_bill"])
print("15달러 미만 잔차 std:", round(resid[df["total_bill"] < 15].std(), 2), "/ 30달러 이상:", round(resid[df["total_bill"] >= 30].std(), 2))
```

15달러 미만 계산서의 잔차 표준편차는 0.68달러, 30달러 이상은 1.73달러로 2.5배입니다. 큰 계산서일수록 팁이 손님마다 들쭉날쭉하다는 뜻입니다. 직선의 기울기 자체는 쓸 만하지만, "예측 오차는 ±1달러"처럼 하나로 말하면 작은 계산서에는 너무 넓고 큰 계산서에는 너무 좁습니다. 이런 경우 팁 비율(팁 ÷ 금액)이나 로그를 써서 분석하기도 합니다.

## 외삽: 데이터 범위 밖은 위험하다

펭귄 데이터의 지느러미 길이는 172~231mm입니다. 이 범위 **밖**의 값을 직선에 넣으면 어떻게 될까요?

```run
import pandas as pd
from scipy import stats

df = pd.read_csv("penguins.csv").dropna(subset=["flipper_length_mm", "body_mass_g"])
res = stats.linregress(df["flipper_length_mm"], df["body_mass_g"])
print("데이터 범위:", df["flipper_length_mm"].min(), "~", df["flipper_length_mm"].max(), "mm")
for f in [150, 300]:
    print(f"지느러미 {f}mm → {res.intercept + res.slope * f:,.0f}g")
```

150mm 펭귄은 1,672g, 300mm 펭귄은 9,125g으로 예측됩니다. 300mm 지느러미를 가진 펭귄은 이 데이터에 한 마리도 없고, 그런 펭귄이 있다 해도 이 직선을 따를 거라는 근거가 전혀 없습니다. 데이터 범위 밖으로 직선을 연장해 예측하는 것을 **외삽**(extrapolation)이라고 하는데, 아주 조심해야 합니다. 관계가 범위 밖에서 휘거나 꺾일 수 있기 때문입니다. 아이의 키가 1년에 6cm씩 자란다고 해서 40살에 키가 3m가 되지는 않지요.

## 실무 예제: 잔차가 U자를 그릴 때

앞 레슨에서 rpm으로 토크를 예측한 직선은 2,800rpm에서 음수 토크를 내놓았습니다. 잔차를 rpm 구간별로 평균 내 보면 원인이 보입니다.

```run
import pandas as pd
from scipy import stats

df = pd.read_csv("ai4i2020.csv")
res = stats.linregress(df["rpm"], df["torque"])
resid = df["torque"] - (res.intercept + res.slope * df["rpm"])
print(resid.groupby(pd.cut(df["rpm"], [1100, 1300, 1400, 1500, 1700, 2000, 2900]), observed=True).mean().round(2))
```

느린 구간(1,100 ~ 1,300rpm)에서는 잔차 평균이 +6.4, 가운데 구간은 0 근처나 음수, 빠른 구간(2,000rpm 이상)에서는 다시 +10.5입니다. 양 끝은 직선보다 위, 가운데는 직선보다 아래인 **U자 모양**입니다. 직선이 휘어진 관계를 억지로 펴서 맞추고 있다는 뜻입니다.

물리적으로 출력 ≈ 토크 × 회전 속도가 일정하다면, 토크는 rpm에 반비례(토크 ∝ 1 ÷ rpm)합니다. x를 `1 / rpm`으로 바꿔 다시 직선을 맞춰 봅니다.

```run
import pandas as pd
from scipy import stats

df = pd.read_csv("ai4i2020.csv")
print("rpm 그대로 R²:", round(stats.linregress(df["rpm"], df["torque"]).rvalue ** 2, 3))
print("1 / rpm으로 R²:", round(stats.linregress(1 / df["rpm"], df["torque"]).rvalue ** 2, 3))
```

R²가 0.766에서 0.837로 올랐습니다. 변수를 도메인 지식에 맞게 바꿨더니 같은 "직선 회귀"로도 훨씬 잘 맞습니다. 이렇게 바꾼 모델은 rpm이 아무리 커져도 토크가 0에 가까워질 뿐 음수가 되지 않습니다. 잔차 그래프 → 패턴 발견 → 원인 추측 → 변수 변환이 회귀 진단의 기본 흐름입니다.

## 자주 하는 실수

1. **R²만 보고 모델을 고른다.** R² 0.77은 꽤 높아 보이지만, 잔차에 뚜렷한 U자가 있었습니다. 잔차 그래프 없이 R²만 보면 이런 문제를 놓칩니다.
2. **R²가 낮으면 쓸모없는 모델이라고 생각한다.** 사람의 행동처럼 원래 흩어짐이 큰 데이터는 R² 0.2도 의미 있을 수 있습니다. 기울기의 신뢰구간이 쓸모 있는 정보인지가 더 중요합니다.
3. **이상치 하나 때문에 생긴 기울기를 믿는다.** 잔차가 유난히 큰 점이 있으면 그 점을 빼고 다시 맞춰 보세요. 기울기가 크게 바뀌면 결론이 그 점 하나에 달려 있는 것입니다.

## 회귀 결과 읽는 순서

회귀 결과를 받으면 이 순서로 확인하세요.

1. **산점도와 잔차 그래프**: 직선 모양이 맞나? 곡선 · 깔때기 · 이상치는 없나?
2. **기울기와 단위**: x가 1 단위 클 때 y가 평균 얼마나 다른가? 방향이 상식과 맞나?
3. **기울기의 p-value · 신뢰구간**: 관계가 우연이 아닌가? 기울기는 어느 범위쯤인가?
4. **R²와 잔차 표준편차**: 얼마나 설명하나? 예측하면 보통 얼마나 빗나가나?
5. **범위와 인과**: 데이터 범위 안에서만 쓰고, 관찰 데이터라면 인과로 말하지 않는다.

## 다음 단계: 여러 변수로 예측하기

몸무게의 나머지 24%를 설명하려면 종, 성별, 부리 길이 같은 변수를 **함께** 넣어야 합니다. x가 여러 개인 회귀를 **다중회귀**라고 하고, 머신러닝 트랙의 [회귀: 선형 모델](#/l/ml-02-1)에서 scikit-learn의 `LinearRegression`으로 배웁니다. 다중회귀의 계수는 "다른 변수를 고정했을 때"의 효과라서, 단순회귀 기울기와 값이 달라질 수 있습니다.

## 정리

- **R²** = 1 − 남은 흩어짐 ÷ 전체 흩어짐 = y의 흩어짐 중 직선이 설명한 비율. 단순회귀에서는 r².
- 기울기 p-value는 "기울기 = 0" 검정. 기울기 95% CI = 기울기 ± t(n − 2) × `stderr`.
- **잔차 그래프**에 패턴(곡선 · 깔때기 · 이상치)이 없어야 직선이 적절하다.
- 데이터 범위 밖 예측(**외삽**)은 위험하다.
