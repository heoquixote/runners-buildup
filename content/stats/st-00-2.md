## 국 한 숟가락으로 냄비 전체 맛 보기

국을 끓일 때 간을 보려고 냄비를 다 마시는 사람은 없습니다. 잘 저은 뒤 **한 숟가락**만 떠서 맛을 보고 "전체가 이 정도 간이겠구나" 하고 판단하지요.

통계도 똑같습니다. 알고 싶은 것은 냄비 전체(**모집단**)인데, 실제로 맛보는 것은 한 숟가락(**표본**)입니다. 이번 레슨에서는 이런 데이터의 기본 재료 이름을 하나씩 정리합니다. 이름이 헷갈리면 나중에 어떤 계산을 써야 할지도 헷갈리기 때문입니다.

## 모집단과 표본, 모수와 통계량

::figure{src="content/img/stats/st00-pop-sample.svg" alt="큰 원(모집단) 안에서 작은 원(표본)을 뽑고, 모집단의 값은 모수, 표본에서 계산한 값은 통계량이라고 부르는 도식" caption="모집단의 참값(모수)은 보통 모릅니다. 표본에서 계산한 통계량으로 모수를 짐작합니다."}

| 이름 | 뜻 | 예 |
| --- | --- | --- |
| **모집단** (population) | 우리가 궁금한 전체 | 전국 고등학생 전체, 오늘 만든 과자 전체 |
| **표본** (sample) | 실제로 데이터를 모은 일부 | 설문에 답한 학생 500명, 검사한 과자 30봉지 |
| **모수** (parameter) | 모집단의 진짜 값 (보통 모름) | 전국 고등학생의 진짜 평균 키 |
| **통계량** (statistic) | 표본에서 계산한 값 | 500명의 평균 키 168.2cm |

표본에서 계산한 평균은 모집단의 평균과 **비슷하길 바라는 값**이지, 똑같은 값이 아닙니다. 국 한 숟가락이 냄비 전체와 정확히 같은 맛이라는 보장은 없는 것처럼요.

## 표 한 장을 통계 눈으로 읽기

이번 레슨의 데이터는 1912년 타이타닉호 승객 기록(`titanic.csv`)입니다. 실제 탑승자는 약 2,200명이었지만, 이 파일에는 그중 891명의 기록만 있습니다. 즉 이 파일은 **표본**이고, 전체 탑승자가 **모집단**입니다.

```run
import pandas as pd

df = pd.read_csv("titanic.csv")
print(df[["survived", "pclass", "sex", "age", "fare", "embarked"]].head())
```

표에서 **가로 한 줄(행)은 승객 한 명**입니다. 이런 관측 대상 하나의 기록을 **관측치**(observation)라고 부릅니다. **세로 한 줄(열)은 승객마다 잰 속성**이고, 이것을 **변수**(variable)라고 부릅니다. 생존 여부(`survived`), 객실 등급(`pclass`), 성별(`sex`), 나이(`age`), 요금(`fare`), 탑승 항구(`embarked`)가 변수입니다.

```run
import pandas as pd

df = pd.read_csv("titanic.csv")
print("행(관측치) 수:", df.shape[0], "/ 열(변수) 수:", df.shape[1])
```

관측치 891개, 변수 15개입니다. 통계 책에서 "n = 891"이라고 쓰면 관측치가 891개라는 뜻입니다.

## 변수의 두 가지 종류

변수는 크게 두 종류로 나눕니다.

- **범주형 변수**: 값이 "이름표"인 변수. 성별(male/female), 탑승 항구(S/C/Q), 혈액형
- **수치형 변수**: 값이 세거나 잴 수 있는 숫자인 변수. 나이, 요금, 형제 수

pandas는 열마다 자료형(dtype)을 붙여 줍니다. 글자면 `object`, 숫자면 `int64`나 `float64`입니다.

```run
import pandas as pd

df = pd.read_csv("titanic.csv")
print(df[["survived", "pclass", "sex", "age", "fare", "embarked"]].dtypes)
```

`sex`와 `embarked`는 `object`라서 범주형이라는 것이 바로 보입니다. 그런데 `survived`(0·1)와 `pclass`(1·2·3)는 숫자 자료형(`int64`)인데도 사실은 범주형입니다. `survived`의 1은 "살았다"는 이름표이고, `pclass`의 3은 "3등석"이라는 이름표일 뿐이니까요. **숫자로 적혀 있다고 해서 숫자로 계산해도 되는 것은 아닙니다.**

## 척도: 그 숫자로 무엇을 계산해도 될까

변수를 어떻게 쟀느냐에 따라 할 수 있는 계산이 달라집니다. 이 측정 방식을 **척도**(scale)라고 하고, 네 가지로 나눕니다.

::figure{src="content/img/stats/st00-scales.svg" alt="명목, 서열, 등간, 비율 척도의 사다리. 위로 갈수록 같다·다르다, 크다·작다, 차이, 몇 배 계산이 하나씩 가능해진다" caption="척도 사다리: 위 칸으로 갈수록 할 수 있는 계산이 하나씩 늘어납니다."}

| 척도 | 뜻 | 예 | 할 수 있는 계산 | 알맞은 요약 |
| --- | --- | --- | --- | --- |
| **명목** | 구분만 | 성별, 항구, 혈액형 | 같다 · 다르다 | 개수, 비율, 최빈값 |
| **서열** | 순서가 있음, 간격은 제각각 | 객실 등급, 만족도 1~5점, 메달 색 | + 크다 · 작다 | + 중앙값 |
| **등간** | 간격이 같음, 0이 "없음"은 아님 | 섭씨온도, 연도 | + 더하기 · 빼기(차이) | + 평균 |
| **비율** | 0이 "없음", 몇 배 비교 가능 | 나이, 요금, 키, 몸무게 | + 곱하기 · 나누기(몇 배) | + 평균, 표준편차, 비율 |

## 척도를 무시하면 생기는 일

`pclass`(객실 등급)의 평균을 내 봅시다. 숫자니까 계산은 됩니다.

```run
import pandas as pd

df = pd.read_csv("titanic.csv")
print("pclass 평균:", round(df["pclass"].mean(), 2))
```

평균 등급이 2.31등석이라는 숫자가 나왔습니다. 하지만 "2.31등석"이라는 자리는 없습니다. 게다가 1등석과 2등석의 차이가 2등석과 3등석의 차이와 같다는 보장도 없습니다(요금도, 시설도 전혀 다릅니다). 서열척도에는 평균보다 **개수와 비율**이 훨씬 정확한 요약입니다.

```run
import pandas as pd

df = pd.read_csv("titanic.csv")
print(df["pclass"].value_counts(normalize=True).sort_index().round(3))
```

1등석 24.2%, 2등석 20.7%, 3등석 55.1%. "승객의 절반 이상이 3등석이었다"는 문장이 2.31이라는 숫자보다 훨씬 많은 것을 알려 줍니다.

반대로 `age`(나이)는 비율척도입니다. 0살이 "나이가 없음"을 뜻하고, 40살은 20살의 두 배라고 말할 수 있습니다. 그래서 평균과 표준편차를 쓰기에 알맞습니다.

```run
import pandas as pd

df = pd.read_csv("titanic.csv")
print("나이 평균:", round(df["age"].mean(), 1), "/ 표준편차:", round(df["age"].std(), 1))
```

등간척도는 조금 헷갈립니다. 섭씨 20도는 10도보다 10도 높지만, "두 배 더 덥다"고 말하면 틀립니다. 0도가 "온도가 없음"이 아니기 때문입니다. 그래서 등간척도는 차이와 평균까지는 괜찮지만 "몇 배"는 말하지 않습니다.

> 만족도 1~5점처럼 서열척도인데 평균을 자주 내는 경우도 있습니다. 평균을 내는 것 자체가 늘 틀린 것은 아니지만, 4.1점과 4.3점의 차이를 대단한 차이처럼 말하면 과장이 됩니다. 중앙값이나 "4점 이상 비율"을 함께 보여 주면 더 안전합니다.

## 분석 전에 데이터 사전부터

실제 분석을 시작하기 전에 변수마다 아래처럼 한 줄씩 정리해 두는 것을 **데이터 사전**(data dictionary)이라고 합니다. 귀찮아 보이지만 "이 열에 평균을 내도 되나?" 같은 실수를 미리 막아 주는 안전장치입니다.

| 변수 | 뜻 | 종류 | 척도 | 쓸 요약 |
| --- | --- | --- | --- | --- |
| `survived` | 생존 여부 (1 = 생존) | 범주 | 명목 | 비율 (생존율) |
| `pclass` | 객실 등급 | 범주 | 서열 | 개수, 비율 |
| `sex` | 성별 | 범주 | 명목 | 개수, 비율 |
| `age` | 나이 (빈 값 있음) | 수치 | 비율 | 평균, 중앙값, 표준편차 |
| `fare` | 요금 | 수치 | 비율 | 중앙값 (치우침 큼, [DAY 02](#/l/st-01-1)) |

## 정리

- **모집단**은 궁금한 전체, **표본**은 실제로 본 일부. 모집단의 참값(**모수**)은 보통 모르고, 표본에서 계산한 **통계량**으로 짐작한다.
- 표의 행은 **관측치**, 열은 **변수**. 변수는 범주형과 수치형으로 나뉜다.
- **척도**(명목 · 서열 · 등간 · 비율)에 따라 할 수 있는 계산과 알맞은 요약이 다르다. 숫자로 적혀 있어도 범주일 수 있다.
- 좋은 통계 분석은 멋진 기법보다 먼저, **누가 들어왔고 무엇을 어떻게 쟀는가**를 분명히 하는 데서 시작합니다.
