## 검정에는 전제 조건이 있다

[st-05-3](#/l/st-05-3)의 t검정과 [지난 레슨](#/l/st-06-2)의 ANOVA는 **평균**을 비교합니다. 평균 비교가 정확하려면 몇 가지 전제(가정)가 대략 맞아야 합니다.

| 가정 | 뜻 | 깨지면 |
| --- | --- | --- |
| 독립 | 값끼리 서로 영향을 주지 않는다 | 어떤 검정도 믿기 어렵다. 데이터 모으는 방법부터 다시 |
| 정규성 | 그룹마다 값이 정규분포에 가깝다 | 표본이 작을 때 p-value가 틀어진다 |
| 등분산 | 그룹마다 흩어짐이 비슷하다 | Welch t검정(`equal_var=False`)으로 피한다 |

이 레슨에서는 정규성과 등분산을 **확인하는 법**, 그리고 정규성이 깨졌을 때 쓰는 **비모수 검정**을 배웁니다. 비모수 검정은 값 대신 **순위**로 비교해서 분포 모양에 대한 가정이 거의 필요 없는 검정입니다.

## 정규성 확인: 그림 먼저, 숫자는 그다음

정규성은 먼저 히스토그램으로 봅니다([st-01-4](#/l/st-01-4)). 숫자로 확인할 때는 **샤피로-윌크 검정**(`stats.shapiro`)을 씁니다. 귀무가설은 "정규분포에서 나온 데이터다"입니다. p-value가 작으면 정규분포가 아니라고 봅니다.

```run
import pandas as pd
from scipy import stats

df = pd.read_csv("tips.csv")
dinner = df[df["time"] == "Dinner"]["tip"]
lunch = df[df["time"] == "Lunch"]["tip"]
print("저녁:", len(dinner), "건, 왜도", round(stats.skew(dinner), 2), ", 샤피로 p =", f"{stats.shapiro(dinner).pvalue:.1e}")
print("점심:", len(lunch), "건, 왜도", round(stats.skew(lunch), 2), ", 샤피로 p =", f"{stats.shapiro(lunch).pvalue:.1e}")
```

팁은 두 그룹 모두 왜도가 1.2 ~ 1.5로 오른쪽 꼬리가 길고, 샤피로 p-value도 아주 작습니다. 정규분포가 아닙니다.

정규에 가까운 데이터와 비교해 봅니다.

```run
import pandas as pd
from scipy import stats

df = pd.read_csv("penguins.csv").dropna()
g = df[df["species"] == "Gentoo"]["body_mass_g"]
print(len(g), "마리, 왜도", round(stats.skew(g), 2), ", 샤피로 p =", round(stats.shapiro(g).pvalue, 3))
```

Gentoo 펭귄 몸무게는 p = 0.261로 정규성을 거부하지 않습니다.

> 샤피로 검정은 표본이 수천 개면 아주 작은 어긋남에도 p-value가 작아지고, 표본이 10개 남짓이면 크게 어긋나도 잡지 못합니다. 그래서 **그림을 먼저 보고, 검정은 보조로** 씁니다. 표본이 그룹마다 30개를 넘으면 [중심극한정리](#/l/st-03-3) 덕분에 평균 비교는 정규성에 크게 흔들리지 않습니다.

## 등분산 확인: 레빈 검정

`stats.levene`은 "그룹들의 분산이 같다"를 귀무가설로 둡니다. p-value가 크면 분산이 다르다고 볼 근거가 없습니다.

```run
import pandas as pd
from scipy import stats

df = pd.read_csv("tips.csv")
dinner = df[df["time"] == "Dinner"]["tip"]
lunch = df[df["time"] == "Lunch"]["tip"]
print("표준편차:", round(dinner.std(), 3), round(lunch.std(), 3))
print("레빈 p =", round(stats.levene(dinner, lunch).pvalue, 3))
```

p = 0.349라 분산이 다르다고 볼 근거는 없습니다. 다만 실무에서는 등분산 검정 결과와 상관없이 **처음부터 Welch t검정**을 쓰는 경우가 많습니다. 분산이 같을 때도 손해가 거의 없기 때문입니다.

## 맨-휘트니 U 검정: 두 그룹을 순위로 비교

정규성이 깨졌고 표본이 작으면, 값 대신 **순위**로 비교합니다. 두 그룹을 합쳐 작은 값부터 1, 2, 3, ... 순위를 매긴 뒤, 한쪽 그룹에 높은 순위가 몰려 있는지 봅니다. 아주 큰 값도 그냥 "1등"이라서 이상치에 흔들리지 않습니다.

이상치 하나가 섞인 작은 표본으로 t검정과 비교해 봅니다. 두 설비에서 7개씩 잰 두께입니다.

```run
import numpy as np
from scipy import stats

A = np.array([12.1, 11.8, 12.4, 12.0, 11.9, 12.2, 25.0])   # 마지막 값은 측정 오류로 의심
B = np.array([12.6, 12.9, 12.7, 13.1, 12.8, 12.5, 13.0])
print("평균:", round(A.mean(), 2), round(B.mean(), 2), "/ 중앙값:", np.median(A), np.median(B))
print("Welch t검정 p =", round(stats.ttest_ind(A, B, equal_var=False).pvalue, 3))
print("맨-휘트니 p =", round(stats.mannwhitneyu(A, B).pvalue, 3))
```

A의 값 7개 중 6개가 B의 모든 값보다 작은데도, 25.0 하나 때문에 A의 평균(13.91)이 B(12.8)보다 커졌습니다. t검정은 p = 0.569로 차이를 놓쳤고, 순위로 비교한 맨-휘트니는 p = 0.026으로 차이를 잡았습니다. 이상치 하나가 평균과 표준편차를 모두 부풀렸기 때문입니다.

> 물론 첫 번째 할 일은 25.0이 정말 측정 오류인지 확인하는 것입니다([st-01-3](#/l/st-01-3)). 비모수 검정은 이상치를 지울 근거가 없을 때 쓰는 안전한 대안입니다.

## 윌콕슨 부호순위 검정: 대응 데이터

같은 대상을 두 번 잰 대응 데이터([st-05-3](#/l/st-05-3)의 대응 t검정)에도 순위판이 있습니다. 차이의 **크기 순위**에 부호(+/−)를 붙여 비교하는 **윌콕슨 부호순위 검정**(`stats.wilcoxon`)입니다. 설비 8대의 개선 전후 진동값입니다.

```run
import numpy as np
from scipy import stats

before = np.array([3.2, 2.8, 4.1, 3.6, 2.9, 3.4, 3.8, 3.0])
after = np.array([2.9, 2.7, 3.5, 3.4, 2.4, 3.0, 3.1, 2.2])
print("차이:", (after - before).round(1))
print("대응 t검정 p =", round(stats.ttest_rel(before, after).pvalue, 4))
print("윌콕슨 p =", round(stats.wilcoxon(before, after).pvalue, 4))
```

8대 모두 진동이 줄었습니다. 두 검정 모두 유의하지만, 윌콕슨 p(0.0078)가 대응 t검정보다 큽니다. 순위만 쓰면 "얼마나 줄었나"의 정보를 일부 버리기 때문입니다. **가정이 맞으면 모수 검정이 조금 더 민감하고, 가정이 깨지면 비모수 검정이 더 안전합니다.**

## 실무 예제: 큰 표본에서는

팁 데이터는 정규가 아니었지만 표본이 저녁 176건, 점심 68건으로 큽니다. 두 검정을 함께 돌려 봅니다.

```run
import pandas as pd
from scipy import stats

df = pd.read_csv("tips.csv")
dinner = df[df["time"] == "Dinner"]["tip"]
lunch = df[df["time"] == "Lunch"]["tip"]
print("Welch t검정 p =", round(stats.ttest_ind(dinner, lunch, equal_var=False).pvalue, 3))
print("맨-휘트니 p =", round(stats.mannwhitneyu(dinner, lunch).pvalue, 3))
```

p-value가 0.041과 0.029로 비슷하고, 결론(유의수준 5%에서 유의)도 같습니다. 표본이 크면 정규성이 깨져도 두 방법이 비슷한 답을 냅니다. 이럴 때는 두 결과를 함께 보고하면 "검정 방법을 바꿔도 결론이 같다"는 근거가 됩니다.

## 어떤 검정을 고를까

| 상황 | 모수 검정 (평균) | 비모수 검정 (순위) |
| --- | --- | --- |
| 두 독립 그룹 | Welch t검정 `ttest_ind(equal_var=False)` | 맨-휘트니 `mannwhitneyu` |
| 같은 대상 전후 | 대응 t검정 `ttest_rel` | 윌콕슨 부호순위 `wilcoxon` |
| 세 그룹 이상 | ANOVA `f_oneway` | 크루스칼-월리스 `kruskal` |

1. 데이터가 어떻게 모였는지(독립 · 대응) 먼저 정한다
2. 히스토그램으로 모양과 이상치를 본다
3. 그룹마다 30개 이상이고 심한 이상치가 없으면 모수 검정
4. 표본이 작고 치우쳤거나 이상치가 있으면 비모수 검정
5. 애매하면 둘 다 돌려 결론이 같은지 확인한다

## 자주 하는 실수

- 샤피로 p-value 하나로 기계적으로 검정을 고르기: 그림과 표본 크기를 함께 본다.
- 비모수 검정 결과를 "평균이 다르다"로 보고하기: 순위 비교라서 "한쪽 값이 전반적으로 더 크다(중앙값 · 분포 위치가 다르다)"로 쓴다.
- 이상치를 확인하지 않고 비모수 검정으로 덮어 두기: 측정 오류면 먼저 바로잡는다.

## 정리

- 평균 비교 검정은 독립 · 정규성 · 등분산을 전제로 한다. 정규성은 그림 먼저, `shapiro`는 보조로.
- 등분산이 의심되면 Welch t검정을 쓴다.
- 정규성이 깨졌고 표본이 작거나 이상치가 있으면 순위로 비교하는 비모수 검정(맨-휘트니, 윌콕슨, 크루스칼-월리스)을 쓴다.
- 표본이 크면 두 방법의 결론이 대개 같다. 함께 보고하면 결론이 더 단단해진다.
