## 공장에서 자주 받는 질문

공장 설비 관리자가 이런 질문을 받았다고 해 봅시다.

- "설비 100대를 돌리면 오늘 고장이 몇 대쯤 날까? 5대보다 많이 날 확률은?"
- "고객센터에 시간당 평균 4건 전화가 오는데, 한 시간에 7건 이상 올 확률은?"

이런 질문은 매번 시뮬레이션을 하지 않아도, 이미 잘 알려진 **확률분포**로 바로 답할 수 있습니다. 셀 수 있는 값(개수)에 가장 많이 쓰는 두 분포, **이항분포**와 **포아송분포**를 배웁니다.

## 베르누이 시행: 결과가 둘뿐인 실험

결과가 딱 두 가지(성공 / 실패)뿐인 실험을 **베르누이 시행**이라고 합니다. 여기서 "성공"은 좋은 일이라는 뜻이 아니라 **우리가 세고 싶은 쪽**이라는 뜻입니다.

- 동전 던지기: 앞면(성공) / 뒷면
- 설비 하나: 고장(성공) / 정상
- 승객 한 명: 생존(성공) / 사망

성공할 확률을 **p**라고 씁니다. 공장 설비 데이터(`ai4i2020.csv`)에는 설비 10,000대의 기록과 고장 여부(`failure`, 1 = 고장)가 있습니다. 여기서 p를 구해 봅니다.

```run
import pandas as pd

df = pd.read_csv("ai4i2020.csv")
print("설비 수:", len(df), "/ 고장 수:", df["failure"].sum())
print("고장률 p =", df["failure"].mean())
```

10,000대 중 339대가 고장 나서 고장률 p = 0.0339(3.39%)입니다. 이제 이 p를 가지고 "설비 100대 중 고장 수"를 생각해 봅니다.

## 이항분포: n번 중 성공 횟수

같은 베르누이 시행을 **n번** 반복할 때 **성공 횟수** X가 따르는 분포가 **이항분포**(binomial distribution)입니다. B(n, p)라고 씁니다. 동전을 100번 던져 앞면 수를 세는 것과 똑같은 구조로, 동전 대신 설비 100대를 "던진다"고 생각하면 됩니다.

::figure{src="content/img/stats/st02-binomial.svg" alt="이항분포의 네 가지 조건(횟수 n이 정해짐, 결과는 성공·실패 둘, 매번 성공 확률 p가 같음, 각 시행이 서로 독립) 체크리스트와 B(100, 0.0339)의 막대 모양. 3대에서 가장 높고 오른쪽으로 갈수록 낮아짐" caption="이항분포를 쓰려면 네 조건이 맞아야 합니다. 설비 100대, 고장률 3.39%라면 고장 수는 3대 근처가 가장 흔합니다."}

이항분포를 쓰려면 네 가지 조건이 맞아야 합니다.

1. 시행 횟수 **n이 미리 정해져** 있다 (설비 100대)
2. 각 시행의 결과는 **성공 / 실패 둘**이다 (고장 / 정상)
3. 성공 확률 **p가 매번 같다** (모든 설비의 고장률이 3.39%)
4. 각 시행은 서로 **독립**이다 (한 대가 고장 나도 다른 설비에 영향 없음)

`scipy.stats`에서는 `stats.binom(n, p)`로 이항분포를 만들고, [지난 레슨](#/l/st-02-1)에서 본 pmf · cdf · sf 메서드를 씁니다. 먼저 "100대 중 **딱 3대** 고장"의 확률입니다.

```run
from scipy import stats

X = stats.binom(n=100, p=0.0339)
print("P(X = 3) =", round(X.pmf(3), 4))
```

딱 3대가 고장 날 확률은 0.2221, 약 22%입니다. 다음은 "**3대 이하**" 고장의 확률입니다.

```run
from scipy import stats

X = stats.binom(n=100, p=0.0339)
print("P(X <= 3) =", round(X.cdf(3), 4))
```

3대 이하로 고장 날 확률은 0.5591로, 절반을 조금 넘습니다. 관리자가 정말 걱정하는 질문, "**5대보다 많이**(6대 이상) 고장 날 확률"은 sf로 구합니다.

```run
from scipy import stats

X = stats.binom(n=100, p=0.0339)
print("P(X > 5) =", round(X.sf(5), 4))
print("1 - cdf(5) =", round(1 - X.cdf(5), 4))
```

약 12.5%입니다. 열흘에 한 번은 설비 6대 이상이 고장 난다는 뜻이니, 예비 부품을 그만큼 준비해야 합니다. sf(5)와 1 − cdf(5)는 같은 값입니다.

## "이상"과 "초과"를 헷갈리지 않기

개수를 세는 이산형 분포에서는 경계값을 포함하는지가 답을 바꿉니다. 질문을 cdf나 sf로 옮길 때 이 표를 참고하세요.

| 질문 | 기호 | scipy |
| --- | --- | --- |
| 딱 3대 | P(X = 3) | `pmf(3)` |
| 3대 이하 | P(X ≤ 3) | `cdf(3)` |
| 3대 미만 (2대 이하) | P(X < 3) | `cdf(2)` |
| 5대 초과 (6대 이상) | P(X > 5) | `sf(5)` |
| 5대 이상 | P(X ≥ 5) | `sf(4)` |

"5대 이상"을 `sf(5)`로 쓰면 5대인 경우가 빠집니다. 한 칸 앞의 값을 넣는 습관을 들이세요.

## 이항분포의 모양

0대부터 10대까지 각 고장 수의 확률을 막대그래프로 그려 봅니다.

```run
import matplotlib.pyplot as plt
import numpy as np
from scipy import stats

k = np.arange(0, 11)
plt.bar(k, stats.binom(100, 0.0339).pmf(k)); plt.xlabel("failures out of 100"); plt.show()
print("가장 흔한 고장 수:", k[np.argmax(stats.binom(100, 0.0339).pmf(k))], "대")
```

3대에서 가장 높고 0대 쪽은 짧게, 큰 쪽은 길게 늘어진 모양입니다. 고장률이 작아서 0 근처에 몰렸고, 음수는 될 수 없으니 오른쪽으로만 꼬리가 생겼습니다.

이항분포의 평균(기댓값)과 분산에는 간단한 공식이 있습니다.

> 평균 = n × p,  분산 = n × p × (1 − p)

```run
from scipy import stats

X = stats.binom(n=100, p=0.0339)
print("평균:", round(X.mean(), 2), "= 100 × 0.0339")
print("표준편차:", round(X.std(), 2))
```

평균 3.39대, 표준편차 1.81대입니다. "하루 평균 3.4대쯤 고장 나고, 보통 ±1.8대 정도 오르내린다"고 말할 수 있습니다.

직접 해 보세요: 위 셀들의 `p=0.0339`를 `p=0.1`로 바꿔 보세요. 평균이 10대로 늘어나고, 막대 모양이 좌우 대칭인 종 모양에 가까워집니다. n × p가 커지면 이항분포는 정규분포를 닮아 갑니다([정규분포와 표준화](#/l/st-02-3)).

## 포아송분포: 일정 시간 동안 일어나는 횟수

이번엔 "고객센터에 **한 시간 동안** 오는 전화 수"를 생각해 봅시다. 이항분포와 비슷해 보이지만, "몇 번 시도했나(n)"가 정해져 있지 않습니다. 그 시간 동안 전화할 수 있는 사람은 사실상 셀 수 없이 많고, 각자 전화할 확률은 아주 작습니다. 우리가 아는 것은 "**평균적으로 시간당 4건**"뿐입니다.

이처럼 **일정한 시간·공간 안에서 드문 일이 일어나는 횟수**는 **포아송분포**(Poisson distribution)를 따릅니다. 필요한 숫자는 평균 횟수 **λ**(람다) 하나뿐입니다.

- 한 시간 동안 고객 문의 수
- 하루 동안 교차로 사고 수
- 원단 1m²에 생긴 흠집 수
- 한 페이지의 오타 수

```run
from scipy import stats

calls = stats.poisson(mu=4)          # 시간당 평균 4건
print("딱 4건:", round(calls.pmf(4), 4))
print("2건 이하:", round(calls.cdf(2), 4))
```

평균이 4건이어도 딱 4건이 올 확률은 19.5%에 불과하고, 2건 이하로 한가할 확률도 23.8%나 됩니다. 이번엔 상담원을 더 배치해야 할지 판단해 봅시다. "7건 **이상**"은 "6건 초과"이니 `sf(6)`입니다.

```run
from scipy import stats

calls = stats.poisson(mu=4)
print("7건 이상:", round(calls.sf(6), 4))
```

약 11.1%입니다. 하루 10시간 운영하면 하루에 한 시간쯤은 7건 이상 몰린다는 뜻입니다. 포아송분포는 평균과 분산이 **둘 다 λ**로 같다는 특징이 있습니다.

## 이항분포 ≈ 포아송분포

설비 100대(n이 큼)에 고장률 3.39%(p가 작음)는 "드문 일이 여러 번 기회를 갖는" 상황이라, 포아송분포로도 거의 똑같이 계산됩니다. 이때 λ = n × p = 3.39입니다.

```run
import numpy as np
from scipy import stats

k = np.arange(0, 7)
print("이항  :", stats.binom(100, 0.0339).pmf(k).round(3))
print("포아송:", stats.poisson(3.39).pmf(k).round(3))
```

두 분포의 확률이 소수 둘째 자리까지 거의 같습니다. 그래서 n이 크고 p가 작을 때는 n을 몰라도 평균 횟수만 알면 포아송분포로 계산할 수 있습니다.

## 어떤 분포를 고를까

| 상황 | 분포 | 필요한 값 | scipy |
| --- | --- | --- | --- |
| 정해진 n번 중 성공 횟수 | 이항 | n, p | `stats.binom(n, p)` |
| 일정 시간 · 공간에서 드문 일의 횟수 | 포아송 | 평균 횟수 λ | `stats.poisson(mu)` |
| 한 번 시행의 성공 / 실패 | 베르누이 (이항의 n = 1) | p | `stats.bernoulli(p)` |
| 키 · 무게처럼 재는 값 | 정규 등 연속형 | 평균, 표준편차 | `stats.norm(loc, scale)` (다음 레슨) |

## 실무 예제: "이번 묶음은 이상하다"의 기준 정하기

공장에서는 "100대 중 고장이 몇 대 이상이면 공정 이상으로 보고 라인을 점검한다" 같은 기준이 필요합니다. 고장률이 3.39%로 일정하고 설비끼리 독립이라면, 100대 중 고장 수는 B(100, 0.0339)를 따릅니다. 이 분포로 "평소라면 거의 나오지 않는" 고장 수를 찾습니다.

```run
from scipy import stats

d = stats.binom(100, 0.0339)
for k in [6, 7, 8, 9, 10]:
    print(f"{k}대 이상: {d.sf(k - 1):.4f}")
```

평소 상태에서 8대 이상이 나올 확률은 2.1%, 9대 이상은 0.7%입니다. "평소에는 1% 미만으로 일어나는 일이 일어나면 점검한다"로 정하면 기준은 **9대 이상**입니다. `d.ppf(0.99)`로도 같은 경계(8대 이하가 99%)를 구할 수 있습니다.

이제 실제 데이터에 이 기준을 대 봅니다. 기록된 순서대로 100대씩 묶은 100개 묶음에서 9대 이상 고장 난 묶음이 몇 개인지 셉니다.

```run
import pandas as pd

fail = pd.read_csv("ai4i2020.csv")["failure"].to_numpy()
per_batch = fail.reshape(100, 100).sum(axis=1)
print("9대 이상 묶음:", (per_batch >= 9).sum(), "개 / 이항분포 기대:", round(100 * 0.007, 1), "개")
```

이항분포대로라면 100묶음 중 0.7개쯤이어야 하는데, 실제로는 **8개**입니다. 고장 수의 분산도 이항분포의 3.3보다 훨씬 큰 14.5입니다. 고장이 일부 묶음에 **몰려서** 일어났다는 뜻입니다. 같은 시기에 만든 설비가 같은 문제를 함께 겪었다면 "각 시행이 독립"이라는 이항분포의 조건이 깨집니다. 이 경우 9대 이상 묶음은 단순한 우연이 아니라 **원인을 찾아야 할 신호**입니다.

## 자주 하는 실수

1. **조건을 확인하지 않고 이항분포를 쓴다.** 시행끼리 독립이 아니거나(같은 원인으로 함께 고장), p가 시기마다 다르면 이항분포가 실제보다 훨씬 좁은 범위를 예측합니다.
2. **"이상"과 "초과"를 헷갈린다.** `sf(k)`는 k **초과**입니다. "k 이상"은 `sf(k - 1)`입니다.
3. **포아송을 "드물다"는 이유만으로 쓴다.** 포아송은 평균 = 분산이 핵심 성질입니다. 데이터의 분산이 평균보다 훨씬 크면(과산포) 포아송도 맞지 않습니다.

## 정리

- **베르누이 시행**: 결과가 성공 / 실패 둘. 성공 확률 p.
- **이항분포** B(n, p): 정해진 n번 중 성공 횟수. 평균 np. 조건(n 고정, 결과 둘, p 일정, 독립)을 확인하자.
- **포아송분포**: 일정 시간 · 공간에서 드문 일의 횟수. 평균 λ 하나로 정해지고, 평균 = 분산 = λ.
- 질문을 메서드로 옮길 때 "이하 = cdf(k)", "초과 = sf(k)", "이상 = sf(k − 1)".
