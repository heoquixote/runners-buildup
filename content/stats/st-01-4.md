## 숫자 요약만으로는 모양이 안 보인다

평균, 중앙값, 표준편차를 구하면 데이터를 꽤 알게 된 것 같습니다. 하지만 **값들이 어떤 모양으로 퍼져 있는지**는 숫자 몇 개로 다 보이지 않습니다. 가운데 몰려 있는지, 한쪽으로 길게 늘어졌는지, 봉우리가 둘인지에 따라 어떤 대표값을 쓸지, 어떤 검정을 쓸지가 달라집니다.

값이 어디에 얼마나 몰려 있는지를 **분포**(distribution)라고 합니다. 분포를 보는 가장 좋은 도구는 히스토그램이고([히스토그램 읽기](#/l/da-14-1)에서 그리는 법을 배웠습니다), 이번 레슨은 그 모양을 **읽고 숫자로 말하는 법**을 배웁니다.

## 분포의 세 가지 기본 모양

::figure{src="content/img/stats/st01-shapes.svg" alt="세 가지 분포 모양: 왼쪽 꼬리가 긴 분포는 평균이 중앙값보다 왼쪽, 좌우 대칭 분포는 평균과 중앙값이 같은 자리, 오른쪽 꼬리가 긴 분포는 평균이 중앙값보다 오른쪽" caption="꼬리가 긴 쪽으로 평균이 끌려갑니다. 평균과 중앙값의 위치만 비교해도 모양을 짐작할 수 있습니다."}

| 모양 | 생김새 | 평균 vs 중앙값 | 예 |
| --- | --- | --- | --- |
| **좌우 대칭** | 가운데 봉우리, 양쪽이 비슷 | 평균 ≈ 중앙값 | 키, 몸무게, 측정 오차 |
| **오른쪽 꼬리** (양의 왜도) | 작은 값에 몰리고 큰 값 쪽으로 길게 늘어짐 | 평균 > 중앙값 | 소득, 요금, 대기 시간, 조회수 |
| **왼쪽 꼬리** (음의 왜도) | 큰 값에 몰리고 작은 값 쪽으로 늘어짐 | 평균 < 중앙값 | 쉬운 시험 점수, 제품 수명 |

꼬리 방향은 "봉우리가 있는 쪽"이 아니라 **길게 늘어진 쪽**으로 부릅니다. 헷갈리면 "평균이 끌려간 쪽이 꼬리"라고 기억하세요.

## 대칭에 가까운 분포: 펭귄 몸무게

펭귄 몸무게의 히스토그램을 그리고 평균과 중앙값을 함께 봅니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

mass = pd.read_csv("penguins.csv")["body_mass_g"].dropna()
plt.hist(mass, bins=20)
plt.xlabel("body mass (g)")
plt.show()
print("평균:", round(mass.mean()), "/ 중앙값:", mass.median())
```

평균 4,202g, 중앙값 4,050g으로 평균이 약간 더 큽니다. 그래프도 가운데보다 왼쪽에 조금 더 몰려 있고 오른쪽 꼬리가 살짝 깁니다. 그래도 크게 치우치지는 않은, 대칭에 가까운 편입니다.

## 오른쪽 꼬리가 긴 분포: 타이타닉 요금

```run
import matplotlib.pyplot as plt
import pandas as pd

fare = pd.read_csv("titanic.csv")["fare"]
plt.hist(fare, bins=40)
plt.xlabel("fare")
plt.show()
print("평균:", round(fare.mean(), 2), "/ 중앙값:", fare.median())
```

대부분의 승객이 0~50 사이에 몰려 있고, 몇몇 값이 500 근처까지 길게 늘어져 있습니다. 전형적인 오른쪽 꼬리 분포입니다. 평균(32.20)이 중앙값(14.45)의 두 배가 넘는 것도 같은 이유입니다.

## 왜도: 치우친 정도를 숫자로

그래프를 보지 않고도 치우침을 숫자로 말하고 싶을 때 **왜도**(skewness)를 씁니다.

- 왜도 ≈ 0: 좌우 대칭
- 왜도 > 0: 오른쪽 꼬리 (클수록 더 길다)
- 왜도 < 0: 왼쪽 꼬리

왜도는 z점수를 세제곱해서 평균 낸 값이라고 생각하면 됩니다. 세제곱은 부호가 남기 때문에, 오른쪽에 멀리 떨어진 값이 많으면 + 쪽이 커집니다. 대략 |왜도| < 0.5면 거의 대칭, 1을 넘으면 꽤 치우쳤다고 봅니다.

```run
import pandas as pd

mass = pd.read_csv("penguins.csv")["body_mass_g"].dropna()
fare = pd.read_csv("titanic.csv")["fare"]
print("펭귄 몸무게 왜도:", round(mass.skew(), 2))
print("타이타닉 요금 왜도:", round(fare.skew(), 2))
```

펭귄 몸무게는 0.47로 거의 대칭, 타이타닉 요금은 4.79로 아주 심하게 오른쪽으로 치우쳐 있습니다. 그래프에서 본 느낌이 숫자로 확인됩니다.

## 첨도: 꼬리가 얼마나 두꺼운가

**첨도**(kurtosis)는 꼬리가 얼마나 두꺼운지, 즉 **극단적인 값이 얼마나 자주 나오는지**를 나타냅니다. pandas의 `kurt()`는 종 모양(정규분포)을 0으로 맞춘 값을 줍니다.

- 첨도 ≈ 0: 정규분포와 비슷한 꼬리
- 첨도 > 0: 꼬리가 두꺼움, 극단값이 자주 나옴
- 첨도 < 0: 꼬리가 얇음, 값들이 고르게 퍼짐

```run
import pandas as pd

mass = pd.read_csv("penguins.csv")["body_mass_g"].dropna()
fare = pd.read_csv("titanic.csv")["fare"]
print("펭귄 몸무게 첨도:", round(mass.kurt(), 2))
print("타이타닉 요금 첨도:", round(fare.kurt(), 2))
```

펭귄 몸무게는 −0.72로 정규분포보다 꼬리가 얇고(값들이 넓게 고루 퍼짐), 요금은 33.40으로 꼬리가 엄청나게 두껍습니다. 첨도가 크면 "가끔 터무니없이 큰 값이 나온다"는 경고로 받아들이면 됩니다. 이런 데이터에서는 평균과 표준편차가 극단값 몇 개에 크게 흔들립니다.

> 왜도와 첨도는 계산 방법이 여러 가지라서 프로그램마다 값이 조금씩 다릅니다. 정확한 숫자보다는 부호와 대략적인 크기를 보세요.

## 봉우리가 두 개라면: 섞인 무리를 의심

봉우리가 두 개인 분포(**쌍봉 분포**)는 "성격이 다른 두 무리가 섞여 있다"는 강한 신호입니다. 펭귄의 지느러미 길이를 봅시다.

```run
import matplotlib.pyplot as plt
import pandas as pd

flipper = pd.read_csv("penguins.csv")["flipper_length_mm"].dropna()
plt.hist(flipper, bins=25)
plt.xlabel("flipper length (mm)")
plt.show()
print("평균:", round(flipper.mean(), 1), "/ 중앙값:", flipper.median())
```

190mm 근처와 215mm 근처에 봉우리가 두 개 있습니다. 평균(200.9mm)은 두 봉우리 사이, 오히려 펭귄이 별로 없는 골짜기에 놓입니다. **봉우리가 둘이면 평균 하나로는 아무것도 대표하지 못합니다.** 종별로 나눠 보면 이유가 보입니다.

```run
import pandas as pd

df = pd.read_csv("penguins.csv").dropna()
print(df.groupby("species")["flipper_length_mm"].median())
```

Adelie(190mm)와 Chinstrap(196mm)이 왼쪽 봉우리를, Gentoo(216mm)가 오른쪽 봉우리를 만들고 있었습니다. 쌍봉 분포를 보면 "어떤 범주로 나누면 봉우리가 갈라질까?"를 먼저 찾아보세요.

## 로그 변환: 긴 꼬리 접기

요금·소득·인구처럼 **곱하기로 커지는 값**은 오른쪽 꼬리가 길어지기 쉽습니다. 이런 값에 **로그**(log)를 씌우면 큰 값은 많이 줄고 작은 값은 조금 줄어서 꼬리가 접힙니다. 로그는 "10을 몇 번 곱했나"처럼 자릿수를 세는 함수라서, 10 → 100 → 1000이 1 → 2 → 3처럼 같은 간격이 됩니다.

요금에는 0원이 있으므로(로그 0은 계산할 수 없음) `np.log1p`(1을 더한 뒤 로그)를 씁니다.

```run
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd

fare = pd.read_csv("titanic.csv")["fare"]
log_fare = np.log1p(fare)
plt.hist(log_fare, bins=40)
plt.xlabel("log(1 + fare)")
plt.show()
print("변환 전 왜도:", round(fare.skew(), 2), "/ 변환 후 왜도:", round(log_fare.skew(), 2))
```

왜도가 4.79에서 0.39로 줄었습니다. 긴 꼬리가 접혀서 훨씬 대칭에 가까워졌습니다. 로그 변환은 이후 회귀분석이나 머신러닝에서 치우친 값을 다룰 때 자주 쓰입니다. 대신 해석할 때는 "원래 값의 몇 배"로 다시 바꿔 말해야 한다는 점을 기억하세요.

직접 해 보세요: 위 셀에서 `titanic.csv`의 `fare` 대신 `tips.csv`의 `total_bill`로 바꿔 보세요. 왜도가 얼마에서 얼마로 바뀌나요?

## 모양을 먼저 봐야 하는 이유

분포 모양은 뒤에 배울 거의 모든 방법과 이어집니다.

- **대표값 고르기**: 치우쳤으면 중앙값([대표값: 평균 · 중앙값 · 최빈값](#/l/st-01-1))
- **이상치 기준 고르기**: 치우쳤으면 IQR, 대칭이면 z점수([위치와 이상치: 사분위수 · 상자그림 · z점수](#/l/st-01-3))
- **확률 계산**: 종 모양이면 정규분포를 쓸 수 있음([정규분포와 표준화](#/l/st-02-3))
- **검정**: 표본이 작고 많이 치우쳤으면 t검정 결과가 흔들림([DAY 07](#/l/st-05-3))

그래서 분석의 첫 단계는 언제나 **그려 보는 것**입니다. 숫자 요약은 그림을 본 다음에 붙이세요.

## 실무 예제: 고장 설비와 정상 설비의 모양 비교

설비 데이터에서 고장 여부별로 토크와 회전 속도의 평균, 중앙값, 왜도를 구해 봅니다.

```run
import pandas as pd

df = pd.read_csv("ai4i2020.csv")
for col in ["torque", "rpm"]:
    print(col); print(df.groupby("failure")[col].agg(["mean", "median", "skew"]).round(2))
```

정상 설비의 토크는 왜도 −0.06으로 거의 좌우 대칭입니다. 그런데 고장 설비의 토크는 왜도 −1.20으로 **왼쪽 꼬리**가 길고, 평균(50.2)보다 중앙값(53.7)이 큽니다. 고장 설비 대부분은 토크가 높았지만, 토크가 낮은데도 고장 난 설비가 일부 섞여 있다는 뜻입니다. 회전 속도는 두 그룹 모두 오른쪽 꼬리가 긴데(왜도 1.58, 2.53), 고장 그룹의 꼬리가 더 깁니다.

이렇게 그룹마다 모양이 다르면 "고장 설비는 토크가 평균 10Nm 높다" 한 문장으로는 부족합니다. 고장에는 **토크가 높아서 생긴 고장과 다른 이유로 생긴 고장이 섞여 있을 수 있다**는 단서이기 때문입니다. 실제로 이 데이터의 고장은 과부하, 공구 마모, 열 방출 부족 등 여러 원인이 합쳐진 것입니다.

## 자주 하는 실수

1. **히스토그램 구간 수를 한 번만 보고 판단한다.** 구간을 너무 크게 잡으면 봉우리 두 개가 하나로 뭉개집니다. `bins`를 두세 가지로 바꿔 보세요.
2. **왜도 숫자만 보고 모양을 단정한다.** 왜도는 이상치 몇 개에도 크게 흔들립니다. 숫자와 그림을 함께 봅니다.
3. **로그 변환한 값의 평균을 원래 단위로 말한다.** log 요금의 평균을 되돌린 값(`np.exp`)은 원래 요금의 평균이 아니라 기하평균입니다. 보고할 때 구분해서 적습니다.

## 정리

- 분포의 기본 모양: **대칭**, **오른쪽 꼬리**(평균 > 중앙값), **왼쪽 꼬리**(평균 < 중앙값).
- **왜도**는 치우친 방향과 정도, **첨도**는 꼬리의 두께(극단값이 얼마나 자주 나오나).
- **봉우리가 둘**이면 서로 다른 무리가 섞였다는 신호. 범주로 나눠 보자.
- 곱으로 커지는 값의 긴 꼬리는 **로그 변환**으로 접을 수 있다.
