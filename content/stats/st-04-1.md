## 평균의 신뢰구간: t 분포

모표준편차를 모르고 표본 표준편차 s를 쓰므로 정규분포 대신 t 분포(자유도 n − 1)를 씁니다.

x̄ ± t(0.975, n−1) · s / √n

```run
import numpy as np
from scipy import stats

ml = np.array([498.2, 501.1, 499.6, 500.4, 497.9, 500.8, 499.1, 501.5])
n = len(ml)
se = ml.std(ddof=1) / np.sqrt(n)
t_crit = stats.t.ppf(0.975, df=n - 1)
print("t 임계값", round(t_crit, 3), "(정규분포라면 1.96)")
print("95% CI", round(ml.mean() - t_crit * se, 2), "~", round(ml.mean() + t_crit * se, 2))

# 한 줄로
print(stats.t.interval(0.95, df=n - 1, loc=ml.mean(), scale=stats.sem(ml)))
```

## 비율의 신뢰구간

불량률·전환율처럼 비율이면 정규근사를 씁니다 (np̂와 n(1−p̂)가 모두 10 이상일 때).

p̂ ± 1.96 · √(p̂(1 − p̂) / n)

```run
import numpy as np

n, bad = 400, 14
p = bad / n
m = 1.96 * np.sqrt(p * (1 - p) / n)
print(f"불량률 {p:.3f}, 95% CI {p - m:.3f} ~ {p + m:.3f}")
```

## 95%의 진짜 의미

같은 방법으로 표본을 100번 뽑아 구간을 100개 만들면 그중 약 95개가 참 평균을 포함합니다. 아래 시뮬레이션으로 확인해 보세요.

```run
import numpy as np
from scipy import stats

rng = np.random.default_rng(3)
true_mu, hit = 50, 0
for _ in range(1000):
    x = rng.normal(true_mu, 5, size=12)
    lo, hi = stats.t.interval(0.95, df=11, loc=x.mean(), scale=stats.sem(x))
    hit += lo <= true_mu <= hi
print("참값을 포함한 구간 비율", hit / 1000)
```
