## 점 하나 vs 범위

일기예보가 "내일 최고 기온은 정확히 20.0도입니다"라고 말하면 왠지 믿음이 가지 않습니다. 하루 뒤 날씨를 소수점까지 맞힐 수는 없으니까요. 대신 "내일 최고 기온은 **18~22도**"라고 하면 훨씬 정직하게 들립니다. 틀릴 가능성을 범위로 솔직하게 보여 주기 때문입니다.

통계도 마찬가지입니다. 표본평균 하나로 "모평균은 4,222g입니다"라고 말하는 것을 **점추정**이라고 합니다. 하지만 [DAY 05](#/l/st-03-2)에서 봤듯이 표본평균은 뽑을 때마다 흔들리므로, 이 숫자가 모평균과 정확히 같을 가능성은 거의 없습니다. 그래서 "모평균은 **3,908g에서 4,536g 사이**쯤일 것입니다"처럼 범위로 말합니다. 이것을 **구간추정**이라 하고, 그 범위를 **신뢰구간**(confidence interval, CI)이라고 합니다.

## 신뢰구간 만드는 법

[중심극한정리](#/l/st-03-3)에 따르면 표본평균은 모평균을 중심으로, 표준오차(SE)만큼 퍼진 정규분포를 따릅니다. 그리고 [정규분포](#/l/st-02-3)에서는 가운데 95%가 평균 ± 1.96 × 표준편차 안에 들어갑니다. 이 두 사실을 합치면,

> 표본평균은 95% 확률로 "모평균 ± 1.96 × SE" 안에 떨어진다.

이 말을 뒤집으면 표본평균에서 ±1.96 × SE만큼 팔을 벌린 구간을 만들 수 있습니다.

> **95% 신뢰구간 = 표본평균 ± 1.96 × SE**

이번 레슨에서는 개념에 집중하기 위해 모표준편차 σ를 **안다고 가정**하고 SE = σ ÷ √n을 씁니다. σ를 모르는 현실적인 경우는 [다음 레슨](#/l/st-04-2)에서 다룹니다.

## 실험: 펭귄 342마리를 모집단으로

펭귄 몸무게 데이터 342마리를 모집단 전체로 놓고 참값(모평균)을 먼저 확인합니다.

```run
import pandas as pd

mass = pd.read_csv("penguins.csv")["body_mass_g"].dropna()
print("모평균(참값):", round(mass.mean(), 1), "g / 모표준편차:", round(mass.std(ddof=0), 1), "g")
```

참값은 4,201.8g입니다. 이제 이 참값을 모른다고 치고, 25마리만 뽑아서 95% 신뢰구간을 만들어 봅니다.

```run
import numpy as np
import pandas as pd

mass = pd.read_csv("penguins.csv")["body_mass_g"].dropna()
se = mass.std(ddof=0) / np.sqrt(25)
sample = np.random.default_rng(0).choice(mass, 25)
print("표본평균:", sample.mean(), "/ 95% CI:", round(sample.mean() - 1.96 * se), "~", round(sample.mean() + 1.96 * se))
```

표본평균은 4,222g이고, 95% 신뢰구간은 3,908g ~ 4,536g입니다. 참값 4,201.8g이 이 구간 안에 있네요. 성공입니다. 하지만 매번 성공할까요?

## 100번 반복하면 몇 번 성공할까

같은 방법으로 표본을 100번 새로 뽑아, 구간을 100개 만들고, 그중 참값을 포함하는 구간이 몇 개인지 세어 봅니다.

```run
import numpy as np
import pandas as pd

mass = pd.read_csv("penguins.csv")["body_mass_g"].dropna()
mu, se, rng = mass.mean(), mass.std(ddof=0) / np.sqrt(25), np.random.default_rng(0)
means = np.array([rng.choice(mass, 25).mean() for _ in range(100)])
print("참값을 포함한 구간:", ((means - 1.96 * se <= mu) & (mu <= means + 1.96 * se)).sum(), "/ 100")
```

100개 중 96개가 참값을 포함했습니다. 약 95개 근처입니다. 구간 100개를 그림으로 그려 보면 더 잘 보입니다. 참값을 놓친 구간은 빨간색입니다.

```run
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd

mass = pd.read_csv("penguins.csv")["body_mass_g"].dropna()
mu, se, rng = mass.mean(), mass.std(ddof=0) / np.sqrt(25), np.random.default_rng(0)
means = np.array([rng.choice(mass, 25).mean() for _ in range(100)])
miss = np.abs(means - mu) > 1.96 * se
plt.errorbar(range(100), means, yerr=1.96 * se, fmt="o", ms=3, ecolor=np.where(miss, "red", "gray"))
plt.axhline(mu, color="C1"); plt.ylabel("body mass (g)"); plt.show()
print("놓친 구간 번호:", np.where(miss)[0])
```

주황색 가로선이 참값입니다. 구간들은 표본마다 위아래로 오르내리지만 대부분 참값 선을 지나가고, 빨간 구간 4개만 참값을 비껴갑니다.

## 95%는 무엇의 확률인가

::figure{src="content/img/stats/st04-ci-coverage.svg" alt="가로로 놓인 참값 선 위로 세로 구간 20개가 표본마다 다른 높이에 그려져 있고, 19개는 참값 선을 지나가고 1개만 선에서 벗어나 빨간색으로 표시된 그림" caption="95% 신뢰구간은 '이 방법으로 만든 구간 중 약 95%가 참값을 붙잡는다'는 뜻입니다. 구간 20개라면 평균 1개쯤은 빗나갑니다."}

이제 "95%"의 진짜 뜻을 정리할 수 있습니다.

> **95% 신뢰구간**: 같은 방법으로 표본을 뽑아 구간을 만드는 일을 아주 많이 반복하면, 그 구간들의 **약 95%가 참값을 포함한다.**

95%는 **구간을 만드는 방법의 성공률**입니다. 고리 던지기 선수에 비유할 수 있습니다. 성공률 95%인 선수가 던진 고리 하나가 막대에 걸렸는지는 이미 정해져 있습니다. 걸렸거나, 안 걸렸거나. 우리가 믿는 것은 그 선수의 **실력**(성공률)입니다.

그래서 아래 해석은 **틀린** 해석입니다.

- ❌ "모평균이 3,908 ~ 4,536g 사이에 있을 확률이 95%다." 모평균은 움직이지 않는 하나의 값이라서, 이미 만든 구간에 들어 있거나(확률 1) 없거나(확률 0) 둘 중 하나입니다.
- ❌ "펭귄의 95%가 3,908 ~ 4,536g 사이다." 신뢰구간은 **평균**에 대한 범위지, 펭귄 한 마리 한 마리의 몸무게 범위가 아닙니다. 실제 펭귄 몸무게는 2,700~6,300g까지 퍼져 있습니다.
- ⭕ "이 방법으로 만든 구간은 100번 중 95번쯤 참값을 포함한다. 이번 구간은 3,908 ~ 4,536g이다."

실무에서는 간단히 "모평균의 95% 신뢰구간은 3,908 ~ 4,536g"이라고 쓰고, 그 뜻을 위처럼 이해하고 있으면 됩니다.

## 신뢰수준을 바꾸면 폭이 바뀐다

95% 말고 90%나 99%로 정할 수도 있습니다. 이 퍼센트를 **신뢰수준**이라고 합니다. 신뢰수준이 바뀌면 1.96 대신 쓰는 배수가 바뀝니다. 가운데 C%를 남기는 경계를 `ppf`로 구합니다.

```run
from scipy import stats

for level in [0.90, 0.95, 0.99]:
    print(f"{level:.0%} 신뢰수준 → 배수 {stats.norm.ppf(1 - (1 - level) / 2):.3f}")
```

90%는 1.645, 95%는 1.960, 99%는 2.576입니다. 더 확실하게 참값을 붙잡으려면(신뢰수준 ↑) 팔을 더 넓게 벌려야(배수 ↑) 합니다. 펭귄 25마리 표본에서 실제 구간 폭(위 끝 − 아래 끝)으로 비교해 봅니다.

```run
import numpy as np
import pandas as pd
from scipy import stats

se = pd.read_csv("penguins.csv")["body_mass_g"].dropna().std(ddof=0) / np.sqrt(25)
for level in [0.90, 0.95, 0.99]:
    print(f"{level:.0%} 구간 폭: {2 * stats.norm.ppf(1 - (1 - level) / 2) * se:.0f} g")
```

90%는 527g, 95%는 628g, 99%는 825g입니다. 일기예보로 치면 "18~22도"(좁지만 가끔 틀림)와 "10~30도"(거의 안 틀리지만 쓸모가 적음) 사이에서 고르는 것입니다. 대부분의 분야에서는 95%를 관례로 씁니다.

## 표본을 늘리면 폭이 좁아진다

정확하면서도 좁은 구간을 원한다면 방법은 **표본을 늘리는 것**뿐입니다. SE = σ ÷ √n이니까요.

직접 해 보세요: 아래 셀의 `[25, 100, 400]`을 바꿔 가며 95% 구간 폭을 비교해 보세요.

```run
import numpy as np
import pandas as pd

sigma = pd.read_csv("penguins.csv")["body_mass_g"].dropna().std(ddof=0)
for n in [25, 100, 400]:
    print(f"n = {n}: 95% 구간 폭 {2 * 1.96 * sigma / np.sqrt(n):.0f} g")
```

25마리면 628g, 100마리면 314g, 400마리면 157g입니다. [표준오차](#/l/st-03-2)와 마찬가지로 **표본을 4배로 늘려야 폭이 절반**이 됩니다.

## 정리

- **점추정**은 값 하나, **구간추정**은 범위. 신뢰구간 = 표본평균 ± 배수 × SE (95%면 1.96).
- 95%는 **구간을 만드는 방법의 성공률**: 반복하면 구간의 약 95%가 참값을 포함한다. 이미 만든 구간 하나에 참값이 있을 확률이 95%라는 뜻이 아니다.
- 신뢰구간은 평균의 범위이지, 개별 값의 범위가 아니다.
- 신뢰수준 ↑ → 구간 넓어짐. 표본 크기 ↑ → 구간 좁아짐(4배 → 절반).
