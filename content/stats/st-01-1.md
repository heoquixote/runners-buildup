## 대표값: 평균과 중앙값

평균은 모든 값을 더해 개수로 나눈 값이고, 중앙값은 크기순으로 줄 세웠을 때 가운데 값입니다. 값 하나가 튀면 평균은 끌려가지만 중앙값은 거의 그대로입니다.

```run
import numpy as np

thick = np.array([8.2, 8.5, 8.1, 8.4, 8.3, 8.2, 8.6, 8.0])
print("평균", thick.mean(), "중앙값", np.median(thick))

thick_out = np.append(thick, 12.0)     # 측정 실수 하나가 섞이면
print("평균", round(thick_out.mean(), 3), "중앙값", np.median(thick_out))
```

> 평균과 중앙값이 크게 다르면 분포가 한쪽으로 치우쳤거나 이상치가 있다는 신호입니다. 보고서에는 두 값을 함께 적는 습관을 들이세요.

## 흩어짐: 분산과 표준편차

표준편차는 "평균에서 보통 얼마나 떨어져 있나"입니다. 표본 데이터라면 n − 1로 나누는 **표본 표준편차**를 씁니다.

| 함수 | 나누는 수 | 언제 |
| --- | --- | --- |
| `np.std(x)` | n (ddof=0) | 모집단 전체를 가진 경우 |
| `np.std(x, ddof=1)` | n − 1 | 표본으로 모집단을 추정할 때 (대부분) |
| `df["col"].std()` | n − 1 | pandas 기본값 |

## 사분위수와 IQR 이상치

Q1(25%), Q3(75%) 사이 폭이 IQR입니다. Q1 − 1.5·IQR 아래, Q3 + 1.5·IQR 위를 이상치로 봅니다. 박스플롯의 수염 끝이 바로 이 기준입니다.

```run
import numpy as np

wait = np.array([5, 7, 6, 8, 5, 6, 30, 7, 6, 5, 7, 1])
q1, q3 = np.percentile(wait, [25, 75])
iqr = q3 - q1
low, high = q1 - 1.5 * iqr, q3 + 1.5 * iqr
print("Q1", q1, "Q3", q3, "IQR", iqr)
print("기준", low, "~", high)
print("이상치", wait[(wait < low) | (wait > high)])
```

## 단위가 다르면 변동계수

평균이 5분인 줄과 평균이 30분인 줄은 표준편차만으로 비교하면 안 됩니다. 변동계수 CV = 표준편차 / 평균 은 단위가 사라진 상대적 흩어짐입니다.

```run
import numpy as np

a = np.array([4, 6, 5, 3, 7])        # 평균 5
b = np.array([28, 31, 30, 29, 32])   # 평균 30
for name, x in [("A", a), ("B", b)]:
    s = x.std(ddof=1)
    print(name, "표준편차", round(s, 2), "CV", round(s / x.mean(), 3))
```
