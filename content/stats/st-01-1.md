## 숫자 244개를 한 줄로 말하기

식당 계산서 244장의 금액을 하나하나 읽어 주면 아무도 기억하지 못합니다. 그래서 "보통 이 정도 나온다"는 **한 숫자**로 요약하는데, 이것을 **대표값**(중심 경향값)이라고 합니다. 대표값은 세 가지를 주로 씁니다: **평균**, **중앙값**, **최빈값**. 셋은 "가운데"를 정하는 방법이 서로 달라서, 데이터 모양에 따라 전혀 다른 답을 내기도 합니다.

## 평균: 모두 똑같이 나눠 가지면

**평균**(mean)은 모든 값을 더해서 개수로 나눈 값입니다. 친구 다섯 명이 가진 사탕을 한데 모았다가 **똑같이 나눠 가지면** 한 명이 받는 개수가 평균입니다.

::figure{src="content/img/stats/st01-mean-median.svg" alt="위: 막대 위에 값들이 놓이고 평균은 시소가 균형을 이루는 받침점. 아래: 값을 크기순으로 줄 세우면 가운데 값이 중앙값" caption="평균은 시소의 균형점이라 멀리 떨어진 값 하나에 크게 끌려가고, 중앙값은 줄의 한가운데라 끝 값이 바뀌어도 그대로입니다."}

그림의 시소처럼 평균은 모든 값이 균형을 이루는 지점입니다. 그래서 **멀리 떨어진 값 하나가 평균을 크게 끌어당깁니다.** 먼저 작은 리스트로 평균을 구해 봅니다.

```run
import numpy as np

candy = np.array([3, 5, 4, 6, 2])
print("합:", candy.sum(), "/ 개수:", len(candy), "/ 평균:", candy.mean())
```

합 20을 5명으로 나눠 평균은 4.0개입니다. 이제 실제 데이터, 식당 계산 금액(`total_bill`)의 평균을 구해 봅니다.

```run
import pandas as pd

df = pd.read_csv("tips.csv")
print("평균 계산 금액:", round(df["total_bill"].mean(), 2), "달러")
```

계산서 244장의 평균은 19.79달러입니다.

## 중앙값: 줄 세웠을 때 한가운데

**중앙값**(median)은 값을 작은 것부터 크기순으로 줄 세웠을 때 **정확히 가운데 있는 값**입니다. 개수가 홀수면 가운데 값 하나, 짝수면 가운데 두 값의 평균을 씁니다.

```run
import numpy as np

print(np.median([1, 3, 9]))        # 홀수 개: 가운데 3
print(np.median([1, 3, 9, 100]))   # 짝수 개: (3 + 9) / 2
```

`[1, 3, 9, 100]`에서 100이 아무리 커져도 중앙값은 6.0 그대로입니다. 줄의 끝에 선 사람이 바뀌어도 가운데 사람은 바뀌지 않으니까요. 같은 식당 데이터의 중앙값을 구해 봅니다.

```run
import pandas as pd

df = pd.read_csv("tips.csv")
print("평균:", round(df["total_bill"].mean(), 2), "/ 중앙값:", df["total_bill"].median())
```

평균은 19.79달러인데 중앙값은 17.80달러입니다. 평균이 2달러쯤 더 높습니다. 몇몇 큰 계산서(최고 50.81달러)가 평균을 위로 끌어올렸기 때문입니다. "보통 손님"의 계산 금액을 말하고 싶다면 중앙값이 더 가깝습니다.

## 최빈값: 가장 흔한 값

**최빈값**(mode)은 가장 많이 나온 값입니다. 계산하는 방법이 "개수 세기"라서 **범주형 데이터에도 쓸 수 있는 유일한 대표값**입니다. 손님 인원 수(`size`)의 최빈값을 봅시다.

```run
import pandas as pd

df = pd.read_csv("tips.csv")
print("최빈값:", df["size"].mode()[0], "명")
print(df["size"].value_counts().head(3))
```

2명이 156번으로 가장 많습니다. 244팀 중 64%가 둘이 온 손님입니다. 요일(`day`)처럼 글자로 된 범주에도 똑같이 쓸 수 있습니다.

```run
import pandas as pd

df = pd.read_csv("tips.csv")
print("가장 손님이 많은 요일:", df["day"].mode()[0])
```

토요일(Sat)이 가장 많습니다. 요일은 평균이나 중앙값을 낼 수 없으니, 최빈값이 유일한 대표값입니다.

> 키나 몸무게처럼 소수점까지 재는 값은 똑같은 값이 거의 나오지 않아서 최빈값이 별 의미가 없습니다. 이런 값은 구간으로 묶어서(히스토그램) 가장 높은 막대를 보는 편이 낫습니다.

## 이상치 하나가 평균을 끌고 간다

반 친구 10명의 한 달 용돈(만 원)이 있습니다. 대부분 4~6만 원입니다.

```run
import numpy as np

money = np.array([5, 5, 4, 6, 5, 3, 5, 7, 5, 5])
print("평균:", money.mean(), "/ 중앙값:", np.median(money))
```

평균과 중앙값이 모두 5.0만 원으로 같습니다. 값이 고르게 퍼져 있으면 두 대표값은 거의 같습니다. 여기에 용돈을 한 달에 100만 원 받는 친구가 한 명 전학을 왔습니다.

```run
import numpy as np

money = np.array([5, 5, 4, 6, 5, 3, 5, 7, 5, 5, 100])
print("평균:", round(money.mean(), 2), "/ 중앙값:", np.median(money))
```

친구 한 명이 더해졌을 뿐인데 평균은 13.64만 원으로 두 배 넘게 뛰었고, 중앙값은 5.0만 원 그대로입니다. "우리 반 평균 용돈은 13만 원이 넘는다"는 말은 계산은 맞지만, 반 친구 11명 중 10명의 현실과는 전혀 다릅니다.

직접 해 보세요: 위 셀의 `100`을 `20`, `500`으로 바꿔 실행해 보세요. 평균은 그 값을 따라 크게 움직이지만 중앙값은 꿈쩍하지 않습니다.

## 꼬리가 긴 데이터에서는 평균 > 중앙값

용돈 예처럼 극단적인 값이 한쪽에만 몰려 있는 데이터를 **꼬리가 긴 분포**라고 합니다. 금액·소득·집값·조회수 같은 데이터는 대부분 오른쪽(큰 값 쪽)으로 꼬리가 깁니다. 타이타닉 요금(`fare`)이 대표적입니다.

```run
import pandas as pd

df = pd.read_csv("titanic.csv")
print("요금 평균:", round(df["fare"].mean(), 2), "/ 중앙값:", df["fare"].median())
print("최댓값:", df["fare"].max())
```

평균 요금은 32.20인데 중앙값은 14.45로, 평균이 중앙값의 두 배가 넘습니다. 최고 요금 512.33을 낸 소수의 1등석 승객이 평균을 끌어올렸습니다. 이런 데이터에서 평균만 보고하면 "보통 승객"의 모습을 크게 부풀리게 됩니다. 분포의 모양은 [st-01-4](#/l/st-01-4)에서 그림으로 자세히 봅니다.

## 언제 어떤 대표값을 쓸까

| 상황 | 추천 | 이유 |
| --- | --- | --- |
| 값이 고르게 퍼지고 좌우가 비슷함 (키, 시험 점수) | 평균 | 모든 값을 반영하고, 이후 통계 계산의 기본 |
| 큰 값 쪽 꼬리가 길거나 이상치가 있음 (금액, 소득, 대기 시간) | 중앙값 | 극단값에 흔들리지 않고 "보통"을 잘 보여 줌 |
| 범주형 데이터, "가장 흔한 선택" (요일, 색상, 메뉴) | 최빈값 | 평균·중앙값을 계산할 수 없음 |

가장 좋은 습관은 **평균과 중앙값을 함께 적는 것**입니다. 두 값이 비슷하면 데이터가 고르게 퍼져 있다는 뜻이고, 크게 다르면 한쪽으로 치우쳤거나 이상치가 있다는 신호입니다.

## 자주 하는 실수

1. **평균을 무조건 기본값으로 쓴다.** 금액·시간 데이터에서 평균만 쓰면 "보통"이 부풀려집니다.
2. **중앙값만 쓰고 전체 규모를 놓친다.** 매출 총액을 예측해야 할 때는 고액 손님까지 다 반영한 평균(또는 합계)이 필요합니다. 중앙값은 "보통 손님"을, 평균은 "전체를 나눈 몫"을 말합니다. 목적에 따라 고르세요.
3. **소수점 데이터에 최빈값을 그대로 쓴다.** 연속된 값은 구간을 어떻게 나누느냐에 따라 최빈값이 달라집니다.

## 정리

- **평균**은 시소의 균형점: 모든 값을 반영하지만 극단값에 끌려간다.
- **중앙값**은 줄의 한가운데: 이상치와 긴 꼬리에 강하다.
- **최빈값**은 가장 흔한 값: 범주형 데이터에도 쓸 수 있다.
- 대표값은 "무엇을 설명하고 싶은가"에 따라 고르고, 평균과 중앙값은 함께 보는 습관을 들이자.
