## 관리 상태와 능력은 다른 질문이다

[관리도](#/l/st-11-1)는 "공정이 평소대로 돌고 있나"를 묻습니다. 그런데 평소대로 잘 돌아도 **평소 흔들림 자체가 규격보다 크면** 불량은 계속 나옵니다. 그래서 두 번째 질문이 필요합니다.

> 이 공정의 평소 흔들림이 **규격 폭 안에 넉넉히** 들어가는가?

이것을 숫자 하나로 나타낸 것이 **공정능력지수**(process capability index), Cp와 Cpk입니다. 납품처가 "Cpk 1.33 이상"을 요구하는 경우가 많아서, 품질 보고서에 가장 자주 나오는 숫자이기도 합니다.

## Cp: 폭만 비교하기

**Cp**는 규격 폭을 공정 흔들림 폭(±3σ, 즉 6σ)으로 나눈 값입니다.

> Cp = (규격 상한 USL − 규격 하한 LSL) ÷ 6σ

주차장 칸 폭(규격)과 차 폭(공정 흔들림)을 비교하는 것과 같습니다. Cp가 1이면 차 폭이 칸에 딱 맞고, 2면 칸이 차보다 두 배 넓습니다.

부품 두께 규격은 9.9 ~ 10.1 mm입니다. 안정된 공정에서 100개를 쟀습니다.

```run
import numpy as np

rng = np.random.default_rng(7)
x = rng.normal(10.02, 0.025, 100)
LSL, USL = 9.9, 10.1
m, s = x.mean(), x.std(ddof=1)
cp = (USL - LSL) / (6 * s)
print("평균:", round(m, 4), "/ 표준편차:", round(s, 4))
print("Cp:", round(cp, 2))
```

Cp는 1.52입니다. 흔들림 폭(6σ = 0.132)이 규격 폭(0.2)보다 좁아 "칸은 충분히 넓다"는 뜻입니다. 그런데 Cp는 **평균이 어디 있는지**를 보지 않습니다. 칸이 넓어도 차가 한쪽 선에 붙어 서 있으면 문을 못 엽니다.

## Cpk: 가까운 쪽 규격까지의 거리

**Cpk**는 평균에서 **더 가까운 규격**까지의 거리를 3σ로 나눈 값입니다.

> Cpk = min(USL − 평균, 평균 − LSL) ÷ 3σ

```run
import numpy as np

rng = np.random.default_rng(7)
x = rng.normal(10.02, 0.025, 100)
LSL, USL = 9.9, 10.1
m, s = x.mean(), x.std(ddof=1)
cpk = min(USL - m, m - LSL) / (3 * s)
print("상한까지:", round(USL - m, 4), "/ 하한까지:", round(m - LSL, 4))
print("Cpk:", round(cpk, 2))
```

평균 10.0157이 규격 중앙(10.0)보다 위로 치우쳐서, 상한까지 거리(0.0843)가 하한까지(0.1157)보다 짧습니다. 그래서 Cpk는 1.28로 Cp(1.52)보다 낮습니다. **Cp와 Cpk의 차이 = 중심이 치우친 정도**입니다. 평균이 규격 중앙에 정확히 있으면 Cp = Cpk입니다.

## Cpk를 불량률로 바꾸면

공정이 정규분포를 따른다면 Cpk에서 예상 불량률을 계산할 수 있습니다. [정규분포와 표준화](#/l/st-02-3)의 정규분포 꼬리 확률입니다. 품질에서는 불량률을 100만 개당 개수, **ppm**으로 씁니다.

```run
import numpy as np
from scipy import stats

rng = np.random.default_rng(7)
x = rng.normal(10.02, 0.025, 100)
LSL, USL = 9.9, 10.1
m, s = x.mean(), x.std(ddof=1)
ppm = (stats.norm.sf(USL, m, s) + stats.norm.cdf(LSL, m, s)) * 1e6
print("예상 불량:", round(ppm, 1), "ppm")
print("중앙으로 옮기면:", round((stats.norm.sf(USL, 10.0, s) + stats.norm.cdf(LSL, 10.0, s)) * 1e6, 2), "ppm")
```

지금 공정은 100만 개 중 약 63개가 규격을 벗어날 것으로 예상됩니다. 흔들림은 그대로 두고 **평균만 10.0으로 옮기면** 5.44ppm으로 열 배 넘게 줄어듭니다. 설비 흔들림을 줄이는 것보다 중심을 맞추는 것이 훨씬 쉽고 싸므로, Cp는 높은데 Cpk가 낮으면 **먼저 중심을 맞추라**는 신호입니다.

양쪽이 대칭이라고 보고 Cpk 값별 예상 불량률을 계산해 보면 기준이 왜 그 숫자인지 보입니다.

```run
from scipy import stats

for c in [0.67, 1.0, 1.33, 1.67]:
    ppm = 2 * stats.norm.sf(3 * c) * 1e6
    print(f"Cpk {c}: 약 {ppm:,.1f} ppm")
```

| Cpk | 예상 불량 (양쪽, 중심일 때) | 흔한 판정 |
| --- | --- | --- |
| 0.67 | 약 44,000 ppm (4.4%) | 능력 부족. 전수 검사 필요 |
| 1.00 | 약 2,700 ppm | 겨우 맞춤. 개선 필요 |
| 1.33 | 약 66 ppm | 보통 요구 수준 |
| 1.67 | 약 0.5 ppm | 우수 |

1.33은 "평균에서 가까운 규격까지 4σ"라는 뜻입니다. 공정이 조금 흔들려도 불량이 거의 나오지 않을 여유입니다.

## σ를 어떻게 구하느냐: Cpk와 Ppk

σ를 구하는 방법이 두 가지라서 지수도 두 개입니다.

| 지수 | σ | 뜻 |
| --- | --- | --- |
| **Cpk** | 부분군 **안** 흔들림 (R 평균 ÷ 상수) | 공정이 **할 수 있는** 수준 |
| **Ppk** | 전체 데이터의 표준편차 | 실제로 **보여 준** 수준 |

[지난 레슨](#/l/st-11-2)의 X̄-R처럼 5개씩 25번 잰 데이터에서, 시간이 지나며 평균이 조금씩 움직인 경우를 봅니다. 부분군 크기 5의 상수는 2.326입니다.

```run
import numpy as np

rng = np.random.default_rng(11)
drift = np.linspace(-0.03, 0.03, 25)[:, None]           # 25시간 동안 평균이 서서히 이동
X = rng.normal(0, 0.02, (25, 5)) + drift + 10.0
LSL, USL = 9.9, 10.1
m = X.mean()

s_within = (X.max(axis=1) - X.min(axis=1)).mean() / 2.326
s_overall = X.std(ddof=1)
print("σ (부분군 안):", round(s_within, 4), "/ σ (전체):", round(s_overall, 4))
print("Cpk:", round(min(USL - m, m - LSL) / (3 * s_within), 2), "/ Ppk:", round(min(USL - m, m - LSL) / (3 * s_overall), 2))
```

부분군 안 흔들림만 보면 Cpk 1.83으로 우수하지만, 시간에 따른 이동까지 포함한 전체로 보면 Ppk 1.23으로 기준(1.33)에 못 미칩니다. **Cpk와 Ppk의 차이가 크면 공정이 시간에 따라 움직이고 있다**는 뜻이고, 관리도로 그 이동의 원인을 찾아 없애면 Ppk가 Cpk에 가까워집니다. 보고서에는 어떤 σ로 계산했는지 반드시 적습니다.

## 계산 전에 확인할 것

1. **관리 상태인가**: 관리도에 신호가 있는 공정은 평균과 σ가 계속 바뀌므로, 공정능력지수 하나로 요약할 수 없습니다. 관리도 → 공정능력 순서입니다.
2. **정규분포에 가까운가**: ppm 계산은 정규분포 가정입니다. 한쪽으로 치우친 데이터(진원도, 평탄도처럼 0 아래가 없는 값)는 그대로 계산하면 불량률을 크게 틀립니다([가정 확인과 비모수 검정](#/l/st-06-3)에서 정규성 확인).
3. **표본이 충분한가**: 30개로 구한 Cpk 1.33은 신뢰구간이 꽤 넓습니다. 보통 100개 이상, 여러 날에 걸쳐 모읍니다([부트스트랩: 공식 없이 구하는 신뢰구간](#/l/st-04-3)의 부트스트랩으로 구간을 붙일 수 있음).

## 자주 하는 실수

- Cp만 보고 "능력 충분": 중심이 치우치면 Cpk가 낮습니다. 항상 Cpk를 함께 봅니다.
- 관리한계로 Cpk 계산하기: Cpk에는 **규격한계**(USL, LSL)를 넣습니다.
- 불안정한 공정의 Cpk 보고: 관리도에서 신호를 먼저 없앤 뒤 계산합니다.
- 규격이 한쪽만 있는데 Cp 계산: 상한만 있으면 (USL − 평균) ÷ 3σ, 즉 한쪽 Cpk만 씁니다.

## 정리

- 관리 상태(안정)와 공정능력(규격을 지킬 힘)은 다른 질문이다.
- Cp = 규격 폭 ÷ 6σ(폭만), Cpk = 가까운 규격까지 거리 ÷ 3σ(중심까지 반영).
- Cpk 1.33 ≈ 66ppm, 1.67 ≈ 0.5ppm. Cp는 높고 Cpk가 낮으면 먼저 중심을 맞춘다.
- 부분군 안 σ로 구하면 Cpk, 전체 σ로 구하면 Ppk. 차이가 크면 공정이 시간에 따라 움직이고 있다.
