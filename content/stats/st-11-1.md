## 측정값은 원래 흔들린다

같은 설비, 같은 재료, 같은 작업자로 부품을 만들어도 두께가 10.00, 9.98, 10.03 mm처럼 조금씩 다릅니다. 이 흔들림에는 두 종류가 있습니다.

| 종류 | 원인 | 예 | 대응 |
| --- | --- | --- | --- |
| **우연 원인** (일반 원인) | 늘 있는 작은 원인 여러 개가 합쳐진 것 | 재료 미세 차이, 온도 미세 변화 | 공정 자체를 바꾸지 않으면 줄지 않음. 매번 손대지 않는다 |
| **이상 원인** (특수 원인) | 평소에 없던 특정한 원인 | 공구 마모, 원료 로트 변경, 설정 실수 | 찾아서 없앤다 |

품질 관리의 첫 질문은 "지금 흔들림이 **평소 수준**인가, 아니면 **무슨 일이 생긴** 것인가"입니다. 평소 흔들림에 매번 설비를 조정하면 오히려 흔들림이 커지고, 이상 원인을 놓치면 불량이 쌓입니다. 이 둘을 가르는 도구가 **관리도**(control chart)입니다. 1920년대 벨 연구소의 월터 슈하트가 만들어 지금도 공장마다 쓰는 방법입니다.

## 관리도의 모양

관리도는 측정값을 **시간 순서대로** 찍은 선 그래프에 가로선 세 개를 그은 것입니다.

- **중심선(CL)**: 공정이 안정적일 때의 평균
- **관리 상한(UCL)과 관리 하한(LCL)**: 중심선 ± 3σ. 평소 흔들림이라면 값이 거의 다(99.7%) 이 안에 들어옵니다([정규분포와 표준화](#/l/st-02-3)의 정규분포)

점이 관리한계 밖으로 나가면 "평소 흔들림으로는 설명하기 어렵다", 즉 **이상 원인 신호**로 보고 원인을 찾습니다. [가설검정](#/l/st-05-1)을 점 하나마다 하는 것과 같은 생각입니다.

> **관리한계는 규격한계가 아닙니다.** 규격한계(9.9 ~ 10.1 mm 같은 것)는 고객이나 설계가 정한 "허용 범위"이고, 관리한계는 **공정이 스스로 보여 준** 평소 흔들림의 범위입니다. 규격 안이어도 관리한계 밖이면 공정에 무슨 일이 생긴 것이고, 관리한계 안이어도 규격을 벗어날 수 있습니다. 둘을 같은 그래프에 그리지 않는 것이 원칙입니다.

## I-MR 관리도: 하나씩 잴 때

부품을 하나씩 재서 기록하는 경우에 쓰는 관리도가 **I-MR 관리도**입니다. I는 개별값(individual), MR은 **이동범위**(moving range), 즉 바로 앞 값과의 차이의 절댓값입니다.

σ는 표준편차를 바로 쓰지 않고 이동범위의 평균으로 추정합니다. 바로 이웃한 두 값의 차이는 **짧은 시간 안의 흔들림**만 담고 있어서, 중간에 평균이 바뀌는 일이 있어도 덜 부풀려지기 때문입니다.

> 관리한계 = 평균 ± 2.66 × MR 평균

2.66은 3 ÷ 1.128입니다. 1.128은 "정규분포에서 두 값 차이의 평균은 σ의 1.128배"라는 상수라서, MR 평균 ÷ 1.128이 σ의 추정값이 됩니다.

부품 두께를 30개 연속으로 쟀습니다. 처음 20개는 공정이 안정적이던 기간이라 이 구간으로 관리한계를 정합니다.

```run
import numpy as np

rng = np.random.default_rng(3)
x = rng.normal(10.0, 0.02, 30)
x[20:] += 0.05                       # 21번째부터 무슨 일이 생겼다고 가정
base = x[:20]

cl = base.mean()
mr_bar = np.abs(np.diff(base)).mean()
ucl, lcl = cl + 2.66 * mr_bar, cl - 2.66 * mr_bar
print("CL:", round(cl, 4), "/ MR 평균:", round(mr_bar, 4))
print("LCL:", round(lcl, 4), "/ UCL:", round(ucl, 4))
print("σ 추정:", round(mr_bar / 1.128, 4), "/ 표본 표준편차:", round(base.std(ddof=1), 4))
```

중심선 9.9974, 관리한계 9.9233 ~ 10.0714입니다. 이동범위로 추정한 σ(0.0247)와 표본 표준편차(0.0252)가 거의 같습니다. 안정된 구간이라 두 방법이 비슷한 답을 냅니다.

## 그려서 읽기

```run
import numpy as np
import matplotlib.pyplot as plt

rng = np.random.default_rng(3)
x = rng.normal(10.0, 0.02, 30)
x[20:] += 0.05
base = x[:20]
cl = base.mean()
mr_bar = np.abs(np.diff(base)).mean()
ucl, lcl = cl + 2.66 * mr_bar, cl - 2.66 * mr_bar

idx = np.arange(1, 31)
out = (x > ucl) | (x < lcl)
fig, ax = plt.subplots(figsize=(7, 3.5))
ax.plot(idx, x, marker="o", color="steelblue")
ax.scatter(idx[out], x[out], color="crimson", zorder=3, s=60)
for y, name in [(ucl, "UCL"), (cl, "CL"), (lcl, "LCL")]:
    ax.axhline(y, color="gray", linestyle="--" if name != "CL" else "-")
    ax.text(30.6, y, name, va="center")
ax.set_xlabel("Sample no.")
ax.set_ylabel("Thickness (mm)")
ax.set_title("I chart: points after #20 shift upward")
print("관리한계 밖:", idx[out].tolist())
```

관리한계를 벗어난 점은 22번과 27번 두 개입니다. 그런데 그래프를 보면 21번부터 **모든 점이 중심선 위**에 있습니다. 점 하나하나는 대부분 한계 안이지만, 전체가 위로 옮겨 간 것이 눈에 보입니다.

## 한계 밖이 아니어도 신호다: 런 규칙

공정이 평소대로라면 점이 중심선 위아래에 반반씩 무작위로 찍힙니다. 동전 던지기와 같습니다. 그런데 **8번 연속 한쪽**에 찍힐 확률은 (1/2)⁸ = 0.4%밖에 안 됩니다. 그래서 관리도에는 한계 밖 점 말고도 "평소라면 거의 안 나오는 모양"을 신호로 보는 **런 규칙**(run rule)이 있습니다.

| 규칙 (대표적인 것) | 의심되는 원인 |
| --- | --- |
| 1. 점 하나가 관리한계 밖 | 갑작스러운 이상 (설정 실수, 불량 원료) |
| 2. 연속 8점이 중심선 한쪽 | 평균이 옮겨 감 (원료 로트 변경, 지그 교체) |
| 3. 연속 6점이 계속 오르거나 내림 | 서서히 변함 (공구 마모, 온도 상승) |

```run
import numpy as np

rng = np.random.default_rng(3)
x = rng.normal(10.0, 0.02, 30)
x[20:] += 0.05
cl = x[:20].mean()

above = x > cl
run, first = 0, None
for i, a in enumerate(above, start=1):
    run = run + 1 if a else 0
    if run >= 8 and first is None:
        first = i
print("중심선 위(1) / 아래(0):", above.astype(int).tolist())
print("연속 8점 규칙이 처음 걸린 번호:", first)
```

21번부터 위쪽이 계속되어 28번에서 "연속 8점" 규칙에 걸렸습니다. 규칙 1(한계 밖)은 22번에서 먼저 신호를 줬지만, 평균이 조금만 옮겨 간 경우에는 한계 밖 점이 안 나오고 규칙 2로만 잡히는 일이 많습니다. 두 규칙을 **함께** 봐야 합니다.

## 실무에서 관리도를 쓰는 순서

1. **안정된 기간**의 데이터(보통 20~25점 이상)로 중심선과 관리한계를 정한다
2. 정한 한계를 **고정**하고, 새로 들어오는 값을 찍어 나간다
3. 신호가 나오면 그 시점에 무엇이 바뀌었는지(원료, 작업자, 설정, 공구) 찾는다
4. 원인을 없앤 뒤, 필요하면 다시 안정 구간으로 한계를 새로 정한다

새 데이터가 들어올 때마다 전체로 한계를 다시 계산하면, 이상 구간이 한계를 넓혀서 신호를 스스로 지워 버립니다. 2번의 "고정"이 중요한 이유입니다.

## 자주 하는 실수

- 관리한계와 규격한계를 같은 것으로 보기: 관리한계는 공정의 목소리, 규격한계는 고객의 목소리입니다.
- 한계 안이면 무조건 정상으로 보기: 런 규칙(한쪽 연속, 계속 상승)도 함께 봅니다.
- 평소 흔들림마다 설비를 조정하기: 관리 상태인 공정을 건드리면 흔들림이 오히려 커집니다(과잉 조정).
- 시간 순서를 섞어서 그리기: 관리도는 측정한 순서 그대로 그려야 의미가 있습니다.

## 정리

- 흔들림에는 늘 있는 우연 원인과 찾아서 없애야 할 이상 원인이 있다. 관리도는 둘을 가른다.
- 관리도 = 시간순 값 + 중심선 + 관리한계(평균 ± 3σ). 관리한계는 규격한계가 아니다.
- I-MR 관리도는 하나씩 잴 때 쓰고, 한계는 평균 ± 2.66 × MR 평균이다.
- 한계 밖 점뿐 아니라 연속 8점 한쪽 같은 런 규칙도 신호다.
