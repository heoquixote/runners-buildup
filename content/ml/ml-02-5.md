## 시작하기 전에

[선형회귀: 직선 하나로 예측하기](#/l/ml-02-1)~4에서는 **숫자**를 예측하는 선형회귀를 배웠습니다. 이번에는 생존/사망처럼 **둘 중 하나**를 맞히는 분류 문제입니다. 이름은 "회귀"지만 분류 모델인 **로지스틱 회귀**가 주인공입니다.

## 로지스틱 회귀: 확률로 분류하기

생존(1)/사망(0)처럼 답이 둘 중 하나일 때 직선을 그대로 쓰면 1보다 크거나 0보다 작은 이상한 값이 나옵니다. 로지스틱 회귀는 직선의 결과를 **S자 곡선(시그모이드)**에 통과시켜 0~1 사이 **확률**로 바꿉니다.

::figure{src="content/img/ml/ml02-sigmoid.svg" alt="직선의 점수를 S자 곡선에 통과시켜 0에서 1 사이 확률로 바꾸고, 0.5를 넘으면 1로 판정" caption="직선이 내는 점수는 끝없이 커지거나 작아지지만, S자 곡선을 거치면 항상 0~1 사이 확률이 됩니다."}

- 확률 0.5 이상 → 1(생존)로 판정
- 확률 0.5 미만 → 0(사망)으로 판정

::video{ref="dl-m29"}

```run
import numpy as np
import matplotlib.pyplot as plt

z = np.linspace(-6, 6, 100)
fig, ax = plt.subplots(figsize=(5, 3))
ax.plot(z, 1 / (1 + np.exp(-z)))
ax.axhline(0.5, color="gray", ls="--"); ax.set_title("Sigmoid: any number -> 0~1")
ax.set_xlabel("linear score"); ax.set_ylabel("probability")
plt.tight_layout(); plt.show()
print("score 0 -> prob", 1 / (1 + np.exp(0)))
```

## 타이타닉 생존 확률 예측

이제 타이타닉 데이터로 로지스틱 회귀를 학습합니다. 숫자 크기가 다른 열(나이 0~80, 운임 0~500)이 섞여 있어서 **표준화**(크기 맞추기)를 함께 붙입니다. `make_pipeline`은 여러 단계를 한 줄로 이어 주는 도구입니다.

```run
import numpy as np
import pandas as pd
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression

df = pd.read_csv("titanic.csv")
df["female"] = (df["sex"] == "female").astype(int)
df["age"] = df["age"].fillna(df["age"].median())
features = ["pclass", "female", "age", "fare"]
model = make_pipeline(StandardScaler(), LogisticRegression()).fit(df[features], df["survived"])

people = pd.DataFrame({"pclass": [1, 3], "female": [1, 0], "age": [30, 30], "fare": [80.0, 8.0]})
print(people)
print("survival probability:", model.predict_proba(people)[:, 1].round(3))
print("prediction (0.5 cut):", model.predict(people))
```

`predict_proba`는 [사망 확률, 생존 확률] 두 열을 돌려줍니다. `[:, 1]`이 생존 확률입니다. 1등실 30세 여성은 약 93%, 3등실 30세 남성은 약 9%로 예측됩니다.

## 계수로 해석하기

표준화한 뒤의 계수는 서로 크기를 비교할 수 있습니다. **+는 생존 확률을 올리고, −는 내리는** 방향입니다.

```run
import pandas as pd
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression

df = pd.read_csv("titanic.csv")
df["female"] = (df["sex"] == "female").astype(int)
df["age"] = df["age"].fillna(df["age"].median())
features = ["pclass", "female", "age", "fare"]
model = make_pipeline(StandardScaler(), LogisticRegression()).fit(df[features], df["survived"])
print(pd.Series(model[-1].coef_[0], index=features).round(2))
```

- `female`가 가장 큰 +: 여성일수록 생존 확률이 높다
- `pclass`가 −: 등급 숫자가 클수록(3등실) 생존 확률이 낮다
- `age`가 −: 나이가 많을수록 조금 낮다
- `fare`는 0에 가까움: 운임 정보는 객실 등급과 겹쳐서 따로 더해 주는 정보가 적다

> 계수는 "모델이 이렇게 배웠다"는 뜻이지 원인을 증명하는 것은 아닙니다. 하지만 역사적 사실과 맞는지 확인하면 모델을 믿을 수 있는지 판단하는 데 도움이 됩니다.

## 로지스틱 회귀는 무엇을 줄이며 배울까

선형회귀는 오차 제곱의 평균(MSE)을 줄이며 배웠습니다([모델은 어떻게 직선을 찾을까: 경사하강법](#/l/ml-02-3)). 로지스틱 회귀는 확률을 내기 때문에 다른 벌점을 씁니다. **로그 손실(log loss)** 입니다.

- 실제로 생존한 사람에게 생존 확률 0.9를 줬다면 → 벌점 작음
- 0.5를 줬다면 → 벌점 중간
- 0.01을 줬다면(자신 있게 틀림) → 벌점이 **아주 크게** 튀어 오름

"자신 있게 틀리는 것"을 가장 크게 혼내는 벌점이라, 모델이 확률을 조심스럽게 내도록 배웁니다. 이 벌점도 경사하강법으로 한 걸음씩 줄여 나갑니다.

## 정리

- 로지스틱 회귀 = 직선의 점수 + **S자 곡선(시그모이드)** → 0~1 확률, 기본 0.5 기준으로 판정
- `predict_proba(X)[:, 1]`이 1(생존)일 확률, `predict`가 판정 결과
- 표준화한 뒤의 계수는 크기를 비교할 수 있고, +는 확률을 올리고 −는 내립니다.
- 확률(0.93)과 판정(1)은 다릅니다. 판정 기준선 0.5는 상황에 따라 바꿀 수 있습니다([임계값: 경보 감도 조절](#/l/ml-03-3)).
