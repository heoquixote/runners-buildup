## 시작하기 전에

[앞 레슨](#/l/ml-06-5)에서 반지름·둘레·넓이처럼 **같은 정보를 가진 열**이 여럿 있으면 하나만 있어도 충분하다는 것을 봤습니다. 이렇게 특성끼리 서로 강하게 얽혀 있는 상태를 **다중공선성**이라고 합니다. 이번 레슨에서는 다중공선성이 왜 문제인지, 어떻게 찾고(상관표·VIF) 어떻게 처방하는지 배웁니다.

## 둘이 같은 일을 하면 누구 공인지 모른다

두 친구가 조별 과제를 **똑같이 같이** 했다고 해 봅시다. 점수가 100점이면 각자 몇 점씩 기여했을까요? 50 : 50일 수도, 80 : 20일 수도, 심지어 130 : −30일 수도 있습니다. 둘이 항상 함께 움직였으니 **나눠 볼 방법이 없습니다.**

선형 모델의 계수도 같습니다. 계수는 "다른 열은 그대로 두고 이 열만 1 늘리면?"이라는 뜻인데, 두 열이 늘 함께 움직이면 "하나만 늘리는" 경우가 데이터에 거의 없습니다. 그래서 모델은 둘의 몫을 제멋대로 나누고, 데이터가 조금만 바뀌어도 계수가 크게 흔들립니다.

## 찾는 법 1: 상관표

가장 먼저 볼 것은 특성끼리의 상관계수 표입니다. 설비 데이터로 확인합니다.

```run
import pandas as pd

df = pd.read_csv("ai4i2020.csv")
features = ["air_temp", "process_temp", "rpm", "torque", "tool_wear"]
print(df[features].corr().round(2))
```

- `air_temp`(공기 온도)와 `process_temp`(공정 온도): **0.88**. 공정 온도는 공기 온도에 열이 더해진 값이라 함께 오르내립니다.
- `rpm`(회전수)와 `torque`(토크): **−0.88**. 같은 동력을 낼 때 빨리 돌면 힘이 덜 들고, 천천히 돌면 힘이 더 듭니다.
- `tool_wear`(공구 마모)는 어느 열과도 거의 0입니다.

## 찾는 법 2: VIF

상관표는 **두 열씩**만 봅니다. 그런데 한 열이 다른 **여러 열의 조합**으로 거의 맞혀지는 경우도 있습니다. 이걸 잡는 게 **VIF**(분산 팽창 계수)입니다. 원리는 간단합니다.

1. 열 하나(예: `air_temp`)를 **정답**으로 놓고, 나머지 열들로 선형회귀를 해서 R²를 구한다.
2. `VIF = 1 / (1 − R²)`

나머지 열로 이 열을 잘 맞힐수록(R²가 1에 가까울수록) VIF가 커집니다.

::figure{src="content/img/ml/ml06-vif.svg" alt="R²가 0이면 VIF 1, 0.5면 2, 0.8이면 5, 0.9면 10, 1에 가까워지면 VIF가 끝없이 커진다" caption="R²(다른 열로 이 열을 맞히는 정도)와 VIF의 관계. 보통 5~10을 넘으면 겹침이 심하다고 봅니다."}

| VIF | R² | 뜻 |
| --- | --- | --- |
| 1 | 0 | 다른 열과 전혀 안 겹침 |
| 5 | 0.8 | 80%가 다른 열로 설명됨, 주의 |
| 10 이상 | 0.9 이상 | 거의 다른 열의 복사본 |

통계 패키지에 VIF 함수가 있지만, 원리대로 직접 계산해 봅니다.

```run
import pandas as pd
from sklearn.linear_model import LinearRegression

def vif(X):
    result = {}
    for col in X.columns:
        others = X.drop(columns=col)
        r2 = LinearRegression().fit(others, X[col]).score(others, X[col])
        result[col] = round(1 / max(1 - r2, 1e-12), 1)
    return result

df = pd.read_csv("ai4i2020.csv")
print(vif(df[["air_temp", "process_temp", "rpm", "torque", "tool_wear"]]))
```

네 열이 모두 **4.3**, 공구 마모는 1.0입니다. 겹침이 있지만 심각한 수준(10)은 아닙니다.

### 파생변수의 함정: 완전히 겹치는 열

[새 특성 만들기](#/l/ml-06-3)에서 온도차 `temp_gap = process_temp − air_temp`를 만들었습니다. 이 열을 원래 두 온도 열과 **함께** 넣으면 어떻게 될까요?

```run
import pandas as pd
from sklearn.linear_model import LinearRegression

def vif(X):
    result = {}
    for col in X.columns:
        others = X.drop(columns=col)
        r2 = LinearRegression().fit(others, X[col]).score(others, X[col])
        result[col] = round(1 / max(1 - r2, 1e-12), 1)
    return result

df = pd.read_csv("ai4i2020.csv")
df["temp_gap"] = df["process_temp"] - df["air_temp"]
print("all three :", vif(df[["air_temp", "process_temp", "temp_gap"]]))
print("swap one  :", vif(df[["air_temp", "temp_gap"]]))
```

세 열을 함께 넣으면 VIF가 1,000,000,000,000입니다. 0으로 나누는 에러를 막으려고 함수에 넣어 둔 상한값이 그대로 나온 것으로, 사실상 **무한대**입니다. `temp_gap`은 두 온도의 뺄셈이라 R²가 정확히 1이기 때문입니다. 이것을 **완전 공선성**이라고 합니다. `process_temp` 대신 `temp_gap`을 넣으면(공기 온도 + 온도차) 같은 정보를 담으면서 VIF가 **2.0**으로 내려갑니다.

> 파생변수를 만들면 **그 재료 열과 반드시 겹칩니다.** 재료를 모두 남길지, 하나를 뺄지 VIF로 확인하세요. 원-핫 인코딩에서 `drop="first"`를 쓰는 이유도 같습니다(모든 종류 열을 더하면 항상 1이라 완전 공선).

## 겹치면 무슨 일이 생기나: 계수가 흔들린다

[Ridge와 Lasso](#/l/ml-02-6)에서 쓴 당뇨 데이터의 `s1`(총콜레스테롤)과 `s2`(나쁜 콜레스테롤 LDL)는 상관이 0.90이고 VIF가 59, 39입니다. 데이터를 조금씩 바꿔(복원 추출로 다시 뽑아) 다섯 번 학습하고 두 계수를 비교해 봅니다.

```run
import numpy as np
import pandas as pd
from sklearn.datasets import load_diabetes
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LinearRegression, Ridge

X, y = load_diabetes(return_X_y=True, as_frame=True)
rows = []
for seed in range(5):
    idx = np.random.RandomState(seed).choice(len(X), len(X), replace=True)
    row = {}
    for name, m in [("linear", LinearRegression()), ("ridge", Ridge(alpha=10))]:
        coef = make_pipeline(StandardScaler(), m).fit(X.iloc[idx], y.iloc[idx])[-1].coef_
        row[name + " s1"], row[name + " s2"] = round(coef[4], 1), round(coef[5], 1)
    rows.append(row)
print(pd.DataFrame(rows))
```

- 선형회귀의 `s1` 계수는 −22.7에서 −68.4까지, `s2`는 +8.4에서 +49.9까지 오갑니다. 둘이 반대 부호로 크게 튀며 **서로를 상쇄**하고 있습니다. "나쁜 콜레스테롤이 높을수록 당뇨가 진행된다(+50)"는 해석이 다음 데이터에서는 +8이 됩니다.
- Ridge(alpha 10)는 `s1`이 −7.2 ~ −19.1, `s2`가 −3.8 ~ +10.3으로 훨씬 덜 흔들립니다. 벌점이 "둘이 크게 튀며 상쇄하는" 해를 막아 주기 때문입니다.

중요한 점은 **예측 성능은 거의 그대로**라는 것입니다. 실제로 `s2`를 빼고 교차검증하면 R²가 0.482 → 0.480으로 거의 같습니다. 다중공선성은 **예측**보다 **해석**(계수, 중요도)을 망가뜨립니다.

## 처방

| 방법 | 언제 | 주의 |
| --- | --- | --- |
| 겹치는 열 중 하나 빼기 | VIF가 10 이상, 해석이 중요할 때 | 현장 의미가 더 분명한 열을 남김 |
| 합쳐서 새 열 만들기 | 온도 둘 → 공기 온도 + 온도차 | 재료 열과의 완전 공선 확인 |
| Ridge 쓰기 | 열을 다 남겨야 할 때 | 계수는 줄어든 값이라 크기 해석은 조심 |
| PCA로 묶기 | 열이 아주 많이 겹칠 때 | 새 축의 의미를 설명하기 어려움 ([PCA](#/l/ml-07-3)) |
| 트리 모델 쓰기 | 예측이 목적일 때 | 예측은 괜찮지만 **중요도를 나눠 가짐** ([순열 중요도](#/l/ml-09-1)) |

## 정리

- **다중공선성**: 특성끼리 강하게 겹쳐서, 모델이 각 열의 몫을 나누지 못하는 상태입니다.
- 찾기: **상관표**(두 열씩), **VIF = 1 / (1 − R²)**(여러 열 조합까지). 5~10을 넘으면 주의합니다.
- 파생변수와 재료 열을 함께 넣으면 **완전 공선**(VIF 무한대)이 될 수 있습니다.
- 겹치면 계수가 크게 흔들리지만(s1: −23 ~ −68) 예측 성능은 거의 그대로입니다. 해석이 목적이면 꼭 처방합니다.
