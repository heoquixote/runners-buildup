## 시작하기 전에

[결정트리: 스무고개로 예측하기](#/l/ml-04-1)에서는 트리로 **종류**(생존/사망)를 맞혔습니다. 같은 스무고개로 **숫자**도 맞힐 수 있습니다. 이것이 **회귀 트리**입니다. 트리 · 랜덤포레스트 · 부스팅이 회귀와 분류 모두에 쓰이는 이유가 여기에 있습니다. 이번 레슨에서는 회귀 트리가 질문을 고르는 기준(분산 줄이기), 예측이 계단 모양이 되는 이유, 그리고 트리가 학습 범위 밖을 예측하지 못한다는 중요한 약점을 봅니다.

## 회귀 트리: 잎에서는 평균을 말한다

분류 트리는 잎에 모인 승객들의 **다수결**로 답했습니다. 회귀 트리는 잎에 모인 값들의 **평균**으로 답합니다. 나머지(예/아니오 질문을 이어 붙이는 구조)는 같습니다.

회전수(rpm) 하나로 토크를 예측하는 깊이 1짜리 트리를 만들고, 트리가 고른 질문을 글로 출력해 봅니다.

```run
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeRegressor, export_text

df = pd.read_csv("ai4i2020.csv")
X_train, X_test, y_train, y_test = train_test_split(df[["rpm"]], df["torque"], test_size=0.25, random_state=0)
stump = DecisionTreeRegressor(max_depth=1).fit(X_train, y_train)
print(export_text(stump, feature_names=["rpm"]))
```

트리가 고른 질문은 "rpm ≤ 1533.5인가?"입니다. 느린 쪽 설비에는 토크 46.27, 빠른 쪽에는 31.20을 예측합니다. 각 값은 그 쪽에 들어간 학습 설비들의 토크 평균입니다.

## 질문을 고르는 기준: 오차 제곱합을 가장 많이 줄이기

분류 트리는 지니 불순도를 가장 많이 줄이는 질문을 골랐습니다. 회귀 트리는 **오차 제곱합(SSE)** 을 가장 많이 줄이는 질문을 고릅니다. 잎이 평균을 말하므로, 한 잎의 SSE는 "값들이 자기 평균에서 얼마나 흩어져 있나"입니다.

`나눈 뒤 SSE = Σ(왼쪽 값 − 왼쪽 평균)² + Σ(오른쪽 값 − 오른쪽 평균)²`

나눈 뒤 SSE가 가장 작은 기준값이 가장 좋은 질문입니다. 같은 말로, 그룹 안의 **분산을 가장 많이 줄이는** 질문입니다. 설비 8대로 직접 계산해 봅니다. 가능한 기준값(이웃한 두 rpm의 중간) 7개를 모두 시도합니다.

```run
import numpy as np
import pandas as pd

df = pd.read_csv("ai4i2020.csv").sample(8, random_state=3).sort_values("rpm")
rpm, torque = df["rpm"].values, df["torque"].values
print("rpm:   ", rpm)
print("torque:", torque)
sse = lambda v: ((v - v.mean()) ** 2).sum()
print("no split SSE:", round(sse(torque), 1))
for i in range(1, len(rpm)):
    cut = (rpm[i - 1] + rpm[i]) / 2
    left, right = torque[:i], torque[i:]
    print(f"rpm <= {cut:6.1f}: left mean {left.mean():5.1f}, right mean {right.mean():5.1f}, SSE {sse(left) + sse(right):6.1f}")
```

나누기 전 SSE는 646.4입니다. 기준값 1,473.5(느린 5대 / 빠른 3대)에서 SSE가 **180.7**로 가장 작습니다. 왼쪽 평균 48.1, 오른쪽 평균 32.3으로 두 그룹이 가장 또렷하게 갈립니다. 트리는 이 질문을 첫 질문으로 고르고, 양쪽에서 같은 계산을 다시 반복합니다. 이렇게 한 번에 가장 좋은 질문 하나씩 고르는 방식을 **탐욕적(greedy)** 분할이라고 합니다. 매 순간 최선을 고를 뿐, 전체 나무가 최선이라는 보장은 없습니다.

:::tip 알아 두면 좋아요 · SSE 줄이기 = 분산 줄이기
한 잎의 SSE를 그 잎의 개수로 나누면 그 잎의 분산(평균 제곱 오차)입니다. 그래서 사이킷런은 이 기준을 `criterion="squared_error"`라고 부릅니다. 이상치에 덜 흔들리게 하려면 `criterion="absolute_error"`를 쓸 수 있는데, 이때 잎은 평균 대신 **중앙값**을 말합니다. [모델 지도](#/l/ml-00-3)에서 본 "손실을 무엇으로 고르면 답이 평균 쪽인가 중앙값 쪽인가"가 여기서도 그대로 나옵니다.
:::

## 예측이 계단 모양인 이유

잎마다 하나의 평균값을 말하니, rpm을 따라 예측을 그리면 **계단**이 됩니다. 깊이를 키우면 계단이 잘아집니다.

::figure{src="content/img/ml/ml04-regtree.svg" alt="회귀 트리는 x축을 몇 개 구간으로 나누고 구간마다 평균 높이의 가로선을 그어 계단 모양으로 예측한다" caption="회귀 트리는 x를 구간으로 나누고, 구간마다 그 안의 평균값을 예측합니다."}

```run
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeRegressor

df = pd.read_csv("ai4i2020.csv")
X_train, X_test, y_train, y_test = train_test_split(df[["rpm"]], df["torque"], test_size=0.25, random_state=0)
grid = pd.DataFrame({"rpm": np.linspace(1170, 2880, 400)})
fig, ax = plt.subplots(figsize=(6, 3.6))
ax.scatter(X_train["rpm"][:800], y_train[:800], s=5, alpha=0.3, color="gray")
for d in [1, 3, 5]:
    tree = DecisionTreeRegressor(max_depth=d, random_state=0).fit(X_train, y_train)
    ax.plot(grid["rpm"], tree.predict(grid), label=f"depth {d}")
    print(f"depth {d}: leaves {tree.get_n_leaves():>2}, train R^2 {tree.score(X_train, y_train):.3f}, test R^2 {tree.score(X_test, y_test):.3f}")
ax.set_xlabel("rpm"); ax.set_ylabel("torque"); ax.legend()
plt.tight_layout(); plt.show()
```

| 깊이 | 잎 수 | 시험 R² |
| --- | --- | --- |
| 1 | 2 | 0.554 |
| 3 | 8 | 0.826 |
| 5 | 32 | 0.847 |

깊이 d인 트리의 잎은 최대 2^d개이므로 계단도 최대 2^d칸입니다. 깊이 5(32칸)면 휘어진 곡선을 꽤 잘 따라가서, [다항회귀](#/l/ml-02-7)의 2차식(시험 R² 0.835)과 비슷한 수준이 됩니다. 곡선의 식을 몰라도 트리가 구간을 잘게 나눠 알아서 모양을 따라간다는 것이 트리의 장점입니다.

## 트리의 약점: 학습 범위 밖을 모른다

잎은 학습 데이터 값들의 평균이므로, 트리는 **학습 때 본 가장 작은 값보다 작게, 가장 큰 값보다 크게 예측할 수 없습니다.** 시험해 봅니다. 1,800rpm 미만 설비로만 학습하고, 2,200rpm 이상인 아주 빠른 설비 96대의 토크를 예측합니다. 실제 평균 토크는 13.71입니다.

```run
import pandas as pd
from sklearn.tree import DecisionTreeRegressor
from sklearn.ensemble import RandomForestRegressor
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import PolynomialFeatures, StandardScaler
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_absolute_error

df = pd.read_csv("ai4i2020.csv")
slow, fast = df[df["rpm"] < 1800], df[df["rpm"] >= 2200]
print("fast machines:", len(fast), "true mean torque:", round(fast["torque"].mean(), 2))
models = {
    "tree (depth 4)": DecisionTreeRegressor(max_depth=4, random_state=0),
    "random forest": RandomForestRegressor(200, min_samples_leaf=5, random_state=0),
    "polynomial (2)": make_pipeline(PolynomialFeatures(2), StandardScaler(), LinearRegression()),
}
for name, m in models.items():
    p = m.fit(slow[["rpm"]], slow["torque"]).predict(fast[["rpm"]])
    print(f"{name:>15}: predictions {p.min():5.2f} ~ {p.max():5.2f}, MAE {mean_absolute_error(fast['torque'], p):5.2f}")
```

- 트리는 96대 모두에 **27.56 하나만** 예측합니다. 가장 오른쪽 잎의 평균에 갇힌 것입니다. 숲(랜덤포레스트)도 24.45 한 값입니다.
- 2차식은 범위 밖에서도 곡선을 이어 그립니다. 처음에는 19.74까지 내려가다가, 아주 빠른 쪽에서는 포물선이 다시 고개를 들어 **49.93**까지 올라갑니다. 실제 토크는 계속 줄어드는데 말입니다. [다항회귀](#/l/ml-02-7)에서 봤듯 다항식의 외삽은 언제든 엉뚱한 방향으로 튈 수 있습니다.
- 평균 오차(MAE)는 트리 13.85, 2차식 12.75, 숲 10.75로 모두 실제 평균(13.71)만큼이나 틀립니다.

결론은 **"어떤 모델도 범위 밖은 믿기 어렵다"** 입니다. 트리는 평평하게 멈추고, 다항식은 엉뚱하게 튈 수 있습니다. 실무에서는 예측하려는 값이 학습 범위 안인지 먼저 확인하고, 범위 밖이 많아지면 [드리프트](#/l/ml-11-1)로 보고 모델을 다시 학습합니다.

## 실무 예제: 여러 특성으로 회전수 예측하기

특성이 여러 개일 때 회귀 트리의 장점이 더 잘 드러납니다. 온도 · 토크 · 공구 마모로 회전수를 예측합니다.

```run
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LinearRegression
from sklearn.tree import DecisionTreeRegressor
from sklearn.ensemble import RandomForestRegressor
from sklearn.metrics import mean_absolute_error

df = pd.read_csv("ai4i2020.csv")
X = df[["air_temp", "process_temp", "torque", "tool_wear"]]
y = df["rpm"]
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.25, random_state=0)
models = {
    "linear regression": LinearRegression(),
    "tree (depth 5)": DecisionTreeRegressor(max_depth=5, random_state=0),
    "random forest": RandomForestRegressor(200, min_samples_leaf=5, random_state=0),
}
for name, m in models.items():
    m.fit(X_train, y_train)
    print(f"{name:>17}: test R^2 {m.score(X_test, y_test):.3f}, MAE {mean_absolute_error(y_test, m.predict(X_test)):.1f} rpm")
```

| 모델 | 시험 R² | MAE (rpm) |
| --- | --- | --- |
| 선형회귀 | 0.768 | 59.3 |
| 회귀 트리 (깊이 5) | 0.919 | 40.8 |
| 랜덤포레스트 | 0.915 | 41.5 |

선형회귀는 토크와 회전수의 **휘어진** 관계를 직선으로 펴서 평균 59rpm씩 틀립니다. 트리는 휘어진 모양을 구간으로 따라가서 오차가 약 3분의 1 줄었습니다. 이번에는 숲이 트리 하나와 비슷한데, 실제로 중요한 열이 토크 하나뿐이라 트리 하나로도 충분했기 때문입니다. 특성이 많고 서로 얽혀 있을수록 숲의 이점이 커집니다([랜덤포레스트: 여러 트리의 투표](#/l/ml-04-3)).

## 자주 하는 실수

| 실수 | 무슨 일이 생기나 | 바로잡기 |
| --- | --- | --- |
| 숫자 정답에 `DecisionTreeClassifier`를 씀 | 토크 값 하나하나를 "종류"로 취급해 수천 개 클래스가 생김 | 숫자는 `...Regressor` |
| 회귀 트리 결과를 정확도(`accuracy`)로 평가 | 숫자가 소수점까지 정확히 같아야 맞힌 것으로 셈 | R², MAE, RMSE |
| 학습 범위 밖에서도 트리 예측을 그대로 믿음 | 평평한 값에 갇혀 체계적으로 틀림 (27.56 vs 실제 13.71) | 범위 확인, 재학습 |

## 정리

- **회귀 트리**는 잎에 모인 값들의 **평균**을 예측합니다. 질문은 **오차 제곱합(분산)** 을 가장 많이 줄이는 것으로 고릅니다.
- 예측은 계단 모양이고, 깊이 d면 계단은 최대 2^d칸입니다. 깊이 5에서 시험 R² 0.847로 2차 다항식(0.835)과 비슷했습니다.
- 트리 · 숲은 학습 범위 밖을 예측하지 못합니다(빠른 설비 96대에 27.56 하나만 예측). 범위 밖 예측은 어떤 모델이든 조심합니다.
- 회귀 · 분류를 가리지 않고 `DecisionTreeRegressor` · `RandomForestRegressor` · `HistGradientBoostingRegressor`처럼 이름 끝만 바꿔 씁니다.
