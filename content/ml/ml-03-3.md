## 시작하기 전에

앞 레슨에서 AI4I 설비 모델의 재현율이 약 0.28로 낮았습니다. 고장 10건 중 7건을 놓친 셈입니다. 모델을 새로 만들지 않고 이 숫자를 바꿀 방법이 있습니다. 확률을 1/0 판정으로 바꾸는 **기준선(임계값)** 을 움직이는 것입니다.

## 임계값: 경보 감도 조절

로지스틱 회귀는 확률을 내고, 기본으로 0.5 이상이면 1로 판정합니다. 이 기준선이 **임계값**입니다. 경보기 감도와 같습니다.

- 임계값을 **낮추면**: 조금만 의심돼도 울림 → 재현율↑, 헛경보도↑(정밀도↓)
- 임계값을 **올리면**: 확실할 때만 울림 → 정밀도↑, 놓침도↑(재현율↓)

::figure{src="content/img/ml/ml03-threshold.svg" alt="정상과 고장 장비의 확률 분포와 임계값 선" caption="두 무리가 겹치는 구간이 있어서, 선을 어디에 두든 놓침과 헛경보를 동시에 0으로 만들 수는 없습니다."}

::video{ref="dl-m11"}

```run
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import precision_score, recall_score

df = pd.read_csv("ai4i2020.csv")
X = df[["air_temp", "process_temp", "rpm", "torque", "tool_wear"]]
y = df["failure"]
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.25, random_state=0, stratify=y)
proba = make_pipeline(StandardScaler(), LogisticRegression()).fit(X_train, y_train).predict_proba(X_test)[:, 1]
for t in [0.5, 0.3, 0.1, 0.05]:
    pred = (proba >= t).astype(int)
    print(f"threshold {t:<4}: recall {recall_score(y_test, pred):.2f}  precision {precision_score(y_test, pred, zero_division=0):.2f}  alarms {pred.sum()}")
```

임계값을 0.1까지 내리면 고장의 대부분을 잡지만 경보 횟수가 크게 늘어납니다. 경보 한 번마다 점검 비용이 들기 때문에, **놓쳤을 때의 손해와 헛경보 비용을 비교해** 임계값을 정합니다.

### 직접 해보기

`threshold` 값을 0.5에서 시작해 0.4, 0.2, 0.08로 낮춰 보세요. 네 칸 숫자가 어떻게 옮겨 가는지 보면, 기준선을 낮출 때 FN(놓침)이 TP로, TN이 FP(헛경보)로 넘어가는 것이 보입니다.

```run
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import confusion_matrix

df = pd.read_csv("ai4i2020.csv")
X = df[["air_temp", "process_temp", "rpm", "torque", "tool_wear"]]
y = df["failure"]
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.25, random_state=0, stratify=y)
proba = make_pipeline(StandardScaler(), LogisticRegression()).fit(X_train, y_train).predict_proba(X_test)[:, 1]

threshold = 0.5   # <- change me
tn, fp, fn, tp = confusion_matrix(y_test, (proba >= threshold).astype(int)).ravel()
print(f"threshold {threshold}:  TP={tp}  FN={fn}  FP={fp}  TN={tn}")
```

## 임계값을 정하는 순서: 목표 재현율부터

"그럼 임계값을 몇으로 할까?"에는 보통 이렇게 답합니다. 현장과 먼저 **목표**를 정합니다. 예를 들어 "고장의 80%는 꼭 잡자(재현율 0.8 이상)"라고 정했다면, 그 조건을 만족하는 임계값 중 **가장 높은 값**(헛경보가 가장 적은 값)을 고릅니다.

이때 중요한 규칙이 있습니다. 임계값도 **모델의 설정값**이라서 시험용 데이터로 고르면 시험지를 미리 본 셈이 됩니다(ml-01-4). 그래서 학습용 안에서 **검증용**을 따로 떼어 고르고, 시험용으로는 마지막에 확인만 합니다.

```run
import numpy as np
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import precision_recall_curve, recall_score, precision_score

df = pd.read_csv("ai4i2020.csv")
X = df[["air_temp", "process_temp", "rpm", "torque", "tool_wear"]]
y = df["failure"]
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.25, random_state=0, stratify=y)
X_fit, X_val, y_fit, y_val = train_test_split(X_train, y_train, test_size=0.25, random_state=0, stratify=y_train)
model = make_pipeline(StandardScaler(), LogisticRegression()).fit(X_fit, y_fit)
prec, rec, thr = precision_recall_curve(y_val, model.predict_proba(X_val)[:, 1])
ok = np.where(rec[:-1] >= 0.8)[0]            # thresholds that keep recall >= 0.8
best = thr[ok[-1]]                             # the highest one among them
print("chosen threshold (from validation):", round(best, 3))

final = make_pipeline(StandardScaler(), LogisticRegression()).fit(X_train, y_train)
pred = (final.predict_proba(X_test)[:, 1] >= best).astype(int)
print("test recall:", round(recall_score(y_test, pred), 3), " precision:", round(precision_score(y_test, pred), 3), " alarms:", pred.sum(), "/", len(y_test))
```

- 검증용에서 재현율 0.8을 지키는 가장 높은 임계값은 약 **0.031**입니다. 0.5와 비교하면 아주 낮습니다.
- 시험용에서도 재현율 **0.80**이 그대로 나왔습니다. 검증용으로 고른 기준이 처음 보는 데이터에서도 통한다는 확인입니다.
- 대가로 정밀도는 0.13입니다. 2,500대 중 518번 경보가 울리고, 그중 진짜 고장은 약 8번에 1번꼴입니다.

이 결과를 현장에 그대로 가져가 "경보 518번 중 고장 68건을 잡는 대신 450번은 헛걸음입니다. 점검 한 번에 드는 비용과 고장 한 번의 손해를 비교하면 괜찮을까요?"라고 물어보는 것이 임계값을 정하는 실제 과정입니다. 모델이 더 좋아지면(ml-04 트리·숲, ml-08 불균형 처리) 같은 재현율에서 정밀도가 올라갑니다.

## 정리

- 임계값은 확률을 1/0 판정으로 바꾸는 기준선입니다(기본 0.5).
- 낮추면 재현율↑·정밀도↓, 올리면 정밀도↑·재현율↓. 한쪽을 얻으면 다른 쪽을 내주는 **줄다리기** 관계입니다.
- 기준선은 "놓쳤을 때의 손해 vs 헛경보 비용"으로 정합니다. 비용으로 정하는 방법은 ml-08-3에서 직접 해 봅니다.
- 목표 재현율(예: 0.8)을 먼저 정하고, 그 조건을 지키는 가장 높은 임계값을 **검증용**으로 고릅니다(0.031). 시험용으로 고르면 누수입니다.
