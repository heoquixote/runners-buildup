## 시작하기 전에

앞 레슨에서 교차검증으로 점수를 믿을 만하게 재는 법을 배웠습니다. 이번에는 그 점수를 이용해 `max_depth` 같은 **설정값을 고르는** 법을 배웁니다.

## 하이퍼파라미터: 사람이 정하는 설정값

모델이 데이터에서 **스스로 배우는 값**(트리의 질문, 회귀의 계수)과 달리, **사람이 학습 전에 정해 주는 값**이 있습니다. 이를 하이퍼파라미터라고 합니다.

- 결정트리의 `max_depth` (질문 단계 수)
- 랜덤포레스트의 `n_estimators` (트리 개수)
- KNN의 `n_neighbors` (참고할 이웃 수)

- 경사하강법의 학습률 `lr` ([모델은 어떻게 직선을 찾을까: 경사하강법](#/l/ml-02-3))

[깊어질수록 외운다: 과적합과 과소적합](#/l/ml-04-2)에서 봤듯이 너무 단순하게 정하면 **과소적합**, 너무 복잡하게 정하면 **과적합**입니다.

적당한 값을 찾아야 합니다. 그런데 후보를 고를 때 시험용 점수를 보면 안 되니([ML 워크플로와 데이터 준비](#/l/ml-01-1)의 "시험지는 마지막에 한 번"), 교차검증 점수로 고릅니다.

## GridSearchCV: 후보를 전부 시험해 보기

후보 값을 목록으로 주면, 후보마다 교차검증을 돌려 가장 좋은 것을 골라 줍니다. 마치 요리할 때 불 세기를 약·중·강으로 다 해 보고 제일 맛있는 것을 고르는 것과 같습니다.

```run
import pandas as pd
from sklearn.model_selection import train_test_split, GridSearchCV
from sklearn.tree import DecisionTreeClassifier

df = pd.read_csv("titanic.csv")
df["female"] = (df["sex"] == "female").astype(int)
df["age"] = df["age"].fillna(df["age"].median())
X = df[["pclass", "female", "age", "sibsp", "parch", "fare"]]
y = df["survived"]
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.25, random_state=0, stratify=y)

grid = GridSearchCV(DecisionTreeClassifier(random_state=0), {"max_depth": [1, 2, 3, 4, 5, 6, 8, None]}, cv=5)
grid.fit(X_train, y_train)
for p, s in zip(grid.cv_results_["params"], grid.cv_results_["mean_test_score"]):
    print(p, round(s, 3))
print("best:", grid.best_params_, " cv score:", round(grid.best_score_, 3))
print("final test score:", round(grid.score(X_test, y_test), 3))
```

중요한 순서:

1. GridSearchCV는 **학습용 데이터 안에서만** 교차검증해서 고릅니다.
2. 고른 설정으로 학습용 전체에 다시 학습합니다(자동).
3. 시험용 데이터로는 **마지막에 딱 한 번** 평가합니다.

> 시험 점수를 보면서 설정을 바꾸고 또 바꾸면, 결국 시험 문제에 맞춘 모델이 됩니다. 시험용 데이터는 끝까지 아껴 두세요.

후보가 아주 많으면 전부 시험하는 데 시간이 너무 오래 걸립니다. 그럴 때는 후보 중 일부만 무작위로 뽑아 시험하는 `RandomizedSearchCV`나, 앞 결과를 보고 다음 후보를 똑똑하게 고르는 Optuna 같은 도구를 씁니다. 원리는 똑같이 "교차검증 점수로 고른다"입니다.

## 설정값 두 개를 함께 고르기

설정값이 두 개면 후보는 **조합**으로 늘어납니다. `max_depth` 4개 × `min_samples_leaf` 4개 = 16가지 조합을 각각 5조각 교차검증하니 모델을 80번 학습합니다. 결과를 표로 펼치면 어떤 조합이 좋은지 한눈에 보입니다.

```run
import pandas as pd
from sklearn.model_selection import train_test_split, GridSearchCV
from sklearn.tree import DecisionTreeClassifier

df = pd.read_csv("titanic.csv")
df["female"] = (df["sex"] == "female").astype(int)
df["age"] = df["age"].fillna(df["age"].median())
X = df[["pclass", "female", "age", "sibsp", "parch", "fare"]]
y = df["survived"]
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.25, random_state=0, stratify=y)
params = {"max_depth": [3, 5, 7, 10], "min_samples_leaf": [1, 5, 10, 20]}
grid = GridSearchCV(DecisionTreeClassifier(random_state=0), params, cv=5).fit(X_train, y_train)
table = pd.DataFrame(grid.cv_results_).pivot_table(index="param_max_depth", columns="param_min_samples_leaf", values="mean_test_score")
print(table.round(3))
print("best:", grid.best_params_, " cv", round(grid.best_score_, 3), " test", round(grid.score(X_test, y_test), 3))
```

표의 행은 깊이, 열은 잎 최소 인원입니다. 읽는 요령은 이렇습니다.

- 깊이가 깊어질수록(아래로) `min_samples_leaf=1`인 왼쪽 칸은 점수가 떨어집니다. 깊게 키우고 브레이크도 없으면 외우기 때문입니다.
- 같은 깊이라도 `min_samples_leaf`를 5 정도로 주면 점수가 회복됩니다. **두 브레이크가 서로를 보완**한다는 것이 보입니다.
- 가장 좋은 조합의 교차검증 점수와 시험 점수가 비슷하면 고른 설정을 믿을 수 있습니다.

`pd.DataFrame(grid.cv_results_)`에는 조합마다 평균 점수, 표준편차, 순위(`rank_test_score`), 학습 시간까지 들어 있어서, 1등만 보지 말고 **비슷한 점수의 더 단순한 조합**이 있는지 찾는 데 씁니다.

## 무엇을 기준으로 고를까: scoring

GridSearchCV도 기본은 정확도로 고릅니다. 고장 데이터에서 기준을 바꾸면 고르는 깊이가 달라지는지 봅니다.

```run
import pandas as pd
from sklearn.model_selection import train_test_split, GridSearchCV, StratifiedKFold
from sklearn.tree import DecisionTreeClassifier

df = pd.read_csv("ai4i2020.csv")
X = df[["air_temp", "process_temp", "rpm", "torque", "tool_wear"]]
y = df["failure"]
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.25, random_state=0, stratify=y)
cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=0)
for scoring in ["accuracy", "recall", "f1"]:
    g = GridSearchCV(DecisionTreeClassifier(random_state=0), {"max_depth": [2, 3, 4, 6, 8, 12, None]}, cv=cv, scoring=scoring).fit(X_train, y_train)
    print(f"{scoring:>8} -> best {g.best_params_}  cv score {g.best_score_:.3f}")
```

정확도와 F1은 깊이 8을, 재현율은 깊이 제한 없음(`None`)을 골랐습니다. 재현율만 보면 "고장을 하나라도 더 잡는" 복잡한 트리가 유리하기 때문입니다. 대신 헛경보가 늘 수 있습니다. **기준을 무엇으로 하느냐가 곧 어떤 모델을 원하느냐**이므로, 그리드 서치를 돌리기 전에 현장과 함께 지표부터 정해야 합니다.

### 자주 하는 실수

| 실수 | 왜 문제인가 | 바로잡기 |
| --- | --- | --- |
| 전체 데이터로 GridSearchCV 후 같은 데이터로 점수 보고 | 고를 때 쓴 데이터로 채점 → 점수가 부풀려짐 | 시험용을 먼저 떼고 학습용으로만 그리드 서치 |
| `best_score_`를 최종 성능으로 보고 | 여러 후보 중 **가장 운 좋은** 점수라 조금 높게 나옴 | 시험용 점수(`grid.score(X_test, y_test)`)를 최종으로 |
| 후보를 너무 촘촘히, 너무 많이 | 시간이 오래 걸리고, 검증 조각에 과하게 맞춤 | 넓게 듬성듬성 → 좋은 근처만 촘촘히 |

### 직접 해보기

후보 목록 `depths`를 바꿔 보세요. 예를 들어 `[2, 3]`처럼 좁게 주면 더 좋은 후보를 놓칠 수 있고, `cv`를 3이나 10으로 바꾸면 평균 점수가 조금씩 달라집니다. 후보와 조각 수가 많을수록 시간이 오래 걸린다는 것도 느껴 보세요.

```run
import pandas as pd
from sklearn.model_selection import GridSearchCV
from sklearn.tree import DecisionTreeClassifier

df = pd.read_csv("titanic.csv")
df["female"] = (df["sex"] == "female").astype(int)
df["age"] = df["age"].fillna(df["age"].median())
X = df[["pclass", "female", "age", "sibsp", "parch", "fare"]]
y = df["survived"]

depths = [2, 3, 4, 5, 6]   # <- change me
cv = 5                     # <- change me
grid = GridSearchCV(DecisionTreeClassifier(random_state=0), {"max_depth": depths}, cv=cv).fit(X, y)
print("best:", grid.best_params_, " mean cv score:", round(grid.best_score_, 3))
```

## 정리

| 데이터 | 하는 일 |
| --- | --- |
| 학습용 | 모델 학습 + 교차검증으로 설정 고르기 |
| 시험용 | 최종 성능을 한 번만 확인 |

- 점수 하나는 운이 섞인다 → **교차검증 평균**을 본다
- 하이퍼파라미터는 GridSearchCV로 고른다. 설정값이 두 개면 조합 표(`pivot_table`)로 펼쳐 본다
- `scoring`을 바꾸면 고르는 값이 달라진다(정확도·F1 → 깊이 8, 재현율 → 제한 없음). 지표부터 정한다
