## 시작하기 전에

[KNN: 가까운 이웃에게 묻기](#/l/ml-10-1)의 KNN은 이웃으로, [나이브 베이즈: 확률을 곱해서 분류하기](#/l/ml-10-2)의 나이브 베이즈는 확률로 분류했습니다. 마지막으로 **경계선을 얼마나 여유 있게 긋느냐**에 집중하는 모델, **SVM(서포트 벡터 머신)** 을 배웁니다. 그리고 이 트랙에서 배운 모델들을 한자리에 모아 비교하며 "무엇부터 써 볼까"를 정리합니다.

## 가장 넓은 복도 내기

운동장에 두 반 학생이 섞이지 않게 서 있고, 그 사이에 줄을 하나 그어 반을 나눠야 한다고 해 봅시다. 나누는 줄은 여러 개 그을 수 있습니다. 그중 어떤 줄이 가장 좋을까요?

SVM의 답은 **양쪽 학생들과 가장 멀리 떨어진 줄**입니다. 줄 양옆으로 복도를 내는데, 그 복도 폭(**마진**)이 가장 넓어지도록 줄을 긋습니다. 복도가 넓을수록 새 학생이 조금 다른 자리에 서도 헷갈리지 않기 때문입니다.

::figure{src="content/img/ml/ml10-svm.svg" alt="두 무리 사이에 가장 넓은 복도를 내고 그 한가운데에 경계선을 긋는다. 복도 가장자리에 닿은 점이 서포트 벡터" caption="경계선은 복도 한가운데, 복도 가장자리에 닿은 점들(서포트 벡터)이 경계선의 위치를 정합니다."}

- **마진(margin)**: 경계선에서 가장 가까운 점까지의 거리(복도 폭의 절반)
- **서포트 벡터(support vector)**: 복도 가장자리에 닿은 점들. 경계선은 **이 점들만으로** 정해지고, 멀리 있는 점들은 경계선에 영향을 주지 않습니다. 이름이 여기서 나왔습니다.

현실 데이터는 깔끔하게 나뉘지 않으니, 복도 안에 몇 명쯤 들어오는 것은 봐줍니다. 얼마나 봐줄지를 `C`라는 설정값으로 정합니다. `C`가 크면 봐주지 않아 복도가 좁아지고(과적합 쪽), 작으면 많이 봐줘서 복도가 넓어집니다(과소적합 쪽).

## 타이타닉에 적용하기

SVM도 거리를 재므로 **표준화가 먼저**입니다.

```run
import pandas as pd
from sklearn.model_selection import cross_val_score, StratifiedKFold
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.svm import SVC

df = pd.read_csv("titanic.csv")
df["female"] = (df["sex"] == "female").astype(int)
df["age"] = df["age"].fillna(df["age"].median())
X = df[["pclass", "female", "age", "sibsp", "parch", "fare"]]
y = df["survived"]
cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=0)

model = make_pipeline(StandardScaler(), SVC(kernel="linear"))
print("linear SVM cv accuracy:", round(cross_val_score(model, X, y, cv=cv).mean(), 3))
model.fit(X, y)
print("support vectors per class:", model[-1].n_support_, "out of", len(X), "passengers")
```

891명 중 404명(사망 쪽 204, 생존 쪽 200)이 서포트 벡터입니다. 타이타닉은 깔끔하게 나뉘는 데이터가 아니라서 복도 근처나 안쪽에 있는 승객이 많기 때문입니다.

### C: 복도에 점이 들어와도 봐줄까

현실의 데이터는 두 무리가 조금씩 섞여 있어서, 모든 점을 복도 밖에 두는 경계선은 없습니다. 그래서 SVM은 "복도 안이나 반대편에 들어온 점"을 어느 정도 봐줍니다. 얼마나 봐줄지를 정하는 설정이 **C**입니다.

- C가 **작으면**: 많이 봐줌 → 넓은 복도, 단순한 경계 (과소적합 쪽)
- C가 **크면**: 거의 안 봐줌 → 좁은 복도, 점 하나하나에 맞춘 복잡한 경계 (과적합 쪽)

```run
import pandas as pd
from sklearn.model_selection import cross_validate, StratifiedKFold
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.svm import SVC

df = pd.read_csv("titanic.csv")
df["female"] = (df["sex"] == "female").astype(int)
df["age"] = df["age"].fillna(df["age"].median())
X = df[["pclass", "female", "age", "sibsp", "parch", "fare"]]
y = df["survived"]
cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=0)
for C in [0.01, 0.1, 1, 10, 100]:
    r = cross_validate(make_pipeline(StandardScaler(), SVC(C=C)), X, y, cv=cv, return_train_score=True)
    n_sv = make_pipeline(StandardScaler(), SVC(C=C)).fit(X, y)[-1].n_support_.sum()
    print(f"C={C:<5} train {r['train_score'].mean():.3f}  valid {r['test_score'].mean():.3f}  support vectors {n_sv}")
```

| C | 학습 | 검증 | 서포트 벡터 수 |
| --- | --- | --- | --- |
| 0.01 | 0.616 | 0.616 | 686 |
| 0.1 | 0.815 | 0.809 | 504 |
| 1 (기본) | 0.836 | **0.827** | 390 |
| 10 | 0.849 | 0.815 | 376 |
| 100 | 0.862 | 0.798 | 377 |

- C=0.01은 너무 많이 봐줘서 891명 중 686명이 서포트 벡터가 되고, 결국 "모두 사망"과 같은 0.616이 나옵니다(과소적합).
- C를 키울수록 학습 점수는 계속 오르지만 검증은 C=1에서 가장 높고 그 뒤로 떨어집니다(과적합). [과적합 레슨](#/l/ml-04-2)의 트리 깊이, [KNN](#/l/ml-10-1)의 k와 같은 모양입니다.

C도 하이퍼파라미터이므로 GridSearchCV로 고르며, rbf 커널을 쓸 때는 곡선이 얼마나 구불구불할지를 정하는 `gamma`와 함께 고르는 것이 보통입니다.

### 원리 한 걸음 더: 복도 폭은 2 ÷ ‖w‖

선형 SVM의 경계선은 `w·x + b = 0`이고, 복도의 양쪽 가장자리는 `w·x + b = +1`, `−1`입니다. 이 두 선 사이의 거리(복도 전체 폭)는 계산하면

`복도 폭 = 2 ÷ ‖w‖`  (‖w‖: 계수 묶음 w의 길이)

입니다. 그래서 "복도를 넓게"는 "**‖w‖를 작게**"와 같은 말입니다. SVM이 줄이는 값은 두 부분의 합입니다.

`½‖w‖² + C × Σ (복도를 침범한 정도)`

- 앞부분은 복도를 넓히려는 힘, 뒷부분은 침범한 점에 매기는 벌점입니다. 침범 정도는 **힌지 손실** max(0, 1 − y·(w·x + b))로 재며, 복도 밖에 제대로 선 점은 0입니다.
- C가 크면 벌점이 비싸서 복도를 좁혀서라도(‖w‖를 키워서라도) 침범을 줄입니다. 릿지 회귀의 벌점 λ와 반대 방향으로 생각하면 됩니다(C ≈ 1/λ).

펭귄 두 종(아델리, 턱끈)을 부리 길이와 깊이로 나누며 C에 따라 복도 폭이 어떻게 바뀌는지 봅니다.

```run
import numpy as np
import pandas as pd
from sklearn.preprocessing import StandardScaler
from sklearn.svm import SVC

pg = pd.read_csv("penguins.csv").dropna()
pg = pg[pg["species"].isin(["Adelie", "Chinstrap"])]
X = StandardScaler().fit_transform(pg[["bill_length_mm", "bill_depth_mm"]])
y = (pg["species"] == "Chinstrap").astype(int)
print("penguins:", len(y))
for C in [0.01, 0.1, 1, 100]:
    m = SVC(kernel="linear", C=C).fit(X, y)
    w = np.linalg.norm(m.coef_[0])
    inside = (np.abs(m.decision_function(X)) < 1).sum()
    print(f"C={C:<5} |w| {w:.2f}  corridor width {2 / w:.2f}  inside corridor {inside:>3}  support vectors {m.n_support_.sum():>3}  misclassified {(m.predict(X) != y).sum()}")
```

| C | ‖w‖ | 복도 폭 | 복도 안 점 | 서포트 벡터 | 틀린 점 |
| --- | --- | --- | --- | --- | --- |
| 0.01 | 0.85 | 2.36 | 128 | 128 | 10 |
| 0.1 | 1.75 | 1.14 | 52 | 54 | 7 |
| 1 | 3.00 | 0.67 | 23 | 23 | 7 |
| 100 | 6.24 | 0.32 | 10 | 12 | 5 |

C를 0.01에서 100으로 키우자 복도 폭이 2.36 → 0.32로 좁아지고, 복도 안의 점과 학습 데이터에서 틀린 점이 줄었습니다. 학습 데이터에는 딱 맞지만 경계가 몇몇 점에 끌려가는 쪽입니다. 어느 C가 좋은지는 위의 타이타닉 예처럼 검증 점수로 고릅니다.

## 직선으로 못 나눌 때: 커널

아래 데이터는 안쪽 원과 바깥 고리 모양입니다. 어떤 직선을 그어도 둘을 나눌 수 없습니다.

```run
import matplotlib.pyplot as plt
from sklearn.datasets import make_circles
from sklearn.model_selection import cross_val_score
from sklearn.svm import SVC

X, y = make_circles(n_samples=400, noise=0.1, factor=0.4, random_state=0)
for kernel in ["linear", "rbf"]:
    print(f"{kernel:>6} kernel: cv accuracy {cross_val_score(SVC(kernel=kernel), X, y, cv=5).mean():.3f}")

fig, ax = plt.subplots(figsize=(4, 4))
ax.scatter(X[:, 0], X[:, 1], c=y, s=10, cmap="coolwarm")
ax.set_title("Inner circle vs outer ring"); ax.set_aspect("equal")
plt.tight_layout(); plt.show()
```

직선 SVM(`linear`)은 0.547로 동전 던지기 수준이지만, `rbf` 커널은 **1.000**으로 완벽하게 나눕니다.

**커널(kernel)** 은 데이터를 더 높은 차원으로 들어 올려서 직선(평면)으로 나눌 수 있게 만드는 기법입니다. 종이 위에 섞인 두 색 구슬을 생각해 보세요. 가운데 구슬만 위로 튕겨 올리면, 공중에 판 하나를 끼워 넣어 위아래로 나눌 수 있습니다. 그 판을 다시 종이 위로 내려 보면 원 모양 경계선이 됩니다. `rbf`는 가장 많이 쓰는 커널이고 `SVC()`의 기본값입니다.

## 지금까지 배운 모델 한자리에 비교하기

같은 타이타닉 데이터, 같은 교차검증으로 지금까지 배운 모델을 모두 비교해 봅니다. (실행에 몇 초 걸립니다.)

```run
import pandas as pd
from sklearn.model_selection import cross_val_score, StratifiedKFold
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression
from sklearn.tree import DecisionTreeClassifier
from sklearn.ensemble import RandomForestClassifier, GradientBoostingClassifier
from sklearn.neighbors import KNeighborsClassifier
from sklearn.naive_bayes import GaussianNB
from sklearn.svm import SVC

df = pd.read_csv("titanic.csv")
df["female"] = (df["sex"] == "female").astype(int)
df["age"] = df["age"].fillna(df["age"].median())
X = df[["pclass", "female", "age", "sibsp", "parch", "fare"]]
y = df["survived"]
cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=0)
models = {
    "logistic regression": make_pipeline(StandardScaler(), LogisticRegression()),
    "decision tree (d=4)": DecisionTreeClassifier(max_depth=4, random_state=0),
    "random forest": RandomForestClassifier(n_estimators=200, min_samples_leaf=3, random_state=0),
    "gradient boosting": GradientBoostingClassifier(random_state=0),
    "knn (k=5)": make_pipeline(StandardScaler(), KNeighborsClassifier(n_neighbors=5)),
    "naive bayes": GaussianNB(),
    "svm (rbf)": make_pipeline(StandardScaler(), SVC()),
}
for name, m in models.items():
    print(f"{name:>20}: {cross_val_score(m, X, y, cv=cv).mean():.3f}")
```

| 랜덤포레스트 | 0.829 | |

차이가 생각보다 작습니다. 1등과 꼴찌가 4%p 차이입니다. 데이터와 특성이 같으면 모델을 바꿔서 얻는 이득은 크지 않은 경우가 많습니다. [새 특성 만들기: 피처 엔지니어링](#/l/ml-06-3)에서 본 것처럼 **좋은 특성을 만드는 것**이 모델 고르기보다 효과가 클 때가 많습니다.

## 어떤 모델부터 써 볼까

| 모델 | 표준화 | 해석 | 속도 | 잘 맞는 상황 |
| --- | --- | --- | --- | --- |
| 선형·로지스틱 회귀 | 필요 | 쉬움 (계수) | 빠름 | 기준 모델, 설명이 중요할 때 |
| 결정트리 | 불필요 | 아주 쉬움 (규칙) | 빠름 | 규칙을 사람에게 보여 줘야 할 때 |
| 랜덤포레스트 | 불필요 | 중간 (중요도) | 중간 | 표 데이터, 설정을 대충 해도 안정적 |
| 부스팅 (XGBoost·LightGBM) | 불필요 | 중간 | 중간 | 표 데이터에서 성능을 끝까지 올릴 때 |
| KNN | **필수** | 쉬움 (이웃) | 예측이 느림 | 데이터가 작고 "비슷한 사례"가 중요할 때 |
| 나이브 베이즈 | 불필요 | 쉬움 (확률) | 아주 빠름 | 텍스트 분류, 데이터가 적을 때 |
| SVM | **필수** | 어려움 | 데이터가 크면 느림 | 중간 크기 데이터, 복잡한 경계 |

실무에서 흔히 쓰는 순서는 이렇습니다.

1. **기준 모델**(DummyClassifier, [기준 모델과 누수](#/l/ml-01-5))로 최소선을 확인합니다.
2. **로지스틱 회귀**(회귀 문제면 선형회귀)로 빠르게 한 번 돌려 봅니다.
3. **랜덤포레스트나 부스팅**으로 성능을 올려 봅니다.
4. 차이가 작으면 **더 단순하고 설명하기 쉬운** 쪽을 고릅니다.
5. 모델보다 **특성과 데이터 품질**을 먼저 의심합니다.

## 정리

- SVM = 두 무리 사이에 **가장 넓은 복도(마진)** 를 내는 경계선. 경계선은 복도 가장자리의 **서포트 벡터**가 정합니다.
- 거리를 재므로 **표준화가 꼭** 필요하고, **커널(rbf)** 로 직선으로 못 나누는 데이터도 나눕니다(원·고리 0.547 → 1.000).
- C가 작으면 많이 봐줘서 과소적합(C=0.01: 0.616), 크면 과적합. 타이타닉에서는 기본값 C=1이 가장 좋았습니다(0.827).
- 같은 데이터에서 모델 간 차이는 생각보다 작습니다. 기준 모델 → 로지스틱 → 트리 앙상블 순서로 시도하고, 특성을 먼저 의심합니다.
