## 시작하기 전에

앞 레슨에서 k=3으로 설비 운전 상태를 묶었습니다. 그런데 왜 3이었을까요? 정답이 없으니 정확도로 고를 수도 없습니다. 이번 레슨에서는 그룹 수 k를 고르는 두 가지 도구, **엘보**와 **실루엣 점수**를 배웁니다.

## k는 몇 개로 해야 할까

k는 사람이 정해야 합니다. 정답이 없으니 "정확도"로 고를 수도 없습니다. 대신 두 가지를 봅니다.

- **inertia(관성)**: 각 점과 자기 깃발 사이 거리의 제곱을 모두 더한 값. 작을수록 촘촘합니다. 그런데 k를 늘리면 깃발이 많아지니 **무조건 줄어듭니다.** 그래서 값 자체보다, 줄어드는 폭이 확 꺾이는 지점(**엘보**, 팔꿈치)을 봅니다.
- **실루엣 점수**: "내 그룹 사람들과는 가깝고, 옆 그룹과는 먼가?"를 -1~1로 잰 값. **클수록** 잘 나뉜 것입니다.

::figure{src="content/img/ml/ml07-elbow.svg" alt="k에 따른 inertia 꺾은선과 엘보 지점" caption="k를 늘리면 inertia는 계속 줄지만, 줄어드는 폭이 확 작아지는 지점(엘보)이 후보입니다."}

```run
import pandas as pd
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score

df = pd.read_csv("ai4i2020.csv").sample(2000, random_state=0)
Xs = StandardScaler().fit_transform(df[["rpm", "torque"]])
for k in range(2, 7):
    km = KMeans(n_clusters=k, n_init=10, random_state=0).fit(Xs)
    print(f"k={k}  inertia={km.inertia_:7.1f}  silhouette={silhouette_score(Xs, km.labels_):.3f}")
```

inertia는 k=2→3에서 크게(1699→987) 줄고, 그 뒤로는 줄어드는 폭이 점점 작아집니다. 실루엣 점수는 k=2가 0.53으로 가장 높고 k=3이 0.48로 뒤따릅니다. 숫자로는 k=2가 조금 낫지만, 앞에서 본 것처럼 k=3이 **고장 위험이 높은 운전 영역**을 따로 떼어 주어 현장에서 더 쓸모가 있습니다. 이렇게 k는 점수 하나로 정하기보다 **엘보·실루엣·해석하기 쉬운지**를 함께 보고 고릅니다.

### 직접 해보기

`k`를 2, 4, 5로 바꿔 그려 보세요. k가 몇이든 K-means는 점들을 그 수만큼 **반드시** 나눕니다. 그래서 "몇 개로 나눌지"는 그림과 점수, 현장에서의 쓸모를 함께 보고 사람이 정해야 합니다.

```run
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans

df = pd.read_csv("ai4i2020.csv").sample(2000, random_state=0)
Xs = StandardScaler().fit_transform(df[["rpm", "torque"]])

k = 3   # <- change me
df["cluster"] = KMeans(n_clusters=k, n_init=10, random_state=0).fit_predict(Xs)
print(df.groupby("cluster")["failure"].mean().round(3))
plt.figure(figsize=(6, 4))
plt.scatter(df["rpm"], df["torque"], c=df["cluster"], s=8, cmap="viridis")
plt.xlabel("rpm"); plt.ylabel("torque (Nm)"); plt.title(f"K-means clusters (k={k})")
plt.show()
```

## 실루엣 점수는 어떻게 계산될까

점 하나에 대해 두 거리를 잽니다.

- **a**: 같은 그룹 친구들까지의 평균 거리 (작을수록 좋음)
- **b**: 가장 가까운 **옆 그룹** 사람들까지의 평균 거리 (클수록 좋음)

`실루엣 = (b − a) / (a와 b 중 큰 값)`

| 값 | 뜻 |
| --- | --- |
| 1에 가까움 | 우리 그룹과는 아주 가깝고 옆 그룹과는 멂 → 잘 묶임 |
| 0 근처 | 두 그룹 경계에 걸쳐 있음 |
| 음수 | 오히려 옆 그룹에 더 가까움 → 잘못 묶였을 수 있음 |

`silhouette_score`는 모든 점의 실루엣을 평균 낸 값입니다.

## 점 하나하나의 실루엣 보기

`silhouette_score`는 평균 하나만 줍니다. `silhouette_samples`로 점마다의 값을 받으면, **어느 그룹이 잘 묶였고 어느 점이 애매한지** 보입니다.

```run
import pandas as pd
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_samples

df = pd.read_csv("ai4i2020.csv").sample(2000, random_state=0)
Xs = StandardScaler().fit_transform(df[["rpm", "torque"]])
df["cluster"] = KMeans(n_clusters=3, n_init=10, random_state=0).fit_predict(Xs)
df["sil"] = silhouette_samples(Xs, df["cluster"])
print(df.groupby("cluster").agg(size=("sil", "size"), mean_sil=("sil", "mean"),
                                negative=("sil", lambda s: (s < 0).sum()),
                                rpm=("rpm", "mean"), torque=("torque", "mean")).round(3))
print("overall:", round(df["sil"].mean(), 3))
```

- 세 그룹의 평균 실루엣이 0.46~0.49로 고르고, 전체 평균은 0.481입니다(앞의 `silhouette_score`와 같은 값).
- 실루엣이 **음수인 점**(옆 그룹에 더 가까운 점)은 2,000개 중 5개뿐입니다.

한 그룹만 평균 실루엣이 유난히 낮거나 음수인 점이 몰려 있다면, 그 그룹은 억지로 만든 그룹일 가능성이 큽니다. k를 바꾸거나 그 그룹을 합치는 것을 고려합니다.

### 자주 하는 실수

| 실수 | 왜 문제인가 | 바로잡기 |
| --- | --- | --- |
| inertia가 가장 작은 k를 고름 | k를 늘리면 inertia는 **항상** 줄어서, 늘 가장 큰 k가 뽑힘 | 엘보(꺾이는 곳)와 실루엣을 봄 |
| 그룹 번호 0, 1, 2에 의미를 둠 | 다시 실행하거나 `random_state`를 바꾸면 번호가 바뀜 | 그룹 평균(중심)을 보고 이름을 붙임 |
| 그룹이 생겼으니 "유형이 3가지 있다"고 결론 | K-means는 구조가 없어도 k개로 나눔 | 실루엣·현장 지표로 그룹이 의미 있는지 확인 |

## 정리

- k는 사람이 정합니다. **엘보**(inertia가 줄어드는 폭이 꺾이는 곳)와 **실루엣 점수**(클수록 잘 나뉨)를 함께 봅니다.
- 점수만이 아니라 **해석하기 쉬운지, 현장에서 쓸모 있는지**도 기준입니다(k=3이 위험 영역을 따로 떼어 줌).
