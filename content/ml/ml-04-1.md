## 결정트리: 스무고개로 예측하기

스무고개 놀이를 떠올려 봅시다. "동물인가요?" → "네 발인가요?" → … 질문을 이어 가며 답을 좁혀 갑니다.

**결정트리**도 똑같이 예/아니오 질문을 이어 붙여 예측합니다. 다른 점은 **어떤 질문을 어떤 순서로 할지 데이터를 보고 스스로 정한다**는 것입니다. 매 단계에서 "이 질문으로 나누면 두 그룹이 가장 깔끔하게 갈린다"는 질문을 고릅니다.

- 맨 위 질문: **뿌리(root)**
- 질문으로 갈라지는 갈래: **가지(branch)**
- 더 이상 나누지 않는 끝: **잎(leaf)**, 여기서 최종 답을 냄

## 타이타닉 트리를 직접 읽어 보기

깊이(질문 단계 수)를 2로 제한한 작은 트리를 만들고 규칙을 글로 출력해 봅니다.

```run
import pandas as pd
from sklearn.tree import DecisionTreeClassifier, export_text

df = pd.read_csv("titanic.csv")
df["female"] = (df["sex"] == "female").astype(int)
df["age"] = df["age"].fillna(df["age"].median())
features = ["pclass", "female", "age", "fare"]
tree = DecisionTreeClassifier(max_depth=2, random_state=0).fit(df[features], df["survived"])
print(export_text(tree, feature_names=features))
```

읽는 법:

- 첫 질문은 `female <= 0.5`(남성인가?)입니다. 성별이 생존을 가장 잘 가르는 질문이라는 뜻입니다.
- 남성 쪽에서는 나이(`age`)로 한 번 더 나눠 6.5세 이하 어린이면 생존으로 봅니다. "여성과 어린이 먼저"가 그대로 보입니다.
- 여성 쪽에서는 객실 등급(`pclass`)으로 나눠 1·2등실이면 생존, 3등실이면 사망으로 봅니다.
- `class: 1`이면 생존, `class: 0`이면 사망으로 예측합니다.

사람이 그대로 읽을 수 있는 규칙이 나온다는 것이 결정트리의 가장 큰 장점입니다.

### 잎마다 몇 명이 있었나

`show_weights=True`를 주면 잎마다 **[사망, 생존] 인원**이 함께 나옵니다. 이 숫자가 곧 트리가 내는 확률의 근거입니다. 그리고 새 승객 세 명을 트리에 넣어 길을 따라가 봅니다.

```run
import pandas as pd
from sklearn.tree import DecisionTreeClassifier, export_text

df = pd.read_csv("titanic.csv")
df["female"] = (df["sex"] == "female").astype(int)
df["age"] = df["age"].fillna(df["age"].median())
features = ["pclass", "female", "age", "fare"]
tree = DecisionTreeClassifier(max_depth=2, random_state=0).fit(df[features], df["survived"])
print(export_text(tree, feature_names=features, show_weights=True))

people = pd.DataFrame({"pclass": [3, 1, 3], "female": [1, 0, 0], "age": [25, 40, 5], "fare": [8.0, 60.0, 20.0]})
print(people.assign(prob=tree.predict_proba(people)[:, 1].round(3), pred=tree.predict(people)))
```

| 승객 | 지나가는 길 | 도착한 잎 [사망, 생존] | 생존 확률 |
| --- | --- | --- | --- |
| 3등실 25세 여성 | 여성 → 3등실 | [72, 72] | 72 / 144 = **0.5** |
| 1등실 40세 남성 | 남성 → 6.5세 초과 | [460, 93] | 93 / 553 = **0.168** |
| 3등실 5세 남자아이 | 남성 → 6.5세 이하 | [8, 16] | 16 / 24 = **0.667** |

트리의 확률은 **"나와 같은 잎에 떨어진 학습 승객 중 생존자 비율"**입니다. 1등실 남성인데 확률이 낮은 이유는, 이 작은 트리가 남성 쪽에서는 객실 등급을 묻지 않았기 때문입니다. 3등실 여성 잎은 생존·사망이 72명씩 정확히 반반이라, 이 트리로는 판단이 안 되는 집단입니다. 깊이를 늘리면 이 잎을 더 나눌 수 있습니다.

## 질문은 어떻게 고를까: 지니 불순도

트리는 첫 질문으로 왜 성별을 골랐을까요? 후보 질문마다 "나눈 뒤 각 그룹이 얼마나 **한쪽으로 깔끔하게** 모였나"를 점수로 매겨, 가장 깔끔한 질문을 고르기 때문입니다.

그 점수가 **지니 불순도(Gini impurity)** 입니다. 상자 안에 생존자와 사망자가 얼마나 **섞여 있나**를 0~0.5로 나타냅니다.

`지니 = 1 − (생존 비율)² − (사망 비율)²`

| 상자 안 | 생존 비율 | 지니 | 뜻 |
| --- | --- | --- | --- |
| 전부 생존 | 1.0 | 1 − 1 − 0 = **0** | 완전히 깔끔 |
| 반반 | 0.5 | 1 − 0.25 − 0.25 = **0.5** | 가장 섞임 |
| 타이타닉 전체 | 0.384 | 약 **0.473** | 꽤 섞여 있음 |

::figure{src="content/img/ml/ml04-gini.svg" alt="반반 섞인 상자는 지니 0.5, 조금 섞인 상자는 0.375, 한쪽만 있는 상자는 0" caption="상자 안이 한쪽으로 깔끔하게 모일수록 지니 불순도가 0에 가까워집니다."}

후보 질문 세 개로 나눠 보고, 나눈 뒤 두 그룹의 지니를 **인원 비율로 가중 평균**해 비교합니다.

```run
import pandas as pd

df = pd.read_csv("titanic.csv")
df["age"] = df["age"].fillna(df["age"].median())

def gini(s):
    p = s.mean()                  # survival rate in this box
    return 1 - p ** 2 - (1 - p) ** 2

print("before split: gini", round(gini(df["survived"]), 3))
questions = {"female?": df["sex"] == "female", "1st class?": df["pclass"] == 1, "age <= 6.5?": df["age"] <= 6.5}
for name, yes in questions.items():
    a, b = df.loc[yes, "survived"], df.loc[~yes, "survived"]
    after = (len(a) * gini(a) + len(b) * gini(b)) / len(df)
    print(f"{name:>12} yes {len(a):>3} (gini {gini(a):.3f}) | no {len(b):>3} (gini {gini(b):.3f}) -> weighted {after:.3f}")
```

나누기 전 지니는 0.473입니다.

- "여성인가?"로 나누면 0.333으로 가장 많이 줄어듭니다(여성 74% 생존, 남성 19% 생존으로 깔끔하게 갈림).
- "1등실인가?"는 0.434, "6.5세 이하인가?"는 0.462로 덜 줄어듭니다.

그래서 트리는 첫 질문으로 성별을 고릅니다. 다음 단계에서는 나뉜 각 그룹 안에서 같은 계산을 다시 해서 다음 질문을 고릅니다. 숫자 열(나이·운임)은 가능한 기준값(6.5, 7.0, …)을 전부 시험해 보고 가장 좋은 값을 고릅니다.

> 지니 대신 **엔트로피**(`criterion="entropy"`)를 쓰기도 합니다. 섞임 정도를 재는 다른 공식이고, 대부분 비슷한 트리가 나옵니다.

## 공장 데이터로 트리 만들기

같은 방법으로 AI4I 설비 데이터에 깊이 2인 트리를 만들어 고장 규칙을 읽어 봅니다.

```run
import pandas as pd
from sklearn.tree import DecisionTreeClassifier, export_text

df = pd.read_csv("ai4i2020.csv")
features = ["air_temp", "process_temp", "rpm", "torque", "tool_wear"]
tree = DecisionTreeClassifier(max_depth=2, random_state=0).fit(df[features], df["failure"])
print(export_text(tree, feature_names=features, show_weights=True))
```

트리가 찾은 규칙을 말로 옮기면 이렇습니다.

- 토크가 **65Nm를 넘고** 회전수가 1,228rpm보다 높으면 → 55대 중 50대가 고장(약 91%)
- 토크가 **13.15Nm 이하로 아주 낮으면** → 30대 중 27대가 고장(90%)
- 그 밖(토크 13~65Nm)은 9,905대 중 258대만 고장(약 2.6%)

"토크가 너무 크거나 너무 작으면 위험하다"는 규칙을 데이터에서 스스로 찾아냈습니다. 직선 하나로 예측하는 로지스틱 회귀는 "토크가 클수록 위험" 또는 "작을수록 위험" 중 한 방향만 표현할 수 있어서 이런 **양쪽 끝이 위험한 패턴**을 잡기 어렵습니다. 트리는 기준값으로 구간을 나누기 때문에 이런 패턴에 강합니다.

> 트리 규칙은 현장 담당자와 함께 읽어 보기 좋습니다. "토크 65Nm 이상이면 위험"이 현장 경험과 맞는지 확인하면, 모델이 엉뚱한 것을 배우지 않았는지 점검할 수 있습니다.

## 정리

- 결정트리는 예/아니오 질문을 이어 붙여 예측하고, 규칙을 사람이 그대로 읽을 수 있습니다.
- 질문은 **나눈 뒤 섞임(지니 불순도)이 가장 많이 줄어드는** 것으로 고릅니다.
- 타이타닉에서는 성별 질문이 지니를 0.473 → 0.333으로 가장 많이 줄였습니다.
- 트리의 확률 = 같은 잎에 떨어진 학습 사례 중 1의 비율입니다(3등실 여성 잎 72 / 144 = 0.5).
- 트리는 구간으로 나누므로 "토크가 너무 크거나 너무 작으면 고장" 같은 양쪽 끝 패턴도 잡습니다.
