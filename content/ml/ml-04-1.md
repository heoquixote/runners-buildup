## 결정트리: 예/아니오 질문 쌓기

"온도 > 54℃?" → "전류밀도 > 3.2?" 처럼 데이터를 가장 잘 나누는 질문을 차례로 고릅니다. 사람이 읽을 수 있는 규칙이 나오는 것이 장점입니다.

::video{ref="dl-m23"}

```run
import numpy as np
from sklearn.tree import DecisionTreeClassifier, export_text

i = np.arange(80)
temp = 52 + 4 * np.sin(i * 0.37)
cur = 3 + 0.6 * np.cos(i * 0.53)
X = np.column_stack([temp, cur])
y = ((temp > 54) & (cur > 2.8)).astype(int)
tree = DecisionTreeClassifier(max_depth=2, random_state=0).fit(X, y)
print(export_text(tree, feature_names=["temp", "current"]))
print("중요도", tree.feature_importances_.round(3))
```

## 깊이와 과적합

깊이 제한이 없으면 트리는 학습 데이터를 거의 외웁니다. 학습 정확도는 1.0이 되지만 새 데이터에서는 떨어집니다.

::video{ref="dl-m10"}

```run
import numpy as np
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier

i = np.arange(200)
X = np.column_stack([np.sin(i * 0.37), np.cos(i * 0.53)])
y = ((X[:, 0] + X[:, 1] + 0.8 * np.sin(i * 3.3)) > 0.3).astype(int)
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.3, random_state=0)
for d in [1, 2, 3, 5, 8, None]:
    m = DecisionTreeClassifier(max_depth=d, random_state=0).fit(X_tr, y_tr)
    print(f"depth {str(d):>4}  train {m.score(X_tr, y_tr):.2f}  test {m.score(X_te, y_te):.2f}")
```

## 랜덤포레스트: 숲의 투표

데이터를 무작위로 뽑고(부트스트랩), 질문 후보 피처도 무작위로 고른 트리 수십~수백 개의 다수결입니다. 트리 하나의 우연한 실수가 상쇄되어 더 안정적입니다.

```run
import numpy as np
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier
from sklearn.ensemble import RandomForestClassifier

i = np.arange(200)
X = np.column_stack([np.sin(i * 0.37), np.cos(i * 0.53), np.sin(i * 1.7)])
y = ((X[:, 0] + X[:, 1] + 0.8 * np.sin(i * 3.3)) > 0.3).astype(int)
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.3, random_state=0)
tree = DecisionTreeClassifier(random_state=0).fit(X_tr, y_tr)
forest = RandomForestClassifier(n_estimators=100, random_state=0).fit(X_tr, y_tr)
print("트리 test", round(tree.score(X_te, y_te), 3), " 포레스트 test", round(forest.score(X_te, y_te), 3))
print("포레스트 중요도", forest.feature_importances_.round(3), "(세 번째 열은 잡음)")
```

> 테스트 세트 하나에서는 트리가 포레스트보다 높게 나올 때도 있습니다. 테스트 30%는 60개뿐이라 한두 개 차이로 순위가 바뀝니다. 그래서 모델 비교는 여러 번 나눠 평균을 보는 교차검증으로 합니다(다음 코스).

> 트리 계열은 값의 크기 비교만 하므로 표준화가 필요 없습니다. 대신 `random_state`를 고정해야 결과가 재현됩니다.
