## 시작하기 전에

앞 레슨에서 빈칸을 채웠습니다. 남은 문제는 **글자**입니다. `male` / `female`, `S` / `C` / `Q`처럼 글자로 된 범주형 열은 모델이 계산할 수 없습니다. 이번 레슨에서는 범주의 모양(두 종류인지, 순서가 있는지)에 따라 알맞게 숫자로 바꾸는 법을 배우고, 마지막에 모델에 넣을 X와 y를 완성합니다.

## 인코딩: 글자를 숫자로 바꾸기

**인코딩(encoding)**은 글자로 된 범주를 모델이 계산할 수 있는 숫자로 바꾸는 일입니다. 범주가 몇 종류인지, 순서가 있는지에 따라 방법이 다릅니다.

### 값이 두 종류일 때: 0과 1로

성별처럼 값이 두 가지뿐이면 한쪽을 1, 다른 쪽을 0으로 바꾸면 됩니다. 두 가지 방법이 있고 결과는 같습니다.

```run
import pandas as pd

df = pd.read_csv("titanic.csv")
df["female"] = (df["sex"] == "female").astype(int)         # way 1: True/False -> 1/0
df["sex_num"] = df["sex"].map({"male": 0, "female": 1})   # way 2: a lookup table
print(df[["sex", "female", "sex_num"]].head())
```

- 방법 1: `df["sex"] == "female"`은 여성이면 True, 아니면 False입니다. `.astype(int)`로 True → 1, False → 0이 됩니다.
- 방법 2: `map({...})`은 "이 글자는 이 숫자로" 바꾸는 **대응표**를 직접 줍니다.

열 이름을 `female`처럼 지어 두면 "1이면 여성"이라는 뜻이 바로 읽혀서 좋습니다.

### 값이 여러 종류일 때: 번호를 매기면 생기는 문제

탑승 항구 `embarked`는 `S`(사우샘프턴), `C`(셰르부르), `Q`(퀸스타운) 세 가지입니다. 똑같이 대응표로 0, 1, 2를 매겨 볼까요? 이것을 **라벨 인코딩(label encoding)**이라고 합니다.

```run
import pandas as pd

df = pd.read_csv("titanic.csv")
df["embarked_num"] = df["embarked"].map({"S": 0, "C": 1, "Q": 2})
print(df[["embarked", "embarked_num"]].dropna().drop_duplicates().astype({"embarked_num": int}))
```

문제는 모델이 이 숫자를 **크기**로 읽는다는 것입니다. "Q(2)는 C(1)의 두 배", "S와 Q의 평균은 C" 같은, 현실에는 없는 관계가 생깁니다. 항구 사이에는 순서도 크기도 없는데 말입니다.

::figure{src="content/img/ml/ml01-encoding.svg" alt="라벨 인코딩과 원-핫 인코딩 비교" caption="번호를 매기면 가짜 크기 관계가 생기고, 원-핫은 범주마다 0/1 열을 따로 만들어 이 문제를 피합니다."}

반대로 **진짜 순서가 있는** 범주라면 번호가 자연스럽습니다. 객실 등급 `pclass`(1등실 < 2등실 < 3등실)가 처음부터 1, 2, 3 숫자로 들어 있는 이유입니다. 이렇게 순서를 지켜 번호를 매기는 것을 **순서 인코딩(ordinal encoding)**이라고 합니다.

### 순서가 없을 때: 원-핫 인코딩

순서 없는 범주는 **종류마다 0/1 열을 하나씩** 만듭니다. 이것이 **원-핫 인코딩(one-hot encoding)**입니다. "hot"은 켜졌다는 뜻으로, 여러 칸 중 **딱 한 칸만 1(켜짐)**이 됩니다. 출석부에서 해당하는 칸에만 동그라미를 치는 것과 같습니다.

```run
import pandas as pd

df = pd.read_csv("titanic.csv")
onehot = pd.get_dummies(df["embarked"], prefix="embarked", dtype=int)
print(pd.concat([df["embarked"], onehot], axis=1).head())
```

`embarked_C`, `embarked_Q`, `embarked_S` 세 열이 생기고, 승객마다 자기 항구 칸만 1입니다. 이제 숫자 사이에 가짜 크기 관계가 없습니다.

### 언제 무엇을 쓸까

| 범주의 모양 | 예 | 방법 | 코드 |
| --- | --- | --- | --- |
| 두 종류 | 성별, 합격/불합격 | 0/1로 바꾸기 | `(df["sex"] == "female").astype(int)` |
| 여러 종류, **순서 있음** | 객실 등급, 학년, 제품 등급 L<M<H | 순서대로 번호 | `map({"L": 0, "M": 1, "H": 2})` |
| 여러 종류, **순서 없음** | 탑승 항구, 혈액형, 색깔 | 원-핫 | `pd.get_dummies(...)` |
| 종류가 아주 많음 | 우편번호, 상품 ID, 설비 번호 | 원-핫을 하면 열이 수백 개 → 자주 나오는 것만 남기거나 **타깃 인코딩**(종류별 정답 평균으로 바꾸기) | [도구로 빈칸 채우고 글자 바꾸기](#/l/ml-06-1)에서 `TargetEncoder` |

## 모델에 넣을 X와 y 만들기

이제 손질한 열을 모아 X와 y를 만듭니다. 빈칸 채우기 → 0/1 바꾸기 → 원-핫 → 열 고르기 순서입니다.

```run
import pandas as pd

df = pd.read_csv("titanic.csv")
df["age"] = df["age"].fillna(df["age"].median())
df["embarked"] = df["embarked"].fillna(df["embarked"].mode()[0])
df["female"] = (df["sex"] == "female").astype(int)
df = pd.concat([df, pd.get_dummies(df["embarked"], prefix="embarked", dtype=int)], axis=1)

features = ["pclass", "female", "age", "fare", "embarked_C", "embarked_Q", "embarked_S"]
X = df[features].values
y = df["survived"].values
print("X shape:", X.shape)      # 891 passengers, 7 features
print("first passenger:", X[0], "-> survived?", y[0])
```

891명, 특성 7개짜리 숫자 표가 완성되었습니다. 첫 승객은 3등실, 남성(0), 22살, 운임 7.25, 사우샘프턴 탑승(`embarked_S`=1)이고 생존하지 못했습니다(0). 이제 모델이 먹을 수 있는 모양이 되었습니다.

## 정리

- 두 종류 → 0/1, 순서 있는 여러 종류 → 순서대로 번호, 순서 없는 여러 종류 → **원-핫**
- 순서 없는 범주에 0, 1, 2를 매기면(라벨 인코딩) 모델이 **가짜 크기 관계**를 배웁니다.
- 결측치 처리 + 인코딩을 마치면 모델이 먹을 수 있는 숫자 표(X)와 정답(y)이 됩니다.
