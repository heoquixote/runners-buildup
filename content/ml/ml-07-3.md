[비지도 학습: 군집](#/l/ml-07-1) 코스에서는 비슷한 **행**끼리 묶었습니다. 이 코스에서는 비지도 학습의 다른 두 가지 일을 배웁니다. 많은 **열**을 몇 개로 요약하는 **차원 축소**(PCA, [t-SNE](#/l/ml-13-1))와, 무리에서 벗어난 행을 찾는 [이상 탐지](#/l/ml-07-4)입니다. 먼저 가장 기본 도구인 PCA입니다.

## PCA: 여러 열을 몇 개로 요약하기

이번에는 열이 많은 데이터를 봅니다. sklearn에 들어 있는 **와인 데이터**는 와인 178병의 알코올, 산도, 색 진하기 등 **13개 성분**을 측정한 표입니다. 13개 열을 한 그래프에 그릴 수는 없죠. 그래서 13개를 **2개의 새 축으로 요약**합니다. 이것이 **PCA(주성분 분석)**입니다.

비유하면 이렇습니다. 학생의 국어·영어·사회 점수는 서로 비슷하게 움직이고, 수학·물리·화학 점수도 비슷하게 움직입니다. 그렇다면 6과목을 "문과 점수", "이과 점수" 두 숫자로 요약해도 정보를 크게 잃지 않습니다. PCA는 이 요약 축을 데이터에서 자동으로 찾습니다.

- **첫 번째 주성분(PC1)**: 데이터가 **가장 넓게 퍼진 방향**. 정보를 가장 많이 담습니다.
- **두 번째 주성분(PC2)**: PC1과 수직이면서, 남은 것 중 가장 넓게 퍼진 방향.

::figure{src="content/img/ml/ml07-pca.svg" alt="길쭉한 점구름 위에 가장 넓게 퍼진 방향 PC1과 그에 수직인 PC2 화살표" caption="PC1은 점들이 가장 넓게 퍼진 방향, PC2는 그와 수직인 방향입니다."}

::video{ref="dl-m26"}

```run
from sklearn.datasets import load_wine
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA

wine = load_wine()
X = wine.data
print("original shape:", X.shape)

Xs = StandardScaler().fit_transform(X)
pca = PCA(n_components=2).fit(Xs)
Z = pca.transform(Xs)
print("after PCA:", Z.shape)
print("explained variance ratio:", pca.explained_variance_ratio_.round(3))
print("total kept:", round(float(pca.explained_variance_ratio_.sum()), 3))
```

- PCA도 퍼진 정도(분산)를 재기 때문에 **표준화가 먼저**입니다.
- `explained_variance_ratio_`: 각 축이 원래 정보(분산)의 몇 %를 담았는지입니다. 13개 열을 2개로 줄였는데도 절반 넘게 남아 있습니다.

### 축을 몇 개 남길까

2개로 줄이면 그림은 그릴 수 있지만 정보가 절반쯤 사라졌습니다. 그림이 목적이 아니라면 **누적 설명 분산**(앞에서부터 축을 더해 가며 원래 정보를 몇 % 담았는지)을 보고, 보통 80~90%를 넘는 지점까지 남깁니다.

```run
import numpy as np
from sklearn.datasets import load_wine
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA

Xs = StandardScaler().fit_transform(load_wine().data)
pca = PCA().fit(Xs)
cum = np.cumsum(pca.explained_variance_ratio_)
for k in range(1, 9):
    print(f"{k} components -> {cum[k - 1]:.1%} kept")
```

와인 데이터는 축 5개면 80%, 7개면 89%를 담습니다. 13개 열을 7개로 줄여도 정보의 90% 가까이가 남는다는 뜻입니다.

## 요약한 2개 축으로 그려 보기

와인에는 실제로 품종(3종류) 정보가 있습니다. PCA를 할 때는 품종을 쓰지 않았지만, 그림에 색으로만 칠해 보면 요약이 잘 됐는지 볼 수 있습니다.

```run
import matplotlib.pyplot as plt
from sklearn.datasets import load_wine
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA

wine = load_wine()
Z = PCA(n_components=2).fit_transform(StandardScaler().fit_transform(wine.data))

plt.figure(figsize=(6, 4))
for k, name in enumerate(wine.target_names):
    m = wine.target == k
    plt.scatter(Z[m, 0], Z[m, 1], s=12, label=name)
plt.xlabel("PC1")
plt.ylabel("PC2")
plt.title("Wine: 13 features -> 2 components")
plt.legend()
plt.show()
print("each wine is now 2 numbers:", Z.shape)
```

세 품종이 2차원 그림에서 꽤 깔끔하게 나뉘어 보입니다. 13개 열을 한눈에 볼 수 없던 데이터를, 정답 없이 요약했는데도 구조가 보이는 것입니다.

## 새 축은 무엇으로 만들어졌나

"PC1은 이름이 없다"고 했지만, 원래 13개 열을 **얼마씩 섞었는지**(`components_`)를 보면 대략의 뜻을 붙일 수 있습니다.

```run
import pandas as pd
from sklearn.datasets import load_wine
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA

wine = load_wine()
pca = PCA(n_components=2).fit(StandardScaler().fit_transform(wine.data))
weights = pd.DataFrame(pca.components_.T, index=wine.feature_names, columns=["PC1", "PC2"])
print(weights.round(2).sort_values("PC1"))
```

- **PC1**에 크게 +로 들어간 열은 `flavanoids`(0.42), `total_phenols`(0.39), `od280/od315`(0.38)입니다. 모두 페놀류(떫은맛·색을 내는 성분) 관련이라, PC1은 대략 **"페놀이 풍부한 정도"**로 읽을 수 있습니다.
- **PC2**에는 `color_intensity`(0.53), `alcohol`(0.48), `proline`(0.36)이 크게 들어가 **"색이 진하고 알코올이 높은 정도"**에 가깝습니다.

이렇게 섞은 비율을 보고 사람이 이름을 붙입니다. 단, 이름은 "대략 이런 성분 쪽"이라는 해석일 뿐 정확한 측정값은 아닙니다.

## 줄인 축으로 모델을 만들면

PCA로 줄인 축을 지도 학습 모델의 입력으로 쓸 수도 있습니다. 와인 품종 분류를 축 개수만 바꿔 교차검증해 봅니다.

```run
from sklearn.datasets import load_wine
from sklearn.model_selection import cross_val_score
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA
from sklearn.linear_model import LogisticRegression

wine = load_wine()
for k in [2, 5, 13]:
    pipe = make_pipeline(StandardScaler(), PCA(n_components=k), LogisticRegression(max_iter=1000))
    print(f"{k:>2} components -> cv accuracy {cross_val_score(pipe, wine.data, wine.target, cv=5).mean():.3f}")
```

13개 열을 **2개로만 줄여도 정확도 0.955**, 5개면 0.978로, 13개 전부(0.983)와 크게 다르지 않습니다. 열이 수백 개라 학습이 느리거나, 서로 비슷한 열이 많을 때 PCA로 줄이면 계산이 빨라지고 잡음도 줄어듭니다. 대신 축의 뜻이 흐려져 **해석은 어려워진다**는 대가가 있습니다. PCA도 스케일러처럼 파이프라인 안에 넣어야 교차검증 조각마다 학습용으로만 fit 됩니다.

## 언제 무엇을 쓰나

| 상황 | 방법 | 주의할 점 |
| --- | --- | --- |
| 비슷한 행끼리 그룹을 만들고 싶다 | K-means | 표준화 먼저, k는 사람이 정함, 그룹 이름도 사람이 붙임 |
| 열이 너무 많아 그림으로 보고 싶다 | PCA (2개 축) | 표준화 먼저, 새 축(PC1, PC2)은 원래 열처럼 이름이 있는 값이 아님 |
| 그룹이 의미 있는지 확인 | 나중에 정답이나 현장 지표와 비교 | K-means는 그룹이 없어도 억지로 나눔 |

## 정리

- PCA는 데이터가 가장 넓게 퍼진 방향(PC1)부터 차례로 새 축을 찾아 열 여러 개를 몇 개로 요약합니다.
- 분산을 재므로 **표준화가 먼저**입니다.
- 몇 개 남길지는 누적 설명 분산(보통 80~90%)을 보고 정합니다. 와인 13개 열 → 축 7개로 89%.
- 새 축은 원래 열처럼 이름이 있는 값이 아니라 여러 열을 섞은 값입니다. `components_`로 섞은 비율을 보고 대략의 뜻을 붙입니다(PC1 ≈ 페놀이 풍부한 정도).
- 줄인 축을 모델 입력으로 쓰면 계산이 빨라지지만 해석은 어려워집니다(와인 2개 축으로도 0.955).
