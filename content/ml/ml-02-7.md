## 시작하기 전에

지금까지의 선형회귀는 **직선(또는 평평한 면)** 만 그었습니다. 그런데 현실의 관계는 휘어 있을 때가 많습니다. 이번 레슨에서는 선형회귀 도구를 그대로 쓰면서 **곡선**을 맞추는 다항회귀를 배우고, 곡선을 너무 구불구불하게 만들면 왜 망가지는지를 **편향과 분산**이라는 두 단어로 설명합니다. 이 두 단어는 이 트랙의 모든 모델에 다시 나옵니다.

## 휘어진 관계: 회전수와 토크

AI4I 설비에서 회전수(rpm)와 토크(Nm)는 반비례에 가깝습니다. 모터가 내는 힘(출력)이 비슷하면 `출력 = 토크 × 회전 속도`라서, 빨리 돌수록 토크가 작아지기 때문입니다. 그림으로 먼저 봅니다.

```run
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv("ai4i2020.csv").sample(800, random_state=0)
fig, ax = plt.subplots(figsize=(5.5, 3.5))
ax.scatter(df["rpm"], df["torque"], s=6, alpha=0.4)
ax.set_xlabel("rotational speed (rpm)"); ax.set_ylabel("torque (Nm)")
ax.set_title("AI4I: rpm vs torque")
plt.tight_layout(); plt.show()
print("rpm range:", df["rpm"].min(), "~", df["rpm"].max())
```

점들이 직선이 아니라 **아래로 휘어지는 곡선**을 그립니다. 특히 2,000rpm을 넘는 오른쪽 끝에서 직선이라면 예측이 크게 빗나갈 것입니다.

## 다항회귀: 곡선을 '열 추가'로 푼다

다항회귀의 아이디어는 단순합니다. x 하나로 직선을 긋는 대신 **x², x³ 같은 열을 새로 만들어** 선형회귀에 넣습니다.

`ŷ = b₀ + b₁·x + b₂·x² + b₃·x³ + …`

x²을 하나의 새 특성으로 보면 이 식은 [특성을 여러 개 쓰면](#/l/ml-02-4)에서 본 다중 선형회귀와 똑같습니다. 그래서 이름에 '다항'이 붙어도 계수를 찾는 방법(최소제곱)은 그대로입니다. "선형"이라는 말은 **계수에 대해** 직선이라는 뜻이지, 그래프가 직선이라는 뜻이 아닙니다. 여기서 곱하는 최고 차수(2면 x², 3이면 x³까지)를 **차수(degree)** 라고 합니다.

`PolynomialFeatures(2)`가 실제로 어떤 열을 만드는지 봅니다.

```run
import pandas as pd
from sklearn.preprocessing import PolynomialFeatures

x = pd.DataFrame({"rpm": [1200, 1500, 2000]})
poly = PolynomialFeatures(degree=2, include_bias=False)
print(poly.fit_transform(x))
print(poly.get_feature_names_out())
```

`rpm` 옆에 `rpm^2` 열이 생겼습니다. 1,500의 제곱은 2,250,000이라 숫자 크기가 크게 다릅니다. 차수가 높아지면 크기 차이가 더 벌어지므로 다항 열을 만든 뒤에는 [표준화](#/l/ml-06-2)(`StandardScaler`)를 함께 씁니다.

## 차수를 올리면: 학습 점수는 계속 오른다

설비 40대만 뽑아 학습용으로 쓰고, 다른 2,000대를 시험용으로 둡니다. 차수를 1, 2, 3, 6, 10으로 올리며 R²를 비교합니다.

```run
import pandas as pd
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import PolynomialFeatures, StandardScaler
from sklearn.linear_model import LinearRegression

df = pd.read_csv("ai4i2020.csv")
train = df.sample(40, random_state=1)
test = df.drop(train.index).sample(2000, random_state=0)
for d in [1, 2, 3, 6, 10]:
    model = make_pipeline(PolynomialFeatures(d, include_bias=False), StandardScaler(), LinearRegression())
    model.fit(train[["rpm"]], train["torque"])
    print(f"degree {d:>2}: train R^2 {model.score(train[['rpm']], train['torque']):.3f}, "
          f"test R^2 {model.score(test[['rpm']], test['torque']):.3f}")
```

| 차수 | 학습 R² | 시험 R² | 읽는 법 |
| --- | --- | --- | --- |
| 1 (직선) | 0.774 | 0.755 | 휘어진 모양을 못 따라감 |
| 2 | 0.827 | **0.835** | 가장 좋음 |
| 3 | 0.829 | 0.800 | 학습은 조금 오르고 시험은 내려가기 시작 |
| 6 | 0.836 | **−1,712** | 시험에서 완전히 망가짐 |
| 10 | 0.852 | −3 × 10¹² | 말이 안 되는 예측 |

학습 R²는 차수를 올릴수록 **한 번도 내려가지 않습니다.** 맞출 수 있는 숫자(계수)가 늘어나니 40개 점에 더 바짝 붙을 수 있기 때문입니다. 하지만 시험 R²는 차수 2에서 가장 좋고, 6부터는 음수로 폭락합니다. R²가 음수라는 것은 "그냥 평균만 찍는 것보다도 못하다"는 뜻입니다([오차 재기: MAE · RMSE · R²](#/l/ml-02-2)).

왜 이렇게까지 망가질까요? 학습용 40대의 회전수는 1,368 ~ 2,293rpm인데, 시험용에는 **이보다 훨씬 빠른 설비(최대 2,886rpm)** 가 있기 때문입니다. 6차식은 학습 범위 안에서는 점들 사이를 구불구불 지나다가, 범위 밖으로 나가면 x⁶이 폭발적으로 커지면서 하늘 높이 튀어 버립니다. 이것이 고차 다항식의 가장 큰 위험인 **외삽(범위 밖 예측) 폭주**입니다.

## 편향과 분산: 오차를 두 갈래로 나눠 보기

모델이 틀리는 이유는 크게 둘입니다.

- **편향(bias)**: 모델의 모양이 너무 단순해서 생기는 **한쪽으로 치우친** 오차. 휘어진 관계에 직선을 대면, 데이터를 아무리 많이 줘도 휘어진 부분에서 늘 같은 방향으로 틀립니다. **과소적합**입니다.
- **분산(variance)**: 모델이 너무 예민해서, **학습 데이터가 조금만 바뀌어도 예측이 크게 흔들리는** 오차. 고차 다항식은 40개 중 몇 개만 바뀌어도 곡선 모양이 확 달라집니다. **과적합**입니다.

과녁에 비유하면, 편향은 화살이 **모두 한쪽으로 쏠린** 것이고 분산은 화살이 **사방으로 흩어진** 것입니다.

정말 그런지 직접 재 봅니다. 학습용 40대를 30번 새로 뽑아 모델을 30번 만들고, 매번 **2,000rpm에서의 토크**를 예측해 봅니다. 실제 데이터에서 1,950~2,050rpm 설비 125대의 평균 토크(20.53)를 정답으로 둡니다.

```run
import numpy as np
import pandas as pd
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import PolynomialFeatures, StandardScaler
from sklearn.linear_model import LinearRegression

df = pd.read_csv("ai4i2020.csv")
truth = df[(df["rpm"] > 1950) & (df["rpm"] < 2050)]["torque"].mean()
x0 = pd.DataFrame({"rpm": [2000.0]})
print("truth at 2000 rpm:", round(truth, 2))
for d in [1, 2, 6]:
    preds = []
    for seed in range(30):
        train = df.sample(40, random_state=seed)
        model = make_pipeline(PolynomialFeatures(d, include_bias=False), StandardScaler(), LinearRegression())
        preds.append(model.fit(train[["rpm"]], train["torque"]).predict(x0)[0])
    preds = np.array(preds)
    print(f"degree {d}: mean prediction {preds.mean():6.2f}  bias {preds.mean() - truth:+6.2f}  spread(std) {preds.std():7.2f}")
```

| 차수 | 30번 예측의 평균 | 편향 (평균 − 정답) | 흩어짐 (표준편차) |
| --- | --- | --- | --- |
| 1 | 18.08 | −2.45 | 3.54 |
| 2 | 19.09 | −1.44 | 1.89 |
| 6 | 19.18 | −1.35 | **168.86** |

- 직선(1차)은 편향이 가장 큽니다. 휘어진 끝을 늘 낮게 예측합니다.
- 6차식은 평균만 보면 정답에 가깝지만(편향 −1.35), 매번 예측이 **±169**만큼 요동칩니다. 실제로 쓰는 모델은 30개 중 하나뿐이라, 이번에 뽑힌 모델이 얼마나 엉뚱할지 모릅니다.
- 2차식은 둘 다 작아서 가장 믿을 만합니다.

::figure{src="content/img/ml/ml02-bias-variance.svg" alt="복잡도가 커질수록 학습 오차는 계속 줄지만 시험 오차는 U자 모양으로 줄었다가 다시 커진다" caption="복잡도를 올리면 편향은 줄고 분산은 커집니다. 시험 오차가 가장 낮은 지점이 '딱 좋은 복잡도'입니다."}

## 원리 한 걸음 더: 오차 = 편향² + 분산 + 잡음

제곱 오차의 기댓값은 정확히 세 조각으로 나뉩니다.

`평균 제곱 오차 = 편향² + 분산 + 줄일 수 없는 잡음`

- **편향²**: 모델 모양 때문에 생기는 체계적인 빗나감. 모델을 복잡하게 하면 줄어듭니다.
- **분산**: 학습 데이터에 따라 흔들리는 정도. 모델을 단순하게 하거나 **데이터를 늘리면** 줄어듭니다.
- **잡음**: 같은 회전수에서도 설비마다 토크가 다른, 데이터 자체의 흩어짐. 어떤 모델로도 줄일 수 없습니다.

복잡도를 올리면 편향은 줄고 분산은 늘어나서, 둘의 합은 U자를 그립니다. 이것을 **편향-분산 트레이드오프**라고 합니다. 머신러닝에서 고르는 거의 모든 설정값(다항 차수, 트리 깊이, KNN의 k, 규제 세기)은 결국 이 U자의 바닥을 찾는 일입니다.

:::tip 알아 두면 좋아요 · 왜 정확히 세 조각으로 나뉠까
정답을 y = f(x) + ε (ε은 평균 0, 분산 σ²인 잡음), 학습 데이터에 따라 달라지는 예측을 f̂(x)라고 하면 E[(y − f̂)²] = (f − E[f̂])² + E[(f̂ − E[f̂])²] + σ²입니다. 가운데 교차항들은 ε과 f̂가 서로 독립이고 평균이 0이라 사라집니다. 위 실험에서 30번의 평균과 표준편차가 바로 E[f̂]와 √분산을 흉내 낸 것입니다.
:::

## 직접 해보기: 데이터를 늘리면 분산이 줄어든다

학습용을 40대 대신 400대로 늘려 6차식을 다시 만들어 보세요. `n`을 40, 400, 4000으로 바꿔 봅니다.

```run
import pandas as pd
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import PolynomialFeatures, StandardScaler
from sklearn.linear_model import LinearRegression

df = pd.read_csv("ai4i2020.csv")
n = 40   # <- change me: 40, 400, 4000
train = df.sample(n, random_state=1)
test = df.drop(train.index).sample(2000, random_state=0)
model = make_pipeline(PolynomialFeatures(6, include_bias=False), StandardScaler(), LinearRegression())
model.fit(train[["rpm"]], train["torque"])
print(f"n={n}: train range {train['rpm'].min()}~{train['rpm'].max()} rpm, test R^2 {model.score(test[['rpm']], test['torque']):.3f}")
```

40대일 때 −1,712였던 시험 R²가 400대에서는 0.834, 4,000대에서는 0.856이 됩니다. 학습 데이터가 많아지면 범위도 넓어지고(4,000대는 1,168 ~ 2,886rpm), 한두 점에 휘둘리지 않아서 같은 6차식도 훨씬 얌전해집니다. "복잡한 모델은 데이터를 많이 먹어야 한다"는 말이 이것입니다. 데이터를 늘릴 수 없을 때 분산을 줄이는 또 다른 방법이 다음 레슨의 **규제**입니다.

## 자주 하는 실수

| 실수 | 무슨 일이 생기나 | 바로잡기 |
| --- | --- | --- |
| 학습 R²만 보고 차수를 고름 | 차수를 올릴수록 무조건 좋아 보임 | 시험용 또는 [교차검증](#/l/ml-05-1) 점수로 고른다 |
| 다항 열을 만들고 표준화를 안 함 | x¹⁰ 같은 열이 너무 커서 계산이 불안정해짐 | `PolynomialFeatures` 다음에 `StandardScaler` |
| 학습 범위 밖을 다항식으로 예측 | 끝에서 곡선이 폭주함 (6차식 R² −1,712) | 예측할 범위가 학습 범위 안인지 먼저 확인 |
| 특성이 여러 개인데 높은 차수 | 열이 폭발적으로 늘어남 (10개 열 2차 → 65개) | 차수는 2~3, 규제를 함께 |

## 정리

- 다항회귀는 x², x³ 같은 열을 만들어 **선형회귀로 곡선을 맞춥니다**. "선형"은 계수에 대해 직선이라는 뜻입니다.
- 차수를 올리면 학습 R²는 계속 오르지만, 시험 R²는 차수 2(0.835)에서 가장 좋고 6차에서는 −1,712로 무너졌습니다.
- **편향** = 너무 단순해서 한쪽으로 틀림(과소적합), **분산** = 너무 예민해서 데이터마다 흔들림(과적합). 오차 = 편향² + 분산 + 잡음.
- 분산을 줄이는 방법은 모델을 단순하게, 데이터를 많이, 또는 **규제**입니다.
