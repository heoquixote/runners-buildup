## 시작하기 전에

[PCA: 여러 열을 몇 개로 요약하기](#/l/ml-07-3)는 분산이 가장 큰 **직선 방향** 몇 개로 데이터를 요약했습니다. 빠르고 해석하기 쉽지만, 데이터가 휘어진 모양으로 놓여 있으면 2차원으로 펼쳤을 때 그룹들이 겹쳐 보입니다. 이번 레슨의 **t-SNE**는 "원래 공간에서 가까웠던 점은 2차원 지도에서도 가깝게"만 지키도록 점을 배치해서, 고차원 데이터의 무리를 눈으로 볼 수 있게 해 줍니다. 대신 지도에서 **믿으면 안 되는 것**이 분명히 있어서 그것까지 함께 배웁니다.

## 데이터: 8 × 8 손글씨 숫자

사이킷런에 들어 있는 손글씨 숫자 이미지를 씁니다. 사진 한 장은 8 × 8 = 64칸이고, 칸마다 0(흰색) ~ 16(검은색) 진하기가 들어 있습니다. 즉 **64개 열을 가진 표**입니다. 64차원은 그림으로 그릴 수 없으니 2차원으로 줄여서 봅니다. 브라우저에서 빨리 돌도록 600장만 씁니다.

```run
from sklearn.datasets import load_digits

X, y = load_digits(return_X_y=True)
X, y = X[:600], y[:600]
print("table shape:", X.shape)
print("first image (8 x 8):")
print(X[0].reshape(8, 8).astype(int))
print("label:", y[0])
```

첫 번째 사진은 숫자 0입니다. 가운데가 비고(0) 테두리가 진한(10 이상) 동그라미 모양이 숫자 표에서도 보입니다.

## PCA로 먼저 펼쳐 보기

```run
import matplotlib.pyplot as plt
from sklearn.datasets import load_digits
from sklearn.decomposition import PCA

X, y = load_digits(return_X_y=True)
X, y = X[:600], y[:600]
pca = PCA(n_components=2).fit(X)
Z = pca.transform(X)
print("variance kept by 2 components:", round(pca.explained_variance_ratio_.sum(), 3))
fig, ax = plt.subplots(figsize=(5, 4))
sc = ax.scatter(Z[:, 0], Z[:, 1], c=y, cmap="tab10", s=10)
fig.colorbar(sc, ax=ax, label="digit")
ax.set_title("PCA (2 components)")
plt.tight_layout(); plt.show()
```

두 주성분이 원래 분산의 28.1%밖에 담지 못합니다. 0, 4, 6처럼 따로 떨어진 숫자도 있지만, 가운데에서는 여러 숫자가 크게 겹칩니다. 64개 열의 정보가 직선 두 개로는 다 표현되지 않기 때문입니다.

## t-SNE의 아이디어: 이웃 관계만 지킨다

t-SNE는 거리 자체를 보존하려 애쓰지 않습니다. 대신 이렇게 합니다.

1. 원래 64차원 공간에서, 점마다 **"누가 내 이웃일 확률"** 을 계산한다. 가까울수록 확률이 큽니다.
2. 2차원에 점들을 아무렇게나 놓고, 2차원에서도 같은 **이웃 확률**을 계산한다.
3. 두 확률 분포가 비슷해지도록 2차원 점들을 조금씩 옮긴다(경사하강법).

반 친구들을 운동장에 세우는데, "평소 친한 친구 옆에 서기"만 지키게 하는 것과 비슷합니다. 친한 무리끼리는 모여 서지만, **무리와 무리 사이가 몇 걸음인지는 아무 의미가 없습니다.**

:::tip 알아 두면 좋아요 · 두 분포를 비교하는 손실
원래 공간의 이웃 확률을 P, 2차원의 이웃 확률을 Q라고 하면 t-SNE는 KL 발산 KL(P‖Q) = Σ p log(p / q)를 줄입니다. 원래 가까웠는데(p가 큼) 지도에서 멀면(q가 작음) 크게 혼나고, 원래 멀었는데 지도에서 가까운 것은 덜 혼납니다. 그래서 **가까운 관계는 잘 지키고 먼 관계는 대충** 지킵니다. 2차원 쪽 확률에 꼬리가 두꺼운 t분포를 써서(이름의 t), 멀리 있는 무리들이 한가운데로 뭉개지지 않게 밀어냅니다.
:::

## t-SNE로 펼쳐 보기

```run
import matplotlib.pyplot as plt
from sklearn.datasets import load_digits
from sklearn.manifold import TSNE

X, y = load_digits(return_X_y=True)
X, y = X[:600], y[:600]
Z = TSNE(n_components=2, perplexity=30, init="pca", random_state=0).fit_transform(X)
fig, ax = plt.subplots(figsize=(5, 4))
sc = ax.scatter(Z[:, 0], Z[:, 1], c=y, cmap="tab10", s=10)
fig.colorbar(sc, ax=ax, label="digit")
ax.set_title("t-SNE (perplexity 30)")
plt.tight_layout(); plt.show()
print("64 columns ->", Z.shape[1], "columns for", Z.shape[0], "images")
```

숫자 10개가 거의 각자의 섬으로 갈라졌습니다. 정답(숫자)은 색칠에만 썼고 t-SNE는 정답을 전혀 보지 않았는데도, 같은 숫자끼리 64차원에서 서로 가까이 있었다는 것을 보여 줍니다.

## 이웃이 얼마나 잘 지켜졌나: 숫자로 확인

"그림이 예쁘다"는 느낌 말고 숫자로도 비교해 봅니다. 2차원 지도에서 **가장 가까운 이웃 5개의 숫자로 다수결**을 했을 때 자기 숫자를 맞히는 비율을 잽니다. 이웃 관계가 잘 지켜졌다면 높게 나옵니다.

```run
from sklearn.datasets import load_digits
from sklearn.decomposition import PCA
from sklearn.manifold import TSNE
from sklearn.neighbors import KNeighborsClassifier
from sklearn.model_selection import cross_val_score

X, y = load_digits(return_X_y=True)
X, y = X[:600], y[:600]
maps = {
    "original 64-D": X,
    "PCA 2-D": PCA(2).fit_transform(X),
    "t-SNE 2-D": TSNE(2, perplexity=30, init="pca", random_state=0).fit_transform(X),
}
for name, Z in maps.items():
    acc = cross_val_score(KNeighborsClassifier(5), Z, y, cv=5).mean()
    print(f"{name:>14}: 5-neighbor vote accuracy {acc:.3f}")
```

| 공간 | 이웃 5개 다수결 정확도 |
| --- | --- |
| 원래 64차원 | 0.927 |
| PCA 2차원 | 0.577 |
| t-SNE 2차원 | 0.940 |

PCA는 2차원으로 줄이면서 이웃 관계가 많이 무너졌고(0.577), t-SNE는 원래 공간만큼 이웃을 지켰습니다(0.940). t-SNE가 **이웃 보존**만을 목표로 하기 때문입니다.

## t-SNE 지도에서 믿으면 안 되는 것

t-SNE 그림은 아름다워서 과하게 해석하기 쉽습니다. 아래 세 가지는 **읽으면 안 됩니다.**

| 지도에서 보이는 것 | 믿어도 되나 | 이유 |
| --- | --- | --- |
| 같은 무리 안에 모인 점들 | 대체로 믿어도 됨 | t-SNE가 지키려는 것이 바로 이웃 관계 |
| 무리 사이의 거리 | **믿으면 안 됨** | 먼 관계는 대충 지켜서, 멀다 · 가깝다를 해석할 근거가 약함 |
| 무리의 크기 (퍼진 정도) | **믿으면 안 됨** | 빽빽한 무리는 늘리고 성긴 무리는 줄여 비슷한 크기로 만듦 |
| 축(가로 · 세로)의 뜻 | **뜻이 없음** | PCA와 달리 축은 어떤 열의 조합도 아님 |

또 하나, t-SNE에는 **새 데이터를 같은 지도에 올리는 `transform`이 없습니다.** 매번 전체를 다시 배치합니다. 그래서 t-SNE 좌표를 모델의 특성으로 쓰지 않습니다. t-SNE는 **눈으로 탐색하는 도구**이고, 특성을 줄여 모델에 넣을 때는 PCA를 씁니다.

## 직접 해보기: perplexity

`perplexity`는 "점 하나가 이웃을 대략 몇 명쯤 챙기나"를 정하는 설정값입니다. 5, 30, 80으로 바꿔 그림을 비교해 보세요.

```run
import matplotlib.pyplot as plt
from sklearn.datasets import load_digits
from sklearn.manifold import TSNE

X, y = load_digits(return_X_y=True)
X, y = X[:600], y[:600]
perplexity = 5   # <- change me: 5, 30, 80
Z = TSNE(n_components=2, perplexity=perplexity, init="pca", random_state=0).fit_transform(X)
fig, ax = plt.subplots(figsize=(5, 4))
ax.scatter(Z[:, 0], Z[:, 1], c=y, cmap="tab10", s=10)
ax.set_title(f"t-SNE (perplexity {perplexity})")
plt.tight_layout(); plt.show()
print("perplexity:", perplexity)
```

perplexity가 작으면 아주 가까운 몇 명만 챙겨서 무리가 잘게 쪼개지고, 크면 넓은 범위를 챙겨서 무리가 더 둥글고 매끈해집니다. 보통 5 ~ 50 사이에서 몇 가지를 그려 보고, **여러 설정에서 공통으로 나타나는 무리**만 믿습니다.

## PCA vs t-SNE

| | PCA | t-SNE |
| --- | --- | --- |
| 방식 | 분산이 큰 직선 방향으로 투영 | 이웃 확률이 비슷해지게 점을 배치 |
| 지키는 것 | 전체적인 큰 구조, 먼 거리 | 가까운 이웃 관계 |
| 축의 뜻 | 있음 (열들의 가중합) | 없음 |
| 새 데이터 | `transform` 가능 → 모델 전처리로 씀 | 불가 → 시각화 전용 |
| 속도 | 아주 빠름 | 느림 (데이터가 크면 PCA로 30 ~ 50차원 줄인 뒤 t-SNE) |
| 결과의 안정성 | 항상 같음 | `random_state`, `perplexity`에 따라 달라짐 |

비슷한 목적의 최신 방법으로 **UMAP**도 많이 씁니다. t-SNE보다 빠르고 큰 구조를 조금 더 잘 지키지만, 해석할 때의 주의점은 같습니다.

## 정리

- **t-SNE**는 고차원에서 가까웠던 점을 2차원에서도 가깝게 놓아 **무리를 눈으로 보게** 해 줍니다. 손글씨 숫자 600장의 10개 숫자가 섬처럼 갈라졌습니다.
- 이웃 보존 정도(이웃 5개 다수결)는 t-SNE 0.940, PCA 0.577, 원래 공간 0.927이었습니다.
- 무리 사이 거리, 무리 크기, 축은 **해석하지 않습니다.** 새 데이터를 올릴 수 없어서 모델 특성으로 쓰지 않습니다.
- `perplexity`(5 ~ 50)를 바꿔 여러 번 그려 보고, 공통으로 나타나는 구조만 믿습니다.
