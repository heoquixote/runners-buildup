## 시작하기 전에

[K-means: 정답 없이 묶기](#/l/ml-07-1)는 중심점에서의 **거리**로 점을 묶었습니다. 그래서 그룹을 늘 **동그랗게** 보고, 점마다 "너는 무조건 2번 그룹"처럼 딱 잘라 배정합니다. 이번 레슨의 **가우시안 혼합 모델(GMM)** 은 그룹을 **정규분포(종 모양, 2차원에서는 타원)** 로 보고, 점마다 "1번 그룹일 확률 52%, 3번 그룹일 확률 48%"처럼 **소속 확률**을 줍니다. 그룹 수를 고르는 BIC라는 기준도 함께 배웁니다.

## 아이디어: 데이터는 종 모양 몇 개가 섞인 것

[정규분포와 표준화](#/l/st-02-3)에서 본 종 모양 분포를 떠올려 봅니다. GMM은 "이 데이터는 정규분포 k개에서 뽑힌 점들이 섞여 있다"고 가정합니다. 각 정규분포가 하나의 그룹이고, 학습은 세 가지를 찾는 일입니다.

- 각 그룹의 **중심**(평균)
- 각 그룹의 **퍼진 모양**(공분산): 얼마나 넓은지, 어느 방향으로 길쭉한지
- 각 그룹의 **비중**: 전체 중 몇 %가 이 그룹인지

::figure{src="content/img/ml/ml07-gmm.svg" alt="왼쪽 K-means는 원으로 그룹을 그려 길쭉한 그룹의 끝을 놓치고, 오른쪽 GMM은 타원으로 길쭉한 그룹을 한 덩어리로 잡는다" caption="K-means는 동그란 영역, GMM은 방향과 길이가 있는 타원으로 그룹을 그립니다."}

## 학습 방법: EM, 두 단계를 번갈아

정답 그룹을 모르는데 중심과 모양을 어떻게 찾을까요? GMM은 K-means와 비슷하게 두 단계를 번갈아 반복합니다. 이것을 **EM 알고리즘**이라고 합니다.

| 단계 | GMM (EM) | K-means |
| --- | --- | --- |
| E: 배정 | 지금 분포들로 점마다 **각 그룹일 확률**을 계산 | 점마다 **가장 가까운** 중심 하나에 배정 |
| M: 갱신 | 확률을 가중치로 써서 중심 · 모양 · 비중을 다시 계산 | 배정된 점들의 평균으로 중심 이동 |

그래서 K-means는 "모든 그룹이 같은 크기의 동그라미이고, 점은 한 그룹에만 속한다"고 가정한 GMM의 특수한 경우로 볼 수 있습니다.

:::tip 알아 두면 좋아요 · 소속 확률은 베이즈 정리
점 x가 그룹 k일 확률은 p(k | x) = 비중ₖ × N(x; 중심ₖ, 모양ₖ) / Σⱼ 비중ⱼ × N(x; 중심ⱼ, 모양ⱼ)입니다. N은 정규분포의 밀도(종 모양 높이)입니다. 사전확률(비중) × 가능도(밀도) ÷ 전체, 바로 [조건부확률과 베이즈 정리](#/l/st-09-2)의 모양입니다. 큰 그룹일수록, 그리고 그 그룹의 종 모양 한가운데에 가까울수록 확률이 높아집니다.
:::

## 펭귄 부리로 비교: K-means vs GMM

펭귄의 **부리 길이와 부리 깊이** 두 열만 보고, 종 이름은 모르는 척 세 그룹으로 묶습니다. 정답(종)은 마지막에 확인용으로만 씁니다. 그룹이 종과 얼마나 맞는지는 ARI(1이면 완벽, 0이면 무작위)로 잽니다.

```run
import pandas as pd
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans
from sklearn.mixture import GaussianMixture
from sklearn.metrics import adjusted_rand_score

df = pd.read_csv("penguins.csv").dropna()
X = StandardScaler().fit_transform(df[["bill_length_mm", "bill_depth_mm"]])
km = KMeans(n_clusters=3, n_init=10, random_state=0).fit(X)
gmm = GaussianMixture(n_components=3, n_init=5, random_state=0).fit(X)
print("K-means ARI:", round(adjusted_rand_score(df["species"], km.labels_), 3))
print("GMM ARI:    ", round(adjusted_rand_score(df["species"], gmm.predict(X)), 3))
print(pd.crosstab(df["species"], gmm.predict(X), rownames=["species"], colnames=["GMM group"]))
```

- K-means는 ARI 0.820, GMM은 **0.909**입니다.
- 교차표를 보면 GMM은 Adelie 146마리 중 145마리, Gentoo 119마리 중 116마리를 각각 한 그룹으로 모았습니다. Chinstrap도 68마리 중 60마리가 한 그룹입니다.

부리 길이와 깊이는 종 안에서도 함께 커지는(상관 있는) 관계라서, 각 종의 점구름이 비스듬한 **타원**입니다. 타원을 그릴 수 있는 GMM이 동그라미만 그리는 K-means보다 종의 모양을 더 잘 따라갔습니다.

## 소속 확률: 애매한 점을 골라내기

GMM의 가장 큰 장점은 `predict_proba`로 **확신도**를 알 수 있다는 것입니다. 가장 높은 소속 확률이 0.8에 못 미치는 "애매한" 펭귄을 세어 봅니다.

```run
import numpy as np
import pandas as pd
from sklearn.preprocessing import StandardScaler
from sklearn.mixture import GaussianMixture

df = pd.read_csv("penguins.csv").dropna()
X = StandardScaler().fit_transform(df[["bill_length_mm", "bill_depth_mm"]])
gmm = GaussianMixture(n_components=3, n_init=5, random_state=0).fit(X)
proba = gmm.predict_proba(X)
top = proba.max(axis=1)
print("unsure penguins (max prob < 0.8):", (top < 0.8).sum(), "of", len(X))
i = np.argmin(top)
print("most unsure:", df["species"].iloc[i], df["bill_length_mm"].iloc[i], df["bill_depth_mm"].iloc[i], "->", proba[i].round(2))
```

333마리 중 14마리가 애매합니다. 가장 애매한 펭귄(부리 45.4mm · 깊이 18.7mm, 실제로는 Chinstrap)은 두 그룹에 0.52와 0.48로 반반 걸쳐 있습니다. K-means라면 이 펭귄도 아무렇지 않게 한 그룹에 넣었을 것입니다. 현장에서는 이런 애매한 행을 **사람이 다시 확인할 목록**으로 뽑는 데 쓸 수 있습니다.

## 그룹 수 고르기: BIC

K-means에서는 엘보와 실루엣으로 k를 골랐습니다([k는 몇 개로 할까: 엘보와 실루엣](#/l/ml-07-2)). GMM은 확률 모델이라 **BIC(베이즈 정보 기준)** 를 씁니다.

`BIC = −2 × (데이터가 이 모델에서 나왔을 가능도의 로그) + (모델 숫자 개수) × log(n)`

- 앞부분: 데이터를 **잘 설명할수록** 작아집니다.
- 뒷부분: 모델이 **복잡할수록**(그룹이 많을수록) 커지는 벌점입니다.

그룹을 늘리면 앞부분은 계속 좋아지지만 벌점도 커지므로, **BIC가 가장 작은 k**가 "설명력과 단순함의 균형"이 가장 좋은 선택입니다. [편향-분산](#/l/ml-02-7)의 균형을 숫자 하나로 잡는 셈입니다.

```run
import pandas as pd
from sklearn.preprocessing import StandardScaler
from sklearn.mixture import GaussianMixture

df = pd.read_csv("penguins.csv").dropna()
X = StandardScaler().fit_transform(df[["bill_length_mm", "bill_depth_mm"]])
for k in range(2, 7):
    gmm = GaussianMixture(n_components=k, n_init=5, random_state=0).fit(X)
    print(f"k={k}: BIC {gmm.bic(X):7.1f}")
```

k = 3에서 BIC가 1,702.4로 가장 작습니다. 종 이름을 하나도 보지 않았는데 "그룹은 셋"이라는 답을 데이터에서 찾았습니다.

## 타원의 자유도: covariance_type

`covariance_type`은 각 그룹 타원이 얼마나 자유로운 모양을 가질지 정합니다.

| 설정 | 타원 모양 | 펭귄 ARI | BIC |
| --- | --- | --- | --- |
| `spherical` | 동그라미 (크기만 다름) | 0.813 | 1,747.0 |
| `diag` | 가로 · 세로로만 길쭉 (기울지 못함) | 0.807 | 1,757.2 |
| `full` (기본값) | 아무 방향으로나 기운 타원 | **0.909** | **1,702.4** |

동그라미(`spherical`)로 제한하면 K-means(0.820)와 거의 같아집니다. 부리 길이와 깊이가 함께 움직이는 **기울어진** 타원이라서, 기울기를 허용한 `full`만 크게 좋아졌습니다. 대신 `full`은 맞출 숫자가 많아서 데이터가 적거나 열이 많으면 불안정할 수 있습니다.

## 자주 하는 실수

| 실수 | 무슨 일이 생기나 | 바로잡기 |
| --- | --- | --- |
| 표준화를 빼먹음 | 단위가 큰 열이 모양을 지배 | K-means와 똑같이 `StandardScaler` 먼저 |
| `n_init=1`로 한 번만 학습 | 시작점이 나쁘면 엉뚱한 해에 갇힘 | `n_init`을 5 ~ 10으로 |
| 소속 확률을 "이 그룹일 진짜 확률"로 과신 | 정규분포 가정이 틀리면 확률도 틀림 | 확률은 상대적인 확신도로, 그림으로 확인 |
| 그룹 = 종(정답)이라고 단정 | 비지도 그룹은 데이터 모양일 뿐 | 정답이 있으면 확인용으로만, 해석은 사람이 |

## 정리

- **GMM**은 데이터를 정규분포 k개의 혼합으로 보고, 그룹마다 중심 · 타원 모양 · 비중을 찾습니다. 학습은 E(소속 확률) → M(갱신)을 번갈아 하는 EM입니다.
- 점마다 **소속 확률**을 줘서 애매한 점(333마리 중 14마리)을 골라낼 수 있습니다.
- 기울어진 타원을 그릴 수 있어서 펭귄 부리에서 K-means(ARI 0.820)보다 종을 잘 찾았습니다(0.909).
- 그룹 수는 **BIC가 가장 작은 k**로 고릅니다(k = 3에서 1,702.4).
