## 시작하기 전에

앞 레슨에서 트리가 질문을 하나씩 골라 나가는 원리를 봤습니다. 그러면 질문은 몇 단계까지 해도 될까요? 많이 할수록 좋을까요? 이번 레슨에서는 트리의 깊이에 따라 생기는 두 가지 문제, **과적합**과 **과소적합**을 직접 확인합니다.

## 깊어질수록 외운다: 과적합

질문을 계속 늘리면(깊이를 키우면) 학습 데이터는 결국 전부 맞힐 수 있습니다. 승객 한 명 한 명에게 맞춘 질문까지 만들어 버리기 때문입니다. 하지만 그건 **이해가 아니라 암기**라서 새 승객에게는 오히려 틀립니다. 이것을 **과적합(overfitting)**이라고 합니다.

::figure{src="content/img/ml/ml04-overfit.svg" alt="트리가 깊어질수록 학습 점수는 계속 오르지만 시험 점수는 어느 지점부터 떨어진다" caption="학습 점수와 시험 점수의 차이가 벌어지기 시작하는 곳부터가 과적합입니다."}

::video{ref="dl-m10"}

```run
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier

df = pd.read_csv("titanic.csv")
df["female"] = (df["sex"] == "female").astype(int)
df["age"] = df["age"].fillna(df["age"].median())
X = df[["pclass", "female", "age", "sibsp", "parch", "fare"]]
y = df["survived"]
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.25, random_state=0, stratify=y)
for d in [1, 2, 3, 4, 6, 10, None]:
    m = DecisionTreeClassifier(max_depth=d, random_state=0).fit(X_train, y_train)
    print(f"depth {str(d):>4}:  train {m.score(X_train, y_train):.3f}   test {m.score(X_test, y_test):.3f}")
```

깊이 제한이 없으면(None) 학습 점수는 0.98 이상인데 시험 점수는 오히려 떨어집니다. 학습 점수와 시험 점수의 차이가 크게 벌어지면 과적합을 의심합니다. 그래서 `max_depth`를 적당히 제한합니다.

## 반대 문제: 너무 단순하면 과소적합

결과를 위에서부터 다시 보면 반대쪽 문제도 보입니다. 깊이 1(질문 하나, "여성인가?")은 학습 0.792, 시험 0.771로 **둘 다** 낮습니다. 외우기는커녕 데이터의 패턴도 다 배우지 못한 상태입니다. 이것을 **과소적합(underfitting)** 이라고 합니다.

| 상태 | 학습 점수 | 시험 점수 | 비유 | 예 (위 결과) |
| --- | --- | --- | --- | --- |
| 과소적합 | 낮음 | 낮음 | 공부를 덜 함 | 깊이 1: 0.792 / 0.771 |
| 적당함 | 높음 | 높음, 차이 작음 | 원리를 이해함 | 깊이 6: 0.870 / 0.825 |
| 과적합 | 아주 높음 | 낮아짐, 차이 큼 | 문제집 답을 외움 | 제한 없음: 0.985 / 0.776 |

좋은 모델은 그 사이 어딘가에 있습니다. 이 실험에서는 깊이 6에서 시험 점수가 가장 높았습니다.

## 깊이 말고 다른 브레이크: min_samples_leaf

깊이를 제한하는 대신 "잎 하나에는 최소 몇 명이 있어야 한다"고 정할 수도 있습니다. 승객 한두 명만 담긴 잎(=한 사람에게 맞춘 규칙)을 못 만들게 막는 것입니다.

```run
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier

df = pd.read_csv("titanic.csv")
df["female"] = (df["sex"] == "female").astype(int)
df["age"] = df["age"].fillna(df["age"].median())
X = df[["pclass", "female", "age", "sibsp", "parch", "fare"]]
y = df["survived"]
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.25, random_state=0, stratify=y)
for leaf in [1, 5, 10, 20, 50]:
    m = DecisionTreeClassifier(min_samples_leaf=leaf, random_state=0).fit(X_train, y_train)
    print(f"min_samples_leaf {leaf:>2}: leaves {m.get_n_leaves():>3}   train {m.score(X_train, y_train):.3f}   test {m.score(X_test, y_test):.3f}")
```

`min_samples_leaf=1`이면 잎이 154개나 생기고 학습 0.985 / 시험 0.776으로 외운 상태입니다. 10으로 올리면 잎이 40개로 줄고 시험 점수가 0.789로 오릅니다. 50까지 올리면 잎 11개로 너무 단순해져 다시 떨어집니다. 이렇게 모델이 너무 복잡해지지 않게 막는 장치를 통틀어 **규제(regularization)**, 트리에서는 **가지치기**라고 부릅니다.

### 직접 해보기

`max_depth`를 1부터 하나씩 올려 보고, `None`(제한 없음)도 넣어 보세요. 그리고 `min_samples_leaf`(잎 하나에 최소 몇 명이 있어야 하는지)를 1에서 10으로 바꿔 보세요. 잎을 너무 잘게 쪼개지 못하게 막는 것도 과적합을 줄이는 방법입니다.

```run
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier

df = pd.read_csv("titanic.csv")
df["female"] = (df["sex"] == "female").astype(int)
df["age"] = df["age"].fillna(df["age"].median())
X = df[["pclass", "female", "age", "sibsp", "parch", "fare"]]
y = df["survived"]
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.25, random_state=0, stratify=y)

max_depth = 3          # <- change me (1, 2, ..., None)
min_samples_leaf = 1   # <- change me (1, 5, 10)
m = DecisionTreeClassifier(max_depth=max_depth, min_samples_leaf=min_samples_leaf, random_state=0).fit(X_train, y_train)
print(f"train {m.score(X_train, y_train):.3f}   test {m.score(X_test, y_test):.3f}   gap {m.score(X_train, y_train) - m.score(X_test, y_test):.3f}")
```

## 정리

- 너무 깊으면 **과적합**(학습 점수만 높음), 너무 얕으면 **과소적합**(둘 다 낮음)
- 학습 점수와 시험 점수의 **차이(gap)** 가 크게 벌어지면 과적합을 의심합니다.
- `max_depth`, `min_samples_leaf`로 트리가 너무 잘게 쪼개지지 않게 막습니다.
- 가장 좋은 설정값을 체계적으로 고르는 법은 ml-05(교차검증, GridSearchCV)에서 배웁니다.
