## 모든 모델의 공통 뼈대: 모양 · 손실 · 최적화

모델 이름은 많지만 속을 열어 보면 같은 세 부품으로 되어 있습니다.

1. **모델의 모양(가설)**: 답을 어떤 꼴로 낼지. 직선인가, 질문 나무인가, 중심점인가.
2. **손실 함수**: 지금 답이 얼마나 나쁜지 재는 점수. 작을수록 좋습니다.
3. **최적화**: 손실이 가장 작아지는 모델 안의 숫자(계수, 질문, 중심)를 찾는 방법.

| 모델 | ① 모양 | ② 손실 (줄이려는 값) | ③ 찾는 방법 |
| --- | --- | --- | --- |
| 선형회귀 | ŷ = b₀ + b₁x₁ + … + bₚxₚ | 오차 제곱의 합 Σ(y − ŷ)² | 공식으로 한 번에(최소제곱) 또는 경사하강법 |
| Ridge | 선형회귀와 같음 | Σ(y − ŷ)² + α Σb² | 공식 또는 경사하강법 |
| 로지스틱 회귀 | p = 1 / (1 + e^−(b₀ + b₁x₁ + …)) | 로그 손실 −Σ[y log p + (1 − y) log(1 − p)] | 경사하강법 계열 |
| 결정트리 | 예/아니오 질문의 나무 | 잎의 불순도(지니) 또는 오차 제곱합 | 한 번에 가장 좋은 질문 하나씩 고르기(탐욕) |
| K-means | 중심점 k개 | 점과 자기 중심 사이 거리 제곱의 합 | 배정 → 중심 옮기기 반복 |

이 표를 기억해 두면 새 모델을 만나도 "모양은? 무엇을 줄이나? 어떻게 찾나?" 세 가지만 물으면 정리됩니다. 예를 들어 Ridge는 선형회귀와 **모양이 같고 손실만 다른** 모델입니다.

:::tip 알아 두면 좋아요 · 손실을 왜 '제곱'으로 잴까
오차를 그냥 더하면 +3과 −3이 서로 지워져 0이 됩니다. 절댓값(|y − ŷ|)이나 제곱으로 부호를 없애야 합니다. 제곱은 큰 오차를 더 크게 혼내고, 매끄러운 곡선이라 미분(기울기 계산)이 쉬워서 최적화에 편합니다. 대신 이상치 하나에 크게 끌려갑니다. 절댓값을 쓰면 이상치에 덜 흔들리고, 그 결과는 평균 대신 **중앙값** 쪽으로 갑니다. 손실을 무엇으로 고르느냐가 곧 "어떤 실수를 더 싫어하나"를 정하는 일입니다.
:::

## 이름은 달라도 쓰는 법은 같다

scikit-learn의 모델은 모두 **만들기 → `fit` → `predict` · `score`** 순서입니다. 그래서 같은 데이터에 여러 모델을 줄 세워 비교하기가 쉽습니다. 타이타닉 생존 예측을 지도의 분류 모델 다섯 개로 돌려 봅니다.

```run
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.dummy import DummyClassifier
from sklearn.linear_model import LogisticRegression
from sklearn.neighbors import KNeighborsClassifier
from sklearn.tree import DecisionTreeClassifier
from sklearn.ensemble import RandomForestClassifier, HistGradientBoostingClassifier

df = pd.read_csv("titanic.csv")
df["female"] = (df["sex"] == "female").astype(int)
df["age"] = df["age"].fillna(df["age"].median())
X = df[["pclass", "female", "age", "sibsp", "parch", "fare"]]
y = df["survived"]
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.25, random_state=0, stratify=y)
models = {
    "baseline (most frequent)": DummyClassifier(),
    "logistic regression": make_pipeline(StandardScaler(), LogisticRegression()),
    "KNN (k=15)": make_pipeline(StandardScaler(), KNeighborsClassifier(15)),
    "decision tree (depth 4)": DecisionTreeClassifier(max_depth=4, random_state=0),
    "random forest": RandomForestClassifier(300, min_samples_leaf=3, random_state=0),
    "gradient boosting": HistGradientBoostingClassifier(random_state=0),
}
for name, m in models.items():
    m.fit(X_train, y_train)
    print(f"{name:>25}: test accuracy {m.score(X_test, y_test):.3f}")
```

- 아무것도 배우지 않고 많은 쪽(사망)만 찍는 기준 모델이 0.614입니다. 모든 모델은 이 줄보다 높아야 의미가 있습니다.
- 나머지 모델은 0.776(로지스틱) ~ 0.821(랜덤포레스트) 사이에 모여 있습니다. 같은 특성 6개를 쓰는 한, 모델을 바꿔서 얻는 차이는 **몇 %p** 정도입니다.
- 시험용 223명에서 0.01 차이는 약 2명입니다. 이 정도 차이는 데이터를 어떻게 나눴느냐(운)에 따라 순위가 바뀔 수 있어서, 모델을 고를 때는 [교차검증](#/l/ml-05-1)으로 여러 번 재 봅니다.

## 모델을 고르는 순서

정답이 하나는 아니지만, 표 데이터에서 실무자들이 흔히 따르는 순서는 이렇습니다.

1. **기준 모델**로 최저선을 잰다 (평균 찍기, 많은 쪽 찍기).
2. **선형 모델**(선형 · 로지스틱 회귀)을 돌린다. 빠르고, 계수로 설명하기 쉽다.
3. **트리 앙상블**(랜덤포레스트, 그래디언트 부스팅)을 돌린다. 표 데이터에서 가장 자주 이기는 모델이다.
4. 차이가 작으면 **설명하기 쉬운 쪽**을 고른다. 차이가 크면 왜 그런지(비선형, 상호작용)를 들여다본다.

| 상황 | 먼저 볼 모델 | 이유 |
| --- | --- | --- |
| 이유를 설명해야 한다 (대출 심사, 의료) | 로지스틱 회귀, 얕은 결정트리 | 계수 · 규칙을 사람이 읽을 수 있다 |
| 점수가 가장 중요하다 (표 데이터) | 그래디언트 부스팅, 랜덤포레스트 | 비선형 · 상호작용을 스스로 찾는다 |
| 데이터가 아주 적다 (수십 ~ 수백 행) | 선형 모델 + 규제, 나이브 베이즈 | 맞출 숫자가 적어 덜 외운다 |
| 글자 수가 많은 문서 분류 | 나이브 베이즈, 로지스틱 회귀 | 열이 수만 개여도 빠르다 |
| 정답이 없다 | 군집 · 차원 축소 | 비지도학습 |

## 정리

- 머신러닝 모델은 **지도학습(회귀 · 분류 · 공통)** 과 **비지도학습(군집 · 차원 축소 · 이상 탐지)** 으로 정리됩니다. 이 트랙의 PART도 이 순서입니다.
- 모든 모델은 **모양 · 손실 · 최적화** 세 부품으로 설명할 수 있습니다. Ridge는 선형회귀와 모양은 같고 손실만 다릅니다.
- scikit-learn에서는 모델 이름만 바꾸면 같은 코드로 비교할 수 있습니다. 타이타닉에서는 기준 0.614, 다른 모델들은 0.776 ~ 0.821이었습니다.
- 고르는 순서: 기준 모델 → 선형 모델 → 트리 앙상블 → 차이가 작으면 설명하기 쉬운 쪽.
