## 정확도만으로는 부족하다

**정확도(accuracy)**는 "전체 중 맞힌 비율"입니다. 이해하기 쉽지만 함정이 있습니다. [기준 모델과 누수](#/l/ml-01-5)에서 본 것처럼 고장이 3%뿐인 설비 데이터에서는 "전부 정상"이라고만 해도 정확도가 97%입니다.

그래서 "**무엇을** 맞히고 **무엇을** 틀렸는지" 나눠서 봐야 합니다. 그 출발점이 혼동행렬입니다.

## 혼동행렬: 맞힘과 틀림을 네 칸으로

화재경보기를 떠올려 봅시다.

::figure{src="content/img/ml/ml03-confusion.svg" alt="실제와 예측으로 나눈 2×2 표: TP 제대로 울림, FN 놓침, FP 헛경보, TN 조용히 잘 있음" caption="가로는 모델의 예측, 세로는 실제입니다. 초록은 맞힘, 빨강은 놓침, 노랑은 헛경보입니다."}

- T(True)/F(False): 예측이 맞았나 틀렸나
- P(Positive)/N(Negative): 모델이 1이라고 했나 0이라고 했나

타이타닉 생존 예측 모델로 네 칸을 세어 봅니다. 여기서 1은 "생존"입니다.

```run
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import confusion_matrix

df = pd.read_csv("titanic.csv")
df["female"] = (df["sex"] == "female").astype(int)
df["age"] = df["age"].fillna(df["age"].median())
X = df[["pclass", "female", "age", "fare"]]
y = df["survived"]
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.25, random_state=0, stratify=y)
model = make_pipeline(StandardScaler(), LogisticRegression()).fit(X_train, y_train)
pred = model.predict(X_test)
tn, fp, fn, tp = confusion_matrix(y_test, pred).ravel()
print(confusion_matrix(y_test, pred))
print(f"TN={tn} FP={fp} FN={fn} TP={tp}")
print("accuracy:", round((tp + tn) / (tp + tn + fp + fn), 3))
```

`confusion_matrix`의 결과는 행이 실제, 열이 예측이고, `.ravel()`로 펴면 TN, FP, FN, TP 순서입니다.

결과는 TN=120, FP=17, FN=28, TP=58입니다. 시험용 승객 223명 중 정확도는 (58 + 120) / 223 ≈ **0.798**입니다. 하지만 네 칸을 보면 더 많은 것이 보입니다.

- 실제 생존자 86명(58 + 28) 중 **28명을 "사망"으로 놓쳤습니다**(FN).
- "생존"이라고 예측한 75명(58 + 17) 중 **17명은 실제로 사망**했습니다(FP).

정확도 하나로는 이 두 종류의 실수가 구분되지 않습니다. 어떤 실수가 더 아픈지는 문제마다 다르기 때문에, 네 칸을 나눠 보는 것이 출발점입니다.

### 이름표를 붙여 읽기 쉽게

`confusion_matrix`는 숫자만 나와서 어느 칸이 무엇인지 헷갈립니다. `pd.crosstab`을 쓰면 행·열에 이름이 붙은 표가 나옵니다. 그리고 **놓친 사람(FN)과 헛경보(FP)가 누구였는지** 직접 꺼내 봅니다.

```run
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression

df = pd.read_csv("titanic.csv")
df["female"] = (df["sex"] == "female").astype(int)
df["age"] = df["age"].fillna(df["age"].median())
X = df[["pclass", "female", "age", "fare"]]
y = df["survived"]
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.25, random_state=0, stratify=y)
model = make_pipeline(StandardScaler(), LogisticRegression()).fit(X_train, y_train)
pred = model.predict(X_test)
print(pd.crosstab(pd.Series(y_test.values, name="actual"), pd.Series(pred, name="predicted")))
missed = X_test[(y_test.values == 1) & (pred == 0)]       # FN
false_alarm = X_test[(y_test.values == 0) & (pred == 1)]  # FP
print("FN  female:", missed["female"].sum(), "/", len(missed), "  by class:", missed["pclass"].value_counts().to_dict())
print("FP  female:", false_alarm["female"].sum(), "/", len(false_alarm), "  by class:", false_alarm["pclass"].value_counts().to_dict())
```

- **놓친 생존자 28명 중 27명이 남성**입니다. 모델은 "남성이면 사망"이라는 규칙에 크게 기대고 있어서, 살아남은 남성은 거의 못 맞힙니다.
- **헛경보 17명은 모두 여성**이고, 그중 15명이 3등실입니다. "여성이면 생존"이라고 봤는데 3등실 여성은 실제로 절반 정도만 살아남았기 때문입니다.

이렇게 틀린 사례를 직접 꺼내 보면 **모델이 어떤 규칙에 기대고 있고, 어디서 약한지**가 보입니다. 숫자 네 개를 세는 것보다 훨씬 많은 것을 알려 주므로, 실무에서도 모델을 평가한 뒤 틀린 사례를 꼭 몇 개 열어 봅니다.

## 고장 데이터의 혼동행렬: 정확도 97%의 실체

이번에는 고장이 3.4%뿐인 AI4I 데이터에서 같은 모델을 만들어 봅니다.

```run
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import confusion_matrix

df = pd.read_csv("ai4i2020.csv")
X = df[["air_temp", "process_temp", "rpm", "torque", "tool_wear"]]
y = df["failure"]
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.25, random_state=0, stratify=y)
pred = make_pipeline(StandardScaler(), LogisticRegression()).fit(X_train, y_train).predict(X_test)
tn, fp, fn, tp = confusion_matrix(y_test, pred).ravel()
print(f"TN={tn} FP={fp} FN={fn} TP={tp}")
print("accuracy:", round((tp + tn) / len(y_test), 3))
```

정확도는 0.974로 아주 높습니다. 그런데 네 칸을 보면 TN이 2,410개로 거의 전부를 차지하고, **실제 고장 85건 중 61건을 놓쳤습니다**(FN=61, TP=24). 정확도가 높은 이유는 "정상을 정상이라고 한 것"이 워낙 많아서입니다. 드문 것을 찾는 문제에서는 TN 칸이 점수를 부풀린다는 것을 꼭 기억하세요.

## 두 종류의 실수 이름 붙이기

| 칸 | 이름 | 화재경보기로 말하면 | 통계에서 부르는 이름 |
| --- | --- | --- | --- |
| FP | 거짓 양성 (헛경보) | 불이 안 났는데 울림 | 1종 오류 |
| FN | 거짓 음성 (놓침) | 불이 났는데 안 울림 | 2종 오류 |

외우는 요령: 뒤 글자(P/N)는 **모델이 한 말**, 앞 글자(T/F)는 **그 말이 맞았는지**입니다. FN = "아니라고(N) 했는데 틀렸다(F)" = 놓침.

## 정리

- 정확도는 전체 중 맞힌 비율이라 **어떤 실수**를 했는지 알려 주지 않습니다.
- 혼동행렬은 실제 × 예측으로 TP, FN, FP, TN 네 칸을 셉니다. `confusion_matrix(y_test, pred).ravel()` → TN, FP, FN, TP 순서.
- 틀린 사례(FN·FP)를 직접 꺼내 보면 모델이 기댄 규칙과 약점이 보입니다(놓친 생존자 28명 중 27명이 남성).
- 드문 것을 찾는 문제에서는 TN이 정확도를 부풀립니다(AI4I 정확도 0.974인데 고장 85건 중 61건 놓침).
- 다음 레슨에서 이 네 칸으로 정밀도와 재현율을 만듭니다.
