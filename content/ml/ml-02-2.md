## 시작하기 전에

앞 레슨에서 공기 온도로 공정 온도를 예측하는 직선을 만들었습니다. 그런데 이 직선이 **얼마나 잘** 맞히는지는 어떻게 말할 수 있을까요? 이번 레슨에서는 회귀 모델을 평가하는 세 가지 숫자, **MAE, RMSE, R²**를 배웁니다.

## 오차란

**오차(error, 잔차)**는 `실제값 − 예측값`입니다. 공정 온도가 실제로 310.5K인데 310.0K로 예측했다면 오차는 0.5K입니다. 데이터가 1만 건이면 오차도 1만 개가 생기니, 이것을 **숫자 하나로 요약**하는 방법이 필요합니다. 그냥 더하면 +와 −가 서로 지워지므로, 크기만 보거나(절댓값) 제곱해서 더합니다.

## 오차를 재는 두 방법: MAE, RMSE

- **MAE(평균 절대 오차)**: 틀린 크기를 그대로 평균. "평균적으로 몇 도 틀리나?" 읽기 가장 쉽습니다.
- **RMSE(평균 제곱 오차의 제곱근)**: 틀린 크기를 제곱해서 평균 낸 뒤 다시 제곱근. 크게 틀린 것에 **벌점을 더 크게** 줍니다. 가끔 크게 틀리면 안 되는 상황에서 봅니다.

```run
import numpy as np
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_absolute_error, mean_squared_error, r2_score

df = pd.read_csv("ai4i2020.csv")
X_train, X_test, y_train, y_test = train_test_split(df[["air_temp"]], df["process_temp"], test_size=0.25, random_state=0)
pred = LinearRegression().fit(X_train, y_train).predict(X_test)
print("MAE :", round(mean_absolute_error(y_test, pred), 3), "K")
print("RMSE:", round(float(np.sqrt(mean_squared_error(y_test, pred))), 3), "K")
print("R^2 :", round(r2_score(y_test, pred), 3))
```

이번에는 학습용으로 배우고 **시험용으로 평가**했습니다(ml-01에서 배운 순서). MAE가 약 0.59이면 "공정 온도를 평균 0.6도 정도 틀리게 예측한다"는 뜻입니다. RMSE(0.72)가 MAE보다 조금 큰 것은 가끔 크게 틀리는 경우가 섞여 있기 때문입니다. 숫자 하나만 보지 말고 **R²(설명력)와 MAE(실제 오차 크기)를 함께** 보는 습관을 들이세요.

## R²: 평균만 찍는 것보다 얼마나 나은가

MAE는 "몇 도 틀리나"를 알려 주지만, 그게 **잘한 건지**는 데이터마다 다릅니다. 0.6도 오차가 공정 온도에서는 괜찮아도, 체온 예측에서는 큰 오차입니다. 그래서 "가장 단순한 예측과 비교해 얼마나 나아졌나"를 보는 점수가 **R²(결정계수)** 입니다.

가장 단순한 예측은 x를 보지 않고 **항상 평균값만 말하는 것**입니다. R²는 이렇게 계산합니다.

`R² = 1 − (내 모델의 오차 제곱합) / (평균만 찍었을 때의 오차 제곱합)`

::figure{src="content/img/ml/ml02-r2.svg" alt="평균선과 회귀 직선의 오차 막대 비교" caption="세로 막대가 오차입니다. 회귀 직선의 막대가 평균선보다 짧을수록 R²가 1에 가까워집니다."}

```run
import numpy as np
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LinearRegression
from sklearn.metrics import r2_score

df = pd.read_csv("ai4i2020.csv")
X_train, X_test, y_train, y_test = train_test_split(df[["air_temp"]], df["process_temp"], test_size=0.25, random_state=0)
pred = LinearRegression().fit(X_train, y_train).predict(X_test)
mean_only = np.full(len(y_test), y_train.mean())     # always say the average
for name, p in [("linear model", pred), ("mean only", mean_only), ("model + 3K mistake", pred + 3)]:
    sse = ((y_test - p) ** 2).sum()
    print(f"{name:>18}: squared error sum {sse:>8.0f}   R^2 {r2_score(y_test, p):6.3f}")
```

- 직선 모델의 오차 제곱합은 약 1,277, 평균만 찍으면 약 5,313입니다. 1 − 1277/5313 ≈ **0.76**. "평균만 찍을 때의 오차 중 76%를 없앴다"는 뜻입니다.
- 평균만 찍으면 R²는 **0**입니다. 아무것도 설명하지 못한 상태입니다.
- 일부러 모든 예측에 3K를 더하면 R²가 **−3.5**로 음수가 됩니다. 평균만 찍는 것보다도 못하다는 뜻입니다.

| R² | 뜻 |
| --- | --- |
| 1 | 완벽하게 맞힘 |
| 0과 1 사이 | 평균보다 그만큼 더 잘 설명 |
| 0 | 평균만 찍은 것과 같음 |
| 음수 | 평균만 찍은 것보다도 못함 (모델이 잘못됨) |

## 오차를 하나씩 들여다보기: 잔차

지표 하나로 요약하기 전에, 오차(**잔차**, residual = 실제 − 예측)들이 어떻게 생겼는지 직접 보면 모델의 버릇이 보입니다.

```run
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LinearRegression

df = pd.read_csv("ai4i2020.csv")
X_train, X_test, y_train, y_test = train_test_split(df[["air_temp"]], df["process_temp"], test_size=0.25, random_state=0)
model = LinearRegression().fit(X_train, y_train)
resid = y_test - model.predict(X_test)
print(resid.describe().round(2))
print("share of errors bigger than 1.5 K:", round((resid.abs() > 1.5).mean(), 3))
```

- 잔차의 평균이 −0.01로 거의 0입니다. 직선이 한쪽으로 치우치지 않고 **위로도 아래로도 비슷하게** 틀린다는 뜻입니다. 평균이 0에서 멀면 예측 전체를 한쪽으로 밀어야 한다는 신호입니다.
- 가장 크게 틀린 것도 약 2.1K이고, 1.5K보다 크게 틀린 경우는 2.4%뿐입니다.

현장에 보고할 때 "MAE 0.6K"만 말하는 것보다 "대부분 ±1K 안, 가장 크게 틀려도 약 2K"처럼 **최악의 경우**를 함께 말하면 듣는 사람이 판단하기 쉽습니다.

## 무엇을 볼까

| 지표 | 질문 | 단위 |
| --- | --- | --- |
| MAE | 평균 몇 도 틀리나? | y와 같은 단위 (K) |
| RMSE | 가끔 크게 틀리지는 않나? | y와 같은 단위 (K) |
| R² | 평균만 찍는 것보다 얼마나 나은가? | 단위 없음 (1이 최고) |

보고할 때는 "R² 0.76, 평균 0.6도 오차(MAE)"처럼 **설명력과 실제 오차 크기를 함께** 말하는 것이 좋습니다.

### 자주 하는 실수

| 실수 | 왜 문제인가 | 바로잡기 |
| --- | --- | --- |
| 학습용 데이터로 R²를 재고 끝냄 | 외운 만큼 점수가 부풀려짐 | 시험용으로 다시 재기 |
| R²만 보고 "좋다/나쁘다" 판단 | R² 0.9여도 오차가 현장 허용치(예: ±0.5K)를 넘을 수 있음 | MAE·RMSE를 **현장 허용 오차와 비교** |
| 서로 다른 데이터의 MAE 비교 | 단위·크기가 다르면 비교가 안 됨 | 같은 시험용 데이터에서 모델끼리 비교 |

## 정리

- 오차 = 실제 − 예측. 여러 개를 하나로 요약할 때 MAE(절댓값 평균), RMSE(제곱 평균의 제곱근)를 씁니다.
- RMSE는 크게 틀린 것에 더 큰 벌점을 줍니다.
- R²는 "평균만 찍는 예측"과 비교한 점수로, 0이면 평균과 같고 음수면 더 못합니다.
