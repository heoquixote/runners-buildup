## 왜 해석이 필요한가

"불량을 예측했다"에서 끝나면 현장은 무엇을 바꿔야 할지 모릅니다. 모델 해석은 두 질문에 답합니다.

1. 어떤 변수가 예측에 많이 쓰였나? (**중요도**)
2. 그 변수가 커지면 예측이 어느 방향으로, 얼마나 움직이나? (**부분 의존도**, 계수)

## 트리의 피처 중요도

랜덤포레스트의 `feature_importances_`는 각 변수로 나눴을 때 불순도가 줄어든 양의 합(합 1)입니다. 빠르지만 학습 데이터 기준이고, 값의 종류가 많은 연속 변수를 과대평가하는 경향이 있습니다.

```run
import numpy as np
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
from sklearn.inspection import permutation_importance

i = np.arange(200)
X = pd.DataFrame({
    "temp": 230 + 6 * np.sin(i * 0.37) + 2 * np.cos(i * 1.91),
    "pressure": 80 + 5 * np.cos(i * 0.53) + 1.5 * np.sin(i * 2.71),
    "speed": 40 + 3 * np.sin(i * 0.83) + np.cos(i * 1.37),
    "humidity": 45 + 8 * np.cos(i * 0.97) + 2 * np.sin(i * 2.17),
})
y = (((X["temp"] - 230) / 6 + 0.6 * (X["pressure"] - 80) / 5 + 0.7 * np.sin(i * 3.33)) > 0.8).astype(int)
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.3, random_state=0, stratify=y)
rf = RandomForestClassifier(n_estimators=50, random_state=0).fit(X_tr, y_tr)
imp = pd.Series(rf.feature_importances_, index=X.columns)
perm = permutation_importance(rf, X_te, y_te, n_repeats=10, random_state=0)
print(pd.DataFrame({"impurity": imp, "permutation": perm.importances_mean}).round(3))
```

humidity는 불량과 무관하게 만든 열인데도 불순도 중요도는 0.13이나 됩니다. 순열 중요도는 거의 0입니다.

## 순열 중요도

테스트 데이터에서 한 열만 무작위로 섞어 그 열의 정보를 망가뜨린 뒤 점수가 얼마나 떨어지는지 봅니다. 모델 종류와 상관없이 쓸 수 있고, 새 데이터 기준이라 더 믿을 만합니다.

> 상관이 높은 두 열(예: 설정 온도와 실제 온도)은 하나를 섞어도 다른 하나가 정보를 대신해 둘 다 중요도가 낮게 나올 수 있습니다.

## 선형 모델은 표준화한 계수로

선형회귀 계수는 "다른 변수를 고정하고 이 변수가 1 단위 늘 때 y의 변화"입니다. 단위가 다르면 크기를 비교할 수 없으므로, 표준화 후 계수(1 표준편차 변화당 효과)로 비교합니다.

```run
import numpy as np
import pandas as pd
from sklearn.linear_model import LinearRegression
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import make_pipeline

i = np.arange(150)
X = pd.DataFrame({
    "visits": 12 + 5 * np.sin(i * 0.41) + 1.5 * np.cos(i * 1.73),
    "coupon": 2 + 1.5 * np.cos(i * 0.59) + 0.5 * np.sin(i * 2.37),
    "age": 35 + 10 * np.sin(i * 0.23) + 3 * np.cos(i * 1.31),
})
y = 3.0 * X["visits"] + 4.0 * X["coupon"] + 0.05 * X["age"] + 2 * np.sin(i * 3.11)
raw = LinearRegression().fit(X, y).coef_
std = make_pipeline(StandardScaler(), LinearRegression()).fit(X, y)[-1].coef_
print(pd.DataFrame({"raw coef": raw, "std coef": std}, index=X.columns).round(3))
```

원래 계수는 coupon(약 4.0)이 가장 크지만, visits의 흩어짐이 더 커서 실제 영향력은 visits가 더 큽니다.

## 부분 의존도(PDP)

한 변수만 여러 값으로 바꾸고 나머지는 그대로 둔 채 **평균 예측**을 그린 곡선입니다. 방향(증가/감소)과 모양(직선, 포화, 임계점)을 보여 줍니다.

```run
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.ensemble import RandomForestRegressor

i = np.arange(150)
X = pd.DataFrame({
    "visits": 12 + 5 * np.sin(i * 0.41) + 1.5 * np.cos(i * 1.73),
    "coupon": 2 + 1.5 * np.cos(i * 0.59) + 0.5 * np.sin(i * 2.37),
    "age": 35 + 10 * np.sin(i * 0.23) + 3 * np.cos(i * 1.31),
})
y = 3.0 * X["visits"] + 4.0 * X["coupon"] + 0.05 * X["age"] + 2 * np.sin(i * 3.11)
rf = RandomForestRegressor(n_estimators=50, random_state=0).fit(X, y)
grid = np.linspace(0, 4, 9)
pdp = [rf.predict(X.assign(coupon=v)).mean() for v in grid]
print([round(float(v), 1) for v in pdp])
fig, ax = plt.subplots(figsize=(5, 3))
ax.plot(grid, pdp, marker="o"); ax.set_xlabel("coupon"); ax.set_ylabel("mean prediction")
ax.set_title("Partial dependence")
plt.tight_layout(); plt.show()
```

> 해석 결과는 "모델이 그렇게 배웠다"는 뜻이지 원인 증명이 아닙니다. 현장 조치로 이어지기 전에 실험(설정을 실제로 바꿔 보기)으로 확인하세요. 더 정교한 개별 예측 설명은 SHAP 같은 도구를 씁니다.
