## 시작하기 전에

앞 레슨에서 토크·회전수가 고장 예측에 가장 중요하다는 것을 확인했습니다. 그런데 토크가 **커질 때** 위험이 오를까요, 내릴까요? 어느 지점부터 위험해질까요? 이번 레슨에서는 방향과 모양을 보는 두 방법, **계수**와 **부분 의존도**를 배웁니다.

## 방법 3: 선형 모델의 계수 (방향까지 알려 준다)

중요도는 "얼마나 중요한가"만 알려 주고, **방향**(커지면 위험이 오르나 내리나)은 알려 주지 않습니다. 로지스틱 회귀 같은 선형 모델은 계수의 **부호**로 방향을 바로 알 수 있습니다.

- 계수 **+**: 이 값이 커지면 예측 확률이 **올라간다**
- 계수 **−**: 이 값이 커지면 예측 확률이 **내려간다**

다만 열마다 단위가 다르면(나이는 0~80, 운임은 0~512) 계수 크기를 비교할 수 없습니다. 그래서 **표준화한 뒤** 계수를 봅니다. 그러면 계수는 "이 값이 보통 정도(1 표준편차) 커질 때의 효과"가 되어 서로 비교할 수 있습니다. 타이타닉 데이터로 해 봅시다.

```run
import pandas as pd
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression

df = pd.read_csv("titanic.csv")
df["female"] = (df["sex"] == "female").astype(int)
df["age"] = df["age"].fillna(df["age"].median())
features = ["pclass", "female", "age", "sibsp", "parch", "fare"]

model = make_pipeline(StandardScaler(), LogisticRegression()).fit(df[features], df["survived"])
coef = pd.Series(model[-1].coef_[0], index=features).sort_values()
print(coef.round(2))
```

- `female`이 +1.30으로 가장 큰 **+**: 여성이면 생존 확률이 크게 올라갑니다.
- `pclass`는 −0.89: 숫자가 클수록(1등실 → 3등실) 생존 확률이 내려갑니다.
- `age`도 −0.50: 나이가 많을수록 생존 확률이 내려갑니다.
- `fare`(+0.14)와 `parch`(−0.08)는 0에 가까워 영향이 작습니다. 운임은 객실 등급과 거의 같은 정보라서, 등급이 이미 들어간 뒤에는 더할 게 별로 없기 때문입니다.

"여성과 아이 먼저, 그리고 상급 객실이 구명보트에 가까웠다"는 역사적 사실과 맞아떨어집니다. 모델의 판단 근거가 상식과 맞으면 그만큼 믿을 수 있습니다.

## 방법 4: 부분 의존도 (그래프로 모양 보기)

계수는 "직선 하나의 기울기"라서 복잡한 모양은 못 보여 줍니다. 랜덤포레스트 같은 모델에서 "토크가 커지면 고장 확률이 어떻게 변하나?"를 보려면 **부분 의존도(PDP)**를 그립니다. 방법은 단순합니다.

1. 모든 설비의 토크를 **똑같이 20**으로 바꾸고, 나머지 열은 그대로 둔 채 고장 확률을 예측해 평균을 낸다.
2. 토크를 25, 30, …, 70으로 바꿔 가며 같은 일을 반복한다.
3. 토크 값(가로)과 평균 고장 확률(세로)을 선으로 잇는다.

"다른 조건은 그대로 두고 토크만 바꿨다면?"이라는 가상 실험을 하는 셈입니다.

::figure{src="content/img/ml/ml09-pdp.svg" alt="모든 설비의 torque를 20, 45, 70으로 바꿔 평균 고장 확률을 구하고, 그 값을 이어 곡선을 그린다" caption="토크 값마다 평균 예측을 구해 점으로 찍고 이으면 부분 의존도 곡선이 됩니다."}

```run
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.ensemble import RandomForestClassifier

df = pd.read_csv("ai4i2020.csv")
features = ["air_temp", "process_temp", "rpm", "torque", "tool_wear"]
rf = RandomForestClassifier(n_estimators=100, min_samples_leaf=5, random_state=0, n_jobs=1).fit(df[features], df["failure"])

sample = df[features].sample(1000, random_state=0)
grid = np.arange(20, 71, 5)
avg = []
for t in grid:
    X_new = sample.copy()
    X_new["torque"] = t
    avg.append(float(rf.predict_proba(X_new)[:, 1].mean()))
for t, a in zip(grid, avg):
    print(f"torque {t}: failure prob {a:.3f}")

plt.figure(figsize=(6, 3.5))
plt.plot(grid, avg, marker="o")
plt.xlabel("torque (Nm)")
plt.ylabel("avg predicted failure prob")
plt.title("Partial dependence of torque")
plt.show()
```

토크 20~50에서는 고장 확률이 3% 근처로 평평하다가, 55에서 8%, 60에서 31%, 70에서 87%로 **급격히 올라갑니다.** 이런 "꺾이는 지점(임계점)"은 현장에서 바로 쓸 수 있는 정보입니다. 예를 들어 "토크가 이 값을 넘으면 경고를 띄우자"는 운전 기준을 정할 수 있습니다.

> 부분 의존도는 **상관관계**를 보여 줄 뿐, "토크를 낮추면 반드시 고장이 줄어든다"는 **인과**를 증명하지는 않습니다. 실제 조치는 현장 지식과 실험으로 확인해야 합니다.

## 설비 한 대로 "만약에" 실험하기

부분 의존도는 **전체 평균**의 모양입니다. 현장에서는 "**이** 설비의 토크를 올리면 어떻게 되나?"를 묻기도 합니다. 설비 한 대의 다른 값은 그대로 두고 토크만, 또는 공구 사용 시간만 바꿔 가며 예측해 봅니다.

```run
import pandas as pd
from sklearn.ensemble import RandomForestClassifier

df = pd.read_csv("ai4i2020.csv")
features = ["air_temp", "process_temp", "rpm", "torque", "tool_wear"]
rf = RandomForestClassifier(n_estimators=100, min_samples_leaf=5, random_state=0, n_jobs=1).fit(df[features], df["failure"])

machine = df[features].iloc[[0]]
print(machine)
torque_test = pd.concat([machine] * 7, ignore_index=True)
torque_test["torque"] = [20, 30, 40, 50, 55, 60, 70]
print("torque   :", torque_test["torque"].tolist())
print("fail prob:", rf.predict_proba(torque_test)[:, 1].round(3).tolist())
wear_test = pd.concat([machine] * 5, ignore_index=True)
wear_test["tool_wear"] = [0, 100, 180, 210, 240]
print("tool_wear:", wear_test["tool_wear"].tolist())
print("fail prob:", rf.predict_proba(wear_test)[:, 1].round(3).tolist())
```

첫 번째 설비(1,551rpm, 토크 42.8Nm, 공구 0분)를 기준으로 하면:

- 토크를 50Nm까지 올려도 고장 확률은 거의 0이다가, **55Nm에서 0.022, 60Nm에서 0.25, 70Nm에서 0.889**로 급하게 뜁니다.
- 공구 사용 시간은 180분까지 0이다가 210분에서 0.017, 240분에서 0.053으로 조금씩 오릅니다(토크가 보통이라 크게 오르지는 않음).

"이 설비는 토크를 55Nm 아래로 유지하면 안전한 편"처럼 **설비별 운전 가이드**로 이어질 수 있는 결과입니다. 이렇게 한 건씩 값을 바꿔 보는 것을 **개별 조건부 기대(ICE)** 라고 부르기도 하며, 부분 의존도는 이런 선들을 모든 설비에 대해 그린 뒤 평균 낸 것입니다.

> 이것도 인과가 아닙니다. 모델이 데이터에서 본 패턴으로 예측한 것이라, 데이터에 없던 조합(예: 이 설비로 토크 70Nm 운전)은 실제와 다를 수 있습니다(ml-02-1 외삽).

### 한 건 한 건 설명하고 싶다면: SHAP

지금까지 본 방법은 "전체적으로 어떤 열이 중요한가"였습니다. 현장에서는 "**이 설비**는 왜 위험하다고 나왔나?"처럼 한 건을 설명해야 할 때도 많습니다. 이때 쓰는 대표 도구가 **SHAP**입니다. 예측 하나를 "기본값 3% + 토크 때문에 +40% + 공구 마모 때문에 +12% …"처럼 열마다 나눠서 보여 줍니다. SHAP 값을 직접 계산하는 방법은 다음 레슨 [이 한 건은 왜?: SHAP 값 직접 계산하기](#/l/ml-09-3)에서 배웁니다.

> 어떤 방법이든 **중요도가 높다 = 원인이다**가 아닙니다. 모델이 그 열을 많이 참고했다는 뜻일 뿐입니다. 그리고 한 모델의 중요도는 그 모델 기준이라, 모델을 바꾸면 순서가 달라질 수 있습니다.

## 정리

| 방법 | 알려 주는 것 | 장점 | 주의 |
| --- | --- | --- | --- |
| `feature_importances_` | 트리가 많이 쓴 열 | 빠름, 바로 나옴 | 학습 데이터 기준, 무의미한 숫자 열도 높게 나올 수 있음 |
| 순열 중요도 | 섞었을 때 점수가 떨어지는 열 | 어떤 모델에도 사용, 테스트 데이터 기준 | 비슷한 열끼리는 서로 가려 줌 |
| 표준화한 계수 | 방향(+/−)과 크기 | 해석이 쉬움 | 선형 모델에서만, 표준화 필수 |
| 부분 의존도 | 값이 바뀔 때 예측이 변하는 모양 | 임계점 같은 모양이 보임 | 인과가 아님 |
