## 시작하기 전에

[머신러닝 시작하기](#/l/ml-00-1)에서 머신러닝은 **예시(X)와 정답(y)을 보여 주고, 컴퓨터가 맞히는 규칙(모델)을 찾게 하는 것**이고, 항상 **학습(fit) → 예측(predict)** 두 단계로 움직인다고 배웠습니다. 이때 쓴 `DecisionTreeClassifier`가 바로 이번에 소개할 **scikit-learn**의 모델입니다.

머신러닝 모델은 종류가 아주 많습니다. 결정트리, 로지스틱 회귀, KNN, 랜덤포레스트… 만약 모델마다 사용법이 전부 다르다면 어떨까요? 새 모델을 써 볼 때마다 설명서를 처음부터 읽고, 코드를 통째로 다시 짜야 합니다. scikit-learn은 이 문제를 **"모든 모델의 사용법을 똑같이 맞춘다"**는 약속으로 풀었습니다.

## scikit-learn은 무엇인가

**scikit-learn**(사이킷런)은 **머신러닝 모델, 데이터 손질 도구, 평가 도구를 같은 사용법으로 모아 둔 라이브러리**입니다. 공구 상자에 비유하면, 공구(모델)는 수십 가지인데 손잡이 모양이 전부 같아서 어느 공구든 같은 방법으로 쥐고 쓰면 됩니다.

이름은 과학 계산 라이브러리 SciPy의 확장 도구(**S**ci**Py** **Kit**, 줄여서 scikit) 중 머신러닝(**learn**)을 맡은 것이라는 뜻입니다. 주의할 점이 하나 있습니다. 설치할 때 이름과 불러올 때 이름이 다릅니다.

- 설치: `pip install scikit-learn`
- 불러오기: `from sklearn.tree import DecisionTreeClassifier`처럼 **`sklearn`**

::figure{src="content/img/libs/lib-map-sklearn.svg" alt="파이썬 위에 NumPy, 그 위에 pandas, matplotlib, scikit-learn, matplotlib 위에 seaborn이 있고 오른쪽에 PyTorch가 있다. scikit-learn이 강조되어 있다" caption="scikit-learn은 NumPy 위에 있고, pandas 표를 그대로 받아 학습합니다."}

## 버튼은 세 개: fit · predict · score

scikit-learn의 모든 모델에는 같은 이름의 버튼이 달려 있습니다.

| 버튼 | 하는 일 | 머신러닝 단계 |
| --- | --- | --- |
| `model.fit(X, y)` | 예시와 정답을 보고 규칙 찾기 | 학습 |
| `model.predict(X)` | 처음 보는 X에 답 내기 | 예측 |
| `model.score(X, y)` | 정답과 비교해 몇 % 맞혔는지 | 채점 |

::figure{src="content/img/libs/sk-api.svg" alt="결정트리, 로지스틱 회귀, KNN 세 모델 카드에 모두 똑같이 fit(X, y) 학습, predict(X) 예측, score(X, y) 채점 버튼이 있다" caption="모델이 달라도 버튼은 같습니다. 모델을 만드는 한 줄만 바꾸면 나머지 코드는 그대로입니다."}

타이타닉 승객의 객실 등급(`pclass`), 나이(`age`), 운임(`fare`)으로 생존 여부를 맞혀 봅니다. 나이가 빈 승객은 빼고, 승객의 4분의 3으로 학습한 뒤 남은 4분의 1로 채점합니다. 학습에 쓴 문제로 채점하면 답을 외운 모델도 100점이 나오기 때문에, 시험용은 따로 떼어 둡니다(자세한 이유는 [학습용과 시험용 나누기](#/l/ml-01-4)에서 배웁니다).

```run
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier

df = pd.read_csv("titanic.csv").dropna(subset=["age"])
X = df[["pclass", "age", "fare"]]
y = df["survived"]
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.25, random_state=0)

model = DecisionTreeClassifier(max_depth=3, random_state=0)
model.fit(X_train, y_train)                  # 학습
print(round(model.score(X_test, y_test), 3))  # 채점
```

처음 보는 승객 179명 중 67.6%를 맞혔습니다. 코드에서 scikit-learn이 한 일은 세 줄입니다. `train_test_split`으로 나누고, `fit`으로 학습하고, `score`로 채점했습니다. `random_state=0`은 무작위로 나눌 때 매번 같은 결과가 나오게 고정하는 번호입니다.

학습한 모델에 새 승객 두 명을 넣어 `predict`로 예측해 봅니다. 둘 다 30살이고, 한 명은 1등실(운임 80), 한 명은 3등실(운임 8)입니다.

```run
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier

df = pd.read_csv("titanic.csv").dropna(subset=["age"])
X = df[["pclass", "age", "fare"]]
y = df["survived"]
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.25, random_state=0)
model = DecisionTreeClassifier(max_depth=3, random_state=0)
model.fit(X_train, y_train)

new = pd.DataFrame({"pclass": [1, 3], "age": [30, 30], "fare": [80.0, 8.0]})
print(model.predict(new))
```

`[1 0]`: 1등실 승객은 생존(1), 3등실 승객은 사망(0)으로 예측했습니다. 새 데이터는 학습할 때와 **같은 열 이름 · 같은 순서**로 넣어야 합니다.

## 모델 갈아 끼우기

이제 scikit-learn의 진짜 장점을 봅니다. 결정트리 대신 **로지스틱 회귀**를 써 봅니다. 바뀌는 곳은 `import` 한 줄과 모델을 만드는 한 줄뿐입니다.

```run
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression

df = pd.read_csv("titanic.csv").dropna(subset=["age"])
X = df[["pclass", "age", "fare"]]
y = df["survived"]
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.25, random_state=0)

model = LogisticRegression()        # ← 이 줄만 바꿨다
model.fit(X_train, y_train)
print(round(model.score(X_test, y_test), 3))
```

로지스틱 회귀는 65.9%입니다. `fit`과 `score` 줄은 한 글자도 바뀌지 않았습니다. 직접 해 보세요. 맨 위 import를 `from sklearn.neighbors import KNeighborsClassifier`로, 모델 줄을 `model = KNeighborsClassifier()`로 바꾸면 KNN 모델의 점수(61.5%)가 나옵니다.

:::tip 점수가 왜 70%도 안 될까
지금은 `sex`(성별)를 빼고 숫자 열 3개만 썼습니다. 성별은 글자라서 모델이 바로 받지 못하기 때문입니다. 글자를 숫자로 바꾸는 [인코딩](#/l/ml-01-3)을 배우면 성별을 넣을 수 있고, 같은 결정트리의 점수가 약 80%로 오릅니다. 모델보다 **데이터 준비**가 점수를 더 크게 바꾸는 경우가 많다는 것이 이 코스 전체의 주제입니다.
:::

## 서랍 지도: sklearn. 뒤에 붙는 이름

scikit-learn의 도구는 하는 일에 따라 서랍(모듈)에 나뉘어 있습니다. `from sklearn.서랍 import 도구` 모양이라서 서랍 이름만 봐도 무슨 일을 하는 도구인지 짐작할 수 있습니다.

## scikit-learn의 역사

| 해 | 일 |
| --- | --- |
| 2007 | 구글이 학생 개발자를 지원하는 여름 프로그램(Google Summer of Code)에서 **데이비드 쿠르나포**(David Cournapeau)가 시작 |
| 2010 | 프랑스 국립 연구소 **INRIA**의 연구자들이 이어받아 첫 공개 버전 발표 |
| 2011 | 학술지 *JMLR*에 소개 논문 발표. 이후 머신러닝 수업과 실무의 표준 도구가 됨 |
| 2021 | **1.0** 발표 |

scikit-learn의 가장 큰 발명은 새로운 모델이 아니라 **"모든 모델을 같은 버튼으로"**라는 약속입니다. 이 약속 덕분에 XGBoost, LightGBM 같은 다른 회사 · 단체의 모델도 같은 `fit` · `predict` 버튼을 달고 나와, scikit-learn 코드에 그대로 끼워 쓸 수 있습니다.

## 잘하는 것과 다른 도구에 맡기는 것

| scikit-learn이 잘하는 것 | 다른 도구가 맡는 것 |
| --- | --- |
| 표 데이터(엑셀 · CSV 모양)의 회귀 · 분류 · 군집 | 사진 · 소리 · 긴 글 → 딥러닝 도구(PyTorch 등) |
| 결측치 · 인코딩 · 표준화 같은 손질 | 수억 행 같은 아주 큰 데이터 → 분산 처리 도구 |
| 교차검증 · 하이퍼파라미터 찾기 · 평가지표 | GPU 계산 → 딥러닝 도구 |

표 데이터 문제는 실무에서도 대부분 scikit-learn(과 같은 버튼을 단 모델들)으로 풉니다. 딥러닝이 필요한 문제는 딥러닝 트랙에서 다룹니다.

## 정리

- **scikit-learn** = 모델 · 손질 · 평가 도구를 같은 사용법으로 모은 머신러닝 공구 상자. 설치는 `scikit-learn`, 불러오기는 `sklearn`
- 모든 모델의 버튼은 `fit`(학습) · `predict`(예측) · `score`(채점)
- 모델을 바꿀 때는 import와 모델 만드는 줄만 바꾼다
- 채점은 학습에 쓰지 않은 시험용 데이터로 한다
