## 선형회귀: 직선 하나

y ≈ 기울기 · x + 절편. 데이터와 직선 사이 오차 제곱합이 가장 작은 직선을 찾습니다(최소제곱).

```run
import numpy as np
from sklearn.linear_model import LinearRegression

temp = np.array([45, 48, 50, 53, 56, 59])
thick = np.array([7.6, 8.1, 8.3, 8.8, 9.3, 9.8])
model = LinearRegression().fit(temp.reshape(-1, 1), thick)   # X는 2차원
print("기울기", round(model.coef_[0], 4), "절편", round(model.intercept_, 3))
print("55℃ 예측", round(model.predict([[55]])[0], 3))
print("R²", round(model.score(temp.reshape(-1, 1), thick), 4))
```

> 기울기 0.156은 "온도 1℃ 오를 때 두께가 약 0.156µm 늘어난다"로 읽습니다. 데이터 범위 밖(예: 80℃)으로 외삽하면 믿기 어렵습니다.

## 경사하강법: 오차를 줄이는 방향으로 조금씩

모델은 손실(오차)을 계산하고, 손실이 줄어드는 방향으로 계수를 조금씩 움직이며 학습합니다. 학습률이 너무 크면 튀고, 너무 작으면 느립니다.

::video{ref="dl-m09"}

```run
import numpy as np

x = np.array([1.0, 2.0, 3.0, 4.0]); y = np.array([2.1, 3.9, 6.2, 7.8])
w, b, lr = 0.0, 0.0, 0.05
for step in range(201):
    pred = w * x + b
    loss = np.mean((pred - y) ** 2)
    w -= lr * np.mean(2 * (pred - y) * x)
    b -= lr * np.mean(2 * (pred - y))
    if step % 50 == 0:
        print(f"step {step:>3}  loss {loss:.4f}  w {w:.3f}  b {b:.3f}")
```

## 로지스틱 회귀: 확률로 분류

선형 결합을 시그모이드 함수로 0~1 사이 확률로 바꿉니다. 이름은 회귀지만 분류 모델입니다.

```run
import numpy as np
from sklearn.linear_model import LogisticRegression

hours = np.array([[1], [2], [3], [4], [5], [6], [7], [8]])
passed = np.array([0, 0, 0, 1, 0, 1, 1, 1])
clf = LogisticRegression().fit(hours, passed)
print("합격 확률", clf.predict_proba([[2], [4.5], [7]])[:, 1].round(3))
print("판정", clf.predict([[2], [4.5], [7]]))
```

`predict`는 확률 0.5를 기준으로 자릅니다. 이 기준(임계값)을 바꾸는 이야기가 다음 코스 평가지표입니다.
