## 예측에는 두 종류가 있다

| 종류 | 맞히는 것 | 예 |
| --- | --- | --- |
| **회귀(regression)** | 숫자 | 내일 기온, 공정 온도, 집값 |
| **분류(classification)** | 범주(종류) | 생존/사망, 고장/정상, 스팸/정상 |

::figure{src="content/img/ml/ml02-reg-vs-clf.svg" alt="회귀는 점들 사이로 직선을 긋고, 분류는 두 종류의 점을 경계선으로 가른다" caption="회귀는 숫자를, 분류는 종류를 맞힙니다."}

이번 레슨에서는 가장 기본 모델인 **선형회귀**(숫자 예측)와 **로지스틱 회귀**(분류)를 배웁니다. 이름이 비슷하지만 로지스틱 회귀는 분류 모델입니다.

## 선형회귀: 자를 대고 선 긋기

점들이 대략 한 방향으로 늘어서 있으면, 그 사이를 지나는 **직선 하나**를 그어 볼 수 있습니다. 직선은 `y = 기울기 × x + 절편`으로 표현됩니다.

- **기울기**: x가 1 늘 때 y가 얼마나 느는지
- **절편**: x가 0일 때의 y

선형회귀는 "모든 점과의 차이(오차)가 가장 작아지는" 직선을 자동으로 찾아 줍니다. 직선을 조금씩 움직여 보며 오차가 줄어드는 쪽으로 계속 옮기는 방법을 **경사하강법**이라고 부릅니다. 안개 낀 산에서 발밑이 내려가는 쪽으로 한 걸음씩 걸어 골짜기(오차가 가장 작은 곳)를 찾는 것과 같습니다.

::video{ref="dl-m09"}

AI4I 설비 데이터에서 **주변 공기 온도**와 **공정 온도**의 관계를 봅니다. 공장 안이 더우면 공정도 뜨거워지겠죠? (단위는 켈빈 K, 섭씨 + 273)

```run
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv("ai4i2020.csv").sample(500, random_state=0)
fig, ax = plt.subplots(figsize=(5, 3.5))
ax.scatter(df["air_temp"], df["process_temp"], s=8, alpha=0.5)
ax.set_xlabel("air temperature (K)"); ax.set_ylabel("process temperature (K)")
ax.set_title("AI4I: air vs process temperature")
plt.tight_layout(); plt.show()
print(df[["air_temp", "process_temp"]].corr().round(3))
```

점들이 오른쪽 위로 뚜렷하게 올라갑니다. 상관계수(함께 움직이는 정도, −1~1) 약 0.86으로 매우 강한 관계입니다.

## LinearRegression으로 직선 찾기

scikit-learn 모델은 모두 같은 순서로 씁니다.

1. 모델 만들기: `model = LinearRegression()`
2. 학습(fit): `model.fit(X, y)` — 데이터를 보고 기울기·절편을 찾음
3. 예측(predict): `model.predict(새 X)`

X는 **2차원**(표 모양)이어야 해서, 열 하나만 쓸 때도 `df[["air_temp"]]`처럼 대괄호를 두 번 씁니다.

```run
import pandas as pd
from sklearn.linear_model import LinearRegression

df = pd.read_csv("ai4i2020.csv")
X = df[["air_temp"]]          # 2D: one column table
y = df["process_temp"]
model = LinearRegression().fit(X, y)
print("slope:", round(model.coef_[0], 3))
print("intercept:", round(model.intercept_, 2))
print("predict at 302 K:", model.predict(pd.DataFrame({"air_temp": [302.0]})).round(2))
print("R^2:", round(model.score(X, y), 3))
```

기울기가 약 0.65라는 것은 공기 온도가 1도 오르면 공정 온도는 평균적으로 약 0.65도 오른다는 뜻입니다.

**R²(결정계수)**는 0~1 사이 점수로, 1에 가까울수록 직선이 데이터를 잘 설명한다는 뜻입니다. 0.77이면 공정 온도 변화의 약 77%를 공기 온도 하나로 설명한다는 의미입니다.

### 오차는 어떻게 잴까: MAE, RMSE

R²는 "얼마나 잘 설명하나"를 0~1로 보여 주지만, **실제로 몇 도나 틀리는지**는 알려 주지 않습니다. 현장에서는 이 질문이 더 중요할 때가 많습니다. 그래서 오차를 직접 재는 지표를 함께 봅니다.

- **MAE(평균 절대 오차)**: 틀린 크기를 그대로 평균. "평균적으로 몇 도 틀리나?" 읽기 가장 쉽습니다.
- **RMSE(평균 제곱 오차의 제곱근)**: 틀린 크기를 제곱해서 평균 낸 뒤 다시 제곱근. 크게 틀린 것에 **벌점을 더 크게** 줍니다. 가끔 크게 틀리면 안 되는 상황에서 봅니다.

```run
import numpy as np
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_absolute_error, mean_squared_error, r2_score

df = pd.read_csv("ai4i2020.csv")
X_train, X_test, y_train, y_test = train_test_split(df[["air_temp"]], df["process_temp"], test_size=0.25, random_state=0)
pred = LinearRegression().fit(X_train, y_train).predict(X_test)
print("MAE :", round(mean_absolute_error(y_test, pred), 3), "K")
print("RMSE:", round(float(np.sqrt(mean_squared_error(y_test, pred))), 3), "K")
print("R^2 :", round(r2_score(y_test, pred), 3))
```

이번에는 학습용으로 배우고 **시험용으로 평가**했습니다(ml-01에서 배운 순서). MAE가 약 0.59이면 "공정 온도를 평균 0.6도 정도 틀리게 예측한다"는 뜻입니다. RMSE(0.72)가 MAE보다 조금 큰 것은 가끔 크게 틀리는 경우가 섞여 있기 때문입니다. 숫자 하나만 보지 말고 **R²(설명력)와 MAE(실제 오차 크기)를 함께** 보는 습관을 들이세요.

## 특성을 여러 개 쓰면

X에 열을 여러 개 넣으면 `y = a₁x₁ + a₂x₂ + … + 절편` 모양이 됩니다. 계수마다 "다른 값은 그대로 두고 이 값만 1 늘면 y가 얼마나 변하나"를 뜻합니다.

```run
import pandas as pd
from sklearn.linear_model import LinearRegression

df = pd.read_csv("ai4i2020.csv")
X = df[["air_temp", "rpm", "torque"]]
y = df["process_temp"]
model = LinearRegression().fit(X, y)
for name, c in zip(X.columns, model.coef_):
    print(f"{name:>9}: {c:+.4f}")
print("R^2:", round(model.score(X, y), 3))
```

회전수·토크 계수는 0에 가깝습니다. 공정 온도는 거의 공기 온도로만 정해진다는 뜻입니다. 이렇게 계수를 보면 어떤 특성이 중요한지도 짐작할 수 있습니다.

### 직접 해보기

`features` 목록을 `["rpm"]`, `["air_temp"]`, `["air_temp", "rpm", "torque"]`로 바꿔 가며 R²를 비교해 보세요. 회전수만 쓰면 R²가 거의 0이고, 공기 온도가 들어가는 순간 크게 오릅니다. **어떤 특성을 넣느냐가 모델 성능을 좌우한다**는 것을 직접 확인할 수 있습니다.

```run
import pandas as pd
from sklearn.linear_model import LinearRegression

df = pd.read_csv("ai4i2020.csv")
features = ["rpm"]   # <- change me
model = LinearRegression().fit(df[features], df["process_temp"])
print(features, "-> R^2:", round(model.score(df[features], df["process_temp"]), 3))
```

## 로지스틱 회귀: 확률로 분류하기

생존(1)/사망(0)처럼 답이 둘 중 하나일 때 직선을 그대로 쓰면 1보다 크거나 0보다 작은 이상한 값이 나옵니다. 로지스틱 회귀는 직선의 결과를 **S자 곡선(시그모이드)**에 통과시켜 0~1 사이 **확률**로 바꿉니다.

::figure{src="content/img/ml/ml02-sigmoid.svg" alt="직선의 점수를 S자 곡선에 통과시켜 0에서 1 사이 확률로 바꾸고, 0.5를 넘으면 1로 판정" caption="직선이 내는 점수는 끝없이 커지거나 작아지지만, S자 곡선을 거치면 항상 0~1 사이 확률이 됩니다."}

- 확률 0.5 이상 → 1(생존)로 판정
- 확률 0.5 미만 → 0(사망)으로 판정

```run
import numpy as np
import matplotlib.pyplot as plt

z = np.linspace(-6, 6, 100)
fig, ax = plt.subplots(figsize=(5, 3))
ax.plot(z, 1 / (1 + np.exp(-z)))
ax.axhline(0.5, color="gray", ls="--"); ax.set_title("Sigmoid: any number -> 0~1")
ax.set_xlabel("linear score"); ax.set_ylabel("probability")
plt.tight_layout(); plt.show()
print("score 0 -> prob", 1 / (1 + np.exp(0)))
```

## 타이타닉 생존 확률 예측

이제 타이타닉 데이터로 로지스틱 회귀를 학습합니다. 숫자 크기가 다른 열(나이 0~80, 운임 0~500)이 섞여 있어서 **표준화**(크기 맞추기)를 함께 붙입니다. `make_pipeline`은 여러 단계를 한 줄로 이어 주는 도구입니다.

```run
import numpy as np
import pandas as pd
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression

df = pd.read_csv("titanic.csv")
df["female"] = (df["sex"] == "female").astype(int)
df["age"] = df["age"].fillna(df["age"].median())
features = ["pclass", "female", "age", "fare"]
model = make_pipeline(StandardScaler(), LogisticRegression()).fit(df[features], df["survived"])

people = pd.DataFrame({"pclass": [1, 3], "female": [1, 0], "age": [30, 30], "fare": [80.0, 8.0]})
print(people)
print("survival probability:", model.predict_proba(people)[:, 1].round(3))
print("prediction (0.5 cut):", model.predict(people))
```

`predict_proba`는 [사망 확률, 생존 확률] 두 열을 돌려줍니다. `[:, 1]`이 생존 확률입니다. 1등실 30세 여성은 약 93%, 3등실 30세 남성은 약 9%로 예측됩니다.

## 계수로 해석하기

표준화한 뒤의 계수는 서로 크기를 비교할 수 있습니다. **+는 생존 확률을 올리고, −는 내리는** 방향입니다.

```run
import pandas as pd
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression

df = pd.read_csv("titanic.csv")
df["female"] = (df["sex"] == "female").astype(int)
df["age"] = df["age"].fillna(df["age"].median())
features = ["pclass", "female", "age", "fare"]
model = make_pipeline(StandardScaler(), LogisticRegression()).fit(df[features], df["survived"])
print(pd.Series(model[-1].coef_[0], index=features).round(2))
```

- `female`가 가장 큰 +: 여성일수록 생존 확률이 높다
- `pclass`가 −: 등급 숫자가 클수록(3등실) 생존 확률이 낮다
- `age`가 −: 나이가 많을수록 조금 낮다
- `fare`는 0에 가까움: 운임 정보는 객실 등급과 겹쳐서 따로 더해 주는 정보가 적다

> 계수는 "모델이 이렇게 배웠다"는 뜻이지 원인을 증명하는 것은 아닙니다. 하지만 역사적 사실과 맞는지 확인하면 모델을 믿을 수 있는지 판단하는 데 도움이 됩니다.

## 정리

- 숫자를 예측하면 **회귀**, 종류를 예측하면 **분류**
- 모든 모델은 `fit`(학습) → `predict`(예측) 순서
- 선형회귀: 직선, 계수 = 기울기, 점수 = R², 실제 오차 크기 = MAE · RMSE
- 로지스틱 회귀: 직선 + S자 곡선 → 확률, 0.5 기준으로 판정

- 확률(0.93)과 판정(1)은 다르다. 판정 기준선 0.5는 상황에 따라 바꿀 수 있다 (ml-03)
