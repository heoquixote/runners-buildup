## 선형회귀: 자를 대고 선 긋기

점들이 대략 한 방향으로 늘어서 있으면, 그 사이를 지나는 **직선 하나**를 그어 볼 수 있습니다. 직선은 `y = 기울기 × x + 절편`으로 표현됩니다.

- **기울기**: x가 1 늘 때 y가 얼마나 느는지
- **절편**: x가 0일 때의 y

선형회귀는 "모든 점과의 차이(오차)가 가장 작아지는" 직선을 자동으로 찾아 줍니다. 컴퓨터가 그 직선을 **어떻게** 찾는지는 [모델은 어떻게 직선을 찾을까: 경사하강법](#/l/ml-02-3)에서 직접 구현해 봅니다.

::video{ref="dl-m22"}

AI4I 설비 데이터에서 **주변 공기 온도**와 **공정 온도**의 관계를 봅니다. 공장 안이 더우면 공정도 뜨거워지겠죠? (단위는 켈빈 K, 섭씨 + 273)

```run
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv("ai4i2020.csv").sample(500, random_state=0)
fig, ax = plt.subplots(figsize=(5, 3.5))
ax.scatter(df["air_temp"], df["process_temp"], s=8, alpha=0.5)
ax.set_xlabel("air temperature (K)"); ax.set_ylabel("process temperature (K)")
ax.set_title("AI4I: air vs process temperature")
plt.tight_layout(); plt.show()
print(df[["air_temp", "process_temp"]].corr().round(3))
```

점들이 오른쪽 위로 뚜렷하게 올라갑니다. 상관계수(함께 움직이는 정도, −1~1) 약 0.86으로 매우 강한 관계입니다.

## LinearRegression으로 직선 찾기

scikit-learn 모델은 모두 같은 순서로 씁니다.

1. 모델 만들기: `model = LinearRegression()`
2. 학습(fit): `model.fit(X, y)` — 데이터를 보고 기울기·절편을 찾음
3. 예측(predict): `model.predict(새 X)`

X는 **2차원**(표 모양)이어야 해서, 열 하나만 쓸 때도 `df[["air_temp"]]`처럼 대괄호를 두 번 씁니다.

```run
import pandas as pd
from sklearn.linear_model import LinearRegression

df = pd.read_csv("ai4i2020.csv")
X = df[["air_temp"]]          # 2D: one column table
y = df["process_temp"]
model = LinearRegression().fit(X, y)
print("slope:", round(model.coef_[0], 3))
print("intercept:", round(model.intercept_, 2))
print("predict at 302 K:", model.predict(pd.DataFrame({"air_temp": [302.0]})).round(2))
print("R^2:", round(model.score(X, y), 3))
```

기울기가 약 0.65라는 것은 공기 온도가 1도 오르면 공정 온도는 평균적으로 약 0.65도 오른다는 뜻입니다.

마지막 줄의 **R²(결정계수)**는 "직선이 데이터를 얼마나 잘 설명하나"를 나타내는 점수입니다(1에 가까울수록 좋음). 0.77이 정확히 무슨 뜻인지는 다음 레슨에서 오차를 재는 방법과 함께 자세히 봅니다.

## 찾은 직선을 점 위에 겹쳐 보기

숫자(기울기·절편)만 보면 감이 잘 안 옵니다. 점 위에 직선을 직접 그려 봅니다.

```run
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.linear_model import LinearRegression

df = pd.read_csv("ai4i2020.csv")
model = LinearRegression().fit(df[["air_temp"]], df["process_temp"])
sample = df.sample(500, random_state=0)
line_x = pd.DataFrame({"air_temp": np.linspace(295, 305, 50)})
fig, ax = plt.subplots(figsize=(5, 3.5))
ax.scatter(sample["air_temp"], sample["process_temp"], s=8, alpha=0.4, label="data")
ax.plot(line_x["air_temp"], model.predict(line_x), color="red", label="fitted line")
ax.set_xlabel("air temperature (K)"); ax.set_ylabel("process temperature (K)")
ax.legend(); plt.tight_layout(); plt.show()
print("line: process_temp =", round(model.coef_[0], 3), "x air_temp +", round(model.intercept_, 2))
```

빨간 직선이 점 무리의 한가운데를 지나갑니다. 직선 위·아래로 흩어진 점과 직선 사이의 세로 거리가 바로 다음 레슨에서 잴 **오차**입니다.

### 예측값을 손으로 계산해 보기

`predict`가 하는 일은 사실 직선 공식에 값을 넣는 것뿐입니다. 앞에서 구한 기울기 약 0.650, 절편 약 115.04를 쓰면 공기 온도 302K일 때

`0.650 × 302 + 115.04 ≈ 311.3`

으로, `predict`가 낸 311.3과 같습니다. 모델이 "학습했다"는 것은 결국 **좋은 기울기와 절편 두 숫자를 찾았다**는 뜻입니다.

## 직선을 믿으면 안 되는 곳: 데이터 범위 밖

이 데이터의 공기 온도는 295.3K~304.5K 사이에만 있습니다. 그 밖의 값을 넣어도 모델은 아무 말 없이 숫자를 내놓습니다.

```run
import pandas as pd
from sklearn.linear_model import LinearRegression

df = pd.read_csv("ai4i2020.csv")
print("air_temp range:", df["air_temp"].min(), "~", df["air_temp"].max())
model = LinearRegression().fit(df[["air_temp"]], df["process_temp"])
print(model.predict(pd.DataFrame({"air_temp": [273.0, 400.0]})).round(1))
```

공기 온도 273K(0℃, 겨울 공장)이면 공정 온도 292.5K, 400K(127℃)이면 375.0K라고 답합니다. 하지만 데이터에 그런 상황이 한 번도 없었으니, 그 범위에서도 같은 직선이 맞는다는 보장은 없습니다. 이렇게 **본 적 없는 범위로 직선을 늘려 예측하는 것**을 **외삽(extrapolation)**이라고 하며, 실무에서 가장 흔한 실수 중 하나입니다.

> 모델은 "모르겠다"고 말하지 않습니다. 새 값이 학습 데이터 범위 안에 있는지는 사람이 확인해야 합니다.

## 원리 한 걸음 더: 직선은 공식으로 바로 나온다

`LinearRegression`은 직선을 "찾아다니지" 않고 공식으로 한 번에 계산합니다. 목표는 **오차 제곱합**을 가장 작게 만드는 것입니다.

`SSE = Σ (y − (a·x + b))²`

- y: 실제 값, a·x + b: 직선의 예측, Σ: 모든 행에 대해 더하기
- 오차를 제곱하는 이유: +와 −가 서로 지워지지 않게 하고, 크게 틀린 것에 더 큰 벌점을 주기 위해서입니다.

SSE를 a와 b로 미분해 0이 되는 곳을 풀면(가장 낮은 골짜기) 다음 공식이 나옵니다.

`a = Σ(x − x̄)(y − ȳ) ÷ Σ(x − x̄)²`,  `b = ȳ − a·x̄`

- 분자는 "x와 y가 평균에서 **함께** 벗어나는 정도"(공분산), 분모는 "x가 평균에서 벗어나는 정도"(분산)입니다. 즉 **기울기 = 공분산 ÷ x의 분산**입니다.
- 두 번째 식은 직선이 항상 **평균점 (x̄, ȳ)** 을 지난다는 뜻입니다.

```run
import pandas as pd
from sklearn.linear_model import LinearRegression

df = pd.read_csv("ai4i2020.csv")
x, y = df["air_temp"], df["process_temp"]
a = ((x - x.mean()) * (y - y.mean())).sum() / ((x - x.mean()) ** 2).sum()
b = y.mean() - a * x.mean()
model = LinearRegression().fit(df[["air_temp"]], y)
print(f"by formula : slope {a:.4f}, intercept {b:.2f}")
print(f"by sklearn : slope {model.coef_[0]:.4f}, intercept {model.intercept_:.2f}")
```

공식으로 구한 값(기울기 0.6499, 절편 115.04)과 사이킷런의 값이 똑같습니다.

:::tip 특성이 여러 개일 때: 정규방정식
특성이 여러 개면 같은 계산을 행렬로 씁니다. 맨 앞에 1로 채운 열(절편용)을 붙인 특성 표를 X라 하면 계수 묶음 β는

`β = (XᵀX)⁻¹ Xᵀ y`

입니다(정규방정식). 넘파이로는 `np.linalg.solve(X.T @ X, X.T @ y)` 한 줄이고, AI4I의 공기 온도 · 회전수 · 토크로 계산하면 사이킷런과 같은 계수(0.6499, −0.0000822, −0.00159)가 나옵니다. 특성이 아주 많으면(수만 개) 이 행렬 계산이 무거워져서 [경사하강법](#/l/ml-02-3)으로 조금씩 찾아갑니다.
:::

## 정리

- 회귀는 **숫자**를, 분류는 **종류**를 맞힙니다.
- 선형회귀는 `y = 기울기 × x + 절편` 직선을 찾습니다. 기울기 0.65 = 공기 온도가 1도 오르면 공정 온도가 약 0.65도 오른다.
- scikit-learn 모델은 모두 **만들기 → `fit` → `predict`** 순서이고, X는 `df[["열"]]`처럼 2차원 표로 넣습니다.
- `predict`는 직선 공식에 값을 넣는 것과 같습니다(0.650 × 302 + 115.04 ≈ 311.3).
- 학습 데이터 범위(295~305K) 밖으로 늘려 예측하는 **외삽**은 믿을 수 없습니다.
