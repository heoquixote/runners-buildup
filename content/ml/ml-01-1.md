## 시작하기 전에

[머신러닝 시작하기](#/l/ml-00-1)에서 머신러닝은 **예시와 정답을 잔뜩 보여 주고 컴퓨터가 스스로 규칙을 찾게 하는 방법**이라고 배웠습니다. 이 코스([ML 워크플로와 데이터 준비](#/l/ml-01-1))에서는 모델을 만들기 **전에** 꼭 해야 하는 준비를 다섯 레슨에 걸쳐 하나씩 해 봅니다.

1. 데이터를 표로 읽고 X(특성)와 y(정답) 구분하기 ← 이번 레슨
2. 빈칸(결측치) 다루기
3. 글자(범주)를 숫자로 바꾸기(인코딩)
4. 학습용과 시험용으로 나누기
5. "찍어도 이 정도"인 기준 점수 알기, 시험지를 미리 보는 실수(누수) 피하기

## 데이터, 특성(X), 정답(y)

머신러닝에서 데이터는 보통 **표**입니다. 엑셀 시트를 떠올리면 됩니다.

- **행(가로 한 줄)**: 사례 하나. 승객 한 명, 설비 기록 한 건
- **특성(feature, X)**: 예측에 쓰는 정보. 나이, 성별, 객실 등급…
- **정답(target, label, y)**: 맞히고 싶은 값. 생존했나(1) 못 했나(0)

::figure{src="content/img/ml/ml01-table-xy.svg" alt="타이타닉 표에서 pclass·sex·age·fare 열은 특성 X, survived 열은 정답 y, 가로 한 줄은 승객 한 명" caption="표의 가로 한 줄이 사례 하나, 예측에 쓰는 열이 X, 맞히고 싶은 열이 y입니다."}

먼저 이 강의에서 계속 쓸 **타이타닉 승객 데이터**를 불러와 봅니다. 1912년 타이타닉호 승객 891명의 실제 기록입니다.

```run
import pandas as pd

df = pd.read_csv("titanic.csv")
print(df.shape)          # (rows, columns)
print(df[["survived", "pclass", "sex", "age", "fare"]].head())
```

`survived`가 정답(y)이고, 나머지 열 중에서 골라 특성(X)으로 씁니다. 실행 결과의 `NaN`은 값이 비어 있다는 뜻입니다(나이를 모르는 승객).

### 한 줄을 자세히 보기

표 전체를 보기 전에, 사례 **하나**를 끝까지 읽어 보면 각 열이 무슨 뜻인지 감이 옵니다. `df.iloc[0]`은 0번째 행(첫 승객)을 세로로 펼쳐 보여 줍니다.

```run
import pandas as pd

df = pd.read_csv("titanic.csv")
print(df.iloc[0])
```

첫 승객은 3등실(`pclass` 3), 남성, 22살, 형제·배우자 1명과 함께 탔고(`sibsp` 1), 운임 7.25파운드를 내고 사우샘프턴(`S`)에서 탔습니다. 결과는 `survived` 0, 즉 생존하지 못했습니다.

그런데 자세히 보면 **같은 정보를 다르게 적은 열**이 섞여 있습니다.

| 원래 열 | 같은 뜻의 다른 열 |
| --- | --- |
| `pclass` (3) | `class` (Third) |
| `embarked` (S) | `embark_town` (Southampton) |
| `survived` (0) | `alive` (no) |

`alive`는 정답을 글자로 다시 쓴 것이라 특성으로 쓰면 안 됩니다([기준 모델과 누수](#/l/ml-01-5)에서 직접 확인합니다). 이렇게 **열마다 "이건 무슨 뜻이고, 예측하는 순간에 알 수 있나?"**를 확인하는 것이 데이터를 들여다보는 첫 단계입니다.

## 데이터를 먼저 들여다보기

모델을 만들기 전에 사람이 먼저 데이터를 봐야 합니다. 어떤 특성이 정답과 관련 있어 보이는지 감을 잡는 단계입니다.

```run
import pandas as pd

df = pd.read_csv("titanic.csv")
print("overall survival rate:", round(df["survived"].mean(), 3))
print(df.groupby("sex")["survived"].mean().round(3))
print(df.groupby("pclass")["survived"].mean().round(3))
```

전체 생존율은 약 38%인데, 여성은 74%, 남성은 19%입니다. 1등실은 63%, 3등실은 24%입니다. "여성과 어린이 먼저", "상층 객실이 구명보트에 가까웠다"는 역사적 사실이 데이터에 그대로 보입니다. 모델도 이런 패턴을 찾아내는 것입니다.

> `0`과 `1`로 된 열의 평균은 `1`의 비율과 같습니다. 생존율을 `mean()`으로 구할 수 있는 이유입니다.

### 숫자 열 한눈에 요약하기: describe

숫자 열이 어떤 범위에 어떻게 퍼져 있는지는 `describe()`로 한 번에 봅니다.

```run
import pandas as pd

df = pd.read_csv("titanic.csv")
print(df[["age", "fare", "sibsp", "parch"]].describe().round(1))
```

읽는 법은 이렇습니다.

| 줄 | 뜻 | 여기서 읽을 것 |
| --- | --- | --- |
| `count` | 비어 있지 않은 값의 개수 | `age`만 714개 → 891명 중 177명은 나이가 **빈칸** |
| `mean` / `50%` | 평균 / 중앙값(가운데 값) | `fare` 평균 32.2, 중앙값 14.5 → 아주 비싼 표 몇 장이 평균을 끌어올림 |
| `min` / `max` | 가장 작은 값 / 가장 큰 값 | `fare` 최솟값 0(공짜 표?), 최댓값 512.3 |
| `25%` / `75%` | 아래에서 4분의 1, 4분의 3 지점 | 승객 절반이 운임 7.9~31.0 사이 |

`count`가 행 수보다 작으면 빈칸이 있다는 신호이고, 평균과 중앙값이 크게 다르면 한쪽으로 튀는 값이 있다는 신호입니다. 두 신호 모두 다음 레슨(결측치)에서 바로 씁니다.

## 열의 종류: 숫자형과 범주형

표의 열은 크게 두 종류입니다.

| 종류 | 뜻 | 타이타닉 예 |
| --- | --- | --- |
| **숫자형(numeric)** | 크기를 비교하고 더하거나 평균 낼 수 있는 값 | 나이 `age`, 운임 `fare` |
| **범주형(categorical)** | 몇 가지 종류 중 하나. 이름표에 가까운 값 | 성별 `sex`, 탑승 항구 `embarked` |

pandas에서는 `select_dtypes`로 숫자 열만, 또는 숫자가 아닌 열만 골라 볼 수 있습니다.

```run
import pandas as pd

df = pd.read_csv("titanic.csv")
print("numeric :", df.select_dtypes("number").columns.tolist())
print("others  :", df.select_dtypes(exclude="number").columns.tolist())
print(df["embarked"].value_counts())
```

숫자 열은 `survived`, `pclass`, `age`, `sibsp`(함께 탄 형제·배우자 수), `parch`(함께 탄 부모·자녀 수), `fare` 여섯 개입니다. `embarked`는 `S` 644명, `C` 168명, `Q` 77명으로 세 종류뿐인 범주형입니다.

> 숫자로 적혀 있다고 모두 숫자형은 아닙니다. `pclass`(1, 2, 3등실)는 숫자로 적혀 있지만 실제로는 "등급"이라는 범주입니다. 다행히 1 < 2 < 3 순서가 있어서 숫자로 그대로 써도 괜찮은 경우입니다. 이 구분은 [인코딩: 글자를 숫자로](#/l/ml-01-3) 인코딩에서 다시 나옵니다.

## 모델은 숫자만 받는다

scikit-learn(파이썬 머신러닝 도구)의 모델은 속으로 덧셈·곱셈 같은 **계산**을 해서 답을 냅니다. 그래서 X에는 **숫자만**, 그리고 **빈칸 없이** 들어가야 합니다. 그런데 타이타닉 표에는 두 가지 문제가 있습니다.

| 문제 | 예 | 해결 | 배우는 레슨 |
| --- | --- | --- | --- |
| 값이 비어 있다 | 나이를 모르는 승객 | **결측치 처리** (지우거나 채우기) | [결측치: 비어 있는 칸 다루기](#/l/ml-01-2) |
| 값이 글자다 | `male` / `female`, `S` / `C` / `Q` | **인코딩** (글자를 숫자로 바꾸기) | [인코딩: 글자를 숫자로](#/l/ml-01-3) |

다음 두 레슨에서 하나씩 쪼개서 해 봅니다.

## 코드로 X와 y 나누기

이제 실제로 X와 y를 떼어 봅니다. 대괄호 개수에 주의하세요.

```run
import pandas as pd

df = pd.read_csv("titanic.csv")
X = df[["pclass", "fare"]]      # two brackets -> a table (DataFrame)
y = df["survived"]              # one bracket  -> a single column (Series)
print("X:", type(X).__name__, X.shape)
print("y:", type(y).__name__, y.shape)
```

- `df[["pclass", "fare"]]`: 대괄호 **두 겹**은 "열 목록으로 표를 잘라 와라"입니다. 결과는 행 891개 × 열 2개인 **표(DataFrame)**.
- `df["survived"]`: 대괄호 **한 겹**은 "열 하나만 꺼내라"입니다. 결과는 값 891개가 한 줄로 늘어선 **Series**.

scikit-learn은 X를 **2차원(행 × 열)**, y를 **1차원(값의 줄)**으로 받습니다. 특성이 하나뿐이어도 X는 `df[["fare"]]`처럼 두 겹으로 써야 합니다.

### 자주 하는 실수

| 실수 | 무슨 일이 생기나 | 바로잡기 |
| --- | --- | --- |
| X에 `survived`까지 넣음 | 정답을 보고 정답을 맞히는 꼴 → 점수 100% 근처 | X 열 목록에서 정답 열을 꼭 빼기 |
| 특성 하나를 `df["fare"]`로 넣음 | "2차원 배열이 필요하다"는 오류 | `df[["fare"]]` 두 겹으로 |
| `class`, `pclass`를 둘 다 넣음 | 같은 정보가 두 번 들어감 | 같은 뜻의 열은 하나만 |

## 정리

- 표의 가로 한 줄은 **사례**, 예측에 쓰는 열은 **특성 X**, 맞히고 싶은 열은 **정답 y**입니다.
- 모델을 만들기 전에 `iloc[0]`(한 줄), `describe()`(숫자 요약), 그룹별 평균으로 데이터를 먼저 봅니다(여성 생존율 74%, 남성 19%).
- X는 대괄호 두 겹 `df[[...]]`(2차원 표), y는 한 겹 `df["..."]`(1차원)입니다.
- 열은 **숫자형**과 **범주형**으로 나뉩니다.
- 모델은 **빈칸 없는 숫자**만 받습니다. 다음 두 레슨에서 빈칸(결측치)과 글자(인코딩)를 차례로 해결합니다.
