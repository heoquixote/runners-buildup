## 머신러닝 작업의 순서

1. 문제 정의: 무엇을 예측하나 (불량 여부, 해지 여부, 두께)
2. **데이터 분할**: 학습용과 평가용을 먼저 떼어 놓기
3. **기준 모델**: 가장 단순한 예측의 점수 확인
4. 전처리 · 모델 학습 (학습 데이터로만)
5. 테스트 데이터로 **딱 한 번** 평가

순서를 지키지 않으면 점수가 실제보다 좋게 나옵니다.

## 분할: train_test_split

```run
import numpy as np
from sklearn.model_selection import train_test_split

X = np.arange(40).reshape(20, 2)              # 샘플 20개, 피처 2개
y = np.array([0] * 16 + [1] * 4)              # 1이 20%
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.25, random_state=0, stratify=y)
print(X_tr.shape, X_te.shape)
print("학습 1 비율", y_tr.mean(), "테스트 1 비율", y_te.mean())
```

`stratify=y`를 빼고 몇 번 돌려 보세요. 테스트 세트에 1이 하나도 안 들어가는 경우가 생깁니다.

## 기준 모델: 넘어야 할 최소선

```run
import numpy as np
from sklearn.dummy import DummyClassifier
from sklearn.metrics import accuracy_score, recall_score

y = np.array([0] * 90 + [1] * 10)          # 불량 10%
X = np.zeros((100, 1))
base = DummyClassifier(strategy="most_frequent").fit(X, y)
pred = base.predict(X)
print("정확도", accuracy_score(y, pred), "불량 재현율", recall_score(y, pred))
```

> 정확도 90%인데 불량은 하나도 못 잡습니다. 불균형 데이터에서 "정확도 90%"는 아무 의미가 없을 수 있습니다.

## 누수: 테스트 정보가 새어 들어가는 것

평균·표준편차로 표준화할 때, 그 평균을 **전체 데이터**로 계산하면 테스트 데이터의 정보가 학습에 섞입니다. 항상 학습 데이터로 `fit`, 테스트에는 `transform`만.

```run
import numpy as np
from sklearn.preprocessing import StandardScaler

X_train = np.array([[50.0], [52.0], [54.0], [56.0]])
X_test = np.array([[60.0], [62.0]])
sc = StandardScaler().fit(X_train)          # 기준은 학습 데이터로만
print("학습 평균", sc.mean_, "테스트 변환", sc.transform(X_test).ravel().round(2))
```
