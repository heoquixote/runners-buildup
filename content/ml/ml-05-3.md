## 시작하기 전에

앞 레슨의 GridSearchCV는 "가장 좋은 값"만 알려 줍니다. 그런데 설정값을 바꿀 때 점수가 **어떤 모양으로** 변하는지 보면 훨씬 많은 것을 알 수 있습니다. 지금 모델이 과소적합 쪽인지 과적합 쪽인지, 데이터를 더 모으면 좋아질지까지 판단할 수 있습니다. 이번 레슨은 그 그래프, **검증 곡선**과 **학습 곡선**입니다.

## 검증 곡선: 설정값 vs 점수

`validation_curve`는 설정값 후보마다 교차검증을 돌려 **학습 점수**와 **검증 점수**를 함께 돌려줍니다. 앞 레슨의 GridSearchCV와 같은 계산이지만, 학습 점수까지 보여 준다는 점이 다릅니다.

::figure{src="content/img/ml/ml05-valcurve.svg" alt="나무 깊이에 따른 학습 점수와 검증 점수 곡선" caption="나무가 깊어질수록 학습 점수는 계속 오르지만 검증 점수는 어느 지점부터 떨어집니다. 그 꼭대기가 고를 값입니다."}

```run
import numpy as np
import pandas as pd
from sklearn.model_selection import validation_curve
from sklearn.tree import DecisionTreeClassifier

df = pd.read_csv("titanic.csv")
df["female"] = (df["sex"] == "female").astype(int)
df["age"] = df["age"].fillna(df["age"].median())
X = df[["pclass", "female", "age", "sibsp", "parch", "fare"]]
y = df["survived"]
depths = [1, 2, 3, 4, 5, 6, 8, 10, 15]
train_s, valid_s = validation_curve(DecisionTreeClassifier(random_state=0), X, y,
                                    param_name="max_depth", param_range=depths, cv=5)
for d, tr, va in zip(depths, train_s.mean(axis=1), valid_s.mean(axis=1)):
    print(f"depth {d:>2}: train {tr:.3f}   valid {va:.3f}   gap {tr - va:.3f}")
```

`train_s`, `valid_s`는 (후보 수 × 조각 수) 모양이라 `mean(axis=1)`로 조각마다의 점수를 평균 냅니다.

- 깊이 1: 학습 0.787, 검증 0.787. 차이는 0이지만 **둘 다 낮습니다** → 과소적합
- 깊이 6: 검증 0.820으로 가장 높음
- 깊이 15: 학습 0.966인데 검증 0.787. 차이가 0.179로 벌어졌습니다 → 과적합

## 그래프로 보기

숫자 표보다 그래프가 한눈에 들어옵니다. (그래프 글자는 영어로 씁니다.)

```run
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.model_selection import validation_curve
from sklearn.tree import DecisionTreeClassifier

df = pd.read_csv("titanic.csv")
df["female"] = (df["sex"] == "female").astype(int)
df["age"] = df["age"].fillna(df["age"].median())
X = df[["pclass", "female", "age", "sibsp", "parch", "fare"]]
y = df["survived"]
depths = [1, 2, 3, 4, 5, 6, 8, 10, 15]
train_s, valid_s = validation_curve(DecisionTreeClassifier(random_state=0), X, y,
                                    param_name="max_depth", param_range=depths, cv=5)
fig, ax = plt.subplots(figsize=(5.5, 3.5))
ax.plot(depths, train_s.mean(axis=1), "o-", label="train")
ax.plot(depths, valid_s.mean(axis=1), "o-", label="validation")
ax.set_xlabel("max_depth"); ax.set_ylabel("accuracy"); ax.set_title("Validation curve")
ax.legend(); plt.tight_layout(); plt.show()
best = depths[int(np.argmax(valid_s.mean(axis=1)))]
print("best depth by validation:", best)
```

그래프 읽는 법:

| 구간 | 모양 | 진단 | 처방 |
| --- | --- | --- | --- |
| 왼쪽 (깊이 1~2) | 두 선이 붙어 있고 **둘 다 낮음** | 과소적합 | 모델을 더 복잡하게 (깊이↑, 특성 추가) |
| 가운데 (깊이 5~6) | 검증 선이 꼭대기 | 적당함 | 이 근처 값을 고름 |
| 오른쪽 (깊이 10~15) | 학습 선만 오르고 **간격이 벌어짐** | 과적합 | 모델을 단순하게 (깊이↓, `min_samples_leaf`↑), 데이터 추가 |

두 선 사이의 간격이 "외운 정도"라고 생각하면 됩니다.

## 학습 곡선: 데이터를 더 모으면 좋아질까

설정값 대신 **학습 데이터의 양**을 가로축에 두면 **학습 곡선(learning curve)** 입니다. [기계는 어떻게 배울까](#/l/ml-00-1)에서 학습 인원 n을 바꿔 본 실험을 도구로 하는 것입니다. "데이터를 더 모으는 데 돈을 쓸 가치가 있나?"를 판단할 때 씁니다.

```run
import pandas as pd
from sklearn.model_selection import learning_curve
from sklearn.tree import DecisionTreeClassifier

df = pd.read_csv("titanic.csv")
df["female"] = (df["sex"] == "female").astype(int)
df["age"] = df["age"].fillna(df["age"].median())
X = df[["pclass", "female", "age", "sibsp", "parch", "fare"]]
y = df["survived"]
for depth in [3, None]:
    sizes, tr, va = learning_curve(DecisionTreeClassifier(max_depth=depth, random_state=0), X, y,
                                   train_sizes=[0.1, 0.25, 0.5, 0.75, 1.0], cv=5, shuffle=True, random_state=0)
    print("max_depth =", depth)
    for n, a, b in zip(sizes, tr.mean(axis=1), va.mean(axis=1)):
        print(f"  {n:>3} rows: train {a:.3f}   valid {b:.3f}")
```

- **깊이 3**: 71명일 때 검증 0.756에서 178명이면 0.819로 오르고, 그 뒤로는 0.81 근처에서 멈춥니다. 학습·검증 점수가 거의 붙었으니 **데이터를 더 모아도 크게 좋아지지 않습니다.** 더 좋아지려면 모델이나 특성을 바꿔야 합니다.
- **깊이 제한 없음**: 학습 점수는 늘 0.98 이상인데 검증은 0.73~0.79로 간격이 큽니다. 이렇게 외우는 모델은 **데이터가 많아질수록** 간격이 조금씩 줄어드는 경향이 있습니다(534명일 때 0.791).

## 정리

- **검증 곡선**: 설정값을 바꿀 때 학습·검증 점수 → 과소적합(둘 다 낮음) / 과적합(간격이 큼) 구간을 읽습니다.
- **학습 곡선**: 데이터 양을 바꿀 때 학습·검증 점수 → 데이터를 더 모을 가치가 있는지 판단합니다.
- 두 그래프 모두 검증 점수는 교차검증으로 냅니다. 시험용 데이터는 여전히 마지막에 한 번만.
