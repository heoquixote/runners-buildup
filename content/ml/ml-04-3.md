## 시작하기 전에

앞 레슨에서 트리 하나는 깊이에 따라 쉽게 외워 버린다는 것을 봤습니다. 트리 하나를 잘 다듬는 대신, **트리를 여러 개 만들어 합치면** 어떨까요? 이것을 **앙상블(ensemble)** 이라고 합니다. 이번 레슨은 가장 대표적인 앙상블, 랜덤포레스트입니다.

## 랜덤포레스트: 여러 트리의 투표

한 사람의 판단보다 여러 사람의 다수결이 더 안정적일 때가 많습니다. **랜덤포레스트**는 트리를 수십~수백 개 만들고 투표로 예측합니다.

트리마다 일부러 조금씩 다르게 만듭니다.

1. 데이터를 무작위로 다시 뽑아서(중복 허용) 트리마다 다른 데이터로 학습
2. 질문 후보도 매번 일부 특성만 무작위로 골라서 사용

그러면 트리 하나하나는 조금씩 틀려도, 그 실수가 서로 다른 방향이라 투표하면 상쇄됩니다.

::figure{src="content/img/ml/ml04-forest.svg" alt="트리 다섯 그루가 각각 생존 또는 사망에 투표하고 다수결로 생존을 고른다" caption="트리 하나하나는 조금씩 틀려도, 다수결을 하면 실수가 상쇄됩니다."}

::video{ref="dl-m23"}

```run
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier
from sklearn.ensemble import RandomForestClassifier

df = pd.read_csv("titanic.csv")
df["female"] = (df["sex"] == "female").astype(int)
df["age"] = df["age"].fillna(df["age"].median())
X = df[["pclass", "female", "age", "sibsp", "parch", "fare"]]
y = df["survived"]
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.25, random_state=0, stratify=y)
tree = DecisionTreeClassifier(random_state=0).fit(X_train, y_train)
forest = RandomForestClassifier(n_estimators=100, random_state=0).fit(X_train, y_train)
print("one tree    test:", round(tree.score(X_test, y_test), 3))
print("100 trees   test:", round(forest.score(X_test, y_test), 3))
```

깊이 제한 없는 트리 하나는 0.776이었는데, 같은 트리를 100그루 모아 투표하니 0.807로 올랐습니다. 트리 하나하나는 외웠지만, 서로 다르게 외운 것들이 투표로 상쇄된 것입니다. 이렇게 데이터를 다시 뽑아 여러 모델을 만들어 합치는 방법을 **배깅(bagging)** 이라고 합니다.

## 숲의 확률은 트리들의 표 비율

숲은 어떻게 확률을 낼까요? 가상의 승객 세 명에 대해 트리 100그루가 각각 어떻게 투표하는지 세어 봅니다.

```run
import numpy as np
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier

df = pd.read_csv("titanic.csv")
df["female"] = (df["sex"] == "female").astype(int)
df["age"] = df["age"].fillna(df["age"].median())
X = df[["pclass", "female", "age", "sibsp", "parch", "fare"]]
y = df["survived"]
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.25, random_state=0, stratify=y)
forest = RandomForestClassifier(n_estimators=100, random_state=0).fit(X_train, y_train)
people = pd.DataFrame({"pclass": [1, 3, 3], "female": [1, 1, 0], "age": [30, 25, 30],
                       "sibsp": [0, 0, 0], "parch": [0, 0, 0], "fare": [80.0, 8.0, 8.0]})
for i, who in enumerate(["1st class woman", "3rd class woman", "3rd class man"]):
    votes = sum(t.predict(people.iloc[[i]].values)[0] for t in forest.estimators_)
    print(f"{who:>16}: {int(votes):>3} of 100 trees say 'survived'  ->  forest prob {forest.predict_proba(people.iloc[[i]])[0, 1]:.2f}")
```

- 1등실 여성은 100그루 **모두** 생존에 투표합니다(확률 1.00).
- 3등실 남성은 3그루만 생존에 투표합니다(0.03).
- 3등실 여성은 **41그루가 생존, 59그루가 사망**에 투표해 확률 0.41입니다. 트리 하나만 봤다면 "생존" 또는 "사망" 중 하나로 단정했겠지만, 숲은 "의견이 갈린다"는 것까지 알려 줍니다.

`forest.estimators_`는 숲 안의 트리 목록입니다. 숲의 확률은 이 트리들의 의견을 평균 낸 값입니다(여기처럼 끝까지 자란 트리는 확률이 0 또는 1이라 표 비율과 같습니다).

### 덤으로 얻는 검증 점수: OOB

트리마다 데이터를 중복 허용으로 다시 뽑으면, 각 트리는 학습 데이터의 약 3분의 1을 **한 번도 보지 못합니다**. 그 "안 본 승객(out-of-bag, OOB)"으로 트리를 채점하면 시험용을 쓰지 않고도 검증 점수를 얻을 수 있습니다. `oob_score=True`를 주면 됩니다.

```run
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier

df = pd.read_csv("titanic.csv")
df["female"] = (df["sex"] == "female").astype(int)
df["age"] = df["age"].fillna(df["age"].median())
X = df[["pclass", "female", "age", "sibsp", "parch", "fare"]]
y = df["survived"]
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.25, random_state=0, stratify=y)
forest = RandomForestClassifier(n_estimators=100, oob_score=True, random_state=0).fit(X_train, y_train)
print("OOB score (from train only):", round(forest.oob_score_, 3))
print("test score:                 ", round(forest.score(X_test, y_test), 3))
```

학습용만으로 구한 OOB 점수 0.807이 시험 점수 0.807과 같게 나왔습니다(항상 이렇게 딱 맞지는 않지만 보통 가깝습니다). 데이터가 적어 검증용을 따로 떼기 아까울 때 유용합니다.

## 직접 해보기: 트리를 몇 그루 심을까

`n_estimators`(트리 개수)를 1, 5, 10, 50, 300으로 바꿔 보세요.

```run
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier

df = pd.read_csv("titanic.csv")
df["female"] = (df["sex"] == "female").astype(int)
df["age"] = df["age"].fillna(df["age"].median())
X = df[["pclass", "female", "age", "sibsp", "parch", "fare"]]
y = df["survived"]
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.25, random_state=0, stratify=y)

n_estimators = 1   # <- change me: 1, 5, 10, 50, 300
forest = RandomForestClassifier(n_estimators=n_estimators, random_state=0).fit(X_train, y_train)
print(f"{n_estimators} trees -> test {forest.score(X_test, y_test):.3f}")
```

| 트리 수 | 시험 점수 |
| --- | --- |
| 1 | 0.717 |
| 5 | 0.780 |
| 10 | 0.803 |
| 50 | 0.812 |
| 100 | 0.807 |
| 300 | 0.807 |

처음 몇 그루를 늘릴 때는 크게 오르다가, 50그루쯤부터는 거의 그대로입니다. 트리를 늘려도 과적합이 생기지는 않지만 계산 시간만 늘어납니다. 보통 100~500 정도로 시작합니다.

## 정리

- **앙상블** = 여러 모델을 합쳐 하나보다 나은 예측을 내는 방법
- 랜덤포레스트 = 데이터와 질문 후보를 무작위로 바꿔 만든 트리들의 **다수결** (배깅)
- 트리 하나(0.776)보다 숲(0.807)이 안정적입니다. 트리 수는 어느 정도 이상이면 점수가 거의 변하지 않습니다.
- 숲의 확률은 트리들의 의견 평균입니다. 3등실 여성은 41 : 59로 의견이 갈립니다(확률 0.41).
- `oob_score=True`로 학습용만 가지고 검증 점수를 얻을 수 있습니다(OOB 0.807).
