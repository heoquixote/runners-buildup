## 시작하기 전에

지금까지 빈칸 채우기, 인코딩, 스케일링, 새 특성을 하나씩 배웠습니다. 단계가 많아지면 "시험용으로 다시 fit 해 버리는" 실수가 생기기 쉽습니다. 이번 레슨에서는 모든 단계와 모델을 **한 덩어리**로 묶는 Pipeline을 배웁니다.

## Pipeline: 손질부터 요리까지 한 줄로

전처리 단계를 따로따로 하면 실수하기 쉽습니다. 특히 시험용 데이터로 기준을 다시 fit 하는 실수가 흔합니다. `ColumnTransformer`로 열마다 할 일을 정하고, `make_pipeline`으로 모델까지 이어 붙이면 **한 덩어리**로 다룰 수 있습니다.

::figure{src="content/img/ml/ml06-pipeline.svg" alt="숫자 열은 빈칸을 중앙값으로 채우고 표준화, 글자 열은 빈칸을 최빈값으로 채우고 원-핫, 두 갈래가 합쳐져 로지스틱 회귀로 들어간다" caption="ColumnTransformer가 열 종류마다 다른 손질을 하고, Pipeline이 그 뒤에 모델을 이어 붙입니다."}

```run
import pandas as pd
from sklearn.compose import ColumnTransformer
from sklearn.pipeline import make_pipeline
from sklearn.impute import SimpleImputer
from sklearn.preprocessing import StandardScaler, OneHotEncoder
from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import cross_val_score

df = pd.read_csv("titanic.csv")
num_cols = ["age", "sibsp", "parch", "fare"]
cat_cols = ["sex", "class", "embarked"]
pre = ColumnTransformer([
    ("num", make_pipeline(SimpleImputer(strategy="median"), StandardScaler()), num_cols),
    ("cat", make_pipeline(SimpleImputer(strategy="most_frequent"), OneHotEncoder(handle_unknown="ignore")), cat_cols),
])
pipe = make_pipeline(pre, LogisticRegression())
scores = cross_val_score(pipe, df[num_cols + cat_cols], df["survived"], cv=5)
print("cv accuracy:", scores.round(3), "mean", round(scores.mean(), 3))
```

- 숫자 열: 빈칸을 중앙값으로 → 표준화
- 글자 열: 빈칸을 최빈값으로 → 원-핫
- 그 뒤 로지스틱 회귀

파이프라인째 교차검증하면 **조각마다 전처리 기준도 학습용 조각으로만 새로 계산**되어 누수가 없습니다.

## 파이프라인 안을 들여다보기

파이프라인은 상자처럼 보이지만 안을 열어 볼 수 있습니다. 학습한 뒤 **전처리 결과 열 이름**과 **모델 계수**를 짝지어 보고, 빈칸과 글자가 섞인 새 승객을 그대로 넣어 예측해 봅니다.

```run
import numpy as np
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.compose import ColumnTransformer
from sklearn.pipeline import make_pipeline
from sklearn.impute import SimpleImputer
from sklearn.preprocessing import StandardScaler, OneHotEncoder
from sklearn.linear_model import LogisticRegression

df = pd.read_csv("titanic.csv")
num_cols = ["age", "sibsp", "parch", "fare"]
cat_cols = ["sex", "class", "embarked"]
pre = ColumnTransformer([
    ("num", make_pipeline(SimpleImputer(strategy="median"), StandardScaler()), num_cols),
    ("cat", make_pipeline(SimpleImputer(strategy="most_frequent"), OneHotEncoder(handle_unknown="ignore")), cat_cols),
])
pipe = make_pipeline(pre, LogisticRegression())
X_train, X_test, y_train, y_test = train_test_split(df[num_cols + cat_cols], df["survived"], test_size=0.25, random_state=0, stratify=df["survived"])
pipe.fit(X_train, y_train)
names = pipe[0].get_feature_names_out()            # columns after preprocessing
print(pd.Series(pipe[-1].coef_[0], index=names).round(2))
print("test accuracy:", round(pipe.score(X_test, y_test), 3))

new = pd.DataFrame({"age": [np.nan, 30], "sibsp": [0, 1], "parch": [0, 2], "fare": [8.05, 120.0],
                    "sex": ["female", "male"], "class": ["Third", "First"], "embarked": ["S", np.nan]})
print("new passengers:", pipe.predict_proba(new)[:, 1].round(3))
```

- `pipe[0]`은 첫 단계(ColumnTransformer), `pipe[-1]`은 마지막 단계(로지스틱 회귀)입니다.
- 열 이름 앞의 `num__`, `cat__`은 어느 갈래에서 나왔는지를 뜻합니다. 글자 열 3개가 원-핫으로 8개 열이 되어, 숫자 4개와 합쳐 12개 열이 모델에 들어갔습니다.
- 계수를 보면 `sex_female` +1.38, `class_First` +0.96, `class_Third` −1.11로, 앞에서 본 패턴(여성·1등실 유리, 3등실 불리)과 같습니다.
- 새 승객 두 명은 **나이가 비어 있고, 탑승 항구가 비어 있고, 글자가 그대로**인데도 오류 없이 확률이 나옵니다(0.587, 0.398). 학습 때 정한 중앙값·최빈값·원-핫 규칙이 자동으로 적용되었기 때문입니다.

## 전처리와 모델 설정을 함께 고르기

파이프라인 안의 설정은 `단계이름__설정이름`으로 부릅니다. `make_pipeline`은 단계 이름을 클래스 이름의 소문자로 자동으로 붙입니다(`LogisticRegression` → `logisticregression`). 로지스틱 회귀의 `C`(규제 강도의 역수. 작을수록 계수를 0 쪽으로 강하게 눌러 단순한 모델)를 GridSearchCV로 골라 봅니다.

```run
import pandas as pd
from sklearn.model_selection import train_test_split, GridSearchCV
from sklearn.compose import ColumnTransformer
from sklearn.pipeline import make_pipeline
from sklearn.impute import SimpleImputer
from sklearn.preprocessing import StandardScaler, OneHotEncoder
from sklearn.linear_model import LogisticRegression

df = pd.read_csv("titanic.csv")
num_cols = ["age", "sibsp", "parch", "fare"]
cat_cols = ["sex", "class", "embarked"]
pre = ColumnTransformer([
    ("num", make_pipeline(SimpleImputer(strategy="median"), StandardScaler()), num_cols),
    ("cat", make_pipeline(SimpleImputer(strategy="most_frequent"), OneHotEncoder(handle_unknown="ignore")), cat_cols),
])
pipe = make_pipeline(pre, LogisticRegression())
X_train, X_test, y_train, y_test = train_test_split(df[num_cols + cat_cols], df["survived"], test_size=0.25, random_state=0, stratify=df["survived"])
grid = GridSearchCV(pipe, {"logisticregression__C": [0.01, 0.1, 1, 10]}, cv=5).fit(X_train, y_train)
for c, s in zip([0.01, 0.1, 1, 10], grid.cv_results_["mean_test_score"]):
    print(f"C={c:<5} cv {s:.3f}")
print("best:", grid.best_params_, " test:", round(grid.score(X_test, y_test), 3))
```

`C=0.01`(규제가 아주 강함)은 0.775로 낮고, 0.1 이상에서는 0.81 근처로 비슷합니다. 전처리 설정도 같은 방식으로 후보에 넣을 수 있습니다. 예를 들어 `"columntransformer__num__simpleimputer__strategy": ["mean", "median"]`처럼 단계 이름을 `__`로 이어 쓰면, 빈칸을 평균으로 채울지 중앙값으로 채울지도 교차검증으로 고를 수 있습니다.

## Pipeline이 좋은 이유

| 손으로 할 때 | Pipeline으로 할 때 |
| --- | --- |
| 단계마다 fit/transform을 직접 호출, 시험용에 실수로 fit 하기 쉬움 | `pipe.fit(X_train, y_train)` 한 번이면 모든 단계가 학습용으로만 fit |
| 교차검증 조각마다 전처리를 다시 해야 함 | `cross_val_score(pipe, ...)`가 자동으로 조각마다 처리 |
| 새 데이터 예측할 때 같은 손질을 다시 짜야 함 | `pipe.predict(new_X)` 한 줄 |
| GridSearchCV로 전처리 설정까지 고르기 어려움 | `logisticregression__C` 같은 이름으로 함께 고를 수 있음 |

## 정리

| 문제 | 해결 | 도구 |
| --- | --- | --- |
| 빈칸 | 중앙값 / 최빈값으로 채우기 | `fillna`, `SimpleImputer` |
| 글자 범주 | 원-핫 인코딩 | `get_dummies`, `OneHotEncoder` |
| 숫자 크기 차이 | 표준화 | `StandardScaler` |
| 좋은 정보가 숨어 있음 | 새 특성 만들기 | 현장 지식 + pandas |
| 단계가 많아 실수 | 한 줄로 묶기 | `ColumnTransformer`, `make_pipeline` |
