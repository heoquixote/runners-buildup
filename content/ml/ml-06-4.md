## 시작하기 전에

지금까지 빈칸 채우기, 인코딩, 스케일링, 새 특성을 하나씩 배웠습니다. 단계가 많아지면 "시험용으로 다시 fit 해 버리는" 실수가 생기기 쉽습니다. 이번 레슨에서는 모든 단계와 모델을 **한 덩어리**로 묶는 Pipeline을 배웁니다.

## Pipeline: 손질부터 요리까지 한 줄로

전처리 단계를 따로따로 하면 실수하기 쉽습니다. 특히 시험용 데이터로 기준을 다시 fit 하는 실수가 흔합니다. `ColumnTransformer`로 열마다 할 일을 정하고, `make_pipeline`으로 모델까지 이어 붙이면 **한 덩어리**로 다룰 수 있습니다.

::figure{src="content/img/ml/ml06-pipeline.svg" alt="숫자 열은 빈칸을 중앙값으로 채우고 표준화, 글자 열은 빈칸을 최빈값으로 채우고 원-핫, 두 갈래가 합쳐져 로지스틱 회귀로 들어간다" caption="ColumnTransformer가 열 종류마다 다른 손질을 하고, Pipeline이 그 뒤에 모델을 이어 붙입니다."}

```run
import pandas as pd
from sklearn.compose import ColumnTransformer
from sklearn.pipeline import make_pipeline
from sklearn.impute import SimpleImputer
from sklearn.preprocessing import StandardScaler, OneHotEncoder
from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import cross_val_score

df = pd.read_csv("titanic.csv")
num_cols = ["age", "sibsp", "parch", "fare"]
cat_cols = ["sex", "class", "embarked"]
pre = ColumnTransformer([
    ("num", make_pipeline(SimpleImputer(strategy="median"), StandardScaler()), num_cols),
    ("cat", make_pipeline(SimpleImputer(strategy="most_frequent"), OneHotEncoder(handle_unknown="ignore")), cat_cols),
])
pipe = make_pipeline(pre, LogisticRegression())
scores = cross_val_score(pipe, df[num_cols + cat_cols], df["survived"], cv=5)
print("cv accuracy:", scores.round(3), "mean", round(scores.mean(), 3))
```

- 숫자 열: 빈칸을 중앙값으로 → 표준화
- 글자 열: 빈칸을 최빈값으로 → 원-핫
- 그 뒤 로지스틱 회귀

파이프라인째 교차검증하면 **조각마다 전처리 기준도 학습용 조각으로만 새로 계산**되어 누수가 없습니다.

## Pipeline이 좋은 이유

| 손으로 할 때 | Pipeline으로 할 때 |
| --- | --- |
| 단계마다 fit/transform을 직접 호출, 시험용에 실수로 fit 하기 쉬움 | `pipe.fit(X_train, y_train)` 한 번이면 모든 단계가 학습용으로만 fit |
| 교차검증 조각마다 전처리를 다시 해야 함 | `cross_val_score(pipe, ...)`가 자동으로 조각마다 처리 |
| 새 데이터 예측할 때 같은 손질을 다시 짜야 함 | `pipe.predict(new_X)` 한 줄 |
| GridSearchCV로 전처리 설정까지 고르기 어려움 | `logisticregression__C` 같은 이름으로 함께 고를 수 있음 |

## 정리

| 문제 | 해결 | 도구 |
| --- | --- | --- |
| 빈칸 | 중앙값 / 최빈값으로 채우기 | `fillna`, `SimpleImputer` |
| 글자 범주 | 원-핫 인코딩 | `get_dummies`, `OneHotEncoder` |
| 숫자 크기 차이 | 표준화 | `StandardScaler` |
| 좋은 정보가 숨어 있음 | 새 특성 만들기 | 현장 지식 + pandas |
| 단계가 많아 실수 | 한 줄로 묶기 | `ColumnTransformer`, `make_pipeline` |
