## 정답이 없는 데이터도 있다

지금까지 배운 머신러닝은 모두 **정답(y)이 있는 데이터**로 공부했습니다. "이 승객은 살았다/죽었다", "이 설비는 고장 났다/안 났다"처럼 답지가 붙어 있었죠. 이런 방식을 **지도 학습**이라고 부릅니다. 선생님(정답)이 옆에서 지도해 주기 때문입니다.

그런데 현실에서는 답지가 없는 경우가 훨씬 많습니다.

- 공장 센서 기록은 매일 쌓이지만, "이 시간대는 어떤 운전 상태였다"라는 표시는 아무도 해 두지 않았습니다.
- 쇼핑몰 고객 데이터는 많지만, "이 사람은 알뜰형 고객"이라는 꼬리표는 없습니다.

이럴 때 데이터 **스스로의 모양**을 보고 구조를 찾는 것을 **비지도 학습**이라고 합니다. 이번 레슨에서는 대표적인 두 가지를 배웁니다.

| 하는 일 | 비유 | 도구 |
| --- | --- | --- |
| 비슷한 것끼리 **묶기** (군집) | 반 친구들을 "취미가 비슷한 사람끼리" 모둠으로 나누기 | K-means |
| 여러 열을 **몇 개로 요약** (차원 축소) | 국어·영어·수학·과학 점수를 "문과력·이과력" 두 숫자로 요약 | PCA |

::figure{src="content/img/ml/ml07-sup-vs-unsup.svg" alt="지도 학습은 점마다 정답 색이 있고, 비지도 학습은 모든 점이 회색이라 비슷한 것끼리 묶어야 한다" caption="지도 학습은 정답(색)을 보고 배우고, 비지도 학습은 정답 없이 점들의 모양만 봅니다."}

## 먼저 데이터 보기

AI4I 설비 데이터에서 `failure`(고장 여부) 열은 **일부러 쓰지 않겠습니다.** 정답 없이 센서 값만으로 어떤 운전 패턴이 있는지 찾아보고, 마지막에 정답을 살짝 꺼내 "찾은 그룹이 의미가 있었나?"를 확인하는 순서로 갑니다.

```run
import pandas as pd

df = pd.read_csv("ai4i2020.csv")
print(df.shape)
print(df[["rpm", "torque"]].describe().round(1))
```

회전수(`rpm`)는 1,000 단위, 토크(`torque`)는 10 단위입니다. 이 두 열만으로 운전 상태를 묶어 보겠습니다. 두 열만 쓰면 그래프로 직접 눈으로 확인할 수 있기 때문입니다.

## K-means는 어떻게 묶을까

K-means는 "그룹 수 k개"를 사람이 정해 주면, 다음 과정을 반복합니다. 운동장에 학생들이 흩어져 있고, 깃발 k개를 꽂는 장면을 떠올려 보세요.

1. 깃발(중심) k개를 아무 데나 꽂는다.
2. 학생마다 **가장 가까운 깃발**로 간다.
3. 깃발을 그 깃발에 모인 학생들의 **한가운데**로 옮긴다.
4. 깃발이 더 이상 움직이지 않을 때까지 2~3을 반복한다.

::figure{src="content/img/ml/ml07-kmeans-steps.svg" alt="K-means 4단계: 깃발 꽂기, 가까운 깃발로 배정, 깃발을 무리의 가운데로 이동, 바뀌지 않을 때까지 반복" caption="깃발(중심)을 꽂고, 가까운 깃발로 모이고, 깃발을 가운데로 옮기는 일을 반복합니다."}

::video{ref="dl-m25"}

여기서 중요한 단어가 **가까운**입니다. 거리를 재서 묶기 때문에, 숫자 크기가 다른 열은 반드시 **표준화**부터 해야 합니다. 표준화하지 않으면 1,000 단위인 회전수 차이가 거리를 거의 다 차지해서, 토크는 무시되고 회전수만 보고 묶게 됩니다.

```run
import pandas as pd
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans

df = pd.read_csv("ai4i2020.csv").sample(2000, random_state=0)
X = df[["rpm", "torque"]].values
Xs = StandardScaler().fit_transform(X)

km = KMeans(n_clusters=3, n_init=10, random_state=0).fit(Xs)
df["cluster"] = km.labels_
print(df.groupby("cluster")[["rpm", "torque"]].mean().round(1))
print()
print("rows per cluster:")
print(df["cluster"].value_counts().sort_index())
```

- `n_clusters=3`: 그룹 3개로 묶어 달라는 뜻입니다.
- `n_init=10`: 깃발의 첫 위치에 따라 결과가 달라질 수 있어서, 10번 새로 시작해 가장 잘 묶인 결과를 고릅니다.
- `km.labels_`: 각 행이 몇 번 그룹에 들어갔는지 담긴 배열입니다.

그룹별 평균을 보면 "빨리 돌고 힘은 약한" 그룹, "천천히 돌고 힘이 센" 그룹, 그 중간 그룹으로 나뉩니다. 회전수와 토크는 반대로 움직이는 관계라서 이렇게 갈립니다. 그룹 번호(0, 1, 2) 자체에는 의미가 없고, 이름은 사람이 평균을 보고 붙입니다.

## 그림으로 확인하기

```run
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans

df = pd.read_csv("ai4i2020.csv").sample(2000, random_state=0)
Xs = StandardScaler().fit_transform(df[["rpm", "torque"]])
df["cluster"] = KMeans(n_clusters=3, n_init=10, random_state=0).fit_predict(Xs)

plt.figure(figsize=(6, 4))
plt.scatter(df["rpm"], df["torque"], c=df["cluster"], s=8, cmap="viridis")
plt.xlabel("rpm")
plt.ylabel("torque (Nm)")
plt.title("K-means clusters (k=3)")
plt.show()
print("points per cluster:", df["cluster"].value_counts().sort_index().tolist())
```

점들이 회전수·토크 평면에서 세 덩어리로 색칠됩니다. 원래 데이터는 길쭉한 한 덩어리라서 경계가 칼같이 나뉘지는 않습니다. **K-means는 데이터에 뚜렷한 그룹이 없어도 무조건 k개로 나눠 준다**는 점을 기억하세요. 나눴다고 해서 그 그룹이 진짜 의미가 있다는 보장은 없습니다.

K-means가 특히 약한 경우도 알아 두세요.

- 그룹 모양이 동그랗지 않을 때 (초승달, 고리 모양) — 중심에서의 거리로만 나누기 때문
- 그룹마다 크기나 빽빽한 정도가 크게 다를 때
- 아주 튀는 값이 많을 때 — 깃발이 그쪽으로 끌려감

이럴 때는 DBSCAN(빽빽한 곳끼리 잇기), 계층 군집 같은 다른 방법을 씁니다.

## 그룹이 쓸모 있었나? 정답을 살짝 꺼내 보기

이제 숨겨 둔 `failure` 열을 꺼내 그룹별 고장률을 봅니다. 학습에는 쓰지 않았으니 "정답 없이 찾은 그룹이 고장과 관련이 있나"를 확인하는 용도입니다.

```run
import pandas as pd
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans

df = pd.read_csv("ai4i2020.csv").sample(2000, random_state=0)
Xs = StandardScaler().fit_transform(df[["rpm", "torque"]])
df["cluster"] = KMeans(n_clusters=3, n_init=10, random_state=0).fit_predict(Xs)

summary = df.groupby("cluster").agg(rpm=("rpm", "mean"), torque=("torque", "mean"), failure_rate=("failure", "mean"))
print(summary.round(3))
```

"천천히 돌고 힘이 센" 그룹(토크 약 49)은 고장률이 약 7.7%로, 전체 평균(약 3.4%)의 2배가 넘습니다. 반대로 중간 그룹은 0.6% 정도로 아주 낮습니다. 정답 없이 묶었는데도 **위험한 운전 영역**이 드러난 셈입니다. 현장에서는 이런 결과를 보고 "이 운전 조건에서는 점검 주기를 짧게 하자" 같은 결정을 합니다.

## k는 몇 개로 해야 할까

k는 사람이 정해야 합니다. 정답이 없으니 "정확도"로 고를 수도 없습니다. 대신 두 가지를 봅니다.

- **inertia(관성)**: 각 점과 자기 깃발 사이 거리의 제곱을 모두 더한 값. 작을수록 촘촘합니다. 그런데 k를 늘리면 깃발이 많아지니 **무조건 줄어듭니다.** 그래서 값 자체보다, 줄어드는 폭이 확 꺾이는 지점(**엘보**, 팔꿈치)을 봅니다.
- **실루엣 점수**: "내 그룹 사람들과는 가깝고, 옆 그룹과는 먼가?"를 -1~1로 잰 값. **클수록** 잘 나뉜 것입니다.

```run
import pandas as pd
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score

df = pd.read_csv("ai4i2020.csv").sample(2000, random_state=0)
Xs = StandardScaler().fit_transform(df[["rpm", "torque"]])
for k in range(2, 7):
    km = KMeans(n_clusters=k, n_init=10, random_state=0).fit(Xs)
    print(f"k={k}  inertia={km.inertia_:7.1f}  silhouette={silhouette_score(Xs, km.labels_):.3f}")
```

inertia는 k=2→3에서 크게(1699→987) 줄고, 그 뒤로는 줄어드는 폭이 점점 작아집니다. 실루엣 점수는 k=2가 0.53으로 가장 높고 k=3이 0.48로 뒤따릅니다. 숫자로는 k=2가 조금 낫지만, 앞에서 본 것처럼 k=3이 **고장 위험이 높은 운전 영역**을 따로 떼어 주어 현장에서 더 쓸모가 있습니다. 이렇게 k는 점수 하나로 정하기보다 **엘보·실루엣·해석하기 쉬운지**를 함께 보고 고릅니다.

### 직접 해보기

`k`를 2, 4, 5로 바꿔 그려 보세요. k가 몇이든 K-means는 점들을 그 수만큼 **반드시** 나눕니다. 그래서 "몇 개로 나눌지"는 그림과 점수, 현장에서의 쓸모를 함께 보고 사람이 정해야 합니다.

```run
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans

df = pd.read_csv("ai4i2020.csv").sample(2000, random_state=0)
Xs = StandardScaler().fit_transform(df[["rpm", "torque"]])

k = 3   # <- change me
df["cluster"] = KMeans(n_clusters=k, n_init=10, random_state=0).fit_predict(Xs)
print(df.groupby("cluster")["failure"].mean().round(3))
plt.figure(figsize=(6, 4))
plt.scatter(df["rpm"], df["torque"], c=df["cluster"], s=8, cmap="viridis")
plt.xlabel("rpm"); plt.ylabel("torque (Nm)"); plt.title(f"K-means clusters (k={k})")
plt.show()
```

## PCA: 여러 열을 몇 개로 요약하기

이번에는 열이 많은 데이터를 봅니다. sklearn에 들어 있는 **와인 데이터**는 와인 178병의 알코올, 산도, 색 진하기 등 **13개 성분**을 측정한 표입니다. 13개 열을 한 그래프에 그릴 수는 없죠. 그래서 13개를 **2개의 새 축으로 요약**합니다. 이것이 **PCA(주성분 분석)**입니다.

비유하면 이렇습니다. 학생의 국어·영어·사회 점수는 서로 비슷하게 움직이고, 수학·물리·화학 점수도 비슷하게 움직입니다. 그렇다면 6과목을 "문과 점수", "이과 점수" 두 숫자로 요약해도 정보를 크게 잃지 않습니다. PCA는 이 요약 축을 데이터에서 자동으로 찾습니다.

- **첫 번째 주성분(PC1)**: 데이터가 **가장 넓게 퍼진 방향**. 정보를 가장 많이 담습니다.
- **두 번째 주성분(PC2)**: PC1과 수직이면서, 남은 것 중 가장 넓게 퍼진 방향.

::figure{src="content/img/ml/ml07-pca.svg" alt="길쭉한 점구름 위에 가장 넓게 퍼진 방향 PC1과 그에 수직인 PC2 화살표" caption="PC1은 점들이 가장 넓게 퍼진 방향, PC2는 그와 수직인 방향입니다."}

::video{ref="dl-m26"}

```run
from sklearn.datasets import load_wine
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA

wine = load_wine()
X = wine.data
print("original shape:", X.shape)

Xs = StandardScaler().fit_transform(X)
pca = PCA(n_components=2).fit(Xs)
Z = pca.transform(Xs)
print("after PCA:", Z.shape)
print("explained variance ratio:", pca.explained_variance_ratio_.round(3))
print("total kept:", round(float(pca.explained_variance_ratio_.sum()), 3))
```

- PCA도 퍼진 정도(분산)를 재기 때문에 **표준화가 먼저**입니다.
- `explained_variance_ratio_`: 각 축이 원래 정보(분산)의 몇 %를 담았는지입니다. 13개 열을 2개로 줄였는데도 절반 넘게 남아 있습니다.

### 축을 몇 개 남길까

2개로 줄이면 그림은 그릴 수 있지만 정보가 절반쯤 사라졌습니다. 그림이 목적이 아니라면 **누적 설명 분산**(앞에서부터 축을 더해 가며 원래 정보를 몇 % 담았는지)을 보고, 보통 80~90%를 넘는 지점까지 남깁니다.

```run
import numpy as np
from sklearn.datasets import load_wine
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA

Xs = StandardScaler().fit_transform(load_wine().data)
pca = PCA().fit(Xs)
cum = np.cumsum(pca.explained_variance_ratio_)
for k in range(1, 9):
    print(f"{k} components -> {cum[k - 1]:.1%} kept")
```

와인 데이터는 축 5개면 80%, 7개면 89%를 담습니다. 13개 열을 7개로 줄여도 정보의 90% 가까이가 남는다는 뜻입니다.

## 요약한 2개 축으로 그려 보기

와인에는 실제로 품종(3종류) 정보가 있습니다. PCA를 할 때는 품종을 쓰지 않았지만, 그림에 색으로만 칠해 보면 요약이 잘 됐는지 볼 수 있습니다.

```run
import matplotlib.pyplot as plt
from sklearn.datasets import load_wine
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA

wine = load_wine()
Z = PCA(n_components=2).fit_transform(StandardScaler().fit_transform(wine.data))

plt.figure(figsize=(6, 4))
for k, name in enumerate(wine.target_names):
    m = wine.target == k
    plt.scatter(Z[m, 0], Z[m, 1], s=12, label=name)
plt.xlabel("PC1")
plt.ylabel("PC2")
plt.title("Wine: 13 features -> 2 components")
plt.legend()
plt.show()
print("each wine is now 2 numbers:", Z.shape)
```

세 품종이 2차원 그림에서 꽤 깔끔하게 나뉘어 보입니다. 13개 열을 한눈에 볼 수 없던 데이터를, 정답 없이 요약했는데도 구조가 보이는 것입니다.

## 언제 무엇을 쓰나

| 상황 | 방법 | 주의할 점 |
| --- | --- | --- |
| 비슷한 행끼리 그룹을 만들고 싶다 | K-means | 표준화 먼저, k는 사람이 정함, 그룹 이름도 사람이 붙임 |
| 열이 너무 많아 그림으로 보고 싶다 | PCA (2개 축) | 표준화 먼저, 새 축(PC1, PC2)은 원래 열처럼 이름이 있는 값이 아님 |
| 그룹이 의미 있는지 확인 | 나중에 정답이나 현장 지표와 비교 | K-means는 그룹이 없어도 억지로 나눔 |
