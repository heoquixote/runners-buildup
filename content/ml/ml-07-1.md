## 정답 없이 구조 찾기

지금까지는 정답(불량 여부)이 있는 **지도 학습**이었습니다. **비지도 학습**은 정답 없이 데이터 자체의 구조를 찾습니다.

- **군집(K-means)**: 비슷한 것끼리 묶기. 설비 운전 패턴, 고객 세그먼트
- **차원 축소(PCA)**: 상관된 여러 열을 몇 개의 축으로 요약. 시각화, 잡음 제거, 다중공선성 완화

## K-means: 중심 찾기 반복

1. 중심 k개를 임의로 놓는다
2. 각 점을 가장 가까운 중심에 배정한다
3. 군집마다 평균으로 중심을 옮긴다
4. 배정이 바뀌지 않을 때까지 2~3 반복

::video{ref="dl-m25"}

거리를 쓰므로 **표준화가 먼저**입니다. 결과는 시작 위치에 따라 달라질 수 있어 `n_init=10`으로 여러 번 시작해 가장 좋은 것을 고릅니다.

```run
import numpy as np
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans

i = np.arange(90)
g = i % 3
vib = np.array([2.0, 4.5, 3.2])[g] + 0.35 * np.sin(i * 1.7)
power = np.array([11.0, 12.5, 15.5])[g] + 0.5 * np.cos(i * 2.3)
X = np.column_stack([vib, power])
Xs = StandardScaler().fit_transform(X)
km = KMeans(n_clusters=3, n_init=10, random_state=0).fit(Xs)
for k in range(3):
    m = km.labels_ == k
    print(f"cluster {k}: n={m.sum()}  vib={X[m, 0].mean():.2f}  power={X[m, 1].mean():.2f}")
```

## k는 몇 개?

inertia(군집 내 제곱합)는 k를 늘리면 계속 줄어듭니다. 그래서 줄어드는 폭이 꺾이는 지점(**엘보**)이나, 군집 안은 가깝고 군집끼리는 먼 정도를 재는 **실루엣 점수**(−1~1, 클수록 좋음)를 봅니다.

```run
import numpy as np
import matplotlib.pyplot as plt
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score

i = np.arange(90)
g = i % 3
X = np.column_stack([np.array([2.0, 4.5, 3.2])[g] + 0.35 * np.sin(i * 1.7),
                     np.array([11.0, 12.5, 15.5])[g] + 0.5 * np.cos(i * 2.3)])
Xs = StandardScaler().fit_transform(X)
ks = range(2, 7)
inertia, sil = [], []
for k in ks:
    km = KMeans(n_clusters=k, n_init=10, random_state=0).fit(Xs)
    inertia.append(km.inertia_); sil.append(silhouette_score(Xs, km.labels_))
    print(k, round(km.inertia_, 2), round(sil[-1], 3))
fig, ax = plt.subplots(1, 2, figsize=(8, 3))
ax[0].plot(list(ks), inertia, marker="o"); ax[0].set_title("Elbow (inertia)"); ax[0].set_xlabel("k")
ax[1].plot(list(ks), sil, marker="o", color="C1"); ax[1].set_title("Silhouette"); ax[1].set_xlabel("k")
plt.tight_layout(); plt.show()
```

> 군집 번호(0, 1, 2)에는 의미가 없습니다. 군집별 평균을 보고 "고진동 · 저전력 그룹"처럼 사람이 이름을 붙입니다.

## PCA: 분산이 큰 방향으로 회전

방문 수 · 이용 시간 · 주문 수가 함께 오르내린다면 사실상 "활동량" 하나의 축으로 요약됩니다. PCA는 분산이 가장 큰 방향(PC1), 그와 직교하면서 남은 분산이 가장 큰 방향(PC2)… 순으로 새 축을 찾습니다.

::video{ref="dl-m26"}

```run
import numpy as np
import pandas as pd
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA

i = np.arange(100)
base = np.sin(i * 0.37) + 0.5 * np.cos(i * 1.13)
df = pd.DataFrame({
    "visits": 10 + 4 * base + 0.8 * np.sin(i * 2.1),
    "minutes": 60 + 25 * base + 6 * np.cos(i * 1.7),
    "orders": 3 + 1.2 * base + 0.5 * np.sin(i * 2.9),
    "reviews": 1 + 0.3 * np.cos(i * 0.71) + 0.4 * np.sin(i * 3.7),
})
pca = PCA().fit(StandardScaler().fit_transform(df))
print("explained ratio", pca.explained_variance_ratio_.round(3))
print("cumulative     ", np.cumsum(pca.explained_variance_ratio_).round(3))
print(pd.DataFrame(pca.components_[:2], columns=df.columns, index=["PC1", "PC2"]).round(2))
```

PC1은 visits · minutes · orders에 비슷한 가중치를 준 "활동량" 축, PC2는 reviews 축입니다. 네 열을 두 축으로 줄여도 분산의 97%가 남습니다.

> PCA 축은 원래 열들의 섞임이라 해석이 어려워질 수 있습니다. 설명이 중요한 보고서에는 원래 열을, 시각화나 잡음 제거에는 PCA를 쓰는 식으로 구분하세요.
