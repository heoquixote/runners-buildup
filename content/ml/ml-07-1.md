## 정답이 없는 데이터도 있다

지금까지 배운 머신러닝은 모두 **정답(y)이 있는 데이터**로 공부했습니다. "이 승객은 살았다/죽었다", "이 설비는 고장 났다/안 났다"처럼 답지가 붙어 있었죠. 이런 방식을 **지도 학습**이라고 부릅니다. 선생님(정답)이 옆에서 지도해 주기 때문입니다.

그런데 현실에서는 답지가 없는 경우가 훨씬 많습니다.

- 공장 센서 기록은 매일 쌓이지만, "이 시간대는 어떤 운전 상태였다"라는 표시는 아무도 해 두지 않았습니다.
- 쇼핑몰 고객 데이터는 많지만, "이 사람은 알뜰형 고객"이라는 꼬리표는 없습니다.

이럴 때 데이터 **스스로의 모양**을 보고 구조를 찾는 것을 **비지도 학습**이라고 합니다. 이 코스([비지도 학습](#/l/ml-07-1))에서는 대표적인 두 가지를 세 레슨에 걸쳐 배웁니다. [K-means: 정답 없이 묶기](#/l/ml-07-1)는 K-means로 묶기, [k는 몇 개로 할까: 엘보와 실루엣](#/l/ml-07-2)은 그룹 수 k 고르기, [PCA: 여러 열을 몇 개로 요약하기](#/l/ml-07-3)는 PCA로 요약하기입니다.

| 하는 일 | 비유 | 도구 |
| --- | --- | --- |
| 비슷한 것끼리 **묶기** (군집) | 반 친구들을 "취미가 비슷한 사람끼리" 모둠으로 나누기 | K-means |
| 여러 열을 **몇 개로 요약** (차원 축소) | 국어·영어·수학·과학 점수를 "문과력·이과력" 두 숫자로 요약 | PCA |

::figure{src="content/img/ml/ml07-sup-vs-unsup.svg" alt="지도 학습은 점마다 정답 색이 있고, 비지도 학습은 모든 점이 회색이라 비슷한 것끼리 묶어야 한다" caption="지도 학습은 정답(색)을 보고 배우고, 비지도 학습은 정답 없이 점들의 모양만 봅니다."}

## 먼저 데이터 보기

AI4I 설비 데이터에서 `failure`(고장 여부) 열은 **일부러 쓰지 않겠습니다.** 정답 없이 센서 값만으로 어떤 운전 패턴이 있는지 찾아보고, 마지막에 정답을 살짝 꺼내 "찾은 그룹이 의미가 있었나?"를 확인하는 순서로 갑니다.

```run
import pandas as pd

df = pd.read_csv("ai4i2020.csv")
print(df.shape)
print(df[["rpm", "torque"]].describe().round(1))
```

회전수(`rpm`)는 1,000 단위, 토크(`torque`)는 10 단위입니다. 이 두 열만으로 운전 상태를 묶어 보겠습니다. 두 열만 쓰면 그래프로 직접 눈으로 확인할 수 있기 때문입니다.

## K-means는 어떻게 묶을까

K-means는 "그룹 수 k개"를 사람이 정해 주면, 다음 과정을 반복합니다. 운동장에 학생들이 흩어져 있고, 깃발 k개를 꽂는 장면을 떠올려 보세요.

1. 깃발(중심) k개를 아무 데나 꽂는다.
2. 학생마다 **가장 가까운 깃발**로 간다.
3. 깃발을 그 깃발에 모인 학생들의 **한가운데**로 옮긴다.
4. 깃발이 더 이상 움직이지 않을 때까지 2~3을 반복한다.

::figure{src="content/img/ml/ml07-kmeans-steps.svg" alt="K-means 4단계: 깃발 꽂기, 가까운 깃발로 배정, 깃발을 무리의 가운데로 이동, 바뀌지 않을 때까지 반복" caption="깃발(중심)을 꽂고, 가까운 깃발로 모이고, 깃발을 가운데로 옮기는 일을 반복합니다."}

::video{ref="dl-m25"}

여기서 중요한 단어가 **가까운**입니다. 거리를 재서 묶기 때문에, 숫자 크기가 다른 열은 반드시 **표준화**부터 해야 합니다. 표준화하지 않으면 1,000 단위인 회전수 차이가 거리를 거의 다 차지해서, 토크는 무시되고 회전수만 보고 묶게 됩니다.

```run
import pandas as pd
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans

df = pd.read_csv("ai4i2020.csv").sample(2000, random_state=0)
X = df[["rpm", "torque"]].values
Xs = StandardScaler().fit_transform(X)

km = KMeans(n_clusters=3, n_init=10, random_state=0).fit(Xs)
df["cluster"] = km.labels_
print(df.groupby("cluster")[["rpm", "torque"]].mean().round(1))
print()
print("rows per cluster:")
print(df["cluster"].value_counts().sort_index())
```

- `n_clusters=3`: 그룹 3개로 묶어 달라는 뜻입니다.
- `n_init=10`: 깃발의 첫 위치에 따라 결과가 달라질 수 있어서, 10번 새로 시작해 가장 잘 묶인 결과를 고릅니다.
- `km.labels_`: 각 행이 몇 번 그룹에 들어갔는지 담긴 배열입니다.

그룹별 평균을 보면 "빨리 돌고 힘은 약한" 그룹, "천천히 돌고 힘이 센" 그룹, 그 중간 그룹으로 나뉩니다. 회전수와 토크는 반대로 움직이는 관계라서 이렇게 갈립니다. 그룹 번호(0, 1, 2) 자체에는 의미가 없고, 이름은 사람이 평균을 보고 붙입니다.

### 표준화를 빼먹으면

정말 표준화가 필요한지, 빼고 묶어서 그룹별 범위를 비교해 봅니다.

```run
import pandas as pd
from sklearn.cluster import KMeans

df = pd.read_csv("ai4i2020.csv").sample(2000, random_state=0)
df["cluster"] = KMeans(n_clusters=3, n_init=10, random_state=0).fit_predict(df[["rpm", "torque"]])
print(df.groupby("cluster")[["rpm", "torque"]].agg(["min", "max"]).round(1))
```

그룹마다 회전수 범위가 1,168~1,513 / 1,514~1,777 / 1,781~2,861로 **칼같이 이어져** 있습니다. 반면 토크 범위는 서로 크게 겹칩니다. 회전수 차이(수백)가 토크 차이(수십)보다 숫자로 훨씬 커서, K-means가 **회전수만 보고** 잘랐다는 뜻입니다. 토크를 넣은 의미가 없어졌습니다. 표준화를 한 위 결과에서는 두 열이 함께 그룹을 가릅니다.

## 그림으로 확인하기

```run
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans

df = pd.read_csv("ai4i2020.csv").sample(2000, random_state=0)
Xs = StandardScaler().fit_transform(df[["rpm", "torque"]])
df["cluster"] = KMeans(n_clusters=3, n_init=10, random_state=0).fit_predict(Xs)

plt.figure(figsize=(6, 4))
plt.scatter(df["rpm"], df["torque"], c=df["cluster"], s=8, cmap="viridis")
plt.xlabel("rpm")
plt.ylabel("torque (Nm)")
plt.title("K-means clusters (k=3)")
plt.show()
print("points per cluster:", df["cluster"].value_counts().sort_index().tolist())
```

점들이 회전수·토크 평면에서 세 덩어리로 색칠됩니다. 원래 데이터는 길쭉한 한 덩어리라서 경계가 칼같이 나뉘지는 않습니다. **K-means는 데이터에 뚜렷한 그룹이 없어도 무조건 k개로 나눠 준다**는 점을 기억하세요. 나눴다고 해서 그 그룹이 진짜 의미가 있다는 보장은 없습니다.

K-means가 특히 약한 경우도 알아 두세요.

- 그룹 모양이 동그랗지 않을 때 (초승달, 고리 모양) — 중심에서의 거리로만 나누기 때문
- 그룹마다 크기나 빽빽한 정도가 크게 다를 때
- 아주 튀는 값이 많을 때 — 깃발이 그쪽으로 끌려감

이럴 때 쓰는 다른 방법(DBSCAN, 계층 군집)은 레슨 끝에서 직접 비교해 봅니다.

## 그룹이 쓸모 있었나? 정답을 살짝 꺼내 보기

이제 숨겨 둔 `failure` 열을 꺼내 그룹별 고장률을 봅니다. 학습에는 쓰지 않았으니 "정답 없이 찾은 그룹이 고장과 관련이 있나"를 확인하는 용도입니다.

```run
import pandas as pd
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans

df = pd.read_csv("ai4i2020.csv").sample(2000, random_state=0)
Xs = StandardScaler().fit_transform(df[["rpm", "torque"]])
df["cluster"] = KMeans(n_clusters=3, n_init=10, random_state=0).fit_predict(Xs)

summary = df.groupby("cluster").agg(rpm=("rpm", "mean"), torque=("torque", "mean"), failure_rate=("failure", "mean"))
print(summary.round(3))
```

"천천히 돌고 힘이 센" 그룹(토크 약 49)은 고장률이 약 7.7%로, 전체 평균(약 3.4%)의 2배가 넘습니다. 반대로 중간 그룹은 0.6% 정도로 아주 낮습니다. 정답 없이 묶었는데도 **위험한 운전 영역**이 드러난 셈입니다. 현장에서는 이런 결과를 보고 "이 운전 조건에서는 점검 주기를 짧게 하자" 같은 결정을 합니다.

### 그룹을 현장 말로 옮기기, 새 데이터 배정하기

깃발(중심) 위치는 표준화된 값이라 그대로는 읽기 어렵습니다. 원래 단위로 되돌리면 각 그룹의 "대표 운전 조건"이 됩니다. 그리고 새 운전 기록이 들어오면 `predict`로 어느 그룹인지 배정할 수 있습니다.

```run
import pandas as pd
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans

df = pd.read_csv("ai4i2020.csv").sample(2000, random_state=0)
scaler = StandardScaler().fit(df[["rpm", "torque"]])
km = KMeans(n_clusters=3, n_init=10, random_state=0).fit(scaler.transform(df[["rpm", "torque"]]))
centers = pd.DataFrame(scaler.inverse_transform(km.cluster_centers_), columns=["rpm", "torque"])
print(centers.round(1))
new = pd.DataFrame({"rpm": [1300, 1700], "torque": [60, 30]})
print("new records go to clusters:", km.predict(scaler.transform(new)))
```

- 그룹 0: 약 1,558rpm·36.6Nm(보통 운전), 그룹 1: 약 1,400rpm·49.5Nm(**저속·고부하**), 그룹 2: 약 1,867rpm·24.3Nm(고속·저부하)
- 새 기록 "1,300rpm·60Nm"는 그룹 1(저속·고부하, 고장률이 높던 그룹)로, "1,700rpm·30Nm"는 그룹 0으로 배정됩니다.

이렇게 하면 "지금 이 설비는 저속·고부하 운전 중이니 점검 주기를 당기자" 같은 현장 규칙으로 이어질 수 있습니다. 새 데이터도 **학습 때 쓴 스케일러로** 바꾼 뒤 배정해야 한다는 점은 지도 학습과 같습니다.

## 모양이 다른 그룹: DBSCAN과 계층 군집

K-means는 깃발(중심)에서의 **거리**로 나누기 때문에 동그란 그룹만 잘 찾습니다. 초승달 두 개가 맞물린 데이터로 확인해 봅니다. 사이킷런의 `make_moons`가 만들어 주는 연습용 데이터로, 정답(어느 달인지)을 알고 있어서 결과를 채점할 수 있습니다. 채점 점수 **ARI**는 "정답과 얼마나 같게 나눴나"로, 1이면 완벽, 0이면 아무렇게나 나눈 수준입니다.

- **DBSCAN**: "주변이 빽빽한 점끼리 손을 잡고 이어 나간다." 반경(`eps`) 안에 이웃이 `min_samples`개 이상이면 같은 그룹으로 잇습니다. k를 정할 필요가 없고, 어디에도 이어지지 않은 외딴 점은 **잡음(−1)**으로 남깁니다.
- **계층 군집**(`AgglomerativeClustering`): 처음엔 점 하나하나가 그룹이고, **가장 가까운 두 그룹을 하나씩 합쳐 나갑니다.** `linkage="single"`은 두 그룹에서 가장 가까운 점끼리의 거리로 합칠 순서를 정해, 길게 이어진 모양을 잘 따라갑니다.

```run
import numpy as np
import matplotlib.pyplot as plt
from sklearn.datasets import make_moons
from sklearn.cluster import KMeans, DBSCAN, AgglomerativeClustering
from sklearn.metrics import adjusted_rand_score

X, y = make_moons(n_samples=300, noise=0.06, random_state=0)
X = np.vstack([X, [[2.5, 1.5], [-1.5, -0.8]]])     # two far-away points
y = np.append(y, [-1, -1])
models = {"K-means": KMeans(2, n_init=10, random_state=0),
          "DBSCAN": DBSCAN(eps=0.2, min_samples=5),
          "Agglomerative": AgglomerativeClustering(2, linkage="single")}
fig, axes = plt.subplots(1, 3, figsize=(10, 3))
for ax, (name, m) in zip(axes, models.items()):
    labels = m.fit_predict(X)
    ari = adjusted_rand_score(y[:300], labels[:300])
    ax.scatter(X[:, 0], X[:, 1], c=labels, s=8, cmap="viridis")
    ax.set_title(f"{name} (ARI {ari:.2f})")
    print(f"{name:>13}: ARI {ari:.3f}, labels of the 2 far points: {labels[-2:]}")
plt.tight_layout()
plt.show()
```

- **K-means**: ARI 0.221. 초승달을 무시하고 왼쪽·오른쪽 반으로 잘라 버립니다.
- **DBSCAN**: ARI **1.000**. 두 초승달을 완벽하게 찾았고, 멀리 떨어진 두 점은 어느 그룹에도 넣지 않고 **−1(잡음)**로 표시했습니다. [이상 탐지](#/l/ml-07-4)로도 쓸 수 있는 성질입니다.
- **계층 군집(single)**: ARI 0.000. 가장 멀리 떨어진 점 **하나**를 따로 한 그룹으로 만들고, 나머지 301개를 한 그룹으로 묶었습니다. 가장 가까운 점끼리 이어 붙이는 방식이라, 외딴 점이 있으면 그 점이 마지막까지 혼자 남기 때문입니다. `AgglomerativeClustering(2, ...)`의 2를 **4**로 바꿔 보세요. 초승달 둘 + 외딴 점 둘로 나뉘면서 초승달은 완벽하게(ARI 1.00) 찾습니다.

| 방법 | 그룹 수 | 잘 찾는 모양 | 약점 |
| --- | --- | --- | --- |
| K-means | 직접 정함 (k) | 동그랗고 크기가 비슷한 그룹 | 길쭉하거나 휘어진 그룹 |
| DBSCAN | 자동 | 아무 모양, 잡음(−1) 따로 표시 | 빽빽한 정도가 그룹마다 다르면 eps 고르기 어려움 |
| 계층 군집 | 정함 (또는 거리 기준으로 자르기) | linkage에 따라 다양, 합쳐지는 과정을 나무 그림으로 볼 수 있음 | 데이터가 수만 개면 느림 |
| 가우시안 혼합 (GMM) | 정함 | 타원 모양, "그룹 A일 확률 70%"처럼 확률로 소속 | 모양 가정이 틀리면 엉뚱함 |

## 정리

- **비지도 학습**은 정답(y) 없이 데이터의 모양만 보고 구조를 찾습니다.
- K-means: 깃발 k개 → 가까운 깃발로 배정 → 깃발을 가운데로 → 반복
- 거리로 묶으므로 **표준화가 먼저**. 빼먹으면 숫자가 큰 회전수만 보고 묶습니다. 그룹 번호에는 의미가 없고, 이름은 중심을 원래 단위로 되돌려 보고 사람이 붙입니다.
- K-means는 그룹이 없어도 k개로 나눕니다. 그룹이 쓸모 있는지는 나중에 정답·현장 지표와 비교해 확인합니다(고장률 7.7% 그룹).
- 동그랗지 않은 그룹은 **DBSCAN**(빽빽한 곳끼리 잇기, 잡음 −1)이나 **계층 군집**으로 찾습니다(초승달 ARI: K-means 0.221 vs DBSCAN 1.000).
