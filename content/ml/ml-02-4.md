## 시작하기 전에

지금까지는 특성(x) **하나**로 예측했습니다. 실제로는 여러 정보를 함께 쓰는 경우가 대부분입니다. 이번 레슨에서는 특성을 여러 개 넣은 선형회귀(다중 선형회귀)를 만들고, 어떤 특성을 넣느냐에 따라 성능이 어떻게 달라지는지 직접 비교합니다.

## 특성을 여러 개 쓰면

X에 열을 여러 개 넣으면 `y = a₁x₁ + a₂x₂ + … + 절편` 모양이 됩니다. 계수마다 "다른 값은 그대로 두고 이 값만 1 늘면 y가 얼마나 변하나"를 뜻합니다.

```run
import pandas as pd
from sklearn.linear_model import LinearRegression

df = pd.read_csv("ai4i2020.csv")
X = df[["air_temp", "rpm", "torque"]]
y = df["process_temp"]
model = LinearRegression().fit(X, y)
for name, c in zip(X.columns, model.coef_):
    print(f"{name:>9}: {c:+.4f}")
print("R^2:", round(model.score(X, y), 3))
```

회전수·토크 계수는 0에 가깝습니다. 공정 온도는 거의 공기 온도로만 정해진다는 뜻입니다. 이렇게 계수를 보면 어떤 특성이 중요한지도 짐작할 수 있습니다.

### 직접 해보기

`features` 목록을 `["rpm"]`, `["air_temp"]`, `["air_temp", "rpm", "torque"]`로 바꿔 가며 R²를 비교해 보세요. 회전수만 쓰면 R²가 거의 0이고, 공기 온도가 들어가는 순간 크게 오릅니다. **어떤 특성을 넣느냐가 모델 성능을 좌우한다**는 것을 직접 확인할 수 있습니다.

```run
import pandas as pd
from sklearn.linear_model import LinearRegression

df = pd.read_csv("ai4i2020.csv")
features = ["rpm"]   # <- change me
model = LinearRegression().fit(df[features], df["process_temp"])
print(features, "-> R^2:", round(model.score(df[features], df["process_temp"]), 3))
```

## 다른 데이터로: 당뇨 진행도 예측하기

설비 데이터 말고 사람 데이터로도 해 봅니다. sklearn에 들어 있는 **당뇨 데이터**(`load_diabetes`)는 환자 442명의 나이, 성별, 체질량지수(bmi), 혈압(bp), 혈액 검사 수치 6개(s1~s6)와, 1년 뒤 병이 얼마나 진행됐는지를 나타내는 점수(25~346)를 담고 있습니다. 파일 없이 바로 불러옵니다.

```run
from sklearn.datasets import load_diabetes

X, y = load_diabetes(return_X_y=True, as_frame=True)
print(X.shape)
print(X.columns.tolist())
print(y.describe().round(1))
```

특성 10개, 정답은 평균 152점짜리 진행도 점수입니다. 이 데이터의 특성은 미리 **표준화**(평균 0으로 맞춤)되어 있어서 값이 0.05, -0.04처럼 아주 작은 소수로 보입니다.

이번에는 학습용 · 시험용으로 나눈 뒤([학습용과 시험용 나누기](#/l/ml-01-4)), 특성을 1개 → 2개 → 10개로 늘리며 **시험용 R²**를 비교합니다.

```run
from sklearn.datasets import load_diabetes
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LinearRegression

X, y = load_diabetes(return_X_y=True, as_frame=True)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.25, random_state=0)
for features in [["bmi"], ["bmi", "bp"], list(X.columns)]:
    model = LinearRegression().fit(X_train[features], y_train)
    print(f"{len(features):>2} features -> test R^2: {model.score(X_test[features], y_test):.3f}")
```

> 해석: bmi 하나만 쓰면 R² 0.158, 혈압을 더하면 0.246, 10개를 모두 쓰면 0.359입니다. 특성이 늘수록 좋아지지만, 10개를 다 써도 진행도의 3분의 1 정도만 설명합니다.

설비 데이터(R² 0.77)보다 훨씬 낮습니다. 모델이 잘못된 게 아니라, 사람의 병 진행은 검사 수치 10개로 다 설명되지 않는 일이 많기 때문입니다. **R²가 얼마면 좋은지는 데이터 분야마다 다릅니다.** 설비처럼 물리 법칙을 따르는 데이터는 0.7~0.9가 나오기도 하지만, 사람 · 사회 데이터는 0.3~0.5도 쓸모 있는 경우가 많습니다.

## 계수를 비교할 때 주의할 점

위 결과에서 `rpm` 계수가 아주 작다고 "회전수는 중요하지 않다"고 바로 말하면 안 될 때가 있습니다. 계수는 **단위**에 따라 크기가 달라집니다. 회전수는 1,000 단위로 움직이고 공기 온도는 1~2도씩 움직이므로, 같은 영향이어도 회전수의 계수는 작게 나옵니다. 특성끼리 계수 크기를 공정하게 비교하려면 먼저 **표준화**(ml-06-2)로 단위를 맞춰야 합니다. ml-02-5의 로지스틱 회귀에서는 표준화한 뒤 계수를 비교합니다.

## 정리

- 특성이 여러 개면 `y = a₁x₁ + a₂x₂ + … + 절편`. 계수는 "나머지는 그대로 두고 이 값만 1 늘 때의 변화"입니다.
- 어떤 특성을 넣느냐가 성능을 좌우합니다(회전수만: R² ≈ 0, 공기 온도 포함: 0.77).
- R²의 기준은 분야마다 다릅니다. 당뇨 데이터는 특성 10개로도 0.36이지만, 사람 데이터에서는 이 정도도 쓸모 있습니다.
- 계수 크기를 비교하려면 단위를 맞춰야(표준화) 합니다.
