## 시작하기 전에

지금까지는 특성(x) **하나**로 예측했습니다. 실제로는 여러 정보를 함께 쓰는 경우가 대부분입니다. 이번 레슨에서는 특성을 여러 개 넣은 선형회귀(다중 선형회귀)를 만들고, 어떤 특성을 넣느냐에 따라 성능이 어떻게 달라지는지 직접 비교합니다.

## 특성을 여러 개 쓰면

X에 열을 여러 개 넣으면 `y = a₁x₁ + a₂x₂ + … + 절편` 모양이 됩니다. 계수마다 "다른 값은 그대로 두고 이 값만 1 늘면 y가 얼마나 변하나"를 뜻합니다.

```run
import pandas as pd
from sklearn.linear_model import LinearRegression

df = pd.read_csv("ai4i2020.csv")
X = df[["air_temp", "rpm", "torque"]]
y = df["process_temp"]
model = LinearRegression().fit(X, y)
for name, c in zip(X.columns, model.coef_):
    print(f"{name:>9}: {c:+.4f}")
print("R^2:", round(model.score(X, y), 3))
```

회전수·토크 계수는 0에 가깝습니다. 공정 온도는 거의 공기 온도로만 정해진다는 뜻입니다. 이렇게 계수를 보면 어떤 특성이 중요한지도 짐작할 수 있습니다.

### 직접 해보기

`features` 목록을 `["rpm"]`, `["air_temp"]`, `["air_temp", "rpm", "torque"]`로 바꿔 가며 R²를 비교해 보세요. 회전수만 쓰면 R²가 거의 0이고, 공기 온도가 들어가는 순간 크게 오릅니다. **어떤 특성을 넣느냐가 모델 성능을 좌우한다**는 것을 직접 확인할 수 있습니다.

```run
import pandas as pd
from sklearn.linear_model import LinearRegression

df = pd.read_csv("ai4i2020.csv")
features = ["rpm"]   # <- change me
model = LinearRegression().fit(df[features], df["process_temp"])
print(features, "-> R^2:", round(model.score(df[features], df["process_temp"]), 3))
```

## 특성을 많이 넣으면 무조건 좋을까

이번에는 사람의 건강 데이터로 해 봅니다. scikit-learn에 들어 있는 **당뇨병 데이터**(`load_diabetes`)는 환자 442명의 나이, 성별, 체질량지수(`bmi`), 혈압(`bp`), 혈액검사 6가지(`s1`~`s6`)와, 1년 뒤 병이 얼마나 진행됐는지를 나타내는 점수(y)로 되어 있습니다. 값은 미리 크기가 맞춰져 있습니다.

특성을 하나씩 늘리면서 **학습용 R²와 시험용 R²**를 함께 봅니다.

```run
import pandas as pd
from sklearn.datasets import load_diabetes
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LinearRegression

data = load_diabetes(as_frame=True)
X, y = data.data, data.target
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.25, random_state=0)
for cols in [["bmi"], ["bmi", "s5"], ["bmi", "s5", "bp"], list(X.columns)]:
    model = LinearRegression().fit(X_train[cols], y_train)
    print(f"{len(cols):>2} features  train R^2 {model.score(X_train[cols], y_train):.3f}   test R^2 {model.score(X_test[cols], y_test):.3f}")
```

| 특성 | 학습 R² | 시험 R² |
| --- | --- | --- |
| `bmi` 하나 | 0.391 | 0.158 |
| + `s5`(혈액검사) | 0.506 | 0.276 |
| + `bp`(혈압) | 0.520 | 0.322 |
| 10개 전부 | 0.555 | 0.359 |

쓸모 있는 특성을 더하면 학습·시험 점수가 함께 오릅니다. 그런데 학습 점수와 시험 점수 사이에 늘 틈이 있다는 것도 보입니다.

### 쓸모없는 특성을 잔뜩 넣으면

이번에는 일부러 **아무 의미 없는 난수 열 40개**를 붙여 봅니다.

```run
import numpy as np
import pandas as pd
from sklearn.datasets import load_diabetes
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LinearRegression

data = load_diabetes(as_frame=True)
X, y = data.data[["bmi", "s5", "bp"]], data.target
rng = np.random.default_rng(0)
noise = pd.DataFrame(rng.normal(size=(len(X), 40)), index=X.index).add_prefix("noise")
for name, XX in [("3 real", X), ("3 real + 40 noise", pd.concat([X, noise], axis=1))]:
    X_train, X_test, y_train, y_test = train_test_split(XX, y, test_size=0.25, random_state=0)
    model = LinearRegression().fit(X_train, y_train)
    print(f"{name:>18}: train R^2 {model.score(X_train, y_train):.3f}   test R^2 {model.score(X_test, y_test):.3f}")
```

난수 열을 넣자 **학습 R²는 0.520 → 0.579로 올랐지만, 시험 R²는 0.322 → 0.285로 떨어졌습니다.** 모델이 난수 속의 우연한 패턴까지 외웠기 때문입니다. 학습 점수는 특성을 더할수록 거의 항상 오르므로, 특성을 넣을지 말지는 **시험(검증) 점수로** 판단해야 합니다. 이렇게 "외워서 학습 점수만 좋은" 상태를 **과대적합**이라고 하며, [깊어질수록 외운다: 과적합과 과소적합](#/l/ml-04-2)에서 자세히 다룹니다.

### 원리 한 걸음 더: 조정 R²

학습 R²가 특성을 더할수록 오르는 것은 우연이 아니라 수학적으로 정해져 있습니다. 특성을 하나 더 주면 모델은 그 계수를 0으로 두어 원래 성능을 지킬 수 있으므로, 학습 SSE가 **늘어날 수 없습니다**. 그래서 학습 R²만 보면 난수 열도 "도움이 된다"고 착각합니다.

이것을 바로잡는 값이 **조정 R²**(adjusted R²)입니다. 특성 수 k만큼 벌점을 줍니다.

`조정 R² = 1 − (1 − R²) × (n − 1) ÷ (n − k − 1)`

- n: 행 수, k: 특성 수. k가 커지면 (n − 1) ÷ (n − k − 1)이 커져서 R²를 깎습니다.
- 새 특성이 들어올 때 **늘어난 설명력이 벌점보다 커야** 조정 R²가 오릅니다.

```run
import numpy as np
import pandas as pd
from sklearn.datasets import load_diabetes
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LinearRegression

data = load_diabetes(as_frame=True)
X, y = data.data[["bmi", "s5", "bp"]], data.target
rng = np.random.default_rng(0)
noise = pd.DataFrame(rng.normal(size=(len(X), 40)), index=X.index).add_prefix("noise")
for name, XX in [("3 real", X), ("3 real + 40 noise", pd.concat([X, noise], axis=1))]:
    X_train, X_test, y_train, y_test = train_test_split(XX, y, test_size=0.25, random_state=0)
    model = LinearRegression().fit(X_train, y_train)
    r2 = model.score(X_train, y_train)
    n, k = X_train.shape
    adj = 1 - (1 - r2) * (n - 1) / (n - k - 1)
    print(f"{name:>18}: n={n}, k={k:>2} | train R^2 {r2:.3f} | adjusted {adj:.3f} | test R^2 {model.score(X_test, y_test):.3f}")
```

| | 학습 R² | 조정 R² | 시험 R² |
| --- | --- | --- | --- |
| 진짜 3개 | 0.520 | 0.516 | 0.322 |
| + 난수 40개 | 0.579 | 0.515 | 0.285 |

학습 R²는 0.059 올랐지만 조정 R²는 그대로(오히려 0.001 내림)입니다. 조정 R²는 "난수 40개는 도움이 안 된다"고 제대로 말해 줍니다. 다만 조정 R²도 학습 데이터로 계산한 값이라, 최종 판단은 시험 · 교차검증 점수로 합니다. 통계 보고서(statsmodels 회귀 결과)에는 조정 R²가 기본으로 나옵니다.

## 계수를 비교할 때 주의할 점

위 결과에서 `rpm` 계수가 아주 작다고 "회전수는 중요하지 않다"고 바로 말하면 안 될 때가 있습니다. 계수는 **단위**에 따라 크기가 달라집니다. 회전수는 1,000 단위로 움직이고 공기 온도는 1~2도씩 움직이므로, 같은 영향이어도 회전수의 계수는 작게 나옵니다. 특성끼리 계수 크기를 공정하게 비교하려면 먼저 **표준화**([숫자 크기 맞추기: 표준화와 정규화](#/l/ml-06-2))로 단위를 맞춰야 합니다. [로지스틱 회귀: 확률로 분류하기](#/l/ml-02-5)의 로지스틱 회귀에서는 표준화한 뒤 계수를 비교합니다.

표준화한 뒤 계수를 다시 보면 차이가 분명해집니다. AI4I에서 세 특성을 표준화하고 학습하면 계수는 `air_temp` 1.30, `rpm` −0.015, `torque` −0.016이 됩니다. 이제는 "표준편차 하나만큼 움직일 때"로 단위가 같아졌으니, 공기 온도가 다른 두 특성보다 약 80배 큰 영향을 준다고 말할 수 있습니다.

```run
import pandas as pd
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LinearRegression

df = pd.read_csv("ai4i2020.csv")
features = ["air_temp", "rpm", "torque"]
print("std of each feature:", df[features].std().round(1).tolist())
Xs = StandardScaler().fit_transform(df[features])
model = LinearRegression().fit(Xs, df["process_temp"])
print(pd.Series(model.coef_, index=features).round(3))
```

## 정리

- 특성이 여러 개면 `y = a₁x₁ + a₂x₂ + … + 절편`. 계수는 "나머지는 그대로 두고 이 값만 1 늘 때의 변화"입니다.
- 어떤 특성을 넣느냐가 성능을 좌우합니다(회전수만: R² ≈ 0, 공기 온도 포함: 0.77).
- 계수 크기를 비교하려면 단위를 맞춰야(표준화) 합니다. 표준화 후 `air_temp` 1.30 vs `rpm`·`torque` 약 −0.02.
- 특성을 더하면 학습 R²는 거의 항상 오르지만, 쓸모없는 특성은 시험 R²를 떨어뜨립니다(0.322 → 0.285). 특성 선택은 시험·검증 점수로 판단합니다.
