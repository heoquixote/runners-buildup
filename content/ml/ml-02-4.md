## 시작하기 전에

지금까지는 특성(x) **하나**로 예측했습니다. 실제로는 여러 정보를 함께 쓰는 경우가 대부분입니다. 이번 레슨에서는 특성을 여러 개 넣은 선형회귀(다중 선형회귀)를 만들고, 어떤 특성을 넣느냐에 따라 성능이 어떻게 달라지는지 직접 비교합니다.

## 특성을 여러 개 쓰면

X에 열을 여러 개 넣으면 `y = a₁x₁ + a₂x₂ + … + 절편` 모양이 됩니다. 계수마다 "다른 값은 그대로 두고 이 값만 1 늘면 y가 얼마나 변하나"를 뜻합니다.

```run
import pandas as pd
from sklearn.linear_model import LinearRegression

df = pd.read_csv("ai4i2020.csv")
X = df[["air_temp", "rpm", "torque"]]
y = df["process_temp"]
model = LinearRegression().fit(X, y)
for name, c in zip(X.columns, model.coef_):
    print(f"{name:>9}: {c:+.4f}")
print("R^2:", round(model.score(X, y), 3))
```

회전수·토크 계수는 0에 가깝습니다. 공정 온도는 거의 공기 온도로만 정해진다는 뜻입니다. 이렇게 계수를 보면 어떤 특성이 중요한지도 짐작할 수 있습니다.

### 직접 해보기

`features` 목록을 `["rpm"]`, `["air_temp"]`, `["air_temp", "rpm", "torque"]`로 바꿔 가며 R²를 비교해 보세요. 회전수만 쓰면 R²가 거의 0이고, 공기 온도가 들어가는 순간 크게 오릅니다. **어떤 특성을 넣느냐가 모델 성능을 좌우한다**는 것을 직접 확인할 수 있습니다.

```run
import pandas as pd
from sklearn.linear_model import LinearRegression

df = pd.read_csv("ai4i2020.csv")
features = ["rpm"]   # <- change me
model = LinearRegression().fit(df[features], df["process_temp"])
print(features, "-> R^2:", round(model.score(df[features], df["process_temp"]), 3))
```

## 계수를 비교할 때 주의할 점

위 결과에서 `rpm` 계수가 아주 작다고 "회전수는 중요하지 않다"고 바로 말하면 안 될 때가 있습니다. 계수는 **단위**에 따라 크기가 달라집니다. 회전수는 1,000 단위로 움직이고 공기 온도는 1~2도씩 움직이므로, 같은 영향이어도 회전수의 계수는 작게 나옵니다. 특성끼리 계수 크기를 공정하게 비교하려면 먼저 **표준화**([숫자 크기 맞추기: 표준화와 정규화](#/l/ml-06-2))로 단위를 맞춰야 합니다. [로지스틱 회귀: 확률로 분류하기](#/l/ml-02-5)에서는 표준화한 뒤 계수를 비교합니다.

## 정리

- 특성이 여러 개면 `y = a₁x₁ + a₂x₂ + … + 절편`. 계수는 "나머지는 그대로 두고 이 값만 1 늘 때의 변화"입니다.
- 어떤 특성을 넣느냐가 성능을 좌우합니다(회전수만: R² ≈ 0, 공기 온도 포함: 0.77).
- 계수 크기를 비교하려면 단위를 맞춰야(표준화) 합니다.
