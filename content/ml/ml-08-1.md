## 고장은 드물다

AI4I 설비 데이터 10,000건 중 고장은 몇 건일까요? 직접 세어 봅시다.

```run
import pandas as pd

df = pd.read_csv("ai4i2020.csv")
print(df["failure"].value_counts())
print("failure rate:", round(df["failure"].mean(), 4))
```

10,000건 중 339건, 약 **3.4%**입니다. 나머지 96.6%는 정상입니다. 이렇게 한쪽 정답이 다른 쪽보다 훨씬 드문 데이터를 **불균형 데이터**라고 합니다. 제조 불량, 카드 부정 결제, 희귀 질병 진단처럼 **우리가 정말 찾고 싶은 것은 대부분 드뭅니다.**

## 정확도의 함정

시험 문제 100개 중 97개의 답이 "O"라고 해 봅시다. 문제를 읽지도 않고 전부 "O"라고 찍으면 97점입니다. 점수는 높지만 실력은 0입니다.

머신러닝도 똑같습니다. 아무것도 배우지 않고 **"전부 정상"이라고만 답하는 모델**을 만들어 보겠습니다. sklearn의 `DummyClassifier`가 바로 이런 "찍기" 모델입니다.

```run
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.dummy import DummyClassifier
from sklearn.metrics import accuracy_score, recall_score

df = pd.read_csv("ai4i2020.csv")
features = ["air_temp", "process_temp", "rpm", "torque", "tool_wear"]
X = df[features].values
y = df["failure"].values
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.3, random_state=0, stratify=y)

dummy = DummyClassifier(strategy="most_frequent").fit(X_tr, y_tr)
pred = dummy.predict(X_te)
print("accuracy:", round(accuracy_score(y_te, pred), 3))
print("recall  :", recall_score(y_te, pred))
```

정확도는 0.966인데 **재현율은 0**입니다. 고장을 단 하나도 잡지 못했습니다. 그래서 불균형 데이터에서는 정확도 대신 [평가지표](#/l/ml-03-1)에서 배운 지표들을 봅니다. 한 번 더 짚어 보면 이렇습니다.

- **재현율(recall)**: 실제 고장 중에서 모델이 잡아낸 비율. "놓치지 않았나?"
- **정밀도(precision)**: 모델이 고장이라고 한 것 중 진짜 고장의 비율. "괜히 울리지 않았나?"
- **F1**: 둘을 함께 보는 점수(조화평균). 둘 중 하나라도 낮으면 낮게 나옵니다.

> `stratify=y`는 학습용과 테스트용에 고장 비율을 똑같이(3.4%) 맞춰 나눠 줍니다. 고장이 드물면 그냥 무작위로 나눴을 때 테스트에 고장이 너무 적게 들어갈 수 있어서, 불균형 데이터에서는 꼭 넣습니다.

## 진짜 모델은 어떨까

이번에는 로지스틱 회귀로 제대로 학습해 봅니다. 숫자 크기가 다른 열들이라 표준화를 함께 묶었습니다.

```run
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import accuracy_score, precision_score, recall_score

df = pd.read_csv("ai4i2020.csv")
features = ["air_temp", "process_temp", "rpm", "torque", "tool_wear"]
X = df[features].values
y = df["failure"].values
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.3, random_state=0, stratify=y)

model = make_pipeline(StandardScaler(), LogisticRegression()).fit(X_tr, y_tr)
pred = model.predict(X_te)
print("accuracy :", round(accuracy_score(y_te, pred), 3))
print("recall   :", round(recall_score(y_te, pred), 3))
print("precision:", round(precision_score(y_te, pred), 3))
print("real failures in test:", y_te.sum(), " caught:", ((pred == 1) & (y_te == 1)).sum())
```

정확도는 0.973으로 찍기 모델(0.966)과 거의 같습니다. 재현율을 보면 테스트의 실제 고장 102건 중 27건, 약 26%만 잡았습니다. 대신 고장이라고 한 34건 중 27건은 진짜라서 정밀도(0.79)는 높습니다. 모델 입장에서는 정상이 압도적으로 많으니 "애매하면 정상"이라고 답하는 쪽이 손해가 적기 때문입니다. 이 문제를 고치는 방법 세 가지를 다음 세 레슨에서 하나씩 해 봅니다.

## 고장은 어디에 몰려 있나

드문 것을 찾기 전에, 그 드문 것이 **어떤 조건에 몰려 있는지** 먼저 들여다보면 모델이 무엇을 배워야 하는지 감이 옵니다. 공구 사용 시간과 토크를 구간으로 나눠 고장률을 봅니다.

```run
import pandas as pd

df = pd.read_csv("ai4i2020.csv")
print(df.groupby("type")["failure"].agg(["mean", "size"]).round(4))
print(df.groupby(pd.cut(df["tool_wear"], [-1, 50, 100, 150, 200, 260]), observed=True)["failure"].agg(["mean", "size"]).round(3))
print(df.groupby(pd.cut(df["torque"], [0, 20, 30, 40, 50, 60, 80]), observed=True)["failure"].agg(["mean", "size"]).round(3))
```

- 제품 등급: L 3.9%, M 2.8%, H 2.1%로 등급이 낮을수록 조금 높습니다.
- 공구 사용 시간: 200분까지는 2~3%로 비슷하다가 **200분이 넘으면 15.5%**로 뜁니다.
- 토크: 20~50Nm에서는 1~2%인데, **20Nm 이하는 14.6%, 60Nm 초과는 41.9%**입니다.

전체로는 3.4%뿐이지만, 특정 조건에서는 고장이 열 번에 한두 번, 많게는 열 번에 네 번꼴입니다. 불균형 데이터에서 모델의 일은 결국 **"이렇게 고장이 몰린 구석"을 찾아내는 것**입니다. 이런 구석은 직선보다 구간으로 나누는 모델(트리, ml-04)이 잘 잡습니다.

## 정리

- 한쪽 정답이 훨씬 드문 데이터를 **불균형 데이터**라고 합니다(AI4I 고장 3.4%).
- 전부 "정상"이라고 찍어도 정확도 0.966. 불균형에서는 정확도 대신 재현율·정밀도·F1을 봅니다.
- 나눌 때는 `stratify=y`
- 그냥 학습한 모델은 "애매하면 정상"으로 기울어 재현율이 낮습니다(0.26).
- 전체 3.4%라도 조건에 따라 고장이 몰립니다(공구 200분 초과 15.5%, 토크 60Nm 초과 41.9%).
