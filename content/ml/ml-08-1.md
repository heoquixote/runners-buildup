## 불량은 드물다

제조 불량, 카드 이상 거래, 설비 고장은 전체의 몇 %에 불과합니다. 이런 **불균형 데이터**에서는 아무것도 학습하지 않고 "모두 정상"이라고만 해도 정확도가 높게 나옵니다.

```run
import numpy as np
from sklearn.dummy import DummyClassifier
from sklearn.metrics import accuracy_score, recall_score

y = np.array([0] * 97 + [1] * 3)
X = np.zeros((100, 1))
pred = DummyClassifier(strategy="most_frequent").fit(X, y).predict(X)
print("accuracy", accuracy_score(y, pred), " recall", recall_score(y, pred))
```

정확도 97%, 재현율 0. 불량을 하나도 못 잡는 모델입니다. 그래서 불균형 데이터에서는 **재현율 · 정밀도 · F1**, PR 곡선(average precision)을 봅니다.

## 대응 방법 세 가지

| 방법 | 하는 일 | 코드 |
| --- | --- | --- |
| 클래스 가중치 | 드문 클래스를 틀리면 손실을 크게 | `class_weight="balanced"` |
| 임계값 조정 | 0.5 대신 더 낮은 확률에서 양성 판정 | `(proba >= 0.2)` |
| 리샘플링 | 학습 데이터의 소수 클래스를 늘리거나 다수를 줄임 | `sklearn.utils.resample` |

```run
import numpy as np
from sklearn.model_selection import train_test_split
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import precision_score, recall_score

i = np.arange(300)
pressure = 50 + 3 * np.sin(i * 0.31) + 1.2 * np.cos(i * 1.77)
dtemp = 0.5 * np.cos(i * 0.47) + 0.3 * np.sin(i * 2.53)
X = np.column_stack([pressure, dtemp])
y = (((pressure - 50) / 3 + dtemp / 0.5 + 0.6 * np.sin(i * 3.41)) > 1.75).astype(int)
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.3, random_state=0, stratify=y)
print("defect rate", round(y.mean(), 3))
for cw in [None, "balanced"]:
    m = make_pipeline(StandardScaler(), LogisticRegression(class_weight=cw)).fit(X_tr, y_tr)
    p = m.predict(X_te)
    print(f"class_weight={cw}: recall {recall_score(y_te, p):.2f}  precision {precision_score(y_te, p, zero_division=0):.2f}  alarms {p.sum()}")
```

## 임계값은 비용으로 정한다

`predict`는 확률 0.5를 기준으로 자릅니다. 하지만 불량 하나를 놓치는 비용(리콜, 클레임)이 오탐 하나의 비용(재검사)보다 훨씬 크다면 기준을 낮추는 것이 맞습니다.

```run
import numpy as np
from sklearn.model_selection import train_test_split
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import precision_score, recall_score

i = np.arange(300)
amount = 8 + 5 * np.sin(i * 0.29) + 2 * np.cos(i * 1.61)
gap = 12 + 8 * np.cos(i * 0.43) + 3 * np.sin(i * 2.21)
X = np.column_stack([amount, gap])
y = (((amount - 8) / 5 - (gap - 12) / 8 + 0.6 * np.sin(i * 3.07)) > 1.6).astype(int)
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.3, random_state=0, stratify=y)
proba = make_pipeline(StandardScaler(), LogisticRegression()).fit(X_tr, y_tr).predict_proba(X_te)[:, 1]
for t in [0.5, 0.3, 0.2, 0.1]:
    p = (proba >= t).astype(int)
    print(f"threshold {t}: recall {recall_score(y_te, p):.2f}  precision {precision_score(y_te, p, zero_division=0):.2f}")
```

임계값은 **검증 데이터**에서 정하고 테스트에서 확인합니다. 테스트를 보며 고르면 낙관적인 점수가 됩니다.

## 리샘플링은 학습 데이터만

오버샘플링(소수 클래스를 복원 추출로 늘리기)은 반드시 train/test로 나눈 **뒤**, 학습 데이터에만 합니다. 나누기 전에 하면 같은 행의 복제본이 학습과 테스트에 동시에 들어가 성능이 부풀려집니다. 교차검증과 함께 쓰려면 `imbalanced-learn`의 파이프라인이 폴드마다 따로 리샘플링해 줍니다.

> 분할할 때 `stratify=y`를 꼭 주세요. 불량이 15개뿐이면 무작위 분할만으로 테스트에 불량이 거의 없을 수 있습니다.
