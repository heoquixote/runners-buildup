## 시작하기 전에

[선형회귀: 직선 하나로 예측하기](#/l/ml-02-1)에서 `LinearRegression().fit()` 한 줄로 기울기 0.65짜리 직선을 얻었습니다. 그런데 컴퓨터는 이 직선을 어떻게 찾았을까요? 이번 레슨에서는 머신러닝·딥러닝 모델 대부분이 쓰는 학습 방법, **경사하강법(gradient descent)** 을 numpy로 직접 구현해 봅니다. 수식보다 그림과 코드로 이해하는 것이 목표입니다.

## 오차를 줄이는 방향으로 한 걸음씩

[오차 재기: MAE · RMSE · R²](#/l/ml-02-2)에서 오차를 하나의 숫자로 요약했습니다. 여기서는 오차 제곱의 평균, **MSE(평균 제곱 오차)** 를 씁니다. 직선의 기울기와 절편을 바꾸면 MSE도 바뀝니다. 그러니 "MSE가 가장 작아지는 기울기·절편"을 찾으면 됩니다.

안개가 짙게 낀 산에서 골짜기(가장 낮은 곳)로 내려가야 한다고 해 봅시다. 멀리는 안 보이지만 **발밑이 어느 쪽으로 기울었는지**는 알 수 있습니다. 그러면 내려가는 쪽으로 한 걸음 걷고, 다시 발밑을 확인하고, 또 한 걸음… 이것을 반복하면 결국 골짜기에 도착합니다.

::figure{src="content/img/ml/ml02-gd.svg" alt="그릇 모양 오차 곡선 위에서 공이 기울기 반대 방향으로 한 걸음씩 내려가 가장 낮은 곳에 도착한다" caption="오차가 높은 곳에서 출발해, 기울기의 반대 방향으로 조금씩 움직이면 오차가 가장 작은 곳에 도착합니다."}

| 산 비유 | 경사하강법 |
| --- | --- |
| 지금 서 있는 위치 | 지금의 기울기 `w`·절편 `b` |
| 높이 | 오차(MSE) |
| 발밑의 기울어진 정도 | 기울기(gradient): 값을 조금 바꾸면 오차가 얼마나 변하나 |
| 한 걸음의 크기 | **학습률(learning rate)** |
| 걸음 수 | 반복 횟수(step, epoch) |

## 직접 구현하기

공기 온도(x)로 공정 온도(y)를 예측하는 직선 `y = w × x + b`를 경사하강법으로 찾습니다. x는 크기를 맞추기 위해 **표준화**(평균 0, 표준편차 1)해서 씁니다. 출발점은 `w = 0`, `b = 0`(바닥에 깔린 평평한 선)입니다.

```run
import numpy as np
import pandas as pd

df = pd.read_csv("ai4i2020.csv")
x = (df["air_temp"] - df["air_temp"].mean()) / df["air_temp"].std()   # standardized
y = df["process_temp"].values

w, b = 0.0, 0.0          # start: flat line at 0
lr = 0.1                 # learning rate (step size)
for step in range(1, 51):
    pred = w * x + b
    error = pred - y
    mse = (error ** 2).mean()
    w -= lr * 2 * (error * x).mean()     # move against the slope of the error
    b -= lr * 2 * error.mean()
    if step in (1, 2, 5, 10, 20, 50):
        print(f"step {step:>2}: MSE {mse:>10.2f}   w {w:6.3f}   b {b:7.2f}")
print("slope in K per K:", round(w / df["air_temp"].std(), 3))
```

코드에서 핵심은 두 줄입니다.

- `w -= lr * 2 * (error * x).mean()`: "w를 조금 늘리면 오차가 늘어나는가?"를 계산해, 늘어나는 방향의 **반대로** `lr`만큼 움직입니다.
- `b -= lr * 2 * error.mean()`: 절편도 같은 방식으로 움직입니다.

결과를 보면 처음 MSE는 약 96,000으로 엉망이지만, 10걸음에 약 1,700, 20걸음에 약 20, 50걸음에 **0.51**까지 줄어듭니다. 마지막 줄의 기울기를 원래 단위로 바꾸면 **0.65**로, [선형회귀: 직선 하나로 예측하기](#/l/ml-02-1)에서 `LinearRegression`이 찾은 값과 같습니다. 도구가 해 주던 일을 직접 해 본 것입니다.

## 직접 해보기: 학습률(보폭) 바꾸기

학습률 `lr`을 0.01, 0.1, 0.5, 1.1로 바꿔 가며 실행해 보세요. 50걸음 뒤의 오차를 비교합니다.

```run
import numpy as np
import pandas as pd

df = pd.read_csv("ai4i2020.csv")
x = (df["air_temp"] - df["air_temp"].mean()) / df["air_temp"].std()
y = df["process_temp"].values

lr = 0.01   # <- change me: 0.01, 0.1, 0.5, 1.1
w, b = 0.0, 0.0
for step in range(50):
    error = w * x + b - y
    w -= lr * 2 * (error * x).mean()
    b -= lr * 2 * error.mean()
print(f"lr {lr}: MSE after 50 steps = {((w * x + b - y) ** 2).mean():.2f}")
```

| 학습률 | 50걸음 뒤 MSE | 무슨 일이 |
| --- | --- | --- |
| 0.01 | 약 12,700 | 보폭이 너무 작아 아직 산 중턱 |
| 0.1 | 약 0.5 | 적당히 내려와 도착 |
| 0.5 | 약 0.5 | 이 문제에서는 한 번에 성큼 도착 |
| 1.1 | 수조 단위로 폭발 | 보폭이 너무 커서 골짜기를 건너뛰고 반대편으로 더 높이 올라가기를 반복 (**발산**) |

학습률은 사람이 정하는 설정값(**하이퍼파라미터**, [교차검증과 하이퍼파라미터](#/l/ml-05-1)에서 자세히)입니다. 너무 작으면 느리고, 너무 크면 아예 도착하지 못합니다.

## 왜 중요한가

`LinearRegression`은 사실 경사하강법 없이 공식 한 번으로 답을 구할 수 있습니다. 하지만 로지스틱 회귀, 부스팅, 그리고 딥러닝의 신경망은 그런 공식이 없어서 **경사하강법으로 한 걸음씩** 학습합니다. 데이터가 아주 많으면 전체 대신 일부(미니배치)만 보고 한 걸음씩 걷는 방법도 씁니다.

## 정리

- 경사하강법 = 오차가 줄어드는 방향(기울기의 반대)으로 값을 조금씩 고치는 것을 반복하는 방법
- **학습률**은 한 걸음의 크기. 너무 작으면 느리고, 너무 크면 발산합니다.
- 직접 구현한 결과(기울기 0.65)가 `LinearRegression`과 같았습니다.
