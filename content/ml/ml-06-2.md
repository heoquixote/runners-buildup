## 시작하기 전에

앞 레슨에서 빈칸과 글자를 해결했습니다. 그런데 숫자 열끼리도 문제가 있습니다. 나이는 0~80, 운임은 0~512, 회전수는 1,000 단위입니다. 이번 레슨에서는 크기가 제각각인 숫자를 같은 잣대에 놓는 **스케일링**을 배웁니다.

## 숫자 크기 맞추기: 표준화

키(cm)와 몸무게(kg)로 "비슷한 사람"을 찾는다고 해 봅시다. 키 차이 10은 작은 차이인데 몸무게 차이 10은 큰 차이입니다. 숫자만 보면 둘 다 10이라 공정하지 않습니다.

**표준화**는 각 열을 "평균에서 표준편차 몇 개만큼 떨어졌나"로 바꿔 모든 열을 같은 잣대로 만듭니다. 결과는 평균 0, 표준편차 1 근처가 됩니다.

::figure{src="content/img/ml/ml06-scale.svg" alt="표준화 전에는 운임이 0~500, 나이가 0~80으로 범위가 다르고, 표준화 후에는 둘 다 0을 중심으로 비슷한 범위에 놓인다" caption="표준화 전에는 운임 숫자가 훨씬 커서 거리 계산을 독차지하지만, 표준화 후에는 두 열이 같은 잣대에 놓입니다."}

::video{ref="dl-m30"}

```run
import pandas as pd
from sklearn.preprocessing import StandardScaler

df = pd.read_csv("ai4i2020.csv")
cols = ["rpm", "torque", "tool_wear"]
print("before:")
print(df[cols].describe().loc[["mean", "std"]].round(1))
scaled = StandardScaler().fit_transform(df[cols])
print("after: mean", scaled.mean(axis=0).round(3), " std", scaled.std(axis=0).round(3))
```

거리나 계수를 쓰는 모델(KNN, 로지스틱 회귀, 신경망)에는 표준화가 중요하고, 트리 모델에는 필요 없습니다.

주의할 점 두 가지:

- **원-핫으로 만든 0/1 열은 표준화하지 않습니다.** 이미 같은 잣대(0 또는 1)이고, 표준화하면 "여성이면 1"처럼 읽기 쉬운 의미가 사라집니다. 그래서 ml-06-4의 Pipeline에서도 표준화는 숫자 열에만 겁니다.
- **아주 튀는 값(이상치)이 많으면** 평균·표준편차가 그 값에 끌려갑니다. 이럴 때는 중앙값 기준으로 맞추는 `RobustScaler`를 고려합니다.

## 또 다른 방법: 정규화(Min-Max)

표준화 말고 많이 쓰는 방법이 하나 더 있습니다. **정규화(Min-Max 스케일링)** 는 각 열의 최솟값을 0, 최댓값을 1로 놓고 그 사이로 줄입니다. 시험 점수를 "100점 만점 중 몇 점"으로 바꾸는 것과 비슷합니다.

`(값 − 최솟값) / (최댓값 − 최솟값)`

```run
import pandas as pd
from sklearn.preprocessing import StandardScaler, MinMaxScaler

df = pd.read_csv("titanic.csv")
d = df[["age", "fare"]].dropna()
std = pd.DataFrame(StandardScaler().fit_transform(d), columns=d.columns)
mm = pd.DataFrame(MinMaxScaler().fit_transform(d), columns=d.columns)
print("original:\n", d.describe().loc[["min", "max"]].round(1))
print("standardized:\n", std.describe().loc[["min", "max"]].round(2))
print("min-max:\n", mm.describe().loc[["min", "max"]].round(2))
print("share of fares below 0.1 after min-max:", round((mm["fare"] < 0.1).mean(), 3))
```

- 표준화 후 범위는 나이 −2.02~3.47, 운임 −0.66~9.03입니다. 평균을 0에 맞출 뿐 범위는 정해지지 않습니다.
- 정규화 후에는 둘 다 정확히 0~1입니다.
- 그런데 운임은 512파운드짜리 표 몇 장 때문에, 정규화하면 승객의 **80.8%가 0.1 아래**에 몰립니다. 튀는 값 하나가 잣대 전체를 늘려 버린 것입니다.

| 방법 | 결과 | 어울릴 때 |
| --- | --- | --- |
| 표준화 `StandardScaler` | 평균 0, 표준편차 1 | 대부분의 경우 기본값 |
| 정규화 `MinMaxScaler` | 0~1 | 범위가 정해진 값(이미지 픽셀 0~255, 퍼센트), 신경망 입력 |
| `RobustScaler` | 중앙값 0, 사분위 범위 기준 | 튀는 값이 많을 때 |

## 어떤 모델에 필요할까

| 모델 | 스케일링 | 이유 |
| --- | --- | --- |
| 선형·로지스틱 회귀 | 필요 (특히 계수 비교, 경사하강법) | 단위가 크면 계수·학습 속도가 왜곡됨 |
| KNN, K-means, SVM | **꼭** 필요 | 거리를 재므로 큰 숫자가 거리를 독차지 |
| 신경망 | 필요 | 경사하강법이 안정적으로 내려가게 |
| 결정트리, 랜덤포레스트, 부스팅 | 필요 없음 | "기준보다 큰가?"만 물음 |

## 정리

- 표준화 = 평균 0·표준편차 1, 정규화 = 0~1 범위
- 튀는 값이 있으면 정규화는 대부분의 값이 한쪽에 몰립니다 → 표준화나 RobustScaler
- 거리·계수·경사하강법을 쓰는 모델에는 필요하고, 트리 모델에는 필요 없습니다.
- 스케일러도 학습용으로만 fit 합니다(ml-01-5 전처리 누수).
