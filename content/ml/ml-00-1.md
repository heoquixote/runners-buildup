## 이름부터 정리하기: AI, 머신러닝, 딥러닝

뉴스에서 "AI", "머신러닝", "딥러닝"이라는 말이 섞여 나옵니다. 셋은 같은 말이 아니라 **큰 상자 안에 작은 상자가 들어 있는 관계**입니다.

::figure{src="content/img/ml/ml00-ai-ml-dl.svg" alt="인공지능 안에 머신러닝이, 머신러닝 안에 딥러닝이 들어 있는 동심원" caption="인공지능이 가장 넓은 말이고, 머신러닝은 그중 '데이터로 배우는' 방법, 딥러닝은 그중 신경망을 깊게 쌓은 방법입니다."}

- **인공지능(AI)**: 사람처럼 판단하는 프로그램을 모두 부르는 말입니다. 사람이 규칙을 전부 써 넣은 체스 프로그램도 AI입니다.
- **머신러닝(Machine Learning, 기계 학습)**: 그중에서 규칙을 사람이 쓰지 않고 **데이터를 보고 스스로 찾게 하는** 방법입니다. 이 트랙에서 배울 내용입니다.
- **딥러닝(Deep Learning)**: 머신러닝 중에서 인공 신경망을 아주 깊게 쌓은 방법입니다. 사진·음성·글처럼 복잡한 데이터에 강합니다. 딥러닝 트랙에서 따로 배웁니다.

## 규칙을 사람이 쓸까, 데이터에서 찾을까

스팸 메일을 걸러내는 프로그램을 만든다고 해 봅시다.

- **사람이 규칙을 쓰는 방법**: "제목에 '무료'가 있으면 스팸", "'광고'가 있으면 스팸"처럼 체크리스트를 직접 적습니다. 그런데 스팸을 보내는 쪽이 '무.료', 'F R E E'처럼 바꾸면 규칙을 계속 고쳐야 합니다.
- **머신러닝**: 지금까지 받은 메일 수만 통과 "이건 스팸이었다 / 아니었다"라는 **정답**을 보여 주고, 어떤 특징이 스팸과 관련 있는지 컴퓨터가 스스로 찾게 합니다. 새로운 수법이 나와도 새 예시를 보여 주면 다시 배웁니다.

::figure{src="content/img/ml/ml01-program-vs-ml.svg" alt="프로그래밍은 규칙과 데이터로 답을 내고, 머신러닝은 데이터와 답으로 규칙을 찾는다" caption="보통의 프로그래밍은 사람이 규칙을 쓰고, 머신러닝은 데이터와 답을 보고 컴퓨터가 규칙을 찾습니다."}

한 줄로 정리하면, 머신러닝은 **체크리스트를 직접 쓰는 대신, 예시를 많이 보여 주고 스스로 기준을 익히게 하는 방법**입니다.

## 사람이 세운 규칙은 얼마나 맞을까

**데이터 소개 · 타이타닉 승객 기록** (`titanic.csv`)

1912년 침몰한 여객선 타이타닉의 승객 **891명** 기록입니다. 누가 살아남았는지와 승객 정보가 들어 있어, 생존에 무엇이 영향을 줬는지 분석하는 고전 예제입니다(seaborn 예제 데이터). **한 행 = 승객 한 명**입니다.

| 컬럼 | 뜻 | 자료형 | 예시 |
| --- | --- | --- | --- |
| `survived` | 생존 여부(1 = 생존, 0 = 사망) | 정수 | 0, 1 |
| `pclass` | 객실 등급(1등석이 가장 비쌈) | 정수 | 1, 2, 3 |
| `sex` | 성별 | 글자 | male, female |
| `age` | 나이(세) | 소수 | 22.0 |
| `sibsp` | 함께 탄 형제자매 · 배우자 수 | 정수 | 1 |
| `parch` | 함께 탄 부모 · 자녀 수 | 정수 | 0 |
| `fare` | 요금(파운드) | 소수 | 7.25 |
| `embarked` | 탄 항구 첫 글자 | 글자 | S, C, Q |
| `class` | 객실 등급(글자) | 글자 | First, Second, Third |
| `who` | 남자 · 여자 · 어린이 | 글자 | man, woman, child |
| `adult_male` | 성인 남성인가 | 참/거짓 | True |
| `deck` | 갑판(객실 층) | 글자 | A ~ G |
| `embark_town` | 탄 항구 이름 | 글자 | Southampton |
| `alive` | 생존 여부(글자) | 글자 | yes, no |
| `alone` | 혼자 탔나 | 참/거짓 | False |

`age`는 177명, `deck`은 688명이 비어 있습니다. `class` · `alive` · `embark_town`은 다른 열을 글자로 다시 쓴 것입니다. 전체 생존율은 38.4%입니다.

1912년 타이타닉호 승객 891명의 기록으로 직접 확인해 봅니다. 역사책에는 "여성과 어린이 먼저 구명보트에 태웠다"고 나옵니다. 그렇다면 **"여성이면 생존, 남성이면 사망"**이라는 규칙 하나로 얼마나 맞힐 수 있을까요?

아래 셀은 승객마다 이 규칙으로 답을 내고, 실제 기록과 비교해 몇 %를 맞혔는지 셉니다. 코드를 다 이해하지 못해도 괜찮습니다. ▶ 실행을 누르고 마지막 숫자만 보세요.

```run
import pandas as pd

df = pd.read_csv("titanic.csv")
rule = (df["sex"] == "female").astype(int)      # 1 = survived, by our rule
correct = (rule == df["survived"])
print("passengers:", len(df))
print("rule accuracy:", round(correct.mean(), 3))
```

사람이 세운 규칙 하나로 약 **78.7%**를 맞힙니다. 꽤 높습니다. 그런데 이 규칙은 사람이 역사를 알고 있었기 때문에 세울 수 있었습니다. 처음 보는 데이터라면 어떤 규칙을 세워야 할지 모를 때가 훨씬 많습니다.

## 컴퓨터에게 규칙을 찾게 해 보기

이번에는 규칙을 알려 주지 않고, 승객 정보(객실 등급·성별·나이·운임)와 정답(생존 여부)만 주겠습니다. 그리고 컴퓨터에게 **"질문 딱 하나로 생존을 가장 잘 가르는 규칙"**을 찾으라고 시킵니다. (이때 쓰는 도구가 결정트리인데, [트리와 앙상블 (회귀 · 분류 공통)](#/l/ml-04-1)에서 자세히 배웁니다.)

```run
import pandas as pd
from sklearn.tree import DecisionTreeClassifier, export_text

df = pd.read_csv("titanic.csv")
df["female"] = (df["sex"] == "female").astype(int)
df["age"] = df["age"].fillna(df["age"].median())
features = ["pclass", "female", "age", "fare"]

model = DecisionTreeClassifier(max_depth=1, random_state=0)
model.fit(df[features], df["survived"])
print(export_text(model, feature_names=features))
```

결과를 읽어 보면, `female <= 0.50`(남성)이면 `class: 0`(사망), 그렇지 않으면(여성) `class: 1`(생존)입니다. 컴퓨터가 **역사를 모르는데도 데이터만 보고 사람과 같은 규칙을 찾아냈습니다.** 네 가지 정보 중에서 성별이 생존을 가장 잘 가른다는 것도 스스로 골랐습니다. 이것이 "기계가 배운다"는 말의 뜻입니다.

## "학습"이란 무엇일까

사람이 수학을 배우는 과정을 떠올려 보세요. 문제집을 풀고, 답지로 채점하고, 틀린 것을 고치다 보면 처음 보는 문제도 풀 수 있게 됩니다.

머신러닝도 똑같습니다.

| 사람의 공부 | 머신러닝 |
| --- | --- |
| 문제집의 문제 | 예전 기록의 정보 → **특성 X** (등급, 성별, 나이…) |
| 답지 | 예전 기록의 결과 → **정답 y** (생존 여부) |
| 풀고 채점하며 요령을 익힘 | **학습(fit)**: X와 y를 보고 맞히는 규칙을 찾음 |
| 익힌 요령 | **모델**: 찾은 규칙이 담긴 상자 |
| 처음 보는 시험 문제를 풂 | **예측(predict)**: 새 X를 넣으면 답을 냄 |

::figure{src="content/img/ml/ml00-train-predict.svg" alt="학습 단계에서는 승객 기록과 정답으로 모델을 만들고, 예측 단계에서는 정답을 모르는 새 승객을 같은 모델에 넣어 생존을 예측한다" caption="머신러닝은 항상 두 단계입니다. 정답이 있는 예전 기록으로 학습하고, 정답을 모르는 새 사례에 예측합니다."}

코드로는 딱 두 줄입니다. `model.fit(X, y)`로 배우고, `model.predict(새 X)`로 맞힙니다. 타이타닉에 없던 가상의 승객 두 명을 만들어 예측해 봅시다.

```run
import pandas as pd
from sklearn.tree import DecisionTreeClassifier

df = pd.read_csv("titanic.csv")
df["female"] = (df["sex"] == "female").astype(int)
df["age"] = df["age"].fillna(df["age"].median())
features = ["pclass", "female", "age", "fare"]

model = DecisionTreeClassifier(max_depth=3, random_state=0)
model.fit(df[features], df["survived"])                    # 1) learn

new_people = pd.DataFrame({"pclass": [1, 3], "female": [1, 0], "age": [25, 25], "fare": [80.0, 8.0]})
print(new_people)
print("prediction:", model.predict(new_people))            # 2) predict
```

1등실 25살 여성은 `1`(생존), 3등실 25살 남성은 `0`(사망)으로 예측합니다. 모델은 이 두 사람을 본 적이 없지만, 891명에게서 배운 규칙을 적용해 답을 냈습니다.

## 많이 볼수록 더 잘 배운다

사람도 문제를 10개 푼 학생보다 600개 푼 학생이 시험을 더 잘 봅니다. 모델도 그런지 확인해 봅시다.

아래 셀은 승객을 **학습용**과 **시험용**으로 나눈 뒤, 학습용에서 `n`명만 골라 배우게 하고 시험용 승객을 얼마나 맞히는지 잽니다. 운에 따라 흔들리지 않게 20번 반복해 평균을 냅니다. (학습용·시험용으로 나누는 이유는 [ML 워크플로와 데이터 준비](#/l/ml-01-0) 코스에서 배웁니다.)

### 직접 해보기

`n`을 10, 30, 100, 300, 600으로 바꿔 가며 실행해 보세요.

```run
import numpy as np
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier

df = pd.read_csv("titanic.csv")
df["female"] = (df["sex"] == "female").astype(int)
df["age"] = df["age"].fillna(df["age"].median())
features = ["pclass", "female", "age", "fare"]
X_train, X_test, y_train, y_test = train_test_split(df[features], df["survived"], test_size=0.3, random_state=0, stratify=df["survived"])

n = 10   # <- change me: how many passengers the model may learn from (max 623)
scores = []
for seed in range(20):
    idx = X_train.sample(n, random_state=seed).index
    model = DecisionTreeClassifier(max_depth=3, random_state=0).fit(X_train.loc[idx], y_train.loc[idx])
    scores.append(model.score(X_test, y_test))
print(f"learned from {n} passengers -> test accuracy {np.mean(scores):.3f}")
```

10명만 보면 약 0.64, 30명이면 0.70, 100명이면 0.75, 300명이면 0.80, 600명이면 0.82까지 오릅니다. **예시(데이터)가 많을수록 더 잘 배운다**는 것이 머신러닝의 기본 성질입니다. 그래서 머신러닝에는 데이터가 중요합니다.

## 정리

- 머신러닝은 **규칙을 사람이 쓰는 대신, 예시(X)와 정답(y)을 보여 주고 컴퓨터가 규칙을 찾게 하는** 방법입니다.
- 순서는 언제나 두 단계: **학습(fit)** 으로 규칙을 찾고, **예측(predict)** 으로 새 사례에 적용합니다.
- 모델은 "규칙이 들어 있는 상자"입니다. 타이타닉에서는 사람이 아는 "여성이면 생존" 규칙을 컴퓨터가 스스로 찾아냈습니다.
- 예시가 많을수록 더 잘 배웁니다(10명 0.64 → 600명 0.82).
