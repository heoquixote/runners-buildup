## 한 번 나눈 테스트 점수는 운이 섞인다

`train_test_split`으로 한 번 나누면 어떤 행이 테스트에 들어갔느냐에 따라 점수가 꽤 흔들립니다. 테스트가 30개라면 한 개만 바뀌어도 정확도가 3%p 움직입니다.

```run
import numpy as np
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier

i = np.arange(120)
X = np.column_stack([52 + 4 * np.sin(i * 0.37), 3 + 0.6 * np.cos(i * 0.53)])
y = (((X[:, 0] - 52) / 4 + (X[:, 1] - 3) / 0.6 + 0.7 * np.sin(i * 3.33)) > 1).astype(int)
for seed in range(5):
    X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.25, random_state=seed, stratify=y)
    acc = DecisionTreeClassifier(max_depth=3, random_state=0).fit(X_tr, y_tr).score(X_te, y_te)
    print("split seed", seed, "-> test acc", round(acc, 3))
```

## K-fold 교차검증

데이터를 K조각(fold)으로 나누고, 한 조각씩 돌아가며 검증에 쓰고 나머지로 학습합니다. 모든 행이 한 번씩 검증에 쓰이고, K개의 점수가 나옵니다.

- **평균**: 성능 추정
- **표준편차**: 데이터에 따라 얼마나 흔들리는지

::video{ref="dl-m24"}

```run
import numpy as np
from sklearn.model_selection import cross_val_score
from sklearn.tree import DecisionTreeClassifier

i = np.arange(120)
X = np.column_stack([52 + 4 * np.sin(i * 0.37), 3 + 0.6 * np.cos(i * 0.53)])
y = (((X[:, 0] - 52) / 4 + (X[:, 1] - 3) / 0.6 + 0.7 * np.sin(i * 3.33)) > 1).astype(int)
scores = cross_val_score(DecisionTreeClassifier(max_depth=3, random_state=0), X, y, cv=5)
print("fold scores", scores.round(3))
print("mean", round(scores.mean(), 3), " std", round(scores.std(), 3))
```

분류 모델에 `cv=5`처럼 숫자를 주면 클래스 비율을 유지하는 **층화 K-fold**(StratifiedKFold)가 기본입니다. 행 순서에 패턴이 있으면 `StratifiedKFold(n_splits=5, shuffle=True, random_state=0)`처럼 섞어서 나눕니다. 시계열은 미래로 과거를 예측하면 안 되므로 `TimeSeriesSplit`을 씁니다.

## 하이퍼파라미터: 사람이 정하는 설정

`max_depth`, `n_neighbors`, `C`처럼 학습 전에 정하는 값입니다. 너무 단순하면 과소적합, 너무 복잡하면 과적합입니다.

::video{ref="dl-m10"}

`GridSearchCV`는 후보마다 교차검증을 돌려 가장 좋은 값을 고르고, 그 값으로 전체 학습 데이터에 다시 학습합니다.

```run
import numpy as np
from sklearn.model_selection import train_test_split, GridSearchCV
from sklearn.tree import DecisionTreeClassifier

i = np.arange(120)
X = np.column_stack([52 + 4 * np.sin(i * 0.37), 3 + 0.6 * np.cos(i * 0.53)])
y = (((X[:, 0] - 52) / 4 + (X[:, 1] - 3) / 0.6 + 0.7 * np.sin(i * 3.33)) > 1).astype(int)
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.25, random_state=0, stratify=y)

grid = GridSearchCV(DecisionTreeClassifier(random_state=0), {"max_depth": [1, 2, 3, 4, 6, None]}, cv=5).fit(X_tr, y_tr)
for p, s in zip(grid.cv_results_["params"], grid.cv_results_["mean_test_score"]):
    print(p, round(s, 3))
print("best", grid.best_params_, "cv", round(grid.best_score_, 3), "test", round(grid.score(X_te, y_te), 3))
```

## 세 가지 데이터의 역할

| 데이터 | 하는 일 |
| --- | --- |
| 학습 (train) | 모델 가중치를 학습 |
| 검증 (validation, CV 폴드) | 모델 · 하이퍼파라미터 선택 |
| 테스트 (test) | 마지막에 **한 번만** 최종 성능 보고 |

> 테스트 점수를 보면서 하이퍼파라미터를 바꾸면 테스트 데이터가 사실상 검증 데이터가 되어 최종 점수가 낙관적으로 부풀려집니다.
