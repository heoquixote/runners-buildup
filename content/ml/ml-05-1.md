## 시험을 한 번만 보면 운이 섞인다

앞에서 데이터를 학습용과 시험용으로 한 번 나눴습니다. 그런데 **어떤 승객이 시험용에 들어갔느냐**에 따라 점수가 달라집니다. 시험 문제가 우연히 쉬우면 점수가 높게, 어려우면 낮게 나오는 것과 같습니다.

나누는 방식(`random_state`)만 바꿔서 같은 모델의 시험 점수를 비교해 봅니다.

```run
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier

df = pd.read_csv("titanic.csv")
df["female"] = (df["sex"] == "female").astype(int)
df["age"] = df["age"].fillna(df["age"].median())
X = df[["pclass", "female", "age", "sibsp", "parch", "fare"]]
y = df["survived"]
for seed in range(5):
    X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.25, random_state=seed, stratify=y)
    acc = DecisionTreeClassifier(max_depth=3, random_state=0).fit(X_tr, y_tr).score(X_te, y_te)
    print("split", seed, "-> test accuracy", round(acc, 3))
```

모델은 똑같은데 나누는 방법만 바꿔도 점수가 몇 %p씩 오르내립니다. 이 점수 하나로 "이 모델이 저 모델보다 낫다"고 말하기 어렵습니다.

## K-fold 교차검증: 돌아가며 시험 보기

해결책은 **여러 번 나눠서 시험을 보고 평균**을 내는 것입니다.

1. 데이터를 K개(보통 5개) 조각으로 나눕니다.
2. 1번 조각을 시험용, 나머지 4개를 학습용으로 써서 점수를 냅니다.
3. 2번 조각을 시험용으로 바꿔 다시 합니다. … 5번까지 반복합니다.
4. 점수 5개의 **평균**이 성능, **흩어짐(표준편차)**이 얼마나 흔들리는지입니다.

::figure{src="content/img/ml/ml05-kfold.svg" alt="데이터를 5조각으로 나누고, 시험 조각을 한 칸씩 옮기며 점수 5개를 얻는다" caption="시험 조각(주황)이 한 칸씩 옮겨 가며 점수 5개를 모읍니다."}

모든 데이터가 한 번씩은 시험용으로 쓰이니 공평합니다.

::video{ref="dl-m24"}

```run
import pandas as pd
from sklearn.model_selection import cross_val_score
from sklearn.tree import DecisionTreeClassifier

df = pd.read_csv("titanic.csv")
df["female"] = (df["sex"] == "female").astype(int)
df["age"] = df["age"].fillna(df["age"].median())
X = df[["pclass", "female", "age", "sibsp", "parch", "fare"]]
y = df["survived"]
scores = cross_val_score(DecisionTreeClassifier(max_depth=3, random_state=0), X, y, cv=5)
print("5 scores:", scores.round(3))
print("mean:", round(scores.mean(), 3), " std:", round(scores.std(), 3))
```

`cross_val_score(모델, X, y, cv=5)` 한 줄이 위의 1~4단계를 모두 해 줍니다.

## 교차검증으로 모델 비교하기

교차검증의 가장 흔한 쓰임은 **모델끼리 공정하게 비교하기**입니다. 세 모델을 같은 5조각으로 채점합니다. 조각을 똑같이 쓰도록 `StratifiedKFold`(정답 비율을 맞춘 K-fold)를 미리 만들어 함께 넘깁니다.

```run
import pandas as pd
from sklearn.model_selection import cross_val_score, StratifiedKFold
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression
from sklearn.tree import DecisionTreeClassifier
from sklearn.ensemble import RandomForestClassifier

df = pd.read_csv("titanic.csv")
df["female"] = (df["sex"] == "female").astype(int)
df["age"] = df["age"].fillna(df["age"].median())
X = df[["pclass", "female", "age", "sibsp", "parch", "fare"]]
y = df["survived"]
cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=0)
models = {"logistic": make_pipeline(StandardScaler(), LogisticRegression()),
          "tree (depth 3)": DecisionTreeClassifier(max_depth=3, random_state=0),
          "random forest": RandomForestClassifier(n_estimators=100, random_state=0)}
for name, m in models.items():
    s = cross_val_score(m, X, y, cv=cv)
    print(f"{name:>15}: {s.round(3)}  mean {s.mean():.3f} +/- {s.std():.3f}")
```

| 모델 | 평균 | 표준편차 |
| --- | --- | --- |
| 로지스틱 회귀 | 0.792 | 0.040 |
| 트리 (깊이 3) | 0.818 | 0.037 |
| 랜덤포레스트 | 0.805 | 0.031 |

평균만 보면 깊이 3 트리가 가장 높습니다. 하지만 세 모델의 차이(최대 0.026)가 각 모델의 흔들림(표준편차 약 0.03~0.04)보다 작습니다. 다섯 조각 점수를 나란히 보면 조각마다 1등이 바뀌기도 합니다. 이럴 때는 "트리가 확실히 낫다"가 아니라 **"세 모델이 비슷하다"**고 말하는 것이 정직합니다. 비슷하다면 설명하기 쉬운 모델(깊이 3 트리)을 고르는 것도 좋은 선택입니다.

> 평균 차이가 표준편차보다 작으면, 그 차이는 조각을 어떻게 나눴느냐에 따른 운일 가능성이 큽니다.

## 조각이 이상하면 점수도 이상하다

설비 데이터로 같은 일을 하면 신기한 결과가 나옵니다.

```run
import pandas as pd
from sklearn.model_selection import cross_val_score, StratifiedKFold
from sklearn.tree import DecisionTreeClassifier

df = pd.read_csv("ai4i2020.csv")
X = df[["air_temp", "process_temp", "rpm", "torque", "tool_wear"]]
y = df["failure"]
model = DecisionTreeClassifier(max_depth=3, random_state=0)
print("in order :", cross_val_score(model, X, y, cv=5).round(3))
shuffled = StratifiedKFold(n_splits=5, shuffle=True, random_state=0)
print("shuffled :", cross_val_score(model, X, y, cv=shuffled).round(3))
```

순서대로 나누면 세 번째 조각만 점수가 0.54로 뚝 떨어집니다. 이 데이터는 시간 순서로 쌓여 있어서, 그 구간만 운전 조건이 달랐던 것입니다. 섞어서 나누면(`shuffle=True`) 점수가 고르게 나옵니다.

교훈은 두 가지입니다.

- 점수 하나가 튀면 **그 조각의 데이터가 어떻게 다른지** 들여다볼 것
- 시간 순서가 있는 데이터는 "과거로 학습해 미래를 예측"하도록 나누는 게 원칙이라(`TimeSeriesSplit`), 섞는 것이 항상 정답은 아님. 이 방법은 [시간 순서가 있는 데이터 나누기](#/l/ml-05-4)에서 직접 비교해 봅니다

## 지표를 바꿔서 교차검증하기

`cross_val_score`는 기본으로 정확도를 냅니다. 고장처럼 드문 것을 찾는 문제라면 `scoring`으로 지표를 바꿔야 합니다. `cross_validate`를 쓰면 지표 여러 개와 학습 점수까지 한 번에 받을 수 있습니다.

```run
import pandas as pd
from sklearn.model_selection import cross_validate, StratifiedKFold
from sklearn.ensemble import RandomForestClassifier

df = pd.read_csv("ai4i2020.csv")
X = df[["air_temp", "process_temp", "rpm", "torque", "tool_wear"]]
y = df["failure"]
cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=0)
r = cross_validate(RandomForestClassifier(n_estimators=100, random_state=0), X, y, cv=cv,
                   scoring=["accuracy", "recall", "f1"], return_train_score=True)
for metric in ["accuracy", "recall", "f1"]:
    print(f"{metric:>8}: train {r['train_' + metric].mean():.3f}   valid {r['test_' + metric].mean():.3f}")
```

정확도는 학습 1.000, 검증 0.984라 문제가 없어 보입니다. 그런데 재현율을 보면 학습 1.000, 검증 0.625입니다. **학습 데이터의 고장은 다 맞히는데 처음 보는 고장은 10건 중 6건 정도만 잡는다**는 것이 드러납니다. 어떤 지표로 교차검증하느냐에 따라 보이는 것이 완전히 달라집니다. `scoring`에 쓸 수 있는 이름은 `"accuracy"`, `"precision"`, `"recall"`, `"f1"`, `"roc_auc"`, `"average_precision"`(PR-AUC) 등입니다.

## 정리

- 한 번 나눈 시험 점수에는 **운**이 섞입니다(같은 모델도 나누는 방식에 따라 몇 %p씩 차이).
- **K-fold 교차검증**: K조각으로 나눠 돌아가며 시험 보고 평균·표준편차를 봅니다. `cross_val_score(모델, X, y, cv=5)`
- 모델 비교는 같은 조각으로 교차검증하고, 평균 차이가 표준편차보다 작으면 "비슷하다"고 봅니다.
- 드문 것을 찾을 때는 `scoring="recall"`, `"f1"` 등으로 지표를 바꿉니다. `cross_validate`는 여러 지표와 학습 점수를 함께 줍니다.
- 한 조각만 점수가 튀면 그 구간의 데이터를 들여다봅니다. 분류에서는 정답 비율을 맞추는 `StratifiedKFold`, 시간 데이터는 `TimeSeriesSplit`.
