## 시험을 한 번만 보면 운이 섞인다

앞에서 데이터를 학습용과 시험용으로 한 번 나눴습니다. 그런데 **어떤 승객이 시험용에 들어갔느냐**에 따라 점수가 달라집니다. 시험 문제가 우연히 쉬우면 점수가 높게, 어려우면 낮게 나오는 것과 같습니다.

나누는 방식(`random_state`)만 바꿔서 같은 모델의 시험 점수를 비교해 봅니다.

```run
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier

df = pd.read_csv("titanic.csv")
df["female"] = (df["sex"] == "female").astype(int)
df["age"] = df["age"].fillna(df["age"].median())
X = df[["pclass", "female", "age", "sibsp", "parch", "fare"]]
y = df["survived"]
for seed in range(5):
    X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.25, random_state=seed, stratify=y)
    acc = DecisionTreeClassifier(max_depth=3, random_state=0).fit(X_tr, y_tr).score(X_te, y_te)
    print("split", seed, "-> test accuracy", round(acc, 3))
```

모델은 똑같은데 나누는 방법만 바꿔도 점수가 몇 %p씩 오르내립니다. 이 점수 하나로 "이 모델이 저 모델보다 낫다"고 말하기 어렵습니다.

## K-fold 교차검증: 돌아가며 시험 보기

해결책은 **여러 번 나눠서 시험을 보고 평균**을 내는 것입니다.

1. 데이터를 K개(보통 5개) 조각으로 나눕니다.
2. 1번 조각을 시험용, 나머지 4개를 학습용으로 써서 점수를 냅니다.
3. 2번 조각을 시험용으로 바꿔 다시 합니다. … 5번까지 반복합니다.
4. 점수 5개의 **평균**이 성능, **흩어짐(표준편차)**이 얼마나 흔들리는지입니다.

::figure{src="content/img/ml/ml05-kfold.svg" alt="데이터를 5조각으로 나누고, 시험 조각을 한 칸씩 옮기며 점수 5개를 얻는다" caption="시험 조각(주황)이 한 칸씩 옮겨 가며 점수 5개를 모읍니다."}

모든 데이터가 한 번씩은 시험용으로 쓰이니 공평합니다.

::video{ref="dl-m24"}

```run
import pandas as pd
from sklearn.model_selection import cross_val_score
from sklearn.tree import DecisionTreeClassifier

df = pd.read_csv("titanic.csv")
df["female"] = (df["sex"] == "female").astype(int)
df["age"] = df["age"].fillna(df["age"].median())
X = df[["pclass", "female", "age", "sibsp", "parch", "fare"]]
y = df["survived"]
scores = cross_val_score(DecisionTreeClassifier(max_depth=3, random_state=0), X, y, cv=5)
print("5 scores:", scores.round(3))
print("mean:", round(scores.mean(), 3), " std:", round(scores.std(), 3))
```

`cross_val_score(모델, X, y, cv=5)` 한 줄이 위의 1~4단계를 모두 해 줍니다.

## 조각이 이상하면 점수도 이상하다

설비 데이터로 같은 일을 하면 신기한 결과가 나옵니다.

```run
import pandas as pd
from sklearn.model_selection import cross_val_score, StratifiedKFold
from sklearn.tree import DecisionTreeClassifier

df = pd.read_csv("ai4i2020.csv")
X = df[["air_temp", "process_temp", "rpm", "torque", "tool_wear"]]
y = df["failure"]
model = DecisionTreeClassifier(max_depth=3, random_state=0)
print("in order :", cross_val_score(model, X, y, cv=5).round(3))
shuffled = StratifiedKFold(n_splits=5, shuffle=True, random_state=0)
print("shuffled :", cross_val_score(model, X, y, cv=shuffled).round(3))
```

순서대로 나누면 세 번째 조각만 점수가 0.54로 뚝 떨어집니다. 이 데이터는 시간 순서로 쌓여 있어서, 그 구간만 운전 조건이 달랐던 것입니다. 섞어서 나누면(`shuffle=True`) 점수가 고르게 나옵니다.

교훈은 두 가지입니다.

- 점수 하나가 튀면 **그 조각의 데이터가 어떻게 다른지** 들여다볼 것
- 시간 순서가 있는 데이터는 "과거로 학습해 미래를 예측"하도록 나누는 게 원칙이라(`TimeSeriesSplit`), 섞는 것이 항상 정답은 아님

## 하이퍼파라미터: 사람이 정하는 설정값

모델이 데이터에서 **스스로 배우는 값**(트리의 질문, 회귀의 계수)과 달리, **사람이 학습 전에 정해 주는 값**이 있습니다. 이를 하이퍼파라미터라고 합니다.

- 결정트리의 `max_depth` (질문 단계 수)
- 랜덤포레스트의 `n_estimators` (트리 개수)
- KNN의 `n_neighbors` (참고할 이웃 수)

너무 단순하게 정하면 패턴을 못 잡고(**과소적합**), 너무 복잡하게 정하면 외워 버립니다(**과적합**). ml-04에서 본 과적합의 반대편입니다.

| 상태 | 학습 점수 | 시험 점수 | 비유 |
| --- | --- | --- | --- |
| 과소적합 | 낮음 | 낮음 | 공부를 덜 해서 문제집도 시험도 못 품 |
| 적당함 | 높음 | 높음 (학습과 비슷) | 원리를 이해함 |
| 과적합 | 아주 높음 | 낮음 | 문제집 답만 외움 |

적당한 값을 찾아야 합니다. 그런데 후보를 고를 때 시험용 점수를 보면 안 되니(ml-01의 "시험지는 마지막에 한 번"), 교차검증 점수로 고릅니다.

## GridSearchCV: 후보를 전부 시험해 보기

후보 값을 목록으로 주면, 후보마다 교차검증을 돌려 가장 좋은 것을 골라 줍니다. 마치 요리할 때 불 세기를 약·중·강으로 다 해 보고 제일 맛있는 것을 고르는 것과 같습니다.

```run
import pandas as pd
from sklearn.model_selection import train_test_split, GridSearchCV
from sklearn.tree import DecisionTreeClassifier

df = pd.read_csv("titanic.csv")
df["female"] = (df["sex"] == "female").astype(int)
df["age"] = df["age"].fillna(df["age"].median())
X = df[["pclass", "female", "age", "sibsp", "parch", "fare"]]
y = df["survived"]
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.25, random_state=0, stratify=y)

grid = GridSearchCV(DecisionTreeClassifier(random_state=0), {"max_depth": [1, 2, 3, 4, 5, 6, 8, None]}, cv=5)
grid.fit(X_train, y_train)
for p, s in zip(grid.cv_results_["params"], grid.cv_results_["mean_test_score"]):
    print(p, round(s, 3))
print("best:", grid.best_params_, " cv score:", round(grid.best_score_, 3))
print("final test score:", round(grid.score(X_test, y_test), 3))
```

::figure{src="content/img/ml/ml05-grid.svg" alt="max_depth 후보 2부터 6까지 각각 교차검증 평균 점수를 막대로 그리고 가장 높은 후보를 고른다" caption="후보마다 교차검증 평균 점수를 내고, 가장 높은 후보를 고릅니다. 막대 높이는 설명용 예시입니다."}

중요한 순서:

1. GridSearchCV는 **학습용 데이터 안에서만** 교차검증해서 고릅니다.
2. 고른 설정으로 학습용 전체에 다시 학습합니다(자동).
3. 시험용 데이터로는 **마지막에 딱 한 번** 평가합니다.

> 시험 점수를 보면서 설정을 바꾸고 또 바꾸면, 결국 시험 문제에 맞춘 모델이 됩니다. 시험용 데이터는 끝까지 아껴 두세요.

후보가 아주 많으면 전부 시험하는 데 시간이 너무 오래 걸립니다. 그럴 때는 후보 중 일부만 무작위로 뽑아 시험하는 `RandomizedSearchCV`나, 앞 결과를 보고 다음 후보를 똑똑하게 고르는 Optuna 같은 도구를 씁니다. 원리는 똑같이 "교차검증 점수로 고른다"입니다.

### 직접 해보기

후보 목록 `depths`를 바꿔 보세요. 예를 들어 `[2, 3]`처럼 좁게 주면 더 좋은 후보를 놓칠 수 있고, `cv`를 3이나 10으로 바꾸면 평균 점수가 조금씩 달라집니다. 후보와 조각 수가 많을수록 시간이 오래 걸린다는 것도 느껴 보세요.

```run
import pandas as pd
from sklearn.model_selection import GridSearchCV
from sklearn.tree import DecisionTreeClassifier

df = pd.read_csv("titanic.csv")
df["female"] = (df["sex"] == "female").astype(int)
df["age"] = df["age"].fillna(df["age"].median())
X = df[["pclass", "female", "age", "sibsp", "parch", "fare"]]
y = df["survived"]

depths = [2, 3, 4, 5, 6]   # <- change me
cv = 5                     # <- change me
grid = GridSearchCV(DecisionTreeClassifier(random_state=0), {"max_depth": depths}, cv=cv).fit(X, y)
print("best:", grid.best_params_, " mean cv score:", round(grid.best_score_, 3))
```

## 정리

| 데이터 | 하는 일 |
| --- | --- |
| 학습용 | 모델 학습 + 교차검증으로 설정 고르기 |
| 시험용 | 최종 성능을 한 번만 확인 |

- 점수 하나는 운이 섞인다 → **교차검증 평균**을 본다
- 하이퍼파라미터는 GridSearchCV로 고른다
