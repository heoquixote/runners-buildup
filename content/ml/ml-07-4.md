## 시작하기 전에

[K-means](#/l/ml-07-1)와 [PCA](#/l/ml-07-3)는 정답 없이 데이터의 **전체 모양**을 봤습니다. 이번 레슨은 반대로 **무리에서 벗어난 몇 개**를 찾습니다. 이것을 **이상 탐지**(anomaly detection)라고 합니다. 제조 현장에서 가장 많이 쓰는 비지도 학습입니다.

## 고장 기록이 없어도 이상은 찾을 수 있다

지금까지 고장 예측은 "예전 고장 기록(정답)"이 있어야 했습니다. 그런데 현장에서는 이런 일이 흔합니다.

- 새 설비라서 고장 기록이 아직 없다.
- 고장이 너무 드물어서 배울 예가 몇 개 안 된다.
- 처음 보는 종류의 고장이 생길 수 있다.

이럴 때 쓰는 생각이 "**평소 모습을 배우고, 평소와 다르면 경보**"입니다. 건강검진에서 정상 범위를 벗어난 수치에 표시를 하는 것과 같습니다. 정답이 필요 없으니 비지도 학습입니다.

## 가장 쉬운 방법: z-점수 3 넘으면 표시

통계 트랙의 [정규분포와 표준화](#/l/st-02-3)에서 배운 z-점수(평균에서 표준편차 몇 개만큼 떨어졌나)를 열마다 구하고, 하나라도 **±3을 넘으면** 이상으로 표시해 봅니다. 정규분포라면 ±3 밖은 0.3%뿐입니다. 학습에는 `failure`를 쓰지 않고, 표시한 뒤에만 꺼내서 실제 고장이 얼마나 섞였는지 확인합니다.

```run
import pandas as pd

df = pd.read_csv("ai4i2020.csv")
features = ["air_temp", "process_temp", "rpm", "torque", "tool_wear"]
z = (df[features] - df[features].mean()) / df[features].std()
flag = (z.abs() > 3).any(axis=1)
print("overall failure rate:", round(df["failure"].mean(), 3))
print("flagged:", flag.sum(), "rows / failure rate among flagged:", round(df.loc[flag, "failure"].mean(), 3))
print("flags per column:", (z.abs() > 3).sum().to_dict())
```

- 전체 고장률은 3.4%인데, 표시된 178개 중에서는 **25.8%**가 고장입니다. 정답 없이 고른 것치고 7배 넘게 진합니다.
- 하지만 표시는 거의 **회전수(164개)** 와 토크(25개)에서만 나왔습니다. 열을 **하나씩 따로** 보기 때문에, "토크가 평범하고 회전수도 평범한데 **둘의 조합**이 이상한" 경우는 놓칩니다.

## IsolationForest: 몇 번 만에 혼자 남나

**IsolationForest**는 열들의 조합을 함께 보는 이상 탐지 모델입니다. 아이디어는 스무고개입니다. 데이터를 무작위 기준으로 계속 잘라서 **점 하나가 혼자 남을 때까지** 몇 번 잘라야 하는지 셉니다.

- 무리 한가운데 있는 평범한 점: 주변에 비슷한 점이 많아서 **여러 번** 잘라야 혼자 남습니다.
- 멀리 떨어진 이상한 점: **몇 번만** 잘라도 혼자 남습니다.

::figure{src="content/img/ml/ml07-isolation.svg" alt="외딴 점은 무작위 선 2번으로 혼자 남고, 무리 속 점은 6번을 잘라야 혼자 남는다" caption="빨리 혼자 남는 점일수록 이상 점수가 높습니다. 이 자르기를 나무 수백 그루로 반복해 평균을 냅니다."}

결정트리처럼 자르지만 정답을 보지 않고 **무작위로** 자릅니다. 이런 나무를 100그루 만들어 평균을 내니 '숲(Forest)'입니다. `contamination`은 "전체 중 몇 %를 이상으로 표시할지"입니다.

```run
import pandas as pd
from sklearn.ensemble import IsolationForest

df = pd.read_csv("ai4i2020.csv")
features = ["air_temp", "process_temp", "rpm", "torque", "tool_wear"]
iso = IsolationForest(contamination=0.01, random_state=0).fit(df[features])
df["anomaly"] = iso.predict(df[features]) == -1      # -1 = anomaly, 1 = normal
df["score"] = -iso.score_samples(df[features])       # higher = more unusual
print("flagged:", df["anomaly"].sum(), "/ failure rate among flagged:", round(df.loc[df["anomaly"], "failure"].mean(), 3))
print(df.sort_values("score", ascending=False)[features + ["failure", "score"]].head(5).round(3))
```

- 상위 1%(100개)를 표시했더니 그중 **34%**가 실제 고장입니다. 전체 고장률 3.4%의 **10배**입니다.
- 가장 이상한 다섯 대는 회전수가 2,270~2,709로 아주 빠르면서 토크는 9.7~14.6으로 아주 작은 설비들입니다(평균은 회전수 1,539, 토크 40). 넷이 실제 고장이었습니다. 회전수와 토크가 **함께** 극단인 조합을 잡아냈습니다.
- 1등(5152번)은 고장이 아니었습니다. **이상하다 = 고장**은 아닙니다. 이상 탐지는 "사람이 먼저 볼 후보"를 뽑아 주는 도구입니다.

### 직접 해보기: 몇 %를 표시할까

`contamination`을 0.01, 0.02, 0.05로 바꿔 보세요. 표시를 늘리면 잡는 고장 수는 늘지만, 표시한 것 중 진짜 고장의 비율은 떨어집니다.

```run
import pandas as pd
from sklearn.ensemble import IsolationForest

df = pd.read_csv("ai4i2020.csv")
features = ["air_temp", "process_temp", "rpm", "torque", "tool_wear"]
for c in [0.01, 0.02, 0.05]:   # <- change me
    flag = IsolationForest(contamination=c, random_state=0).fit_predict(df[features]) == -1
    print(f"contamination {c}: flagged {flag.sum():>3}, failures caught {df.loc[flag, 'failure'].sum():>2} / 339, precision {df.loc[flag, 'failure'].mean():.3f}")
```

| contamination | 표시 | 잡은 고장 (전체 339) | 표시 중 고장 비율 |
| --- | --- | --- | --- |
| 1% | 100 | 34 | 0.340 |
| 2% | 200 | 39 | 0.195 |
| 5% | 500 | 57 | 0.114 |

[임계값: 경보 감도 조절](#/l/ml-03-3)에서 본 정밀도와 재현율의 줄다리기가 그대로 나타납니다. 현장에서는 "하루에 점검할 수 있는 설비 수"로 표시 비율을 정합니다.

## 정상 데이터만으로 배우기

이상 탐지의 진짜 장점은 **정상 데이터만 있어도 된다**는 점입니다. 정상 설비 5,000개만으로 학습하고 전체 10,000개에 점수를 매겨, 고장과 정상을 얼마나 잘 가르는지 [ROC-AUC](#/l/ml-03-4)로 봅니다.

```run
import pandas as pd
from sklearn.ensemble import IsolationForest
from sklearn.metrics import roc_auc_score

df = pd.read_csv("ai4i2020.csv")
features = ["air_temp", "process_temp", "rpm", "torque", "tool_wear"]
normal = df[df["failure"] == 0].sample(5000, random_state=0)
iso = IsolationForest(random_state=0).fit(normal[features])
score = -iso.score_samples(df[features])
print("ROC-AUC (trained on normal only):", round(roc_auc_score(df["failure"], score), 3))
```

AUC **0.824**입니다. 고장 예를 하나도 보여 주지 않았는데, 무작위로 고른 고장 설비가 정상 설비보다 이상 점수가 높을 확률이 82%라는 뜻입니다. 고장 기록이 쌓이면 지도 학습(랜덤포레스트 등)으로 넘어가는 게 성능은 더 좋지만, 기록이 없는 초기에는 이상 탐지가 좋은 출발점입니다.

## 정리

| | 지도 학습 (고장 분류) | 이상 탐지 |
| --- | --- | --- |
| 필요한 것 | 고장·정상 정답 기록 | 정상 데이터만 있어도 됨 |
| 찾는 것 | 예전에 본 종류의 고장 | 평소와 다른 모든 것 (새 종류 포함) |
| 결과 | 고장 확률 | 이상 점수 (고장이라는 보장 없음) |
| 도구 | 로지스틱, 랜덤포레스트 | z-점수, `IsolationForest` |

- z-점수는 열을 하나씩 보고, IsolationForest는 **열의 조합**까지 봅니다. 상위 1% 표시 중 34%가 실제 고장이었습니다(기본 비율의 10배).
- 이상 점수가 높다고 반드시 고장은 아닙니다. 사람이 먼저 볼 **후보**로 씁니다.
- 사진·소리처럼 복잡한 데이터의 이상 탐지는 딥러닝 트랙의 [오토인코더](#/l/dl-08-1)에서 같은 원리(정상만 배우기)로 다룹니다.
