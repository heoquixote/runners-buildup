## 시작하기 전에

앞 레슨까지 모델에 넣을 X와 y를 만들었습니다. 이제 바로 학습시키면 될까요? 아닙니다. 모델이 **처음 보는 데이터도 잘 맞히는지** 확인할 방법이 먼저 필요합니다. 이번 레슨에서는 데이터를 학습용과 시험용으로 나누는 법과, 나눌 때 조심할 점을 배웁니다.

## 왜 데이터를 나눌까: 시험 문제 비유

학생에게 문제집을 풀게 한 뒤, **같은 문제**로 시험을 보면 100점이 나와도 실력이라고 할 수 없습니다. 답을 외웠을 수도 있으니까요.

모델도 똑같습니다. 그래서 데이터를 두 묶음으로 나눕니다.

| 묶음 | 비유 | 하는 일 |
| --- | --- | --- |
| 학습용 (train) | 문제집 | 모델이 보고 규칙을 배움 |
| 시험용 (test) | 처음 보는 시험지 | 배운 모델이 얼마나 잘 맞히는지 확인 |

::figure{src="content/img/ml/ml01-split.svg" alt="891명을 학습용 75퍼센트와 시험용 25퍼센트로 나누기" caption="학습용으로 배우고, 한 번도 보지 않은 시험용으로 실력을 잽니다."}

`train_test_split`이 이 일을 해 줍니다. `test_size=0.25`는 25%를 시험용으로 떼라는 뜻이고, `random_state=0`은 매번 같은 방식으로 섞으라는 뜻(재현용)입니다.

```run
import pandas as pd
from sklearn.model_selection import train_test_split

df = pd.read_csv("titanic.csv")
df["female"] = (df["sex"] == "female").astype(int)
X = df[["pclass", "female", "fare"]].values
y = df["survived"].values
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.25, random_state=0)
print("train:", X_train.shape, " test:", X_test.shape)
```

### 직접 해보기

아래 셀에서 `test_size` 값을 0.2, 0.3, 0.5로 바꿔 실행해 보세요. 시험용이 커질수록 학습용은 줄어듭니다. 보통은 0.2~0.3을 씁니다. 학습용이 너무 적으면 배울 거리가 부족하고, 시험용이 너무 적으면 점수가 운에 크게 흔들리기 때문입니다.

```run
import pandas as pd
from sklearn.model_selection import train_test_split

df = pd.read_csv("titanic.csv")
X = df[["pclass", "fare"]].values
y = df["survived"].values

test_size = 0.25   # <- change me
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=test_size, random_state=0)
print("train rows:", len(X_train), " test rows:", len(X_test))
```

### 검증용(validation)까지 세 덩어리로

모델을 여러 개 만들어 비교하거나 설정을 이리저리 바꿔 볼 때, 시험용 점수를 보면서 고르면 어떻게 될까요? 시험지를 여러 번 보면서 공부한 셈이라, 결국 그 시험지에만 잘 맞는 모델이 됩니다. 그래서 실제로는 세 덩어리로 나눕니다.

| 덩어리 | 비유 | 언제 쓰나 |
| --- | --- | --- |
| 학습용 (train) | 문제집 | 모델이 규칙을 배울 때 |
| 검증용 (validation) | 모의고사 | 어떤 모델·설정이 나은지 고를 때 (여러 번 봐도 됨) |
| 시험용 (test) | 수능 | 모든 결정이 끝난 뒤 **딱 한 번** 최종 점수 확인 |

검증용을 따로 떼는 대신 학습용을 돌려 가며 쓰는 방법(교차검증)은 ml-05에서 배웁니다.

> 날짜가 있는 데이터(매출, 수요 등)는 무작위로 섞어 나누면 안 됩니다. 과거로 학습하고 **미래로 시험**해야 실제 상황과 같습니다. 또 한 사람의 기록이 여러 줄이면, 같은 사람이 학습용과 시험용에 동시에 들어가지 않게 **사람 단위로** 나눠야 합니다.

## stratify: 정답 비율을 똑같이

설비 고장처럼 정답 1이 드문 데이터에서는 그냥 나누면 시험용에 고장이 거의 안 들어갈 수도 있습니다. `stratify=y`를 주면 학습용과 시험용의 1 비율이 원래 데이터와 같게 맞춰집니다.

여기서는 두 번째 실제 데이터인 **AI4I 2020 설비 고장 데이터**(UCI 공개, 1만 건)를 씁니다. 회전수·토크·공구 사용 시간 같은 센서 값과 고장 여부(`failure`)가 들어 있고, 고장은 약 3.4%뿐입니다.

```run
import pandas as pd
from sklearn.model_selection import train_test_split

df = pd.read_csv("ai4i2020.csv")
X = df[["air_temp", "process_temp", "rpm", "torque", "tool_wear"]].values
y = df["failure"].values
print("failure rate (all):", round(y.mean(), 4))
for strat in [None, y]:
    _, _, y_tr, y_te = train_test_split(X, y, test_size=0.02, random_state=3, stratify=strat)
    print("stratify" if strat is not None else "no stratify", "-> test failure rate", round(y_te.mean(), 4))
```

시험용을 작게(2%) 떼어 보면 차이가 분명합니다. stratify 없이는 시험용의 고장 비율이 원래(3.4%)와 꽤 달라질 수 있습니다.

## 나누는 방식에 따라 점수가 흔들린다

`random_state`는 "어떻게 섞을지"를 정하는 번호입니다. 번호만 바꿔서 같은 모델의 시험 점수를 다섯 번 재 봅니다.

```run
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier

df = pd.read_csv("titanic.csv")
df["female"] = (df["sex"] == "female").astype(int)
X, y = df[["pclass", "female", "fare"]], df["survived"]
for seed in range(5):
    X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.25, random_state=seed)
    model = DecisionTreeClassifier(max_depth=3, random_state=0).fit(X_tr, y_tr)
    print("seed", seed, "-> test accuracy", round(model.score(X_te, y_te), 3))
```

모델도 데이터도 똑같은데 점수가 0.789에서 0.843까지 오갑니다. 시험용에 **어떤 승객이 뽑혔느냐**에 따라 문제가 쉬워지기도, 어려워지기도 하기 때문입니다. 시험용이 작을수록 이 흔들림은 더 커집니다(`test_size=0.05`로 바꾸면 45명뿐이라 0.756~0.933까지 벌어집니다).

그래서 "모델 A가 0.80, 모델 B가 0.81"처럼 작은 차이는 나누는 운일 수 있습니다. 여러 번 나눠 평균을 내는 **교차검증**(ml-05-1)이 이 문제를 해결합니다.

### 자주 하는 실수

| 실수 | 왜 문제인가 |
| --- | --- |
| 나누기 **전에** 전체 데이터로 결측치를 채우거나 표준화 | 시험용 정보가 학습에 섞임(누수) |
| 점수가 마음에 들 때까지 `random_state`를 바꿔 가며 시도 | 운 좋은 시험지를 고른 것일 뿐, 실력이 아님 |
| 고장처럼 드문 정답인데 `stratify` 없이 나눔 | 시험용에 고장이 몇 개 안 들어가 점수를 믿기 어려움 |

## 정리

- 학습용으로 배우고, 한 번도 보지 않은 **시험용**으로 실력을 잽니다. 보통 시험용은 20~30%.
- 모델·설정을 고를 때는 **검증용**, 마지막 한 번은 **시험용**.
- 날짜가 있으면 과거로 학습·미래로 시험, 한 사람의 기록이 여러 줄이면 사람 단위로 나눕니다.
- 정답 1이 드물면 `stratify=y`로 비율을 맞춥니다.
- 한 번 나눈 시험 점수는 나누는 운에 따라 흔들립니다(0.789~0.843). 작은 차이로 모델을 고르지 않습니다.
