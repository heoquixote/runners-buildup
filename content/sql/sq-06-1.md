## 함수: 값을 넣으면 값이 나오는 기계

자판기에 동전을 넣으면 음료가 나오듯, **함수**는 값을 넣으면 가공된 값을 돌려줍니다. `UPPER('kim')`에 `'kim'`을 넣으면 `'KIM'`이 나옵니다. 앞 레슨의 `ROUND`, `COUNT`도 함수였습니다.

이번 레슨에서는 실무에서 가장 자주 쓰는 세 가지를 배웁니다. **글자 다듬기**, **빈 값 채우기**, **조건에 따라 다른 값 붙이기(CASE)**, 그리고 **날짜 다루기**입니다.

## 글자 이어 붙이기: ||

SQLite에서는 `||`(세로 막대 두 개)로 글자를 이어 붙입니다. "이름 [직급]" 모양을 만들어 봅니다.

```sqlrun
SELECT ename_ko || ' [' || joblv || ']' AS name_job FROM emp;
```

> MySQL에서는 `CONCAT(ename_ko, ' [', joblv, ']')`로 씁니다. 이 사이트의 SQLite에는 CONCAT이 없으니 `||`를 쓰세요.

## 대소문자 · 길이

`UPPER`는 대문자로, `LOWER`는 소문자로, `LENGTH`는 글자 수를 셉니다.

```sqlrun
SELECT ename_en, UPPER(ename_en) AS upper_en, LENGTH(ename_ko) AS len_ko, LENGTH(ename_en) AS len_en
FROM emp;
```

`LENGTH(ename_en)`은 띄어쓰기까지 세어 "Kim Daepyo"가 10입니다. 한글 이름도 글자 수(3, 4)로 셉니다.

> MySQL의 `LENGTH`는 **바이트** 수를 세서 한글 한 글자가 3이 됩니다. MySQL에서 한글 글자 수는 `CHAR_LENGTH`로 셉니다.

## SUBSTR: 글자 자르기

`SUBSTR(글자, 시작 위치, 개수)`는 글자의 일부를 잘라 냅니다. 위치는 **1부터** 셉니다(첫 글자가 1번). 성만 남기고 이름을 `**`로 가리는 익명 처리를 해 봅니다.

```sqlrun
SELECT joblv, SUBSTR(ename_ko, 1, 1) || '**' AS name, sal FROM emp;
```

시작 위치에 **음수**를 쓰면 끝에서부터 셉니다. 이름의 마지막 글자가 '수'인 사원입니다.

```sqlrun
SELECT ename_ko, UPPER(ename_en) AS name_en FROM emp WHERE SUBSTR(ename_ko, -1) = '수';
```

> MySQL의 `LEFT(이름, 1)`은 `SUBSTR(이름, 1, 1)`, `RIGHT(이름, 1)`은 `SUBSTR(이름, -1)`과 같습니다.

## REPLACE · TRIM · INSTR

| 함수 | 하는 일 | 예 → 결과 |
| --- | --- | --- |
| `REPLACE(글자, 찾을 것, 바꿀 것)` | 바꾸기 | `REPLACE('부장', '부장', '상무')` → 상무 |
| `TRIM(글자)` | 앞뒤 공백 지우기 | `TRIM('  hello  ')` → hello |
| `INSTR(글자, 찾을 것)` | 처음 나오는 위치 (없으면 0) | `INSTR('BIGDATA', 'D')` → 4 |

김낙수 부장의 승진 직급을 미리 만들어 봅니다.

```sqlrun
SELECT ename_ko, joblv AS now_job, REPLACE(joblv, '부장', '상무') AS next_job
FROM emp WHERE ename_ko = '김낙수';
```

`TRIM`은 실무에서 아주 자주 씁니다. 엑셀에서 옮겨 온 데이터에 `'서울 '`처럼 끝에 공백이 붙어 있으면 `= '서울'` 조건에 걸리지 않기 때문입니다.

```sqlrun
SELECT '서울 ' = '서울' AS before_trim, TRIM('서울 ') = '서울' AS after_trim;
```

0은 거짓, 1은 참입니다. 눈에 안 보이는 공백 하나 때문에 조건이 틀어집니다.

## NULL을 다른 값으로: IFNULL · COALESCE

NULL은 계산과 조건을 자꾸 꼬이게 합니다. 화면에 보여 주거나 계산할 때는 다른 값으로 바꿔 두면 편합니다.

- `IFNULL(값, 대신할 값)`: 값이 NULL이면 대신할 값을
- `COALESCE(값1, 값2, 값3, …)`: 왼쪽부터 보며 **NULL이 아닌 첫 값**을

상사 사번이 없으면 본인 사번을 보여 줍니다.

```sqlrun
SELECT empno, mgr, IFNULL(mgr, empno) AS boss FROM emp;
```

쇼핑몰 방문 기록의 `user_id`는 로그인하지 않은 방문이면 비어 있습니다. NULL을 '비회원'으로 바꿔 방문자별 기록 수를 셉니다.

```sqlrun
SELECT COALESCE(user_id, '비회원') AS who, COUNT(*) AS n
FROM events GROUP BY 1 ORDER BY n DESC LIMIT 5;
```

`GROUP BY 1`은 "SELECT의 첫 번째 열로 묶어라"라는 줄임 표현입니다. '비회원'이 488건으로 압도적인 1위입니다. NULL을 그대로 두면 표에서 빈칸으로 보여 놓치기 쉬운데, 이름을 붙이니 "방문의 절반 가까이는 누군지 모른다"는 사실이 바로 보입니다.

## CASE: 조건에 따라 다른 값

`CASE`는 SQL의 if문입니다. 조건을 **위에서부터 차례로** 확인해서 **처음 맞는** 줄의 값을 돌려주고, 아무것도 안 맞으면 `ELSE` 값을 돌려줍니다.

```
CASE
    WHEN 조건1 THEN 값1
    WHEN 조건2 THEN 값2
    ELSE 그 밖의 값
END
```

재직 여부 1 · 0을 글자로 바꿉니다.

```sqlrun
SELECT ename_ko, CASE WHEN employed = 1 THEN '재직중' ELSE '퇴사' END AS status FROM emp;
```

> MySQL에서는 간단한 경우 `IF(employed = 1, '재직중', '퇴사')`로도 씁니다. SQLite에서는 같은 일을 `IIF(…)`로 하지만, CASE는 어느 DB에서나 통하는 표준 문법이라 CASE를 먼저 익히세요.

부서 번호로 직군을 나눠 봅니다. 10 · 11 · 12번은 영업, 40번은 생산, 80번은 인사, 나머지(부서 없음)는 기타입니다.

```sqlrun
SELECT ename_ko, deptno,
       CASE
           WHEN deptno IN (10, 11, 12) THEN '영업'
           WHEN deptno = 40 THEN '생산'
           WHEN deptno = 80 THEN '인사'
           ELSE '기타'
       END AS job_group
FROM emp;
```

김대표는 `deptno`가 NULL이라 어떤 WHEN에도 맞지 않아 '기타'가 됐습니다.

## 조건 순서가 틀리면

위 그림의 규칙을 순서만 바꿔서 써 봅니다. 6000 이상을 먼저 검사하면 어떻게 될까요?

```sqlrun
SELECT ename_ko, sal,
       CASE
           WHEN sal >= 6000 THEN '중간'
           WHEN sal >= 10000 THEN '고급여'
           ELSE '기본'
       END AS grade
FROM emp ORDER BY sal DESC;
```

> 직접 해보기: 연봉 80000인 김대표까지 모두 '중간'이 됐습니다. 10000 이상인 사람은 전부 6000 이상이기도 해서, 첫 줄에서 멈춰 버리기 때문입니다. 두 WHEN 줄의 순서를 바꿔 다시 실행해 보세요. 구간을 나눌 때는 **큰 값(좁은 조건)부터** 씁니다.

## CASE + GROUP BY = 구간별 분석

CASE로 만든 구간으로 묶으면 "금액대별 주문 수 · 매출" 같은 분석이 됩니다. 쇼핑몰 주문을 금액대 세 개로 나눠 봅니다.

```sqlrun
SELECT CASE
           WHEN amount >= 100000 THEN '10만 원 이상'
           WHEN amount >= 30000 THEN '3만~10만 원'
           ELSE '3만 원 미만'
       END AS band,
       COUNT(*) AS n,
       SUM(amount) AS revenue
FROM orders
GROUP BY band
ORDER BY revenue DESC;
```

10만 원 이상 주문은 38건(전체의 약 10%)뿐인데 매출은 8,766,800원으로, 3만 원 미만 주문 163건의 매출(3,076,400원)보다 3배 가까이 큽니다. 적은 수의 큰 주문이 매출을 떠받치는 모양이 숫자로 보입니다.

> 주의: 값이 NULL이면 `amount >= 100000`도 `amount >= 30000`도 참이 아니라서 ELSE로 들어갑니다. NULL이 있을 수 있는 열이라면 `WHEN 열 IS NULL THEN '모름'`을 맨 위에 따로 두세요.

## 날짜 다루기

SQLite에는 날짜 전용 자료형이 따로 없고, 날짜를 `'2025-07-04'` 같은 **글자**로 저장합니다. 그래도 `연-월-일` 모양으로 저장했다면 글자 비교가 곧 날짜 비교가 됩니다. 앞자리(연도)부터 비교하기 때문입니다.

2020년 이후 입사자입니다.

```sqlrun
SELECT ename_ko, hiredate FROM emp WHERE hiredate >= '2020-01-01';
```

`strftime(형식, 날짜)`로 연 · 월 같은 부분을 뽑습니다. `%Y`는 연도, `%m`은 월, `%d`는 일입니다.

```sqlrun
SELECT ename_ko, hiredate, strftime('%Y', hiredate) AS hire_year, strftime('%m', hiredate) AS hire_month
FROM emp;
```

날짜를 더하고 빼는 것도 됩니다. `date(날짜, '+1 year')`는 1년 뒤, `julianday(날짜)`끼리 빼면 두 날짜 사이의 **일 수**가 나옵니다. 2025년 말 기준 근속 일수와 연수를 계산해 봅니다.

```sqlrun
SELECT ename_ko, hiredate,
       date(hiredate, '+1 year') AS first_anniv,
       CAST(julianday('2025-12-31') - julianday(hiredate) AS INTEGER) AS days,
       CAST((julianday('2025-12-31') - julianday(hiredate)) / 365.25 AS INTEGER) AS years
FROM emp ORDER BY days DESC;
```

김대표가 10957일, 29년으로 가장 오래 근무했습니다.

실무에서 가장 많이 쓰는 날짜 작업은 **월별로 묶기**입니다. 쇼핑몰 주문을 `'%Y-%m'`(연-월)로 묶어 월별 주문 수와 매출을 냅니다.

```sqlrun
SELECT strftime('%Y-%m', order_date) AS ym, COUNT(*) AS orders, SUM(amount) AS revenue
FROM orders GROUP BY ym;
```

1월 24건에서 6월 73건까지 늘다가 7월에 35건으로 줄었습니다. 왜 줄었는지는 Day 09(실무 분석)에서 가입 데이터와 함께 확인합니다.

> 날짜 범위 조건에 시간이 섞이면 함정이 있습니다. `'2025-07-31 15:00'`처럼 시간이 붙은 값은 `BETWEEN '2025-07-01' AND '2025-07-31'`에 **들어가지 않습니다**(`'2025-07-31'`이 `'2025-07-31 15:00'`보다 작으므로). 하루 끝까지 넣으려면 `order_date < '2025-08-01'`처럼 **다음 날 미만**으로 쓰는 것이 안전합니다.

## 정리

- 글자는 `||`로 잇고, `UPPER` · `LOWER` · `LENGTH` · `SUBSTR` · `REPLACE` · `TRIM`으로 다듬습니다.
- `IFNULL` · `COALESCE`로 NULL을 다른 값으로 바꿉니다.
- `CASE WHEN … THEN … ELSE … END`는 위에서부터 **처음 맞는** 조건을 고릅니다. 좁은 조건부터, NULL은 따로.
- CASE로 만든 구간을 GROUP BY 하면 구간별 분석이 됩니다.
- 날짜는 `'YYYY-MM-DD'` 글자로 비교하고, `strftime`으로 연 · 월을 뽑아 묶습니다.
