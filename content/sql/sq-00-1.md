## 회사 데이터는 어디에 있을까

파이썬 트랙에서는 `titanic.csv` 같은 **파일**을 열어 분석했습니다. 그런데 회사에서 매일 쌓이는 주문 · 회원 · 생산 기록은 파일 하나에 담기지 않습니다. 수백만 줄이 1초에도 몇 번씩 새로 들어오고, 여러 사람이 동시에 읽고 고치기 때문입니다.

그래서 회사 데이터는 대부분 **데이터베이스(Database, DB)** 라는 전용 창고에 들어 있습니다. 그리고 이 창고에서 데이터를 꺼낼 때 쓰는 공식 언어가 **SQL**(에스큐엘 또는 시퀄)입니다.

> SQL은 데이터베이스에 던지는 **질문 문장**입니다. "이 표에서, 이런 조건으로, 이것만 보여 줘"를 정해진 단어로 적습니다.

## 질문을 SQL로 바꾸는 연습

우리가 평소에 하는 질문은 말로 되어 있습니다. SQL로 바꾸려면 질문을 아래 다섯 조각으로 쪼개야 합니다. 이렇게 질문을 데이터 구조로 바꿔 읽는 힘을 **데이터 리터러시**라고 합니다.

| 질문 | 어느 표? | 어떤 조건? | 무엇을 기준으로 묶어? | 무엇을 세거나 더해? |
| --- | --- | --- | --- | --- |
| 이번 달 매출은 얼마야? | 주문 | 이번 달 주문만 | (묶지 않음) | 결제 금액 합계 |
| 부서마다 몇 명이야? | 사원 | (전부) | 부서 | 사람 수 |
| 재구매한 고객만 보고 싶어 | 주문 | 주문이 2번 이상 | 고객 | 주문 수 |

이 표의 칸 하나하나가 앞으로 배울 SQL 단어와 짝을 이룹니다. 어느 표 = `FROM`, 조건 = `WHERE`, 묶기 = `GROUP BY`, 세기 · 더하기 = `COUNT` · `SUM`. 이 트랙을 다 마치면 왼쪽 질문을 오른쪽 조각으로 나눠 바로 쿼리로 쓸 수 있게 됩니다.

## 첫 쿼리 실행하기

아래 회색 상자가 **SQL 실행 셀**입니다. **▶ 실행**을 누르거나, 셀 안을 클릭하고 `Ctrl + Enter`(맥은 `Cmd + Enter`)를 누르면 결과 표가 바로 아래에 나옵니다. 처음 한 번은 실행 엔진을 불러오느라 몇 초 걸립니다.

부서 테이블 `dept`를 통째로 봅니다. `*`는 "모든 열"이라는 뜻입니다.

```sqlrun
SELECT * FROM dept;
```

결과 위에 **5행 × 3열**이라고 나옵니다. 부서가 5개(행 5개)이고, 부서마다 번호 · 이름 · 위치(열 3개)가 적혀 있다는 뜻입니다. 문장 끝의 `;`(세미콜론)은 "질문 하나가 여기서 끝난다"는 마침표입니다.

이번에는 사원 테이블 `emp`입니다. 사원 14명의 기록이 나옵니다.

```sqlrun
SELECT * FROM emp;
```

열이 10개입니다. 처음 보는 열 이름은 아래 표로 확인하세요. 이 표는 실무에서 **테이블 정의서**라고 부르는 문서와 같은 모양입니다.

| 열 | 뜻 | 예 |
| --- | --- | --- |
| `empno` | 사번 (사원마다 하나뿐인 번호) | 7002 |
| `ename_ko` · `ename_en` | 이름 (한글 · 영문) | 김낙수, Kim Naksu |
| `joblv` | 직급 | 부장 |
| `mgr` | 직속 상사의 사번 | 7001 |
| `hiredate` | 입사일 | 2000-03-15 |
| `sal` · `comm` | 연봉 · 성과급 (만 원 단위) | 15000, 5000 |
| `deptno` | 부서 번호 | 11 |
| `employed` | 재직 여부 (1 재직, 0 퇴사) | 1 |

대표(김대표)의 `mgr`와 `deptno` 칸에는 `NULL`이라고 나옵니다. **NULL은 "값이 없음"** 입니다. 대표는 상사도, 소속 부서도 없으니까요. NULL은 0과도, 빈 글자와도 다른 특별한 상태라서 다음 레슨부터 여러 번 다시 만납니다.

- **기본키 (PK, Primary Key)**: 행 하나를 콕 집어 주는 번호. 겹치면 안 됩니다. `emp.empno`, `dept.deptno`

## 이 사이트에서 SQL을 실행하는 방식

실무에서는 MySQL · PostgreSQL 같은 DB 서버에 접속 도구(DBeaver 등)로 연결해서 쿼리를 칩니다. 이 사이트는 설치 없이 바로 연습할 수 있도록 **브라우저 안에서 SQLite**라는 작은 데이터베이스를 띄워 실행합니다.

- 셀을 실행할 때마다 **새 데이터베이스**를 만들고 실습 데이터를 넣습니다. 그래서 데이터를 지우거나 바꾸는 문장을 실행해도, 다음 실행 때는 원래대로 돌아옵니다. 마음껏 고쳐 보세요.
- 코드를 바꿨다가 처음으로 돌리고 싶으면 **원래대로** 버튼을 누릅니다.
- 결과는 100행까지만 표로 보여 주고, 전체 행 수는 표 위에 적어 줍니다.
- SELECT 문법은 MySQL과 거의 같습니다. 함수 이름처럼 다른 곳은 레슨에서 "MySQL에서는"으로 따로 짚어 줍니다.

타이타닉은 행이 891개라 앞의 5행만 봅니다. `LIMIT 5`는 "5행만 보여 줘"라는 뜻입니다(Day 03에서 자세히 배웁니다).

```sqlrun
SELECT * FROM titanic LIMIT 5;
```

`survived`는 생존(1) · 사망(0), `pclass`는 객실 등급(1 · 2 · 3등실), `fare`는 운임, `deck`은 갑판입니다. `age`와 `deck`의 NULL은 기록이 남지 않은 승객입니다.

쇼핑몰의 주문 테이블도 한 번 열어 봅니다.

```sqlrun
SELECT * FROM orders LIMIT 5;
```

주문 한 건이 한 줄이고, `user_id`가 고객 테이블 `users`를 가리키는 외래키입니다.

## 정리

- 회사 데이터는 데이터베이스에 있고, SQL은 거기에 던지는 질문 문장입니다.
- 서버 > 데이터베이스 > 테이블 > 행 · 열. 테이블 한 장 = 엑셀 시트 한 장.
- 기본키는 행을 하나로 집는 번호, 외래키는 다른 표를 가리키는 번호입니다.
- `SELECT * FROM 테이블;` 로 표 전체를 볼 수 있습니다. 다음 레슨에서는 필요한 **열만**, 필요한 **행만** 골라 봅니다.
