## SQL이란?

SQL(Structured Query Language)은 **데이터베이스에 저장된 데이터를 꺼내고, 넣고, 고치는 언어**입니다. 이름의 Query(쿼리)가 "질문"이라는 뜻이듯, SQL 문장 하나는 데이터베이스에 던지는 질문 하나입니다.

```sqlrun
SELECT '안녕하세요, SQL!' AS greeting, 1 + 1 AS answer;
```

▶ 실행을 누르면 바로 아래에 **표**가 나옵니다. SQL은 질문을 받으면 언제나 표(행과 열)로 답합니다. 이 페이지에서는 SQL이 무엇이고 어디에 쓰이는지 먼저 살펴보고, 실제 데이터로 질문하는 것은 다음 페이지부터 합니다.

### 데이터베이스와 DBMS

**데이터베이스(Database, DB)** 는 데이터를 정해진 모양(표)으로 모아 둔 창고입니다. 이 창고를 관리하는 프로그램을 **DBMS**(Database Management System)라고 부릅니다. MySQL, Oracle, PostgreSQL, SQLite 같은 이름이 모두 DBMS입니다.

> 비유하면 데이터베이스는 **도서관 서고**, DBMS는 **사서**, SQL은 사서에게 건네는 **신청서**입니다. 서고에 들어가 책을 직접 뒤지지 않아도, 신청서에 "2020년 이후에 나온 통계 책"이라고 적어 내면 사서가 찾아서 가져다줍니다.

데이터를 파일이 아니라 DB에 두는 이유는 세 가지입니다.

- **크기**: 수억 행이 쌓여도 필요한 행만 빠르게 찾습니다.
- **여러 사람이 동시에**: 수백 명이 한꺼번에 읽고 써도 데이터가 꼬이지 않습니다.
- **안전**: 정전이 나도 반쯤 저장된 데이터가 남지 않고, 누가 무엇을 볼 수 있는지 권한을 나눌 수 있습니다.

### "무엇을"만 적는 언어

SQL의 가장 큰 특징은 **원하는 결과(무엇을)만 적고, 찾는 방법(어떻게)은 적지 않는다**는 점입니다. 이런 언어를 **선언형 언어**라고 합니다.

예를 들어 "11번 부서 사원의 이름과 연봉"은 이렇게 씁니다.

```
SELECT ename_ko, sal     -- 무엇을: 이름과 연봉
FROM emp                 -- 어디서: 사원 표
WHERE deptno = 11;       -- 조건: 11번 부서
```

표를 처음부터 한 줄씩 읽을지, 미리 만들어 둔 목차(인덱스)로 바로 찾아갈지는 DBMS가 알아서 고릅니다. 그래서 SQL은 영어 문장처럼 짧고, 처음 배우는 사람도 읽을 수 있습니다.

- **데이터 분석**: "지난달 신규 고객은 몇 명이고, 그중 재구매한 사람은?" 같은 지표를 직접 뽑습니다. 분석 직무 채용 공고에서 가장 자주 보이는 기술이 SQL입니다.

- **마케팅 · CRM**: "3개월간 구매가 없는 고객"처럼 조건에 맞는 고객 목록을 뽑아 쿠폰을 보냅니다.
- **생산 · 품질**: 설비가 1초마다 남기는 기록을 DB에 쌓아 두고, 라인별 · 시간대별 불량을 집계합니다.

## DBMS 종류와 "방언"

SQL은 표준이 있지만, DBMS마다 함수 이름이나 세부 문법이 조금씩 다릅니다. 같은 한국어라도 지역마다 사투리가 있듯, 이런 차이를 **방언(dialect)** 이라고 부릅니다. `SELECT`, `FROM`, `WHERE`, `GROUP BY`, `JOIN` 같은 **핵심 문법은 어디서나 같습니다.**

| DBMS | 만든 곳 | 특징 | 주로 쓰는 곳 |
| --- | --- | --- | --- |
| Oracle | Oracle | 유료, 대용량 · 안정성 | 은행 · 대기업 업무 시스템 |
| MySQL | Oracle (오픈소스) | 무료, 가장 널리 쓰임 | 웹 서비스, 쇼핑몰 |
| PostgreSQL | 오픈소스 커뮤니티 | 무료, 표준에 충실, 기능이 풍부 | 스타트업, 데이터 분석 |
| SQL Server | Microsoft | Windows · 엑셀 · Power BI와 잘 맞음 | 사내 업무 시스템 |
| SQLite | 오픈소스 (D. Richard Hipp) | 서버 없이 **파일 하나**가 DB | 스마트폰 앱, 브라우저, **이 사이트** |
| BigQuery · Snowflake | Google · Snowflake | 클라우드, 수십억 행 집계 | 데이터 웨어하우스, 대규모 분석 |

이 트랙은 SQLite로 실습하고, MySQL과 문법이 다른 곳은 레슨마다 **"MySQL에서는"** 으로 따로 짚어 줍니다. 회사에서 다른 DBMS를 쓰게 되더라도 여기서 익힌 문법이 그대로 통합니다.

## 엑셀 · 파이썬과 비교하면

SQL이 엑셀이나 파이썬을 대신하는 것은 아닙니다. **잘하는 일이 다르고**, 실무에서는 단계마다 나눠 씁니다.

| 기준 | 엑셀 | SQL | 파이썬 |
| --- | --- | --- | --- |
| 처음 배우기 | 매우 쉬움 | 쉬움 (단어 몇 개로 시작) | 보통 |
| 데이터가 사는 곳 | 내 PC의 파일 | 회사 DB 서버 | 파일 · DB 어디서든 읽어 옴 |
| 데이터 크기 | 약 100만 행 한계, 수십만 행부터 느려짐 | DB 용량만큼 (수억 행) | 내 PC 메모리만큼 |
| 여러 사람이 동시에 | 파일을 돌려 보며 버전이 꼬임 | 모두가 같은 최신 데이터를 봄 | 각자 복사본으로 작업 |

## 이 사이트에서 SQL이 실행되는 방식

실무에서는 회사 DB 서버에 접속 프로그램으로 연결해서 쿼리를 칩니다. 이 사이트는 **설치 없이** 바로 연습할 수 있도록, 여러분의 **브라우저 안에서 SQLite를 띄워** 실행합니다.

- 처음 실행할 때는 실행 엔진을 내려받느라 몇 초 걸립니다. 그다음부터는 바로 실행됩니다.
- 코드를 고쳤다가 처음으로 돌리고 싶으면 **원래대로** 버튼을 누릅니다.
- 오류가 나면 빨간 상자에 오류 메시지와 함께 **쉬운 말 힌트**가 나옵니다. 오류 메시지를 읽는 것도 SQL 공부의 일부입니다.

> 내 PC에서 직접 해 보고 싶다면: SQLite 파일을 여는 **DB Browser for SQLite**(무료), 여러 DBMS에 접속하는 **DBeaver**(무료), MySQL 전용 **MySQL Workbench**가 많이 쓰입니다. 이 트랙은 사이트 안에서 끝까지 진행할 수 있으니 설치는 나중에 해도 됩니다.
