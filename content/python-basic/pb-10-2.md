검사 장비, 설비 로그, 엑셀에서 내보낸 데이터는 대부분 **CSV**(쉼표로 칸을 나눈 텍스트 파일)입니다. [파일을 열고 CSV · JSON 읽기](#/l/pb-10-1)에서 `csv.DictReader`로 한 번 읽어 봤다면, 이번에는 읽은 값을 **숫자로 바꿔 집계하고, 결과를 다시 CSV로 저장하는** 한 바퀴를 돌아 봅니다.

> 브라우저 실행 셀은 셀마다 따로 실행되므로, 각 셀 맨 위에서 예제 CSV 파일을 먼저 만듭니다. 실제로는 장비가 남긴 파일을 바로 읽으면 됩니다.

### CSV 파일의 생김새

```
lot,line,qty,defects
A0915,L1,1250,18
A0916,L2,980,7
A0917,L1,1100,25
```

첫 줄은 **열 이름(헤더)**, 다음 줄부터 한 줄이 한 행입니다. 메모장으로 열어도 이렇게 보입니다.

### csv.reader: 한 줄을 리스트로

`csv.reader`는 한 줄을 **문자열 리스트**로 줍니다. 쉼표로 나누는 일을 `split(",")` 대신 해 주는데, 값 안에 쉼표가 있어 따옴표로 감싼 경우(`"1,250"`)까지 올바르게 처리합니다.

```run
import csv

with open("lots.csv", "w", encoding="utf-8", newline="") as f:
    f.write("lot,line,qty,defects\nA0915,L1,1250,18\nA0916,L2,980,7\nA0917,L1,1100,25\n")

with open("lots.csv", encoding="utf-8") as f:
    for row in csv.reader(f):
        print(row)
```

헤더 줄도 리스트 하나로 나왔습니다. 계산할 때는 헤더를 빼야 합니다.

### 헤더 건너뛰기: next()

`next()`는 다음 한 줄을 꺼내 줍니다. 반복 전에 한 번 부르면 헤더를 따로 받아 두고, 반복은 둘째 줄부터 돕니다.

```run
import csv

with open("lots.csv", "w", encoding="utf-8", newline="") as f:
    f.write("lot,line,qty,defects\nA0915,L1,1250,18\nA0916,L2,980,7\nA0917,L1,1100,25\n")

with open("lots.csv", encoding="utf-8") as f:
    reader = csv.reader(f)
    header = next(reader)
    print("헤더:", header)
    for lot, line, qty, defects in reader:
        print(lot, int(defects) / int(qty))
```

한 행이 4칸이므로 바로 언패킹([튜플과 언패킹](#/l/pb-04-2))했습니다. CSV에서 읽은 값은 **모두 문자열**이라 `int()`로 바꾼 뒤 나눴습니다.

### DictReader로 집계하기

열 이름으로 꺼내는 `DictReader`가 읽기 쉽습니다. 라인별 불량 합계를 딕셔너리로 모아 봅니다.

```run
import csv

with open("lots.csv", "w", encoding="utf-8", newline="") as f:
    f.write("lot,line,qty,defects\nA0915,L1,1250,18\nA0916,L2,980,7\nA0917,L1,1100,25\n")

qty_by_line = {}
def_by_line = {}
with open("lots.csv", encoding="utf-8") as f:
    for row in csv.DictReader(f):
        line = row["line"]
        qty_by_line[line] = qty_by_line.get(line, 0) + int(row["qty"])
        def_by_line[line] = def_by_line.get(line, 0) + int(row["defects"])

for line in sorted(qty_by_line):
    print(line, qty_by_line[line], def_by_line[line], f"{def_by_line[line] / qty_by_line[line]:.2%}")
```

L1은 2350개 중 43개(1.83%), L2는 980개 중 7개(0.71%)입니다. `d.get(line, 0) + 값`은 "처음 나온 라인이면 0에서 시작해 더한다"는 집계의 기본 모양입니다([함수 안에서 세고 찾고 집계하기](#/l/pb-09-1) 패턴 4).

### 문자열 그대로 더하면 생기는 일

`int()`를 빼먹으면 에러가 나는 대신 **글자가 이어 붙는** 경우가 있어 더 위험합니다.

```run
a = "18"
b = "25"
print(a + b)
print(int(a) + int(b))
```

`1825`와 43입니다. 결과가 이상하게 크면 문자열끼리 더하지 않았는지 의심하세요.

### 결과를 CSV로 저장하기

집계 결과는 `csv.writer`로 씁니다. `writerow()`에 리스트 하나를 넣으면 한 줄이 됩니다. 쓰기용으로 열 때는 `newline=""`을 꼭 넣습니다. 빼면 Windows에서 줄 사이에 빈 줄이 끼어 저장됩니다.

```run
import csv

summary = [("L1", 2350, 43), ("L2", 980, 7)]
with open("summary.csv", "w", encoding="utf-8", newline="") as f:
    writer = csv.writer(f)
    writer.writerow(["line", "qty", "defects", "rate"])
    for line, qty, d in summary:
        writer.writerow([line, qty, d, round(d / qty, 4)])

with open("summary.csv", encoding="utf-8") as f:
    print(f.read())
```

숫자는 저장할 때 자동으로 글자로 바뀝니다. 엑셀에서 한글이 깨지면 `encoding="utf-8-sig"`로 저장하면 됩니다.

### 이어 쓰기: 로그 쌓기

모드 `"a"`([파일을 열고 CSV · JSON 읽기](#/l/pb-10-1))로 열면 기존 내용 뒤에 붙습니다. 검사할 때마다 한 줄씩 기록을 쌓는 로그 파일에 씁니다.

```run
import csv

with open("log.csv", "w", encoding="utf-8", newline="") as f:
    csv.writer(f).writerow(["lot", "result"])
for lot, result in [("A0915", "PASS"), ("A0916", "FAIL")]:
    with open("log.csv", "a", encoding="utf-8", newline="") as f:
        csv.writer(f).writerow([lot, result])

with open("log.csv", encoding="utf-8") as f:
    print(f.read())
```

### 정리

| 하고 싶은 일 | 코드 |
| --- | --- |
| 줄을 리스트로 읽기 | `csv.reader(f)` |
| 헤더 따로 받기 | `header = next(reader)` |
| 줄을 딕셔너리로 읽기 | `csv.DictReader(f)` |
| 숫자로 바꾸기 | `int(row["qty"])`, `float(row["value"])` |
| 한 줄 쓰기 | `csv.writer(f).writerow([...])` (`newline=""`로 열기) |
| 기록 이어 쓰기 | `open(..., "a", newline="")` |
