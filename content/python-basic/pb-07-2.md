pb-07-1에서 `for`로 `range()`와 리스트를 돌았습니다. 실제 데이터는 리스트 하나보다 복잡합니다. 번호도 같이 필요하고, 두 리스트를 나란히 봐야 하고, 딕셔너리나 행 목록(pb-06-2)을 돌아야 합니다. 이 레슨에서는 **무엇을 돌리느냐에 따라 for를 쓰는 모양**을 정리합니다.

| 돌리고 싶은 것 | 쓰는 모양 |
| --- | --- |
| 리스트의 값 | `for v in values:` |
| 값과 번호 | `for i, v in enumerate(values):` |
| 두 리스트를 나란히 | `for a, b in zip(xs, ys):` |
| 문자열의 글자 | `for ch in text:` |
| 딕셔너리의 key와 value | `for k, v in d.items():` |
| 표 (행 목록) | `for row in rows:` |

### 값이 필요하면 값을 바로 돌립니다

번호(`range(len(...))`)로 돌리는 습관이 있으면 코드가 길어지고 틀리기 쉽습니다. 값만 필요하면 리스트를 바로 돌립니다.

```run
temps = [23.1, 25.4, 22.8]
for i in range(len(temps)):     # 번호로 돌기: 동작은 하지만 길다
    print(temps[i])
for t in temps:                 # 값으로 돌기: 짧고 실수가 적다
    print(t)
```

두 반복의 출력은 같습니다.

### 번호도 필요하면 enumerate

몇 번째 값인지도 알아야 하면 `enumerate()`가 **(번호, 값)** 쌍을 줍니다. 받는 쪽에서 튜플 언패킹(pb-04-2)으로 둘로 나눕니다. `start=1`을 주면 1부터 셉니다.

```run
temps = [23.1, 25.4, 22.8]
for no, t in enumerate(temps, start=1):
    flag = " <- 높음" if t > 25 else ""
    print(f"{no}번 {t}{flag}")
```

`A if 조건 else B`는 조건이 참이면 A, 거짓이면 B가 되는 한 줄짜리 if입니다(pb-11-2에서 자세히). 2번 측정값에만 표시가 붙었습니다.

### 두 리스트를 나란히: zip

로트 목록과 불량 수 목록처럼 **같은 순서로 짝이 맞는** 리스트는 `zip()`으로 묶어 함께 돕니다.

```run
lots = ["A0915", "A0916", "A0917"]
defects = [18, 7, 12]
for lot, d in zip(lots, defects):
    print(lot, d)
```

길이가 다르면 **짧은 쪽에 맞춰** 멈춥니다. 남은 값이 조용히 버려지므로 두 리스트의 길이가 같은지 먼저 확인하는 습관이 좋습니다.

```run
lots = ["A0915", "A0916", "A0917"]
defects = [18, 7]
print(len(lots) == len(defects))
for lot, d in zip(lots, defects):
    print(lot, d)
```

A0917은 짝이 없어 출력되지 않았습니다.

### 문자열도 한 글자씩 돕니다

```run
results = "PPFPF"
fails = 0
for ch in results:
    if ch == "F":
        fails += 1
print(fails)
```

불합격 2개입니다. 이 경우는 `results.count("F")`(pb-03-2)가 더 짧지만, 글자마다 다른 일을 해야 할 때는 이렇게 돕니다.

### 딕셔너리는 items()로

딕셔너리를 그냥 `for`로 돌면 **key만** 나옵니다. key와 value가 모두 필요하면 `items()`를 씁니다.

```run
stock = {"볼트": 120, "너트": 35, "와셔": 8}
for name, qty in stock.items():
    if qty < 50:
        print(f"{name} 재고 부족: {qty}개")
```

너트와 와셔가 출력됩니다.

### 표(행 목록)를 돌기

pb-06-2의 "딕셔너리 리스트"는 for로 한 행씩 꺼내 계산합니다. 파일에서 읽은 표를 처리하는 가장 기본 모양입니다.

```run
rows = [
    {"lot": "A0915", "qty": 1250, "defects": 18},
    {"lot": "A0916", "qty": 980, "defects": 7},
    {"lot": "A0917", "qty": 1100, "defects": 25},
]
for row in rows:
    rate = row["defects"] / row["qty"]
    print(f"{row['lot']} {rate:.2%}")
```

A0917이 2.27%로 가장 높습니다.

### 반복 안에 반복

라인 × 교대조처럼 **모든 조합**을 돌 때는 for 안에 for를 넣습니다. 안쪽 반복이 한 바퀴 다 돈 뒤에 바깥 반복이 한 칸 나아갑니다.

```run
lines = ["L1", "L2"]
shifts = ["주간", "야간"]
for line in lines:
    for shift in shifts:
        print(line, shift)
```

출력은 4줄(2 × 2)입니다. 바깥 L1이 고정된 채 안쪽이 주간 → 야간을 돌고, 그다음 L2로 넘어갑니다.

### 자주 하는 실수

반복하면서 **같은 리스트에서 값을 지우면** 번호가 당겨져 값을 건너뜁니다.

```python
sizes = [9.2, 9.1, 10.0]
for s in sizes:
    if s < 9.5:
        sizes.remove(s)
print(sizes)     # [9.1, 10.0] : 9.1 이 남는다
```

9.2를 지우는 순간 9.1이 0번 자리로 당겨지고, 반복은 다음 번호(1번, 10.0)로 넘어가 버립니다. 남길 값을 **새 리스트에 모으면** 안전합니다.

```run
sizes = [9.2, 9.1, 10.0]
keep = []
for s in sizes:
    if s >= 9.5:
        keep.append(s)
print(keep)
```
