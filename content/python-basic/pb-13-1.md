### 시작하기 전에

지금까지는 `print`, `len`, `sorted`처럼 **파이썬에 처음부터 들어 있는 기능**과 우리가 `def`로 직접 만든 함수만 썼습니다. 그런데 제곱근 계산, 오늘 날짜, 난수, 폴더 만들기 같은 일은 매번 직접 만들기에는 어렵고 번거롭습니다. 다행히 이런 기능은 누군가 이미 만들어서 **모듈**이라는 상자에 담아 두었습니다. 이 레슨에서는 그 상자를 불러오는 법(`import`)을 배우고, 내 함수도 상자로 만들어 봅니다.

이번 코스에서 배우는 것:

| 레슨 | 모듈 | 하는 일 |
| --- | --- | --- |
| 이번 레슨 | `import` | 모듈을 불러오는 방법 |
| [datetime: 날짜와 시간 계산하기](#/l/pb-13-2) | `datetime` | 날짜 · 시각 만들기, 더하고 빼기, 문자열로 바꾸기 |
| [math와 random: 계산 도구와 난수](#/l/pb-13-3) | `math`, `random` | 올림 · 내림, 난수와 표본 뽑기 |
| [os: 폴더와 파일 경로 다루기](#/l/pb-13-4) | `os` | 폴더 만들기, 경로 확인, 날짜별 로그 저장 |

### 모듈: 작은 도구 상자

**모듈(module)**은 파이썬 코드가 들어 있는 **`.py` 파일 하나**입니다. 안에는 쓸모 있는 함수 · 변수가 모여 있습니다. 공구함에 비유하면, 드라이버만 모아 둔 상자, 렌치만 모아 둔 상자처럼 **용도별로 정리한 작은 도구 상자**입니다. 수학 기능은 `math` 모듈에, 날짜 · 시간 기능은 `datetime` 모듈에 들어 있습니다.

모듈이 많아지면 폴더로 묶습니다. 모듈 여러 개를 폴더 구조로 묶은 것을 **패키지(package)**라고 하고, 이렇게 남이 쓰라고 만들어 둔 모듈 · 패키지를 통틀어 **라이브러리(library)**라고 부릅니다. 실무에서는 패키지와 라이브러리를 거의 같은 뜻으로 섞어 씁니다.

::figure{src="content/img/py/py-module-library.svg" alt="왼쪽 모듈 상자에는 math.py 파일 하나에 sqrt, ceil, floor, pi가 들어 있다. 가운데 패키지 상자에는 pandas 폴더 안에 frame.py, series.py, io 폴더가 있다. 오른쪽 라이브러리 상자는 설치 없이 쓰는 표준 라이브러리(math, datetime, random, os, csv, json)와 pip로 설치하는 외부 라이브러리(numpy, pandas, matplotlib, scikit-learn)로 나뉜다" caption="모듈은 파일 하나, 패키지는 모듈을 묶은 폴더, 라이브러리는 이것들을 모아 부르는 말입니다."}

### import로 불러와서 점(.)으로 꺼내 쓰기

모듈을 쓰려면 먼저 `import 모듈이름`으로 불러옵니다. 그다음 `모듈이름.기능이름`처럼 **점(.)**을 찍어 안에 든 기능을 꺼냅니다. "math 상자 안의 sqrt"라는 뜻입니다.

```run
import math

result = math.sqrt(25)    # math 모듈 안의 sqrt(제곱근) 함수
print(result)
print(math.pi)            # 함수뿐 아니라 값(변수)도 들어 있다
```

`5.0`과 `3.141592653589793`이 나옵니다. `import` 문은 **코드 맨 위**에 모아 둡니다. 코드를 읽는 사람이 "이 파일은 어떤 도구를 쓰는구나"를 첫 줄에서 알 수 있기 때문입니다.

### 표준 라이브러리와 외부 라이브러리

라이브러리는 어디서 오느냐에 따라 두 가지로 나뉩니다.

| 구분 | 설치 | 예 | 비유 |
| --- | --- | --- | --- |
| **표준 라이브러리** | 파이썬을 설치하면 함께 들어 있음 | `math`, `datetime`, `random`, `os`, `csv`, `json` | 새 집에 붙박이로 달린 수납장 |
| **외부 라이브러리** | `pip install 이름`으로 따로 설치 | `numpy`, `pandas`, `matplotlib`, `scikit-learn` | 필요할 때 사 오는 가구 |

[파일 입출력과 데이터 형식](#/l/pb-10-1)에서 쓴 `csv`, `json`도 표준 라이브러리였습니다. 이 사이트에서는 표준 라이브러리와 numpy · pandas · matplotlib · seaborn · scipy · scikit-learn을 설치 없이 바로 쓸 수 있습니다. 내 컴퓨터에서 외부 라이브러리를 쓰려면 먼저 설치해야 합니다(Anaconda에는 대부분 들어 있습니다).

### import 네 가지 모양

같은 모듈도 불러오는 모양에 따라 쓰는 법이 달라집니다.

::figure{src="content/img/py/py-import-forms.svg" alt="import math는 math.sqrt(25)로, from math import sqrt는 sqrt(25)로, import numpy as np는 np.array로 쓴다. from math import *는 전부 꺼내서 이름이 겹칠 수 있어 쓰지 않는다고 빨간색으로 표시되어 있다" caption="import 문의 네 가지 모양. 위의 세 가지를 쓰고, 맨 아래 별표(*)는 피합니다."}

**from 모듈 import 이름**: 필요한 기능만 꺼내 오면 모듈 이름 없이 바로 씁니다.

```run
from math import sqrt, ceil

print(sqrt(16))     # math. 없이 바로
print(ceil(4.1))    # 올림
```

쉼표로 여러 개를 한 번에 꺼낼 수 있습니다. 대신 코드 아래쪽에서 `sqrt`만 보고는 어느 모듈에서 왔는지 바로 알기 어렵습니다.

**import 모듈 as 별명**: 이름이 길면 짧은 별명을 붙입니다. 데이터 분석에서는 모두가 같은 별명을 씁니다(`numpy as np`, `pandas as pd`, `matplotlib.pyplot as plt`). 남의 코드를 읽을 때 `np.`가 보이면 NumPy라는 것을 바로 알 수 있습니다.

```run
import statistics as st

values = [23.4, 22.9, 24.1, 23.8]
print(st.mean(values))     # 평균
print(st.median(values))   # 중앙값
```

`statistics`도 표준 라이브러리입니다. `st`라는 별명으로 줄여 불렀습니다.

**여러 모듈 불러오기**: 한 줄에 쉼표로 쓰거나 줄을 나눠 씁니다. 줄을 나누는 쪽이 읽기 쉽습니다.

```run
import math
import random
from datetime import date

print(math.floor(3.7), random.randint(1, 6), date(2026, 11, 7))
```

`random.randint(1, 6)`은 주사위처럼 1~6 중 하나라 실행할 때마다 바뀝니다.

:::tip 알아 두면 좋아요 · 이름이 겹치면 나중 것이 이깁니다
`from datetime import datetime`은 **datetime 모듈 안의 datetime 타입**을 꺼내는 줄입니다. 모듈과 타입 이름이 같아서 헷갈리기 쉽습니다.

```python
import datetime
datetime.datetime.now()      # 모듈.타입.함수

from datetime import datetime
datetime.now()               # 타입.함수 (이 모양을 더 많이 쓴다)
```

두 줄을 한 파일에 같이 쓰면 뒤에 쓴 줄이 `datetime`이라는 이름을 덮어써서 앞의 모양이 에러가 납니다. 같은 이유로 `from math import *`(전부 꺼내기)도 피합니다. 내가 만든 변수 이름과 모듈 안 이름이 조용히 겹칠 수 있기 때문입니다.
:::

### 왜 모듈을 쓸까요

- **코드 재사용**: 이미 잘 만들어지고 많은 사람이 검증한 코드를 가져다 씁니다. 처음부터 만들 필요가 없습니다.
- **효율**: 복잡한 기능(제곱근, 날짜 계산, 폴더 만들기)을 한 줄로 실행합니다. 코드가 짧아지고 실수가 줄어듭니다.
- **정리**: 관련 기능이 모듈별로 묶여 있어 찾기 쉽고, 내 코드도 모듈로 나눠 체계적으로 관리할 수 있습니다.

### 다 외우지 않아도 됩니다

표준 라이브러리만 해도 모듈이 200개가 넘습니다. 외울 필요는 없습니다. 자동차를 운전하려고 엔진 부품을 다 만들 줄 알 필요가 없는 것처럼, **필요한 도구의 이름과 쓰는 법을 찾아 적용하는 능력**이 중요합니다. 모듈 안에 무엇이 들었는지는 `dir()`로 훑어볼 수 있습니다.

```run
import math

names = [n for n in dir(math) if not n.startswith("_")]
print(len(names), "개")
print(names[:12])
```

이름만 봐도 `ceil`(올림), `cos`(코사인), `factorial`(팩토리얼) 같은 기능이 짐작됩니다. 자세한 사용법은 [파이썬 공식 문서의 표준 라이브러리 목록](https://docs.python.org/ko/3/library/index.html)에서 찾습니다. 한국어 번역도 있습니다.

### 함수 설명서 읽기: help()

이름을 찾았으면 다음은 "무엇을 넣으면 무엇이 나오나"입니다. `help(함수)`를 쓰면 그 함수의 설명서가 나옵니다. 인터넷 검색 없이 코드 안에서 바로 확인할 수 있습니다.

```run
help(round)
```

설명서는 보통 세 부분입니다.

| 부분 | 예 | 읽는 법 |
| --- | --- | --- |
| 첫 줄 | `Help on built-in function round in module builtins` | 어느 모듈의 무엇인지 |
| **시그니처** | `round(number, ndigits=None)` | 넣을 값의 이름과 순서. `=` 뒤는 **기본값**(생략하면 이 값) |
| 설명 | `Round a number to a given precision ...` | 하는 일과 돌려주는 값 |

시그니처만 읽어도 많은 것을 알 수 있습니다. `round(number, ndigits=None)`은 "숫자 하나는 꼭 넣고, 자리수는 안 넣으면 None(정수로 반올림)"이라는 뜻입니다. [함수 만들기 기본기: 기본값 · 키워드 인자 · 여러 값 반환](#/l/pb-08-2)에서 우리가 만든 `def judge(value, low=9.5, high=10.5)`와 같은 모양입니다.

시그니처에는 가끔 `/`와 `*`가 끼어 있습니다.

```run
help(sorted)
```

`sorted(iterable, /, *, key=None, reverse=False)`에서 **`/` 앞**(`iterable`)은 이름을 붙이지 말고 **순서대로만** 넣고, **`*` 뒤**(`key`, `reverse`)는 반드시 **`key=...`처럼 이름을 붙여** 넣으라는 표시입니다. 그래서 `sorted(lots, key=len)`은 되고 `sorted(lots, len)`은 에러가 납니다. `*args` · `**kwargs`가 보이면 [개수가 정해지지 않은 인자: *args · **kwargs](#/l/pb-08-4)를 떠올리면 됩니다.

내가 만든 함수에 docstring(함수 첫 줄의 설명 문자열)을 써 두면 `help`에 그대로 나옵니다.

```run
def defect_rate(defects, qty, digits=2):
    """불량 수와 검사 수를 받아 불량률(%)을 digits 자리로 돌려준다."""
    return round(defects / qty * 100, digits)

help(defect_rate)
```

남이 만든 라이브러리 함수도 모두 이렇게 docstring이 달려 있어서 `help(pd.read_csv)`처럼 볼 수 있습니다. 다만 pandas · scikit-learn 함수는 설명이 수백 줄이라, 처음에는 **시그니처와 첫 문단만** 읽는 습관을 들이면 충분합니다.

:::tip 알아 두면 좋아요 · Jupyter · Colab에서는 더 짧게
노트북에서는 `round?`처럼 이름 뒤에 물음표를 붙여 실행하거나, 함수 이름의 괄호 안에 커서를 두고 **Shift + Tab**을 누르면 같은 설명서가 팝업으로 나옵니다. VS Code에서는 함수 이름에 마우스를 올리면 됩니다.
:::

### 내 모듈 만들어 보기

모듈은 그냥 `.py` 파일이므로 우리도 만들 수 있습니다. 자주 쓰는 함수를 `qaqc.py`에 저장해 두면 다른 파일이나 노트북에서 `import qaqc`로 불러 쓸 수 있습니다. 내 컴퓨터에서는 이렇게 합니다.

```python
# qaqc.py  (같은 폴더에 저장한 파일)
def my_func(a, b):
    return a + b
```

```python
# test.ipynb  (같은 폴더의 노트북)
import qaqc
print(qaqc.my_func(1, 2))    # 3
```

**파일 이름(확장자 `.py` 뺀 것)이 곧 모듈 이름**입니다. 그리고 `import`는 **지금 작업 중인 폴더**에서 그 파일을 찾습니다. 그래서 두 파일이 같은 폴더에 있어야 합니다.

이 사이트는 실행 셀을 누를 때마다 **빈 연습 폴더**에서 코드를 실행합니다. 그래서 아래 셀은 ① 먼저 `qaqc.py` 파일을 직접 쓰고 ② 불러옵니다. 맨 위 `import` 문은 셀이 시작할 때 실행되는데 그때는 아직 `qaqc.py`가 없으므로, 파일을 만든 뒤에 `importlib.import_module("qaqc")`로 불러옵니다. `import qaqc`와 같은 일을 하는 함수입니다.

```run
import importlib

# ① 모듈 파일 만들기 (내 컴퓨터에서는 편집기로 qaqc.py를 저장하는 단계)
with open("qaqc.py", "w", encoding="utf-8") as f:
    f.write("def my_func(a, b):\n")
    f.write("    return a + b\n")
    f.write("\n")
    f.write("def defect_rate(defects, total):\n")
    f.write("    return round(defects / total * 100, 2)\n")

# ② 불러와서 쓰기 (import qaqc 와 같다)
qaqc = importlib.import_module("qaqc")
print(qaqc.my_func(1, 2))
print(qaqc.defect_rate(18, 1250), "%")
```

`3`과 `1.44 %`가 나옵니다. 불량률 계산처럼 여러 노트북에서 반복해 쓰는 함수를 모듈 하나에 모아 두면, 계산식을 고칠 때도 그 파일 한 곳만 고치면 됩니다.

### 정리

- **모듈** = `.py` 파일 하나, **패키지** = 모듈을 묶은 폴더, **라이브러리** = 이것들을 통틀어 부르는 말.
- **표준 라이브러리**(`math`, `datetime`, `random`, `os`, `csv`, `json`)는 설치 없이, **외부 라이브러리**(`numpy`, `pandas` …)는 `pip install`로 설치해서 쓴다.
- `import math` → `math.sqrt()`, `from math import sqrt` → `sqrt()`, `import numpy as np` → `np.array()`. `from 모듈 import *`는 피한다.
- `import` 문은 코드 맨 위에 모은다.
- 내 함수를 `.py` 파일에 저장하면 그 파일 이름으로 `import`할 수 있다. 같은 폴더에 있어야 찾는다.
