들어온 로트 코드가 규칙에 맞는지 확인하는 일을 생각해 봅시다. 공백을 지우고, 대문자로 맞추고, 자리별로 나누고, 각 자리가 규칙에 맞는지 봐야 합니다. 이걸 함수 하나에 다 넣으면 길고 어디가 틀렸는지 찾기 어렵습니다. 이 레슨에서는 **한 함수에 한 가지 일만** 맡기고, 작은 함수를 이어 붙여 문제를 푸는 방법을 연습합니다.

### 문제: 로트 코드 검증

로트 코드 규칙([슬라이싱으로 코드 해독하기](#/l/pb-02-3)와 같음)입니다.

| 자리 | 0~1 | 2~3 | 4 | 5~8 | 9 |
| --- | --- | --- | --- | --- | --- |
| 뜻 | 공장 | 연도 | 라인 | 월일 | 등급 |
| 규칙 | `KR` 또는 `VN` | 숫자 2개 | 영문 1개 | 숫자 4개 | `A`, `B`, `X` 중 하나 |

사람이 입력한 값은 `" kr24a0915x "`처럼 앞뒤 공백과 소문자가 섞여 들어옵니다. 할 일을 세 단계로 나눕니다.

1. **정리**(normalize): 공백 제거, 대문자로
2. **분해**(parse): 자리별로 잘라 딕셔너리로
3. **검증**(validate): 규칙에 맞으면 True

### 1단계: 정리 함수

```run
def normalize(code):
    """앞뒤 공백을 지우고 대문자로 맞춘다."""
    return code.strip().upper()

print(normalize(" kr24a0915x "))
```

`KR24A0915X`가 됩니다. 한 줄짜리지만 함수로 빼 두면 다른 곳(설비 코드, 불량 코드)에서도 그대로 씁니다.

### 2단계: 분해 함수

자리별로 잘라 이름을 붙여 딕셔너리로 돌려줍니다([딕셔너리로 기록 다루기](#/l/pb-06-2)의 "행 = 딕셔너리").

```run
def parse(code):
    """정리된 10자리 코드를 자리별로 나눈다."""
    return {
        "plant": code[0:2],
        "year": code[2:4],
        "line": code[4],
        "date": code[5:9],
        "grade": code[9],
    }

print(parse("KR24A0915X"))
```

### 3단계: 검증 함수

검증 함수는 **True나 False를 돌려주는 함수**입니다. 이름을 `is_...`로 지으면 돌려주는 값이 참·거짓이라는 것이 이름에서 보입니다. 규칙 하나라도 어기면 바로 `return False`로 끝내고, 끝까지 통과하면 `return True`입니다.

```run
def parse(code):
    return {"plant": code[0:2], "year": code[2:4], "line": code[4],
            "date": code[5:9], "grade": code[9]}

def is_valid(code):
    if len(code) != 10:
        return False
    p = parse(code)
    if p["plant"] not in ("KR", "VN"):
        return False
    if not (p["year"].isdigit() and p["date"].isdigit()):
        return False
    if not p["line"].isalpha():
        return False
    return p["grade"] in ("A", "B", "X")

print(is_valid("KR24A0915X"))
print(is_valid("JP24A0915X"))
print(is_valid("KR24A09X5X"))
```

True, False(공장), False(월일에 X)입니다. 길이 검사를 **맨 먼저** 한 이유는, 길이가 짧으면 `parse()`의 `code[9]`에서 IndexError가 나기 때문입니다. 위험한 일을 하기 전에 안전한 검사부터 합니다.

### 조합: 작은 함수를 이어 붙이기

이제 세 함수를 차례로 부르는 함수 하나로 묶습니다. 이 함수는 짧아서 무엇을 하는지 한눈에 보입니다.

```run
def normalize(code):
    return code.strip().upper()

def parse(code):
    return {"plant": code[0:2], "year": code[2:4], "line": code[4],
            "date": code[5:9], "grade": code[9]}

def is_valid(code):
    if len(code) != 10:
        return False
    p = parse(code)
    return (p["plant"] in ("KR", "VN") and p["year"].isdigit()
            and p["line"].isalpha() and p["date"].isdigit()
            and p["grade"] in ("A", "B", "X"))

def check(raw):
    code = normalize(raw)
    if not is_valid(code):
        return "형식 오류: " + raw.strip()
    p = parse(code)
    return f"{p['plant']} 공장 20{p['year']}년 {p['line']}라인 등급 {p['grade']}"

for raw in [" kr24a0915x ", "VN25C1201B", "KR24A0915"]:
    print(check(raw))
```

세 입력 중 마지막은 9자리라 형식 오류입니다. 괄호로 감싸면 긴 조건을 여러 줄에 걸쳐 쓸 수 있습니다.

### 예시 입력으로 확인하기

함수를 만들면 **기대값을 정해 두고** 실제 결과와 비교해 봅니다. 맞으면 True가 줄줄이 나옵니다. 정상 입력뿐 아니라 경계(9자리, 11자리)와 이상한 입력(빈 문자열)도 넣어 봅니다.

```run
def normalize(code):
    return code.strip().upper()

def is_valid(code):
    if len(code) != 10:
        return False
    return (code[0:2] in ("KR", "VN") and code[2:4].isdigit()
            and code[4].isalpha() and code[5:9].isdigit()
            and code[9] in ("A", "B", "X"))

cases = [("KR24A0915X", True), (" kr24a0915x ", True), ("KR24A0915", False),
         ("KR24A0915XX", False), ("", False), ("KR2BA0915X", False)]
for raw, want in cases:
    got = is_valid(normalize(raw))
    print(repr(raw), got == want)
```

모두 True면 함수가 예시 입력 범위에서는 규칙대로 동작한다는 뜻입니다. False가 나온 줄이 있으면 그 입력 하나만 따로 넣어 보면서 고칩니다. [알고리즘 (함수형)](#/l/pb-09-1) 이후의 함수 문제도 이렇게 직접 몇 개 넣어 본 뒤 제출하면 실수가 크게 줄어듭니다.

### 정리

- 함수 하나 = 일 하나. 이름이 그 일을 말하게 짓는다(`normalize`, `parse`, `is_valid`).
- 참·거짓을 돌려주는 함수는 `is_...`로 짓고, 규칙을 어기면 바로 `return False`.
- 위험한 일(인덱싱) 전에 안전한 검사(길이)부터.
- 만든 함수는 **기대값과 비교하는 예시 입력**으로 확인한다.
