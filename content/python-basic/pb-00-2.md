Colab 파일은 **노트북**(`.ipynb`)이라고 부릅니다. 노트북은 **셀**이라는 칸을 위에서 아래로 쌓은 문서입니다. 셀은 두 종류입니다.

- **코드 셀**: 파이썬 코드를 쓰고 실행하는 칸. 결과가 셀 바로 아래에 나옵니다.
- **텍스트 셀**: 설명을 적는 메모 칸. 실행되지 않습니다.

## 따라 하기

### 1단계. 접속하고 로그인하기

1. 브라우저 주소창에 [colab.research.google.com](https://colab.research.google.com/) 을 입력하거나 링크를 누릅니다.
2. 오른쪽 위 **로그인** 버튼으로 구글 계정에 로그인합니다. 이미 로그인되어 있으면 이 단계는 넘어갑니다.
3. "노트 열기" 창이 뜨면 왼쪽 아래 **+ 새 노트**를 누릅니다. 창이 안 뜨면 메뉴에서 **파일 → 새 노트**를 누릅니다.

### 2단계. 이름 바꾸기 (①)

왼쪽 위 `Untitled0.ipynb` 글자를 클릭하면 이름을 바꿀 수 있습니다. 예를 들어 `day01_hello.ipynb` 처럼 영문과 숫자로 짓는 습관을 들이세요.

### 3단계. 첫 코드 실행하기 (③)

빈 코드 셀을 클릭하고 아래 코드를 그대로 입력합니다.

```
print("Hello, Colab!")
```

셀 왼쪽의 **▶ 버튼**을 누르거나, 키보드로 **Shift + Enter**를 누르면 실행됩니다. 처음 실행할 때는 구글 서버에 연결하느라 5~10초 걸리고, 오른쪽 위에 **연결됨**(초록 체크)이 표시됩니다. 셀 아래에 `Hello, Colab!` 이 나오면 성공입니다.

### 4단계. 셀 추가하기 (②)

위쪽 **+ 코드** 버튼을 누르면 아래에 새 코드 셀이 생깁니다. 셀 하나에 한 가지 일만 시키고, 결과를 확인하며 다음 셀로 넘어가는 것이 노트북을 쓰는 기본 방식입니다.

| 키 | 하는 일 |
| --- | --- |
| `Shift + Enter` | 지금 셀 실행하고 다음 셀로 이동 |
| `Ctrl + Enter` (macOS `Cmd + Enter`) | 지금 셀만 실행하고 그 자리에 머무름 |
| `Ctrl + M` 다음 `B` (macOS `Cmd + M` 다음 `B`) | 아래에 새 코드 셀 추가 |

### 5단계. 내 데이터 파일 올리기 (④)

1. 왼쪽 세로 막대의 **폴더 아이콘**을 누르면 파일 패널이 열립니다.
2. 패널 위쪽 **업로드 아이콘**(위쪽 화살표가 있는 종이)을 누르고 CSV 파일을 고릅니다.
3. 올린 파일은 코드에서 이름만으로 읽을 수 있습니다.

```
import pandas as pd
df = pd.read_csv("sales.csv")
df.head()
```

> 주의: 이렇게 올린 파일은 **연결이 끊기면 사라지는 임시 파일**입니다. 계속 쓸 파일은 다음 단계처럼 구글 드라이브에 두세요.

### 6단계. 구글 드라이브 연결하기

드라이브에 있는 파일을 읽고, 결과 파일을 드라이브에 저장하려면 아래 코드를 실행합니다. 권한 허용 창이 뜨면 내 계정을 고르고 **허용**을 누릅니다.

```
from google.colab import drive
drive.mount("/content/drive")
```

연결되면 내 드라이브는 `/content/drive/MyDrive/` 아래에 보입니다.

```
df = pd.read_csv("/content/drive/MyDrive/data/sales.csv")
```

### 7단계. 저장 위치 확인하기

노트북은 자동으로 내 구글 드라이브의 **Colab Notebooks** 폴더에 저장됩니다. 메뉴 **파일 → 다운로드 → .ipynb 다운로드**로 내 PC에 받아 둘 수도 있습니다.

## 자주 막히는 문제와 해결법

| 증상 | 원인 | 해결 |
| --- | --- | --- |
| Colab 페이지가 안 열리거나 "관리자가 차단" 메시지 | 회사·학교 계정이나 네트워크에서 Colab을 막아 둠 | 개인 Gmail 계정으로 로그인해 보고, 그래도 안 되면 다른 설치 방법을 쓰거나 담당자에게 문의 |
| 한동안 안 쓰다 오니 변수가 다 사라지고 `NameError` | 일정 시간 사용하지 않으면 런타임(구글 서버) 연결이 끊김 | 메뉴 **런타임 → 모두 실행**(⑤)으로 위에서부터 다시 실행 |
| 올렸던 CSV 파일이 없어짐 | 업로드 파일은 연결이 끊기면 지워지는 임시 파일 | 파일을 구글 드라이브에 두고 6단계처럼 연결해서 읽기 |
| `ModuleNotFoundError: No module named ...` | Colab에 기본으로 없는 패키지 | 셀에 `!pip install 패키지이름` 을 실행한 뒤 다시 import (앞의 `!`는 터미널 명령이라는 뜻) |
| 그래프의 한글이 네모(□□)로 나옴 | Colab 서버에 한글 글꼴이 없음 | 수업에서는 그래프 제목·축 이름을 영어로 쓰기. 한글이 꼭 필요하면 한글 글꼴 패키지를 설치하는 방법을 검색 |
| 실행 버튼을 눌러도 계속 빙글빙글 돎 | 앞 셀이 아직 실행 중이거나 무한 반복 | 셀 왼쪽 ■(중지) 버튼을 누르고 코드를 확인 |
