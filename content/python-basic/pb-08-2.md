[solution 함수로 문자열 처리하기](#/l/pb-08-1)에서 함수가 값을 받아 `return`으로 돌려주는 기계라는 것을 봤습니다. 그때 함수는 값을 **하나** 받아 **하나** 돌려줬습니다. 실제로 쓸 함수는 규격 하한·상한처럼 값을 여러 개 받고, 평균과 범위처럼 여러 개를 돌려주고, 자주 쓰는 값은 기본으로 정해 둡니다. 이 레슨에서는 함수를 **쓰기 편하게** 만드는 문법을 익힙니다.

### 매개변수 여러 개

괄호 안에 매개변수를 쉼표로 나열합니다. 호출할 때 넣은 값이 **순서대로** 담깁니다.

```run
def judge(value, low, high):
    if low <= value <= high:
        return "합격"
    return "불합격"

print(judge(10.2, 9.5, 10.5))
print(judge(10.8, 9.5, 10.5))
```

합격, 불합격입니다. 첫 번째 `return`을 만나면 함수가 바로 끝나므로 `else`가 없어도 됩니다.

### 기본값: 생략하면 이 값으로

대부분의 제품 규격이 9.5~10.5라면, 매번 쓰지 않도록 **기본값**을 정해 둡니다. `매개변수=값` 모양입니다.

```run
def judge(value, low=9.5, high=10.5):
    if low <= value <= high:
        return "합격"
    return "불합격"

print(judge(10.2))               # 기본 규격
print(judge(10.2, 9.8, 10.1))    # 다른 규격
```

규격을 생략하면 기본값으로 합격, 직접 넣으면 그 값으로 불합격입니다. 기본값이 있는 매개변수는 **없는 것보다 뒤에** 둬야 합니다. `def judge(low=9.5, value):`는 SyntaxError입니다.

### 키워드 인자: 이름을 붙여 넣기

호출할 때 `이름=값`으로 넣으면 순서를 외우지 않아도 되고, 원하는 것만 바꿀 수 있습니다.

```run
def judge(value, low=9.5, high=10.5):
    if low <= value <= high:
        return "합격"
    return "불합격"

print(judge(10.6, high=11.0))     # 상한만 바꾸기
print(judge(high=11.0, value=10.6, low=10.0))
```

둘 다 합격입니다. 숫자가 여러 개 나란히 있는 호출(`judge(10.6, 9.5, 11.0)`)보다 `high=11.0`이 무엇을 바꿨는지 훨씬 잘 보입니다.

### 여러 값을 돌려주기

`return` 뒤에 값을 쉼표로 늘어놓으면 **튜플 하나**로 묶여 돌아옵니다. 받는 쪽에서 언패킹([튜플과 언패킹](#/l/pb-04-2))으로 나눕니다.

```run
def summary(values):
    mean = sum(values) / len(values)
    spread = max(values) - min(values)
    return mean, spread

result = summary([10.1, 9.2, 10.4, 10.8, 9.9])
print(result)
m, r = summary([10.1, 9.2, 10.4, 10.8, 9.9])
print(f"평균 {m:.2f}, 범위 {r:.2f}")
```

`result`에는 `(평균, 범위)` 튜플이 담깁니다. 범위가 `1.6000000000000014`처럼 보이는 것은 [숫자 계산 자세히: 우선순위 · 누적 · 반올림](#/l/pb-01-2)에서 본 소수 오차입니다. 언패킹해서 각각 받은 뒤 f-string으로 자리수를 정하면 평균 10.08, 범위 1.60으로 깔끔하게 나옵니다.

### return이 없으면 None

`return`이 없거나 `return`만 쓰면 함수는 `None`을 돌려줍니다. 화면에 보여 주는 일만 하는 함수라면 괜찮지만, 결과를 받아 쓰려는 함수라면 실수입니다.

```run
def report(lot, rate):
    print(f"{lot}: {rate:.2%}")

x = report("A0915", 0.0144)
print(x)
```

출력은 `A0915: 1.44%` 다음에 `None`입니다.

### 함수 설명 한 줄: docstring

함수 첫 줄에 따옴표 세 개로 쓴 문자열은 **함수 설명(docstring)**이 됩니다. 무엇을 받아 무엇을 돌려주는지 적어 두면 나중에 읽는 사람(미래의 나)이 편합니다.

```run
def defect_rate(defects, qty):
    """불량 수와 검사 수를 받아 불량률(0~1)을 돌려준다."""
    return defects / qty

print(defect_rate(18, 1250))
print(defect_rate.__doc__)
```

```run
def judge(value, low=9.5, high=10.5):
    if low <= value <= high:
        return "합격"
    return "불합격"

print(judge(9.5), judge(10.5), judge(10.51))   # 경계값을 바꿔 보세요
```

### 자주 하는 실수

| 실수 | 결과 | 고치기 |
| --- | --- | --- |
| 기본값 매개변수를 앞에 | SyntaxError | 기본값 없는 매개변수를 먼저 |
| 넣는 값 개수가 다름 | TypeError: missing 1 required positional argument | 매개변수 수 확인 |
| `return`을 빠뜨림 | 결과가 None | 돌려줄 값을 `return` |
| 여러 값을 받을 변수 개수가 다름 | ValueError (언패킹) | `return` 개수와 맞추기 |
