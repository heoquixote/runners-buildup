함수 문법을 익혔으니 이제 **문제를 푸는 패턴**을 연습합니다. 코딩 테스트 문제도, 실무의 데이터 처리도 대부분 세기, 찾기, 집계하기의 조합입니다.

### solution 함수 문제

프로그래머스처럼 `solution` 함수를 완성하는 문제입니다. 채점기가 여러 입력으로 함수를 호출하고 **반환값**을 비교합니다.

::video{ref="dl-m16"}

### print가 아니라 return

값을 화면에 출력(`print`)하면 채점기는 받을 수 없습니다. 결과는 반드시 `return`으로 돌려주세요. 자세한 차이는 pb-08에서 다뤘습니다.

### 함수 안의 변수는 함수 안에서만 삽니다

함수 안에서 만든 변수는 **지역 변수**입니다. 함수가 끝나면 사라지기 때문에 밖에서 쓰려면 `return`으로 내보내야 합니다.

```run
def count_ng(values):
    ng = 0                    # 지역 변수: 함수 안에서만 존재
    for v in values:
        if v == "NG":
            ng += 1
    return ng                 # 밖으로 전달

result = count_ng(["OK", "NG", "NG", "OK"])
print(result)
# print(ng) 를 여기서 쓰면 NameError 가 납니다
```

### 패턴 1: 세기

시작값 0을 만들고, 조건에 맞을 때마다 1을 더합니다.

```run
def solution(temps, limit):
    count = 0
    for t in temps:
        if t > limit:
            count += 1
    return count

print(solution([23.1, 25.4, 26.0, 22.8], 25))
```

### 패턴 2: 최댓값과 위치 찾기

값만 필요하면 `max()`, `min()`으로 충분합니다. **몇 번째인지**도 알아야 하면 `enumerate`가 번호와 값을 함께 꺼내 줍니다.

```run
values = [3, 11, 5]
best, cur = 7, 9
print(min(values), max(best, cur))     # 3 9

for i, v in enumerate(values):
    print(i, v)                        # 인덱스와 값을 함께

def worst_position(defects):
    best_i = 0
    for i, d in enumerate(defects):
        if d > defects[best_i]:        # 지금까지의 최대보다 크면 위치를 바꾼다
            best_i = i
    return best_i

print(worst_position([3, 11, 5, 11]))
```

불량이 11인 곳이 두 군데지만 `>`는 같은 값에서 바꾸지 않으므로 **먼저 나온 1번**을 돌려줍니다. 마지막 위치가 필요하면 `>=`로 바꾸면 됩니다.

### 패턴 3: 조건에 맞는 것만 모으기

빈 리스트에 `append`로 담거나, pb-11에서 배울 리스트 컴프리헨션으로 한 줄에 씁니다.

```run
codes = ["KR24A091", "KR24A0", "KR24B112"]

bad = []
for c in codes:
    if len(c) != 8:
        bad.append(c)
print(bad)

print([c for c in codes if len(c) != 8])   # 조건에 맞는 것만 모으기
```

### 패턴 4: 딕셔너리로 집계하기

"라인별 불량 수"처럼 **이름별로 묶어 세려면** 딕셔너리를 씁니다. 처음 보는 키는 없으므로 `get(키, 0)`으로 기본값을 줍니다.

```run
def count_by_line(records):
    result = {}
    for line, defect in records:
        result[line] = result.get(line, 0) + defect
    return result

data = [("A", 3), ("B", 1), ("A", 2), ("C", 4), ("B", 5)]
print(count_by_line(data))
```

A는 3 + 2 = 5, B는 1 + 5 = 6, C는 4입니다. 이 집계 방식은 pandas의 `groupby`가 하는 일과 같습니다. 데이터 분석 트랙의 da-06에서 다시 만납니다.

### 패턴을 조합하기

딕셔너리로 집계한 뒤 가장 큰 키를 찾아 봅니다. `max`의 `key`에 `dict.get`을 넣으면 값이 가장 큰 키를 돌려줍니다.

```run
def worst_line(records):
    totals = {}
    for line, defect in records:
        totals[line] = totals.get(line, 0) + defect
    return max(totals, key=totals.get)

print(worst_line([("A", 3), ("B", 1), ("A", 2), ("C", 4), ("B", 5)]))
```

### 문제를 받으면 이렇게 고릅니다

| 문제에 나오는 말 | 먼저 떠올릴 패턴 |
| --- | --- |
| 몇 개, 몇 번 | 세기 (`count += 1`) |
| 가장 큰, 가장 작은, 몇 번째 | `max`, `min`, `enumerate` |
| ~인 것만, 걸러서 | 빈 리스트 + `append` |
| ~별로, 종류마다 | 딕셔너리 + `get` |

### 자주 하는 실수

- 값이 하나도 없는 빈 리스트가 들어오면 `max([])`는 에러가 납니다. 문제의 입력 조건을 먼저 읽으세요.
- `return`을 `for` 안에 쓰면 첫 회차에서 함수가 끝납니다. 결과는 반복이 끝난 뒤에 돌려줍니다.
- 시작값 `count = 0`을 `for` 안에 쓰면 매번 초기화됩니다.
