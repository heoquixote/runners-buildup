반복문이 헷갈리는 이유는 코드는 몇 줄인데 **실행은 여러 번** 되기 때문입니다. 눈으로 코드만 보면 지금 몇 번째 회차인지, 변수에 무엇이 들어 있는지 알 수 없습니다. 이 레슨에서는 반복을 **추적표**로 한 회차씩 따라가는 법을 익히고, `while`, `break`, `continue`가 흐름을 어떻게 바꾸는지 봅니다.

### 추적표: 회차마다 변수 값을 적습니다

재고 100개에서 하루 30개씩 출고할 때 며칠 만에 바닥나는지 계산하는 코드입니다.

```run
stock = 100
day = 0
while stock > 0:
    stock -= 30
    day += 1
    print(day, stock)
```

출력을 표로 옮기면 다음과 같습니다. `while`은 **반복을 시작하기 전에 매번** 조건을 검사합니다.

| 검사 시점 stock | `stock > 0` | 실행 후 stock | 실행 후 day |
| --- | --- | --- | --- |
| 100 | True | 70 | 1 |
| 70 | True | 40 | 2 |
| 40 | True | 10 | 3 |
| 10 | True | -20 | 4 |
| -20 | **False** → 끝 | | |

stock이 10일 때 조건이 아직 참이라 한 번 더 돌아서 -20이 됩니다. 결과가 이상하면 이렇게 **반복 안에 print를 넣어 추적표를 만들어 보는 것**이 가장 빠른 디버깅입니다.

### 경계값이 결과를 바꿉니다

"재고가 30개 이상일 때만 출고"라면 조건이 달라집니다.

```run
stock = 100            # 90, 120 으로 바꿔 보세요
day = 0
while stock >= 30:
    stock -= 30
    day += 1
print(day, "일 출고, 남은 재고", stock)
```

3일 출고하고 10개가 남습니다. `> 0`과 `>= 30` 중 무엇이 맞는지는 코드가 아니라 **업무 규칙**이 정합니다.

### break: 찾으면 바로 멈춘다

"첫 번째 불량이 몇 번째에서 나왔나"는 찾는 순간 더 볼 필요가 없습니다. `break`는 반복을 **즉시 끝냅니다.**

```run
sizes = [10.1, 10.3, 9.2, 10.0, 10.8]
found = -1                 # 못 찾으면 -1 로 남는다
for i, s in enumerate(sizes):
    print("검사", i, s)
    if s < 9.5 or s > 10.5:
        found = i
        break
print("첫 불량 위치:", found)
```

검사 출력은 0, 1, 2번까지만 나옵니다. 2번(9.2)에서 `break`로 빠져나왔기 때문에 10.8은 검사하지 않았습니다. `found = -1`처럼 **못 찾았을 때의 값을 먼저 정해 두는 것**이 이 패턴의 핵심입니다.

### continue: 이번 회차만 건너뛴다

`continue`는 반복을 끝내지 않고, **이번 회차의 남은 줄만 건너뛰고** 다음 회차로 갑니다. 결측값을 빼고 평균을 낼 때 씁니다.

```run
raw = [23.1, None, 23.4, None, 22.8]
total = 0
count = 0
for v in raw:
    if v is None:
        continue           # 아래 두 줄을 건너뛰고 다음 값으로
    total += v
    count += 1
print(count, round(total / count, 2))
```

`None`은 "값이 없음"을 뜻하는 특별한 값입니다. 5개 중 3개로 평균 23.1이 나옵니다. 결측을 0으로 넣고 5로 나눴다면 13.86이라는 엉뚱한 평균이 됐을 것입니다.

| 키워드 | 하는 일 | 다음에 실행되는 곳 |
| --- | --- | --- |
| `break` | 반복 전체를 끝냄 | 반복문 **다음 줄** |
| `continue` | 이번 회차만 끝냄 | 반복의 **다음 회차 첫 줄** |

### 상태 변수: 연속 불량 세기

"불량이 3번 **연속**으로 나오면 라인 정지" 같은 규칙은 회차를 넘어 기억할 값이 필요합니다. 이런 변수를 **상태 변수**라고 합니다.

```run
results = ["P", "F", "F", "P", "F", "F", "F", "P"]
streak = 0
for i, r in enumerate(results):
    if r == "F":
        streak += 1
    else:
        streak = 0         # 합격이 나오면 연속 기록 초기화
    if streak == 3:
        print(i, "번째에서 3연속 불량, 라인 정지")
        break
```

| i | r | streak |
| --- | --- | --- |
| 0 | P | 0 |
| 1 | F | 1 |
| 2 | F | 2 |
| 3 | P | 0 |
| 4 | F | 1 |
| 5 | F | 2 |
| 6 | F | **3** → break |

1~2번의 불량 두 번은 3번의 합격으로 초기화돼서 정지 조건이 되지 않았습니다. 추적표를 그려 보면 `streak = 0`이 왜 필요한지 바로 보입니다.

### 끝나지 않는 반복 막기

`while` 안에서 조건에 쓰인 변수가 바뀌지 않으면 반복이 끝나지 않습니다. 횟수 상한을 같이 두면 안전합니다.

```run
value = 1.0
tries = 0
while value < 100 and tries < 10:    # 최대 10번
    value *= 1.8
    tries += 1
print(tries, round(value, 1))
```

8번 만에 100을 넘었습니다. 상한 10은 혹시 계산이 잘못돼 값이 커지지 않을 때 반복을 멈춰 주는 안전장치입니다.

### 정리

- 반복이 헷갈리면 **안에 print를 넣어 추적표**를 만든다.
- `while`은 매 회차 **시작 전에** 조건을 검사한다.
- 찾으면 멈출 때 `break`, 건너뛸 때 `continue`.
- 회차를 넘어 기억할 값은 반복 **밖에서** 시작값을 주고, 안에서 바꾼다.
