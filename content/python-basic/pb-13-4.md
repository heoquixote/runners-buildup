### 시작하기 전에

[파일을 열고 CSV · JSON 읽기](#/l/pb-10-1)에서 `open()`으로 파일을 만들고 읽었습니다. 그런데 실무에서는 파일이 한 폴더에 한두 개만 있지 않습니다. 설비는 날마다 `logs/20261107/` 같은 **날짜별 폴더**에 로그를 쌓고, 우리는 "이 폴더가 있나?", "안에 파일이 몇 개지?", "없으면 만들어야지"를 코드로 처리해야 합니다. 이 일을 맡는 모듈이 `os`(Operating System, 운영체제)입니다. 마지막에는 이번 코스에서 배운 `datetime`, `random`, `os`와 `csv`를 엮어 **날짜별 검사 로그 파일**을 만듭니다.

### 폴더는 서랍, 경로는 주소

컴퓨터의 파일은 폴더 안에, 폴더는 또 다른 폴더 안에 들어 있습니다. 서랍장 속 서랍, 그 속의 칸과 같습니다. 파일이 어디 있는지 적은 **주소**를 **경로(path)**라고 합니다.

::figure{src="content/img/py/py-os-paths.svg" alt="왼쪽 폴더 나무: 맨 꼭대기 / 아래 tmp, 그 아래 rb-a1b2c3(지금 위치, 작업 폴더), 그 아래 logs, 20261107, inspection.csv가 있다. 오른쪽 위 상대 경로 logs/20261107/inspection.csv는 지금 위치에서 출발해 짧지만 작업 폴더가 바뀌면 가리키는 곳도 바뀐다. 오른쪽 아래 절대 경로 /tmp/rb-a1b2c3/logs/20261107/inspection.csv는 맨 꼭대기에서 출발해 어디서 실행해도 같은 곳이다" caption="상대 경로는 '지금 위치에서 몇 번째 서랍', 절대 경로는 '맨 꼭대기부터 전체 주소'입니다."}

- **작업 폴더(현재 위치)**: 코드가 지금 서 있는 폴더. `open("a.csv")`처럼 이름만 쓰면 이 폴더에서 찾습니다.
- **상대 경로**: 작업 폴더에서 출발하는 주소. `logs/20261107/inspection.csv`
- **절대 경로**: 맨 꼭대기부터 적은 전체 주소. Windows는 `C:\Users\...`, Mac · 리눅스는 `/Users/...`처럼 시작합니다.

### 이 사이트의 연습 폴더

이 사이트의 파이썬은 내 컴퓨터가 아니라 **브라우저 안의 작은 가상 컴퓨터**에서 돌아갑니다. 실행 셀을 누를 때마다 `/tmp/rb-…`라는 **빈 연습 폴더**가 새로 생기고, 실행이 끝나면 지워집니다. 그래서

- 내 컴퓨터의 파일은 보이지 않고, 여기서 만든 파일도 내 컴퓨터에 저장되지 않습니다.
- 앞 셀에서 만든 파일은 다음 셀에 남아 있지 않습니다. 아래 예제가 셀마다 파일을 새로 만들고 시작하는 이유입니다.

### 지금 위치와 폴더 목록: getcwd, listdir

`os.getcwd()`(get current working directory)는 작업 폴더의 절대 경로를, `os.listdir(경로)`는 그 폴더 안의 항목 이름을 리스트로 돌려줍니다. `"."`은 "지금 폴더"라는 뜻입니다.

```run
import os

print(os.getcwd())          # 지금 위치
print(os.listdir("."))      # 빈 연습 폴더라서 []

open("a.csv", "w").close()  # 빈 파일 하나를 만들고
os.mkdir("logs")            # 폴더 하나도 만든 뒤
print(os.listdir("."))      # 다시 보기
```

처음엔 빈 리스트 `[]`, 파일과 폴더를 만든 뒤에는 `['a.csv', 'logs']`(순서는 다를 수 있음)가 나옵니다. 내 컴퓨터의 Jupyter에서 실행하면 노트북 파일이 있는 폴더가 나옵니다.

### 경로 이어 붙이기: os.path.join

경로의 구분 기호는 운영체제마다 다릅니다. Windows는 `\`, Mac · 리눅스는 `/`입니다. 문자열을 `+`로 붙이면 다른 컴퓨터에서 틀어질 수 있으니 `os.path.join`에 맡깁니다. 실행 중인 운영체제에 맞는 기호로 이어 줍니다.

```run
import os

p = os.path.join("logs", "20261107", "inspection.csv")
print(p)
```

여기서는 `logs/20261107/inspection.csv`가 나오고, Windows에서 실행하면 `logs\20261107\inspection.csv`가 나옵니다. 코드는 그대로 두고 어디서든 맞는 경로가 됩니다.

### 있는지 확인하기: exists, isfile, isdir

파일을 열거나 폴더를 만들기 전에 **먼저 확인**하면 에러를 미리 막을 수 있습니다.

```run
import os

open("winner.txt", "w").close()
os.mkdir("logs")

print(os.path.exists("winner.txt"))   # 있나? (파일이든 폴더든)
print(os.path.exists("nothing.txt"))  # 없는 파일
print(os.path.isfile("winner.txt"), os.path.isdir("winner.txt"))  # 파일인가, 폴더인가
print(os.path.isdir("logs"))
```

`True`, `False`, `True False`, `True`입니다. `exists`는 있는지만, `isfile` · `isdir`은 종류까지 봅니다.

### 경로 쪼개기: abspath, dirname, basename, splitext

경로 문자열에서 필요한 부분만 꺼낼 때 씁니다.

```run
import os

p = os.path.join("logs", "20261107", "inspection.csv")
print(os.path.abspath(p))      # 절대 경로로 (작업 폴더 + p)
print(os.path.dirname(p))      # 파일이 든 폴더 부분
print(os.path.basename(p))     # 맨 끝 이름 (파일 이름)
print(os.path.splitext(p))     # (확장자 앞, 확장자) 튜플
```

`dirname`은 `logs/20261107`, `basename`은 `inspection.csv`, `splitext`는 `('logs/20261107/inspection', '.csv')`입니다. 파일이 실제로 없어도 됩니다. 이 함수들은 **문자열만 다루기** 때문입니다. "확장자가 `.csv`인 파일만 고르기"는 `splitext(이름)[1] == ".csv"`로 합니다.

### 폴더 만들기: makedirs와 exist_ok

`os.makedirs(경로)`는 중간 폴더까지 한 번에 만듭니다. `logs`가 없어도 `logs/20261107`을 바로 만들 수 있습니다.

```run
import os

os.makedirs(os.path.join("logs", "20261107"), exist_ok=True)
os.makedirs(os.path.join("logs", "20261107"), exist_ok=True)   # 두 번째: 이미 있어도 OK
print(os.listdir("logs"))
```

두 번 실행해도 에러가 나지 않습니다. `exist_ok=True`를 빼면 두 번째 줄에서 이렇게 멈춥니다.

```python
os.makedirs("logs")
os.makedirs("logs")   # 이미 있는 폴더를 또 만들려고 함
```

```
FileExistsError: [Errno 17] File exists: 'logs'
```

매일 도는 자동화 코드는 "오늘 폴더가 이미 있는" 날도 있으므로, 폴더를 만드는 줄에는 **거의 항상 `exist_ok=True`**를 붙입니다.

### 이름 바꾸기와 폴더 전체 훑기: rename, walk

`os.rename(옛 이름, 새 이름)`은 파일 · 폴더 이름을 바꿉니다. `os.walk(폴더)`는 그 폴더와 **모든 하위 폴더**를 차례로 돌며 `(폴더 경로, 하위 폴더 목록, 파일 목록)`을 하나씩 줍니다.

```run
import os

os.makedirs(os.path.join("logs", "nested"), exist_ok=True)
open(os.path.join("logs", "a.txt"), "w").close()
open(os.path.join("logs", "nested", "b.txt"), "w").close()

os.rename("logs", "logs_backup")             # 폴더 이름 바꾸기
for folder, subdirs, files in os.walk("logs_backup"):
    print(folder, subdirs, files)
```

`logs_backup` 안에 `nested` 폴더와 `a.txt`, `logs_backup/nested` 안에 `b.txt`가 보입니다. 날짜별 폴더가 수십 개 쌓인 로그 폴더에서 **CSV 파일을 전부 찾아 모을 때** `os.walk`를 씁니다.

:::tip 알아 두면 좋아요 · os.name과 환경 변수
`os.name`은 운영체제 종류, `os.environ`은 **환경 변수**(운영체제가 프로그램에게 알려 주는 설정값)입니다.

```run
import os

print(os.name)                    # 'posix'(Mac · 리눅스) 또는 'nt'(Windows)
print(os.environ.get("HOME"))     # 사용자 폴더
print(os.environ.get("PATH"))     # 프로그램을 찾는 폴더 목록
```

이 사이트는 브라우저 안의 가상 컴퓨터라서 내 컴퓨터가 Windows여도 `posix`가 나오고, `PATH`도 `/` 하나뿐입니다. 내 컴퓨터의 Jupyter에서 실행하면 Windows는 `nt`, `PATH`에는 긴 폴더 목록이 나옵니다. 실무에서는 비밀번호 · API 키를 코드에 직접 쓰지 않고 환경 변수에 넣어 `os.environ.get("API_KEY")`로 읽습니다.
:::

### 종합 예제: 날짜별 검사 로그 파일 만들기

이번 코스에서 배운 `datetime`, `random`, `os`와 [CSV 파일 읽고 쓰기](#/l/pb-10-2)의 `csv`를 한 번에 엮어 봅니다. 설비가 날짜별 폴더에 검사 로그를 쌓는 상황을 재현합니다.

**요구사항**

1. `logs/오늘날짜(YYYYMMDD)` 폴더를 만든다. 이미 있어도 에러가 나면 안 된다.
2. 오늘 09:00부터 10분 간격으로 검사 시각 5개를 만든다.
3. 시각마다 온도를 23.0~27.0 사이 난수(소수점 1자리)로 만들고, 25.0 초과면 `NG`, 아니면 `OK`로 판정한다. seed는 42.
4. `inspection.csv`로 저장하고 파일이 생겼는지 확인한다.

```run
import os
import random
import csv
from datetime import datetime, timedelta

random.seed(42)

# 1. 날짜 폴더 만들기
today = datetime.now().strftime("%Y%m%d")
folder = os.path.join("logs", today)
os.makedirs(folder, exist_ok=True)

# 2~3. 검사 시각, 온도, 판정
start = datetime.now().replace(hour=9, minute=0, second=0, microsecond=0)
rows = []
for i in range(5):
    ts = start + timedelta(minutes=10 * i)
    temp = round(random.uniform(23.0, 27.0), 1)
    result = "NG" if temp > 25.0 else "OK"
    rows.append([ts.strftime("%Y-%m-%d %H:%M"), temp, result])

# 4. CSV 저장
path = os.path.join(folder, "inspection.csv")
with open(path, "w", newline="", encoding="utf-8") as f:
    writer = csv.writer(f)
    writer.writerow(["time", "temp", "result"])
    writer.writerows(rows)

print(path, os.path.exists(path))
for r in rows:
    print(r)
```

날짜는 실행한 날로 바뀌지만, seed를 42로 고정했으므로 온도와 판정은 언제 실행해도 같습니다.

```
logs/20261107/inspection.csv True
['2026-11-07 09:00', 25.6, 'NG']
['2026-11-07 09:10', 23.1, 'OK']
['2026-11-07 09:20', 24.1, 'OK']
['2026-11-07 09:30', 23.9, 'OK']
['2026-11-07 09:40', 25.9, 'NG']
```

코드를 단계별로 다시 보면 다음과 같습니다.

| 단계 | 쓴 도구 | 배운 레슨 |
| --- | --- | --- |
| 오늘 날짜로 폴더 이름 | `datetime.now().strftime("%Y%m%d")` | [datetime](#/l/pb-13-2) |
| 폴더 만들기(있어도 OK) | `os.makedirs(..., exist_ok=True)` | 이번 레슨 |
| 09:00 기준 10분 간격 | `replace(hour=9, …)` + `timedelta(minutes=10 * i)` | [datetime](#/l/pb-13-2) |
| 같은 결과가 나오는 온도 | `random.seed(42)`, `random.uniform` | [math와 random](#/l/pb-13-3) |
| 경로 만들고 저장 확인 | `os.path.join`, `os.path.exists` | 이번 레슨 |
| CSV 저장 | `csv.writer`, `newline=""` | [CSV 파일 읽고 쓰기](#/l/pb-10-2) |

내 컴퓨터에서 이 코드를 매일 실행하면 `logs/` 아래에 날짜 폴더가 하나씩 쌓입니다. 연습문제에서는 날짜를 고정해 같은 일을 직접 짜 봅니다.

:::tip 알아 두면 좋아요 · pathlib
요즘 코드에서는 `os.path` 대신 `pathlib.Path`도 많이 씁니다. 경로를 문자열이 아니라 **객체**로 다루고, `/` 기호로 이어 붙입니다.

```run
from pathlib import Path

p = Path("logs") / "20261107" / "inspection.csv"
p.parent.mkdir(parents=True, exist_ok=True)    # os.makedirs와 같다
p.write_text("time,temp,result\n", encoding="utf-8")
print(p, p.exists(), p.name, p.suffix)
```

하는 일은 같으므로 둘 중 편한 쪽을 쓰면 됩니다. 남의 코드에서 두 모양을 모두 만나게 되니 둘 다 읽을 줄 알면 충분합니다.
:::

### 정리

- **작업 폴더**는 코드가 서 있는 위치. 상대 경로는 여기서 출발, 절대 경로는 맨 꼭대기에서 출발한다.
- 이 사이트는 셀마다 빈 연습 폴더에서 실행되고 끝나면 지워진다.
- `os.getcwd()` 지금 위치, `os.listdir()` 목록, `os.path.join()` 경로 잇기(운영체제에 맞는 기호).
- `os.path.exists` · `isfile` · `isdir`로 먼저 확인하고, `dirname` · `basename` · `splitext`로 경로를 쪼갠다.
- `os.makedirs(경로, exist_ok=True)`는 중간 폴더까지, 이미 있어도 에러 없이 만든다.
- `os.rename`으로 이름을 바꾸고, `os.walk`로 하위 폴더까지 전부 훑는다.
