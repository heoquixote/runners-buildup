### 딕셔너리: 이름(key)으로 값을 찾는 자료형

**딕셔너리**는 중괄호 `{ }` 안에 `키: 값` 쌍을 담습니다. 리스트가 번호로 찾는다면, 딕셔너리는 **이름(키)으로** 찾습니다.

```run
eqp = {"id": "EQ-07", "line": "L2", "temp": 180}
print(eqp["line"])
```

**없는 키**에 값을 대입하면 새 쌍이 **추가**됩니다.

```run
eqp = {"id": "EQ-07", "temp": 180}
eqp["status"] = "RUN"
print(eqp)
```

**있는 키**에 대입하면 값이 **수정**됩니다.

```run
eqp = {"id": "EQ-07", "temp": 180}
eqp["temp"] = 185
print(eqp)
```

`del`로 키와 값을 함께 **삭제**합니다.

```run
eqp = {"id": "EQ-07", "line": "L2"}
del eqp["line"]
print(eqp)
```

리스트처럼 `eqp[0]`으로는 꺼낼 수 없습니다. 반드시 키로 접근합니다.

### 한꺼번에 보기

`keys()`는 **키 목록**, `values()`는 **값 목록**을 보여 줍니다.

```run
eqp = {"id": "EQ-07", "temp": 185, "status": "RUN"}
print(eqp.keys())
print(eqp.values())
```

`items()`는 **(키, 값) 쌍**을 보여 줍니다. 반복문에서 키와 값을 함께 꺼낼 때 씁니다.

```run
eqp = {"id": "EQ-07", "temp": 185, "status": "RUN"}
print(list(eqp.items()))
```

`keys()`의 결과는 바로 번호로 꺼낼 수 없습니다. `list()`로 리스트로 바꾸면 인덱싱할 수 있습니다.

```run
eqp = {"id": "EQ-07", "temp": 185, "status": "RUN"}
print(list(eqp.keys())[0])
```

`in`은 **그 키가 있는지** 검사합니다.

```run
eqp = {"id": "EQ-07", "temp": 185}
print("temp" in eqp)
print("vib" in eqp)
```

없는 키를 `eqp["vib"]`로 읽으면 `KeyError`가 납니다. `get(키, 기본값)`은 키가 없을 때 **기본값을 대신** 돌려줍니다.

```run
eqp = {"id": "EQ-07", "temp": 185}
print(eqp.get("vib", 0))
```

`clear()`는 내용을 **모두 비웁니다.**

```run
eqp = {"id": "EQ-07", "temp": 185}
eqp.clear()
print(eqp)
```

### Set: 중복 없는 모음

**Set**은 중복을 허락하지 않는 모음입니다. 리스트를 `set()`에 넣으면 **중복이 사라집니다.**

```run
s = set(["A01", "A03", "A03"])
print(s)
```

`add()`로 값을 하나 추가합니다. 이미 있는 값을 넣으면 아무 변화가 없습니다.

```run
s = {"A01", "A03"}
s.add("B02")
s.add("A01")
print(len(s))
```

`union()`은 **합집합**, 두 모음의 값을 모두 모읍니다.

```run
print({1, 2, 3}.union({3, 4}))
```

`intersection()`은 **교집합**, 양쪽에 다 있는 값만 남깁니다.

```run
print({1, 2, 3}.intersection({3, 4}))
```

`-`는 **차집합**, 왼쪽에만 있는 값입니다.

```run
print({1, 2, 3} - {3, 4})
```

> Set은 순서가 없어서 인덱싱이 안 됩니다. 순서대로 보고 싶으면 `sorted(s)`로 리스트를 만드세요.
