### 딕셔너리: 이름(key)으로 값을 찾는 자료형

```run
eqp = {"id": "EQ-07", "line": "L2", "temp": 180}
print(eqp["line"])     # 읽기 → 'L2'
eqp["status"] = "RUN"  # 추가 (없는 키)
eqp["temp"] = 185      # 수정 (있는 키)
del eqp["line"]        # 삭제
print(eqp)
```

리스트처럼 `eqp[0]`으로는 꺼낼 수 없습니다. 반드시 키로 접근합니다.

### 한꺼번에 보기

```run
eqp = {"id": "EQ-07", "temp": 185, "status": "RUN"}
print(eqp.keys())          # dict_keys(['id', 'temp', 'status'])
print(eqp.values())        # dict_values(['EQ-07', 185, 'RUN'])
print(list(eqp.items()))   # (키, 값) 쌍
print(list(eqp.keys())[0]) # 리스트로 바꾸면 인덱싱 가능
print("temp" in eqp)       # True  (키가 있는지)
print(eqp.get("vib", 0))   # 키가 없으면 0  (eqp["vib"]는 KeyError)
eqp.clear()
print(eqp)                 # {}
```

### Set: 중복 없는 모음

```run
s = set(["A01", "A03", "A03"])
print(s)                                # {'A01', 'A03'}  중복이 사라진다
s.add("B02")
print(len(s))
print({1, 2, 3}.union({3, 4}))          # {1, 2, 3, 4}  합집합
print({1, 2, 3}.intersection({3, 4}))   # {3}  교집합
print({1, 2, 3} - {3, 4})               # {1, 2}  차집합
```

> Set은 순서가 없어서 인덱싱이 안 됩니다. 순서대로 보고 싶으면 `sorted(s)`로 리스트를 만드세요.
