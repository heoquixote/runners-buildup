### 파일은 프로그램이 끝나도 남습니다

변수는 프로그램이 끝나면 사라지지만, 파일에 쓰면 남습니다. 파일에서 읽기가 **입력**, 파일에 쓰기가 **출력**입니다.

### with open()

```run
with open("memo.txt", "w", encoding="utf-8") as f:
    f.write("LOT-001 OK\n")      # 줄바꿈은 직접 넣는다
    f.write("LOT-002 NG\n")
print("저장 완료")
```

`with`를 쓰면 블록이 끝날 때 파일이 자동으로 닫힙니다. 한글이 있으면 `encoding="utf-8"`을 꼭 쓰세요.

### 읽기 세 가지

```run
# 위 예제에서 만든 memo.txt 를 읽는다 (없으면 먼저 만든다)
import os
if not os.path.exists("memo.txt"):
    open("memo.txt", "w", encoding="utf-8").write("LOT-001 OK\nLOT-002 NG\n")
with open("memo.txt", encoding="utf-8") as f:
    print(repr(f.read()))        # 전체를 문자열 하나로
with open("memo.txt", encoding="utf-8") as f:
    print(repr(f.readline()))    # 한 줄
with open("memo.txt", encoding="utf-8") as f:
    print(f.readlines())         # 모든 줄을 리스트로 (각 줄 끝에 \n 포함)
```

### CSV

```run
import csv
with open("measure.csv", "w", encoding="utf-8", newline="") as f:
    f.write("lot,value\nLOT-001,23.4\nLOT-002,22.9\n")
with open("measure.csv", encoding="utf-8") as f:
    for row in csv.DictReader(f):     # 첫 줄을 키로 쓰는 딕셔너리
        print(row["lot"], float(row["value"]))   # 값은 모두 문자열!
```

쓸 때는 `open(..., "w", newline="")`으로 열어야 빈 줄이 끼지 않습니다.

### JSON

```run
import json
data = {"lot": "LOT-001", "values": [23.4, 22.9], "ok": True}
with open("result.json", "w", encoding="utf-8") as f:
    json.dump(data, f, ensure_ascii=False, indent=2)   # 파이썬 → 파일
with open("result.json", encoding="utf-8") as f:
    loaded = json.load(f)                              # 파일 → 파이썬
print(loaded["values"][0], loaded == data)
```

> 현장 활용: 검사 장비가 남긴 CSV 로그 집계, 설비 설정값(JSON) 관리
