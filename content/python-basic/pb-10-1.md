:::tip 이 코스는 가볍게 읽고 넘어가는 참고 코스입니다
파일 입출력은 나중에 데이터 분석 트랙에서 pandas의 `pd.read_csv()`, `pd.read_json()` 한 줄로 대부분 해결합니다. 여기서는 **데이터에는 어떤 모양이 있는지**와 **파이썬이 파일을 어떻게 열고 닫는지**만 맛보고 넘어갑니다. 연습문제는 없습니다. 끝까지 읽고 '다 읽었어요'를 누르면 됩니다.
:::

### 데이터의 세 가지 모양: 정형 · 반정형 · 비정형

파일을 열기 전에, 파일 안에 든 **데이터가 어떤 모양인지**부터 봅니다. 모양에 따라 저장하는 파일 형식도, 읽는 도구도 달라지기 때문입니다. 데이터는 "얼마나 칸이 딱딱 정해져 있느냐"에 따라 세 가지로 나눕니다.

::figure{src="content/img/py/py-data-structure-types.svg" alt="정형 데이터는 행과 열이 정해진 표로 lot, qty, defects 열이 있고 CSV · 엑셀 · DB 표가 예다. 반정형 데이터는 이름표(key)가 붙은 상자가 겹겹이 들어간 모양으로 equip, sensors 안에 temp와 pressure, alarms 목록이 있고 JSON · XML · 로그가 예다. 비정형 데이터는 정해진 칸이 없는 사진, 글, 소리로 불량 사진 · 작업 일지 · 설비 소리가 예다" caption="칸이 정해진 정도에 따라 정형 → 반정형 → 비정형. 오른쪽으로 갈수록 그대로 계산하기 어려워집니다."}

| 구분 | 모양 | 비유 | 대표 파일 · 예 | 파이썬에서 |
| --- | --- | --- | --- | --- |
| **정형 데이터** | 행과 열이 정해진 **표**. 모든 행이 같은 칸을 가짐 | 칸이 그려진 출석부 | CSV, 엑셀, 데이터베이스 표 · 검사 기록표 | `csv` 모듈, pandas `read_csv` |
| **반정형 데이터** | 칸은 자유롭지만 **이름표(key)**가 붙어 있고 겹겹이 들어갈 수 있음 | 이름표 붙은 서랍 속 작은 상자들 | JSON, XML, 장비 로그 · 설비 설정값, API 응답 | `json` 모듈 (딕셔너리 · 리스트) |
| **비정형 데이터** | 정해진 칸이 없음 | 서랍에 그냥 넣은 사진 · 메모 | 이미지, 글, 음성, 영상 · 불량 사진, 작업 일지 | 이미지 · 텍스트 처리, 딥러닝 |

- **정형**은 바로 합계 · 평균을 낼 수 있어 분석이 가장 쉽습니다. 실무 분석 데이터의 대부분이 결국 이 모양으로 정리됩니다.
- **반정형**은 행마다 칸이 달라도 됩니다. 어떤 설비는 센서가 2개, 어떤 설비는 5개여도 담을 수 있어 **유연**합니다. 대신 분석하려면 필요한 값을 꺼내 표로 펼치는 과정이 필요합니다.
- **비정형**은 그대로는 계산할 수 없어, 숫자로 바꾸는 과정(특징 추출)이 먼저 필요합니다. 딥러닝 트랙에서 다룹니다.

같은 검사 결과도 모양을 바꿔 담을 수 있습니다. 아래 셀은 같은 내용을 정형(표 한 줄)과 반정형(이름표 붙은 묶음)으로 보여 줍니다.

```run
row = ["A0915", 1250, 18]                                  # 정형: 칸 순서가 곧 의미 (lot, qty, defects)
record = {"lot": "A0915", "qty": 1250, "defects": 18,       # 반정형: 이름표로 의미를 붙이고
          "sensors": {"temp": 78.5}, "alarms": ["E205"]}    #         안에 묶음 · 목록을 더 넣을 수 있다
print(row)
print(record["sensors"]["temp"], record["alarms"])
```

### 파일 열고 닫기: with open()

변수는 프로그램이 끝나면 사라지지만, 파일에 쓰면 남습니다. 파일에 쓰는 것이 **출력**, 파일에서 읽는 것이 **입력**입니다. 파이썬은 `open()`으로 파일을 열고, `with`를 쓰면 블록이 끝날 때 **자동으로 닫아** 줍니다.

```run
with open("memo.txt", "w", encoding="utf-8") as f:     # "w" 쓰기
    f.write("LOT-001 OK\n")                            # 줄바꿈 \n 은 직접 넣는다
    f.write("LOT-002 NG\n")

with open("memo.txt", encoding="utf-8") as f:          # 모드를 안 쓰면 "r" 읽기
    print(f.readlines())                               # 모든 줄을 리스트로
```

| 모드 | 뜻 |
| --- | --- |
| `"r"` | 읽기 (기본값) |
| `"w"` | 쓰기. 기존 내용을 **지우고** 새로 씀 |
| `"a"` | 이어 쓰기. 기존 내용 뒤에 붙임 |

한글이 들어 있으면 `encoding="utf-8"`을 꼭 넣으세요. 빼면 컴퓨터에 따라 글자가 깨집니다.

### 정형 데이터 파일: CSV

**CSV**(Comma-Separated Values)는 쉼표로 칸을 나눈 텍스트 파일입니다. 첫 줄이 열 이름(헤더), 다음 줄부터 한 줄이 한 행인 **정형 데이터**입니다. 표준 라이브러리 `csv`의 `DictReader`는 한 행을 `{열 이름: 값}` 딕셔너리로 줍니다.

```run
import csv

with open("lots.csv", "w", encoding="utf-8", newline="") as f:
    f.write("lot,qty,defects\nA0915,1250,18\nA0916,980,7\n")

with open("lots.csv", encoding="utf-8") as f:
    for row in csv.DictReader(f):
        print(row["lot"], int(row["defects"]) / int(row["qty"]))
```

CSV에서 읽은 값은 숫자처럼 보여도 **모두 문자열**이라 `int()`로 바꾼 뒤 계산했습니다.

:::tip 더 알아 두기 · CSV를 쓸 때와 pandas
- 쓸 때는 `csv.writer(f)`의 `writerow(한 행)` · `writerows(여러 행)`를 쓰고, 파일은 `open(..., "w", newline="")`으로 엽니다. `newline=""`을 빼면 Windows에서 줄 사이에 빈 줄이 낍니다.
- 실무에서는 `import pandas as pd` 후 `pd.read_csv("lots.csv")` 한 줄로 표 전체를 읽고, 숫자 변환도 알아서 해 줍니다. [pandas 소개](#/l/da-03-0)에서 이어집니다.
:::

### 반정형 데이터 파일: JSON

**JSON**은 파이썬의 딕셔너리 · 리스트와 거의 같은 모양으로 적는 **반정형 데이터** 파일입니다. 설비 설정값, 검사 기준표, 웹 API가 돌려주는 데이터가 대부분 JSON입니다. 표준 라이브러리 `json`으로 저장(`dump`)하고 불러(`load`)옵니다.

```run
import json

spec = {"product": "볼트-M8", "length": [9.5, 10.5], "visual_check": True, "memo": None}
with open("spec.json", "w", encoding="utf-8") as f:
    json.dump(spec, f, ensure_ascii=False, indent=2)    # 파이썬 → 파일

with open("spec.json", encoding="utf-8") as f:
    print(f.read())                                     # 파일에 적힌 모양
with open("spec.json", encoding="utf-8") as f:
    loaded = json.load(f)                               # 파일 → 파이썬
print(loaded["length"][1], loaded == spec)
```

파일 안에서는 `True`가 `true`, `None`이 `null`로 적히고, 불러오면 다시 파이썬 값으로 돌아옵니다. `ensure_ascii=False`는 한글을 그대로 저장하고, `indent=2`는 사람이 읽기 좋게 줄을 바꿉니다.

:::tip 더 알아 두기 · JSON과 파이썬의 차이
| JSON | 파이썬 |
| --- | --- |
| `{"a": 1}` 객체 | 딕셔너리 |
| `[1, 2]` 배열 | 리스트 |
| `true` / `false` / `null` | `True` / `False` / `None` |

JSON은 문자열에 **큰따옴표만** 씁니다. `{'a': 1}`처럼 작은따옴표로 적힌 글자는 JSON이 아니라서 `json.loads()`가 에러를 냅니다. 파일이 아니라 문자열을 다룰 때는 `s`가 붙은 `json.dumps()` / `json.loads()`를 씁니다.
:::

### 정리

- **정형**(표: CSV · 엑셀) / **반정형**(이름표 붙은 묶음: JSON · 로그) / **비정형**(사진 · 글 · 소리). 정형일수록 바로 계산하기 쉽고, 반정형은 유연하다.
- `with open(파일, 모드, encoding="utf-8") as f:`로 열면 블록이 끝날 때 자동으로 닫힌다. `"w"`는 덮어쓰기, `"a"`는 이어 쓰기.
- CSV는 `csv.DictReader`, JSON은 `json.dump` · `json.load`. CSV에서 읽은 값은 모두 문자열이다.
- 실제 분석에서는 pandas가 이 일을 대신한다. 여기서는 모양과 흐름만 기억하면 충분하다.
