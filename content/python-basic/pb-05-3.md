코드를 쓰다 보면 에러는 반드시 납니다. 처음 배우는 사람과 익숙한 사람의 차이는 에러가 나느냐가 아니라, **에러 메시지를 읽고 바로 고칠 수 있느냐**입니다. [정렬 두 가지와 에러 메시지 읽는 법](#/l/pb-05-1)에서 에러 이름 다섯 가지를 봤다면, 이번에는 에러 메시지 전체(Traceback)를 읽는 순서와 에러별로 고치는 법을 익힙니다.

### Traceback은 아래에서 위로 읽습니다

파이썬은 에러가 나면 **어디를 거쳐 어디서 멈췄는지** 기록을 보여 줍니다. 이것을 Traceback(거슬러 올라간 기록)이라고 합니다.

```python
sizes = [10.1, 9.2, 10.4]
label = "평균: "
mean = sum(sizes) / len(sizes)
print(label + mean)
```

```
Traceback (most recent call last):
  File "main.py", line 4, in <module>
    print(label + mean)
          ~~~~~~^~~~~~
TypeError: can only concatenate str (not "float") to str
```

| 읽는 순서 | 위치 | 이 예에서 |
| --- | --- | --- |
| ① | **맨 아래 줄**: 에러 이름과 설명 | `TypeError`: 문자열에는 문자열만 이을 수 있다 |
| ② | 바로 위: 멈춘 코드 줄과 `^` 표시 | `label + mean` 의 `+` |
| ③ | 그 위: 파일과 **줄 번호** | 4번째 줄 |
| ④ | 맨 위 `Traceback ...` | "이제부터 기록"이라는 머리말 |

맨 아래 줄만 읽어도 절반은 해결됩니다. 이 에러는 숫자(float)를 문자열에 `+`로 이으려 해서 났습니다. 숫자를 글자로 바꾸거나 f-string을 쓰면 됩니다.

```run
sizes = [10.1, 9.2, 10.4]
mean = sum(sizes) / len(sizes)
print(f"평균: {mean:.2f}")
```

### 흔한 에러 여섯 가지와 고치는 법

| 에러 | 뜻 | 흔한 원인 |
| --- | --- | --- |
| `SyntaxError` | 문법이 틀림 | 괄호·따옴표 짝, `:` 빠짐 |
| `IndentationError` | 들여쓰기가 어긋남 | 칸 수가 다름, 탭과 빈칸 섞임 |
| `NameError` | 그런 이름이 없음 | 오타, 만들기 전에 사용 |
| `TypeError` | 자료형이 안 맞음 | 숫자 + 문자열, 함수 인자 개수 |
| `ValueError` | 자료형은 맞는데 값이 안 됨 | `int("N/A")`, 없는 값 `index()` |
| `IndexError` | 번호가 범위 밖 | 길이 3인 리스트의 `[3]` |

하나씩 "증상 → 원인 → 고친 코드"로 봅니다.

**NameError: 오타**

```python
temp_avg = 23.4
print(tmp_avg)
```

```
NameError: name 'tmp_avg' is not defined. Did you mean: 'temp_avg'?
```

최근 파이썬은 비슷한 이름을 `Did you mean`으로 알려 줍니다. 대소문자도 다른 이름입니다(`Temp`와 `temp`).

```run
temp_avg = 23.4
print(temp_avg)
```

**ValueError: 바꿀 수 없는 값**

```python
qty = int("1,250")
```

```
ValueError: invalid literal for int() with base 10: '1,250'
```

쉼표가 섞인 숫자는 `int()`가 읽지 못합니다. 메시지 끝에 **문제가 된 값**이 따옴표로 나와 있으니 그것부터 봅니다.

```run
qty = int("1,250".replace(",", ""))
print(qty)
```

**IndexError: 번호가 범위 밖**

```python
lots = ["A0915", "A0916", "A0917"]
print(lots[3])
```

```
IndexError: list index out of range
```

길이가 3이면 번호는 0, 1, 2까지입니다. 마지막 값이 필요하면 `[-1]`을 씁니다.

```run
lots = ["A0915", "A0916", "A0917"]
print(len(lots), lots[-1])
```

**SyntaxError · IndentationError: 실행 전에 걸리는 에러**

이 둘은 코드를 **한 줄도 실행하기 전에** 납니다. 그래서 에러 위치보다 **한 줄 위**를 봐야 할 때가 많습니다. 괄호를 열고 안 닫았으면 다음 줄에서 에러가 보고됩니다.

```python
total = sum([10.1, 9.2, 10.4]
print(total)
```

```
SyntaxError: '(' was never closed
```

```run
total = sum([10.1, 9.2, 10.4])
print(total)
```

### 메시지로 모르겠으면 중간값을 찍어 봅니다

에러는 안 나는데 결과가 이상할 때가 더 어렵습니다. 이럴 때는 의심 가는 변수를 **중간중간 print로 찍어** 내가 생각한 값과 같은지 확인합니다. 값과 함께 `type()`도 찍으면 자료형 문제를 바로 찾습니다.

```run
raw = ["9", "10", "2"]
print(raw, type(raw[0]))     # 확인용: 숫자가 아니라 문자열이었다
print(max(raw))
```

`max`가 `'9'`를 돌려준 이유가 바로 보입니다. 원소가 `str`이라 글자 순서로 비교했기 때문입니다([리스트에서 찾고 요약하기](#/l/pb-05-2)). 확인이 끝나면 확인용 print는 지웁니다.

### 고치는 순서

1. **맨 아래 줄**에서 에러 이름과 설명을 읽는다.
2. **줄 번호**로 가서 그 줄(SyntaxError면 한 줄 위까지)을 본다.
3. 메시지에 나온 **값**(따옴표 안)이나 **이름**을 확인한다.
4. 그래도 모르겠으면 의심 가는 변수를 `print(값, type(값))`으로 찍는다.
5. 에러 메시지 맨 아래 줄을 그대로 검색한다.
