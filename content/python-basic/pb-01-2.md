pb-01-1에서 `+ - * / // % **`를 하나씩 써 봤습니다. 실제 계산은 이 기호들이 **한 줄에 여러 개** 섞여 나옵니다. 불량률, 수율, 평균처럼 현장에서 매일 쓰는 식을 틀리지 않게 쓰려면 세 가지를 알아야 합니다. 계산 순서, 값을 쌓아 가는 방법, 소수점 정리입니다.

### 계산 순서는 수학 시간과 같습니다

파이썬도 곱하기·나누기를 더하기·빼기보다 먼저 합니다. 순서를 바꾸고 싶으면 **괄호**를 씁니다.

| 순서 | 연산 |
| --- | --- |
| 1 | `( )` 괄호 |
| 2 | `**` 거듭제곱 |
| 3 | `*` `/` `//` `%` |
| 4 | `+` `-` |

같은 순서끼리는 왼쪽부터 계산합니다.

```run
print(2 + 3 * 4)       # 3 * 4 먼저
print((2 + 3) * 4)     # 괄호 먼저
```

첫 줄은 14, 둘째 줄은 20입니다. 기호는 같은데 괄호 하나로 결과가 달라졌습니다.

### 평균을 구할 때 가장 많이 틀립니다

측정값 세 개의 평균은 "모두 더한 뒤 3으로 나누기"입니다. 괄호를 빼먹으면 마지막 값만 3으로 나뉩니다.

```run
a = 10.2
b = 9.8
c = 10.3
print(a + b + c / 3)      # 틀린 식: c 만 3으로 나뉜다
print((a + b + c) / 3)    # 맞는 식
```

틀린 식은 23.43…, 맞는 식은 10.1입니다. 측정값이 10 근처인데 평균이 23이 나오면 식을 의심해야 합니다. **결과가 상식적인 범위인지 한 번 보는 습관**이 계산 실수를 가장 많이 잡아 줍니다.

### 불량률과 수율

불량률은 "불량 수 ÷ 검사 수 × 100"입니다. 수율은 "양품 수 ÷ 투입 수 × 100"입니다.

```run
inspected = 1250     # 검사 수량
defects = 18         # 불량 수량
rate = defects / inspected * 100
print(rate)
print(100 - rate)    # 수율(%)
```

불량률은 1.44%, 수율은 98.56%입니다. `/`와 `*`는 순서가 같아서 왼쪽부터 계산되므로 괄호 없이도 맞습니다. 헷갈리면 `(defects / inspected) * 100`처럼 괄호를 넣어도 결과는 같고 읽기는 더 쉽습니다.

```run
inspected = 1250     # 값을 바꿔 보세요
defects = 18
print((defects / inspected) * 100)
```

### `/`의 결과는 항상 소수(float)입니다

`/`는 딱 나누어떨어져도 `5.0`처럼 소수점을 붙입니다. 개수처럼 정수가 필요하면 `//`(몫)를 씁니다.

```run
print(10 / 2)     # 5.0
print(10 // 2)    # 5
print(1000 // 24, 1000 % 24)   # 박스 41개, 남는 16개
```

### 값을 쌓아 갈 때: `+=`

`total = total + 30`은 "지금 total에 30을 더해서 다시 total에 담는다"는 뜻입니다. 이 모양은 너무 자주 나와서 `total += 30`으로 줄여 씁니다.

```run
total = 0
total += 120     # 1교대 생산량
total += 135     # 2교대
total += 118     # 3교대
print(total)
```

`-=`, `*=`, `/=`도 같은 방식입니다. 이 "누적" 모양은 pb-07에서 반복문과 만나면 합계를 구하는 기본 패턴이 됩니다.

### 소수는 아주 작은 오차가 있습니다

컴퓨터는 소수를 2진수로 저장해서 `0.1`을 정확히 담지 못합니다. 그래서 다음 결과가 0.3이 아닙니다.

```run
print(0.1 + 0.2)
print(0.1 + 0.2 == 0.3)
```

`0.30000000000000004`가 나오고 비교는 False입니다. 파이썬이 틀린 게 아니라 모든 프로그래밍 언어에서 생기는 일입니다. 보고용 숫자는 `round(값, 자리수)`로 반올림하고, 소수끼리 같은지 비교할 때는 `==` 대신 차이가 아주 작은지 봅니다.

```run
x = 0.1 + 0.2
print(round(x, 2))
print(abs(x - 0.3) < 1e-9)     # 차이가 0.000000001 보다 작으면 같다고 본다
```

`round(x, 2)`는 0.3, 차이 비교는 True입니다. `abs()`는 절댓값(부호를 뗀 값)입니다.

```run
rate = 18 / 1250 * 100
print(round(rate, 1))    # 소수 첫째 자리까지
print(round(rate))       # 자리수를 비우면 정수로
```

### 자주 하는 실수

| 실수 | 결과 | 고치기 |
| --- | --- | --- |
| `a + b + c / 3` | 마지막 값만 나뉨 | `(a + b + c) / 3` |
| `x ^ 2` 로 제곱 | 엉뚱한 값 (`^`는 다른 연산) | `x ** 2` |
| 소수를 `==`로 비교 | False가 나올 수 있음 | `round()` 후 비교하거나 차이로 비교 |
| `total + 30` 만 쓰고 끝 | total이 그대로 | `total += 30` 처럼 다시 담기 |
