"점검표에 있는데 오늘 안 한 항목은?", "두 라인에서 모두 나온 불량 유형은?", "어제는 없다가 오늘 새로 생긴 알람은?" 이런 질문은 모두 **두 목록을 비교**하는 일입니다. Set의 연산을 쓰면 반복문 없이 한 줄로 답이 나옵니다. pb-06-1에서 본 `union`, `intersection`을 기호로 더 짧게 쓰고, 차집합과 부분집합까지 넓혀 봅니다.

### 두 목록 준비

점검표의 필수 항목과 오늘 실제로 점검한 항목입니다.

```run
required = {"온도", "압력", "진동", "소음", "누유"}
done = {"온도", "압력", "소음", "전류"}
print(len(required), len(done))
```

Set은 순서가 없어서 출력할 때마다 순서가 달라 보일 수 있습니다. 순서대로 보고 싶으면 `sorted()`로 정렬된 리스트를 만들어 봅니다.

### 네 가지 연산

<table class="ex-table"><thead><tr><th>기호</th><th>메서드</th><th>뜻</th><th>질문</th></tr></thead><tbody>
<tr><td><code>A | B</code></td><td><code>union</code></td><td>합집합: 둘 중 하나라도</td><td>전체 항목은?</td></tr>
<tr><td><code>A &amp; B</code></td><td><code>intersection</code></td><td>교집합: 둘 다</td><td>둘 다 있는 것은?</td></tr>
<tr><td><code>A - B</code></td><td><code>difference</code></td><td>차집합: A에만</td><td>A에는 있는데 B에 없는 것은?</td></tr>
<tr><td><code>A ^ B</code></td><td><code>symmetric_difference</code></td><td>대칭차: 한쪽에만</td><td>서로 다른 것은?</td></tr></tbody></table>

**교집합**: 필수 항목 중 점검한 것

```run
required = {"온도", "압력", "진동", "소음", "누유"}
done = {"온도", "압력", "소음", "전류"}
print(sorted(required & done))
```

**차집합**: 빼먹은 항목. 순서가 중요합니다.

```run
required = {"온도", "압력", "진동", "소음", "누유"}
done = {"온도", "압력", "소음", "전류"}
print(sorted(required - done))     # 필수인데 안 한 것
print(sorted(done - required))     # 필수가 아닌데 한 것
```

빼먹은 항목은 `['누유', '진동']`, 점검표에 없는 추가 항목은 `['전류']`입니다. `A - B`와 `B - A`는 **다른 질문**입니다. "누구 기준으로 빠진 것인가"를 먼저 정하고 앞에 둡니다.

**합집합과 대칭차**

```run
required = {"온도", "압력", "진동", "소음", "누유"}
done = {"온도", "압력", "소음", "전류"}
print(len(required | done))
print(sorted(required ^ done))
```

전체 항목은 6개, 한쪽에만 있는 것은 누유·전류·진동입니다. 대칭차는 `(A - B) | (B - A)`와 같습니다.

### 알람 비교: 새로 생긴 것, 사라진 것

```run
yesterday = {"E101", "E205", "E310"}
today = {"E205", "E310", "E412"}
print("새 알람:", sorted(today - yesterday))
print("해소:", sorted(yesterday - today))
print("계속:", sorted(today & yesterday))
```

E412가 새로 생겼고, E101이 해소됐고, E205·E310은 이어지고 있습니다. 목록이 수백 개여도 코드는 그대로입니다.

### 부분집합: 다 들어 있나

`A <= B`는 "A의 원소가 모두 B에 있는가"입니다. 필수 항목을 **모두** 점검했는지 확인할 때 씁니다.

```run
required = {"온도", "압력"}
done = {"온도", "압력", "소음"}
print(required <= done)
print({"온도", "진동"} <= done)
```

True, False입니다.

```run
required = {"온도", "압력", "진동"}
done = {"온도", "압력"}
done.add("진동")             # 이 줄을 지우고 다시 실행해 보세요
print(required <= done, sorted(required - done))
```

### 넣고 빼기: add, discard

`add()`는 하나 넣고, 이미 있으면 아무 일도 하지 않습니다(중복이 생기지 않음). `discard()`는 하나 빼고, 없어도 에러가 나지 않습니다. 비슷한 `remove()`는 없는 값을 빼려 하면 KeyError를 냅니다.

```run
alarms = {"E205"}
alarms.add("E205")
alarms.add("E412")
alarms.discard("E999")
print(sorted(alarms), len(alarms))
```

### 리스트에서 Set으로, 다시 리스트로

데이터는 보통 리스트로 들어옵니다. `set()`으로 바꿔 비교하고, 결과를 쓰기 좋게 `sorted()`로 리스트로 돌려놓는 것이 기본 흐름입니다.

```run
line1 = ["스크래치", "찍힘", "스크래치", "변색"]
line2 = ["찍힘", "버", "찍힘"]
common = set(line1) & set(line2)
print(sorted(common))
```

두 라인에 모두 나온 불량 유형은 찍힘입니다. Set으로 바꾸는 순간 **중복과 순서가 사라지므로**, 몇 번 나왔는지가 필요하면 Set이 아니라 딕셔너리로 세야 합니다(pb-09).
