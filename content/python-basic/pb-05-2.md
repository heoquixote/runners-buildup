측정값이 리스트에 쌓이면 바로 궁금해지는 것들이 있습니다. "이 로트가 목록에 있나?", "몇 번째에 있나?", "불량이 몇 번 나왔나?", "평균과 최댓값은?" 이 레슨에서는 반복문 없이 **한 줄로** 리스트를 찾고 요약하는 도구를 배웁니다.

### 들어 있나, 몇 번째인가

문자열에서 쓴 `in`([찾고 세고 검사하기: in · find · count · isdigit](#/l/pb-03-2))은 리스트에도 똑같이 씁니다. 위치는 `index()`로 찾습니다.

```run
lots = ["A0915", "A0916", "A0917"]
print("A0916" in lots)
print(lots.index("A0916"))
```

True, 그리고 번호 1입니다. 리스트에는 `find()`가 없고, `index()`는 값이 없으면 **에러(ValueError)**를 냅니다. 그래서 확실하지 않으면 `in`으로 먼저 확인합니다.

```run
lots = ["A0915", "A0916", "A0917"]
target = "A0999"
print(target in lots)
```

False이니 `lots.index(target)`은 부르면 안 됩니다. 이 "확인하고 쓰기"는 [제어문 (if · for · while)](#/l/pb-07-1)에서 `if`와 묶여 `if target in lots:` 모양이 됩니다.

### 몇 번 나왔나: count

```run
results = ["P", "P", "F", "P", "F", "P"]
print(results.count("F"))
print(results.count("P"))
```

불합격 2번, 합격 4번입니다. 문자열의 `count()`와 이름도 쓰는 법도 같습니다.

### 원하는 자리에 넣기: insert

`append()`는 끝에만 붙입니다. 중간에 넣으려면 `insert(번호, 값)`을 씁니다. 그 자리에 있던 값부터 한 칸씩 뒤로 밀립니다.

```run
steps = ["투입", "가공", "출하"]
steps.insert(2, "검사")
print(steps)
```

`['투입', '가공', '검사', '출하']`가 됩니다. 2번 자리에 "검사"가 들어가고 "출하"가 3번으로 밀렸습니다.

### 숫자 리스트 요약 네 가지

숫자 리스트는 내장 함수 네 개로 바로 요약합니다.

| 함수 | 뜻 |
| --- | --- |
| `len(x)` | 개수 |
| `sum(x)` | 합계 |
| `min(x)` | 가장 작은 값 |
| `max(x)` | 가장 큰 값 |

```run
sizes = [10.1, 9.2, 10.4, 10.8, 9.9]
print(len(sizes), sum(sizes))
print(min(sizes), max(sizes))
print(sum(sizes) / len(sizes))
```

5개, 합계 50.4, 최솟값 9.2, 최댓값 10.8입니다. 평균은 **합계 ÷ 개수**로 10.08입니다. 범위(최댓값 - 최솟값)는 1.6으로, 값이 얼마나 퍼졌는지 보여 줍니다.

```run
sizes = [10.1, 9.2, 10.4, 10.8, 9.9]     # 값을 바꿔 보세요
mean = sum(sizes) / len(sizes)
print(f"평균 {mean:.2f}, 범위 {max(sizes) - min(sizes):.2f}")
```

### 상위 N개, 하위 N개

정렬한 뒤 슬라이싱하면 됩니다. `sorted()`는 원본을 바꾸지 않으니([정렬 두 가지와 에러 메시지 읽는 법](#/l/pb-05-1)) 안전합니다.

```run
defects = [3, 12, 0, 7, 5, 9]
print(sorted(defects, reverse=True)[:3])   # 불량 많은 3개
print(sorted(defects)[:2])                 # 불량 적은 2개
```

`[12, 9, 7]`과 `[0, 3]`입니다.

### 숫자 모양 글자는 글자 순서로 정렬됩니다

파일에서 읽은 값은 문자열인 경우가 많습니다. 문자열은 **앞 글자부터 하나씩** 비교하기 때문에 `"10"`이 `"9"`보다 앞에 옵니다. `"1"`이 `"9"`보다 작기 때문입니다.

```run
raw = ["9", "10", "2"]
print(sorted(raw))
print(max(raw))
```

`['10', '2', '9']`, 그리고 최댓값이 `'9'`로 나옵니다. 숫자로 바꾼 리스트로 정렬해야 맞습니다(바꾸는 방법은 컴프리헨션([컴프리헨션과 람다](#/l/pb-11-1))이나 [제어문 (if · for · while)](#/l/pb-07-1)의 반복문으로 배웁니다). 지금은 숫자 모양 글자를 정렬하면 이상한 결과가 나온다는 것만 기억하세요.

```run
nums = [9, 10, 2]
print(sorted(nums))
```

### 자주 하는 실수

| 실수 | 결과 | 고치기 |
| --- | --- | --- |
| 없는 값으로 `index()` | ValueError | `in`으로 먼저 확인 |
| `sum()`에 문자열 리스트 | TypeError | 숫자로 바꾼 뒤 합계 |
| 평균을 `sum(x) / 5`처럼 개수를 손으로 | 값이 늘면 틀림 | `sum(x) / len(x)` |
| 숫자 모양 문자열 정렬 | `'10' < '9'` | 숫자로 바꿔서 정렬 |
