### 메서드는 값 뒤에 점(.)을 찍고 부르는 함수

**메서드**는 특정 값에 딸린 기능입니다. `값.메서드()` 모양으로 부릅니다. `upper()`는 모두 **대문자**로 바꿉니다.

```run
raw = "qc-Line3-Pass"
print(raw.upper())
```

`lower()`는 모두 **소문자**로 바꿉니다. 대소문자가 섞인 데이터를 비교하기 전에 맞춰 둘 때 씁니다.

```run
raw = "qc-Line3-Pass"
print(raw.lower())
```

`startswith()`는 **~로 시작하는지**, `endswith()`는 **~로 끝나는지** 검사해 `True` / `False`로 알려 줍니다.

```run
raw = "qc-Line3-Pass"
print(raw.startswith("qc"))
print(raw.endswith("Pass"))
```

### split: 나눠서 리스트로

`split()`을 괄호 안을 비워 부르면 **공백**을 기준으로 잘라 리스트로 돌려줍니다.

```run
print("A동 2층 3라인".split())
```

괄호 안에 구분 문자를 넣으면 그 문자를 기준으로 자릅니다. CSV 한 줄을 나눌 때 `","`를 넣습니다.

```run
print("23.1,23.4,22.9".split(","))
```

### join: 리스트를 이어서 문자열로

`join()`은 `split()`의 반대입니다. **붙일 문자가 앞에** 오고, 이어 붙일 리스트를 괄호 안에 넣습니다.

```run
print("-".join(["2024", "10", "25"]))
```

`join`은 **문자열만** 이어 붙입니다. 숫자 리스트는 `str()`로 하나씩 바꾼 뒤 이어 붙입니다.

```run
temps = [23.1, 23.4]
print(",".join(str(v) for v in temps))
```

### replace, strip

`replace(바꿀 것, 새것)`은 글자를 **찾아 바꿉니다.**

```run
print("2024.10.25".replace(".", "-"))
```

`strip()`은 **앞뒤의 공백과 줄바꿈**을 지웁니다. 파일에서 읽은 줄을 정리할 때 꼭 씁니다. `repr()`은 보이지 않는 공백까지 드러내서 보여 줍니다.

```run
line = "  OK \n"
print(repr(line))
print(repr(line.strip()))
```

> 문자열은 바뀌지 않는 값입니다. `s.upper()`만 쓰면 s는 그대로이고, `s = s.upper()`처럼 다시 담아야 바뀝니다.

```run
s = "pass"
s.upper()
print(s)
s = s.upper()
print(s)
```
