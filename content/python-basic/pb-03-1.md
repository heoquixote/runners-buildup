### 메서드는 값 뒤에 점(.)을 찍고 부르는 함수

```run
raw = "qc-Line3-Pass"
print(raw.upper())              # 'QC-LINE3-PASS'
print(raw.lower())              # 'qc-line3-pass'
print(raw.startswith("qc"))     # True
print(raw.endswith("Pass"))     # True
```

### split: 나눠서 리스트로

```run
print("A동 2층 3라인".split())        # ['A동', '2층', '3라인']  (공백 기준)
print("23.1,23.4,22.9".split(","))   # ['23.1', '23.4', '22.9']
```

### join: 리스트를 이어서 문자열로

```run
print("-".join(["2024", "10", "25"]))   # '2024-10-25'
# join은 문자열만 이어 붙인다. 숫자는 str()로 바꿔서
print(",".join(str(v) for v in [23.1, 23.4]))
```

`split`과 `join`은 반대 방향입니다. join은 **붙일 문자**가 앞에 옵니다.

### replace, strip

```run
print("2024.10.25".replace(".", "-"))   # '2024-10-25'
print(repr("  OK \n".strip()))           # 'OK'  앞뒤 공백·줄바꿈 제거
```

> 문자열은 바뀌지 않는 값입니다. `s.upper()`만 쓰면 s는 그대로이고, `s = s.upper()`처럼 다시 담아야 바뀝니다.
