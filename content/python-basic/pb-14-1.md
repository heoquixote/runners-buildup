### 객체: 값과 기능을 함께 가진 것

파이썬에서 다루는 값 하나하나를 **객체(object)**라고 부릅니다. 숫자 `3`, 문자열 `"A0915"`, 리스트 `[1, 2]`, 날짜 `datetime(2026, 11, 7)` 모두 객체입니다.

객체는 스마트폰과 비슷합니다. 스마트폰에는 **가지고 있는 정보**(배터리 잔량, 색상, 저장된 사진)가 있고, **할 수 있는 일**(전화 걸기, 사진 찍기)이 있습니다. 객체도 마찬가지입니다.

- **속성(attribute)**: 객체가 가지고 있는 값. 점 뒤에 이름만 쓴다. `made.year`
- **메서드(method)**: 객체가 할 수 있는 일(객체에 딸린 함수). 점 뒤에 이름과 괄호를 쓴다. `made.strftime("%Y")`

### type()이 말해 주는 class

값의 종류는 `type()`으로 확인했습니다([자료형과 형변환](#/l/pb-01-3)). 결과를 다시 보면 `class`라는 말이 들어 있습니다.

```run
print(type("A0915"))
print(type([10.1, 9.8]))
print(type({"lot": "A0915"}))
```

`<class 'str'>`는 "이 값은 **str이라는 종류(class)**로 만들어진 객체"라는 뜻입니다. **클래스(class)는 객체의 종류, 즉 설계도**입니다. 같은 설계도로 만든 객체는 같은 속성과 메서드를 가집니다. 그래서 모든 문자열에는 `upper()`가 있고, 모든 리스트에는 `append()`가 있습니다.

### 속성: 괄호 없이 값을 꺼낸다

날짜 객체로 확인해 봅시다. `year`, `month`, `day`는 객체가 이미 가지고 있는 값이라 괄호 없이 꺼냅니다.

```run
from datetime import datetime

made = datetime(2026, 11, 7, 9, 30)
print(made.year, made.month, made.day)
print(made.hour, made.minute)
```

`2026 11 7`, `9 30`이 나옵니다. 계산하는 것이 아니라 들어 있는 값을 읽기만 합니다.

### 메서드: 괄호를 붙여 일을 시킨다

`weekday()`는 요일 번호를 **계산**하고, `strftime()`은 원하는 모양의 문자열을 **만듭니다**. 일을 시키는 것이라 괄호를 붙이고, 필요하면 괄호 안에 재료(인자)를 넣습니다.

```run
from datetime import datetime

made = datetime(2026, 11, 7, 9, 30)
print(made.weekday())               # 월 0 ~ 일 6
print(made.strftime("%Y-%m-%d"))    # 재료: 포맷 문자열
```

`5`(토요일)와 `2026-11-07`입니다.

괄호를 빼먹으면 어떻게 될까요? 에러는 나지 않지만 **일을 시키지 않고 메서드 자체**를 보여 줍니다.

```run
from datetime import datetime

made = datetime(2026, 11, 7, 9, 30)
print(made.weekday)      # 괄호 없음
```

`<built-in method weekday of datetime.datetime object at 0x...>`처럼 이상한 글자가 나오면 "괄호를 빠뜨렸구나" 하고 알아차리면 됩니다.

| 모양 | 이름 | 하는 일 | 예 |
| --- | --- | --- | --- |
| `객체.이름` | 속성 | 가진 값을 꺼낸다 | `made.year` |
| `객체.이름()` | 메서드 | 일을 시킨다(계산 · 변환 · 변경) | `made.weekday()` |

### 함수와 메서드는 무엇이 다른가요

`len(lots)`처럼 값을 괄호 **안에** 넣는 것은 **함수**, `lots.count("A0915")`처럼 값 **뒤에 점을 찍는** 것은 **메서드**입니다.

```run
lots = ["A0915", "A0916", "A0915"]
print(len(lots))              # 함수: 무엇이든 받아서 길이를 잰다
print(lots.count("A0915"))    # 메서드: 리스트가 자기 안을 센다
```

함수는 **밖에 있는 도구**에 값을 넣는 것이고, 메서드는 **객체에게 직접 시키는 것**입니다. `len()`은 문자열 · 리스트 · 딕셔너리 어디에나 쓰는 공용 도구이고, `count()`는 리스트(와 문자열)가 각자 가진 기능입니다. 메서드는 자기 객체의 값을 이미 알고 있으므로, 괄호 안에는 **추가 재료**만 넣습니다.

### 메서드 두 종류: 새 값을 돌려주는 것, 원본을 바꾸는 것

메서드는 하는 일에 따라 두 종류로 나뉩니다. 이 차이를 모르면 실수가 자주 납니다.

**새 값을 돌려주는 메서드**: 원본은 그대로 두고 결과를 새로 만들어 줍니다. 문자열 메서드는 모두 이쪽입니다(문자열은 바꿀 수 없는 값이라서, [슬라이싱으로 코드 해독하기](#/l/pb-02-3)).

```run
code = "kr24a0915"
big = code.upper()
print(code, big)
```

`code`는 그대로 `kr24a0915`이고, 바뀐 값은 `big`에 담겼습니다. 결과를 변수에 받아야 쓸 수 있습니다.

**원본을 바꾸는 메서드**: 객체 자신을 고치고, 돌려주는 값은 `None`입니다. 리스트의 `append`, `sort`, `remove`가 이쪽입니다.

```run
sizes = [10.4, 9.8, 10.1]
result = sizes.sort()
print(sizes)
print(result)
```

`sizes`는 정렬되었고 `result`는 `None`입니다. 그래서 `sizes = sizes.sort()`처럼 쓰면 리스트를 잃어버립니다. [정렬 두 가지와 에러 메시지 읽는 법](#/l/pb-05-1)에서 본 `sort`와 `sorted`의 차이가 바로 이것입니다.

| 종류 | 원본 | 돌려주는 값 | 예 |
| --- | --- | --- | --- |
| 새 값을 돌려준다 | 그대로 | 새 결과 | `s.upper()`, `s.replace()`, `made.strftime()` |
| 원본을 바꾼다 | 바뀜 | `None` | `lst.append()`, `lst.sort()`, `d.update()` |

헷갈릴 때는 실행해 보고 `print`로 원본과 결과를 둘 다 찍어 보면 바로 알 수 있습니다.

### 이 객체에는 무엇이 있을까: dir()

[모듈과 import: 남이 만든 도구 상자 쓰기](#/l/pb-13-1)에서 `dir(math)`로 모듈 안을 둘러봤습니다. 객체에도 똑같이 쓸 수 있습니다.

```run
lots = ["A0915", "A0916"]
names = [n for n in dir(lots) if not n.startswith("_")]
print(names)
```

`append`, `count`, `pop`, `sort` 등 리스트가 가진 메서드 목록입니다. 밑줄로 시작하는 이름(`__len__` 등)은 파이썬 내부용이라 걸러 냈습니다.

### 다음 트랙 미리보기: pandas의 표도 객체입니다

데이터 분석 트랙에서 쓰는 표(DataFrame)도 객체입니다. 이제 아래 코드에서 무엇이 속성이고 무엇이 메서드인지 구분할 수 있습니다.

```run
import pandas as pd

df = pd.DataFrame({"lot": ["A0915", "A0916", "A0917"], "defects": [18, 7, 25]})
print(df.shape)       # 속성: (행 수, 열 수)
print(df.head(2))     # 메서드: 앞의 2행을 보여 줘
```

`df.shape`는 괄호가 없으니 **표가 가진 값**(3행 2열)이고, `df.head(2)`는 괄호가 있으니 **표에게 시킨 일**(앞 2행 보여 주기)입니다. pandas 코드를 읽을 때 이 구분이 계속 쓰입니다.

### 정리

- 파이썬의 모든 값은 **객체**다. 객체의 종류(설계도)를 **클래스**라고 하며, `type()`이 보여 준다.
- **속성** = 객체가 가진 값, `객체.이름` (괄호 없음). 예: `made.year`, `df.shape`
- **메서드** = 객체에게 시키는 일, `객체.이름()` (괄호 있음). 예: `made.weekday()`, `df.head()`
- 괄호를 빠뜨리면 `<built-in method ...>`처럼 메서드 자체가 출력된다.
- 메서드는 **새 값을 돌려주는 것**(`upper`)과 **원본을 바꾸고 None을 돌려주는 것**(`sort`, `append`)이 있다.
- 객체에 무엇이 있는지는 `dir(객체)`로 둘러본다.
