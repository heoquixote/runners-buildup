[이름으로 찾는 딕셔너리, 중복 없는 Set](#/l/pb-06-1)에서는 `{"A": 3}`처럼 key 하나에 숫자 하나가 붙은 딕셔너리를 봤습니다. 실제 기록은 더 복잡합니다. 설비 하나에 온도·압력·상태가 함께 붙고, 라인 하나에 측정값이 여러 개 쌓입니다. 이 레슨에서는 **값 자리에 리스트나 딕셔너리를 넣어** 표 같은 기록을 담고, 꺼내고, 고치는 법을 배웁니다.

### 표의 한 행 = 딕셔너리 하나

엑셀 표를 떠올리면 쉽습니다. **열 이름이 key, 칸의 값이 value**입니다.

| lot | line | qty | defects |
| --- | --- | --- | --- |
| A0915 | L1 | 1250 | 18 |

```run
row = {"lot": "A0915", "line": "L1", "qty": 1250, "defects": 18}
print(row["lot"], row["qty"])
print(f"불량률 {row['defects'] / row['qty']:.2%}")
```

리스트였다면 `row[3]`처럼 몇 번째 칸인지 외워야 하지만, 딕셔너리는 `row["defects"]`처럼 **이름으로** 꺼내서 코드가 읽기 쉽습니다. f-string 안에서는 바깥 따옴표와 다른 따옴표(`'defects'`)를 씁니다.

### 값이 리스트인 딕셔너리

라인별로 측정값을 여러 개 모을 때는 값 자리에 리스트를 넣습니다.

```run
temps = {"L1": [23.1, 23.4, 22.8], "L2": [24.0, 24.6]}
print(temps["L1"])
print(temps["L1"][-1])
print(len(temps["L2"]))
```

`temps["L1"]`이 리스트이므로 그 뒤에 리스트 문법(`[-1]`, `len`)을 이어 씁니다. **바깥(딕셔너리 key) → 안쪽(리스트 번호)** 순서입니다.

값 리스트에 측정값을 추가할 때는 그 리스트에 `append()`합니다.

```run
temps = {"L1": [23.1, 23.4], "L2": [24.0]}
temps["L2"].append(24.6)
temps["L3"] = [22.5]          # 새 라인은 새 리스트로
print(temps)
```

### 딕셔너리 안의 딕셔너리

설비마다 여러 항목을 붙이려면 값 자리에 딕셔너리를 넣습니다. key를 두 번 써서 꺼냅니다.

```run
equip = {
    "EQ-07": {"temp": 78.5, "pressure": 1.2, "status": "RUN"},
    "EQ-08": {"temp": 91.0, "pressure": 1.4, "status": "ALARM"},
}
print(equip["EQ-08"]["status"])
print(equip["EQ-07"]["temp"])
```

`ALARM`과 78.5입니다. 안쪽 값을 고치는 것도 같은 방식입니다.

```run
equip = {"EQ-08": {"temp": 91.0, "status": "ALARM"}}
equip["EQ-08"]["status"] = "STOP"
print(equip)
```

### 리스트 안의 딕셔너리: 여러 행

표 전체(여러 행)는 **딕셔너리를 리스트에 담습니다.** 파일에서 표를 읽으면([파일 입출력 (CSV · JSON)](#/l/pb-10-1)) 대부분 이 모양이 됩니다.

```run
rows = [
    {"lot": "A0915", "qty": 1250, "defects": 18},
    {"lot": "A0916", "qty": 980, "defects": 7},
]
print(len(rows))
print(rows[1]["lot"], rows[1]["defects"])
```

행이 2개, 두 번째 행은 A0916, 불량 7개입니다. 이번에는 **바깥(리스트 번호) → 안쪽(key)** 순서입니다. 모든 행을 차례로 계산하는 것은 다음 코스 [제어문 (if · for · while)](#/l/pb-07-1)의 반복문으로 합니다.

### 여러 값 한 번에 바꾸기: update

`update()`에 딕셔너리를 넣으면 **있는 key는 값을 바꾸고, 없는 key는 새로 추가**합니다.

```run
row = {"lot": "A0915", "qty": 1250}
row.update({"qty": 1240, "defects": 18})
print(row)
```

qty는 1240으로 바뀌고 defects가 새로 생겼습니다.

### 지우기: pop과 del

`pop(key)`는 그 항목을 지우면서 **값을 돌려줍니다.** 값이 필요 없으면 `del`을 씁니다.

```run
row = {"lot": "A0915", "qty": 1250, "memo": "재검"}
memo = row.pop("memo")
print(memo)
del row["qty"]
print(row)
```

```run
equip = {"EQ-07": {"temp": 78.5}, "EQ-08": {"temp": 91.0}}
name = "EQ-08"                 # "EQ-07" 로 바꿔 보세요
print(name in equip, equip[name]["temp"])
```

### 자주 하는 실수

| 실수 | 결과 | 고치기 |
| --- | --- | --- |
| 없는 key로 `d["EQ-99"]` | KeyError | `in`으로 확인하거나 `get()` |
| `"eq-07"`과 `"EQ-07"` | 다른 key로 취급 | 넣을 때 `upper()`로 맞추기 |
| 값 리스트에 `d["L1"] + [24.6]`만 씀 | 원본 그대로 | `d["L1"].append(24.6)` |
| 중첩 꺼내기 순서 혼동 | KeyError, TypeError | 바깥부터 한 겹씩 `print`로 확인 |
