설비 로그나 검사 기록은 대부분 글자로 남습니다. 그 안에 "ERROR가 있나", "몇 번 나왔나", "어디서 시작하나", "숫자만 들어 있나"를 묻는 일이 매일 생깁니다. pb-03-1이 텍스트를 **고치는** 메서드였다면, 이번에는 텍스트를 **찾고 세고 검사하는** 도구입니다. 모두 원본을 바꾸지 않고 답(True/False, 위치, 개수)만 돌려줍니다.

### in: 들어 있는가

`"찾을 글자" in 문자열`은 들어 있으면 True, 없으면 False입니다. 메서드가 아니라 연산자라서 점을 찍지 않습니다.

```run
log = "2024-09-15 10:32 EQ-07 ERROR Temp High"
print("ERROR" in log)
print("WARN" in log)
print("WARN" not in log)
```

True, False, True입니다. `not in`은 "들어 있지 않은가"입니다.

### find: 어디에 있는가

`find()`는 찾는 글자가 **처음 나오는 번호**를 돌려줍니다. 못 찾으면 **-1**을 돌려줍니다.

```run
log = "2024-09-15 10:32 EQ-07 ERROR Temp High"
print(log.find("EQ"))
print(log.find("WARN"))
```

`EQ`는 17번 자리에서 시작하고, `WARN`은 없어서 -1입니다. -1은 "맨 끝 글자"라는 뜻이 아니라 "못 찾음"이라는 약속입니다. 찾은 번호는 슬라이싱과 함께 쓰면 위치가 매번 달라도 원하는 부분을 꺼낼 수 있습니다.

```run
log = "2024-09-15 10:32 EQ-07 ERROR Temp High"
i = log.find("EQ")
print(log[i:i + 5])
```

`EQ-07`이 나옵니다. 비슷한 메서드 `index()`는 못 찾으면 -1 대신 에러(ValueError)를 냅니다.

### count: 몇 번 나오는가

```run
results = "PPFPPPFFPP"     # P 합격, F 불합격
print(results.count("F"))
print(results.count("FF"))
```

불합격은 3번, 연속 불합격 `FF`는 1번 나옵니다. 겹치는 부분은 두 번 세지 않습니다.

### startswith, endswith: 어떻게 시작하고 끝나는가

코드의 앞뒤 규칙을 확인할 때 씁니다. 괄호 안에 **튜플**(값 여러 개를 괄호로 묶은 것, pb-04-2)을 넣으면 그중 하나라도 맞으면 True입니다.

```run
code = "KR24A0915X"
print(code.startswith("KR"))
print(code.startswith(("KR", "VN")))     # KR 이나 VN 으로 시작하는가
print("sensor_0915.csv".endswith(".csv"))
```

모두 True입니다. 파일 이름이 `.csv`로 끝나는지 확인하는 것은 파일을 다룰 때(pb-10) 자주 씁니다.

### is로 시작하는 검사 메서드

| 메서드 | True가 되는 경우 |
| --- | --- |
| `isdigit()` | 모든 글자가 숫자 |
| `isalpha()` | 모든 글자가 문자(한글·영문) |
| `isupper()` | 영문자가 모두 대문자 |
| `isspace()` | 모두 공백 |

```run
print("0915".isdigit())
print("09-15".isdigit())
print("23.4".isdigit())
```

True, False, False입니다. `isdigit()`은 **숫자 글자만** 있어야 True라서, 하이픈이나 소수점이 하나만 있어도 False입니다. 소수 모양인지 확인할 때는 `isdigit()`으로 부족하고, pb-12에서 배우는 `float()` + 예외 처리가 정확합니다.

```run
qty = "1250"           # "12a0", "" 로 바꿔 보세요
print(qty.isdigit())
```

### 대소문자를 맞춘 뒤 비교합니다

사람이 입력한 값은 `Error`, `ERROR`, `error`가 섞여 있습니다. `==`와 `in`은 대소문자를 구분하므로, 먼저 `upper()`나 `lower()`로 한쪽으로 맞추고 비교합니다.

```run
status = " Error "
print(status == "ERROR")
print(status.strip().upper() == "ERROR")
```

False, True입니다. `strip()`으로 앞뒤 공백을 지우고 `upper()`로 대문자를 맞춘 다음 비교했습니다. 메서드는 이렇게 점을 이어서 **왼쪽부터 차례로** 적용할 수 있습니다.

### 정리

| 묻고 싶은 것 | 코드 | 돌려주는 값 |
| --- | --- | --- |
| 들어 있나 | `"ERR" in s` | True / False |
| 어디 있나 | `s.find("ERR")` | 번호, 없으면 -1 |
| 몇 번 | `s.count("F")` | 개수 |
| 이렇게 시작하나 | `s.startswith("KR")` | True / False |
| 숫자만 있나 | `s.isdigit()` | True / False |
