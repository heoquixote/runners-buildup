CSV가 **표**를 담는 파일이라면, JSON은 **딕셔너리와 리스트**를 그대로 담는 파일입니다. 설비 설정값, 검사 기준표, API가 돌려주는 데이터, 분석 결과 요약처럼 겹겹이 들어간 구조는 JSON이 잘 맞습니다. 이 레슨에서는 JSON 글자와 파이썬 값을 오가는 법, 설정 파일을 읽고 고쳐 다시 저장하는 흐름을 익힙니다.

### JSON과 파이썬은 거의 같은 모양입니다

| JSON | 파이썬 |
| --- | --- |
| `{"a": 1}` 객체 | 딕셔너리 |
| `[1, 2]` 배열 | 리스트 |
| `"글자"` | 문자열 |
| `12`, `3.5` | int, float |
| `true` / `false` | `True` / `False` |
| `null` | `None` |

차이는 두 가지입니다. JSON은 문자열과 key에 **큰따옴표만** 쓰고, 참·거짓과 빈 값을 **소문자** `true`, `false`, `null`로 씁니다.

### 파이썬 값 → JSON 글자: dumps

`json.dumps()`는 파이썬 값을 JSON **문자열**로 바꿉니다(dump + s, string의 s). 한글이 `온` 같은 기호로 바뀌지 않게 `ensure_ascii=False`, 보기 좋게 줄을 바꾸려면 `indent=2`를 줍니다.

```run
import json

spec = {"product": "볼트-M8", "length": [9.5, 10.5], "visual_check": True, "memo": None}
print(json.dumps(spec))
print(json.dumps(spec, ensure_ascii=False, indent=2))
```

첫 줄은 한글이 기호로 바뀌고 한 줄로 붙어 있습니다. 둘째는 사람이 읽기 좋은 모양입니다. `True`가 `true`로, `None`이 `null`로 바뀐 것도 확인하세요.

### JSON 글자 → 파이썬 값: loads

반대로 JSON 문자열을 받으면 `json.loads()`로 딕셔너리로 바꿉니다. 바꾼 뒤에는 pb-06-2에서 배운 대로 key를 따라 꺼냅니다.

```run
import json

text = '{"equip": "EQ-07", "sensors": {"temp": 78.5, "pressure": 1.2}, "alarms": ["E205", "E310"], "ok": false}'
data = json.loads(text)
print(type(data))
print(data["sensors"]["temp"])
print(data["alarms"][-1], data["ok"])
```

딕셔너리가 됐고, 온도 78.5, 마지막 알람 E310, `false`는 파이썬 `False`로 바뀌었습니다.

### 파일로 저장하고 불러오기: dump, load

`s`가 없는 `json.dump()`, `json.load()`는 문자열 대신 **파일**을 다룹니다.

| 함수 | 방향 | 다루는 것 |
| --- | --- | --- |
| `json.dumps(값)` | 파이썬 → JSON | 문자열 |
| `json.loads(문자열)` | JSON → 파이썬 | 문자열 |
| `json.dump(값, f)` | 파이썬 → JSON | 파일 |
| `json.load(f)` | JSON → 파이썬 | 파일 |

```run
import json

config = {"line": "L2", "spec": {"low": 9.5, "high": 10.5}, "sample_every": 5}
with open("config.json", "w", encoding="utf-8") as f:
    json.dump(config, f, ensure_ascii=False, indent=2)

with open("config.json", encoding="utf-8") as f:
    loaded = json.load(f)
print(loaded["spec"]["high"], loaded == config)
```

10.5, True입니다. 저장했다 불러온 값이 원래 딕셔너리와 똑같습니다.

### 설정 파일 읽고 → 고치고 → 저장하기

설비 설정을 JSON으로 두면 코드를 고치지 않고 파일만 바꿔 기준을 바꿀 수 있습니다. 실무에서 가장 자주 하는 흐름입니다.

```run
import json

with open("config.json", "w", encoding="utf-8") as f:
    json.dump({"line": "L2", "spec": {"low": 9.5, "high": 10.5}}, f)

with open("config.json", encoding="utf-8") as f:
    config = json.load(f)
config["spec"]["high"] = 10.4          # 상한 강화
config["updated_by"] = "QA"            # 새 항목
with open("config.json", "w", encoding="utf-8") as f:
    json.dump(config, f, ensure_ascii=False, indent=2)

with open("config.json", encoding="utf-8") as f:
    print(f.read())
```

### 설정값으로 판정하기

불러온 설정을 판정 코드에 그대로 씁니다. 규격이 바뀌어도 코드는 그대로입니다.

```run
import json

text = '{"spec": {"low": 9.5, "high": 10.5}}'     # high 를 10.2 로 바꿔 보세요
spec = json.loads(text)["spec"]
sizes = [10.1, 10.3, 9.8]
for s in sizes:
    ok = spec["low"] <= s <= spec["high"]
    print(s, "합격" if ok else "불합격")
```

### 자주 하는 실수

JSON은 작은따옴표를 허용하지 않습니다. 파이썬 딕셔너리를 `print()`한 결과를 JSON 파일에 붙여 넣으면 이 에러가 납니다.

```python
json.loads("{'lot': 'A0915'}")
```

```
json.decoder.JSONDecodeError: Expecting property name enclosed in double quotes
```

파이썬 값을 JSON으로 만들 때는 직접 쓰지 말고 항상 `json.dumps()`나 `json.dump()`를 거칩니다.

| 실수 | 결과 | 고치기 |
| --- | --- | --- |
| 작은따옴표 JSON | JSONDecodeError | `json.dumps()`로 만들기 |
| `json.load("config.json")` | 파일 이름 문자열을 넘김 | `with open(...) as f:` 후 `json.load(f)` |
| 한글이 `설` 로 저장 | 읽기 어려움 | `ensure_ascii=False` |
| 저장할 때 `"w"` 대신 `"a"` | JSON 두 개가 붙어 깨진 파일 | 덮어쓰기 `"w"` |
