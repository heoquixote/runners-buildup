### 시작하기 전에

[함수 안에서 세고 찾고 집계하기](#/l/pb-09-1)에서 "종류마다 몇 개인가"를 딕셔너리와 `get`으로 셌습니다.

```run
defects = ["scratch", "dent", "scratch", "crack", "scratch", "dent"]
counts = {}
for d in defects:
    counts[d] = counts.get(d, 0) + 1
print(counts)
```

`{'scratch': 3, 'dent': 2, 'crack': 1}`입니다. 세기와 묶기는 데이터 처리에서 가장 자주 하는 일이라, 표준 라이브러리의 `collections` 모듈에 전용 도구가 있습니다. 이번 레슨에서는 **세는 도구 `Counter`**와 **묶는 도구 `defaultdict`**를 배웁니다. 둘 다 데이터 분석 트랙의 `value_counts()`, `groupby`와 같은 생각이라, 여기서 익혀 두면 pandas가 훨씬 쉬워집니다.

### Counter: 한 줄로 세기

`Counter(목록)`은 목록 안의 값이 각각 몇 번 나오는지 세어 줍니다. 위의 반복문 네 줄이 한 줄이 됩니다.

```run
from collections import Counter

defects = ["scratch", "dent", "scratch", "crack", "scratch", "dent"]
counts = Counter(defects)
print(counts)
print(counts["scratch"])
```

`Counter({'scratch': 3, 'dent': 2, 'crack': 1})`이 나오고, 많은 순서로 보여 줍니다. `Counter`는 딕셔너리의 한 종류라서 `counts["scratch"]`처럼 key로 꺼내고, `items()`, `keys()`도 그대로 씁니다.

### most_common: 많은 것부터 n개

"가장 많은 불량 유형 2개"처럼 상위 몇 개가 필요할 때는 `most_common(n)`을 씁니다. `(값, 개수)` 튜플의 리스트를 돌려줍니다.

```run
from collections import Counter

defects = ["scratch", "dent", "scratch", "crack", "scratch", "dent"]
counts = Counter(defects)
print(counts.most_common(2))
top, n = counts.most_common(1)[0]
print(f"가장 많은 불량: {top} ({n}건)")
```

`[('scratch', 3), ('dent', 2)]`이고, 1등만 꺼내 언패킹하면 `scratch`와 `3`입니다. 품질 회의의 "파레토 분석"(많은 불량 순으로 줄 세우기)을 이 한 줄로 시작할 수 있습니다.

### 없는 값은 0

보통 딕셔너리는 없는 key를 꺼내면 `KeyError`가 납니다. `Counter`는 **0을 돌려줍니다**. "한 번도 안 나왔다"는 뜻이니 자연스럽습니다.

```run
from collections import Counter

counts = Counter(["scratch", "dent", "scratch"])
print(counts["crack"])
print("crack" in counts)
```

`0`과 `False`입니다. 꺼내도 에러는 나지 않지만, key로 들어가지는 않습니다.

문자열을 넣으면 **글자마다** 셉니다. 검사 결과를 한 글자씩 기록한 코드(`P` = 합격, `F` = 불합격)를 셀 때 편합니다.

```run
from collections import Counter

result = "PPFPPPFPPP"
print(Counter(result))
```

`P` 8개, `F` 2개입니다.

### 두 Counter 더하기

`Counter`끼리는 `+`로 더할 수 있습니다. 같은 key의 개수가 합쳐집니다. 오전 · 오후 집계를 하루치로 합칠 때 씁니다.

```run
from collections import Counter

am = Counter(["scratch", "dent", "scratch"])
pm = Counter(["dent", "crack", "dent"])
print(am + pm)
```

`scratch` 2, `dent` 3, `crack` 1입니다. 일반 딕셔너리였다면 key마다 반복하며 더해야 합니다.

### 그룹별로 모으기: 일반 딕셔너리로 하면

이번에는 세는 것이 아니라 **묶는** 일입니다. 측정값을 라인별 목록으로 모으고 싶습니다. 일반 딕셔너리로 하면 "처음 보는 라인이면 빈 리스트부터 만들기"를 매번 챙겨야 합니다.

```run
records = [("A", 10.1), ("B", 10.6), ("A", 9.8), ("B", 10.9), ("A", 10.4)]
groups = {}
for line, v in records:
    if line not in groups:
        groups[line] = []
    groups[line].append(v)
print(groups)
```

`if` 두 줄을 빼먹으면 첫 `append`에서 `KeyError: 'A'`가 납니다. 없는 key `groups["A"]`를 꺼내려 했기 때문입니다.

### defaultdict: 없으면 빈 그릇부터

`defaultdict(list)`는 **없는 key를 꺼내는 순간 빈 리스트를 자동으로 만들어 넣는** 딕셔너리입니다. 괄호 안에는 "빈 그릇을 만드는 방법"을 넣습니다. `list()`를 부르면 `[]`가 나오기 때문에 `list`를 넣습니다(괄호 없이 이름만).

```run
from collections import defaultdict

records = [("A", 10.1), ("B", 10.6), ("A", 9.8), ("B", 10.9), ("A", 10.4)]
groups = defaultdict(list)
for line, v in records:
    groups[line].append(v)
print(dict(groups))
```

`{'A': [10.1, 9.8, 10.4], 'B': [10.6, 10.9]}`입니다. `if`가 사라졌습니다. 출력할 때 `dict()`로 감싼 것은 보기 좋게 일반 딕셔너리 모양으로 바꾼 것입니다.

모은 뒤에는 그룹마다 계산합니다. [컴프리헨션 넓히기: 조건식 · 딕셔너리 · Set](#/l/pb-11-2)의 딕셔너리 컴프리헨션과 잘 맞습니다.

```run
from collections import defaultdict

records = [("A", 10.1), ("B", 10.6), ("A", 9.8), ("B", 10.9), ("A", 10.4)]
groups = defaultdict(list)
for line, v in records:
    groups[line].append(v)
means = {line: round(sum(vs) / len(vs), 2) for line, vs in groups.items()}
print(means)
```

라인 A 평균 10.1, B 평균 10.75입니다. **"묶고(group) → 계산한다(aggregate)"**, 이 두 단계가 바로 pandas `groupby`가 하는 일입니다.

`defaultdict(int)`는 빈 그릇이 `0`입니다(`int()`는 0). 그룹별 **합계**를 낼 때 씁니다.

```run
from collections import defaultdict

records = [("A", 18), ("B", 7), ("A", 6), ("B", 12), ("A", 3)]
total = defaultdict(int)
for line, d in records:
    total[line] += d
print(dict(total))
```

라인 A 불량 27개, B 19개입니다. 일반 딕셔너리였다면 `total[line] += d`에서 `KeyError`가 납니다.

| 하고 싶은 일 | 도구 | 빈 그릇 |
| --- | --- | --- |
| 값마다 몇 개인지 세기 | `Counter(목록)` | (알아서 0) |
| 그룹별로 목록 모으기 | `defaultdict(list)` → `d[k].append(v)` | `[]` |
| 그룹별 합계 | `defaultdict(int)` → `d[k] += v` | `0` |
| 그룹별 고유값 모으기 | `defaultdict(set)` → `d[k].add(v)` | `set()` |

### 다음 트랙 미리보기: pandas에서는

데이터 분석 트랙에서는 표의 열에 같은 일을 시킵니다. `value_counts()`가 `Counter`, `groupby(...).mean()`이 `defaultdict`로 묶고 평균 내기입니다.

```run
import pandas as pd

df = pd.DataFrame({"line": ["A", "B", "A", "B", "A"], "size": [10.1, 10.6, 9.8, 10.9, 10.4]})
print(df["line"].value_counts())
print(df.groupby("line")["size"].mean())
```

결과가 위에서 직접 계산한 것과 같습니다(A 3개 · 평균 10.1, B 2개 · 평균 10.75). 원리를 알고 쓰면 결과가 이상할 때 어디를 의심할지 알 수 있습니다.

### 정리

- `from collections import Counter, defaultdict`
- `Counter(목록)`: 값마다 개수. 없는 key는 0, `most_common(n)`으로 상위 n개, `+`로 합치기.
- `defaultdict(list)`: 없는 key를 꺼내면 빈 리스트를 만들어 준다. 그룹별로 모을 때 `d[k].append(v)` 한 줄.
- `defaultdict(int)`: 빈 그릇이 0. 그룹별 합계 `d[k] += v`.
- 세기 = pandas `value_counts()`, 묶고 계산하기 = pandas `groupby`.
