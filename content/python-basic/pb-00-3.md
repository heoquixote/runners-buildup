## 이런 분께 맞습니다

- 내 PC에서 회사 데이터를 다뤄야 하는데, 패키지를 하나하나 설치하기는 어려울 때
- 데이터 분석 위주로 쓰고, 프로그램 개발까지는 생각하지 않을 때
- 노트북(Jupyter) 화면이 익숙하거나, 결과를 셀 단위로 보며 분석하고 싶을 때

**준비물**: 설치 권한이 있는 PC, 저장 공간 약 5GB, 인터넷.

**내려받기**: [anaconda.com/download](https://www.anaconda.com/download) (새 탭에서 열립니다)

> Anaconda(아나콘다)는 **파이썬 + 데이터 분석 패키지 수백 개 + Jupyter**를 한 상자에 담은 "종합 선물 세트"입니다. 설치 한 번으로 pandas, NumPy, matplotlib, scikit-learn을 바로 쓸 수 있습니다. 대신 용량이 큽니다.

### 먼저 확인할 것: 라이선스

Anaconda 배포판은 개인과 교육 목적은 무료지만, **직원 200명 이상인 조직에서 업무용으로 쓰면 유료 라이선스**가 필요합니다(2024년 기준 정책). 회사 PC라면 IT 담당자에게 먼저 물어보세요. 쓰기 어렵다면 [python.org + VS Code](#/l/pb-00-4) 레슨을 따라 하면 됩니다.

### 세 가지 프로그램의 관계

설치가 끝나면 시작 메뉴에 프로그램이 여러 개 생깁니다. 역할은 이렇습니다.

| 이름 | 하는 일 | 언제 쓰나 |
| --- | --- | --- |
| **Anaconda Navigator** | 버튼으로 Jupyter 등을 실행하는 런처 | 명령어가 낯설 때 |
| **Anaconda Prompt** (macOS는 터미널) | `conda`, `pip`, `jupyter` 명령을 입력하는 창 | 패키지 설치, Jupyter 실행 |
| **Jupyter Notebook / JupyterLab** | 브라우저에서 노트북을 쓰고 실행하는 화면 | 실제 분석 작업 |

## 따라 하기: Windows

### 1단계. 설치 파일 내려받기

1. [anaconda.com/download](https://www.anaconda.com/download) 에 접속합니다.
2. 이메일 입력 화면이 나오면 이메일을 넣거나, 아래쪽 **Skip registration**으로 건너뜁니다.
3. **Windows 64-Bit Graphical Installer**를 내려받습니다.

### 2단계. 설치하기

1. **Install for**: **Just Me**를 고릅니다. (관리자 권한 문제가 적습니다.)
2. **Destination Folder**: 경로에 **한글이나 띄어쓰기가 없어야** 합니다. Windows 사용자 이름이 한글이면(예: `C:\Users\홍길동`) 경로를 `C:\anaconda3` 처럼 바꿉니다.
3. **Advanced Options**: "Add Anaconda3 to my PATH"는 **체크하지 않습니다**. 다른 프로그램과 충돌할 수 있어 Anaconda도 권장하지 않습니다. 대신 Anaconda Prompt를 씁니다.

설치는 5~15분 걸립니다. 끝나면 Finish를 누릅니다.

### 3단계. Jupyter 열기

시작 메뉴에서 **Anaconda Prompt**를 열고 아래를 입력한 뒤 Enter를 누릅니다.

```
jupyter lab
```

잠시 뒤 브라우저가 자동으로 열리며 JupyterLab 화면이 나옵니다. **검은 Prompt 창은 닫지 마세요.** 그 창이 Jupyter를 돌리는 엔진입니다. 명령어 대신 **Anaconda Navigator**를 열고 JupyterLab의 **Launch** 버튼을 눌러도 됩니다.

## 따라 하기: macOS

### 1단계. 내 Mac의 칩 확인하기

화면 왼쪽 위 **Apple 메뉴 → 이 Mac에 관하여**를 누릅니다. "칩"에 **Apple M1/M2/M3…**가 보이면 Apple Silicon, "프로세서"에 **Intel**이 보이면 Intel Mac입니다.

### 2단계. 내려받고 설치하기

1. [anaconda.com/download](https://www.anaconda.com/download) 에서 칩에 맞는 **Graphical Installer**(`.pkg`)를 내려받습니다. (Apple Silicon은 "Apple Silicon", Intel은 "Intel chip")
2. `.pkg` 파일을 더블클릭하고 계속, 동의, 설치를 차례로 누릅니다. Mac 암호를 물으면 입력합니다.

### 3단계. Jupyter 열기

**응용 프로그램 → 유틸리티 → 터미널**을 열고 입력합니다. 터미널 맨 앞에 `(base)` 가 보이면 Anaconda가 준비된 상태입니다.

```
jupyter lab
```

명령어 대신 Launchpad에서 **Anaconda-Navigator**를 열고 JupyterLab **Launch**를 눌러도 됩니다.

## 첫 코드 실행 확인

새 노트북 셀에 아래 코드를 넣고 실행합니다. 세 줄이 모두 나오면 성공입니다.

```
import sys
import pandas as pd
print("파이썬 버전:", sys.version.split()[0])
print("pandas 버전:", pd.__version__)
print("파이썬 위치:", sys.executable)
```

마지막 줄의 위치에 `anaconda3`가 들어 있으면 Anaconda의 파이썬으로 실행되고 있는 것입니다.

새 패키지가 필요할 때는 Anaconda Prompt(macOS 터미널)에서 설치합니다.

```
conda install 패키지이름
pip install 패키지이름      # conda에 없는 패키지일 때
```

## 자주 막히는 문제와 해결법

| 증상 | 원인 | 해결 |
| --- | --- | --- |
| 설치 중 오류, 또는 설치 뒤 Jupyter가 안 열림 | 설치 경로나 사용자 폴더에 한글·띄어쓰기가 있음 | 제어판에서 제거한 뒤 `C:\anaconda3` 같은 영문 경로로 다시 설치 |
| `'conda'은(는) 내부 또는 외부 명령...이 아닙니다` | 일반 명령 프롬프트(cmd)나 PowerShell에서 입력함 | 시작 메뉴의 **Anaconda Prompt**에서 입력 |
| `jupyter lab` 을 쳐도 브라우저가 안 열림 | 기본 브라우저 설정 문제 | Prompt에 출력된 `http://localhost:8888/lab?token=...` 주소를 복사해 브라우저에 붙여넣기 |
| 만든 노트북 파일이 어디 있는지 모르겠음 | Jupyter를 실행한 폴더 기준으로 저장됨 | 셀에서 `import os; print(os.getcwd())` 실행해 위치 확인 |
| Jupyter 화면이 갑자기 "연결 끊김" | Prompt(터미널) 창을 닫아 Jupyter가 꺼짐 | Prompt를 다시 열고 `jupyter lab` 재실행 |
| 회사에서 Anaconda 사용이 막힘 | 조직 라이선스 정책 | 패키지 관리만 하는 가벼운 **Miniconda**를 쓰거나 [python.org + VS Code](#/l/pb-00-4) 방식으로 설치 |
