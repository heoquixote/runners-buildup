pb-09-1에서 세기·최댓값 찾기·조건 모으기를 반복문으로 직접 짰습니다. 원리를 알았으니 이제 **파이썬이 미리 만들어 둔 내장 함수**로 같은 일을 한 줄에 하는 법을 배웁니다. 내장 함수는 짧고, 빠르고, 실수할 자리가 적습니다.

| 하고 싶은 일 | 반복문으로 | 내장 함수로 |
| --- | --- | --- |
| 합계 | `total += v` 반복 | `sum(values)` |
| 최댓값 | 비교하며 갱신 | `max(values)` |
| 기준을 정한 최댓값 | 비교 대상을 골라 갱신 | `max(items, key=...)` |
| 하나라도 조건 만족? | 찾으면 `break` | `any(...)` |
| 모두 조건 만족? | 하나라도 아니면 `break` | `all(...)` |
| 두 목록 짝 맞추기 | 번호로 접근 | `zip(a, b)` |

### 합계와 평균

```run
qty = [1250, 980, 1100, 1310]
print(sum(qty), len(qty))
print(round(sum(qty) / len(qty), 1))
```

합계 4640, 평균 1160.0입니다.

### 최댓값의 "주인" 찾기: max의 key

`max(stock)`처럼 딕셔너리를 그냥 넣으면 **key 중 가장 큰 것(글자 순서)**이 나옵니다. "값이 가장 큰 key"를 찾으려면 `key=`에 비교 기준을 넘깁니다. `d.get`은 key를 넣으면 값을 돌려주는 함수라서 기준으로 딱 맞습니다.

```run
defects = {"L1": 18, "L2": 7, "L3": 25}
print(max(defects))                    # key 글자 순서로 가장 큰 것
print(max(defects, key=defects.get))   # 값이 가장 큰 key
print(min(defects, key=defects.get))
```

`L3`, `L3`, `L2`입니다. 첫 줄의 L3은 우연히 글자 순서로도 마지막이라 같아 보일 뿐입니다. 기록이 튜플 리스트이면 `lambda`로 기준 위치를 정합니다(pb-11-1).

```run
records = [("A0915", 1250, 18), ("A0916", 980, 7), ("A0917", 1100, 25)]
worst = max(records, key=lambda r: r[2] / r[1])     # 불량률 기준
print(worst[0], f"{worst[2] / worst[1]:.2%}")
```

불량률이 가장 높은 로트는 A0917(2.27%)입니다. `max`는 기준값(불량률)이 아니라 **그 기준이 가장 큰 원소 전체**를 돌려줍니다.

### any와 all: 하나라도? 모두?

`any()`는 하나라도 True면 True, `all()`은 전부 True여야 True입니다. 괄호 안에 조건을 반복으로 쓰는 모양(생성식)과 함께 씁니다.

```run
sizes = [10.1, 10.3, 9.2, 10.0]
print(any(s < 9.5 for s in sizes))            # 규격 미달이 하나라도?
print(all(9.5 <= s <= 10.5 for s in sizes))   # 전부 규격 안?
```

True, False입니다. 9.2 하나 때문입니다. `s < 9.5 for s in sizes`는 "sizes의 각 s에 대해 s < 9.5인가"를 차례로 만들어 내는 식으로, pb-11의 컴프리헨션과 같은 모양에서 대괄호만 뺀 것입니다.

```run
sizes = [10.1, 10.3, 9.8, 10.0]     # 값을 바꿔 보세요
if all(9.5 <= s <= 10.5 for s in sizes):
    print("로트 합격")
else:
    print("로트 불합격")
```

### zip으로 두 목록의 차이

목표 수량과 실적을 라인 순서대로 갖고 있으면 `zip()`으로 짝지어 바로 계산합니다(pb-07-2).

```run
lines = ["L1", "L2", "L3"]
target = [1200, 1000, 1100]
actual = [1250, 980, 1100]
for line, t, a in zip(lines, target, actual):
    print(line, a - t)
```

L1은 목표보다 50개 많고, L2는 20개 모자라고(-20), L3은 딱 맞습니다(0). `zip`은 목록을 셋 이상도 묶습니다.

### abs와 round: 편차 다루기

`abs()`는 부호를 뗀 크기입니다. 기준값에서 위로든 아래로든 **얼마나 벗어났는지** 볼 때 씁니다.

```run
nominal = 10.0
sizes = [10.1, 9.7, 10.4, 9.9]
devs = []
for s in sizes:
    devs.append(round(abs(s - nominal), 2))
print(devs)
print(max(devs))
```

편차는 `[0.1, 0.3, 0.4, 0.1]`, 가장 크게 벗어난 것은 0.4입니다. `round(..., 2)`는 소수 오차(pb-01-2)를 정리하려고 넣었습니다.

### 정리

반복문으로 직접 짤 줄 알아야 문제를 쪼갤 수 있고, 내장 함수를 알아야 코드가 짧아집니다. 함수 문제를 풀 때는 먼저 **"이건 sum/max/any로 되나?"**를 떠올리고, 안 되면 pb-09-1의 패턴으로 직접 짭니다.

| 함수 | 돌려주는 것 |
| --- | --- |
| `sum(x)`, `len(x)` | 합계, 개수 |
| `max(x, key=f)`, `min(x, key=f)` | 기준 f가 가장 큰·작은 **원소** |
| `any(조건 for v in x)` | 하나라도 참이면 True |
| `all(조건 for v in x)` | 모두 참이면 True |
| `abs(x)`, `round(x, n)` | 절댓값, 반올림 |
