[for문 세 줄을 한 줄로, 정렬 기준은 lambda로](#/l/pb-11-1)에서 `[식 for 변수 in 목록 if 조건]`으로 리스트를 한 줄에 만들었습니다. 이 레슨에서는 컴프리헨션을 세 방향으로 넓힙니다. 값마다 **라벨을 붙이는 조건식**, **딕셔너리**를 만드는 컴프리헨션, **Set**을 만드는 컴프리헨션입니다. 그리고 언제 컴프리헨션 대신 for문을 써야 하는지도 정리합니다.

### 한 줄 if: 조건식

`A if 조건 else B`는 조건이 참이면 A, 거짓이면 B가 되는 **값**입니다. [for 반복 깊게: 리스트 · 문자열 · 딕셔너리 돌기](#/l/pb-07-2)에서 잠깐 봤습니다. if문과 달리 줄을 나누지 않고, 결과가 값이라 변수에 바로 담습니다.

```run
size = 10.8
label = "OK" if 9.5 <= size <= 10.5 else "NG"
print(label)
```

`else`를 빼고 쓸 수는 없습니다. 조건식은 언제나 값 하나를 내놓아야 하기 때문입니다.

### 컴프리헨션 안의 조건식: 모든 값에 라벨 붙이기

조건식을 컴프리헨션 **앞쪽(식 자리)**에 넣으면, 원소를 거르지 않고 **모든 원소를 변환**합니다.

```run
sizes = [10.1, 9.2, 10.4, 10.8]
labels = ["OK" if 9.5 <= s <= 10.5 else "NG" for s in sizes]
print(labels)
```

4개 그대로 `['OK', 'NG', 'OK', 'NG']`가 됩니다. 뒤쪽 `if`([for문 세 줄을 한 줄로, 정렬 기준은 lambda로](#/l/pb-11-1))는 거르기라서 결과 개수가 줄어듭니다. **if의 위치에 따라 뜻이 다릅니다.**

| 모양 | 뜻 | 결과 개수 |
| --- | --- | --- |
| `[s for s in sizes if 조건]` | 조건 맞는 것만 **거른다** | 줄어든다 |
| `[A if 조건 else B for s in sizes]` | 모두 **바꾼다** | 그대로 |

```run
sizes = [10.1, 9.2, 10.4, 10.8]
print([s for s in sizes if s > 10.5])
print([round(s - 10.0, 1) if s > 10.0 else 0 for s in sizes])
```

첫 줄은 10.8 하나만 남고, 둘째 줄은 4개 모두 남되 10.0을 넘은 만큼(넘지 않으면 0)으로 바뀝니다.

### 딕셔너리 컴프리헨션

중괄호 안에 `key: value for ...`를 쓰면 딕셔너리가 만들어집니다.

```run
lots = ["A0915", "A0916", "A0917"]
defects = [18, 7, 25]
qty = [1250, 980, 1100]
rate = {lot: round(d / q * 100, 2) for lot, d, q in zip(lots, defects, qty)}
print(rate)
```

로트별 불량률(%) 딕셔너리입니다. `zip`([for 반복 깊게: 리스트 · 문자열 · 딕셔너리 돌기](#/l/pb-07-2))으로 세 목록을 묶어 한 줄에 만들었습니다.

딕셔너리에서 조건에 맞는 항목만 남길 때도 씁니다. `items()`로 key와 value를 함께 꺼냅니다.

```run
rate = {"A0915": 1.44, "A0916": 0.71, "A0917": 2.27}
alert = {lot: r for lot, r in rate.items() if r >= 1.0}
print(alert)
```

1% 이상인 두 로트만 남습니다.

### Set 컴프리헨션

중괄호 안에 식만 쓰면(콜론 없이) Set이 됩니다. 중복 없는 값 목록이 필요할 때 씁니다.

```run
codes = ["kr24a0915x", "KR24A0916B", "vn25c1201b", "KR24B0917A"]
plants = {c[:2].upper() for c in codes}
print(sorted(plants))
```

공장 코드는 KR, VN 두 가지입니다. 대소문자를 맞춘 뒤 모았기 때문에 `kr`과 `KR`이 하나로 합쳐졌습니다.

| 괄호 | 안의 모양 | 만들어지는 것 |
| --- | --- | --- |
| `[ ]` | `식 for ...` | 리스트 |
| `{ }` | `key: value for ...` | 딕셔너리 |
| `{ }` | `식 for ...` | Set |

```run
temps = [23.1, 25.4, 22.8, 26.0]       # 기준 25 를 바꿔 보세요
print(["HIGH" if t > 25 else "OK" for t in temps])
```

### 중첩 컴프리헨션: 2차원 리스트 펼치기

라인별 측정값처럼 **리스트 안에 리스트**가 있는 자료를 한 줄로 펼치고 싶을 때가 있습니다. for문으로 쓰면 반복이 두 겹입니다.

```run
grid = [[10.1, 9.8], [10.6, 10.9, 10.7], [10.4]]
flat = []
for row in grid:
    for v in row:
        flat.append(v)
print(flat)
```

컴프리헨션에서는 `for`를 두 번 이어 씁니다. **순서는 풀어 쓴 for문과 똑같이 바깥 → 안쪽**입니다.

```run
grid = [[10.1, 9.8], [10.6, 10.9, 10.7], [10.4]]
flat = [v for row in grid for v in row]
print(flat)
```

| 풀어 쓴 for문 | 컴프리헨션 |
| --- | --- |
| `for row in grid:` | `[v` **`for row in grid`** |
| `    for v in row:` | **`for v in row`** |
| `        flat.append(v)` | `]` 맨 앞의 `v` |

for문을 위에서부터 읽은 순서대로 왼쪽에서 오른쪽으로 적고, 담을 값만 맨 앞으로 옮긴 모양입니다. 거르기 조건도 맨 뒤에 붙일 수 있습니다.

```run
grid = [[10.1, 9.8], [10.6, 10.9, 10.7], [10.4]]
print([v for row in grid for v in row if v > 10.5])
```

`[10.6, 10.9, 10.7]`입니다. `for`가 세 번 이상 겹치면 읽기 어려우니 그때는 for문으로 풀어 씁니다.

### 괄호만 바꾸면: 제너레이터 표현식

합계나 개수처럼 **결과 하나만** 필요할 때는 리스트를 다 만들 필요가 없습니다. 함수 괄호 안에 컴프리헨션을 쓰면 대괄호를 생략할 수 있습니다.

```run
temps = [23.1, 25.4, 26.0, 22.8, 25.9]
print(sum([t for t in temps if t > 25]))     # 리스트를 만든 뒤 더한다
print(sum(t for t in temps if t > 25))       # 하나씩 흘려 보내며 더한다
```

결과는 같습니다. 대괄호 없는 쪽을 **제너레이터 표현식**이라고 부릅니다. 리스트를 메모리에 한꺼번에 만들지 않고, 값을 **하나씩 만들어 바로 넘깁니다**. 값이 수백만 개일 때 차이가 커집니다. [내장 함수로 짧게 쓰기: sum · max(key) · any · all](#/l/pb-09-3)에서 쓴 `any(s < 9.5 for s in sizes)`가 바로 이 모양이었습니다.

```run
sizes = [10.1, 9.2, 10.4, 10.8]
print(any(s < 9.5 for s in sizes))                 # 하나라도?
print(sum(1 for s in sizes if s > 10.5), "개 초과")  # 조건에 맞는 개수
```

`sum(1 for ... if 조건)`은 "조건에 맞을 때마다 1을 더한다", 즉 개수 세기입니다.

함수 괄호 밖에서 소괄호로 감싸 변수에 담을 수도 있지만, 이것은 리스트가 아니라 **한 번 쓰면 끝나는 흐름**입니다.

```run
gen = (t * 2 for t in [1, 2, 3])
print(sum(gen))
print(sum(gen))      # 이미 다 흘려 보냈다
```

처음은 `12`, 두 번째는 `0`입니다. 여러 번 쓸 값이라면 리스트 컴프리헨션(대괄호)으로 만드세요.

| 괄호 | 결과 | 쓰는 곳 |
| --- | --- | --- |
| `[t for t in temps]` | 리스트 (여러 번 쓸 수 있음) | 결과를 저장 · 출력 · 다시 쓸 때 |
| `sum(t for t in temps)` | 값을 하나씩 흘려 보냄 (한 번) | `sum`, `max`, `min`, `any`, `all`, `"".join` 안에서 바로 쓸 때 |

### 언제 for문이 나은가

컴프리헨션은 **짧은 변환이나 거르기 하나**일 때 읽기 좋습니다. 다음 경우에는 for문으로 풀어 쓰는 편이 낫습니다.

- 조건식 안에 조건식이 또 들어갈 때 (`"A" if ... else "B" if ... else "C"`)
- 반복 안에서 `print`, `break`, 여러 변수 갱신 등 **값 만들기 말고 다른 일**도 할 때
- 한 줄이 화면을 넘어갈 때

```run
sizes = [10.1, 9.2, 10.8]
grades = []
for s in sizes:
    if s < 9.5:
        grades.append("미달")
    elif s > 10.5:
        grades.append("초과")
    else:
        grades.append("합격")
print(grades)
```

경우가 셋이면 컴프리헨션 한 줄보다 이 모양이 훨씬 잘 읽힙니다.
