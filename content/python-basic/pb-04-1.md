### 리스트는 여러 값을 순서대로 담는 상자

**리스트**는 대괄호 `[ ]` 안에 값을 쉼표로 나열해 만듭니다. 값 여러 개를 이름 하나로 묶어 다룰 수 있습니다.

```run
temps = [23.1, 23.4, 22.8, 24.0]
print(temps)
```

문자열처럼 **번호는 0부터** 셉니다. 첫 값은 `[0]`, 마지막 값은 `[-1]`입니다.

```run
temps = [23.1, 23.4, 22.8, 24.0]
print(temps[0])
print(temps[-1])
```

슬라이싱도 문자열과 같습니다. `[1:3]`은 1번과 2번 값을 리스트로 돌려줍니다.

```run
temps = [23.1, 23.4, 22.8, 24.0]
print(temps[1:3])
```

`len()`은 리스트에 든 **값의 개수**를 셉니다.

```run
temps = [23.1, 23.4, 22.8, 24.0]
print(len(temps))
```

### 리스트 안의 리스트

리스트 안에 리스트를 넣을 수 있습니다. 표의 **행**을 하나씩 담는 모양이라고 생각하면 됩니다.

```run
lines = [["L1", 980], ["L2", 1010]]
print(lines[1])
```

안쪽 값은 번호를 두 번 씁니다. **바깥 번호 → 안쪽 번호** 순서입니다.

```run
lines = [["L1", 980], ["L2", 1010]]
print(lines[1][1])
```

### 바꾸기와 지우기

번호로 가리킨 자리에 새 값을 대입하면 **수정**됩니다.

```run
q = ["A01", "A02", "A03"]
q[1] = "A02-R"
print(q)
```

`del`은 그 자리의 값을 **삭제**합니다. 뒤에 있던 값들이 한 칸씩 앞으로 당겨집니다.

```run
q = ["A01", "A02", "A03"]
del q[0]
print(q)
```

### append vs extend

`append()`는 괄호 안의 값을 **통째로 하나** 붙입니다. 리스트를 넣으면 리스트가 한 덩어리로 들어갑니다.

```run
a = [1, 2]
a.append([3, 4])
print(a)
```

`extend()`는 괄호 안의 리스트를 **하나씩 풀어서** 붙입니다.

```run
e = [1, 2]
e.extend([3, 4])
print(e)
```

### + 와 *

`+`는 두 리스트를 **이어 붙인 새 리스트**를 만듭니다.

```run
print([1, 2] + [3])
```

`*`는 리스트를 **반복**합니다. 같은 값으로 채운 리스트를 만들 때 씁니다.

```run
print([0] * 3)
```

### 같은 리스트를 두 이름이 가리킬 때

`b = a`는 리스트를 복사하지 않습니다. 같은 리스트에 이름을 하나 더 붙일 뿐이라, b를 고치면 a도 바뀝니다. 원본을 지키는 복사 방법은 이 코스의 세 번째 레슨([참조와 복사: 이름표 두 개, 상자 하나](#/l/pb-04-3) 참조와 복사)에서 자세히 봅니다.
