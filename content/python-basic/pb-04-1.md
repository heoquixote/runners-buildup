### 리스트는 여러 값을 순서대로 담는 상자

```run
temps = [23.1, 23.4, 22.8, 24.0]
print(temps[0])      # 23.1
print(temps[-1])     # 24.0
print(temps[1:3])    # [23.4, 22.8]
print(len(temps))    # 4
```

### 리스트 안의 리스트

```run
lines = [["L1", 980], ["L2", 1010]]
print(lines[1])       # ['L2', 1010]
print(lines[1][1])    # 1010   (바깥 번호 → 안쪽 번호 순서)
```

### 바꾸기와 지우기 (CRUD의 U, D)

```run
q = ["A01", "A02", "A03"]
q[1] = "A02-R"    # 수정
del q[0]          # 삭제
print(q)          # ['A02-R', 'A03']
```

### append vs extend

```run
a = [1, 2]; a.append([3, 4])
print(a)   # [1, 2, [3, 4]]  통째로 1개 추가
e = [1, 2]; e.extend([3, 4])
print(e)   # [1, 2, 3, 4]    하나씩 풀어서 추가
```

### + 와 *

```run
print([1, 2] + [3])   # [1, 2, 3]
print([0] * 3)        # [0, 0, 0]
# 변수는 이름표: b = a 는 같은 리스트를 가리킨다
a = [1, 2]; b = a; b.append(99)
print(a)              # [1, 2, 99]  a도 바뀐다
c = a.copy(); c.append(0)
print(a, c)           # copy()는 새 리스트
```
