### 시작하기 전에

[class로 나만의 객체 만들기: __init__ · self](#/l/pb-14-2)에서 설계도(클래스)를 만들고, 객체가 속성에 상태를 기억하고, 메서드가 그 상태를 쓰거나 바꾸는 것을 봤습니다. 이번 레슨에서는 이 문법으로 **아주 작은 머신러닝 모델**을 직접 만듭니다.

머신러닝 트랙에 가면 거의 모든 예제가 이 세 줄로 시작합니다.

```python
model = DecisionTreeClassifier(max_depth=3)   # ① 모델 객체 만들기
model.fit(X, y)                               # ② 데이터로 배우기
model.predict(new_X)                          # ③ 새 데이터에 답하기
```

이제 읽을 수 있습니다. `DecisionTreeClassifier`는 **클래스**, `model`은 그 **객체**, `fit`과 `predict`는 **메서드**, `max_depth=3`은 `__init__`에 넣는 값입니다. 속에서 무슨 일이 일어나는지, 같은 모양의 클래스를 직접 만들어 확인해 봅시다.

### 세 단계: 뽑고, 가르치고, 일 시키기

모델 객체의 일생은 신입 사원과 비슷합니다.

1. **만들기** `Model()`: 사람을 뽑았습니다. 아직 아무것도 모릅니다. 정할 수 있는 것은 "어떤 방식으로 일할지"(설정값) 정도입니다.
2. **배우기** `fit(X, y)`: 과거 기록(문제 X와 정답 y)으로 교육합니다. 배운 내용은 **머릿속(객체의 속성)**에 저장됩니다.
3. **일하기** `predict(X)`: 처음 보는 문제를 주면, 배운 내용으로 답을 냅니다.

::figure{src="content/img/py/py-fit-predict.svg" alt="MeanModel 객체 상자가 세 단계로 그려져 있다. ① model = MeanModel() 직후 상자 안 mean_은 None이다. ② model.fit([10.1, 9.8, 10.4, 10.3]) 뒤에는 mean_이 10.15로 채워져 있다. ③ model.predict(['new1', 'new2'])는 상자 안 mean_을 꺼내 [10.15, 10.15]를 돌려준다" caption="fit은 배운 결과를 객체 안(속성)에 저장하고, predict는 그 저장된 값을 꺼내 답합니다. 객체가 상태를 기억하기 때문에 가능한 흐름입니다."}

### 가장 단순한 모델: 평균으로 예측하기

어떤 부품의 두께를 예측하는 모델을 만듭니다. 가장 단순한 방법은 "지금까지 잰 두께의 **평균**으로 답하기"입니다. 단순하지만 실제로 쓰는 기준 모델입니다. 더 복잡한 모델이 이 평균보다도 못 맞히면 쓸 이유가 없기 때문입니다.

```run
class MeanModel:
    def __init__(self):
        self.mean_ = None                 # 아직 배운 것이 없다

    def fit(self, y):
        self.mean_ = sum(y) / len(y)      # 배운 결과를 객체 안에 저장
        return self

    def predict(self, X):
        return [self.mean_ for _ in X]    # 문제 수만큼 같은 답

model = MeanModel()
model.fit([10.1, 9.8, 10.4, 10.3])
print(model.mean_)
print(model.predict(["new1", "new2"]))
```

`fit`이 평균 `10.15`를 계산해 `self.mean_`에 저장했고, `predict`는 그 값을 문제 수(2개)만큼 돌려줬습니다. `for _ in X`의 `_`는 "값은 안 쓰고 횟수만 센다"는 뜻으로 쓰는 변수 이름입니다.

`fit`을 하기 전에 `predict`를 부르면 어떻게 될까요?

```run
class MeanModel:
    def __init__(self):
        self.mean_ = None

    def fit(self, y):
        self.mean_ = sum(y) / len(y)
        return self

    def predict(self, X):
        return [self.mean_ for _ in X]

model = MeanModel()
print(model.predict(["new1", "new2"]))
```

`[None, None]`입니다. 교육받지 않은 신입은 답을 모릅니다. scikit-learn 모델은 이때 `NotFittedError`라는 에러를 내서 알려 줍니다.

### 이름 끝의 밑줄(_)은 "배워서 생긴 값"

`mean_`처럼 이름 끝에 밑줄을 붙인 것은 scikit-learn의 관례를 따른 것입니다. **`fit`을 해야 생기는 속성**에는 끝에 밑줄을 붙입니다. 머신러닝 트랙에서 만날 이름들이 모두 이 모양입니다.

| 속성 | 모델 | 뜻 |
| --- | --- | --- |
| `coef_` | 선형 회귀 | 배운 기울기(특성마다 얼마나 영향을 주나) |
| `intercept_` | 선형 회귀 | 배운 절편 |
| `feature_importances_` | 결정 트리 · 랜덤 포레스트 | 배운 특성 중요도 |
| `classes_` | 분류 모델 | 배운 정답의 종류 |

끝에 밑줄이 보이면 "아, fit한 뒤에 꺼내 보는 학습 결과구나"라고 읽으면 됩니다.

### 같은 설계도, 다른 데이터, 다른 모델

객체는 각자 자기 상태를 가집니다. 같은 `MeanModel` 클래스로 객체를 두 개 만들어 서로 다른 데이터로 배우게 하면, 두 모델은 다른 값을 기억합니다.

```run
class MeanModel:
    def __init__(self):
        self.mean_ = None

    def fit(self, y):
        self.mean_ = sum(y) / len(y)
        return self

    def predict(self, X):
        return [self.mean_ for _ in X]

line_a = MeanModel()
line_b = MeanModel()
line_a.fit([10.1, 9.8, 10.4, 10.3])
line_b.fit([10.6, 10.9, 10.7])
print(line_a.mean_, line_b.mean_)
```

`10.15`와 `10.733...`입니다. 라인 A용 모델과 라인 B용 모델이 따로 있는 셈입니다. 머신러닝에서 "모델을 여러 개 학습해 비교한다"는 말은 이렇게 객체를 여러 개 만든다는 뜻입니다.

### 설정값과 특성(X)이 있는 모델

진짜 모델은 ① 만들 때 **설정값**을 받고 ② 문제(특성) **X**를 보고 답을 다르게 냅니다. 이번에는 "어느 라인에서 만든 부품인가"(X)를 보고 그 **라인의 평균**으로 답하는 모델을 만듭니다. 처음 보는 라인이 들어오면 전체 평균으로 답합니다. 설정값 `digits`는 답을 몇 자리로 반올림할지입니다.

```run
class GroupMeanModel:
    def __init__(self, digits=2):
        self.digits = digits              # 설정값: 만들 때 정한다

    def fit(self, X, y):
        groups = {}
        for g, v in zip(X, y):
            groups.setdefault(g, []).append(v)
        self.means_ = {g: sum(vs) / len(vs) for g, vs in groups.items()}
        self.overall_ = sum(y) / len(y)
        return self

    def predict(self, X):
        return [round(self.means_.get(g, self.overall_), self.digits) for g in X]

X = ["A", "A", "B", "B", "A"]
y = [10.1, 9.8, 10.6, 10.9, 10.4]
model = GroupMeanModel(digits=1)
model.fit(X, y)
print(model.means_)
print(model.predict(["B", "A", "C"]))
```

`fit`이 라인별 평균(`means_`)과 전체 평균(`overall_`)을 배웠고, `predict`는 B → 10.8, A → 10.1, 처음 보는 C → 전체 평균 10.4로 답했습니다. `setdefault`는 key가 없을 때만 빈 리스트를 넣어 주는 딕셔너리 메서드입니다. [collections: Counter로 세고 defaultdict로 모으기](#/l/pb-13-5)에서 본 `defaultdict(list)`로 써도 됩니다.

| 부분 | 우리 코드 | scikit-learn |
| --- | --- | --- |
| 설정값 | `GroupMeanModel(digits=1)` | `DecisionTreeClassifier(max_depth=3)` |
| 배우기 | `fit(X, y)` | `fit(X, y)` |
| 배운 결과 | `means_`, `overall_` | `feature_importances_`, `coef_` |
| 답하기 | `predict(X)` | `predict(X)` |

### return self: 한 줄로 이어 쓰기

`fit`의 마지막 줄 `return self`는 **객체 자신을 돌려줍니다**. 그래서 `fit(...)`의 결과에 바로 점을 찍어 `predict`를 이어 쓸 수 있습니다.

```run
class MeanModel:
    def __init__(self):
        self.mean_ = None

    def fit(self, y):
        self.mean_ = sum(y) / len(y)
        return self

    def predict(self, X):
        return [self.mean_ for _ in X]

print(MeanModel().fit([10.1, 9.8, 10.4, 10.3]).predict(["new1"]))
```

`MeanModel()`이 객체를 만들고, `.fit(...)`이 배운 뒤 그 객체를 돌려주고, `.predict(...)`가 답합니다. scikit-learn의 `fit`도 `self`를 돌려주도록 만들어져 있어서 `model = Model().fit(X, y)`처럼 쓸 수 있습니다. pandas에서 `df.dropna().head()`처럼 메서드를 줄줄이 잇는 것도 같은 원리입니다(앞 메서드가 객체를 돌려주니 또 점을 찍을 수 있다).

### 진짜 라이브러리로 확인하기

scikit-learn에는 우리가 만든 것과 똑같이 평균으로 답하는 모델 `DummyRegressor`가 있습니다. 같은 데이터로 돌려 봅시다.

```run
from sklearn.dummy import DummyRegressor

X = [[1], [2], [3], [4]]               # scikit-learn은 X를 표(2차원) 모양으로 받는다
y = [10.1, 9.8, 10.4, 10.3]
model = DummyRegressor(strategy="mean")
model.fit(X, y)
print(model.constant_)
print(model.predict([[5], [6]]))
```

학습 결과 속성 `constant_`(끝에 밑줄!)가 우리 `mean_`과 같은 10.15입니다. scikit-learn은 결과를 NumPy 배열에 담아서 `[[10.15]]`, `[10.15 10.15]`처럼 대괄호 모양이 조금 다를 뿐, `predict`도 같은 답을 냅니다. 만들기 → `fit` → 밑줄 속성 → `predict`, 흐름이 완전히 같습니다. 머신러닝 트랙의 결정 트리 · 회귀 · 랜덤 포레스트는 `fit` 안의 계산만 더 똑똑할 뿐, **객체로서 쓰는 방법은 이것과 같습니다.**

:::tip 알아 두면 좋아요 · 상속: 설계도를 물려받아 고치기
클래스를 만들 때 괄호 안에 다른 클래스를 쓰면 그 클래스의 속성 · 메서드를 **물려받습니다(상속)**. 딥러닝 라이브러리 PyTorch에서는 신경망을 이렇게 만듭니다.

```python
import torch.nn as nn

class MyNet(nn.Module):              # nn.Module의 기능을 물려받는다
    def __init__(self):
        super().__init__()           # 물려받은 쪽의 __init__도 실행
        self.layer = nn.Linear(4, 1)

    def forward(self, x):            # 내가 정할 부분만 새로 쓴다
        return self.layer(x)
```

`class 이름(부모 클래스):`, `super().__init__()` 두 가지만 알아보면 충분합니다. 이 사이트의 딥러닝 트랙은 코드 없이 개념으로 다루므로, 지금은 "괄호 안 클래스를 물려받는구나" 정도로 읽을 수 있으면 됩니다.
:::

### 정리

| 단계 | 코드 | 객체 안에서 일어나는 일 |
| --- | --- | --- |
| 만들기 | `model = Model(설정)` | `__init__`이 설정값을 속성에 저장. 아직 배운 것 없음 |
| 배우기 | `model.fit(X, y)` | 데이터로 계산한 결과를 **끝에 밑줄 붙은 속성**(`mean_`, `coef_`)에 저장, `self`를 돌려줌 |
| 답하기 | `model.predict(new_X)` | 저장된 속성을 꺼내 새 데이터의 답을 계산 |

- 머신러닝 모델은 **상태(배운 것)를 기억하는 객체**다. 그래서 클래스로 만든다.
- 같은 클래스로 만든 모델 객체 여러 개는 각자 다른 데이터를 배워 다른 값을 기억한다.
- `fit`이 `return self`를 하면 `Model().fit(X, y).predict(new_X)`처럼 이어 쓸 수 있다.
