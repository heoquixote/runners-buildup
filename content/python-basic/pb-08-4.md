### 시작하기 전에

[함수 만들기 기본기: 기본값 · 키워드 인자 · 여러 값 반환](#/l/pb-08-2)에서 만든 함수는 받을 값의 **개수가 정해져** 있었습니다. `judge(value, low, high)`는 정확히 값 3개(기본값을 쓰면 1~3개)를 받습니다.

그런데 이미 써 본 함수 중에는 값을 **몇 개든** 받는 것이 있습니다.

```run
print("A0915", "A0916", "A0917", "A0918")
print(max(10.1, 9.8, 10.4))
print(max(10.1, 9.8, 10.4, 10.9, 9.7))
```

`print`에는 값을 4개, `max`에는 3개도 5개도 넣었습니다. 이번 레슨에서는 이렇게 **개수가 정해지지 않은 인자**를 받는 함수를 만들고, 반대로 리스트 · 딕셔너리를 함수에 **풀어서 넣는** 방법을 배웁니다. 데이터 분석 · 머신러닝 라이브러리의 설명서에 `*args`, `**kwargs`가 자주 나오는데, 그 뜻을 읽을 수 있게 됩니다.

### *args: 위치 인자를 튜플로 모은다

매개변수 이름 앞에 별(`*`)을 하나 붙이면, 넣은 값을 **몇 개든 모두 모아 튜플 하나**로 받습니다.

```run
def average(*values):
    return sum(values) / len(values)

print(average(10.1, 9.8))
print(average(10.1, 9.8, 10.4, 10.3))
```

값 2개를 넣어도, 4개를 넣어도 동작합니다. 함수 안에서 `values`가 무엇인지 찍어 봅시다.

```run
def show(*values):
    print(values, type(values))

show(10.1, 9.8, 10.4)
show()
```

`(10.1, 9.8, 10.4) <class 'tuple'>`, 그리고 아무것도 안 넣으면 빈 튜플 `()`입니다. 튜플이므로 [튜플과 언패킹](#/l/pb-04-2)에서 배운 대로 `for`로 돌거나, `len`, `sum`, 인덱싱을 그대로 쓸 수 있습니다.

### 고정 매개변수와 함께 쓰기

앞쪽에 반드시 필요한 매개변수를 두고, 나머지만 `*`로 모을 수 있습니다. 넣은 값이 앞에서부터 순서대로 채워지고, **남은 것이 모두** 별 붙은 매개변수로 갑니다.

```run
def report(lot, *values):
    print(f"{lot}: {len(values)}회 측정, 최대 {max(values)}")

report("A0915", 10.1, 9.8, 10.4)
report("A0916", 10.9, 10.2)
```

`"A0915"`는 `lot`에, 나머지 측정값은 `values`에 들어갔습니다.

이름은 `values`든 `args`든 상관없습니다. 뜻을 만드는 것은 **별**입니다. 다만 특별한 이름이 떠오르지 않을 때 모두가 `*args`(arguments, 인자들)라고 쓰기 때문에 설명서에서 이 이름을 자주 봅니다.

### **kwargs: 키워드 인자를 딕셔너리로 모은다

별을 **두 개** 붙이면 `이름=값` 모양으로 넣은 인자를 몇 개든 모아 **딕셔너리**로 받습니다.

```run
def show(**info):
    print(info, type(info))

show(line="A", shift="day", operator="Kim")
```

`{'line': 'A', 'shift': 'day', 'operator': 'Kim'} <class 'dict'>`입니다. 넣은 이름이 key, 값이 value가 됐습니다. 이쪽도 이름은 자유이고, 관례적으로 `**kwargs`(keyword arguments)라고 씁니다.

검사 기록에 붙는 부가 정보는 날마다 다를 수 있습니다. 그럴 때 `**`로 받으면 함수를 고치지 않고 정보를 더 붙일 수 있습니다.

```run
def log_line(lot, **extra):
    parts = []
    for k, v in extra.items():
        parts.append(f"{k}={v}")
    return f"[{lot}] " + ", ".join(parts)

print(log_line("A0915", line="A", temp=24.3))
print(log_line("A0916", line="B", temp=25.1, note="재검사"))
```

`extra.items()`로 key와 value를 함께 꺼내([for 반복 깊게: 리스트 · 문자열 · 딕셔너리 돌기](#/l/pb-07-2)) `"이름=값"` 조각을 만들고, `join`으로 한 줄로 이었습니다([문자열 메서드로 데이터 정리하기](#/l/pb-03-1)).

### 거꾸로: 호출할 때 * 와 ** 로 풀어 넣기

별은 함수를 **부를 때**도 쓸 수 있는데, 이때는 반대로 **풀어 넣는** 뜻이 됩니다.

::figure{src="content/img/py/py-args-pack-unpack.svg" alt="위쪽 '정의할 때 모은다' 줄에서 average(10.1, 9.8, 10.4)로 넣은 값 세 개가 def average(*values) 안에서 튜플 (10.1, 9.8, 10.4) 하나로 모인다. 아래쪽 '호출할 때 푼다' 줄에서는 리스트 temps = [10.1, 9.8, 10.4]가 average(*temps)를 거치며 값 세 개로 흩어져 들어가고, 딕셔너리 spec = {'low': 9.8, 'high': 10.2}가 judge(10.1, **spec)을 거치며 low=9.8, high=10.2로 풀려 들어간다" caption="별은 def 줄에서는 '모아라', 호출할 때는 '풀어라'입니다. * 는 리스트 · 튜플, ** 는 딕셔너리에 씁니다."}

**`*리스트`**: 리스트 안의 값을 꺼내 하나씩 따로 넣은 것처럼 만듭니다.

```run
lots = ["A0915", "A0916", "A0917"]
print(lots)
print(*lots)
print(*lots, sep=" / ")
```

`print(lots)`는 리스트 하나를 찍고, `print(*lots)`는 `print("A0915", "A0916", "A0917")`과 같아서 값 세 개를 띄어 찍습니다. [문자열 출력 다루기: sep · end · 이스케이프](#/l/pb-02-2)의 `sep`과 함께 쓰면 편합니다.

이미 리스트로 가진 값을 `*values`로 받는 함수에 넣을 때도 씁니다.

```run
def average(*values):
    return sum(values) / len(values)

temps = [10.1, 9.8, 10.4, 10.3]
print(average(*temps))
```

`average(temps)`라고 쓰면 리스트 하나가 통째로 들어가서 `values`가 `([10.1, 9.8, 10.4, 10.3],)`가 되고 `sum`에서 에러가 납니다. 풀어 넣어야 값 4개로 들어갑니다.

**`**딕셔너리`**: key를 이름으로, value를 값으로 해서 키워드 인자로 풀어 넣습니다. 규격처럼 **설정값을 딕셔너리에 모아 두고** 한 번에 넘길 때 아주 편합니다.

```run
def judge(value, low=9.5, high=10.5):
    return "합격" if low <= value <= high else "불합격"

spec = {"low": 9.8, "high": 10.2}
print(judge(10.1, **spec))            # judge(10.1, low=9.8, high=10.2) 와 같다
print(judge(10.3, **spec))
```

`합격`, `불합격`입니다. 제품마다 규격 딕셔너리만 바꿔 끼우면 됩니다. 딕셔너리의 key가 함수의 매개변수 이름과 **똑같아야** 합니다.

:::tip 미리보기 · 머신러닝 트랙에서 만나는 **
머신러닝에서는 여러 설정값 조합을 시험해 가장 좋은 조합을 딕셔너리로 받은 뒤, 그대로 풀어서 모델을 만듭니다.

```python
best_params = {"C": 10, "kernel": "rbf"}      # 탐색으로 찾은 가장 좋은 설정
model = SVC(**best_params)                    # SVC(C=10, kernel="rbf") 와 같다
```

그래프 함수 설명서에 `plot(x, y, **kwargs)`라고 적혀 있으면 "색 · 선 굵기 같은 추가 설정을 이름=값으로 얼마든지 넣을 수 있다"는 뜻입니다.
:::

### 매개변수 순서 규칙

한 함수에 여러 종류를 섞을 때는 순서가 정해져 있습니다.

| 순서 | 종류 | 예 |
| --- | --- | --- |
| 1 | 일반 매개변수 | `lot` |
| 2 | 기본값 매개변수 | `unit="mm"` |
| 3 | `*args` | `*values` |
| 4 | `**kwargs` (항상 맨 끝) | `**extra` |

```run
def record(lot, unit="mm", *values, **extra):
    print(lot, unit, values, extra)

record("A0915", "mm", 10.1, 9.8, line="A")
```

`A0915 mm (10.1, 9.8) {'line': 'A'}`입니다. 실제로 네 가지를 한 번에 섞는 일은 드뭅니다. "별 두 개는 맨 끝"만 기억해도 충분합니다.

### 자주 하는 실수

| 실수 | 결과 | 고치기 |
| --- | --- | --- |
| `*values`로 받는 함수에 리스트를 그대로 `average(temps)` | 값이 하나(리스트)로 들어가 계산 에러 | `average(*temps)` |
| `**spec`의 key가 매개변수 이름과 다름 (`{"min": 9.5}`) | `TypeError: ... got an unexpected keyword argument 'min'` | key를 매개변수 이름과 같게 |
| `def f(**extra, *values)` | SyntaxError | `**`는 맨 끝 |
| 함수 안에서 `values.append(...)` | `AttributeError` (튜플은 바꿀 수 없음) | `list(values)`로 바꾼 뒤 수정 |

### 정리

| 어디서 | `*` (별 하나) | `**` (별 두 개) |
| --- | --- | --- |
| `def` 줄 (정의) | 남은 위치 인자를 **튜플**로 모은다 `def f(*args)` | 남은 키워드 인자를 **딕셔너리**로 모은다 `def f(**kwargs)` |
| 호출할 때 | 리스트 · 튜플을 값 여러 개로 **푼다** `f(*lst)` | 딕셔너리를 `이름=값` 여러 개로 **푼다** `f(**d)` |

- 이름(`args`, `kwargs`)은 관례일 뿐, 뜻은 별 개수가 만든다.
- 설정값 딕셔너리를 `**`로 풀어 넘기는 모양은 머신러닝 트랙에서 계속 나온다.
