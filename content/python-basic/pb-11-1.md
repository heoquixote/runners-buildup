## 리스트 컴프리헨션

빈 리스트를 만들고 for문으로 하나씩 `append` 하는 코드는 자주 나옵니다. 리스트 컴프리헨션은 이 세 줄을 한 줄로 씁니다.

```python
# for문
out = []
for v in values:
    out.append(v * 2)

# 컴프리헨션
out = [v * 2 for v in values]
```

읽는 순서는 **"values의 각 v에 대해, v * 2를 모은다"** 입니다. 맨 앞의 식이 새 리스트에 들어갈 값입니다.

```run
values = [12, 9, 15, 10]
doubled = [v * 2 for v in values]
print(doubled)
```

## 조건을 붙여 골라내기

뒤에 `if 조건`을 붙이면 조건이 True인 원소만 남습니다. 규격 밖 측정값, 5만 원 이상 주문처럼 **필터링**할 때 씁니다.

> `[식 for 변수 in 반복 if 조건]` — 고르는 조건(if)은 맨 뒤, 바꾸는 식은 맨 앞

```run
thickness = [10.1, 9.7, 10.4, 9.9, 10.6]
out_of_spec = [t for t in thickness if t < 9.8 or t > 10.5]
print(out_of_spec)
print(len(out_of_spec), "개 규격 밖")
```

## lambda: 이름 없는 한 줄 함수

`lambda 인자: 식` 은 `def`로 만드는 함수를 한 줄로 줄인 것입니다. 혼자 쓰기보다는 **다른 함수에 기준을 넘길 때** 씁니다.

```run
double = lambda x: x * 2
print(double(5))

def double2(x):
    return x * 2
print(double2(5))
```

## sorted의 key: 무엇을 기준으로 정렬할까

`sorted(목록, key=함수)`는 각 원소를 함수에 넣어 나온 값으로 정렬합니다. 튜플이나 딕셔너리 리스트를 정렬할 때 key가 필요합니다.

- 내림차순: `reverse=True`
- 기준이 두 개: `key=lambda m: (m["age"], m["name"])` → 나이가 같으면 이름순
- `sorted`는 새 리스트를 돌려주고, `list.sort()`는 원본을 바꿉니다

```run
machines = [("M1", 82.5), ("M2", 91.0), ("M3", 77.3)]
ranked = sorted(machines, key=lambda m: m[1], reverse=True)
print(ranked)
print([name for name, rate in ranked])
```

> 컴프리헨션이 두세 줄로 길어지면 for문으로 풀어 쓰는 편이 읽기 쉽습니다. 짧고 단순한 변환·필터에만 쓰세요.
