## 에러가 나면 프로그램이 멈춘다

현장 데이터에는 `"err"`, 빈칸, 0 같은 값이 섞여 있습니다. `float("err")` 한 줄에서 에러가 나면 그 아래 코드는 실행되지 않고 프로그램이 멈춥니다.

| 에러 | 언제 | 예 |
| --- | --- | --- |
| `ValueError` | 값의 형식이 맞지 않을 때 | `float("err")`, `int("서른")` |
| `ZeroDivisionError` | 0으로 나눌 때 | `95 / 0` |
| `KeyError` | 딕셔너리에 없는 키 | `prices["치즈"]` |
| `IndexError` | 리스트 범위 밖 | `[1, 2][5]` |

## try / except

에러가 날 수 있는 줄을 `try:` 안에 넣고, 그 에러가 나면 할 일을 `except 에러이름:` 아래에 씁니다. 에러가 나도 프로그램은 멈추지 않고 다음 줄로 넘어갑니다.

```run
logs = ["23.5", "err", "24.1", ""]
vals = []
for s in logs:
    try:
        vals.append(float(s))
    except ValueError:
        print("건너뜀:", repr(s))
print(vals)
```

## 여러 에러를 따로 처리하기

`except`를 여러 개 두면 에러 종류마다 다르게 처리할 수 있습니다. `as e`로 에러 객체를 받으면 메시지도 볼 수 있습니다.

```run
def safe_yield(good, total):
    try:
        return round(good / total * 100, 1)
    except ZeroDivisionError:
        return 0.0
    except TypeError as e:
        print("숫자가 아닙니다:", e)
        return None

print(safe_yield(95, 100))
print(safe_yield(0, 0))
print(safe_yield("95", 100))
```

## else와 finally

- `else:` try 안에서 에러가 **나지 않았을 때만** 실행
- `finally:` 에러가 났든 안 났든 **항상** 실행 (파일 닫기 같은 정리 작업)

```run
for text in ["42", "사십이"]:
    try:
        n = int(text)
    except ValueError:
        print(text, "→ 변환 실패")
    else:
        print(text, "→", n * 2)
    finally:
        print("  검사 끝")
```

> `except:` 처럼 에러 이름을 비워 두면 변수 이름 오타(NameError)까지 조용히 숨겨집니다. 잡을 에러를 이름으로 적어야 진짜 버그를 놓치지 않습니다.
