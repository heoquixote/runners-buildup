검사 결과를 출력할 때 `"불량률: " + str(rate) + "%"`처럼 쓰면 따옴표와 `+`가 복잡하게 얽히고, 소수점 아래가 `1.4400000000000002`처럼 길게 붙기도 합니다. **f-string**을 쓰면 문장 안에 값을 바로 끼워 넣고, 자리수와 정렬까지 한 번에 정할 수 있습니다.

### 따옴표 앞에 f, 값은 중괄호 안에

문자열 앞에 `f`를 붙이고, 넣고 싶은 변수를 `{ }` 안에 씁니다.

```run
lot = "A0915"
qty = 1250
print(f"로트 {lot}의 검사 수량은 {qty}개입니다.")
```

숫자를 `str()`로 바꿀 필요도, `+`로 이을 필요도 없습니다.

중괄호 안에는 변수뿐 아니라 **계산식**도 넣을 수 있습니다.

```run
defects = 7
qty = 980
print(f"양품 {qty - defects}개, 불량률 {defects / qty * 100}%")
```

양품 973개는 깔끔하지만 불량률은 `0.7142857142857143%`처럼 소수점 아래가 길게 나옵니다. 보고서에 쓰기엔 너무 깁니다. 그래서 다음의 **포맷 지정**이 필요합니다.

### 콜론 뒤에 모양을 적습니다

`{값:모양}`처럼 콜론 뒤에 출력 모양을 적습니다.

| 쓰는 법 | 뜻 | 예 | 결과 |
| --- | --- | --- | --- |
| `:.2f` | 소수 둘째 자리까지 (반올림) | `f"{3.14159:.2f}"` | `3.14` |
| `:,` | 천 단위 쉼표 | `f"{1234567:,}"` | `1,234,567` |
| `:.1%` | 100을 곱해 퍼센트, 소수 첫째 자리 | `f"{0.0345:.1%}"` | `3.5%` |
| `:>8` | 8칸 안에서 오른쪽 정렬 | `f"{'A':>8}"` | `       A` |
| `:<8` | 8칸 안에서 왼쪽 정렬 | `f"{'A':<8}"` | `A       ` |
| `:^8` | 8칸 안에서 가운데 | `f"{'A':^8}"` | `   A    ` |

```run
rate = 18 / 1250
print(f"불량률 {rate:.4f}")
print(f"불량률 {rate:.2%}")
print(f"월 생산량 {1234567:,}개")
```

`0.0144`, `1.44%`, `1,234,567개`가 나옵니다. `%` 포맷은 **알아서 100을 곱하므로** 비율(0.0144)을 그대로 넣어야 합니다. 이미 100을 곱한 값(1.44)을 넣으면 144.00%가 됩니다.

```run
mean = 10.04666        # 값을 바꾸고 자리수(.1f, .3f)도 바꿔 보세요
print(f"평균 {mean:.2f} mm")
```

### 칸을 맞춰 표처럼 출력하기

폭(칸 수)을 정해 두면 줄마다 길이가 달라도 세로줄이 맞습니다. 글자는 왼쪽, 숫자는 오른쪽 정렬이 읽기 좋습니다.

```run
print(f"{'라인':<6}{'수량':>8}{'불량률':>8}")
print(f"{'L1':<6}{1250:>8,}{0.0144:>8.1%}")
print(f"{'L2':<6}{980:>8,}{0.0071:>8.1%}")
```

폭과 다른 모양을 같이 쓸 때는 `{1250:>8,}`처럼 **정렬·폭을 먼저, 그 뒤에 쉼표나 소수 자리**를 씁니다. 한글은 화면에서 영문보다 넓게 보여서 제목 줄이 조금 어긋나 보일 수 있습니다. 숫자 열이 맞는 것이 중요합니다.

### 자주 하는 실수

| 실수 | 결과 | 고치기 |
| --- | --- | --- |
| `"{lot}"` 처럼 f를 빠뜨림 | `{lot}`이 글자 그대로 출력 | `f"{lot}"` |
| `f"{rate*100:.1%}"` | 100을 두 번 곱해 144.0% | 비율 그대로 `f"{rate:.1%}"` |
| `f"{"A":>8}"` 처럼 같은 따옴표 | 오래된 파이썬에서 SyntaxError | 안쪽은 다른 따옴표 `f"{'A':>8}"` |
| `round()`와 `:.2f` 중복 | 결과는 같지만 불필요 | 출력용이면 `:.2f`만 |

`round()`는 **값 자체**를 반올림하고, `:.2f`는 값은 그대로 두고 **보여 주는 모양**만 바꿉니다. 계산을 이어 갈 값이면 반올림하지 말고 출력할 때만 포맷을 쓰는 것이 정확합니다.
