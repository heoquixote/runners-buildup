[datetime: 날짜와 시간 계산하기](#/l/pb-13-2)에서는 날짜를 다뤘습니다. 이번에는 숫자 쪽 도구 둘입니다. `math`는 올림 · 내림 · 제곱근처럼 **정확한 수학 계산**을, `random`은 **난수(무작위 수)와 표본 뽑기**를 맡습니다. 포장 박스 수 계산, 측정값 비교, 샘플 검사 대상 뽑기, 연습용 가짜 데이터 만들기에 바로 씁니다.

### math: 자주 쓰는 수학 함수

`math`에는 원주율 같은 상수와 계산 함수가 들어 있습니다.

```run
import math

print(math.pi, math.e)      # 원주율, 자연상수
print(math.sqrt(16))        # 제곱근 → 4.0
print(math.factorial(5))    # 5! = 5 × 4 × 3 × 2 × 1
```

`sqrt`는 정수를 넣어도 항상 소수(`4.0`)를 돌려줍니다. `factorial(5)`는 120입니다.

### 올림 · 내림 · 버림: ceil, floor, trunc

소수를 정수로 만드는 방법은 네 가지입니다. 양수에서는 비슷해 보이지만 **음수에서 결과가 갈립니다**. 수직선으로 보면 헷갈리지 않습니다.

::figure{src="content/img/py/py-ceil-floor-trunc.svg" alt="-6부터 6까지 수직선 위에 4.6과 -4.6이 점으로 찍혀 있다. 아래 표: math.ceil은 큰 쪽으로 4.6은 5, -4.6은 -4. math.floor는 작은 쪽으로 4, -5. math.trunc는 0 쪽으로 4, -4. round는 가까운 쪽으로 5, -5. 양수에서는 floor와 trunc가 같고 음수에서는 갈린다고 적혀 있다" caption="ceil은 오른쪽, floor는 왼쪽, trunc는 0 쪽, round는 가까운 쪽으로 움직입니다."}

```run
import math

x = 4.6
print(math.ceil(x), math.floor(x), math.trunc(x), round(x))
```

양수 4.6에서는 올림 5, 내림 4, 버림 4, 반올림 5입니다. 내림과 버림이 같습니다.

```run
import math

x = -4.6
print(math.ceil(x), math.floor(x), math.trunc(x), round(x))
```

음수 -4.6에서는 올림 **-4**, 내림 **-5**, 버림 **-4**, 반올림 -5입니다. "내림"은 수직선의 **왼쪽(더 작은 쪽)**이라서 -5가 되고, "버림"은 소수 부분을 **잘라 0 쪽으로** 가서 -4가 됩니다. 온도 편차, 오차처럼 음수가 나오는 값을 다룰 때 이 차이로 결과가 달라집니다. `int(-4.6)`도 버림과 같은 -4입니다.

### 실무 예: 필요한 박스 수는 올림

부품 1,250개를 한 박스에 48개씩 담으면 박스가 몇 개 필요할까요? 나눗셈 결과 26.04…에서 남는 2개도 박스가 하나 더 필요하므로 **올림**입니다.

```run
import math

parts, per_box = 1250, 48
print(parts / per_box)               # 26.04…
print(parts // per_box)              # 몫 26 → 2개가 남는다
print(math.ceil(parts / per_box))    # 필요한 박스 27
```

`//`(몫)는 내림이라 26이 나와 박스가 모자랍니다. "모자라면 안 되는" 개수(박스, 페이지, 작업 인원)는 `math.ceil`을 씁니다.

### 소수끼리 같은지 비교: isclose

[숫자 계산 자세히](#/l/pb-01-2)에서 본 것처럼 컴퓨터의 소수에는 아주 작은 오차가 있어 `0.1 + 0.2 == 0.3`이 `False`입니다. 소수가 "같은지"는 `math.isclose`로 **차이가 충분히 작은지** 봅니다.

```run
import math

a = 0.1 + 0.2
print(a, a == 0.3)
print(math.isclose(a, 0.3))                   # 기본: 아주 작은 상대 오차까지 같다고 본다
print(math.isclose(10.02, 10.0, abs_tol=0.05))  # 측정값이 기준과 ±0.05 안이면 True
```

`abs_tol`(허용 오차)을 주면 "기준값과 ±0.05 안이면 같다고 친다"처럼 규격 비교에도 쓸 수 있습니다.

:::tip 알아 두면 좋아요 · pow, hypot, 각도
```run
import math

print(math.pow(2, 3), 2 ** 3)      # math.pow는 항상 소수, **는 정수끼리면 정수
print(math.hypot(3, 4))            # 두 변이 3, 4인 직각삼각형의 빗변 = 원점에서 (3, 4)까지 거리
print(math.copysign(3, -1.0))      # 3에 -1.0의 부호를 붙인다
print(math.cos(math.radians(180))) # 삼각함수는 '라디안'을 받는다. 각도 → 라디안 변환
print(math.degrees(math.pi / 2))   # 라디안 → 각도
```

정수 거듭제곱은 `**`가 결과도 정수라 더 편합니다. `hypot`은 두 점 사이 거리를 구할 때 씁니다(좌표 측정, 위치 편차).
:::

### random: 난수 만들기

**난수**는 규칙 없이 고른 것처럼 보이는 수입니다. 주사위, 제비뽑기를 코드로 하는 것이라고 생각하면 됩니다.

```run
import random

print(random.random())               # 0.0 이상 1.0 미만 소수
print(random.randint(1, 10))         # 1 이상 10 이하 정수 (10도 포함!)
print(random.uniform(23.0, 27.0))    # 23.0 ~ 27.0 사이 소수
print(random.randrange(0, 10, 2))    # 0, 2, 4, 6, 8 중 하나 (range와 같은 규칙)
```

실행할 때마다 값이 바뀝니다. `randint(1, 10)`은 끝 값 10을 **포함**하고, `randrange(0, 10)`은 `range`처럼 10을 **빼는** 점이 다릅니다.

### 재현성: seed로 같은 난수 다시 만들기

난수가 매번 바뀌면 곤란할 때가 있습니다. 연습용 데이터로 분석했는데 다시 실행하니 숫자가 달라져 보고서와 안 맞는 경우입니다. `random.seed(숫자)`로 **시작 번호를 고정**하면 몇 번을 실행해도 같은 난수가 같은 순서로 나옵니다.

::figure{src="content/img/py/py-random-seed.svg" alt="random.seed(42)를 쓴 1회차와 2회차 실행은 둘 다 1, 1, 3, 2, 2가 나와 같은 순서 그대로다. seed가 없으면 실행마다 다른 순서가 나온다" caption="seed는 난수 목록의 시작 번호입니다. 번호가 같으면 같은 목록을 처음부터 다시 읽습니다."}

```run
import random

random.seed(42)
print([random.randint(1, 5) for _ in range(5)])
random.seed(42)                                  # 같은 번호로 다시 고정
print([random.randint(1, 5) for _ in range(5)])
```

두 줄이 똑같이 `[1, 1, 3, 2, 2]`입니다. 셀을 다시 실행해도 같습니다. 머신러닝에서 `random_state=42`를 넣는 것도 같은 이유입니다. 숫자 자체(42)에는 의미가 없고, **같은 숫자를 쓰는 것**이 중요합니다.

### 뽑기와 섞기: choice, sample, shuffle

리스트에서 무작위로 고를 때 씁니다.

```run
import random

random.seed(1)
lots = ["A0915", "A0916", "A0917", "A0918", "A0919"]
print(random.choice(lots))       # 1개 뽑기
print(random.sample(lots, 2))    # 중복 없이 2개 뽑기 (샘플 검사 대상)
```

`sample`은 같은 로트를 두 번 뽑지 않습니다. 전체 중 일부만 검사하는 **샘플링 검사 대상**을 고를 때 이 함수를 씁니다.

`shuffle`은 리스트 순서를 **제자리에서** 섞습니다. 새 리스트를 돌려주지 않고 원본을 바꾼 뒤 `None`을 돌려주는 점을 주의하세요([sort와 sorted](#/l/pb-05-1)의 `sort`와 같은 방식입니다).

```run
import random

random.seed(1)
order = ["L1", "L2", "L3", "L4"]
result = random.shuffle(order)
print(result)    # None: 돌려주는 값이 없다
print(order)     # 원본이 섞였다
```

`order = random.shuffle(order)`처럼 쓰면 리스트가 `None`으로 바뀌어 버리는 실수가 흔합니다. 섞은 결과는 원래 변수에서 봅니다.

### 확률을 다르게: choices의 weights

`choices`는 **중복을 허용**하며 `k`개를 뽑고, `weights`로 각 항목이 뽑힐 비율을 정합니다. 불량이 드물게 섞인 연습 데이터를 만들 때 좋습니다.

```run
import random

random.seed(8)
result = random.choices(["OK", "NG"], weights=[95, 5], k=20)
print(result)
print("NG", result.count("NG"), "건")
```

OK가 95, NG가 5의 비율로 뽑혀 20개 중 NG가 2건(10%) 나왔습니다. 적게 뽑으면 비율이 5%에서 벗어나기 쉽고, 많이 뽑을수록 5%에 가까워집니다. seed를 지우고 여러 번 실행해 보면 NG가 0건인 때도 있습니다.

:::tip 알아 두면 좋아요 · 비밀번호는 random이 아니라 secrets
`random`은 seed만 알면 결과를 다시 만들 수 있습니다. 재현에는 장점이지만 **비밀번호 · 인증 코드**에는 위험합니다. 이럴 때는 예측할 수 없게 설계된 `secrets` 모듈을 씁니다(seed가 없습니다).

```run
import secrets
import string

alphabet = string.ascii_letters + string.digits    # 영문 대소문자 + 숫자
pwd = "".join(secrets.choice(alphabet) for _ in range(12))
print(pwd)
```
:::

### 정리

- `math.ceil` 올림(큰 쪽), `math.floor` 내림(작은 쪽), `math.trunc` 버림(0 쪽), `round` 반올림. 음수에서 결과가 갈린다.
- 모자라면 안 되는 개수(박스 · 페이지)는 `math.ceil(전체 / 단위)`.
- 소수가 같은지는 `==` 대신 `math.isclose(a, b)`, 허용 오차는 `abs_tol`.
- `randint(a, b)`는 b 포함, `randrange(a, b)`는 b 제외. `uniform(a, b)`는 소수.
- `random.seed(숫자)`로 고정하면 같은 난수가 다시 나온다.
- `choice` 1개, `sample` 중복 없이 k개, `choices` 중복 허용 + 가중치, `shuffle`은 제자리 섞기(반환값 `None`).
