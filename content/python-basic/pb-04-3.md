리스트를 다른 변수에 담았을 뿐인데, 한쪽을 고쳤더니 다른 쪽도 같이 바뀌는 일이 있습니다. 실수로 원본 데이터를 망가뜨리는 가장 흔한 원인입니다. 이 레슨에서는 **변수가 값을 담는 상자가 아니라 값에 붙인 이름표**라는 사실과, 원본을 지키는 복사 방법을 배웁니다.

### 변수는 이름표입니다

`a = [1, 2]`를 실행하면 파이썬은 먼저 리스트 `[1, 2]`를 만들고, 거기에 `a`라는 **이름표**를 붙입니다. 이어서 `b = a`라고 쓰면 리스트를 하나 더 만드는 게 아니라, **같은 리스트에 이름표 b를 하나 더** 붙입니다.

| 코드 | 리스트 개수 | 이름표 |
| --- | --- | --- |
| `a = [1, 2]` | 1개 | a |
| `b = a` | 여전히 1개 | a, b (같은 리스트) |
| `c = a.copy()` | 2개 | a·b는 원래 것, c는 새것 |

그래서 b로 리스트를 고치면, a로 봐도 바뀌어 있습니다.

```run
a = [1, 2]
b = a
b.append(99)
print(a)
print(b)
```

두 줄 모두 `[1, 2, 99]`입니다. a는 건드리지 않았는데 바뀐 것처럼 보이는 이유는, 애초에 리스트가 하나뿐이었기 때문입니다.

### is와 ==는 다른 질문입니다

`==`는 **내용이 같은가**, `is`는 **같은 물건(같은 리스트)인가**를 묻습니다.

```run
a = [1, 2]
b = a
c = [1, 2]
print(a == b, a is b)
print(a == c, a is c)
```

a와 b는 내용도 같고 같은 리스트라 True, True입니다. c는 내용은 같지만 따로 만든 리스트라 True, False입니다.

### copy()로 새 리스트를 만듭니다

원본을 그대로 두고 따로 고치고 싶으면 `copy()`로 **새 리스트**를 만들어 이름표를 붙입니다. `a[:]`(처음부터 끝까지 슬라이싱)나 `list(a)`도 같은 일을 합니다.

```run
raw = [23.1, 23.4, 99.9, 22.8]     # 원본 측정값 (99.9 는 센서 오류)
clean = raw.copy()
del clean[2]
print(raw)
print(clean)
```

원본 `raw`에는 99.9가 남아 있고 `clean`에서만 빠졌습니다. 데이터를 정리할 때는 **원본은 남기고 복사본을 고치는** 습관이 안전합니다. 나중에 무엇을 지웠는지 확인할 수 있기 때문입니다.

### 리스트 안의 리스트는 한 번 더 조심

`copy()`는 **바깥 리스트만** 새로 만듭니다. 안쪽 리스트는 여전히 원본과 같은 것을 가리킵니다. 이것을 **얕은 복사**라고 합니다.

```run
lines = [["L1", 980], ["L2", 1010]]
backup = lines.copy()
backup[0][1] = 0          # 안쪽 리스트의 값을 바꿈
print(lines)
```

`lines`의 L1 수량까지 0이 됐습니다. 안쪽까지 모두 새로 만들려면 `copy` 모듈의 `deepcopy()`(**깊은 복사**)를 씁니다.

```run
import copy

lines = [["L1", 980], ["L2", 1010]]
backup = copy.deepcopy(lines)
backup[0][1] = 0
print(lines)
print(backup)
```

이번에는 원본 `lines`가 그대로입니다. `import copy`는 파이썬에 들어 있는 `copy` 도구 모음을 불러오는 줄이라 코드 맨 위에 씁니다.

### 숫자와 문자열은 걱정하지 않아도 됩니다

숫자·문자열·튜플은 애초에 **고칠 수 없는 값**이라, 이름표가 두 개여도 한쪽에서 "바꾸는" 순간 새 값이 만들어집니다.

```run
x = "A0915"
y = x
y = y + "-R"
print(x, y)
```

x는 그대로 `A0915`입니다. `y + "-R"`가 새 문자열을 만들고, y 이름표만 그쪽으로 옮겨 붙었기 때문입니다. **값 자체를 고치는 메서드(append, remove, 대입)가 있는 리스트·딕셔너리**에서만 이 레슨의 문제가 생깁니다.

### 정리

| 상황 | 쓰는 코드 |
| --- | --- |
| 같은 리스트를 다른 이름으로 부르기 | `b = a` |
| 원본은 두고 따로 고치기 | `b = a.copy()` |
| 리스트 안에 리스트가 있을 때 따로 고치기 | `b = copy.deepcopy(a)` |
| 같은 리스트인지 확인 | `a is b` |
| 내용이 같은지 확인 | `a == b` |
