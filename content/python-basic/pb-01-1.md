### 변수는 값에 붙이는 이름표

```run
good = 1180      # 숫자
line = "L2"      # 문자 (따옴표)
# 으로 시작하는 줄은 주석. 실행되지 않습니다.
print(good, line)
print(good * 2)          # 변수는 값처럼 계산에 쓸 수 있다
a, b = 10, 3
print(a // b, a % b)     # 몫 3, 나머지 1
```

변수 이름은 영문으로 짓고, 띄어쓰기 대신 `_`를 씁니다. `=`는 "같다"가 아니라 "오른쪽 값을 왼쪽 이름에 담는다"는 뜻입니다.
