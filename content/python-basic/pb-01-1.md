### 변수는 값에 붙이는 이름표

앞 레슨의 f-string 예제에서 `line`, `qty`처럼 이름에 값을 담아 썼습니다. 이것이 **변수**, 값에 붙이는 **이름표**입니다. 값을 한 번 담아 두면 그 뒤로는 이름만으로 값을 꺼내 쓸 수 있습니다.

```run
good = 1180
print(good)
```

`=`는 "같다"가 아니라 **"오른쪽 값을 왼쪽 이름에 담는다"**는 뜻입니다. 변수 이름은 영문으로 짓고, 띄어쓰기 대신 `_`를 씁니다(예: `good_count`).

숫자가 아닌 **문자**는 따옴표로 감쌉니다. 따옴표가 없으면 파이썬은 `L2`를 변수 이름으로 착각합니다.

```run
line = "L2"
print(line)
```

`print()`에 쉼표로 여러 값을 넣으면 한 줄에 띄어서 출력합니다.

```run
good = 1180
line = "L2"
print(good, line)
```

변수는 값 그 자체처럼 **계산에 쓸 수 있습니다.**

```run
good = 1180
print(good * 2)
```

쉼표를 쓰면 **변수 여러 개를 한 줄에** 담을 수 있습니다. 왼쪽 이름과 오른쪽 값이 순서대로 짝지어집니다.

```run
a, b = 10, 3
print(a, b)
```

### 값에는 종류가 있습니다: 자료형

변수에 담는 값은 모두 같은 종류가 아닙니다. `1180`은 셀 수 있는 숫자이고, `"L2"`는 글자입니다. 값의 종류를 **자료형**(data type)이라고 부릅니다. 처음에는 네 가지만 알면 됩니다.

| 자료형 | 뜻 | 예 | 언제 쓰나 |
| --- | --- | --- | --- |
| `int` | 정수 | `1180`, `-3`, `0` | 개수, 수량 |
| `float` | 소수 | `23.5`, `1.0` | 측정값, 비율 |
| `str` | 문자열(글자) | `"L2"`, `'불량'`, `"3"` | 이름, 코드, 메모 |
| `bool` | 참 · 거짓 | `True`, `False` | 합격 여부, 조건 결과 |

`type()`에 값을 넣으면 그 값의 자료형을 알려 줍니다.

```run
print(type(1180))
print(type(23.5))
```

글자는 `str`, 참 · 거짓은 `bool`로 나옵니다. `True`와 `False`는 따옴표 없이 첫 글자를 대문자로 씁니다.

```run
print(type("L2"))
print(type(True))
```

**따옴표가 있으면 무조건 문자열**입니다. 숫자처럼 보여도 따옴표 안에 있으면 글자입니다.

```run
print(type(3))
print(type("3"))
```

> 자료형이 중요한 이유: 같은 `+`라도 **자료형에 따라 하는 일이 달라집니다.** 아래 사칙연산 뒤에서 직접 확인합니다.

### 사칙연산 (a = 10, b = 3)

<table class="ex-table"><thead><tr><th>연산자</th><th>뜻</th><th>결과</th></tr></thead><tbody>
<tr><td><code>a + b</code></td><td>덧셈</td><td>13</td></tr>
<tr><td><code>a - b</code></td><td>뺄셈</td><td>7</td></tr>
<tr><td><code>a * b</code></td><td>곱셈</td><td>30</td></tr>
<tr><td><code>a / b</code></td><td>나눗셈 (항상 소수)</td><td>3.333…</td></tr>
<tr><td><code>a // b</code></td><td>몫</td><td>3</td></tr>
<tr><td><code>a % b</code></td><td>나머지</td><td>1</td></tr>
<tr><td><code>a ** b</code></td><td>거듭제곱</td><td>1000</td></tr></tbody></table>

더하기, 빼기, 곱하기는 수학 시간과 같습니다.

```run
a, b = 10, 3
print(a + b, a - b, a * b)
```

`/`는 나누어떨어져도 결과가 **항상 소수(float)**입니다.

```run
print(10 / 3)
print(10 / 2)
```

`//`는 나눗셈의 **몫**, `%`는 **나머지**입니다. 둘은 늘 짝으로 씁니다.

```run
a, b = 10, 3
print(a // b)
print(a % b)
```

> 현장 활용: 24개들이 박스에 몇 박스가 차고 몇 개가 남는지는 `//`와 `%`로 바로 나옵니다.

```run
print(100 // 24)   # 가득 찬 박스 수
print(100 % 24)    # 남는 개수
```

`**`는 거듭제곱입니다. `2 ** 3`은 2를 세 번 곱한 8입니다.

```run
print(2 ** 3)
```

### 자료형이 다르면 계산은 어떻게 될까

정수와 소수를 섞어 계산하면 결과는 **소수**가 됩니다. 소수가 더 넓은 범위를 담을 수 있기 때문입니다.

```run
print(3 + 0.5)
print(type(3 + 0.5))
```

문자열끼리 `+`를 하면 더하는 게 아니라 **이어 붙입니다.**

```run
print("3" + "3")
print("L2" + "-" + "0457")
```

문자열에 정수를 `*` 하면 그 횟수만큼 **반복합니다.** 구분선을 그릴 때 자주 씁니다.

```run
print("3" * 3)
print("=" * 20)
```

그런데 **문자열과 숫자를 `+`로 섞으면 에러**가 납니다. 파이썬이 "이어 붙이라는 건지, 더하라는 건지" 정할 수 없기 때문입니다.

```python
print("3" + 3)
```

```
TypeError: can only concatenate str (not "int") to str
```

숫자로 계산하고 싶으면 `int()`로, 글자로 붙이고 싶으면 `str()`로 자료형을 맞춘 뒤 계산합니다. (자세한 형변환은 이 DAY의 [자료형과 형변환](#/l/pb-01-3)에서 다룹니다.)

```run
print(int("3") + 3)
print("3" + str(3))
```

문자열끼리 빼기, 나누기는 할 수 없습니다. 글자에서 쓸 수 있는 연산은 `+`(이어 붙이기)와 `*`(반복) 두 가지뿐입니다.

```python
print("L2" - "L")
```

```
TypeError: unsupported operand type(s) for -: 'str' and 'str'
```

`bool`은 계산할 때 **True는 1, False는 0**으로 취급됩니다. 그래서 합격 여부를 더하면 합격 개수가 나옵니다.

```run
print(True + 1)
print(True + True + False)   # 합격, 합격, 불합격 → 합격 2개
```

| 계산 | 결과 | 이유 |
| --- | --- | --- |
| `3 + 0.5` | `3.5` | 정수 + 소수 → 소수 |
| `10 / 2` | `5.0` | `/`는 항상 소수 |
| `"3" + "3"` | `"33"` | 문자열 + 문자열 → 이어 붙이기 |
| `"3" * 3` | `"333"` | 문자열 × 정수 → 반복 |
| `"3" + 3` | `TypeError` | 문자열과 숫자는 섞어 더할 수 없음 |
| `True + 1` | `2` | True는 1, False는 0 |
