[for문 세 줄을 한 줄로, 정렬 기준은 lambda로](#/l/pb-11-1)에서 `sorted(목록, key=lambda m: m[1])`로 정렬 기준을 정했습니다. 실무 정렬은 기준이 하나로 끝나지 않습니다. "불량률 높은 순, 같으면 로트 번호 순"처럼 기준이 두 개이고, 방향(오름·내림)이 서로 다를 때도 있습니다. 이 레슨에서는 **key 함수를 설계하는 법**과, key를 받는 다른 함수(`max`, `min`), 그리고 `map`, `filter`를 정리합니다.

### key는 "비교할 값을 뽑는 함수"입니다

`sorted`는 원소끼리 직접 비교하지 않고, 각 원소를 key 함수에 넣어 **나온 값끼리** 비교합니다. lambda는 그 함수를 한 줄로 쓰는 방법입니다.

```run
lots = [("A0916", 0.71), ("A0915", 1.44), ("A0917", 2.27)]
print(sorted(lots))                          # key 없음: 튜플 첫 값(로트) 순
print(sorted(lots, key=lambda r: r[1]))      # 불량률 순
```

key가 없으면 튜플을 **앞에서부터** 비교해 로트 이름 순이 되고, `key=lambda r: r[1]`이면 불량률 순입니다.

이미 있는 함수도 key로 넘길 수 있습니다. 괄호 없이 **이름만** 넘깁니다.

```run
codes = ["b2", "A1", "c3", "B1", "a3"]
print(sorted(codes))                 # 대문자가 소문자보다 앞
print(sorted(codes, key=str.lower))  # 대소문자 무시

equip = ["EQ-107", "EQ-7", "EQ-17"]
print(sorted(equip))                 # 글자 순서: '1' 이 '7' 보다 앞
print(sorted(equip, key=len))        # 길이 순
```

기본 정렬은 대문자 A, B가 소문자 a, b보다 앞에 오지만 `str.lower`를 key로 주면 a와 A가 나란히 놓입니다. 설비 번호는 글자 순서로 정렬하면 `EQ-107`이 `EQ-7`보다 앞에 오는데([리스트에서 찾고 요약하기](#/l/pb-05-2)의 `"10" < "9"`와 같은 이유), 자리수가 다를 때는 `len`을 key로 주면 번호 순서에 가까워집니다.

### 기준이 두 개: 튜플을 돌려준다

key가 **튜플**을 돌려주면 첫 값으로 비교하고, 같으면 둘째 값으로 비교합니다.

```run
rows = [("L2", "A0916", 7), ("L1", "A0917", 25), ("L1", "A0915", 18), ("L2", "A0918", 7)]
by_line = sorted(rows, key=lambda r: (r[0], r[1]))
for r in by_line:
    print(r)
```

라인 순(L1, L2)으로 묶이고, 같은 라인 안에서는 로트 순입니다.

### 방향이 다른 두 기준: 숫자에 마이너스

"불량 많은 순(내림), 같으면 로트 순(오름)"처럼 방향이 다르면 `reverse=True`를 쓸 수 없습니다(둘 다 뒤집히니까). 숫자 기준에 **마이너스**를 붙여 내림차순을 만듭니다.

```run
rows = [("L2", "A0916", 7), ("L1", "A0917", 25), ("L1", "A0915", 18), ("L2", "A0918", 7)]
ranked = sorted(rows, key=lambda r: (-r[2], r[1]))
for r in ranked:
    print(r[1], r[2])
```

25, 18이 먼저 오고, 불량 7개로 같은 A0916과 A0918은 로트 순서대로 놓였습니다. `-r[2]`는 큰 값을 작은 값으로 바꿔서, 오름차순 정렬이 곧 불량 많은 순이 됩니다. 마이너스는 숫자에만 쓸 수 있으니, 내림차순으로 정할 쪽이 숫자여야 합니다.

```run
rows = [("L2", "A0916", 7), ("L1", "A0917", 25), ("L1", "A0915", 18)]
print(sorted(rows, key=lambda r: (r[0], -r[2])))   # 라인 순, 라인 안에서는 불량 많은 순
```

### max, min도 key를 받습니다

정렬 전체가 필요 없고 1등만 알고 싶으면 `max`, `min`에 같은 key를 넘깁니다([내장 함수로 짧게 쓰기: sum · max(key) · any · all](#/l/pb-09-3)).

```run
equip = [{"id": "EQ-07", "temp": 78.5}, {"id": "EQ-08", "temp": 91.0}, {"id": "EQ-09", "temp": 84.2}]
hot = max(equip, key=lambda e: e["temp"])
print(hot["id"], hot["temp"])
print(sorted(equip, key=lambda e: e["temp"], reverse=True)[0]["id"])
```

둘 다 EQ-08입니다. 1등만 필요하면 `max`가 짧고 빠릅니다.

### map과 filter

`map(함수, 목록)`은 모든 원소에 함수를 적용하고, `filter(함수, 목록)`은 함수가 True를 돌려주는 원소만 남깁니다. 결과를 보려면 `list()`로 감쌉니다.

```run
raw = ["23.1", "25.4", "22.8"]
temps = list(map(float, raw))
high = list(filter(lambda t: t > 25, temps))
print(temps, high)
```

같은 일을 컴프리헨션으로도 쓸 수 있습니다.

```run
raw = ["23.1", "25.4", "22.8"]
temps = [float(s) for s in raw]
high = [t for t in temps if t > 25]
print(temps, high)
```

결과는 같습니다. 이미 이름 있는 함수를 그대로 적용할 때(`map(float, raw)`)는 `map`이 짧고, 그 밖에는 컴프리헨션이 더 읽기 쉬워서 많이 씁니다. 다른 사람 코드에서 `map`, `filter`를 만나면 읽을 수 있으면 됩니다.

### pandas에서 다시 만나는 lambda

lambda가 가장 자주 쓰이는 곳은 사실 데이터 분석입니다. pandas 표의 열(Series)에 `apply(함수)`를 쓰면 **모든 값에 함수를 적용**합니다. `map`과 같은 일을 열 하나에 하는 셈이고, 그 함수 자리에 lambda가 들어갑니다.

```run
import pandas as pd

rate = pd.Series([1.44, 0.71, 2.27], index=["A0915", "A0916", "A0917"])
print(rate.apply(lambda r: "NG" if r > 2.0 else "OK"))
```

불량률이 2%를 넘는 A0917만 `NG`입니다. 조건식([컴프리헨션 넓히기: 조건식 · 딕셔너리 · Set](#/l/pb-11-2))과 lambda를 합친 모양이 그대로 쓰였습니다. 표의 열 다루기는 데이터 분석 트랙의 [빈칸과 지저분한 값 정리하기](#/l/da-05-1)에서 이어집니다.

### 정리

| 하고 싶은 일 | key |
| --- | --- |
| 두 번째 값 기준 | `key=lambda r: r[1]` |
| 대소문자 무시 | `key=str.lower` |
| 0번 순, 같으면 1번 순 | `key=lambda r: (r[0], r[1])` |
| 숫자 2번 내림, 같으면 1번 오름 | `key=lambda r: (-r[2], r[1])` |
| 1등만 | `max(목록, key=...)` |

lambda는 **식 하나**만 쓸 수 있습니다. 여러 줄이 필요하면 `def`로 함수를 만들어 그 이름을 key로 넘깁니다.
