### 문자열은 따옴표로 감쌉니다

글자 데이터를 **문자열**(string, `str`)이라고 합니다. 작은따옴표 `'...'`와 큰따옴표 `"..."` 어느 쪽으로 감싸도 같습니다.

```run
code = 'KR24A0915X'
print(code)
```

`type()`은 값의 **자료형**을 알려 줍니다. 문자열은 `str`로 나옵니다.

```run
code = 'KR24A0915X'
print(type(code))
```

숫자도 종류가 나뉩니다. 정수는 `int`, 소수는 `float`, 참/거짓은 `bool`입니다.

```run
print(type(1180))
print(type(23.5))
print(type(True))
```

### 인덱싱: 한 글자 꺼내기

문자열의 글자마다 **번호**(인덱스)가 붙어 있습니다. 번호는 **0부터** 셉니다. 첫 글자는 `[0]`입니다.

```run
code = 'KR24A0915X'
print(code[0])
```

음수 번호는 **뒤에서부터** 셉니다. 마지막 글자는 `[-1]`입니다.

```run
code = 'KR24A0915X'
print(code[-1])
```

### 슬라이싱: 구간 잘라내기

`[시작:끝]`은 시작 번호부터 **끝 번호 바로 앞까지** 잘라냅니다. 끝 번호는 포함되지 않습니다.

```run
code = 'KR24A0915X'
print(code[0:2])
```

시작을 비우면 **처음부터**입니다. `[:2]`는 `[0:2]`와 같습니다.

```run
code = 'KR24A0915X'
print(code[:2])
```

끝을 비우면 **끝까지**입니다. `[-3:]`은 뒤에서 3글자입니다.

```run
code = 'KR24A0915X'
print(code[-3:])
```

세 번째 칸은 **건너뛰는 간격**입니다. `[::2]`는 한 칸씩 건너뛰고, `[::-1]`은 거꾸로 읽습니다.

```run
code = 'KR24A0915X'
print(code[::2])
print(code[::-1])
```

### 더하기, 곱하기, 길이

`+`는 문자열을 **이어 붙입니다.**

```run
print("L2" + "-" + "0457")
```

`*`는 문자열을 **반복합니다.** 구분선을 그릴 때 자주 씁니다.

```run
print("=" * 10)
```

`len()`은 **글자 수**를 셉니다. 기호와 공백도 한 글자로 셉니다.

```run
print(len("L2-0457"))
```

### 숫자와 문자는 바로 더할 수 없습니다

`"불량 " + 3`처럼 문자열과 숫자를 바로 더하면 `TypeError`가 납니다. 숫자를 `str()`로 문자열로 바꾼 뒤 더합니다.

```run
count = 3
print("불량 " + str(count) + "개")
```

반대로 문자열로 된 숫자를 계산하려면 `int()`나 `float()`로 바꿉니다.

```run
print(int("120") + 1)
print(float("35.5") * 2)
```
