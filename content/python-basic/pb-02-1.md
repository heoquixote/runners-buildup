### 문자열은 따옴표로 감쌉니다

```run
code = 'KR24A0915X'
print(type(code))        # <class 'str'>
print(type(1180), type(23.5), type(True))
```

### 인덱싱: 한 글자 꺼내기

첫 글자는 `[0]`, 마지막 글자는 `[-1]`입니다.

### 슬라이싱: 구간 잘라내기

```run
code = 'KR24A0915X'
print(code[0:2])    # 'KR'   0번부터 1번까지 (끝 번호는 포함 안 됨)
print(code[:2])     # 'KR'   처음부터
print(code[-3:])    # '15X'  뒤에서 3글자
print(code[::2])    # 한 칸씩 건너뛰며
print(code[::-1])   # 거꾸로
```

### 더하기, 곱하기, 길이

```run
print("L2" + "-" + "0457")   # 'L2-0457'
print("=" * 10)              # '=========='
print(len("L2-0457"))        # 7
```

### 숫자와 문자는 바로 더할 수 없습니다

`"불량 " + 3`은 TypeError입니다. `str(3)`으로 바꿔서 더하고, 반대로 `"120"`을 계산하려면 `int("120")`, `float("35.5")`로 바꿉니다.
