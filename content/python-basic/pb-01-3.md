`3`과 `"3"`은 눈으로 보기엔 비슷하지만 파이썬에게는 완전히 다른 값입니다. 하나는 계산할 수 있는 숫자이고, 하나는 글자입니다. 값의 **종류(자료형)**를 알고 필요할 때 바꾸는 법을 익히면, 파일이나 입력에서 들어온 데이터를 계산할 수 있게 됩니다.

### 복습: 네 가지 자료형

[변수 · 자료형 · 사칙연산](#/l/pb-01-1)에서 본 네 가지 자료형을 다시 떠올려 봅니다. 정수 `int`, 소수 `float`, 문자열 `str`, 참 · 거짓 `bool`입니다.

```run
print(type(1250), type(23.45))
print(type("1250"), type(True))
```

`1250`과 `"1250"`은 자료형이 다릅니다. `"3" + 3`이 `TypeError`가 났던 것처럼, 파일이나 `input()`으로 들어온 값은 대부분 문자열이라 **계산 전에 자료형을 바꿔야** 합니다.

### 형변환: 다른 자료형으로 바꾸기

자료형 이름을 함수처럼 쓰면 그 자료형으로 바뀝니다.

```run
raw = "23.45"          # 파일이나 input()으로 들어온 값은 문자열
value = float(raw)
print(value + 1)
print(int("1250") + 1)
print(str(98) + "%")
```

`float("23.45")`는 소수 23.45, `int("1250")`은 정수 1250이 됩니다. 반대로 숫자를 글자 사이에 넣으려면 `str()`로 바꿉니다.

`int()`에 소수를 넣으면 반올림이 아니라 **소수점 아래를 버립니다.**

```run
print(int(9.99))
print(round(9.99))
```

`int(9.99)`는 9, `round(9.99)`는 10입니다.

### 바꿀 수 없는 값도 있습니다

숫자 모양이 아닌 글자는 숫자로 바꿀 수 없습니다. 이때 나는 에러가 `ValueError`입니다.

```python
int("N/A")
```

```
ValueError: invalid literal for int() with base 10: 'N/A'
```

`int("3.5")`도 같은 에러가 납니다. `int()`는 정수 모양의 글자만 받기 때문입니다. 소수 모양이면 `float()`를 거쳐야 합니다.

```run
print(int(float("3.5")))
```

결측값(`"N/A"`, 빈 칸)이 섞인 데이터를 안전하게 바꾸는 방법은 [예외 처리](#/l/pb-12-1) 예외 처리에서 배웁니다.

### 참과 거짓으로 보는 값

`bool()`은 값을 True나 False로 바꿉니다. 규칙은 간단합니다. **비어 있거나 0이면 False, 나머지는 True**입니다.

```run
print(bool(0), bool(0.0), bool(""))
print(bool(3), bool(-1), bool("0"), bool(" "))
```

첫 줄은 모두 False, 둘째 줄은 모두 True입니다. 특히 `"0"`과 `" "`(빈칸 하나)는 글자가 들어 있는 문자열이라 True입니다. 나중에 배울 리스트·딕셔너리도 비어 있으면 False입니다. 이 규칙은 [제어문 (if · for · while)](#/l/pb-07-1)의 `if` 조건에서 "값이 비어 있지 않으면"을 짧게 쓸 때 다시 나옵니다.

```run
note = ""                 # 비고란이 비어 있다
print(bool(note))
note = "재검 필요"
print(bool(note))
```

### 정리

| 하고 싶은 일 | 쓰는 코드 |
| --- | --- |
| 자료형 확인 | `type(x)` |
| 글자 → 정수 | `int("1250")` |
| 글자 → 소수 | `float("23.45")` |
| 숫자 → 글자 | `str(98)` |
| 소수 → 정수 (버림) | `int(9.99)` |
| 참·거짓 판단 | `bool(x)` : 0, 빈 값이면 False |
