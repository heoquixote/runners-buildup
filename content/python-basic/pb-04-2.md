리스트는 담은 값을 언제든 바꿀 수 있어서 편합니다. 그런데 **바뀌면 안 되는 묶음**도 있습니다. 제품 규격의 하한·상한, 설비 좌표, (로트, 수량)처럼 한 쌍으로 다니는 기록이 그렇습니다. 이런 값은 **튜플**에 담습니다.

### 튜플은 괄호로 만듭니다

튜플은 소괄호 `( )` 안에 값을 쉼표로 나열합니다. 꺼내는 방법(인덱싱, 슬라이싱, `len`)은 리스트와 같습니다.

```run
spec = (9.5, 10.5)        # (하한, 상한)
print(spec)
print(spec[0], spec[1])
print(len(spec))
```

괄호 없이 쉼표만 써도 튜플이 됩니다. 값이 하나뿐인 튜플은 끝에 쉼표가 꼭 필요합니다.

```run
a = 9.5, 10.5
b = (3,)
c = (3)
print(type(a), type(b), type(c))
```

`(3)`은 그냥 괄호로 감싼 숫자 3(int)이고, `(3,)`이 튜플입니다.

### 튜플은 바꿀 수 없습니다

리스트처럼 한 자리에 새 값을 대입하면 에러가 납니다. `append`도 없습니다.

```python
spec = (9.5, 10.5)
spec[1] = 11.0
```

```
TypeError: 'tuple' object does not support item assignment
```

불편해 보이지만 이것이 튜플을 쓰는 이유입니다. 코드 어딘가에서 실수로 규격값을 바꾸는 일을 **파이썬이 막아 줍니다.** 정말 바꿔야 하면 새 튜플을 만들어 다시 담습니다.

```run
spec = (9.5, 10.5)
spec = (spec[0], 11.0)
print(spec)
```

### 언패킹: 한 번에 풀어 담기

튜플의 값 개수만큼 변수를 쉼표로 늘어놓으면 **순서대로 하나씩** 담깁니다. 이것을 **언패킹**(unpacking, 풀기)이라고 합니다.

```run
spec = (9.5, 10.5)
low, high = spec
print(low)
print(high)
```

`spec[0]`, `spec[1]`로 꺼내는 것보다 각 값의 뜻이 이름으로 드러나서 읽기 쉽습니다. 리스트도 같은 방법으로 풀 수 있습니다.

```run
record = ("A0915", 1250, 18)
lot, qty, defects = record
print(f"{lot}: 불량률 {defects / qty:.2%}")
```

변수 개수와 값 개수가 다르면 에러가 납니다.

```python
lot, qty = ("A0915", 1250, 18)
```

```
ValueError: too many values to unpack (expected 2)
```

### 두 값 바꾸기

언패킹을 쓰면 임시 변수 없이 두 변수의 값을 맞바꿀 수 있습니다.

```run
first = "L2"
second = "L1"
first, second = second, first
print(first, second)
```

오른쪽 `second, first`가 먼저 튜플 `("L1", "L2")`로 묶인 다음, 왼쪽에 풀어 담기 때문입니다.

### 리스트 안에 튜플: 기록 여러 개

같은 모양의 기록이 여러 개면 **튜플을 리스트에 담습니다.** 기록 하나(튜플)는 고정, 기록 목록(리스트)은 늘었다 줄었다 할 수 있습니다.

```run
records = [("A0915", 1250, 18), ("A0916", 980, 7)]
records.append(("A0917", 1100, 12))
print(len(records))
print(records[1])
print(records[1][2])
```

기록은 3개, 두 번째 기록은 `('A0916', 980, 7)`, 그 불량 수는 7입니다. `records[1][2]`는 [리스트에 담고 꺼내고 고치기](#/l/pb-04-1)의 중첩 리스트처럼 **바깥 번호 → 안쪽 번호** 순서입니다.

```run
records = [("A0915", 1250, 18), ("A0916", 980, 7)]
lot, qty, defects = records[0]       # 0 을 1 로 바꿔 보세요
print(lot, f"{defects / qty:.2%}")
```

### 리스트와 튜플, 언제 무엇을

| | 리스트 `[ ]` | 튜플 `( )` |
| --- | --- | --- |
| 값 바꾸기 · 추가 | 된다 | 안 된다 |
| 잘 맞는 데이터 | 계속 쌓이는 목록 (측정값, 로트 목록) | 한 쌍·한 묶음으로 고정된 값 (규격, 좌표, 기록 한 줄) |
| 예 | `temps = [23.1, 23.4]` | `spec = (9.5, 10.5)` |

[문자열 활용 (함수 문제)](#/l/pb-08-1)에서 함수가 값을 여러 개 돌려줄 때도 튜플이 쓰입니다. `return low, high`가 튜플을 돌려주는 것입니다.
