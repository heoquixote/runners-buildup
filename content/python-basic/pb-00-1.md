## 파이썬이란?

파이썬(Python)은 **사람이 읽기 쉬운 문법**을 목표로 만든 범용 프로그래밍 언어입니다. 중괄호 `{ }` 대신 들여쓰기로 코드 블록을 나누고, 영어 문장에 가까운 키워드(`if`, `for`, `in`, `not`)를 씁니다. 그래서 처음 배우는 사람도 코드를 "읽을" 수 있습니다.

```python
defects = [0, 2, 0, 5, 1]
if max(defects) > 3:
    print("불량이 많은 로트가 있습니다")
```

특징을 세 가지로 요약하면 이렇습니다.

- **인터프리터 언어**: 컴파일 과정 없이 한 줄씩 바로 실행합니다. 쓰고, 돌려 보고, 고치는 주기가 짧아 데이터 탐색에 잘 맞습니다.
- **동적 타입**: `x = 3` 처럼 자료형을 선언하지 않고 값을 담습니다. 편한 대신, 자료형이 다르면 실행 중에 에러가 납니다(Day 05에서 에러 읽는 법을 배웁니다).
- **라이브러리 생태계**: 기본 언어는 작고, 필요한 기능은 패키지로 가져다 씁니다. 데이터 분석의 pandas, 시각화의 matplotlib, 머신러닝의 scikit-learn, 딥러닝의 PyTorch가 모두 파이썬 패키지입니다.

> 비유하면 파이썬은 "공구함"이고 라이브러리는 "전동 공구"입니다. 공구함 사용법(문법)을 이 트랙에서 익히면, 다음 트랙에서 전동 공구(pandas · scikit-learn)를 바로 끼워 쓸 수 있습니다.

### 공식 설치 순서 (Windows 기준)

1. [python.org/downloads](https://www.python.org/downloads/)에서 최신 안정 버전(3.x)을 내려받습니다.
2. 설치 첫 화면에서 **"Add python.exe to PATH"를 반드시 체크**합니다. 이걸 빠뜨리면 터미널에서 `python` 명령을 찾지 못합니다.
3. 설치가 끝나면 터미널(명령 프롬프트 또는 PowerShell)을 열고 아래처럼 버전을 확인한 뒤, 분석에 쓸 패키지를 설치합니다.
4. [VS Code](https://code.visualstudio.com/)를 설치하고 확장(Extensions)에서 **Python**과 **Jupyter**를 추가하면 `.py` 파일과 노트북(`.ipynb`)을 모두 열 수 있습니다.

```
python --version          # Python 3.x.x 가 나오면 성공 (macOS는 python3 --version)
pip install pandas matplotlib jupyter
```

> 자주 막히는 곳: "python은 내부 또는 외부 명령이 아닙니다" 메시지가 나오면 PATH 체크를 빠뜨린 것입니다. 설치 파일을 다시 실행해 Modify → PATH 추가를 선택하세요. 회사 PC라 설치 권한이 없다면 Colab이 가장 빠른 대안입니다.

## 다른 툴과 비교하면

파이썬이 모든 면에서 낫다는 뜻은 아닙니다. **도구마다 잘하는 일이 다르고**, 실무에서는 함께 씁니다. 핵심 차이는 "반복 가능성"과 "확장성"입니다.

| 기준 | 엑셀 | SQL | R | 파이썬 |
| --- | --- | --- | --- | --- |
| 처음 배우기 | 매우 쉬움 | 쉬움 | 보통 | 쉬움 |
| 데이터 크기 | 약 100만 행 한계, 수십만 행부터 느려짐 | DB 용량만큼 (수억 행) | 메모리만큼 | 메모리만큼, 넘으면 DB · Spark와 연결 |
| 작업 반복 · 자동화 | 수작업 반복, 매크로(VBA)는 관리 어려움 | 쿼리 저장으로 반복 가능 | 스크립트로 자동화 | 스크립트 · 스케줄러로 완전 자동화 |
| 작업 기록 · 재현 | 어떤 셀을 고쳤는지 남지 않음 | 쿼리가 곧 기록 | 코드가 곧 기록 | 코드가 곧 기록, Git으로 버전 관리 |
| 통계 · 시각화 | 기본 차트 · 함수 | 집계 위주, 시각화 없음 | 통계에 가장 강함 | scipy · seaborn으로 충분히 강함 |
| 머신러닝 · 딥러닝 | 사실상 불가 | 불가(일부 DB 제외) | 가능, 딥러닝은 약함 | **표준** (scikit-learn, PyTorch) |
| 다른 일과 연결 | 파일 공유 중심 | DB 안에서만 | 분석 중심 | 웹 수집, API, 엑셀 · DB 읽기/쓰기, 서비스 배포까지 |

정리하면 이렇게 나눠 쓰는 경우가 많습니다.

- **엑셀**: 작은 표를 빠르게 확인하고 공유할 때. 결과 보고용으로는 여전히 최고입니다.
- **SQL**: 데이터가 DB에 있을 때 필요한 만큼 **꺼내고 집계**하는 단계. (SQL 트랙에서 따로 다룹니다.)
- **R**: 통계 연구 · 논문 분석처럼 통계 기법이 중심일 때.
- **파이썬**: 꺼낸 데이터를 **정리 → 분석 → 시각화 → 모델링 → 자동화**까지 한 언어로 이어갈 때.

> 실무 예: 매일 아침 설비 로그 CSV 10개를 엑셀로 열어 복사 · 붙여넣기 · 피벗하던 30분짜리 작업은, 파이썬 스크립트 한 번 작성으로 몇 초짜리 작업이 됩니다. 그리고 그 스크립트는 다음 사람이 그대로 다시 쓸 수 있습니다.
