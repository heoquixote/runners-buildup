## 파이썬이란?

파이썬(Python)은 **사람이 읽기 쉬운 문법**을 목표로 만든 범용 프로그래밍 언어입니다. 중괄호 `{ }` 대신 들여쓰기로 코드 블록을 나누고, 영어 문장에 가까운 키워드(`if`, `for`, `in`, `not`)를 씁니다. 그래서 처음 배우는 사람도 코드를 "읽을" 수 있습니다.

```python
defects = [0, 2, 0, 5, 1]
if max(defects) > 3:
    print("불량이 많은 로트가 있습니다")
```

특징을 세 가지로 요약하면 이렇습니다.

- **인터프리터 언어**: 컴파일 과정 없이 한 줄씩 바로 실행합니다. 쓰고, 돌려 보고, 고치는 주기가 짧아 데이터 탐색에 잘 맞습니다.
- **동적 타입**: `x = 3` 처럼 자료형을 선언하지 않고 값을 담습니다. 편한 대신, 자료형이 다르면 실행 중에 에러가 납니다(Day 06에서 에러 읽는 법을 배웁니다).
- **라이브러리 생태계**: 기본 언어는 작고, 필요한 기능은 패키지로 가져다 씁니다. 데이터 분석의 pandas, 시각화의 matplotlib, 머신러닝의 scikit-learn, 딥러닝의 PyTorch가 모두 파이썬 패키지입니다.

### 컴파일 언어와 인터프리터 언어

컴퓨터의 CPU는 사람이 쓴 코드를 바로 알아듣지 못하고, 0과 1로 된 **기계어**만 실행합니다. 그래서 어떤 언어든 "사람의 코드 → 기계가 실행할 수 있는 형태"로 바꾸는 단계가 필요합니다. 이 변환을 **언제, 어떻게** 하느냐에 따라 두 방식으로 나뉩니다.

**컴파일 언어 (C, C++, Go 등)** 는 실행하기 전에 **컴파일러**가 코드 전체를 한꺼번에 기계어로 번역해 실행 파일(Windows의 `.exe` 같은 파일)을 만듭니다. 실행할 때는 이미 번역된 파일을 그대로 돌리므로 빠릅니다. 대신 코드를 한 글자라도 고치면 다시 컴파일해야 하고, 문법 오류가 하나라도 있으면 번역 자체가 되지 않습니다.

**인터프리터 언어 (파이썬, R, 자바스크립트 등)** 는 **인터프리터**라는 프로그램이 코드를 읽으면서 그 자리에서 한 줄씩 실행합니다. 따로 실행 파일을 만들지 않으므로 쓰자마자 바로 돌려 볼 수 있고, 위에서부터 실행하다가 문제가 있는 줄에서 멈춰 그 줄을 알려 줍니다.

> 비유하면 컴파일 언어는 **번역서**입니다. 책 한 권을 미리 통째로 번역해 두면 독자는 빠르게 읽을 수 있지만, 원문이 바뀌면 다시 번역해서 찍어야 합니다. 인터프리터 언어는 **동시통역**입니다. 말하는 즉시 옮겨 주니 내용을 바로바로 바꿀 수 있지만, 매번 통역을 거치므로 조금 느립니다.

| 구분 | 컴파일 언어 | 인터프리터 언어 |
| --- | --- | --- |
| 번역 시점 | 실행 **전**에 전체를 한 번 | 실행하면서 **그때그때** |
| 실행 결과물 | 실행 파일(`.exe` 등)이 따로 생김 | 따로 없음, 코드 파일을 바로 실행 |
| 실행 속도 | 빠름 | 상대적으로 느림 |
| 고치고 다시 보기 | 수정 → 컴파일 → 실행 | 수정 → 바로 실행 |
| 오류를 알게 되는 때 | 컴파일할 때 미리 상당수 발견 | 그 줄을 실행할 때 발견 |
| 잘 맞는 일 | 게임 엔진, 운영체제, 임베디드처럼 속도가 중요한 프로그램 | 데이터 탐색, 자동화 스크립트, 빠른 시제품 |

**Java는 중간형입니다.** 그림에서는 편의상 컴파일 쪽에 두었지만, 엄밀히는 `javac`가 코드를 기계어가 아닌 **바이트코드**(`.class` 파일)로 먼저 컴파일하고, 실행할 때 **JVM**(자바 가상 머신)이 이 바이트코드를 해석하거나 자주 쓰는 부분을 그때 기계어로 바꿔(JIT 컴파일) 실행합니다. 덕분에 같은 `.class` 파일이 Windows, macOS, Linux 어디서든 돌아갑니다.

**사실 파이썬도 속에서는 비슷한 일을 합니다.** 파이썬은 실행 직전에 코드를 바이트코드로 바꾸고(폴더에 생기는 `__pycache__`와 `.pyc` 파일이 그 흔적입니다), 파이썬 가상 머신이 이를 한 줄씩 실행합니다. 다만 사용자는 컴파일 단계를 의식할 필요 없이 "쓰고 바로 실행"하므로 인터프리터 언어라고 부릅니다.

> 실무에서 속도 걱정은? 파이썬 자체는 C보다 느리지만, NumPy · pandas · scikit-learn의 무거운 계산은 내부가 C로 짜여 있어 빠르게 돌아갑니다. 그래서 데이터 분석에서는 "사람이 코드를 쓰고 고치는 속도"가 빠른 파이썬의 장점이 더 크게 작용합니다. 다만 반복문으로 수백만 행을 하나씩 돌리면 느려지는데, 이 문제를 피하는 방법은 데이터분석 트랙의 NumPy 레슨에서 배웁니다.


> 비유하면 파이썬은 "공구함"이고 라이브러리는 "전동 공구"입니다. 공구함 사용법(문법)을 이 트랙에서 익히면, 다음 트랙에서 전동 공구(pandas · scikit-learn)를 바로 끼워 쓸 수 있습니다.

### 공식 설치 순서 (Windows 기준)

1. [python.org/downloads](https://www.python.org/downloads/)에서 최신 안정 버전(3.x)을 내려받습니다.
2. 설치 첫 화면에서 **"Add python.exe to PATH"를 반드시 체크**합니다. 이걸 빠뜨리면 터미널에서 `python` 명령을 찾지 못합니다.
3. 설치가 끝나면 터미널(명령 프롬프트 또는 PowerShell)을 열고 아래처럼 버전을 확인한 뒤, 분석에 쓸 패키지를 설치합니다.
4. [VS Code](https://code.visualstudio.com/)를 설치하고 확장(Extensions)에서 **Python**과 **Jupyter**를 추가하면 `.py` 파일과 노트북(`.ipynb`)을 모두 열 수 있습니다.

```
python --version          # Python 3.x.x 가 나오면 성공 (macOS는 python3 --version)
pip install pandas matplotlib jupyter
```

> 자주 막히는 곳: "python은 내부 또는 외부 명령이 아닙니다" 메시지가 나오면 PATH 체크를 빠뜨린 것입니다. 설치 파일을 다시 실행해 Modify → PATH 추가를 선택하세요. 회사 PC라 설치 권한이 없다면 Colab이 가장 빠른 대안입니다.
