### print: 화면에 보여 주기

코드는 계산을 해도 **보여 달라고 하기 전에는** 아무것도 화면에 나오지 않습니다. `print()`는 괄호 안의 값을 화면에 **출력**하는 명령입니다. 글자는 따옴표로 감쌉니다.

```run
print("안녕하세요, 러너즈빌드업!")
```

숫자는 따옴표 없이 넣습니다. 괄호 안에 계산식을 쓰면 **계산한 결과**를 출력합니다.

```run
print(120 * 8)
```

따옴표로 감싸면 계산식이 아니라 **글자 그대로** 나옵니다. 따옴표가 있느냐 없느냐가 "글자냐 값이냐"를 가릅니다.

```run
print("120 * 8")
print(120 * 8)
```

쉼표로 여러 값을 넣으면 **한 줄에 빈칸 하나씩 띄워서** 출력합니다. 글자와 숫자를 섞어도 됩니다.

```run
print("오늘 생산량", 960, "개")
```

`print()`를 여러 번 쓰면 **한 번에 한 줄씩** 출력합니다. 괄호를 비워 두면 빈 줄이 하나 생깁니다.

```run
print("1교대 완료")
print()
print("2교대 시작")
```

> 쉼표 사이 빈칸을 다른 글자로 바꾸는 `sep`, 줄바꿈을 바꾸는 `end`는 DAY 03 [문자열 출력 다루기](#/l/pb-02-2)에서 다룹니다.

### 주석: 실행되지 않는 메모

`#` 뒤에 쓴 글은 **주석**입니다. 사람이 읽으라고 남기는 메모라서 파이썬은 그 줄을 건너뜁니다.

```run
# 하루 생산량을 출력하는 코드
print(120 * 8)
```

주석은 코드 **줄 끝**에 붙여도 됩니다. `#` 앞까지만 실행됩니다.

```run
print(120 * 8)  # 시간당 120개 × 8시간
```

줄 앞에 `#`를 붙이면 그 줄을 지우지 않고 **잠시 꺼 둘 수** 있습니다. 이것을 "주석 처리한다"고 합니다.

```run
print("이 줄은 실행됩니다")
# print("이 줄은 잠시 꺼 두었습니다")
```

> 주석에는 **왜** 이렇게 했는지를 적습니다. "8을 곱한다"보다 "8시간 근무 기준"이 몇 주 뒤의 나에게 훨씬 도움이 됩니다.

### f-string: 문장 안에 값 끼워 넣기

중괄호 안에는 계산식을 그대로 쓸 수 있습니다. 출력할 때 계산한 결과로 바뀝니다.

```run
print(f"오늘 생산량은 {120 * 8}개입니다")
```

중괄호는 한 문장에 **여러 개** 써도 됩니다.

```run
print(f"양품 {960 - 12}개, 불량 {12}개")
```

앞의 `f`를 빠뜨리면 중괄호가 계산되지 않고 **글자 그대로** 나옵니다. 결과에 `{ }`가 보이면 `f`부터 확인하세요.

```run
print("오늘 생산량은 {120 * 8}개입니다")
```

f-string이 진짜 편해지는 때는 **변수**와 함께 쓸 때입니다. 변수는 값에 붙이는 이름표로, 바로 다음 레슨에서 자세히 배웁니다. 지금은 "이름을 중괄호에 넣으면 그 값이 들어간다"만 보고 넘어가세요.

```run
line = "L2"
qty = 960
print(f"{line} 라인 생산량 {qty}개")
```
