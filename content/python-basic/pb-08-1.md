### 인덱싱

특정 한 글자를 가져옵니다. 파이썬은 0부터 셉니다. `s[-3]`은 뒤에서 세 번째 글자입니다.

> 활용: 장비 모델명 `'EQP-A2024-001'`에서 뒤 3자리 일련번호만 추출

### 슬라이싱

`s[a:b]`는 a부터 b-1까지, `s[3:]`는 4번째 글자부터 끝까지, `s[-3:]`는 마지막 3글자입니다.

> 활용: 센서 파일명 `'Temp_Sensor_20240901.csv'`에서 날짜 부분만 분리

```run
String = 'Hello, World'
print(String[4])    # o
print(String[-3])   # r
print(String[3:])   # lo, World
```

### 결합과 길이

`+`로 문자열을 합치고, `len()`으로 글자 수를 셉니다.

> 활용: 부서 코드와 검사 일자를 합쳐 `'QA-2024-09-01'` 같은 ID 생성, 결과 코드가 8자리인지 검증

### 대소문자 변환과 split

`.upper()`, `.lower()`, `.capitalize()`로 표기를 통일합니다. `.split(',')`은 구분자로 잘라 리스트를 돌려줍니다.

> 활용: 로그 `'ERROR,Temp,A20240901,High'`를 쉼표로 나눠 상태, 종류, 일시, 값을 추출
