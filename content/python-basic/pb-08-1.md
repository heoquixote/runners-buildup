이번 코스의 문제는 `solution` **함수**를 완성하는 방식입니다. 문자열 문법은 [문자열 기초](#/l/pb-02-1), [문자열 메서드](#/l/pb-03-1)에서 배웠으니, 여기서는 그 도구를 함수 안에 넣어 쓰는 법에 집중합니다.

### 함수는 입력을 받아 결과를 돌려주는 기계

함수는 자주 쓰는 일을 묶어 이름을 붙인 것입니다. 자판기에 돈을 넣으면 음료가 나오듯, **매개변수**로 값을 받아 **`return`**으로 결과를 돌려줍니다.

```run
def add_tax(price):          # price: 받는 값(매개변수)
    result = price * 1.1
    return result            # 돌려주는 값

print(add_tax(1000))         # 호출: 1000을 넣는다
print(add_tax(2500))         # 같은 함수를 다른 값으로
```

`def` 줄은 함수를 **만들기만** 합니다. `add_tax(1000)`처럼 괄호를 붙여 호출해야 실행됩니다.

### print와 return은 다릅니다

`print`는 화면에 보여 줄 뿐이고, `return`은 값을 **호출한 곳으로 돌려줍니다.** 돌려받은 값은 변수에 담아 계속 계산할 수 있습니다. 채점기는 `return` 값을 확인합니다.

```run
def with_print(s):
    print(s.upper())         # 보여 주기만 한다

def with_return(s):
    return s.upper()         # 값을 돌려준다

a = with_print("ok")
b = with_return("ok")
print("a:", a)               # 돌려준 값이 없으면 None
print("b:", b)
```

`with_print`는 아무것도 돌려주지 않아서 `a`에는 빈 값을 뜻하는 `None`이 담깁니다. 함수 문제에서 답이 `None`으로 나오면 `return`을 빠뜨린 것입니다.

### 인덱싱

특정 한 글자를 가져옵니다. 파이썬은 0부터 셉니다. `s[-3]`은 뒤에서 세 번째 글자입니다.

> 활용: 장비 모델명 `'EQP-A2024-001'`에서 뒤 3자리 일련번호만 추출

### 슬라이싱

`s[a:b]`는 a부터 b-1까지, `s[3:]`는 4번째 글자부터 끝까지, `s[-3:]`는 마지막 3글자입니다.

> 활용: 센서 파일명 `'Temp_Sensor_20240901.csv'`에서 날짜 부분만 분리

```run
String = 'Hello, World'
print(String[4])    # o
print(String[-3])   # r
print(String[3:])   # lo, World

def serial(model):
    return model[-3:]

print(serial('EQP-A2024-001'))
print(serial('EQP-B2024-117'))
```

슬라이싱 번호가 헷갈리면 글자 수부터 세어 보세요. 파일명에서 날짜를 꺼낼 때는 앞에서 세기보다 뒤에서 세는 편이 안전합니다. 앞쪽 이름 길이가 달라져도 `.csv` 앞 8자리는 그대로이기 때문입니다.

```run
def file_date(name):
    return name[-12:-4]          # 뒤에서 12번째부터 뒤에서 4번째 앞까지

print(file_date('Temp_Sensor_20240901.csv'))
print(file_date('Press_20241105.csv'))
```

### 결합과 길이

`+`로 문자열을 합치고, `len()`으로 글자 수를 셉니다.

> 활용: 부서 코드와 검사 일자를 합쳐 `'QA-2024-09-01'` 같은 ID 생성, 결과 코드가 8자리인지 검증

```run
def make_id(dept, date):
    return dept + "-" + date

def is_valid(code):
    return len(code) == 8        # 비교 결과(True/False)를 바로 돌려준다

print(make_id("QA", "2024-09-01"))
print(is_valid("KR24A091"), is_valid("KR24A0"))
```

### 대소문자 변환과 split

`.upper()`, `.lower()`, `.capitalize()`로 표기를 통일합니다. `.split(',')`은 구분자로 잘라 리스트를 돌려줍니다.

> 활용: 로그 `'ERROR,Temp,A20240901,High'`를 쉼표로 나눠 상태, 종류, 일시, 값을 추출

```run
def parse_log(line):
    parts = line.split(",")
    status = parts[0].lower()
    value = parts[-1]
    return status + ":" + value

print(parse_log("ERROR,Temp,A20240901,High"))
print(parse_log("INFO,Press,A20240902,Low"))
```

`split`의 결과는 리스트라서 번호로 꺼낼 수 있습니다. 문자열을 나눈 뒤 필요한 칸만 골라 다시 조립하는 흐름은 로그 처리에서 가장 많이 쓰입니다.

### 함수 문제를 푸는 순서

1. **입력과 출력을 적습니다.** 예: `'EQP-A2024-001'`을 받아 `'001'`을 돌려준다
2. **예시 하나를 손으로 풉니다.** 어떤 문자열 도구가 필요한지 정합니다
3. **`return`까지 씁니다.** `def solution(s):` 아래에 코드를 넣고 결과를 돌려줍니다
4. **직접 호출해 확인합니다.** 제출 전에 `print(solution('...'))`으로 값을 봅니다

### 자주 하는 실수

| 증상 | 원인 | 고치는 법 |
| --- | --- | --- |
| 답이 `None` | `return` 없음 | `print`를 `return`으로 바꿉니다 |
| `IndexError` | 없는 번호를 꺼냄 | `len()`으로 길이를 먼저 봅니다 |
| 첫 줄만 처리됨 | `return`이 반복문 안에 있음 | `return`을 만나면 함수가 끝납니다. 반복문 밖으로 뺍니다 |
