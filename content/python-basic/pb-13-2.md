### 시작하기 전에

[모듈과 import](#/l/pb-13-1)에서 모듈을 불러오는 법을 배웠습니다. 이번에는 현장 데이터에서 거의 빠지지 않는 **날짜와 시간**을 다루는 `datetime` 모듈입니다. 검사 로그의 시각, 로트 생산일, 유효기간, 설비 가동 시간은 모두 날짜 · 시간 값입니다. "생산일로부터 30일 뒤는 언제지?", "두 검사 사이 몇 분이 지났지?" 같은 계산을 손으로 하면 월말 · 윤년 · 자정에서 쉽게 틀립니다. `datetime`은 이런 계산을 대신 정확하게 해 줍니다.

### 날짜 · 시간을 담는 네 가지 타입

`datetime` 모듈에는 용도가 다른 네 가지 타입이 있습니다.

::figure{src="content/img/py/py-datetime-types.svg" alt="date는 달력의 한 칸으로 date(2026, 11, 7)이 2026-11-07이 된다. time은 시계의 한 순간으로 time(9, 30)이 09:30:00이 된다. datetime은 달력과 시계를 합친 것으로 2026-11-07 09:30:00이다. timedelta는 스톱워치처럼 시간 간격이고 timedelta(days=1, hours=3)은 1 day, 3:00:00이다. 아래에 datetime에 timedelta를 더하면 datetime, datetime끼리 빼면 timedelta라고 적혀 있다" caption="datetime 모듈의 네 가지 타입. 실무에서는 datetime과 timedelta를 가장 많이 씁니다."}

| 타입 | 담는 것 | 비유 |
| --- | --- | --- |
| `date` | 연 · 월 · 일 | 달력의 한 칸 |
| `time` | 시 · 분 · 초 | 시계의 한 순간 |
| `datetime` | 날짜 + 시각 (가장 많이 씀) | 달력 + 시계 |
| `timedelta` | 시간 간격 (며칠, 몇 시간) | 스톱워치 |

### 지금 시각 알아내기

`datetime.now()`는 지금 날짜와 시각을, `date.today()`는 오늘 날짜를 돌려줍니다.

```run
from datetime import datetime, date

print(datetime.now())    # 지금 날짜 + 시각
print(date.today())      # 오늘 날짜
```

실행할 때마다 결과가 바뀝니다. 이 사이트에서는 **내 브라우저(컴퓨터)의 시계와 시간대**를 따릅니다. 맨 뒤 소수점 아래 숫자는 초보다 작은 단위(마이크로초)입니다.

### 날짜를 직접 만들고 부분만 꺼내기

특정 날짜는 `datetime(연, 월, 일, 시, 분, 초)`로 만듭니다. 시 · 분 · 초는 빼면 0입니다. 만든 값에서 `.year`, `.month`, `.hour`처럼 **부분만 꺼낼** 수 있습니다.

```run
from datetime import datetime

made = datetime(2026, 11, 7, 9, 30)     # 2026년 11월 7일 9시 30분
print(made)
print(made.year, made.month, made.day, made.hour, made.minute)
print(made.weekday())                    # 요일 번호: 월요일 0 ~ 일요일 6
```

2026년 11월 7일은 토요일이라 `weekday()`가 `5`입니다. "주말 생산분만 따로 보기" 같은 조건에 씁니다.

### 날짜 ↔ 문자열: strftime과 strptime

파일이나 엑셀에서 읽은 날짜는 대부분 **문자열**(`"2026-11-07 09:00"`)입니다. 문자열은 보기 좋지만 계산이 안 됩니다. 그래서 **계산할 때는 datetime으로, 보여 주거나 저장할 때는 문자열로** 바꿉니다.

::figure{src="content/img/py/py-strftime-strptime.svg" alt="왼쪽 datetime 상자(계산 · 비교 가능)에서 오른쪽 문자열 상자(보기 · 저장용)로 가는 화살표에는 strftime, 반대 방향 화살표에는 datetime.strptime이 적혀 있다. 두 방향 모두 같은 포맷 코드를 쓴다" caption="f는 format(모양 내기), p는 parse(읽어 내기). 두 방향 모두 같은 포맷 코드를 씁니다."}

**strftime: 날짜 → 문자열.** 원하는 모양을 **포맷 코드**로 알려 줍니다.

```run
from datetime import datetime

made = datetime(2026, 11, 7, 9, 5, 30)
print(made.strftime("%Y-%m-%d %H:%M:%S"))
print(made.strftime("%Y%m%d"))            # 폴더 · 파일 이름용
print(made.strftime("%m/%d %A"))          # 월/일 요일
```

자주 쓰는 포맷 코드입니다. 대문자 · 소문자에 따라 뜻이 다르니 주의하세요(`%M`은 분, `%m`은 월).

| 코드 | 의미 | 예 |
| --- | --- | --- |
| `%Y` | 연도(4자리) | 2026 |
| `%m` | 월(01~12) | 11 |
| `%d` | 일(01~31) | 07 |
| `%H` | 시(00~23) | 09 |
| `%M` | 분(00~59) | 05 |
| `%S` | 초(00~59) | 30 |
| `%A` | 요일(영문) | Saturday |

**strptime: 문자열 → 날짜.** 문자열이 어떤 모양인지 같은 포맷 코드로 알려 주면 datetime으로 읽어 냅니다. 모양이 조금이라도 다르면 `ValueError`가 납니다.

```run
from datetime import datetime

text = "2026-11-12 09:00:00"
dt = datetime.strptime(text, "%Y-%m-%d %H:%M:%S")
print(dt, type(dt).__name__)

dt2 = datetime.strptime("2026/11/12", "%Y/%m/%d")    # 슬래시 모양도 그대로 적어 준다
print(dt2)
```

### 왜 꼭 바꿔야 할까요

문자열로 된 날짜를 그대로 비교하면 **글자 순서**로 비교합니다. 모양이 `2026-11-07`처럼 딱 맞으면 우연히 맞지만, 월이나 일을 한 자리로 쓴 기록이 섞이면 틀립니다.

```run
from datetime import datetime

a, b = "2026-11-9", "2026-11-10"
print("문자열 비교:", a < b)          # 글자 '9'와 '1'을 비교

da = datetime.strptime(a, "%Y-%m-%d")
db = datetime.strptime(b, "%Y-%m-%d")
print("날짜 비교:", da < db)
```

문자열 비교는 `False`(11월 9일이 10일보다 늦다고 판단), 날짜 비교는 `True`입니다. 날짜 계산 · 비교 · 정렬 전에는 **꼭 datetime으로 바꾸는 습관**을 들이세요.

### 날짜 더하기: timedelta

`timedelta`는 **시간 간격**입니다. datetime에 더하거나 빼면 그만큼 앞뒤의 날짜가 됩니다. 월말 · 윤년은 알아서 처리합니다.

```run
from datetime import datetime, timedelta

made = datetime(2026, 11, 7, 9, 0)
print(made + timedelta(days=30))            # 30일 뒤 (유효기간)
print(made + timedelta(weeks=1))            # 1주 뒤
print(made - timedelta(hours=10))           # 10시간 전 (전날로 넘어감)
print(timedelta(days=7, hours=3))           # 간격 자체를 출력하면
```

11월 7일 + 30일이 12월 7일로 정확히 넘어갑니다. `timedelta`에는 `days`, `hours`, `minutes`, `seconds`, `weeks`를 넣을 수 있습니다(`months`는 없습니다. 달마다 날 수가 달라서입니다).

### 두 시각의 차이

datetime끼리 빼면 **timedelta**가 나옵니다. `.days`로 날 수를, `.total_seconds()`로 전체 초를 꺼냅니다.

```run
from datetime import datetime

start = datetime(2026, 11, 6, 22, 40)      # 설비 정지
end = datetime(2026, 11, 7, 1, 10)         # 재가동
gap = end - start
print(gap)
print(gap.total_seconds() / 60, "분")
print((datetime(2026, 12, 25) - datetime(2026, 11, 7)).days, "일 남음")
```

자정을 넘긴 정지 시간도 `2:30:00`(150분)으로 정확히 나옵니다. 주의할 점: `.days`는 **며칠인지만** 담고 남은 시간은 버립니다. 분 단위 간격은 `total_seconds()`로 구하세요.

### 정해진 간격으로 시각 만들기

`replace()`는 일부만 바꾼 새 datetime을 만듭니다. "오늘 09:00"을 기준으로 잡고 `timedelta`를 반복해 더하면 **일정 간격의 검사 시각표**가 됩니다.

```run
from datetime import datetime, timedelta

start = datetime(2026, 11, 7, 14, 23).replace(hour=9, minute=0)   # 같은 날 09:00
times = [start + timedelta(minutes=10 * i) for i in range(5)]
for t in times:
    print(t.strftime("%Y-%m-%d %H:%M"))
```

09:00부터 10분 간격으로 5개가 나옵니다. 실제로는 `datetime.now().replace(hour=9, minute=0, second=0, microsecond=0)`처럼 **오늘 09:00 정각**을 만들 때 많이 씁니다. 이 시각표는 [os: 폴더와 파일 경로 다루기](#/l/pb-13-4)의 날짜별 검사 로그 예제에서 다시 씁니다.

### 정리

- `datetime`(날짜 + 시각)과 `timedelta`(간격)를 가장 많이 쓴다. `from datetime import datetime, timedelta`.
- `datetime.now()`는 지금, `datetime(2026, 11, 7, 9, 30)`은 특정 시각. `.year`, `.hour`, `.weekday()`로 부분을 꺼낸다.
- **strftime**: 날짜 → 문자열, **strptime**: 문자열 → 날짜. 같은 포맷 코드(`%Y %m %d %H %M %S`)를 쓴다.
- 문자열 날짜는 계산 · 비교 전에 반드시 datetime으로 바꾼다.
- datetime ± timedelta → datetime, datetime − datetime → timedelta. 분 단위 차이는 `total_seconds()`.
