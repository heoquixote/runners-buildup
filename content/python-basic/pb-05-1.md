### sorted()와 .sort()

<table class="ex-table"><thead><tr><th></th><th><code>sorted(리스트)</code></th><th><code>리스트.sort()</code></th></tr></thead><tbody>
<tr><td>종류</td><td>내장 함수</td><td>리스트 메서드</td></tr>
<tr><td>원본</td><td>그대로 (새 리스트를 돌려줌)</td><td>원본이 바뀜 (돌려주는 값은 None)</td></tr></tbody></table>

```run
w = [3.2, 1.8, 2.5]
s = sorted(w)            # 새 리스트를 돌려주고 w는 그대로
print(s, w)
w.sort()                 # w 자체가 바뀌고 None을 돌려준다
print(w)
w.reverse()              # 순서 뒤집기
print(w)
print(sorted(w, reverse=True))  # 큰 값부터
```

### remove와 pop

```run
q = ["P1", "P2", "P3"]
q.remove("P2")    # 값으로 지우기
last = q.pop()    # 맨 뒤를 꺼내서 돌려줌
first = q.pop(0)  # 0번을 꺼냄
print(last, first, q)   # P3 P1 []
```
