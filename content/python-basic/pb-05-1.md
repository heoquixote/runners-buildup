### sorted()와 .sort()

<table class="ex-table"><thead><tr><th></th><th><code>sorted(리스트)</code></th><th><code>리스트.sort()</code></th></tr></thead><tbody>
<tr><td>종류</td><td>내장 함수</td><td>리스트 메서드</td></tr>
<tr><td>원본</td><td>그대로 (새 리스트를 돌려줌)</td><td>원본이 바뀜 (돌려주는 값은 None)</td></tr></tbody></table>

`sorted()`는 정렬된 **새 리스트**를 돌려줍니다. 원래 리스트 `w`는 그대로입니다.

```run
w = [3.2, 1.8, 2.5]
s = sorted(w)
print(s)
print(w)
```

`.sort()`는 **원래 리스트 자체**를 정렬합니다. 따로 돌려주는 값은 없습니다(`None`).

```run
w = [3.2, 1.8, 2.5]
w.sort()
print(w)
```

그래서 `.sort()`의 결과를 변수에 담으면 `None`이 들어갑니다. 자주 하는 실수입니다.

```run
w = [3.2, 1.8, 2.5]
result = w.sort()
print(result)
```

`reverse=True`를 넣으면 **큰 값부터** 정렬합니다.

```run
w = [3.2, 1.8, 2.5]
print(sorted(w, reverse=True))
```

`.reverse()`는 정렬이 아니라 **지금 순서를 거꾸로** 뒤집기만 합니다.

```run
w = [3.2, 1.8, 2.5]
w.reverse()
print(w)
```

### remove와 pop

`remove()`는 **값**을 찾아 지웁니다. 같은 값이 여러 개면 맨 앞의 것 하나만 지웁니다.

```run
q = ["P1", "P2", "P3"]
q.remove("P2")
print(q)
```

`pop()`은 **맨 뒤 값을 꺼내서 돌려줍니다.** 꺼낸 값은 리스트에서 빠집니다.

```run
q = ["P1", "P2", "P3"]
last = q.pop()
print(last)
print(q)
```

`pop(번호)`는 그 **번호의 값**을 꺼냅니다. `pop(0)`은 맨 앞입니다.

```run
q = ["P1", "P2", "P3"]
first = q.pop(0)
print(first)
print(q)
```
