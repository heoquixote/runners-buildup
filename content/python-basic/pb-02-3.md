현장 데이터에는 **자리마다 뜻이 정해진 코드**가 많습니다. 로트 번호, 시리얼 번호, 설비 코드처럼요. 이런 코드는 슬라이싱으로 자리를 잘라 내기만 하면 공장, 연도, 라인 같은 정보를 꺼낼 수 있습니다. pb-02-1에서 배운 `[시작:끝]`을 실제 코드 해독에 써 봅니다.

### 코드의 자리별 뜻부터 확인합니다

예를 들어 로트 코드 `KR24A0915X`가 다음 규칙으로 만들어졌다고 합시다.

| 자리(번호) | 0~1 | 2~3 | 4 | 5~8 | 9 |
| --- | --- | --- | --- | --- | --- |
| 글자 | `KR` | `24` | `A` | `0915` | `X` |
| 뜻 | 공장 | 연도 | 라인 | 생산일(월일) | 검사 등급 |

슬라이싱 `[시작:끝]`은 **끝 번호를 포함하지 않으니**, 0~1번은 `[0:2]`, 5~8번은 `[5:9]`입니다.

```run
code = "KR24A0915X"
print(code[0:2])     # 공장
print(code[2:4])     # 연도
print(code[4])       # 라인 (한 글자는 인덱싱)
print(code[5:9])     # 생산일
print(code[-1])      # 등급 (맨 끝)
```

`KR`, `24`, `A`, `0915`, `X`가 차례로 나옵니다. 끝 번호는 **"마지막 자리 + 1"**로 쓴다고 기억하면 됩니다.

### 꺼낸 조각으로 새 문자열 만들기

잘라 낸 조각은 `+`로 다시 이어 다른 모양을 만들 수 있습니다.

```run
code = "KR24A0915X"
date = "20" + code[2:4] + "-" + code[5:7] + "-" + code[7:9]
print(date)
```

`2024-09-15`가 됩니다. 연도 `24` 앞에 `20`을 붙이고, `0915`를 월 `09`와 일 `15`로 다시 나눴습니다.

### 간격 지정: [시작:끝:간격]

세 번째 숫자는 **몇 칸씩 건너뛸지**입니다. 생략하면 1입니다.

```run
s = "0123456789"
print(s[::2])     # 처음부터 끝까지 2칸씩
print(s[1::2])    # 1번부터 2칸씩
print(s[::-1])    # 거꾸로
```

`02468`, `13579`, `9876543210`이 나옵니다. 간격이 음수이면 뒤에서 앞으로 갑니다. `[::-1]`은 "문자열 뒤집기"로 외워 두면 편합니다.

```run
code = "KR24A0915X"
print(code[::3])      # 간격을 2, 4, -1 로 바꿔 보세요
```

### 범위를 넘어도 슬라이싱은 에러가 아닙니다

인덱싱으로 없는 번호를 읽으면 `IndexError`가 나지만, 슬라이싱은 **있는 데까지만** 잘라 줍니다.

```run
code = "KR24"
print(code[2:10])
print(code[10:20] == "")
```

`24`와 True가 나옵니다. 범위 밖은 빈 문자열이 됩니다. 편리하지만, 코드 길이가 규칙보다 짧아도 조용히 넘어간다는 뜻이기도 합니다. 길이 검사(`len(code) == 10`)를 먼저 하는 습관이 필요합니다.

### 문자열은 고칠 수 없습니다

문자열은 한 글자만 골라 바꿀 수 없습니다. (pb-04에서 배울 리스트는 한 자리씩 바꿀 수 있어서 대조됩니다.)

```python
code = "KR24A0915X"
code[4] = "B"
```

```
TypeError: 'str' object does not support item assignment
```

글자를 바꾸고 싶으면 **새 문자열을 만들어** 다시 담습니다. 바꿀 자리 앞뒤를 잘라 새 글자와 잇습니다.

```run
code = "KR24A0915X"
code = code[:4] + "B" + code[5:]
print(code)
```

`KR24B0915X`가 됩니다. 문자열 메서드 `replace()`(pb-03-1)도 원본을 고치지 않고 새 문자열을 돌려주는 것과 같은 이유입니다.

### 정리

| 하고 싶은 일 | 코드 |
| --- | --- |
| n번부터 m번까지 | `s[n:m+1]` |
| 앞 k글자 / 뒤 k글자 | `s[:k]` / `s[-k:]` |
| 2칸씩 | `s[::2]` |
| 뒤집기 | `s[::-1]` |
| 한 글자 바꾸기 | `s[:i] + "새" + s[i+1:]` |
