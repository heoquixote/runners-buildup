## 이런 분께 맞습니다

- 가볍고 표준적인 환경을 원할 때 (설치 용량 수백 MB)
- 분석뿐 아니라 자동화 스크립트나 프로그램도 만들고 싶을 때
- 회사에서 Anaconda 라이선스 때문에 쓰기 어려울 때

**준비물**: 설치 권한이 있는 PC, 인터넷.

**내려받기**: 파이썬 [python.org/downloads](https://www.python.org/downloads/) · VS Code [code.visualstudio.com](https://code.visualstudio.com/) (새 탭에서 열립니다)

> 이 방법은 두 프로그램을 따로 설치합니다. **python.org의 파이썬은 엔진**(코드를 실행하는 인터프리터)이고, **VS Code는 작업대**(코드를 쓰고 실행 버튼을 누르는 편집기)입니다. 엔진만 있어도 실행은 되지만, 작업대가 있어야 편하게 일할 수 있습니다.

## 따라 하기 1. 파이썬 설치

### Windows

1. [python.org/downloads](https://www.python.org/downloads/) 에 접속해 노란 **Download Python 3.x.x** 버튼을 누릅니다.
2. 내려받은 설치 파일을 실행합니다.

4. **Install Now**를 누릅니다(②). 끝 화면에 "Disable path length limit"이 보이면 한 번 눌러 두면 좋습니다.

`Python 3.x.x` 가 나오면 성공입니다.

### macOS

1. [python.org/downloads](https://www.python.org/downloads/) 에서 **macOS 64-bit universal2 installer**(`.pkg`)를 내려받아 실행하고 계속, 동의, 설치를 누릅니다.
2. 설치가 끝나면 Finder의 **응용 프로그램 → Python 3.x** 폴더가 열립니다. 그 안의 **Install Certificates.command**를 더블클릭해 한 번 실행합니다. (인터넷에서 데이터를 받을 때 나는 SSL 오류를 막아 줍니다.)
3. 설치 확인: **터미널**을 열고 입력합니다. macOS에서는 `python` 대신 **`python3`**를 씁니다.

```
python3 --version
```

## 따라 하기 2. VS Code 설치

1. [code.visualstudio.com](https://code.visualstudio.com/) 에서 내 운영체제용 VS Code를 내려받아 설치합니다.
   - Windows: 설치 중 "추가 작업 선택" 화면에서 **PATH에 추가**와 **"Code(으)로 열기" 작업 추가**를 체크해 두면 편합니다.
   - macOS: 내려받은 앱을 **응용 프로그램** 폴더로 끌어다 놓습니다.
2. VS Code를 열고 왼쪽 세로 막대의 **확장(Extensions)** 아이콘(네모 네 개 모양)을 누릅니다. 단축키는 `Ctrl + Shift + X` (macOS `Cmd + Shift + X`).
3. 검색창에 `Python` 을 입력하고 게시자가 **Microsoft**인 Python 확장을 **설치**합니다.
4. 같은 방법으로 **Jupyter** 확장(Microsoft)도 설치합니다. 노트북(`.ipynb`)을 VS Code에서 열 수 있게 됩니다.

## 따라 하기 3. 첫 파이썬 파일 실행

1. 바탕화면이나 문서 폴더에 **`my-python`** 이라는 빈 폴더를 만듭니다. (폴더 이름도 영문으로)
2. VS Code 메뉴 **파일 → 폴더 열기**로 그 폴더를 엽니다. "이 폴더의 작성자를 신뢰하십니까?"가 나오면 **예**를 누릅니다.
3. 탐색기(①)에서 새 파일 아이콘을 누르고 이름을 **`hello.py`** 로 짓습니다. 확장자 `.py`가 파이썬 파일이라는 표시입니다.
4. 편집기(③)에 아래 코드를 입력하고 저장합니다(`Ctrl + S`, macOS `Cmd + S`).

```
import sys
print("Hello, VS Code!", sys.version.split()[0])
```

5. 오른쪽 위 **▶ 버튼**(④)을 누릅니다. 아래 터미널(⑤)에 `Hello, VS Code! 3.x.x` 가 나오면 성공입니다.
6. 오른쪽 아래 상태 표시줄(⑥)에 지금 쓰는 파이썬 버전이 보입니다. 다른 버전이 보이면 클릭하거나 `Ctrl + Shift + P` → **Python: Select Interpreter**에서 방금 설치한 파이썬을 고릅니다.

## 따라 하기 4. 가상환경 만들고 pandas 설치

**가상환경**은 프로젝트마다 따로 쓰는 **파이썬 패키지 보관함**입니다. 프로젝트 A에서 설치한 패키지가 프로젝트 B를 망가뜨리지 않도록 칸막이를 치는 것이라고 생각하면 됩니다. 실무에서는 프로젝트 폴더마다 하나씩 만드는 것이 표준입니다.

VS Code 메뉴 **터미널 → 새 터미널**을 열고, 운영체제에 맞게 입력합니다.

**Windows (PowerShell)**

```
python -m venv .venv
.venv\Scripts\activate
python -m pip install pandas matplotlib
```

**macOS (터미널)**

```
python3 -m venv .venv
source .venv/bin/activate
python -m pip install pandas matplotlib
```

활성화되면 터미널 줄 맨 앞에 **`(.venv)`** 가 붙습니다. VS Code가 "새 환경을 선택할까요?"라고 물으면 **예**를 누르고, 상태 표시줄(⑥)이 `('.venv')` 로 바뀌었는지 확인합니다.

## 첫 코드 실행 확인

`hello.py` 내용을 아래로 바꾸고 ▶ 버튼을 누릅니다.

```
import sys
import pandas as pd
print("파이썬 위치:", sys.executable)
print("pandas 버전:", pd.__version__)
```

파이썬 위치에 `.venv` 가 들어 있고 pandas 버전이 나오면, 가상환경까지 모두 준비된 것입니다.

## 자주 막히는 문제와 해결법

| 증상 | 원인 | 해결 |
| --- | --- | --- |
| `python` 을 입력하면 Microsoft Store가 열림 | Windows의 "앱 실행 별칭"이 가로챔 | **설정 → 앱 → 고급 앱 설정 → 앱 실행 별칭**에서 `python.exe`, `python3.exe`를 끔 |
| `'python'은(는) 내부 또는 외부 명령...이 아닙니다` | 설치할 때 PATH 체크를 빠뜨림 | 설치 파일을 다시 실행 → **Modify** → 다음 화면에서 "Add Python to environment variables" 체크. 또는 `py --version` 처럼 `py` 명령 사용 |
| `pip` 를 인식하지 못함 | pip 경로가 PATH에 없음 | `pip install` 대신 **`python -m pip install`** 사용 (macOS는 `python3 -m pip`) |
| `activate` 할 때 "이 시스템에서 스크립트를 실행할 수 없으므로…" | PowerShell 보안 정책 | PowerShell에 `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` 입력 후 `Y`, 다시 activate |
| 설치했는데 `ModuleNotFoundError: No module named 'pandas'` | 패키지를 설치한 파이썬과 실행하는 파이썬이 다름 | 상태 표시줄(⑥)에서 `.venv` 파이썬을 고르고, 그 터미널에서 `python -m pip install pandas` |
| macOS에서 데이터 받을 때 `SSL: CERTIFICATE_VERIFY_FAILED` | 인증서 설정이 안 됨 | 응용 프로그램 → Python 3.x → **Install Certificates.command** 실행 |
| ▶ 버튼이 안 보임 | Python 확장이 없거나 `.py` 파일이 아님 | 확장에서 Python(Microsoft) 설치, 파일 이름이 `.py` 로 끝나는지 확인 |
