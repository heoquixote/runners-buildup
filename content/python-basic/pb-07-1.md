### input()은 항상 문자열을 돌려줍니다

숫자로 계산하려면 `int()`나 `float()`로 바꿔야 합니다. 측정값처럼 소수점이 있으면 `float()`를 씁니다.

```run
# input()은 받은 글자를 그대로 문자열로 돌려준다. 계산하려면 숫자로 바꿔야 한다.
raw = "1180"                 # input("로트 번호: ") 로 받았다고 가정
print(repr(raw))             # '1180' 은 문자열 — raw + 1 은 TypeError
lot = int(raw)
x = float("23.45")
print(lot + 1, x * 2)        # 1181 46.9
print(type(lot), type(x))
```

### 나머지 연산자 %

`n % 2 == 0`이면 짝수입니다. `i % 5 == 0`처럼 쓰면 "5개마다 1개" 같은 발취 규칙을 표현할 수 있습니다.

### if / elif / else

규격 판정처럼 경우가 셋 이상이면 `elif`를 씁니다. 경계값(9.5, 10.5)이 규격 안인지 밖인지 `<`와 `<=`를 구분해서 생각하세요.

### for와 range

`range(1, n + 1)`은 1부터 n까지입니다. 끝 숫자는 포함되지 않습니다.

### while과 break

"조건을 만족할 때까지 반복"은 `while True:` 안에서 조건을 만족하면 `break`로 빠져나옵니다.
