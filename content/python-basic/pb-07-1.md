지금까지 쓴 코드는 위에서 아래로 한 줄씩 그대로 내려갔습니다. 하지만 실제 일은 그렇지 않습니다. 규격 안이면 합격, 밖이면 불합격처럼 **상황에 따라 갈라지고**, 100개 제품을 똑같이 검사하듯 **같은 일을 되풀이합니다.** 이 흐름을 만드는 문법이 제어문입니다.

| 하고 싶은 일 | 쓰는 문법 |
| --- | --- |
| 조건에 따라 다른 일을 한다 | `if`, `elif`, `else` |
| 정해진 횟수나 목록만큼 반복한다 | `for` |
| 조건을 만족할 때까지 반복한다 | `while` |

### input()은 항상 문자열을 돌려줍니다

`input()`은 사용자가 입력한 값을 받습니다. 숫자를 입력해도 **문자열**로 들어오기 때문에, 계산하려면 `int()`나 `float()`로 바꿔야 합니다. 측정값처럼 소수점이 있으면 `float()`를 씁니다.

```run
# input()은 받은 글자를 그대로 문자열로 돌려준다. 계산하려면 숫자로 바꿔야 한다.
raw = "1180"                 # input("로트 번호: ") 로 받았다고 가정
print(repr(raw))             # '1180' 은 문자열 — raw + 1 은 TypeError
lot = int(raw)
x = float("23.45")
print(lot + 1, x * 2)        # 1181 46.9
print(type(lot), type(x))
```

### 비교하면 True나 False가 나옵니다

조건문은 **참(True)인지 거짓(False)인지**만 봅니다. 비교 연산자는 그 답을 만들어 줍니다.

| 연산자 | 뜻 | 예 (x = 10) | 결과 |
| --- | --- | --- | --- |
| `==` | 같다 | `x == 10` | True |
| `!=` | 다르다 | `x != 10` | False |
| `>`, `<` | 크다, 작다 | `x > 10` | False |
| `>=`, `<=` | 크거나 같다, 작거나 같다 | `x >= 10` | True |

`=`는 값을 담는 기호이고, 같은지 묻는 기호는 `==`입니다. 조건 여러 개는 `and`(둘 다), `or`(하나라도), `not`(반대)으로 묶습니다.

```run
x = 10.2
print(x == 10.2)
print(x >= 9.5 and x <= 10.5)     # 둘 다 참이어야 True
print(9.5 <= x <= 10.5)           # 파이썬은 이렇게 이어 써도 됩니다
print(x < 9.5 or x > 10.5)        # 규격을 벗어났는가?
```

### if / elif / else

**위에서부터 차례로** 조건을 검사하고, 처음 참이 된 곳 하나만 실행한 뒤 나머지는 건너뜁니다. 규격 판정처럼 경우가 셋 이상이면 `elif`를 씁니다.

조건 줄 끝에는 콜론 `:`을 붙이고, 그 조건에서 실행할 줄은 **네 칸 들여씁니다.** 파이썬은 들여쓰기로 어디까지가 조건 안인지 구분합니다.

```run
size = 10.6                # 값을 9.4, 9.5, 10.0, 10.5 로 바꿔 보세요

if size < 9.5:
    print("불합격: 규격 미달")
elif size > 10.5:
    print("불합격: 규격 초과")
else:
    print("합격")
print("검사 끝")            # 들여쓰지 않았으니 항상 실행
```

위 코드는 경계값 9.5와 10.5를 합격으로 처리합니다. 규격이 "10.5 **미만**"이라면 `size >= 10.5`로 써야 합니다. 판정 문제에서는 경계값(9.5, 10.5)이 규격 안인지 밖인지 `<`와 `<=`를 꼭 구분해서 생각하세요.

### 나머지 연산자 %로 규칙 만들기

`n % 2 == 0`이면 짝수입니다. `i % 5 == 0`처럼 쓰면 "5개마다 1개" 같은 발취 규칙을 표현할 수 있습니다.

```run
n = 7
if n % 2 == 0:
    print(n, "짝수")
else:
    print(n, "홀수")

i = 15
print(i % 5 == 0)      # 15번째 제품은 발취 대상인가?
```

### for와 range

`for`는 목록에서 값을 하나씩 꺼내 같은 코드를 실행합니다. 정해진 횟수만큼 돌리고 싶으면 `range()`로 숫자 목록을 만듭니다.

| 코드 | 나오는 숫자 |
| --- | --- |
| `range(4)` | 0, 1, 2, 3 |
| `range(1, 4)` | 1, 2, 3 |
| `range(0, 10, 3)` | 0, 3, 6, 9 |

`range(1, n + 1)`은 1부터 n까지입니다. **끝 숫자는 포함되지 않습니다.** 슬라이싱과 같은 규칙입니다.

```run
for i in range(1, 4):
    print(i, "번째 제품 검사")

temps = [23.1, 25.4, 22.8]
for t in temps:            # 리스트에서 값을 하나씩 꺼낸다
    print(t, "높음" if t > 25 else "정상")
```

### 반복의 기본 패턴: 세기와 더하기

`for` 안에 `if`를 넣으면 "조건에 맞는 것만 세기"가 됩니다. 반복 **밖에서** 시작값을 만들고, 반복 **안에서** 조금씩 키우는 모양이 핵심입니다.

```run
sizes = [10.1, 9.2, 10.4, 10.8, 9.9]
ok = 0                     # 합격 개수를 셀 변수
total = 0                  # 합계를 모을 변수

for s in sizes:
    total = total + s
    if 9.5 <= s <= 10.5:
        ok += 1            # ok = ok + 1 과 같습니다

print("합격", ok, "개 / 전체", len(sizes), "개")
print("평균", round(total / len(sizes), 2))
```

다섯 개 중 9.2와 10.8이 규격을 벗어나 합격은 3개이고, 평균은 10.08입니다. `ok = 0`을 `for` 안에 넣으면 매번 0으로 돌아가니 조심하세요.

### while과 break

`for`는 횟수가 정해져 있을 때, `while`은 **언제 끝날지 모를 때** 씁니다. 조건이 참인 동안 계속 반복합니다.

"조건을 만족할 때까지 반복"은 `while True:` 안에서 조건을 만족하면 `break`로 빠져나옵니다. `continue`는 이번 회차의 나머지를 건너뛰고 다음 회차로 넘어갑니다.

```run
stock = 100
day = 0
while stock > 0:           # 재고가 있는 동안
    stock -= 30
    day += 1
print(day, "일 만에 재고 소진, 남은 값:", stock)

codes = ["A1", "", "B2", "END", "C3"]
for c in codes:
    if c == "":
        continue           # 빈 값은 건너뛴다
    if c == "END":
        break              # END를 만나면 반복 종료
    print("처리:", c)
```

재고는 100, 70, 40, 10을 지나 -20이 되는 4일째에 멈춥니다. `C3`은 `break` 뒤에 있어서 처리되지 않습니다.

### 자주 하는 실수

| 증상 | 원인 | 고치는 법 |
| --- | --- | --- |
| `IndentationError` | 들여쓰기가 어긋남 | 같은 블록은 같은 칸 수로 맞춥니다 |
| `SyntaxError` | `if`, `for` 줄 끝에 `:` 누락 | 콜론을 붙입니다 |
| 끝나지 않음 | `while` 안에서 조건이 바뀌지 않음 | 변수를 줄이거나 `break`를 넣습니다 |
| 숫자가 하나 모자람 | `range(1, n)` | `range(1, n + 1)`로 씁니다 |
