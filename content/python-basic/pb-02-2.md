`print()`는 지금까지 값 하나를 보여 주는 데만 썼습니다. 검사 결과를 보고서처럼 보여 주려면 값 사이를 무엇으로 띄울지, 줄을 언제 바꿀지 정할 수 있어야 합니다. 이 레슨에서는 출력 모양을 마음대로 다루는 방법을 배웁니다.

### print에 값 여러 개 넣기

쉼표로 값을 여러 개 넣으면 사이에 **빈칸 하나**를 넣어 출력합니다. 숫자와 문자열을 섞어도 됩니다.

```run
lot = "A0915"
qty = 1250
print("로트", lot, "수량", qty)
```

`+`로 이으려면 숫자를 `str()`로 바꿔야 했지만([자료형과 형변환](#/l/pb-01-3)), 쉼표로 넣으면 그럴 필요가 없습니다.

### sep: 값 사이에 넣을 글자

`sep`(separator, 구분자)을 지정하면 빈칸 대신 그 글자를 넣습니다.

```run
print("2024", "09", "15", sep="-")
print("A01", "PASS", "23.4", sep=",")
print("L1", "L2", "L3", sep="")
```

첫 줄은 날짜 모양 `2024-09-15`, 둘째 줄은 CSV 한 줄 모양, 셋째 줄은 사이에 아무것도 없이 붙습니다.

### end: 줄 끝에 넣을 글자

`print()`는 출력이 끝나면 자동으로 **줄을 바꿉니다.** `end`를 바꾸면 줄을 바꾸지 않고 이어서 출력할 수 있습니다.

```run
print("검사 중", end="... ")
print("완료")
```

두 번 호출했지만 한 줄에 `검사 중... 완료`가 나옵니다. `end`의 기본값은 줄바꿈 글자 `"\n"`입니다.

```run
print("A", "B", "C", sep=" | ", end=" <끝>\n")    # sep, end 값을 바꿔 보세요
```

### 이스케이프: 글자로 못 쓰는 글자

줄바꿈이나 탭은 키보드로 문자열 안에 바로 쓸 수 없습니다. 그래서 역슬래시 `\` 뒤에 약속된 글자를 붙여 표시합니다. 이것을 **이스케이프 문자**라고 합니다.

| 쓰는 법 | 뜻 |
| --- | --- |
| `\n` | 줄바꿈 |
| `\t` | 탭 (칸 맞춤) |
| `\\` | 역슬래시 글자 하나 |
| `\'`, `\"` | 따옴표 글자 |

```run
print("1행\n2행")
print("로트\t수량\t판정")
print("A0915\t1250\tPASS")
```

`\t`는 다음 칸 위치까지 띄우기 때문에 간단한 표 모양을 만들 때 씁니다. `\n`은 화면에서는 줄바꿈으로 보이지만 **글자 하나**로 셉니다.

```run
s = "A\nB"
print(len(s))
```

`A`, 줄바꿈, `B`로 3글자입니다.

### 따옴표 안에 따옴표

문자열을 감싼 따옴표와 **다른 종류**의 따옴표는 안에 그대로 쓸 수 있습니다.

```run
print("설비 'EQ-07' 점검")
print('판정: "보류"')
```

### 여러 줄 문자열

따옴표를 세 개(`"""` 또는 `'''`) 쓰면 엔터로 바꾼 줄이 그대로 들어갑니다. 짧은 보고서 틀을 만들 때 편합니다.

```run
report = """[일일 검사 보고]
라인: L2
불량: 18건"""
print(report)
```

### 자주 하는 실수

파일 경로를 쓸 때 Windows의 역슬래시가 이스케이프로 읽힐 수 있습니다. `"C:\new\test.csv"`의 `\n`과 `\t`는 줄바꿈과 탭이 됩니다. 이때는 역슬래시를 두 번 쓰거나, 따옴표 앞에 `r`을 붙여 "이스케이프 없이 그대로"라고 알려 줍니다.

```run
print("C:\\new\\test.csv")
print(r"C:\new\test.csv")
```

두 줄 모두 `C:\new\test.csv`가 그대로 나옵니다.
