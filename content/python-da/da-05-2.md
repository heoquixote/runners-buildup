da-05-1에서 `strip` · `upper` · `replace`로 표기를 맞추고, `to_numeric(errors='coerce')`로 숫자로 바꿨습니다. 실제 현장 데이터는 한 단계 더 지저분합니다. 로트 번호 안에 날짜와 설비 정보가 섞여 있고, 측정값에 단위가 붙어 있고, 단위마저 mm와 cm가 섞여 있습니다. 이 레슨에서는 **한 칸에 섞인 정보를 나누고, 숫자만 뽑아내고, 변환에 실패한 값을 찾아내는** 과정을 익힙니다.

## 한 칸을 여러 열로: str.split(expand=True)

로트 번호 `L240915-A03`은 "생산일 240915, 설비 A03"이라는 정보 두 개가 붙어 있습니다. `str.split('-')`은 칸마다 리스트를 주고, `expand=True`를 붙이면 바로 **열 여러 개**로 펼쳐 줍니다.

```run
import pandas as pd

df = pd.DataFrame({'lot': ['L240915-A03', 'L240915-B11', 'L240916-A07'], 'qty': [500, 480, 520]})
parts = df['lot'].str.split('-', expand=True)
print(parts)

df['day'] = parts[0].str[1:]          # 맨 앞 L을 빼고 날짜만
df['machine'] = parts[1]
df['line'] = parts[1].str[0]          # 설비 코드 첫 글자 = 라인
print(df)
```

`expand=True` 결과는 열 이름이 0, 1인 표입니다. 여기서 원하는 열만 골라 원래 표에 붙였습니다. `.str[1:]`처럼 슬라이싱도 열 전체에 됩니다. pb-02-3에서 고정 길이 코드를 잘라 읽던 방법을 표에 그대로 쓴 것입니다.

나눈 열이 생기면 바로 집계할 수 있습니다.

```run
import pandas as pd

df = pd.DataFrame({'lot': ['L240915-A03', 'L240915-B11', 'L240916-A07'], 'qty': [500, 480, 520]})
df['line'] = df['lot'].str.split('-').str[1].str[0]
print(df.groupby('line')['qty'].sum())
```

`str.split('-').str[1]`처럼 쓰면 `expand` 없이 두 번째 조각만 바로 꺼냅니다.

## 글자 사이에서 숫자만 뽑기: str.extract

`'12.5mm'`, `'1.3 cm'`처럼 숫자와 단위가 붙어 있으면 `replace`로 단위를 하나씩 지우기 번거롭습니다. `str.extract`는 **패턴**에 맞는 부분만 뽑아냅니다. 패턴은 **정규표현식**이라는 작은 문법으로 쓰는데, 여기서는 세 가지만 알면 됩니다.

| 기호 | 뜻 |
| --- | --- |
| `[\d.]+` | 숫자나 점이 1개 이상 이어진 부분 (12.5) |
| `\s*` | 공백이 0개 이상 |
| `[a-zA-Z]+` | 영문자가 1개 이상 (mm, cm) |
| `( )` | 이 괄호 안을 뽑아 열 하나로 |

```run
import pandas as pd

m = pd.Series(['12.5mm', '1.3 cm', '13.1MM', '?', '12.8 mm'])
x = m.str.extract(r'([\d.]+)\s*([a-zA-Z]+)')
x.columns = ['val', 'unit']
print(x)
```

괄호가 두 개라 열도 두 개(값, 단위)가 나왔습니다. 패턴에 맞지 않는 `'?'`는 두 칸 모두 `NaN`입니다. 패턴 앞의 `r`은 역슬래시(`\`)를 글자 그대로 쓰겠다는 표시이니 정규표현식에는 항상 붙입니다.

## 단위 맞추기

뽑은 값은 아직 문자열입니다. 숫자로 바꾸고, 단위가 cm인 행만 10을 곱해 mm로 통일합니다. 단위 열은 소문자로 맞춘 뒤 비교합니다.

```run
import numpy as np
import pandas as pd

m = pd.Series(['12.5mm', '1.3 cm', '13.1MM', '?', '12.8 mm'])
x = m.str.extract(r'([\d.]+)\s*([a-zA-Z]+)')
x.columns = ['val', 'unit']

val = pd.to_numeric(x['val'], errors='coerce')
unit = x['unit'].str.lower()
mm = np.where(unit == 'cm', val * 10, val)
print(mm)
print(round(np.nanmean(mm), 2))       # NaN을 빼고 평균
```

1.3cm가 13.0mm로 바뀌어 다른 값들과 같은 크기가 됐습니다. 단위를 맞추지 않고 평균을 냈다면 1.3이 섞여 평균이 크게 낮아졌을 것입니다. `np.nanmean`은 NaN을 빼고 평균을 냅니다(pandas Series의 `mean()`은 기본으로 NaN을 뺍니다).

## 변환에 실패한 값 찾아내기

`errors='coerce'`는 편리하지만, 숫자로 못 바꾼 값을 **조용히** NaN으로 만듭니다. 몇 개가 실패했는지, 원래 무엇이었는지 반드시 확인합니다. 실패한 값 중에 살릴 수 있는 것이 있기 때문입니다.

```run
import pandas as pd

raw = pd.Series(['1,250', '980개', ' 1105 ', 'N/A', '1.2k'])
clean = (raw.str.replace(',', '', regex=False)
            .str.replace('개', '', regex=False)
            .str.strip())
num = pd.to_numeric(clean, errors='coerce')
print(num.tolist())
print(num.isna().sum(), "개 실패:", raw[num.isna()].tolist())
```

괄호로 감싸면 메서드를 여러 줄에 나눠 쓸 수 있습니다. 실패한 2개를 보면 `'N/A'`는 정말 값이 없는 것이지만, `'1.2k'`는 1,200이라는 값이 있습니다. 실패 목록을 확인하지 않았다면 1,200개를 잃어버렸을 것입니다. 실패한 값의 종류를 보고 규칙을 하나 더 추가할지 판단합니다.

```run
import pandas as pd

raw = pd.Series(['1,250', '980개', ' 1105 ', 'N/A', '1.2k'])
clean = raw.str.replace(',', '', regex=False).str.replace('개', '', regex=False).str.strip()
is_k = clean.str.endswith('k', na=False)
base = pd.to_numeric(clean.str.rstrip('k'), errors='coerce')
num = base.where(~is_k, base * 1000)          # k로 끝나면 1000배
print(num.tolist())
```

`where(조건, 다른 값)`은 조건이 True인 자리는 그대로 두고, False인 자리를 다른 값으로 바꿉니다. `np.where`와 비슷하지만 Series 메서드라 인덱스가 그대로 유지됩니다.

## 정리 순서

1. `value_counts()`나 `unique()`로 어떤 표기가 섞였는지 먼저 봅니다
2. 한 칸에 정보가 여러 개면 `split(expand=True)`나 `extract`로 나눕니다
3. 단위 · 기호를 지우거나 맞추고 `to_numeric(errors='coerce')`로 바꿉니다
4. 실패한 값을 원래 값과 함께 확인하고, 살릴 수 있으면 규칙을 추가합니다
