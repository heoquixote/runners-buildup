[나누고, 집계하고, 합치기](#/l/da-06-1)에서 `groupby`로 그룹마다 값 하나를 내고(`agg`), 원래 행 수 그대로 그룹 값을 붙였습니다(`transform`). 실무 질문은 한 걸음 더 나갑니다. "그룹마다 최대 − 최소 폭은?", "표본이 너무 적은 그룹은 빼고 비교하자", "라인마다 불량이 가장 많은 로트 2개", "그 로트가 라인 안에서 몇 등인가" 같은 질문입니다. 이 레슨에서는 이런 질문을 groupby로 푸는 방법을 다룹니다.

## 내가 만든 집계 함수 쓰기

`agg`에는 `'mean'` 같은 이름뿐 아니라 **함수**도 넣을 수 있습니다. 그룹마다 Series 하나를 받아 값 하나를 돌려주는 함수면 됩니다. 짧으면 lambda, 길거나 여러 번 쓰면 `def`로 만듭니다.

```run
import pandas as pd

df = pd.read_csv("penguins.csv").dropna()

def p90(s):
    return s.quantile(0.9)            # 상위 10% 경계

result = df.groupby('species').agg(
    mass_mean=('body_mass_g', 'mean'),
    mass_range=('body_mass_g', lambda s: s.max() - s.min()),
    mass_p90=('body_mass_g', p90),
).round(0)
print(result)
```

Gentoo는 평균(5,092g)도 크고 몸무게 폭(2,350g)도 가장 넓습니다. 이름 붙인 집계(`새이름=('열', 함수)`)로 쓰면 lambda를 넣어도 열 이름이 깔끔하게 나옵니다. 이름 없이 `agg([lambda ...])`로 쓰면 열 이름이 `<lambda_0>`처럼 나와 읽기 어렵습니다.

## 표본이 적은 그룹 빼기: filter

그룹별 비율은 그룹 크기가 작으면 믿기 어렵습니다. 타이타닉 객실 갑판(deck)별 생존율을 보면 G 갑판은 4명뿐입니다.

```run
import pandas as pd

df = pd.read_csv("titanic.csv")
print(df.groupby('deck')['survived'].agg(['size', 'mean']).round(2))
```

4명 중 2명이 살아 50%라는 숫자는, 한 명만 달라도 25%나 75%로 바뀝니다. `groupby(...).filter(함수)`는 함수가 True를 돌려주는 **그룹의 행만** 남깁니다. 함수는 그룹 하나를 작은 DataFrame으로 받습니다.

```run
import pandas as pd

df = pd.read_csv("titanic.csv")
big = df.groupby('deck').filter(lambda d: len(d) >= 30)
print(len(big), sorted(big['deck'].unique()))
print(big.groupby('deck')['survived'].mean().round(2))
```

30명 이상인 갑판 B · C · D · E만 남았습니다. `filter`는 집계가 아니라 **행 고르기**라서 결과가 원래 표 모양(171행)입니다. 이 표로 다시 groupby 하면 믿을 만한 그룹끼리만 비교됩니다.

| 도구 | 결과 행 수 | 쓰임 |
| --- | --- | --- |
| `agg` | 그룹 수만큼 | 그룹 요약 |
| `transform` | 원래 행 수 | 그룹 값을 행마다 붙이기 |
| `filter` | 조건을 통과한 그룹의 행 수 | 그룹 단위로 행 고르기 |

## 그룹마다 상위 n개

"종마다 가장 무거운 펭귄 2마리"처럼 그룹 안에서 상위 몇 개를 고르려면, **먼저 전체를 정렬한 뒤** 그룹마다 앞에서 n개를 자릅니다. `groupby(...).head(n)`은 그룹마다 앞 n행을 원래 순서 그대로 돌려줍니다.

```run
import pandas as pd

df = pd.read_csv("penguins.csv").dropna()
top2 = (df.sort_values('body_mass_g', ascending=False)
          .groupby('species')
          .head(2))
print(top2[['species', 'island', 'body_mass_g']])
```

정렬을 먼저 했기 때문에 그룹마다 앞 2행이 곧 가장 무거운 2마리입니다. 정렬을 빼면 그냥 표에서 먼저 나온 2마리가 나옵니다. 하위 n개가 필요하면 `ascending=True`로 정렬하거나 `tail(n)`을 씁니다.

## 그룹 안에서 순위: rank

행을 고르지 않고, 모든 행에 "그룹 안에서 몇 등인지"를 붙이려면 `groupby(...)['열'].rank()`를 씁니다. 결과가 원래 행 수 그대로라 새 열로 붙일 수 있습니다.

```run
import pandas as pd

lots = pd.DataFrame({
    'line': ['A', 'A', 'A', 'B', 'B', 'C'],
    'lot':  ['L1', 'L2', 'L3', 'L4', 'L5', 'L6'],
    'ng':   [3, 8, 5, 2, 9, 4],
})
lots['rank'] = lots.groupby('line')['ng'].rank(ascending=False, method='min').astype(int)
print(lots)
print(lots[lots['rank'] == 1])        # 라인마다 불량 1등 로트
```

`ascending=False`는 큰 값이 1등, `method='min'`은 값이 같으면 같은 등수를 줍니다(1, 1, 3처럼). L2는 A라인 1등, L5는 B라인 1등이고, 로트가 하나뿐인 C라인은 L6가 1등입니다. 전체에서 순위를 매기면 B라인 L5가 1등, A라인 L2가 2등이지만, 라인 안 순위로 보면 둘 다 1등입니다. 라인마다 설비 조건이 다를 때는 이렇게 **같은 라인 안에서** 비교하는 편이 공정합니다.

## 그룹 안에서 누적: cumsum, cumcount

그룹마다 누적 합을 내거나 몇 번째 행인지 번호를 붙일 수도 있습니다. 둘 다 원래 행 수 그대로입니다.

```run
import pandas as pd

d = pd.DataFrame({'day': [1, 1, 2, 2, 3, 3],
                  'line': ['A', 'B', 'A', 'B', 'A', 'B'],
                  'qty': [520, 480, 505, 470, 530, 460]})
d['cum_qty'] = d.groupby('line')['qty'].cumsum()
d['nth_day'] = d.groupby('line').cumcount() + 1
print(d)
```

A라인은 사흘 동안 520 → 1,025 → 1,555개를 쌓았습니다. `cumcount`는 그룹 안에서 0부터 번호를 매기므로 1을 더해 "몇 번째 날"로 만들었습니다.

## 정리

- `agg`에는 lambda나 직접 만든 함수도 넣을 수 있고, 이름 붙인 집계로 열 이름을 정합니다
- `filter`는 그룹 단위로 행을 고릅니다. 표본이 적은 그룹을 뺄 때 씁니다
- 그룹별 상위 n개는 정렬 후 `groupby().head(n)`
- `rank` · `cumsum` · `cumcount`는 원래 행 수 그대로 그룹 안 순위 · 누적을 줍니다
