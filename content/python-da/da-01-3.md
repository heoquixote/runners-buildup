da-01-1에서 불리언 인덱싱으로 조건에 맞는 값을 **골라냈습니다**. 이번에는 조건에 따라 값을 **바꾸고**, 결과를 **세고**, **순서**를 매깁니다. 검사 결과에 OK/NG 라벨을 붙이고, 라벨별 개수를 세고, 가장 나쁜 로트 번호를 찾는 흐름입니다.

## 조건으로 값 고르기: np.where

`np.where(조건, 참일 때 값, 거짓일 때 값)`은 값마다 조건을 보고 둘 중 하나를 고릅니다. 엑셀의 `IF` 함수를 열 전체에 쓰는 것과 같습니다.

```run
import numpy as np

size = np.array([10.1, 9.2, 10.4, 10.8, 9.9, 10.0])
ok = (size >= 9.5) & (size <= 10.5)
label = np.where(ok, 'OK', 'NG')
print(label)
```

두 번째(9.2)와 네 번째(10.8)가 NG입니다. 조건 자리에 `ok`처럼 True/False 배열을 그대로 넣으면 됩니다.

갈래가 셋이면 `np.where`를 겹쳐 쓸 수 있습니다. 바깥 조건이 거짓일 때 안쪽 `np.where`가 다시 판단합니다.

```run
import numpy as np

size = np.array([10.1, 9.2, 10.4, 10.8, 9.9, 10.0])
label = np.where(size > 10.5, 'HIGH', np.where(size < 9.5, 'LOW', 'OK'))
print(label)
```

세 갈래가 넘으면 읽기 어려워지므로, 그때는 da-04-3에서 배우는 `np.select`를 씁니다.

## 범위 밖 값을 경계로 자르기: clip

센서가 가끔 말도 안 되는 값을 내보내면, 분석 전에 범위 밖 값을 경계값으로 바꿔 두기도 합니다. `clip(아래, 위)`가 한 줄로 해 줍니다.

```run
import numpy as np

temp = np.array([24.1, -999.0, 25.6, 88.0, 23.9])
print(temp.clip(0, 50))
```

-999는 0으로, 88은 50으로 바뀌었습니다. 다만 -999처럼 **고장 신호**인 값은 경계로 자르기보다 결측으로 처리하는 편이 정확합니다. clip은 "값은 맞지만 너무 크거나 작은" 경우에 씁니다.

## 종류별로 세기: np.unique

`np.unique`는 중복을 뺀 값 목록을 줍니다. `return_counts=True`를 붙이면 각 값의 개수도 함께 돌려줍니다.

```run
import numpy as np

result = np.array(['OK', 'NG', 'OK', 'OK', 'RW', 'NG', 'OK'])
values, counts = np.unique(result, return_counts=True)
print(values)
print(counts)
print(dict(zip(values.tolist(), counts.tolist())))
```

값은 가나다(알파벳)순으로 정렬되어 나옵니다. NG 2개, OK 4개, RW(재작업) 1개입니다. `zip`으로 묶어 딕셔너리로 만들면 읽기 편합니다.

## 누적 합: cumsum

하루 생산량을 차례로 더해 가면 "몇 번째 날에 목표 3,000개를 넘었나"를 알 수 있습니다.

```run
import numpy as np

daily = np.array([980, 1020, 950, 1100, 1010])
total = daily.cumsum()
print(total)
print(np.argmax(total >= 3000) + 1, "일째에 3000개 돌파")
```

누적은 980, 2000, 2950, 4050, 5060입니다. `total >= 3000`에서 처음 True가 나오는 위치는 3(네 번째)이고, `argmax`는 True(1) 중 가장 앞 위치를 줍니다. 날짜는 1부터 세므로 1을 더해 4일째입니다.

## 순서 매기기: sort와 argsort

`np.sort`는 **값**을 정렬하고, `argsort`는 정렬했을 때의 **원래 위치**를 줍니다. "불량률이 가장 높은 로트가 몇 번인가"처럼 위치가 필요할 때는 `argsort`를 씁니다.

```run
import numpy as np

lots = np.array(['L01', 'L02', 'L03', 'L04', 'L05'])
rate = np.array([1.2, 3.5, 0.8, 2.9, 4.1])

print(np.sort(rate))              # 값만 오름차순
order = rate.argsort()[::-1]      # 큰 값부터의 위치
print(order)
print(lots[order[:3]], rate[order[:3]])
```

`argsort`는 오름차순 위치를 주므로 `[::-1]`로 뒤집어 큰 값부터 봅니다. 불량률 상위 3개는 L05(4.1), L02(3.5), L04(2.9)입니다. 같은 위치 배열을 `lots`와 `rate`에 함께 쓰면 이름과 값이 짝이 맞습니다.

## 정리

- `np.where(조건, A, B)`로 값마다 둘 중 하나를 고르고, `clip`으로 범위를 제한합니다
- `np.unique(..., return_counts=True)`로 종류별 개수를 셉니다
- `cumsum`은 누적 합, `argsort`는 정렬 순서의 위치를 줍니다
