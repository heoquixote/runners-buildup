## 여러 그룹의 구성 비교하기

파이는 전체 하나의 구성만 보여 줍니다. "등급마다 생존자 비율이 어떻게 다른가"처럼 **여러 그룹의 구성을 나란히 비교**하려면 막대를 조각으로 쌓은 **누적 막대**를 씁니다. 누적 막대는 두 가지가 있고, 답하는 질문이 다릅니다.

| 그래프 | 막대 전체 높이 | 답하는 질문 |
| --- | --- | --- |
| **누적 막대** | 그룹의 **개수** | 그룹마다 몇 명이고, 그중 몇 명이 ~인가? |
| **100% 누적 막대** | 모두 100% | 그룹마다 ~인 **비율**이 얼마인가? |

## 누적 막대: 개수를 쌓는다

`pd.crosstab(행, 열)`로 등급 × 생존 개수 표를 만들고, `.plot.bar(stacked=True)`로 쌓습니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("titanic.csv")
table = pd.crosstab(df["class"], df["survived"])
ax = table.plot.bar(stacked=True, rot=0, figsize=(5, 3.5))
print(table)
```

**무엇을 나타내나**

- 막대 하나 = 등급 하나, 막대 **전체 높이** = 그 등급의 승객 수
- 아래 조각(0) = 사망자 수, 위 조각(1) = 생존자 수

**이렇게 읽는다**

1. **전체 높이**끼리 비교 → 어느 그룹이 큰가
2. **맨 아래 조각**끼리 비교 → 바닥이 같은 높이(0)에서 시작하므로 정확히 비교할 수 있다
3. 위 조각은 **길이**로만 비교한다(시작 높이가 막대마다 다름)

> 해석: 3등실은 491명으로 가장 크고 그중 372명이 사망해, 사망자 수는 3등실이 압도적이다. 생존자 수는 1등실 136명, 3등실 119명, 2등실 87명으로 생각보다 차이가 크지 않다.

**잘못 읽기 쉬운 점**: 위쪽 조각은 막대마다 **시작 높이가 달라서** 끝 높이로 비교하면 틀립니다. 3등실 생존 조각의 끝이 가장 높지만, 생존자가 가장 많은 것은 1등실입니다. 위 조각은 **조각 자체의 길이**만 비교하세요. 그리고 이 그래프만 보면 "3등실도 생존자가 꽤 많네"라고 생각하기 쉽지만, **비율**은 전혀 다릅니다. 그래서 다음 그래프가 필요합니다.

## 100% 누적 막대: 비율을 쌓는다

`crosstab(..., normalize="index")`는 행(등급)마다 합이 1이 되도록 나눠 줍니다. 그대로 쌓으면 모든 막대가 같은 높이(100%)가 됩니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("titanic.csv")
rate = pd.crosstab(df["class"], df["survived"], normalize="index") * 100
ax = rate.plot.bar(stacked=True, rot=0, figsize=(5, 3.5))
ax.set_ylabel("%")
print(rate.round(1))
```

**이렇게 읽는다**: 막대 높이는 모두 같으니 무시하고, **조각의 경계선 높이**를 비교합니다. 여기서는 아래 조각(사망)과 위 조각(생존) 사이 경계가 낮을수록 생존율이 높습니다.

> 해석: 생존율은 1등실 63.0%, 2등실 47.3%, 3등실 24.2%로 등급이 낮을수록 뚜렷하게 떨어진다. 개수로는 1등실(136명)과 3등실(119명)의 생존자가 비슷했지만, 비율로 보면 1등실 승객의 생존 가능성이 3등실의 2.6배였다.

같은 데이터라도 **개수(누적 막대)**와 **비율(100% 막대)**은 다른 이야기를 합니다. "몇 명?"을 묻는지 "몇 %?"를 묻는지 먼저 정하고 그래프를 고릅니다.

## 조각이 셋 이상이면: 가운데 조각은 읽기 어렵다

등급마다 남자(man)·여자(woman)·아이(child)가 몇 %인지 100% 막대로 그려 봅니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("titanic.csv")
mix = pd.crosstab(df["class"], df["who"], normalize="index")[["woman", "child", "man"]] * 100
ax = mix.plot.bar(stacked=True, rot=0, figsize=(5, 3.5))
ax.legend(loc="upper left", bbox_to_anchor=(1, 1))
print(mix.round(1))
```

**이렇게 읽는다**: **맨 아래 조각**(여기서는 woman)과 **맨 위 조각**(man)은 바닥이나 천장에 붙어 있어 비교하기 쉽습니다. 가운데 조각(child)은 위아래가 모두 들쭉날쭉해 길이를 눈으로 비교하기 어렵습니다.

> 해석: 여자 비율은 1등실 42.1% → 2등실 35.9% → 3등실 23.2%로 등급이 낮을수록 줄고, 남자 비율은 3등실이 65.0%로 가장 높다. 가운데 아이 조각은 1등실 2.8%, 2등실 10.3%, 3등실 11.8%인데 그래프만으로는 2등실과 3등실의 차이를 말하기 어렵다.

**그릴 때 요령**: 가장 중요한 범주를 **맨 아래**에 둡니다. 열 순서(`[["woman", "child", "man"]]`)를 바꾸면 쌓는 순서가 바뀝니다. 조각이 4~5개를 넘으면 [묶음 막대 · 칸 나누기 읽기](#/l/da-12-3)의 묶음 막대(hue)로 바꾸는 것을 고려합니다.

## 100% 막대에는 n을 적는다

100% 막대는 모든 막대가 같은 높이라서, **10명짜리 그룹과 500명짜리 그룹이 똑같아 보입니다.** 막대 위에 n을 적어 둡니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("titanic.csv")
rate = pd.crosstab(df["class"], df["survived"], normalize="index") * 100
n = df["class"].value_counts()[rate.index]
ax = rate.plot.bar(stacked=True, rot=0, figsize=(5, 3.5))
for i, count in enumerate(n):
    ax.text(i, 102, f"n={count}", ha="center")
ax.set_ylim(0, 110)
print(n.to_dict())
```

> 해석: 막대 높이는 같지만 3등실(491명)이 2등실(184명)보다 2.7배 많은 사람을 대표한다. 전체 생존자 수에 미치는 영향은 3등실 막대가 훨씬 크다.

## 연속값 위의 구성: histplot(multiple="fill")

x가 범주가 아니라 나이 같은 **연속값**이면, 히스토그램의 막대마다 100%로 채워서 "나이대별 생존 비율"을 볼 수 있습니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("titanic.csv")
ax = sns.histplot(data=df, x="age", hue="survived", multiple="fill", bins=range(0, 90, 10))
ax.set_ylabel("share")
age_group = pd.cut(df["age"], [0, 10, 20, 30, 40, 50, 60, 70, 81], right=False)
print(df.groupby(age_group, observed=True)["survived"].agg(["size", "mean"]).round(2))
```

> 해석: 0~9세 구간은 생존(주황) 비율이 61%로 가장 높고, 10대부터 60대까지는 32~44% 사이에 머문다. 70세 이상 구간은 생존이 아주 적어 보이지만 7명뿐이라 이 구간의 비율은 믿기 어렵다.

**잘못 읽기 쉬운 점**: `multiple="fill"`은 막대 높이를 모두 1로 맞추기 때문에, **사람이 몇 명 없는 양 끝 구간**도 가운데 구간과 똑같은 크기로 보입니다. 끝 구간에서 비율이 크게 튀면 먼저 개수(size)를 확인합니다.

## 정리: 누적 막대 읽기

| 그래프 | 코드 | 먼저 읽을 것 | 주의 |
| --- | --- | --- | --- |
| 누적 막대 | `pd.crosstab(a, b).plot.bar(stacked=True)` | 전체 높이, 맨 아래 조각 | 위 조각은 길이로만 비교 |
| 100% 막대 | `pd.crosstab(a, b, normalize="index").plot.bar(stacked=True)` | 조각 경계선 높이 | 그룹 크기가 사라짐 → n 표시 |
| 연속값 비율 | `sns.histplot(..., hue=, multiple="fill")` | 구간별 비율 변화 | 양 끝 구간은 개수 확인 |
