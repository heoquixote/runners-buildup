## 분포: "값들이 어떻게 퍼져 있나?"

반 학생 30명의 키 평균이 165cm라고 해 봅시다. 모두 163~167cm일 수도 있고, 150cm와 180cm가 섞여 평균이 165cm일 수도 있습니다. 평균 하나로는 이 둘을 구분할 수 없습니다. 값들이 **어디에 몰려 있고, 얼마나 퍼져 있고, 어떤 모양이고, 튀는 값이 있는지**를 **분포**라고 하고, DAY 05에서는 분포를 보는 그래프를 모두 읽어 봅니다.

분포 그래프는 무엇이든 같은 네 가지를 순서대로 읽습니다.

| 순서 | 볼 것 | 질문 |
| --- | --- | --- |
| 1 | **중심** | 값이 주로 어디쯤에 있나? (봉우리, 중앙값) |
| 2 | **퍼짐** | 얼마나 넓게 흩어져 있나? (폭, IQR) |
| 3 | **모양** | 대칭인가, 한쪽으로 꼬리가 긴가, 봉우리가 몇 개인가? |
| 4 | **튀는 값** | 무리에서 멀리 떨어진 값이 있나? |

첫 그래프는 가장 기본인 **히스토그램**입니다.

## 히스토그램이 나타내는 것

히스토그램은 값의 범위를 같은 폭의 **구간(bin)**으로 나누고, 각 구간에 들어간 데이터 개수를 막대 높이로 그립니다. "60점대 몇 명, 70점대 몇 명"처럼 세는 것과 같습니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("titanic.csv")
age = df["age"].dropna()
fig, ax = plt.subplots(figsize=(6, 3))
counts, edges, bars = ax.hist(age, bins=10, edgecolor="white")
ax.set_xlabel("Age")
ax.set_ylabel("Passengers")
print("구간 경계:", edges.round(0).astype(int).tolist())
print("구간별 인원:", counts.astype(int).tolist())
```

**무엇을 나타내나**

- x축: **값**(나이). 이어진 숫자라서 막대 사이에 틈이 없습니다.
- 막대 하나: 구간 하나(예: 16~24세)
- 막대 높이: 그 구간에 속한 **데이터 개수**

막대 그래프(da-12-1)와 비슷해 보이지만 다릅니다. 막대 그래프의 x는 **범주**(1등실, 2등실)이고 막대 하나가 범주 하나지만, 히스토그램의 x는 **숫자 범위**이고 막대 하나가 구간 하나입니다.

> 해석: 나이를 아는 승객 714명 중 16~32세 구간에 346명(약 48%)이 몰려 있어 20대가 중심이다. 나이가 많아질수록 인원이 줄어 64세 이상은 11명뿐이다. 0~8세 구간에도 54명이 있어 어린이 승객이 적지 않았다.

## 분포의 네 가지 모양

히스토그램의 모양은 크게 네 가지로 나뉩니다. 모양을 알아보면 **어떤 대표값을 써야 하는지**까지 정해집니다.

::figure{src="content/img/viz/viz11-hist-shapes.svg" alt="분포 모양 네 가지: 좌우 대칭은 평균과 중앙값이 같고, 오른쪽 꼬리는 평균이 중앙값보다 크고, 왼쪽 꼬리는 평균이 중앙값보다 작고, 봉우리가 두 개면 서로 다른 무리가 섞여 있을 가능성이 크다" caption="모양에 따라 평균과 중앙값의 위치가 달라집니다."}

| 모양 | 생김새 | 평균과 중앙값 | 예 |
| --- | --- | --- | --- |
| 대칭 | 가운데 봉우리, 좌우가 비슷 | 거의 같다 | 키, 시험 점수 |
| 오른쪽 꼬리(오른쪽으로 치우침) | 왼쪽에 몰리고 오른쪽으로 길게 늘어짐 | 평균 > 중앙값 | 소득, 집값, 운임 |
| 왼쪽 꼬리 | 오른쪽에 몰리고 왼쪽으로 늘어짐 | 평균 < 중앙값 | 쉬운 시험 점수, 수명 |
| 봉우리 두 개 | 봉우리가 둘 | 둘 다 대표하지 못함 | 서로 다른 무리가 섞임 |

## 오른쪽 꼬리: 평균이 끌려간다

운임(`fare`)은 대부분 싼 표이고, 몇몇 승객만 아주 비싼 표를 샀습니다. 평균(빨간 선)과 중앙값(검은 점선)을 함께 그려 봅니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("titanic.csv")
fig, ax = plt.subplots(figsize=(6, 3))
ax.hist(df["fare"], bins=40)
ax.axvline(df["fare"].mean(), color="red", label="mean")
ax.axvline(df["fare"].median(), color="black", linestyle="--", label="median")
ax.legend()
print("평균", round(df["fare"].mean(), 1), "/ 중앙값", round(df["fare"].median(), 1), "/ 최댓값", df["fare"].max())
```

> 해석: 운임은 왼쪽(50 이하)에 대부분 몰려 있고 오른쪽으로 512까지 긴 꼬리가 있는 오른쪽 꼬리 분포다. 비싼 표 몇 장이 평균(32.2)을 중앙값(14.5)의 두 배 넘게 끌어올렸으므로, "보통 승객의 운임"은 중앙값 14.5로 말하는 것이 맞다.

**잘못 읽기 쉬운 점**: "꼬리가 오른쪽"이라는 말이 헷갈리기 쉽습니다. 기준은 **봉우리가 아니라 꼬리**입니다. 봉우리는 왼쪽에 있어도 꼬리가 오른쪽으로 길면 "오른쪽 꼬리(오른쪽으로 치우친) 분포"라고 부릅니다.

## 봉우리 두 개: 무리가 섞여 있다

펭귄 333마리의 지느러미 길이를 그려 봅니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("penguins.csv").dropna()
ax = sns.histplot(data=df, x="flipper_length_mm", binwidth=3)
print("평균", round(df["flipper_length_mm"].mean(), 1), "/ 중앙값", df["flipper_length_mm"].median())
```

190mm 근처와 215mm 근처에 봉우리가 두 개 있습니다. 이럴 때 평균(201mm)은 두 봉우리 **사이의 골짜기**에 떨어져, 실제로 가장 드문 값을 "대표값"이라고 부르는 꼴이 됩니다.

봉우리가 두 개면 "**서로 다른 무리가 섞여 있지 않나?**"를 먼저 의심합니다. 종(`species`)으로 색을 나눠 확인합니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("penguins.csv").dropna()
ax = sns.histplot(data=df, x="flipper_length_mm", hue="species", binwidth=3)
print(df.groupby("species")["flipper_length_mm"].median())
```

> 해석: 지느러미 길이 분포에는 봉우리가 두 개 있는데, 왼쪽 봉우리는 Adelie(중앙값 190mm)와 Chinstrap(196mm), 오른쪽 봉우리는 Gentoo(216mm)다. 종을 섞어 평균 201mm라고 말하면 어느 종도 대표하지 못하므로, 종별로 나눠 보고해야 한다.

## bins에 따라 달라지는 모양

히스토그램의 모양은 **구간을 어떻게 나누느냐**에 따라 달라 보입니다. 같은 데이터를 구간 4개와 40개로 그려 봅니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("penguins.csv").dropna()
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(9, 3))
ax1.hist(df["flipper_length_mm"], bins=4)
ax1.set_title("bins=4")
ax2.hist(df["flipper_length_mm"], bins=40)
ax2.set_title("bins=40")
print("bins=4 막대 높이:", [int(p.get_height()) for p in ax1.patches])
```

구간이 4개면 막대 높이가 45, 150, 80, 58로 봉우리가 하나뿐인 오른쪽 꼬리 분포처럼 보이고, 40개면 막대가 들쭉날쭉해 우연한 작은 봉우리가 생깁니다. 직접 해 보세요: 숫자를 5, 10, 20으로 바꿔 모양이 안정되는 구간 수를 찾아봅니다.

**잘못 읽기 쉬운 점**: bins 하나로 그린 그림만 보고 "봉우리가 두 개다", "대칭이다"를 단정하면 안 됩니다. **bins를 두세 가지로 바꿔도 유지되는 모양**만 믿을 수 있습니다. 단위가 분명한 값은 `binwidth=5`(5mm씩)처럼 폭으로 정하면 설명하기도 쉽습니다.

## 그룹 크기가 다를 때: 개수 말고 비율

그룹별 분포를 겹쳐 비교할 때, 그룹 크기가 다르면 큰 그룹의 막대가 그냥 다 높아서 **모양**을 비교할 수 없습니다. 타이타닉 남성(453명)과 여성(261명)의 나이 분포를 비율로 맞춰 그려 봅니다. `stat="density"`는 막대 높이를 비율로, `common_norm=False`는 그룹마다 따로 100%를 맞춥니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("titanic.csv")
ax = sns.histplot(data=df, x="age", hue="sex", stat="density", common_norm=False, binwidth=5)
print(df.groupby("sex")["age"].agg(["count", "median"]))
```

> 해석: 비율로 맞춰 보면 남녀 모두 20~40대에 몰린 비슷한 모양이지만, 0~15세 구간에서는 여성(주황) 막대가 더 높다. 여자아이 승객의 비율이 상대적으로 높았고, 그래서 여성의 중앙값(27세)이 남성(29세)보다 조금 낮다.

**잘못 읽기 쉬운 점**: `stat="density"`로 그린 그래프의 y값(0.03 같은 숫자)은 개수가 아니라 비율 밀도입니다. y값 자체보다 **막대들의 상대적인 높이와 모양**을 비교하세요.

## 정리: 히스토그램 읽기

| 단계 | 볼 것 | 해석 문장 틀 |
| --- | --- | --- |
| 1. 중심 | 가장 높은 막대의 위치 | "값은 주로 ~ 근처에 몰려 있다" |
| 2. 퍼짐 | 막대가 있는 범위의 폭 | "대부분 ~에서 ~ 사이다" |
| 3. 모양 | 대칭 / 오른쪽 꼬리 / 왼쪽 꼬리 / 봉우리 두 개 | "오른쪽으로 긴 꼬리가 있어 중앙값으로 말하는 것이 맞다" |
| 4. 튀는 값 | 멀리 떨어진 외딴 막대 | "~ 이상인 값이 n개 있다" |
| 확인 | bins를 바꿔도 같은가, 그룹 크기가 같은가 | |

| 그래프 | 코드 |
| --- | --- |
| 기본 히스토그램 | `ax.hist(값, bins=)`, `sns.histplot(data=, x=, binwidth=)` |
| 그룹 겹치기 | `sns.histplot(..., hue=)` (`multiple="layer"/"stack"/"dodge"`) |
| 크기 다른 그룹 비교 | `sns.histplot(..., hue=, stat="density", common_norm=False)` |
