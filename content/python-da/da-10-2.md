## 분포 그래프 다시 보기

da-09-3에서 히스토그램으로 "값이 어디에 몰려 있나"를 봤습니다. seaborn의 분포 그래프는 여기에 두 가지를 더해 줍니다. 첫째, `hue=` 하나로 **그룹별 분포를 겹치거나 쌓아서** 비교할 수 있습니다. 둘째, 막대 대신 **부드러운 곡선**(kde)이나 **누적 비율**(ecdf)로도 분포를 그릴 수 있습니다.

이번 레슨은 펭귄 데이터의 지느러미 길이(`flipper_length_mm`)를 중심으로 씁니다. 빈 값이 있는 11행은 `dropna()`로 빼고 333마리를 씁니다.

## histplot: seaborn의 히스토그램

`sns.histplot(data=df, x="열")`이 히스토그램입니다. matplotlib의 `ax.hist`와 같지만, 열 이름으로 그리고 축 이름도 자동으로 붙습니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("penguins.csv").dropna()
ax = sns.histplot(data=df, x="flipper_length_mm")
print("막대 개수:", len(ax.patches), "/ 중앙값:", df["flipper_length_mm"].median())
```

봉우리가 190mm 근처와 215mm 근처, **두 개**로 보입니다. 봉우리가 두 개인 분포는 "성격이 다른 두 무리가 섞여 있다"는 신호인 경우가 많습니다.

구간을 정하는 방법은 두 가지입니다. `bins=20`은 구간 **개수**, `binwidth=5`는 구간 **폭**(5mm씩)입니다. 단위가 분명한 값은 폭으로 정하는 편이 설명하기 쉽습니다. 직접 해 보세요: `binwidth`를 2, 5, 10으로 바꿔 봅니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("penguins.csv").dropna()
ax = sns.histplot(data=df, x="flipper_length_mm", binwidth=5)
print("막대 개수:", len(ax.patches))
```

## hue로 그룹 나누기

봉우리 두 개가 정말 종의 차이일까요? `hue="species"`를 주면 종마다 색을 달리해 겹쳐 그립니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("penguins.csv").dropna()
ax = sns.histplot(data=df, x="flipper_length_mm", hue="species")
print(df.groupby("species")["flipper_length_mm"].median())
```

Adelie(중앙값 190)와 Chinstrap(196)이 왼쪽 봉우리를, Gentoo(216)가 오른쪽 봉우리를 만들고 있었습니다. 그룹이 겹치는 곳은 색이 섞여 보이도록 반투명하게 그려집니다.

## multiple: 겹치기 · 쌓기 · 나란히

그룹 막대가 겹쳐서 보기 어려울 때는 `multiple=`로 배치를 바꿉니다.

| 값 | 모양 | 언제 |
| --- | --- | --- |
| `"layer"` (기본) | 반투명하게 겹치기 | 그룹이 2~3개, 많이 안 겹칠 때 |
| `"stack"` | 위로 쌓기 | 전체 분포와 그 구성을 함께 볼 때 |
| `"dodge"` | 구간마다 나란히 | 구간별로 그룹을 직접 비교할 때 |
| `"fill"` | 높이를 100%로 맞춰 비율로 | 구간마다 그룹 비율이 어떻게 바뀌는지 |

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("penguins.csv").dropna()
ax = sns.histplot(data=df, x="flipper_length_mm", hue="species", multiple="stack")
print("쌓은 막대 조각 수:", len(ax.patches))
```

쌓으면 막대 전체 높이가 처음 그린 히스토그램과 같아지고, 그 안의 색 조각이 종별 구성입니다. 직접 해 보세요: `multiple`을 `"dodge"`, `"fill"`로 바꿔 봅니다. `"fill"`에서는 200mm를 넘어가면서 Gentoo 비율이 갑자기 커지는 것이 보입니다.

## 그룹 크기가 다를 때: 개수 말고 비율로

타이타닉 승객의 나이를 성별로 비교해 봅시다. 남성 453명, 여성 261명으로 수가 크게 다르면, 개수로 그린 히스토그램에서는 **남성 막대가 그냥 다 높아서** 모양을 비교할 수 없습니다. `stat="density"`는 막대 높이를 개수 대신 **비율(밀도)**로 바꾸고, `common_norm=False`는 그룹마다 따로 100%를 맞춥니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("titanic.csv")
ax = sns.histplot(data=df, x="age", hue="sex", stat="density", common_norm=False, binwidth=5)
print(df.groupby("sex")["age"].agg(["count", "median"]))
```

이제 두 그룹의 모양을 공정하게 비교할 수 있습니다. 20~40대에 몰린 큰 모양은 비슷하지만, 0~15세 구간에서는 여성(주황) 막대가 더 높습니다. 여자아이 승객 비율이 상대적으로 높았다는 뜻이고, 그래서 중앙값도 여성이 조금 더 젊습니다(27세 vs 29세). 개수로 그렸다면 남성 막대에 가려 이 차이가 잘 안 보였을 것입니다. **그룹 크기가 다르면 비율로 비교한다**, 이것이 분포 비교의 기본 원칙입니다.

## kdeplot: 부드러운 곡선

히스토그램은 구간 경계에 따라 모양이 들쭉날쭉합니다. **KDE**(커널 밀도 추정)는 점 하나하나에 작은 언덕을 쌓아 **매끈한 곡선**으로 분포를 그립니다. 모래알을 한 알씩 떨어뜨려 쌓인 모래 언덕의 윤곽을 그린다고 생각하면 됩니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("penguins.csv").dropna()
ax = sns.kdeplot(data=df, x="flipper_length_mm", hue="species", fill=True)
print("곡선 개수:", len(ax.collections))
```

곡선 세 개가 종별 분포입니다. 겹치는 부분이 히스토그램보다 훨씬 잘 보입니다. 곡선 아래 넓이는 1(100%)이라서 y축 값 자체보다 **모양과 위치**를 읽습니다.

곡선이 얼마나 매끄러운지는 `bw_adjust`로 정합니다. 값이 작으면 울퉁불퉁(데이터를 너무 따라감), 크면 뭉개짐(봉우리가 사라짐)입니다. 직접 해 보세요: `0.3`, `1`, `3`을 넣어 비교합니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("penguins.csv").dropna()
ax = sns.kdeplot(data=df, x="flipper_length_mm", bw_adjust=0.3)
print("bw_adjust=0.3: 봉우리가 더 많이 보입니다")
```

> KDE 곡선은 데이터가 없는 곳까지 꼬리를 늘려 그립니다. 나이처럼 0보다 작을 수 없는 값에서 곡선이 음수 쪽으로 넘어가도 실제로 그런 값이 있다는 뜻은 아닙니다. 히스토그램과 함께 보면 오해를 줄일 수 있습니다(`histplot(..., kde=True)`).

## ecdfplot: "이 값 이하가 몇 %?"

**ECDF**(누적 분포)는 x값까지 오면서 데이터의 몇 %를 지나왔는지를 계단 모양으로 그립니다. y축이 0에서 1까지 올라갑니다. 구간을 정할 필요가 없어서 bins에 따라 모양이 바뀌는 문제가 없습니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("penguins.csv").dropna()
ax = sns.ecdfplot(data=df, x="flipper_length_mm", hue="species")
ax.axhline(0.5, color="gray", linestyle="--")
print("200mm 이하 비율:", round((df["flipper_length_mm"] <= 200).mean(), 3))
```

회색 점선(0.5)과 곡선이 만나는 x가 각 종의 **중앙값**입니다. 또 전체 펭귄 중 지느러미 200mm 이하가 56.8%라는 식으로 "몇 % 이하"를 바로 읽을 수 있습니다. 곡선이 오른쪽에 있을수록 값이 큰 그룹입니다.

## rugplot: 바닥에 실제 값 표시

`rugplot`은 x축 바닥에 값마다 짧은 눈금을 그어 **실제 데이터가 어디에 있는지** 보여 줍니다. 곡선과 함께 그리면 "곡선은 매끈하지만 실제 값은 여기 있다"를 같이 보여 줍니다. 같은 `ax`에 두 함수를 연달아 부르면 겹쳐 그려집니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("penguins.csv").dropna()
ax = sns.kdeplot(data=df, x="body_mass_g")
sns.rugplot(data=df, x="body_mass_g", ax=ax)
print("눈금 개수:", len(df))
```

## displot: 칸을 나눠 그리기

그룹이 많아 한 칸에 겹치면 복잡할 때는 그림 단위 함수 `displot`으로 **그룹마다 칸을 나눕니다.** `kind=`로 `"hist"`, `"kde"`, `"ecdf"`를 고르고, `col=`로 칸을 나눌 열을 정합니다. da-10-1에서 본 대로 그림 단위 함수는 새 도화지를 만들고 칸끼리 축을 공유합니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("penguins.csv").dropna()
g = sns.displot(data=df, x="flipper_length_mm", col="species", binwidth=5, height=2.8)
print("칸:", [ax.get_title() for ax in g.axes.flat])
```

세 칸의 x축이 같아서 Gentoo가 오른쪽에 있다는 것이 바로 보입니다. `row="sex"`까지 주면 3열 × 2행으로 종과 성별을 함께 나눌 수 있습니다.

## 정리: 분포 함수 고르기

| 하고 싶은 것 | 함수 | 핵심 설정 |
| --- | --- | --- |
| 기본 분포 모양 | `histplot` | `bins`, `binwidth` |
| 그룹 겹치기·쌓기·나란히 | `histplot(hue=)` | `multiple="layer" / "stack" / "dodge" / "fill"` |
| 크기가 다른 그룹 비교 | `histplot(hue=)` | `stat="density"`, `common_norm=False` |
| 매끈한 곡선, 겹침 비교 | `kdeplot` | `bw_adjust`, `fill=True` |
| "몇 % 이하" 읽기, 중앙값 비교 | `ecdfplot` | `hue` |
| 실제 값 위치 표시 | `rugplot` | 다른 그래프와 겹쳐 그리기 |
| 그룹마다 칸 나누기 | `displot` | `kind=`, `col=`, `row=` |
