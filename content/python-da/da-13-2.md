## 들쭉날쭉한 선에서 추세 찾기

매일 기록하는 데이터는 하루하루 오르내림이 커서, 선 그래프가 톱니처럼 보입니다. 톱니 속에 숨은 추세를 또렷하게 보는 도구 세 가지를 배웁니다.

| 도구 | 답하는 질문 |
| --- | --- |
| **이동평균** | 하루하루 소음을 빼면 어느 방향으로 가고 있나? |
| **로그 축** | 몇 개씩이 아니라 **몇 %씩** 늘고 있나? |
| **기준선 · 목표 범위** | 기준보다 위인가 아래인가, 얼마나 오래? |

먼저 어느 웹사이트의 90일간 일별 방문자 수를 만들어 봅니다. 연습용 가상 데이터로, 방문자가 조금씩 늘고 주말(토·일)에 많아지며 3월 21일에 행사가 있었다고 설정했습니다.

```run
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd

rng = np.random.default_rng(7)
days = pd.date_range("2026-01-01", periods=90)
visits = 200 + np.arange(90) + np.where(days.dayofweek >= 5, 60, 0) + rng.normal(0, 15, 90)
visits[79] += 150
s = pd.Series(visits.round(), index=days)
fig, ax = plt.subplots(figsize=(8, 3))
ax.plot(s.index, s.values)
print("처음 7일:", s.iloc[:7].tolist())
print("최댓값:", s.max(), s.idxmax().date())
```

> 해석: 일별 방문자는 매주 주말마다 50~60명씩 튀어 올라 톱니 모양이고, 3월 21일(토) 하루는 행사로 512명까지 치솟았다(급변). 전체적으로 늘고 있는 것 같지만 톱니 때문에 얼마나 늘었는지 읽기 어렵다.

## 이동평균: 최근 며칠의 평균으로 다듬기

**이동평균**은 "오늘을 포함한 최근 N일의 평균"을 날마다 다시 계산한 값입니다. 7일 이동평균이면 매일 1주일치 평균을 내므로, 주말 효과가 한 창(window) 안에 늘 똑같이 들어가 톱니가 사라집니다. pandas에서는 `s.rolling(7).mean()`입니다.

```run
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd

rng = np.random.default_rng(7)
days = pd.date_range("2026-01-01", periods=90)
visits = 200 + np.arange(90) + np.where(days.dayofweek >= 5, 60, 0) + rng.normal(0, 15, 90)
visits[79] += 150
s = pd.Series(visits.round(), index=days)
ma = s.rolling(7).mean()
fig, ax = plt.subplots(figsize=(8, 3))
ax.plot(s.index, s.values, color="lightgray", label="daily")
ax.plot(ma.index, ma.values, color="crimson", label="7-day average")
ax.legend()
print("첫 7일 평균:", round(ma.iloc[6], 1), "/ 마지막 7일 평균:", round(ma.iloc[-1], 1))
```

**무엇을 나타내나**: 회색 = 원래 일별 값, 빨간 선 = 7일 이동평균. 처음 6일은 7일치가 모이지 않아 빨간 선이 없습니다.

**이렇게 읽는다**: 빨간 선의 **방향과 기울기**로 추세를 읽고, 회색이 빨간 선에서 **크게 벗어난 날**을 예외로 봅니다.

> 해석: 7일 평균 방문자는 1월 첫 주 215명에서 3월 마지막 주 303명으로 약 41% 늘었다. 3월 21일 행사 날은 평균선(약 320명)보다 190명 넘게 높았지만, 이 하루 때문에 이후 7일 동안 평균선이 약 20명(150명 ÷ 7일) 솟았다가 원래 추세로 돌아왔다.

직접 해 보세요: `rolling(7)`을 `rolling(3)`, `rolling(28)`로 바꿔 봅니다.

| 창 크기 | 모양 | 장점 | 단점 |
| --- | --- | --- | --- |
| 작다 (3일) | 덜 매끄러움, 주말 톱니가 남음 | 변화에 빨리 반응 | 소음이 남는다 |
| 반복 주기와 같다 (7일) | 주말 효과가 사라짐 | 추세가 또렷 | |
| 크다 (28일) | 아주 매끄러움 | 큰 흐름만 | 변화를 **늦게** 반영, 행사 같은 급변이 뭉개짐 |

**잘못 읽기 쉬운 점**: 이동평균은 과거 N일을 평균하므로 **실제 변화보다 늦게** 꺾입니다. 이동평균선이 이제 막 꺾였다면 실제 변화는 며칠 전에 시작됐습니다. 또 행사 같은 하루짜리 급변은 이동평균에서 작고 넓은 언덕으로 퍼져 보이니, 급변은 원래 값(회색)에서 찾아야 합니다.

## 로그 축: "몇 %씩" 늘었나

[선 그래프 읽기](#/l/da-13-1)에서 항공 승객의 여름 봉우리가 해마다 커지는 것을 봤습니다. 이런 데이터는 "매년 몇 명씩"이 아니라 **"매년 몇 %씩"** 늘고 있을 가능성이 큽니다. y축을 **로그 축**으로 바꾸면 이것을 확인할 수 있습니다. 로그 축은 눈금이 100, 200, 400처럼 **같은 배수마다 같은 간격**입니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("flights.csv")
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(10, 3))
ax1.plot(df["passengers"].values)
ax1.set_title("Linear y-axis")
ax2.plot(df["passengers"].values)
ax2.set_yscale("log")
ax2.set_title("Log y-axis")
print("1949년 계절 폭:", df["passengers"][:12].max() - df["passengers"][:12].min(), "/ 1960년:", df["passengers"][-12:].max() - df["passengers"][-12:].min())
```

**이렇게 읽는다**

| 로그 축에서 보이는 모양 | 뜻 |
| --- | --- |
| 곧은 직선 | **일정한 비율**로 증가(매년 같은 %) |
| 점점 완만해짐 | 증가율이 줄어들고 있다 |
| 점점 가팔라짐 | 증가율이 커지고 있다 |
| 봉우리 높이가 일정 | 계절 변동이 전체 규모에 **비례** |

> 해석: 일반 축(왼쪽)에서는 계절 폭이 1949년 44에서 1960년 232로 5배 넘게 커져 보이지만, 로그 축(오른쪽)에서는 봉우리 높이가 거의 일정하고 전체가 곧은 선에 가깝다. 승객은 해마다 거의 같은 비율로 늘었고, 여름 성수기 효과도 규모에 비례해 일정한 비율이었다.

**잘못 읽기 쉬운 점**: 로그 축에서는 눈금 간격이 같아도 실제 차이는 다릅니다(100→200과 200→400이 같은 간격). 로그 축 그래프를 보고 "조금 늘었다"고 읽으면 실제로는 2배일 수 있으니, **축 눈금 숫자를 꼭 확인**하세요. 보고서에 로그 축을 쓸 때는 축 이름에 "(log scale)"이라고 적어 줍니다.

## 기준선과 목표 범위

선 그래프에 **기준**을 함께 그리면 "좋은가 나쁜가"를 바로 읽을 수 있습니다. 가로 기준선은 `ax.axhline(값)`, 범위는 `ax.axhspan(아래, 위)`로 칠합니다. 위 방문자 데이터에 "하루 250명 이상"이라는 목표선을 그어 봅니다.

```run
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd

rng = np.random.default_rng(7)
days = pd.date_range("2026-01-01", periods=90)
visits = 200 + np.arange(90) + np.where(days.dayofweek >= 5, 60, 0) + rng.normal(0, 15, 90)
visits[79] += 150
s = pd.Series(visits.round(), index=days)
ma = s.rolling(7).mean()
fig, ax = plt.subplots(figsize=(8, 3))
ax.plot(ma.index, ma.values, color="crimson")
ax.axhline(250, color="black", linestyle="--", label="Target 250")
ax.legend()
print("7일 평균이 목표를 처음 넘은 날:", ma[ma >= 250].index[0].date())
print("목표 미달 일수(일별):", int((s < 250).sum()), "/ 90일")
```

**이렇게 읽는다**: 선이 기준선을 **처음 넘은 시점**, 기준선 위에 **머무른 기간**, 다시 아래로 내려간 적이 있는지를 봅니다.

> 해석: 7일 평균 방문자는 2월 9일에 처음 목표 250명을 넘었고, 그 뒤로는 목표 아래로 떨어지지 않았다. 다만 일별로 보면 90일 중 36일(40%)은 여전히 250명 미만이라, 평일 방문자는 아직 목표에 못 미치는 날이 많다.

같은 데이터라도 **이동평균으로 보느냐 일별로 보느냐**에 따라 "목표 달성" 해석이 달라집니다. 보고서에는 어느 기준으로 판단했는지 함께 적으세요.

## 정리: 추세를 또렷하게 보는 도구

| 도구 | 코드 | 해석할 때 |
| --- | --- | --- |
| 이동평균 | `s.rolling(창).mean()` | 반복 주기와 같은 창(주간 패턴이면 7). 실제 변화보다 늦게 꺾인다 |
| 로그 축 | `ax.set_yscale("log")` | 직선 = 일정 비율 증가. 눈금 숫자로 크기 확인 |
| 기준선 | `ax.axhline(값)` | 처음 넘은 시점, 머문 기간 |
| 목표 범위 | `ax.axhspan(아래, 위, alpha=0.2)` | 범위 안에 있던 비율 |
