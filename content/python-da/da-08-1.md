센서 값, 매출, 접속 기록처럼 시간 순서가 있는 데이터는 **앞뒤 관계**에 의미가 있습니다. 날짜 형식을 바로잡으면 월별로 묶고, 전일과 비교하고, 들쭉날쭉한 값을 다듬는 일을 몇 줄로 할 수 있습니다.

## 문자열을 날짜로

날짜가 문자열이면 정렬·계산이 안 됩니다. `pd.to_datetime`으로 바꾸면 `.dt`로 부분을 꺼낼 수 있습니다.

```run
import pandas as pd
ts = pd.to_datetime(pd.Series(['2026-11-02 09:30', '2026-11-03 21:40', '2026-11-08 13:05']))
print(ts.dt.month.tolist(), ts.dt.hour.tolist())
print(ts.dt.day_name().tolist())
print((ts.max() - ts.min()).days, "일 차이")
```

문자열로 두면 어떤 문제가 생기는지 봅니다. 글자 순서로 정렬되어 `'10/2'`가 `'9/30'`보다 앞에 옵니다. 날짜 모양이 낯설면 `format`을 알려 줍니다.

```run
import pandas as pd
s = pd.Series(['9/30/2026', '10/2/2026', '10/15/2026'])
print(s.sort_values().tolist())                     # 글자 순서
d = pd.to_datetime(s, format='%m/%d/%Y')
print(d.sort_values().dt.strftime('%Y-%m-%d').tolist())   # 날짜 순서
```

| 코드 | 뜻 | 예 |
| --- | --- | --- |
| `%Y`, `%m`, `%d` | 연, 월, 일 | 2026, 11, 05 |
| `%H`, `%M` | 시, 분 | 21, 30 |

## 파생 열 만들기

`.dt`로 꺼낸 값을 열로 만들면 [groupby와 pivot_table](#/l/da-06-1)의 `groupby`를 바로 쓸 수 있습니다. 항공 승객 데이터로 연도별, 월별 흐름을 봅니다.

```run
import pandas as pd
df = pd.read_csv("flights.csv")
df['date'] = pd.to_datetime(df['year'].astype(str) + '-' + df['month'], format='%Y-%B')
df = df.sort_values('date')
print(df.head(3))
print(df.groupby('year')['passengers'].sum().iloc[[0, -1]])
print(df.groupby(df['date'].dt.month)['passengers'].mean().round(0).nlargest(3))
```

이 데이터의 단위는 천 명입니다. 연간 승객은 1949년 1,520에서 1960년 5,714로 약 3.8배 늘었고, 월 평균은 7월과 8월이 351로 가장 높습니다.

## resample: 시간 단위로 묶기

날짜가 index인 Series는 `resample('D')`, `resample('W')`로 일·주 단위로 묶어 집계합니다. 결과 행 수가 줄어듭니다.

```run
import pandas as pd
idx = pd.date_range('2026-11-01', periods=8, freq='6h')
s = pd.Series([201.0, 203.5, 205.2, 202.1, 200.8, 204.4, 206.9, 203.0], index=idx)
print(s.resample('D').mean())
```

6시간 간격 8개 값이 하루 평균 2개로 줄었습니다. 평균 말고 `max`, `sum`도 같은 방식으로 씁니다. 월 단위는 `'MS'`(월초 기준)입니다.

```run
import pandas as pd
df = pd.read_csv("flights.csv")
df['date'] = pd.to_datetime(df['year'].astype(str) + '-' + df['month'], format='%Y-%B')
s = df.set_index('date')['passengers'].sort_index()
print(s.resample('YS').sum().head(3))
print(s.resample('QS').mean().round(1).head(3))
```

## 실제 기록으로: 서울 따릉이 대여 데이터

**데이터 소개 · 서울 따릉이 시간별 대여 수** (`seoul_bike.csv`)

2017년 12월 ~ 2018년 11월, 1년 동안 서울 공공자전거(따릉이)가 **매시간** 몇 대 빌려졌는지와 그 시간의 날씨를 적은 **8,760행**(365일 × 24시간)입니다(UCI Seoul Bike Sharing Demand, CC BY 4.0). **한 행 = 한 시간**입니다.

| 컬럼 | 뜻 | 자료형 | 예시 |
| --- | --- | --- | --- |
| `date` | 날짜 | 글자(날짜로 바꿔 씀) | 2017-12-01 |
| `rented_bikes` | 그 시간 대여 수(대) | 정수 | 254 |
| `hour` | 시각(0 ~ 23) | 정수 | 0 |
| `temp` | 기온(℃) | 소수 | -5.2 |
| `humidity` | 습도(%) | 정수 | 37 |
| `wind_speed` | 풍속(m/s) | 소수 | 2.2 |
| `solar_rad` | 햇빛 양(MJ/m²) | 소수 | 0.0 |
| `rainfall` | 강수량(mm) | 소수 | 0.0 |
| `snowfall` | 적설량(cm) | 소수 | 0.0 |
| `season` | 계절 | 글자 | Winter, Spring, Summer, Autumn |
| `holiday` | 공휴일인가 | 글자 | Yes, No |
| `functioning_day` | 운영한 날인가 | 글자 | Yes, No |

빈칸은 없습니다. `functioning_day`가 No인 시간(295행)은 점검으로 대여가 0이라, 평균을 낼 때는 빼고 계산합니다.

지금까지 배운 것을 실제 기록에 써 봅니다. 위 표의 따릉이 데이터를 불러와 모양과 자료형부터 확인합니다.

```run
import pandas as pd

df = pd.read_csv("seoul_bike.csv")
print(df.shape)
print(df.head(3))
print(df["date"].dtype)
```

`date` 열의 자료형이 `object`(문자열)입니다. 그대로는 요일도, 월도 꺼낼 수 없으니 먼저 날짜로 바꾸고 파생 열을 만듭니다. `dt.dayofweek`는 월요일 0 ~ 일요일 6이라, 5 이상이면 주말입니다.

```run
import pandas as pd

df = pd.read_csv("seoul_bike.csv")
df["date"] = pd.to_datetime(df["date"])
df["weekday"] = df["date"].dt.day_name()
df["weekend"] = df["date"].dt.dayofweek >= 5
print(df[["date", "hour", "weekday", "weekend", "rented_bikes"]].head(3))
print(df.groupby(df["date"].dt.month)["rented_bikes"].sum().nlargest(3))
```

2017년 12월 1일은 금요일입니다. 월별로 합치면 6월(약 89.7만 대), 7월, 5월 순으로 많아, 따릉이는 늦봄 ~ 초여름에 가장 많이 탑니다.

이번에는 평일과 주말을 나눠 시간대별 평균을 봅니다. `functioning_day`가 `No`인 날은 시스템 점검으로 대여가 0이라, 평균을 끌어내리지 않게 빼고 계산합니다.

```run
import pandas as pd

df = pd.read_csv("seoul_bike.csv")
df["date"] = pd.to_datetime(df["date"])
df = df[df["functioning_day"] == "Yes"]
df["weekend"] = df["date"].dt.dayofweek >= 5
by_hour = df.groupby(["weekend", "hour"])["rented_bikes"].mean().round(0).unstack(0)
print(by_hour.loc[[8, 14, 18]])
```

평일(`False`)은 오전 8시 1,306대, 오후 6시 1,724대로 출퇴근 시간에 몰리고 낮 2시는 721대로 줄어듭니다. 주말(`True`)은 오전 8시가 421대뿐이고 낮 2시(940대)가 평일보다 많습니다. 같은 자전거라도 평일에는 **출퇴근 수단**, 주말에는 **나들이 수단**으로 쓰인다는 것이 날짜 파생 열 하나로 드러납니다.

시간 단위 기록을 하루 단위로 합칠 때는 `resample('D')`를 씁니다.

```run
import pandas as pd

df = pd.read_csv("seoul_bike.csv")
df["date"] = pd.to_datetime(df["date"])
daily = df.set_index("date")["rented_bikes"].resample("D").sum()
print(len(daily), "days")
print(daily.describe().round(0))
print(daily.idxmax().date(), daily.max())
```

8,760행이 365일로 줄었습니다. 하루 평균 약 1만 6,910대이고, 가장 많은 날은 2018년 6월 13일(3만 6,149대)입니다. 최솟값 0은 운영하지 않은 날입니다. 이렇게 **0이 "적게 빌린 날"인지 "기록이 없는 날"인지**를 구분하는 것도 시계열을 다룰 때 꼭 확인할 점입니다.

## rolling, shift, diff

- `rolling(n).mean()`: n개 창을 밀며 평균 → 들쭉날쭉한 추세를 부드럽게. 처음 n−1개는 NaN
- `shift(1)`: 한 칸 밀어 **전 시점 값**
- `diff()` / `pct_change()`: 직전 대비 차이 / 변화율

::video{ref="dl-m19"}

```run
import pandas as pd
qty = pd.Series([1610, 1650, 1595, 1702, 1688])
print(qty.rolling(3).mean().round(1).tolist())
print(qty.shift(1).tolist())
print((qty.pct_change() * 100).round(2).tolist())
```

3일 이동평균의 첫 값 1618.3은 1610, 1650, 1595의 평균입니다. 앞의 두 칸은 창이 다 차지 않아 비어 있습니다. `shift`로 전일 값을 옆에 두면 변화량을 직접 계산할 수 있습니다.

```run
import pandas as pd
df = pd.DataFrame({'day': ['월', '화', '수', '목'], 'qty': [100, 120, 90, 135]})
df['prev'] = df['qty'].shift(1)
df['diff'] = df['qty'] - df['prev']
df['pct'] = (df['diff'] / df['prev'] * 100).round(1)
print(df)
```

항공 승객은 7~8월에 치솟는 계절성이 있습니다. 12개월 이동평균으로 계절을 지우면 큰 흐름이 보이고, 전년 같은 달과 비교(`pct_change(12)`)하면 계절의 영향 없이 성장률을 볼 수 있습니다.

```run
import pandas as pd
df = pd.read_csv("flights.csv")
df['date'] = pd.to_datetime(df['year'].astype(str) + '-' + df['month'], format='%Y-%B')
s = df.set_index('date')['passengers'].sort_index()
result = pd.DataFrame({'value': s, 'ma12': s.rolling(12).mean().round(1), 'yoy_%': (s.pct_change(12) * 100).round(1)})
print(result.loc['1950-05':'1950-08'])
```

## resample과 rolling의 차이

| | resample | rolling |
| --- | --- | --- |
| 하는 일 | 시간 구간으로 묶기 | 창을 밀며 계산 |
| 행 수 | 줄어듦 | 그대로 |
| 쓰임 | 일별을 월별로 요약 | 추세 다듬기 |
| 준비 | 날짜 index 필요 | 정렬만 되어 있으면 됨 |

시간 연산 전에는 항상 **날짜순으로 정렬**하세요. 순서가 뒤섞이면 `shift`와 `rolling` 결과가 틀어져도 에러가 나지 않습니다.

> resample은 시간 간격으로 **묶고**(행 수 감소), rolling은 행마다 **창을 밀며** 계산합니다(행 수 유지). 헷갈리면 결과의 len()을 비교해 보세요.
