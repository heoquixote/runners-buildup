[반복문 없이 배열을 한 번에 계산하기](#/l/da-01-1)에서는 이미 있는 리스트를 `np.array`로 바꿔 계산했습니다. 실무에서는 배열을 **직접 만들어야** 할 때도 많습니다. 규격 기준값을 일정 간격으로 늘어놓거나, 결과를 담을 빈 배열을 미리 준비하거나, 코드를 시험하려고 가짜 측정값을 만들 때입니다. 이 레슨에서는 배열을 만드는 함수와, 배열 안 값의 종류인 **자료형(dtype)**을 다룹니다.

## 일정 간격으로 만들기: arange와 linspace

둘 다 일정한 간격으로 숫자를 늘어놓지만, 무엇을 정하느냐가 다릅니다.

| 함수 | 정하는 것 | 끝 값 |
| --- | --- | --- |
| `np.arange(시작, 끝, 간격)` | 간격 | 포함하지 않음 (`range`와 같음) |
| `np.linspace(시작, 끝, 개수)` | 개수 | 포함 |

```run
import numpy as np

print(np.arange(0, 10, 2))            # 0부터 2씩, 10은 빠짐
print(np.arange(10.0, 10.5, 0.1))     # 소수 간격도 된다
print(np.linspace(10.0, 10.5, 6))     # 10.0과 10.5 사이를 6개로
```

`arange`는 10.5가 빠지고 `linspace`는 10.5까지 들어갔습니다. 소수 간격에서는 `arange`가 끝 값 근처에서 반올림 오차 때문에 개수가 하나 더 생기기도 합니다. **개수가 중요하면 linspace**를 쓰는 편이 안전합니다.

## 같은 값으로 채우기: zeros, ones, full

결과를 담을 자리를 먼저 만들거나, 모든 칸에 같은 기준값을 넣을 때 씁니다. 모양은 숫자 하나(1차원) 또는 `(행, 열)` 튜플로 줍니다.

```run
import numpy as np

print(np.zeros(3))            # 0으로 3칸
print(np.ones((2, 3)))        # 1로 2행 3열
print(np.full(4, 9.5))        # 9.5로 4칸 (하한 규격 4개)
```

`zeros`와 `ones`는 기본이 소수(`0.`, `1.`)입니다. 점이 찍힌 것이 소수라는 표시입니다.

## 가짜 측정값 만들기: 난수

코드를 실제 데이터에 쓰기 전에 그럴듯한 값으로 먼저 시험해 보면 좋습니다. `np.random.default_rng(seed)`로 **난수 생성기**를 만들고, 거기서 값을 뽑습니다. `seed`는 출발점 번호입니다. 같은 seed면 언제 실행해도 같은 값이 나와서 결과를 다시 확인할 수 있습니다.

```run
import numpy as np

rng = np.random.default_rng(42)       # seed 42로 고정
x = rng.normal(10.0, 0.05, 5)         # 평균 10.0, 표준편차 0.05인 값 5개
print(x.round(3))
print(rng.integers(0, 5, size=8))     # 0~4 정수 8개 (5는 빠짐)
```

`normal`은 평균 근처에 많이 모이는 정규분포에서 값을 뽑습니다. 다섯 값이 모두 9.9~10.05 사이에 있습니다. `integers`도 `arange`처럼 끝 값 5는 나오지 않습니다.

> 예전 코드에는 `np.random.seed(0)` 후 `np.random.normal(...)`로 쓰는 방식이 많습니다. 결과는 비슷하지만, 새로 쓰는 코드는 `default_rng`를 권장합니다.

## 자료형 dtype

배열은 모든 값이 **같은 종류**여야 합니다. 그래서 종류가 섞이면 NumPy가 하나로 맞춥니다.

```run
import numpy as np

a = np.array([1, 2, 3])
b = np.array([1, 2.5, 3])
c = np.array([1, 2.5, '3'])
print(a.dtype, b.dtype)
print(c)                   # 문자 하나 때문에 전부 문자
```

정수만 있으면 `int64`(환경에 따라 `int32`), 소수가 하나라도 섞이면 전부 `float64`가 됩니다. 문자열이 하나라도 섞이면 모든 값이 문자열(`'1'`, `'2.5'`)이 되어 계산을 할 수 없습니다. CSV에서 읽은 숫자가 계산이 안 되면 이 경우를 먼저 의심합니다.

## 자료형 바꾸기: astype

`astype(자료형)`으로 바꿉니다. 소수를 정수로 바꿀 때는 **반올림이 아니라 버림**이라는 점을 꼭 기억하세요.

```run
import numpy as np

x = np.array([9.7, 10.2, 10.6])
print(x.astype(int))                  # 소수점 아래를 버린다
print(np.round(x).astype(int))        # 반올림한 뒤 정수로

codes = np.array(['3', '12'])
print(codes.astype(int).sum())        # 문자 숫자를 정수로 바꿔 합계
```

9.7이 9, 10.6이 10이 됐습니다. 반올림이 필요하면 `np.round` 다음에 `astype`을 씁니다. 문자열 `'3'`, `'12'`는 정수로 바꾼 뒤에야 합계 15가 나옵니다.

## 직접 해보기

```run
import numpy as np

spec = np.linspace(10.0, 10.5, 6)
print(spec, len(spec))
```

## 정리

- 간격을 정하면 `arange`(끝 미포함), 개수를 정하면 `linspace`(끝 포함)
- `zeros` · `ones` · `full`로 같은 값을 채우고, `default_rng(seed)`로 재현되는 난수를 만듭니다
- 배열은 자료형이 하나뿐이고, `astype(int)`는 버림입니다
