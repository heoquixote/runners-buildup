## 시작하기 전에

앞 PART에서 matplotlib으로 그래프의 뼈대를 배웠습니다. matplotlib은 원하는 것을 거의 다 그릴 수 있지만, **표를 그룹별로 나눠 그리는 그래프**에서는 할 일이 많아집니다. 식당 계산서 244건으로 "계산 금액이 클수록 팁도 많을까? 남녀에 따라 다를까?"를 그려 봅니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("tips.csv")
fig, ax = plt.subplots(figsize=(5, 3.5))
for sex, g in df.groupby("sex"):          # 성별로 나눠서 하나씩
    ax.scatter(g["total_bill"], g["tip"], label=sex, s=15)
ax.set_xlabel("total_bill")
ax.set_ylabel("tip")
ax.legend(title="sex")
print(df.groupby("sex")["tip"].mean().round(2))
```

남성 계산서의 평균 팁(3.09)이 여성(2.83)보다 조금 큽니다. 그래프는 잘 나왔지만 코드를 보면 내가 해야 할 일이 많았습니다. 성별로 표를 **나누고**, 그룹마다 **반복**해서 점을 찍고, 축 이름과 **범례**를 직접 달았습니다. 이 일을 대신해 주는 도구가 **seaborn**입니다.

## seaborn은 무엇인가

**seaborn**(시본)은 **matplotlib 위에서 동작하는 통계 그래프 라이브러리**입니다. pandas 표(DataFrame)를 통째로 넘기고 **"x축은 이 열, y축은 이 열, 색은 이 열"처럼 열 이름만 배정**하면, 나누기 · 집계 · 색 구분 · 범례 · 축 이름을 알아서 해 줍니다.

불러올 때는 `sns`라는 별명을 씁니다. 이 사이트에서는 처음 실행할 때 seaborn을 내려받느라 몇 초 더 걸립니다.

::figure{src="content/img/libs/lib-map-seaborn.svg" alt="파이썬 위에 NumPy, 그 위에 pandas, matplotlib, scikit-learn, matplotlib 위에 seaborn이 있고 오른쪽에 PyTorch가 있다. seaborn이 강조되어 있다" caption="seaborn은 지도의 맨 위층입니다. pandas 표를 받아 matplotlib으로 그립니다."}

앞의 그래프를 seaborn으로 다시 그립니다.

```run
import matplotlib.pyplot as plt
import pandas as pd
import seaborn as sns

df = pd.read_csv("tips.csv")
fig, ax = plt.subplots(figsize=(5, 3.5))
sns.scatterplot(data=df, x="total_bill", y="tip", hue="sex", ax=ax)
print(df.shape)
```

계산서 244장이 점 244개가 되었고, 점의 위치와 색이 앞의 그래프와 같습니다. 반복문도, 범례 코드도, 축 이름 코드도 없습니다. `hue`는 "색으로 구분할 열"이라는 뜻입니다. 두 방법 모두 계산 금액이 클수록 팁도 커지는 오른쪽 위로 올라가는 모양을 보여 줍니다.

::figure{src="content/img/libs/sns-vs-mpl.svg" alt="왼쪽 matplotlib 코드는 groupby 반복, scatter, set_xlabel, set_ylabel, legend 일곱 줄. 오른쪽 seaborn 코드는 scatterplot에 data, x, y, hue를 배정하는 한 문장. 가운데 두 색 산점도는 같은 그림" caption="matplotlib은 '어떻게 그릴지'를 하나하나 지시하고, seaborn은 '무엇을 어느 역할에 쓸지'만 말합니다."}

## 함수 가족: 질문마다 고르는 그래프

seaborn 함수는 거의 모두 `data=`, `x=`, `y=`, `hue=`라는 같은 모양을 씁니다. 그래서 **함수 이름만 바꾸면** 같은 데이터를 다른 질문으로 볼 수 있습니다. 함수는 답하는 질문에 따라 다섯 가족으로 나뉩니다.

::figure{src="content/img/libs/sns-families.svg" alt="관계 scatterplot·lineplot 두 값이 함께 움직이나, 분포 histplot·kdeplot 값이 어떻게 퍼져 있나, 범주 barplot·boxplot 그룹끼리 다른가, 회귀 regplot·lmplot 추세선, 행렬 heatmap 표 전체를 한눈에" caption="seaborn 함수 가족. 그래프보다 질문을 먼저 고르면 함수가 정해집니다."}

방금 산점도(관계 가족)의 `scatterplot`을 `boxplot`(범주 가족)으로 바꾸고, x를 요일로 바꿔 봅니다. "요일마다 계산 금액이 다를까?"라는 질문이 됩니다.

```run
import matplotlib.pyplot as plt
import pandas as pd
import seaborn as sns

df = pd.read_csv("tips.csv")
fig, ax = plt.subplots(figsize=(5, 3.5))
sns.boxplot(data=df, x="day", y="total_bill", ax=ax)
print(df.groupby("day")["total_bill"].median())
```

상자 가운데 선이 그룹의 가운데 값(중앙값)입니다. 출력한 숫자와 같이 일요일(Sun) 19.63, 토요일(Sat) 18.24로 주말 계산 금액이 평일보다 큽니다. 데이터를 요일별로 나누는 일은 seaborn이 했습니다. 상자그림 읽는 법은 질문별 차트 PART의 [상자그림 읽기](#/l/da-14-3)에서 자세히 배웁니다. seaborn 함수 가족마다 어떤 차트가 있는지는 다음 페이지 [seaborn 차트 갤러리: 함수 가족별 대표 차트](#/l/da-10-5)에서 한눈에 봅니다.

## matplotlib과 언제 무엇을 쓸까

| 상황 | 고르는 도구 |
| --- | --- |
| 표에서 그룹별 비교 · 분포 · 관계를 빠르게 보기 | **seaborn** |
| 평균과 오차 막대, 추세선처럼 통계 계산이 들어간 그래프 | **seaborn** |
| 제목 · 축 · 글자 크기 · 기준선 같은 마무리 손질 | **matplotlib** (`ax.set_title` 등) |
| 아주 특이한 모양, 칸 배치를 세세하게 | **matplotlib** |

둘은 경쟁 관계가 아니라 **함께 쓰는 짝**입니다. seaborn으로 그리고, 돌려받은 `ax`에 matplotlib 명령으로 다듬는 것이 가장 흔한 방법입니다.

## 정리

- **seaborn** = matplotlib 위의 통계 그래프 도구. `import seaborn as sns`
- 표를 `data=`로 넘기고 `x=` · `y=` · `hue=`에 열 이름을 배정하면 나누기 · 색 · 범례를 알아서
- 함수 이름만 바꾸면 같은 데이터를 다른 질문으로: 관계 · 분포 · 범주 · 회귀 · 행렬
- seaborn으로 그리고 matplotlib으로 다듬는다
