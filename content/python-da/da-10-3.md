## 범주형 그래프 세 가족

"요일별로 비교해 보자"처럼 x축이 **범주**(요일, 등급, 성별)인 그래프를 범주형 그래프라고 합니다. seaborn에는 범주형 그래프가 여러 개 있는데, **무엇을 비교하느냐**에 따라 세 가족으로 나누면 고르기 쉽습니다.

::figure{src="content/img/viz/viz08-cat-family.svg" alt="범주형 그래프 세 가족: 개수를 세는 countplot, 평균 같은 요약값을 보여 주는 barplot과 pointplot, 분포 전체를 보여 주는 boxplot, violinplot, stripplot, swarmplot" caption="범주별로 '몇 개?', '평균은?', '어떻게 퍼져 있나?' 중 무엇이 궁금한지에 따라 가족을 고릅니다."}

| 가족 | 질문 | 함수 |
| --- | --- | --- |
| 개수 | 범주마다 몇 개(몇 행) 있나? | `countplot` |
| 요약값 | 범주마다 평균은 얼마인가? | `barplot`, `pointplot` |
| 분포 | 범주마다 값이 어떻게 퍼져 있나? 이상치는? | `boxplot`, `violinplot`, `stripplot`, `swarmplot` |

모든 함수가 `data · x · y · hue` 모양이고, `order=`로 범주 순서를 정할 수 있습니다. 이번 레슨은 식당 계산서(`tips.csv`)와 타이타닉(`titanic.csv`)을 씁니다. 요일은 목·금·토·일 순서로 보기 위해 `order=["Thur", "Fri", "Sat", "Sun"]`을 넣습니다.

## countplot: 몇 개인가

`countplot`은 y값 없이 x만 주면 범주마다 **행 개수**를 막대로 그립니다. 데이터가 어느 범주에 얼마나 있는지, 한쪽에 쏠리지 않았는지 처음 확인할 때 씁니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("tips.csv")
ax = sns.countplot(data=df, x="day", order=["Thur", "Fri", "Sat", "Sun"])
print(df["day"].value_counts())
```

토요일 87건, 일요일 76건, 목요일 62건인데 금요일은 19건뿐입니다. 금요일은 데이터가 적어서 금요일 평균은 **덜 믿을 만하다**는 점을 기억해 두세요. 바로 아래 오차 막대에서 이것이 보입니다.

## barplot: 막대 높이는 평균

`barplot`은 x 범주마다 y의 **평균**을 막대 높이로 그립니다. 개수도 합계도 아니라 **평균**이라는 점이 가장 많이 틀리는 부분입니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("tips.csv")
ax = sns.barplot(data=df, x="day", y="total_bill", order=["Thur", "Fri", "Sat", "Sun"])
print(df.groupby("day")["total_bill"].mean().round(2))
```

일요일 21.41달러, 토요일 20.44달러로 주말 평균이 높습니다. 막대 위의 검은 세로선은 **오차 막대**(신뢰 구간)입니다. "데이터를 다시 모으면 평균이 대략 이 범위 안에 들어올 것"이라는 표시로, 선이 길수록 평균이 덜 확실합니다. 데이터가 19건뿐인 금요일 선이 가장 깁니다.

오차 막대 대신 데이터가 얼마나 퍼져 있는지(표준편차)를 보여 주려면 `errorbar="sd"`, 끄려면 `errorbar=None`을 씁니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("tips.csv")
ax = sns.barplot(data=df, x="day", y="total_bill", order=["Thur", "Fri", "Sat", "Sun"], errorbar="sd")
print(df.groupby("day")["total_bill"].std().round(2))
```

평균이 아니라 **합계**를 그리고 싶으면 `estimator="sum"`을 줍니다. "요일별 총매출"처럼 합계가 의미 있는 질문일 때 씁니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("tips.csv")
ax = sns.barplot(data=df, x="day", y="total_bill", order=["Thur", "Fri", "Sat", "Sun"], estimator="sum", errorbar=None)
print(df.groupby("day")["total_bill"].sum().round(0))
```

합계로 보면 토요일(1,778달러)이 일요일(1,627달러)보다 큽니다. 평균은 일요일이 높았는데 말이죠. 토요일에 손님이 더 많았기 때문입니다. **평균과 합계는 다른 질문에 대한 답**이므로, 그래프 제목에 무엇인지 꼭 적으세요.

## pointplot: 평균의 변화를 점과 선으로

`pointplot`은 막대 대신 **점(평균)과 오차 막대**만 그리고, 같은 hue끼리 점을 선으로 잇습니다. 막대보다 가벼워서 **그룹끼리 평균이 어떻게 엇갈리는지** 보기 좋습니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("tips.csv")
ax = sns.pointplot(data=df, x="day", y="tip", hue="sex", order=["Thur", "Fri", "Sat", "Sun"], dodge=True)
print(df.pivot_table(index="day", columns="sex", values="tip").round(2))
```

남성(Male)의 평균 팁이 목·토요일에는 높고, 금·일요일에는 여성(Female)이 높습니다. 선이 서로 **엇갈리면** "성별에 따른 차이가 요일마다 다르다"는 뜻입니다. `dodge=True`는 두 그룹 점이 겹치지 않게 살짝 옆으로 비킵니다.

## boxplot: 범주별 분포와 이상치

평균 하나로는 부족할 때가 많습니다. 평균이 같아도 값이 고르게 모여 있을 수도, 크게 들쭉날쭉할 수도 있으니까요. `boxplot`은 범주마다 상자그림을 나란히 그립니다. 상자 읽는 법은 da-09-3에서 배운 그대로입니다(가운데 선 = 중앙값, 상자 = 가운데 50%, 점 = 이상치).

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("tips.csv")
ax = sns.boxplot(data=df, x="day", y="total_bill", order=["Thur", "Fri", "Sat", "Sun"])
print(df.groupby("day")["total_bill"].median())
```

중앙값은 일요일 19.63, 토요일 18.24로 막대그래프의 평균(21.41, 20.44)보다 낮습니다. 위쪽에 큰 금액의 이상치 점들이 평균을 끌어올리기 때문입니다. 특히 토요일에 40달러가 넘는 계산서가 여럿 있습니다. **"요일별로 이상치가 있나?"**라는 질문에는 barplot이 아니라 boxplot으로 답해야 합니다.

## violinplot: 상자 + 분포 모양

상자그림은 다섯 숫자로 요약하느라 **봉우리가 몇 개인지** 같은 모양 정보를 버립니다. `violinplot`은 상자 양옆에 da-10-2의 KDE 곡선을 좌우 대칭으로 붙여, 바이올린 같은 모양으로 분포의 생김새까지 보여 줍니다. 몸통이 두꺼운 곳에 값이 많습니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("penguins.csv").dropna()
ax = sns.violinplot(data=df, x="species", y="body_mass_g")
print(df.groupby("species")["body_mass_g"].median())
```

직접 해 보세요. `hue="sex", split=True`를 더하면 바이올린 왼쪽 절반은 암컷, 오른쪽 절반은 수컷으로 나뉩니다. 세 종 모두 수컷 쪽이 위(무거운 쪽)에 있습니다. `inner="quart"`는 가운데에 사분위 점선을 그립니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("penguins.csv").dropna()
ax = sns.violinplot(data=df, x="species", y="body_mass_g", hue="sex", split=True, inner="quart")
print(df.groupby(["species", "sex"])["body_mass_g"].median().unstack())
```

## stripplot · swarmplot: 점 하나하나 다 보기

데이터가 수백 개 이하라면 요약하지 않고 **점을 전부** 찍어 보는 것도 좋은 방법입니다. `stripplot`은 범주마다 점을 세로로 찍고 옆으로 살짝 흩어 겹침을 줄입니다. `swarmplot`은 점이 **절대 겹치지 않게** 벌집처럼 옆으로 펼쳐서, 점이 넓게 퍼진 곳이 곧 값이 많은 곳입니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("tips.csv")
fig, ax = plt.subplots(figsize=(6, 4))
sns.swarmplot(data=df, x="day", y="total_bill", order=["Thur", "Fri", "Sat", "Sun"], size=3, ax=ax)
print("찍은 점:", sum(len(c.get_offsets()) for c in ax.collections))
```

금요일에 점이 얼마나 적은지(19개)가 한눈에 보입니다. 상자그림만 보면 알 수 없는 정보입니다. 다만 점이 수천 개가 되면 swarmplot은 느려지고 빽빽해지니 상자·바이올린을 씁니다.

## 겹쳐 그리기: 요약과 실제 값을 함께

같은 ax에 두 함수를 차례로 부르면 겹쳐 그려집니다. **상자그림 위에 점**을 찍으면 요약(상자)과 실제 데이터 개수·위치(점)를 함께 보여 줄 수 있어 보고서에서 자주 씁니다. `fliersize=0`은 상자그림의 이상치 점을 숨겨 점이 두 번 찍히지 않게 합니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("tips.csv")
order = ["Thur", "Fri", "Sat", "Sun"]
ax = sns.boxplot(data=df, x="day", y="total_bill", order=order, color="lightgray", fliersize=0)
sns.stripplot(data=df, x="day", y="total_bill", order=order, size=3, alpha=0.6, ax=ax)
print("상자 위에 점 겹치기 완료")
```

## catplot: 범주형 그래프를 칸으로 나누기

범주형 그래프의 그림 단위 함수가 `catplot`입니다. `kind=`에 `"count"`, `"bar"`, `"point"`, `"box"`, `"violin"`, `"strip"`, `"swarm"`을 넣으면 위의 함수들과 같은 그래프가 되고, `col=`로 칸을 나눌 수 있습니다. 타이타닉 생존율을 등급(x) × 성인 남자/여자/어린이(hue) × 승선 항구(col)로 나눠 봅니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("titanic.csv")
g = sns.catplot(data=df, x="class", y="survived", hue="who", kind="bar", errorbar=None,
                order=["First", "Second", "Third"], height=3.2, aspect=1.3)
g.set_axis_labels("Class", "Survival rate")
print(df.pivot_table(index="class", columns="who", values="survived").round(2))
```

`survived`는 0과 1이라서 막대 높이(평균)가 곧 생존율입니다. 모든 등급에서 성인 남자(man) 생존율이 가장 낮고(2등실 0.08), 2등실 어린이는 모두 살아남았습니다(1.00). "여성과 어린이 먼저"라는 원칙이 등급을 가리지 않고 적용됐지만, 3등실에서는 여성·어린이 생존율도 절반 이하였다는 것까지 한 그림에서 읽힙니다.

## 정리: 범주형 그래프 고르기

| 질문 | 함수 | 막대·상자·점이 뜻하는 것 | 주의 |
| --- | --- | --- | --- |
| 범주마다 몇 개? | `countplot` | 행 개수 | y를 주지 않는다 |
| 범주마다 평균은? | `barplot` | **평균** + 오차 막대 | 합계는 `estimator="sum"` |
| 평균이 그룹끼리 어떻게 엇갈리나? | `pointplot` | 평균 점을 선으로 연결 | `dodge=True`로 겹침 방지 |
| 분포·이상치 비교 | `boxplot` | 중앙값, 사분위, 이상치 | 봉우리 모양은 안 보임 |
| 분포 모양까지 | `violinplot` | 상자 + KDE 곡선 | 데이터가 적으면 모양이 과장됨 |
| 점 하나하나 | `stripplot`, `swarmplot` | 행 하나 = 점 하나 | 수천 개 이상이면 느리고 빽빽 |
| 칸 나누기 | `catplot(kind=, col=)` | 위와 같음 | 그림 단위 → `ax=` 대신 `col=`·`row=` |
