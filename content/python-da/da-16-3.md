## 구성이 시간에 따라 어떻게 변하나

누적 막대([누적 막대와 100% 막대 읽기](#/l/da-16-2))를 시간 순서로 늘어놓고 막대 사이를 메우면 **누적 영역 그래프**가 됩니다. "전체 승객은 늘었는데, 그중 여름 비중도 늘었나?"처럼 **전체의 추이와 구성의 변화를 함께** 묻는 질문에 씁니다.

연도별 항공 승객을 계절로 묶어 준비합니다. 겨울은 그해 12·1·2월, 봄은 3~5월, 여름은 6~8월, 가을은 9~11월입니다.

```run
import pandas as pd

df = pd.read_csv("flights.csv")
season = {"December": "Winter", "January": "Winter", "February": "Winter",
          "March": "Spring", "April": "Spring", "May": "Spring",
          "June": "Summer", "July": "Summer", "August": "Summer",
          "September": "Fall", "October": "Fall", "November": "Fall"}
df["season"] = df["month"].map(season)
table = df.pivot_table(index="year", columns="season", values="passengers", aggfunc="sum")
table = table[["Winter", "Spring", "Summer", "Fall"]]
print(table.loc[[1949, 1960]])
```

## 누적 영역 그래프가 나타내는 것

`ax.stackplot(x, 층1, 층2, ...)`은 층을 아래부터 차례로 쌓아 칠합니다. 표의 열을 한꺼번에 넘기려면 `table.T.values`(행과 열을 뒤집은 값)를 씁니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("flights.csv")
season = {"December": "Winter", "January": "Winter", "February": "Winter",
          "March": "Spring", "April": "Spring", "May": "Spring",
          "June": "Summer", "July": "Summer", "August": "Summer",
          "September": "Fall", "October": "Fall", "November": "Fall"}
df["season"] = df["month"].map(season)
table = df.pivot_table(index="year", columns="season", values="passengers", aggfunc="sum")
table = table[["Winter", "Spring", "Summer", "Fall"]]
fig, ax = plt.subplots(figsize=(7, 3.5))
ax.stackplot(table.index, table.T.values, labels=table.columns)
ax.legend(loc="upper left")
print("연간 합계 1949:", table.loc[1949].sum(), "/ 1960:", table.loc[1960].sum())
```

**무엇을 나타내나**

- x축: 시간(연도)
- **맨 위 경계선**: 모든 층의 합 = 전체 승객 수
- 층 하나의 **두께**: 그 계절의 승객 수

**이렇게 읽는다**

1. **맨 위 선**으로 전체 추이를 읽는다 (선 그래프처럼)
2. **맨 아래 층**(겨울)은 바닥이 0에 붙어 있어 선처럼 정확히 읽을 수 있다
3. 위쪽 층은 **두께**의 변화로 읽는다 (높이가 아님)

> 해석: 전체 승객은 1949년 1,520명에서 1960년 5,714명으로 약 3.8배가 됐다. 네 층 모두 오른쪽으로 갈수록 두꺼워져 모든 계절에서 승객이 늘었고, 세 번째 층(여름)이 처음부터 끝까지 가장 두껍다.

## 가운데 층의 두께는 읽기 어렵다

누적 영역에서 위쪽 층은 **바닥이 아래 층을 따라 울퉁불퉁 올라가서**, 두께가 얼마나 변했는지 눈으로 재기 어렵습니다. 같은 데이터를 계절별 선 4개로 그려 비교해 봅니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("flights.csv")
season = {"December": "Winter", "January": "Winter", "February": "Winter",
          "March": "Spring", "April": "Spring", "May": "Spring",
          "June": "Summer", "July": "Summer", "August": "Summer",
          "September": "Fall", "October": "Fall", "November": "Fall"}
df["season"] = df["month"].map(season)
table = df.pivot_table(index="year", columns="season", values="passengers", aggfunc="sum")
table = table[["Winter", "Spring", "Summer", "Fall"]]
ax = table.plot(figsize=(7, 3.5), marker="o", markersize=3)
growth = (table.loc[1960] / table.loc[1949]).round(2)
print("1949 대비 1960 배수:", growth.to_dict())
```

> 해석: 선으로 그리면 여름 선이 다른 세 계절보다 점점 더 위로 벌어지는 것이 바로 보인다. 1949년 대비 1960년에 여름은 4.09배, 겨울은 3.56배로 늘어 여름이 가장 빨리 성장했다. 봄과 가을 선은 거의 겹쳐 비슷하게 움직였다.

누적 영역은 **"전체가 얼마이고, 대략 어떤 층으로 이뤄졌나"**를 보여 줄 때 좋고, **층끼리 성장을 정확히 비교**해야 할 때는 선 그래프가 낫습니다.

## 100% 누적 영역: 비중의 변화

각 연도를 100%로 맞추면 전체 크기는 사라지고 **비중의 변화**만 남습니다. 표를 행 합계로 나눕니다(`table.div(table.sum(axis=1), axis=0)`).

```run
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("flights.csv")
season = {"December": "Winter", "January": "Winter", "February": "Winter",
          "March": "Spring", "April": "Spring", "May": "Spring",
          "June": "Summer", "July": "Summer", "August": "Summer",
          "September": "Fall", "October": "Fall", "November": "Fall"}
df["season"] = df["month"].map(season)
table = df.pivot_table(index="year", columns="season", values="passengers", aggfunc="sum")
table = table[["Winter", "Spring", "Summer", "Fall"]]
share = table.div(table.sum(axis=1), axis=0) * 100
fig, ax = plt.subplots(figsize=(7, 3.5))
ax.stackplot(share.index, share.T.values, labels=share.columns)
ax.set_ylim(0, 100)
ax.legend(loc="upper left", bbox_to_anchor=(1, 1))
print(share.loc[[1949, 1960]].round(1))
```

**이렇게 읽는다**: 맨 위가 항상 100%라 전체 추이는 없습니다. **층 경계선이 기울어지는지**를 봅니다. 경계선이 평평하면 비중이 그대로, 기울어지면 비중이 바뀐 것입니다.

> 해석: 층 경계가 거의 평평해 네 계절의 비중은 12년 동안 크게 변하지 않았다. 다만 여름 비중은 28.4%에서 30.9%로 2.5%p 늘고, 겨울은 22.9%에서 21.7%로 줄어 여름 쏠림이 조금씩 커졌다.

**잘못 읽기 쉬운 점**: 100% 그래프에서 겨울 층이 얇아졌다고 "겨울 승객이 줄었다"고 읽으면 틀립니다. 겨울 승객 수는 348명에서 1,240명으로 3.6배 늘었습니다. **비중이 줄었을 뿐, 개수는 늘었습니다.** 100% 그래프는 비중만, 누적 영역은 개수를 말합니다.

## 정리: 구성 그래프 세 가지

| 그래프 | 코드 | 먼저 읽을 것 | 주의 |
| --- | --- | --- | --- |
| 파이 · 도넛 | `ax.pie(값, autopct=)` | 가장 큰 조각, 절반을 넘나 | 조각 5개 이하, 분모 확인 |
| 누적 · 100% 막대 | `crosstab(...).plot.bar(stacked=True)` | 맨 아래 조각, 경계선 높이 | 가운데 조각은 어려움, n 표시 |
| 누적 영역 | `ax.stackplot(x, table.T.values)` | 맨 위 선 = 전체, 층 두께 | 층끼리 성장 비교는 선 그래프로 |
| 100% 누적 영역 | `table.div(table.sum(axis=1), axis=0)` 후 stackplot | 경계선 기울기 = 비중 변화 | 비중 감소 ≠ 개수 감소 |
