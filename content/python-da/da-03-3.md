DataFrame을 출력하면 왼쪽에 0, 1, 2 같은 번호가 붙습니다. 이것이 **인덱스(index)**, 즉 행 이름표입니다. 지금까지는 그냥 지나쳤지만, pandas는 계산할 때 이 이름표를 기준으로 값을 맞춥니다. 인덱스를 모르면 "숫자가 왜 NaN이 됐지?" 같은 버그를 만나게 됩니다. 이 레슨에서는 인덱스를 바꾸고, 되돌리고, 인덱스가 계산에 어떻게 쓰이는지 봅니다.

## 인덱스는 행의 이름표입니다

열의 이름이 `columns`이듯, 행의 이름은 `index`입니다. 따로 정하지 않으면 0부터 번호가 붙습니다.

```run
import pandas as pd

df = pd.DataFrame({'lot': ['L01', 'L02', 'L03'], 'qty': [500, 480, 610]})
print(df.index.tolist())
print(df.columns.tolist())
```

## 열을 인덱스로: set_index

로트 번호처럼 **행마다 겹치지 않는 값**이 있으면 인덱스로 올려 쓸 수 있습니다. 그러면 `loc`로 번호 대신 이름으로 행을 찾습니다.

```run
import pandas as pd

df = pd.DataFrame({'lot': ['L01', 'L02', 'L03'], 'qty': [500, 480, 610], 'defect': [6, 9, 4]})
by_lot = df.set_index('lot')
print(by_lot)
print(by_lot.loc['L02'])               # 이름으로 행 찾기
print(by_lot.loc['L03', 'qty'])        # 행 이름, 열 이름
```

`lot`이 열에서 빠지고 왼쪽 이름표 자리로 갔습니다. `loc['L02']`는 그 행을 Series로 돌려줍니다. 사전에서 단어로 뜻을 찾는 것과 같습니다.

## 인덱스를 다시 열로: reset_index

반대로 인덱스를 열로 내리고 0부터 번호를 새로 붙이려면 `reset_index()`를 씁니다. 필터나 정렬 후 번호가 뒤죽박죽일 때도 씁니다.

```run
import pandas as pd

df = pd.DataFrame({'lot': ['L01', 'L02', 'L03', 'L04'], 'qty': [500, 480, 610, 455]})
big = df[df['qty'] >= 480]
print(big.index.tolist())                          # 0, 1, 2 (3은 빠짐)

sorted_df = df.sort_values('qty')
print(sorted_df.index.tolist())                    # 정렬하면 순서가 섞인다
print(sorted_df.reset_index(drop=True))            # 번호를 새로 붙인다
```

`drop=True`는 옛 번호를 열로 남기지 않고 버리라는 뜻입니다. 빼면 `index`라는 열이 하나 생깁니다. `set_index`로 올린 열을 되돌릴 때는 `drop=True` 없이 써서 열로 내립니다.

인덱스를 기준으로 정렬하려면 `sort_index()`를 씁니다.

```run
import pandas as pd

s = pd.Series([3, 7, 5], index=['L03', 'L01', 'L02'])
print(s.sort_index())
```

## 계산은 인덱스끼리 맞춰집니다

여기가 가장 중요합니다. Series 두 개를 더하면 pandas는 **같은 위치**가 아니라 **같은 이름표**끼리 더합니다. 한쪽에만 있는 이름표는 짝이 없으니 결과가 `NaN`입니다.

```run
import pandas as pd

mon = pd.Series({'A': 520, 'B': 480, 'C': 610})    # 월요일 라인별 생산량
tue = pd.Series({'B': 500, 'C': 590, 'D': 300})    # 화요일 (A 없음, D 신설)
print(mon + tue)
```

B와 C는 정상으로 더해졌지만, 월요일에만 있는 A와 화요일에만 있는 D는 `NaN`입니다. 순서도 이름표 기준으로 정리되어 나옵니다. 엑셀에서 두 열을 **줄 위치대로** 더하던 습관과 다르니 조심하세요.

없는 쪽을 0으로 보고 더하려면 연산자 대신 메서드를 쓰고 `fill_value`를 줍니다.

```run
import pandas as pd

mon = pd.Series({'A': 520, 'B': 480, 'C': 610})
tue = pd.Series({'B': 500, 'C': 590, 'D': 300})
total = mon.add(tue, fill_value=0)
print(total)
print(total.sum())
```

| 연산자 | 메서드 |
| --- | --- |
| `a + b` | `a.add(b, fill_value=0)` |
| `a - b` | `a.sub(b, fill_value=0)` |
| `a * b` | `a.mul(b, fill_value=1)` |
| `a / b` | `a.div(b)` |

## 이 규칙이 실제로 문제가 되는 때

필터로 행을 고른 뒤 다른 Series와 계산하면, 이름표가 엇갈려서 `NaN`이 섞입니다.

```run
import pandas as pd

df = pd.DataFrame({'qty': [500, 480, 610, 455]})
big = df[df['qty'] >= 480]['qty']          # 이름표 0, 1, 2
target = pd.Series([450, 450, 600])        # 이름표 0, 1, 2
print((big - target).tolist())

big2 = df[df['qty'] >= 500]['qty']         # 이름표 0, 2
print((big2 - target).tolist())            # 1번은 짝이 없고, 2번은 엉뚱한 값과 계산
```

첫 번째는 이름표가 우연히 0, 1, 2로 같아서 맞게 계산됐습니다. 두 번째는 필터 결과 이름표가 0과 2뿐이라 1번 자리가 `NaN`이 되고, 2번 행(610)은 `target`의 세 번째 값(600)과 계산됐습니다. 위치로 맞추려는 의도였다면 둘 다 `reset_index(drop=True)`로 번호를 다시 붙인 뒤 계산합니다.

> 열끼리 계산할 때(`df['a'] - df['b']`)는 같은 표 안이라 이름표가 항상 같으므로 걱정하지 않아도 됩니다. **서로 다른 표에서 온 Series**를 계산할 때 인덱스를 확인하세요.

## 정리

- 인덱스는 행 이름표이고, `set_index`로 열을 올리고 `reset_index`로 내립니다
- 필터 · 정렬 후 번호를 새로 붙이려면 `reset_index(drop=True)`
- Series 연산은 위치가 아니라 이름표끼리 맞춰지고, 짝이 없으면 `NaN`입니다
- 없는 쪽을 0으로 보려면 `add(..., fill_value=0)`
