## 시작하기 전에

앞 PART에서 NumPy 배열로 숫자 묶음을 한 번에 계산했습니다. 그런데 실제로 받는 데이터는 대부분 이렇게 생긴 **표**입니다.

- 열마다 이름이 있다 (`이름`, `나이`, `운임`)
- 열마다 종류가 다르다 (글자 열, 숫자 열, 날짜 열)
- 빈칸이 섞여 있다

엑셀로 이런 표를 다룰 때 매주 같은 일을 반복한 적이 있다면, 필터 걸고 → 피벗 만들고 → VLOOKUP으로 다른 표 붙이고 → 저장하는 클릭을 매번 다시 해야 했을 겁니다. 이 과정을 **코드로 적어 두고 다시 돌릴 수 있게** 해 주는 도구가 **pandas**입니다.

## pandas는 무엇인가

**pandas**(판다스)는 **엑셀 표 같은 데이터를 파이썬 코드로 불러오고, 고르고, 정리하고, 요약하는 라이브러리**입니다. NumPy 배열에 **열 이름**과 **행 이름표**를 붙이고, 열마다 다른 종류의 값을 담을 수 있게 만든 것이라고 생각하면 됩니다.

이름은 동물 판다가 아니라, 경제학에서 여러 시점 · 여러 대상의 기록을 뜻하는 **panel data**(패널 데이터)에서 왔습니다. 불러올 때는 모두 `pd`라는 별명을 씁니다.

::figure{src="content/img/libs/lib-map-pandas.svg" alt="파이썬 위에 NumPy, 그 위에 pandas, matplotlib, scikit-learn, 맨 위에 seaborn이 있고 오른쪽에 PyTorch가 있다. pandas가 강조되어 있다" caption="pandas는 NumPy 바로 위에 있습니다. 표를 정리한 다음에는 matplotlib으로 그리고, scikit-learn으로 예측합니다."}

CSV 파일 하나를 읽는 데 한 줄이면 됩니다. 타이타닉호 승객 891명의 기록을 열어 봅니다.

```run
import pandas as pd

df = pd.read_csv("titanic.csv")
print(df.shape)
print(df[["survived", "pclass", "sex", "age", "fare"]].head(4))
```

`shape`의 `(891, 15)`는 행 891개, 열 15개라는 뜻입니다. 화면이 넓어지지 않게 열 5개만 골라 앞의 4행을 봤습니다. `survived`는 생존 여부(1 = 생존), `pclass`는 객실 등급, `fare`는 운임입니다. `df`는 DataFrame의 줄임말로, 표를 담는 변수 이름으로 가장 흔히 씁니다.

## 표의 부품: DataFrame · Series · index · columns

pandas 표는 네 가지 부품으로 되어 있습니다.

- **DataFrame**: 표 전체
- **columns**: 맨 위의 열 이름들
- **index**: 맨 왼쪽의 행 이름표 (따로 정하지 않으면 0, 1, 2 …)
- **Series**: 표에서 꺼낸 **열 하나**. 이름표(index)가 붙은 1차원 데이터

::figure{src="content/img/libs/pd-anatomy.svg" alt="타이타닉 표의 맨 위 줄 survived, pclass, sex, age, fare는 columns, 왼쪽 0, 1, 2, 3은 index, 강조된 fare 열 하나는 Series이고 속은 NumPy 배열이다" caption="DataFrame은 같은 index를 공유하는 Series(열)들의 묶음입니다. 열 하나의 속은 앞 PART에서 배운 NumPy 배열입니다."}

열 하나를 꺼내서 정말 그런지 확인해 봅니다.

```run
import pandas as pd

df = pd.read_csv("titanic.csv")
s = df["fare"]                    # 대괄호에 열 이름 → 열 하나(Series)
print(type(df).__name__, type(s).__name__)
print(type(s.to_numpy()).__name__)
print(df.columns[:5].tolist())
```

표는 `DataFrame`, 꺼낸 열은 `Series`, 그 속은 `ndarray`(NumPy 배열)입니다. 그래서 앞 PART에서 배운 "반복문 없이 한 번에 계산"이 pandas 열에도 그대로 됩니다. 예를 들어 `df["fare"] * 1300`은 모든 승객의 운임을 원화로 바꿉니다.

## 엑셀 피벗을 한 줄로

pandas의 힘을 보여 주는 대표 예가 **묶어서 요약하기**입니다. "남녀별 생존율은?"을 엑셀로 구하려면 피벗 테이블을 만들어야 합니다. pandas에서는 한 줄입니다.

```run
import pandas as pd

df = pd.read_csv("titanic.csv")
print(df.groupby("sex")["survived"].mean().round(3))
```

"`sex`로 묶고(`groupby`) → `survived` 열의 → 평균(`mean`)"이라고 왼쪽에서 오른쪽으로 읽으면 됩니다. `survived`가 0과 1이라서 평균이 곧 생존율입니다. 여성은 74.2%, 남성은 18.9%가 살아남았습니다. "여성과 아이 먼저"라는 구조 원칙이 숫자로 보입니다.

`"sex"`를 `"pclass"`로 바꿔 다시 실행해 보세요. 객실 등급별 생존율이 나옵니다(1등실 0.630, 2등실 0.473, 3등실 0.242). 질문이 바뀌어도 코드는 단어 하나만 바뀝니다. 이것이 클릭 대신 코드로 분석하는 이유입니다.

## pandas의 역사

| 해 | 일 |
| --- | --- |
| 2008 | 금융 회사에서 일하던 **웨스 매키니**(Wes McKinney)가 엑셀 · SQL로 하기 힘든 금융 데이터 분석을 위해 만들기 시작 |
| 2009 | 오픈소스로 공개. 누구나 무료로 쓰고 고칠 수 있게 됨 |
| 2012 | 매키니가 책 *Python for Data Analysis* 출간. 파이썬 데이터 분석 입문서의 표준이 됨 |
| 2020 | **pandas 1.0** 발표 |
| 2023 | **pandas 2.0** 발표 |

pandas가 나오기 전에는 표 데이터 분석을 주로 R이나 엑셀, SAS 같은 통계 프로그램으로 했습니다. pandas 덕분에 파이썬 하나로 "데이터 정리 → 분석 → 머신러닝"을 이어서 할 수 있게 되었고, 파이썬이 데이터 분야의 공용어가 되는 데 가장 큰 역할을 했습니다.

## 엑셀 · SQL과 비교하면

| 하고 싶은 일 | 엑셀 | SQL | pandas |
| --- | --- | --- | --- |
| 조건으로 행 고르기 | 필터 | `WHERE` | `df[df["age"] >= 20]` |
| 그룹별 요약 | 피벗 테이블 | `GROUP BY` | `df.groupby("sex")["fare"].mean()` |
| 다른 표 붙이기 | VLOOKUP | `JOIN` | `pd.merge(a, b, on="id")` |
| 같은 작업 반복 | 클릭을 다시 | 쿼리 다시 실행 | 코드 다시 실행 |
| 다룰 수 있는 크기 | 약 100만 행 | 데이터베이스 크기만큼 | 컴퓨터 메모리만큼(수백만~수천만 행) |

SQL을 배웠다면 pandas는 "데이터베이스에서 꺼낸 표를 파이썬 안에서 SQL처럼 다루는 도구"로 이해하면 됩니다. 실무에서는 SQL로 필요한 만큼 꺼내고, pandas로 다듬고 분석하는 식으로 둘을 함께 씁니다.

## 정리

- **pandas** = 표 데이터를 코드로 불러오고 · 고르고 · 정리하고 · 요약하는 라이브러리. `import pandas as pd`
- **DataFrame**(표) = 같은 **index**(행 이름표)를 공유하는 **Series**(열)들의 묶음. 열 하나의 속은 NumPy 배열
- `df.groupby("열")["값 열"].mean()` 한 줄이 엑셀 피벗 테이블 하나
- 클릭 대신 코드로 남기면 질문이 바뀌어도, 다음 달 파일이 와도 그대로 다시 돌릴 수 있습니다
