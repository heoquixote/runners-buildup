데이터가 늘 원하는 모양으로 오지는 않습니다. 하루 24시간 측정값이 한 줄로 길게 오면 "날짜 × 시간" 표로 접어야 비교가 쉽고, 반대로 표를 한 줄로 펴야 하는 함수도 있습니다. 이 레슨에서는 배열의 **모양(shape)**을 바꾸고, 배열을 이어 붙이고, 모양을 바꾼 배열이 원본과 연결되어 있는지 확인합니다.

## reshape: 같은 값을 다른 모양으로

`reshape(행, 열)`은 값의 순서는 그대로 두고 모양만 바꿉니다. 값의 개수가 같아야 합니다. 12개를 `(3, 4)`나 `(4, 3)`으로는 바꿀 수 있지만 `(5, 3)`으로는 못 바꿉니다.

```run
import numpy as np

hourly = np.arange(1, 13)            # 1~12, 값 12개
print(hourly.reshape(3, 4))          # 왼쪽 위부터 행을 따라 채운다
print(hourly.reshape(4, -1).shape)   # -1은 "알아서 계산"
```

값은 **행 방향으로** 차례로 채워집니다. 첫 행이 1~4, 둘째 행이 5~8입니다. `-1`을 쓰면 나머지 크기를 NumPy가 계산합니다. 12개를 4행으로 나누니 열은 3입니다.

실제로 써 봅니다. 사흘 동안 6시간마다 잰 온도 12개가 한 줄로 왔습니다. 하루를 한 행으로 접으면 날짜별 · 시간대별 비교가 됩니다.

```run
import numpy as np

temp = np.array([21.0, 24.5, 27.2, 23.1,
                 20.4, 25.0, 28.1, 22.8,
                 21.5, 24.0, 26.9, 23.4])
day = temp.reshape(3, 4)             # 3일 × 4시간대
print(day.mean(axis=1).round(2))     # 날짜별 평균
print(day.mean(axis=0).round(2))     # 시간대별 평균
```

시간대별 평균을 보면 세 번째 시간대(27.4℃)가 가장 덥습니다. 한 줄로 늘어선 상태에서는 보이지 않던 하루 주기가 표로 접자 바로 보입니다.

## 다시 펴기: ravel과 reshape(-1)

표를 한 줄로 펴려면 `ravel()` 또는 `reshape(-1)`을 씁니다. 결과는 같습니다.

```run
import numpy as np

day = np.array([[1, 2, 3],
                [4, 5, 6]])
print(day.ravel())
print(day.reshape(-1))
```

## 행과 열 바꾸기: T

`.T`는 행과 열을 맞바꿉니다(**전치**). `(2, 3)`이 `(3, 2)`가 됩니다. 엑셀의 "행/열 바꿈 붙여넣기"와 같습니다.

```run
import numpy as np

day = np.array([[1, 2, 3],
                [4, 5, 6]])
print(day.T)
print(day.shape, day.T.shape)
```

## 차원 하나 끼워 넣기: np.newaxis

da-02-1에서 1차원 배열을 세로로 세울 때 `a[:, None]`을 썼습니다. `None` 자리에 `np.newaxis`라고 써도 같은 뜻이고, 이름 그대로 "새 축"을 끼워 넣는다는 의미가 잘 드러납니다.

```run
import numpy as np

a = np.array([10, 20, 30])
print(a.shape)
print(a[:, np.newaxis].shape)        # 세로 (3, 1)
print(a[np.newaxis, :].shape)        # 가로 (1, 3)
```

## 이어 붙이기: concatenate, vstack, hstack

배열 여러 개를 하나로 붙일 때 씁니다.

| 함수 | 방향 | 조건 |
| --- | --- | --- |
| `np.vstack([a, b])` | 아래로 (행 늘림) | 열 개수가 같아야 함 |
| `np.hstack([a, b])` | 옆으로 (열 늘림) | 행 개수가 같아야 함 |
| `np.concatenate([a, b], axis=0 또는 1)` | axis로 지정 | 위와 같음 |

```run
import numpy as np

mon = np.array([[10.1, 10.0], [9.9, 10.2]])    # 월요일 로트 2개 × 측정 2곳
tue = np.array([[10.3, 10.1]])                  # 화요일 로트 1개
print(np.vstack([mon, tue]))                     # 로트를 아래로 추가
print(np.vstack([mon, tue]).shape)

extra = np.array([[0.5], [0.7]])                 # 월요일 로트별 추가 측정 1곳
print(np.hstack([mon, extra]))                   # 측정 열을 옆으로 추가
```

`vstack`은 행을 늘리니 `(2, 2)`와 `(1, 2)`가 붙어 `(3, 2)`가 됐습니다. `hstack`은 행 개수(2)가 같아야 붙습니다. 모양이 맞지 않으면 에러가 나므로, 붙이기 전에 `shape`를 찍어 보세요.

## 조심할 점: 잘라낸 배열은 원본과 연결되어 있습니다

pb-04-3에서 "이름표 두 개, 상자 하나"를 배웠습니다. NumPy에서 **슬라이싱으로 잘라낸 배열**도 원본과 같은 상자를 가리킵니다. 이런 배열을 **뷰(view)**라고 합니다. 뷰를 고치면 원본도 바뀝니다.

```run
import numpy as np

data = np.array([10.1, 9.8, 10.4, 10.0])
first2 = data[:2]          # 뷰: 원본과 연결
first2[0] = 0
print(data)                # 원본도 바뀌었다

data = np.array([10.1, 9.8, 10.4, 10.0])
safe = data[:2].copy()     # 복사본: 따로 떨어진 상자
safe[0] = 0
print(data)                # 원본 그대로
```

파이썬 리스트는 슬라이싱하면 복사본이 생기지만, NumPy는 큰 데이터를 빠르게 다루려고 복사하지 않습니다. 잘라낸 부분을 고쳐 쓸 생각이면 **`.copy()`를 붙이는 습관**을 들이세요. `reshape`나 `.T` 결과도 대부분 뷰입니다. 반대로 불리언 인덱싱(`data[data > 10]`)의 결과는 항상 복사본입니다.

## 정리

- `reshape`는 값 순서를 유지한 채 모양만 바꾸고, `-1`은 크기를 자동 계산합니다
- `ravel`로 펴고, `.T`로 행 · 열을 바꾸고, `np.newaxis`로 축을 끼워 넣습니다
- `vstack`은 아래로, `hstack`은 옆으로 붙입니다
- 슬라이싱 결과는 뷰라 원본과 연결됩니다. 따로 쓰려면 `.copy()`
