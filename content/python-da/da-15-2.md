## 점 구름에 선 하나 긋기

산점도의 점 구름을 보고 "대략 이런 방향"이라고 말하는 대신, 구름 한가운데를 지나는 **추세선**을 그으면 관계를 숫자 하나(기울기)로 말할 수 있습니다. 이 레슨에서는 추세선과 그 주변 띠를 읽는 법, 그리고 추세선을 믿으면 안 되는 경우를 배웁니다.

## regplot: 산점도 + 추세선

`sns.regplot`은 산점도를 그리고, 점들에 가장 잘 맞는 직선(회귀선)과 그 주변의 옅은 띠를 함께 그립니다. 기울기와 절편은 `np.polyfit(x, y, 1)`로 직접 구할 수 있습니다(1은 직선이라는 뜻).

```run
import matplotlib.pyplot as plt
import numpy as np
import seaborn as sns
import pandas as pd

df = pd.read_csv("tips.csv")
ax = sns.regplot(data=df, x="total_bill", y="tip")
slope, intercept = np.polyfit(df["total_bill"], df["tip"], 1)
print("기울기:", round(slope, 3), "/ 절편:", round(intercept, 2))
```

**무엇을 나타내나**

- **선**: 점들 한가운데를 지나는 직선. 각 점에서 선까지의 세로 거리를 모두 합쳐 가장 작아지도록 그은 선입니다.
- **기울기**: x가 1 늘 때 선 위의 y가 얼마나 늘어나나
- **옅은 띠**: 데이터를 다시 모았을 때 **선이** 대략 지나갈 범위(신뢰 구간). 데이터가 적은 양 끝에서 넓어집니다.

**이렇게 읽는다**: 기울기를 "x가 1 늘면 y가 ~ 늘어난다"는 문장으로 바꿉니다.

> 해석: 기울기 0.105는 계산 금액이 1달러 늘 때 팁이 평균 약 0.1달러(10.5센트) 늘어난다는 뜻이다. 계산 금액이 10달러 많은 테이블은 팁이 약 1달러 많다고 기대할 수 있다.

## 선 위와 아래: 잔차

추세선은 "보통이라면 이 정도"를 나타냅니다. 그래서 점이 선보다 **위에 있으면 보통보다 많이**, **아래에 있으면 보통보다 적게** 준 것입니다. 점과 선 사이의 세로 거리를 **잔차**라고 합니다.

```run
import numpy as np
import pandas as pd

df = pd.read_csv("tips.csv")
slope, intercept = np.polyfit(df["total_bill"], df["tip"], 1)
df["expected"] = intercept + slope * df["total_bill"]
df["residual"] = df["tip"] - df["expected"]
print(df.sort_values("residual")[["total_bill", "tip", "expected", "residual"]].iloc[[0, -1]].round(2))
print("선보다 위에 있는 점:", int((df["residual"] > 0).sum()), "/", len(df))
```

> 해석: 32.83달러 계산서에 팁 1.17달러는 선이 기대한 4.37달러보다 3.2달러 적어 가장 아래에 있는 점이다. 반대로 50.81달러에 팁 10달러는 기대보다 3.74달러 많다. 244개 중 112개가 선 위, 나머지가 선 아래에 있어 선이 구름 한가운데를 지나간다.

## 그룹마다 추세선: 기울기 비교

`sns.lmplot`에 `hue=`를 주면 그룹마다 추세선을 따로 긋습니다. 흡연석(Yes)과 금연석(No)을 나눠 봅니다.

```run
import matplotlib.pyplot as plt
import numpy as np
import seaborn as sns
import pandas as pd

df = pd.read_csv("tips.csv")
g = sns.lmplot(data=df, x="total_bill", y="tip", hue="smoker", height=3.5)
for name, part in df.groupby("smoker"):
    print(name, "기울기:", round(np.polyfit(part["total_bill"], part["tip"], 1)[0], 3))
```

**이렇게 읽는다**: 선 높이보다 **기울기 차이**를 먼저 봅니다. 선이 평행하면 두 그룹의 관계가 같고, 기울기가 다르면 x에 따라 두 그룹의 차이가 벌어지거나 줄어듭니다([점 그래프 읽기: pointplot · dot plot](#/l/da-12-4)의 평행 vs 교차와 같은 생각입니다).

> 해석: 금연석의 기울기(0.137)가 흡연석(0.070)의 약 두 배다. 금연석 손님은 금액이 커질수록 팁도 꾸준히 늘지만, 흡연석 손님은 금액이 커져도 팁이 덜 늘어 두 선이 오른쪽으로 갈수록 벌어진다.

**잘못 읽기 쉬운 점**: 흡연석 점들은 선 주위에 넓게 흩어져 있습니다. 기울기가 작다는 것과 **점들이 선에 얼마나 붙어 있나**(관계의 강도)는 다른 이야기입니다. 강도는 [상관계수와 히트맵 읽기](#/l/da-15-3)의 상관계수로 봅니다.

## 직선이 안 맞을 때: 곡선 추세선

[산점도 읽기](#/l/da-15-1)에서 회전 속도와 토크의 관계는 휘어 있었습니다. 휜 구름에 직선을 그으면 어떻게 될까요? `order=2`는 직선 대신 **한 번 휘는 곡선**(2차식)을 긋습니다. 점이 많아 계산이 오래 걸리지 않게 띠는 끕니다(`ci=None`).

```run
import matplotlib.pyplot as plt
import numpy as np
import seaborn as sns
import pandas as pd

df = pd.read_csv("ai4i2020.csv")
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(9, 3.5), sharey=True)
kw = {"scatter_kws": {"s": 3, "alpha": 0.1}, "ci": None, "line_kws": {"color": "red"}}
sns.regplot(data=df, x="rpm", y="torque", ax=ax1, **kw)
ax1.set_title("straight line")
sns.regplot(data=df, x="rpm", y="torque", order=2, ax=ax2, **kw)
ax2.set_title("order=2")
slope, intercept = np.polyfit(df["rpm"], df["torque"], 1)
print("직선이 예측한 2,800rpm의 토크:", round(intercept + slope * 2800, 1))
```

**이렇게 읽는다**: 추세선이 잘 맞는지는 **선의 양 끝**을 보면 압니다. 점들이 양 끝에서 모두 선 위에 있거나 모두 아래에 있으면, 선의 모양이 데이터와 맞지 않는 것입니다.

> 해석: 직선(왼쪽)은 가운데는 그럭저럭 지나가지만, 양 끝에서 점들이 모두 선보다 위에 있다. 2,800rpm에서는 토크가 −21이라는 불가능한 값을 예측한다. 곡선(오른쪽)은 1,200~2,300rpm 구간에서 점 구름을 잘 따라가므로, 이 관계는 곡선으로 말해야 한다. 다만 2,400rpm을 넘으면 곡선이 다시 올라가는데 실제 점들은 계속 내려간다. 2차 곡선은 "한 번 휘는 모양"을 억지로 맞춘 것이라, 점이 드문 끝부분에서는 곡선도 틀릴 수 있다.

## 추세선을 잘못 읽기 쉬운 점

**① 데이터 밖까지 선을 늘리기(외삽)**: 팁 데이터의 계산 금액은 3~51달러입니다. 같은 직선으로 100달러 계산서의 팁을 계산하면 11.4달러가 나오지만, 그 범위에는 데이터가 하나도 없어 **선이 맞는지 알 수 없습니다.** 추세선은 점이 있는 범위 안에서만 읽습니다.

**② 띠를 점들의 범위로 읽기**: 옅은 띠는 "**선이** 있을 법한 범위"이지 "**점들이** 있을 범위"가 아닙니다. 대부분의 점은 띠 바깥에 있습니다.

**③ 튀는 점 하나에 끌려가는 선**: 추세선은 멀리 떨어진 점 하나에도 크게 기울어질 수 있습니다. 이상치가 있으면 그 점을 빼고 그린 선과 비교해 봅니다.

**④ 선이 있으면 원인이 있다고 읽기**: 추세선은 "함께 움직이는 정도"를 요약할 뿐입니다. "계산 금액을 올리면 팁이 오른다"는 원인 이야기는 그래프가 증명하지 않습니다.

## 정리: 추세선 읽기

| 단계 | 볼 것 | 해석 문장 틀 |
| --- | --- | --- |
| 1. 기울기 | 선의 방향과 가파름 | "x가 1 늘면 y가 평균 ~ 늘어난다" |
| 2. 잔차 | 선 위·아래의 점 | "~는 기대보다 n만큼 많았다" |
| 3. 그룹 비교 | 선끼리 기울기 | "A 그룹이 기울기가 두 배다" |
| 4. 맞는지 | 양 끝의 점이 한쪽에 몰렸나 | "직선이 맞지 않아 곡선으로 봐야 한다" |
| 확인 | 데이터 범위 밖이 아닌가, 이상치에 끌렸나 | |

| 그래프 | 코드 |
| --- | --- |
| 산점도 + 직선 | `sns.regplot(data=, x=, y=)` |
| 그룹별 직선 | `sns.lmplot(data=, x=, y=, hue=)` |
| 곡선 | `sns.regplot(..., order=2)` |
| 기울기·절편 | `np.polyfit(x, y, 1)` |
