받은 데이터가 처음부터 깨끗한 경우는 거의 없습니다. 분석가의 시간 대부분은 빈칸을 처리하고, 글자로 된 숫자를 고치고, 같은 값을 하나로 맞추는 데 쓰입니다. 이번 레슨은 **어떤 방법을 왜 고르는지**에 초점을 맞춥니다.

## 결측치 확인

현장 데이터에는 센서 오류, 미응답으로 빈칸(NaN)이 생깁니다. 먼저 **어디에 몇 개** 있는지 봅니다.

```run
import numpy as np
import pandas as pd
df = pd.DataFrame({'temp': [201.2, np.nan, 203.5, np.nan, 204.1], 'pressure': [1.02, 1.01, np.nan, 1.03, 1.04]})
print(df.isna().sum())
print(df.isna().sum().sum(), "칸 비어 있음")
```

`isna()`는 칸마다 True/False를 돌려주고, `sum()`이 True의 개수를 셉니다. [NumPy 배열과 연산](#/l/da-01-1)에서 본 원리와 같습니다.

실제 데이터에서는 개수와 **비율**을 함께 봅니다. 비율에 따라 처리 방법이 달라지기 때문입니다.

```run
import pandas as pd
df = pd.read_csv("titanic.csv")
missing = df.isna().sum()
ratio = (df.isna().mean() * 100).round(1)
print(pd.DataFrame({'count': missing, 'ratio_%': ratio}).query("count > 0"))
```

`deck`은 77.2%가 비어 있어 채우기 어렵습니다. `age`는 19.9%, `embarked`는 0.2%입니다. 세 열의 처리 방법은 서로 달라야 합니다.

| 결측 비율 | 일반적인 판단 |
| --- | --- |
| 아주 적음 (5% 미만) | 해당 행 삭제 또는 대표값으로 채우기 |
| 중간 | 대표값이나 그룹별 값으로 채우고 영향 확인 |
| 대부분 비어 있음 | 열을 쓰지 않거나, 빈칸 여부를 새 정보로 활용 |

## 채울까, 지울까

| 방법 | 코드 | 언제 |
| --- | --- | --- |
| 대표값으로 채우기 | `fillna(df['a'].median())` | 무작위로 빠진 수치 |
| 앞 값으로 채우기 | `ffill()` | 시간 순서 센서 값 |
| 행 지우기 | `dropna()` | 결측 행이 아주 적을 때 |

평균은 이상치에 끌려가므로, 치우친 데이터는 **중앙값**으로 채우는 편이 안전합니다.

```run
import numpy as np
import pandas as pd
s = pd.Series([201.2, np.nan, 203.5, np.nan, 204.1])
print(s.fillna(s.mean()).round(2).tolist())
print(s.ffill().tolist())
print(s.dropna().tolist())
```

타이타닉의 운임으로 평균과 중앙값의 차이를 확인해 봅니다. 나이는 등급별로 다르므로 그룹 중앙값으로 채우면 더 자연스럽습니다.

```run
import pandas as pd
df = pd.read_csv("titanic.csv")
print(round(df['fare'].mean(), 2), round(df['fare'].median(), 2))

print(df.groupby('class')['age'].median())
age = df['age'].fillna(df.groupby('class')['age'].transform('median'))
print(df['age'].isna().sum(), "→", age.isna().sum())
```

운임 평균은 32.2인데 중앙값은 14.45입니다. 비싼 표 몇 장이 평균을 끌어올린 것입니다. 나이 중앙값은 1등석 37세, 2등석 29세, 3등석 24세로 다릅니다. `transform`은 [groupby와 pivot_table](#/l/da-06-1)에서 자세히 배웁니다.

어떤 방법이 항상 옳지는 않습니다. `dropna()`는 편하지만 행을 잃습니다. 타이타닉에서 `deck`까지 포함해 지우면 어떻게 되는지 보세요.

```run
import pandas as pd
df = pd.read_csv("titanic.csv")
print(len(df), "→", len(df.dropna()))
print(len(df), "→", len(df.dropna(subset=['age'])))
```

891행이 182행으로 줄어듭니다. `subset`으로 필요한 열만 지정해야 714행을 지킬 수 있습니다.

## 중복 확인

같은 행이 두 번 들어오면 합계가 부풀려집니다. `duplicated()`로 세고 `drop_duplicates()`로 지웁니다.

```run
import pandas as pd
df = pd.DataFrame({'lot': ['L1', 'L2', 'L2', 'L3'], 'qty': [100, 120, 120, 90]})
print(df.duplicated().sum(), "행 중복")
clean = df.drop_duplicates()
print(df['qty'].sum(), "→", clean['qty'].sum())
print(df.drop_duplicates(subset='lot', keep='last'))
```

## 형변환과 문자열 정리

엑셀에서 옮긴 숫자는 `'1,250'`, `'₩39,000'`처럼 문자열인 경우가 많습니다. `.str` 메서드로 정리한 뒤 `astype`으로 바꿉니다. 값마다 규칙을 적용할 때는 `apply(lambda x: ...)`.

```run
import pandas as pd
df = pd.DataFrame({'qty': ['1,250', '980', '1,105'], 'rate': ['1.8%', '2.6%', '0.9%']})
qty = df['qty'].str.replace(',', '').astype(int)
rate = df['rate'].str.rstrip('%').astype(float)
print(qty.tolist(), qty.sum())
print(rate.apply(lambda r: 'NG' if r > 2.0 else 'OK').tolist())
```

같은 뜻인데 표기가 다른 값은 그룹이 나뉘어 집계가 틀어집니다. 공백을 지우고 대소문자를 맞춘 뒤 `map`으로 정리합니다. 숫자로 못 바꾸는 값이 섞였을 때는 `pd.to_numeric`의 `errors='coerce'`가 그 칸을 NaN으로 바꿔 줍니다.

```run
import pandas as pd
line = pd.Series([' A', 'a', 'B ', 'b', 'A'])
print(line.value_counts())
clean = line.str.strip().str.upper()
print(clean.value_counts())

print(clean.map({'A': '1공장', 'B': '2공장'}).tolist())

raw = pd.Series(['12.5', '13.1', '오류', '12.9'])
num = pd.to_numeric(raw, errors='coerce')
print(num.tolist(), num.isna().sum(), "개 변환 실패")
```

## 전처리 순서

1. `info()`, `isna().sum()`으로 상태를 봅니다
2. 자료형을 바로잡습니다 (글자로 된 숫자, 날짜)
3. 표기를 통일하고 중복을 지웁니다
4. 결측을 처리합니다
5. 처리 전후 행 수와 합계를 비교합니다
