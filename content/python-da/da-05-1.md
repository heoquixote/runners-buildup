## 결측치 확인

현장 데이터에는 센서 오류, 미응답으로 빈칸(NaN)이 생깁니다. 먼저 **어디에 몇 개** 있는지 봅니다.

```run
import numpy as np
import pandas as pd
df = pd.DataFrame({'temp': [201.2, np.nan, 203.5, np.nan, 204.1], 'pressure': [1.02, 1.01, np.nan, 1.03, 1.04]})
print(df.isna().sum())
print(df.isna().sum().sum(), "칸 비어 있음")
```

## 채울까, 지울까

| 방법 | 코드 | 언제 |
| --- | --- | --- |
| 대표값으로 채우기 | `fillna(df['a'].median())` | 무작위로 빠진 수치 |
| 앞 값으로 채우기 | `ffill()` | 시간 순서 센서 값 |
| 행 지우기 | `dropna()` | 결측 행이 아주 적을 때 |

평균은 이상치에 끌려가므로, 치우친 데이터는 **중앙값**으로 채우는 편이 안전합니다.

```run
import numpy as np
import pandas as pd
s = pd.Series([201.2, np.nan, 203.5, np.nan, 204.1])
print(s.fillna(s.mean()).round(2).tolist())
print(s.ffill().tolist())
print(s.dropna().tolist())
```

## 형변환과 문자열 정리

엑셀에서 옮긴 숫자는 `'1,250'`, `'₩39,000'`처럼 문자열인 경우가 많습니다. `.str` 메서드로 정리한 뒤 `astype`으로 바꿉니다. 값마다 규칙을 적용할 때는 `apply(lambda x: ...)`.

```run
import pandas as pd
df = pd.DataFrame({'qty': ['1,250', '980', '1,105'], 'rate': ['1.8%', '2.6%', '0.9%']})
qty = df['qty'].str.replace(',', '').astype(int)
rate = df['rate'].str.rstrip('%').astype(float)
print(qty.tolist(), qty.sum())
print(rate.apply(lambda r: 'NG' if r > 2.0 else 'OK').tolist())
```
