## 비교: "어느 쪽이 더 큰가?"

데이터를 보며 가장 많이 던지는 질문은 **비교**입니다. "어느 반 평균이 높지?", "어느 요일에 손님이 많지?", "1등실과 3등실 생존율은 얼마나 다르지?" DAY 03에서는 비교에 쓰는 그래프를 모두 모아, 각 그래프를 **어떻게 읽고 해석하는지**까지 배웁니다.

이 트랙의 모든 그래프는 같은 네 칸으로 설명합니다.

| 칸 | 내용 |
| --- | --- |
| **무엇을 나타내나** | 축, 막대·점·선·색 하나가 각각 무엇인지 |
| **이렇게 읽는다** | 눈으로 볼 순서 |
| **해석 문장 예** | 실행 결과 숫자를 넣은 완성 문장 |
| **잘못 읽기 쉬운 점** | 자주 하는 오독과 바로잡는 법 |

비교 그래프의 기본은 **막대 그래프**입니다. 막대 그래프는 "길이"로 비교하는 그래프라서, 사람 눈이 가장 정확하게 읽을 수 있는 그래프이기도 합니다.

## 세로 막대 그래프

타이타닉 승객 수를 객실 등급별로 세어 막대로 그려 봅니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("titanic.csv")
counts = df["class"].value_counts().reindex(["First", "Second", "Third"])
fig, ax = plt.subplots(figsize=(5, 3))
ax.bar(counts.index, counts.values)
ax.set_ylabel("Passengers")
print(counts)
```

**무엇을 나타내나**

- x축: 범주(객실 등급). 막대 하나 = 범주 하나
- y축: 값(승객 수). **막대의 길이 = 값의 크기**
- 막대 사이 간격은 의미가 없습니다. 범주는 순서대로 이어진 숫자가 아니니까요.

**이렇게 읽는다**

1. 가장 긴 막대와 가장 짧은 막대를 찾는다.
2. 둘의 차이를 **"몇 개 더"**와 **"몇 배"** 두 가지로 말해 본다.
3. 길이가 비슷한 막대끼리 묶어 본다.
4. y축이 0에서 시작하는지 확인한다.

> 해석: 3등실 승객이 491명으로 가장 많고, 2등실이 184명으로 가장 적다. 3등실은 1등실(216명)보다 275명 많아 약 2.3배다. 1등실과 2등실은 비슷한 규모다.

"몇 개 더"만 말하면 크기 감이 안 오고, "몇 배"만 말하면 실제 규모를 모릅니다. 둘을 같이 쓰는 습관을 들이세요.

## 막대는 0에서 시작해야 한다

막대 그래프는 **길이**를 비교합니다. 그런데 y축이 0이 아닌 곳에서 시작하면, 막대의 아랫부분이 잘려 길이 비율이 망가집니다.

::figure{src="content/img/viz/viz02-bar-zero.svg" alt="같은 두 값 96과 100을 y축 95부터 그리면 다섯 배 차이처럼 보이고, 0부터 그리면 거의 같아 보인다" caption="막대 축을 자르면 4% 차이가 5배처럼 보입니다."}

같은 데이터를 두 가지로 그려 봅니다.

```run
import matplotlib.pyplot as plt

shops = ["A", "B", "C"]
score = [4.5, 4.6, 4.8]
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(8, 3))
ax1.bar(shops, score)
ax1.set_ylim(4.4, 4.85)
ax1.set_title("Starts at 4.4")
ax2.bar(shops, score)
ax2.set_title("Starts at 0")
print("C는 A보다", round((4.8 - 4.5) / 4.5 * 100, 1), "% 높다")
```

왼쪽은 C 가게 평점이 A의 몇 배처럼 보이지만, 실제로는 6.7% 높을 뿐입니다.

**잘못 읽기 쉬운 점**: 막대 그래프를 보면 **제일 먼저 y축의 시작값**을 확인하세요. 0이 아니라면 막대 길이 비율로 해석하면 안 되고, 축에 적힌 숫자로 다시 계산해야 합니다. 작은 차이를 꼭 보여 줘야 한다면 막대 대신 점 그래프(da-12-3)를 쓰는 것이 정직합니다.

## 가로 막대와 정렬

범주가 많거나 이름이 길면 **가로 막대**(`ax.barh`)가 읽기 쉽습니다. 그리고 막대를 **크기순으로 정렬**하면 순위가 바로 보입니다. 펭귄 세 종 × 세 섬의 조합별 마릿수를 세어 봅니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("penguins.csv")
counts = (df["species"] + " / " + df["island"]).value_counts().sort_values()
fig, ax = plt.subplots(figsize=(6, 3))
ax.barh(counts.index, counts.values, color="slateblue")
ax.set_xlabel("Penguins")
print(counts)
```

`sort_values()`로 작은 값부터 정렬했고, `barh`는 첫 값을 맨 아래에 그리므로 가장 큰 조합이 맨 위에 옵니다.

**이렇게 읽는다**: 정렬된 막대는 위에서 아래로 순위를 읽고, 막대 길이가 **뚝 떨어지는 곳**을 찾습니다. 그곳이 "주요 그룹"과 "나머지"의 경계입니다.

> 해석: Gentoo / Biscoe 조합이 124마리로 가장 많고, Chinstrap / Dream(68마리)이 그다음이다. Adelie는 세 섬에 고르게 나뉘어(44~56마리) 있어 섬 하나에 몰려 사는 다른 두 종과 다르다.

**잘못 읽기 쉬운 점**: 정렬하지 않은 막대(알파벳 순서 등)에서 순위를 읽으려면 눈이 왔다 갔다 하다가 비슷한 막대를 잘못 고르기 쉽습니다. 순서가 정해진 범주(요일, 학년, 등급)가 아니라면 **크기순 정렬**이 기본입니다.

## 막대 위에 값 쓰기

길이만으로 정확한 숫자를 읽기는 어렵습니다. `ax.bar_label`로 막대 끝에 값을 써 주면 해석 문장을 바로 만들 수 있습니다. 등급별 **생존율**을 그려 봅니다. 0과 1로 된 `survived`의 평균이 곧 생존율입니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("titanic.csv")
rate = df.groupby("class")["survived"].mean().reindex(["First", "Second", "Third"])
fig, ax = plt.subplots(figsize=(5, 3))
bars = ax.bar(rate.index, rate.values, color="orange")
ax.bar_label(bars, labels=[f"{v:.0%}" for v in rate.values])
ax.set_ylim(0, 1)
print(rate.round(3))
```

> 해석: 1등실 생존율은 63%로 3등실(24%)의 약 2.6배다. 등급이 낮아질수록 생존율이 계단처럼 낮아진다(63% → 47% → 24%).

## countplot: 개수를 세는 막대

seaborn의 `countplot`은 표를 넘기면 범주별 **행 개수**를 세어 막대로 그립니다. 집계를 따로 할 필요가 없어 데이터를 처음 볼 때 많이 씁니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("tips.csv")
ax = sns.countplot(data=df, x="day", order=["Thur", "Fri", "Sat", "Sun"])
ax.bar_label(ax.containers[0])
print(df["day"].value_counts())
```

**무엇을 나타내나**: 막대 높이 = 그 범주의 **행 개수**(여기서는 계산서 장수). 값의 크기(금액)는 전혀 반영되지 않습니다.

> 해석: 계산서는 토요일 87장, 일요일 76장, 목요일 62장이고 금요일은 19장뿐이다. 금요일 데이터가 다른 요일의 4분의 1 수준이라, 금요일에 대한 평균이나 비율은 다른 요일보다 덜 믿을 만하다.

countplot은 "어느 범주가 많은가"를 보여 주는 동시에, **뒤에 나올 다른 비교가 얼마나 믿을 만한지**(표본 수)를 알려 주는 역할도 합니다.

## 개수가 많다 ≠ 비율이 높다

비교 그래프에서 가장 흔한 오독은 **개수와 비율을 헷갈리는 것**입니다. 타이타닉 생존자 수와 생존율을 나란히 그려 봅니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("titanic.csv")
g = df.groupby("class")["survived"].agg(["sum", "mean"]).reindex(["First", "Second", "Third"])
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(8, 3))
ax1.bar(g.index, g["sum"])
ax1.set_title("Survivors (count)")
ax2.bar(g.index, g["mean"], color="orange")
ax2.set_title("Survival rate")
print(g.round(2))
```

생존자 **수**는 1등실 136명, 3등실 119명으로 비슷해 보입니다. 하지만 3등실은 승객 자체가 491명으로 많았기 때문이고, 생존**율**은 63% 대 24%로 크게 다릅니다.

**잘못 읽기 쉬운 점**: "3등실 생존자도 1등실만큼 많았으니 차이가 없다"는 잘못된 해석입니다. 그룹 크기가 다를 때는 **개수가 아니라 비율로 비교**해야 합니다. 그래프 제목이나 축 이름에 "count"인지 "rate"인지 꼭 적으세요.

## 정리: 막대 그래프 읽기

| 단계 | 확인할 것 |
| --- | --- |
| 1. 축 | y축이 0에서 시작하나? 단위는? 개수인가 비율인가 평균인가? |
| 2. 순위 | 가장 긴·짧은 막대, 정렬돼 있나 |
| 3. 차이 | "몇 개 더"와 "몇 배"를 함께 |
| 4. 무리 | 비슷한 막대끼리, 길이가 뚝 떨어지는 경계 |
| 5. 믿음 | 막대마다 데이터가 충분한가(countplot으로 확인) |

| 그래프 | 코드 | 언제 |
| --- | --- | --- |
| 세로 막대 | `ax.bar(범주, 값)` | 범주 2~7개 |
| 가로 막대 | `ax.barh(범주, 값)` + 정렬 | 범주가 많거나 이름이 길 때, 순위 |
| 값 표시 막대 | `ax.bar_label(막대)` | 정확한 숫자가 필요할 때 |
| 개수 막대 | `sns.countplot(data=, x=)` | 범주별 행 개수, 표본 수 확인 |
