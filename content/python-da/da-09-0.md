## 시작하기 전에

엑셀에서 차트를 만들 때는 범위를 드래그하고 → 차트 종류를 고르고 → 제목과 축을 클릭해서 고칩니다. 한 번은 편하지만, 이런 상황에서는 금방 힘들어집니다.

- 공장 라인 20개마다 같은 모양의 그래프가 필요할 때
- 매주 새 데이터가 들어와 같은 차트를 다시 그려야 할 때
- 분석 결과를 보고서에 넣으려고 같은 크기 · 같은 색으로 맞춰야 할 때

코드로 그래프를 그리면 **한 번 적은 코드를 데이터만 바꿔 몇 번이고 다시 돌릴 수 있습니다**. 파이썬에서 그 일을 맡는 기본 도구가 **matplotlib**입니다.

## matplotlib은 무엇인가

**matplotlib**(맷플롯립)은 **파이썬에서 선 · 막대 · 산점도 · 히스토그램 같은 그래프를 그리는 가장 기본 라이브러리**입니다. 이름은 당시 과학자들이 많이 쓰던 계산 프로그램 **MATLAB**의 그래프 기능(**plot**)을 파이썬 **lib**rary로 옮겼다는 뜻에서 왔습니다.

보통 그래프를 그리는 부분인 `pyplot`만 `plt`라는 별명으로 불러옵니다. `import matplotlib.pyplot as plt`는 데이터 분석 코드 맨 위에 거의 항상 보이는 줄입니다.

::figure{src="content/img/libs/lib-map-matplotlib.svg" alt="파이썬 위에 NumPy, 그 위에 pandas, matplotlib, scikit-learn, matplotlib 위에 seaborn이 있고 오른쪽에 PyTorch가 있다. matplotlib이 강조되어 있다" caption="matplotlib은 NumPy 위에서 그래프를 그리고, seaborn은 다시 matplotlib 위에 지어졌습니다."}

가장 짧은 그래프는 세 줄이면 됩니다. x값 목록과 y값 목록을 주면 점을 이어 선을 그립니다.

```run
import matplotlib.pyplot as plt

x = [1, 2, 3, 4]
y = [10, 30, 20, 40]
plt.plot(x, y)
plt.title("My first plot")
print("points:", len(x))
```

x가 1, 2, 3, 4일 때 y가 10, 30, 20, 40인 점 네 개가 선으로 이어졌습니다. 제목이 영어인 것은 이 사이트의 브라우저 파이썬에 한글 글꼴이 없어서입니다. 내 컴퓨터에서는 한글 글꼴을 설정하면 한글도 쓸 수 있습니다.

## 그림을 그리는 것은 결국 matplotlib

앞으로 그래프를 그리는 길은 여러 가지입니다. `plt.plot`처럼 직접 그릴 수도 있고, pandas 표에서 `df.plot()`을 부를 수도 있고, 다음 PART의 seaborn을 쓸 수도 있습니다. 그런데 **어느 길로 가든 마지막에 실제로 그림을 그리는 것은 matplotlib**입니다.

::figure{src="content/img/libs/mpl-layers.svg" alt="plt.plot, df.plot, sns.barplot 세 가지 코드가 모두 matplotlib으로 들어가고, matplotlib의 Figure 도화지 안에 Axes 그래프 칸 두 개가 있으며, 결과는 화면이나 PNG·PDF·SVG 파일로 나간다" caption="pandas와 seaborn은 matplotlib을 대신 불러 주는 지름길입니다. 그래서 matplotlib의 뼈대를 알면 어느 도구로 그린 그래프든 고칠 수 있습니다."}

pandas로 연도별 비행기 승객 수를 그려 보고, 돌려받은 것이 무엇인지 확인합니다.

```run
import pandas as pd

df = pd.read_csv("flights.csv")
yearly = df.groupby("year")["passengers"].sum()
ax = yearly.plot(marker="o", title="Passengers per year")
print(type(ax).__name__)
print(yearly.head(3))
```

pandas가 그려 준 그래프인데 돌려받은 것은 matplotlib의 `Axes`(그래프 칸)입니다. 그래서 여기에 `ax.set_ylabel(...)`처럼 matplotlib 명령을 그대로 이어 쓸 수 있습니다. 1949년 1,520(천 명)에서 시작해 해마다 늘어나는 모습이 한눈에 보입니다.

## 그릴 수 있는 것

matplotlib은 데이터 분석에 필요한 기본 차트를 거의 다 그립니다. 차트마다 답하는 질문이 다릅니다.

::figure{src="content/img/libs/mpl-gallery.svg" alt="선 그래프 ax.plot 추이, 막대 그래프 ax.bar 비교, 산점도 ax.scatter 관계, 히스토그램 ax.hist 분포, 상자그림 ax.boxplot 분포 비교, 파이 ax.pie 구성" caption="기본 차트 여섯 가지와 그리는 명령. 이름이 거의 그대로 명령이 됩니다."}

한 도화지에 그래프 칸 두 개를 만들어 막대와 산점도를 나란히 그려 봅니다. 명령 이름만 바뀌고 순서는 같습니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("flights.csv")
y1960 = df[df["year"] == 1960]
fig, axes = plt.subplots(1, 2, figsize=(9, 3))
axes[0].bar(y1960["month"].str[:3], y1960["passengers"])
axes[0].set_title("1960 by month")
axes[1].scatter(df["year"], df["passengers"], s=8)
axes[1].set_title("All months, 1949-1960")
print(y1960["passengers"].max())
```

왼쪽은 1960년 월별 승객(막대, 비교)으로 7월이 622(천 명)로 가장 많습니다. 오른쪽은 12년 동안 모든 달의 승객(산점도, 관계)입니다. `fig`(도화지)와 `axes`(그래프 칸들)라는 이름이 처음 나왔는데, 바로 다음 레슨 [그래프의 뼈대: fig와 ax](#/l/da-09-1)에서 하나씩 뜯어봅니다.

## matplotlib의 역사

| 해 | 일 |
| --- | --- |
| 2003 | 뇌 신호를 연구하던 신경과학자 **존 헌터**(John D. Hunter)가 뇌전증 환자의 뇌파 데이터를 그리려고 만들어 공개. 비싼 MATLAB 대신 파이썬으로 같은 그래프를 그리고 싶었음 |
| 2008 | 화성 탐사선 피닉스의 착륙 데이터 시각화에 쓰임 |
| 2012 | 존 헌터 별세. 이후 전 세계 개발자 공동체가 이어서 관리 |
| 2017 | **matplotlib 2.0**: 기본 색과 스타일을 지금의 모습으로 새로 바꿈 |
| 2019 | 블랙홀 첫 사진을 만드는 과정의 그래프에 쓰임 |

20년 넘게 쓰인 덕분에, 그래프에 관한 거의 모든 질문은 검색하면 matplotlib 예제가 나옵니다. 공식 홈페이지의 [예제 갤러리](https://matplotlib.org/stable/gallery/index.html)에서 원하는 모양을 찾아 코드를 가져다 쓰는 것도 흔한 방법입니다.

## 다른 시각화 도구와 비교하면

| 도구 | 방식 | 잘 맞는 일 |
| --- | --- | --- |
| 엑셀 차트 | 클릭 | 한두 개를 빠르게, 보고서에 바로 |
| Tableau · Power BI | 끌어다 놓기 | 대시보드, 여러 사람이 보는 화면 |
| **matplotlib** | 코드 | 원하는 모양을 세세하게, 같은 그래프 대량 생산, 논문 · 보고서 그림 |
| seaborn | 코드 (matplotlib 위) | 표를 넘겨 통계 그래프를 짧게 |
| plotly | 코드 | 마우스로 확대 · 값 확인이 되는 웹 그래프 |

matplotlib은 자유도가 가장 높은 대신 코드가 조금 깁니다. 그래서 실무에서는 seaborn이나 pandas로 빠르게 그리고, 마지막 다듬기를 matplotlib 명령으로 하는 경우가 많습니다.

## 정리

- **matplotlib** = 파이썬 그래프의 기본 도구. `import matplotlib.pyplot as plt`
- pandas `.plot()`과 seaborn도 속에서는 matplotlib으로 그린다. 그래서 matplotlib 명령으로 어느 그래프든 다듬을 수 있다
- 선 `plot` · 막대 `bar` · 산점도 `scatter` · 히스토그램 `hist`: 명령 이름만 바뀌고 순서는 같다
- 클릭 대신 코드로 그리면 데이터가 바뀌어도 같은 그래프를 다시 그릴 수 있다
