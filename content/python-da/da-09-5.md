## 시작하기 전에

앞 페이지 [matplotlib 소개: 파이썬 그래프의 바탕](#/l/da-09-0)에서 matplotlib이 무엇이고 그래프 몇 개가 어떻게 그려지는지 봤습니다. 이번 페이지는 **차트 도감**입니다. 식당 메뉴판에 음식 사진 · 이름 · 짧은 설명이 붙어 있듯이, matplotlib으로 그릴 수 있는 대표 차트를 그림 · 명령 · 쓰임새로 한눈에 모았습니다.

전부 외울 필요는 없습니다. "이런 그래프가 있었지" 하고 떠올릴 수 있으면 충분하고, 그래프가 필요할 때 다시 와서 찾아보면 됩니다.

## 카드 읽는 법

카드 하나에는 네 가지가 있습니다.

| 칸 | 뜻 | 예 |
| --- | --- | --- |
| 그림 | 이 명령이 실제로 그린 모양 | 막대 다섯 개 |
| 이름 | 차트의 우리말 이름 | 막대 그래프 |
| 명령 | 그래프 칸 `ax`에 내리는 명령과 꼭 넣어야 하는 재료 | `ax.bar(x, height)` |
| 언제 쓰나 | 이 차트가 답하는 질문 | 범주끼리 크기를 비교할 때 |

명령 칸의 `ax.bar(x, height)`는 "그래프 칸(`ax`)에 막대(`bar`)를 그려라, 재료는 위치 `x`와 높이 `height`"라는 뜻입니다. 괄호 안 이름은 matplotlib 공식 설명서에 적힌 재료 이름을 그대로 옮겼습니다. 썸네일은 모두 이 사이트에서 연습용 숫자로 직접 그린 그림입니다.

어떤 차트든 그리는 순서는 같습니다. **① 도화지와 그래프 칸 만들기 → ② 명령 하나로 그리기 → ③ 제목 · 축 이름 달기**. 아래 셀에서 ②번 줄만 바꾸면 이 페이지의 어떤 차트든 그릴 수 있습니다.

```run
import matplotlib.pyplot as plt

fig, ax = plt.subplots(figsize=(5, 3))
ax.bar(["A", "B", "C"], [5, 8, 3])
ax.set_title("Same 3 steps for every chart")
print(len(ax.patches), "bars")
```

막대 3개가 그려졌습니다. `ax.patches`는 그래프 칸에 그려진 도형(막대 · 조각) 목록이라 개수를 세면 막대 수가 나옵니다. 이제 질문별로 차트를 살펴봅니다.

## 비교: 어느 쪽이 더 큰가

범주(라인 A · B · C, 요일, 나라처럼 이름으로 나뉘는 값)마다 숫자 하나씩을 나란히 놓고 크기를 견줄 때 씁니다.

::chart{src="content/img/gallery/mpl-bar.png" name="막대 그래프" sig="ax.bar(x, height)" desc="범주마다 값 하나를 막대 높이로 비교합니다. 막대는 길이로 읽으므로 y축은 0에서 시작해야 합니다." more="자세히: [막대 그래프 읽기](#/l/da-12-1)"}
::chart{src="content/img/gallery/mpl-barh.png" name="가로 막대 그래프" sig="ax.barh(y, width)" desc="범주 이름이 길거나 개수가 많을 때 막대를 눕힙니다. 큰 값부터 정렬하면 순위가 바로 보입니다." more="자세히: [막대 그래프 읽기](#/l/da-12-1)"}
::chart{src="content/img/gallery/mpl-errorbar.png" name="오차 막대" sig="ax.errorbar(x, y, yerr)" desc="평균 같은 대표값 옆에 '얼마나 흔들릴 수 있는지'를 위아래 선으로 붙입니다. 두 그룹 차이가 믿을 만한지 볼 때 씁니다." more="자세히: [평균과 오차 막대 읽기](#/l/da-12-2)"}

요일별 계산서 수를 세로 막대와 가로 막대로 나란히 그려 봅니다. 재료는 같고 명령 이름과 재료 이름만 바뀝니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("tips.csv")
counts = df["day"].value_counts()
fig, axes = plt.subplots(1, 2, figsize=(8, 3))
axes[0].bar(counts.index, counts.values)
axes[1].barh(counts.index, counts.values)
print(counts)
```

토요일(Sat) 87장이 가장 많고 금요일(Fri) 19장이 가장 적습니다. 범주가 네 개뿐이라 세로 막대도 충분히 읽히지만, 범주가 열 개를 넘거나 이름이 길어지면 가로 막대가 훨씬 읽기 편합니다.

## 추이: 시간에 따라 어떻게 변하나

x축이 시간(날짜 · 월 · 연도)이고, 값이 어느 방향으로 움직이는지 볼 때 씁니다.

::chart{src="content/img/gallery/mpl-plot.png" name="선 그래프" sig="ax.plot(x, y)" desc="점을 순서대로 이어 오르내림을 보여 줍니다. 시간 흐름, 여러 계열의 추세 비교에 가장 많이 씁니다." more="자세히: [선 그래프 읽기](#/l/da-13-1)"}
::chart{src="content/img/gallery/mpl-step.png" name="계단 그래프" sig="ax.step(x, y)" desc="값이 다음 시점까지 그대로 있다가 한 번에 바뀌는 데이터(요금제, 재고, 누적 개수)를 그릴 때 씁니다."}
::chart{src="content/img/gallery/mpl-fill_between.png" name="영역 채우기" sig="ax.fill_between(x, y1, y2)" desc="두 선 사이를 색으로 칠합니다. 예측값의 위아래 범위, 목표 구간처럼 '띠'를 보여 줄 때 씁니다." more="자세히: [추세를 또렷하게: 이동평균 · 로그 축 · 기준선](#/l/da-13-2)"}

1949 ~ 1960년 해마다 비행기 승객 합계를 선으로 그리고, 같은 값을 계단 모양으로도 그려 봅니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("flights.csv")
yearly = df.groupby("year")["passengers"].sum()
fig, ax = plt.subplots(figsize=(6, 3))
ax.plot(yearly.index, yearly.values, marker="o", label="plot")
ax.step(yearly.index, yearly.values, where="post", label="step")
ax.legend()
print(yearly.iloc[0], "->", yearly.iloc[-1])
```

승객 합계가 1,520에서 5,714(천 명)로 12년 만에 약 3.8배가 되었습니다. 선 그래프는 해와 해 사이를 비스듬히 이어 "꾸준히 늘었다"는 느낌을 주고, 계단 그래프는 "한 해 동안은 같은 값, 해가 바뀌면 껑충"이라는 느낌을 줍니다. 승객 수처럼 1년 내내 조금씩 바뀐 값에는 선 그래프가 어울립니다.

## 분포: 값들이 어떻게 퍼져 있나

한 열의 값이 어디에 몰려 있고, 얼마나 넓게 퍼져 있고, 튀는 값이 있는지 볼 때 씁니다.

::chart{src="content/img/gallery/mpl-hist.png" name="히스토그램" sig="ax.hist(x, bins)" desc="값의 범위를 구간(bins)으로 나눠 구간마다 몇 개인지 막대로 셉니다. 분포 모양을 처음 볼 때 가장 먼저 그립니다." more="자세히: [히스토그램 읽기](#/l/da-14-1)"}

::chart{src="content/img/gallery/mpl-violinplot.png" name="바이올린 그래프" sig="ax.violinplot(dataset)" desc="분포 모양을 좌우 대칭 곡선으로 그립니다. 상자그림이 감추는 봉우리 두 개 같은 모양까지 보여 줍니다." more="자세히: [바이올린 그래프 읽기](#/l/da-14-4)"}
::chart{src="content/img/gallery/mpl-ecdf.png" name="누적 분포(ECDF)" sig="ax.ecdf(x)" desc="'이 값 이하가 전체의 몇 %인가'를 계단 곡선으로 그립니다. 구간을 고를 필요가 없어 두 분포 비교에 정확합니다." more="자세히: [ECDF 읽기](#/l/da-14-5)"}

계산 금액 244개를 히스토그램과 상자그림으로 그려 봅니다. 같은 값을 두 가지 방법으로 요약한 것입니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("tips.csv")
fig, axes = plt.subplots(1, 2, figsize=(8, 3))
axes[0].hist(df["total_bill"], bins=15)
axes[1].boxplot(df["total_bill"], vert=False)
print(df["total_bill"].median())
```

히스토그램은 10 ~ 20달러 근처에 막대가 높이 몰리고 오른쪽으로 길게 꼬리가 늘어진 모양입니다. 상자그림의 가운데 선이 중앙값 17.8달러이고, 오른쪽 끝에 따로 찍힌 점들이 꼬리 쪽의 큰 계산서입니다. 히스토그램은 **모양**을, 상자그림은 **요약 숫자**를 보기 좋습니다.

## 관계: 두 값이 함께 움직이나

숫자 열 두 개를 x와 y에 놓고, 한쪽이 커질 때 다른 쪽도 커지는지(또는 작아지는지) 볼 때 씁니다.

::chart{src="content/img/gallery/mpl-scatter.png" name="산점도" sig="ax.scatter(x, y)" desc="행 하나를 점 하나로 찍습니다. 점들이 오른쪽 위로 올라가면 함께 커지는 관계입니다. 점 크기(s)와 색(c)에 다른 열을 실을 수도 있습니다." more="자세히: [산점도 읽기](#/l/da-15-1)"}
::chart{src="content/img/gallery/mpl-hexbin.png" name="육각형 밀도" sig="ax.hexbin(x, y, gridsize)" desc="점이 수천 개라 겹쳐서 까맣게 뭉칠 때, 평면을 육각형 칸으로 나눠 칸마다 점 개수를 색으로 칠합니다."}
::chart{src="content/img/gallery/mpl-imshow.png" name="히트맵(색 격자)" sig="ax.imshow(Z)" desc="표(2차원 배열)의 숫자를 칸마다 색으로 칠합니다. 상관계수 표, 요일 × 시간 같은 교차표를 한눈에 볼 때 씁니다." more="자세히: [상관계수와 히트맵 읽기](#/l/da-15-3)"}

계산 금액과 팁을 산점도로 그려 봅니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("tips.csv")
fig, ax = plt.subplots(figsize=(5, 3.5))
ax.scatter(df["total_bill"], df["tip"], s=12)
ax.set_xlabel("total_bill")
ax.set_ylabel("tip")
print(round(df["total_bill"].corr(df["tip"]), 2))
```

점들이 왼쪽 아래에서 오른쪽 위로 올라갑니다. 함께 움직이는 정도를 -1 ~ 1 사이 숫자로 잰 상관계수가 0.68로, 계산 금액이 클수록 팁도 큰 편이라는 뜻입니다. 다만 같은 금액에서도 팁이 꽤 흩어져 있어서 금액만으로 팁이 정해지지는 않습니다.

## 구성: 전체 중 얼마인가

전체를 100%로 놓고 각 부분이 차지하는 몫을 볼 때 씁니다.

::chart{src="content/img/gallery/mpl-pie.png" name="파이 차트" sig="ax.pie(x)" desc="전체 원을 몫만큼 조각으로 나눕니다. 조각이 2 ~ 4개이고 '절반을 넘나'처럼 큰 몫을 볼 때만 씁니다. 조각이 많으면 막대가 낫습니다." more="자세히: [파이 · 도넛 읽기](#/l/da-16-1)"}
::chart{src="content/img/gallery/mpl-stacked-bar.png" name="누적 막대" sig="ax.bar(x, height, bottom)" desc="막대 위에 다음 막대를 bottom 자리부터 쌓습니다. 그룹마다 전체 크기와 구성을 함께 봅니다." more="자세히: [누적 막대와 100% 막대 읽기](#/l/da-16-2)"}
::chart{src="content/img/gallery/mpl-stackplot.png" name="누적 영역" sig="ax.stackplot(x, y1, y2, ...)" desc="선 그래프 여러 개를 아래부터 쌓아 칠합니다. 시간에 따라 전체와 구성이 어떻게 바뀌는지 볼 때 씁니다." more="자세히: [시간에 따른 구성: 누적 영역](#/l/da-16-3)"}

점심(Lunch)과 저녁(Dinner) 계산서 비율을 파이로, 요일별 점심 · 저녁 수를 누적 막대로 그립니다. 누적 막대의 두 번째 `bar`에 `bottom=`으로 첫 번째 막대 높이를 주는 것이 핵심입니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("tips.csv")
share = df["time"].value_counts()
table = pd.crosstab(df["day"], df["time"])
fig, axes = plt.subplots(1, 2, figsize=(8, 3))
axes[0].pie(share.values, labels=share.index, autopct="%.0f%%")
axes[1].bar(table.index, table["Lunch"], label="Lunch")
axes[1].bar(table.index, table["Dinner"], bottom=table["Lunch"], label="Dinner")
axes[1].legend()
print(table)
```

전체 계산서의 72%가 저녁입니다. 누적 막대를 보면 그 이유가 보입니다. 목요일(Thur)은 점심이 61장으로 대부분이고, 토요일(Sat) · 일요일(Sun)은 점심이 한 장도 없이 모두 저녁입니다. 파이는 "전체 비율" 하나만, 누적 막대는 "그룹마다 구성"까지 보여 줍니다.

## 더 많은 차트가 필요할 때

이 페이지의 16가지면 데이터 분석에서 쓰는 그래프는 거의 다 그릴 수 있습니다. 더 특별한 모양(등고선, 극좌표, 3D 등)이 필요하면 matplotlib 공식 홈페이지의 [Plot types](https://matplotlib.org/stable/plot_types/index.html)와 [예제 갤러리](https://matplotlib.org/stable/gallery/index.html)에서 그림을 보고 고른 뒤 예제 코드를 가져다 쓰면 됩니다. 어느 예제든 `fig, ax = plt.subplots()` 다음 줄의 명령만 보면 무엇을 그리는지 알 수 있습니다.

질문마다 어떤 차트를 고르고 어떻게 읽는지는 뒤의 **비교 · 추이 · 분포 · 관계 · 구성** PART에서 하나씩 자세히 배웁니다. 다음 레슨 [그래프의 뼈대: fig와 ax](#/l/da-09-1)에서는 먼저 모든 차트가 공유하는 뼈대를 뜯어봅니다.

## 정리

| 질문 | 차트 | 명령 |
| --- | --- | --- |
| 어느 쪽이 더 큰가 (비교) | 막대 · 가로 막대 · 오차 막대 | `ax.bar` · `ax.barh` · `ax.errorbar` |
| 시간에 따라 어떻게 변하나 (추이) | 선 · 계단 · 영역 채우기 | `ax.plot` · `ax.step` · `ax.fill_between` |
| 값이 어떻게 퍼져 있나 (분포) | 히스토그램 · 상자그림 · 바이올린 · ECDF | `ax.hist` · `ax.boxplot` · `ax.violinplot` · `ax.ecdf` |
| 두 값이 함께 움직이나 (관계) | 산점도 · 육각형 밀도 · 히트맵 | `ax.scatter` · `ax.hexbin` · `ax.imshow` |
| 전체 중 얼마인가 (구성) | 파이 · 누적 막대 · 누적 영역 | `ax.pie` · `ax.bar(bottom=)` · `ax.stackplot` |

- 차트가 달라도 순서는 같다: 도화지와 칸 만들기 → **명령 하나** → 제목 · 축 이름
- 차트 고르기는 그래프 모양이 아니라 **질문**에서 출발한다
