## 히스토그램 말고 다른 눈으로

히스토그램은 bins에 따라 모양이 달라 보이는 약점이 있었습니다([히스토그램 읽기](#/l/da-14-1)). 이 레슨에서는 같은 분포를 **매끈한 곡선**으로 그리는 밀도 곡선과, 곡선이 가린 실제 데이터 위치를 보여 주는 러그를 읽습니다.

| 그래프 | 한 줄 설명 | 잘하는 것 |
| --- | --- | --- |
| **밀도 곡선(KDE)** | 히스토그램을 매끈한 곡선으로 | 여러 그룹의 모양을 겹쳐 비교 |
| **러그(rug)** | 바닥에 실제 값마다 눈금 | 실제 데이터 위치 확인 |

## 밀도 곡선(KDE)

**KDE**(커널 밀도 추정)는 데이터 하나하나에 작은 언덕을 하나씩 쌓아 올려, 그 윤곽을 매끈한 곡선으로 그립니다. 모래알을 한 알씩 떨어뜨려 쌓인 모래 언덕의 윤곽을 그린다고 생각하면 됩니다. 펭귄 세 종의 지느러미 길이를 곡선으로 겹쳐 봅니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("penguins.csv").dropna()
ax = sns.kdeplot(data=df, x="flipper_length_mm", hue="species", fill=True, alpha=0.3)
print(df.groupby("species")["flipper_length_mm"].agg(["median", "min", "max"]))
```

**무엇을 나타내나**

- x축: 값(지느러미 길이)
- 곡선 높이: 그 값 근처에 데이터가 **얼마나 빽빽한가**(밀도)
- 곡선 아래 넓이: 항상 1(=100%). 그래서 그룹 크기가 달라도 모양을 바로 비교할 수 있습니다.

**이렇게 읽는다**

1. 곡선마다 **봉우리 위치**(중심)
2. 곡선의 **폭**(퍼짐)
3. 곡선끼리 **겹치는 정도**: 많이 겹치면 두 그룹을 그 값만으로 구분하기 어렵다

> 해석: Gentoo의 곡선은 216mm 근처에 봉우리가 있고 다른 두 종과 거의 겹치지 않는다. 반면 Adelie(190mm)와 Chinstrap(196mm)은 곡선이 크게 겹쳐, 지느러미 길이만으로는 두 종을 구분하기 어렵다.

"겹치는 정도"는 KDE가 가장 잘 보여 주는 정보입니다. 나중에 머신러닝에서 "이 특성으로 그룹을 구분할 수 있나"를 판단할 때 그대로 쓰입니다.

## 밀도 곡선을 잘못 읽기 쉬운 점

**① y축 숫자를 개수나 확률로 읽기**: y축의 0.04 같은 숫자는 "4%"도 "4마리"도 아닙니다. 넓이를 1로 맞추느라 생긴 숫자라서 단위가 x축에 따라 달라집니다. **y값 자체는 해석하지 말고 모양과 위치만** 읽습니다.

**② 매끄러움에 속기**: 곡선이 얼마나 매끄러운지는 `bw_adjust`로 정하는데, 이 값에 따라 봉우리 개수가 달라집니다. 직접 해 보세요: 아래 셀의 `0.3`을 `1`, `3`으로 바꿔 봅니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("penguins.csv").dropna()
ax = sns.kdeplot(data=df, x="flipper_length_mm", bw_adjust=0.3)
ax.set_title("bw_adjust=0.3")
print("값이 작을수록 곡선이 데이터를 너무 따라가 작은 봉우리가 많아집니다")
```

0.3이면 작은 봉우리가 여러 개 생기고, 3이면 두 봉우리가 하나로 뭉개집니다. 히스토그램의 bins와 같은 문제입니다. **설정을 바꿔도 유지되는 봉우리만** 믿습니다.

**③ 데이터가 없는 곳까지 뻗은 꼬리**: KDE는 양 끝에서도 언덕을 쌓기 때문에 실제 최솟값·최댓값 바깥까지 꼬리가 뻗습니다. 나이처럼 0보다 작을 수 없는 값에서 곡선이 음수까지 넘어가도 **그런 값이 있다는 뜻이 아닙니다.**

## 러그: 실제 데이터는 어디에

곡선이 매끈할수록 "실제 데이터가 어디 있었는지"는 가려집니다. `rugplot`은 x축 바닥에 값마다 짧은 눈금을 그어 실제 위치를 보여 줍니다. 같은 칸(ax)에 이어 그리면 곡선과 겹쳐집니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("penguins.csv").dropna()
ax = sns.kdeplot(data=df, x="body_mass_g")
sns.rugplot(data=df, x="body_mass_g", ax=ax, height=0.05)
print("최솟값", df["body_mass_g"].min(), "/ 최댓값", df["body_mass_g"].max())
```

> 해석: 몸무게 곡선은 2,500g 아래와 6,500g 위까지 뻗어 있지만, 바닥 눈금을 보면 실제 데이터는 2,700~6,300g 사이에만 있다. 눈금이 빽빽한 3,300~4,000g 구간이 곡선의 봉우리와 일치한다.

## 정리: 밀도 곡선 · 러그

| 그래프 | 코드 | 먼저 읽을 것 | 주의 |
| --- | --- | --- | --- |
| 히스토그램 | `sns.histplot` | 봉우리, 모양 | bins에 따라 모양이 바뀜 |
| 밀도 곡선 | `sns.kdeplot(hue=, fill=True)` | 봉우리 위치, 그룹끼리 겹침 | y값은 해석 안 함, bw_adjust, 꼬리 |
| 러그 | `sns.rugplot` | 실제 값 위치 | 다른 그래프와 겹쳐 그림 |
