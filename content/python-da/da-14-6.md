## 점을 다 찍는다

상자그림과 바이올린([바이올린 그래프 읽기](#/l/da-14-4))은 요약한 그림이라 **데이터가 몇 개인지**가 보이지 않습니다. 스트립과 스웜은 요약하지 않고 값 하나하나를 점으로 찍습니다.

| 그래프 | 한 줄 설명 | 상자 · 바이올린보다 나은 점 |
| --- | --- | --- |
| **스트립(strip)** | 값마다 점 하나, 옆으로 살짝 흩뿌림 | 실제 데이터와 개수가 보인다 |
| **스웜(swarm)** | 점이 겹치지 않게 옆으로 쌓음 | 개수와 모양이 동시에 보인다 |

## 스트립 그래프: 점을 다 찍는다

`stripplot`은 값 하나하나를 점으로 찍고, 겹치지 않도록 옆으로 살짝 무작위로 흩뿌립니다(jitter). 요일별 팁을 찍어 봅니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("tips.csv")
order = ["Thur", "Fri", "Sat", "Sun"]
ax = sns.stripplot(data=df, x="day", y="tip", order=order, alpha=0.6)
print(df["day"].value_counts()[order].to_dict())
print("가장 많은 팁 금액:", df["tip"].value_counts().head(3).to_dict())
```

**무엇을 나타내나**: 점 하나 = 계산서 하나. 가로 위치는 의미가 없고(겹치지 않게 흩뿌린 것), **세로 위치만** 값입니다.

**이렇게 읽는다**

1. **점이 얼마나 많은가** → 그룹 크기(상자·바이올린에서는 안 보이던 것)
2. **점이 빽빽한 높이** → 값이 몰린 곳
3. **줄지어 늘어선 점** → 같은 값이 반복됨
4. **혼자 떨어진 점** → 튀는 값

> 해석: 금요일은 점이 19개뿐이라 한눈에 데이터가 적다는 것이 보인다. 네 요일 모두 2달러, 3달러 높이에 점이 가로로 줄지어 있는데, 손님들이 팁을 딱 떨어지는 금액(2달러 33번, 3달러 23번)으로 주는 습관이 있기 때문이다. 10달러 점 하나는 토요일에만 있다.

"딱 떨어지는 금액에 몰린다"는 사실은 상자그림이나 바이올린으로는 절대 보이지 않습니다. **실제 점을 찍어 봐야 보이는 패턴**이 있습니다.

## 스웜 그래프: 점을 겹치지 않게 쌓기

`swarmplot`은 점을 무작위로 흩뿌리지 않고, **겹치지 않게 옆으로 차곡차곡** 쌓습니다. 그래서 점들의 윤곽이 바이올린 모양이 되어, 개수와 모양을 동시에 보여 줍니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("penguins.csv").dropna()
fig, ax = plt.subplots(figsize=(6, 4))
sns.swarmplot(data=df, x="species", y="body_mass_g", hue="sex", hue_order=["FEMALE", "MALE"], size=3, ax=ax)
print(df.groupby("species").size().to_dict())
```

**이렇게 읽는다**: 무리가 **옆으로 넓게 퍼진 높이**가 값이 많은 곳(바이올린의 불룩한 곳)이고, 무리의 **전체 크기**가 데이터 개수입니다. 색을 나누면 두 그룹이 위아래로 갈리는지 섞이는지가 보입니다.

> 해석: Adelie(146마리) 무리가 Chinstrap(68마리)보다 옆으로 두 배쯤 넓어 개수 차이가 그대로 보인다. 세 종 모두 수컷(주황) 점은 위쪽, 암컷(파랑) 점은 아래쪽에 모여 암수가 몸무게로 꽤 잘 갈린다.

**잘못 읽기 쉬운 점**: 스웜은 데이터가 수백 개를 넘으면 점을 놓을 자리가 없어 옆으로 끝없이 퍼지거나 경고가 납니다. 데이터가 많으면 스트립에 `alpha`(투명도)를 주거나 바이올린을 씁니다.

## 상자 + 점 겹쳐 그리기

실무에서 가장 많이 쓰는 조합은 **상자그림 위에 스트립**을 겹치는 것입니다. 상자로 요약(중앙값·IQR)을 읽고, 점으로 개수와 실제 값을 확인합니다. 상자의 이상치 점은 스트립 점과 겹치므로 `fliersize=0`으로 끕니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("tips.csv")
order = ["Thur", "Fri", "Sat", "Sun"]
ax = sns.boxplot(data=df, x="day", y="total_bill", order=order, fliersize=0, color="lightgray")
sns.stripplot(data=df, x="day", y="total_bill", order=order, ax=ax, size=3, alpha=0.6)
print(df.groupby("day")["total_bill"].median()[order].round(1).to_dict())
```

> 해석: 상자로는 주말 중앙값(토 18.2, 일 19.6)이 평일(목 16.2, 금 15.4)보다 조금 높다는 것을 읽고, 점으로는 금요일 데이터가 유난히 적어 금요일 상자를 덜 믿어야 한다는 것을 함께 읽을 수 있다.

## 정리: 분포 그래프 여섯 가지

| 그래프 | 코드 | 보이는 것 | 안 보이는 것 | 언제 |
| --- | --- | --- | --- | --- |
| 히스토그램 | `sns.histplot` | 모양, 봉우리, 개수 | 그룹 여러 개 비교는 어지러움 | 그룹 1~2개 자세히 |
| 밀도 곡선 | `sns.kdeplot` | 모양, 그룹끼리 겹침 | 개수, 실제 범위 | 그룹 2~4개 모양 비교 |
| ECDF | `sns.ecdfplot` | 중앙값, "~ 이하 몇 %" | 봉우리가 직관적이지 않음 | 백분위 비교 |
| 상자그림 | `sns.boxplot` | 중앙값, IQR, 이상치 | 봉우리, 개수 | 그룹 여러 개를 한 줄로 |
| 바이올린 | `sns.violinplot` | 상자 + 모양(봉우리) | 개수 | 그룹 여러 개 모양까지 |
| 스트립 · 스웜 | `sns.stripplot`, `sns.swarmplot` | 모든 점, 개수, 반복 값 | 데이터가 많으면 뭉개짐 | 데이터가 수백 개 이하 |

고르는 기준은 간단합니다. **데이터가 적으면 점을 다 찍고, 많으면 요약(상자·바이올린)하고, 둘 다 원하면 겹쳐 그립니다.**
