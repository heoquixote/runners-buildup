## 평균을 비교하는 막대

[막대 그래프 읽기](#/l/da-12-1)의 막대는 이미 세어 둔 값(개수, 비율)을 그렸습니다. 이번에는 "요일별 **평균** 계산 금액"처럼 **각 그룹의 평균을 비교**하는 그래프를 읽습니다. seaborn의 `barplot`은 표를 넘기면 그룹마다 평균을 계산해 막대로 그리고, 막대 위에 **오차 막대**(검은 세로선)를 덧붙입니다. 이 검은 선을 바르게 읽는 것이 이 레슨의 핵심입니다.

::figure{src="content/img/viz/viz08-cat-family.svg" alt="범주 비교 그래프 세 가족: 개수(countplot), 요약값(barplot, pointplot), 분포(boxplot, violinplot, stripplot, swarmplot)" caption="범주별로 무엇을 비교하나: 개수(막대 그래프 읽기), 평균 같은 요약값(이 레슨), 분포 전체(DAY 05)."}

## barplot: 막대 높이는 평균

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("tips.csv")
ax = sns.barplot(data=df, x="day", y="total_bill", order=["Thur", "Fri", "Sat", "Sun"])
print(df.groupby("day")["total_bill"].mean().round(2))
```

**무엇을 나타내나**

- x축: 그룹(요일)
- 막대 높이: 그 그룹 y값(계산 금액)의 **평균**. 합계도 개수도 아닙니다.
- 검은 세로선: **오차 막대**. 기본값은 평균의 **95% 신뢰구간**입니다.

**이렇게 읽는다**

1. 막대 높이로 평균의 순위를 본다.
2. 오차 막대 길이로 "그 평균이 얼마나 확실한가"를 본다.
3. 두 그룹의 오차 막대가 **겹치는지** 본다.

> 해석: 평균 계산 금액은 일요일 21.41달러, 토요일 20.44달러로 주말이 목·금요일(약 17달러)보다 3~4달러 높다.

## 오차 막대: 평균이 얼마나 흔들릴 수 있나

신뢰구간은 "**같은 방식으로 데이터를 다시 모으면, 평균이 대략 이 범위 안에 들어올 것**"이라는 표시입니다. 데이터가 적거나 값이 들쭉날쭉할수록 평균은 다시 잴 때마다 많이 흔들리므로 선이 길어집니다.

막대마다 데이터 개수와 함께 오차 막대 길이를 꺼내 봅니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("tips.csv")
order = ["Thur", "Fri", "Sat", "Sun"]
ax = sns.barplot(data=df, x="day", y="total_bill", order=order)
lengths = [round(float(l.get_ydata()[1] - l.get_ydata()[0]), 1) for l in ax.lines]
print("건수:", df["day"].value_counts()[order].tolist())
print("오차 막대 길이:", lengths)
```

계산서가 19장뿐인 금요일의 오차 막대가 가장 깁니다. 금요일 평균 17.15달러는 "대략 14~21달러 어딘가"라는 뜻이라, 다른 요일보다 덜 확실합니다.

::figure{src="content/img/viz/viz14-errorbar.svg" alt="오차 막대가 겹치지 않는 두 막대는 차이가 있다고 볼 근거가 강하고, 크게 겹치는 두 막대는 차이를 단정하기 어렵다" caption="오차 막대가 크게 겹치면 '평균이 다르다'고 단정하기 어렵습니다."}

**이렇게 읽는다**: 두 그룹의 오차 막대가

- **전혀 겹치지 않으면** → 평균 차이가 우연이 아닐 가능성이 크다.
- **크게 겹치면** → 이 데이터만으로는 차이가 있다고 단정하기 어렵다.

> 해석: 일요일(21.41)과 토요일(20.44)은 평균이 1달러 차이 나지만 오차 막대가 크게 겹쳐, "일요일이 더 많이 쓴다"고 말하기는 어렵다. 반면 목요일(17.68)과 일요일은 오차 막대가 거의 겹치지 않아 차이가 있다고 볼 만하다.

**잘못 읽기 쉬운 점**

- 오차 막대를 **최솟값~최댓값**으로 읽기: 실제 계산서는 3달러부터 50달러까지 있습니다. 오차 막대는 데이터 범위가 아니라 **평균의 흔들림**입니다.
- 막대 높이 차이만 보고 결론 내기: 높이가 달라도 오차 막대가 겹치면 차이가 없을 수도 있습니다. 정확한 판단은 통계 트랙의 검정(t-검정)에서 배웁니다.

## 표준편차 막대: 데이터가 얼마나 퍼졌나

`errorbar="sd"`를 주면 오차 막대가 **표준편차**(평균에서 값들이 평균적으로 얼마나 떨어져 있나)로 바뀝니다. 같은 검은 선이지만 뜻이 완전히 다릅니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("tips.csv")
ax = sns.barplot(data=df, x="day", y="total_bill", order=["Thur", "Fri", "Sat", "Sun"], errorbar="sd")
ax.set_title("Mean ± SD")
print(df.groupby("day")["total_bill"].std().round(2))
```

| 오차 막대 | 뜻 | 데이터가 많아지면 |
| --- | --- | --- |
| 신뢰구간 (기본, `"ci"`) | **평균**이 얼마나 확실한가 | 짧아진다 |
| 표준편차 (`"sd"`) | **값들**이 얼마나 퍼져 있나 | 거의 그대로 |

> 해석: 토요일은 표준편차가 9.48달러로 가장 커서, 손님마다 쓰는 금액 차이가 가장 크다.

**잘못 읽기 쉬운 점**: 보고서의 그래프에 오차 막대가 있으면, 그것이 신뢰구간인지 표준편차인지 **반드시 확인하고 적어야** 합니다. 같은 그림도 뜻이 달라집니다.

## 평균 말고 합계로

`estimator="sum"`을 주면 막대 높이가 합계가 됩니다. 질문이 "요일별 **총매출**"이라면 합계가 맞습니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("tips.csv")
ax = sns.barplot(data=df, x="day", y="total_bill", order=["Thur", "Fri", "Sat", "Sun"], estimator="sum", errorbar=None)
ax.set_title("Total sales by day")
print(df.groupby("day")["total_bill"].sum().round(0))
```

> 해석: 총매출은 토요일(1,778달러)이 가장 크다. 평균은 일요일이 더 높았지만, 토요일 손님 수(87장)가 더 많아 합계는 토요일이 앞선다.

같은 데이터에서 "평균 1위"와 "합계 1위"가 다를 수 있습니다. **평균은 "한 번에 얼마나", 합계는 "모두 합쳐 얼마나"**에 대한 답입니다. 그래프 제목에 무엇인지 꼭 적으세요.

## pointplot: 평균을 점으로

`pointplot`은 막대 대신 **점(평균) + 오차 막대**만 그리고 점을 선으로 잇습니다. 막대가 없어서 y축이 0에서 시작하지 않아도 괜찮고, 그룹이 많을 때 평균의 변화를 읽기 좋습니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("tips.csv")
ax = sns.pointplot(data=df, x="size", y="tip")
ax.set_xlabel("Party size")
print(df.groupby("size")["tip"].agg(["mean", "count"]).round(2))
```

**무엇을 나타내나**: 점 = 그룹 평균, 세로선 = 신뢰구간, 점을 잇는 선 = 그룹이 바뀔 때 평균이 어떻게 변하나(x에 순서가 있을 때만 의미 있음).

> 해석: 인원이 1명에서 4명으로 늘수록 평균 팁이 1.44달러에서 4.14달러로 커진다. 5·6명 그룹은 각각 5건, 4건뿐이라 오차 막대가 매우 길어서 평균을 믿기 어렵다.

**잘못 읽기 쉬운 점**: 점을 잇는 선은 "중간 값이 있다"는 뜻이 아닙니다. 순서가 없는 범주(성별, 지역)에 선을 이으면 의미 없는 기울기를 읽게 되니, 그럴 때는 `linestyle="none"`으로 선을 끕니다.

## 정리: 평균 비교 그래프 읽기

| 확인할 것 | 질문 |
| --- | --- |
| 막대·점이 뜻하는 값 | 평균인가 합계인가? (`estimator`) |
| 검은 선이 뜻하는 것 | 신뢰구간(평균의 흔들림)인가 표준편차(값의 퍼짐)인가? |
| 오차 막대 겹침 | 크게 겹치면 차이를 단정하지 않는다 |
| 표본 수 | 데이터가 적은 그룹은 오차 막대가 길다 (countplot으로 확인) |

| 그래프 | 코드 | 언제 |
| --- | --- | --- |
| 평균 막대 | `sns.barplot(data=, x=, y=)` | 그룹 평균 비교 |
| 표준편차 막대 | `sns.barplot(..., errorbar="sd")` | 평균과 함께 퍼짐도 보여 줄 때 |
| 합계 막대 | `sns.barplot(..., estimator="sum")` | 총량 비교 |
| 평균 점 | `sns.pointplot(data=, x=, y=)` | 순서 있는 그룹, 그룹이 많을 때 |
