## 관계 그래프: 두 값이 함께 움직이나

"계산 금액이 크면 팁도 많이 줄까?", "지느러미가 길면 몸무게도 무거울까?"처럼 **숫자 두 개의 관계**를 묻는 질문에는 관계 그래프로 답합니다. da-09-3에서 matplotlib으로 그렸던 산점도를 seaborn으로 그리면, 색·크기·모양으로 정보를 더하고 추세선을 긋는 일이 한 줄로 끝납니다. 이 레슨의 후반부에서는 숫자 열이 여러 개일 때 **모든 쌍의 관계를 한 번에** 보는 히트맵과 pairplot을 배웁니다.

## scatterplot: 점 하나 = 계산서 한 장

`sns.scatterplot(data=df, x="열", y="열")`이 산점도입니다. 식당 계산서의 금액과 팁을 그려 봅니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("tips.csv")
ax = sns.scatterplot(data=df, x="total_bill", y="tip")
print("점 개수:", len(df))
```

점들이 왼쪽 아래에서 오른쪽 위로 퍼져 있습니다. 금액이 클수록 팁도 커지는 **양의 관계**입니다. 다만 같은 금액이어도 팁은 꽤 제각각이라, 점들이 한 줄로 서 있지는 않습니다.

seaborn 산점도는 세 가지 방법으로 정보를 더할 수 있습니다. `hue`(색), `size`(점 크기), `style`(점 모양)입니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("tips.csv")
ax = sns.scatterplot(data=df, x="total_bill", y="tip", hue="time", size="size", alpha=0.7)
print(df.groupby("time")[["total_bill", "tip"]].mean().round(2))
```

색은 점심/저녁, 점 크기는 인원입니다. 큰 점(인원 많음)이 오른쪽(금액 큼)에 몰려 있는 것이 보입니다. 하지만 hue·size·style을 **한꺼번에 다 쓰면** 그래프가 복잡해져 아무것도 안 읽힙니다. 정보는 **두 개(x, y) + 하나(색)**까지가 적당하고, 더 필요하면 칸을 나눕니다(아래 relplot).

## regplot · lmplot: 추세선 긋기

점들 사이로 가장 잘 맞는 **직선**을 그어 주면 관계의 방향과 기울기가 분명해집니다. `regplot`은 산점도 위에 직선(회귀선)과, 그 직선이 흔들릴 수 있는 범위(옅은 띠, 신뢰 구간)를 그립니다.

```run
import matplotlib.pyplot as plt
import numpy as np
import seaborn as sns
import pandas as pd

df = pd.read_csv("tips.csv")
ax = sns.regplot(data=df, x="total_bill", y="tip", scatter_kws={"alpha": 0.4})
slope, intercept = np.polyfit(df["total_bill"], df["tip"], 1)
print("기울기:", round(slope, 3), "/ 절편:", round(intercept, 2))
```

기울기 0.105는 "계산 금액이 1달러 늘 때 팁이 평균 약 0.1달러(10센트) 늘어난다"는 뜻입니다. 팁이 금액의 약 10%라는 말과 같습니다. 띠는 데이터가 적은 오른쪽 끝(금액 40달러 이상)에서 넓어집니다. 데이터가 적은 곳일수록 직선이 덜 확실하다는 뜻입니다.

그룹마다 추세선을 따로 긋고 싶으면 그림 단위 함수 `lmplot`에 `hue=`를 줍니다.

```run
import matplotlib.pyplot as plt
import numpy as np
import seaborn as sns
import pandas as pd

df = pd.read_csv("tips.csv")
g = sns.lmplot(data=df, x="total_bill", y="tip", hue="smoker", height=3.5)
for name, part in df.groupby("smoker"):
    print("smoker =", name, "기울기:", round(np.polyfit(part["total_bill"], part["tip"], 1)[0], 3))
```

비흡연석(No)은 기울기 0.137, 흡연석(Yes)은 0.070으로, 흡연석 손님은 금액이 커져도 팁이 덜 늘었습니다. 선 두 개의 **기울기 차이**가 그룹의 차이를 보여 줍니다.

> 추세선은 "관계가 있어 보인다"를 보여 주는 탐색 도구입니다. 정식으로 직선을 맞추고 해석하는 방법은 머신러닝 트랙(ml-02 회귀)에서 배웁니다.

## lineplot: 같은 x에 값이 여러 개일 때

`lineplot`은 선 그래프입니다. matplotlib의 `ax.plot`과 다른 점은, **같은 x에 값이 여러 개 있으면 알아서 평균을 구해 선으로 잇고, 흔들림 범위를 띠로** 그려 준다는 것입니다. 항공 승객 데이터는 월마다 12년치 값(12개)이 있습니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("flights.csv")
df["month"] = df["month"].str[:3]
ax = sns.lineplot(data=df, x="month", y="passengers", marker="o")
print(df.groupby("month", sort=False)["passengers"].mean().round(0))
```

선은 월별 12년 평균이고, 7·8월이 351(천 명)로 가장 높습니다. 띠가 넓은 것은 같은 7월이라도 1949년과 1960년의 승객 수가 크게 달랐기 때문입니다. `hue="year"`를 주면 연도마다 선을 따로 그립니다(직접 해 보세요. 선이 12개라 seaborn이 색을 연속 색상으로 칠해 줍니다).

## relplot: 조건별로 칸 나누기

관계 그래프의 그림 단위 함수는 `relplot`입니다. `kind="scatter"`(기본) 또는 `kind="line"`을 고르고, `col=`로 칸을 나눕니다. 위에서 "정보가 너무 많으면 칸을 나눈다"고 했던 것이 이것입니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("tips.csv")
g = sns.relplot(data=df, x="total_bill", y="tip", hue="smoker", col="time", height=3)
print("칸:", [ax.get_title() for ax in g.axes.flat])
```

점심(Lunch)과 저녁(Dinner)을 나눠 같은 관계를 비교합니다. 칸끼리 축을 공유하므로 저녁 칸에 큰 금액 계산서가 훨씬 많다는 것이 바로 보입니다.

## heatmap ① 상관 행렬

숫자 열이 여러 개면 "어떤 쌍이 함께 움직이나"를 한 번에 보고 싶어집니다. **상관계수**는 두 값이 얼마나 직선 모양으로 함께 움직이는지를 −1부터 1 사이 숫자 하나로 요약한 것입니다.

::figure{src="content/img/viz/viz09-corr.svg" alt="상관계수 눈금: -1이면 한쪽이 오를 때 다른 쪽이 내려가는 점 구름, 0이면 방향 없는 점 구름, +1이면 함께 오르는 점 구름" caption="+1에 가까우면 함께 오르고, −1에 가까우면 반대로 움직이고, 0 근처면 직선 관계가 거의 없습니다."}

pandas의 `df.corr()`가 모든 숫자 열 쌍의 상관계수 표를 만들고, `sns.heatmap`이 그 표를 **색으로 칠한 격자**로 그립니다. `annot=True`는 칸마다 숫자를 씁니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("penguins.csv").dropna()
num = df[["bill_length_mm", "bill_depth_mm", "flipper_length_mm", "body_mass_g"]]
num.columns = ["bill_len", "bill_depth", "flipper", "mass"]
corr = num.corr()
ax = sns.heatmap(corr, annot=True, fmt=".2f", cmap="coolwarm", vmin=-1, vmax=1)
print(corr.round(2))
```

읽는 법은 이렇습니다.

- 대각선은 자기 자신과의 상관이라 항상 1.00입니다. 표는 대각선을 기준으로 위아래가 똑같습니다.
- `flipper`와 `mass`가 **0.87**로 가장 강한 양의 상관입니다. 지느러미가 길면 몸무게도 무겁습니다.
- `bill_depth`와 `mass`는 **−0.47**, 부리가 두꺼울수록 가볍다는 음의 상관입니다. 정말 그럴까요? 아래 pairplot에서 다시 봅니다.

`vmin=-1, vmax=1`은 색의 범위를 상관계수 전체 범위로 고정해서, 0은 흰색, 양수는 빨강, 음수는 파랑이 되게 합니다. 이걸 빼면 표 안의 최솟값·최댓값에 맞춰 색이 정해져 0.3 같은 약한 상관도 진하게 보일 수 있습니다. 직접 해 보세요: `cmap`을 `"Blues"`, `"vlag"`로 바꾸거나 `vmin`·`vmax`를 지워 보세요.

## heatmap ② 어떤 표든 색으로

히트맵은 상관 행렬 전용이 아닙니다. **행과 열이 있는 숫자 표**면 무엇이든 색으로 그릴 수 있습니다. 항공 승객을 월(행) × 연도(열) 표로 바꿔(pivot) 그려 봅니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("flights.csv")
table = df.pivot(index="month", columns="year", values="passengers")
table = table.loc[df["month"].unique()]
fig, ax = plt.subplots(figsize=(8, 4))
sns.heatmap(table, cmap="YlGnBu", ax=ax)
print("연도별 가장 붐빈 달:", table.idxmax().value_counts().to_dict())
```

두 가지 패턴이 한 그림에 보입니다. **왼쪽에서 오른쪽으로 갈수록 진해지고**(해마다 승객 증가), **가운데 7·8월 줄이 가장 진합니다**(여름 성수기). 12년 중 7번은 7월, 5번은 8월이 가장 붐볐습니다(두 달의 승객 수가 똑같은 해는 앞에 있는 7월로 셉니다). `table.loc[df["month"].unique()]`는 월을 알파벳순이 아니라 1월~12월 순서로 다시 세운 것입니다.

## pairplot: 모든 쌍을 한 번에

`pairplot`은 숫자 열의 **모든 쌍**으로 산점도를 그려 격자로 늘어놓고, 대각선에는 각 열의 분포를 그립니다. 데이터를 처음 받았을 때 전체를 훑어보기 좋습니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("penguins.csv").dropna()
cols = ["bill_depth_mm", "flipper_length_mm", "body_mass_g", "species"]
g = sns.pairplot(df[cols], hue="species", height=2)
print("격자:", g.axes.shape)
print(df.groupby("species")[["bill_depth_mm", "body_mass_g"]].corr().round(2).iloc[1::2, 0])
```

`bill_depth_mm`(부리 두께)와 `body_mass_g`(몸무게) 칸을 보세요. 전체 상관은 −0.47이었는데, **종마다 색을 나눠 보면 세 종 모두 오른쪽 위로 올라갑니다**(종 안에서는 +0.58~+0.72). 부리가 얇고 몸이 무거운 Gentoo가 한쪽에 따로 모여 있어서, 종을 섞어 계산하면 관계가 거꾸로 보였던 것입니다. 이렇게 **그룹을 합치면 관계 방향이 뒤집히는 현상**은 실제 데이터에서 자주 일어납니다. 숫자 하나(상관계수)만 믿지 말고 그림을 함께 봐야 하는 이유입니다.

> pairplot은 열이 n개면 그래프를 n × n개 그립니다. 열이 10개면 100개라 느리고 읽기도 어렵습니다. 관심 있는 열 3~5개만 골라서 그리세요.

## jointplot: 산점도 + 양옆 분포

두 변수 하나의 관계를 자세히 볼 때는 `jointplot`이 좋습니다. 가운데 산점도, 위쪽과 오른쪽에 각 변수의 분포(히스토그램)를 함께 붙여 줍니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("tips.csv")
g = sns.jointplot(data=df, x="total_bill", y="tip", kind="reg", height=4.5)
print("상관계수:", round(df["total_bill"].corr(df["tip"]), 2))
```

`kind=`에 `"scatter"`, `"reg"`(추세선), `"kde"`(등고선), `"hex"`(육각형 칸으로 점 밀도)를 고를 수 있습니다. 위쪽 분포를 보면 계산 금액은 10~20달러에, 오른쪽 분포를 보면 팁은 2~3달러에 몰려 있습니다.

## 상관은 인과가 아니다

여름에는 아이스크림 판매량도 늘고, 물놀이 사고도 늘어납니다. 두 숫자의 상관계수는 높게 나오겠지만 **아이스크림이 사고를 일으키지는 않습니다.** 둘 다 '더운 날씨'라는 제3의 원인에 함께 움직였을 뿐입니다.

히트맵에서 진한 칸, 산점도의 기울어진 점 구름은 "함께 움직인다"까지만 말해 줍니다. "이것 때문에 저것이 변한다"고 말하려면 실험이나 더 깊은 분석이 필요합니다. 그래프 보고서에는 "상관이 높다"고 쓰되, 원인이라고 단정하지 마세요.

## 정리: 관계 · 상관 그래프 고르기

| 질문 | 칸 단위 | 그림 단위 | 주의 |
| --- | --- | --- | --- |
| 두 숫자의 관계 | `scatterplot` | `relplot(kind="scatter")` | hue·size·style을 한꺼번에 다 쓰지 않기 |
| 관계의 방향·기울기 | `regplot` | `lmplot(hue=)` | 추세선은 탐색용, 인과 아님 |
| 순서 있는 x의 평균 추이 | `lineplot` | `relplot(kind="line")` | 띠 = 평균의 흔들림 범위 |
| 여러 숫자 열의 상관 | `heatmap(df.corr(), annot=True)` | | `vmin=-1, vmax=1`로 색 범위 고정 |
| 행 × 열 숫자 표 | `heatmap(pivot 표)` | | 행·열 순서를 의미 있게 정렬 |
| 모든 쌍 훑어보기 | | `pairplot(hue=)` | 열 3~5개만 |
| 한 쌍 자세히 | | `jointplot(kind=)` | |

이어지는 실습 문제에서 상자그림, 상관 히트맵, 범주 비교, 산점도를 직접 그려 봅니다.
