같은 데이터도 표 모양이 두 가지입니다. 로트마다 한 행에 측정 위치 세 곳을 옆으로 늘어놓은 **넓은 표(wide)**, 그리고 "로트 · 위치 · 값"을 한 행씩 세로로 쌓은 **긴 표(long)**입니다. 사람이 읽기에는 넓은 표가 편하고, groupby · 시각화 · 저장에는 긴 표가 편합니다. 이 레슨에서는 두 모양을 오가는 방법을 익힙니다.

## 넓은 표와 긴 표

| 넓은 표 | | | | 긴 표 | | |
| --- | --- | --- | --- | --- | --- | --- |
| **lot** | **pos1** | **pos2** | **pos3** | **lot** | **pos** | **size** |
| L01 | 10.02 | 9.98 | 10.05 | L01 | pos1 | 10.02 |
| L02 | 10.10 | 10.04 | 10.12 | L01 | pos2 | 9.98 |
| | | | | L01 | pos3 | 10.05 |
| | | | | L02 | pos1 | 10.10 |
| | | | | ... | ... | ... |

넓은 표에서 "위치"라는 정보는 **열 이름**에 숨어 있습니다. 긴 표에서는 `pos`라는 **열의 값**입니다. 열의 값이어야 `groupby('pos')`를 할 수 있습니다. 측정 위치가 네 번째로 늘어나면 넓은 표는 열을 추가해야 하지만, 긴 표는 행만 늘어납니다.

## 넓은 표 → 긴 표: melt

`melt(id_vars=그대로 둘 열, var_name=열 이름이 들어갈 새 열, value_name=값이 들어갈 새 열)`로 녹입니다.

```run
import pandas as pd

wide = pd.DataFrame({'lot': ['L01', 'L02', 'L03'],
                     'pos1': [10.02, 10.10, 9.95],
                     'pos2': [9.98, 10.04, 9.91],
                     'pos3': [10.05, 10.12, 9.99]})
long = wide.melt(id_vars='lot', var_name='pos', value_name='size')
print(long)
print(long.groupby('pos')['size'].mean().round(3))
```

3행 × 측정 열 3개가 9행이 됐습니다. 행 수는 항상 "원래 행 수 × 녹인 열 개수"입니다. 긴 표가 되자 위치별 평균이 groupby 한 줄로 나옵니다. 세 로트 모두 pos2가 가장 작아서, 위치별 평균도 pos2가 9.977로 가장 낮습니다.

## 긴 표 → 넓은 표: pivot과 pivot_table

거꾸로 펼칠 때는 `pivot(index=행이 될 열, columns=열이 될 열, values=값 열)`을 씁니다.

```run
import pandas as pd

long = pd.DataFrame({'lot': ['L01', 'L01', 'L02', 'L02'],
                     'pos': ['pos1', 'pos2', 'pos1', 'pos2'],
                     'size': [10.02, 9.98, 10.10, 10.04]})
print(long.pivot(index='lot', columns='pos', values='size'))
```

| | pivot | pivot_table |
| --- | --- | --- |
| 같은 (행, 열) 조합이 여러 개면 | 에러 | `aggfunc`로 집계 (기본 평균) |
| 쓰임 | 모양만 바꾸기 | 모양 바꾸기 + 집계 |

`pivot`은 칸 하나에 값이 하나일 때만 됩니다. 같은 로트 · 위치를 두 번 쟀다면 `pivot_table`로 평균 등을 내야 합니다.

## pivot_table의 margins와 fill_value

`margins=True`는 행 · 열 합계(전체) 줄을 붙여 줍니다. 엑셀 피벗의 "총합계"와 같습니다. 개수 교차표는 `pd.crosstab`이 더 짧습니다.

```run
import pandas as pd

df = pd.read_csv("tips.csv")
print(pd.crosstab(df['day'], df['time'], margins=True))
print(df.pivot_table(index='day', columns='time', values='tip', aggfunc='mean', margins=True).round(2))
```

토요일 · 일요일에는 점심 손님이 한 건도 없어서 평균 표의 그 칸이 `NaN`입니다. `All` 줄과 열은 그 행 · 열 전체의 평균이라, 칸 평균들을 다시 평균 낸 값이 아닙니다. 예를 들어 목요일 All 2.77은 저녁 1건과 점심 61건을 합친 62건의 평균이라 점심 값에 가깝습니다.

빈칸을 채우는 `fill_value`는 조심해서 씁니다.

```run
import pandas as pd

df = pd.read_csv("tips.csv")
print(df.pivot_table(index='day', columns='time', values='tip', aggfunc='mean', fill_value=0).round(2))
```

토요일 점심 평균 팁이 0.00으로 나왔습니다. 실제로는 "손님이 없었다"인데, 표만 보면 "팁을 한 푼도 안 줬다"로 읽힙니다. **개수 · 합계 표의 빈칸은 0이 맞지만, 평균 표의 빈칸은 NaN으로 두는 편이 정확**합니다.

## 실제 데이터: 월별 승객을 연도 × 월 표로

`flights.csv`는 긴 표(연도 · 월 · 승객)입니다. 넓은 표로 펼치면 계절 패턴이 한눈에 보이는데, 열 순서를 확인해야 합니다.

```run
import pandas as pd

df = pd.read_csv("flights.csv")
wide = df.pivot(index='year', columns='month', values='passengers')
print(wide.columns.tolist()[:4])            # 알파벳 순서로 정렬됨

months = df['month'].unique().tolist()      # 데이터에 나온 순서 = 1월부터
wide = wide[months]
print(wide.iloc[:3, :6])
```

`pivot`은 열 이름을 글자 순서로 정렬해서 April, August, December 순이 됩니다. 원래 데이터에 나온 순서(1월부터)로 열을 다시 골라 세우면 달력 순서가 됩니다. 이렇게 펼친 표는 seaborn 히트맵(`sns.heatmap`)에 그대로 들어갑니다.

## stack과 unstack

인덱스가 두 층인 Series(예: `groupby(['lot', 'pos'])`의 결과)는 `unstack()`으로 안쪽 층을 열로 펼치고, `stack()`으로 다시 접습니다. pivot과 melt의 인덱스 버전입니다.

```run
import pandas as pd

df = pd.DataFrame({'line': ['A', 'A', 'B', 'B', 'A'],
                   'shift': ['day', 'night', 'day', 'night', 'day'],
                   'ng': [3, 5, 2, 4, 1]})
s = df.groupby(['line', 'shift'])['ng'].sum()
print(s)
print(s.unstack())                 # shift를 열로
print(s.unstack().stack().tolist())   # 다시 접기
```

groupby를 두 기준으로 하면 결과가 두 층 인덱스 Series입니다. `unstack()` 한 번이면 "라인 × 근무조" 표가 됩니다. `pivot_table(index='line', columns='shift', values='ng', aggfunc='sum')`과 같은 결과입니다.

## 정리

- 넓은 표는 읽기용, 긴 표는 groupby · 시각화 · 저장용입니다
- 넓은 → 긴 표는 `melt`, 긴 → 넓은 표는 `pivot`(집계가 필요하면 `pivot_table`)
- `margins=True`로 전체 줄을 붙이고, 평균 표의 빈칸은 0으로 채우지 않습니다
- 두 층 인덱스 결과는 `unstack`으로 펼치고 `stack`으로 접습니다
