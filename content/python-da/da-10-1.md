## seaborn은 matplotlib 위에 지은 집

DAY 01에서 matplotlib으로 그래프의 뼈대를 배웠습니다. 그런데 "요일별 평균 계산 금액"처럼 **표를 묶고 집계한 다음** 그려야 하는 그래프는 코드가 길어집니다. **seaborn**은 matplotlib 위에서 동작하는 통계 그래프 도구로, DataFrame을 통째로 넘기고 **열 이름만 고르면** 묶기·집계·색 구분·범례를 알아서 해 줍니다. 속은 matplotlib이라서 [matplotlib 기본 구조](#/l/da-09-0)에서 배운 `ax.set_title` 같은 다듬기는 그대로 씁니다.

보통 `sns`라는 별명으로 불러옵니다. 이 사이트에서는 처음 실행할 때 seaborn을 내려받느라 몇 초 더 걸립니다.

이번 레슨은 식당 계산서 244건(`tips.csv`)을 씁니다.

```run
import pandas as pd

df = pd.read_csv("tips.csv")
print(df.head())
print(df.shape)
```

한 행이 계산서 한 장입니다. `total_bill`(계산 금액, 달러), `tip`(팁), `sex`(계산한 사람 성별), `smoker`(흡연석), `day`(요일), `time`(Lunch/Dinner), `size`(인원)입니다.

## 같은 그래프, 두 가지 방법

"요일별 평균 계산 금액"을 matplotlib으로 그리려면 먼저 `groupby`로 평균을 구한 뒤 `ax.bar`를 불러야 합니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("tips.csv")
avg = df.groupby("day")["total_bill"].mean()
fig, ax = plt.subplots(figsize=(5, 3))
ax.bar(avg.index, avg.values)
print(avg.round(2))
```

seaborn은 집계를 직접 하지 않습니다. 표와 열 이름만 넘기면 됩니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("tips.csv")
ax = sns.barplot(data=df, x="day", y="total_bill")
print("막대 높이:", [round(float(p.get_height()), 2) for p in ax.patches])
```

막대 높이가 위의 `groupby` 평균과 같습니다(일요일 21.41, 토요일 20.44…). 게다가 seaborn은 막대마다 **검은 세로선**(오차 막대)까지 그려 줬습니다. 평균이 이 정도 범위에서 흔들릴 수 있다는 표시로, [평균과 오차 막대 읽기](#/l/da-12-2)에서 자세히 읽습니다. 요일 순서가 Sun, Sat, Thur, Fri로 섞인 것은 데이터에 처음 나온 순서이기 때문인데, `order=["Thur", "Fri", "Sat", "Sun"]`을 주면 바꿀 수 있습니다.

## data · x · y · hue: 역할 배정

seaborn 함수는 거의 모두 같은 모양입니다.

```
sns.그래프함수(data=표, x="열", y="열", hue="열")
```

- `data`: 어떤 표를 쓸지
- `x`, `y`: 어떤 열을 가로·세로 위치에 놓을지
- `hue`: 어떤 열로 **색을 나눌지** (hue는 '색조'라는 뜻)

연극 배우에게 역할을 나눠 주듯, 표의 열마다 "너는 가로, 너는 세로, 너는 색"이라고 역할을 정해 주는 것입니다.

::figure{src="content/img/viz/viz05-roles.svg" alt="tips 표의 day 열은 x축 위치로, total_bill 열은 y축 높이로, sex 열은 막대 색으로 이어지는 화살표" caption="열 이름 하나로 그래프의 한 역할을 맡깁니다. 묶고 평균 내는 일은 seaborn이 합니다."}

`hue="sex"`를 더하면 요일마다 막대가 성별로 두 개씩 나뉘고 범례도 자동으로 생깁니다. matplotlib으로 그리려면 x 위치를 막대마다 옮겨 가며 그려야 하는 묶음 막대가 한 줄이 됐습니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("tips.csv")
ax = sns.barplot(data=df, x="day", y="total_bill", hue="sex", errorbar=None)
print(df.pivot_table(index="day", columns="sex", values="total_bill").round(1))
```

`errorbar=None`은 오차 막대를 끕니다. 모든 요일에서 남성(Male)의 평균 계산 금액이 조금 더 높습니다.

## seaborn이 좋아하는 표: 긴 표

`hue`가 동작하려면 표가 **한 행에 관측 하나**, 한 열에 변수 하나인 모양이어야 합니다. 이런 표를 **긴 표(long, tidy data)**라고 합니다. tips처럼요.

반대로 엑셀에서 흔히 만드는, 그룹마다 열이 하나씩 있는 표를 **넓은 표(wide)**라고 합니다. 넓은 표에는 "반"이라는 열이 없어서 `hue="반"`이라고 쓸 수가 없습니다.

::figure{src="content/img/viz/viz06-wide-long.svg" alt="반별 열 A, B가 나란히 있는 넓은 표를 melt하면 반 열과 점수 열 두 개로 된 긴 표가 된다" caption="넓은 표는 사람이 읽기 좋고, 긴 표는 seaborn이 읽기 좋습니다. pd.melt로 바꿉니다."}

넓은 표는 pandas의 `melt`로 긴 표로 바꿀 수 있습니다.

```run
import pandas as pd

wide = pd.DataFrame({"A": [70, 85, 90], "B": [60, 75, 95]})
long = wide.melt(var_name="class", value_name="score")
print(wide)
print(long)
```

넓은 표 3행 × 2열이 긴 표 6행으로 바뀌었고, 이제 `class` 열이 생겼으니 `x="class"`나 `hue="class"`로 쓸 수 있습니다.

## seaborn 함수는 ax를 돌려준다

`sns.barplot(...)`이 돌려주는 값은 [matplotlib 기본 구조](#/l/da-09-0)에서 쓰던 그 **ax(그래프 칸)**입니다. 그래서 받아 두었다가 matplotlib 문법으로 제목·축 이름을 바꾸면 됩니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("tips.csv")
ax = sns.barplot(data=df, x="day", y="tip", order=["Thur", "Fri", "Sat", "Sun"])
ax.set_title("Average tip by day")
ax.set_ylabel("Tip ($)")
print(type(ax).__name__)
```

seaborn이 축 이름을 열 이름(`tip`)으로 자동으로 달아 주지만, 단위를 넣어 `Tip ($)`처럼 고쳐 주는 것이 좋습니다.

## ax=로 원하는 칸에 그리기

seaborn 함수에 `ax=칸`을 넘기면 그 칸에 그립니다. [여러 그래프 배치와 다듬기](#/l/da-09-4)의 서브플롯과 그대로 섞어 쓸 수 있습니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("tips.csv")
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(9, 3))
sns.countplot(data=df, x="day", ax=ax1)
sns.scatterplot(data=df, x="total_bill", y="tip", ax=ax2)
fig.tight_layout()
print("왼쪽 막대:", len(ax1.patches), "/ 오른쪽 점:", len(ax2.collections[0].get_offsets()))
```

왼쪽은 요일별 계산서 개수(countplot), 오른쪽은 금액과 팁의 관계(scatterplot)입니다. 함수만 바뀌고 `data · x · y` 모양은 같습니다.

## 테마와 색 팔레트

seaborn의 **스타일**은 그래프 배경과 격자를 한 번에 바꿉니다. `"whitegrid"`, `"darkgrid"`, `"white"`, `"ticks"`가 있습니다. `with sns.axes_style("스타일"):` 안에서 그린 그래프에만 적용되고, `palette=`는 색 묶음을 고릅니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("tips.csv")
with sns.axes_style("whitegrid"):
    ax = sns.barplot(data=df, x="day", y="total_bill", hue="day", palette="pastel", legend=False)
print("팔레트 색 개수:", len(sns.color_palette("pastel")))
```

직접 해 보세요. `palette`에 `"Set2"`, `"deep"`, `"muted"`, `"colorblind"`(색맹도 구분하기 쉬운 색)를 넣어 봅니다. `hue="day"`, `legend=False`는 "막대마다 색을 다르게 하되 범례는 필요 없다"는 뜻입니다. 내 컴퓨터의 노트북 전체에 스타일을 적용하려면 맨 위에서 `sns.set_theme(style="whitegrid")`를 한 번 부릅니다.

## 두 종류의 함수: 칸 단위와 그림 단위

seaborn 함수는 두 종류로 나뉩니다.

| 종류 | 함수 예 | 그리는 곳 | 돌려주는 것 |
| --- | --- | --- | --- |
| 칸 단위 (axes-level) | `histplot`, `boxplot`, `barplot`, `scatterplot`, `heatmap` | 칸(ax) **하나** | ax |
| 그림 단위 (figure-level) | `displot`, `catplot`, `relplot`, `pairplot`, `jointplot`, `lmplot` | **새 도화지 전체** | Grid(격자) |

::figure{src="content/img/viz/viz07-levels.svg" alt="칸 단위 함수는 내가 만든 도화지의 한 칸에 그리고, 그림 단위 함수는 새 도화지를 만들어 col= 값마다 칸을 나눠 그린다" caption="칸 단위 함수는 ax=로 자리를 정해 주고, 그림 단위 함수는 col=·row=로 칸을 스스로 나눕니다."}

그림 단위 함수는 스스로 도화지를 만들기 때문에 `ax=`를 받지 않습니다. 대신 `col="열"`(또는 `row=`)을 주면 그 열의 값마다 칸을 나눠 같은 그래프를 그려 줍니다. 점심과 저녁을 나눠 요일별 평균 금액을 그려 봅니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("tips.csv")
g = sns.catplot(data=df, x="day", y="total_bill", col="time", kind="bar", height=3)
print("칸 개수:", len(g.axes.flat))
print(df.groupby(["time", "day"])["total_bill"].count())
```

Lunch 칸에는 금요일·목요일 막대만, Dinner 칸에는 목·금·토·일 막대가 있습니다(목요일 저녁은 1건뿐). 이 식당은 주말에는 저녁 영업만 했다는 것을 그래프가 알려 줍니다. 그림 단위 함수의 칸 제목은 `g.set_titles(...)`, 축 이름은 `g.set_axis_labels(...)`로 바꿉니다.
