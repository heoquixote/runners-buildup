## seaborn은 DataFrame을 그대로

seaborn은 matplotlib 위에서 동작하는 통계 그래프 도구입니다. `data=df, x='열', y='열', hue='열'`처럼 열 이름만 넘기면 집계와 색 구분을 알아서 합니다. 처음 실행할 때는 seaborn을 내려받느라 시간이 조금 더 걸립니다.

| 목적 | 함수 | 막대·상자가 뜻하는 것 |
| --- | --- | --- |
| 분포 | `histplot`, `boxplot` | 개수 / 중앙값·사분위·이상치 |
| 범주 비교 | `barplot`, `countplot` | **평균** / 개수 |
| 관계 | `scatterplot(hue=)` | 점 하나 = 행 하나 |
| 상관 | `heatmap(df.corr(), annot=True)` | 칸 = 상관계수 |

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd
df = pd.DataFrame({'line': ['A', 'B', 'C'] * 3,
                   'temp': [201.5, 207.2, 198.9, 203.1, 209.4, 199.5, 202.0, 208.1, 197.6]})
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(9, 3))
sns.histplot(data=df, x='temp', bins=5, ax=ax1)
sns.boxplot(data=df, x='line', y='temp', ax=ax2)
print(df.groupby('line')['temp'].median())
```

## 상관 히트맵

여러 공정 변수 사이의 관계를 한눈에 볼 때 `df.corr()`를 히트맵으로 그립니다. 1에 가까우면 함께 오르고, −1에 가까우면 반대로 움직입니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd
df = pd.DataFrame({'qty': [520, 480, 610, 505, 470, 630],
                   'defect': [6, 9, 4, 3, 12, 5],
                   'temp': [201.5, 207.2, 198.9, 203.1, 209.4, 199.5]})
corr = df.corr()
fig, ax = plt.subplots(figsize=(4, 3))
sns.heatmap(corr, annot=True, cmap='coolwarm', ax=ax)
print(corr.round(2))
```

> `barplot`의 막대 높이는 합계가 아니라 **평균**입니다. 합계를 보여 주려면 groupby로 먼저 집계한 뒤 그리세요. 상관은 인과가 아니라는 점도 보고서에 함께 적어 두세요.
