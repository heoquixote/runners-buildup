## 조건으로 행 고르기

`df[조건]`은 조건이 True인 행만 남깁니다. 조건은 True/False Series입니다.

- 두 조건 모두: `(조건1) & (조건2)`
- 하나라도: `(조건1) | (조건2)`
- 조건마다 **괄호**를 꼭 칩니다. `and`, `or`는 쓸 수 없습니다

```run
import pandas as pd
df = pd.DataFrame({'line': ['A', 'B', 'C', 'A', 'B'], 'qty': [520, 480, 610, 505, 470], 'defect': [6, 9, 4, 3, 12]})
print(df[df['line'] == 'B'])
print(df[(df['defect'] >= 5) & (df['qty'] < 500)])
```

## loc와 iloc

| | loc | iloc |
| --- | --- | --- |
| 기준 | 라벨(이름) · 조건 | 위치(번호) |
| 예 | `df.loc[df['qty'] > 500, ['line', 'qty']]` | `df.iloc[:3, 0]` |
| 슬라이싱 끝 | 포함 | 미포함 |

```run
import pandas as pd
df = pd.DataFrame({'line': ['A', 'B', 'C', 'A', 'B'], 'qty': [520, 480, 610, 505, 470]})
print(df.loc[df['qty'] > 500, ['line', 'qty']])
print(df.iloc[:2])
print(df['qty'].iloc[-1])
```

## isin과 query

여러 값 중 하나는 `isin([...])`, 조건이 길면 `query("...")`로 문자열처럼 씁니다.

```run
import pandas as pd
df = pd.DataFrame({'region': ['서울', '부산', '대구', '서울'], 'price': [39000, 12000, 8500, 159000]})
print(df[df['region'].isin(['서울', '부산'])])
print(df.query("price >= 10000 and region != '대구'"))
```

> 필터 결과를 고쳐 쓰려면 `sub = df[조건].copy()`처럼 복사본을 만드세요. 원본과 섞여 경고(SettingWithCopyWarning)가 나는 것을 막습니다.
