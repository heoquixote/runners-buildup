분석의 절반은 **필요한 행과 열만 남기는 일**입니다. "B라인에서 불량이 5개 이상인 날"처럼 말로 한 조건을 코드로 옮겨 봅니다. [NumPy 배열과 연산](#/l/da-01-0)의 불리언 인덱싱이 표에서도 그대로 쓰입니다.

## 조건으로 행 고르기

`df[조건]`은 조건이 True인 행만 남깁니다. 조건은 True/False Series입니다.

- 두 조건 모두: `(조건1) & (조건2)`
- 하나라도: `(조건1) | (조건2)`
- 조건마다 **괄호**를 꼭 칩니다. `and`, `or`는 쓸 수 없습니다

```run
import pandas as pd
df = pd.DataFrame({'line': ['A', 'B', 'C', 'A', 'B'], 'qty': [520, 480, 610, 505, 470], 'defect': [6, 9, 4, 3, 12]})
print(df['line'] == 'B')                         # 조건만 찍어 보기
print(df[df['line'] == 'B'])
print(df[(df['defect'] >= 5) & (df['qty'] < 500)])
```

조건만 따로 찍으면 행마다 True/False가 나옵니다. 왼쪽 번호가 원래 행 번호 그대로 유지된다는 점도 보세요. 1번과 4번 행이 남았습니다.

## loc와 iloc

`loc`는 **이름**으로, `iloc`는 **위치 번호**로 고릅니다. 둘 다 `[행, 열]` 순서입니다.

| | loc | iloc |
| --- | --- | --- |
| 기준 | 라벨(이름) · 조건 | 위치(번호) |
| 예 | `df.loc[df['qty'] > 500, ['line', 'qty']]` | `df.iloc[:3, 0]` |
| 슬라이싱 끝 | 포함 | 미포함 |

```run
import pandas as pd
df = pd.DataFrame({'line': ['A', 'B', 'C', 'A', 'B'], 'qty': [520, 480, 610, 505, 470]})
print(df.loc[df['qty'] > 500, ['line', 'qty']])
print(df.iloc[:2])
print(df['qty'].iloc[-1])
```

슬라이싱의 끝이 다른 점을 눈으로 확인해 봅니다. 필터를 거치면 행 번호가 건너뛰기 때문에, 이때는 둘의 결과가 크게 달라집니다.

```run
import pandas as pd
df = pd.DataFrame({'line': ['A', 'B', 'C', 'A', 'B'], 'qty': [520, 480, 610, 505, 470]})
print(df.loc[0:2])                 # 이름 0, 1, 2 (끝 포함)
print(df.iloc[0:2])                # 위치 0, 1 (끝 미포함)

sub = df[df['qty'] > 500]
print(sub)                         # 행 이름은 0, 2, 3
print(sub.iloc[1])                 # 두 번째 행 (이름 2)
print(sub.loc[3])                  # 이름이 3인 행
```

## isin과 query

여러 값 중 하나는 `isin([...])`, 조건이 길면 `query("...")`로 문자열처럼 씁니다.

```run
import pandas as pd
df = pd.DataFrame({'region': ['서울', '부산', '대구', '서울'], 'price': [39000, 12000, 8500, 159000]})
print(df[df['region'].isin(['서울', '부산'])])
print(df.query("price >= 10000 and region != '대구'"))
```

`query` 안에서는 `and`, `or`를 그대로 쓸 수 있습니다. 문자열 전체를 큰따옴표로 감쌌으니, 안쪽 값은 작은따옴표로 씁니다.

## 정렬과 상위 n개

`sort_values`로 정렬합니다. 기본은 오름차순이고 `ascending=False`면 큰 값이 먼저 나옵니다. 상위 몇 개만 필요하면 `nlargest`가 짧습니다.

```run
import pandas as pd
df = pd.DataFrame({'line': ['A', 'B', 'C', 'A', 'B'], 'qty': [520, 480, 610, 505, 470], 'defect': [6, 9, 4, 3, 12]})
print(df.sort_values('defect', ascending=False).head(2))
print(df.nlargest(2, 'qty'))
print(df.sort_values(['line', 'qty'], ascending=[True, False]))   # 기준 두 개
```

## 실제 데이터로 묻고 답하기

타이타닉 승객 데이터로 질문을 코드로 옮겨 봅니다.

```run
import pandas as pd
df = pd.read_csv("titanic.csv")

# 질문 1: 1등석 여성은 몇 명이고 생존율은?
first_f = df[(df['class'] == 'First') & (df['sex'] == 'female')]
print(len(first_f), round(first_f['survived'].mean(), 3))

# 질문 2: 3등석 남성은?
third_m = df[(df['class'] == 'Third') & (df['sex'] == 'male')]
print(len(third_m), round(third_m['survived'].mean(), 3))

# 질문 3: 운임 상위 3명의 나이와 등급
print(df.nlargest(3, 'fare')[['fare', 'age', 'class']])
```

1등석 여성 94명의 생존율은 96.8%, 3등석 남성 347명은 13.5%입니다. 필터 두 줄만으로 데이터의 큰 그림이 드러났습니다.

설비 데이터에서도 같은 방식으로 찾아봅니다. 공구 마모가 큰 구간에서 고장이 더 많은지 비교합니다.

```run
import pandas as pd
df = pd.read_csv("ai4i2020.csv")
worn = df[df['tool_wear'] >= 200]
print(len(worn), round(worn['failure'].mean() * 100, 2), "%")
print(round(df['failure'].mean() * 100, 2), "% (전체)")
```

마모 200 이상인 801건의 고장률은 15.36%로, 전체 3.39%의 네 배가 넘습니다. 구간을 잘라 전체와 비교하는 방식은 분석의 기본 동작입니다.

## 값을 고칠 때

필터 결과에 그대로 대입하면 원본이 바뀌지 않거나 경고가 납니다. 원본을 고칠 때는 `loc`로 행과 열을 함께 지정합니다.

```run
import pandas as pd
df = pd.DataFrame({'line': ['A', 'B', 'C'], 'qty': [520, 480, 610]})
df.loc[df['qty'] < 500, 'status'] = 'LOW'
df.loc[df['qty'] >= 500, 'status'] = 'OK'
print(df)
```

> 필터 결과를 고쳐 쓰려면 `sub = df[조건].copy()`처럼 복사본을 만드세요. 원본과 섞여 경고(SettingWithCopyWarning)가 나는 것을 막습니다.
