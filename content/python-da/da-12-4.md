## 막대 대신 점으로

[묶음 막대 · 칸 나누기 읽기](#/l/da-12-3)에서는 두 기준을 막대로 나눠 봤습니다. 막대는 길이로 읽는 그래프라 축이 0에서 시작해야 하고, 막대가 많아지면 빽빽해집니다. **점 그래프**는 막대 대신 값 자리에 점 하나만 찍습니다. 이 레슨에서는 점 그래프 두 가지를 읽습니다.

| 그래프 | 한 줄 설명 | 잘하는 것 |
| --- | --- | --- |
| **pointplot** | 그룹 평균을 점으로 찍고 같은 색끼리 선으로 이음 | 두 기준의 관계(평행 · 엇갈림) 읽기 |
| **dot plot · 롤리팝** | 범주마다 점 하나, 값순으로 정렬 | 범주가 많을 때 순위와 무리 읽기 |

## 평행한 선, 엇갈리는 선

두 기준의 관계를 읽을 때 가장 강력한 그래프는 **점 그래프**(`pointplot`)입니다. 같은 색의 평균을 선으로 이어 주므로, 선의 모양으로 "한 기준의 효과가 다른 기준에 따라 달라지는가"를 읽을 수 있습니다.

::figure{src="content/img/viz/viz15-interaction.svg" alt="두 선이 평행하면 한 기준의 효과가 다른 기준과 상관없이 일정하고, 기울기가 다르거나 엇갈리면 효과가 조건에 따라 달라진다" caption="평행하면 '효과가 일정', 엇갈리면 '조건에 따라 효과가 달라진다'."}

먼저 펭귄 종별 몸무게를 성별로 나눠 봅니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("penguins.csv").dropna()
ax = sns.pointplot(data=df, x="species", y="body_mass_g", hue="sex", dodge=True)
print(df.pivot_table(index="species", columns="sex", values="body_mass_g").round(0))
```

> 해석: 세 종 모두 수컷이 암컷보다 400~800g 무겁고, 두 선이 거의 나란히 움직인다. 종이 달라도 "수컷이 더 무겁다"는 관계는 일정하다.

이번에는 식당 팁을 점심·저녁과 흡연석 여부로 나눠 봅니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("tips.csv")
ax = sns.pointplot(data=df, x="time", y="tip", hue="smoker", dodge=True, errorbar=None)
print(df.pivot_table(index="time", columns="smoker", values="tip").round(2))
```

> 해석: 점심에는 흡연석(Yes) 팁이 2.83달러로 비흡연석(2.67달러)보다 많지만, 저녁에는 비흡연석이 3.13달러로 조금 더 많다. 두 선이 엇갈려, 흡연석 여부와 팁의 관계는 시간대에 따라 방향이 바뀐다. 다만 차이가 0.06~0.16달러로 작아서, 실제로 의미 있는 차이인지는 오차 막대와 함께 봐야 한다.

**이렇게 읽는다**

| 선 모양 | 뜻 | 해석 문장 틀 |
| --- | --- | --- |
| 평행 | 두 기준의 효과가 따로따로 일정 | "A와 상관없이 B가 ~할수록 ~하다" |
| 기울기가 다름 | 한 기준의 효과 크기가 다른 기준에 따라 다름 | "B의 효과는 A가 ~일 때 더 크다" |
| 엇갈림 | 효과의 방향이 뒤집힘 | "A가 ~일 때는 ~, ~일 때는 반대다" |

**잘못 읽기 쉬운 점**: 선이 조금만 엇갈려도 "방향이 바뀐다"고 단정하기 쉽습니다. 차이가 오차 막대 안에 들어오는 정도라면 우연일 수 있습니다. `errorbar=None`을 지우고 다시 실행해 오차 막대와 함께 보세요.

## 점 그래프(dot plot): 범주가 많을 때

비교할 범주가 6개, 9개처럼 많아지면 막대가 빽빽해집니다. **점 그래프**(dot plot)는 막대 대신 점 하나만 찍어 잉크를 줄이고, 값순으로 정렬해 순위를 읽기 쉽게 합니다. 막대가 없으니 축이 0에서 시작하지 않아도 됩니다. 타이타닉 등급 × (성인 남자·여자·어린이) 9개 조합의 생존율을 그려 봅니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("titanic.csv")
rate = df.groupby(["class", "who"])["survived"].mean().sort_values()
labels = [f"{c} {w}" for c, w in rate.index]
fig, ax = plt.subplots(figsize=(6, 4))
ax.hlines(labels, 0, rate.values, color="lightgray")
ax.plot(rate.values, labels, "o", color="crimson")
ax.set_xlabel("Survival rate")
print(rate.round(2))
```

점에서 왼쪽 축까지 가는 회색 선을 그은 모양을 **롤리팝(막대사탕) 그래프**라고 부릅니다. 점만 남기면 점 그래프입니다.

> 해석: 생존율 하위 3개는 모두 성인 남자(2등실 0.08, 3등실 0.12, 1등실 0.35)이고, 상위 4개는 1·2등실 여성과 어린이(0.83~1.00)다. 3등실 여성과 어린이(0.43~0.49)는 그 중간에 따로 모여 있다.

**이렇게 읽는다**: 정렬된 점 그래프는 **점들이 모여 있는 무리와 무리 사이 빈틈**을 찾으면 됩니다. 위 결과에서는 0.35와 0.43 사이, 0.49와 0.83 사이가 큰 빈틈이라 세 무리로 나뉩니다.
## 정리: 점 그래프

| 그래프 | 코드 | 먼저 읽을 것 | 주의 |
| --- | --- | --- | --- |
| 점 그래프 (평행 · 엇갈림) | `sns.pointplot(..., hue=, dodge=True)` | 선이 평행인가, 엇갈리나 | 작은 엇갈림은 오차 막대와 함께 |
| 점 그래프 · 롤리팝 | `ax.hlines` + `ax.plot(..., "o")` | 정렬 순위, 무리와 빈틈 | 값순으로 정렬 |

비교 그래프를 모두 봤습니다. 막대는 **길이**, 점은 **위치**로 읽습니다. 길이로 읽는 막대는 축이 0에서 시작해야 하고, 위치로 읽는 점은 그럴 필요가 없습니다.
