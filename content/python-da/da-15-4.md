## 여러 관계를 한 번에

열이 4개면 두 개씩 짝지은 산점도가 6개 나옵니다. 하나씩 그리는 대신 **한 장에 모두** 깔아 놓고 훑어보는 그래프가 `pairplot`이고, 관계 하나를 산점도와 분포까지 함께 자세히 보는 그래프가 `jointplot`입니다. 이 레슨의 마지막에는 그룹을 섞어 보면 관계가 **뒤집히는** 현상을 직접 확인합니다.

## pairplot: 산점도 행렬

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("penguins.csv").dropna()
cols = ["bill_length_mm", "bill_depth_mm", "flipper_length_mm", "body_mass_g"]
g = sns.pairplot(df[cols], height=1.6)
print("칸 개수:", len(g.axes.flat))
```

**무엇을 나타내나**

- 4 × 4 = 16칸. 행의 변수가 y, 열의 변수가 x인 산점도입니다.
- **대각선**: 자기 자신과의 산점도는 의미가 없으므로 그 변수의 **히스토그램**을 그립니다.
- 대각선 **위아래는 x·y만 바뀐 같은 그림**입니다. 한쪽만 읽으면 됩니다.

**이렇게 읽는다**

1. 대각선의 히스토그램으로 각 변수의 **분포**(봉우리 개수)를 먼저 봅니다.
2. 대각선 아래 산점도 6개를 훑으며 **띠 모양이 뚜렷한 칸**(강한 관계)을 찾습니다.
3. **점이 덩어리로 나뉜 칸**을 찾습니다. 덩어리가 보이면 숨은 그룹이 있다는 신호입니다.

> 해석: 지느러미-몸무게 칸이 가장 가는 띠를 이뤄 관계가 가장 강하다([상관계수와 히트맵 읽기](#/l/da-15-3)의 r = 0.87). 그런데 대각선의 히스토그램 여러 개가 봉우리 두 개이고, 부리 깊이가 들어간 칸들은 점이 두 덩어리로 뚜렷하게 나뉜다. 섞인 그룹이 있다는 신호다.

## 색으로 그룹 나누기

덩어리가 보였으니 `hue="species"`로 종을 칠합니다. 대각선은 히스토그램 대신 종별 밀도 곡선(KDE)으로 바뀝니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("penguins.csv").dropna()
cols = ["bill_length_mm", "bill_depth_mm", "flipper_length_mm", "body_mass_g", "species"]
g = sns.pairplot(df[cols], hue="species", height=1.6, plot_kws={"s": 10})
print(df.groupby("species")[["bill_length_mm", "bill_depth_mm"]].median())
```

> 해석: 부리 깊이 칸에서 나뉘던 두 덩어리 중 아래쪽(부리 깊이 15mm 근처)은 Gentoo, 위쪽(18mm 근처)은 Adelie와 Chinstrap이다. 부리 길이-부리 깊이 칸에서는 세 종이 각각 따로 모여, 이 두 변수만 알아도 종을 거의 구분할 수 있다.

**잘못 읽기 쉬운 점**: pairplot은 **훑어보기용**입니다. 칸이 작아서 세부 패턴을 단정하기 어렵고, 변수가 6~7개를 넘으면 칸이 너무 많아집니다. 흥미로운 칸을 찾으면 그 두 변수만 따로 크게 그려 확인합니다.

## jointplot: 관계 하나를 자세히

`jointplot`은 가운데에 산점도, 위와 오른쪽에 x와 y 각각의 분포를 붙입니다. 관계와 분포를 한 그림에서 봅니다. `kind="reg"`는 추세선까지 긋습니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("tips.csv")
g = sns.jointplot(data=df, x="total_bill", y="tip", kind="reg", height=4.5)
print("r:", round(df["total_bill"].corr(df["tip"]), 2))
print("계산 금액 중앙값:", df["total_bill"].median(), "/ 팁 중앙값:", df["tip"].median())
```

**이렇게 읽는다**: ① 가운데 산점도로 관계([산점도 읽기](#/l/da-15-1)의 네 가지) ② 위쪽 히스토그램으로 x의 분포 ③ 오른쪽 히스토그램으로 y의 분포.

> 해석: 가운데는 r = 0.68의 양의 관계이고, 위·오른쪽 히스토그램을 보면 계산 금액(중앙값 17.8달러)과 팁(중앙값 2.9달러) 모두 오른쪽 꼬리 분포다. 큰 금액·큰 팁의 점이 드물기 때문에, 오른쪽 위에서 추세선의 띠가 넓어진다.

데이터가 많아 점이 겹치면 `kind="hex"`(육각형 칸마다 개수를 색으로)나 `kind="kde"`(등고선)로 바꿀 수 있습니다.

## 섞으면 뒤집힌다: 심슨의 역설

[상관계수와 히트맵 읽기](#/l/da-15-3)의 히트맵에서 부리 깊이와 몸무게의 r은 −0.47이었습니다. "부리가 깊을수록 가볍다"는 뜻일까요? 전체와 종별 추세선을 함께 그려 봅니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("penguins.csv").dropna()
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(10, 4), sharey=True)
sns.regplot(data=df, x="bill_depth_mm", y="body_mass_g", ax=ax1, scatter_kws={"s": 10}, ci=None)
ax1.set_title("all penguins")
sns.scatterplot(data=df, x="bill_depth_mm", y="body_mass_g", hue="species", s=10, ax=ax2)
for name, part in df.groupby("species"):
    sns.regplot(data=part, x="bill_depth_mm", y="body_mass_g", scatter=False, ci=None, ax=ax2)
    print(name, "r:", round(part["bill_depth_mm"].corr(part["body_mass_g"]), 2))
ax2.set_title("by species")
print("전체 r:", round(df["bill_depth_mm"].corr(df["body_mass_g"]), 2))
```

**이렇게 읽는다**: 전체 선의 방향과 **그룹 안의 선의 방향**을 비교합니다. 방향이 반대면 그룹을 섞어서 생긴 착시입니다.

> 해석: 전체로 보면 r = −0.47로 부리가 깊을수록 가벼워 보인다. 하지만 종별로 나누면 Adelie 0.58, Chinstrap 0.60, Gentoo 0.72로 **세 종 모두** 부리가 깊을수록 무겁다. Gentoo가 "부리는 얕고(15mm) 몸은 무거운(5,050g)" 종이라 오른쪽 아래가 아닌 왼쪽 위에 따로 모여 있어서, 섞어 그으면 선이 거꾸로 기운 것이다.

이렇게 **그룹을 섞으면 관계 방향이 뒤집히는 현상**을 **심슨의 역설**이라고 합니다. 이 데이터에서 올바른 결론은 "같은 종 안에서는 부리가 깊을수록 무겁다"입니다.

| 상황 | 의심할 것 |
| --- | --- |
| 산점도에 덩어리가 보인다 | 숨은 그룹이 있다 → `hue=`로 나눠 본다 |
| 전체 r과 그룹별 r의 부호가 다르다 | 심슨의 역설 → 그룹별 결론을 보고한다 |
| 그룹별로 나눌 변수가 없다 | 결론에 "다른 요인이 섞였을 수 있다"고 적는다 |

## 정리: 여러 관계 보기

| 그래프 | 코드 | 먼저 읽을 것 | 주의 |
| --- | --- | --- | --- |
| 산점도 행렬 | `sns.pairplot(df[열들])` | 대각선 분포 → 띠가 뚜렷한 칸 → 덩어리 | 훑어보기용, 변수 6개 이하 |
| 그룹별 행렬 | `sns.pairplot(..., hue=)` | 그룹이 갈리는 칸 | 칸이 작아 세부는 따로 확인 |
| 관계 + 분포 | `sns.jointplot(data=, x=, y=, kind="reg")` | 가운데 관계, 가장자리 분포 | 점이 많으면 `kind="hex"` |
| 심슨의 역설 확인 | 전체 선 vs `hue=` 그룹별 선 | 선 방향이 같은가 | 그룹별 결론을 보고 |
