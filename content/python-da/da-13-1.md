## 추이: "시간에 따라 어떻게 변하나?"

매달 매출, 매일 방문자, 해마다 인구처럼 **시간 순서가 있는 값**을 볼 때의 질문은 "늘고 있나, 줄고 있나, 반복되는 패턴이 있나"입니다. 이런 질문에는 **선 그래프**로 답합니다. 점과 점을 선으로 잇는 이유는 "그 사이에도 시간이 이어져 있다"는 흐름을 보여 주기 위해서입니다.

선 그래프를 보면 네 가지를 구분해 읽어야 합니다.

::figure{src="content/img/viz/viz12-line-patterns.svg" alt="선 그래프 패턴 네 가지: 꾸준히 오르는 추세, 일정한 간격으로 반복되는 계절성, 규칙 없이 오르내리는 불규칙 변동, 한 지점에서 갑자기 튀는 급변" caption="추세 · 계절성 · 불규칙 변동 · 급변. 실제 데이터에는 이것들이 섞여 있습니다."}

| 패턴 | 뜻 | 예 |
| --- | --- | --- |
| **추세** | 긴 시간 동안의 전체 방향 | 해마다 승객이 늘어난다 |
| **계절성** | 일정한 간격으로 반복되는 오르내림 | 매년 여름에 승객이 몰린다 |
| **불규칙 변동** | 규칙 없는 작은 들쭉날쭉 | 날씨, 우연 |
| **급변(이상점)** | 한두 지점에서 갑자기 튀거나 꺾임 | 행사, 사고, 기록 오류 |

이번 레슨은 1949~1960년 월별 항공 승객 수(`flights.csv`, 단위 천 명, 144개월)로 이 네 가지를 하나씩 떼어 읽어 봅니다.

## 전체 선 그래프: 패턴이 섞여 있다

144개월을 순서대로 이어 그려 봅니다. x축에 쓸 날짜는 연도와 월을 합쳐 만듭니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("flights.csv")
df["date"] = pd.to_datetime(df["year"].astype(str) + "-" + df["month"], format="%Y-%B")
fig, ax = plt.subplots(figsize=(8, 3))
ax.plot(df["date"], df["passengers"])
ax.set_ylabel("Passengers (thousands)")
print("처음:", df["passengers"].iloc[0], "/ 마지막:", df["passengers"].iloc[-1], "/ 최댓값:", df["passengers"].max())
```

**무엇을 나타내나**

- x축: 시간(월). 왼쪽이 과거, 오른쪽이 최근
- y축: 그 달의 승객 수
- 선의 **기울기**: 변화의 속도. 가파를수록 빠르게 변함

**이렇게 읽는다**

1. **전체 방향**: 왼쪽 끝과 오른쪽 끝을 이어 보면 어느 쪽으로 기울었나 → 추세
2. **반복**: 같은 모양의 봉우리가 일정한 간격으로 나오나 → 계절성
3. **폭**: 오르내림의 폭이 일정한가, 커지나
4. **튀는 곳**: 패턴에서 벗어난 점이 있나

> 해석: 승객 수는 1949년 1월 112(천 명)에서 1960년 12월 432로 꾸준히 늘었다(추세). 해마다 여름에 봉우리가 생기는 계절 패턴이 있고, 봉우리 높이가 해가 갈수록 커져 1960년 7월 622로 최고를 기록했다. 뚜렷하게 튀는 이상점은 없다.

"봉우리 높이가 커진다"는 것도 중요한 해석입니다. 계절에 따른 차이가 일정한 숫자가 아니라 **전체 규모에 비례해** 커지고 있다는 뜻이기 때문입니다([추세를 또렷하게: 이동평균 · 로그 축 · 기준선](#/l/da-13-2)의 로그 축에서 다시 봅니다).

## 추세만 보기: 연도별로 묶기

계절 오르내림을 지우고 추세만 보려면, 1년치를 합쳐 연도별 선을 그립니다. 묶는 단위를 크게 하면 짧은 반복이 사라집니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("flights.csv")
yearly = df.groupby("year")["passengers"].sum()
fig, ax = plt.subplots(figsize=(7, 3))
ax.plot(yearly.index, yearly.values, marker="o")
growth = (yearly.pct_change() * 100).round(1)
print(growth.tolist())
```

출력은 전년 대비 증가율(%)입니다. 첫해는 비교할 전년이 없어 `nan`입니다.

> 해석: 연간 승객은 12년 동안 한 번도 줄지 않고 1,520에서 5,714로 약 3.8배가 됐다. 증가율은 해마다 3~22%로 들쭉날쭉한데, 1958년(3.4%)에 가장 낮았다가 다시 11~12%로 회복했다.

**이렇게 읽는다**: 연도별 선에서는 **기울기가 가장 가파른 구간**과 **가장 완만한 구간**을 찾습니다. 위 그래프에서 1957~1958년 구간이 눈에 띄게 완만한데, 증가율 숫자(3.4%)가 그 사실을 확인해 줍니다. 그래프로 찾고 숫자로 확인하는 것이 좋은 순서입니다.

## 계절성만 보기: 같은 달끼리 평균

반대로 추세를 지우고 계절 패턴만 보려면, **같은 달끼리** 12년치를 평균 냅니다. seaborn의 `lineplot`은 같은 x에 값이 여러 개면 알아서 평균을 선으로 잇고 흔들림 범위를 띠로 그립니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("flights.csv")
df["month"] = df["month"].str[:3]
ax = sns.lineplot(data=df, x="month", y="passengers", marker="o")
print(df.groupby("month", sort=False)["passengers"].mean().round(0).to_dict())
```

**무엇을 나타내나**: 선 = 그 달의 12년 평균, 옅은 띠 = 평균의 신뢰구간([평균과 오차 막대 읽기](#/l/da-12-2)의 오차 막대와 같은 뜻).

> 해석: 평균 승객은 7·8월에 351(천 명)로 가장 많고, 11월(233)과 2월(235)에 가장 적다. 여름 성수기는 비수기보다 약 1.5배 붐빈다.

**잘못 읽기 쉬운 점**: 여기서 띠가 넓은 것은 "여름이 불확실하다"는 뜻이 아닙니다. 같은 7월이라도 1949년(148)과 1960년(622)이 크게 다르기 때문입니다. 즉 띠의 폭에는 **추세가 섞여 있습니다.** 띠를 해석할 때는 "무엇이 섞여서 넓어졌나"를 먼저 생각하세요.

## y축 범위가 바꾸는 인상

같은 선이라도 y축 범위에 따라 변화가 크게도 작게도 보입니다. 1958년 한 해만 두 가지로 그려 봅니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("flights.csv")
y58 = df[df["year"] == 1958]
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(9, 3))
ax1.plot(y58["month"].str[:3], y58["passengers"], marker="o")
ax1.set_title("Auto y-range")
ax2.plot(y58["month"].str[:3], y58["passengers"], marker="o")
ax2.set_ylim(0, 700)
ax2.set_title("y from 0")
print("최소", y58["passengers"].min(), "/ 최대", y58["passengers"].max())
```

왼쪽은 y축이 데이터 범위(310~505)에 딱 맞춰져 계절 변화가 극적으로 보이고, 오른쪽은 0부터라 완만해 보입니다.

**잘못 읽기 쉬운 점**: 막대 그래프와 달리 **선 그래프는 y축이 0에서 시작하지 않아도 괜찮습니다.** 선 그래프는 길이가 아니라 **모양(오르내림)**을 보는 그래프이기 때문입니다. 대신 해석할 때는 **눈에 보이는 기울기가 아니라 축에 적힌 숫자로** 변화의 크기를 말해야 합니다. "그래프가 크게 올랐다"가 아니라 "310에서 505로 63% 늘었다"처럼요.

## 순서가 없는 범주를 선으로 잇지 않기

선 그래프는 x에 **순서**가 있을 때만 씁니다. 반, 지역, 제품처럼 순서가 없는 범주를 선으로 이으면, 선의 기울기가 아무 의미 없는 "변화"처럼 보입니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("titanic.csv")
fare = df.groupby("embark_town")["fare"].mean()
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(9, 3))
ax1.plot(fare.index, fare.values, marker="o")
ax1.set_title("Wrong: line")
ax2.bar(fare.index, fare.values)
ax2.set_title("Right: bar")
print(fare.round(1))
```

왼쪽 선은 "Cherbourg에서 Queenstown으로 갈수록 운임이 떨어진다"는 흐름처럼 보이지만, 항구 이름에는 순서가 없습니다(알파벳순일 뿐). 범주 비교는 막대([막대 그래프 읽기](#/l/da-12-1))로 그립니다.

## 정리: 선 그래프 읽기

| 단계 | 확인할 것 | 해석 문장 틀 |
| --- | --- | --- |
| 1. 축 | x가 시간 순서인가, y 단위, y축 범위 | |
| 2. 추세 | 처음과 끝, 전체 기울기 | "A에서 B로 N배 늘었다" |
| 3. 계절성 | 같은 간격의 반복, 봉우리 시기 | "매년 ~월에 가장 많다" |
| 4. 변동 폭 | 오르내림이 일정한가 커지나 | "계절 차이가 해마다 커진다" |
| 5. 예외 | 튀거나 꺾인 점 | "~년에 증가세가 가장 둔했다" |

| 떼어 보기 | 방법 |
| --- | --- |
| 추세만 | 큰 단위로 묶기 (`groupby("year").sum()`), 이동평균([추세를 또렷하게: 이동평균 · 로그 축 · 기준선](#/l/da-13-2)) |
| 계절성만 | 같은 시기끼리 평균 (`sns.lineplot(x="month")`) |
