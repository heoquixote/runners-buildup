## merge: 키로 두 표 잇기

`pd.merge(왼쪽, 오른쪽, on='키', how=...)`는 엑셀의 VLOOKUP과 같은 일을 합니다.

| how | 남는 행 |
| --- | --- |
| `'inner'` (기본) | 양쪽에 모두 있는 키 |
| `'left'` | 왼쪽 행 전부 (짝 없으면 NaN) |
| `'outer'` | 양쪽 전부 |

```run
import pandas as pd
prod = pd.DataFrame({'line': ['A', 'B', 'C'], 'qty': [520, 480, 610]})
lines = pd.DataFrame({'line': ['A', 'B'], 'manager': ['김현우', '이수진']})
print(pd.merge(prod, lines, on='line'))
left = pd.merge(prod, lines, on='line', how='left')
print(left)
print(left['manager'].isna().sum(), "행은 담당자 없음")
```

## 행이 늘어나는 함정

오른쪽 표에 같은 키가 여러 번 있으면 왼쪽 행이 **그 수만큼 복제**됩니다(1:N). 매출을 합산하면 금액이 부풀려집니다.

::video{ref="dl-m18"}

```run
import pandas as pd
members = pd.DataFrame({'customer': ['c01', 'c02'], 'name': ['서연', '도윤']})
coupons = pd.DataFrame({'customer': ['c01', 'c01', 'c02'], 'coupon': ['W5', 'F10', 'S3']})
merged = pd.merge(members, coupons, on='customer')
print(len(members), "→", len(merged), "행")
print(coupons['customer'].duplicated().any())
```

## concat: 위아래로 붙이기

같은 열 구조의 표(날짜별 파일 등)는 `pd.concat([a, b], ignore_index=True)`로 붙이고, 겹친 행은 `drop_duplicates()`로 정리합니다.

> 결합 전후로 `len()`을 꼭 찍어 보세요. 행 수가 예상과 다르면 키 중복이나 오타(공백, 대소문자)를 의심합니다. `validate='one_to_one'`을 주면 중복이 있을 때 바로 에러가 납니다.
