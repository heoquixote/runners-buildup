데이터는 보통 여러 표로 나뉘어 있습니다. 생산 실적은 현장 시스템에, 담당자는 인사 시스템에 있는 식입니다. 두 표를 붙여야 "담당자별 생산량" 같은 질문에 답할 수 있습니다. 옆으로 잇는 것이 `merge`, 위아래로 쌓는 것이 `concat`입니다.

## merge: 키로 두 표 잇기

`pd.merge(왼쪽, 오른쪽, on='키', how=...)`는 엑셀의 VLOOKUP과 같은 일을 합니다. 양쪽 표에 공통으로 있는 열(키)을 기준으로 짝을 찾아 옆으로 붙입니다.

| how | 남는 행 |
| --- | --- |
| `'inner'` (기본) | 양쪽에 모두 있는 키 |
| `'left'` | 왼쪽 행 전부 (짝 없으면 NaN) |
| `'outer'` | 양쪽 전부 |

```run
import pandas as pd
prod = pd.DataFrame({'line': ['A', 'B', 'C'], 'qty': [520, 480, 610]})
lines = pd.DataFrame({'line': ['A', 'B'], 'manager': ['김현우', '이수진']})
print(pd.merge(prod, lines, on='line'))
left = pd.merge(prod, lines, on='line', how='left')
print(left)
print(left['manager'].isna().sum(), "행은 담당자 없음")
```

기본값인 inner는 담당자가 없는 C라인을 **조용히 없앱니다.** 에러가 나지 않아서 놓치기 쉽습니다. 기준이 되는 표의 행을 지키고 싶으면 `how='left'`를 씁니다.

양쪽 키가 어떻게 어긋나는지는 `indicator=True`로 확인합니다.

```run
import pandas as pd
prod = pd.DataFrame({'line': ['A', 'B', 'C'], 'qty': [520, 480, 610]})
lines = pd.DataFrame({'line': ['A', 'B', 'D'], 'manager': ['김현우', '이수진', '박서준']})
check = pd.merge(prod, lines, on='line', how='outer', indicator=True)
print(check)
print(check['_merge'].value_counts())
```

`both`는 양쪽에 있는 행, `left_only`는 왼쪽에만, `right_only`는 오른쪽에만 있는 행입니다.

## 키 이름이 다를 때

두 표의 키 이름이 다르면 `left_on`, `right_on`으로 각각 지정합니다. 둘 다 있는 열은 `_x`, `_y`가 붙습니다.

```run
import pandas as pd
orders = pd.DataFrame({'order_id': [1, 2, 3], 'cust': ['c01', 'c02', 'c01'], 'date': ['11-01', '11-01', '11-02']})
members = pd.DataFrame({'customer_id': ['c01', 'c02'], 'name': ['서연', '도윤'], 'date': ['01-15', '03-02']})
m = pd.merge(orders, members, left_on='cust', right_on='customer_id', suffixes=('_order', '_join'))
print(m[['order_id', 'name', 'date_order', 'date_join']])
```

## 행이 늘어나는 함정

오른쪽 표에 같은 키가 여러 번 있으면 왼쪽 행이 **그 수만큼 복제**됩니다(1:N). 매출을 합산하면 금액이 부풀려집니다.

::video{ref="dl-m18"}

```run
import pandas as pd
members = pd.DataFrame({'customer': ['c01', 'c02'], 'name': ['서연', '도윤']})
coupons = pd.DataFrame({'customer': ['c01', 'c01', 'c02'], 'coupon': ['W5', 'F10', 'S3']})
merged = pd.merge(members, coupons, on='customer')
print(len(members), "→", len(merged), "행")
print(coupons['customer'].duplicated().any())
```

금액이 어떻게 틀어지는지 숫자로 확인합니다. 주문 금액 합계는 30,000원인데 결합 후에는 40,000원이 됩니다.

```run
import pandas as pd
orders = pd.DataFrame({'customer': ['c01', 'c02'], 'amount': [10000, 20000]})
coupons = pd.DataFrame({'customer': ['c01', 'c01', 'c02'], 'coupon': ['W5', 'F10', 'S3']})
bad = pd.merge(orders, coupons, on='customer')
print(orders['amount'].sum(), "→", bad['amount'].sum())

count = coupons.groupby('customer').size().reset_index(name='n_coupons')
good = pd.merge(orders, count, on='customer')
print(good)
print(good['amount'].sum())
```

오른쪽 표를 **키당 한 행으로 먼저 집계하고** 붙이면 금액이 그대로 유지됩니다. 이 순서만 지켜도 대부분의 사고를 막습니다.

## concat: 위아래로 붙이기

같은 열 구조의 표(날짜별 파일 등)는 `pd.concat([a, b], ignore_index=True)`로 붙이고, 겹친 행은 `drop_duplicates()`로 정리합니다.

```run
import pandas as pd
day1 = pd.DataFrame({'lot': ['L1', 'L2'], 'qty': [100, 120]})
day2 = pd.DataFrame({'lot': ['L2', 'L3'], 'qty': [120, 90]})
all_days = pd.concat([day1, day2], ignore_index=True)
print(all_days)
print(all_days.drop_duplicates())
```

`ignore_index=True`를 빼면 행 번호 0, 1이 두 번씩 나옵니다. 열 이름이 다른 표를 붙이면 없는 칸이 NaN으로 채워지니 열 이름을 먼저 맞춥니다.

## 결합을 검증하는 습관

결합 전후로 `len()`을 꼭 찍어 보세요. 행 수가 예상과 다르면 키 중복이나 오타(공백, 대소문자)를 의심합니다. `validate='one_to_one'`을 주면 중복이 있을 때 바로 에러가 납니다.

```run
import pandas as pd
orders = pd.DataFrame({'customer': ['c01', 'c02'], 'amount': [10000, 20000]})
coupons = pd.DataFrame({'customer': ['c01', 'c01', 'c02'], 'coupon': ['W5', 'F10', 'S3']})
try:
    pd.merge(orders, coupons, on='customer', validate='one_to_one')
except Exception as e:
    print(type(e).__name__, e)

a = pd.DataFrame({'line': ['A ', 'b']})
b = pd.DataFrame({'line': ['A', 'B'], 'manager': ['김현우', '이수진']})
print(len(pd.merge(a, b, on='line')), "행: 공백과 대소문자 때문에 짝을 못 찾음")
a['line'] = a['line'].str.strip().str.upper()
print(len(pd.merge(a, b, on='line')), "행: 정리 후")
```

| 확인 | 코드 |
| --- | --- |
| 키 중복 | `df['key'].duplicated().sum()` |
| 결합 전후 행 수 | `len(left)`, `len(merged)` |
| 짝을 못 찾은 행 | `indicator=True` 또는 `isna().sum()` |
| 합계 유지 | 결합 전후 금액의 `sum()` 비교 |
