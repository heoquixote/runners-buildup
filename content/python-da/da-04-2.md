[원하는 행과 열만 골라내기](#/l/da-04-1)에서 `==`, `>=`, `isin`으로 행을 골랐습니다. 실제 질문은 더 다양합니다. "에러 코드에 TEMP가 들어간 기록", "운임이 10~30 사이인 승객", "나이가 비어 있는 행"처럼 **글자 일부**, **범위**, **빈칸**으로 고르는 경우입니다. 이 레슨에서는 이런 조건을 True/False Series로 만드는 방법을 익힙니다. 만들기만 하면 고르는 방법은 [원하는 행과 열만 골라내기](#/l/da-04-1)와 같습니다.

## 글자 일부로 고르기: str.contains

문자열 열 뒤에 `.str`을 붙이면 [문자열 메서드](#/l/pb-03-1)에서 배운 메서드를 열 전체에 쓸 수 있습니다. `str.contains('글자')`는 그 글자가 **들어 있는지** 행마다 True/False를 줍니다.

```run
import pandas as pd

log = pd.DataFrame({
    'time': ['08:10', '08:45', '09:20', '10:05', '10:30'],
    'code': ['E-TEMP-01', 'W-PRES-02', 'E-TEMP-03', 'I-STARTUP', 'E-RPM-01'],
})
print(log['code'].str.contains('TEMP'))
print(log[log['code'].str.contains('TEMP')])
```

온도 관련 에러 두 건이 골라졌습니다. 앞글자로 고르려면 `str.startswith`, 끝글자로 고르려면 `str.endswith`를 씁니다.

```run
import pandas as pd

log = pd.DataFrame({
    'time': ['08:10', '08:45', '09:20', '10:05', '10:30'],
    'code': ['E-TEMP-01', 'W-PRES-02', 'E-TEMP-03', 'I-STARTUP', 'E-RPM-01'],
})
errors = log[log['code'].str.startswith('E-')]     # E로 시작 = 에러 등급
print(len(errors), errors['code'].tolist())
print(log[log['code'].str.endswith('-01')]['code'].tolist())
```

## 대소문자와 빈칸 조심하기

사람이 입력한 메모는 대소문자가 섞이고 빈칸(`NaN`)도 있습니다. 그대로 `contains`를 쓰면 대소문자가 다른 행을 놓치고, 빈칸에서는 True/False가 아닌 값이 나와 필터가 실패할 수 있습니다.

```run
import pandas as pd

memo = pd.Series(['Leak found', 'no issue', None, 'LEAK suspected', 'ok'])
print(memo.str.contains('leak').tolist())                       # 소문자 leak만 찾는다
print(memo.str.contains('leak', case=False, na=False).tolist())
```

| 옵션 | 뜻 |
| --- | --- |
| `case=False` | 대소문자를 구분하지 않음 |
| `na=False` | 빈칸은 False로 취급 (필터에서 빠짐) |

첫 줄은 `'Leak found'`와 `'LEAK suspected'`를 모두 놓쳤습니다. 대소문자가 다르기 때문입니다. 빈칸 자리는 pandas 버전에 따라 False 또는 NaN이 나오는데, NaN이 섞이면 필터에 넣을 때 에러가 납니다. 두 옵션을 붙이면 두 건을 모두 찾고 빈칸은 확실히 False가 됩니다. **사람이 입력한 열에는 두 옵션을 기본으로 붙인다**고 기억하세요.

## 범위로 고르기: between

`between(아래, 위)`는 `(x >= 아래) & (x <= 위)`를 짧게 쓴 것입니다. **양 끝을 포함**합니다.

```run
import pandas as pd

df = pd.read_csv("titanic.csv")
mid = df[df['fare'].between(10, 30)]
print(len(mid), round(mid['survived'].mean(), 3))
```

운임 10~30 사이 승객 321명의 생존율은 43.3%입니다. 끝을 빼고 싶으면 `inclusive='neither'`, 왼쪽만 포함하려면 `inclusive='left'`를 줍니다.

## 빈칸으로 고르기: isna, notna

"값이 비어 있는 행"도 조건이 됩니다. `isna()`는 빈칸이면 True, `notna()`는 값이 있으면 True입니다.

```run
import pandas as pd

df = pd.read_csv("titanic.csv")
no_age = df[df['age'].isna()]
print(len(no_age), "명 나이 모름")
print(no_age['class'].value_counts())
print(round(no_age['survived'].mean(), 3), round(df[df['age'].notna()]['survived'].mean(), 3))
```

나이가 빈 177명 중 136명이 3등석이고, 이들의 생존율(29.4%)은 나이가 있는 승객(40.6%)보다 낮습니다. 빈칸이 아무 데나 고르게 생긴 것이 아니라 **특정 집단에 몰려 있다**는 뜻입니다. 이럴 때 빈칸 행을 그냥 지우면 3등석 승객이 줄어 결과가 한쪽으로 치우칩니다. 결측을 채우거나 지우기 전에 이렇게 먼저 확인하는 습관이 중요합니다.

> `df['age'] == None`이나 `df['age'] == np.nan`으로는 빈칸을 찾을 수 없습니다. NaN은 자기 자신과도 같지 않다고 정해져 있기 때문입니다. 빈칸은 반드시 `isna()`로 찾습니다.

## 반대 조건: ~

조건 앞에 `~`를 붙이면 True와 False가 뒤집힙니다. "~이 아닌 행"을 고를 때 씁니다.

```run
import pandas as pd

df = pd.read_csv("penguins.csv")
not_biscoe = df[~df['island'].isin(['Biscoe'])]
print(len(df), len(not_biscoe))
print(not_biscoe['island'].value_counts())
```

344마리 중 Biscoe 섬이 아닌 펭귄 176마리가 남았습니다. `~`는 `isin`, `str.contains`, `isna`처럼 True/False를 만드는 어떤 조건에도 붙일 수 있습니다.

## 조건 여러 개 묶기

지금까지 만든 조건은 모두 True/False Series라서 `&`, `|`로 자유롭게 묶을 수 있습니다. 조건마다 괄호를 치는 규칙은 그대로입니다. 조건이 길어지면 변수로 나눠 이름을 붙이면 읽기 쉽습니다.

```run
import pandas as pd

df = pd.read_csv("titanic.csv")
is_child = df['age'] < 15
known_town = df['embark_town'].notna()
cheap = df['fare'].between(0, 15)

sub = df[is_child & known_town & cheap]
print(len(sub), round(sub['survived'].mean(), 3))
```

"승선 항구가 기록되어 있고 운임 15 이하로 탄 15세 미만 아이"는 14명이고 생존율은 78.6%입니다. 조건에 이름을 붙이면 나중에 코드를 읽을 때 질문이 그대로 보입니다.

## 정리

- 글자 일부는 `str.contains` · `startswith` · `endswith`, 사람이 입력한 열에는 `case=False, na=False`
- 범위는 `between`(양 끝 포함), 빈칸은 `isna` · `notna`
- `~`는 조건을 뒤집고, 긴 조건은 변수로 나눠 이름을 붙입니다
