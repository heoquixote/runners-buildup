## 선 그래프: 시간에 따라 어떻게 변하나

선 그래프는 **순서가 있는 x**(날짜, 월, 연도) 위에서 값이 어떻게 변하는지 보여 줍니다. 점과 점을 선으로 잇는 이유는 "그 사이에도 값이 이어져 있다"는 흐름을 보여 주기 위해서입니다. 그래서 순서가 없는 범주(A반, B반, C반)를 선으로 이으면 엉뚱한 흐름을 만들어 냅니다.

이번 레슨에서는 1949~1960년 월별 항공 승객 수(`flights.csv`, 단위 천 명)와 타이타닉 승객 기록(`titanic.csv`)을 씁니다. 먼저 연도별 승객 합계를 구합니다. `groupby`는 데이터 분석 트랙(da-06)에서 배운 "묶어서 집계하기"입니다.

```run
import pandas as pd

df = pd.read_csv("flights.csv")
yearly = df.groupby("year")["passengers"].sum()
print(yearly)
```

12년치 숫자를 선으로 그려 봅니다. 뼈대는 da-09-1과 같고, ③ 그리기에 `ax.plot`을 씁니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("flights.csv")
yearly = df.groupby("year")["passengers"].sum()
fig, ax = plt.subplots(figsize=(7, 3))
ax.plot(yearly.index, yearly.values, marker="o")
ax.set_title("Passengers per year")
ax.set_ylabel("Passengers (thousands)")
print("1949 →", yearly[1949], "/ 1960 →", yearly[1960])
```

1949년 1,520에서 1960년 5,714로, 12년 만에 약 3.8배가 됐습니다. 선이 오른쪽 위로 꾸준히 올라가는 모양이 "계속 늘었다"는 결론을 한눈에 보여 줍니다.

## 여러 선으로 비교하기

같은 칸에 `ax.plot`을 여러 번 부르면 선이 겹쳐 그려집니다. 연도별로 선을 하나씩 그려 "해마다 같은 계절 패턴이 반복되나"를 봅니다. 반복문으로 연도를 돌며 `label`을 붙입니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("flights.csv")
fig, ax = plt.subplots(figsize=(7, 3))
for year in [1950, 1955, 1960]:
    part = df[df["year"] == year]
    ax.plot(part["month"].str[:3], part["passengers"], marker="o", label=str(year))
ax.legend()
print("그린 선:", len(ax.lines), "개")
```

세 선 모두 7~8월에 봉우리가 있습니다. 해마다 여름 휴가철에 승객이 몰리는 **계절 패턴**입니다. 직접 해 보세요: 리스트의 연도를 `[1949, 1952, 1958]`으로 바꾸거나 연도를 더 넣어 보세요. 선이 6개를 넘어가면 색이 비슷해져 읽기 어려워집니다. **한 그래프에 선은 3~5개까지**가 적당합니다.

## 영역 그래프: 선 아래를 칠해 '양' 강조

선과 바닥 사이를 색으로 채우면 '얼마나 많은가'라는 양의 느낌이 강해집니다. `ax.fill_between(x, y)`가 x축(0)부터 y까지를 칠합니다. `alpha`는 투명도(0 투명 ~ 1 불투명)입니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("flights.csv")
yearly = df.groupby("year")["passengers"].sum()
fig, ax = plt.subplots(figsize=(7, 3))
ax.plot(yearly.index, yearly.values, color="teal")
ax.fill_between(yearly.index, yearly.values, color="teal", alpha=0.3)
print("칠한 면적 객체:", len(ax.collections))
```

영역 그래프는 바닥이 0이어야 의미가 있습니다. 값이 오르내리는 모양만 보고 싶다면 그냥 선 그래프가 낫습니다.

## 막대 그래프: 범주끼리 크기 비교

막대 그래프는 **범주(그룹)마다 하나의 값**을 막대 길이로 비교합니다. "어느 그룹이 가장 큰가, 얼마나 차이 나나"에 답합니다. 타이타닉 승객을 객실 등급(First, Second, Third)별로 세어 봅니다.

```run
import pandas as pd

df = pd.read_csv("titanic.csv")
counts = df["class"].value_counts()
print(counts)
```

이 숫자를 `ax.bar(범주, 값)`로 그립니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("titanic.csv")
counts = df["class"].value_counts()
fig, ax = plt.subplots(figsize=(5, 3))
ax.bar(counts.index, counts.values)
ax.set_title("Passengers by class")
print("막대 개수:", len(ax.patches))
```

3등실(Third) 막대가 491명으로 1등실(216명)의 두 배가 넘습니다. 막대 그래프에서 비교하는 것은 **막대의 길이**입니다. 그래서 막대는 반드시 **0에서 시작**해야 합니다.

## 가로 막대와 정렬

범주 이름이 길거나 범주가 많으면 x축 글자가 겹칩니다. 이럴 때는 **가로 막대** `ax.barh(범주, 값)`가 읽기 편합니다. 그리고 막대를 **크기순으로 정렬**하면 순위가 바로 보입니다. 승선 항구(embark_town)별 평균 운임을 정렬해서 그려 봅니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("titanic.csv")
fare = df.groupby("embark_town")["fare"].mean().sort_values()
fig, ax = plt.subplots(figsize=(5, 2.5))
ax.barh(fare.index, fare.values, color="slateblue")
ax.set_xlabel("Average fare")
print(fare.round(1))
```

`sort_values()`로 작은 값부터 정렬했기 때문에 가장 큰 Cherbourg(60.0)가 맨 위에 옵니다. `barh`는 첫 번째 값을 맨 아래에 그리기 때문입니다.

## 막대 위에 값 쓰기

막대 길이만으로는 정확한 숫자를 알기 어렵습니다. `ax.bar`가 돌려주는 막대 묶음을 `ax.bar_label`에 넘기면 막대 끝에 값이 붙습니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("titanic.csv")
rate = df.groupby("class")["survived"].mean().round(2)
fig, ax = plt.subplots(figsize=(5, 3))
bars = ax.bar(rate.index, rate.values, color="orange")
ax.bar_label(bars)
print(rate)
```

`0`과 `1`로 된 열의 평균은 `1`의 비율이므로, 이 막대들은 등급별 **생존율**입니다. 1등실 0.63, 2등실 0.47, 3등실 0.24로 등급이 낮을수록 생존율이 낮았습니다.

## 묶음 막대: 두 기준으로 나눠 비교

"등급별 생존율"을 **성별로 나눠서** 보고 싶다면 막대를 나란히 묶어 그립니다. 핵심은 막대의 **x 위치를 조금씩 옮기는 것**입니다. 범주 위치를 0, 1, 2로 두고, 여성 막대는 왼쪽(−0.2), 남성 막대는 오른쪽(+0.2)에 그립니다.

```run
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd

df = pd.read_csv("titanic.csv")
table = df.pivot_table(index="class", columns="sex", values="survived")
x = np.arange(len(table))
fig, ax = plt.subplots(figsize=(6, 3))
ax.bar(x - 0.2, table["female"], width=0.4, label="female")
ax.bar(x + 0.2, table["male"], width=0.4, label="male")
ax.set_xticks(x, table.index)
ax.legend()
print(table.round(2))
```

`width=0.4`는 막대 폭, `set_xticks(x, 이름)`은 0·1·2 위치에 등급 이름을 붙입니다. 결과를 보면 1등실 여성은 0.97, 3등실 남성은 0.14로, 성별 차이가 등급 차이보다 더 크다는 것이 드러납니다.

## 누적 막대: 전체 안의 구성

막대 하나를 여러 조각으로 **쌓으면** "전체 크기"와 "그 안의 구성"을 함께 보여 줍니다. 두 번째 막대를 그릴 때 `bottom=첫 번째 값`을 주면 그 위에 쌓입니다. 등급별 승객을 생존(1)·사망(0)으로 나눠 쌓아 봅니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("titanic.csv")
table = pd.crosstab(df["class"], df["survived"])
fig, ax = plt.subplots(figsize=(5, 3))
ax.bar(table.index, table[0], label="died", color="gray")
ax.bar(table.index, table[1], bottom=table[0], label="survived", color="seagreen")
ax.legend()
print(table)
```

막대 전체 높이는 등급별 승객 수, 초록 조각은 생존자 수입니다. 3등실은 전체가 가장 크지만 초록 조각(119명)은 작습니다. 누적 막대는 **맨 아래 조각만 0에서 시작**하므로, 위쪽 조각끼리 크기를 정확히 비교하기는 어렵다는 점을 기억하세요. 조각끼리 비교가 중요하면 묶음 막대가 낫습니다.

## pandas로 빠르게 그리기

DataFrame과 Series에는 `.plot()`이 붙어 있어서 한 줄로 그릴 수 있습니다. `kind=`로 종류를 고르고, `ax=`로 그릴 칸을 넘기면 나머지 다듬기는 ax 방식 그대로 이어집니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("titanic.csv")
fig, ax = plt.subplots(figsize=(5, 3))
df["class"].value_counts().plot(kind="bar", ax=ax, rot=0)
ax.set_title("Passengers by class (pandas)")
print("막대 개수:", len(ax.patches))
```

`kind`에는 `"line"`, `"bar"`, `"barh"`, `"hist"`, `"box"`, `"pie"`, `"area"`, `"scatter"`를 넣을 수 있습니다. 데이터를 빠르게 훑어볼 때 편하고, 세밀하게 다듬을 때는 이번 레슨에서처럼 `ax.bar` 등을 직접 씁니다.

## 정리: 추이와 비교 차트

| 차트 | 답하는 질문 | 코드 | 흔한 실수 |
| --- | --- | --- | --- |
| 선 | 시간에 따라 어떻게 변하나 | `ax.plot(x, y)` | 순서 없는 범주를 선으로 잇기, 선 6개 이상 |
| 영역 | 양이 얼마나 쌓였나 | `ax.fill_between(x, y)` | 바닥이 0이 아닌데 칠하기 |
| 막대 | 어느 그룹이 큰가 | `ax.bar(범주, 값)` | 축을 0이 아닌 곳에서 자르기 |
| 가로 막대 | 순위, 긴 이름 | `ax.barh(범주, 값)` | 정렬하지 않기 |
| 묶음 막대 | 두 기준으로 나눠 비교 | `ax.bar(x ± 0.2, 값, width=0.4)` | 묶음이 너무 많기 |
| 누적 막대 | 전체와 구성 | `ax.bar(..., bottom=아래값)` | 위쪽 조각끼리 비교하기 |
