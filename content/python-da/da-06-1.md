## split-apply-combine

`groupby`는 세 단계로 움직입니다. 키별로 **나누고**(split), 그룹마다 **집계하고**(apply), 결과를 **합칩니다**(combine). 결과의 index는 그룹 키입니다.

::video{ref="dl-m03"}

```run
import pandas as pd
df = pd.DataFrame({'line': ['A', 'B', 'C', 'A', 'B', 'C'], 'qty': [520, 480, 610, 505, 470, 630], 'defect': [6, 9, 4, 3, 12, 5]})
qty = df.groupby('line')['qty'].sum()
print(qty)
print((df.groupby('line')['defect'].sum() / qty * 100).round(2))
```

## 여러 집계를 한 번에: agg

`agg(새이름=('열', '함수'))` 형태로 쓰면 결과 열 이름까지 정할 수 있습니다.

```run
import pandas as pd
df = pd.DataFrame({'line': ['A', 'B', 'C', 'A', 'B', 'C'], 'qty': [520, 480, 610, 505, 470, 630], 'temp': [201.5, 207.2, 198.9, 203.1, 209.4, 199.5]})
print(df.groupby('line').agg(qty_sum=('qty', 'sum'), temp_max=('temp', 'max')))
```

## transform과 pivot_table

- `transform`: 그룹 집계값을 **원래 행 수 그대로** 돌려줍니다. "자기 그룹 평균보다 큰가", "그룹 안 비중" 계산에 씁니다
- `pivot_table(index, columns, values, aggfunc)`: 두 키로 교차표를 만듭니다. aggfunc 기본값은 평균입니다

::video{ref="dl-m17"}

```run
import pandas as pd
df = pd.DataFrame({'date': ['11-01', '11-01', '11-02', '11-02'], 'line': ['A', 'B', 'A', 'B'], 'qty': [520, 480, 505, 470]})
df['line_avg'] = df.groupby('line')['qty'].transform('mean')
print(df)
print(df.pivot_table(index='date', columns='line', values='qty', aggfunc='sum'))
```

> groupby 결과를 다시 표로 쓰려면 `.reset_index()`로 키를 열로 되돌립니다.
