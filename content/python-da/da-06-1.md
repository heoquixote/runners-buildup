"라인별 합계", "요일별 평균"처럼 **~별로** 묶어 보는 일은 분석에서 가장 자주 합니다. pb-09에서 딕셔너리로 직접 짰던 집계를 pandas는 한 줄로 해 줍니다.

## split-apply-combine

`groupby`는 세 단계로 움직입니다. 키별로 **나누고**(split), 그룹마다 **집계하고**(apply), 결과를 **합칩니다**(combine). 결과의 index는 그룹 키입니다.

::video{ref="dl-m03"}

```run
import pandas as pd
df = pd.DataFrame({'line': ['A', 'B', 'C', 'A', 'B', 'C'], 'qty': [520, 480, 610, 505, 470, 630], 'defect': [6, 9, 4, 3, 12, 5]})
qty = df.groupby('line')['qty'].sum()
print(qty)
print((df.groupby('line')['defect'].sum() / qty * 100).round(2))
```

읽는 순서대로 쓰면 됩니다. `line`별로 묶어서(`groupby('line')`) `qty` 열을(`['qty']`) 합칩니다(`.sum()`). B라인의 불량률이 2.21%로 가장 높습니다.

불량률은 평균의 평균을 내면 틀립니다. 위 코드처럼 **불량 합계를 수량 합계로 나누어야** 수량이 많은 날이 제대로 반영됩니다.

## 자주 쓰는 집계

| 함수 | 뜻 |
| --- | --- |
| `sum`, `mean`, `median` | 합계, 평균, 중앙값 |
| `min`, `max`, `std` | 최솟값, 최댓값, 표준편차 |
| `count` | 빈칸이 아닌 값의 개수 |
| `size` | 그룹의 행 수 (빈칸 포함) |
| `nunique` | 고유값 개수 |

## 여러 집계를 한 번에: agg

`agg(새이름=('열', '함수'))` 형태로 쓰면 결과 열 이름까지 정할 수 있습니다.

```run
import pandas as pd
df = pd.DataFrame({'line': ['A', 'B', 'C', 'A', 'B', 'C'], 'qty': [520, 480, 610, 505, 470, 630], 'temp': [201.5, 207.2, 198.9, 203.1, 209.4, 199.5]})
print(df.groupby('line').agg(qty_sum=('qty', 'sum'), temp_max=('temp', 'max')))
```

설비 데이터에서 제품 등급별 고장 현황을 정리합니다. 건수와 비율을 함께 봐야 판단할 수 있습니다.

```run
import pandas as pd
df = pd.read_csv("ai4i2020.csv")
result = df.groupby('type').agg(
    n=('failure', 'size'),
    fails=('failure', 'sum'),
    rate=('failure', 'mean'),
    wear=('tool_wear', 'mean'),
).round(3)
print(result.sort_values('rate', ascending=False))
```

고장 건수는 L등급이 235건으로 가장 많은데, L은 전체 건수도 6,000건으로 가장 많습니다. 그래서 비율까지 봐야 합니다. 비율로도 L이 3.9%로 가장 높고 H가 2.1%로 가장 낮으니, 이 데이터에서는 등급이 낮을수록 고장이 잦다고 말할 수 있습니다.

## 두 기준으로 묶기

`groupby`에 리스트를 넣으면 기준이 여러 개가 됩니다. 결과의 index가 두 층이 되니, `reset_index()`로 평범한 표로 되돌리면 다루기 쉽습니다.

```run
import pandas as pd
df = pd.read_csv("titanic.csv")
g = df.groupby(['sex', 'class'], observed=True)['survived'].mean().round(3)
print(g)
print(g.reset_index().head(3))
```

## transform과 pivot_table

- `transform`: 그룹 집계값을 **원래 행 수 그대로** 돌려줍니다. "자기 그룹 평균보다 큰가", "그룹 안 비중" 계산에 씁니다
- `pivot_table(index, columns, values, aggfunc)`: 두 키로 교차표를 만듭니다. aggfunc 기본값은 평균입니다

::video{ref="dl-m17"}

```run
import pandas as pd
df = pd.DataFrame({'date': ['11-01', '11-01', '11-02', '11-02'], 'line': ['A', 'B', 'A', 'B'], 'qty': [520, 480, 505, 470]})
df['line_avg'] = df.groupby('line')['qty'].transform('mean')
print(df)
print(df.pivot_table(index='date', columns='line', values='qty', aggfunc='sum'))
```

`sum`이나 `agg`는 그룹 수만큼 행이 줄고, `transform`은 4행이 그대로 남습니다. 그래서 새 열로 붙일 수 있습니다. 라인 안에서 그날의 비중을 구해 봅니다.

```run
import pandas as pd
df = pd.DataFrame({'date': ['11-01', '11-01', '11-02', '11-02'], 'line': ['A', 'B', 'A', 'B'], 'qty': [520, 480, 505, 470]})
df['share'] = (df['qty'] / df.groupby('date')['qty'].transform('sum') * 100).round(1)
print(df)
print(len(df), "행 그대로,", df.groupby('line')['qty'].sum().shape[0], "행으로 줄어든 집계와 비교")
```

교차표는 두 범주의 조합을 한눈에 보여 줍니다. 앞의 타이타닉 결과를 표로 바꿔 봅니다.

```run
import pandas as pd
df = pd.read_csv("titanic.csv")
print(df.pivot_table(index='sex', columns='class', values='survived', aggfunc='mean', observed=True).round(2))
print(pd.crosstab(df['sex'], df['class']))
```

여성은 1, 2등석 생존율이 90%를 넘고 3등석은 50%입니다. 남성은 1등석도 37%입니다. `crosstab`은 인원수를 세는 교차표입니다. 비율을 볼 때는 인원이 충분한 칸인지 함께 확인합니다.

## 어떤 도구를 고를까

| 원하는 결과 | 도구 |
| --- | --- |
| 그룹마다 값 하나 | `groupby(...).sum()` |
| 그룹마다 여러 지표 | `agg` |
| 원래 표에 그룹 값 붙이기 | `transform` |
| 두 범주의 교차표 | `pivot_table`, `crosstab` |

> groupby 결과를 다시 표로 쓰려면 `.reset_index()`로 키를 열로 되돌립니다.
