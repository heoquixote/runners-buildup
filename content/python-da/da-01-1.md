### 배열은 한 번에 계산합니다

NumPy 배열끼리는 같은 위치끼리 바로 연산됩니다. 반복문 없이 일별 불량률을 구할 수 있습니다.

```run
import numpy as np
defects = np.array([12, 8, 15, 10, 5])
production = np.array([1000, 1050, 980, 1020, 950])
rate = defects / production * 100     # 반복문 없이 원소별 계산
print(np.round(rate, 2))              # 소수 둘째 자리 반올림
print(rate.mean(), rate.max())
```

### 기본 통계량

`np.sum`, `np.mean`, `arr.std(ddof=1)`. 표본 표준편차는 `ddof=1`입니다. 공정능력지수(Cp, Cpk) 계산에서 자주 틀리는 부분입니다.

### 불리언 인덱싱

```run
import numpy as np
sensor_data = np.array([24.1, 25.6, 23.9, 26.2, 25.0])
bool_idx = sensor_data > 25.0        # True/False 배열
print(bool_idx)
print(sensor_data[bool_idx])         # 조건을 만족하는 값만
sensor_data[bool_idx] = -1           # 조건을 만족하는 값을 한 번에 변경
print(sensor_data)
```

> 채점은 출력 문자열이 아니라 문제에서 정한 **변수 값**으로 합니다. 변수 이름을 그대로 쓰세요.
