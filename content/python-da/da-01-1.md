파이썬 리스트로 불량률을 계산하려면 `for`를 돌려 값을 하나씩 처리해야 합니다. 값이 100만 개여도 마찬가지입니다. **NumPy**는 값 묶음을 한 덩어리로 계산하게 해 주는 라이브러리이고, pandas도 그 위에 만들어졌습니다.

## 리스트와 배열은 연산이 다릅니다

엑셀에서 열 전체에 수식을 한 번에 적용하는 것을 떠올리면 됩니다. 배열에 곱하기를 하면 **모든 값에** 곱해집니다. 같은 `* 2`라도 리스트는 전혀 다르게 움직입니다.

```run
import numpy as np

nums = [1, 2, 3]
arr = np.array(nums)        # 리스트를 배열로 바꾼다

print(nums * 2)             # 리스트: 통째로 두 번 반복
print(arr * 2)              # 배열: 값마다 2를 곱함
print(arr + 10)
print(arr.shape, arr.dtype)
```

`shape`는 모양, `dtype`은 값의 종류입니다. `(3,)`은 값이 3개인 1차원 배열이라는 뜻입니다. 배열은 값의 종류가 하나로 통일되어 있어서 계산이 빠릅니다.

## 배열은 한 번에 계산합니다

NumPy 배열끼리는 같은 위치끼리 바로 연산됩니다. 반복문 없이 일별 불량률을 구할 수 있습니다.

```run
import numpy as np
defects = np.array([12, 8, 15, 10, 5])
production = np.array([1000, 1050, 980, 1020, 950])
rate = defects / production * 100     # 반복문 없이 원소별 계산
print(np.round(rate, 2))              # 소수 둘째 자리 반올림
print(rate.mean(), rate.max())
```

닷새의 불량률이 한 줄로 나왔습니다. 가장 높은 값은 3일째의 1.53%입니다. 값을 하나씩 꺼내는 코드가 없어서 읽기도 쉽습니다.

## 기본 통계량

| 코드 | 뜻 |
| --- | --- |
| `arr.sum()`, `arr.mean()` | 합계, 평균 |
| `arr.min()`, `arr.max()` | 최솟값, 최댓값 |
| `arr.argmax()` | 가장 큰 값의 위치 |
| `arr.std(ddof=1)` | 표본 표준편차 |

`np.sum`, `np.mean`처럼 함수로 써도 같습니다. 표준편차는 값이 평균에서 얼마나 퍼져 있는지 나타냅니다. 표본 표준편차는 `ddof=1`입니다. 기본값인 `ddof=0`을 그대로 쓰면 값이 작게 나오므로, 공정능력지수(Cp, Cpk) 계산에서 자주 틀리는 부분입니다.

```run
import numpy as np
x = np.array([10.02, 9.98, 10.05, 10.10, 9.95])
print(round(x.mean(), 3))
print(round(x.std(), 4))          # 기본값 ddof=0
print(round(x.std(ddof=1), 4))    # 표본 표준편차
print(x.argmax(), x.max())
```

표본 표준편차가 0.0587로 기본값 0.0525보다 큽니다. 데이터가 적을수록 둘의 차이가 벌어집니다. `argmax`는 3이므로 네 번째 값 10.10이 가장 큽니다.

## 불리언 인덱싱

배열에 비교 연산을 하면 값마다 True/False가 나옵니다. 이 결과를 대괄호에 넣으면 **True인 자리의 값만** 남습니다. 체로 거르는 것과 같습니다.

```run
import numpy as np
sensor_data = np.array([24.1, 25.6, 23.9, 26.2, 25.0])
bool_idx = sensor_data > 25.0        # True/False 배열
print(bool_idx)
print(sensor_data[bool_idx])         # 조건을 만족하는 값만
sensor_data[bool_idx] = -1           # 조건을 만족하는 값을 한 번에 변경
print(sensor_data)
```

25.0은 "초과"가 아니므로 남지 않습니다. 조건이 몇 개인지 세는 일도 자주 합니다. True는 1, False는 0으로 계산되기 때문에 `sum()`이 개수, `mean()`이 비율이 됩니다.

```run
import numpy as np
size = np.array([10.1, 9.2, 10.4, 10.8, 9.9, 10.0])
ok = (size >= 9.5) & (size <= 10.5)
print(ok)
print(ok.sum(), "개 합격,", round(ok.mean() * 100, 1), "%")
print(size[~ok])                  # ~ 는 True와 False를 뒤집는다
```

조건 여러 개는 `and` 대신 `&`, `or` 대신 `|`를 쓰고, 조건마다 **괄호**를 칩니다. 배열은 값마다 판단해야 하기 때문입니다.

## 이상치 찾기

평균에서 표준편차의 3배 넘게 떨어진 값은 이상치 후보로 봅니다. 데이터가 정규분포에 가까울 때 쓰는 간단한 기준입니다.

```run
import numpy as np
np.random.seed(0)
data = np.append(np.random.normal(100, 2, 50), 125)   # 끝에 튀는 값 하나 추가

z = (data - data.mean()) / data.std(ddof=1)
print(round(data.mean(), 2), round(data.std(ddof=1), 2))
print(data[np.abs(z) > 3].round(1))
```

직접 넣은 125만 걸렸습니다. 이상치를 찾았다고 바로 지우지는 않습니다. 측정 오류인지 실제 이상인지 원인을 먼저 확인합니다.

## 정리

- 배열 연산은 값마다 적용되고, 리스트의 `*`는 반복입니다
- `& | ~`로 조건을 묶고 조건마다 괄호를 칩니다
- True/False의 `sum()`은 개수, `mean()`은 비율입니다
