## 왜 그래프로 그릴까

숫자가 몇 개뿐이면 표로 봐도 충분합니다. 하지만 숫자가 열 개, 백 개가 되면 머릿속으로 흐름을 그리기 어렵습니다. 아래는 1949년 한 해 동안 매달 비행기를 탄 승객 수(단위: 천 명)입니다. 먼저 숫자로만 봅니다.

```run
import pandas as pd

df = pd.read_csv("flights.csv")
y1949 = df[df["year"] == 1949]
print(y1949[["month", "passengers"]].to_string(index=False))
```

12줄을 읽고 "언제 가장 많았나, 늘고 있나 줄고 있나"를 바로 말하기는 쉽지 않습니다. 같은 숫자를 선 하나로 그려 보면 다릅니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("flights.csv")
y1949 = df[df["year"] == 1949]
fig, ax = plt.subplots(figsize=(7, 3))
ax.plot(y1949["month"].str[:3], y1949["passengers"], marker="o")
print("최댓값:", y1949["passengers"].max())
```

여름(7~8월)에 148까지 올랐다가 11월에 104로 떨어지는 모양이 한눈에 보입니다. **시각화는 숫자를 예쁘게 꾸미는 일이 아니라, 데이터를 더 빨리 이해하기 위한 도구**입니다. 그래프는 이런 질문에 답해 줍니다.

- 시간에 따라 값이 어떻게 변하나
- 그룹끼리 차이가 있나
- 값이 어디에 몰려 있고, 튀는 값(이상치)이 있나
- 두 값이 함께 움직이나

이 트랙에서는 파이썬 그래프의 기초 도구인 **matplotlib**(맷플롯립)를 먼저 배우고, 그 위에 지은 **seaborn**(시본)으로 넘어갑니다. seaborn도 속은 matplotlib이라서 여기서 배우는 뼈대가 그대로 쓰입니다.

## 도화지(Figure)와 그래프 칸(Axes)

matplotlib의 그래프는 두 층으로 되어 있습니다.

- **Figure (fig)**: 그림 전체, 즉 **도화지**입니다. 크기를 정하고, 저장할 때 이 단위로 저장합니다.
- **Axes (ax)**: 도화지 위에 놓인 **그래프 한 칸**입니다. x축, y축, 제목, 선, 막대가 모두 이 칸 안에 그려집니다.

액자(fig) 안에 그림(ax)이 한 장 들어갈 수도, 여러 장 들어갈 수도 있다고 생각하면 됩니다. 이름이 헷갈리는데, Axes는 '축(axis)'의 복수형이 아니라 **그래프 한 칸 전체**를 가리킵니다.

::figure{src="content/img/viz/viz01-anatomy.svg" alt="Figure 도화지 안에 Axes 그래프 칸이 있고, 칸 안에 제목, 선, 범례, 격자, 눈금, x축 이름, y축 이름이 있다" caption="그래프의 부품과 그 부품을 정하는 코드. 모든 부품은 ax(그래프 칸) 안에 있습니다."}

`plt.subplots()`는 도화지 한 장과 그래프 칸 하나를 한 번에 만들어 돌려줍니다. 아직 아무것도 그리지 않았으니 빈 칸만 나옵니다.

```run
import matplotlib.pyplot as plt

fig, ax = plt.subplots()
print(type(fig).__name__, type(ax).__name__)
```

출력의 `Figure`와 `Axes`가 바로 도화지와 그래프 칸입니다. `fig, ax = ...`는 두 값을 한 번에 받는 문법입니다(파이썬 기초의 `a, b = 10, 3`과 같습니다).

## 어떤 그래프든 같은 4단계

matplotlib 그래프는 종류가 달라도 순서가 같습니다. 이 순서만 기억하면 선이든 막대든 산점도든 그릴 수 있습니다.

| 단계 | 하는 일 | 코드 |
| --- | --- | --- |
| ① 데이터 | x, y로 쓸 값 준비 | `x = [...]`, `df[...]` |
| ② 판 만들기 | 도화지와 칸 만들기 | `fig, ax = plt.subplots()` |
| ③ 그리기 | 칸에 선·막대·점 그리기 | `ax.plot(x, y)`, `ax.bar(...)`, `ax.scatter(...)` |
| ④ 다듬기 | 제목, 축 이름, 범례 | `ax.set_title(...)`, `ax.set_xlabel(...)` |

아래 셀이 이 4단계를 그대로 따른 가장 작은 그래프입니다. 요일별 방문자 수라고 생각해 보세요.

```run
import matplotlib.pyplot as plt

days = ["Mon", "Tue", "Wed", "Thu", "Fri"]
visits = [120, 135, 128, 160, 190]
fig, ax = plt.subplots(figsize=(6, 3))
ax.plot(days, visits)
ax.set_title("Visits by day")
ax.set_xlabel("Day")
ax.set_ylabel("Visits")
print("그린 선의 개수:", len(ax.lines))
```

`ax.plot(x, y)`에서 **x는 가로축 값, y는 세로축 값**이고, 두 리스트의 길이가 같아야 합니다. 이 사이트(브라우저)에는 한글 글꼴이 없어서 그래프 안의 글자는 영어로 씁니다.

## 짧은 방식 plt.plot과 ax 방식

인터넷 예제에는 `plt.plot(...)`처럼 fig, ax 없이 바로 그리는 코드도 많습니다. 이 방식은 matplotlib이 "지금 그리고 있는 칸"을 알아서 골라 그려 줍니다.

```run
import matplotlib.pyplot as plt

plt.plot([1, 2, 3, 4], [1, 4, 9, 16])
plt.title("Quick plot")
print("plt 방식도 그래프가 나옵니다")
```

짧고 편하지만, 그래프가 두 개 이상이 되면 "지금 어느 칸에 그리는지"가 헷갈립니다. 그래서 이 트랙은 **fig, ax 방식**을 기본으로 씁니다. 함수 이름도 조금 다릅니다.

| plt 방식 | ax 방식 |
| --- | --- |
| `plt.title()` | `ax.set_title()` |
| `plt.xlabel()` / `plt.ylabel()` | `ax.set_xlabel()` / `ax.set_ylabel()` |
| `plt.xlim()` / `plt.ylim()` | `ax.set_xlim()` / `ax.set_ylim()` |

> 입문은 `plt`, 실전은 `ax`. 여러 그래프를 배치하거나 보고서용으로 반복해서 그릴 때 ax 방식이 훨씬 안정적입니다.

## 색 · 선 모양 · 마커

`ax.plot`에 이름 붙은 값(인자)을 더하면 선의 모양이 바뀝니다. `color`는 색, `linestyle`은 선 모양, `marker`는 점 모양입니다.

```run
import matplotlib.pyplot as plt

days = ["Mon", "Tue", "Wed", "Thu", "Fri"]
visits = [120, 135, 128, 160, 190]
fig, ax = plt.subplots(figsize=(6, 3))
ax.plot(days, visits, color="tomato", linestyle="--", marker="o")
print("marker:", ax.lines[0].get_marker())
```

직접 바꿔 보세요. `linestyle`에 `"-"`(실선), `":"`(점선), `"-."`, `marker`에 `"s"`(네모), `"^"`(세모), `"x"`를 넣고 다시 실행합니다. `linewidth=3`으로 굵기도 바꿀 수 있습니다.

```run
import matplotlib.pyplot as plt

days = ["Mon", "Tue", "Wed", "Thu", "Fri"]
visits = [120, 135, 128, 160, 190]
fig, ax = plt.subplots(figsize=(6, 3))
ax.plot(days, visits, color="seagreen", linestyle=":", marker="s", linewidth=3)
print("linestyle:", ax.lines[0].get_linestyle())
```

> `ax.plot(x, y, "ro-")`처럼 색·마커·선을 글자 세 개로 줄여 쓰는 방식(포맷 문자열)도 있습니다. 알아만 두고, 코드를 읽기 쉽게 이름을 붙여 쓰는 편을 권합니다.

## 범례: 선이 여러 개일 때

선을 두 개 이상 그리면 어느 선이 무엇인지 알려 줘야 합니다. 각 `plot`에 `label="이름"`을 주고, 마지막에 `ax.legend()`를 부르면 범례 상자가 생깁니다.

```run
import matplotlib.pyplot as plt

days = ["Mon", "Tue", "Wed", "Thu", "Fri"]
fig, ax = plt.subplots(figsize=(6, 3))
ax.plot(days, [120, 135, 128, 160, 190], marker="o", label="Store A")
ax.plot(days, [90, 110, 140, 150, 145], marker="o", label="Store B")
ax.legend()
print("범례 항목:", [t.get_text() for t in ax.get_legend().get_texts()])
```

`label`만 주고 `legend()`를 안 부르면 범례가 나오지 않습니다. 반대로 `label` 없이 `legend()`만 부르면 빈 범례가 됩니다. 둘은 짝입니다.

## 축 범위 · 격자 · 기준선

y축이 어디서 시작하느냐에 따라 같은 차이도 크게, 작게 보입니다. `set_ylim(아래, 위)`로 범위를 직접 정할 수 있습니다. `grid`는 눈금선을 그어 값을 읽기 쉽게 하고, `axhline`은 목표·기준 같은 **가로 기준선**을 긋습니다.

```run
import matplotlib.pyplot as plt

days = ["Mon", "Tue", "Wed", "Thu", "Fri"]
visits = [120, 135, 128, 160, 190]
fig, ax = plt.subplots(figsize=(6, 3))
ax.plot(days, visits, marker="o")
ax.set_ylim(0, 220)
ax.grid(True, alpha=0.3)
ax.axhline(150, color="red", linestyle="--", label="Target 150")
ax.legend()
print("목표를 넘긴 날:", [d for d, v in zip(days, visits) if v > 150])
```

빨간 점선 위로 올라간 목요일과 금요일이 목표를 넘긴 날입니다. 기준선 하나가 "그래서 좋은 거야, 나쁜 거야?"라는 질문에 바로 답해 줍니다. 세로 기준선은 `ax.axvline(x값)`입니다.

## 크기와 저장

도화지 크기는 `plt.subplots(figsize=(가로, 세로))`로 정합니다. 단위는 인치이고, 가로로 긴 추이 그래프는 `(8, 3)`, 정사각형에 가까운 산점도는 `(5, 4)` 정도가 보기 좋습니다.

```run
import matplotlib.pyplot as plt

fig, ax = plt.subplots(figsize=(8, 2))
ax.plot([3, 5, 4, 6, 8, 7, 9])
print("도화지 크기(인치):", fig.get_size_inches())
```

그래프를 파일로 남기려면 `fig.savefig("파일이름.png", dpi=150, bbox_inches="tight")`를 씁니다. `dpi`는 선명도(높을수록 선명), `bbox_inches="tight"`는 바깥 빈 여백을 잘라 줍니다. 자세한 저장은 da-09-4에서 다시 다룹니다.

> **내 컴퓨터에서 한글 쓰기**: 주피터·VS Code에서는 맨 위에 `plt.rc("font", family="Malgun Gothic")`(윈도우) 또는 `"AppleGothic"`(맥)과 `plt.rc("axes", unicode_minus=False)`(마이너스 기호 깨짐 방지)를 넣으면 한글 제목을 쓸 수 있습니다. 내 컴퓨터에서 그릴 때는 마지막에 `plt.show()`로 그림을 띄웁니다.
