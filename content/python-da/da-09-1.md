## fig와 ax

matplotlib는 **그림(fig)** 위에 **축(ax)**을 놓고 그립니다. `fig, ax = plt.subplots()`로 만든 뒤 `ax.plot`, `ax.bar`, `ax.scatter`를 부릅니다. 실행하면 아래 실습 결과에 그래프가 이미지로 나옵니다.

> 이 사이트(브라우저)에는 한글 글꼴이 없어 그래프 글자는 영어로 씁니다. 내 컴퓨터에서는 `plt.rc('font', family='Malgun Gothic')`(윈도우), `'AppleGothic'`(맥)으로 한글을 쓸 수 있습니다.

## 무엇을 보여 줄까 → 어떤 그래프

| 질문 | 그래프 | 메서드 |
| --- | --- | --- |
| 시간에 따라 어떻게 변하나 | 선 | `ax.plot` |
| 범주끼리 얼마나 다른가 | 막대 | `ax.bar`, `ax.barh` |
| 두 변수가 함께 움직이나 | 산점도 | `ax.scatter` |
| 값이 어떻게 퍼져 있나 | 히스토그램 | `ax.hist` |

```run
import matplotlib.pyplot as plt
days = ['11-01', '11-02', '11-03', '11-04', '11-05']
rate = [1.8, 2.4, 1.5, 3.1, 2.2]
fig, ax = plt.subplots(figsize=(6, 3))
ax.plot(days, rate, marker='o')
ax.axhline(2.5, color='red', linestyle='--')
ax.set_title('Daily defect rate')
ax.set_ylabel('Defect rate (%)')
print("평균 불량률", sum(rate) / len(rate))
```

## 서브플롯: 한 그림에 여러 축

`plt.subplots(1, 2)`는 축 두 개를 돌려줍니다. 비교할 그래프를 나란히 둘 때 씁니다.

```run
import matplotlib.pyplot as plt
lines = ['A', 'B', 'C']
qty = [1565, 1405, 1840]
temp = [201.5, 207.2, 198.9, 203.1, 209.4, 199.5]
defect = [6, 9, 4, 3, 12, 5]
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(9, 3))
ax1.bar(lines, qty)
ax1.set_title('Output by line')
ax2.scatter(temp, defect)
ax2.set_xlabel('Temp')
ax2.set_ylabel('Defects')
print(len(ax1.patches), "개 막대,", len(temp), "개 점")
```

> 그래프마다 제목과 축 이름(단위 포함)을 다는 습관이 보고서의 질을 가릅니다. 기준선(규격, 목표)이 있으면 `axhline`으로 함께 그려 주세요.
