[표 데이터를 불러와 첫인상 잡기](#/l/da-03-1)에서 딕셔너리로 표를 만들고, 대입으로 새 열을 하나 추가했습니다. 실무에서는 표를 만들고 나서 열을 **더하고, 이름을 바꾸고, 빼고, 순서를 정리하는** 일을 계속 반복합니다. 이 레슨에서는 그 동작을 하나씩 익힙니다.

## 표를 만드는 두 가지 방법

같은 표를 두 방향으로 만들 수 있습니다.

| 방법 | 모양 | 어울리는 경우 |
| --- | --- | --- |
| 열 단위 딕셔너리 | `{'열': [값, 값, ...]}` | 열마다 값을 이미 모아 둔 경우 |
| 행 단위 딕셔너리 리스트 | `[{'열': 값, ...}, {...}]` | 기록이 한 건씩 생기는 경우 (로그, API 응답) |

```run
import pandas as pd

by_col = pd.DataFrame({'lot': ['L01', 'L02'], 'qty': [500, 480]})

records = [
    {'lot': 'L01', 'qty': 500},
    {'lot': 'L02', 'qty': 480, 'memo': '재검'},   # 이 행에만 memo가 있다
]
by_row = pd.DataFrame(records)
print(by_col)
print(by_row)
```

행 단위로 만들면 어떤 행에만 있는 키(`memo`)도 열이 되고, 값이 없는 칸은 `NaN`(값 없음)으로 채워집니다. [JSON으로 설정과 결과 저장하기](#/l/pb-10-3)의 JSON 기록이나 API 응답은 대부분 이 모양이라 `pd.DataFrame(records)` 한 줄로 표가 됩니다.

## 열 여러 개 꺼내기와 순서 바꾸기

열 하나는 `df['qty']`로 꺼내면 Series입니다. 열 여러 개는 **리스트**를 넣어 `df[['lot', 'qty']]`처럼 꺼내고, 결과는 DataFrame입니다. 대괄호가 두 겹인 이유는 안쪽이 리스트이기 때문입니다.

```run
import pandas as pd

df = pd.DataFrame({'qty': [500, 480, 610], 'lot': ['L01', 'L02', 'L03'], 'defect': [6, 9, 4]})
print(df.columns.tolist())
print(df[['lot', 'qty', 'defect']])     # 원하는 순서로 다시 꺼내기
```

리스트에 적은 순서대로 열이 나옵니다. 보고서용 표를 만들 때 이 방법으로 열 순서를 정리합니다.

## 계산으로 새 열 만들기

열끼리 계산한 결과를 대입하면 새 열이 맨 오른쪽에 생깁니다. 같은 이름에 대입하면 덮어씁니다.

```run
import pandas as pd

df = pd.DataFrame({'lot': ['L01', 'L02', 'L03'], 'qty': [500, 480, 610], 'defect': [6, 9, 4]})
df['good'] = df['qty'] - df['defect']
df['rate'] = (df['defect'] / df['qty'] * 100).round(2)
df['line'] = 'A'                          # 값 하나를 넣으면 모든 행에 같은 값
print(df)
```

## 이름 바꾸기와 빼기: rename, drop

`rename(columns={옛 이름: 새 이름})`으로 바꾸고, `drop(columns=[...])`로 뺍니다. 둘 다 **새 표를 돌려주고 원본은 그대로**입니다. 결과를 쓰려면 변수에 다시 담습니다.

```run
import pandas as pd

df = pd.DataFrame({'lot': ['L01', 'L02'], 'qty': [500, 480], 'defect': [6, 9], 'memo': ['', '재검']})
df2 = df.rename(columns={'qty': 'produced', 'defect': 'ng'})
df2 = df2.drop(columns=['memo'])
print(df2)
print(df.columns.tolist())           # 원본 df는 그대로
```

원본 `df`의 열 이름이 바뀌지 않은 것을 확인하세요. `df.rename(...)`만 쓰고 결과를 담지 않으면 아무 일도 일어나지 않은 것처럼 보입니다. 처음 pandas를 쓸 때 가장 흔한 실수입니다.

## 여러 열을 한 번에: assign

`assign(새열=계산, ...)`은 새 열 여러 개를 한 번에 만들어 새 표로 돌려줍니다. 원본을 건드리지 않고, 앞에서 만든 열을 뒤에서 바로 쓸 수 있습니다.

```run
import pandas as pd

df = pd.DataFrame({'lot': ['L01', 'L02', 'L03'], 'qty': [500, 480, 610], 'defect': [6, 9, 4]})
out = df.assign(
    good=df['qty'] - df['defect'],
    rate=lambda d: (d['defect'] / d['qty'] * 100).round(2),
)
print(out)
```

`lambda d:`의 `d`는 "지금까지 만든 표"입니다. [lambda와 key: 정렬 기준 고르기](#/l/pb-11-3)에서 배운 lambda를 여기서 씁니다. 대입 방식(`df['x'] = ...`)은 원본을 바꾸고, `assign`은 새 표를 만든다는 점만 기억하면 됩니다.

## 열 자료형 확인하고 바꾸기: dtypes, astype

`dtypes`는 열마다 자료형을 보여 줍니다. 숫자여야 할 열이 문자열 자료형으로 나오면 계산이 안 됩니다. 문자열 열은 pandas 버전에 따라 `object` 또는 `str`로 표시됩니다.

```run
import pandas as pd

df = pd.DataFrame({'lot': ['L01', 'L02'], 'qty': ['500', '480'], 'pass': [1, 0]})
print(df.dtypes)
df['qty'] = df['qty'].astype(int)
df['pass'] = df['pass'].astype(bool)
print(df.dtypes)
print(df['qty'].sum())
```

`qty`가 처음에는 따옴표로 감싼 문자열이라 숫자 자료형이 아니었습니다. `astype(int)`로 바꾼 뒤에야 합계 980이 나옵니다. 숫자로 못 바꾸는 값이 섞여 있을 때는 [문자열 열 깊게 정리하기](#/l/da-05-2)의 `pd.to_numeric`을 씁니다.

## 실제 데이터로 열 만들기

식당 계산서 데이터 `tips.csv`에 1인당 금액과 팁 비율 열을 만들어 봅니다.

```run
import pandas as pd

df = pd.read_csv("tips.csv")
df = df.assign(
    per_person=(df['total_bill'] / df['size']).round(2),
    tip_pct=(df['tip'] / df['total_bill'] * 100).round(1),
)
print(df[['total_bill', 'size', 'per_person', 'tip_pct']].head(3))
print(round(df['tip_pct'].mean(), 1))
```

팁은 평균적으로 계산서의 16.1% 정도입니다. 원래 열(`total_bill`, `tip`)만으로는 보이지 않던 "비율"을 새 열로 만들어야 비교가 됩니다.

## 정리

- 열 단위는 딕셔너리, 행 단위 기록은 딕셔너리 리스트로 표를 만듭니다
- 열 여러 개는 `df[['a', 'b']]`, 결과는 DataFrame
- `rename` · `drop` · `assign`은 새 표를 돌려줍니다. 결과를 변수에 담으세요
- 계산이 안 되면 `dtypes`부터 확인하고 `astype`으로 바꿉니다
