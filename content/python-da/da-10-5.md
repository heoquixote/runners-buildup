## 시작하기 전에

앞 페이지 [seaborn 소개: 표를 넘기면 통계 그래프가 나온다](#/l/da-10-0)에서 seaborn은 표를 `data=`로 넘기고 `x=` · `y=` · `hue=`에 열 이름만 배정하면 그래프를 그려 준다는 것을 봤습니다. 이번 페이지는 seaborn으로 그릴 수 있는 대표 차트를 모은 **차트 도감**입니다.

seaborn은 함수 이름만 바꿔 끼우면 같은 표를 다른 질문으로 볼 수 있습니다. 그래서 이 도감은 함수를 **가족**(답하는 질문)별로 묶었습니다. 다 외울 필요는 없고, 그래프가 필요할 때 다시 와서 찾아보면 됩니다.

## 카드 읽는 법

카드는 matplotlib 차트 갤러리와 같은 모양입니다. 그림 · 이름 · 함수 · 언제 쓰나. 다른 점은 함수 칸입니다.

- `sns.boxplot(data, x, y, hue)`처럼 괄호 안에는 **열 이름을 배정할 역할**이 적혀 있습니다. 실제로는 `sns.boxplot(data=df, x="day", y="total_bill")`처럼 씁니다.
- 이름 옆에 **그림 단위**라고 붙은 함수(`relplot`, `lmplot`, `pairplot`, `jointplot`)는 도화지를 스스로 새로 만듭니다. 그래서 `ax=`로 자리를 정해 줄 수 없고, 대신 `col=`로 칸을 나누거나 여러 칸을 한 번에 그립니다. 나머지는 **칸 단위** 함수라 `ax=`로 원하는 칸에 그립니다.

썸네일은 모두 이 사이트의 실습 데이터(식당 계산서 `tips.csv`, 펭귄 `penguins.csv`, 항공 승객 `flights.csv`)로 직접 그린 그림입니다. seaborn의 기본 모양은 아래 한 줄이면 됩니다.

```run
import matplotlib.pyplot as plt
import pandas as pd
import seaborn as sns

df = pd.read_csv("tips.csv")
fig, ax = plt.subplots(figsize=(5, 3))
sns.histplot(data=df, x="total_bill", ax=ax)
print(len(ax.patches), "bars")
```

`histplot` 한 줄로 계산 금액의 히스토그램이 나왔습니다. 막대가 몇 개일지(구간 수)도 seaborn이 데이터를 보고 정했습니다. 이 줄의 함수 이름과 열 이름만 바꾸면 아래의 어떤 차트든 그릴 수 있습니다.

항공 승객 데이터에는 연도마다 12개월의 값이 있습니다. `lineplot`에 x="year"만 주면 해마다 12개 값의 평균을 이어 줍니다.

```run
import matplotlib.pyplot as plt
import pandas as pd
import seaborn as sns

df = pd.read_csv("flights.csv")
fig, ax = plt.subplots(figsize=(5, 3))
sns.lineplot(data=df, x="year", y="passengers", ax=ax)
print(df.groupby("year")["passengers"].mean().round(1).iloc[[0, -1]])
```

선이 1949년 평균 126.7에서 1960년 476.2(천 명)로 올라갑니다. 선 둘레의 옅은 띠는 그 해 12개월 값으로 계산한 평균이 얼마나 흔들릴 수 있는지(신뢰구간)입니다. 평균을 직접 계산하지 않았는데 seaborn이 묶어서 계산해 준 것입니다.

펭귄 세 종의 날개 길이를 `kdeplot`으로 겹쳐 그립니다. `hue="species"` 하나로 종마다 곡선이 따로 생깁니다.

```run
import matplotlib.pyplot as plt
import pandas as pd
import seaborn as sns

df = pd.read_csv("penguins.csv")
fig, ax = plt.subplots(figsize=(5, 3))
sns.kdeplot(data=df, x="flipper_length_mm", hue="species", fill=True, ax=ax)
print(df.groupby("species")["flipper_length_mm"].median())
```

봉우리가 셋입니다. 아델리(Adelie, 중앙값 190mm)와 턱끈(Chinstrap, 196mm) 곡선은 많이 겹치고, 젠투(Gentoo, 216mm)는 오른쪽에 따로 떨어져 있습니다. 날개 길이만으로도 젠투는 거의 구별되지만 나머지 두 종은 구별이 어렵다는 뜻입니다.

같은 요일별 계산 금액을 평균 막대와 상자그림으로 나란히 그립니다. 함수 이름만 다르고 나머지 재료는 똑같습니다.

```run
import matplotlib.pyplot as plt
import pandas as pd
import seaborn as sns

df = pd.read_csv("tips.csv")
order = ["Thur", "Fri", "Sat", "Sun"]
fig, axes = plt.subplots(1, 2, figsize=(9, 3))
sns.barplot(data=df, x="day", y="total_bill", order=order, ax=axes[0])
sns.boxplot(data=df, x="day", y="total_bill", order=order, ax=axes[1])
print(df.groupby("day")["total_bill"].agg(["mean", "max"]).round(1))
```

왼쪽 평균 막대는 일요일(21.4)이 가장 높고 금요일(17.2)이 가장 낮다는 **평균 하나**만 보여 줍니다. 오른쪽 상자그림을 보면 토요일에는 50.8달러 같은 아주 큰 계산서가 위쪽에 점으로 따로 찍혀 있습니다. 평균 막대는 이런 튀는 값을 숨기므로, 그룹 비교를 할 때는 분포 함수도 함께 그려 보는 습관이 좋습니다.

## 회귀 가족: 추세선 긋기

산점도에 "가장 잘 맞는 직선"(회귀선)을 함께 그립니다. 관계가 얼마나 기울었는지 볼 때 씁니다.

::chart{src="content/img/gallery/sns-regplot.png" name="회귀선 산점도" sig="sns.regplot(data, x, y)" desc="산점도 위에 직선을 긋고, 선이 흔들릴 수 있는 범위를 옅은 띠로 그립니다. 칸 단위라 ax=로 자리를 정합니다." more="자세히: [추세선 읽기](#/l/da-15-2)"}
::chart{src="content/img/gallery/sns-lmplot.png" name="그룹별 회귀선 · 그림 단위" sig="sns.lmplot(data, x, y, hue, col)" desc="regplot을 hue 그룹마다 따로 그리거나 col로 칸을 나눕니다. 그룹마다 기울기가 다른지 볼 때 씁니다." more="자세히: [추세선 읽기](#/l/da-15-2)"}

펭귄의 부리 길이와 부리 깊이를 `lmplot`으로 그립니다. 종을 나누지 않으면 어떻게 되는지 숫자로 함께 봅니다.

```run
import pandas as pd
import seaborn as sns

df = pd.read_csv("penguins.csv").dropna()
sns.lmplot(data=df, x="bill_length_mm", y="bill_depth_mm", hue="species", height=3.2)
print("all:", round(df["bill_length_mm"].corr(df["bill_depth_mm"]), 2))
for name, g in df.groupby("species"):
    print(name, round(g["bill_length_mm"].corr(g["bill_depth_mm"]), 2))
```

세 종 모두 선이 **오른쪽 위로** 올라갑니다(종별 상관계수 아델리 0.39, 턱끈 · 젠투 0.65). 그런데 종을 섞어서 한꺼번에 계산하면 상관계수가 -0.23으로 **반대 방향**이 됩니다. 부리가 긴 젠투가 부리 깊이는 얕아서 생기는 착시입니다. `hue`로 그룹을 나눠 보는 것이 왜 중요한지 보여 주는 유명한 예입니다.

## 행렬 가족: 표 전체를 색으로

::chart{src="content/img/gallery/sns-heatmap.png" name="히트맵" sig="sns.heatmap(data, annot, cmap)" desc="표의 숫자를 칸마다 색으로 칠합니다. annot=True면 칸에 숫자도 적습니다. 상관계수 표나 월 × 연도 같은 교차표에 씁니다." more="자세히: [상관계수와 히트맵 읽기](#/l/da-15-3)"}

`heatmap`은 다른 함수와 달리 **x · y 열 이름이 아니라 이미 만들어 둔 표**를 받습니다. 항공 승객을 월(행) × 연도(열) 표로 바꿔 넘깁니다.

```run
import matplotlib.pyplot as plt
import pandas as pd
import seaborn as sns

df = pd.read_csv("flights.csv")
months = df["month"].unique()
table = df.pivot(index="month", columns="year", values="passengers").loc[months]
fig, ax = plt.subplots(figsize=(7, 4))
sns.heatmap(table, cmap="mako", ax=ax)
print(table.shape)
print(table.loc[["July", "November"], 1960])
```

12개월 × 12년 표가 색 격자가 되었습니다. 오른쪽(최근 연도)으로 갈수록 밝아지는 것은 해마다 승객이 늘었다는 뜻이고, 가운데 여름(7 ~ 8월) 줄이 밝은 것은 계절성입니다. 1960년만 봐도 7월 622, 11월 390(천 명)으로 차이가 큽니다. 선 그래프 12개로 볼 내용을 그림 하나로 봅니다.

`pairplot`은 숫자 열이 많을수록 칸이 늘어나 그리는 데 시간이 걸립니다. 펭귄의 숫자 열 세 개만 골라 그립니다.

```run
import pandas as pd
import seaborn as sns

df = pd.read_csv("penguins.csv").dropna()
cols = ["bill_length_mm", "bill_depth_mm", "flipper_length_mm"]
g = sns.pairplot(df, vars=cols, hue="species", height=1.8)
print(len(g.axes.flat), "panels")
```

열 3개를 둘씩 짝지어 3 × 3 = 9칸입니다. 대각선 3칸은 열 하나의 분포(종별 밀도 곡선), 나머지 6칸은 두 열의 산점도입니다. 초록 점(젠투)이 파랑(아델리) · 주황(턱끈) 점과 따로 떨어진 칸을 찾아 훑어보면 "어떤 열이 종을 잘 가르나"가 한눈에 보입니다.

## 더 많은 차트가 필요할 때

seaborn 공식 홈페이지의 [Example gallery](https://seaborn.pydata.org/examples/index.html)에 그림과 코드가 함께 있습니다. 함수 가족과 칸 단위 · 그림 단위의 관계는 [API 목록](https://seaborn.pydata.org/api.html)에서 확인할 수 있습니다. 그림 단위 함수 `displot`(분포) · `catplot`(범주)도 있는데, 이 페이지의 칸 단위 함수를 `kind=`로 골라 `col=`로 칸을 나눠 그리는 함수라고 보면 됩니다.

다음 페이지 [EDA 자동화 라이브러리: fasteda · YData Profiling · Sweetviz · PyGWalker](#/l/da-10-6)에서는 이런 차트를 한꺼번에 만들어 주는 도구를 소개하고, 이어서 [seaborn의 기본 구조: data · x · y · hue](#/l/da-10-1)에서 이 모든 함수가 공유하는 열 이름 배정 방식을 익힙니다. 질문마다 어떤 차트를 고르고 어떻게 읽는지는 뒤의 **비교 · 추이 · 분포 · 관계 · 구성** PART에서 자세히 배웁니다.

## 정리

| 가족 | 질문 | 함수 |
| --- | --- | --- |
| 관계 | 두 값이 함께 움직이나 | `scatterplot` · `lineplot` · `relplot`(그림 단위) |
| 분포 | 값이 어떻게 퍼져 있나 | `histplot` · `kdeplot` · `ecdfplot` |
| 범주 | 그룹끼리 다른가 | `countplot` · `barplot` · `pointplot` · `boxplot` · `violinplot` · `boxenplot` · `stripplot` · `swarmplot` |
| 회귀 | 추세선은 얼마나 기우나 | `regplot` · `lmplot`(그림 단위) |
| 행렬 | 표 전체를 한눈에 | `heatmap` |
| 여러 변수 | 모든 짝을 한 번에 | `pairplot` · `jointplot`(그림 단위) |

- seaborn은 함수 이름만 바꿔 끼우면 같은 표를 다른 질문으로 본다
- 칸 단위 함수는 `ax=`로 자리를 정하고, 그림 단위 함수는 도화지를 스스로 만든다
- 평균 막대 하나로 끝내지 말고 분포 함수로 튀는 값을, `hue`로 숨은 그룹을 함께 확인한다
