## 분포: 값들이 어디에 몰려 있나

반 학생 30명의 키를 생각해 보세요. 평균 키 하나만 들으면 "대부분 비슷하구나" 싶지만, 실제로는 아주 큰 학생과 작은 학생이 섞여 있을 수 있습니다. 값들이 **어디에 몰려 있고, 얼마나 넓게 퍼져 있고, 튀는 값이 있는지**를 **분포**라고 합니다. 분포를 보는 대표 그래프가 히스토그램과 상자그림입니다.

이번 레슨은 타이타닉 승객의 나이(`age`)와 운임(`fare`), 그리고 펭귄 344마리의 신체 치수(`penguins.csv`)를 씁니다.

## 히스토그램: 구간마다 몇 개

히스토그램은 값의 범위를 같은 폭의 **구간(bin)**으로 나누고, 각 구간에 들어간 개수를 막대 높이로 그립니다. 시험 점수를 "60점대 몇 명, 70점대 몇 명"으로 세는 것과 같습니다. 막대 그래프와 달리 x축이 **이어진 숫자**라서 막대 사이에 틈이 없습니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("titanic.csv")
age = df["age"].dropna()
fig, ax = plt.subplots(figsize=(6, 3))
counts, edges, bars = ax.hist(age, bins=10, edgecolor="white")
ax.set_xlabel("Age")
print("구간별 인원:", counts.astype(int))
```

나이를 모르는 177명은 `dropna()`로 빼고 714명만 그렸습니다. 가장 높은 막대는 3번째 구간(약 16~24세, 177명)과 4번째 구간(24~32세, 169명)입니다. 20대가 가장 많고, 나이가 많아질수록 줄어드는 모양입니다. 왼쪽 끝 구간(0~8세, 54명)에 어린이 승객도 꽤 있습니다.

직접 해 보세요. `bins=10`을 `bins=5`와 `bins=40`으로 바꿔 실행합니다. 구간이 너무 적으면 모양이 뭉개지고, 너무 많으면 막대가 들쭉날쭉해 패턴이 안 보입니다. **같은 데이터도 bins에 따라 달라 보인다**는 것이 히스토그램의 가장 큰 주의점입니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("titanic.csv")
age = df["age"].dropna()
fig, ax = plt.subplots(figsize=(6, 3))
counts, edges, bars = ax.hist(age, bins=40, edgecolor="white")
print("구간 수:", len(counts), "/ 구간 폭:", round(edges[1] - edges[0], 1), "살")
```

## 긴 꼬리: 평균과 중앙값이 다를 때

운임(`fare`)은 나이와 모양이 아주 다릅니다. 대부분은 싼 표인데 몇몇 승객이 매우 비싼 표를 샀습니다. 평균(mean)과 중앙값(median, 줄 세웠을 때 한가운데 값)을 세로선으로 함께 그려 봅니다. 세로 기준선은 `ax.axvline(x값)`입니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("titanic.csv")
fig, ax = plt.subplots(figsize=(6, 3))
ax.hist(df["fare"], bins=40)
ax.axvline(df["fare"].mean(), color="red", label="mean")
ax.axvline(df["fare"].median(), color="black", linestyle="--", label="median")
ax.legend()
print("평균", round(df["fare"].mean(), 1), "/ 중앙값", round(df["fare"].median(), 1))
```

막대는 왼쪽에 몰려 있고 오른쪽으로 가늘고 긴 **꼬리**가 512까지 이어집니다. 이렇게 꼬리가 길면 비싼 표 몇 장이 평균을 끌어올려, 평균(32.2)이 중앙값(14.5)의 두 배가 넘습니다. "보통 승객은 얼마를 냈나"에는 중앙값이 더 정직한 답입니다.

## 상자그림: 분포를 다섯 숫자로 요약

히스토그램은 모양을 자세히 보여 주지만, 그룹이 여러 개면 나란히 놓고 비교하기 어렵습니다. **상자그림(box plot)**은 분포를 상자 하나로 요약해서 여러 그룹을 쉽게 비교하게 해 줍니다.

::figure{src="content/img/viz/viz03-boxplot.svg" alt="위쪽 히스토그램과 아래쪽 상자그림을 맞대어, 상자의 왼쪽 끝은 Q1, 가운데 선은 중앙값, 오른쪽 끝은 Q3, 양쪽 수염은 1.5 IQR 안의 끝값, 그 밖의 점은 이상치임을 보여 준다" caption="상자는 가운데 50%가 있는 곳, 상자 속 선은 중앙값, 수염 밖의 점은 이상치입니다."}

- **중앙값**: 상자 속 가로선. 줄 세웠을 때 한가운데 값
- **Q1·Q3 (상자 아래·위 끝)**: 아래에서 25%, 75% 지점. 상자 안에 가운데 50%가 들어 있습니다
- **IQR**: 상자의 높이(Q3 − Q1). 가운데 절반이 얼마나 퍼졌나
- **수염**: 상자 끝에서 IQR의 1.5배 안에 있는 가장 먼 값까지
- **점(이상치)**: 수염 밖으로 벗어난 값

운임 전체를 상자그림으로 그려 봅니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("titanic.csv")
fig, ax = plt.subplots(figsize=(3, 4))
ax.boxplot(df["fare"])
q1, q2, q3 = df["fare"].quantile([0.25, 0.5, 0.75])
print("Q1", round(q1, 1), "/ 중앙값", round(q2, 1), "/ Q3", round(q3, 1))
```

상자가 7.9~31.0 사이로 아주 좁게 아래쪽에 붙어 있고, 그 위로 점(이상치)이 길게 늘어서 있습니다. 위의 히스토그램에서 본 '긴 꼬리'가 상자그림에서는 **점들의 줄**로 보이는 것입니다.

## 여러 그룹의 상자를 나란히

상자그림의 진짜 힘은 **그룹 비교**입니다. `ax.boxplot`에 그룹별 값 리스트를 넘기면 상자가 나란히 그려집니다. 객실 등급별 운임을 비교합니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("titanic.csv")
groups = [df[df["class"] == c]["fare"] for c in ["First", "Second", "Third"]]
fig, ax = plt.subplots(figsize=(6, 3))
ax.boxplot(groups)
ax.set_xticks([1, 2, 3], ["First", "Second", "Third"])
print(df.groupby("class")["fare"].median().round(1))
```

1등실 상자가 다른 두 등급보다 훨씬 위에 있고 길기도 합니다. 중앙값은 1등실 60.3, 2등실 14.2, 3등실 8.0입니다. 상자 위치로 "어느 그룹이 높은가", 상자 길이로 "그룹 안에서 얼마나 제각각인가"를 한 번에 읽습니다.

## 산점도: 두 값이 함께 움직이나

산점도(scatter plot)는 **점 하나가 행 하나**입니다. 한 값은 x축, 다른 값은 y축에 놓아 두 값의 관계를 봅니다. 펭귄의 지느러미 길이와 몸무게를 그려 봅니다. 빈 값이 있는 행은 `dropna()`로 뺍니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("penguins.csv").dropna()
fig, ax = plt.subplots(figsize=(5, 4))
ax.scatter(df["flipper_length_mm"], df["body_mass_g"])
ax.set_xlabel("Flipper length (mm)")
ax.set_ylabel("Body mass (g)")
print("점 개수:", len(df))
```

점 333개가 왼쪽 아래에서 오른쪽 위로 비스듬히 퍼져 있습니다. **지느러미가 길수록 몸무게도 무겁다**(양의 관계)는 뜻입니다. 산점도에서는 이런 것들을 읽습니다.

- **방향**: 오른쪽 위로(함께 증가), 오른쪽 아래로(하나가 늘면 하나는 줄어듦), 방향 없음
- **덩어리**: 점들이 몇 무리로 나뉘어 있나
- **튀는 점**: 무리에서 멀리 떨어진 점

## 색으로 세 번째 정보 더하기

위 산점도를 자세히 보면 점들이 두 덩어리로 나뉘어 보입니다. 펭귄 종(species)이 다르기 때문일까요? 종마다 `scatter`를 따로 불러 색과 범례를 붙이면 확인할 수 있습니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("penguins.csv").dropna()
fig, ax = plt.subplots(figsize=(5, 4))
for name, part in df.groupby("species"):
    ax.scatter(part["flipper_length_mm"], part["body_mass_g"], label=name, alpha=0.7)
ax.legend()
print(df["species"].value_counts())
```

오른쪽 위 덩어리는 거의 다 Gentoo(젠투)입니다. 색 하나로 "덩어리 = 종의 차이"라는 설명이 생겼습니다. `alpha=0.7`은 점을 약간 투명하게 해 겹친 곳이 진하게 보이게 합니다. 점이 많아 서로 가릴 때 꼭 써 보세요.

점 크기로도 정보를 담을 수 있습니다. `s=`에 숫자 열을 넣으면 값이 클수록 점이 커집니다(버블 차트).

```run
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("penguins.csv").dropna()
fig, ax = plt.subplots(figsize=(5, 4))
ax.scatter(df["bill_length_mm"], df["bill_depth_mm"], s=df["body_mass_g"] / 50, alpha=0.4)
ax.set_xlabel("Bill length (mm)")
ax.set_ylabel("Bill depth (mm)")
print("점 크기 범위:", df["body_mass_g"].min() / 50, "~", df["body_mass_g"].max() / 50)
```

다만 크기 차이는 눈으로 정확히 비교하기 어렵습니다. 세 번째 정보는 **색이 먼저, 크기는 보조**로 쓰는 것이 좋습니다.

## 파이(원) 그래프: 전체 중 비율

파이 그래프는 전체를 100%로 놓고 각 부분이 차지하는 **비율**을 조각으로 보여 줍니다. 승선 항구별 승객 비율을 그려 봅니다. `autopct="%.1f%%"`는 조각 위에 소수 첫째 자리까지 퍼센트를 씁니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("titanic.csv")
share = df["embark_town"].value_counts()
fig, ax = plt.subplots(figsize=(4, 4))
ax.pie(share.values, labels=share.index, autopct="%.1f%%")
print((share / share.sum()).round(3))
```

Southampton이 72.4%로 거의 4분의 3을 차지합니다. 조각이 2~4개이고 "한 부분이 전체의 대부분"이라는 메시지를 줄 때 파이 그래프가 잘 어울립니다.

> **파이 그래프의 함정**: 사람 눈은 각도·면적 비교에 약합니다. 조각이 5개를 넘거나, 30%와 33%처럼 비슷한 조각을 비교해야 하면 **정렬한 막대 그래프**가 훨씬 정확합니다. 파이의 가운데를 비운 도넛 모양은 `ax.pie(..., wedgeprops={"width": 0.4})`로 만들 수 있습니다.

## 정리: 분포 · 관계 · 비율 차트

| 차트 | 답하는 질문 | 코드 | 읽는 법 / 주의 |
| --- | --- | --- | --- |
| 히스토그램 | 값이 어디에 몰려 있나 | `ax.hist(값, bins=)` | 봉우리, 꼬리. bins에 따라 모양이 달라 보임 |
| 상자그림 | 그룹마다 분포가 어떻게 다른가, 이상치는 | `ax.boxplot([그룹1, 그룹2])` | 가운데 선 = 중앙값, 상자 = 가운데 50%, 점 = 이상치 |
| 산점도 | 두 값이 함께 움직이나 | `ax.scatter(x, y)` | 방향·덩어리·튀는 점. 겹치면 alpha |
| 버블 | 세 번째 값까지 | `ax.scatter(x, y, s=값)` | 크기 비교는 부정확, 보조로만 |
| 파이 | 전체 중 비율 | `ax.pie(값, labels=)` | 조각 5개 이하. 비교가 목적이면 막대 |
