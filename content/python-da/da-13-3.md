## 시계열이 여러 개일 때

"연도별 월간 승객", "지점별 일별 매출"처럼 **시계열이 여러 개**면 비교 방법이 중요해집니다. 선을 전부 한 칸에 겹치면 금방 스파게티처럼 엉킵니다. 이 레슨에서는 여러 시계열을 비교하는 네 가지 방법과 각각의 읽는 법을 배웁니다.

| 방법 | 언제 |
| --- | --- |
| 여러 선 한 칸에 | 시계열 2~5개, 서로 직접 비교할 때 |
| 작은 여러 칸 | 시계열이 많을 때, 각각의 모양을 볼 때 |
| 시작점 기준 지수화 | 크기가 다른 시계열의 **증가율**을 비교할 때 |
| 달력형 히트맵 | 같은 주기(월·요일)를 여러 해에 걸쳐 볼 때 |

## 여러 선을 한 칸에

seaborn `lineplot`에 `hue=`를 주면 그 열의 값마다 선을 그립니다. 연도 12개를 모두 그려 봅니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("flights.csv")
df["month"] = df["month"].str[:3]
ax = sns.lineplot(data=df, x="month", y="passengers", hue="year", palette="viridis")
print("선 개수:", df["year"].nunique())
```

**무엇을 나타내나**: 선 하나 = 연도 하나. `year`가 숫자라서 seaborn이 **연속 색**(viridis: 보라 → 노랑)으로 칠해, 색이 밝을수록 최근 해입니다.

**이렇게 읽는다**: 선이 많을 때는 선 하나하나를 따라가지 말고 **전체 모양**을 봅니다. ① 선들이 아래에서 위로 층층이 쌓였나(해마다 증가) ② 모든 선이 같은 달에 봉우리를 갖나(계절성) ③ 층 사이 간격이 일정한가.

> 해석: 12개 선이 모두 7~8월에 봉우리를 이루고, 밝은 색(최근 해)일수록 위에 있다. 해마다 같은 계절 패턴을 유지하면서 전체 수준이 올라갔다.

**잘못 읽기 쉬운 점**: 선이 5개를 넘으면 특정 연도(예: 1955년)를 골라 정확히 읽기는 거의 불가능합니다. 이런 그래프는 "전체 패턴"을 말할 때만 쓰고, 개별 값을 말해야 하면 아래의 작은 여러 칸이나 표를 씁니다.

## 작은 여러 칸

선을 겹치는 대신 시계열마다 **작은 칸을 하나씩** 주고 축을 공유하게 합니다. `sns.relplot(..., kind="line", col=, col_wrap=)`이 칸을 나눠 줍니다. `col_wrap=4`는 한 줄에 4칸씩 놓으라는 뜻입니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("flights.csv")
df["m"] = df.groupby("year").cumcount() + 1
g = sns.relplot(data=df, x="m", y="passengers", col="year", col_wrap=4, kind="line", height=1.6, aspect=1.3)
g.set_titles("{col_name}")
print("칸 개수:", len(g.axes.flat))
```

`m`은 1~12월을 숫자로 바꾼 것입니다(칸이 작아 영어 달 이름이 겹치지 않게).

**이렇게 읽는다**: 모든 칸이 같은 y축을 쓰므로 ① **칸마다 모양**(봉우리 위치)을 비교하고 ② **칸끼리 높이**(전체 수준)를 비교합니다. 그다음 ③ 모양이 다른 칸을 찾습니다.

> 해석: 12개 칸 모두 여름에 봉우리가 하나 있는 같은 모양이고, 칸이 오른쪽 아래로 갈수록(최근 해일수록) 선 전체가 높아진다. 1949~1950년은 봉우리가 낮고 완만한데, 1958년 이후는 봉우리가 뾰족하게 솟는다.

작은 여러 칸은 "모양을 비교"할 때 가장 정직한 방법입니다. 선이 겹치지 않으면서도 축을 공유해 높이까지 비교할 수 있기 때문입니다.

## 시작점을 100으로 맞추기 (지수화)

크기가 다른 두 시계열을 같은 칸에 그리면, 큰 쪽의 변화만 크게 보입니다. 7월 승객(148명에서 시작)과 1월 승객(112명에서 시작) 중 **어느 쪽이 더 빨리** 늘었는지 비교하려면, 둘 다 **첫해 값을 100**으로 바꿔서 그립니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("flights.csv")
fig, ax = plt.subplots(figsize=(7, 3))
for month in ["January", "July"]:
    part = df[df["month"] == month]
    index = part["passengers"] / part["passengers"].iloc[0] * 100
    ax.plot(part["year"], index, marker="o", label=month)
    print(month, "1960년 지수:", round(index.iloc[-1]))
ax.axhline(100, color="gray", linestyle=":")
ax.legend()
```

**무엇을 나타내나**: y = (그해 값 ÷ 첫해 값) × 100. 100이면 첫해와 같고, 200이면 2배입니다. 크기가 아니라 **첫해 대비 몇 배가 됐나**를 나타냅니다.

> 해석: 12년 동안 7월 승객은 4.2배(지수 420), 1월 승객은 3.7배(372)가 됐다. 성수기인 7월이 비수기보다 더 빠르게 성장해, 계절에 따른 차이가 해마다 벌어졌다.

**잘못 읽기 쉬운 점**: 지수화한 그래프에서는 **원래 크기를 알 수 없습니다.** 두 선이 같은 높이라도 실제 승객 수는 다릅니다. 또 기준 시점(첫해)을 어디로 잡느냐에 따라 결과가 달라지니, 기준 시점을 축 이름이나 제목에 적어 둡니다("1949 = 100").

## 달력형 히트맵

연도 × 월처럼 **두 시간 단위**가 있는 데이터는 표로 펼쳐 색으로 칠하면 한 장에 다 들어갑니다. 행은 월, 열은 연도, 칸 색은 승객 수입니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("flights.csv")
table = df.pivot(index="month", columns="year", values="passengers")
table = table.loc[df["month"].unique()]
fig, ax = plt.subplots(figsize=(8, 4))
sns.heatmap(table, cmap="YlGnBu", ax=ax, cbar_kws={"label": "Passengers"})
print("1960년에 가장 붐빈 달:", table[1960].idxmax(), "/ 1949년에 가장 한산한 달:", table[1949].idxmin())
```

**무엇을 나타내나**: 칸 하나 = 어느 해 어느 달, 색이 진할수록 승객이 많음. 오른쪽 색 막대(color bar)가 색과 숫자를 이어 줍니다. `table.loc[...]`은 월을 알파벳순이 아니라 1월~12월 순서로 세운 것입니다.

**이렇게 읽는다**: 히트맵은 **두 방향으로** 읽습니다.

- **가로로(→)**: 같은 달이 해마다 어떻게 변했나 → **추세**
- **세로로(↓)**: 같은 해 안에서 어느 달이 진한가 → **계절성**
- **가장 진한·옅은 칸**: 최고·최저 시점

> 해석: 가로로 보면 모든 줄이 오른쪽으로 갈수록 진해져 해마다 승객이 늘었다. 세로로 보면 가운데 7·8월 줄이 항상 가장 진해 여름이 성수기다. 가장 진한 칸은 1960년 7월, 가장 옅은 칸은 1949년 11월이다.

**잘못 읽기 쉬운 점**: 색 차이는 숫자만큼 정확하게 읽히지 않습니다. 히트맵으로는 "패턴"을 찾고, 정확한 비교는 숫자(`annot=True`로 칸에 숫자 쓰기)나 선 그래프로 확인합니다. 또 행 순서가 알파벳순이면 계절 패턴이 흩어져 안 보이니, 시간 순서로 정렬하는 것을 잊지 마세요.

## 실제 데이터로: 평일과 주말의 따릉이

**데이터 소개 · 서울 따릉이 시간별 대여 수** (`seoul_bike.csv`)

2017년 12월 ~ 2018년 11월, 1년 동안 서울 공공자전거(따릉이)가 **매시간** 몇 대 빌려졌는지와 그 시간의 날씨를 적은 **8,760행**(365일 × 24시간)입니다(UCI Seoul Bike Sharing Demand, CC BY 4.0). **한 행 = 한 시간**입니다.

| 컬럼 | 뜻 | 자료형 | 예시 |
| --- | --- | --- | --- |
| `date` | 날짜 | 글자(날짜로 바꿔 씀) | 2017-12-01 |
| `rented_bikes` | 그 시간 대여 수(대) | 정수 | 254 |
| `hour` | 시각(0 ~ 23) | 정수 | 0 |
| `temp` | 기온(℃) | 소수 | -5.2 |
| `humidity` | 습도(%) | 정수 | 37 |
| `wind_speed` | 풍속(m/s) | 소수 | 2.2 |
| `solar_rad` | 햇빛 양(MJ/m²) | 소수 | 0.0 |
| `rainfall` | 강수량(mm) | 소수 | 0.0 |
| `snowfall` | 적설량(cm) | 소수 | 0.0 |
| `season` | 계절 | 글자 | Winter, Spring, Summer, Autumn |
| `holiday` | 공휴일인가 | 글자 | Yes, No |
| `functioning_day` | 운영한 날인가 | 글자 | Yes, No |

빈칸은 없습니다. `functioning_day`가 No인 시간(295행)은 점검으로 대여가 0이라, 평균을 낼 때는 빼고 계산합니다.

여러 선을 한 칸에 겹치는 방법을 서울 따릉이 대여 기록(`seoul_bike.csv`, 2017-12 ~ 2018-11, 시간별)에 써 봅니다. x축은 하루 중 시간(0~23시), 선은 평일과 주말 두 개입니다. `errorbar=None`은 평균 주변의 띠를 그리지 않고 선만 남기는 옵션입니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("seoul_bike.csv")
df["date"] = pd.to_datetime(df["date"])
df = df[df["functioning_day"] == "Yes"]
df["day_type"] = (df["date"].dt.dayofweek >= 5).map({True: "weekend", False: "weekday"})
fig, ax = plt.subplots(figsize=(8, 3.5))
sns.lineplot(data=df, x="hour", y="rented_bikes", hue="day_type", errorbar=None, ax=ax)
ax.set_xticks(range(0, 24, 2))
ax.set_ylabel("Rented bikes per hour")
by = df.groupby(["day_type", "hour"])["rented_bikes"].mean().round(0)
print("weekday 8h:", by["weekday"][8], "/ 18h:", by["weekday"][18], "/ 14h:", by["weekday"][14])
print("weekend 8h:", by["weekend"][8], "/ 18h:", by["weekend"][18], "/ 14h:", by["weekend"][14])
```

**이렇게 읽는다**: 두 선의 **봉우리 위치**와 **모양**을 비교합니다. 여기서 x축은 날짜가 아니라 "하루 중 시간"이라, 한 선은 1년치 같은 시간대의 평균입니다.

> 해석: 평일 선은 오전 8시(1,306대)와 오후 6시(1,724대)에 봉우리가 두 개 솟는 쌍봉 모양이고, 낮 2시에는 721대로 내려간다. 주말 선은 오전 8시가 421대로 낮고, 오후로 갈수록 완만하게 올라 오후 5~6시(1,100대 남짓)에 가장 높다. 낮 2시에는 주말(940대)이 평일(721대)보다 많다.

**잘못 읽기 쉬운 점**: 평균선 하나에는 계절 차이가 숨어 있습니다. 시간당 평균이 겨울 226대, 여름 1,034대로 4배 넘게 차이 나므로, 계절별로 칸을 나눠 그리면(앞의 "작은 여러 칸") 모양은 같고 높이만 다른지 확인할 수 있습니다.

## 정리: 여러 시계열 비교

| 방법 | 코드 | 먼저 읽을 것 | 주의 |
| --- | --- | --- | --- |
| 여러 선 | `sns.lineplot(..., hue=)` | 층이 쌓이는 방향, 공통 봉우리 | 5개 넘으면 개별 선은 못 읽음 |
| 작은 여러 칸 | `sns.relplot(..., kind="line", col=, col_wrap=)` | 칸마다 모양 → 칸끼리 높이 | 축 공유 확인 |
| 지수화 | `값 / 첫값 * 100` | 누가 더 빨리 늘었나 | 원래 크기는 사라짐, 기준 시점 표시 |
| 달력형 히트맵 | `sns.heatmap(df.pivot(...))` | 가로 = 추세, 세로 = 계절성 | 시간 순서로 정렬, 정확한 값은 숫자로 |
