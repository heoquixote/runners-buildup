[두 표를 키로 잇고 위아래로 붙이기](#/l/da-07-1)에서 표 두 개를 키로 잇고, 행이 늘어나는 함정을 봤습니다. 실무 데이터는 보통 표가 세 개 이상입니다. 주문 표에는 제품 번호만, 제품 표에는 공장 번호만, 공장 표에 공장 이름이 있는 식입니다. "공장별 매출"을 구하려면 표를 **차례로** 이어야 합니다. 이 레슨에서는 여러 표를 단계적으로 잇고, 단계마다 결합이 제대로 됐는지 확인하는 습관을 만듭니다.

## 오늘 쓸 표 세 개

```run
import pandas as pd

orders = pd.DataFrame({'order_id': [1, 2, 3, 4, 5],
                       'product_id': ['P1', 'P2', 'P1', 'P3', 'P2'],
                       'qty': [10, 5, 8, 4, 6]})
products = pd.DataFrame({'product_id': ['P1', 'P2', 'P3'],
                         'name': ['볼트', '너트', '와셔'],
                         'plant_id': [101, 102, 101],
                         'price': [300, 150, 80]})
plants = pd.DataFrame({'plant_id': ['101', '102'],
                       'plant': ['화성', '구미']})
print(orders.dtypes['product_id'], products.dtypes['plant_id'], plants.dtypes['plant_id'])
```

| 표 | 한 행의 뜻 | 키 |
| --- | --- | --- |
| orders | 주문 한 건 | product_id → products |
| products | 제품 하나 | plant_id → plants |
| plants | 공장 하나 | plant_id |

주문(많음) → 제품(하나), 제품(많음) → 공장(하나) 관계입니다. 이런 관계를 **다대일(many-to-one)**이라고 합니다. 그런데 `plant_id`의 자료형이 products에서는 정수, plants에서는 문자열입니다. 엑셀에서 가져온 표에서 흔히 생기는 일입니다.

## 1단계: 주문 + 제품

```run
import pandas as pd

orders = pd.DataFrame({'order_id': [1, 2, 3, 4, 5], 'product_id': ['P1', 'P2', 'P1', 'P3', 'P2'], 'qty': [10, 5, 8, 4, 6]})
products = pd.DataFrame({'product_id': ['P1', 'P2', 'P3'], 'name': ['볼트', '너트', '와셔'], 'plant_id': [101, 102, 101], 'price': [300, 150, 80]})

step1 = orders.merge(products, on='product_id', how='left', validate='many_to_one')
print(len(orders), "→", len(step1))
print(step1)
```

`df.merge(다른표, ...)`는 `pd.merge(df, 다른표, ...)`와 같고, 체인으로 이어 쓰기 좋습니다. 기준 표(주문)를 왼쪽에 두고 `how='left'`로 이었습니다. 주문은 하나도 빠지면 안 되기 때문입니다.

`validate='many_to_one'`은 "오른쪽 표의 키는 겹치지 않아야 한다"고 pandas에 미리 알려 주는 옵션입니다. 제품 표에 P1이 두 번 있으면 행이 불어나기 전에 바로 에러로 멈춥니다.

```python
# products2: 제품 표에 P1 행을 하나 더 넣은 표
orders.merge(products2, on='product_id', validate='many_to_one')
# MergeError: Merge keys are not unique in right dataset; not a many-to-one merge
```

| validate 값 | 뜻 |
| --- | --- |
| `'one_to_one'` | 양쪽 모두 키가 겹치지 않음 |
| `'one_to_many'` | 왼쪽 키만 겹치지 않음 |
| `'many_to_one'` | 오른쪽 키만 겹치지 않음 (가장 흔함) |

행 수도 5 → 5로 그대로입니다. 다대일 left 결합은 **왼쪽 행 수가 그대로**여야 정상입니다.

## 2단계: 키 자료형이 다르면 이어지지 않습니다

이제 공장 표를 붙입니다. 그런데 `plant_id`가 한쪽은 정수 101, 한쪽은 문자열 `'101'`입니다. 사람 눈에는 같지만 파이썬에게 `101 == '101'`은 False입니다.

```run
import pandas as pd

step1 = pd.DataFrame({'order_id': [1, 2], 'plant_id': [101, 102], 'qty': [10, 5]})
plants = pd.DataFrame({'plant_id': ['101', '102'], 'plant': ['화성', '구미']})
try:
    step1.merge(plants, on='plant_id', how='left')
except ValueError as e:
    print("에러:", type(e).__name__)
print(step1['plant_id'].dtype, plants['plant_id'].dtype)
```

pandas가 정수와 문자열 키를 잇지 못하고 `ValueError`를 냅니다. 에러가 나면 그나마 다행입니다. 양쪽이 모두 문자열인데 한쪽에 공백이 섞인 `' 101'` 같은 경우는 **에러 없이 짝을 못 찾고 NaN**이 됩니다. 키 자료형과 표기를 먼저 맞춥니다.

```run
import pandas as pd

step1 = pd.DataFrame({'order_id': [1, 2, 3], 'plant_id': [101, 102, 101], 'qty': [10, 5, 4]})
plants = pd.DataFrame({'plant_id': ['101', ' 102'], 'plant': ['화성', '구미']})   # 102 앞에 공백

plants['plant_id'] = plants['plant_id'].str.strip().astype(int)     # 공백 제거 후 정수로
step2 = step1.merge(plants, on='plant_id', how='left', validate='many_to_one')
print(step2)
print(step2['plant'].isna().sum(), "건 짝 없음")
```

`str.strip()`으로 공백을 지우고 `astype(int)`로 맞춘 뒤 이으니 모든 주문에 공장 이름이 붙었습니다. 마지막 줄처럼 **붙인 열의 NaN 개수**를 세면 짝을 못 찾은 행이 있는지 바로 확인할 수 있습니다.

## 3단계: 이은 다음 집계

세 표를 모두 이었으면 금액을 계산하고 공장별로 집계합니다. 처음부터 끝까지 한 번에 써 봅니다.

```run
import pandas as pd

orders = pd.DataFrame({'order_id': [1, 2, 3, 4, 5], 'product_id': ['P1', 'P2', 'P1', 'P3', 'P2'], 'qty': [10, 5, 8, 4, 6]})
products = pd.DataFrame({'product_id': ['P1', 'P2', 'P3'], 'name': ['볼트', '너트', '와셔'], 'plant_id': [101, 102, 101], 'price': [300, 150, 80]})
plants = pd.DataFrame({'plant_id': ['101', '102'], 'plant': ['화성', '구미']})

plants['plant_id'] = plants['plant_id'].astype(int)
full = (orders
        .merge(products, on='product_id', how='left', validate='many_to_one')
        .merge(plants, on='plant_id', how='left', validate='many_to_one'))
print(len(orders), len(full), full['plant'].isna().sum())

full['amount'] = full['qty'] * full['price']
print(full.groupby('plant')['amount'].sum())
print(full['amount'].sum(), (orders['qty'] * orders['product_id'].map(products.set_index('product_id')['price'])).sum())
```

주문 5건이 그대로 5행이고 짝 없는 행도 0입니다. 공장별 매출은 화성 5,720원, 구미 1,650원입니다. 마지막 줄은 결합 없이 `map`으로 가격만 붙여 계산한 총액과 비교한 것입니다. 두 값이 같은 7,370원이니 결합 과정에서 금액이 불어나거나 빠지지 않았다는 확인이 됩니다.

## 결합 체크리스트

| 언제 | 확인 | 코드 |
| --- | --- | --- |
| 잇기 전 | 키 자료형이 같은가 | `a['key'].dtype, b['key'].dtype` |
| 잇기 전 | 오른쪽 키가 겹치지 않는가 | `validate='many_to_one'` |
| 이은 후 | 행 수가 그대로인가 | `len(전)`, `len(후)` |
| 이은 후 | 짝 못 찾은 행이 있나 | `결과['붙인열'].isna().sum()` |
| 집계 후 | 총합이 원본과 같은가 | 원본 합계와 비교 |

## 정리

- 여러 표는 기준 표를 왼쪽에 두고 `how='left'`로 하나씩 잇습니다
- `validate='many_to_one'`으로 오른쪽 키 중복을 미리 막습니다
- 키 자료형과 공백을 먼저 맞추고, 이은 뒤 NaN 개수와 행 수를 확인합니다
