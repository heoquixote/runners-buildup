[모양이 다른 배열끼리 계산하는 규칙](#/l/da-02-1)에서 axis로 접는 방향과 브로드캐스팅 규칙을 배웠습니다. 이번에는 그 두 가지를 실제 질문에 씁니다. 로트(행) × 센서(열) 표를 놓고 "어느 로트가 어느 센서에서 튀었나", "규격을 벗어난 칸은 몇 개인가"를 반복문 없이 답합니다.

## 단위가 다른 센서는 그대로 비교할 수 없습니다

로트 5개에서 온도(℃), 압력(MPa), 회전수(rpm)를 쟀습니다. 열마다 숫자의 크기가 완전히 다릅니다.

```run
import numpy as np

data = np.array([[205.1, 1.21, 1510],
                 [198.4, 1.18, 1495],
                 [210.3, 1.25, 1540],
                 [201.0, 1.19, 1470],
                 [199.2, 1.32, 1505]])
print(data.shape)
print(data.std(axis=0, ddof=1).round(3))     # 열(센서)마다 표준편차
```

표준편차가 온도 4.9, 압력 0.057, 회전수 25.3입니다. "회전수가 가장 많이 흔들린다"고 말할 수 있을까요? 아닙니다. 단위가 달라서 숫자 크기를 비교하는 것은 의미가 없습니다. 키(cm)와 몸무게(kg)를 숫자만 보고 비교하지 않는 것과 같습니다.

## 같은 잣대로 바꾸기: 열마다 z-score

**z-score**는 "평균에서 표준편차 몇 개만큼 떨어졌나"를 나타내는 값입니다. 단위가 사라지므로 서로 다른 센서를 같은 잣대로 볼 수 있습니다.

> z = (값 − 평균) ÷ 표준편차

열마다 평균과 표준편차는 `axis=0`으로 구하면 `(3,)`이고, `(5, 3)` 표에서 브로드캐스팅으로 행마다 빠지고 나뉩니다.

```run
import numpy as np

data = np.array([[205.1, 1.21, 1510],
                 [198.4, 1.18, 1495],
                 [210.3, 1.25, 1540],
                 [201.0, 1.19, 1470],
                 [199.2, 1.32, 1505]])
z = (data - data.mean(axis=0)) / data.std(axis=0, ddof=1)
print(z.round(2))
```

이제 숫자를 직접 비교할 수 있습니다. 3번 로트는 온도(1.52)와 회전수(1.42)가 함께 높고, 5번 로트는 압력만 1.58로 튑니다. 열마다 z의 평균은 0, 표준편차는 1이 됩니다.

> z-score로 바꾸는 일을 **표준화**라고 합니다. 머신러닝 트랙에서 `StandardScaler`라는 이름으로 다시 만납니다. 하는 일은 이 한 줄과 같습니다.

## 로트마다 가장 튄 센서: argmax(axis=1)

행마다 "z의 절댓값이 가장 큰 열"을 찾으면 로트별로 가장 튄 센서가 나옵니다. 행마다 하나씩 남기려면 `axis=1`입니다.

```run
import numpy as np

data = np.array([[205.1, 1.21, 1510],
                 [198.4, 1.18, 1495],
                 [210.3, 1.25, 1540],
                 [201.0, 1.19, 1470],
                 [199.2, 1.32, 1505]])
z = (data - data.mean(axis=0)) / data.std(axis=0, ddof=1)

names = np.array(['temp', 'press', 'rpm'])
worst = np.abs(z).argmax(axis=1)       # 행마다 가장 큰 열의 위치
print(worst)
print(names[worst])
```

위치 번호 배열을 `names`에 넣으면 이름으로 바뀝니다. 4번 로트는 회전수(-1.34, 평균보다 낮음), 5번 로트는 압력이 가장 튀었습니다. 2번 로트는 온도(-0.89)와 압력(-0.88)이 거의 같아서, 이런 경우는 값도 함께 보고 판단합니다.

## 열마다 다른 규격으로 한 번에 판정하기

센서마다 규격이 다르면 하한 · 상한도 `(3,)` 배열로 만듭니다. 비교 연산도 브로드캐스팅되므로 표 전체를 한 줄로 판정합니다.

```run
import numpy as np

data = np.array([[205.1, 1.21, 1510],
                 [198.4, 1.18, 1495],
                 [210.3, 1.25, 1540],
                 [201.0, 1.19, 1470],
                 [199.2, 1.32, 1505]])
lo = np.array([195, 1.15, 1480])      # 온도, 압력, 회전수 하한
hi = np.array([208, 1.30, 1530])      # 상한

bad = (data < lo) | (data > hi)       # (5, 3) True/False 표
print(bad)
```

True가 규격을 벗어난 칸입니다. 이 표를 axis 방향으로 접으면 두 가지 질문에 바로 답할 수 있습니다.

```run
import numpy as np

data = np.array([[205.1, 1.21, 1510],
                 [198.4, 1.18, 1495],
                 [210.3, 1.25, 1540],
                 [201.0, 1.19, 1470],
                 [199.2, 1.32, 1505]])
lo = np.array([195, 1.15, 1480])
hi = np.array([208, 1.30, 1530])
bad = (data < lo) | (data > hi)

print(bad.sum(axis=0))                 # 센서별 이탈 횟수
print(bad.any(axis=1))                 # 로트별: 하나라도 이탈했나
print(np.where(bad.any(axis=1))[0] + 1)   # 이탈 로트 번호 (1부터)
```

| 코드 | 질문 | 답 |
| --- | --- | --- |
| `bad.sum(axis=0)` | 센서마다 몇 번 벗어났나 | 온도 1, 압력 1, 회전수 2 |
| `bad.any(axis=1)` | 로트마다 하나라도 벗어났나 | 3 · 4 · 5번 로트 |
| `bad.all(axis=1)` | 로트마다 모두 벗어났나 | (모두 벗어난 로트는 없음) |

`np.where(조건)`에 값 두 개를 주지 않으면 True인 **위치**를 돌려줍니다. 1차원이라 `[0]`으로 꺼내고, 로트 번호는 1부터 세므로 1을 더했습니다.

## 실제 데이터: 설비 1만 건에서 튀는 행 찾기

**데이터 소개 · 설비 고장 기록 (AI4I 2020)** (`ai4i2020.csv`)

공작 기계 설비의 작동 조건과 고장 여부를 기록한 데이터 **10,000건**입니다. 실제 공장 데이터를 본떠 만든 공개 데이터(UCI 머신러닝 저장소, CC BY 4.0)로, 예지 보전(고장 나기 전에 미리 알아채기) 연습에 많이 씁니다. **한 행 = 작업 한 건**입니다.

| 컬럼 | 뜻 | 자료형 | 예시 |
| --- | --- | --- | --- |
| `type` | 제품 품질 등급(L < M < H) | 글자 | L, M, H |
| `air_temp` | 주변 공기 온도(K, 켈빈) | 소수 | 298.1 |
| `process_temp` | 공정 온도(K) | 소수 | 308.6 |
| `rpm` | 분당 회전 수 | 정수 | 1551 |
| `torque` | 토크(Nm, 돌리는 힘) | 소수 | 42.8 |
| `tool_wear` | 공구를 쓴 시간(분) | 정수 | 0 |
| `failure` | 고장 여부(1 = 고장, 0 = 정상) | 정수 | 0, 1 |

빈칸은 없습니다. 고장(`failure` = 1)은 339건(3.4%)뿐이라 아주 드뭅니다. 켈빈 온도에서 273.15를 빼면 섭씨입니다(298K ≈ 25℃).

`ai4i2020.csv`는 설비 운전 기록 1만 건입니다. pandas로 읽은 뒤 `to_numpy()`로 숫자 열만 배열로 꺼내면 지금까지의 코드를 그대로 쓸 수 있습니다.

```run
import numpy as np
import pandas as pd

df = pd.read_csv("ai4i2020.csv")
X = df[['air_temp', 'process_temp', 'rpm', 'torque']].to_numpy()
print(X.shape)

Z = (X - X.mean(axis=0)) / X.std(axis=0, ddof=1)
far = np.abs(Z) > 3
print(far.sum(axis=0))                 # 센서별로 3을 넘은 개수
out = far.any(axis=1)
print(out.sum())
print(round(df['failure'][out].mean() * 100, 1), "% vs 전체", round(df['failure'].mean() * 100, 2), "%")
```

네 센서 중 한 곳이라도 |z| > 3인 운전은 178건이고, 대부분 회전수(164건)에서 나왔습니다. 이 178건의 고장률은 25.8%로 전체 3.39%의 7배가 넘습니다. 표준화와 axis 집계만으로 "평소와 다른 운전이 고장과 관련 있다"는 단서를 찾은 셈입니다.

## 정리

- 단위가 다른 열은 z-score로 바꿔 같은 잣대로 비교합니다
- 행마다 하나씩 답이 필요하면 `axis=1`, 열마다면 `axis=0`
- 규격도 배열로 만들면 표 전체를 한 줄로 판정하고, `sum` · `any` · `all`로 접어 요약합니다
