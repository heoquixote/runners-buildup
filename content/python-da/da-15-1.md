## 두 값 사이의 관계

"계산 금액이 크면 팁도 많을까?", "회전 속도가 빠르면 토크는 낮을까?"처럼 **두 숫자가 함께 움직이는지** 묻는 질문에는 **산점도(scatter plot)**로 답합니다. DAY 06에서는 관계를 보는 그래프와 그 숫자 요약(상관계수)을 읽습니다.

## 산점도가 나타내는 것

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("tips.csv")
ax = sns.scatterplot(data=df, x="total_bill", y="tip")
print("점 개수:", len(df))
print(df[["total_bill", "tip"]].describe().loc[["min", "max"]])
```

**무엇을 나타내나**

- 점 하나 = 행 하나(계산서 하나)
- 가로 위치 = x값(계산 금액), 세로 위치 = y값(팁)
- 점들이 만드는 **구름의 모양** = 두 값의 관계

관례적으로 **원인이나 먼저 정해지는 값을 x**, 그 결과로 궁금한 값을 y에 둡니다. 계산 금액이 정해지고 팁을 주므로 x = 계산 금액입니다.

## 산점도는 네 가지를 읽는다

::figure{src="content/img/viz/viz13-scatter-patterns.svg" alt="산점도 모양 여섯 가지: 오른쪽 위로 올라가는 양의 관계, 오른쪽 아래로 내려가는 음의 관계, 아무 모양이 없는 관계 없음, 휘어진 곡선 관계, 덩어리가 나뉜 무리, 혼자 떨어진 이상치" caption="점 구름의 방향, 모양, 퍼짐, 튀는 점을 차례로 읽습니다."}

| 순서 | 볼 것 | 질문 | 표현 |
| --- | --- | --- | --- |
| 1 | **방향** | 오른쪽으로 갈수록 올라가나, 내려가나? | 양의 관계 / 음의 관계 / 관계 없음 |
| 2 | **모양** | 곧은 띠인가, 휘었나, 덩어리로 나뉘었나? | 직선 / 곡선 / 무리 |
| 3 | **강도** | 점들이 띠에 얼마나 바짝 붙었나? | 강하다(가늘다) / 약하다(두껍다) |
| 4 | **튀는 점** | 구름에서 멀리 떨어진 점이 있나? | 이상치 |

위 팁 산점도에 적용하면 이렇게 됩니다.

> 해석: 점들이 왼쪽 아래에서 오른쪽 위로 올라가는 띠를 이뤄, 계산 금액이 클수록 팁도 많은 **양의 관계**다. 띠는 곧은 편이지만 오른쪽으로 갈수록 점이 넓게 퍼져, 큰 금액에서는 팁이 손님마다 크게 다르다. 50.8달러 계산서에 팁 10달러를 준 점이 맨 오른쪽 위에 떨어져 있다.

**"오른쪽으로 갈수록 퍼짐이 커진다"**는 것도 중요한 정보입니다. 큰 금액일수록 팁을 예측하기 어렵다는 뜻이기 때문입니다.

## 색으로 무리 나누기

점 구름이 덩어리로 나뉘어 보이면, 그 덩어리가 어떤 그룹인지 `hue=`로 색을 칠해 확인합니다. 펭귄의 지느러미 길이와 몸무게를 봅니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("penguins.csv").dropna()
ax = sns.scatterplot(data=df, x="flipper_length_mm", y="body_mass_g", hue="species")
print(df.groupby("species")[["flipper_length_mm", "body_mass_g"]].median())
```

**이렇게 읽는다**: ① 전체 구름의 방향 ② 색깔별 덩어리가 어디에 있나 ③ **덩어리 안에서도** 같은 방향인가.

> 해석: 지느러미가 길수록 몸무게도 무거운 강한 양의 관계다. 점들은 왼쪽 아래 덩어리(Adelie·Chinstrap, 지느러미 190mm대·3,700g)와 오른쪽 위 덩어리(Gentoo, 216mm·5,050g)로 나뉘고, 각 덩어리 안에서도 오른쪽 위로 올라가는 방향이 유지된다.

## 점이 너무 많을 때: 겹침

AI4I 공정 데이터는 1만 행입니다. 회전 속도(rpm)와 토크(torque)를 그대로 찍으면 점이 겹쳐 진한 덩어리만 보입니다. `alpha`(투명도)를 낮추고 점을 작게(`s=`) 하면 **겹친 곳일수록 진해져** 어디에 점이 몰렸는지 보입니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("ai4i2020.csv")
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(9, 3.5), sharey=True)
ax1.scatter(df["rpm"], df["torque"])
ax1.set_title("default")
ax2.scatter(df["rpm"], df["torque"], s=4, alpha=0.1)
ax2.set_title("s=4, alpha=0.1")
print("점 개수:", len(df))
```

> 해석: 왼쪽은 가운데가 한 덩어리로 칠해져 어디가 빽빽한지 알 수 없다. 투명하게 그린 오른쪽을 보면 점이 1,400~1,600rpm, 토크 35~50 부근에 가장 진하게 몰려 있다. 회전이 빠를수록 토크가 낮아지는 **음의 관계**이고, 곧은 띠가 아니라 아래로 휘어지는 곡선 모양이다.

**잘못 읽기 쉬운 점**: 점이 수천 개 이상이면 기본 산점도에서 **가장자리의 드문 점이 가운데의 수천 개와 똑같이 눈에 띕니다.** 그러면 드문 값이 흔한 것처럼 보입니다. 점이 많으면 투명도를 꼭 낮추세요.

## 셋째 정보 얹기: 색으로 결과 표시

산점도에 **결과(고장 여부)**를 색으로 얹으면 "어떤 조건에서 고장이 나는가"를 읽을 수 있습니다. 고장(1)이 위에 그려지도록 고장 행을 나중에 그립니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("ai4i2020.csv")
ok = df[df["failure"] == 0]
bad = df[df["failure"] == 1]
fig, ax = plt.subplots(figsize=(6, 4))
ax.scatter(ok["rpm"], ok["torque"], s=4, alpha=0.1, color="gray", label="normal")
ax.scatter(bad["rpm"], bad["torque"], s=10, color="red", label="failure")
ax.legend()
print("고장 수:", len(bad), "/", len(df))
print("고장 rpm 중앙값:", bad["rpm"].median(), "/ 정상:", ok["rpm"].median())
```

> 해석: 고장 339건(3.4%)의 빨간 점은 가운데가 아니라 **양 끝**에 몰려 있다. 왼쪽 위(1,300rpm 이하, 토크 60 이상: 느리게 돌면서 힘을 많이 받는 경우)와 오른쪽 아래(2,000rpm 이상, 토크 20 이하: 빠르게 헛도는 경우) 두 곳이다.

이 "양 끝에서 고장" 패턴은 da-15-3에서 상관계수가 놓치는 관계의 예로 다시 나옵니다.

## 크기로 넷째 정보 얹기 (버블)

`size=`에 열을 주면 점 크기로 값을 나타냅니다. 팁 산점도에 일행 수(`size`)를 크기로 얹어 봅니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("tips.csv")
ax = sns.scatterplot(data=df, x="total_bill", y="tip", size="size", sizes=(10, 200), alpha=0.5)
print(df.groupby("size")["total_bill"].median().round(1).to_dict())
```

> 해석: 오른쪽 위(큰 금액, 큰 팁)일수록 큰 원이 많아, 일행이 많을수록 금액과 팁이 함께 커진다. 2인 일행(중앙값 15.4달러)이 가장 많아 작은 원이 왼쪽 아래를 채운다.

**잘못 읽기 쉬운 점**: 사람 눈은 원의 **넓이 차이를 정확히 읽지 못합니다.** 크기는 "크다/작다" 정도의 보조 정보로만 쓰고, 정확한 비교가 필요한 값은 x·y축이나 색으로 보냅니다.

## 산점도를 잘못 읽기 쉬운 점

**① 관계가 보이면 원인이라고 단정하기**: 산점도는 "함께 움직인다"까지만 보여 줍니다. 왜 그런지는 따로 따져야 합니다(da-15-3).

**② 축 범위에 속기**: 산점도는 축이 0에서 시작할 필요가 없습니다. 대신 축 범위를 좁히면 약한 관계도 가파르게 보이니, **눈금 숫자**로 실제 변화 폭을 확인합니다.

**③ 점 몇 개로 관계 단정하기**: 점이 10개 정도면 우연히 띠처럼 보일 수 있습니다. 점 개수를 꼭 확인합니다.

## 정리: 산점도 읽기

| 단계 | 볼 것 | 해석 문장 틀 |
| --- | --- | --- |
| 1. 방향 | 오른쪽 위로? 아래로? | "x가 클수록 y도 크다(양의 관계)" |
| 2. 모양 | 직선 / 곡선 / 덩어리 | "두 무리로 나뉜다", "휘어 있다" |
| 3. 강도 | 띠의 두께 | "점들이 띠에 바짝 붙어 관계가 강하다" |
| 4. 튀는 점 | 구름 밖의 점 | "~인 점 하나가 떨어져 있다" |
| 확인 | 점 개수, 겹침, 축 범위 | |

| 그래프 | 코드 |
| --- | --- |
| 기본 산점도 | `ax.scatter(x, y)`, `sns.scatterplot(data=, x=, y=)` |
| 그룹 색 | `sns.scatterplot(..., hue=)` |
| 점이 많을 때 | `ax.scatter(x, y, s=4, alpha=0.1)` |
| 버블 | `sns.scatterplot(..., size=, sizes=(작게, 크게))` |
