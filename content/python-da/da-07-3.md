라인마다, 날짜마다, 설비마다 파일이 따로 쌓이는 경우가 많습니다. 분석하려면 이 파일들을 **하나의 표**로 이어 붙여야 합니다. [두 표를 키로 잇고 위아래로 붙이기](#/l/da-07-1)에서 `pd.concat`으로 표 두 개를 위아래로 붙였습니다. 이 레슨에서는 파일 여러 개를 반복문으로 읽어 붙이고, 붙일 때 생기는 세 가지 문제(출처를 잃어버림, 열 이름이 다름, 기간이 겹침)를 해결합니다.

## 연습용 파일 만들기

라인 A · B · C의 생산 기록이 파일 세 개로 있다고 하겠습니다. 실습을 위해 셀 안에서 파일을 직접 만듭니다. C라인 파일만 불량 열 이름이 `ng`가 아니라 `defect`입니다.

```run
files = {
    'line_A.csv': "date,lot,qty,ng\n11-01,A01,500,6\n11-02,A02,520,4\n",
    'line_B.csv': "date,lot,qty,ng\n11-01,B01,480,9\n11-02,B02,470,12\n",
    'line_C.csv': "date,lot,qty,defect\n11-01,C01,610,4\n11-02,C02,600,3\n",
}
for name, text in files.items():
    with open(name, 'w') as f:
        f.write(text)
print("파일", len(files), "개 저장")
```

[CSV 파일 읽고 쓰기](#/l/pb-10-2)에서 배운 `with open(..., 'w')`로 파일을 썼습니다. 아래 셀들도 맨 앞에서 같은 방식으로 파일을 다시 만듭니다. 어느 셀을 먼저 실행해도 되게 하기 위해서이니, 그 부분은 건너뛰고 읽어도 됩니다.

## 파일 목록 만들고 반복문으로 읽기

파일 이름에 규칙이 있으면 `glob`으로 목록을 만듭니다. `*`는 "아무 글자나"라는 뜻이라 `line_*.csv`는 line_으로 시작하는 CSV 파일 모두입니다.

```run
import glob
import pandas as pd

for name, text in {'line_A.csv': "date,lot,qty,ng\n11-01,A01,500,6\n11-02,A02,520,4\n",
                   'line_B.csv': "date,lot,qty,ng\n11-01,B01,480,9\n11-02,B02,470,12\n",
                   'line_C.csv': "date,lot,qty,defect\n11-01,C01,610,4\n11-02,C02,600,3\n"}.items():
    with open(name, 'w') as f:
        f.write(text)

files = sorted(glob.glob('line_*.csv'))
print(files)

parts = []
for path in files:
    df = pd.read_csv(path)
    df['source'] = path              # 어느 파일에서 왔는지 기록
    parts.append(df)

merged = pd.concat(parts, ignore_index=True)
print(merged)
```

반복문에서 표를 하나씩 읽어 **리스트에 모은 뒤, 마지막에 한 번만** `concat` 합니다. 반복문 안에서 매번 concat하면 표를 계속 새로 만들어서 파일이 많을 때 느려집니다.

`source` 열을 붙이지 않았다면 합친 뒤에는 어느 행이 어느 라인 것인지 알 수 없습니다. **붙이기 전에 출처를 열로 남기는 것**이 첫 번째 습관입니다.

## 열 이름이 다르면 NaN 열이 생깁니다

결과를 보면 `ng`와 `defect` 열이 따로 있고, 서로 반대쪽이 NaN입니다. concat은 **열 이름이 같은 것끼리** 위아래로 맞추고, 한쪽에만 있는 열은 빈칸으로 채우기 때문입니다.

```run
import glob
import pandas as pd

for name, text in {'line_A.csv': "date,lot,qty,ng\n11-01,A01,500,6\n11-02,A02,520,4\n",
                   'line_B.csv': "date,lot,qty,ng\n11-01,B01,480,9\n11-02,B02,470,12\n",
                   'line_C.csv': "date,lot,qty,defect\n11-01,C01,610,4\n11-02,C02,600,3\n"}.items():
    with open(name, 'w') as f:
        f.write(text)

merged = pd.concat([pd.read_csv(p) for p in sorted(glob.glob('line_*.csv'))], ignore_index=True)
print(merged.columns.tolist())
print(merged.isna().sum())
```

열이 예상보다 많거나, 숫자 열에 NaN이 생겼다면 이름이 다른 열이 있다는 신호입니다. 읽을 때 `rename`으로 이름을 맞춥니다. 출처는 파일 이름에서 라인 글자만 뽑아 `line` 열로 만들었습니다.

```run
import glob
import pandas as pd

for name, text in {'line_A.csv': "date,lot,qty,ng\n11-01,A01,500,6\n11-02,A02,520,4\n",
                   'line_B.csv': "date,lot,qty,ng\n11-01,B01,480,9\n11-02,B02,470,12\n",
                   'line_C.csv': "date,lot,qty,defect\n11-01,C01,610,4\n11-02,C02,600,3\n"}.items():
    with open(name, 'w') as f:
        f.write(text)

parts = []
for path in sorted(glob.glob('line_*.csv')):
    df = pd.read_csv(path).rename(columns={'defect': 'ng'})   # 이름 통일
    df['line'] = path[5]                                     # 'line_A.csv'의 6번째 글자
    parts.append(df)

merged = pd.concat(parts, ignore_index=True)
print(merged)
print(merged.groupby('line')[['qty', 'ng']].sum())
```

`rename`은 없는 열 이름을 줘도 에러 없이 넘어가므로, 모든 파일에 같은 코드를 써도 됩니다. 이제 열이 깔끔하게 맞고, 라인별 집계가 바로 됩니다. 불량은 B라인이 21개로 가장 많습니다.

## keys로 출처 붙이기

표가 몇 개 안 되면 리스트 대신 **딕셔너리**를 concat에 넣는 방법도 있습니다. 키가 바깥 인덱스 층이 됩니다.

```run
import pandas as pd

a = pd.DataFrame({'lot': ['A01', 'A02'], 'qty': [500, 520]})
b = pd.DataFrame({'lot': ['B01', 'B02'], 'qty': [480, 470]})
both = pd.concat({'A': a, 'B': b})
print(both)
print(both.loc['B'])
print(both.reset_index(level=0).rename(columns={'level_0': 'line'}).reset_index(drop=True))
```

두 층 인덱스가 생겨서 `loc['B']`로 B 표만 다시 꺼낼 수 있습니다. 보통의 표로 쓰려면 `reset_index(level=0)`으로 바깥 층을 열로 내립니다. 반복문 방식과 결과는 같으니 편한 쪽을 쓰면 됩니다.

## 기간이 겹치면 나중 파일을 남깁니다

월별 파일을 받다 보면 10월 파일의 마지막 날과 11월 파일의 첫날이 겹치기도 합니다. 겹친 날의 값이 **수정된** 값이라면 나중 파일을 믿어야 합니다. concat을 파일 순서대로 했다면, 같은 키에서 `keep='last'`가 나중 파일 값입니다.

```run
import pandas as pd

oct_file = pd.DataFrame({'date': ['10-30', '10-31'], 'qty': [500, 505]})
nov_file = pd.DataFrame({'date': ['10-31', '11-01'], 'qty': [512, 498]})   # 10-31 수정본 포함

merged = pd.concat([oct_file, nov_file], ignore_index=True)
print(merged['date'].duplicated().sum(), "일 겹침")
clean = merged.drop_duplicates(subset='date', keep='last').reset_index(drop=True)
print(clean)
print(merged['qty'].sum(), "→", clean['qty'].sum())
```

10-31이 두 번 있었고, 나중 파일의 512만 남았습니다. 겹친 날을 지우지 않으면 합계가 505만큼 부풀려집니다. [이상치 · 구간 · 중복](#/l/da-05-3)에서 본 것처럼 기준이 "파일 순서"가 아니라 "기록 시각"이라면 시각으로 정렬한 뒤 지웁니다.

## 정리

- 파일 목록은 `glob`, 읽은 표는 리스트에 모아 마지막에 한 번 `concat`
- 붙이기 전에 출처 열을 만들고, 열 이름은 `rename`으로 통일합니다
- 합친 뒤 `columns`와 `isna().sum()`으로 열이 어긋나지 않았는지 확인합니다
- 기간이 겹치면 `drop_duplicates(subset, keep='last')`로 나중 값을 남깁니다
