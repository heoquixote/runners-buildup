엑셀 표를 코드로 다루는 도구가 **pandas**입니다. NumPy 배열에 열 이름과 행 이름표를 붙이고, 숫자와 글자가 섞인 표도 다룰 수 있게 만든 라이브러리입니다.

## Series와 DataFrame

pandas의 기본 자료구조는 두 가지입니다.

- **Series**: 이름표(index)가 붙은 1차원 데이터. 엑셀의 열 하나
- **DataFrame**: 같은 index를 공유하는 Series 여러 개를 묶은 표. 열 하나를 꺼내면 Series

```run
import pandas as pd
s = pd.Series([4.98, 5.03, 5.10], index=['L01', 'L02', 'L03'])
print(s)
print(s['L02'], s.idxmax())
```

리스트는 번호로만 꺼낼 수 있지만, Series는 `'L02'` 같은 이름표로 꺼낼 수 있습니다. `idxmax()`는 가장 큰 값의 **이름표**를 돌려줍니다.

딕셔너리로 DataFrame을 직접 만들 수도 있습니다. 키가 열 이름, 값이 그 열의 내용입니다.

```run
import pandas as pd
df = pd.DataFrame({'line': ['A', 'B', 'C'], 'qty': [520, 480, 610], 'defect': [6, 9, 4]})
print(df)
print(type(df), type(df['qty']))
df['rate'] = df['defect'] / df['qty'] * 100      # 새 열은 대입으로 만든다
print(df.round(2))
```

왼쪽의 0, 1, 2가 행 이름표(index)입니다. 새 열을 만드는 계산은 NumPy처럼 값마다 적용됩니다. B라인의 불량률이 1.88%로 가장 높습니다.

## 불러오고 첫인상 보기

CSV는 `pd.read_csv('파일.csv')`로 읽습니다. 받은 데이터는 항상 같은 순서로 확인하세요.

1. `head()`: 처음 몇 행이 생각한 모양인지
2. `shape`, `columns`: 행·열 수와 열 이름
3. `info()`: 열별 자료형과 결측 개수
4. `describe()`: 숫자 열 요약 (평균, 표준편차, 사분위수)

```run
import io
import pandas as pd
csv = io.StringIO("date,line,qty,defect\n11-01,A,520,6\n11-01,B,480,9\n11-02,A,505,3\n11-02,B,470,12\n")
df = pd.read_csv(csv)
print(df.head())
print(df.shape, df.columns.tolist())
print(df.describe().round(1))
```

`shape`와 `columns`는 값이고 `head()`와 `describe()`는 기능이라 괄호가 다릅니다. `df.shape`에 괄호를 붙이면 에러가 납니다.

## 실제 데이터로 연습하기

설비 1만 건의 센서 기록(AI4I 2020)을 열어 봅니다. 처음 보는 데이터도 순서는 같습니다.

```run
import pandas as pd
df = pd.read_csv("ai4i2020.csv")
print(df.shape)
print(df.head(3))
df.info()
```

행 10,000개, 열 7개입니다. `info()`에서 모든 열의 Non-Null 수가 10000이니 빈칸이 없습니다. `type`만 글자(`object` 또는 `str`)이고 나머지는 숫자입니다.

```run
import pandas as pd
df = pd.read_csv("ai4i2020.csv")
print(df[['air_temp', 'rpm', 'torque']].describe().round(1))
print(df['failure'].mean())
```

| describe 행 | 뜻 |
| --- | --- |
| count | 빈칸이 아닌 값의 개수 |
| mean, std | 평균, 표준편차 |
| min, max | 최솟값, 최댓값 |
| 25%, 50%, 75% | 사분위수. 50%가 중앙값 |

`rpm`은 평균 1538.8, 최댓값 2886입니다. 최댓값이 평균과 멀리 떨어져 있으니 회전 수가 유난히 높은 기록이 섞여 있다고 짐작할 수 있습니다. `failure`는 0과 1로 된 열이라 평균 0.0339가 곧 고장 비율 3.39%입니다.

## 열 꺼내기와 범주 세기

`df['qty']`는 Series, `df[['qty', 'defect']]`는 DataFrame입니다. 글자로 된 범주 열은 `value_counts()`와 `nunique()`로 봅니다.

```run
import pandas as pd
df = pd.DataFrame({'region': ['서울', '부산', '서울', '대구', '서울'], 'price': [39000, 12000, 159000, 8500, 23000]})
print(df['price'].mean())
print(df['region'].value_counts())
print(df['region'].nunique(), "개 지역")
```

```run
import pandas as pd
df = pd.read_csv("ai4i2020.csv")
print(df['type'].value_counts())
print(df['type'].value_counts(normalize=True).round(3))   # 비율로 보기
```

제품 등급 L이 6,000건으로 60%를 차지합니다. 평균만 보면 놓치기 쉬운 구성 비율을 먼저 확인하는 습관을 들이세요.

## 첫인상 체크리스트

| 질문 | 확인 코드 |
| --- | --- |
| 생각한 표 모양인가? | `head()`, `shape` |
| 숫자 열이 글자로 읽히지 않았나? | `info()` |
| 빈칸이 있나? | `info()`, `isna().sum()` |
| 말이 안 되는 값이 있나? | `describe()`의 min, max |
| 범주가 몇 종류인가? | `value_counts()` |
