## 관계를 숫자 하나로: 상관계수

산점도를 보고 "꽤 강한 양의 관계"라고 말하는 대신 숫자 하나로 말할 수 있으면 편합니다. **상관계수(r)**는 두 값이 **직선 모양으로** 함께 움직이는 정도를 −1에서 +1 사이 숫자로 나타냅니다.

::figure{src="content/img/viz/viz09-corr.svg" alt="상관계수 눈금: -1이면 한쪽이 오를 때 다른 쪽이 내려가는 점 구름, 0이면 방향 없는 점 구름, +1이면 함께 오르는 점 구름" caption="+1에 가까우면 함께 오르고, −1에 가까우면 반대로 움직이며, 0 근처면 직선 관계가 거의 없습니다."}

| r | 뜻 |
| --- | --- |
| **부호** (+ / −) | 방향: +는 함께 오름, −는 한쪽이 오르면 다른 쪽이 내려감 |
| **크기** (0 ~ 1) | 강도: 1에 가까울수록 점들이 직선에 바짝 붙음 |
| 0.7 이상 | 강한 관계 (대략적인 기준) |
| 0.3 ~ 0.7 | 중간 정도 |
| 0.3 미만 | 약하거나 직선 관계가 거의 없음 |

기준 숫자는 분야마다 다르니 "대략"으로만 기억하세요. pandas에서는 `df["x"].corr(df["y"])`입니다.

```run
import pandas as pd

tips = pd.read_csv("tips.csv")
peng = pd.read_csv("penguins.csv").dropna()
print("계산 금액 - 팁:", round(tips["total_bill"].corr(tips["tip"]), 2))
print("지느러미 - 몸무게:", round(peng["flipper_length_mm"].corr(peng["body_mass_g"]), 2))
```

> 해석: 지느러미와 몸무게의 r = 0.87은 da-15-1 산점도에서 점들이 가는 띠를 이룬 것과 맞는다. 계산 금액과 팁의 r = 0.68은 양의 관계지만, 큰 금액에서 점이 넓게 퍼졌던 만큼 펭귄보다 약하다.

**잘못 읽기 쉬운 점**: r은 **기울기가 아닙니다.** r = 0.87이 "지느러미 1mm에 몸무게 0.87g"이라는 뜻이 아닙니다. 기울기는 "얼마나 가파른가", r은 "점들이 선에 얼마나 붙었나"입니다. 가파르지만 점이 흩어진 관계도, 완만하지만 점이 선에 딱 붙은 관계도 있습니다.

## 상관계수 히트맵

열이 여러 개면 모든 쌍의 r을 한꺼번에 구해(`df.corr()`) 히트맵으로 칠합니다. 열 이름이 길면 칸이 좁아지니 짧게 바꿉니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("penguins.csv").dropna()
num = df[["bill_length_mm", "bill_depth_mm", "flipper_length_mm", "body_mass_g"]]
num.columns = ["bill_len", "bill_depth", "flipper", "mass"]
corr = num.corr()
fig, ax = plt.subplots(figsize=(5, 4))
sns.heatmap(corr, annot=True, fmt=".2f", cmap="coolwarm", vmin=-1, vmax=1, ax=ax)
print(corr.round(2))
```

**무엇을 나타내나**

- 칸 하나 = 두 열의 r. 행과 열이 만나는 칸을 읽습니다.
- **대각선**은 자기 자신과의 r이라 항상 1.00 → 읽지 않습니다.
- 대각선을 기준으로 **위아래가 똑같습니다**(A와 B의 r = B와 A의 r). 절반만 읽으면 됩니다.
- 색: 빨강 = +, 파랑 = −, 흰색 = 0 근처. `vmin=-1, vmax=1`로 0을 가운데 색에 고정했습니다.

**이렇게 읽는다**

1. 대각선을 빼고 **가장 진한 빨강·파랑 칸** → 가장 강한 관계
2. **한 줄을 가로로** 읽기 → 그 변수와 관계가 강한 변수들
3. 흰색에 가까운 칸 → 직선 관계가 거의 없는 쌍

> 해석: 가장 강한 관계는 지느러미-몸무게(0.87)이고, 부리 길이도 지느러미(0.65)·몸무게(0.59)와 중간 정도의 양의 관계다. 부리 깊이는 나머지 셋과 모두 음의 관계(−0.23 ~ −0.58)라서, 부리가 깊은 펭귄일수록 몸이 작다는 뜻처럼 보인다.

"부리가 깊을수록 작다"는 이 해석은 사실 **틀렸습니다.** 왜 틀렸는지는 da-15-4에서 종을 나눠 보면 드러납니다.

**잘못 읽기 쉬운 점**: `vmin`, `vmax`를 정하지 않으면 seaborn이 데이터의 최솟값·최댓값에 맞춰 색을 칠해, 0.2짜리 약한 관계도 진한 색이 될 수 있습니다. 상관계수 히트맵에는 **항상 `vmin=-1, vmax=1`**을 줍니다.

## 같은 r, 전혀 다른 그림

1973년 통계학자 앤스콤(Anscombe)은 r도 평균도 똑같지만 그림은 전혀 다른 데이터 네 쌍을 만들었습니다. 11개씩의 숫자를 직접 넣어 그려 봅니다.

```run
import matplotlib.pyplot as plt
import numpy as np

x = [10, 8, 13, 9, 11, 14, 6, 4, 12, 7, 5]
sets = {
    "I": (x, [8.04, 6.95, 7.58, 8.81, 8.33, 9.96, 7.24, 4.26, 10.84, 4.82, 5.68]),
    "II": (x, [9.14, 8.14, 8.74, 8.77, 9.26, 8.10, 6.13, 3.10, 9.13, 7.26, 4.74]),
    "III": (x, [7.46, 6.77, 12.74, 7.11, 7.81, 8.84, 6.08, 5.39, 8.15, 6.42, 5.73]),
    "IV": ([8, 8, 8, 8, 8, 8, 8, 19, 8, 8, 8], [6.58, 5.76, 7.71, 8.84, 8.47, 7.04, 5.25, 12.50, 5.56, 7.91, 6.89]),
}
fig, axes = plt.subplots(1, 4, figsize=(11, 2.8), sharey=True)
for ax, (name, (xs, ys)) in zip(axes, sets.items()):
    ax.scatter(xs, ys)
    ax.set_title(name)
    print(name, "평균 y:", round(np.mean(ys), 2), "/ r:", round(np.corrcoef(xs, ys)[0, 1], 2))
```

| 데이터 | 실제 모양 | r = 0.82가 말해 주는 것 |
| --- | --- | --- |
| I | 흩어진 직선 관계 | 맞다 |
| II | 깔끔한 **곡선** | 틀렸다: 직선이 아니다 |
| III | 완벽한 직선 + **이상치 하나** | 틀렸다: 점 하나가 r을 끌어내렸다 |
| IV | x가 거의 다 8, **점 하나**만 19 | 틀렸다: 점 하나가 관계를 만들었다 |

> 해석: 네 데이터 모두 y 평균 7.5, r = 0.82로 숫자 요약은 같지만, 산점도로 보면 직선·곡선·이상치·점 하나 네 가지로 완전히 다르다. 상관계수만 보고 "네 데이터 모두 강한 직선 관계"라고 보고하면 셋은 틀린 보고가 된다.

교훈은 하나입니다. **r을 보고하기 전에 반드시 산점도를 그립니다.**

## r = 0이어도 관계가 있을 수 있다

r은 **직선** 관계만 잽니다. da-15-1에서 AI4I 고장은 회전 속도의 **양 끝**에서 났습니다. 이런 관계의 r은 얼마일까요? 회전 속도를 구간으로 나눠(`pd.cut`) 구간마다 고장률도 막대로 그려 봅니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("ai4i2020.csv")
print("rpm - 고장 r:", round(df["rpm"].corr(df["failure"]), 2))
names = ["~1300", "1300-1400", "1400-1500", "1500-1600", "1600-1800", "1800-2000", "2000~"]
bins = pd.cut(df["rpm"], [1100, 1300, 1400, 1500, 1600, 1800, 2000, 3000], labels=names)
rate = df.groupby(bins, observed=True)["failure"].mean() * 100
ax = rate.plot.bar(figsize=(8, 3), rot=0)
ax.set_ylabel("Failure rate (%)")
print(rate.round(1))
```

> 해석: 회전 속도와 고장의 r은 −0.04로 "관계가 거의 없다"처럼 보인다. 하지만 구간별 고장률은 1,300rpm 이하에서 22.7%, 2,000rpm 초과에서 14.6%이고 가운데(1,500~1,600rpm)는 0.5%뿐이다. 너무 느려도 너무 빨라도 고장 나는 **U자 관계**라서, 직선만 재는 r이 0에 가깝게 나온 것이다.

**r ≈ 0은 "관계가 없다"가 아니라 "직선 관계가 없다"**입니다. 머신러닝에서 상관계수가 낮다고 변수를 버리면 이런 중요한 변수를 잃습니다.

## 상관은 원인이 아니다

여름에는 아이스크림 판매도 늘고 물놀이 사고도 늘어서, 둘 사이의 r은 높게 나옵니다. 하지만 아이스크림이 사고를 일으키지는 않습니다. 둘 다 **더위**라는 제3의 원인을 따라 움직였을 뿐입니다.

| 높은 r이 나오는 이유 | 예 |
| --- | --- |
| A가 B의 원인 | 계산 금액 → 팁 |
| B가 A의 원인 (방향이 반대) | 소방관이 많이 출동한 화재일수록 피해가 크다 (큰 화재라서 많이 출동) |
| 제3의 원인 C가 둘 다 움직임 | 더위 → 아이스크림, 물놀이 사고 |
| 우연 | 데이터가 적을 때 |

팁 데이터에서 일행 수(`size`)와 팁의 r은 0.49입니다. 사람이 많으면 팁을 많이 주는 걸까요, 아니면 사람이 많아 **계산 금액이 커서** 팁이 커진 걸까요? 그래프와 r만으로는 알 수 없습니다. 해석 문장에는 "**함께 늘었다**", "**관계가 있다**"까지만 쓰고, "때문에"는 근거가 있을 때만 씁니다.

## 정리: 상관 읽기

| 단계 | 볼 것 | 해석 문장 틀 |
| --- | --- | --- |
| 1. 부호 | + / − | "x가 클수록 y도 크다 / 작다" |
| 2. 크기 | 0 ~ 1 | "r = 0.87로 강한 직선 관계다" |
| 3. 산점도 확인 | 곡선, 이상치, 점 하나 | "r은 높지만 이상치 하나 때문이다" |
| 4. 원인 주의 | 제3의 원인 | "함께 늘었지만 원인인지는 알 수 없다" |

| 그래프 | 코드 | 주의 |
| --- | --- | --- |
| 두 열의 r | `df["x"].corr(df["y"])` | 직선 관계만 잰다 |
| 상관 행렬 | `df[열들].corr()` | 대각선은 1, 위아래 대칭 |
| 상관 히트맵 | `sns.heatmap(corr, annot=True, cmap="coolwarm", vmin=-1, vmax=1)` | vmin·vmax 고정 |
