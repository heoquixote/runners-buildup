## 시작하기 전에

새 데이터를 받으면 그래프를 그리기 전에 먼저 데이터를 훑어봅니다. 행과 열은 몇 개인지, 빈칸은 어디 있는지, 숫자 열은 어떻게 퍼져 있는지, 어떤 열끼리 관계가 있는지. 이렇게 데이터를 이리저리 살펴보며 특징을 파악하는 일을 **EDA**(Exploratory Data Analysis, **탐색적 데이터 분석**)라고 합니다.

앞의 두 갤러리에서 본 차트로 이 일을 하나하나 할 수도 있지만, 열이 수십 개라면 그래프만 수십 장입니다. 그래서 **표를 넣으면 요약 · 그래프 · 경고를 한 번에 만들어 주는 라이브러리**가 여럿 있습니다. 건강검진에 비유하면, 의사가 한 항목씩 재는 대신 종합검진 결과지를 한 번에 받아 보는 것과 같습니다. 이 페이지에서는 그중 많이 쓰는 네 가지를 소개합니다.

## 자동화 라이브러리가 대신해 주는 일

자동화 라이브러리가 무엇을 대신하는지 알면 결과 보고서도 잘 읽을 수 있습니다. 손으로 하는 기본 EDA는 이렇습니다. 먼저 크기와 빈칸입니다.

```run
import pandas as pd

df = pd.read_csv("penguins.csv")
print(df.shape)
print(df.isna().sum())
```

펭귄 344마리 × 7개 열이고, 성별(`sex`)에 빈칸 11개, 숫자 열 네 개에 빈칸이 2개씩 있습니다. 자동화 보고서에서는 이 내용이 '결측치(Missing values)' 칸에 표와 그림으로 나옵니다.

다음은 숫자 열의 요약 통계와 열끼리의 상관계수입니다.

```run
import pandas as pd

df = pd.read_csv("penguins.csv")
print(df.describe().round(1).to_string())
print(df.select_dtypes("number").corr().round(2).to_string())
```

`describe()`는 숫자 열마다 개수 · 평균 · 표준편차 · 최솟값 · 사분위수 · 최댓값을 보여 줍니다. `.to_string()`은 표가 넓어도 가운데를 `...`로 줄이지 말고 전부 출력하라는 뜻입니다. 상관계수 표를 보면 날개 길이와 몸무게가 0.87로 가장 강하게 함께 움직입니다. 열이 7개라 이 정도지만, 열이 50개라면 이 표들만으로는 한눈에 보기 어렵습니다. 여기에 열마다 히스토그램, 범주 열마다 막대, 경고 메시지까지 붙여 HTML 보고서 한 장으로 만들어 주는 것이 아래 라이브러리들입니다.

## 1. fasteda: 노트북에서 한 줄로 훑어보기

[fasteda](https://pypi.org/project/fasteda/)는 함수 하나 `fast_eda(표)`로 노트북 화면에 바로 요약을 출력하는 가벼운 라이브러리입니다.

**설치** (Colab · Jupyter 셀에서)

```python
!pip install fasteda -q  # -q: 설치 메시지를 줄여서 보여 줌
```

**사용법**

```python
from fasteda import fast_eda
import seaborn as sns

tips = sns.load_dataset("tips")  # seaborn이 인터넷에서 예제 데이터를 받아 옴
fast_eda(tips)
```

**보여 주는 것**: 앞 · 뒤 몇 행, 결측치 개수와 결측치 위치 그림, 표 크기, `info()`, `describe()`에 중앙값 · 왜도(치우친 정도) · 첨도(꼬리 두께)를 더한 요약표, 상관계수 히트맵, pairplot, 숫자 열마다 히스토그램과 상자그림, 범주 열마다 개수 막대. `fast_eda(tips, target="tip")`처럼 target을 주면 그 열을 기준으로 살펴봅니다.

**이럴 때 좋아요**: 보고서 파일 없이 노트북 화면에서 빠르게 훑어볼 때.

:::tip fasteda를 쓸 때 알아 둘 점
- 노트북 화면에 결과를 바로 그리는 함수(`display`)를 쓰기 때문에 Colab · Jupyter에서만 제대로 동작합니다. `.py` 파일로 실행하면 오류가 납니다.
- 불러오는 순간 matplotlib 스타일을 `fivethirtyeight`로 바꿉니다. 이후 그리는 그래프 모양도 달라지니, 원래대로 돌리려면 `plt.style.use("default")`를 실행하세요.
- 2023년 이후 업데이트가 없는 작은 라이브러리라 아주 최신 pandas에서는 경고나 오류가 날 수 있습니다.
:::

## 2. YData Profiling: 가장 유명한 EDA 보고서

[ydata-profiling](https://pypi.org/project/ydata-profiling/)(예전 이름 pandas-profiling)은 가장 널리 쓰이는 EDA 자동화 라이브러리입니다. 표 하나로 **여러 페이지짜리 HTML 보고서**를 만듭니다.

**설치**

```python
!pip install ydata-profiling -q
```

**사용법**

```python
from ydata_profiling import ProfileReport
import seaborn as sns

tips = sns.load_dataset("tips")
profile = ProfileReport(
    tips,
    title="Tips Dataset Profiling Report",
    explorative=True,          # 더 자세한 분석까지
)
profile.to_file("tips_report.html")   # 파일로 저장
profile.to_notebook_iframe()          # 노트북 화면에 바로 보기
```

**보고서에서 확인할 수 있는 내용**

| 칸 | 내용 |
| --- | --- |
| Overview | 행 · 열 수, 결측치 비율, 중복 행 수, 열 종류(숫자 · 범주 · 날짜) |
| Alerts | "이 열은 결측치가 많다", "이 두 열은 상관이 너무 높다", "값이 하나뿐이다" 같은 경고 |
| Variables | 열마다 분포 그래프와 통계 요약(평균 · 중앙값 · 최빈값 · 치우침) |
| Interactions | 두 숫자 열을 골라 보는 산점도 |
| Correlations | 상관계수 히트맵 |
| Missing values | 결측치가 어디에 몰려 있는지 그림 |
| Duplicate rows | 완전히 같은 행 목록 |

**장점**: 코드 3줄로 완성되고, HTML 파일 하나라 팀원에게 그대로 공유할 수 있습니다. 새 데이터를 받았을 때 **데이터 품질 점검표**처럼 쓰기 좋습니다. Alerts 칸부터 읽으면 손봐야 할 열이 바로 보입니다.

:::tip 이름이 또 바뀌었어요
2026년 4월부터 이 라이브러리는 **fg-data-profiling**이라는 새 이름으로 개발이 이어지고, ydata-profiling은 더 이상 업데이트되지 않습니다. 새로 시작한다면 `pip install fg-data-profiling` 후 `from data_profiling import ProfileReport`로 쓰면 됩니다. 사용법은 같습니다. 옛 이름으로 설치했는데 `No module named 'pkg_resources'` 오류가 나면 `pip install "setuptools<81"`을 먼저 실행하세요. 데이터가 수십만 행 이상이면 보고서가 오래 걸리니 `ProfileReport(df, minimal=True)`로 가볍게 만듭니다.
:::

## 3. Sweetviz: 깔끔한 그림과 비교 분석

[Sweetviz](https://pypi.org/project/sweetviz/)는 시각화가 깔끔하기로 유명한 EDA 라이브러리입니다. 결과는 한 화면짜리 HTML 앱으로, 왼쪽에 열 목록, 오른쪽에 고른 열의 자세한 그래프가 나옵니다.

**설치**

```python
!pip install sweetviz -q
```

**사용법**

```python
import sweetviz as sv
import seaborn as sns

tips = sns.load_dataset("tips")
report = sv.analyze(tips)
report.show_html("tips_sweetviz.html")   # 파일로 저장(Colab에서는 report.show_notebook()으로 화면에 바로)
```

**특정 타겟 변수 분석**: 팁 금액(`tip`)을 중심으로 보고 싶다면 `target_feat`에 그 열을 줍니다. 그러면 열마다 "이 열의 값에 따라 팁이 어떻게 달라지나"를 함께 그려 줍니다.

```python
report = sv.analyze(tips, target_feat="tip")
report.show_html("tips_target.html")
```

**두 데이터 비교**: Sweetviz만의 강점입니다. 학습용과 시험용 데이터처럼 두 표의 분포를 나란히 비교합니다.

```python
lunch = tips[tips["time"] == "Lunch"]
dinner = tips[tips["time"] == "Dinner"]
report = sv.compare([lunch, "Lunch"], [dinner, "Dinner"])
report.show_html("lunch_vs_dinner.html")
```

**장점**: 변수별 분포 그림이 보기 좋고, 범주 열 분석이 강력합니다. 타겟 열과 다른 열의 관계를 바로 보여 줘서 머신러닝 전에 데이터를 탐색할 때 잘 맞습니다.

## 4. PyGWalker: 파이썬 안의 Tableau

[PyGWalker](https://github.com/kanaries/pygwalker)는 표를 넣으면 노트북 안에 **Tableau처럼 열을 끌어다 놓아 차트를 만드는 화면**을 띄워 줍니다. 앞의 세 가지가 "보고서를 받아 읽는" 도구라면, PyGWalker는 "직접 이리저리 그려 보는" 도구입니다.

**설치**

```python
!pip install pygwalker -q
```

**사용법**

```python
import pygwalker as pyg
import seaborn as sns

tips = sns.load_dataset("tips")
pyg.walk(tips)
```

**특징**: Tableau 스타일 화면에서 열 이름을 x축 · y축 · 색 칸으로 끌어다 놓으면 차트가 바로 바뀝니다. 코드 없이 막대 · 선 · 산점도 · 히트맵을 오가며, 필터와 집계(합계 · 평균)도 마우스로 바꿉니다.

**추천 대상**: Tableau에 익숙한 사람, 코드보다 클릭이 편한 사람, 회의 중 데이터를 빠르게 이리저리 돌려 봐야 할 때.

## 자동화 보고서를 쓸 때 기억할 것

- **출발점이지 결론이 아닙니다.** 보고서는 "이 열에 결측치가 많다", "이 두 열의 상관이 높다"처럼 **무엇을 더 볼지** 알려 줍니다. 왜 그런지, 그래서 무엇을 할지는 앞의 차트로 직접 확인하고 판단해야 합니다.
- **상관이 높다는 경고 = 원인이라는 뜻이 아닙니다.** 앞 페이지의 펭귄처럼 그룹을 섞으면 관계가 뒤집히기도 합니다.
- **큰 데이터는 느립니다.** 수십만 행이면 일부만 뽑아(`df.sample(10000)`) 먼저 돌려 보세요.
- **회사 데이터는 조심합니다.** HTML 보고서에는 실제 값이 들어 있으니 외부에 공유하기 전에 개인정보가 없는지 확인합니다.

## 정리

- **EDA** = 그래프와 요약으로 데이터를 이리저리 살펴 특징을 파악하는 일
- 자동화 라이브러리는 `shape` · `isna()` · `describe()` · `corr()` · 열별 그래프를 한 번에 묶어 준다
- 빠른 훑어보기는 **fasteda**, 품질 점검 보고서는 **YData Profiling**, 타겟 분석 · 데이터 비교는 **Sweetviz**, 드래그로 직접 탐색은 **PyGWalker**
- 브라우저 실습 셀에서는 설치가 안 되니 Colab이나 내 컴퓨터에서 실행한다
- 보고서는 어디를 더 볼지 알려 주는 지도이고, 해석과 판단은 직접 그린 차트로 한다
