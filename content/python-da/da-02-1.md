## 2차원 배열에서 꺼내기

2차원 배열은 `a[행, 열]`로 꺼냅니다. 쉼표 앞이 행, 뒤가 열입니다.

| 코드 | 뜻 |
| --- | --- |
| `a[1]` | 1번 행 전체 |
| `a[:, 2]` | 모든 행의 2번 열 |
| `a[:2, 1:]` | 0~1번 행 × 1번 열부터 끝 (부분 표) |
| `a.shape` | (행 수, 열 수) |

```run
import numpy as np
data = np.array([[10.02, 9.98, 10.05],
                 [10.10, 10.04, 10.12],
                 [9.95, 9.91, 9.99]])
print(data.shape)
print(data[1])        # 두 번째 로트
print(data[:, 2])     # 세 번째 측정 위치
print(data[:2, 1:])   # 부분 표
```

## axis: 어느 방향으로 접을까

`axis=0`은 **행을 따라 위에서 아래로** 접어 열마다 결과 하나, `axis=1`은 **열을 따라 옆으로** 접어 행마다 결과 하나를 남깁니다.

## 브로드캐스팅

모양이 다른 배열끼리 계산하면, NumPy가 **뒤쪽 차원부터** 맞춰 보며 크기가 1이거나 없는 쪽을 늘려 맞춥니다.

- (4, 3) − (3,) → (3,)이 4행으로 늘어나 행마다 같은 값을 뺌
- (4, 1) × (3,) → (4, 3) 표가 만들어짐
- (4,)를 세로로 쓰고 싶으면 `a[:, None]`으로 (4, 1)을 만듭니다

::video{ref="dl-m01"}

```run
import numpy as np
data = np.array([[10.02, 9.98, 10.05],
                 [10.10, 10.04, 10.12],
                 [9.95, 9.91, 9.99]])
col_mean = data.mean(axis=0)          # (3,)
print(col_mean.round(3))
print((data - col_mean).round(3))     # (3, 3) - (3,) → 위치별 편차
```

```run
import numpy as np
prices = np.array([12000, 39000, 8500])
rates = np.array([0.1, 0.2, 0.3])
table = prices[:, None] * (1 - rates)   # (3, 1) × (3,) → (3, 3)
print(table)
```

> 모양이 맞지 않으면 `ValueError: operands could not be broadcast together`가 납니다. `print(a.shape, b.shape)`부터 찍어 보세요.
