da-08-1에서 문자열을 날짜로 바꾸고, `.dt`로 연 · 월 · 요일을 꺼내고, `resample`로 묶었습니다. 이번에는 날짜끼리 **계산**합니다. "고장과 고장 사이가 평균 며칠인가", "유효기간이 며칠 남았나", "10월 둘째 주만 잘라서 보자" 같은 질문입니다. 핵심 도구는 날짜의 차이를 나타내는 **Timedelta**와 날짜 인덱스로 자르기입니다.

## 날짜끼리 빼면 Timedelta

날짜에서 날짜를 빼면 "얼마나 지났나"를 나타내는 **Timedelta**가 나옵니다. 반대로 날짜에 Timedelta를 더하면 그만큼 뒤의 날짜가 됩니다.

```run
import pandas as pd

today = pd.to_datetime('2026-11-06')
xmas = pd.to_datetime('2026-12-25')
gap = xmas - today
print(gap, type(gap).__name__)
print(gap.days, "일")
print(today + pd.Timedelta(days=30))
print(today - pd.Timedelta(hours=36))
```

`pd.Timedelta(days=30)`, `pd.Timedelta(hours=36)`처럼 단위를 이름으로 줍니다. `.days`로 일수만 꺼내고, 시간까지 정확히 필요하면 `.total_seconds()`로 초를 받아 3600으로 나눕니다.

## 열 전체로 계산하기: 유효기간 남은 일수

열끼리도 똑같이 계산됩니다. 숫자 열을 Timedelta로 바꿀 때는 `pd.to_timedelta(열, unit='D')`를 씁니다. `'D'`는 일(day)입니다.

```run
import pandas as pd

today = pd.to_datetime('2026-11-06')
lots = pd.DataFrame({
    'lot': ['L1', 'L2', 'L3'],
    'made': pd.to_datetime(['2026-10-01', '2026-10-20', '2026-11-01']),
    'shelf_days': [30, 30, 45],
})
lots['expire'] = lots['made'] + pd.to_timedelta(lots['shelf_days'], unit='D')
lots['left'] = (lots['expire'] - today).dt.days
print(lots)
print(lots[lots['left'] < 0]['lot'].tolist(), "기한 지남")
```

Series에서 Timedelta의 일수를 꺼낼 때는 `.dt.days`입니다(값 하나일 때는 `.days`). L1은 10월 31일에 기한이 끝나 오늘 기준 -6일, 이미 지났습니다.

## 고장 간격: 그룹 안에서 diff

설비별 고장 기록이 있으면, 설비마다 시간순으로 정렬한 뒤 **직전 고장과의 간격**을 구할 수 있습니다. da-08-1의 `diff`를 날짜 열에 쓰면 Timedelta가 나오고, da-06-2처럼 groupby와 함께 쓰면 설비마다 따로 계산됩니다.

```run
import pandas as pd

log = pd.DataFrame({
    'machine': ['M1', 'M2', 'M1', 'M3', 'M2', 'M1'],
    'fail_time': ['2026-09-03 08:20', '2026-09-10 14:05', '2026-09-18 22:40',
                  '2026-09-21 09:00', '2026-10-02 11:30', '2026-10-05 07:15'],
})
log['fail_time'] = pd.to_datetime(log['fail_time'])
log = log.sort_values(['machine', 'fail_time'])
log['gap_h'] = (log.groupby('machine')['fail_time'].diff().dt.total_seconds() / 3600).round(1)
print(log)
print(log.groupby('machine')['gap_h'].mean().round(1))
```

설비마다 첫 고장은 직전 기록이 없어서 NaN입니다. M1은 약 374시간, 393시간 간격으로 고장 났고 평균은 383.5시간(약 16일)입니다. 고장이 한 번뿐인 M3는 간격을 낼 수 없습니다. 이 평균 간격이 설비 관리에서 말하는 **MTBF**(평균 고장 간격)입니다.

> 정렬을 빼먹으면 간격이 음수가 되거나 엉뚱한 기록끼리 계산됩니다. 시간 계산 전에는 항상 `sort_values`부터 합니다.

## 날짜 인덱스로 기간 자르기

날짜가 인덱스인 데이터는 `loc`에 **날짜 문자열**을 넣어 기간을 자를 수 있습니다. 월까지만 쓰면 그 달 전체, 범위를 쓰면 양 끝을 포함합니다.

```run
import numpy as np
import pandas as pd

idx = pd.date_range('2026-09-01', '2026-11-30', freq='D')
weekend = idx.dayofweek >= 5
qty = pd.Series(np.where(weekend, 600, 1000) + (idx.day % 5) * 10, index=idx)

oct_qty = qty.loc['2026-10']                       # 10월 전체
print(len(oct_qty), oct_qty.sum())
week = qty.loc['2026-10-12':'2026-10-18']          # 양 끝 포함
print(week.tolist())
```

`pd.date_range(시작, 끝, freq='D')`는 하루 간격 날짜 목록을 만듭니다. 생산량은 평일 1,000개, 주말 600개에 날짜마다 조금씩 다른 값을 더해 만든 가상 데이터입니다. `loc['2026-10']`은 10월 31일치를 모두 골랐고, `loc['2026-10-12':'2026-10-18']`은 월요일부터 일요일까지 7일입니다. 마지막 두 값이 주말이라 600대입니다.

## 요일 · 주말 파생 열로 비교하기

날짜 인덱스에서 `dayofweek`(월요일 0 ~ 일요일 6)를 꺼내면 평일 · 주말 비교가 됩니다.

```run
import numpy as np
import pandas as pd

idx = pd.date_range('2026-09-01', '2026-11-30', freq='D')
qty = pd.Series(np.where(idx.dayofweek >= 5, 600, 1000) + (idx.day % 5) * 10, index=idx)

df = qty.to_frame('qty')
df['dow'] = df.index.dayofweek
df['is_weekend'] = df['dow'] >= 5
print(df.groupby('is_weekend')['qty'].agg(['size', 'mean']).round(1))
print(df.groupby('dow')['qty'].mean().round(0).tolist())
```

석 달 91일 중 주말이 26일입니다. 요일별 평균을 보면 5 · 6번(토 · 일)만 600대로 뚝 떨어집니다. 주말을 섞어 하루 평균을 내면 평일 생산 능력을 낮게 보게 되므로, 일 평균 비교는 평일 · 주말을 나눠서 합니다.

| 하고 싶은 일 | 코드 |
| --- | --- |
| 날짜 차이 (일) | `(d2 - d1).days`, 열이면 `.dt.days` |
| 날짜 차이 (시간) | `.total_seconds() / 3600` |
| n일 뒤 | `d + pd.Timedelta(days=n)` |
| 숫자 열을 일수로 | `pd.to_timedelta(열, unit='D')` |
| 한 달 자르기 | `s.loc['2026-10']` |
| 기간 자르기 | `s.loc['2026-10-12':'2026-10-18']` (양 끝 포함) |

## 정리

- 날짜 − 날짜 = Timedelta, 날짜 + Timedelta = 날짜
- 그룹별 간격은 정렬 후 `groupby(...)['시각'].diff()`
- 날짜 인덱스는 `loc['연-월']`이나 `loc['시작':'끝']`으로 자릅니다
- 요일(`dayofweek`)로 평일 · 주말을 나눠 비교합니다
