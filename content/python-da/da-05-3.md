결측과 표기를 정리했다면 남은 일은 세 가지입니다. **튀는 값(이상치)**을 찾아 어떻게 할지 정하고, 연속된 숫자를 **구간**으로 묶어 비교하기 쉽게 만들고, 같은 대상을 여러 번 잰 **중복 측정**에서 어느 것을 남길지 정합니다. [반복문 없이 배열을 한 번에 계산하기](#/l/da-01-1)에서는 평균 ± 3 표준편차로 이상치를 찾았습니다. 이번에는 분포 모양에 덜 흔들리는 IQR 규칙을 씁니다.

## IQR 규칙으로 이상치 찾기

값을 크기순으로 세웠을 때 아래에서 25% 지점이 **Q1**, 75% 지점이 **Q3**입니다. 그 사이 폭 `Q3 − Q1`이 **IQR**(사분위 범위)이고, 가운데 절반의 값이 들어 있는 폭입니다. IQR 규칙은 이 폭의 1.5배보다 더 바깥에 있는 값을 이상치 후보로 봅니다.

> 아래 경계 = Q1 − 1.5 × IQR, 위 경계 = Q3 + 1.5 × IQR

평균과 표준편차는 튀는 값 하나에 크게 끌려가지만, Q1과 Q3는 순서로 정하는 값이라 거의 흔들리지 않습니다. 시각화 트랙의 상자그림([상자그림 읽기](#/l/da-14-3))에서 점으로 찍히는 값이 바로 이 규칙으로 고른 값입니다.

```run
import pandas as pd

df = pd.read_csv("tips.csv")
s = df['total_bill']
q1, q3 = s.quantile([0.25, 0.75])
iqr = q3 - q1
lo, hi = q1 - 1.5 * iqr, q3 + 1.5 * iqr
print(round(q1, 2), round(q3, 2), round(iqr, 2))
print(round(lo, 2), round(hi, 2))
out = (s < lo) | (s > hi)
print(out.sum(), "건, 가장 큰 값", s.max())
```

계산서 금액의 가운데 절반은 13.35~24.13달러이고, 위 경계는 40.3달러입니다. 이보다 큰 계산서 9건이 이상치 후보입니다. 아래 경계는 음수라 아래쪽 이상치는 없습니다.

## 찾은 다음에는: 지우기, 자르기, 그대로 두기

이상치 후보를 찾았다고 바로 지우지 않습니다. 원인에 따라 처리가 다릅니다.

| 원인 | 처리 |
| --- | --- |
| 측정 · 입력 오류 (센서 고장, 단위 실수) | 지우거나 결측으로 바꾼 뒤 [빈칸과 지저분한 값 정리하기](#/l/da-05-1) 방식으로 처리 |
| 실제로 일어난 큰 값 (단체 손님) | 그대로 둔다. 다만 평균 대신 중앙값으로 요약 |
| 분석에 너무 큰 영향을 주는 값 | 경계값으로 자른다 (`clip`) |

`clip(upper=경계)`는 경계보다 큰 값을 경계값으로 바꿉니다. 행은 지우지 않으므로 행 수는 그대로입니다.

```run
import pandas as pd

df = pd.read_csv("tips.csv")
s = df['total_bill']
q1, q3 = s.quantile([0.25, 0.75])
hi = q3 + 1.5 * (q3 - q1)
capped = s.clip(upper=hi)
print(round(s.mean(), 2), "→", round(capped.mean(), 2))
print(len(s), len(capped))
```

평균이 19.79에서 19.59로 조금 줄었습니다. 이 데이터에서는 큰 계산서가 실제 손님이므로 그대로 두는 편이 맞습니다. 처리 방법을 고른 이유를 함께 기록하세요.

설비 데이터에서는 이상치가 오히려 **찾던 신호**일 수 있습니다.

```run
import pandas as pd

df = pd.read_csv("ai4i2020.csv")
r = df['rpm']
q1, q3 = r.quantile([0.25, 0.75])
hi = q3 + 1.5 * (q3 - q1)
high = df[r > hi]
print(hi, len(high))
print(round(high['failure'].mean() * 100, 1), "% vs 전체", round(df['failure'].mean() * 100, 2), "%")
```

회전수가 위 경계 1,895.5를 넘은 418건의 고장률은 8.4%로 전체의 두 배가 넘습니다. 이런 값을 "튀니까 지우자"고 했다면 고장 원인 하나를 함께 지운 셈입니다.

## 구간으로 묶기: cut과 qcut

연속된 숫자는 그대로 groupby 하기 어렵습니다. 구간으로 묶으면 "구간별 비교"가 됩니다.

| 함수 | 구간을 정하는 기준 | 결과 |
| --- | --- | --- |
| `pd.cut(s, bins=[경계들])` | 내가 정한 **경계값** | 구간마다 개수가 다름 |
| `pd.qcut(s, 4)` | 데이터 **개수**가 같도록 | 구간마다 개수가 같음 |

공구 마모 시간을 50분 단위로 자르면 업무에서 쓰는 기준 그대로 비교할 수 있습니다.

```run
import pandas as pd

df = pd.read_csv("ai4i2020.csv")
df['wear_band'] = pd.cut(df['tool_wear'], bins=[0, 50, 100, 150, 200, 260], right=False)
print(df.groupby('wear_band', observed=True)['failure'].agg(['size', 'mean']).round(3))
```

`[0, 50)`은 0 이상 50 미만이라는 뜻입니다. `right=False`가 "오른쪽 끝은 빼라"는 옵션입니다. 고장률은 150분까지 2%대로 거의 같다가 200분을 넘자 15.4%로 뛰어오릅니다. 공구 교체 기준을 정할 때 바로 쓸 수 있는 결과입니다.

`qcut`은 개수가 같은 구간을 만들어서, 구간마다 표본이 고르게 필요할 때 씁니다. `labels`로 이름을 붙입니다.

```run
import pandas as pd

df = pd.read_csv("tips.csv")
df['tip_pct'] = df['tip'] / df['total_bill'] * 100
df['bill_q'] = pd.qcut(df['total_bill'], 4, labels=['Q1', 'Q2', 'Q3', 'Q4'])
print(df.groupby('bill_q', observed=True)['tip_pct'].agg(['size', 'mean']).round(1))
```

네 구간 모두 61건씩입니다. 계산서가 작은 Q1의 팁 비율이 18.6%로 가장 높고, 큰 Q4는 13.3%입니다. 금액이 커질수록 팁 "비율"은 줄어드는 경향입니다.

> 구간 결과는 `category`라는 자료형입니다. groupby에 쓸 때 `observed=True`를 붙이면 값이 없는 구간을 결과에서 뺍니다.

## 중복 측정에서 마지막 값만 남기기

같은 로트를 재검사하면 측정 기록이 두 번 남습니다. [빈칸과 지저분한 값 정리하기](#/l/da-05-1)의 `drop_duplicates(subset='lot', keep='last')`는 **표에 들어온 순서상** 마지막 행을 남깁니다. 기록 순서가 시간 순서와 다르면 엉뚱한 값이 남으므로, **시간순으로 정렬한 뒤** 지웁니다.

```run
import pandas as pd

log = pd.DataFrame({
    'lot':  ['L01', 'L02', 'L01', 'L03', 'L02'],
    'time': ['09:40', '09:10', '09:05', '10:00', '11:30'],
    'size': [10.2, 10.9, 10.7, 10.1, 10.3],
})
print(log.duplicated(subset='lot').sum(), "건 재측정")

wrong = log.drop_duplicates(subset='lot', keep='last')
right = log.sort_values('time').drop_duplicates(subset='lot', keep='last')
print(wrong.sort_values('lot'))
print(right.sort_values('lot'))
```

L01은 09:05에 10.7, 09:40에 재측정해 10.2였습니다. 표에는 09:40 기록이 먼저 들어와 있어서, 정렬 없이 `keep='last'`를 쓰면 옛 값 10.7이 남습니다. 시간순으로 정렬하고 지워야 최신 값 10.2가 남습니다. 두 결과의 L01 줄을 비교해 보세요.

## 정리

- IQR 규칙: Q1 − 1.5·IQR보다 작거나 Q3 + 1.5·IQR보다 크면 이상치 후보
- 이상치는 원인을 보고 지우기 · 자르기(`clip`) · 그대로 두기 중에 고릅니다
- `cut`은 내가 정한 경계, `qcut`은 같은 개수로 구간을 나눕니다
- 중복 측정은 시간순 정렬 후 `drop_duplicates(subset, keep='last')`
