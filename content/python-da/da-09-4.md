## 왜 여러 그래프를 한 그림에

보고서에서 "1등실과 3등실을 비교하면…", "작년과 올해를 나란히 보면…"처럼 **비교**를 할 때가 많습니다. 그래프를 따로따로 그리면 눈이 왔다 갔다 해야 하지만, 한 도화지에 나란히 놓으면 바로 비교됩니다. da-09-1에서 배운 도화지(fig) 하나에 **그래프 칸(ax)을 여러 개** 놓는 방법이 서브플롯(subplots)입니다.

## plt.subplots(행, 열)

`plt.subplots(2, 2)`는 2행 2열, 칸 4개짜리 도화지를 만듭니다. 이때 두 번째 값은 칸 하나가 아니라 **칸들이 든 표(배열)**라서 이름을 `axes`(복수)로 받습니다. 칸은 `axes[행, 열]`로 고르고, 번호는 0부터 셉니다.

::figure{src="content/img/viz/viz04-subplots.svg" alt="plt.subplots(2, 2)로 만든 도화지에 axes[0, 0], axes[0, 1], axes[1, 0], axes[1, 1] 네 칸이 2행 2열로 놓여 있다" caption="axes[행, 열]. 첫 번째 숫자가 위아래(행), 두 번째 숫자가 좌우(열)이고 0부터 셉니다."}

빈 칸 4개에 각자의 주소를 제목으로 써 봅니다.

```run
import matplotlib.pyplot as plt

fig, axes = plt.subplots(2, 2, figsize=(6, 4))
axes[0, 0].set_title("axes[0, 0]")
axes[0, 1].set_title("axes[0, 1]")
axes[1, 0].set_title("axes[1, 0]")
axes[1, 1].set_title("axes[1, 1]")
print("axes 모양:", axes.shape)
```

`axes.shape`가 `(2, 2)`, 즉 2행 2열 표입니다. 이제 각 칸은 da-09-1~3에서 쓴 `ax`와 똑같습니다. 칸마다 다른 차트를 그려 봅니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("titanic.csv")
fig, axes = plt.subplots(2, 2, figsize=(8, 5))
axes[0, 0].hist(df["age"].dropna(), bins=20)
axes[0, 1].bar(["First", "Second", "Third"], df["class"].value_counts()[["First", "Second", "Third"]])
axes[1, 0].scatter(df["age"], df["fare"], alpha=0.3)
axes[1, 1].boxplot(df["fare"])
print("칸 개수:", axes.size)
```

한 줄짜리 배치는 `plt.subplots(1, 3)`처럼 쓰고, 이때는 `axes[0]`, `axes[1]`처럼 번호 하나로 고릅니다. 바로 받아서 이름을 붙일 수도 있습니다: `fig, (ax1, ax2) = plt.subplots(1, 2)`.

## 반복문으로 칸 채우기

그룹마다 같은 차트를 그릴 때는 칸을 하나씩 손으로 쓰지 말고 반복문을 씁니다. `zip(axes, 그룹들)`으로 칸과 그룹을 짝지어 돌립니다. 펭귄 세 종의 몸무게 분포를 칸 3개에 나눠 그려 봅니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("penguins.csv").dropna()
species = ["Adelie", "Chinstrap", "Gentoo"]
fig, axes = plt.subplots(1, 3, figsize=(9, 3))
for ax, name in zip(axes, species):
    ax.hist(df[df["species"] == name]["body_mass_g"], bins=15)
    ax.set_title(name)
print(df.groupby("species")["body_mass_g"].median())
```

2행 이상일 때는 `axes.flat`이 칸들을 한 줄로 펴 주므로 `for ax in axes.flat:`처럼 씁니다.

## 축 공유: 공정하게 비교하기

위 그래프를 다시 보세요. 칸마다 x축 범위가 제각각이라 Gentoo가 실제로 얼마나 무거운지 눈으로 비교하기 어렵습니다. `sharex=True`를 주면 모든 칸이 **같은 x축 눈금**을 씁니다. 세로축을 맞추려면 `sharey=True`입니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("penguins.csv").dropna()
species = ["Adelie", "Chinstrap", "Gentoo"]
fig, axes = plt.subplots(1, 3, figsize=(9, 3), sharex=True, sharey=True)
for ax, name in zip(axes, species):
    ax.hist(df[df["species"] == name]["body_mass_g"], bins=15)
    ax.set_title(name)
print("x 범위:", [tuple(round(v) for v in ax.get_xlim()) for ax in axes])
```

이제 세 칸의 x 범위가 모두 같아서, Gentoo(중앙값 5,050g)의 막대들이 오른쪽에 몰려 있는 것이 바로 보입니다. 직접 해 보세요: `sharex=True`를 지우고 실행해 두 그림을 비교해 봅니다. **비교가 목적인 서브플롯은 축을 공유**하는 것이 원칙입니다.

## 전체 제목과 겹침 정리

칸마다 제목이 있어도, 그림 전체가 무엇인지 알려 주는 **큰 제목**이 있으면 좋습니다. `fig.suptitle()`이 도화지 맨 위에 제목을 답니다. 칸이 많으면 글자끼리 겹치기 쉬운데, `fig.tight_layout()`이 간격을 자동으로 맞춰 줍니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("tips.csv")
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(8, 3))
ax1.hist(df["total_bill"], bins=20)
ax1.set_xlabel("Total bill ($)")
ax2.scatter(df["total_bill"], df["tip"], alpha=0.5)
ax2.set_xlabel("Total bill ($)")
fig.suptitle("Restaurant tips: 244 bills")
fig.tight_layout()
print("행 수:", len(df))
```

이번에 처음 쓰는 `tips.csv`는 한 식당의 계산서 244건입니다. 계산 금액(total_bill), 팁(tip), 성별, 흡연석 여부, 요일(day), 점심/저녁(time), 인원(size)이 들어 있고, seaborn 레슨에서도 계속 씁니다.

## 주석: "여기를 보세요"

그래프에서 가장 중요한 점 하나를 짚어 주면 읽는 사람이 헤매지 않습니다. `ax.annotate("글", xy=(가리킬 점), xytext=(글자 위치), arrowprops=...)`는 화살표와 함께 글을 씁니다. 항공 승객이 가장 많았던 달을 표시해 봅니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("flights.csv")
top = df.loc[df["passengers"].idxmax()]
fig, ax = plt.subplots(figsize=(8, 3))
ax.plot(df.index, df["passengers"])
ax.annotate(f"Peak: {top['month']} {top['year']}", xy=(top.name, top["passengers"]),
            xytext=(top.name - 60, top["passengers"] - 50), arrowprops={"arrowstyle": "->"})
print(top.to_dict())
```

1960년 7월 622(천 명)이 최고점입니다. `idxmax()`는 가장 큰 값이 있는 행 번호를 돌려줍니다. 화살표 없이 글만 쓰려면 `ax.text(x, y, "글")`을 씁니다.

## 두 번째 y축: 단위가 다른 두 값

계산 금액(달러)과 건수(개)처럼 **단위가 다른 두 값**을 한 칸에 그리고 싶을 때가 있습니다. `ax.twinx()`는 같은 x축을 쓰면서 오른쪽에 새 y축을 가진 칸을 하나 더 만듭니다. 인원(size)별 평균 금액은 선으로, 건수는 막대로 그려 봅니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("tips.csv")
g = df.groupby("size")["total_bill"].agg(["mean", "count"])
fig, ax = plt.subplots(figsize=(6, 3))
ax.bar(g.index, g["count"], color="lightgray")
ax2 = ax.twinx()
ax2.plot(g.index, g["mean"], color="crimson", marker="o")
ax.set_ylabel("Number of bills")
ax2.set_ylabel("Average bill ($)", color="crimson")
print(g.round(1))
```

2인 손님이 156건으로 압도적으로 많고, 인원이 늘수록 평균 금액은 7.2달러에서 34.8달러까지 오릅니다. 다만 두 번째 y축은 **오해를 부르기 쉽습니다.** 양쪽 축의 범위를 어떻게 잡느냐에 따라 두 선이 "같이 움직이는 것처럼" 얼마든지 보이게 만들 수 있기 때문입니다. 꼭 필요할 때만 쓰고, 축 이름에 색을 맞춰 어느 축이 어느 선인지 분명히 하세요. 대부분은 칸 두 개로 나누는 편이 더 정직합니다.

## 스타일 바꾸기

matplotlib에는 미리 만들어 둔 **스타일**(배경색, 격자, 글꼴 크기 묶음)이 있습니다. `plt.style.context("스타일")` 안에서 그린 그래프에만 스타일이 적용됩니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("flights.csv")
yearly = df.groupby("year")["passengers"].sum()
with plt.style.context("ggplot"):
    fig, ax = plt.subplots(figsize=(6, 3))
    ax.plot(yearly.index, yearly.values, marker="o")
print("사용할 수 있는 스타일 예:", plt.style.available[:5])
```

`"ggplot"` 대신 `"bmh"`, `"fivethirtyeight"`, `"seaborn-v0_8-whitegrid"`를 넣어 비교해 보세요. 노트북 전체에 적용하려면 맨 위에서 `plt.style.use("ggplot")`을 한 번 부릅니다.

## 그림 파일로 저장하기

완성한 그래프는 `fig.savefig()`로 파일이 됩니다. 보고서·발표에 넣을 때는 이 세 가지만 기억하면 됩니다.

- `dpi=150` 이상: 선명도. 인쇄용은 300
- `bbox_inches="tight"`: 바깥 빈 여백을 잘라 줌
- 확장자로 형식 결정: `.png`(일반), `.svg`·`.pdf`(확대해도 깨지지 않음)

```run
import os
import matplotlib.pyplot as plt

fig, ax = plt.subplots(figsize=(4, 3))
ax.bar(["A", "B", "C"], [3, 7, 5])
fig.savefig("my_chart.png", dpi=150, bbox_inches="tight")
print("저장한 파일 크기:", os.path.getsize("my_chart.png"), "바이트")
```

이 사이트에서는 브라우저 속 가상 폴더에 저장되므로 내 컴퓨터에 파일이 생기지는 않습니다. 주피터나 VS Code에서 실행하면 코드 파일과 같은 폴더에 `my_chart.png`가 생깁니다. `savefig`는 `plt.show()`보다 **먼저** 불러야 빈 그림이 저장되지 않습니다.

## 보고서용 그래프 체크리스트

- 제목이 있나? (가능하면 결론을 제목에: "3등실 생존율이 가장 낮다")
- 축 이름과 **단위**가 있나? (Fare ($), Passengers (thousands))
- 선·색이 여러 개면 범례가 있나?
- 비교하는 칸끼리 축을 공유했나?
- 막대는 0에서 시작하나?
- 한 칸에 한 가지 질문만 담았나?

이어지는 실습 문제에서 선·막대·산점도·서브플롯을 직접 그려 봅니다.
