## 상자가 버린 모양을 되찾기

상자그림([상자그림 읽기](#/l/da-14-3))은 다섯 숫자로 요약하느라 **분포의 모양**을 버립니다. 봉우리가 두 개여도 상자는 평범하게 그려집니다. **바이올린 그래프**는 상자 양옆에 밀도 곡선을 붙여 그 모양을 다시 보여 줍니다.

| 그래프 | 한 줄 설명 | 상자그림보다 나은 점 |
| --- | --- | --- |
| **바이올린** | 상자 양옆에 밀도 곡선을 붙인 것 | 봉우리 개수, 모양이 보인다 |

## 상자는 봉우리를 숨긴다

[히스토그램 읽기](#/l/da-14-1)에서 펭귄 지느러미 길이는 봉우리가 두 개였습니다. 같은 데이터를 상자그림과 바이올린으로 나란히 그려 봅니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("penguins.csv").dropna()
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(7, 4), sharey=True)
sns.boxplot(y=df["flipper_length_mm"], ax=ax1)
ax1.set_title("box")
sns.violinplot(y=df["flipper_length_mm"], ax=ax2)
ax2.set_title("violin")
print(df["flipper_length_mm"].quantile([0.25, 0.5, 0.75]).tolist())
```

> 해석: 상자그림은 190~213mm에 상자가 있고 중앙값이 197mm인 평범한 모양이라, 봉우리가 두 개라는 사실이 전혀 드러나지 않는다. 바이올린은 190mm 근처와 215mm 근처 두 곳이 불룩하고 그 사이(약 205mm)가 잘록해, 서로 다른 무리가 섞여 있음을 보여 준다.

## 바이올린 그래프

**무엇을 나타내나**

- 몸통의 **폭**: 그 값 근처에 데이터가 얼마나 빽빽한가([밀도 곡선(KDE) · 러그 읽기](#/l/da-14-2)의 KDE를 세워서 좌우로 붙인 것)
- 가운데의 작은 상자와 흰 점: 상자그림과 같은 Q1·중앙값·Q3
- 위아래 끝: 데이터가 있는 범위(조금 더 뻗을 수 있음)

종별 몸무게를 바이올린으로 비교합니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("penguins.csv").dropna()
ax = sns.violinplot(data=df, x="species", y="body_mass_g")
print(df.groupby("species")["body_mass_g"].quantile([0.25, 0.5, 0.75]).unstack())
```

**이렇게 읽는다**

1. **가장 불룩한 높이**(봉우리 위치)와 가운데 흰 점(중앙값) → 중심
2. 바이올린의 **세로 길이와 폭** → 퍼짐
3. 불룩한 곳이 **한 군데인지 여러 군데인지**, 위아래 대칭인지 → 모양
4. 다른 바이올린과 **겹치는 높이** → 그룹 차이

> 해석: Adelie와 Chinstrap은 중앙값이 둘 다 3,700g이고 불룩한 높이도 비슷해 몸무게만으로는 구분하기 어렵다. Gentoo는 중앙값 5,050g으로 1,000g 넘게 무겁고, 바이올린이 위아래로 길쭉해 개체마다 차이가 크다.

`hue=`와 `split=True`를 주면 바이올린 하나를 반으로 갈라 왼쪽·오른쪽에 두 그룹을 붙입니다. `inner="quart"`는 안쪽에 사분위(Q1·중앙값·Q3) 점선을 그립니다. `hue_order=`로 암컷을 왼쪽(파랑), 수컷을 오른쪽(주황)에 고정합니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("penguins.csv").dropna()
ax = sns.violinplot(data=df, x="species", y="body_mass_g", hue="sex", hue_order=["FEMALE", "MALE"], split=True, inner="quart")
print(df.groupby(["species", "sex"])["body_mass_g"].median().unstack())
```

> 해석: 세 종 모두 수컷(오른쪽 절반)이 암컷보다 위에 있다. 특히 Gentoo는 암컷 중앙값 4,700g, 수컷 5,500g으로 800g 차이가 나서, 위에서 본 Gentoo 바이올린이 길쭉했던 이유가 암수 차이 때문임을 알 수 있다.

나눠 보기 전에는 "Gentoo는 제각각"이었지만, 나눠 보니 "암수가 다른 두 무리"였습니다. 퍼짐이 크면 **섞인 무리가 없는지** 먼저 의심하는 습관은 히스토그램 때와 같습니다.

## 바이올린을 잘못 읽기 쉬운 점

**① 폭을 데이터 개수로 읽기**: 바이올린은 그룹마다 넓이를 똑같이 맞춰 그립니다. Chinstrap(68마리)과 Adelie(146마리)의 바이올린 크기가 비슷해도 **개수는 두 배 차이**입니다. 바이올린끼리는 모양만 비교하고, 개수는 따로 확인합니다.

**② 끝을 최솟값·최댓값으로 읽기**: 바이올린은 KDE라서 실제 데이터 바깥까지 조금 뻗습니다([밀도 곡선(KDE) · 러그 읽기](#/l/da-14-2)의 꼬리 문제). 정확한 범위가 필요하면 숫자로 확인합니다.

**③ 데이터가 적을 때 모양 믿기**: 데이터가 20개 정도면 매끈한 바이올린 모양은 대부분 곡선이 만들어 낸 것입니다. 이럴 때는 다음 레슨 [스트립 · 스웜 읽기](#/l/da-14-6)처럼 점을 다 찍는 그래프가 더 정직합니다.

## 정리: 바이올린

| 그래프 | 코드 | 보이는 것 | 안 보이는 것 |
| --- | --- | --- | --- |
| 상자그림 | `sns.boxplot` | 중앙값, IQR, 이상치 | 봉우리, 개수 |
| 바이올린 | `sns.violinplot` | 상자 + 모양(봉우리) | 개수, 정확한 범위 |
