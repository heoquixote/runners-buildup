## 상자가 버린 정보를 되찾기

상자그림([상자그림 읽기](#/l/da-14-3))은 다섯 숫자로 요약하느라 **분포의 모양**과 **데이터 개수**를 버립니다. 이 레슨의 세 그래프는 그 정보를 다시 보여 줍니다.

| 그래프 | 한 줄 설명 | 상자그림보다 나은 점 |
| --- | --- | --- |
| **바이올린** | 상자 양옆에 밀도 곡선을 붙인 것 | 봉우리 개수, 모양이 보인다 |
| **스트립(strip)** | 값마다 점 하나, 옆으로 살짝 흩뿌림 | 실제 데이터와 개수가 보인다 |
| **스웜(swarm)** | 점이 겹치지 않게 옆으로 쌓음 | 개수와 모양이 동시에 보인다 |

## 상자는 봉우리를 숨긴다

[히스토그램 읽기](#/l/da-14-1)에서 펭귄 지느러미 길이는 봉우리가 두 개였습니다. 같은 데이터를 상자그림과 바이올린으로 나란히 그려 봅니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("penguins.csv").dropna()
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(7, 4), sharey=True)
sns.boxplot(y=df["flipper_length_mm"], ax=ax1)
ax1.set_title("box")
sns.violinplot(y=df["flipper_length_mm"], ax=ax2)
ax2.set_title("violin")
print(df["flipper_length_mm"].quantile([0.25, 0.5, 0.75]).tolist())
```

> 해석: 상자그림은 190~213mm에 상자가 있고 중앙값이 197mm인 평범한 모양이라, 봉우리가 두 개라는 사실이 전혀 드러나지 않는다. 바이올린은 190mm 근처와 215mm 근처 두 곳이 불룩하고 그 사이(약 205mm)가 잘록해, 서로 다른 무리가 섞여 있음을 보여 준다.

## 바이올린 그래프

**무엇을 나타내나**

- 몸통의 **폭**: 그 값 근처에 데이터가 얼마나 빽빽한가([밀도 곡선과 ECDF 읽기](#/l/da-14-2)의 KDE를 세워서 좌우로 붙인 것)
- 가운데의 작은 상자와 흰 점: 상자그림과 같은 Q1·중앙값·Q3
- 위아래 끝: 데이터가 있는 범위(조금 더 뻗을 수 있음)

종별 몸무게를 바이올린으로 비교합니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("penguins.csv").dropna()
ax = sns.violinplot(data=df, x="species", y="body_mass_g")
print(df.groupby("species")["body_mass_g"].quantile([0.25, 0.5, 0.75]).unstack())
```

**이렇게 읽는다**

1. **가장 불룩한 높이**(봉우리 위치)와 가운데 흰 점(중앙값) → 중심
2. 바이올린의 **세로 길이와 폭** → 퍼짐
3. 불룩한 곳이 **한 군데인지 여러 군데인지**, 위아래 대칭인지 → 모양
4. 다른 바이올린과 **겹치는 높이** → 그룹 차이

> 해석: Adelie와 Chinstrap은 중앙값이 둘 다 3,700g이고 불룩한 높이도 비슷해 몸무게만으로는 구분하기 어렵다. Gentoo는 중앙값 5,050g으로 1,000g 넘게 무겁고, 바이올린이 위아래로 길쭉해 개체마다 차이가 크다.

`hue=`와 `split=True`를 주면 바이올린 하나를 반으로 갈라 왼쪽·오른쪽에 두 그룹을 붙입니다. `inner="quart"`는 안쪽에 사분위(Q1·중앙값·Q3) 점선을 그립니다. `hue_order=`로 암컷을 왼쪽(파랑), 수컷을 오른쪽(주황)에 고정합니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("penguins.csv").dropna()
ax = sns.violinplot(data=df, x="species", y="body_mass_g", hue="sex", hue_order=["FEMALE", "MALE"], split=True, inner="quart")
print(df.groupby(["species", "sex"])["body_mass_g"].median().unstack())
```

> 해석: 세 종 모두 수컷(오른쪽 절반)이 암컷보다 위에 있다. 특히 Gentoo는 암컷 중앙값 4,700g, 수컷 5,500g으로 800g 차이가 나서, 위에서 본 Gentoo 바이올린이 길쭉했던 이유가 암수 차이 때문임을 알 수 있다.

나눠 보기 전에는 "Gentoo는 제각각"이었지만, 나눠 보니 "암수가 다른 두 무리"였습니다. 퍼짐이 크면 **섞인 무리가 없는지** 먼저 의심하는 습관은 히스토그램 때와 같습니다.

## 바이올린을 잘못 읽기 쉬운 점

**① 폭을 데이터 개수로 읽기**: 바이올린은 그룹마다 넓이를 똑같이 맞춰 그립니다. Chinstrap(68마리)과 Adelie(146마리)의 바이올린 크기가 비슷해도 **개수는 두 배 차이**입니다. 바이올린끼리는 모양만 비교하고, 개수는 따로 확인합니다.

**② 끝을 최솟값·최댓값으로 읽기**: 바이올린은 KDE라서 실제 데이터 바깥까지 조금 뻗습니다([밀도 곡선과 ECDF 읽기](#/l/da-14-2)의 꼬리 문제). 정확한 범위가 필요하면 숫자로 확인합니다.

**③ 데이터가 적을 때 모양 믿기**: 데이터가 20개 정도면 매끈한 바이올린 모양은 대부분 곡선이 만들어 낸 것입니다. 이럴 때는 아래의 점 그래프가 더 정직합니다.

## 스트립 그래프: 점을 다 찍는다

`stripplot`은 값 하나하나를 점으로 찍고, 겹치지 않도록 옆으로 살짝 무작위로 흩뿌립니다(jitter). 요일별 팁을 찍어 봅니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("tips.csv")
order = ["Thur", "Fri", "Sat", "Sun"]
ax = sns.stripplot(data=df, x="day", y="tip", order=order, alpha=0.6)
print(df["day"].value_counts()[order].to_dict())
print("가장 많은 팁 금액:", df["tip"].value_counts().head(3).to_dict())
```

**무엇을 나타내나**: 점 하나 = 계산서 하나. 가로 위치는 의미가 없고(겹치지 않게 흩뿌린 것), **세로 위치만** 값입니다.

**이렇게 읽는다**

1. **점이 얼마나 많은가** → 그룹 크기(상자·바이올린에서는 안 보이던 것)
2. **점이 빽빽한 높이** → 값이 몰린 곳
3. **줄지어 늘어선 점** → 같은 값이 반복됨
4. **혼자 떨어진 점** → 튀는 값

> 해석: 금요일은 점이 19개뿐이라 한눈에 데이터가 적다는 것이 보인다. 네 요일 모두 2달러, 3달러 높이에 점이 가로로 줄지어 있는데, 손님들이 팁을 딱 떨어지는 금액(2달러 33번, 3달러 23번)으로 주는 습관이 있기 때문이다. 10달러 점 하나는 토요일에만 있다.

"딱 떨어지는 금액에 몰린다"는 사실은 상자그림이나 바이올린으로는 절대 보이지 않습니다. **실제 점을 찍어 봐야 보이는 패턴**이 있습니다.

## 스웜 그래프: 점을 겹치지 않게 쌓기

`swarmplot`은 점을 무작위로 흩뿌리지 않고, **겹치지 않게 옆으로 차곡차곡** 쌓습니다. 그래서 점들의 윤곽이 바이올린 모양이 되어, 개수와 모양을 동시에 보여 줍니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("penguins.csv").dropna()
fig, ax = plt.subplots(figsize=(6, 4))
sns.swarmplot(data=df, x="species", y="body_mass_g", hue="sex", hue_order=["FEMALE", "MALE"], size=3, ax=ax)
print(df.groupby("species").size().to_dict())
```

**이렇게 읽는다**: 무리가 **옆으로 넓게 퍼진 높이**가 값이 많은 곳(바이올린의 불룩한 곳)이고, 무리의 **전체 크기**가 데이터 개수입니다. 색을 나누면 두 그룹이 위아래로 갈리는지 섞이는지가 보입니다.

> 해석: Adelie(146마리) 무리가 Chinstrap(68마리)보다 옆으로 두 배쯤 넓어 개수 차이가 그대로 보인다. 세 종 모두 수컷(주황) 점은 위쪽, 암컷(파랑) 점은 아래쪽에 모여 암수가 몸무게로 꽤 잘 갈린다.

**잘못 읽기 쉬운 점**: 스웜은 데이터가 수백 개를 넘으면 점을 놓을 자리가 없어 옆으로 끝없이 퍼지거나 경고가 납니다. 데이터가 많으면 스트립에 `alpha`(투명도)를 주거나 바이올린을 씁니다.

## 상자 + 점 겹쳐 그리기

실무에서 가장 많이 쓰는 조합은 **상자그림 위에 스트립**을 겹치는 것입니다. 상자로 요약(중앙값·IQR)을 읽고, 점으로 개수와 실제 값을 확인합니다. 상자의 이상치 점은 스트립 점과 겹치므로 `fliersize=0`으로 끕니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("tips.csv")
order = ["Thur", "Fri", "Sat", "Sun"]
ax = sns.boxplot(data=df, x="day", y="total_bill", order=order, fliersize=0, color="lightgray")
sns.stripplot(data=df, x="day", y="total_bill", order=order, ax=ax, size=3, alpha=0.6)
print(df.groupby("day")["total_bill"].median()[order].round(1).to_dict())
```

> 해석: 상자로는 주말 중앙값(토 18.2, 일 19.6)이 평일(목 16.2, 금 15.4)보다 조금 높다는 것을 읽고, 점으로는 금요일 데이터가 유난히 적어 금요일 상자를 덜 믿어야 한다는 것을 함께 읽을 수 있다.

## 정리: 분포 그래프 여섯 가지

| 그래프 | 코드 | 보이는 것 | 안 보이는 것 | 언제 |
| --- | --- | --- | --- | --- |
| 히스토그램 | `sns.histplot` | 모양, 봉우리, 개수 | 그룹 여러 개 비교는 어지러움 | 그룹 1~2개 자세히 |
| 밀도 곡선 | `sns.kdeplot` | 모양, 그룹끼리 겹침 | 개수, 실제 범위 | 그룹 2~4개 모양 비교 |
| ECDF | `sns.ecdfplot` | 중앙값, "~ 이하 몇 %" | 봉우리가 직관적이지 않음 | 백분위 비교 |
| 상자그림 | `sns.boxplot` | 중앙값, IQR, 이상치 | 봉우리, 개수 | 그룹 여러 개를 한 줄로 |
| 바이올린 | `sns.violinplot` | 상자 + 모양(봉우리) | 개수 | 그룹 여러 개 모양까지 |
| 스트립 · 스웜 | `sns.stripplot`, `sns.swarmplot` | 모든 점, 개수, 반복 값 | 데이터가 많으면 뭉개짐 | 데이터가 수백 개 이하 |

고르는 기준은 간단합니다. **데이터가 적으면 점을 다 찍고, 많으면 요약(상자·바이올린)하고, 둘 다 원하면 겹쳐 그립니다.**
