## 분포를 상자 하나로 요약하기

히스토그램은 분포를 자세히 보여 주지만, 그룹이 서너 개만 돼도 나란히 놓고 비교하기 어렵습니다. **상자그림(box plot)**은 분포를 **다섯 개의 숫자와 이상치**로 요약한 그림이라, 여러 그룹을 한 줄로 세워 비교하기에 가장 좋습니다. 대신 요약하느라 버리는 정보도 있어서, 무엇을 읽을 수 있고 무엇을 읽을 수 없는지 정확히 알아야 합니다.

## 상자그림의 부품

::figure{src="content/img/viz/viz03-boxplot.svg" alt="위쪽 히스토그램과 아래쪽 상자그림을 맞대어, 상자의 한쪽 끝은 Q1, 가운데 선은 중앙값, 다른 쪽 끝은 Q3, 양쪽 수염은 이상치를 뺀 최솟값과 최댓값, 그 밖의 점은 이상치임을 보여 준다" caption="같은 데이터를 히스토그램(위)과 상자그림(아래)으로. 상자에는 가운데 50%가 들어 있습니다."}

데이터를 작은 값부터 한 줄로 세웠다고 생각하세요.

| 부품 | 뜻 | 줄 세운 데이터에서 |
| --- | --- | --- |
| **중앙값** (상자 속 선) | 한가운데 값 | 50% 지점 |
| **Q1** (상자 아래 끝) | 1사분위수 | 아래에서 25% 지점 |
| **Q3** (상자 위 끝) | 3사분위수 | 아래에서 75% 지점 |
| **IQR** (상자 높이) | Q3 − Q1 | 가운데 50%가 퍼진 폭 |
| **수염** | 상자에서 IQR × 1.5 안에 있는 가장 먼 값까지 | 이상치를 뺀 최솟값·최댓값 |
| **점** | 수염 밖의 값 | 이상치 후보 |

## 상자 하나 읽기

타이타닉 운임을 상자그림으로 그려 봅니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("titanic.csv")
fig, ax = plt.subplots(figsize=(3, 4))
ax.boxplot(df["fare"])
q1, q2, q3 = df["fare"].quantile([0.25, 0.5, 0.75])
upper = q3 + 1.5 * (q3 - q1)
print("Q1", round(q1, 1), "/ 중앙값", round(q2, 1), "/ Q3", round(q3, 1), "/ 수염 한계", round(upper, 1))
print("이상치 개수:", int((df["fare"] > upper).sum()))
```

**이렇게 읽는다**

1. **중앙값**: 상자 속 선의 높이 → 중심
2. **상자 높이(IQR)**: 가운데 절반이 얼마나 퍼졌나 → 퍼짐
3. **중앙값이 상자 안 어디에 있나, 위아래 수염 길이가 같나** → 모양(치우침)
4. **점**: 개수와 위치 → 튀는 값

> 해석: 승객 절반의 운임은 7.9~31.0 사이에 있고 중앙값은 14.5다. 상자 위쪽 수염이 아래쪽보다 길고, 65.6을 넘는 이상치가 116개(13%)나 위쪽에만 있어 비싼 쪽으로 꼬리가 긴 분포다.

## 상자로 치우침 읽기

상자그림에서도 분포의 모양([히스토그램 읽기](#/l/da-14-1)의 네 가지)을 어느 정도 읽을 수 있습니다.

| 상자에서 보이는 것 | 분포 모양 |
| --- | --- |
| 중앙값이 상자 한가운데, 수염 길이가 비슷 | 대칭 |
| 중앙값이 상자 **아래쪽**에 붙고, **위** 수염과 점이 김 | 위(큰 값) 쪽 꼬리 |
| 중앙값이 상자 **위쪽**에 붙고, **아래** 수염과 점이 김 | 아래(작은 값) 쪽 꼬리 |

**잘못 읽기 쉬운 점**: 상자그림에서는 **봉우리가 두 개인지 알 수 없습니다.** 봉우리 두 개짜리 분포도 상자는 평범하게 그려집니다. 이것이 상자그림의 가장 큰 약점이고, 다음 레슨 [바이올린 그래프 읽기](#/l/da-14-4)가 이를 보완합니다.

## 그룹별 상자 나란히 놓기

상자그림의 진짜 힘은 **그룹 비교**입니다. seaborn `boxplot`에 x(그룹)와 y(값)를 주면 상자가 나란히 섭니다. 객실 등급별 운임을 비교합니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("titanic.csv")
ax = sns.boxplot(data=df, x="class", y="fare", order=["First", "Second", "Third"])
print(df.groupby("class")["fare"].quantile([0.25, 0.5, 0.75]).unstack().round(1))
```

**이렇게 읽는다**

1. **중앙값 선끼리** 높이 비교 → 어느 그룹이 전반적으로 높은가
2. **상자 높이끼리** 비교 → 어느 그룹이 그룹 안에서 더 제각각인가
3. **상자끼리 겹치는 정도** → 겹치지 않으면 확실히 다른 그룹, 많이 겹치면 차이가 작음
4. **점** → 어느 그룹에 이상치가 많은가

> 해석: 1등실 운임의 중앙값(60.3)은 2등실(14.2)의 4배, 3등실(8.0)의 7배가 넘는다. 1등실 상자는 30.9~93.5로 길어 같은 1등실 안에서도 운임 차이가 컸고, 다른 두 등급의 상자와 거의 겹치지 않는다. 2등실과 3등실은 상자가 일부 겹쳐 차이가 상대적으로 작다.

식당 계산 금액을 요일별로도 비교해 봅니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("tips.csv")
order = ["Thur", "Fri", "Sat", "Sun"]
ax = sns.boxplot(data=df, x="day", y="total_bill", order=order)
q = df.groupby("day")["total_bill"].quantile([0.25, 0.5, 0.75]).unstack().loc[order]
print(q.round(1))
```

> 해석: 중앙값은 일요일 19.6, 토요일 18.2로 주말이 목·금요일(약 16)보다 2~4달러 높다. 하지만 네 상자가 대부분 겹쳐 요일에 따른 차이는 크지 않다. 네 요일 모두 위쪽에만 이상치 점이 있어, 가끔 큰 금액을 쓰는 손님이 요일과 상관없이 있다.

## 상자그림을 잘못 읽기 쉬운 점

**① 가운데 선을 평균으로 읽기**: 상자 속 선은 **중앙값**입니다. 꼬리가 긴 분포에서는 평균과 꽤 다릅니다(운임: 평균 32.2, 중앙값 14.5).

**② 상자 크기를 데이터 개수로 읽기**: 상자가 크다 = 데이터가 많다가 **아닙니다.** 상자 높이는 **값이 퍼진 정도**일 뿐, 데이터가 19개든 87개든 상관없습니다. 요일별 계산서 수를 함께 확인해 봅니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("tips.csv")
order = ["Thur", "Fri", "Sat", "Sun"]
ax = sns.boxplot(data=df, x="day", y="total_bill", order=order)
n = df["day"].value_counts()[order]
ax.set_xticks(range(4), [f"{d}\nn={n[d]}" for d in order])
print(n.to_dict())
```

금요일 상자는 다른 요일과 비슷한 크기지만 데이터는 19개뿐입니다. **상자그림 아래에 n(데이터 개수)을 적어 주는 것**이 좋은 습관입니다.

**③ 이상치 = 잘못된 값이라고 단정하기**: 수염 밖의 점은 "다른 값들에서 멀리 떨어졌다"는 뜻일 뿐, 오류라는 뜻이 아닙니다. 1등실의 비싼 운임은 실제로 비싼 표였습니다. 이상치는 지우기 전에 **왜 그런 값이 나왔는지** 먼저 확인합니다.

## 정리: 상자그림 읽기

| 단계 | 볼 것 | 해석 문장 틀 |
| --- | --- | --- |
| 1. 중심 | 중앙값 선 높이 | "A의 중앙값은 B의 N배다" |
| 2. 퍼짐 | 상자 높이(IQR) | "A는 그룹 안에서 값 차이가 크다" |
| 3. 겹침 | 상자끼리 겹치나 | "상자가 거의 겹치지 않아 확실히 다르다" |
| 4. 모양 | 중앙값 위치, 수염 길이 | "위쪽 꼬리가 길다" |
| 5. 이상치 | 점의 개수와 방향 | "큰 쪽에만 이상치가 n개 있다" |
| 확인 | 데이터 개수 n, 봉우리 개수(상자로는 안 보임) | |

| 그래프 | 코드 |
| --- | --- |
| 상자 하나 | `ax.boxplot(값)` |
| 그룹별 상자 | `sns.boxplot(data=, x="그룹", y="값", order=)` |
| 두 기준으로 나눈 상자 | `sns.boxplot(..., hue=)` |
