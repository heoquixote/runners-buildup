## 기준이 두 개일 때

"등급별 생존율"은 기준이 하나(등급)입니다. 그런데 "등급별 생존율을 **성별로 나눠서**"처럼 기준이 둘이 되면 그래프를 읽는 방향도 둘이 됩니다.

- **묶음 안에서** 비교: 같은 1등실 안에서 여성 vs 남성
- **묶음끼리** 비교: 같은 여성끼리 1등실 vs 3등실

이 레슨에서는 두 기준으로 나눈 비교 그래프 네 가지(묶음 막대, 점 그래프의 평행·엇갈림, 점 그래프(dot plot), 칸 나누기)를 읽습니다.

## 묶음 막대

seaborn에서는 `hue=`만 더하면 막대가 두 번째 기준으로 나뉘어 나란히 섭니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("titanic.csv")
ax = sns.barplot(data=df, x="class", y="survived", hue="sex", order=["First", "Second", "Third"], errorbar=None)
ax.set_ylabel("Survival rate")
print(df.pivot_table(index="class", columns="sex", values="survived").round(2))
```

**무엇을 나타내나**

- x축: 첫 번째 기준(등급). 한 자리에 막대 묶음 하나
- 색: 두 번째 기준(성별). 범례로 확인
- 막대 높이: 그 조합의 값(생존율)

**이렇게 읽는다**

1. **묶음 안**: 같은 등급 안에서 색끼리 차이가 얼마나 큰가
2. **묶음끼리**: 같은 색끼리 등급이 바뀔 때 어떻게 변하나
3. 두 차이 중 **어느 쪽이 더 큰가** → 더 큰 쪽이 결과에 더 크게 관련된 기준

> 해석: 모든 등급에서 여성 생존율이 남성보다 훨씬 높다(1등실 0.97 vs 0.37, 3등실 0.50 vs 0.14). 성별 차이(약 0.35~0.76)가 같은 성별 안의 등급 차이보다 대체로 커서, 생존에는 성별이 등급보다 더 크게 관련돼 있었다.

**잘못 읽기 쉬운 점**: 묶음 막대는 `hue`로 나눈 쪽(색끼리)을 가까이 두므로, **묶음 안 비교가 쉽고 묶음끼리 비교는 어렵습니다.** 어떤 비교가 중요한지 정한 뒤, 그 비교를 쉽게 하는 쪽을 `hue`로 두세요. 성별끼리 등급을 비교하고 싶다면 `x="sex", hue="class"`로 바꾸면 됩니다.

## 평행한 선, 엇갈리는 선

두 기준의 관계를 읽을 때 가장 강력한 그래프는 **점 그래프**(`pointplot`)입니다. 같은 색의 평균을 선으로 이어 주므로, 선의 모양으로 "한 기준의 효과가 다른 기준에 따라 달라지는가"를 읽을 수 있습니다.

::figure{src="content/img/viz/viz15-interaction.svg" alt="두 선이 평행하면 한 기준의 효과가 다른 기준과 상관없이 일정하고, 기울기가 다르거나 엇갈리면 효과가 조건에 따라 달라진다" caption="평행하면 '효과가 일정', 엇갈리면 '조건에 따라 효과가 달라진다'."}

먼저 펭귄 종별 몸무게를 성별로 나눠 봅니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("penguins.csv").dropna()
ax = sns.pointplot(data=df, x="species", y="body_mass_g", hue="sex", dodge=True)
print(df.pivot_table(index="species", columns="sex", values="body_mass_g").round(0))
```

> 해석: 세 종 모두 수컷이 암컷보다 400~800g 무겁고, 두 선이 거의 나란히 움직인다. 종이 달라도 "수컷이 더 무겁다"는 관계는 일정하다.

이번에는 식당 팁을 점심·저녁과 흡연석 여부로 나눠 봅니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("tips.csv")
ax = sns.pointplot(data=df, x="time", y="tip", hue="smoker", dodge=True, errorbar=None)
print(df.pivot_table(index="time", columns="smoker", values="tip").round(2))
```

> 해석: 점심에는 흡연석(Yes) 팁이 2.83달러로 비흡연석(2.67달러)보다 많지만, 저녁에는 비흡연석이 3.13달러로 조금 더 많다. 두 선이 엇갈려, 흡연석 여부와 팁의 관계는 시간대에 따라 방향이 바뀐다. 다만 차이가 0.06~0.16달러로 작아서, 실제로 의미 있는 차이인지는 오차 막대와 함께 봐야 한다.

**이렇게 읽는다**

| 선 모양 | 뜻 | 해석 문장 틀 |
| --- | --- | --- |
| 평행 | 두 기준의 효과가 따로따로 일정 | "A와 상관없이 B가 ~할수록 ~하다" |
| 기울기가 다름 | 한 기준의 효과 크기가 다른 기준에 따라 다름 | "B의 효과는 A가 ~일 때 더 크다" |
| 엇갈림 | 효과의 방향이 뒤집힘 | "A가 ~일 때는 ~, ~일 때는 반대다" |

**잘못 읽기 쉬운 점**: 선이 조금만 엇갈려도 "방향이 바뀐다"고 단정하기 쉽습니다. 차이가 오차 막대 안에 들어오는 정도라면 우연일 수 있습니다. `errorbar=None`을 지우고 다시 실행해 오차 막대와 함께 보세요.

## 점 그래프(dot plot): 범주가 많을 때

비교할 범주가 6개, 9개처럼 많아지면 막대가 빽빽해집니다. **점 그래프**(dot plot)는 막대 대신 점 하나만 찍어 잉크를 줄이고, 값순으로 정렬해 순위를 읽기 쉽게 합니다. 막대가 없으니 축이 0에서 시작하지 않아도 됩니다. 타이타닉 등급 × (성인 남자·여자·어린이) 9개 조합의 생존율을 그려 봅니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("titanic.csv")
rate = df.groupby(["class", "who"])["survived"].mean().sort_values()
labels = [f"{c} {w}" for c, w in rate.index]
fig, ax = plt.subplots(figsize=(6, 4))
ax.hlines(labels, 0, rate.values, color="lightgray")
ax.plot(rate.values, labels, "o", color="crimson")
ax.set_xlabel("Survival rate")
print(rate.round(2))
```

점에서 왼쪽 축까지 가는 회색 선을 그은 모양을 **롤리팝(막대사탕) 그래프**라고 부릅니다. 점만 남기면 점 그래프입니다.

> 해석: 생존율 하위 3개는 모두 성인 남자(2등실 0.08, 3등실 0.12, 1등실 0.35)이고, 상위 4개는 1·2등실 여성과 어린이(0.83~1.00)다. 3등실 여성과 어린이(0.43~0.49)는 그 중간에 따로 모여 있다.

**이렇게 읽는다**: 정렬된 점 그래프는 **점들이 모여 있는 무리와 무리 사이 빈틈**을 찾으면 됩니다. 위 결과에서는 0.35와 0.43 사이, 0.49와 0.83 사이가 큰 빈틈이라 세 무리로 나뉩니다.

## 칸 나누기: 기준이 세 개일 때

기준이 하나 더 늘면 색만으로는 부족합니다. `sns.catplot(..., col=)`은 세 번째 기준의 값마다 **칸을 나눠** 같은 그래프를 나란히 그립니다. 등급별 생존율을 승선 항구별 칸으로 나눠 봅니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("titanic.csv")
g = sns.catplot(data=df, x="class", y="survived", col="embark_town", kind="bar", errorbar=None,
                order=["First", "Second", "Third"], height=2.8)
print(pd.crosstab(df["embark_town"], df["class"]))
```

**이렇게 읽는다**: 칸끼리 y축을 공유하므로 칸을 가로질러 같은 막대 높이를 비교할 수 있습니다. 먼저 **모든 칸에 공통인 패턴**을 찾고, 그다음 **한 칸만 다른 곳**을 찾습니다.

> 해석: 세 항구 모두 대체로 등급이 낮을수록 생존율이 낮다. 다만 Queenstown 칸은 2등실이 1등실보다 높아 보이는데, 아래 표를 보면 Queenstown의 1등실은 2명, 2등실은 3명뿐이다. 이 칸의 1·2등실 막대는 사람 몇 명으로 정해진 값이라 해석하면 안 된다.

**잘못 읽기 쉬운 점**: 칸을 나눌수록 칸마다 데이터가 줄어듭니다. **이상해 보이는 칸이 있으면 먼저 그 칸의 데이터 개수를 확인**하세요(`pd.crosstab`). 대부분은 데이터가 너무 적어서 생긴 착시입니다.

## 정리: 두 기준 비교 그래프

| 그래프 | 코드 | 먼저 읽을 것 | 주의 |
| --- | --- | --- | --- |
| 묶음 막대 | `sns.barplot(..., hue=)` | 묶음 안 차이 vs 묶음끼리 차이 | 중요한 비교를 hue 쪽에 |
| 점 그래프 (평행·엇갈림) | `sns.pointplot(..., hue=, dodge=True)` | 선이 평행인가, 엇갈리나 | 작은 엇갈림은 오차 막대와 함께 |
| 점 그래프 · 롤리팝 | `ax.hlines` + `ax.plot(..., "o")` | 정렬 순위, 무리와 빈틈 | 값순으로 정렬 |
| 칸 나누기 | `sns.catplot(..., col=)` | 모든 칸 공통 패턴 → 다른 칸 | 칸마다 데이터 개수 확인 |
