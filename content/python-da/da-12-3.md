## 기준이 두 개일 때

"등급별 생존율"은 기준이 하나(등급)입니다. 그런데 "등급별 생존율을 **성별로 나눠서**"처럼 기준이 둘이 되면 그래프를 읽는 방향도 둘이 됩니다.

- **묶음 안에서** 비교: 같은 1등실 안에서 여성 vs 남성
- **묶음끼리** 비교: 같은 여성끼리 1등실 vs 3등실

이 레슨에서는 기준이 둘일 때 쓰는 **묶음 막대**와, 기준이 셋으로 늘었을 때 쓰는 **칸 나누기**를 읽습니다. 둘 다 [막대 그래프 읽기](#/l/da-12-1)의 막대를 그대로 쓰고, 나누는 방법만 다릅니다.

## 묶음 막대

seaborn에서는 `hue=`만 더하면 막대가 두 번째 기준으로 나뉘어 나란히 섭니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("titanic.csv")
ax = sns.barplot(data=df, x="class", y="survived", hue="sex", order=["First", "Second", "Third"], errorbar=None)
ax.set_ylabel("Survival rate")
print(df.pivot_table(index="class", columns="sex", values="survived").round(2))
```

**무엇을 나타내나**

- x축: 첫 번째 기준(등급). 한 자리에 막대 묶음 하나
- 색: 두 번째 기준(성별). 범례로 확인
- 막대 높이: 그 조합의 값(생존율)

**이렇게 읽는다**

1. **묶음 안**: 같은 등급 안에서 색끼리 차이가 얼마나 큰가
2. **묶음끼리**: 같은 색끼리 등급이 바뀔 때 어떻게 변하나
3. 두 차이 중 **어느 쪽이 더 큰가** → 더 큰 쪽이 결과에 더 크게 관련된 기준

> 해석: 모든 등급에서 여성 생존율이 남성보다 훨씬 높다(1등실 0.97 vs 0.37, 3등실 0.50 vs 0.14). 성별 차이(약 0.35~0.76)가 같은 성별 안의 등급 차이보다 대체로 커서, 생존에는 성별이 등급보다 더 크게 관련돼 있었다.

**잘못 읽기 쉬운 점**: 묶음 막대는 `hue`로 나눈 쪽(색끼리)을 가까이 두므로, **묶음 안 비교가 쉽고 묶음끼리 비교는 어렵습니다.** 어떤 비교가 중요한지 정한 뒤, 그 비교를 쉽게 하는 쪽을 `hue`로 두세요. 성별끼리 등급을 비교하고 싶다면 `x="sex", hue="class"`로 바꾸면 됩니다.

## 칸 나누기: 기준이 세 개일 때

기준이 하나 더 늘면 색만으로는 부족합니다. `sns.catplot(..., col=)`은 세 번째 기준의 값마다 **칸을 나눠** 같은 그래프를 나란히 그립니다. 등급별 생존율을 승선 항구별 칸으로 나눠 봅니다.

```run
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("titanic.csv")
g = sns.catplot(data=df, x="class", y="survived", col="embark_town", kind="bar", errorbar=None,
                order=["First", "Second", "Third"], height=2.8)
print(pd.crosstab(df["embark_town"], df["class"]))
```

**이렇게 읽는다**: 칸끼리 y축을 공유하므로 칸을 가로질러 같은 막대 높이를 비교할 수 있습니다. 먼저 **모든 칸에 공통인 패턴**을 찾고, 그다음 **한 칸만 다른 곳**을 찾습니다.

> 해석: 세 항구 모두 대체로 등급이 낮을수록 생존율이 낮다. 다만 Queenstown 칸은 2등실이 1등실보다 높아 보이는데, 아래 표를 보면 Queenstown의 1등실은 2명, 2등실은 3명뿐이다. 이 칸의 1·2등실 막대는 사람 몇 명으로 정해진 값이라 해석하면 안 된다.

**잘못 읽기 쉬운 점**: 칸을 나눌수록 칸마다 데이터가 줄어듭니다. **이상해 보이는 칸이 있으면 먼저 그 칸의 데이터 개수를 확인**하세요(`pd.crosstab`). 대부분은 데이터가 너무 적어서 생긴 착시입니다.
