필터로 행을 고른 다음에는 대개 **무언가를 고치거나 새 열을 붙입니다**. "규격 밖인 행에 NG 표시", "출력 구간에 따라 LOW · MID · HIGH 라벨" 같은 일입니다. 이 레슨에서는 필터 결과를 안전하게 고치는 법, 조건에 따라 라벨 열을 만드는 법, 그리고 여러 단계로 된 질문을 나눠 푸는 법을 다룹니다.

## 필터 결과에 바로 대입하면 원본이 바뀌지 않습니다

다음 코드는 "수량 500 미만인 행의 status를 LOW로" 바꾸려는 의도입니다. 하지만 원본 `df`는 바뀌지 않습니다.

```python
df[df['qty'] < 500]['status'] = 'LOW'     # 원본은 그대로
```

`df[조건]`이 먼저 **새 표**를 만들고, 그 새 표의 열에 대입했기 때문입니다. pandas 버전에 따라 `SettingWithCopyWarning`이나 `ChainedAssignmentError` 경고가 나오기도 하고, 아무 말 없이 무시되기도 합니다. 어느 쪽이든 원본은 바뀌지 않습니다.

원본을 고치려면 [원하는 행과 열만 골라내기](#/l/da-04-1)에서 본 것처럼 `loc[조건, 열]`로 **한 번에** 지정합니다.

```run
import pandas as pd

df = pd.DataFrame({'lot': ['L01', 'L02', 'L03', 'L04'], 'qty': [520, 480, 610, 455]})
df['status'] = 'OK'
df.loc[df['qty'] < 500, 'status'] = 'LOW'
print(df)
```

## 고른 행만 따로 고쳐 쓰려면 copy

반대로 원본은 두고 **고른 행만 따로** 고쳐 쓰고 싶을 때가 있습니다. 이때는 필터 결과에 `.copy()`를 붙여 별도의 표로 만듭니다.

```run
import pandas as pd

df = pd.DataFrame({'lot': ['L01', 'L02', 'L03', 'L04'], 'qty': [520, 480, 610, 455]})
low = df[df['qty'] < 500].copy()       # 따로 떨어진 표
low['action'] = 'recheck'
print(low)
print(df.columns.tolist())             # 원본에는 action 열이 없다
```

| 하고 싶은 일 | 코드 |
| --- | --- |
| 원본의 일부 행을 고치기 | `df.loc[조건, '열'] = 값` |
| 고른 행으로 새 표를 만들어 고치기 | `sub = df[조건].copy()` 후 `sub['열'] = 값` |

[배열 모양 바꾸기](#/l/da-02-3)의 "뷰와 복사본", [참조와 복사: 이름표 두 개, 상자 하나](#/l/pb-04-3)의 "이름표와 상자"와 같은 이야기입니다. 무엇을 고치려는지 먼저 정하고 둘 중 하나를 고릅니다.

## 두 갈래 라벨: np.where

[조건으로 바꾸고 세기](#/l/da-01-3)의 `np.where`는 pandas 열에도 그대로 씁니다. 조건이 True면 앞 값, False면 뒤 값입니다.

```run
import numpy as np
import pandas as pd

df = pd.DataFrame({'lot': ['L01', 'L02', 'L03', 'L04'], 'size': [10.1, 9.2, 10.4, 10.8]})
df['judge'] = np.where(df['size'].between(9.5, 10.5), 'OK', 'NG')
print(df)
```

`loc`로 두 번 대입하는 것보다 한 줄로 끝나고, 모든 행에 반드시 값이 들어갑니다.

## 세 갈래 이상: np.select

갈래가 셋 이상이면 `np.select(조건 리스트, 값 리스트, default=나머지 값)`를 씁니다. **위에서부터 차례로** 조건을 보고 처음 True인 값을 고릅니다. 엑셀의 `IFS` 함수와 같습니다.

```run
import numpy as np
import pandas as pd

df = pd.read_csv("tips.csv")
df['tip_pct'] = df['tip'] / df['total_bill'] * 100

conds = [df['tip_pct'] >= 20, df['tip_pct'] >= 15]
labels = ['HIGH', 'MID']
df['grade'] = np.select(conds, labels, default='LOW')
print(df['grade'].value_counts())
```

팁 비율 20% 이상은 HIGH(39건), 15~20%는 MID(97건), 나머지는 LOW(108건)입니다. 두 번째 조건에 `< 20`을 쓰지 않아도 되는 이유는, 20 이상인 행이 이미 첫 조건에서 HIGH로 정해졌기 때문입니다. 그래서 **조건 순서가 중요**합니다. 순서를 바꾸면 20% 이상도 모두 MID가 됩니다.

설비 데이터에서도 써 봅니다. 출력(W)은 토크 × 회전 속도로 계산합니다. 이 데이터는 출력이 3,500W 미만이거나 9,000W를 넘으면 고장으로 기록되도록 만들어졌습니다.

```run
import numpy as np
import pandas as pd

df = pd.read_csv("ai4i2020.csv")
df['power'] = df['torque'] * df['rpm'] * 2 * np.pi / 60

conds = [df['power'] < 3500, df['power'] > 9000]
df['band'] = np.select(conds, ['LOW', 'HIGH'], default='MID')
print(df.groupby('band')['failure'].agg(['size', 'mean']).round(3))
```

LOW 31건과 HIGH 64건은 고장률이 100%이고, 나머지 9,905건(MID)은 2.5%입니다. 라벨 열을 만들고 나면 [groupby와 pivot_table](#/l/da-06-1)에서 배울 `groupby`로 라벨별 비교가 바로 됩니다.

## 여러 단계 질문은 나눠 풉니다

"L 등급 설비 중 공구 마모가 상위 10%인 운전의 고장률은, L 등급 전체와 비교해 몇 배인가?" 같은 질문을 한 줄로 쓰려고 하면 괄호가 엉킵니다. 질문을 단계로 쪼개고, 단계마다 이름 붙인 변수에 담습니다.

```run
import pandas as pd

df = pd.read_csv("ai4i2020.csv")

low_type = df[df['type'] == 'L']                     # 1단계: L 등급만
cut = low_type['tool_wear'].quantile(0.9)            # 2단계: 상위 10% 경계
worn = low_type[low_type['tool_wear'] >= cut]        # 3단계: 경계 이상만

r_worn = worn['failure'].mean() * 100                # 4단계: 비교
r_all = low_type['failure'].mean() * 100
print(len(low_type), cut, len(worn))
print(round(r_worn, 2), round(r_all, 2), round(r_worn / r_all, 1), "배")
```

L 등급 6,000건 중 공구 마모 196분 이상인 614건의 고장률은 15.64%로, L 등급 전체 3.92%의 약 4배입니다. 단계마다 `len`을 찍어 두면 어느 단계에서 행이 예상과 다르게 줄었는지 바로 찾을 수 있습니다.

> `quantile(0.9)`는 "아래에서 90% 지점의 값"입니다. 이 값 이상이면 상위 10%입니다. 같은 값이 많으면 상위 10%보다 조금 많이 잡힐 수 있어서 600건이 아니라 614건이 됐습니다.

## 정리

- 원본을 고치려면 `df.loc[조건, '열'] = 값`, 따로 고쳐 쓰려면 `df[조건].copy()`
- 두 갈래 라벨은 `np.where`, 세 갈래 이상은 `np.select`(위 조건부터 적용)
- 여러 단계 질문은 단계마다 변수에 담고 `len`으로 확인합니다
