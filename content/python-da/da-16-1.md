## 전체 중 얼마인가: 구성

"승객 중 3등실이 몇 %인가", "매출 중 주말 비중은?"처럼 **전체를 100%로 놓고 각 부분이 얼마를 차지하나**를 묻는 질문을 **구성(비율)** 질문이라고 합니다. 구성 PART에서는 구성을 보여 주는 그래프를 차트 하나씩 읽습니다.

| 그래프 | 언제 |
| --- | --- |
| 파이 · 도넛 | 부분이 2~5개, 한 번에 하나의 전체 |
| 누적 막대 · 100% 막대 | 여러 그룹의 구성을 비교 ([누적 막대와 100% 막대 읽기](#/l/da-16-2)) |
| 누적 영역 | 구성이 시간에 따라 어떻게 변하나 ([시간에 따른 구성: 누적 영역](#/l/da-16-3)) |

## 파이 그래프가 나타내는 것

타이타닉 승객의 객실 등급 구성을 파이로 그립니다. `autopct="%.1f%%"`는 조각마다 소수 첫째 자리까지 %를 적고, `startangle=90, counterclock=False`는 12시 방향에서 시계 방향으로 조각을 놓습니다(시계 읽듯 읽기 쉽게).

```run
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("titanic.csv")
share = df["class"].value_counts()
fig, ax = plt.subplots(figsize=(4, 4))
ax.pie(share.values, labels=share.index, autopct="%.1f%%", startangle=90, counterclock=False)
print(share.to_dict())
print((share / share.sum() * 100).round(1).to_dict())
```

**무엇을 나타내나**

- 원 전체 = 100% (여기서는 승객 891명)
- 조각의 **각도(넓이)** = 그 부분의 비율. 원 한 바퀴 360°에서 1%는 3.6°입니다.

**이렇게 읽는다**: 파이는 정확한 숫자보다 **기준선과 비교**해서 읽습니다.

| 조각 크기 | 읽는 법 |
| --- | --- |
| 원의 절반을 넘는다 | "과반이다" |
| 4분의 1(직각) 정도 | "약 4분의 1" |
| 다른 조각들의 합보다 크다 | "나머지를 합친 것보다 많다" |

> 해석: 3등실이 55.1%로 승객의 절반을 넘고, 1등실(24.2%)과 2등실(20.7%)은 각각 약 4분의 1과 5분의 1이다. 3등실 한 등급이 나머지 두 등급을 합친 것보다 많다.

## 비슷한 조각은 파이로 비교할 수 없다

식당 계산서의 요일 비율은 토 35.7%, 일 31.1%, 목 25.4%로 비슷비슷합니다. 숫자를 지운 파이와 정렬한 막대를 나란히 놓고, 어느 쪽이 순서를 바로 알 수 있는지 비교해 봅니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("tips.csv")
share = df["day"].value_counts(normalize=True).sort_values() * 100
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(9, 3.5))
ax1.pie(share.values, labels=share.index, startangle=90, counterclock=False)
ax1.set_title("pie (no numbers)")
ax2.barh(share.index, share.values)
ax2.set_title("sorted bar (%)")
print(share.round(1).to_dict())
```

> 해석: 파이에서는 토요일과 일요일 조각 중 어느 쪽이 큰지 바로 말하기 어렵지만, 막대에서는 토 35.7% > 일 31.1% > 목 25.4% > 금 7.8% 순서가 한눈에 보인다.

사람 눈은 **길이**는 정확하게 비교하지만 **각도와 넓이**는 잘 비교하지 못합니다. 그래서 파이는 "한 조각이 압도적이다", "절반을 넘는다"처럼 **큰 차이를 말할 때만** 씁니다. 비슷한 값들의 순서를 말해야 하면 정렬한 막대로 바꿉니다.

## 100%는 무엇의 100%인가

타이타닉의 `deck`(객실이 있던 갑판) 열을 파이로 그려 봅니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("titanic.csv")
deck = df["deck"].value_counts().sort_index()
fig, ax = plt.subplots(figsize=(4, 4))
ax.pie(deck.values, labels=deck.index, autopct="%.0f%%", startangle=90, counterclock=False)
print("갑판을 아는 승객:", int(deck.sum()), "/ 전체:", len(df))
print("갑판 정보 없음:", int(df["deck"].isna().sum()))
```

> 해석: 파이만 보면 C 갑판이 29%로 가장 많지만, 이 파이의 100%는 갑판을 아는 승객 203명뿐이다. 전체 891명 중 688명(77%)은 갑판 정보가 없다. 갑판 정보는 주로 1등실 승객에게만 남아 있어서, 이 파이를 "전체 승객의 갑판 분포"로 읽으면 크게 틀린다.

**잘못 읽기 쉬운 점**: 파이는 무엇을 넣든 항상 꽉 찬 원(100%)으로 그려집니다. 그래서 **빠진 값이 있어도 그림에서는 티가 나지 않습니다.** 파이를 볼 때는 "전체(분모)가 몇 명인가"를 제목이나 설명에서 꼭 확인하고, 그릴 때는 제목에 n을 적어 둡니다. 또 조각이 7개처럼 많으면 작은 조각들(G 2%)은 글자가 겹쳐 읽기 어렵습니다. 조각이 5개를 넘으면 작은 것들을 "기타"로 묶거나 막대를 씁니다.

## 도넛: 가운데에 합계를

파이의 가운데를 비우면 **도넛**이 됩니다. `wedgeprops={"width": 0.4}`는 고리 두께를 반지름의 40%로 만듭니다. 빈 가운데에 전체 개수를 적어 "무엇의 100%인지"를 함께 보여 줄 수 있습니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("titanic.csv")
share = df["embark_town"].value_counts()
fig, ax = plt.subplots(figsize=(4, 4))
ax.pie(share.values, labels=share.index, autopct="%.0f%%", startangle=90, counterclock=False, wedgeprops={"width": 0.4}, pctdistance=0.8)
ax.text(0, 0, f"n={share.sum()}", ha="center", va="center", fontsize=14)
print((share / share.sum() * 100).round(1).to_dict())
```

> 해석: 탑승 항구가 기록된 889명 중 72%가 Southampton에서 탔고, Cherbourg 19%, Queenstown 9% 순이다. 한 항구가 4분의 3 가까이를 차지한다.

도넛은 읽는 법이 파이와 같습니다. 가운데에 합계를 쓰는 것 말고는 정보가 더 늘지 않으니, 둘 중 편한 것을 씁니다.

## 파이 여러 개를 나란히 놓지 않기

등급별로 남자·여자·아이 구성이 어떻게 다른지 보려고 파이를 3개 그리면, 조각이 같은 자리에 있지 않아 비교가 아주 어렵습니다. **여러 그룹의 구성을 비교**할 때는 다음 레슨의 **100% 누적 막대**를 씁니다.

## 정리: 파이 · 도넛 읽기

| 단계 | 볼 것 | 해석 문장 틀 |
| --- | --- | --- |
| 1. 분모 | 원 전체가 무엇인가 (n, 빠진 값) | "~명 중" |
| 2. 가장 큰 조각 | 절반을 넘나, 4분의 1인가 | "~이 과반(55%)을 차지한다" |
| 3. 나머지 | 큰 차이만 말하기 | "나머지를 합친 것보다 많다" |
| 확인 | 조각 5개 이하인가, 비슷한 조각을 비교하려는 건 아닌가 | 아니면 막대로 |

| 그래프 | 코드 |
| --- | --- |
| 파이 | `ax.pie(값, labels=, autopct="%.1f%%", startangle=90, counterclock=False)` |
| 도넛 | `ax.pie(..., wedgeprops={"width": 0.4})` + `ax.text(0, 0, "n=...")` |
