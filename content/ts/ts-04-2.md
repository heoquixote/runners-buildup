## 시작하기 전에

[정상성: 성질이 변하지 않는 시계열](#/l/ts-04-1)에서 항공 승객 데이터는 평균도 흔들림도 변해서 정상이 아니라는 것을 확인했습니다. 이번 레슨에서는 이런 시계열을 **정상으로 바꾸는 도구 세 가지**를 배웁니다. 로그, 차분, 계절 차분입니다.

## 키 대신 "자란 양"을 보기

아이의 키는 해마다 커지니 평균이 일정하지 않습니다. 그런데 **1년 동안 자란 양**은 어떨까요? 매년 5 ~ 6cm로 비슷합니다. 값 자체는 추세가 있어도 **변화량**은 일정한 경우가 많습니다.

**차분(differencing)** 은 바로 이 변화량을 구하는 일입니다. 오늘 값에서 어제 값을 뺍니다. [시간 순서가 있는 데이터 다루기](#/l/da-08-1)에서 배운 `diff()`가 차분입니다.

| 도구 | 하는 일 | 없애는 것 | pandas |
| --- | --- | --- | --- |
| 로그 | 큰 값일수록 더 많이 눌러 준다 | 수준과 함께 커지는 흔들림 | `np.log(y)` |
| 1차 차분 | 바로 앞 값과의 차이 | 추세 | `y.diff()` |
| 계절 차분 | 한 주기 전 값과의 차이 | 계절성 (추세도 함께 줄어듦) | `y.diff(12)` |

## 한 단계씩 적용해 보기

항공 승객 데이터에 변환을 하나씩 더해 가며 그래프를 그리고, 앞 절반과 뒤 절반의 평균 · 표준편차를 비교합니다.

```run
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd

df = pd.read_csv("flights.csv")
df["date"] = pd.to_datetime(df["year"].astype(str) + "-" + df["month"], format="%Y-%B")
y = df.set_index("date")["passengers"].asfreq("MS")
steps = {
    "original": y,
    "log": np.log(y),
    "log + diff(1)": np.log(y).diff(),
    "log + diff(12)": np.log(y).diff(12),
    "log + diff(12) + diff(1)": np.log(y).diff(12).diff(),
}
fig, axes = plt.subplots(len(steps), 1, figsize=(9, 9), sharex=True)
for ax, (name, s) in zip(axes, steps.items()):
    ax.plot(s.index, s.values)
    ax.set_title(name, fontsize=10)
    s = s.dropna()
    half = len(s) // 2
    print(f"{name:>25}: mean {s.iloc[:half].mean():8.3f} -> {s.iloc[half:].mean():8.3f} | std {s.iloc[:half].std():7.3f} -> {s.iloc[half:].std():7.3f}")
fig.tight_layout()
```

::figure{src="content/img/ts/ts04-diff-steps.svg" alt="올라가면서 물결이 커지는 선에 로그를 씌우면 물결 높이가 일정해지고, 계절 차분을 하면 물결이 사라지고, 1차 차분까지 하면 0 주변에서 고르게 떨리는 선이 된다" caption="로그로 흔들림을 고르게 하고, 차분으로 계절성과 추세를 차례로 없앱니다."}

한 줄씩 읽어 봅니다.

- **original**: 평균 182.9 → 377.7, 표준편차 47.7 → 86.4. 둘 다 변합니다.
- **log**: 표준편차가 0.263 → 0.224로 비슷해졌습니다. 흔들림은 고르게 됐지만 평균은 5.175 → 5.909로 여전히 오릅니다.
- **log + diff(1)**: 평균이 0.010 → 0.009로 일정해졌습니다. 추세가 사라졌습니다. 하지만 그래프에는 1년 주기의 물결이 그대로 남아 있습니다.
- **log + diff(12)**: 계절 물결이 사라졌습니다. 평균은 0.130 → 0.110으로 조금 내려갑니다.
- **log + diff(12) + diff(1)**: 평균이 0.002 → −0.002로 0 근처에서 일정합니다.

## 변환한 값은 무슨 뜻일까

변환을 여러 번 하면 숫자가 무엇을 뜻하는지 놓치기 쉽습니다. 1960년 5 ~ 9월을 놓고 확인합니다.

```run
import numpy as np
import pandas as pd

df = pd.read_csv("flights.csv")
df["date"] = pd.to_datetime(df["year"].astype(str) + "-" + df["month"], format="%Y-%B")
y = df.set_index("date")["passengers"].asfreq("MS")
view = pd.DataFrame({"passengers": y, "diff1": y.diff(), "log_diff1": np.log(y).diff().round(3), "pct": y.pct_change().round(3), "log_diff12": np.log(y).diff(12).round(3)})
print(view["1960-05":"1960-09"])
```

- `diff1`: 지난달보다 몇 천 명 늘었나. 7월은 +87.
- `log_diff1`: 로그를 씌운 뒤의 차이. 7월은 0.151입니다. 옆의 `pct`(지난달 대비 증가율 0.163 = 16.3%)와 비슷합니다. **로그 차분은 대략 증가율**입니다. 변화가 작을수록 두 값이 더 가깝습니다(5월 0.024와 0.024).
- `log_diff12`: 작년 같은 달과 비교한 로그 차이. 7월은 0.127로, 작년 7월보다 약 13% 늘었다는 뜻입니다. 뉴스에서 말하는 "전년 동월 대비 증가율"이 계절 차분입니다.

## 자기상관으로 확인하기

변환이 잘 됐는지는 ACF로도 확인합니다. [어제가 오늘을 말해 준다: 자기상관과 ACF](#/l/ts-03-1)에서 ACF가 천천히 줄면 추세, 주기마다 솟으면 계절성이라고 배웠습니다.

```run
import numpy as np
import pandas as pd
from statsmodels.tsa.stattools import acf

df = pd.read_csv("flights.csv")
df["date"] = pd.to_datetime(df["year"].astype(str) + "-" + df["month"], format="%Y-%B")
y = df.set_index("date")["passengers"].asfreq("MS")
log_y = np.log(y)
for name, s in [("log", log_y), ("log + diff(1)", log_y.diff()), ("log + diff(12) + diff(1)", log_y.diff(12).diff())]:
    a = acf(s.dropna(), nlags=24)
    print(f"{name:>25}: lag 1 {a[1]:5.2f}, lag 2 {a[2]:5.2f}, lag 12 {a[12]:5.2f}, lag 24 {a[24]:5.2f}")
```

- **log**: 래그 1이 0.95, 래그 2가 0.90으로 천천히 줄어듭니다. 추세가 남아 있습니다.
- **log + diff(1)**: 래그 1은 0.20으로 뚝 떨어졌지만 래그 12가 0.84, 래그 24가 0.74입니다. 추세는 사라지고 **계절성만 선명하게** 남았습니다.
- **log + diff(12) + diff(1)**: 래그 24가 −0.02로 사라졌습니다. 래그 1(−0.34)과 래그 12(−0.39)에 음의 자기상관이 조금 남았는데, 이 정도는 뒤에서 ARIMA 모델이 처리합니다.

## 직접 해보기: 이산화탄소 농도

이산화탄소 농도의 월 평균에 같은 순서를 적용합니다. 이 데이터는 계절 폭이 커지지 않으므로 로그 없이 차분만 합니다.

```run
import pandas as pd

co2 = pd.read_csv("co2.csv", parse_dates=["date"]).set_index("date")["co2"]
co2m = co2.resample("MS").mean().interpolate()
print("rows:", len(co2m))
once = co2m.diff(12).dropna()
print("yearly change: 1960s mean", round(once["1960":"1969"].mean(), 2), "/ 1990s mean", round(once["1990":"1999"].mean(), 2))
twice = once.diff().dropna()
print("after one more diff: 1960s mean", round(twice["1960":"1969"].mean(), 3), "/ 1990s mean", round(twice["1990":"1999"].mean(), 3))
```

계절 차분(`diff(12)`)의 결과는 "1년 전보다 몇 ppm 늘었나"입니다. 1960년대에는 해마다 평균 0.86ppm씩, 1990년대에는 1.54ppm씩 늘었습니다. **늘어나는 속도 자체가 빨라졌으니** 계절 차분만으로는 평균이 일정하지 않습니다. 한 번 더 차분하면 0.003, −0.001로 0 근처에서 일정해집니다.

아래 셀에서 `diff(12)`를 `diff(1)`로 바꿔 실행해 보세요. 계절성이 남아 있어서 월마다 값이 크게 다릅니다.

## 차분은 필요한 만큼만

차분을 많이 할수록 좋은 것은 아닙니다. 이미 정상인 백색잡음을 한 번 더 차분해 봅니다.

```run
import numpy as np
import pandas as pd
from statsmodels.tsa.stattools import acf

rng = np.random.default_rng(3)
white = pd.Series(rng.normal(size=500))
over = white.diff().dropna()
print("std :", round(white.std(), 2), "->", round(over.std(), 2))
print("ACF lag 1:", round(acf(white, nlags=1)[1], 2), "->", round(acf(over, nlags=1)[1], 2))
```

표준편차가 1.0에서 1.43으로 **오히려 커졌고**, 없던 자기상관이 래그 1에 −0.52로 생겼습니다. 필요 없는 차분은 잡음을 키우고 가짜 패턴을 만듭니다. 이것을 **과차분**이라고 합니다. 차분한 뒤 래그 1 자기상관이 −0.5 근처로 크게 음수가 되면 과차분을 의심합니다.

실무에서는 대부분 1차 차분 한 번, 계절 차분 한 번이면 충분합니다.

## 되돌리는 법

변환한 값으로 예측했다면 원래 단위로 되돌려야 합니다. 되돌릴 때는 **거꾸로 순서**로 합니다.

- 차분의 반대는 누적 합(`cumsum`)입니다. 마지막으로 알고 있는 값에 예측한 변화량을 차례로 더합니다.
- 로그의 반대는 지수(`np.exp`)입니다.

statsmodels의 ARIMA 모델은 차분과 되돌리기를 알아서 해 주므로, 직접 할 일은 보통 로그와 `exp`뿐입니다.

## 정리

- 로그는 수준과 함께 커지는 흔들림을, 1차 차분은 추세를, 계절 차분은 계절성을 없앱니다.
- 순서는 로그 → 계절 차분 → (필요하면) 1차 차분입니다.
- 로그 차분은 대략 증가율이고, 계절 차분은 전년 같은 시기 대비 변화입니다.
- 필요 없는 차분은 잡음을 키우고 가짜 자기상관을 만듭니다.
