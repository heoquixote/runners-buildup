## 시작하기 전에

[기준 예측 네 가지](#/l/ts-05-1)에서는 예측 오차를 MAE 하나로 쟀습니다. [오차 재기: MAE · RMSE · R²](#/l/ml-02-2)에서 배운 MAE와 RMSE는 시계열에서도 그대로 씁니다.

이번 레슨에서는 예측에서 특히 자주 쓰는 지표 두 가지를 더 배웁니다. 퍼센트로 말하는 **MAPE**와, 기준 예측과 비교해서 말하는 **MASE**입니다. 그리고 MAPE가 엉뚱한 답을 내는 상황도 확인합니다.

## 네 가지 지표

| 지표 | 계산 | 단위 | 한마디로 |
| --- | --- | --- | --- |
| MAE | 오차 절댓값의 평균 | 원래 단위 | 평균 몇 명 틀렸나 |
| RMSE | 오차 제곱 평균의 제곱근 | 원래 단위 | 크게 틀린 것에 벌점을 더 준다 |
| MAPE | (오차 절댓값 ÷ 실제값)의 평균 × 100 | % | 평균 몇 % 틀렸나 |
| MASE | 내 MAE ÷ naive의 MAE | 배 | naive보다 몇 배 틀렸나 |

MAE와 RMSE를 간단히 복습하면, 둘 다 원래 단위(천 명)로 나오고, RMSE는 오차를 제곱하므로 한두 번 크게 틀리면 MAE보다 훨씬 커집니다.

## MAPE: 퍼센트로 말하기

"MAE가 71.2입니다"라고 하면 듣는 사람은 그것이 큰지 작은지 알 수 없습니다. "평균 15% 틀립니다"라고 하면 바로 이해합니다. MAPE는 **보고할 때 가장 설명하기 쉬운** 지표입니다.

세 가지 지표를 함수로 만들어 기준 예측에 적용합니다.

```run
import numpy as np
import pandas as pd

df = pd.read_csv("flights.csv")
df["date"] = pd.to_datetime(df["year"].astype(str) + "-" + df["month"], format="%Y-%B")
y = df.set_index("date")["passengers"].asfreq("MS")
train, test = y.iloc[:-24], y.iloc[-24:]
h = len(test)
naive = pd.Series(train.iloc[-1], index=test.index)
mean_fc = pd.Series(train.mean(), index=test.index)
snaive = pd.Series(np.tile(train.iloc[-12:].values, 2), index=test.index)
slope = (train.iloc[-1] - train.iloc[0]) / (len(train) - 1)
drift = pd.Series(train.iloc[-1] + slope * np.arange(1, h + 1), index=test.index)
def mae(actual, pred):
    return np.mean(np.abs(actual - pred))
def rmse(actual, pred):
    return np.sqrt(np.mean((actual - pred) ** 2))
def mape(actual, pred):
    return np.mean(np.abs((actual - pred) / actual)) * 100
for name, fc in [("naive", naive), ("seasonal naive", snaive), ("drift", drift)]:
    print(f"{name:>14}: MAE {mae(test, fc):5.1f} | RMSE {rmse(test, fc):5.1f} | MAPE {mape(test, fc):4.1f}%")
```

seasonal naive는 MAE 71.2, RMSE 77.0, MAPE **15.5%** 입니다. naive는 RMSE(137.3)가 MAE(115.2)보다 꽤 큽니다. 여름철에 특히 크게 틀리기 때문입니다.

MAPE가 어떻게 계산되는지 몇 달만 골라 봅니다.

```run
import numpy as np
import pandas as pd

df = pd.read_csv("flights.csv")
df["date"] = pd.to_datetime(df["year"].astype(str) + "-" + df["month"], format="%Y-%B")
y = df.set_index("date")["passengers"].asfreq("MS")
train, test = y.iloc[:-24], y.iloc[-24:]
h = len(test)
naive = pd.Series(train.iloc[-1], index=test.index)
mean_fc = pd.Series(train.mean(), index=test.index)
snaive = pd.Series(np.tile(train.iloc[-12:].values, 2), index=test.index)
slope = (train.iloc[-1] - train.iloc[0]) / (len(train) - 1)
drift = pd.Series(train.iloc[-1] + slope * np.arange(1, h + 1), index=test.index)
view = pd.DataFrame({"actual": test, "pred": snaive})
view["error"] = view["actual"] - view["pred"]
view["ape_%"] = (view["error"].abs() / view["actual"] * 100).round(1)
print(view.iloc[[0, 6, 12, 18]])
```

1959년 1월은 실제 360, 예측 340으로 20 차이, 20 ÷ 360 = 5.6%입니다. 1960년 7월은 131 차이로 21.1%입니다. 이런 퍼센트 오차를 24개월 평균 낸 것이 MAPE 15.5%입니다. 예측 시점에서 멀어질수록 오차가 커지는 것도 보입니다.

## MAPE의 함정 1: 실제값이 0이면

MAPE는 오차를 **실제값으로 나눕니다.** 실제값이 0이면 나눌 수 없습니다. 운영하지 않은 날이 0으로 적힌 따릉이 데이터로 확인합니다. 9월 10일부터 4주간을, 그 전 주의 평균으로 예측했다고 해 봅니다.

```run
import numpy as np
import pandas as pd

bike = pd.read_csv("seoul_bike.csv", parse_dates=["date"])
daily = bike.groupby("date")["rented_bikes"].sum().asfreq("D")
part = daily["2018-09-10":"2018-10-07"]
pred = pd.Series(daily["2018-09-03":"2018-09-09"].mean(), index=part.index)
ape = (part - pred).abs() / part * 100
print("zero days:", (part == 0).sum())
print("MAPE:", ape.mean())
print("MAPE without zero days:", round(ape[part > 0].mean(), 1))
print("MAE :", round((part - pred).abs().mean()))
```

이 구간에 대여 수가 0인 날이 6일 있고, MAPE가 **`inf`(무한대)** 로 나옵니다. 0으로 나눈 결과입니다. 0인 날을 빼고 계산해도 46.4%인데, 이것은 "문제가 되는 날을 빼고 잰" 값이라 공정하지 않습니다. MAE는 10,278로 문제없이 계산됩니다.

## MAPE의 함정 2: 값이 작으면 부풀려진다

0이 아니더라도 실제값이 작으면 퍼센트 오차가 크게 부풀려집니다. 다섯 번 모두 **똑같이 2만큼** 틀린 예측을 봅니다.

```run
import numpy as np

actual = np.array([2, 4, 1, 100, 120])
pred = np.array([4, 2, 3, 98, 122])
ape = np.abs(actual - pred) / actual * 100
print("abs error:", np.abs(actual - pred).tolist())
print("APE (%)  :", ape.round(1).tolist())
print("MAE:", np.abs(actual - pred).mean(), "/ MAPE:", round(ape.mean(), 1))
```

절대 오차는 모두 2입니다. 그런데 실제값이 1일 때는 200%, 100일 때는 2%입니다. 평균하면 MAPE가 70.7%나 됩니다. 값이 작은 구간 몇 개가 지표 전체를 좌우합니다.

하루 판매량이 0 ~ 5개인 상품, 불량 건수처럼 **작은 숫자나 0이 자주 나오는 데이터에는 MAPE를 쓰지 않습니다.**

## MASE: 기준 예측과 비교해서 말하기

MASE는 내 예측의 MAE를 **"학습 구간에서 naive로 한 칸 앞을 예측했을 때의 MAE"** 로 나눕니다.

- MASE < 1: naive의 한 칸 예측보다 잘한다.
- MASE = 1: 비슷하다.
- MASE > 1: 그보다 못하다.

나누는 값이 실제값이 아니라 **학습 구간 전체의 평균 변화량**이므로, 실제값에 0이 섞여 있어도 계산됩니다. 계절성이 있는 데이터는 나누는 기준을 seasonal naive(`m=12`)로 잡기도 합니다.

```run
import numpy as np
import pandas as pd

df = pd.read_csv("flights.csv")
df["date"] = pd.to_datetime(df["year"].astype(str) + "-" + df["month"], format="%Y-%B")
y = df.set_index("date")["passengers"].asfreq("MS")
train, test = y.iloc[:-24], y.iloc[-24:]
h = len(test)
naive = pd.Series(train.iloc[-1], index=test.index)
mean_fc = pd.Series(train.mean(), index=test.index)
snaive = pd.Series(np.tile(train.iloc[-12:].values, 2), index=test.index)
slope = (train.iloc[-1] - train.iloc[0]) / (len(train) - 1)
drift = pd.Series(train.iloc[-1] + slope * np.arange(1, h + 1), index=test.index)
def mase(actual, pred, train, m=1):
    scale = np.mean(np.abs(train.values[m:] - train.values[:-m]))
    return np.mean(np.abs(actual - pred)) / scale
print("naive one-step MAE on train  :", round(np.mean(np.abs(train.diff().dropna())), 2))
print("seasonal one-step MAE on train:", round(np.mean(np.abs(train.diff(12).dropna())), 2))
for name, fc in [("naive", naive), ("seasonal naive", snaive), ("drift", drift)]:
    print(f"{name:>14}: MASE(m=1) {mase(test, fc, train):.2f} | MASE(m=12) {mase(test, fc, train, 12):.2f}")
```

학습 구간에서 "다음 달 = 이번 달"로 예측하면 평균 22.16, "다음 달 = 작년 같은 달"로 예측하면 평균 28.57 틀립니다. 이것이 나누는 기준입니다.

seasonal naive의 MASE는 3.22(m=1 기준)입니다. 1보다 큰데, 이것은 이상한 일이 아닙니다. 기준은 **한 칸 앞** 예측 오차이고, 우리는 **1 ~ 24칸 앞**을 예측했기 때문입니다. 먼 미래일수록 오차가 큰 것은 당연합니다. MASE는 값 하나만 보기보다 **모델끼리 비교**할 때 씁니다. 나중에 만들 모델의 MASE가 3.22보다 작으면 seasonal naive보다 나은 것입니다.

## 어떤 지표를 쓸까

| 상황 | 지표 | 이유 |
| --- | --- | --- |
| 값이 늘 0보다 충분히 크고, 다른 사람에게 설명해야 한다 | MAPE | 퍼센트라 이해하기 쉽다 |
| 0이나 작은 값이 섞여 있다 | MAE, MASE | 나눗셈 문제가 없다 |
| 크게 틀리는 것이 특히 위험하다 (재고 부족, 정전) | RMSE | 큰 오차에 벌점이 크다 |
| 단위가 다른 여러 시계열을 비교한다 (A 상품은 만 개, B 상품은 열 개) | MASE | 단위가 사라진다 |

실무에서는 지표 하나만 보지 않고 MAE와 MAPE(또는 MASE)를 함께 보고합니다. 이 트랙에서는 항공 승객은 MAPE, 따릉이와 설비 온도는 MAE를 주로 쓰겠습니다.

## 정리

- MAPE는 평균 몇 %를 틀렸는지로, 설명하기 쉽습니다.
- 실제값이 0이면 MAPE는 무한대가 되고, 값이 작으면 크게 부풀려집니다.
- MASE는 naive의 한 칸 예측 오차와 비교한 배율이며, 0이 있어도 계산됩니다.
- 항공 승객 24개월 예측에서 seasonal naive의 MAPE는 15.5%입니다. 앞으로 만들 모델이 넘어야 할 숫자입니다.
