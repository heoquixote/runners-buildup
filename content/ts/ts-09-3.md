## 시작하기 전에

지금까지 찾은 이상은 값이 크게 튀는 순간이었습니다. 그런데 설비 고장은 대개 갑자기 오지 않습니다. 부품이 닳으면서 온도가 **평소보다 조금 낮은 상태**가 며칠 이어지다가 어느 날 멈춥니다.

하루하루의 값은 모두 정상 범위 안에 있어서 한계선에는 걸리지 않습니다. 하지만 "평소보다 조금 낮은 날"이 계속된다는 것 자체가 신호입니다. [이상의 세 종류와 이동 z-점수](#/l/ts-09-1)에서 말한 **집단 이상**이고, 평균 수준이 바뀐 그 시점을 **변화점(change point)** 이라고 합니다. 이번 레슨에서는 변화점을 잡는 가장 오래되고 간단한 도구인 **CUSUM**을 배웁니다.

## 조금씩 새는 통장

통장에서 매달 몇천 원씩 알 수 없는 돈이 빠져나간다고 해 봅시다. 한 달 치 내역만 보면 눈에 띄지 않습니다. 그런데 **빠져나간 돈을 계속 더해 보면** 1년 뒤에는 꽤 큰 금액이 되어 있습니다.

CUSUM(cumulative sum, 누적 합)은 바로 이 생각입니다. 값이 기준에서 벗어난 양을 **계속 더해 갑니다.**

**CUSUM = max(0, 이전 CUSUM + (값 − 기준 − k))**

- **기준**: 평소의 평균입니다.
- **k (허용폭)**: 이 정도 벗어나는 것은 평소의 흔들림으로 보고 눈감아 주는 양입니다.
- **max(0, …)**: 누적이 0 아래로 내려가면 0으로 되돌립니다. 평소에는 0 근처에 머물게 하는 장치입니다.
- CUSUM이 **한계값**을 넘으면 경보를 울립니다.

값이 평소 수준이면 (값 − 기준 − k)가 대부분 음수라서 CUSUM은 0에 붙어 있습니다. 평균이 조금이라도 올라가면 양수가 계속 더해져 CUSUM이 꾸준히 올라갑니다.

## 손으로 따라 하기

기준이 50, k가 1일 때 값 51, 49, 53, 54, 52, 55가 차례로 들어옵니다.

```run
values = [51, 49, 53, 54, 52, 55]
target, k = 50, 1
c = 0
for v in values:
    c = max(0, c + (v - target - k))
    print(f"value {v}: add {v - target - k:+d} -> CUSUM = {c}")
```

- 51: 51 − 50 − 1 = 0을 더합니다. 그대로 0.
- 49: −2를 더하면 음수라서 0으로 되돌립니다.
- 53, 54, 52, 55: +2, +3, +1, +4가 차례로 쌓여 2 → 5 → 6 → **10**.

어느 값도 혼자서는 크게 튀지 않았지만, 연달아 기준보다 높았기 때문에 누적이 10까지 올라갔습니다.

## 한계선은 못 잡고 CUSUM은 잡는 변화

평균 50, 표준편차 2인 값 100개 뒤에 평균이 **52로 살짝 올라간** 값 100개를 붙입니다. 표준편차 하나만큼의 작은 변화입니다.

```run
import matplotlib.pyplot as plt
import numpy as np

rng = np.random.default_rng(1)
x = np.concatenate([rng.normal(50, 2, 100), rng.normal(52, 2, 100)])
target, k, limit = 50, 1, 10
cusum = np.zeros(len(x))
for t in range(1, len(x)):
    cusum[t] = max(0, cusum[t - 1] + (x[t] - target - k))
fig, (ax1, ax2) = plt.subplots(2, 1, figsize=(9, 4.5), sharex=True)
ax1.plot(x, linewidth=0.8)
ax1.axhline(56, color="gray", linestyle=":")
ax1.set_title("Values (mean shifts from 50 to 52 at t = 100)")
ax2.plot(cusum)
ax2.axhline(limit, color="crimson", linestyle="--")
ax2.set_title("CUSUM")
print("mean before:", round(x[:100].mean(), 2), "/ after:", round(x[100:].mean(), 2))
print("values above 3-sigma limit (56):", int((x > 56).sum()), "of 200")
print("highest CUSUM before the shift:", round(cusum[:100].max(), 1))
print("first time CUSUM > 10: t =", int(np.argmax(cusum > limit)))
```

::figure{src="content/img/ts/ts09-cusum.svg" alt="위 그래프는 평균이 중간에 조금 올라간 시계열로, 눈으로는 변화가 잘 보이지 않는다. 아래 그래프는 CUSUM으로, 변화 전에는 0 근처에 붙어 있다가 변화 시점부터 꾸준히 올라가 한계선을 넘는다" caption="값 그래프에서는 잘 보이지 않는 작은 수준 변화가 CUSUM에서는 뚜렷한 오르막이 됩니다."}

- 3σ 한계선(56)을 넘은 값은 200개 중 **2개뿐**입니다. 한계선으로는 평균이 바뀌었다는 것을 알 수 없습니다.
- 변화 전 100개 구간에서 CUSUM은 가장 높을 때도 3.7입니다. 평소에는 0 근처에 머뭅니다.
- CUSUM이 한계값 10을 처음 넘는 시점은 **t = 105**입니다. 평균이 바뀐 지 다섯 번 만에 알아챘습니다.

위 그래프에서는 100번째 전후의 차이가 눈에 잘 보이지 않지만, 아래 CUSUM 그래프는 100번째부터 꾸준히 올라갑니다.

## 허용폭 k를 바꿔 보기

```run
import numpy as np

rng = np.random.default_rng(1)
x = np.concatenate([rng.normal(50, 2, 100), rng.normal(52, 2, 100)])
for k in [0, 0.5, 1, 2]:
    cusum = np.zeros(len(x))
    for t in range(1, len(x)):
        cusum[t] = max(0, cusum[t - 1] + (x[t] - 50 - k))
    over = cusum > 10
    print(f"k = {k}: highest before shift = {cusum[:100].max():5.1f}, first alarm t = {int(np.argmax(over)) if over.any() else None}")
```

- k = 0: 눈감아 주는 것이 없어서 평소의 흔들림도 쌓입니다. 변화 전에 이미 8.8까지 올라가 헛경보 직전입니다.
- k = 1: 변화 전 최고 3.7, 변화 후 105번째에 경보. 균형이 좋습니다.
- k = 2: 변화량(2)을 통째로 눈감아 주니 거의 쌓이지 않아, 183번째에야 경보가 울립니다.

k는 보통 **잡고 싶은 변화량의 절반**으로 둡니다. 평균이 2만큼 바뀌는 것을 잡고 싶으면 k = 1입니다. 흔히 k = 0.5σ, 한계값 = 4σ ~ 5σ에서 시작합니다.

## 설비 온도에서 고장 전 변화 찾기

설비 온도에 적용합니다. 온도가 **내려가는** 쪽을 잡아야 하므로 (기준 − 값 − k)를 쌓습니다. 하루 평균으로 묶고, 안정적으로 가동된 12월 18일 ~ 1월 23일을 기준 구간으로 삼습니다. k = 0.5σ, 한계값 = 4σ입니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

m = pd.read_csv("machine_temp.csv", parse_dates=["timestamp"]).set_index("timestamp")["temp"]
daily = m.resample("D").mean()
base = daily["2013-12-18":"2014-01-23"]
target, sigma = base.mean(), base.std()
part = daily["2013-12-18":"2014-02-12"]
k, limit = 0.5 * sigma, 4 * sigma
c, values = 0, []
for v in part:
    c = max(0, c + (target - v - k))
    values.append(c)
cusum = pd.Series(values, index=part.index)
fig, (ax1, ax2) = plt.subplots(2, 1, figsize=(10, 4.5), sharex=True)
ax1.plot(part.index, part.values, marker="o", markersize=3)
ax1.axhline(target - 3 * sigma, color="gray", linestyle=":")
ax2.plot(cusum.index, cusum.values)
ax2.axhline(limit, color="crimson", linestyle="--")
print("baseline mean:", round(target, 1), "/ std:", round(sigma, 1), "/ 3-sigma lower limit:", round(target - 3 * sigma, 1))
print(pd.DataFrame({"daily_mean": part, "cusum": cusum}).loc["2014-01-23":"2014-01-29"].round(1))
print("first day below 3-sigma limit:", part[part < target - 3 * sigma].index[0].strftime("%m-%d"))
print("first day CUSUM over limit   :", cusum[cusum > limit].index[0].strftime("%m-%d"), "(limit", round(limit, 1), ")")
```

기준 구간의 하루 평균은 89.1, 표준편차는 5.9입니다.

- 1월 24일(80.9)과 25일(81.1): 평소보다 8쯤 낮지만 3σ 한계선(71.3)보다는 한참 위입니다. 한계선은 조용합니다. CUSUM은 9.6, 14.6으로 쌓이기 시작합니다.
- 1월 27일(74.7): 여전히 한계선 위입니다. CUSUM은 **24.7**로 한계값(23.7)을 넘습니다. **경보.**
- 1월 28일(60.9): 이제야 3σ 한계선 아래로 내려갑니다.

CUSUM이 한계선보다 **하루 먼저** 울렸습니다. 1월 28일은 데이터 제공자가 "눈에 덜 띄지만 나중에 큰 고장으로 이어진 이상"으로 표시한 날입니다. 그 나흘 전부터 하루 평균이 조금씩 낮았고, CUSUM은 그 조용한 변화를 모아서 알려 준 것입니다.

## 이상 탐지 방법 정리

| 방법 | 잘 잡는 것 | 못 잡는 것 |
| --- | --- | --- |
| 고정 한계선 | 크게 튀는 점 | 작은 수준 변화, 맥락 이상 |
| 분해 후 잔차 | 계절 맥락을 벗어난 값 | 주기가 없는 데이터에는 맞지 않음 |
| CUSUM | 작지만 계속되는 수준 변화 | 한 번 튀고 마는 값(천천히 반응) |

현장에서는 하나만 쓰지 않고 **함께** 씁니다. 급락은 한계선이 즉시 알리고, 서서히 진행되는 변화는 CUSUM이 알리는 식입니다. [관리도의 원리와 I-MR 관리도](#/l/st-11-1)에서 관리선과 함께 런 규칙(같은 쪽에 연속 8점 등)을 쓰는 것도 같은 이유입니다.

## 정리

- 변화점은 시계열의 평균 수준이 바뀌는 시점입니다. 하나하나의 값은 정상 범위라 한계선에 걸리지 않습니다.
- CUSUM은 기준에서 벗어난 양을 계속 더하고, 허용폭 k만큼은 눈감아 줍니다.
- k는 잡고 싶은 변화량의 절반, 한계값은 4σ ~ 5σ에서 시작합니다.
- 설비 온도에서 CUSUM은 3σ 한계선보다 하루 먼저 경보를 울렸습니다.
