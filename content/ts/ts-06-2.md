## 시작하기 전에

[단순 지수평활: 최근일수록 크게](#/l/ts-06-1)의 예측은 수평선이었습니다. 꾸준히 오르거나 내리는 데이터에서는 예측이 계속 뒤처집니다. 이번 레슨에서는 지수평활에 **추세**를 더한 Holt의 방법을 배웁니다. 1957년에 찰스 홀트가 만들어서 그의 이름이 붙었습니다.

## 높이와 기울기를 함께 기억하기

등산할 때 "지금 해발 몇 미터인가"만 알면 10분 뒤 높이를 알 수 없습니다. "지금 얼마나 가파르게 오르고 있는가"도 알아야 합니다.

Holt의 방법은 두 가지를 함께 기억하고, 새 값이 들어올 때마다 둘 다 조금씩 고칩니다.

- **수준(level)**: 지금의 높이. α로 갱신합니다.
- **추세(trend)**: 한 칸에 얼마씩 변하는가(기울기). β(베타)로 갱신합니다.

예측은 **수준 + 추세 × 몇 칸 앞**입니다. 수평선 대신 기울어진 직선이 됩니다.

| | 단순 지수평활 | Holt |
| --- | --- | --- |
| 기억하는 것 | 수준 | 수준, 추세 |
| 조절 값 | α | α, β |
| 예측 모양 | 수평선 | 직선 |

## 이산화탄소 농도로 비교하기

추세가 뚜렷한 이산화탄소 농도를 연평균으로 묶어 씁니다. 1958 ~ 1996년으로 학습하고 1997 ~ 2001년 5년을 예측합니다. 먼저 단순 지수평활입니다.

```run
import pandas as pd
from statsmodels.tsa.holtwinters import SimpleExpSmoothing

co2 = pd.read_csv("co2.csv", parse_dates=["date"]).set_index("date")["co2"]
co2m = co2.resample("MS").mean().interpolate()
train, test = co2m.iloc[:-60], co2m.iloc[-60:]
year_train = train.resample("YS").mean()
year_test = test.resample("YS").mean()
print("train:", year_train.index[0].year, "~", year_train.index[-1].year, "/ test:", year_test.index[0].year, "~", year_test.index[-1].year)
fit = SimpleExpSmoothing(year_train, initialization_method="estimated").fit()
fc = fit.forecast(5)
print(pd.DataFrame({"actual": year_test.values, "ses": fc.values}, index=year_test.index.year).round(1))
print("MAE:", round(abs(year_test.values - fc.values).mean(), 2))
```

예측이 5년 내내 362.6입니다. 실제는 363.7에서 370.9로 계속 오르니, 해가 갈수록 차이가 벌어집니다. MAE 5.16.

같은 데이터에 Holt를 씁니다.

```run
import pandas as pd
from statsmodels.tsa.holtwinters import Holt

co2 = pd.read_csv("co2.csv", parse_dates=["date"]).set_index("date")["co2"]
co2m = co2.resample("MS").mean().interpolate()
train, test = co2m.iloc[:-60], co2m.iloc[-60:]
year_train = train.resample("YS").mean()
year_test = test.resample("YS").mean()
fit = Holt(year_train, initialization_method="estimated").fit()
fc = fit.forecast(5)
print("level:", round(fit.level.iloc[-1], 2), "/ trend per year:", round(fit.trend.iloc[-1], 2))
print(pd.DataFrame({"actual": year_test.values, "holt": fc.values}, index=year_test.index.year).round(1))
print("MAE:", round(abs(year_test.values - fc.values).mean(), 2))
```

Holt는 마지막 수준을 362.59, 추세를 **해마다 +1.54ppm**으로 추정했습니다. 그래서 예측이 364.1, 365.7, 367.2 …로 해마다 약 1.5씩 오릅니다. MAE는 **0.72**로, 단순 지수평활(5.16)의 7분의 1입니다.

## 직선이 영원히 이어질까

Holt의 예측은 직선이라, 멀리 갈수록 끝없이 오르거나 내립니다. 가까운 미래에는 괜찮지만 먼 미래에는 위험합니다. 세상의 많은 성장은 언젠가 느려지기 때문입니다.

그래서 추세를 조금씩 줄여 가는 **감쇠 추세(damped trend)** 를 씁니다. 감쇠 계수 φ(파이, 0.8 ~ 1 사이)를 두고, 한 칸 앞으로 갈 때마다 추세에 φ를 한 번 더 곱합니다. φ = 0.9라면 1년 뒤에는 추세의 90%, 2년 뒤에는 81%만 더합니다. 예측선이 점점 눕다가 수평에 가까워집니다.

항공 승객을 연간 합계로 묶어 1949 ~ 1958년으로 학습하고 12년 앞(1970년)까지 예측합니다.

```run
import matplotlib.pyplot as plt
import pandas as pd
from statsmodels.tsa.holtwinters import Holt

df = pd.read_csv("flights.csv")
df["date"] = pd.to_datetime(df["year"].astype(str) + "-" + df["month"], format="%Y-%B")
y = df.set_index("date")["passengers"].asfreq("MS")
year = y.resample("YS").sum()
train = year.iloc[:-2]
fig, ax = plt.subplots(figsize=(9, 3.5))
ax.plot(year.index.year, year.values, color="black", label="actual")
for damped in [False, True]:
    fit = Holt(train, damped_trend=damped, initialization_method="estimated").fit(damping_trend=0.9 if damped else None)
    fc = fit.forecast(12)
    ax.plot(fc.index.year, fc.values, linestyle="--", label=f"damped={damped}")
    print(f"damped={damped!s:>5}: 1959 {fc.iloc[0]:.0f}, 1960 {fc.iloc[1]:.0f}, 1970 {fc.iloc[-1]:.0f}")
ax.legend()
print("actual 1959:", year.iloc[-2], "/ 1960:", year.iloc[-1])
```

- 감쇠 없음: 1970년 8,898천 명. 직선으로 계속 올라갑니다.
- 감쇠 있음(φ = 0.9): 1970년 6,542천 명. 올라가는 속도가 점점 줄어듭니다.

실제 값이 있는 1959년(5,140)과 1960년(5,714)은 감쇠 없는 쪽(4,933, 5,294)이 더 가깝습니다. 이 시기에는 항공 수요가 아직 한창 크고 있었기 때문입니다. **가까운 미래는 둘의 차이가 작고, 먼 미래에서 크게 갈립니다.**

어느 쪽이 맞을지는 미리 알 수 없습니다. 다만 여러 예측 대회의 결과를 보면, 먼 미래를 예측할 때는 감쇠 추세가 **평균적으로 더 안전**했습니다. 직선 추세가 크게 틀릴 때의 피해가 훨씬 크기 때문입니다. 1년 넘게 예측해야 한다면 감쇠를 켜는 쪽을 먼저 고려합니다.

## 정리

- Holt는 수준과 추세 두 가지를 함께 갱신하고, 예측은 수준 + 추세 × 칸 수인 직선입니다.
- 이산화탄소 연평균 5년 예측에서 단순 지수평활 MAE 5.16, Holt 0.72입니다.
- 직선 추세는 먼 미래로 갈수록 위험합니다.
- 감쇠 추세는 추세를 점점 줄여 예측선을 눕힙니다. 먼 미래를 예측할 때 더 안전한 선택입니다.
