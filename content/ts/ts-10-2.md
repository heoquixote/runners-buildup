## 시작하기 전에

이 트랙에서는 분해, 지수평활, ARIMA, 머신러닝 회귀, 이상 탐지를 배웠습니다. 실무에서 만나는 시계열 문제의 대부분은 이 도구들로 풀 수 있습니다.

마지막 레슨에서는 그 너머에 무엇이 있는지 둘러봅니다. 여기서 소개하는 도구들은 이 사이트의 브라우저 파이썬에서는 실행할 수 없어서, 실행 셀 없이 **무엇이고 언제 쓰는지**만 정리합니다. 내 컴퓨터에 설치해 써 보려면 [pip: 라이브러리를 설치하고 관리하는 도구](#/l/da-00-1)를 참고하세요.

## 배운 도구로 충분한 경우, 부족한 경우

| 상황 | 알맞은 도구 |
| --- | --- |
| 시계열이 하나 ~ 수십 개, 길이는 수백 ~ 수천 | 지수평활, ARIMA (이 트랙) |
| 바깥 변수가 여러 개 있다 | 머신러닝 회귀 (이 트랙) |
| 휴일 효과가 크고 추세가 여러 번 꺾인다 | Prophet |
| 시계열이 수천 ~ 수만 개 (상품별 · 매장별 수요) | 그래디언트 부스팅, 딥러닝 |
| 아주 길고 복잡한 패턴, 여러 센서를 한꺼번에 | 딥러닝 (RNN · LSTM · Transformer) |
| 데이터가 거의 없는 새 시계열 | 시계열 기초 모델 |

## Prophet: 달력을 잘 아는 도구

**Prophet**은 메타(페이스북)가 공개한 예측 라이브러리입니다. 시계열을 **추세 + 여러 계절성 + 휴일 효과**의 합으로 보고 각각을 곡선으로 맞춥니다. [시계열을 이루는 세 가지](#/l/ts-02-1)의 분해를 그대로 예측 모델로 만든 것이라고 보면 됩니다.

- 1년 · 일주일 · 하루 주기를 **동시에** 다룹니다.
- 설날, 추석처럼 해마다 날짜가 바뀌는 휴일을 목록으로 넣을 수 있습니다.
- 추세가 꺾이는 지점을 스스로 찾습니다.
- 빈칸이 있어도, 간격이 조금 고르지 않아도 돌아갑니다.

사용법은 아주 간단합니다. 아래는 읽기용 코드입니다.

```python
from prophet import Prophet

df = daily.reset_index()
df.columns = ["ds", "y"]          # 날짜 열은 ds, 값 열은 y 로 이름을 맞춘다
model = Prophet()
model.add_country_holidays(country_name="KR")
model.fit(df)
future = model.make_future_dataframe(periods=28)
forecast = model.predict(future)  # yhat(예측), yhat_lower, yhat_upper(구간)
```

다만 Prophet이 언제나 더 정확한 것은 아닙니다. 여러 비교 연구에서 잘 조정한 지수평활이나 ARIMA가 Prophet보다 나은 경우가 많았습니다. Prophet의 강점은 정확도보다 **빨리 쓸 만한 결과를 얻고, 휴일 같은 사전 지식을 넣기 쉽다**는 데 있습니다.

## 여러 시계열을 한꺼번에: 전역 모델

편의점 본사가 상품 5,000개 × 매장 1,000개의 수요를 예측해야 한다고 해 봅시다. 시계열이 500만 개입니다. 하나하나에 ARIMA를 맞추는 것은 불가능에 가깝고, 새로 나온 상품은 기록이 짧아서 맞출 수도 없습니다.

이럴 때는 **모든 시계열을 한 표에 쌓아 모델 하나**를 학습시킵니다. [시계열을 표로 바꾸기](#/l/ts-08-1)의 방법 그대로, 래그 · 달력 특성에 "어느 상품인가", "어느 매장인가" 열을 더합니다. 이것을 **전역 모델(global model)** 이라고 합니다. 한 상품에서 배운 "비 오는 날 우산이 팔린다"가 다른 매장의 예측에도 쓰입니다.

전역 모델에는 [부스팅과 피처 중요도](#/l/ml-04-4)에서 배운 그래디언트 부스팅 계열(LightGBM 등)이 가장 널리 쓰입니다. 대규모 수요 예측 대회의 상위권이 대부분 이 방식이었습니다.

## 딥러닝: 순서를 직접 읽는 모델

이 트랙에서 머신러닝 모델을 쓸 때는 래그와 이동평균을 **사람이 직접** 만들어 줬습니다. 딥러닝 모델은 과거 값들을 순서대로 읽으면서 **어떤 과거가 중요한지를 스스로 배웁니다.**

| 모델 | 한 줄 설명 | 배우는 곳 |
| --- | --- | --- |
| RNN | 값을 하나씩 읽으며 "지금까지의 요약"을 갱신한다 | [순서를 기억하는 네트워크](#/l/dl-06-1) |
| LSTM | 오래된 정보도 잊지 않도록 기억 장치를 단 RNN | 딥러닝 트랙의 RNN · LSTM 코스 |
| Transformer | 과거의 모든 시점을 한꺼번에 보고 중요한 곳에 집중한다 | 딥러닝 트랙의 어텐션 · Transformer 코스 |

지수평활의 "수준을 조금씩 갱신한다"는 생각과 RNN의 "요약을 조금씩 갱신한다"는 생각은 닮았습니다. 이 트랙에서 배운 것이 바로 다음 [딥러닝 트랙](#/l/dl-00-1)으로 이어집니다.

딥러닝이 유리한 조건은 분명합니다.

- 시계열이 **아주 많거나 아주 길다.** 데이터가 적으면 지수평활을 이기지 못합니다.
- 진동 파형, 심전도처럼 **촘촘하고 복잡한 신호**다.
- 여러 센서의 값을 **함께** 봐야 한다.

반대로 월별 매출 5년 치(60개) 같은 데이터에 딥러닝을 쓰는 것은 낭비이고, 대개 Holt-Winters보다 못합니다.

## 시계열 기초 모델

최근에는 수많은 시계열을 미리 학습해 둔 **시계열 기초 모델(foundation model)** 이 나왔습니다. 글을 미리 많이 읽어 둔 언어 모델이 처음 보는 질문에도 답하듯이, 이 모델들은 **처음 보는 시계열도 추가 학습 없이** 예측합니다. Chronos, TimesFM, Moirai 같은 이름으로 공개돼 있습니다.

- 장점: 기록이 짧은 새 시계열에도 쓸 수 있고, 모델을 직접 학습시킬 필요가 없습니다.
- 한계: 왜 그렇게 예측했는지 설명하기 어렵고, 우리 데이터만의 특수한 사정(행사, 정비 일정)은 모릅니다. 빠르게 발전하는 분야라 성능과 쓰임새가 계속 바뀌고 있습니다.

## 어떤 도구를 쓰든 변하지 않는 것

도구는 계속 바뀌지만, 이 트랙에서 배운 **절차**는 어떤 모델에도 그대로 적용됩니다.

1. 간격을 고르게 하고, 값의 종류에 맞게 묶는다.
2. 그래프와 분해로 추세 · 계절성 · 잡음의 크기를 먼저 본다.
3. **기준 예측을 반드시 먼저** 만든다. 최신 모델도 seasonal naive를 못 이기면 쓸 이유가 없다.
4. 시간 순서대로, 여러 원점에서, 실제로 필요한 지평으로 평가한다.
5. 예측하는 순간에 알 수 없는 정보를 쓰지 않는다.
6. 예측은 구간과 함께 말한다.
7. 배포 뒤에는 오차를 지켜본다.

[예측 프로젝트 순서](#/l/ts-10-1)에서 가장 단순한 "최근 7일 평균"이 이겼던 것을 기억하세요. 좋은 예측은 복잡한 모델이 아니라 **데이터를 제대로 이해하고 공정하게 비교하는 습관**에서 나옵니다.

## 정리

- Prophet은 여러 계절성과 휴일을 쉽게 다루는 도구입니다. 빠르게 쓸 만한 결과를 얻을 때 유용합니다.
- 시계열이 아주 많으면 모두 한 표에 쌓아 모델 하나로 학습하는 전역 모델을 씁니다.
- 딥러닝은 데이터가 많고 신호가 복잡할 때 유리하고, 짧은 시계열에는 지수평활이 더 낫습니다.
- 어떤 도구를 쓰든 기준 예측, 시간 순서 검증, 누수 점검, 구간 예측의 절차는 같습니다.
