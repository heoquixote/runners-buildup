## 시작하기 전에

[Holt: 추세 더하기](#/l/ts-06-2)까지 수준과 추세를 다뤘습니다. 이제 마지막 조각인 **계절성**을 더합니다. Holt의 제자 피터 윈터스가 1960년에 계절성을 추가해서 **Holt-Winters** 방법이라고 부릅니다.

이번 레슨에서 드디어 [예측 오차 재기: MAE · RMSE · MAPE · MASE](#/l/ts-05-2)에서 세운 문턱, seasonal naive의 MAPE 15.5%에 도전합니다.

## 세 가지를 함께 기억하기

Holt-Winters는 세 가지를 기억하고 새 값이 들어올 때마다 모두 조금씩 고칩니다.

| 기억하는 것 | 뜻 | 조절 값 |
| --- | --- | --- |
| 수준 | 지금의 높이 | α |
| 추세 | 한 칸에 얼마씩 변하나 | β |
| 계절 | 이 달은 평소보다 얼마나 높거나 낮은가 (열두 달 각각) | γ(감마) |

::figure{src="content/img/ts/ts06-hw-three.svg" alt="Holt-Winters가 수준, 추세, 계절 세 가지를 각각 갱신하고, 셋을 합쳐 예측선을 만드는 흐름" caption="새 값이 들어올 때마다 수준 · 추세 · 계절을 각각 조금씩 고치고, 셋을 합쳐 예측합니다."}

[덧셈 분해와 곱셈 분해](#/l/ts-02-2)에서 계절 효과가 일정한 양이면 덧셈형, 일정한 비율이면 곱셈형이라고 배웠습니다. Holt-Winters도 계절을 더할지 곱할지 고릅니다.

- 덧셈 계절: 예측 = 수준 + 추세 + 계절
- 곱셈 계절: 예측 = (수준 + 추세) × 계절

## 덧셈 계절로 예측하기

statsmodels의 `ExponentialSmoothing`을 씁니다. `trend="add"`는 추세를 더한다, `seasonal="add"`는 계절을 더한다, `seasonal_periods=12`는 주기가 12개월이라는 뜻입니다. 항공 승객의 마지막 24개월을 예측합니다.

```run
import numpy as np
import pandas as pd
from statsmodels.tsa.holtwinters import ExponentialSmoothing

df = pd.read_csv("flights.csv")
df["date"] = pd.to_datetime(df["year"].astype(str) + "-" + df["month"], format="%Y-%B")
y = df.set_index("date")["passengers"].asfreq("MS")
train, test = y.iloc[:-24], y.iloc[-24:]
fit = ExponentialSmoothing(train, trend="add", seasonal="add", seasonal_periods=12, initialization_method="estimated").fit()
fc = fit.forecast(24)
print("MAE :", round((test - fc).abs().mean(), 1))
print("MAPE:", round(((test - fc).abs() / test).mean() * 100, 1), "%")
```

MAPE **6.6%** 입니다. seasonal naive의 15.5%를 절반 아래로 낮췄습니다. 추세와 계절성을 함께 다루자 처음으로 기준 예측을 크게 넘었습니다.

## 곱셈 계절로 예측하기

항공 승객은 곱셈형이었으니 `seasonal="mul"`이 더 맞을 것입니다.

```run
import matplotlib.pyplot as plt
import pandas as pd
from statsmodels.tsa.holtwinters import ExponentialSmoothing

df = pd.read_csv("flights.csv")
df["date"] = pd.to_datetime(df["year"].astype(str) + "-" + df["month"], format="%Y-%B")
y = df.set_index("date")["passengers"].asfreq("MS")
train, test = y.iloc[:-24], y.iloc[-24:]
fit = ExponentialSmoothing(train, trend="add", seasonal="mul", seasonal_periods=12, initialization_method="estimated").fit()
fc = fit.forecast(24)
fig, ax = plt.subplots(figsize=(9, 3.5))
ax.plot(train.index[-36:], train.values[-36:], color="gray", label="train")
ax.plot(test.index, test.values, color="black", label="actual")
ax.plot(fc.index, fc.values, color="crimson", linestyle="--", label="Holt-Winters")
ax.legend()
print("MAE :", round((test - fc).abs().mean(), 1))
print("MAPE:", round(((test - fc).abs() / test).mean() * 100, 1), "%")
print("alpha, beta, gamma:", [round(float(fit.params[k]), 2) for k in ("smoothing_level", "smoothing_trend", "smoothing_seasonal")])
```

MAPE **6.4%**, MAE 29.0입니다. 덧셈 계절(6.6%)보다 조금 더 좋습니다. 그래프에서 빨간 점선이 검은 실제 값의 여름 봉우리와 겨울 골짜기를 잘 따라갑니다.

statsmodels가 고른 조절 값은 α = 0.36, β = 0.0, γ = 0.64입니다. β가 0이라는 것은 추세(기울기)를 처음 추정한 값에서 거의 바꾸지 않았다는 뜻입니다. 이 데이터의 성장 속도가 그만큼 꾸준했기 때문입니다.

## 설정별 비교

추세 · 계절 · 감쇠 설정을 바꿔 가며 같은 시험 구간에서 비교합니다.

```run
import numpy as np
import pandas as pd
from statsmodels.tsa.holtwinters import ExponentialSmoothing

df = pd.read_csv("flights.csv")
df["date"] = pd.to_datetime(df["year"].astype(str) + "-" + df["month"], format="%Y-%B")
y = df.set_index("date")["passengers"].asfreq("MS")
train, test = y.iloc[:-24], y.iloc[-24:]
def mape(fc):
    return ((test - fc).abs() / test).mean() * 100
snaive = pd.Series(np.tile(train.iloc[-12:].values, 2), index=test.index)
print(f"{'seasonal naive':>22}: MAPE {mape(snaive):4.1f}%")
for trend, seasonal, damped in [("add", "add", False), ("add", "mul", False), ("add", "mul", True)]:
    fit = ExponentialSmoothing(train, trend=trend, seasonal=seasonal, damped_trend=damped, seasonal_periods=12, initialization_method="estimated").fit()
    name = f"trend={trend}, season={seasonal}" + (", damped" if damped else "")
    print(f"{name:>30}: MAPE {mape(fit.forecast(24)):4.1f}%")
```

| 모델 | MAPE |
| --- | --- |
| seasonal naive | 15.5% |
| Holt-Winters, 덧셈 계절 | 6.6% |
| Holt-Winters, 곱셈 계절 | **6.4%** |
| Holt-Winters, 곱셈 계절 + 감쇠 추세 | 7.9% |

감쇠를 켜자 오히려 나빠졌습니다(7.9%). 1959 ~ 1960년에는 승객이 계속 빠르게 늘었는데, 감쇠가 추세를 일찍 눕혀 버렸기 때문입니다. 앞 레슨에서 말했듯 감쇠는 먼 미래에 대한 보험이지, 언제나 이기는 설정은 아닙니다.

여기서 주의할 점이 있습니다. 지금처럼 **시험 구간의 점수를 보고 설정을 고르면** 그 점수는 낙관적으로 부풀려집니다. [하이퍼파라미터와 GridSearchCV](#/l/ml-05-2)에서 배운 것과 같은 문제입니다. 실제로는 [시간 순서대로 검증하기: 롤링 원점](#/l/ts-05-3)의 방법으로 여러 원점에서 비교해 설정을 고르고, 마지막 시험 구간은 한 번만 봅니다.

## 예측은 구간으로 말한다

예측값 하나만 내놓으면 "얼마나 믿을 수 있는지"를 알 수 없습니다. **예측 구간**은 "90% 확률로 이 범위 안에 있을 것"이라는 띠입니다.

`simulate`는 모델이 추정한 오차 크기만큼 무작위 흔들림을 넣어 가상의 미래를 여러 개 만들어 줍니다. 500개를 만들어, 달마다 아래 5% 지점과 위 5% 지점을 구하면 90% 구간이 됩니다.

```run
import matplotlib.pyplot as plt
import pandas as pd
from statsmodels.tsa.holtwinters import ExponentialSmoothing

df = pd.read_csv("flights.csv")
df["date"] = pd.to_datetime(df["year"].astype(str) + "-" + df["month"], format="%Y-%B")
y = df.set_index("date")["passengers"].asfreq("MS")
train, test = y.iloc[:-24], y.iloc[-24:]
fit = ExponentialSmoothing(train, trend="add", seasonal="mul", seasonal_periods=12, initialization_method="estimated").fit()
sims = fit.simulate(24, repetitions=500, error="mul", random_state=0)
low, high = sims.quantile(0.05, axis=1), sims.quantile(0.95, axis=1)
fc = fit.forecast(24)
fig, ax = plt.subplots(figsize=(9, 3.5))
ax.plot(test.index, test.values, color="black", label="actual")
ax.plot(fc.index, fc.values, color="crimson", label="forecast")
ax.fill_between(fc.index, low, high, color="crimson", alpha=0.2, label="90% interval")
ax.legend()
print("width of interval: month 1 =", round(high.iloc[0] - low.iloc[0]), "/ month 12 =", round(high.iloc[11] - low.iloc[11]), "/ month 24 =", round(high.iloc[23] - low.iloc[23]))
print("actual inside interval:", int(((test >= low) & (test <= high)).sum()), "of 24")
```

- 구간의 폭이 1개월 뒤에는 50, 12개월 뒤에는 77, 24개월 뒤에는 114입니다. **먼 미래일수록 띠가 넓어집니다.** 오차가 달마다 쌓이기 때문입니다.
- 실제 값 24개 중 23개가 띠 안에 들었습니다. 90% 구간이니 24개 중 21 ~ 22개쯤 들어오면 잘 맞는 것입니다.

현장에서는 이 구간이 예측값만큼 중요합니다. 자전거를 몇 대 준비할지 정할 때 "예측 500대"보다 "450 ~ 560대 사이, 넉넉히 560대 준비"가 훨씬 쓸모 있습니다.

## 지수평활 가족 정리

| 방법 | 다루는 것 | 알맞은 데이터 |
| --- | --- | --- |
| 단순 지수평활 | 수준 | 추세도 계절성도 없다 |
| Holt | 수준 + 추세 | 추세만 있다 |
| Holt (감쇠) | 수준 + 줄어드는 추세 | 추세가 있고 먼 미래를 예측한다 |
| Holt-Winters | 수준 + 추세 + 계절 | 추세와 계절성이 모두 있다 |

## 정리

- Holt-Winters는 수준, 추세, 계절을 α, β, γ로 각각 갱신합니다.
- 계절 효과가 비율로 움직이면 `seasonal="mul"`을 씁니다.
- 항공 승객 24개월 예측에서 MAPE 6.4%로, seasonal naive(15.5%)를 크게 넘었습니다.
- 예측은 구간과 함께 말하고, 구간은 먼 미래일수록 넓어집니다.
