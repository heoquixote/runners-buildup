## 시작하기 전에

[AR과 MA: 과거 값과 과거 오차로 예측](#/l/ts-07-1)에서 AR과 MA를 배웠습니다. 두 모델은 모두 **정상 시계열**을 가정합니다. 그런데 실제 데이터는 대부분 추세가 있어서 정상이 아닙니다.

그래서 [차분과 로그로 정상 만들기](#/l/ts-04-2)에서 배운 차분을 먼저 하고, 그 결과에 AR과 MA를 적용합니다. 이 세 단계를 하나로 묶은 것이 **ARIMA**입니다. 이번 레슨에서는 ARIMA의 세 숫자를 정하는 방법을 배웁니다.

## ARIMA(p, d, q)의 세 숫자

| 글자 | 이름 | 숫자의 뜻 |
| --- | --- | --- |
| AR | 자기회귀 | **p**: 과거 값 몇 개를 쓸까 |
| I | 누적 (Integrated) | **d**: 차분을 몇 번 할까 |
| MA | 이동평균 | **q**: 과거 오차 몇 개를 쓸까 |

I는 Integrated(누적)의 머리글자입니다. 차분한 값으로 예측한 뒤 다시 누적해서 원래 단위로 되돌린다는 뜻입니다. `ARIMA(order=(p, d, q))`에 d를 주면 statsmodels가 차분과 되돌리기를 알아서 합니다.

세 숫자를 정하는 순서는 다음과 같습니다.

1. **d**: 그래프와 단위근 검정으로 정합니다. 보통 0 아니면 1입니다.
2. **p와 q의 후보**: 차분한 시계열의 ACF와 PACF를 보고 짐작합니다.
3. **확정**: 후보 몇 개를 실제로 학습시켜 AIC로 비교합니다.
4. **점검**: 잔차가 백색잡음인지 확인합니다.

## 데이터 준비와 d 정하기

이산화탄소 농도 월 평균을 씁니다. 계절성은 다음 레슨에서 다루므로, 여기서는 계절 차분을 미리 해서 **"1년 전보다 몇 ppm 늘었나"** 를 대상으로 삼습니다. 마지막 60개월은 시험용으로 떼어 놓았습니다.

[차분과 로그로 정상 만들기](#/l/ts-04-2)에서 이 값의 평균이 1960년대 0.86에서 1990년대 1.54로 올라가는 것을 봤습니다. 평균이 변하니 한 번 더 차분해야 합니다. 검정으로 확인하고, 차분한 뒤의 ACF와 PACF를 봅니다.

```run
import pandas as pd
from statsmodels.tsa.stattools import acf, adfuller, pacf

co2 = pd.read_csv("co2.csv", parse_dates=["date"]).set_index("date")["co2"]
co2m = co2.resample("MS").mean().interpolate()
train, test = co2m.iloc[:-60], co2m.iloc[-60:]
season_adj = train.diff(12).dropna()
print("ADF p of yearly change:", round(adfuller(season_adj)[1], 3), "/ after one more diff:", round(adfuller(season_adj.diff().dropna())[1], 4))
z = season_adj.diff().dropna()
print("ACF  lag 1~5:", acf(z, nlags=5)[1:].round(2).tolist())
print("PACF lag 1~5:", pacf(z, nlags=5)[1:].round(2).tolist())
```

한 번 더 차분하면 ADF p-값이 0.0입니다. **d = 1**로 정합니다.

## ACF와 PACF로 후보 짐작하기

앞 레슨의 표를 다시 씁니다.

| 모양 | 후보 |
| --- | --- |
| PACF가 래그 p 뒤에서 끊기고 ACF는 천천히 준다 | AR(p) |
| ACF가 래그 q 뒤에서 끊기고 PACF는 천천히 준다 | MA(q) |
| 둘 다 천천히 준다 | AR과 MA를 함께 |

위 결과에서 ACF는 래그 1이 −0.31이고 래그 2는 0.02로 바로 끊깁니다. PACF는 −0.31, −0.08, −0.20, −0.10으로 더 길게 이어집니다. **ACF가 래그 1에서 끊기는 MA(1)** 모양에 가깝습니다. 첫 후보는 ARIMA(0, 1, 1)입니다.

실제 데이터에서는 이렇게 깔끔하게 읽히지 않는 경우가 더 많습니다. ACF와 PACF는 **출발점을 정하는 도구**로만 쓰고, 최종 결정은 다음 단계에서 합니다.

## 모델 학습하고 결과표 읽기

```run
import pandas as pd
import warnings
from statsmodels.tsa.arima.model import ARIMA

co2 = pd.read_csv("co2.csv", parse_dates=["date"]).set_index("date")["co2"]
co2m = co2.resample("MS").mean().interpolate()
train, test = co2m.iloc[:-60], co2m.iloc[-60:]
season_adj = train.diff(12).dropna()
warnings.filterwarnings("ignore")
fit = ARIMA(season_adj, order=(0, 1, 1)).fit()
print(fit.summary().tables[1])
print("AIC:", round(fit.aic, 1))
```

결과표에서 볼 것은 두 가지입니다.

- `ma.L1`의 `coef`가 −0.4070입니다. 이것이 θ입니다. 지난달의 예측 오차에 −0.407을 곱해 이번 달 예측에 반영합니다.
- `P>|z|`가 0.000입니다. "이 계수가 실제로는 0이다"라는 귀무가설의 p-값입니다. 0.05보다 작으니 이 항은 모델에 필요합니다. p-값이 큰 항은 빼도 되는 항입니다.

`sigma2`는 잔차의 분산입니다.

## AIC로 후보 비교하기

p와 q를 늘리면 모델은 학습 데이터에 점점 더 잘 맞습니다. 하지만 [깊어질수록 외운다: 과적합과 과소적합](#/l/ml-04-2)에서 배웠듯이, 복잡한 모델은 학습 데이터를 외울 뿐 새 데이터에는 약할 수 있습니다.

**AIC**는 "얼마나 잘 맞는가"에서 "얼마나 복잡한가"를 벌점으로 뺀 점수입니다. **작을수록 좋습니다.** 항을 하나 늘렸는데 맞는 정도가 벌점만큼 나아지지 않으면 AIC가 오히려 커집니다.

p와 q를 0, 1, 2로 바꿔 가며 아홉 가지 조합을 모두 학습해 AIC를 표로 만듭니다.

```run
import pandas as pd
import warnings
from statsmodels.tsa.arima.model import ARIMA

co2 = pd.read_csv("co2.csv", parse_dates=["date"]).set_index("date")["co2"]
co2m = co2.resample("MS").mean().interpolate()
train, test = co2m.iloc[:-60], co2m.iloc[-60:]
season_adj = train.diff(12).dropna()
warnings.filterwarnings("ignore")
rows = []
for p in range(3):
    for q in range(3):
        fit = ARIMA(season_adj, order=(p, 1, q)).fit()
        rows.append({"p": p, "q": q, "aic": round(fit.aic, 1)})
table = pd.DataFrame(rows).pivot(index="p", columns="q", values="aic")
print(table)
best = min(rows, key=lambda r: r["aic"])
print("lowest AIC: p =", best["p"], ", q =", best["q"])
```

- (0, 1, 0)은 487.3으로 가장 나쁩니다. AR도 MA도 없는 모델입니다.
- 우리가 짐작한 (0, 1, 1)은 432.2로 크게 좋아졌습니다.
- 가장 작은 것은 **(2, 1, 1)의 418.0** 입니다.
- (2, 1, 2)는 428.1로, 항을 하나 더 넣었는데 오히려 커졌습니다. 벌점이 더 컸다는 뜻입니다.

AIC는 **같은 데이터, 같은 d** 를 쓴 모델끼리만 비교할 수 있습니다. d가 다르면 모델이 보는 데이터 자체가 달라지므로 비교할 수 없습니다.

## 잔차 점검하기

마지막으로 잔차가 백색잡음인지 [백색잡음: 더 뽑아낼 게 없는 상태](#/l/ts-03-3)의 Ljung-Box 검정으로 확인합니다. p-값이 **커야** 통과입니다.

```run
import matplotlib.pyplot as plt
import pandas as pd
import warnings
from statsmodels.stats.diagnostic import acorr_ljungbox
from statsmodels.tsa.arima.model import ARIMA

co2 = pd.read_csv("co2.csv", parse_dates=["date"]).set_index("date")["co2"]
co2m = co2.resample("MS").mean().interpolate()
train, test = co2m.iloc[:-60], co2m.iloc[-60:]
season_adj = train.diff(12).dropna()
warnings.filterwarnings("ignore")
for order in [(0, 1, 0), (0, 1, 1), (2, 1, 1)]:
    fit = ARIMA(season_adj, order=order).fit()
    resid = fit.resid.iloc[1:]
    p = acorr_ljungbox(resid, lags=[10])["lb_pvalue"].iloc[0]
    print(f"order {order}: AIC {fit.aic:7.1f}, residual Ljung-Box p = {p:.4f}")
fit.plot_diagnostics(figsize=(9, 6))
plt.tight_layout()
```

- (0, 1, 0): p = 0.0000. 잔차에 패턴이 많이 남았습니다.
- (0, 1, 1): p = 0.0436. 0.05를 살짝 넘지 못했습니다. 아직 조금 남았습니다.
- (2, 1, 1): p = **0.1134**. 통과입니다. AIC도 가장 작고 잔차도 깨끗합니다.

`plot_diagnostics()`는 잔차 그림 네 장을 한 번에 그려 줍니다.

| 그림 | 좋은 모양 |
| --- | --- |
| 왼쪽 위: 잔차의 시간 그래프 | 0 주변에서 고르게 떨린다 |
| 오른쪽 위: 잔차의 히스토그램 | 종 모양에 가깝다 |
| 왼쪽 아래: Q-Q 그림 | 점들이 직선 위에 있다 |
| 오른쪽 아래: 잔차의 ACF | 막대가 모두 띠 안에 있다 |

## 자동으로 골라 주는 도구

p, d, q를 자동으로 골라 주는 `auto_arima`(pmdarima 라이브러리) 같은 도구도 있습니다. 하는 일은 방금 우리가 한 것과 같습니다. 검정으로 d를 정하고, 여러 조합의 AIC를 비교합니다. 이 사이트의 브라우저 파이썬에는 pmdarima가 없어서 위처럼 반복문으로 직접 했습니다. 원리를 알고 있으면 자동 도구가 내놓은 결과가 이상할 때 알아챌 수 있습니다.

## 정리

- ARIMA(p, d, q)에서 p는 AR 항의 수, d는 차분 횟수, q는 MA 항의 수입니다.
- d는 정상성으로, p와 q의 후보는 ACF와 PACF로 짐작하고, AIC로 확정합니다.
- AIC는 맞는 정도에서 복잡도를 벌점으로 뺀 점수로, 작을수록 좋습니다.
- 마지막에 잔차의 Ljung-Box p-값이 큰지 확인합니다.
