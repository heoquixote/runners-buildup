## 시작하기 전에

[회귀 모델로 예측하고 비교하기](#/l/ts-08-2)의 모델은 **내일 하루**만 예측했습니다. 특성에 "어제 값"이 있으니, 내일을 예측하려면 오늘 값만 알면 됩니다.

그런데 다음 주 인력 배치를 짜려면 7일 뒤까지, 다음 달 정비 계획을 세우려면 28일 뒤까지 알아야 합니다. 7일 뒤의 "어제 값"은 아직 일어나지 않은 6일 뒤입니다. 이번 레슨에서는 여러 걸음 앞을 예측하는 두 가지 전략과, 트리 모델이 시계열에서 부딪히는 한계를 배웁니다.

## 두 가지 전략

::figure{src="content/img/ts/ts08-recursive-direct.svg" alt="재귀 전략은 모델 하나가 내일을 예측하고 그 예측값을 입력으로 다시 넣어 모레를 예측하는 일을 반복한다. 직접 전략은 1일 뒤용, 2일 뒤용, 7일 뒤용 모델을 각각 따로 만든다" caption="재귀 전략은 예측을 다시 입력으로 넣고, 직접 전략은 지평마다 모델을 따로 둡니다."}

| | 재귀 전략 (recursive) | 직접 전략 (direct) |
| --- | --- | --- |
| 방법 | 내일을 예측하고, 그 **예측값을 어제 값 자리에 넣어** 모레를 예측. 반복 | "7일 뒤 값"을 정답으로 두고 **7일 전까지의 정보만** 특성으로 써서 따로 학습 |
| 모델 수 | 1개 | 지평마다 1개 |
| 약점 | 예측의 오차가 다음 예측의 입력이 되어 **오차가 쌓인다** | 모델이 많아지고, 지평끼리 예측이 매끄럽게 이어지지 않을 수 있다 |

ARIMA와 지수평활의 여러 걸음 예측은 내부적으로 재귀 방식입니다.

## 재귀 전략

`lag1`과 `lag7` 두 특성만 쓰는 선형회귀를 만들고, 28일을 재귀로 예측합니다. `history` 목록 끝에 예측값을 계속 붙여 가며 다음 날의 입력으로 씁니다.

```run
import pandas as pd
from sklearn.linear_model import LinearRegression

bike = pd.read_csv("seoul_bike.csv", parse_dates=["date"])
day = bike.groupby("date").agg(rented=("rented_bikes", "sum"), temp=("temp", "mean"), rain=("rainfall", "sum"), open=("functioning_day", lambda s: (s == "Yes").any()))
day = day.asfreq("D")
day["rented"] = day["rented"].where(day["open"]).interpolate()
train, test = day.iloc[:-28], day.iloc[-28:]
s = day["rented"]
X = pd.DataFrame({"lag1": s.shift(1), "lag7": s.shift(7)}).dropna()
train_end = len(s) - 28
model = LinearRegression().fit(X.iloc[: train_end - 7], s.iloc[7:train_end])
history = s.iloc[:train_end].tolist()
preds = []
for step in range(28):
    nxt = model.predict(pd.DataFrame({"lag1": [history[-1]], "lag7": [history[-7]]}))[0]
    preds.append(nxt)
    history.append(nxt)
test = s.iloc[train_end:]
one_step = model.predict(X.iloc[train_end - 7:])
print("one-step MAE (uses actual yesterday):", round(abs(test.values - one_step).mean()))
print("recursive 28-day MAE               :", round(abs(test.values - preds).mean()))
print("recursive forecasts day 1, 7, 14, 28:", [round(preds[i]) for i in (0, 6, 13, 27)])
```

- 매일 실제 어제 값을 받아 하루씩 예측하면 MAE 3,033입니다.
- 재귀로 28일을 한 번에 예측하면 MAE **3,963**으로 커집니다.
- 재귀 예측값은 22,126 → 20,870 → 19,687 → 19,039로 점점 한 값에 가까워집니다. [AR과 MA: 과거 값과 과거 오차로 예측](#/l/ts-07-1)에서 AR 모델의 예측이 평균으로 돌아가던 것과 같은 현상입니다. 자기 예측을 계속 다시 넣으면 하루하루의 출렁임은 사라지고 매끄러운 선만 남습니다.

## 직접 전략

이번에는 지평마다 모델을 따로 만듭니다. h일 뒤를 예측하는 모델은 h일 전 값과 그보다 6일 더 전의 값을 특성으로 씁니다.

```run
import pandas as pd
from sklearn.linear_model import LinearRegression

bike = pd.read_csv("seoul_bike.csv", parse_dates=["date"])
day = bike.groupby("date").agg(rented=("rented_bikes", "sum"), temp=("temp", "mean"), rain=("rainfall", "sum"), open=("functioning_day", lambda s: (s == "Yes").any()))
day = day.asfreq("D")
day["rented"] = day["rented"].where(day["open"]).interpolate()
train, test = day.iloc[:-28], day.iloc[-28:]
s = day["rented"]
train_end = len(s) - 28
test = s.iloc[train_end:]
for h in [1, 7, 14]:
    X = pd.DataFrame({"lag_h": s.shift(h), "lag_h7": s.shift(h + 6)}).dropna()
    y_all = s.loc[X.index]
    model = LinearRegression().fit(X.iloc[: train_end - h - 6], y_all.iloc[: train_end - h - 6])
    pred = model.predict(X.loc[test.index])
    print(f"direct model for {h:>2} days ahead: MAE = {abs(test.values - pred).mean():.0f}")
```

1일 뒤용 모델의 MAE는 3,033, 7일 뒤용은 3,932, 14일 뒤용은 4,351입니다. 지평이 멀수록 쓸 수 있는 정보가 오래된 것뿐이라 오차가 커집니다.

실무에서는 두 전략을 섞기도 하고, 며칠 뒤까지 필요한지에 따라 고릅니다. 지평이 짧고 한두 개면 직접 전략이 간단하고, 지평이 길면 재귀 전략이 모델 하나로 끝나서 편합니다.

## 트리는 본 적 없는 높이를 예측하지 못한다

[시간 순서가 있는 데이터 나누기](#/l/ml-05-4)에서 랜덤포레스트가 항공 승객의 상승 추세를 따라가지 못하는 것을 봤습니다. 다시 확인합니다.

```run
import matplotlib.pyplot as plt
import pandas as pd
from sklearn.ensemble import RandomForestRegressor
from sklearn.linear_model import LinearRegression

df = pd.read_csv("flights.csv")
df["date"] = pd.to_datetime(df["year"].astype(str) + "-" + df["month"], format="%Y-%B")
y = df.set_index("date")["passengers"].asfreq("MS")
df = pd.DataFrame({"y": y, "lag1": y.shift(1), "lag12": y.shift(12)}).dropna()
train, test = df.iloc[:-24], df.iloc[-24:]
fig, ax = plt.subplots(figsize=(9, 3.5))
ax.plot(test.index, test["y"], color="black", label="actual")
print("train max:", train["y"].max(), "/ test max:", test["y"].max())
for name, model in [("forest", RandomForestRegressor(n_estimators=200, random_state=0, n_jobs=1)), ("linear", LinearRegression())]:
    pred = model.fit(train[["lag1", "lag12"]], train["y"]).predict(test[["lag1", "lag12"]])
    ax.plot(test.index, pred, linestyle="--", label=name)
    print(f"{name:>6}: max prediction {pred.max():.0f}, MAPE {(abs(test['y'] - pred) / test['y']).mean() * 100:.1f}%")
ax.legend()
```

학습 구간의 최대 승객 수는 505인데 시험 구간에는 622까지 올라갑니다. 랜덤포레스트의 예측은 **495에서 막힙니다.** 그래프에서 주황색 점선이 천장에 붙은 듯 평평해지는 것이 보입니다.

::figure{src="content/img/ts/ts08-tree-ceiling.svg" alt="계속 올라가는 시계열에서 학습 구간의 최댓값 높이에 수평 천장이 있고, 트리 모델의 예측은 그 천장을 넘지 못하고 평평해진다. 선형 모델의 예측은 천장을 넘어 계속 올라간다" caption="트리 모델의 예측은 학습 때 본 정답 값들의 평균이라, 본 적 없는 높이를 낼 수 없습니다."}

[결정트리: 스무고개로 예측하기](#/l/ml-04-1)를 떠올려 보세요. 트리는 데이터를 상자로 나누고, 각 상자에 든 학습 데이터 **정답의 평균**을 예측값으로 내놓습니다. 평균은 가장 큰 값보다 클 수 없습니다. 그래서 트리 계열 모델(랜덤포레스트, 그래디언트 부스팅)은 **학습 때 본 범위 밖의 값을 예측하지 못합니다.**

추세가 있는 시계열은 미래 값이 과거의 범위를 계속 벗어나므로, 트리 모델을 그대로 쓰면 반드시 이 문제에 부딪힙니다.

## 처방: 값 대신 변화를 예측하게 하기

해결책은 [차분과 로그로 정상 만들기](#/l/ts-04-2)에서 배운 것 그대로입니다. 모델에게 **값이 아니라 변화율**을 예측하게 합니다.

승객 수는 112에서 622까지 계속 커지지만, "작년 같은 달보다 몇 % 늘었나"(로그 계절 차분)는 12년 내내 비슷한 범위에 있습니다. 범위가 일정하니 트리도 잘 예측합니다. 예측한 변화율을 작년 같은 달 값에 더해 되돌리면 됩니다.

```run
import numpy as np
import pandas as pd
from sklearn.ensemble import RandomForestRegressor

df = pd.read_csv("flights.csv")
df["date"] = pd.to_datetime(df["year"].astype(str) + "-" + df["month"], format="%Y-%B")
y = df.set_index("date")["passengers"].asfreq("MS")
log_y = np.log(y)
growth = log_y.diff(12)
df = pd.DataFrame({"target": growth, "lag1": growth.shift(1), "lag2": growth.shift(2), "lag12": growth.shift(12)}).dropna()
train, test = df.iloc[:-24], df.iloc[-24:]
forest = RandomForestRegressor(n_estimators=200, random_state=0, n_jobs=1).fit(train.drop(columns="target"), train["target"])
pred_growth = forest.predict(test.drop(columns="target"))
pred = np.exp(log_y.shift(12).loc[test.index] + pred_growth)
actual = y.loc[test.index]
print("predicted growth, first 3:", pred_growth[:3].round(3).tolist())
print("max prediction:", round(pred.max()), "/ actual max:", actual.max())
print("MAPE:", round((abs(actual - pred) / actual).mean() * 100, 1), "%")
```

- 모델이 예측한 것은 −0.003, 0.029, 0.045 같은 작은 변화율입니다.
- 되돌린 예측의 최댓값은 **627**로, 학습 구간 최대인 505를 훌쩍 넘습니다. 실제 최댓값 622와 가깝습니다.
- MAPE는 6.5%에서 **3.7%** 로 줄었습니다.

참고로 이 숫자들은 "지난달 실제 값을 아는 상태에서 다음 달 한 칸"을 예측한 것입니다. 24개월을 한 번에 예측한 Holt-Winters(6.4%)나 SARIMA(8.5%)와 직접 비교하면 안 됩니다. 지평이 다르면 난이도가 다릅니다.

| 문제 | 처방 |
| --- | --- |
| 추세가 있다 | 차분(변화량)이나 변화율을 정답으로 삼는다 |
| 계절 폭이 커진다 | 로그를 씌운다 |
| 그래도 추세가 남는다 | 선형 모델로 추세를 먼저 예측하고, 남은 부분을 트리로 예측한다 |

## 정리

- 여러 걸음 앞 예측에는 재귀 전략(예측을 다시 입력으로)과 직접 전략(지평마다 모델)이 있습니다.
- 재귀 전략은 오차가 쌓이고 예측이 점점 매끄러워집니다.
- 트리 모델은 학습 때 본 정답의 범위를 벗어난 값을 예측하지 못합니다.
- 추세가 있으면 값 대신 변화량 · 변화율을 예측하게 한 뒤 되돌립니다.
