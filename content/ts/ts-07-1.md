## 시작하기 전에

[백색잡음: 더 뽑아낼 게 없는 상태](#/l/ts-03-3)에서 추세와 계절성을 빼고 남은 잔차에도 자기상관이 남아 있는 것을 봤습니다. "지난달에 평소보다 높았으면 이번 달도 평소보다 높은" 경향이었습니다. 지수평활은 이 정보를 직접 쓰지 않습니다.

이 코스에서 배울 **ARIMA**는 바로 그 자기상관을 모델로 만듭니다. ARIMA는 AR, I, MA 세 조각을 합친 이름입니다. 이번 레슨에서는 그중 두 조각인 **AR**과 **MA**를 하나씩 배웁니다.

## AR: 어제 값이 오늘에 남는다

뜨거운 커피를 책상에 두면 천천히 식습니다. 1분 뒤의 온도는 지금 온도와 아주 가깝고, 조금씩 실내 온도 쪽으로 다가갑니다. **지금 상태가 다음 상태를 대부분 결정**하는 것입니다.

**AR(자기회귀, AutoRegressive)** 모델은 이 생각을 식으로 옮긴 것입니다. 이름 그대로 "자기 자신의 과거 값으로 회귀"합니다.

**오늘 값 = c + φ × 어제 값 + 오늘의 잡음**

- φ(파이)는 어제 값이 오늘에 얼마나 남는지를 정합니다. 0.8이면 80%가 남습니다.
- c는 상수입니다.
- 어제 값 하나만 쓰면 AR(1), 어제와 그저께 두 개를 쓰면 AR(2)입니다. 괄호 안 숫자 p를 **차수**라고 합니다.

## AR(1) 손으로 예측하기

c = 2, φ = 0.8이고 오늘 값이 20이라고 하겠습니다. 내일, 모레, 글피를 차례로 예측합니다. 미래의 잡음은 알 수 없으니 0으로 둡니다.

```run
c, phi = 2, 0.8
value = 20
for step in range(1, 4):
    value = c + phi * value
    print(f"step {step}: {c} + {phi} * previous = {round(value, 2)}")
print("long-run mean = c / (1 - phi) =", round(c / (1 - phi), 1))
```

- 내일: 2 + 0.8 × 20 = 18
- 모레: 2 + 0.8 × 18 = 16.4
- 글피: 2 + 0.8 × 16.4 = 15.12

예측이 20에서 18, 16.4, 15.12로 점점 내려가며 **10을 향해 다가갑니다.** 10은 c ÷ (1 − φ) = 2 ÷ 0.2로 구한 이 시계열의 장기 평균입니다. 커피가 실내 온도로 식어 가는 것과 같습니다. AR 모델의 예측은 멀리 갈수록 평균으로 돌아갑니다.

## 직접 만들어서 맞혀 보기

같은 규칙(c = 2, φ = 0.8)에 잡음을 넣어 시계열 500개를 만들고, statsmodels의 `ARIMA`에게 φ를 알아맞혀 보라고 합니다. `order=(1, 0, 0)`은 AR(1)이라는 뜻입니다.

```run
import numpy as np
from statsmodels.tsa.arima.model import ARIMA

rng = np.random.default_rng(0)
noise = rng.normal(size=500)
x = np.zeros(500)
x[0] = 10
for t in range(1, 500):
    x[t] = 2 + 0.8 * x[t - 1] + noise[t]
print("mean of series:", round(x.mean(), 2))
fit = ARIMA(x, order=(1, 0, 0)).fit()
print("estimated phi:", round(fit.params[1], 3), "/ estimated mean:", round(fit.params[0], 2))
print("last value:", round(x[-1], 2), "-> forecasts:", fit.forecast(5).round(2).tolist())
```

모델이 추정한 φ는 0.78로, 우리가 넣은 0.8에 가깝습니다. 평균도 9.87로 장기 평균 10 근처입니다. 마지막 값이 8.97이었는데, 예측은 9.17, 9.32, 9.44 …로 평균(9.87)을 향해 조금씩 올라갑니다.

## MA: 어제의 예측 실수가 오늘에 남는다

**MA(이동평균, Moving Average)** 모델은 과거 **값**이 아니라 과거의 **예측 오차**를 씁니다. 이름이 같아서 헷갈리지만, [시계열을 이루는 세 가지](#/l/ts-02-1)에서 추세를 뽑을 때 쓴 이동평균(`rolling().mean()`)과는 다른 것입니다.

**오늘 값 = 평균 + 오늘의 잡음 + θ × 어제의 잡음**

가게에 어제 단체 손님이 예고 없이 왔다고 해 봅시다. 예상보다 많이 팔렸으니 어제의 오차는 큰 양수입니다. 그 손님 중 일부가 오늘 또 올 수 있으니 오늘도 평소보다 조금 더 팔립니다. 하지만 모레가 되면 그 영향은 사라집니다. MA(1)에서 **충격은 딱 한 칸만 남고 끝납니다.**

θ = 0.8인 MA(1) 시계열을 만들어 ACF와 PACF를 봅니다.

```run
import numpy as np
from statsmodels.tsa.stattools import acf, pacf

rng = np.random.default_rng(0)
noise = rng.normal(size=501)
ma = noise[1:] + 0.8 * noise[:-1]
print("ACF  lag 1~4:", acf(ma, nlags=4)[1:].round(2).tolist())
print("PACF lag 1~4:", pacf(ma, nlags=4)[1:].round(2).tolist())
```

ACF가 래그 1에서만 0.48이고, 래그 2부터는 −0.04, −0.06, −0.02로 **뚝 끊깁니다.** 충격이 한 칸만 남는다는 것이 그대로 드러납니다. PACF는 0.48, −0.35, 0.20, −0.15로 부호를 바꿔 가며 천천히 줄어듭니다.

[PACF: 중간을 빼고 본 직접 관계](#/l/ts-03-2)에서 본 AR(1)과 정반대입니다.

| | ACF | PACF |
| --- | --- | --- |
| AR(p) | 천천히 줄어든다 | 래그 p 뒤에서 끊긴다 |
| MA(q) | 래그 q 뒤에서 끊긴다 | 천천히 줄어든다 |

::figure{src="content/img/ts/ts07-ar-ma.svg" alt="AR은 어제의 값이 오늘 값으로 이어지고 그 영향이 오래 남아 서서히 줄어든다. MA는 어제의 잡음이 오늘 값에 한 번 더해지고 그 뒤로는 사라진다" caption="AR은 '값'이 이어지고, MA는 '충격'이 잠깐 남습니다."}

MA 모델의 예측도 확인합니다. `order=(0, 0, 1)`이 MA(1)입니다.

```run
import numpy as np
from statsmodels.tsa.arima.model import ARIMA

rng = np.random.default_rng(0)
noise = rng.normal(size=501)
ma = noise[1:] + 0.8 * noise[:-1]
fit = ARIMA(ma, order=(0, 0, 1)).fit()
print("estimated theta:", round(fit.params[1], 3))
print("last error:", round(fit.resid[-1], 2), "-> forecasts:", fit.forecast(4).round(2).tolist())
```

추정한 θ는 0.769로 0.8에 가깝습니다. 마지막 날의 오차가 1.34였으므로 내일 예측은 평균보다 높은 0.99이고, **모레부터는 평균(−0.04) 그대로**입니다. MA(1)은 한 칸 앞까지만 정보가 있습니다.

## φ를 바꿔 보기

AR(1)에서 φ의 크기에 따라 시계열의 성격이 어떻게 달라지는지 봅니다.

```run
import numpy as np

for phi in [0.2, 0.8, 1.0]:
    rng = np.random.default_rng(0)
    noise = rng.normal(size=500)
    x = np.zeros(500)
    for t in range(1, 500):
        x[t] = phi * x[t - 1] + noise[t]
    print(f"phi {phi}: std of first half {x[:250].std():5.2f}, second half {x[250:].std():5.2f}, range {x.min():6.1f} ~ {x.max():5.1f}")
```

- φ = 0.2: 어제의 영향이 금방 사라져 백색잡음에 가깝습니다. 값의 범위가 −4.0 ~ 2.9.
- φ = 0.8: 한번 올라가면 한동안 높은 데 머뭅니다. 범위가 −5.8 ~ 5.5로 넓어졌습니다.
- φ = 1.0: 범위가 −17.6 ~ 11.4로 훨씬 넓습니다. 어제의 영향이 **전혀 줄지 않고 그대로** 쌓입니다. 이것이 바로 랜덤워크입니다.

φ가 1보다 작으면 시계열은 평균으로 돌아오는 정상 시계열이고, φ가 1이면 돌아올 평균이 없는 비정상 시계열입니다. [단위근 검정: ADF와 KPSS](#/l/ts-04-3)에서 말한 "단위근이 있다"가 바로 φ = 1이라는 뜻입니다.

## ARMA: 둘을 합치기

실제 시계열에는 두 성격이 섞여 있는 경우가 많습니다. AR 항 p개와 MA 항 q개를 함께 쓰는 모델을 **ARMA(p, q)** 라고 합니다. 여기에 차분(I)까지 넣으면 ARIMA가 됩니다. 다음 레슨에서 다룹니다.

## 정리

- AR은 과거 값의 일부가 오늘에 남는 모델입니다. 예측은 멀리 갈수록 평균으로 돌아갑니다.
- MA는 과거 예측 오차(충격)의 일부가 오늘에 남는 모델입니다. q칸이 지나면 영향이 사라집니다.
- AR은 PACF가 끊기고, MA는 ACF가 끊깁니다.
- AR(1)의 φ가 1이면 랜덤워크가 됩니다.
