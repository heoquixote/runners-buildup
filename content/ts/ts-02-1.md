## 시작하기 전에

[선 그래프 읽기](#/l/da-13-1)에서 항공 승객 그래프를 연도별 평균으로 묶어 추세를 보고, 같은 달끼리 평균 내어 계절성을 봤습니다. 눈으로 "오르는 흐름이 있고, 여름마다 솟는다"를 확인한 것입니다.

이번 코스에서는 그 일을 **숫자로** 합니다. 시계열 하나를 추세, 계절성, 나머지 세 줄로 나누는 것을 **분해(decomposition)** 라고 합니다. 이 레슨에서는 분해가 무엇인지 알아보고, 이동평균만으로 직접 분해해 봅니다.

## 바닷가에서 물 높이 재기

바닷가 말뚝에 눈금을 그려 놓고 물 높이를 1분마다 적는다고 해 봅시다. 기록은 복잡하게 오르내리지만, 사실은 세 가지 움직임이 겹친 것입니다.

- **밀물과 썰물**: 몇 시간에 걸쳐 천천히 오르고 내립니다. → 추세
- **파도**: 몇 초마다 규칙적으로 오르내립니다. → 계절성
- **물보라**: 바람이나 지나가는 배 때문에 불규칙하게 튑니다. → 잔차

::figure{src="content/img/ts/ts02-components.svg" alt="복잡하게 오르내리는 선 하나가 천천히 오르는 추세선, 일정한 주기로 반복되는 계절 물결, 불규칙한 잔차 세 줄로 나뉜다" caption="시계열 = 추세 + 계절성 + 잔차. 세 줄을 다시 더하면 원래 선이 됩니다."}

| 성분 | 뜻 | 항공 승객이라면 |
| --- | --- | --- |
| 추세 (trend) | 길게 봤을 때의 방향 | 해마다 승객이 늘어남 |
| 계절성 (seasonality) | **정해진 주기**로 되풀이되는 모양 | 매년 7 ~ 8월에 많고 11월에 적음 |
| 잔차 (residual) | 추세와 계절성을 빼고 남는 것 | 파업, 날씨, 우연 |

계절성이라는 이름 때문에 봄 · 여름 · 가을 · 겨울만 떠올리기 쉽지만, **주기가 일정하면 모두 계절성**입니다. 하루 주기(출퇴근 시간), 일주일 주기(주말), 1년 주기가 모두 해당됩니다.

비슷해 보이지만 다른 것이 **순환(cycle)** 입니다. 경기 호황과 불황처럼 오르내리기는 하는데 주기가 3년일 때도 7년일 때도 있는 움직임입니다. 주기가 일정하지 않아서 계절성처럼 깔끔하게 떼어 낼 수 없고, 보통 추세에 포함해서 봅니다.

## 데이터 보기: 이산화탄소 농도

하와이 마우나로아 관측소의 주별 이산화탄소 농도입니다. 빈칸 59개는 선형 보간으로 채우고 그립니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

co2 = pd.read_csv("co2.csv", parse_dates=["date"]).set_index("date")["co2"]
print("rows:", len(co2), "/ missing:", co2.isna().sum())
co2 = co2.interpolate()
fig, ax = plt.subplots(figsize=(9, 3))
ax.plot(co2.index, co2.values, linewidth=0.8)
ax.set_ylabel("CO2 (ppm)")
print("1959 mean:", round(co2["1959"].mean(), 1), "/ 2001 mean:", round(co2["2001"].mean(), 1))
print("2000 max:", co2["2000"].idxmax().date(), round(co2["2000"].max(), 1), "/ min:", co2["2000"].idxmin().date(), round(co2["2000"].min(), 1))
```

연평균이 1959년 316.0ppm에서 2001년 370.9ppm으로 올랐습니다. 꾸준히 오르는 추세입니다. 그리고 선이 톱니처럼 잘게 떨립니다. 2000년 한 해만 보면 4월 22일에 372.0으로 가장 높고 9월 16일에 366.2로 가장 낮습니다. 북반구의 식물이 봄 · 여름에 자라면서 이산화탄소를 빨아들이고, 가을 · 겨울에 잎이 지면서 다시 내놓기 때문에 생기는 1년 주기의 물결입니다.

## 이동평균으로 추세 뽑기

추세를 뽑는 가장 간단한 방법은 **이동평균**입니다. [이동평균: 최근 며칠의 평균으로 다듬기](#/l/da-13-2)에서 톱니 같은 선을 부드럽게 만들 때 썼던 도구입니다.

여기서 중요한 것은 창의 크기입니다. **창을 계절 주기와 똑같이** 잡습니다. 주별 데이터의 1년은 52주이므로 창을 52로 잡습니다. `center=True`는 평균을 창의 한가운데 날짜에 적으라는 뜻입니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

co2 = pd.read_csv("co2.csv", parse_dates=["date"]).set_index("date")["co2"]
co2 = co2.interpolate()
trend = co2.rolling(52, center=True).mean()
fig, ax = plt.subplots(figsize=(9, 3))
ax.plot(co2.index, co2.values, color="lightgray", label="weekly")
ax.plot(trend.index, trend.values, color="crimson", label="52-week average")
ax.legend()
print(trend["1990-01"].round(2).tolist())
print("empty at each end:", trend.isna().sum())
```

빨간 선이 톱니 없이 매끄럽게 올라갑니다. 1990년 1월의 추세 값은 353.5 → 353.51 → 353.52 → 353.54로 주마다 아주 조금씩만 오릅니다. 계절 물결이 사라진 것입니다.

양 끝 51칸은 비어 있습니다. 가운데 정렬 이동평균은 앞뒤로 반 년씩 값이 있어야 계산할 수 있어서, 맨 처음 반 년과 맨 마지막 반 년은 구하지 못합니다.

## 창 크기를 바꿔 보기

창 크기가 주기와 다르면 어떻게 될까요? 창을 4주, 26주, 52주로 바꿔 가며 1990년 한 해 동안 추세선이 얼마나 오르내리는지(최대 − 최소) 비교합니다.

```run
import pandas as pd

co2 = pd.read_csv("co2.csv", parse_dates=["date"]).set_index("date")["co2"]
co2 = co2.interpolate()
for w in [4, 26, 52]:
    t = co2.rolling(w, center=True).mean()
    year = t["1990"]
    print(f"window {w:>2}: 1990 range = {year.max() - year.min():.2f}")
```

- 창 4주: 1년 사이 6.12ppm이나 오르내립니다. 계절 물결이 거의 그대로 남았습니다.
- 창 26주: 3.00ppm. 절반쯤 남았습니다.
- 창 52주: 1.48ppm. 이 정도는 1년 동안 실제로 추세가 오른 만큼입니다.

아래 셀에서 창 크기를 `[13, 52, 104]`로 바꿔서 실행해 보세요. 104주(2년)도 주기의 배수라서 계절성을 잘 지웁니다.

## 원리 한 걸음 더: 왜 주기만큼 평균 내면 계절성이 사라질까

계절 효과는 1년을 한 바퀴 돌면 **더해서 0**이 됩니다. 봄에 평소보다 높았던 만큼 가을에 낮기 때문입니다.

52주 창은 언제나 정확히 1년 치를 담습니다. 창이 어디에 놓이든 봄의 높은 값과 가을의 낮은 값이 한 번씩 다 들어가므로, 평균을 내면 계절 효과가 서로 지워지고 추세만 남습니다. 창이 26주면 높은 반년만 들어가거나 낮은 반년만 들어가는 때가 생겨서 지워지지 않습니다.

## 계절성과 잔차까지

추세를 뺀 값을 **같은 달끼리 평균** 내면 달마다의 계절 효과가 나옵니다.

```run
import pandas as pd

co2 = pd.read_csv("co2.csv", parse_dates=["date"]).set_index("date")["co2"]
co2 = co2.interpolate()
trend = co2.rolling(52, center=True).mean()
detrended = co2 - trend
season = detrended.groupby(detrended.index.month).mean()
print(season.round(2).to_dict())
```

5월이 +2.92로 가장 높고 10월이 −3.12로 가장 낮습니다. "5월에는 추세보다 약 3ppm 높고, 10월에는 약 3ppm 낮다"는 뜻입니다. 열두 달의 값을 모두 더하면 0에 가깝습니다.

마지막으로 원래 값에서 추세와 계절 효과를 모두 빼면 잔차가 남습니다. 세 성분이 각각 얼마나 크게 움직이는지 표준편차로 비교합니다.

```run
import pandas as pd

co2 = pd.read_csv("co2.csv", parse_dates=["date"]).set_index("date")["co2"]
co2 = co2.interpolate()
trend = co2.rolling(52, center=True).mean()
detrended = co2 - trend
season = detrended.groupby(detrended.index.month).transform("mean")
resid = co2 - trend - season
print("std of original:", round(co2.std(), 2))
print("std of seasonal:", round(season.std(), 2))
print("std of residual:", round(resid.std(), 2))
```

원래 값의 표준편차는 17.1(대부분 추세 때문), 계절 성분은 2.02, 잔차는 0.52입니다. 이산화탄소 농도는 **추세와 계절성만으로 거의 다 설명되는** 아주 규칙적인 시계열입니다. 잔차가 작을수록 예측하기 쉬운 데이터입니다.

## 정리

- 분해는 시계열을 추세 + 계절성 + 잔차로 나누는 일입니다.
- 계절성은 주기가 일정한 반복입니다. 하루, 일주일, 1년 모두 될 수 있습니다.
- 창 크기를 계절 주기와 같게 잡은 이동평균이 추세입니다. 한 바퀴를 평균 내면 계절 효과가 서로 지워집니다.
- 추세를 뺀 값을 같은 달끼리 평균 내면 계절성, 그것까지 빼면 잔차입니다.
