## 시작하기 전에

[기준 예측 네 가지](#/l/ts-05-1)에서 따릉이 대여 수를 예측할 때 naive(마지막 하루 값만 본다)는 운에 너무 흔들렸고, mean(전체 평균)은 1년 전 겨울 값까지 똑같이 반영했습니다. 둘 다 아쉽습니다.

그 사이 어딘가에 더 좋은 답이 있을 것 같습니다. **최근 값을 더 중요하게 보되, 과거 값도 조금씩은 반영하는** 방법입니다. 이것이 **지수평활(exponential smoothing)** 입니다. 1950년대에 나온 오래된 방법이지만, 간단하고 잘 맞아서 지금도 수요 예측 현장에서 널리 씁니다.

## 최근 기억일수록 선명하게

친구가 약속에 얼마나 늦는지 예상한다고 해 봅시다. 지난주에 20분 늦은 것은 또렷이 기억나고, 석 달 전에 5분 늦은 것은 희미합니다. 우리는 자연스럽게 **최근 일에 더 큰 비중**을 둡니다.

단순 지수평활은 이 생각을 식 하나로 옮긴 것입니다.

**새 수준 = α × 방금 본 값 + (1 − α) × 이전 수준**

- **수준(level)** 은 "지금 이 시계열이 대략 어느 높이에 있는가"에 대한 추정입니다.
- **α(알파)** 는 0과 1 사이의 숫자로, 방금 본 값을 얼마나 믿을지를 정합니다.
- 다음 값의 예측은 지금의 수준 그대로입니다.

## 손으로 계산해 보기

값이 100, 110, 90, 120 순서로 들어오고 α = 0.5라고 하겠습니다. 처음 수준은 첫 값 100으로 둡니다.

```run
values = [100, 110, 90, 120]
alpha = 0.5
level = values[0]
print(f"start: level = {level}")
for v in values[1:]:
    level = alpha * v + (1 - alpha) * level
    print(f"new value {v:>3} -> level = {alpha} * {v} + {1 - alpha} * previous = {level}")
print("forecast for next step:", level)
```

- 110이 들어오면: 0.5 × 110 + 0.5 × 100 = 105
- 90이 들어오면: 0.5 × 90 + 0.5 × 105 = 97.5
- 120이 들어오면: 0.5 × 120 + 0.5 × 97.5 = 108.75

다음 값의 예측은 108.75입니다. 새 값이 들어올 때마다 수준이 그쪽으로 **절반만** 따라갑니다.

## 왜 '지수'평활일까

마지막 수준 108.75를 풀어 쓰면 과거 값들에 가중치를 곱해 더한 것입니다. 가장 최근 값(120)에는 0.5, 그 앞(90)에는 0.25, 그 앞(110)에는 0.125가 곱해집니다.

```run
alpha = 0.5
weights = [alpha * (1 - alpha) ** k for k in range(6)]
print([round(w, 3) for w in weights])
print("sum of first 6:", round(sum(weights), 3))
```

가중치가 0.5, 0.25, 0.125 …로 **한 칸 과거로 갈 때마다 (1 − α)배씩** 줄어듭니다. 이렇게 일정한 비율로 줄어드는 것을 수학에서 지수적 감소라고 합니다. 그래서 이름이 지수평활입니다. 가중치를 모두 더하면 1에 가까워지므로(여섯 개만 더해도 0.984), 이것은 **최근에 무게를 둔 평균**입니다.

::figure{src="content/img/ts/ts06-weights.svg" alt="과거 값에 주는 가중치를 막대로 그린 세 그림. 평균은 모든 막대 높이가 같고, naive는 마지막 막대 하나만 있고, 지수평활은 최근일수록 높고 과거로 갈수록 낮아진다" caption="평균은 모두 똑같이, naive는 마지막 하나만, 지수평활은 최근일수록 크게 봅니다."}

## 따릉이 데이터로 확인하기

따릉이 일별 대여 수에 α = 0.3으로 직접 계산한 결과와 statsmodels의 `SimpleExpSmoothing` 결과를 비교합니다.

```run
import pandas as pd
from statsmodels.tsa.holtwinters import SimpleExpSmoothing

bike = pd.read_csv("seoul_bike.csv", parse_dates=["date"])
daily = bike.groupby("date")["rented_bikes"].sum().asfreq("D")
bike_ok = bike.groupby("date")["functioning_day"].apply(lambda s: (s == "Yes").any())
daily = daily.where(bike_ok).interpolate()
train = daily.iloc[:-28]
alpha = 0.3
level = train.iloc[0]
for v in train.iloc[1:]:
    level = alpha * v + (1 - alpha) * level
fit = SimpleExpSmoothing(train, initialization_method="known", initial_level=train.iloc[0]).fit(smoothing_level=alpha, optimized=False)
print("by hand    :", round(level, 1))
print("statsmodels:", round(fit.forecast(1).iloc[0], 1))
print("forecast 1, 2, 28 days ahead:", fit.forecast(28).iloc[[0, 1, 27]].round(1).tolist())
```

직접 반복문으로 구한 수준과 statsmodels의 예측이 21,833.1로 똑같습니다. 라이브러리가 하는 일이 위의 식 한 줄이라는 것을 확인했습니다.

그리고 1일 뒤, 2일 뒤, 28일 뒤 예측이 **모두 21,833.1**입니다. 단순 지수평활의 예측은 수평선입니다. 추세나 계절성은 전혀 반영하지 않습니다.

## α를 바꿔 보기

α에 따라 무엇이 달라지는지 0.1, 0.5, 0.9를 비교합니다. 그래프는 최근 60일의 실제 값과 각 α의 수준 선입니다.

```run
import matplotlib.pyplot as plt
import pandas as pd
from statsmodels.tsa.holtwinters import SimpleExpSmoothing

bike = pd.read_csv("seoul_bike.csv", parse_dates=["date"])
daily = bike.groupby("date")["rented_bikes"].sum().asfreq("D")
bike_ok = bike.groupby("date")["functioning_day"].apply(lambda s: (s == "Yes").any())
daily = daily.where(bike_ok).interpolate()
train, test = daily.iloc[:-28], daily.iloc[-28:]
fig, ax = plt.subplots(figsize=(9, 3.5))
ax.plot(train.index[-60:], train.values[-60:], color="lightgray", label="actual")
for alpha in [0.1, 0.5, 0.9]:
    fit = SimpleExpSmoothing(train, initialization_method="known", initial_level=train.iloc[0]).fit(smoothing_level=alpha, optimized=False)
    ax.plot(fit.fittedvalues.index[-60:], fit.fittedvalues.values[-60:], label=f"alpha={alpha}")
    fc = fit.forecast(28)
    print(f"alpha {alpha}: forecast = {fc.iloc[0]:.0f}, test MAE = {(test - fc).abs().mean():.0f}")
ax.legend(fontsize=8)
```

- **α = 0.1**: 선이 아주 매끄럽습니다. 새 값을 10%만 반영하니 하루하루의 출렁임에 거의 반응하지 않습니다. 시험 MAE 5,559.
- **α = 0.9**: 선이 실제 값을 거의 그대로 따라갑니다. naive에 가깝습니다. 시험 MAE 7,128.
- **α = 0.5**: 그 중간입니다.

| α | 성격 | 가까운 기준 예측 |
| --- | --- | --- |
| 0에 가까움 | 과거를 오래 기억, 변화에 느리게 반응, 매끄러움 | mean |
| 1에 가까움 | 최근만 기억, 변화에 빠르게 반응, 들쭉날쭉 | naive |

따릉이처럼 하루하루 잡음이 큰 데이터는 작은 α가 유리합니다. 아래 셀에서 α 목록을 `[0.05, 0.2, 0.3]`으로 바꿔 더 좋은 값을 찾아보세요.

## α를 자동으로 정하기

α를 직접 정하지 않고 `fit()`만 부르면, statsmodels가 학습 구간에서 한 칸 앞 예측 오차가 가장 작아지는 α를 찾아 줍니다.

```run
import pandas as pd
from statsmodels.tsa.holtwinters import SimpleExpSmoothing

bike = pd.read_csv("seoul_bike.csv", parse_dates=["date"])
daily = bike.groupby("date")["rented_bikes"].sum().asfreq("D")
bike_ok = bike.groupby("date")["functioning_day"].apply(lambda s: (s == "Yes").any())
daily = daily.where(bike_ok).interpolate()
train, test = daily.iloc[:-28], daily.iloc[-28:]
fit = SimpleExpSmoothing(train, initialization_method="estimated").fit()
fc = fit.forecast(28)
print("chosen alpha:", round(fit.params["smoothing_level"], 3))
print("forecast:", round(fc.iloc[0]), "/ test MAE:", round((test - fc).abs().mean()))
```

α = 0.224를 골랐고 시험 MAE는 5,059입니다. naive(7,254)보다는 훨씬 낫지만 mean(3,615)보다는 못합니다. 이 데이터의 마지막 28일(11월)은 날이 추워지며 대여가 줄어드는 시기인데, 수평선 예측은 그 **내려가는 추세**를 따라가지 못하기 때문입니다. 추세를 다루는 방법은 다음 레슨에서 배웁니다.

## 정리

- 단순 지수평활은 "새 수준 = α × 새 값 + (1 − α) × 이전 수준"을 반복합니다.
- 과거 값의 가중치가 (1 − α)배씩 줄어드는, 최근에 무게를 둔 평균입니다.
- α가 작으면 매끄럽고 느리게, 크면 민감하고 빠르게 반응합니다.
- 예측은 수평선이라 추세와 계절성을 따라가지 못합니다.
