## 시작하기 전에

지금까지는 마지막 24개월 한 구간만 시험용으로 썼습니다. 그런데 [K-fold 교차검증: 돌아가며 시험 보기](#/l/ml-05-1)에서 배웠듯이, **한 번의 시험에는 운이 섞입니다.** 시험 구간이 하필 유난히 예측하기 쉬운 해였을 수도, 어려운 해였을 수도 있습니다.

[시간 순서가 있는 데이터 나누기](#/l/ml-05-4)에서 시계열용 교차검증 `TimeSeriesSplit`을 한 번 써 봤습니다. 이번 레슨에서는 그 원리와 설정을 자세히 봅니다.

## 예측하는 시작점을 옮겨 가며 시험하기

시계열 교차검증의 원칙은 하나입니다. **언제나 과거로 학습하고 그 바로 뒤를 시험한다.** 시험을 여러 번 보려면 "지금"이라고 가정하는 시점을 뒤로 한 칸씩 옮기면 됩니다.

- 1955년 말에 서서 1956년을 예측한다.
- 1956년 말에 서서 1957년을 예측한다.
- 1957년 말에 서서 1958년을 예측한다. …

예측을 시작하는 시점을 **원점(origin)** 이라고 하고, 원점을 옮겨 가며 평가하는 방법을 **롤링 원점(rolling origin) 검증**이라고 합니다.

::figure{src="content/img/ts/ts05-rolling-origin.svg" alt="시간 축 위에 다섯 줄의 띠. 줄마다 학습 구간이 왼쪽에서 시작해 점점 길어지고, 그 바로 뒤에 같은 길이의 시험 구간이 붙는다. 아래쪽에는 학습 구간 길이가 고정된 채 통째로 오른쪽으로 옮겨 가는 방식" caption="위: 학습 구간이 점점 늘어나는 방식(expanding). 아래: 학습 구간 길이를 고정하고 옮겨 가는 방식(sliding)."}

## TimeSeriesSplit

scikit-learn의 `TimeSeriesSplit`이 이 나누기를 해 줍니다. `n_splits=5`는 시험을 5번, `test_size=12`는 한 번에 12개월씩 시험한다는 뜻입니다.

```run
import pandas as pd
from sklearn.model_selection import TimeSeriesSplit

df = pd.read_csv("flights.csv")
df["date"] = pd.to_datetime(df["year"].astype(str) + "-" + df["month"], format="%Y-%B")
y = df.set_index("date")["passengers"].asfreq("MS")
tscv = TimeSeriesSplit(n_splits=5, test_size=12)
for i, (tr, te) in enumerate(tscv.split(y)):
    print(f"fold {i + 1}: train {y.index[tr[0]].year}-{y.index[tr[-1]].year} ({len(tr)}) -> test {y.index[te[0]].year} ({len(te)})")
```

첫 조각은 1949 ~ 1955년(84개월)으로 학습해 1956년을 시험하고, 마지막 조각은 1949 ~ 1959년(132개월)으로 학습해 1960년을 시험합니다. 학습 구간이 12개월씩 늘어나고, 시험 구간은 언제나 학습 구간 **바로 다음 해**입니다. 미래로 과거를 맞히는 일은 한 번도 없습니다.

## 다섯 번의 시험으로 기준 예측 비교하기

naive와 seasonal naive를 다섯 조각에서 각각 평가합니다.

```run
import numpy as np
import pandas as pd
from sklearn.model_selection import TimeSeriesSplit

df = pd.read_csv("flights.csv")
df["date"] = pd.to_datetime(df["year"].astype(str) + "-" + df["month"], format="%Y-%B")
y = df.set_index("date")["passengers"].asfreq("MS")
tscv = TimeSeriesSplit(n_splits=5, test_size=12)
rows = []
for tr, te in tscv.split(y):
    train, test = y.iloc[tr], y.iloc[te]
    naive = train.iloc[-1]
    snaive = train.iloc[-12:].values
    rows.append({"test_year": test.index[0].year, "naive": np.abs(test - naive).mean(), "snaive": np.abs(test.values - snaive).mean()})
result = pd.DataFrame(rows).set_index("test_year").round(1)
print(result)
print("mean:", result.mean().round(1).to_dict())
```

다섯 해 모두 seasonal naive가 naive보다 낫습니다. 평균 MAE는 naive 66.9, seasonal naive 38.4입니다.

그런데 seasonal naive의 오차는 해마다 크게 다릅니다. 1958년은 **12.6**인데 1959년은 47.3입니다. 1958년은 미국 경기가 나빠 승객이 전년과 거의 같았던 해라서 "작년과 같다"는 예측이 유난히 잘 맞았습니다. 만약 1958년 하나만 시험했다면 "seasonal naive는 거의 완벽하다"고 착각했을 것입니다. 여러 원점에서 시험해야 하는 이유입니다.

## 학습 구간을 늘릴까, 옮길까

학습 구간을 다루는 방식은 두 가지입니다.

| | 늘려 가기 (expanding) | 옮겨 가기 (sliding) |
| --- | --- | --- |
| 학습 구간 | 처음부터 원점까지 전부 | 원점 직전 일정 기간만 |
| 장점 | 데이터를 최대한 쓴다 | 오래된 패턴에 끌려가지 않는다 |
| 알맞은 경우 | 패턴이 오래 유지되는 데이터 | 패턴이 변해 가는 데이터 |
| 설정 | 기본값 | `max_train_size=36` |

`max_train_size`를 주면 학습 구간의 최대 길이가 고정됩니다.

```run
import pandas as pd
from sklearn.model_selection import TimeSeriesSplit

df = pd.read_csv("flights.csv")
df["date"] = pd.to_datetime(df["year"].astype(str) + "-" + df["month"], format="%Y-%B")
y = df.set_index("date")["passengers"].asfreq("MS")
tscv = TimeSeriesSplit(n_splits=5, test_size=12, max_train_size=36, gap=0)
for i, (tr, te) in enumerate(tscv.split(y)):
    print(f"fold {i + 1}: train {y.index[tr[0]].strftime('%Y-%m')} ~ {y.index[tr[-1]].strftime('%Y-%m')} ({len(tr)}) -> test {y.index[te[0]].strftime('%Y-%m')} ~ {y.index[te[-1]].strftime('%Y-%m')}")
```

학습 구간이 언제나 36개월이고, 통째로 1년씩 옮겨 갑니다. 10년 전 고객의 행동이 지금과 많이 다르다면 이 방식이 더 맞을 수 있습니다.

`gap`은 학습 구간과 시험 구간 사이를 몇 칸 띄울지입니다. 아래 셀에서 `gap=0`을 `gap=3`으로 바꿔 보세요. 학습이 석 달 일찍 끝납니다. "데이터가 집계되어 들어오는 데 석 달이 걸려서, 예측하는 시점에는 최근 석 달 값을 모른다" 같은 현실 조건을 흉내 낼 때 씁니다.

## 얼마나 먼 미래인가에 따라 오차가 다르다

예측에서 "몇 칸 앞을 맞히는가"를 **예측 지평(horizon)** 이라고 합니다. 내일을 맞히는 것과 4주 뒤를 맞히는 것은 난이도가 다릅니다. 따릉이 일별 데이터에서 naive 예측의 오차를 지평별로 따로 잽니다. 원점을 하루씩 옮겨 가며 137번 시험한 평균입니다.

```run
import numpy as np
import pandas as pd

bike = pd.read_csv("seoul_bike.csv", parse_dates=["date"])
daily = bike.groupby("date")["rented_bikes"].sum().asfreq("D")
bike_ok = bike.groupby("date")["functioning_day"].apply(lambda s: (s == "Yes").any())
daily = daily.where(bike_ok).interpolate()
errors = {h: [] for h in (1, 7, 14, 28)}
for origin in range(200, len(daily) - 28):
    last = daily.iloc[origin - 1]
    for h in errors:
        errors[h].append(abs(daily.iloc[origin + h - 1] - last))
for h, e in errors.items():
    print(f"{h:>2} days ahead: naive MAE = {np.mean(e):.0f}")
```

하루 뒤 예측의 MAE는 4,627이고, 7일 뒤는 6,938, 28일 뒤는 7,258입니다. 멀수록 오차가 커집니다.

모델의 성능을 말할 때는 **"며칠 뒤 예측 기준인지"** 를 반드시 함께 말해야 합니다. "MAE 4,600"이 하루 뒤 예측이라면 naive 수준이고, 28일 뒤 예측이라면 naive보다 훨씬 좋은 것입니다. 실제로 필요한 지평(내일 배치할 자전거 수인지, 다음 달 정비 계획인지)에 맞춰 평가합니다.

## 정리

- 한 번의 시험에는 운이 섞이므로, 원점을 옮겨 가며 여러 번 시험합니다.
- `TimeSeriesSplit`은 언제나 과거로 학습하고 바로 뒤를 시험합니다.
- 학습 구간은 계속 늘리거나(expanding), `max_train_size`로 길이를 고정해 옮깁니다(sliding).
- 오차는 예측 지평에 따라 달라지므로, 필요한 지평에 맞춰 평가하고 함께 보고합니다.
