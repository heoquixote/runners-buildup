## 시작하기 전에

오늘 낮 기온이 30도였다면 내일 기온은 몇 도쯤일까요? 정확히는 몰라도 "30도 근처"라고 답할 수 있습니다. 내일 갑자기 5도가 될 것이라고 생각하는 사람은 없습니다. **오늘 값이 내일 값에 대한 정보를 담고 있기** 때문입니다.

이렇게 시계열의 값이 자기 자신의 과거 값과 닮은 정도를 **자기상관(autocorrelation)** 이라고 합니다. 예측이 가능한 이유가 바로 자기상관입니다. 이번 레슨에서는 자기상관을 재는 법과, 그것을 한눈에 보여 주는 ACF 그래프를 읽는 법을 배웁니다.

## 자기 자신을 한 칸 밀어서 비교하기

[공분산과 상관계수](#/l/st-07-1)에서 상관계수는 두 변수가 함께 움직이는 정도를 −1 ~ 1로 나타낸다고 배웠습니다. 키와 몸무게처럼 **서로 다른 두 열**을 비교했습니다.

자기상관은 비교 상대가 **자기 자신의 과거**입니다. 시계열을 한 칸 아래로 밀어 "어제 값" 열을 만들고, 원래 열과 상관계수를 구합니다. 몇 칸 밀었는지를 **래그(lag, 시차)** 라고 부릅니다.

::figure{src="content/img/ts/ts03-shift.svg" alt="같은 시계열을 한 칸 밀어 나란히 놓고, 위아래로 짝지어진 값끼리 상관계수를 구한다. 한 칸 밀면 래그 1, 일곱 칸 밀면 래그 7이다" caption="자기상관 = 원래 시계열과, 그것을 k칸 민 시계열 사이의 상관계수."}

따릉이 일별 대여 수로 해 봅니다. `shift(1)`은 어제 값, `shift(7)`은 일주일 전 값입니다.

```run
import pandas as pd

bike = pd.read_csv("seoul_bike.csv", parse_dates=["date"])
daily = bike.groupby("date")["rented_bikes"].sum().asfreq("D")
bike_ok = bike.groupby("date")["functioning_day"].apply(lambda s: (s == "Yes").any())
daily = daily.where(bike_ok).interpolate()
pair = pd.DataFrame({"today": daily, "yesterday": daily.shift(1), "week_ago": daily.shift(7)})
print(pair.head(9).round(0))
print("corr(today, yesterday):", round(pair["today"].corr(pair["yesterday"]), 3))
print("corr(today, week_ago) :", round(pair["today"].corr(pair["week_ago"]), 3))
```

12월 2일 행의 `yesterday`는 9,539로, 12월 1일의 `today` 값입니다. 한 칸씩 밀린 것을 확인할 수 있습니다. 일주일 전 값은 8일째부터 채워집니다.

- 래그 1 자기상관은 **0.80**입니다. 어제 많이 빌렸으면 오늘도 많이 빌립니다.
- 래그 7 자기상관은 **0.658**입니다. 일주일 전과도 꽤 닮았습니다.

## 래그 산점도

상관계수는 산점도로 보면 더 잘 이해됩니다. 가로축에 k일 전 값, 세로축에 오늘 값을 놓고 점을 찍습니다. 래그 1, 7, 180 세 가지를 그립니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

bike = pd.read_csv("seoul_bike.csv", parse_dates=["date"])
daily = bike.groupby("date")["rented_bikes"].sum().asfreq("D")
bike_ok = bike.groupby("date")["functioning_day"].apply(lambda s: (s == "Yes").any())
daily = daily.where(bike_ok).interpolate()
fig, axes = plt.subplots(1, 3, figsize=(11, 3.2))
for ax, k in zip(axes, [1, 7, 180]):
    ax.scatter(daily.shift(k), daily, s=8)
    r = daily.corr(daily.shift(k))
    ax.set_title(f"lag {k}: r = {r:.2f}")
    print(f"lag {k:>3}: r = {r:.2f}")
fig.tight_layout()
```

- 래그 1(r = 0.80): 점들이 오른쪽 위로 향하는 띠 모양입니다.
- 래그 7(r = 0.66): 방향은 같지만 띠가 더 퍼졌습니다.
- 래그 180(r = −0.25): 방향이 **반대**가 됐습니다. 반년 전이 여름이면 지금은 겨울이니, 그때 많이 빌렸으면 지금은 적게 빌립니다.

## ACF 그래프: 모든 래그를 한 번에

래그마다 산점도를 그릴 수는 없으니, 래그 1, 2, 3 …의 자기상관을 막대로 늘어놓은 그래프를 씁니다. 이것이 **ACF(자기상관함수) 그래프**입니다. statsmodels의 `plot_acf`가 그려 줍니다.

```run
import matplotlib.pyplot as plt
import pandas as pd
from statsmodels.graphics.tsaplots import plot_acf
from statsmodels.tsa.stattools import acf

bike = pd.read_csv("seoul_bike.csv", parse_dates=["date"])
daily = bike.groupby("date")["rented_bikes"].sum().asfreq("D")
bike_ok = bike.groupby("date")["functioning_day"].apply(lambda s: (s == "Yes").any())
daily = daily.where(bike_ok).interpolate()
fig, ax = plt.subplots(figsize=(9, 3))
plot_acf(daily, lags=30, ax=ax)
values = acf(daily, nlags=30)
print("lag 1~7  :", values[1:8].round(2).tolist())
print("lag 14, 21, 28:", values[[14, 21, 28]].round(2).tolist())
print("band: +/-", round(1.96 / len(daily) ** 0.5, 3))
```

읽는 법은 다음과 같습니다.

- 가로축은 래그, 세로축은 자기상관입니다. 래그 0은 자기 자신과의 상관이라 언제나 1입니다.
- 막대가 래그 1에서 0.80으로 시작해 래그 28에서도 0.57로 **아주 천천히 줄어듭니다.**
- 파란 띠는 "자기상관이 실제로는 0인데 우연히 나올 수 있는 범위"입니다. 대략 ±0.103입니다. 막대가 띠 밖으로 나가면 우연이 아니라고 봅니다.

막대가 이렇게 천천히 줄어드는 것은 **추세가 있다는 신호**입니다. 따릉이는 겨울에 적고 여름에 많습니다. 1년 치 데이터에서 이 느린 오르내림은 추세처럼 작용합니다. 한 달 전에도 지금과 같은 계절이었으니 값이 비슷한 것입니다.

## 계절성이 있을 때의 ACF

주기가 뚜렷한 데이터의 ACF는 다르게 생겼습니다. 2018년 6월의 **시간별** 따릉이 대여 수로 그려 봅니다.

```run
import matplotlib.pyplot as plt
import pandas as pd
from statsmodels.graphics.tsaplots import plot_acf
from statsmodels.tsa.stattools import acf

bike = pd.read_csv("seoul_bike.csv", parse_dates=["date"])
bike["ts"] = bike["date"] + pd.to_timedelta(bike["hour"], unit="h")
june = bike.set_index("ts")["rented_bikes"]["2018-06"].asfreq("h")
fig, ax = plt.subplots(figsize=(9, 3))
plot_acf(june, lags=72, ax=ax)
values = acf(june, nlags=72)
print("lag 1, 6, 12, 18, 24:", values[[1, 6, 12, 18, 24]].round(2).tolist())
print("lag 36, 48, 72:", values[[36, 48, 72]].round(2).tolist())
```

래그 1은 0.86으로 높고(한 시간 전과 비슷), 래그 12는 **−0.29**로 음수이며(낮과 밤은 반대), 래그 24는 다시 **0.60**으로 솟습니다(어제 같은 시각과 비슷). 래그 48, 72에서도 0.67, 0.61로 다시 솟습니다. **주기의 배수마다 봉우리**가 생기는 것이 계절성의 신호입니다.

항공 승객처럼 추세와 계절성이 함께 있으면 두 모양이 겹칩니다.

```run
import matplotlib.pyplot as plt
import pandas as pd
from statsmodels.graphics.tsaplots import plot_acf
from statsmodels.tsa.stattools import acf

df = pd.read_csv("flights.csv")
df["date"] = pd.to_datetime(df["year"].astype(str) + "-" + df["month"], format="%Y-%B")
y = df.set_index("date")["passengers"].asfreq("MS")
fig, ax = plt.subplots(figsize=(9, 3))
plot_acf(y, lags=36, ax=ax)
values = acf(y, nlags=36)
print("lag 1, 6, 12, 18, 24:", values[[1, 6, 12, 18, 24]].round(2).tolist())
```

전체적으로 천천히 줄어들면서(추세), 래그 12에서 0.76, 래그 24에서 0.53으로 주변(래그 6은 0.68, 래그 18은 0.47)보다 솟습니다(1년 주기).

| ACF 모양 | 뜻 |
| --- | --- |
| 천천히 줄어든다 | 추세가 있다 |
| 일정한 간격으로 솟는다 | 그 간격이 계절 주기다 |
| 물결치며 양수 · 음수를 오간다 | 주기적으로 오르내린다 |
| 래그 1부터 모두 띠 안에 있다 | 앞뒤 값이 무관하다 (예측할 패턴이 없다) |

## 원리 한 걸음 더: 직접 계산해 보기

`acf` 함수가 내놓는 값을 직접 계산해 봅니다. 평균에서 벗어난 정도(편차)를 한 칸 밀어 서로 곱해 더한 뒤, 편차 제곱의 합으로 나눕니다.

```run
import pandas as pd
from statsmodels.tsa.stattools import acf

bike = pd.read_csv("seoul_bike.csv", parse_dates=["date"])
daily = bike.groupby("date")["rented_bikes"].sum().asfreq("D")
bike_ok = bike.groupby("date")["functioning_day"].apply(lambda s: (s == "Yes").any())
daily = daily.where(bike_ok).interpolate()
k = 1
by_corr = daily.corr(daily.shift(k))
dev = (daily - daily.mean()).values
by_hand = (dev[k:] * dev[:-k]).sum() / (dev ** 2).sum()
print("corr with shift :", round(by_corr, 4))
print("by hand         :", round(by_hand, 4))
print("statsmodels acf :", round(acf(daily, nlags=k)[k], 4))
```

직접 계산한 값(0.7996)이 `acf`의 결과와 정확히 같습니다. `shift` 후 `corr`로 구한 값(0.8003)은 아주 조금 다릅니다. `corr`는 밀려서 짝이 없는 첫 행을 빼고 **남은 364쌍만의 평균과 표준편차**로 계산하고, `acf`는 **전체 365개의 평균과 분산**을 쓰기 때문입니다. 데이터가 길면 두 값은 거의 같습니다.

## 정리

- 자기상관은 시계열과, 그것을 k칸 민 자기 자신 사이의 상관계수입니다. k를 래그라고 합니다.
- ACF 그래프는 래그별 자기상관을 막대로 늘어놓은 것입니다.
- ACF가 천천히 줄어들면 추세, 일정한 간격으로 솟으면 계절성입니다.
- 파란 띠 안의 막대는 우연으로 볼 수 있는 크기입니다.
