## 시작하기 전에

[ARIMA(p, d, q) 정하기](#/l/ts-07-2)에서는 계절성을 미리 차분으로 없앤 뒤 ARIMA를 썼습니다. 이번 레슨에서는 계절성까지 모델 안에 넣는 **SARIMA**를 배웁니다. 맨 앞의 S는 Seasonal(계절)입니다.

그리고 항공 승객 데이터로 [Holt-Winters: 계절까지](#/l/ts-06-3)의 기록(MAPE 6.4%)과 겨뤄 봅니다.

## 숫자가 일곱 개로 늘어난다

SARIMA는 숫자 묶음이 두 개입니다.

**SARIMA (p, d, q) (P, D, Q)ₛ**

| 묶음 | 보는 간격 | 뜻 |
| --- | --- | --- |
| (p, d, q) | 바로 앞 칸 (지난달) | 지금까지 배운 ARIMA |
| (P, D, Q) | 한 주기 앞 칸 (작년 같은 달) | 같은 일을 계절 간격으로 |
| s | | 계절 주기 (월별 데이터는 12) |

대문자 쪽은 소문자 쪽과 하는 일이 같고, **간격만 s칸**입니다.

- D = 1: 계절 차분을 한 번 한다. `diff(12)`
- P = 1: 작년 같은 달의 **값**을 쓴다.
- Q = 1: 작년 같은 달의 **예측 오차**를 쓴다.

## 항공 승객 모델

항공 승객 데이터에는 아주 유명한 모델이 있습니다. 이 데이터를 처음 분석한 박스와 젠킨스가 쓴 **(0, 1, 1)(0, 1, 1)₁₂** 로, "항공 모델(airline model)"이라는 별명이 있습니다. 하나씩 풀어 보면 지금까지 배운 것들입니다.

- 먼저 **로그**를 씌웁니다. 곱셈형이기 때문입니다. ([덧셈 분해와 곱셈 분해](#/l/ts-02-2))
- d = 1, D = 1: 1차 차분과 계절 차분을 한 번씩 합니다. [단위근 검정: ADF와 KPSS](#/l/ts-04-3)에서 이 조합으로 ADF p-값이 0.0002가 됐습니다.
- q = 1: 지난달의 예측 오차를 씁니다.
- Q = 1: 작년 같은 달의 예측 오차를 씁니다.

[차분과 로그로 정상 만들기](#/l/ts-04-2)에서 로그 + 두 차분 뒤에 래그 1(−0.34)과 래그 12(−0.39)에 음의 자기상관이 남아 있었습니다. 그 둘을 MA 항 두 개(q = 1, Q = 1)가 각각 맡는 것입니다.

계절 모델은 `SARIMAX` 클래스로 만듭니다. `order`에 (p, d, q), `seasonal_order`에 (P, D, Q, s)를 줍니다.

```run
import numpy as np
import pandas as pd
import warnings
from statsmodels.tsa.statespace.sarimax import SARIMAX

df = pd.read_csv("flights.csv")
df["date"] = pd.to_datetime(df["year"].astype(str) + "-" + df["month"], format="%Y-%B")
y = df.set_index("date")["passengers"].asfreq("MS")
train, test = y.iloc[:-24], y.iloc[-24:]
warnings.filterwarnings("ignore")
model = SARIMAX(np.log(train), order=(0, 1, 1), seasonal_order=(0, 1, 1, 12))
fit = model.fit(disp=False)
print(fit.summary().tables[1])
print("AIC:", round(fit.aic, 1))
```

`ma.L1`(지난달 오차의 계수)은 −0.3424, `ma.S.L12`(작년 같은 달 오차의 계수)는 −0.5404입니다. 둘 다 p-값이 0.000이라 필요한 항입니다.

## 예측하고 원래 단위로 되돌리기

로그 값으로 학습했으므로 예측도 로그 값으로 나옵니다. **`np.exp`로 되돌려야** 승객 수가 됩니다. `get_forecast`는 예측값과 예측 구간을 함께 줍니다.

```run
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
import warnings
from statsmodels.tsa.statespace.sarimax import SARIMAX

df = pd.read_csv("flights.csv")
df["date"] = pd.to_datetime(df["year"].astype(str) + "-" + df["month"], format="%Y-%B")
y = df.set_index("date")["passengers"].asfreq("MS")
train, test = y.iloc[:-24], y.iloc[-24:]
warnings.filterwarnings("ignore")
fit = SARIMAX(np.log(train), order=(0, 1, 1), seasonal_order=(0, 1, 1, 12)).fit(disp=False)
pred = fit.get_forecast(24)
fc = np.exp(pred.predicted_mean)
band = np.exp(pred.conf_int(alpha=0.1))
fig, ax = plt.subplots(figsize=(9, 3.5))
ax.plot(train.index[-36:], train.values[-36:], color="gray", label="train")
ax.plot(test.index, test.values, color="black", label="actual")
ax.plot(fc.index, fc.values, color="crimson", linestyle="--", label="SARIMA")
ax.fill_between(fc.index, band.iloc[:, 0], band.iloc[:, 1], color="crimson", alpha=0.2)
ax.legend()
print("log forecast, first 3:", pred.predicted_mean.iloc[:3].round(3).tolist())
print("back to passengers  :", fc.iloc[:3].round(1).tolist(), "/ actual:", test.iloc[:3].tolist())
print("MAPE:", round(((test - fc).abs() / test).mean() * 100, 1), "%")
print("inside 90% interval:", int(((test >= band.iloc[:, 0]) & (test <= band.iloc[:, 1])).sum()), "of 24")
```

- 로그 예측 5.854, 5.804, 5.948을 `exp`로 되돌리면 348.6, 331.6, 383.2천 명입니다. 실제는 360, 342, 406이었습니다.
- MAPE는 **8.5%** 입니다. seasonal naive(15.5%)보다는 훨씬 좋지만 Holt-Winters(6.4%)보다는 못합니다.
- 실제 값 24개가 모두 90% 구간 안에 들었습니다.

되돌리기를 잊고 로그 값을 그대로 실제 값과 비교하면 오차가 엉뚱하게 나옵니다. 변환해서 학습했을 때 가장 흔한 실수입니다.

## 잔차 점검

```run
import numpy as np
import pandas as pd
import warnings
from statsmodels.stats.diagnostic import acorr_ljungbox
from statsmodels.tsa.statespace.sarimax import SARIMAX
from statsmodels.tsa.stattools import acf

df = pd.read_csv("flights.csv")
df["date"] = pd.to_datetime(df["year"].astype(str) + "-" + df["month"], format="%Y-%B")
y = df.set_index("date")["passengers"].asfreq("MS")
train, test = y.iloc[:-24], y.iloc[-24:]
warnings.filterwarnings("ignore")
fit = SARIMAX(np.log(train), order=(0, 1, 1), seasonal_order=(0, 1, 1, 12)).fit(disp=False)
resid = fit.resid.iloc[13:]
print("residual ACF lag 1, 2, 12:", acf(resid, nlags=12)[[1, 2, 12]].round(2).tolist())
print("Ljung-Box p (lag 12):", round(acorr_ljungbox(resid, lags=[12])["lb_pvalue"].iloc[0], 3))
```

잔차의 자기상관이 래그 1에서 0.01, 래그 2에서 0.04, 래그 12에서 −0.05로 거의 0입니다. Ljung-Box p-값은 **0.912**로 백색잡음 검정을 넉넉히 통과합니다. 모델이 데이터의 자기상관을 남김없이 가져갔습니다.

처음 13개 잔차를 뺀 이유는, 차분(1칸)과 계절 차분(12칸) 때문에 모델이 맨 앞 13개월은 제대로 예측할 수 없어서입니다.

## Holt-Winters와 공정하게 겨루기

한 구간에서 8.5% 대 6.4%로 Holt-Winters가 이겼습니다. 하지만 [시간 순서대로 검증하기: 롤링 원점](#/l/ts-05-3)에서 배웠듯 한 번의 시험에는 운이 섞입니다. 원점을 다섯 번 옮겨 가며 12개월 예측을 비교합니다.

```run
import numpy as np
import pandas as pd
import warnings
from sklearn.model_selection import TimeSeriesSplit
from statsmodels.tsa.holtwinters import ExponentialSmoothing
from statsmodels.tsa.statespace.sarimax import SARIMAX

df = pd.read_csv("flights.csv")
df["date"] = pd.to_datetime(df["year"].astype(str) + "-" + df["month"], format="%Y-%B")
y = df.set_index("date")["passengers"].asfreq("MS")
warnings.filterwarnings("ignore")
rows = []
for tr, te in TimeSeriesSplit(n_splits=5, test_size=12).split(y):
    train, test = y.iloc[tr], y.iloc[te]
    mape = lambda fc: float((np.abs(test.values - np.asarray(fc)) / test.values).mean() * 100)
    hw = ExponentialSmoothing(train, trend="add", seasonal="mul", seasonal_periods=12, initialization_method="estimated").fit().forecast(12)
    sa = np.exp(SARIMAX(np.log(train), order=(0, 1, 1), seasonal_order=(0, 1, 1, 12)).fit(disp=False).forecast(12))
    rows.append({"year": test.index[0].year, "snaive": mape(train.iloc[-12:].values), "holt_winters": mape(hw), "sarima": mape(sa)})
result = pd.DataFrame(rows).set_index("year").round(1)
print(result)
print("mean:", result.mean().round(1).to_dict())
```

| 시험 연도 | seasonal naive | Holt-Winters | SARIMA |
| --- | --- | --- | --- |
| 1956 | 13.5 | 2.8 | **1.7** |
| 1957 | 10.8 | 3.7 | **1.7** |
| 1958 | **3.1** | 4.2 | 7.6 |
| 1959 | 11.1 | **4.8** | 6.8 |
| 1960 | 10.0 | **2.2** | 2.9 |
| 평균 | 9.7 | **3.5** | 4.1 |

- 두 모델 모두 seasonal naive(9.7%)를 크게 앞섭니다.
- 1956, 1957년은 SARIMA가, 1959, 1960년은 Holt-Winters가 낫습니다. 평균은 Holt-Winters 3.5%, SARIMA 4.1%로 비슷합니다.
- 1958년은 **seasonal naive가 가장 좋습니다**(3.1%). 경기가 나빠 승객이 전년과 거의 같았던 해입니다. 두 모델은 "늘 그랬듯 올해도 늘 것"이라고 예측했다가 틀렸습니다. 과거 패턴이 깨지는 해에는 정교한 모델이 오히려 더 크게 틀릴 수 있습니다.

**항상 이기는 모델은 없습니다.** 그래서 실무에서는 여러 모델을 같은 조건에서 비교하고, 성능이 비슷하면 더 단순하고 설명하기 쉬운 쪽을 고릅니다.

| | Holt-Winters | SARIMA |
| --- | --- | --- |
| 생각의 출발 | 수준 · 추세 · 계절을 직접 추적 | 차분으로 정상화한 뒤 자기상관을 모델링 |
| 정할 것 | 덧셈/곱셈, 감쇠 여부 | 숫자 일곱 개 |
| 장점 | 직관적이고 설정이 적다 | 잔차 진단 등 통계적 점검 도구가 많다, 바깥 변수를 넣을 수 있다 |

## 정리

- SARIMA (p, d, q)(P, D, Q)ₛ의 대문자 묶음은 같은 일을 계절 간격으로 합니다.
- 항공 모델은 로그 뒤에 (0, 1, 1)(0, 1, 1)₁₂를 쓰며, 24개월 예측 MAPE는 8.5%입니다.
- 로그로 학습했으면 예측을 `exp`로 되돌립니다.
- 다섯 원점에서 비교하면 Holt-Winters 3.5%, SARIMA 4.1%로 비슷하고, 해마다 승자가 다릅니다.
