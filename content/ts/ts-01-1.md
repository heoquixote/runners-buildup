[시간 순서가 있는 데이터 다루기](#/l/da-08-1)에서 `pd.to_datetime`으로 글자를 날짜로 바꾸고 `resample`로 시간 단위를 묶었습니다. [센서 시계열 다듬기](#/l/da-08-3)에서는 빠진 시각을 `ffill`과 `interpolate`로 채웠습니다.

이번 레슨에서는 한 걸음 더 나아가, 시계열 모델에 넣기 전에 꼭 확인해야 하는 한 가지를 배웁니다. **기록이 일정한 간격으로 빠짐없이 있는가**입니다.

## 시계열 모델은 눈금이 고른 자를 가정한다

시계열 분석에서는 "한 칸 전 값", "일곱 칸 전 값" 같은 말을 계속 씁니다. 일별 데이터에서 한 칸 전은 어제, 일곱 칸 전은 지난주 같은 요일입니다.

그런데 중간에 며칠 기록이 빠져 있으면 어떻게 될까요? 수요일 다음 행이 토요일이면, "한 칸 전"이 어제가 아니라 사흘 전이 됩니다. "일곱 칸 전"도 더 이상 같은 요일이 아닙니다. 눈금 몇 개가 지워진 자로 길이를 재는 것과 같습니다.

::figure{src="content/img/ts/ts01-ruler.svg" alt="눈금이 고른 자에서는 한 칸이 언제나 하루지만, 눈금이 빠진 자에서는 한 칸이 하루일 때도 사흘일 때도 있다" caption="칸이 고르지 않으면 '한 칸 전'의 뜻이 행마다 달라집니다."}

그래서 시계열 분석의 첫 단계는 언제나 **간격을 확인하고 고르게 만드는 것**입니다.

## 빈도 확인하기

따릉이 시간별 기록에서 운영한 날만 골라 하루 합계를 구합니다. 그리고 날짜 인덱스의 `freq`(빈도)를 확인합니다.

```run
import pandas as pd

bike = pd.read_csv("seoul_bike.csv", parse_dates=["date"])
open_days = bike[bike["functioning_day"] == "Yes"]
daily = open_days.groupby("date")["rented_bikes"].sum()
print(daily.head(3))
print("rows:", len(daily), "/ freq:", daily.index.freq)
```

행은 353개이고 `freq`는 `None`입니다. pandas가 "이 인덱스는 간격이 일정하다고 보장할 수 없다"고 말하는 것입니다. 1년은 365일인데 353행뿐이니 12일이 빠져 있습니다.

어디가 빠졌는지는 이웃한 날짜의 차이를 세어 보면 알 수 있습니다. `diff()`로 바로 앞 날짜와의 차이를 구하고 `value_counts()`로 종류별 개수를 셉니다.

```run
import pandas as pd

bike = pd.read_csv("seoul_bike.csv", parse_dates=["date"])
daily = bike[bike["functioning_day"] == "Yes"].groupby("date")["rented_bikes"].sum()
gaps = daily.index.to_series().diff().value_counts()
print(gaps)
```

차이가 하루인 곳이 341번, 이틀인 곳이 10번, 사흘인 곳이 1번입니다. 이틀 차이는 하루가 빠졌다는 뜻이고, 사흘 차이는 이틀이 연달아 빠졌다는 뜻입니다. 10 + 2 = 12일이 맞습니다.

## asfreq: 빠진 칸을 드러내기

`asfreq("D")`는 인덱스를 **하루 간격으로 빠짐없이** 다시 깔아 줍니다. 원래 없던 날짜는 값이 빈칸(NaN)인 행으로 생깁니다. 숨어 있던 구멍이 눈에 보이게 되는 것입니다.

```run
import pandas as pd

bike = pd.read_csv("seoul_bike.csv", parse_dates=["date"])
daily = bike[bike["functioning_day"] == "Yes"].groupby("date")["rented_bikes"].sum()
full = daily.asfreq("D")
print("rows:", len(full), "/ freq:", full.index.freq)
print("missing days:", full.isna().sum())
print(full[full.isna()].index.strftime("%m-%d").tolist())
```

행이 365개가 되고 `freq`가 `<Day>`로 바뀌었습니다. 빈칸 12개의 날짜도 나옵니다. 9월 18일과 19일이 연달아 빠진 곳이 아까 본 "사흘 차이"입니다.

자주 쓰는 빈도 글자는 다음과 같습니다.

| 글자 | 뜻 | 예 |
| --- | --- | --- |
| `min` | 분 | `"5min"` = 5분 간격 |
| `h` | 시간 | 설비 온도 1시간 평균 |
| `D` | 일 | 따릉이 일별 합계 |
| `W` | 주(일요일 끝) | 주간 매출 |
| `MS` | 월(매달 1일) | 항공 승객 |

## 빈칸을 무엇으로 채울까

빈칸을 채우는 방법은 여러 가지이고, **값의 종류에 따라** 맞는 방법이 다릅니다. 9월 18 ~ 19일 주변을 세 가지 방법으로 채워서 비교합니다.

```run
import pandas as pd

bike = pd.read_csv("seoul_bike.csv", parse_dates=["date"])
daily = bike[bike["functioning_day"] == "Yes"].groupby("date")["rented_bikes"].sum()
full = daily.asfreq("D")
view = pd.DataFrame({"raw": full, "ffill": full.ffill(), "linear": full.interpolate(), "zero": full.fillna(0)})
print(view.loc["2018-09-16":"2018-09-21"].round(0))
```

- `ffill`은 바로 앞 값(30,290)을 그대로 복사합니다. 17일은 유난히 대여가 많은 날이었는데, 그 값이 이틀 더 반복됩니다.
- `linear`(선형 보간)는 앞뒤 값을 직선으로 이어 24,954, 19,618로 채웁니다. 완만하게 이어집니다.
- `zero`는 0으로 채웁니다. 실제로 이 날은 운영을 안 해서 대여가 0이었으니, 사실에는 가장 가깝습니다.

어느 것이 정답일까요? **무엇을 하려는지**에 달려 있습니다.

| 하려는 일 | 알맞은 채우기 | 이유 |
| --- | --- | --- |
| 실제 대여량 합계 내기 | 0 | 운영을 안 했으니 실제로 0이다 |
| "평소 수요"를 예측하는 모델 만들기 | 선형 보간 | 0을 넣으면 모델이 "수요가 갑자기 사라지는 날"을 패턴으로 배운다 |
| 온도 · 압력 같은 상태값 | 선형 보간 또는 ffill | 상태는 갑자기 0이 되지 않고 이어진다 |

이 트랙에서 따릉이 수요를 예측할 때는 보간한 값을 쓰겠습니다.

## 센서 데이터의 간격 확인

5분마다 기록된다는 설비 온도 데이터도 정말 5분 간격인지 같은 방법으로 확인합니다.

```run
import pandas as pd

m = pd.read_csv("machine_temp.csv", parse_dates=["timestamp"]).set_index("timestamp")["temp"]
print(m.head(3))
print(m.index.to_series().diff().value_counts().head(3))
print("inferred freq:", pd.infer_freq(m.index[:100]), "/ duplicated stamps:", m.index.duplicated().sum())
hourly = m.resample("h").mean()
print("hourly rows:", len(hourly), "/ missing:", hourly.isna().sum())
```

거의 모든 간격이 5분이지만, 한 곳은 차이가 **−55분**입니다(`-1 days +23:05:00`은 하루를 빼고 23시간 5분을 더했다는 표기입니다). 시각이 55분 뒤로 돌아갔다는 뜻이고, 그래서 같은 시각이 두 번 찍힌 행이 12개 있습니다. 기록 장치의 시계가 다시 맞춰질 때 실제 센서 데이터에서 흔히 생기는 일입니다.

`resample("h").mean()`은 같은 시간대에 든 값을 모두 평균 내므로, 겹친 시각도 자연스럽게 정리됩니다. 1시간 평균으로 바꾸면 1,891행이고 빈칸은 없습니다. 앞으로 설비 온도는 이 1시간 평균을 주로 씁니다.

## 원리 한 걸음 더: 왜 굳이 freq를 붙일까

`freq`가 붙은 인덱스는 "다음 칸이 언제인지"를 알고 있습니다. 그래서 statsmodels의 예측 함수가 미래 날짜를 스스로 만들어 붙여 줍니다. `freq`가 없으면 모델은 경고를 내고 예측 결과에 날짜 대신 0, 1, 2 같은 번호를 붙입니다. 모델에 넣기 전 `asfreq`를 한 번 하는 습관을 들이면 이런 문제를 피할 수 있습니다.

## 정리

- 시계열 분석은 기록이 일정한 간격으로 빠짐없이 있다고 가정합니다.
- `index.to_series().diff().value_counts()`로 간격이 고른지 확인합니다.
- `asfreq`로 빠진 칸을 빈칸으로 드러낸 다음, 값의 종류와 목적에 맞게 채웁니다.
- 센서 데이터는 `resample`로 시간 단위를 묶으면 겹치거나 어긋난 시각이 함께 정리됩니다.
