## 시작하기 전에

지금까지는 시계열의 **평소 모습**을 이해하고 예측했습니다. 이번 코스에서는 반대로 **평소와 다른 순간**을 찾습니다. 설비가 고장 나기 전의 낌새, 결제 시스템의 장애, 센서 오류를 데이터에서 잡아내는 일입니다. 이것을 **이상 탐지(anomaly detection)** 라고 합니다.

[센서 시계열 다듬기](#/l/da-08-3)에서 튀는 값을 `diff`와 이동 중앙값으로 찾아봤고, [관리도의 원리와 I-MR 관리도](#/l/st-11-1)에서는 평균 ± 3σ 관리선을 벗어나는 점을 이상으로 봤습니다. 이번 레슨에서는 이상의 종류를 정리하고, 실제 설비 데이터에 두 가지 경보 규칙을 적용해 비교합니다.

## 이상의 세 종류

::figure{src="content/img/ts/ts09-anomaly-types.svg" alt="이상의 세 종류. 점 이상은 한 점만 혼자 크게 튄다. 맥락 이상은 값 자체는 평범하지만 그 시각에는 나올 수 없는 값이다. 집단 이상은 하나하나는 평범한 값이 길게 이어져 평소 모양과 달라진다" caption="같은 '이상'이라도 종류에 따라 잡는 방법이 다릅니다."}

| 종류 | 뜻 | 예 | 잡는 방법 |
| --- | --- | --- | --- |
| 점 이상 | 한 값이 전체 범위를 크게 벗어난다 | 온도 센서가 순간 0을 기록 | 고정된 한계선 |
| 맥락 이상 | 값 자체는 흔하지만 **그 상황에서는** 이상하다 | 퇴근 시간인데 대여가 새벽 수준 | 계절성을 빼고 본다 |
| 집단 이상 | 하나하나는 정상 범위인데 **이어지는 모양**이 이상하다 | 온도가 며칠째 조금씩 낮게 유지된다 | 누적해서 본다 |

이번 레슨은 점 이상, 다음 레슨은 맥락 이상, 그다음 레슨은 집단 이상을 다룹니다.

## 데이터 보기: 고장이 기록된 설비

산업 설비 안쪽 부품의 온도를 1시간 평균으로 묶어 그립니다. 빨간 점선은 데이터 제공자가 알려 준 **이상 시점 네 곳**입니다.

```run
import matplotlib.pyplot as plt
import pandas as pd

m = pd.read_csv("machine_temp.csv", parse_dates=["timestamp"]).set_index("timestamp")["temp"]
hourly = m.resample("h").mean()

labels = pd.to_datetime(["2013-12-11 06:00", "2013-12-16 17:00", "2014-01-28 13:00", "2014-02-08 14:00"])
fig, ax = plt.subplots(figsize=(10, 3.5))
ax.plot(hourly.index, hourly.values, linewidth=0.7)
for t in labels:
    ax.axvline(t, color="crimson", linestyle="--", linewidth=1)
print("mean:", round(hourly.mean(), 1), "/ std:", round(hourly.std(), 1))
for t in labels:
    window = hourly[t - pd.Timedelta("24h"): t + pd.Timedelta("24h")]
    print(f"{t:%Y-%m-%d %H:%M}: lowest within a day = {window.min():5.1f}")
```

평소 온도는 평균 85.9, 표준편차 13.7입니다. 네 시점 근처에서 온도가 얼마나 떨어졌는지 보면 차이가 큽니다.

- 12월 16일: **20.6**까지 급락
- 2월 8일: **27.0**까지 급락 (설비의 치명적 고장)
- 12월 11일: 49.3 (계획된 정지)
- 1월 28일: 52.2 (나중에 큰 고장으로 이어진, 눈에 덜 띄는 이상)

앞의 둘은 그래프에서 바로 보이지만 뒤의 둘은 평소의 작은 출렁임과 구분하기 어렵습니다.

## 방법 1: 고정된 한계선

가장 간단한 규칙은 관리도와 같습니다. 전체 평균에서 표준편차의 3배 넘게 벗어나면 경보를 울립니다. 값을 **z-점수**(평균에서 표준편차의 몇 배 떨어졌는가)로 바꿔 −3보다 작은 시간을 찾습니다.

```run
import pandas as pd

m = pd.read_csv("machine_temp.csv", parse_dates=["timestamp"]).set_index("timestamp")["temp"]
hourly = m.resample("h").mean()
z = (hourly - hourly.mean()) / hourly.std()
alarm = z < -3
print("lower limit:", round(hourly.mean() - 3 * hourly.std(), 1))
print("alarm hours:", int(alarm.sum()))
print("alarm days :", sorted(set(alarm[alarm].index.strftime("%m-%d"))))
```

한계선은 44.9입니다. 경보는 38시간이고, 날짜로는 12월 16일, 2월 8일, 2월 9일 사흘뿐입니다. **모두 실제 이상이 있던 날**입니다. 헛경보가 하나도 없습니다.

대신 49.3까지만 떨어진 12월 11일과 52.2까지만 떨어진 1월 28일은 한계선(44.9)에 닿지 않아 놓쳤습니다. 큰 이상 둘은 정확히 잡고, 작은 이상 둘은 놓친 것입니다.

## 방법 2: 움직이는 기준 (이동 z-점수)

고정된 한계선은 평소 수준이 변하는 데이터에는 쓸 수 없습니다. 여름과 겨울의 기온처럼요. 그럴 때는 **최근 구간의 평균과 표준편차**를 기준으로 삼습니다.

**이동 z-점수 = (지금 값 − 지난 24시간 평균) ÷ 지난 24시간 표준편차**

[시계열을 표로 바꾸기](#/l/ts-08-1)에서 배운 대로 `shift(1)`을 먼저 해서 지금 값이 기준에 섞이지 않게 합니다.

```run
import pandas as pd

m = pd.read_csv("machine_temp.csv", parse_dates=["timestamp"]).set_index("timestamp")["temp"]
hourly = m.resample("h").mean()
past = hourly.shift(1).rolling(24)
z = (hourly - past.mean()) / past.std()
alarm = z.abs() > 3
days = sorted(set(alarm[alarm].index.strftime("%m-%d")))
print("alarm hours:", int(alarm.sum()), "/ alarm days:", len(days), "of", len(hourly.resample("D").size()))
print(days[:10], "...")
```

경보가 123시간, 날짜로는 **80일 중 46일**입니다. 이틀에 한 번 넘게 울립니다. 이런 경보는 아무도 믿지 않게 됩니다.

## 이동 z-점수는 왜 이렇게 많이 울릴까

두 장면을 들여다봅니다.

```run
import pandas as pd

m = pd.read_csv("machine_temp.csv", parse_dates=["timestamp"]).set_index("timestamp")["temp"]
hourly = m.resample("h").mean()
past = hourly.shift(1).rolling(24)
view = pd.DataFrame({"temp": hourly, "past_mean": past.mean(), "past_std": past.std()})
view["z"] = (view["temp"] - view["past_mean"]) / view["past_std"]
print(view.loc["2014-01-02 09:00":"2014-01-02 13:00"].round(2))
print(view.loc["2013-12-16 20:00":"2013-12-16 23:00"].round(2))
```

**첫 번째 장면(1월 2일 9시)**: 온도가 69.84로 내려가자 z가 −5.52가 됐습니다. 직전 24시간이 아주 안정적이어서 표준편차가 4.77밖에 안 됐기 때문입니다. **조용한 구간 뒤에서는 작은 움직임도 큰 z-점수가 됩니다.** 69.84는 이 설비에서 흔한 값인데도 경보가 울렸습니다.

**두 번째 장면(12월 16일 밤)**: 온도가 20까지 떨어졌다가 100으로 회복한 직후입니다. 온도는 정상인 100인데, 지난 24시간 평균이 56.63으로 내려앉아 있어서 z가 **+2.40**입니다. 정상으로 돌아온 값을 오히려 "높은 쪽 이상"에 가깝다고 봅니다. **이상 구간이 기준 자체를 오염**시킨 것입니다.

| | 고정 한계선 | 이동 z-점수 |
| --- | --- | --- |
| 기준 | 전체 기간의 평균 · 표준편차 | 최근 구간의 평균 · 표준편차 |
| 알맞은 데이터 | 평소 수준이 일정하다 (정상 시계열) | 평소 수준이 천천히 변한다 |
| 약점 | 수준이 변하면 쓸 수 없다 | 조용한 구간 뒤에 과민하고, 이상이 기준을 오염시킨다 |

이 설비는 정상 가동 중에 온도가 일정한 수준 주변에 머뭅니다. [단위근 검정: ADF와 KPSS](#/l/ts-04-3)에서 정상 가동 구간이 정상 시계열로 판정됐던 것을 떠올려 보세요. 그래서 단순한 고정 한계선이 더 잘 맞습니다.

## 창과 한계값 바꿔 보기

이동 z-점수의 창 크기와 한계값을 바꾸면 경보 수가 어떻게 변하는지 봅니다.

```run
import pandas as pd

m = pd.read_csv("machine_temp.csv", parse_dates=["timestamp"]).set_index("timestamp")["temp"]
hourly = m.resample("h").mean()
for window, limit in [(24, 3), (24, 5), (72, 3), (72, 5), (168, 4)]:
    past = hourly.shift(1).rolling(window)
    z = (hourly - past.mean()) / past.std()
    alarm = z.abs() > limit
    days = sorted(set(alarm[alarm].index.strftime("%m-%d")))
    print(f"window {window:>3}h, limit {limit}: {int(alarm.sum()):>3} hours on {len(days):>2} days")
```

창을 넓히고(72시간, 168시간) 한계값을 높일수록(5) 경보가 줄어듭니다. 168시간 창에 한계값 4로는 12시간, 3일까지 줄어듭니다. 아래 셀의 목록에 `(336, 4)`를 넣어 보세요. 다만 경보를 줄이면 놓치는 이상도 함께 늘어납니다. 이 줄다리기를 숫자로 따지는 법은 다음 레슨에서 배웁니다.

## 정리

- 이상에는 점 이상, 맥락 이상, 집단 이상 세 종류가 있습니다.
- 평소 수준이 일정한 데이터는 고정 한계선(평균 ± 3σ)이 간단하고 헛경보가 적습니다.
- 이동 z-점수는 수준이 변하는 데이터에 쓰지만, 조용한 구간 뒤에 과민하고 이상이 기준을 오염시킵니다.
- 이 설비 데이터에서 고정 한계선은 큰 이상 둘을 헛경보 없이 잡았고, 작은 이상 둘은 놓쳤습니다.
