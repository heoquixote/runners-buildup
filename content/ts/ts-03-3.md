## 시작하기 전에

지금까지는 시계열에서 패턴을 **찾는** 법을 배웠습니다. 이번에는 반대로 **패턴이 전혀 없는** 시계열을 봅니다. 아무 패턴이 없는 시계열을 **백색잡음(white noise)** 이라고 합니다.

백색잡음을 따로 배우는 이유는 이것이 **목표 지점**이기 때문입니다. 좋은 모델은 데이터에서 패턴을 모두 뽑아내고, 뽑아낼 것이 없는 찌꺼기만 남깁니다. 남은 것이 백색잡음인지 확인하는 것이 모델 점검의 기본입니다.

## 백색잡음과 랜덤워크

**백색잡음**은 매번 주사위를 새로 던지는 것과 같습니다.

- 평균이 0 근처에서 일정하고
- 흔들리는 폭이 일정하고
- 앞에 나온 값이 다음 값에 **아무 영향도 주지 않습니다.**

**랜덤워크(random walk)** 는 백색잡음을 **계속 더해 나간** 것입니다. 술 취한 사람이 한 걸음마다 왼쪽이나 오른쪽으로 무작위로 발을 내딛는 모습에서 나온 이름입니다. 한 걸음 한 걸음은 무작위지만, 지금 위치는 지난 걸음들이 모두 쌓인 결과입니다.

같은 난수 500개로 두 가지를 만들어 비교합니다. `cumsum()`은 누적 합입니다.

```run
import matplotlib.pyplot as plt
import numpy as np
from statsmodels.tsa.stattools import acf

rng = np.random.default_rng(3)
white = rng.normal(size=500)
walk = white.cumsum()
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(10, 3))
ax1.plot(white, linewidth=0.7)
ax1.set_title("White noise")
ax2.plot(walk)
ax2.set_title("Random walk")
print("white ACF lag 1~5:", acf(white, nlags=5)[1:].round(2).tolist())
print("walk  ACF lag 1~5:", acf(walk, nlags=5)[1:].round(2).tolist())
print("band: +/-", round(1.96 / 500 ** 0.5, 3))
```

- 백색잡음의 ACF는 −0.03, 0.02, −0.01 …로 모두 띠(±0.088) 안에 있습니다. 어제 값을 알아도 오늘 값을 짐작할 수 없습니다.
- 랜덤워크의 ACF는 0.99, 0.98, 0.97 …로 매우 높고 천천히 줄어듭니다. [어제가 오늘을 말해 준다: 자기상관과 ACF](#/l/ts-03-1)에서 본 **추세가 있는 시계열**의 모양과 같습니다.

::figure{src="content/img/ts/ts03-white-vs-walk.svg" alt="백색잡음은 0 주변에서 일정한 폭으로 떨리고, 그 값을 누적해 더한 랜덤워크는 한쪽으로 흘러가는 추세처럼 보인다" caption="같은 난수라도 그대로 놓으면 백색잡음, 누적해서 더하면 랜덤워크입니다."}

## 랜덤워크의 가짜 추세

랜덤워크 그래프는 뚜렷하게 오르거나 내리는 것처럼 보입니다. 하지만 그것은 진짜 추세가 아닙니다. 난수의 씨앗만 바꿔서 다섯 번 만들어 봅니다.

```run
import numpy as np

for seed in range(5):
    walk = np.random.default_rng(seed).normal(size=500).cumsum()
    print(f"seed {seed}: end = {walk[-1]:6.1f}, highest = {walk.max():5.1f}, lowest = {walk.min():6.1f}")
```

같은 규칙으로 만들었는데 어떤 것은 −26.7로 끝나고 어떤 것은 +27.5로 끝납니다. 방향이 그때그때 다릅니다. 랜덤워크의 "추세"는 **우연히 쌓인 결과**일 뿐이라, 지금까지 올랐다고 해서 앞으로도 오른다는 보장이 전혀 없습니다.

주가나 환율이 랜덤워크에 가깝다고 알려져 있습니다. 주가 그래프에서 패턴이 보이는 것 같아도 예측이 어려운 이유입니다. 랜덤워크에 대한 가장 좋은 예측은 **"내일 값 = 오늘 값"** 입니다. 변화량이 백색잡음이라 더 알 수 있는 것이 없기 때문입니다.

## Ljung-Box 검정: 숫자로 판정하기

ACF 막대가 띠 안에 있는지 눈으로 보는 대신, 검정 하나로 판정할 수 있습니다. **Ljung-Box(융-박스) 검정**은 여러 래그의 자기상관을 한꺼번에 모아서 따집니다.

[가설검정의 논리와 p-value](#/l/st-05-1)에서 배운 순서 그대로입니다.

- 귀무가설: 래그 1부터 k까지 **자기상관이 모두 0이다** (백색잡음이다).
- p-값이 0.05보다 작으면 귀무가설을 기각합니다. → 자기상관이 있다, 패턴이 남아 있다.
- p-값이 크면 기각하지 못합니다. → 백색잡음이 아니라는 증거가 없다.

방금 만든 백색잡음과 항공 승객 데이터에 각각 적용합니다. `lags=[10]`은 래그 10까지 모아서 본다는 뜻입니다.

```run
import numpy as np
import pandas as pd
from statsmodels.stats.diagnostic import acorr_ljungbox

df = pd.read_csv("flights.csv")
df["date"] = pd.to_datetime(df["year"].astype(str) + "-" + df["month"], format="%Y-%B")
y = df.set_index("date")["passengers"].asfreq("MS")
rng = np.random.default_rng(3)
white = rng.normal(size=500)
print(acorr_ljungbox(white, lags=[10]).round(3))
print(acorr_ljungbox(y, lags=[10]).round(3))
```

- 백색잡음: p-값 **0.885**. 자기상관이 있다는 증거가 없습니다.
- 항공 승객: p-값 **0.0**(검정 통계량 857). 자기상관이 매우 뚜렷합니다.

이 검정은 방향이 헷갈리기 쉽습니다. 보통 검정에서는 p-값이 작게 나오길 기대하지만, 모델의 잔차를 점검할 때는 **p-값이 크게 나와야 좋은 것**입니다. "남은 패턴이 없다"가 우리가 바라는 결과이기 때문입니다.

## 분해하고 남은 잔차는 백색잡음일까

[STL과 여러 겹의 계절성](#/l/ts-02-3)에서 추세와 계절성을 빼고 남은 잔차에도 패턴이 남아 있는지 확인해 봅니다.

```run
import numpy as np
import pandas as pd
from statsmodels.stats.diagnostic import acorr_ljungbox
from statsmodels.tsa.seasonal import STL
from statsmodels.tsa.stattools import acf

df = pd.read_csv("flights.csv")
df["date"] = pd.to_datetime(df["year"].astype(str) + "-" + df["month"], format="%Y-%B")
y = df.set_index("date")["passengers"].asfreq("MS")

bike = pd.read_csv("seoul_bike.csv", parse_dates=["date"])
daily = bike.groupby("date")["rented_bikes"].sum().asfreq("D")
bike_ok = bike.groupby("date")["functioning_day"].apply(lambda s: (s == "Yes").any())
daily = daily.where(bike_ok).interpolate()
r1 = STL(np.log(y), period=12).fit().resid
r2 = STL(daily, period=7).fit().resid
print("flights STL residual p:", round(acorr_ljungbox(r1, lags=[12])["lb_pvalue"].iloc[0], 4))
print("bike STL residual p   :", round(acorr_ljungbox(r2, lags=[14])["lb_pvalue"].iloc[0], 4))
print("flights residual ACF lag 1~3:", acf(r1, nlags=3)[1:].round(2).tolist())
```

두 데이터 모두 p-값이 0.0입니다. **잔차가 백색잡음이 아닙니다.** 항공 승객 잔차의 래그 1 자기상관은 0.24입니다. 추세와 계절성을 빼고도 "지난달에 평소보다 높았으면 이번 달도 평소보다 높은" 경향이 남아 있다는 뜻입니다.

이것은 나쁜 소식이 아닙니다. **아직 예측에 써먹을 정보가 남아 있다**는 뜻이니까요. 분해는 추세와 계절성만 떼어 낼 뿐, 잔차 안의 자기상관까지 다루지는 않습니다. 이 남은 자기상관을 모델로 만드는 것이 뒤에서 배울 [AR과 MA: 과거 값과 과거 오차로 예측](#/l/ts-07-1)입니다.

## 정리

- 백색잡음은 평균과 흔들림이 일정하고 자기상관이 없는 시계열입니다. 예측할 패턴이 없습니다.
- 랜덤워크는 백색잡음을 누적한 것으로, 추세처럼 보이지만 방향은 우연입니다.
- Ljung-Box 검정의 귀무가설은 "자기상관이 없다"입니다. 잔차를 점검할 때는 p-값이 커야 좋습니다.
- 모델의 잔차가 백색잡음이 아니면 아직 뽑아낼 정보가 남았다는 뜻입니다.
