## 시작하기 전에

[어제가 오늘을 말해 준다: 자기상관과 ACF](#/l/ts-03-1)에서 따릉이 일별 대여 수의 래그 1 자기상관이 0.80, 래그 2가 0.70이었습니다. 그러면 **그저께 값이 오늘 값에 직접 영향을 준다**고 말할 수 있을까요?

그렇지 않을 수도 있습니다. 그저께가 어제에 영향을 주고, 어제가 오늘에 영향을 주면, 그저께와 오늘은 직접 관계가 없어도 닮게 됩니다. 이번 레슨에서는 이런 "건너서 전해진 영향"을 걷어 내고 **직접 관계만** 보는 PACF를 배웁니다.

## 소문은 건너서도 퍼진다

지수가 민호에게 소문을 전하고, 민호가 서연에게 전했습니다. 지수와 서연은 서로 말을 한 적이 없지만 둘이 아는 내용은 비슷합니다. 겉으로만 보면 "지수와 서연은 관계가 깊다"고 착각할 수 있습니다.

::figure{src="content/img/ts/ts03-rumor.svg" alt="그저께 값이 어제 값을 거쳐 오늘 값에 전해지는 경로와, 그저께 값이 오늘 값에 직접 닿는 경로. ACF는 두 경로를 합쳐서 보고 PACF는 직접 경로만 본다" caption="ACF는 건너서 온 영향까지 모두 합친 것, PACF는 중간을 거치지 않은 직접 영향만 남긴 것입니다."}

- **ACF**: 지수와 서연이 얼마나 비슷한 말을 하는가. 민호를 거쳐 전해진 것까지 모두 포함합니다.
- **PACF(편자기상관)**: 민호가 전한 내용을 빼고도 지수와 서연 사이에 **따로 주고받은 것**이 있는가.

래그 2의 PACF는 "어제 값을 이미 알고 있을 때, 그저께 값이 오늘 값에 대해 **추가로** 알려 주는 것이 있는가"를 잽니다.

## 직접 만든 시계열로 확인하기

정답을 아는 데이터로 확인하는 것이 가장 확실합니다. **오늘 값 = 0.8 × 어제 값 + 무작위 잡음**이라는 규칙으로 시계열 500개를 만듭니다. 이 규칙에는 그저께 값이 들어 있지 않습니다. 오직 어제만 오늘에 직접 영향을 줍니다.

```run
import numpy as np
from statsmodels.tsa.stattools import acf, pacf

def make_ar1(phi, n=500, seed=0):
    rng = np.random.default_rng(seed)
    noise = rng.normal(size=n)
    x = np.zeros(n)
    for t in range(1, n):
        x[t] = phi * x[t - 1] + noise[t]
    return x
x = make_ar1(0.8)
print("ACF  lag 1~5:", acf(x, nlags=5)[1:].round(2).tolist())
print("0.8 ** k    :", [round(0.8 ** k, 2) for k in range(1, 6)])
print("PACF lag 1~5:", pacf(x, nlags=5)[1:].round(2).tolist())
```

- ACF는 0.78, 0.61, 0.47 …로 천천히 줄어듭니다. 0.8, 0.8², 0.8³ …(0.8, 0.64, 0.51)과 거의 같습니다. 어제의 영향이 0.8이니, 그저께의 영향은 어제를 거쳐 0.8 × 0.8 = 0.64만큼 전해지는 것입니다.
- PACF는 래그 1에서 0.78이고, **래그 2부터는 0.00, −0.02, 0.06으로 뚝 끊깁니다.** 그저께 값은 어제를 거쳐서만 전해질 뿐, 직접 주는 영향은 없다는 것을 정확히 짚어 냅니다.

두 그래프를 나란히 그립니다.

```run
import matplotlib.pyplot as plt
import numpy as np
from statsmodels.graphics.tsaplots import plot_acf, plot_pacf

def make_ar1(phi, n=500, seed=0):
    rng = np.random.default_rng(seed)
    noise = rng.normal(size=n)
    x = np.zeros(n)
    for t in range(1, n):
        x[t] = phi * x[t - 1] + noise[t]
    return x
phi = 0.8
x = make_ar1(phi)
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(10, 3))
plot_acf(x, lags=15, ax=ax1)
plot_pacf(x, lags=15, ax=ax2)
print("phi =", phi, "/ std of series:", round(x.std(), 2))
```

왼쪽 ACF는 계단처럼 서서히 내려가고, 오른쪽 PACF는 래그 1만 우뚝 서 있고 나머지는 파란 띠 안에 있습니다.

이 셀에서 `phi = 0.8`을 `0.3`으로 바꿔 실행해 보세요. ACF가 훨씬 빨리 0에 가까워집니다. 어제의 영향이 약하면 건너서 전해지는 영향은 더 빨리 사라집니다. `-0.8`로 바꾸면 ACF가 양수와 음수를 번갈아 오갑니다.

## 원리 한 걸음 더: PACF는 회귀 계수다

래그 2의 PACF는 사실 **오늘 값을 어제 값과 그저께 값 두 개로 회귀했을 때, 그저께 값에 붙는 계수**입니다. [특성을 여러 개 쓰면](#/l/ml-02-4)에서 배운 다중 선형회귀의 계수는 "다른 특성이 같을 때 이 특성이 한 단위 늘면"이라는 뜻이었습니다. 어제 값을 고정했을 때 그저께 값의 효과가 바로 PACF입니다.

numpy의 `lstsq`로 직접 회귀해서 확인합니다.

```run
import numpy as np
from statsmodels.tsa.stattools import pacf

def make_ar1(phi, n=500, seed=0):
    rng = np.random.default_rng(seed)
    noise = rng.normal(size=n)
    x = np.zeros(n)
    for t in range(1, n):
        x[t] = phi * x[t - 1] + noise[t]
    return x
x = make_ar1(0.8)
X = np.column_stack([np.ones(len(x) - 2), x[1:-1], x[:-2]])
coef = np.linalg.lstsq(X, x[2:], rcond=None)[0]
print("regression coef on lag 1, lag 2:", coef[1:].round(3).tolist())
print("pacf lag 2 (ols)               :", round(pacf(x, nlags=2, method="ols")[2], 3))
```

회귀 계수는 어제 0.778, 그저께 0.004입니다. 그저께의 계수 0.004가 `pacf` 함수의 래그 2 값과 같습니다. 그리고 어제의 계수 0.778은 우리가 데이터를 만들 때 쓴 0.8에 가깝습니다.

## 실제 데이터의 PACF

따릉이 일별 대여 수의 ACF와 PACF를 나란히 봅니다.

```run
import pandas as pd
from statsmodels.tsa.stattools import acf, pacf

bike = pd.read_csv("seoul_bike.csv", parse_dates=["date"])
daily = bike.groupby("date")["rented_bikes"].sum().asfreq("D")
bike_ok = bike.groupby("date")["functioning_day"].apply(lambda s: (s == "Yes").any())
daily = daily.where(bike_ok).interpolate()
print("ACF  lag 1~8:", acf(daily, nlags=8)[1:].round(2).tolist())
print("PACF lag 1~8:", pacf(daily, nlags=8)[1:].round(2).tolist())
```

ACF는 0.80, 0.70, 0.67 …로 래그 8까지 계속 높습니다. PACF는 래그 1이 0.80이고 그 뒤로는 0.17, 0.20, 0.29, 0.13 …으로 훨씬 작습니다. 높은 ACF의 대부분은 **어제를 거쳐 전해진 것**이었습니다.

다만 직접 만든 시계열처럼 깔끔하게 끊기지는 않습니다. 래그 2 ~ 4의 PACF(0.17 ~ 0.29)는 띠(±0.103) 밖에 있습니다. 실제 수요에는 어제뿐 아니라 며칠 전의 직접 영향도 조금씩 남아 있다는 뜻입니다.

## ACF와 PACF는 언제 쓰나

| | ACF | PACF |
| --- | --- | --- |
| 재는 것 | k칸 전과 닮은 정도 (건너온 것 포함) | 중간을 빼고 k칸 전이 직접 주는 영향 |
| 주로 읽는 것 | 추세 · 계절성이 있는가 | 과거 몇 칸까지 모델에 넣어야 하는가 |

PACF가 래그 p에서 끊기면 "과거 p칸의 값만 있으면 충분하다"는 뜻입니다. 이 성질은 [ARIMA(p, d, q) 정하기](#/l/ts-07-2)에서 모델의 크기를 정할 때 그대로 씁니다.

## 정리

- ACF에는 중간 값을 거쳐 전해진 영향이 섞여 있습니다.
- PACF는 중간 래그의 영향을 빼고 남은 직접 관계입니다.
- "오늘 = 0.8 × 어제 + 잡음"인 시계열은 ACF가 0.8, 0.64, 0.51 …로 천천히 줄고, PACF는 래그 1에서만 높습니다.
- PACF가 끊기는 래그는 모델에 넣을 과거 값의 개수를 알려 줍니다.
