## 시작하기 전에

지금까지는 그래프와 구간별 평균을 보고 "정상인 것 같다", "아닌 것 같다"를 판단했습니다. 눈으로 하는 판단은 사람마다 다를 수 있습니다. 이번 레슨에서는 정상성을 **검정으로 판정**하는 방법 두 가지, ADF와 KPSS를 배웁니다.

두 검정 모두 [가설검정의 논리와 p-value](#/l/st-05-1)에서 배운 방식 그대로입니다. 귀무가설을 세우고, p-값이 0.05보다 작으면 기각합니다. 주의할 점은 **두 검정의 귀무가설이 서로 반대**라는 것입니다.

## 두 검정은 묻는 방향이 반대다

| | ADF 검정 | KPSS 검정 |
| --- | --- | --- |
| 귀무가설 | 정상이 **아니다** (단위근이 있다) | 정상**이다** |
| p < 0.05이면 | 귀무가설 기각 → **정상이다** | 귀무가설 기각 → **정상이 아니다** |
| p가 크면 | 정상이라는 증거가 없다 | 정상이 아니라는 증거가 없다 |
| 함수 | `adfuller` | `kpss` |

**단위근(unit root)** 은 "랜덤워크처럼, 한 번 받은 충격이 사라지지 않고 계속 쌓이는 성질"을 뜻합니다. [백색잡음: 더 뽑아낼 게 없는 상태](#/l/ts-03-3)에서 본 랜덤워크가 단위근이 있는 대표적인 시계열입니다. ADF 검정은 "이 시계열이 랜덤워크 같은가?"를 묻는 검정이라고 생각하면 됩니다.

::figure{src="content/img/ts/ts04-adf-kpss.svg" alt="ADF 검정은 비정상이라고 가정하고 시작해 증거가 충분하면 정상으로 판정하고, KPSS 검정은 정상이라고 가정하고 시작해 증거가 충분하면 비정상으로 판정한다" caption="두 검정은 출발점이 반대입니다. p-값이 작을 때의 결론도 반대가 됩니다."}

## ADF 검정

항공 승객 원본에 ADF 검정을 합니다. `adfuller`는 값을 여러 개 돌려주는데, 그중 검정 통계량, p-값, 기준값을 봅니다.

```run
import pandas as pd
from statsmodels.tsa.stattools import adfuller

df = pd.read_csv("flights.csv")
df["date"] = pd.to_datetime(df["year"].astype(str) + "-" + df["month"], format="%Y-%B")
y = df.set_index("date")["passengers"].asfreq("MS")
stat, p, used_lag, n, crit, _ = adfuller(y)
print("statistic:", round(stat, 3))
print("p-value  :", round(p, 3))
print("5% critical value:", round(crit["5%"], 3))
```

p-값이 **0.992**입니다. 0.05보다 훨씬 크므로 "정상이 아니다"라는 귀무가설을 기각하지 못합니다. 정상이라는 증거가 없습니다.

검정 통계량으로도 읽을 수 있습니다. 통계량(0.815)이 5% 기준값(−2.884)보다 **작아야**(더 큰 음수여야) 정상으로 판정합니다. 0.815는 한참 못 미칩니다.

## 변환 단계별로 검정하기

[차분과 로그로 정상 만들기](#/l/ts-04-2)의 다섯 단계에 차례로 ADF 검정을 합니다.

```run
import numpy as np
import pandas as pd
from statsmodels.tsa.stattools import adfuller

df = pd.read_csv("flights.csv")
df["date"] = pd.to_datetime(df["year"].astype(str) + "-" + df["month"], format="%Y-%B")
y = df.set_index("date")["passengers"].asfreq("MS")
log_y = np.log(y)
steps = {"original": y, "log": log_y, "log + diff(1)": log_y.diff(), "log + diff(12)": log_y.diff(12), "log + diff(12) + diff(1)": log_y.diff(12).diff()}
for name, s in steps.items():
    print(f"{name:>25}: ADF p = {adfuller(s.dropna())[1]:.4f}")
```

- 원본 0.9919, 로그 0.4224: 정상이 아닙니다. 로그는 흔들림만 고르게 할 뿐 추세는 그대로이기 때문입니다.
- 로그 + 1차 차분 0.0711, 로그 + 계절 차분 0.0724: 0.05에 가깝지만 넘지 못했습니다.
- 로그 + 계절 차분 + 1차 차분 **0.0002**: 정상으로 판정합니다.

앞 레슨에서 그래프와 ACF로 내린 결론과 같습니다.

## KPSS를 함께 보기

ADF 검정에는 약점이 있습니다. 데이터가 짧으면 실제로 정상인데도 p-값이 크게 나오는 일이 잦습니다. "정상이라는 증거가 없다"가 곧 "정상이 아니다"는 아니기 때문입니다. 그래서 방향이 반대인 KPSS 검정을 함께 봅니다.

```run
import numpy as np
import pandas as pd
import warnings
from statsmodels.tsa.stattools import adfuller, kpss

df = pd.read_csv("flights.csv")
df["date"] = pd.to_datetime(df["year"].astype(str) + "-" + df["month"], format="%Y-%B")
y = df.set_index("date")["passengers"].asfreq("MS")
warnings.filterwarnings("ignore")
log_y = np.log(y)
steps = {"original": y, "log + diff(1)": log_y.diff(), "log + diff(12) + diff(1)": log_y.diff(12).diff()}
for name, s in steps.items():
    s = s.dropna()
    print(f"{name:>25}: ADF p = {adfuller(s)[1]:.3f} | KPSS p = {kpss(s, nlags='auto')[1]:.3f}")
```

statsmodels의 KPSS는 p-값을 0.01 ~ 0.10 범위로만 알려 줍니다. 0.010은 "0.01 이하", 0.100은 "0.10 이상"이라는 뜻입니다.

- 원본: ADF 0.992(정상 증거 없음), KPSS 0.010(정상 아님). 두 검정이 **한목소리로 비정상**이라고 합니다.
- 로그 + 계절 차분 + 1차 차분: ADF 0.000(정상), KPSS 0.100(정상 아니라는 증거 없음). 두 검정이 **한목소리로 정상**이라고 합니다.
- 로그 + 1차 차분: ADF 0.071, KPSS 0.100. ADF는 "정상이라고 하기엔 증거가 조금 모자라다", KPSS는 "정상이 아니라는 증거가 없다"입니다. 이럴 때는 그래프와 ACF를 다시 봅니다. 앞 레슨에서 본 것처럼 계절성이 남아 있었습니다.

| ADF | KPSS | 결론 |
| --- | --- | --- |
| p < 0.05 | p ≥ 0.05 | 정상 |
| p ≥ 0.05 | p < 0.05 | 정상 아님 → 차분한다 |
| p ≥ 0.05 | p ≥ 0.05 | 판단하기 어렵다 (데이터가 짧거나 애매함) → 그래프와 ACF로 판단 |
| p < 0.05 | p < 0.05 | 서로 엇갈린다 → 차분해서 다시 검정 |

## 다른 데이터에도 해 보기

성질을 이미 아는 시계열과 실제 데이터에 두 검정을 함께 적용합니다.

```run
import numpy as np
import pandas as pd
import warnings
from statsmodels.tsa.stattools import adfuller, kpss

m = pd.read_csv("machine_temp.csv", parse_dates=["timestamp"]).set_index("timestamp")["temp"]
hourly = m.resample("h").mean()

bike = pd.read_csv("seoul_bike.csv", parse_dates=["date"])
daily = bike.groupby("date")["rented_bikes"].sum().asfreq("D")
bike_ok = bike.groupby("date")["functioning_day"].apply(lambda s: (s == "Yes").any())
daily = daily.where(bike_ok).interpolate()
warnings.filterwarnings("ignore")
rng = np.random.default_rng(3)
white = pd.Series(rng.normal(size=500))
series = {"white noise": white, "random walk": white.cumsum(), "bike daily": daily, "bike daily diff": daily.diff().dropna(), "machine hourly (Jan 1-20)": hourly["2014-01-01":"2014-01-20"]}
for name, s in series.items():
    print(f"{name:>25}: ADF p = {adfuller(s)[1]:.3f} | KPSS p = {kpss(s, nlags='auto')[1]:.3f}")
```

- 백색잡음: ADF 0.000, KPSS 0.100 → 정상.
- 랜덤워크: ADF 0.918, KPSS 0.010 → 정상 아님. 두 검정이 정확히 구분합니다.
- 따릉이 일별: ADF 0.486, KPSS 0.010 → 정상 아님. 계절에 따라 수준이 크게 달라지기 때문입니다.
- 따릉이 일별 1차 차분: 정상.
- 설비 온도(1월 1 ~ 20일, 정상 가동 구간): 정상. 설비가 안정적으로 돌아갈 때의 센서 값은 일정한 수준 주변에서 떨립니다. 이 성질은 [이상의 세 종류와 이동 z-점수](#/l/ts-09-1)에서 이상을 찾는 근거가 됩니다.

## 검정을 쓸 때 주의할 점

- **검정은 보조 도구**입니다. 그래프, 구간별 평균, ACF를 먼저 보고 검정은 확인용으로 씁니다.
- ADF 검정은 **계절성을 잘 잡아내지 못합니다.** 계절성만 있고 추세가 없는 시계열은 ADF가 "정상"이라고 답할 수 있습니다. 계절성은 ACF의 주기적인 봉우리로 따로 확인합니다.
- 설비 정지 같은 큰 이상 구간이 섞이면 검정 결과가 흔들립니다. 그런 구간은 빼고 검정합니다.

## 정리

- ADF의 귀무가설은 "정상이 아니다", KPSS의 귀무가설은 "정상이다"로 서로 반대입니다.
- ADF는 p가 작아야, KPSS는 p가 커야 정상입니다.
- 항공 승객은 원본의 ADF p-값이 0.992이고, 로그 + 계절 차분 + 1차 차분 후 0.0002가 됩니다.
- 두 검정이 엇갈리거나 애매하면 그래프와 ACF로 판단합니다.
