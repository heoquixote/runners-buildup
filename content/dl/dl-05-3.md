## 시작하기 전에

앞 레슨에서 **합성곱**은 작은 필터로 사진을 훑어 특징 맵을 만드는 계산이고, 필터는 학습되며, 스트라이드·패딩으로 출력 크기가 정해진다고 했습니다.

이번 레슨에서 배울 것

- 풀링: 특징 맵 요약하기
- CNN 전체 구조: 블록을 쌓아 분류하기
- 층이 깊어질수록 더 넓게 본다(수용 영역)
- 대표적인 CNN 모델과 공장에서의 쓰임

## 풀링: 썸네일 만들기

휴대폰 사진첩의 작은 썸네일만 봐도 무슨 사진인지 대충 압니다. 세부는 사라졌지만 중요한 특징은 남아 있기 때문입니다. **풀링(pooling)**은 특징 맵의 썸네일을 만드는 일입니다.

가장 많이 쓰는 **최대 풀링(max pooling)**은 특징 맵을 2 × 2 구역으로 나눠 **구역마다 가장 큰 값 하나만** 남깁니다.

::figure{src="content/img/dl/dl05-pooling.svg" alt="4×4 특징 맵을 색으로 구분한 2×2 구역 네 개로 나누고, 구역별 최댓값 4, 2, 2, 5만 남겨 2×2 결과를 만든다" caption="구역마다 가장 큰 값만 남기면 가로·세로가 절반이 됩니다. 학습할 가중치는 없습니다."}

손으로 따라가 봅시다. 4 × 4 특징 맵이

| 1열 | 2열 | 3열 | 4열 |
| --- | --- | --- | --- |
| 1 | 3 | 2 | 0 |
| 4 | 2 | 1 | 1 |
| 0 | 1 | 5 | 2 |
| 2 | 1 | 3 | 4 |

일 때, 2 × 2 구역 네 개의 최댓값은

- 왼쪽 위 (1, 3, 4, 2) → **4**
- 오른쪽 위 (2, 0, 1, 1) → **2**
- 왼쪽 아래 (0, 1, 2, 1) → **2**
- 오른쪽 아래 (5, 2, 3, 4) → **5**

결과는 2 × 2 = [[4, 2], [2, 5]]입니다.

## 풀링이 주는 것

- **크기가 줄어 계산이 가벼워집니다.** 2 × 2 풀링(스트라이드 2)이면 가로·세로가 각각 절반, 면적은 1/4입니다.
- **작은 위치 변화에 둔감해집니다.** 특징이 한 칸 옆으로 밀려도 같은 구역 안이면 최댓값은 그대로입니다. "정확히 어느 픽셀인지"보다 "이 근처에 있다"가 중요할 때 유리합니다.
- **학습할 가중치가 없습니다.** 최댓값을 고르는 규칙일 뿐이라 파라미터가 0개입니다.

구역 평균을 내는 **평균 풀링**도 있지만, 중간층에서는 "특징이 강하게 나타났는가"를 보존하는 최대 풀링을 더 많이 씁니다.

## CNN 전체 구조

CNN은 이 부품들을 블록으로 묶어 쌓습니다.

::figure{src="content/img/dl/dl05-cnn-pipeline.svg" alt="입력 사진 → 합성곱+ReLU → 풀링 → 합성곱+ReLU → 풀링 → 펼치기와 완전연결 층 → 불량 0.97. 뒤로 갈수록 격자 크기는 작아지고 겹친 장 수(필터 수)는 늘어난다" caption="[합성곱 → ReLU → 풀링] 블록을 여러 번 쌓아 특징을 뽑고, 마지막에 펼쳐서 완전연결 층과 출력층으로 판단합니다."}

1. **특징 뽑기 부분**: [합성곱 → ReLU → 풀링] 블록을 여러 번 반복합니다. 블록을 지날수록 격자 크기(가로·세로)는 줄고, 필터 수(특징 맵 장 수)는 늘어납니다. 예: 224 × 224 × 3 → 112 × 112 × 64 → 56 × 56 × 128 → …
2. **판단 부분**: 충분히 작아진 특징 맵을 한 줄로 펼쳐 MLP(완전연결 층)에 넣고, 출력층(dl-04-1의 세트)에서 결과를 냅니다. 불량/정상이면 시그모이드, 불량 유형 5종이면 소프트맥스.

앞 레슨에서 걱정한 "펼치면 가중치 폭발" 문제는 이제 없습니다. 펼치는 시점엔 이미 격자가 아주 작아졌기 때문입니다.

## 깊어질수록 더 넓게 본다

3 × 3 필터 하나는 사진의 3 × 3 영역만 봅니다. 그런데 그 결과 위에 또 3 × 3 필터를 쓰면, 두 번째 층의 한 칸은 원래 사진의 5 × 5 영역을 본 셈입니다. 중간에 풀링까지 있으면 더 빨리 넓어집니다. 한 칸이 원래 사진에서 보는 범위를 **수용 영역(receptive field)**이라고 합니다.

그래서 dl-00-1의 그림처럼 **앞 층은 좁게(선 · 점), 뒤 층은 넓게(모양 → 부품 → 물체)** 봅니다. 작은 필터를 깊이 쌓는 것만으로 작은 무늬부터 큰 구조까지 단계적으로 보게 됩니다.

## 대표적인 CNN 모델

| 모델 | 해 | 한 줄 설명 |
| --- | --- | --- |
| LeNet | 1998 | 손글씨 숫자 인식. 합성곱 → 풀링 → 완전연결의 원형 |
| AlexNet | 2012 | 이미지 대회 압승(dl-00-2의 부활). ReLU · 드롭아웃 · GPU 학습 |
| VGG | 2014 | 3 × 3 필터만 깊게 쌓는 단순하고 규칙적인 구조 |
| ResNet | 2015 | 잔차 연결(지름길, dl-03-3)로 100층 이상을 학습 |

지금은 이들을 바탕으로 한 더 효율적인 모델이나, 사진을 조각내 Transformer(DAY 08)로 보는 모델도 많이 씁니다. 하지만 "작은 영역을 보고 → 모아서 → 판단한다"는 CNN의 생각은 그대로 이어집니다.

## 공장에서의 CNN

| 쓰임 | 입력 | 출력 |
| --- | --- | --- |
| 외관 불량 검사 | 부품·기판 사진 | 정상 / 불량 (또는 불량 유형) |
| 불량 위치 찾기 | 사진 | 긁힘이 있는 사각형 위치 |
| 웨이퍼 맵 분류 | 웨이퍼의 불량 칩 배치 그림 | 불량 패턴 종류(가장자리형, 중심형 …) |

사람이 눈으로 하던 검사를 대신하거나 보조하는 데 많이 씁니다. 실제로는 불량 사진이 적은 경우가 많아서, DAY 10의 **전이 학습**과 dl-04-3의 **데이터 증강**을 함께 씁니다.

## 자주 하는 오해

- **"풀링 층에도 학습되는 가중치가 많다."** 풀링은 최댓값(또는 평균)을 고르는 정해진 규칙이라 학습할 가중치가 **없습니다.** 가중치는 합성곱 필터와 완전연결 층에 있습니다.
- **"CNN은 사진에만 쓴다."** 격자 모양에서 '이웃'이 의미 있는 데이터면 다 씁니다. 소리를 시간 × 주파수 그림으로 바꾼 것, 센서 시계열(1차원 합성곱)에도 씁니다.

## 정리

- **최대 풀링**은 구역마다 가장 큰 값만 남겨 크기를 절반으로 줄이고, 작은 위치 변화에 둔감하게 만듭니다. 가중치는 없습니다. 예: 4 × 4 → [[4, 2], [2, 5]].
- CNN = [합성곱 → ReLU → 풀링] 블록 반복(특징 뽑기) + 펼치기 → 완전연결 → 출력층(판단).
- 깊어질수록 **수용 영역**이 넓어져 선 → 모양 → 물체 순으로 봅니다.
- LeNet → AlexNet → VGG → ResNet으로 발전했고, 공장에서는 외관 불량 검사에 많이 씁니다.
