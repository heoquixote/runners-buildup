## 시작하기 전에

앞 DAY에서 사진처럼 **격자 모양** 데이터는 CNN이 작은 창으로 훑어 본다고 했습니다. 이번에는 **순서가 있는 데이터**입니다.

이번 레슨에서 배울 것

- 순서가 의미를 갖는 데이터(시퀀스)
- MLP로는 왜 불편한가
- RNN: 메모를 넘기며 한 칸씩 읽기
- 시간 순서로 펼쳐 보기와 입출력 모양 세 가지

## 순서가 바뀌면 뜻이 바뀐다

두 문장을 비교해 보세요.

- "개가 사람을 물었다."
- "사람이 개를 물었다."

쓰인 단어는 똑같은데 뜻이 완전히 다릅니다. **순서가 의미의 일부**입니다. 이렇게 순서가 중요한 데이터를 **시퀀스(sequence)** 또는 순차 데이터라고 부릅니다.

| 데이터 | 순서의 단위 | 예 |
| --- | --- | --- |
| 문장 | 단어(토큰) | 리뷰가 긍정인지 부정인지 |
| 센서 시계열 | 1초마다 측정값 | 진동 패턴이 고장 전조인가 |
| 음성 | 짧은 소리 구간 | 말소리를 글자로 |
| 주가·수요 | 하루마다 값 | 다음 주 수요 예측 |

## MLP로는 왜 불편할까

센서 30분치 기록(1초마다 1개, 1,800개 숫자)을 MLP에 넣는다고 해 봅시다.

- **길이가 제각각입니다.** 어떤 문장은 5단어, 어떤 문장은 50단어입니다. MLP는 입력 노드 수가 고정이라([신경망 설계도: 층 · 노드 · 출력층](#/l/dl-04-1)) 길이가 바뀌면 받을 수 없습니다.
- **순서를 모릅니다.** MLP는 입력 노드들을 그냥 각각 다른 칸으로 볼 뿐, "3번 칸 다음이 4번 칸"이라는 걸 따로 활용하지 않습니다.
- **같은 패턴을 위치마다 따로 배웁니다.** 진동 이상 패턴이 5분 시점에 나오든 25분 시점에 나오든 같은 패턴인데, MLP는 다른 입력 칸이라 따로 배워야 합니다.

## RNN: 책 읽으며 줄거리 메모하기

책을 읽는 모습을 떠올려 보세요. 우리는 한 문장씩 읽으면서 **머릿속 줄거리 메모**를 계속 고쳐 씁니다. 새 문장을 읽으면 "지금까지의 줄거리 + 새 문장"으로 메모를 업데이트하고, 다음 문장으로 넘어갑니다. 책을 다 읽고 나면 메모를 보고 "이 책은 슬픈 이야기였다"고 판단합니다.

**RNN(순환 신경망, Recurrent Neural Network)**이 이렇게 동작합니다.

- 시퀀스를 **한 칸(한 단어, 한 시점)씩** 읽습니다.
- 칸마다 **(지금까지의 메모) + (지금 입력)**으로 새 메모를 계산합니다.
- 이 메모를 **은닉 상태(hidden state)**, 보통 h라고 부릅니다.
- 마지막 메모(또는 칸마다의 메모)로 출력을 냅니다.

계산 자체는 새로울 게 없습니다. "이전 메모 h와 지금 입력 x에 각각 가중치를 곱해 더하고, tanh 활성화"를 할 뿐입니다([뉴런 하나가 하는 일](#/l/dl-01-1), [활성화 함수: 신호를 다듬는 스위치](#/l/dl-01-2)). 새로운 것은 **출력(메모)이 다음 칸의 입력으로 다시 들어간다**는 순환 구조입니다.

## 시간 순서로 펼쳐 보기

순환 구조는 한 장의 그림으로 보면 헷갈리니, 시점마다 옆으로 **펼쳐서** 그립니다.

::figure{src="content/img/dl/dl06-rnn-unroll.svg" alt="오늘, 날씨, 정말, 좋다 네 단어가 차례로 RNN 셀에 들어가고, 셀은 h1, h2, h3로 메모를 다음 셀에 넘긴다. 마지막 셀의 출력이 긍정 0.92" caption="같은 RNN 셀을 단어마다 다시 쓰며, 메모 h를 오른쪽으로 넘깁니다. 마지막 메모로 문장 전체를 판단합니다."}

"오늘 날씨 정말 좋다"를 읽는 과정을 말로 따라가 봅시다.

1. "오늘"을 읽음 → h₁: "시간 이야기가 시작됐다"
2. "날씨" + h₁ → h₂: "오늘 날씨에 대한 말이다"
3. "정말" + h₂ → h₃: "뭔가 강조가 나올 참이다"
4. "좋다" + h₃ → h₄: "오늘 날씨가 아주 좋다는 긍정적인 말" → 출력 **긍정 0.92**

물론 실제 h는 이런 문장이 아니라 숫자 수십~수백 개입니다. 하지만 '지금까지 읽은 내용의 요약'이라는 역할은 같습니다.

## 같은 셀, 같은 가중치

펼친 그림에서 RNN 셀이 네 개처럼 보이지만, 실제로는 **셀 하나를 네 번 재사용**한 것입니다. 모든 시점에서 **같은 가중치**를 씁니다. CNN이 같은 필터를 사진 모든 위치에 썼던 것(가중치 공유, [합성곱: 이미지를 훑는 작은 필터](#/l/dl-05-2))과 같은 아이디어를 시간 축에 적용한 것입니다. 덕분에

- 문장이 5단어든 50단어든 같은 셀로 처리할 수 있고(길이 문제 해결)
- 패턴이 어느 시점에 나와도 같은 가중치로 알아봅니다.

## 입력과 출력의 모양 세 가지

RNN은 어디서 입력을 받고 어디서 출력을 내느냐에 따라 여러 문제에 쓰입니다.

::figure{src="content/img/dl/dl06-io-shapes.svg" alt="다대일: 입력 네 개, 마지막에만 출력 하나(문장 → 긍정/부정, 센서 30분 → 고장 여부). 다대다: 입력 네 개, 출력 네 개(번역, 단어마다 품사). 일대다: 입력 하나, 출력 네 개(사진 한 장 → 설명 문장)" caption="입력이 여러 칸이고 출력이 하나면 다대일, 칸마다 출력하면 다대다, 입력 하나로 여러 칸을 만들면 일대다입니다."}

| 모양 | 예 |
| --- | --- |
| 다대일 | 리뷰 문장 → 긍정/부정, 센서 30분치 → 다음 1시간 안 고장 여부 |
| 다대다 | 문장 번역, 문장의 단어마다 품사 붙이기, 시점마다 이상 여부 표시 |
| 일대다 | 사진 한 장 → 설명 문장 만들기 |

## 공장에서의 RNN

설비의 온도·진동·전류를 1초마다 기록한 시계열을 RNN에 넣으면, 은닉 상태가 "최근 몇 분간 설비가 어떻게 움직였는지"를 요약합니다. 이 요약으로 **고장 전조**를 잡거나 **다음 값을 예측**해, 예측값과 실제값이 크게 다를 때 이상 경보를 냅니다.

## 자주 하는 오해

- **"RNN은 시점마다 다른 가중치를 쓴다."** 모든 시점에서 **같은 가중치**를 재사용합니다. 그래서 길이가 달라도 처리할 수 있습니다.
- **"RNN은 앞의 내용을 전부 완벽하게 기억한다."** 메모(은닉 상태)의 크기는 고정이라, 문장이 길어질수록 오래전 내용이 흐려집니다. 이 문제가 다음 레슨의 주제입니다.

## 정리

- 순서가 의미를 갖는 데이터(문장, 시계열, 음성)를 **시퀀스**라고 합니다. MLP는 길이가 고정이고 순서를 활용하지 못해 불편합니다.
- **RNN**은 한 칸씩 읽으며 **(이전 메모 + 지금 입력) → 새 메모(은닉 상태 h)**를 만들어 다음 칸으로 넘깁니다.
- 모든 시점에서 같은 셀(같은 가중치)을 재사용합니다. 펼쳐 그리면 셀이 옆으로 이어진 모양입니다.
- 입출력 모양에 따라 다대일 · 다대다 · 일대다로 씁니다.

다음 레슨에서는 문장이 길어지면 RNN이 앞 내용을 잊어버리는 이유와, 이를 고친 **LSTM · GRU**를 봅니다.
