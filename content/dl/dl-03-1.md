## 학습 한 바퀴의 네 단계

신경망 학습은 아래 네 단계를 계속 반복하는 일입니다.

::figure{src="content/img/dl/dl03-train-loop.svg" alt="① 순전파 입력에서 예측, ② 손실 계산 예측 대 정답, ③ 역전파 가중치별 책임 계산, ④ 업데이트 w에서 학습률 곱하기 기울기를 뺌, 다시 ①로 돌아가는 순환" caption="학습은 순전파 → 손실 → 역전파 → 업데이트의 반복입니다. 미니배치 하나마다 한 바퀴씩 돕니다."}

1. **순전파**: 입력을 넣어 앞에서 뒤로 계산하며 예측을 냅니다. (이번 레슨)
2. **손실 계산**: 예측과 정답을 손실 함수로 비교합니다. ([틀린 정도 재기: 손실 함수](#/l/dl-02-1))
3. **역전파**: 손실을 줄이려면 가중치 하나하나를 어느 방향으로 바꿔야 하는지, 즉 **기울기**를 거꾸로 계산합니다. (다음 레슨)
4. **업데이트**: w ← w − 학습률 × 기울기로 모든 가중치를 고칩니다. ([내리막으로 걷기: 경사하강법과 학습률](#/l/dl-02-2), [더 똑똑하게 내려가기: 옵티마이저](#/l/dl-02-4))

1에폭에 배치가 10개면 이 바퀴를 10번 돕니다([조금씩 보고 고치기: 배치 · 미니배치 · 에폭](#/l/dl-02-3)).

## 순전파는 컨베이어 벨트

**순전파(forward propagation)**는 입력이 층을 하나씩 **앞으로** 지나가는 계산입니다. 공장 컨베이어 벨트를 떠올리면 됩니다. 원재료(입력)가 첫 번째 공정(은닉층 1)을 거쳐 반제품이 되고, 다음 공정을 거쳐 완제품(예측)이 됩니다. 각 공정은 [뉴런 하나가 하는 일](#/l/dl-01-1)에서 배운 **가중합 → 활성화**를 할 뿐입니다.

## 손으로 계산해 보기

입력 2개, 은닉 뉴런 2개(ReLU), 출력 1개(활성화 없음, 숫자 예측)인 작은 신경망입니다. 가중치와 편향은 이미 정해져 있다고 합시다.

::figure{src="content/img/dl/dl03-forward.svg" alt="입력 x1=1, x2=2가 가중치와 함께 은닉 뉴런 h1, h2로 가고, h1은 0.5·1 + 0.5·2 − 1 = 0.5, h2는 1·1 − 1·2 + 0 = −1에서 ReLU로 0, 출력은 2·0.5 + 3·0 + 0.5 = 1.5, 정답 2와의 손실 0.25" caption="입력 → 은닉층 → 출력 순서로 한 층씩 계산합니다. 화살표 위 숫자가 가중치, 아래가 각 뉴런의 계산입니다."}

**1단계: 은닉층**

- h₁: 가중합 = 0.5 × 1 + 0.5 × 2 + (−1) = **0.5** → ReLU(0.5) = **0.5**
- h₂: 가중합 = 1 × 1 + (−1) × 2 + 0 = **−1** → ReLU(−1) = **0**

h₂는 음수라서 ReLU가 0으로 잘랐습니다. 이 입력에 대해서는 h₂가 "꺼져 있다"는 뜻입니다.

**2단계: 출력층**

- 예측 ŷ = 2 × h₁ + 3 × h₂ + 0.5 = 2 × 0.5 + 3 × 0 + 0.5 = **1.5**

(ŷ는 "와이햇"이라고 읽고, 예측값이라는 뜻입니다.)

**3단계: 손실까지**

정답이 2라면 MSE 손실은 (2 − 1.5)² = **0.25**입니다. 예측이 정답보다 0.5 작습니다. 이 0.25를 줄이려면 어느 가중치를 어떻게 바꿔야 할까요? 그게 다음 레슨의 역전파입니다.

## 층 하나 = 뉴런 여러 개를 한꺼번에

위 예에서는 뉴런을 하나씩 계산했지만, 실제로는 **한 층의 뉴런 전부를 한 번에** 계산합니다. 입력 숫자들과 가중치 표를 맞춰 곱하고 더하는 이 계산을 수학에서는 **행렬 곱**이라고 부릅니다. 이름만 알아 두면 됩니다. GPU가 이 행렬 곱을 수백만 개 동시에 처리하는 데 특화되어 있어서 딥러닝이 빨라졌습니다([딥러닝의 역사와 쓸 때 · 안 쓸 때](#/l/dl-00-2)의 '화력').

## 은닉층 값은 모델이 만든 새 특징

h₁ = 0.5, h₂ = 0은 사람이 의미를 붙여 준 값이 아닙니다. 입력을 보고 **모델이 만들어 낸 새 특징**입니다. [왜 층을 쌓을까: XOR과 비선형](#/l/dl-01-3)에서 XOR을 풀 때 은닉층이 점을 새 자리로 옮긴 것처럼, 은닉층은 출력층이 판단하기 쉬운 형태로 정보를 바꿔 줍니다. 학습이 진행되면 이 값들이 점점 쓸모 있는 특징이 되도록 가중치가 고쳐집니다.

## 예측할 때는 순전파만

학습이 끝난 모델로 새 데이터를 예측할 때(머신러닝의 `predict`)는 **순전파만** 합니다. 손실도 역전파도 업데이트도 필요 없습니다. 정답을 모르니 손실을 계산할 수도 없고, 가중치를 고칠 이유도 없습니다. 그래서 예측은 학습보다 훨씬 빠릅니다.

| | 순전파 | 손실 | 역전파 | 업데이트 |
| --- | --- | --- | --- | --- |
| 학습할 때 | O | O | O | O |
| 예측할 때 | O | X | X | X |

## 자주 하는 오해

- **"순전파 중에 가중치가 조금씩 바뀐다."** 순전파 동안 가중치는 고정입니다. 가중치는 역전파로 기울기를 다 구한 뒤 **업데이트 단계에서 한꺼번에** 바뀝니다.
- **"ReLU로 0이 된 뉴런은 버려도 된다."** 이 입력에서만 꺼진 것입니다. 다른 입력에서는 켜져서 중요한 역할을 할 수 있습니다.

## 정리

- 학습은 **순전파 → 손실 → 역전파 → 업데이트**의 반복입니다.
- 순전파는 입력이 층마다 **가중합 → 활성화**를 거치며 앞으로 흘러 예측이 되는 과정입니다. 예: h₁ = 0.5, h₂ = 0 → ŷ = 1.5, 손실 0.25.
- 한 층의 계산은 행렬 곱으로 한꺼번에 하고, 은닉층 값은 모델이 만든 새 특징입니다.
- 예측할 때는 순전파만 합니다.

다음 레슨에서는 손실 0.25에 대해 가중치 하나하나가 얼마나 '책임'이 있는지 거꾸로 계산하는 **역전파**를 봅니다.
