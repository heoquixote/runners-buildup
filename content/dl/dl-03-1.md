## 순전파: 앞으로 계산하고 기억하기

입력 → 은닉층 → 출력 → 손실 순서로 계산합니다. 이때 **중간값을 모두 저장**해 둡니다. 역전파에서 다시 쓰기 때문입니다.

## 역전파: 손실에서 거꾸로

손실 L을 각 가중치로 미분한 값(기울기)이 있어야 경사하강법을 할 수 있습니다. 가중치가 수백만 개여도 **연쇄법칙**으로 한 번의 역방향 계산에 모두 구합니다.

∂L/∂x = ∂L/∂y · ∂y/∂x

출력 쪽에서 받은 기울기(∂L/∂y)에 자기 노드의 국소 기울기(∂y/∂x)를 곱해 앞쪽으로 넘깁니다.

## 노드별 국소 기울기

| 노드 | 순전파 | 역전파 (위에서 온 기울기 g) |
| --- | --- | --- |
| 덧셈 z = x + y | 더하기 | x, y에 g를 그대로 |
| 곱셈 z = x · y | 곱하기 | x에 g·y, y에 g·x (서로 바꿔 곱함) |
| ReLU | max(0, z) | z > 0이면 g, 아니면 0 |
| 시그모이드 s | 1/(1+e⁻ᶻ) | g · s(1 − s) |

## 작은 계산 그래프 따라가기

ŷ = σ(w·x + b), 손실 L = (ŷ − y)²에서 w와 b의 기울기를 직접 계산하고, w를 아주 조금 바꿔 본 수치 미분과 비교합니다.

```run
import numpy as np

x, y = 2.0, 1.0
w, b = 0.3, -0.1
sig = lambda z: 1 / (1 + np.exp(-z))

# forward (keep intermediates)
z = w * x + b
yhat = sig(z)
L = (yhat - y) ** 2
print(f"forward: z={z:.3f} yhat={yhat:.4f} L={L:.5f}")

# backward (chain rule)
dL_dyhat = 2 * (yhat - y)
dyhat_dz = yhat * (1 - yhat)
dL_dz = dL_dyhat * dyhat_dz
dL_dw = dL_dz * x
dL_db = dL_dz * 1
print(f"backward: dL/dw={dL_dw:.5f} dL/db={dL_db:.5f}")

# numerical check
eps = 1e-6
num = ((sig((w + eps) * x + b) - y) ** 2 - L) / eps
print(f"numerical dL/dw={num:.5f}")
```

## 왜 중요한가

- 프레임워크(PyTorch, TensorFlow)는 이 계산을 **자동 미분**으로 해 줍니다. 직접 짤 일은 드물지만, 원리를 알아야 학습이 안 될 때 원인을 짐작할 수 있습니다.
- 시그모이드의 국소 기울기 s(1 − s)는 최대 0.25입니다. 층이 10개면 0.25¹⁰ ≈ 0.000001이 곱해져 앞쪽 층은 거의 학습되지 않습니다(기울기 소실). 은닉층에 ReLU를 쓰는 이유입니다.
- 역전파에 순전파 중간값이 필요하므로, 학습은 추론보다 메모리를 훨씬 많이 씁니다.
