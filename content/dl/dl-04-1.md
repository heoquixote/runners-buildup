## 시작하기 전에

지금까지 신경망이 **어떻게 계산하고(순전파), 어떻게 배우는지(손실 → 역전파 → 업데이트)**를 봤습니다. 이번 DAY는 실제로 신경망을 만들 때 사람이 무엇을 정하는지, 그리고 신경망의 가장 흔한 고민인 **과적합**을 다룹니다.

이번 레슨에서 배울 것

- 사람이 정하는 것과 학습이 정하는 것
- 입력층 · 은닉층 · 출력층 정하기
- 문제 종류별 출력층과 손실 세트
- 학습할 숫자(파라미터)가 몇 개인지 세기

## 신경망 설계도

건물을 지을 때 건축가는 설계도(몇 층, 방 몇 개, 문 위치)를 그리고, 실제 벽돌을 쌓는 건 공사입니다. 신경망도 똑같이 둘로 나뉩니다.

| 사람이 정하는 것 (설계도, 하이퍼파라미터) | 학습이 정하는 것 (파라미터) |
| --- | --- |
| 은닉층을 몇 개 쌓을지 | 가중치 w |
| 층마다 뉴런(노드)을 몇 개 둘지 | 편향 b |
| 활성화 함수, 출력층 모양, 손실 함수 | |
| 학습률, 배치 크기, 에폭, 옵티마이저 | |

[하이퍼파라미터와 GridSearchCV](#/l/ml-05-2)에서 배운 **하이퍼파라미터**(사람이 정하는 설정값)와 **파라미터**(데이터로 학습되는 값)의 구분과 같습니다.

## 입력층: 특성 수만큼

입력층의 노드 수는 사람이 고르는 게 아니라 **데이터가 정합니다.** 특성(열)이 4개면 입력 노드도 4개입니다. 28 × 28 흑백 사진을 펼쳐 넣으면 784개입니다. 입력층은 계산을 하지 않고 숫자를 받아 넘기기만 합니다.

한 가지 꼭 할 일은 [숫자 크기 맞추기: 표준화와 정규화](#/l/ml-06-2)에서 배운 **표준화**입니다. 신경망은 경사하강법으로 배우기 때문에, 특성마다 단위가 크게 다르면(온도 300, 회전 속도 1,500, 마모 0.1) 큰 숫자 쪽만 학습이 휘둘립니다. 입력을 비슷한 범위로 맞춰 주면 학습이 훨씬 빠르고 안정적입니다.

## 은닉층: 몇 층, 몇 개?

정답 공식은 없습니다. 출발점으로 쓰는 감각은 이렇습니다.

- **작게 시작해서 키운다.** 은닉층 1~2개, 노드 수십 개로 시작해 성능이 부족하면 늘립니다.
- **깔때기 모양**이 흔합니다. 64 → 32 → 16처럼 뒤로 갈수록 줄여 정보를 요약해 갑니다.
- 노드를 늘리는 것보다 층을 늘리는 쪽이 같은 파라미터 수로 더 복잡한 것을 표현하는 경우가 많지만, 표 데이터에서는 2~3층이면 충분한 경우가 대부분입니다.
- 은닉층 활성화는 **ReLU**([활성화 함수: 신호를 다듬는 스위치](#/l/dl-01-2)).

## 출력층: 문제 모양에 맞춘 세트

출력층은 고민할 게 거의 없습니다. 문제 종류가 정해지면 노드 수 · 활성화 · 손실이 **세트로** 정해집니다.

| 문제 | 예 | 출력 노드 수 | 출력 활성화 | 손실 함수 |
| --- | --- | --- | --- | --- |
| 회귀 | 내일 공정 온도 | 1 | 없음 | MSE |
| 이진 분류 | 불량 / 정상 | 1 | 시그모이드 | 이진 교차엔트로피 |
| 다중 분류 | 불량 유형 5종 중 하나 | 클래스 수 (5) | 소프트맥스 | 범주형 교차엔트로피 |
| 다중 레이블 | 한 사진에 긁힘·찍힘·얼룩이 각각 있나 | 레이블 수 (3) | 각각 시그모이드 | 이진 교차엔트로피 (레이블마다) |

마지막 줄은 덤입니다. "여러 개 중 **하나**"면 소프트맥스(합 1), "여러 개가 **각각** 있나 없나"면 시그모이드 여러 개를 씁니다.

## 학습할 숫자 세기

완전연결 층(모든 노드가 다음 층 모든 노드와 연결된 층) 하나의 파라미터 수는 이렇게 셉니다.

> **파라미터 수 = 입력 노드 수 × 출력 노드 수 (가중치) + 출력 노드 수 (편향)**

편향은 받는 쪽 노드마다 하나씩 있으니 출력 노드 수만큼 더합니다. 위 그림(4 → 8 → 3)을 세어 봅시다.

1. 입력층 → 은닉층: 4 × 8 + 8 = 32 + 8 = **40개**
2. 은닉층 → 출력층: 8 × 3 + 3 = 24 + 3 = **27개**
3. 합계: 40 + 27 = **67개**

이 작은 신경망도 학습할 숫자가 67개입니다. 입력 784 → 은닉 128 → 출력 10인 손글씨 숫자 분류기라면 784 × 128 + 128 = 100,480개, 128 × 10 + 10 = 1,290개로 **10만 개가 넘습니다.**

## 파라미터가 많다는 것의 의미

파라미터가 많으면 세 가지가 같이 커집니다.

- **표현력**: 더 복잡한 패턴을 담을 수 있습니다.
- **필요한 데이터 양**: 숫자 10만 개를 정하려면 예시도 많아야 합니다.
- **외우기 쉬움**: 데이터가 적으면 패턴 대신 데이터 자체를 외워 버립니다. 이게 **과적합**입니다.

그래서 데이터가 1,000건인데 파라미터가 100만 개인 신경망을 쓰면 거의 틀림없이 과적합됩니다. 다음 두 레슨에서 과적합을 알아보고 막는 법을 봅니다.

## 자주 하는 오해

- **"입력층 노드 수는 많을수록 좋다."** 입력층 노드 수는 **특성 수로 정해집니다.** 바꾸고 싶다면 특성을 늘리거나 줄이는 것이지, 노드 수만 바꿀 수는 없습니다.
- **"이진 분류는 출력 노드가 2개여야 한다."** 시그모이드 노드 1개(불량 확률 p, 정상은 1 − p)로 충분합니다. 소프트맥스 노드 2개로 해도 같은 결과지만, 1개가 기본입니다.

## 정리

- 사람이 정하는 것: 층 수 · 노드 수 · 활성화 · 출력층 · 손실 · 학습 설정(하이퍼파라미터). 학습이 정하는 것: 가중치와 편향(파라미터).
- 입력층 노드 = 특성 수(표준화 필수), 은닉층은 작게 시작해 키우고 ReLU, 출력층은 문제 모양에 맞춘 세트.
- **완전연결 층 파라미터 = 입력 × 출력 + 출력.** 4 → 8 → 3은 40 + 27 = 67개.
- 파라미터가 많을수록 표현력도, 필요한 데이터도, 과적합 위험도 커집니다.

다음 레슨에서는 학습 중에 과적합이 시작되는 순간을 **학습 곡선**으로 알아보는 법을 봅니다.
