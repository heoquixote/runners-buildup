## 다층 퍼셉트론(MLP)

입력층 → 은닉층 여러 개 → 출력층으로 뉴런을 완전히 연결한 신경망입니다. 은닉층이 입력을 점점 더 쓸모 있는 표현으로 바꾸고, 출력층이 그 표현으로 예측합니다.

입력 4개, 은닉 10개, 출력 1개라면 파라미터는 (4×10 + 10) + (10×1 + 1) = 61개입니다. 층과 뉴런을 늘리면 표현력이 커지지만 과적합 위험과 필요한 데이터도 커집니다.

```run
import numpy as np
from sklearn.datasets import make_moons
from sklearn.model_selection import train_test_split
from sklearn.neural_network import MLPClassifier
from sklearn.linear_model import LogisticRegression

X, y = make_moons(n_samples=300, noise=0.25, random_state=0)
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.3, random_state=0)
lin = LogisticRegression().fit(X_tr, y_tr)
mlp = MLPClassifier(hidden_layer_sizes=(16, 16), max_iter=2000, random_state=0).fit(X_tr, y_tr)
print("logistic (straight line) test acc", round(lin.score(X_te, y_te), 3))
print("MLP (16, 16) test acc           ", round(mlp.score(X_te, y_te), 3))
print("weight shapes", [w.shape for w in mlp.coefs_])
```

## 에폭 · 배치 · 반복

| 용어 | 뜻 |
| --- | --- |
| 배치 크기 | 기울기 한 번 계산에 쓰는 샘플 수 (예: 32) |
| 반복(iteration) | 가중치 업데이트 1회 |
| 에폭(epoch) | 학습 데이터 전체를 한 바퀴 |

데이터 1,000개, 배치 32라면 1에폭 = 32번(마지막 배치는 8개) 업데이트입니다.

## 학습 곡선으로 과적합 보기

학습 손실은 에폭이 늘수록 계속 내려갑니다. 검증 성능이 어느 순간 멈추거나 나빠지면 그때부터는 학습 데이터를 외우는 중입니다.

```run
import numpy as np
import matplotlib.pyplot as plt
from sklearn.datasets import make_moons
from sklearn.model_selection import train_test_split
from sklearn.neural_network import MLPClassifier

X, y = make_moons(n_samples=200, noise=0.35, random_state=1)
X_tr, X_va, y_tr, y_va = train_test_split(X, y, test_size=0.4, random_state=0)
mlp = MLPClassifier(hidden_layer_sizes=(64, 64), learning_rate_init=0.01, random_state=0)
tr, va = [], []
for epoch in range(300):
    mlp.partial_fit(X_tr, y_tr, classes=[0, 1])
    tr.append(mlp.score(X_tr, y_tr)); va.append(mlp.score(X_va, y_va))
best = int(np.argmax(va))
print("best validation epoch", best, "acc", round(va[best], 3), "| last epoch train", round(tr[-1], 3), "val", round(va[-1], 3))
fig, ax = plt.subplots(figsize=(6, 3.2))
ax.plot(tr, label="train acc"); ax.plot(va, label="validation acc")
ax.axvline(best, color="gray", ls="--"); ax.set_xlabel("epoch"); ax.legend(); ax.set_title("Learning curve")
plt.tight_layout(); plt.show()
```

## 과적합을 막는 방법

- **조기 종료(early stopping)**: 검증 성능이 일정 에폭 동안 좋아지지 않으면 멈추고 가장 좋았던 가중치로 되돌림
- **드롭아웃**: 학습 때 뉴런을 무작위로 꺼서(예: 50%) 특정 뉴런에 의존하지 않게. 추론 때는 모두 켬
- **가중치 감쇠(L2)**: 가중치가 커지면 벌점. scikit-learn MLP의 `alpha`
- **데이터 늘리기**: 더 모으거나, 이미지라면 회전 · 뒤집기 같은 증강

## 표 데이터에는 무엇을?

제조 공정 변수 같은 **표(tabular) 데이터**에서는 랜덤포레스트 · 그래디언트 부스팅이 MLP보다 좋거나 비슷한 경우가 많고, 튜닝과 해석도 쉽습니다. 신경망은 이미지(CNN), 시퀀스(RNN · Transformer), 텍스트처럼 **구조가 있는 데이터**에서 강점이 큽니다.
