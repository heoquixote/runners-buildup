## 뉴런 하나 = 가중합 + 활성화

딥러닝의 가장 작은 단위인 뉴런(퍼셉트론)은 두 단계로 계산합니다.

1. **가중합**: z = w₁x₁ + w₂x₂ + … + b. 입력마다 중요도(가중치 w)를 곱해 더하고 편향 b를 더함
2. **활성화**: 출력 = f(z). z를 다음 층으로 넘길 값으로 바꿈

로지스틱 회귀(ml-02)가 바로 뉴런 하나에 시그모이드 활성화를 붙인 것입니다. 딥러닝은 이런 뉴런을 층으로 수백~수백만 개 쌓은 것입니다.

```run
import numpy as np

x = np.array([1.0, 2.0])        # inputs (e.g. temp, current - scaled)
w = np.array([0.5, -1.0])       # weights
b = 1.0                         # bias
z = w @ x + b
print("z =", z)
print("sigmoid(z) =", round(1 / (1 + np.exp(-z)), 3))
```

## 활성화 함수 비교

| 함수 | 식 | 출력 범위 | 주로 쓰는 곳 |
| --- | --- | --- | --- |
| 계단 | z > 0이면 1 | 0 또는 1 | 초기 퍼셉트론 (미분 불가) |
| 시그모이드 | 1 / (1 + e⁻ᶻ) | 0 ~ 1 | 이진 분류 출력층 |
| tanh | (eᶻ − e⁻ᶻ) / (eᶻ + e⁻ᶻ) | −1 ~ 1 | RNN 내부 |
| ReLU | max(0, z) | 0 ~ ∞ | 은닉층 기본값 |
| softmax | eᶻⁱ / Σeᶻʲ | 0 ~ 1, 합 1 | 다중 분류 출력층 |

```run
import numpy as np
import matplotlib.pyplot as plt

z = np.linspace(-5, 5, 200)
fig, ax = plt.subplots(figsize=(6, 3.5))
ax.plot(z, 1 / (1 + np.exp(-z)), label="sigmoid")
ax.plot(z, np.tanh(z), label="tanh")
ax.plot(z, np.maximum(0, z), label="ReLU")
ax.set_ylim(-1.5, 3); ax.axhline(0, color="gray", lw=0.5); ax.legend(); ax.set_title("Activation functions")
plt.tight_layout(); plt.show()
print("sigmoid slope at z=5:", round(np.exp(-5) / (1 + np.exp(-5)) ** 2, 4), "(almost flat)")
```

시그모이드와 tanh는 z가 크거나 작으면 곡선이 평평해져 기울기가 0에 가까워집니다. 층이 깊으면 이 작은 기울기가 계속 곱해져 학습이 멈추는데(기울기 소실), ReLU는 양수 쪽 기울기가 항상 1이라 이 문제가 적습니다.

## 왜 비선형 활성화가 필요한가

활성화 없이 선형층 두 개를 쌓으면 W₂(W₁x) = (W₂W₁)x로, 결국 선형층 하나와 같습니다. 비선형 활성화가 있어야 층을 쌓을수록 곡선 · 복잡한 경계를 표현할 수 있습니다.

## 퍼셉트론의 한계: XOR

단층 퍼셉트론은 직선(평면) 하나로 나누는 문제만 풉니다. AND, OR는 되지만 XOR(두 입력이 다를 때만 1)은 직선 하나로 나눌 수 없습니다. 은닉층을 하나 추가하면 풀 수 있고, 이것이 다층 퍼셉트론(MLP)의 출발점입니다.

```run
import numpy as np

X = np.array([[0, 0], [0, 1], [1, 0], [1, 1]])
step = lambda z: (z > 0).astype(int)
# hidden layer: h1 = OR, h2 = NAND  -> output = AND(h1, h2) = XOR
h1 = step(X @ np.array([1, 1]) - 0.5)
h2 = step(X @ np.array([-1, -1]) + 1.5)
out = step(h1 + h2 - 1.5)
print("x1 x2 | XOR")
for x, o in zip(X, out):
    print(x[0], " ", x[1], " |", o)
```
