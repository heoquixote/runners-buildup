## 시작하기 전에

앞 레슨에서 딥러닝은 **특징 만들기까지 모델이 배우는 머신러닝**이고, "딥"은 층이 많다는 뜻이라고 했습니다.

이번 레슨에서 배울 것

- 신경망이 두 번이나 "버려졌다가" 다시 살아난 이야기
- 지금 딥러닝이 가능해진 세 가지 조건
- 딥러닝을 써야 할 때와 쓰지 말아야 할 때
- 이 트랙의 지도

## 역사를 왜 볼까

역사를 외우자는 게 아닙니다. 신경망의 역사는 **"문제가 생기고 → 해법이 나오고 → 또 다른 문제가 생기는"** 이야기라서, 순서대로 따라가면 이 트랙에서 배울 개념이 왜 필요한지가 자연스럽게 보입니다.

::figure{src="content/img/dl/dl00-timeline.svg" alt="1958 퍼셉트론, 1969 첫 번째 겨울, 1986 역전파, 1990년대 두 번째 겨울, 2012 딥러닝 부활, 2017 Transformer, 2020년대 대규모 언어 모델" caption="신경망은 두 번의 침체(겨울)를 겪었고, 겨울마다 그 원인을 푸는 기법이 나오며 다시 살아났습니다."}

## 1958년, 뉴런 하나: 퍼셉트론

처음 나온 것은 **퍼셉트론**이었습니다. 입력에 가중치를 곱해 더한 뒤, 기준을 넘으면 1, 아니면 0을 내는 아주 단순한 구조입니다. "기계가 스스로 배운다"는 생각에 큰 기대를 받았습니다. 퍼셉트론이 하는 계산은 [dl-01-1](#/l/dl-01-1)에서 손으로 해 봅니다.

## 첫 번째 겨울: XOR을 못 푼다

그런데 퍼셉트론은 아무리 학습해도 풀지 못하는 문제가 있었습니다. 대표가 **XOR**(두 입력이 서로 다를 때만 1)입니다. 퍼셉트론은 직선 하나로 나눌 수 있는 문제만 풀 수 있는데, XOR은 직선 하나로 나뉘지 않습니다. 이 한계가 알려지며 연구 지원이 끊기고 신경망 연구가 오래 멈췄습니다. 왜 안 되는지, 어떻게 풀었는지는 [dl-01-3](#/l/dl-01-3)에서 봅니다.

## 1986년, 층을 쌓고 거꾸로 배우기: 역전파

해법은 **층을 하나 더 두는 것**이었습니다. 그런데 층이 여러 개면 "어느 가중치를 얼마나 고쳐야 하나"를 계산하기 어렵습니다. 이 계산을 효율적으로 하는 방법이 **역전파**입니다(dl-03). 은닉층이 있는 신경망, 즉 다층 퍼셉트론이 실제로 학습될 수 있게 되었습니다.

## 두 번째 겨울: 깊게 쌓으면 안 배운다

층을 2~3개 넘게 쌓으면 이번엔 **앞쪽 층이 거의 학습되지 않는** 문제가 생겼습니다. 뒤에서 앞으로 전해지는 신호(기울기)가 층을 지날 때마다 작아져 앞에 도착할 즈음엔 거의 0이 되기 때문입니다. 이를 **기울기 소실**이라고 합니다([dl-03-3](#/l/dl-03-3)). 마침 다른 머신러닝 방법(SVM 등)이 더 좋은 성능을 내면서 신경망은 다시 밀려났습니다.

## 2012년, 딥러닝의 부활

2012년 이미지 분류 대회에서 깊은 신경망(CNN)이 2등과 큰 차이로 우승하면서 분위기가 바뀌었습니다. 아이디어 자체는 오래된 것이었는데, 왜 이제야 됐을까요? 요리에 비유하면 세 가지가 동시에 갖춰졌기 때문입니다.

| 조건 | 요리 비유 | 실제 내용 |
| --- | --- | --- |
| 데이터 | 재료 | 인터넷과 스마트폰 덕분에 사진·글·소리가 엄청나게 쌓였습니다. 학습할 값이 많은 신경망에는 데이터가 많이 필요합니다. |
| 연산 장치 (GPU) | 화력 | 게임용 그래픽 카드(GPU)가 곱셈·덧셈 수백만 개를 동시에 처리할 수 있었습니다. 몇 달 걸리던 학습이 며칠로 줄었습니다. |
| 학습 기법 | 레시피 | ReLU(dl-01-2), 드롭아웃·배치 정규화(dl-04-3) 같은 기법이 깊은 층의 학습 문제를 풀었습니다. |

셋 중 하나만 빠져도 성립하지 않습니다. 재료가 없으면 요리를 못 하고, 불이 약하면 하루 종일 걸리고, 레시피가 엉망이면 타 버립니다.

## 2017년 이후: Transformer와 대규모 언어 모델

2017년에 **어텐션**만으로 문장을 처리하는 **Transformer** 구조가 나왔습니다([dl-07](#/l/dl-07-2)). 문장의 모든 단어를 한꺼번에 계산할 수 있어 아주 큰 모델을 학습시킬 수 있게 되었고, 이것이 오늘날 챗봇 같은 **대규모 언어 모델(LLM)**의 바탕이 되었습니다.

## 딥러닝을 쓸 때와 쓰지 않을 때

딥러닝이 강력하다고 모든 문제에 쓰는 것은 아닙니다. 실무에서는 아래 표로 먼저 판단합니다.

| 딥러닝이 유리한 경우 | 다른 방법이 나은 경우 |
| --- | --- |
| 사진·소리·글 같은 **비정형** 데이터 | 행과 열로 된 **표(정형)** 데이터 |
| 데이터가 아주 많음 (수만 건 이상) | 데이터가 적음 (수백~수천 건) |
| 사람이 특징을 정의하기 어려움 | 현장 지식으로 좋은 특징을 만들 수 있음 |
| 예측 정확도가 가장 중요함 | **판단 근거를 설명해야 함** (대출 심사, 품질 판정 근거) |
| GPU 같은 계산 자원이 있음 | 빠르고 가볍게 돌려야 함 |

표 데이터에서는 [ml-04-4](#/l/ml-04-4)에서 배운 **그래디언트 부스팅** 계열이 딥러닝보다 성능이 좋거나 비슷한 경우가 많습니다. 학습도 빠르고, 피처 중요도로 설명하기도 쉽습니다. 그래서 "표 데이터면 부스팅부터, 사진·소리·글이면 딥러닝부터"가 현장의 기본 감각입니다.

## 이 트랙의 지도

::figure{src="content/img/dl/dl00-track-map.svg" alt="DAY 01 시작하기부터 DAY 10 실무와 전이 학습까지 이어지는 징검다리" caption="DAY 02~05는 모든 신경망에 공통인 기초 원리, DAY 06~08은 데이터 모양(사진·순서·글)에 맞춘 구조, DAY 09~10은 생성 모델과 실무입니다."}

- **DAY 02~05 기초 원리**: 뉴런 하나 → 틀린 정도 재기 → 고치는 방향 계산 → 과적합 막기
- **DAY 06~08 구조**: 사진은 CNN, 순서 데이터는 RNN, 글은 어텐션과 Transformer
- **DAY 09~10 응용**: 새로 만드는 생성 모델, 남이 학습한 모델을 빌려 쓰는 전이 학습과 프로젝트 흐름

## 자주 하는 오해

- **"딥러닝은 2010년대에 새로 발명된 기술이다."** 핵심 아이디어(뉴런, 역전파)는 수십 년 전에 나왔습니다. 새로 생긴 것은 데이터·GPU·학습 기법이라는 **조건**입니다.
- **"최신 기술이니 무조건 딥러닝으로 해야 한다."** 표 데이터 몇천 행이라면 부스팅이 더 빠르고 정확하고 설명하기 쉬울 수 있습니다. 문제와 데이터에 맞는 도구를 고르는 게 실력입니다.

## 정리

- 신경망은 퍼셉트론 → (XOR 겨울) → 역전파 → (기울기 소실 겨울) → 딥러닝 부활 → Transformer 순으로 발전했습니다. 각 단계가 앞 단계의 문제를 풀었습니다.
- 지금의 딥러닝은 **데이터 · GPU · 학습 기법** 세 조건이 함께 갖춰져 가능해졌습니다.
- 사진·소리·글, 많은 데이터, 특징 정의가 어려운 문제엔 딥러닝. 표 데이터, 적은 데이터, 설명이 필요한 문제엔 부스팅 같은 전통 머신러닝을 먼저 봅니다.

다음 DAY부터는 신경망의 가장 작은 단위인 **뉴런 하나**가 무슨 계산을 하는지부터 시작합니다.
