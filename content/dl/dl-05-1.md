## 이미지를 완전연결로 다루면

28×28 흑백 이미지를 한 줄로 펴면 784개 입력입니다. 은닉 뉴런 100개와 완전히 연결하면 가중치만 78,400개, 컬러 224×224라면 1,500만 개입니다. 게다가 펴는 순간 "옆 픽셀"이라는 위치 정보가 사라집니다.

## 합성곱: 작은 필터로 훑기

3×3 같은 작은 필터를 이미지 위로 밀면서 겹친 부분끼리 곱해 더합니다. 결과가 **특징 맵**입니다.

- **국소 연결**: 출력 한 칸은 입력의 작은 영역만 봄
- **가중치 공유**: 같은 필터를 모든 위치에서 사용 → 파라미터가 적고, 패턴이 어디 있든 찾음

::video{ref="dl-m13"}

```run
import numpy as np

img = np.array([
    [0, 0, 0, 9, 9, 9],
    [0, 0, 0, 9, 9, 9],
    [0, 0, 0, 9, 9, 9],
    [0, 0, 0, 9, 9, 9],
], dtype=float)
kernel = np.array([[-1, 0, 1],
                   [-1, 0, 1],
                   [-1, 0, 1]], dtype=float)   # vertical edge detector
H, W = img.shape
out = np.zeros((H - 2, W - 2))
for r in range(H - 2):
    for c in range(W - 2):
        out[r, c] = (img[r:r + 3, c:c + 3] * kernel).sum()
print(out)
```

밝기가 바뀌는 세로 경계에서만 큰 값이 나옵니다. CNN은 이런 필터의 숫자를 사람이 정하지 않고 **학습**합니다. 앞쪽 층은 경계 · 질감, 뒤쪽 층은 부품 모양 같은 복잡한 패턴을 잡습니다.

## 출력 크기 계산

**출력 = (N − F + 2P) / S + 1**

- N: 입력 크기, F: 필터 크기, P: 패딩(가장자리에 0을 덧댐), S: 스트라이드(한 번에 이동하는 칸)
- 3×3 필터, P = 1, S = 1이면 크기 유지('same')

```run
def out_size(N, F, P=0, S=1):
    return (N - F + 2 * P) // S + 1

print("28, 3x3, P0 S1 ->", out_size(28, 3))
print("28, 3x3, P1 S1 ->", out_size(28, 3, P=1))
print("32, 5x5, P0 S2 ->", out_size(32, 5, S=2))
print("params of conv(3 -> 16 ch, 3x3) =", 3 * 3 * 3 * 16, "+ bias 16")
```

## 풀링: 요약하고 줄이기

2×2 최대 풀링은 각 2×2 칸에서 가장 큰 값만 남깁니다. 크기가 절반이 되어 계산이 줄고, 특징이 한두 픽셀 움직여도 결과가 덜 변합니다.

```run
import numpy as np

a = np.arange(1, 17).reshape(4, 4)
print(a)
pooled = a.reshape(2, 2, 2, 2).max(axis=(1, 3))
print("2x2 max pooling ->")
print(pooled)
```

## 전형적인 CNN 구조

[합성곱 → ReLU → 풀링] × 여러 번 → 펼치기 → 완전연결 → softmax

제조 현장에서는 외관 검사(스크래치 · 이물), 웨이퍼 맵 불량 패턴 분류에 많이 씁니다. 데이터가 적으면 ImageNet 등으로 미리 학습된 모델을 가져와 마지막 층만 다시 학습하는 **전이 학습**이 기본입니다.
