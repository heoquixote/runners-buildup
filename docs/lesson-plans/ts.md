# 시계열 분석 트랙 레슨 기획안

작성 기준은 [lesson-plan-guide.md](lesson-plan-guide.md). 기호: `S` 설명, `F` 그림, `C` 실행 셀, `T` 직접 해보기, `R` 결과 해석, `E` 손 계산 예.

- 작성: 2026-11-12 (진성 요청 "시계열 분석 딥러닝 앞에 새로 하나 추가하자")
- 상태: 구현 완료 (아래 구현 메모 참고)
- 원본 원고: `docs/sources/`에 시계열 전용 원고는 없습니다. 앞 트랙 레슨(아래 "앞 트랙과의 연결")과 이 기획안의 예비 실험을 바탕으로 새로 씁니다. 진성 님 원고가 생기면 9번 항목(원본 원고)을 채웁니다.

## 1. 트랙 한눈에 보기

| 항목 | 내용 |
| --- | --- |
| 트랙 id · 이름 | `ts` · 시계열 분석 (Time Series) |
| 위치 | `TRACKS` 배열에서 `ml` 다음, `dl` 앞. 홈 카테고리는 **통계 · 머신러닝** 묶음에 추가(`TRACK_GROUPS.ml.tracks = ["stats", "ml", "ts"]`) |
| 한 줄 소개(blurb) | 추세 · 계절성 분해부터 지수평활 · ARIMA · 머신러닝 예측, 센서 이상 탐지까지. 시간 순서가 있는 데이터를 읽고 미래를 예측합니다. |
| 규모 | 코스 11개 · 레슨 31개 (레슨 하나 = 큰 개념 1~2개 = 15~25분) |
| 실습 방식 | 실행 셀 + 직접 해보기 셀 (딥러닝과 달리 **코드 실습 있음**). 라이브러리는 pandas · statsmodels · scikit-learn · matplotlib |
| 연습문제 | 코스마다 제조 2 + 일반 2 (유닛 52~60, ts-00 · ts-10은 유닛 없음) |
| 깊이 기준 | 레슨마다 "원리 한 걸음 더"(수식 한 줄 + numpy로 직접 계산해 라이브러리 결과와 맞춰 보기) 1곳 |

### 왜 별도 트랙인가

지금 시계열은 여러 트랙에 조각으로 흩어져 있습니다. 데이터를 **다루는 법**(da-08)과 **그리는 법**(da-13), 시간 순서로 **나누는 법**(ml-05-4)은 있지만, 시계열을 **분해하고, 자기상관을 읽고, 예측 모델을 세우고, 이상을 잡는** 흐름은 없습니다. 딥러닝 트랙의 RNN · LSTM(dl-06)이 "순서가 있는 데이터"를 다루기 전에, 고전 시계열 모델로 기준을 세워 두면 "딥러닝이 이걸 얼마나 더 잘하나"를 비교할 눈이 생깁니다.

### ts-03-1 어제가 오늘을 말해 준다: 자기상관과 ACF

- **목표**: 래그 산점도와 ACF 그래프에서 추세 · 계절 신호를 읽을 수 있다.
- **전제**: [공분산과 상관계수](#/l/st-07-1)의 상관계수(-1~1).
- **개념**: ① 자기상관 = 시계열을 한 칸 밀어 자기 자신과 상관계수 구하기 ② 래그 산점도(어제 vs 오늘) ③ ACF 그래프 읽기: 천천히 줄어듦 = 추세, 12 · 24마다 솟음 = 계절 ④ 파란 띠(유의 범위)의 뜻 ⑤ 원리 한 걸음 더: `y.corr(y.shift(k))`로 직접 계산해 `acf()`와 비교(값이 살짝 다른 이유: 분모를 전체 분산으로 씀).

### ts-03-2 PACF: 중간을 빼고 본 직접 관계

- **목표**: ACF와 PACF의 차이를 설명하고 두 그래프를 나란히 읽을 수 있다.
- **개념**: ① 소문 전달 비유: A → B → C면 A와 C도 닮지만 직접 들은 건 아님 ② PACF = 중간 래그의 영향을 뺀 직접 상관 ③ AR 과정의 PACF는 p 이후 뚝 끊김(ts-07-2 복선) ④ 원리 한 걸음 더: lag 2 PACF = y_t를 y_{t-1}, y_{t-2}로 회귀했을 때 y_{t-2}의 계수(numpy lstsq로 확인).
- **배치**: S(비유) → F(소문 전달) → C(numpy로 AR(1) 시뮬레이션: ACF · PACF 나란히) → R → T(계수 0.9 → 0.3) → S(원리) → C.
- **판단**: 퀴즈 1(ox: "ACF가 lag 3에서 크면 lag 3이 직접 영향을 준다").
- **그림**: `ts03-rumor.svg`.

### ts-03-3 백색잡음: 더 뽑아낼 게 없는 상태

- **목표**: 백색잡음을 알아보고, Ljung-Box 검정으로 잔차에 패턴이 남았는지 판단할 수 있다.
- **전제**: 귀무가설 · p-값(st-05 제목 링크).
- **개념**: ① 백색잡음 = 평균 0, 분산 일정, 자기상관 없음(동전 던지기) ② 좋은 모델의 잔차는 백색잡음이어야 한다(남은 패턴 = 놓친 정보) ③ Ljung-Box: 귀무가설 "자기상관이 없다", p가 크면 통과 ④ 랜덤워크: 백색잡음을 누적하면 추세처럼 보인다(주가가 예측이 어려운 이유).
- **배치**: S → C(백색잡음 생성 · ACF) → C(랜덤워크 · ACF) → R → S(Ljung-Box) → C(백색잡음 vs flights 원본 p-값) → R.
- **판단**: 검정 방향 오개념이 잦음 → 퀴즈 2(ox: "p=0.9면 잔차에 패턴이 있다", choice: 랜덤워크 그래프 고르기).
- **그림**: `ts03-white-vs-walk.svg`.

### ts-04-1 정상성: 성질이 변하지 않는 시계열

- **목표**: 정상 · 비정상 그래프를 구분하고 정상성이 왜 필요한지 말할 수 있다.
- **개념**: ① 정상성 = 어느 구간을 잘라 봐도 평균 · 흔들림 · 자기상관 모양이 같다 ② 비유: 같은 규칙으로 계속 열리는 시장 vs 해마다 규칙이 바뀌는 시장 ③ 비정상 세 유형: 추세 · 분산 변화 · 계절 ④ 왜 필요한가: 과거에서 배운 패턴이 미래에도 통하려면 성질이 같아야 한다 ⑤ 원리 한 걸음 더: 앞 절반 · 뒤 절반 평균 · 표준편차 비교 셀.
- **배치**: S → F(4칸: 정상 1 + 비정상 3) → C(flights 앞 · 뒤 절반 통계) → R → C(rolling 평균 · 표준편차 겹쳐 그리기) → R.
- **판단**: 그래프 판단 → 퀴즈 2(choice: 정상인 그래프 고르기, ox).

- **전제**: [정밀도, 재현율, F1](#/l/ml-03-2).
- **개념**: ① 추세 · 계절을 빼고 남은 잔차에서 튀는 값 = 맥락 이상 ② `STL(robust=True)`가 필요한 이유(이상이 계절 모양을 오염) ③ 경보 평가: 라벨 창 안에 울리면 적중 ④ 임계값 줄다리기(ml-03-3 연결) ⑤ 현장 기준: 놓치면 얼마, 오경보면 얼마.
- **배치**: S → C(STL 잔차 z) → R(16시간, 12-16 · 02-09 적중) → C(라벨 창과 비교: 정밀도 · 재현율) → T(임계값 3 · 4 · 5) → R.
- **판단**: 코드 실습, 퀴즈 없음.

### ts-09-3 변화점: 수준이 바뀌는 순간

- **목표**: CUSUM으로 평균이 바뀐 시점을 찾을 수 있다.
- **개념**: ① 튀는 값과 다른 문제: 어느 순간부터 수준이 바뀜(부품 마모, 설정 변경) ② CUSUM = 기준에서 벗어난 양을 계속 더하기(통장 잔고 비유) ③ numpy 10줄 구현 ④ 설비 온도의 고장 전조 구간 찾기.
- **배치**: S(통장 비유) → F(누적합 그래프) → C(합성 예: 평균이 중간에 바뀌는 데이터) → C(설비 온도 일 평균 CUSUM) → R → T(허용폭 k 바꾸기).
- **판단**: 퀴즈 1(choice: 변화점 vs 점 이상).
- **그림**: `ts09-cusum.svg`.

### ts-10-1 예측 프로젝트 순서

- **목표**: 질문 정의부터 모니터링까지 순서대로 따라가며 따릉이 7일 예측을 완성한다.
- **개념**: ① 순서 8단계: 질문(무엇을, 며칠 뒤까지, 어떤 단위로) → 빈도 · 결측 → 그래프 · 분해 → 기준 예측 → 후보 모델 → 롤링 원점 검증 → 구간 포함 예측 → 운영 후 오차 모니터링 ② 각 단계에서 앞 레슨 링크.
- **배치**: F(8단계 흐름) → 단계마다 S + C(짧게) → R(최종 비교 표).
- **판단**: 종합 실습, 레슨 완료.
- **그림**: `ts10-workflow.svg`.

### ts-10-2 다음 단계: 딥러닝과 최신 도구

- **목표**: RNN · LSTM, Prophet, 시계열 기초 모델이 언제 쓰이는지 안다.
- **개념**: ① 딥러닝이 유리한 경우: 시계열이 수천 개, 길고 복잡한 패턴, 여러 센서를 함께 → 딥러닝 트랙의 RNN · LSTM 레슨으로 앞으로 링크 ② 고전 모델이 유리한 경우: 데이터가 짧고 해석이 필요할 때 ③ Prophet(휴일 · 추세 변화를 다루는 도구) ④ 시계열 기초 모델(대규모로 미리 학습해 바로 예측) ⑤ 이 사이트에선 실행하지 않는 이유(브라우저 파이썬 미지원), 내 PC 설치는 데이터 분석 트랙의 환경 준비 레슨 링크.
- **배치**: S → R(언제 무엇을 표) → S(도구 소개, 읽기용 코드 한 블록, 실행 셀 아님).
- **판단**: 선택 판단 → 퀴즈 2.
