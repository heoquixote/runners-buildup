# 파이썬 기초 트랙 레슨 기획안

작성 기준은 [README.md](README.md). 기호: `S` 설명, `F` 그림, `C` 실행 셀, `T` 직접 해보기, `R` 결과 해석.

원본은 진성 님의 Python 기초 원고(`docs/sources/python/`, 매핑은 `docs/sources/README.md`)입니다. 원고는 실무자 기준이라, 레슨에서는 원고의 뼈대(왜 필요한가 → 문법 → 언제 쓰나 → 자주 하는 실수)를 가져오고 고등학생~대학 초년생 눈높이로 전제 개념을 보태 풀어 씁니다. 설치 레슨(pb-00-2~4)은 [python-basic-install.md](python-basic-install.md), 2026-11-05 보강 내역은 [python-core.md](python-core.md)에 있습니다.

## 범위와 원칙 (2026-11-06)

- **과정**: QAQC 과정 기준으로 먼저 만든다. 레슨 예제 소재는 제조·품질(로트, 측정값, 규격, 불량, 설비 로그). 기본 데이터 과정 수강생도 같은 레슨을 읽고, 연습문제만 일반 소재(`domain: "general"`)로 바뀐다.
- **우선순위**: 콘텐츠 분량 리스크 대응 순서는 파이썬 → 분석 → 시각화 → 통계 → 머신러닝 → SQL → 딥러닝. 파이썬 기초를 2026-11-09(월)까지 먼저 완성한다.
- **분량 기준**: 확장 기획서의 "코스 하나 = 레슨 3~5개 + 체크 퀴즈 + 연습문제 4~5개". 지금은 코스 12개(pb-01~pb-12) × 레슨 1개라, 코스마다 레슨 2개를 더해 **코스 12개 · 레슨 36개**(소개 코스 pb-00의 4개 제외)로 만든다.
- **연습문제**: 유닛마다 제조 문제 5개 + 개념 퀴즈가 이미 있다. 2개뿐이던 유닛 21 · 22에는 새 레슨 내용에 맞춘 제조 문제를 3개씩 더했다(21-5 조건식 라벨, 21-6 딕셔너리 컴프리헨션, 21-7 여러 기준 정렬, 22-5 표기 섞인 수량 합계, 22-6 실패 행 찾기, 22-7 깨진 설정이면 기본 규격). 기존 QAQC 과제와 중복되는 문제를 만들지 않는다는 규칙도 그대로다.
- **기존 레슨**: id · 퀴즈 · 영상 위치는 그대로 둔다. 새 레슨과 겹치는 부분은 한 줄 연결로 줄이고 자세한 설명은 새 레슨으로 옮긴다.
- **실행 셀**: 셀 하나에 개념 하나, 1~6줄. 에러를 보여 주는 코드는 실행 셀이 아니라 읽기 전용 블록(```python)과 에러 메시지로 보여 준다(검증 스크립트가 에러 나는 셀을 막는다).
- **순서 의존**: pb-06까지는 반복문을 배우기 전이다. pb-01~06 레슨에서는 `for`를 쓰지 않는다.

## 레슨별 기획

### pb-01-2 숫자 계산 자세히: 우선순위 · 누적 · 반올림
- 전제: pb-01-1 사칙연산
- 개념: 연산 우선순위(괄호 → ** → * / // % → + -) · 복합 대입(`+=`) · `/`는 항상 float · 부동소수 오차와 `round()`
- 배치: S(계산 순서 비유: 수학 시간과 같다) → C(괄호 유무 비교) → R → S(불량률 = 불량 / 검사 × 100) → C → T(숫자 바꿔 보기) → S(+= 누적) → C → S(0.1 + 0.2) → C → R → 자주 하는 실수
- 퀴즈: choice(괄호 없는 평균식), ox(`10 / 2`는 int 5)
- 원본: 02-2 연산자와 표현식(우선순위, 복합 대입), 02-1(부동소수점)

### pb-01-3 자료형과 형변환
- 개념: int · float · str · bool, `type()`, `int()` · `float()` · `str()` 변환, 변환 실패(ValueError), `int("3.5")`가 안 되는 이유, 참·거짓으로 평가되는 값(0, 빈 문자열, 빈 리스트)
- 배치: S(값마다 종류가 있다) → C(type 4종) → S(변환) → C → 에러 예시(읽기 전용) → S(bool) → C → 정리 표
- 퀴즈: short(`int("3.5")`의 에러 이름), choice(False로 평가되는 값)
- 원본: 02-1, 02-4 형변환과 불리언 평가

### pb-02-2 문자열 출력 다루기
- 개념: `print`의 여러 값 · `sep` · `end`, 이스케이프(`\n`, `\t`, `\\`), 따옴표 안의 따옴표, 여러 줄 문자열 `"""`
- 배치: S → C(sep) → C(end) → T → S(이스케이프 표) → C → S(""") → C → 자주 하는 실수(파일 경로 역슬래시)
- 퀴즈: choice(`print("A", "B", sep="-")`), ox(`\n`은 두 글자로 센다)
- 원본: 02-3 문자열과 입력/출력

### pb-02-3 슬라이싱으로 코드 해독하기
- 개념: 고정 길이 코드의 자리별 의미, `[시작:끝:간격]`, `[::-1]`, 범위를 넘는 슬라이싱은 에러가 아님, 문자열은 바뀌지 않음(TypeError) → 새로 만들기
- 배치: S(로트 코드 표: 자리 → 뜻) → C(필드 분해) → R → S(간격) → C → T → S(불변) → 에러 예시 → C(새 문자열 만들기)
- 퀴즈: write(코드 뒤집기), ox(문자열 한 글자 대입 가능)
- 원본: 02-3 문자열 인덱싱·슬라이싱

### pb-03-2 찾고 세고 검사하기

#### pb-13-2 datetime: 날짜와 시간 계산하기
- 목표: 날짜 문자열을 datetime으로 바꿔 더하고 빼고, 원하는 모양의 문자열로 되돌린다
- 개념: 네 가지 타입(date · time · datetime · timedelta), now · today, 직접 만들기, 속성(year · month · day · hour, weekday), strftime(날짜 → 문자열) / strptime(문자열 → 날짜) + 포맷 코드 표, 문자열 날짜는 계산 · 비교가 위험한 이유, timedelta 더하기 · 빼기, 두 시각의 차 `.days` · `total_seconds()`, `replace`로 시 · 분 맞추기, 일정 간격 시각 만들기
- 배치: S(달력 · 시계 · 스톱워치 비유) → F(네 타입) → C(now) → C(직접 만들기 + 속성) → S(문자열 ↔ datetime) → F(strftime · strptime 화살표) → C(strftime) → 포맷 표 → C(strptime) → S(왜 바꿔야 하나: 문자열 비교 함정) → C → C(timedelta 더하기) → C(두 시각 빼기) → C(replace + 10분 간격) → R → 정리
- 퀴즈: choice(문자열 "2026-11-07"을 날짜로 바꾸는 함수), write(timedelta로 30일 뒤 날짜 출력)
- 그림: `py-datetime-types.svg`, `py-strftime-strptime.svg`

#### pb-13-3 math와 random: 계산 도구와 난수
- 목표: 올림 · 내림 · 버림과 소수 비교를 math로 하고, seed를 고정해 같은 난수 · 표본을 다시 만든다
- 개념: math.pi · sqrt · factorial, ceil · floor · trunc · round 차이(음수에서 갈림), pow vs `**`(항상 float), isclose, hypot · 각도(:::tip). random.random · randint · uniform · randrange, seed와 재현성, choice · sample · shuffle(제자리, None 반환) · choices(weights), secrets(:::tip)
- 배치: S → C(pi, sqrt) → S(올림 · 내림 · 버림) → F(수직선) → C(양수) → C(음수) → R → S(실무: 박스 수 계산 ceil) → C → S(소수 비교) → C(isclose) → :::tip(pow, hypot, radians) → S(난수) → C(random · randint · uniform) → S(seed) → F → C(seed 두 번) → C(choice · sample) → C(shuffle None 함정) → C(choices weights) → :::tip(secrets) → 정리
- 퀴즈: choice(`math.floor(-2.5)`), ox(seed를 같은 값으로 고정하면 같은 순서의 난수가 나온다)

#### pb-13-4 os: 폴더와 파일 경로 다루기

- 개념: 작업 폴더(현재 위치)와 상대 · 절대 경로, 이 사이트의 임시 연습 폴더, getcwd · listdir, `os.path.join`(운영체제마다 구분자 다름), exists · isfile · isdir, abspath · dirname · basename · splitext, makedirs(exist_ok), rename, walk, os.name · environ(:::tip), pathlib(:::tip)
- 배치: S(폴더 = 서랍, 경로 = 주소) → F(폴더 나무와 상대 · 절대 경로) → S(이 사이트의 연습 폴더) → C(getcwd · listdir) → C(join) → C(exists 등) → C(abspath · dirname · basename · splitext) → C(makedirs 두 번) → R(exist_ok 없으면 FileExistsError, 읽기 전용 블록) → C(rename · walk) → :::tip(os.name · environ) → S(종합 예제: 날짜별 검사 로그) → C(원고 실습 정답, 고정 날짜 대신 오늘 날짜) → R → :::tip(pathlib) → 정리
