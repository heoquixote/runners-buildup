# 통계 트랙 레슨 기획안

작성 기준은 [README.md](README.md). 기호: `S` 설명, `F` 그림, `C` 실행 셀, `T` 직접 해보기, `R` 결과 해석.

원본은 진성 님의 통계 기초 원고(`docs/sources/stats/`, 8장 24쪽, 매핑은 `docs/sources/README.md`)입니다. 원고는 실무자(전환율·KPI·A/B 테스트) 기준이라, 레슨에서는 **원고의 뼈대(왜 필요한가 → 정의 → 언제 쓰나 → 자주 하는 실수 → 대안)**를 그대로 가져오고, 고등학생~대학 초년생 눈높이로 전제 개념을 보태 풀어 씁니다. 원고의 "한 문장 정리"는 레슨 끝 정리 문단으로 살립니다.

## 왜 개편하나

기존 트랙은 코스 8개 × 레슨 1개(레슨마다 긴 셀 3~4개)라서

1. 통계를 처음 보는 학생에게 **"왜 이걸 배우나, 모집단·표본이 뭔가"** 같은 출발점이 없었고,
2. 한 레슨에 개념이 4~5개씩 몰려 있었으며(예: st-05-1에 p-value · 1표본 · Welch · 대응 · 단측 · 검정력),
3. 확률 기초(사건·조건부확률·베이즈)와 "통계 해석 실수"(상관 ≠ 인과, 심슨의 역설, 보고 방법)가 빠져 있었습니다.

개편 후에는 **코스 11개 · 레슨 28개**로 늘리고, 레슨 하나에 큰 개념 하나만 둡니다. 셀은 개념 하나당 1~4줄(데이터 읽기·import 제외)로 쪼개고, 셀 앞에 무엇을 보는 셀인지 한두 문장, 셀 뒤에 실행 결과 숫자를 짚는 해석을 둡니다.

## 공통 규칙

- 셀 하나 = 개념 하나, 1~4줄(데이터 읽기와 import 제외). 셀은 각자 독립 실행되므로 import·데이터 읽기·변수 정의를 셀마다 반복하고 import는 맨 위.
- 시뮬레이션은 `np.random.default_rng(0)`처럼 시드를 고정해 본문의 숫자와 실행 결과가 항상 같게 한다.
- 실행 결과에 나온 숫자를 본문 R 문단에서 그대로 짚는다.
- 수식은 꼭 필요할 때 한 줄. 기호보다 말로 먼저 설명("평균에서 얼마나 떨어져 있는지를 표준편차 몇 개로 잰 값").
- 그래프 글자는 영어. 그림(SVG)은 개념도 위주로 레슨마다 1~2개, `content/img/stats/`.
- 외부 자료는 링크로: [scipy.stats 문서](https://docs.scipy.org/doc/scipy/reference/stats.html) 등.

## st-00-1 통계는 왜 배울까 (트랙 소개)

- **목표**: "통계 = 일부만 보고, 흔들리는 숫자로, 믿을 만한 결론을 내리는 방법"을 자기 말로 설명할 수 있다.
- **전제 개념**: 없음. 평균을 구할 줄 알면 충분. 코드는 읽고 실행만.
- **알아야 할 개념**
  1. 우리가 데이터에서 부딪히는 두 가지 한계: 전체를 다 볼 수 없다 / 숫자는 매번 흔들린다(노이즈)
  2. 같은 식당의 두 날 평균 팁이 다르다 — 이건 진짜 차이일까 우연일까? (tips 토요일 vs 일요일)
  3. 통계가 하는 두 가지 일: **기술**(지금 있는 데이터를 요약) · **추론**(일부로 전체에 대해 조심스럽게 말하기)
  4. 기술 문장 vs 추론 문장 구분하기 (원고 01-3의 예문을 학생 눈높이로)
  5. 통계가 없으면 생기는 실수 세 가지: 평균 하나로 판단 / 편향된 표본 / "유의하다 = 중요하다"
  6. 좋은 분석가의 세 문장: "이런 패턴이 보입니다 · 다만 이런 한계가 있습니다 · 그래서 여기까지 말할 수 있습니다"
  7. 이 트랙의 지도: 요약 → 확률 → 표본 → 추정 → 검정 → 관계 → 실험 → 해석
- **배치**: S(전학 온 첫날 반 평균 키 비유: 몇 명만 보고 짐작) → S(두 가지 한계) → C(tips 전체 평균 팁) → C(토·일 평균 팁 비교) → R(3.26 vs 2.99, 차이 0.26달러) → S(이 차이는 진짜?) → C(같은 데이터에서 무작위 40건씩 두 번 뽑아 평균 비교) → R(같은 식당인데도 평균이 다르게 나옴 = 흔들림) → **T**(seed 바꿔 보기) → S(기술 vs 추론) → **F1** → S(문장 구분 표) → S(통계가 없을 때의 실수 3가지) → S(세 문장 태도) → **F2** 트랙 지도 → S(한 문장 정리)
- **퀴즈 vs 코드**: **퀴즈 2문항**. 목표가 "기술 vs 추론 문장 판단"이라 상황형 퀴즈가 효과적. 코드는 관찰용.
  - choice: 다음 중 추론통계 문장은? / ox: 데이터가 아주 많으면 표본 편향 문제는 저절로 사라진다(X)
- **그림**: F1 기술통계(손에 든 데이터 요약) → 추론통계(모집단에 대해 말하기) 흐름도, F2 트랙 지도(DAY 01~11 징검다리)
- **연결 실습**: 없음 (소개 코스)
- **원본 원고**: 01-1-why-statistics(두 한계, 전환율 4.8% 질문 목록, 자주 하는 오해, 세 문장 태도), 01-3-descriptive-vs-inferential(기술 vs 추론, 좋은 분석 흐름 4단계, "지도와 판단" 한 문장 정리). KPI·믹스 변화·모델 성능 재현성 같은 실무 사례는 빼고 식당 팁·반 평균 키로 바꿈.

## st-00-2 데이터의 재료: 모집단 · 표본 · 변수 · 척도

- **목표**: 데이터 표를 보고 모집단·표본·변수·관측치를 짚고, 변수마다 척도를 정해 알맞은 요약(평균·중앙값·빈도)을 고를 수 있다.
- **전제 개념**: st-00-1의 "일부로 전체를 짐작한다". pandas로 CSV 읽기(데이터 분석 트랙)는 몰라도 실행만 하면 됨.
- **알아야 할 개념**
  1. 모집단(알고 싶은 전체)과 표본(실제로 본 일부): 국 간 보기 비유(한 숟가락으로 냄비 전체 맛)
  2. 모수(모집단의 값, 보통 모름)와 통계량(표본에서 계산한 값)
  3. 관측치(행 하나)와 변수(열 하나): 타이타닉 표로 짚기
  4. 변수의 두 종류: 범주형(이름표) · 수치형(셀 수 있거나 잴 수 있는 값)
  5. 척도 4가지: 명목 · 서열 · 등간 · 비율 — 각 척도에서 "할 수 있는 계산"
  6. 숫자로 적혀 있어도 범주일 수 있다: `pclass`(1·2·3등석), `survived`(0·1)
  7. 척도에 맞는 요약: 명목 → 빈도·비율·최빈값, 서열 → 중앙값, 비율척도 → 평균·표준편차
  8. 데이터 사전(변수 이름 · 뜻 · 종류 · 척도)을 먼저 적는 습관
- **배치**: S(국 맛보기 비유) → **F1**(모집단 ⊃ 표본, 모수 ↔ 통계량) → S(타이타닉 이야기: 우리가 가진 891명은 전체 승객 약 2,200명 중 일부) → C(head) → R(행 = 승객 한 명, 열 = 변수) → C(shape) → S(범주형 vs 수치형) → C(dtypes) → R(숫자 dtype인데 범주인 열 찾기) → S(척도 4가지 표) → **F2**(척도 사다리: 할 수 있는 계산이 하나씩 늘어남) → S(pclass 평균 2.31의 함정) → C(pclass 평균) → R(의미 없는 숫자) → C(pclass 빈도) → R → S(서열척도엔 중앙값) → C(age 평균·표준편차: 비율척도) → S(섭씨온도 20도는 10도의 두 배로 덥다? 등간척도) → S(데이터 사전 표 예시) → S(한 문장 정리)
- **퀴즈 vs 코드**: **퀴즈 3문항**. 척도 판단은 분류 감각이라 퀴즈가 효과적.
  - choice: 만족도 1~5점은 어떤 척도? (서열) / choice: 지역 코드(1=서울, 2=부산…)에 알맞은 요약은? (빈도·최빈값) / ox: 표본에서 계산한 평균은 모집단 평균과 항상 같다(X)
- **그림**: F1 모집단·표본·모수·통계량 도식, F2 척도 사다리(명목 → 서열 → 등간 → 비율, 칸마다 가능한 연산 = · < − ÷)
- **연결 실습**: 없음
- **원본 원고**: 01-2-population-sample-variable-scale 전체(용어 정의, 척도 4종 + 가능한 일·주의점, 척도를 무시한 문제 3가지, 데이터 사전 권장 항목). 온라인 강의 만족도 예 → 타이타닉으로 바꿈.

## st-01-1 대표값: 평균 · 중앙값 · 최빈값

- **목표**: 평균·중앙값·최빈값을 구하고, 데이터 모양(치우침·이상치)을 보고 어떤 대표값을 보고할지 고를 수 있다.
- **전제 개념**: st-00-2 척도(명목은 최빈값, 수치는 평균·중앙값).
- **알아야 할 개념**
  1. 대표값이 필요한 이유: 244개 숫자를 한 줄로 말하기
  2. 평균: "모두 똑같이 나눠 가지면" 비유. 모든 값을 반영하지만 극단값에 끌려감 (시소의 균형점)
  3. 중앙값: 키 순서로 줄 세운 가운데 사람. 이상치에 강함. 짝수 개면 가운데 둘의 평균
  4. 최빈값: 가장 흔한 값. 범주형에도 쓸 수 있음
  5. 이상치 하나가 평균을 얼마나 끌고 가나 (반 친구 10명 용돈 + 재벌 친구 1명)
  6. 오른쪽 꼬리 분포에서 평균 > 중앙값 (tips total_bill, titanic fare)
  7. 언제 무엇을 쓰나 표, 그리고 "두 값을 함께 쓰는" 습관
- **배치**: S(대표값 왜) → S(평균 정의 + 시소 비유) → **F1** → C(작은 리스트 평균) → C(tips total_bill 평균) → S(중앙값 정의) → C(np.median, 홀수·짝수) → C(tips 중앙값) → R(19.79 vs 17.80) → S(최빈값) → C(tips size 최빈값 = 2명) → C(day 최빈값 = Sat) → S(이상치 실험) → C(용돈 10명 평균·중앙값) → C(1명 추가 후) → R → **T**(이상치 값을 바꿔 보기) → S(꼬리 분포) → C(titanic fare 평균 vs 중앙값) → R(32.2 vs 14.45 — 평균이 두 배) → S(선택 표) → S(자주 하는 실수 3가지) → S(정리)
- **퀴즈 vs 코드**: **퀴즈 2문항**. 기존 "이상치가 있는 데이터의 대표값" choice 유지 + choice "가장 많이 팔린 색상(빨강·파랑·검정)의 대표값은?"(최빈값).
- **그림**: F1 시소(평균 = 균형점)와 줄 세우기(중앙값 = 가운데) 비교 그림
- **원본 원고**: 02-1-central-tendency(평균·중앙값·최빈값 장단점, 언제 쓰나, 자주 하는 실수 3가지). 결제금액 예 → 용돈·식당 계산서.

## st-01-2 흩어짐: 범위 · 분산 · 표준편차 · 변동계수

- **목표**: 평균이 같아도 흩어짐이 다르면 다른 데이터라는 것을 범위·표준편차로 보여 주고, 단위가 다르면 변동계수로 비교할 수 있다.
- **전제 개념**: st-01-1 평균.
- **알아야 할 개념**
  1. 왜 흩어짐이 필요한가: 평균 3일 배송인 두 택배사(늘 3일 vs 1일~8일) — 원고 사례
  2. 범위 = 최댓값 − 최솟값. 쉽지만 양 끝 두 값에만 의존
  3. 편차(값 − 평균)와 편차의 합은 항상 0 → 그래서 제곱한다
  4. 분산 = 편차 제곱의 평균, 단위도 제곱(g²)
  5. 표준편차 = √분산, 원래 단위로 돌아옴 "평균에서 보통 이만큼 떨어져 있다"
  6. 표본이면 n − 1로 나눈다 (ddof=1), pandas 기본값, NumPy 기본값 차이
  7. 변동계수 CV = 표준편차 ÷ 평균: 단위나 크기가 다른 것끼리 비교 (펭귄 몸무게 g vs 지느러미 mm)
- **배치**: S(택배 비유) → **F1**(평균은 같고 흩어짐이 다른 두 점 그림) → C(두 택배사 평균) → C(두 택배사 범위) → R → S(편차) → C(편차와 그 합) → R(합이 0) → S(분산) → C(직접 계산 vs np.var) → S(표준편차) → C(np.std) → R → S(n−1 표) → C(ddof=0 vs ddof=1 vs pandas) → R → C(penguins 종별 몸무게 평균·표준편차) → R → S(단위가 다를 때) → C(몸무게 std vs 지느러미 std — 비교 불가) → C(CV) → R → **T**(ai4i 열 바꿔 CV 비교) → S(자주 하는 실수) → S(정리)
- **퀴즈 vs 코드**: **퀴즈 2문항**. 기존 ox "np.std(x, ddof=1)" 문항을 이 레슨으로 옮김 + short "값 2, 4, 6의 분산(n으로 나눔)은?" 손 계산(8/3≈2.67 → 답 "2.67").
- **그림**: F1 평균선이 같은 두 점 줄(좁게 vs 넓게), 편차 화살표
- **원본 원고**: 02-2-dispersion(범위·분산·표준편차·IQR, std vs IQR 선택, CV·MAD 대안, 자주 하는 실수). 사분위수·IQR은 st-01-3으로 넘김.

## st-01-3 위치와 이상치: 사분위수 · 상자그림 · z점수

- **목표**: 사분위수로 IQR 이상치 기준을 계산하고, z점수로 "평균에서 표준편차 몇 개만큼 떨어졌나"를 말할 수 있다.
- **전제 개념**: st-01-1 중앙값, st-01-2 표준편차.
- **알아야 할 개념**
  1. 백분위수: 100명 중 아래에서 몇 번째 (성적표 상위 %)
  2. 사분위수 Q1·Q2·Q3, IQR = Q3 − Q1 (가운데 50%의 폭)
  3. 1.5 × IQR 규칙: 상자그림 수염이 바로 이 기준 (da-09-3의 상자그림 연결)
  4. describe() 한 줄로 다섯 숫자 요약
  5. z점수 = (값 − 평균) ÷ 표준편차. 서로 다른 시험 점수 비교 비유(국어 80점 vs 수학 70점)
  6. |z| > 3 규칙과 그 한계(치우친 분포에서는 IQR이 더 안전)
  7. 이상치는 지우기 전에 이유부터: 입력 실수 vs 진짜 드문 값
- **배치**: S(백분위 비유) → C(np.percentile 25·50·75) → S(사분위수·IQR) → **F1**(상자그림 = 다섯 숫자) → C(titanic fare Q1·Q3·IQR) → C(이상치 기준) → C(이상치 개수) → R(116명, 꽤 많음 → 꼬리가 긴 데이터에선 '이상'이 아니라 '드문 비싼 표') → C(describe) → S(z점수 + 시험 비유) → **F2**(정규 곡선 위 z = −2…2 눈금) → C(두 과목 점수 z 비교) → R → C(tips total_bill z점수 최대) → R → S(|z|>3 규칙) → C(z 기준 이상치 수 vs IQR 기준) → R → **T**(1.5를 3으로 바꿔 보기) → S(이상치 처리 원칙) → S(정리)
- **퀴즈 vs 코드**: **레슨 완료**. 기준값을 바꾸며 이상치 수가 바뀌는 T 셀이 핵심이고 계산 절차는 유닛 12 실습 문제(IQR 이상치)가 맡는다.
- **그림**: F1 상자그림 해부(최솟값 쪽 수염 · Q1 · 중앙값 · Q3 · 수염 · 이상치, 아래에 1.5 × IQR 자), F2 정규 곡선과 z 눈금
- **원본 원고**: 02-2 사분위수·IQR 절, 02-3-shape-and-outlier의 이상치 절(이상치 = 오류? 아니면 신호?, 처리 원칙).

## st-01-4 분포의 모양: 히스토그램 · 왜도 · 첨도

- **목표**: 히스토그램을 보고 대칭·오른쪽 꼬리·왼쪽 꼬리·봉우리 둘을 말하고, 왜도로 숫자 확인, 로그 변환으로 꼬리를 줄일 수 있다.
- **전제 개념**: st-01-1 평균 vs 중앙값, 히스토그램(da-09-3).
- **알아야 할 개념**
  1. 분포 = 값이 어디에 얼마나 몰려 있나
  2. 대칭 / 오른쪽 꼬리(양의 왜도) / 왼쪽 꼬리(음의 왜도) — 평균·중앙값 위치로 구분
  3. 왜도(skewness): 0이면 대칭, +면 오른쪽 꼬리
  4. 첨도(kurtosis): 꼬리가 얼마나 두꺼운가(극단값이 얼마나 자주 나오나). 정규분포 기준 0(scipy 기본 Fisher)
  5. 봉우리 두 개 = 다른 무리가 섞였다는 신호 (펭귄 지느러미)
  6. 로그 변환: 곱으로 커지는 값(요금·소득)의 꼬리 줄이기
  7. 모양을 먼저 봐야 하는 이유: 평균·t검정이 흔들리는 경우
- **배치**: S(분포란) → **F1**(세 모양 + 평균·중앙값 위치) → C(penguins 몸무게 히스토그램 + 평균·중앙값) → R(거의 대칭) → C(titanic fare 히스토그램) → R(오른쪽 꼬리) → S(왜도) → C(두 변수 왜도) → R(0.47 vs 4.79) → S(첨도) → C(첨도) → R → S(봉우리 둘) → C(지느러미 히스토그램) → C(종별 중앙값) → R → S(로그 변환) → C(np.log1p 후 히스토그램 + 왜도) → R → **T**(tips total_bill로 바꿔 보기) → S(모양을 먼저 보는 이유) → S(정리)
- **퀴즈 vs 코드**: **퀴즈 2문항**. choice: 평균 > 중앙값이면 어떤 모양? / ox: 왜도가 0에 가까우면 이상치가 없다(X).
- **그림**: F1 세 분포 모양(왼쪽 꼬리·대칭·오른쪽 꼬리)과 평균·중앙값·최빈값 위치
- **연결 실습**: 유닛 12 (st-01 코스 마지막)
- **원본 원고**: 02-3-shape-and-outlier(왜도·첨도 의미, 분포 모양이 평균·검정에 주는 영향, 로그 변환 대안).

## st-09-1 사건과 확률, 큰 수의 법칙

- **목표**: 확률을 "같은 일을 아주 많이 반복했을 때 그 일이 일어나는 비율"로 이해하고, 시뮬레이션으로 확률을 근사할 수 있다.
- **전제 개념**: 비율(%) 계산.
- **알아야 할 개념**
  1. 실험·결과·표본공간·사건 (주사위 한 번 던지기)
  2. 확률 = 사건에 속한 결과 수 ÷ 전체 결과 수 (모든 결과가 똑같이 그럴듯할 때)
  3. 확률의 규칙 3개: 0~1 / 전체는 1 / 여사건 1 − P
  4. 파이썬으로 던지기: `rng.integers`, 시드
  5. 큰 수의 법칙: 많이 던질수록 비율이 확률에 다가간다 (10번 vs 10,000번)
  6. 합사건(또는)·곱사건(그리고), 독립이면 곱하기
  7. 데이터에서의 확률 = 상대도수 (타이타닉 생존 비율 0.384)
- **배치**: S(용어: 주사위) → **F1**(표본공간·사건 벤 다이어그램) → S(확률 정의) → C(짝수 확률 3/6) → S(규칙 3개) → S(시뮬레이션이란) → C(주사위 10번) → C(10번 중 짝수 비율) → R → C(10,000번) → R → **F2**(던진 횟수 ↑ 비율이 0.5로 수렴 선 그래프) → C(누적 비율 그래프) → R → **T**(횟수 바꿔 보기) → S(또는·그리고) → C(동전 두 개 둘 다 앞면 시뮬레이션 vs 0.25) → R → S(데이터 속 확률) → C(titanic 생존 비율) → R → S(정리)
- **퀴즈 vs 코드**: **퀴즈 2문항**. short: 주사위 한 번에 3 이하가 나올 확률(1/2, "0.5") / ox: 동전을 10번 던져 앞면이 7번 나왔으니 이 동전은 앞면 확률이 0.7이다(X, 적게 던지면 흔들림).
- **그림**: F1 주사위 표본공간과 사건 A(짝수)·B(4 이상) 벤 다이어그램, F2 큰 수의 법칙 개념 곡선

## st-09-2 조건부확률과 베이즈 정리

- **목표**: "~일 때 ~일 확률"을 교차표에서 계산하고, 검사 양성일 때 실제로 병일 확률을 베이즈 정리로 구할 수 있다.
- **전제 개념**: st-09-1 확률 = 비율.
- **알아야 할 개념**
  1. 조건부확률 P(A|B): "B인 사람들만 모아 놓고 그중 A의 비율" — 분모가 바뀐다
  2. 교차표(crosstab)로 계산: P(생존|여성) = 233/314 = 0.742, P(생존|남성) = 0.189
  3. P(A|B) ≠ P(B|A): P(여성|생존) = 0.681 vs P(생존|여성) = 0.742
  4. 독립: P(A|B) = P(A)이면 B가 A에 대해 아무 정보도 주지 않음
  5. 베이즈 정리: 새 정보를 보고 믿음을 고친다(사전확률 → 사후확률)
  6. 검사 양성 문제: 유병률 1%, 민감도 90%, 위양성 5% → 양성일 때 진짜 병일 확률 15.4%
  7. 자연빈도(10,000명으로 바꿔 세기)로 직관 만들기
  8. 나이브 베이즈 분류기로 이어진다 (머신러닝 영상 연결)
- **배치**: S(우산 비유: 비 올 확률 vs 하늘이 흐릴 때 비 올 확률) → C(titanic 생존율 전체) → C(crosstab) → S(조건부확률 = 분모 바꾸기) → **F1**(전체 사각형 → 여성 칸만 잘라서 보기) → C(P(생존|여성), P(생존|남성)) → R → S(뒤집으면 다르다) → C(P(여성|생존)) → R → C(normalize="index" 한 줄) → S(독립) → C(pclass별 생존율) → R(독립이 아님) → S(베이즈: 검사 이야기) → **F2**(10,000명 자연빈도 나무: 병 100 → 양성 90 / 건강 9,900 → 양성 495) → C(자연빈도 계산) → R(15.4%) → C(베이즈 공식으로 같은 값) → **T**(유병률을 10%로 바꿔 보기) → R → S(나이브 베이즈 연결) → ::video{dl-m33} → S(정리)
- **퀴즈 vs 코드**: **퀴즈 3문항**. 조건부확률은 "분모 선택"이 핵심이라 short 계산 + 오개념 확인.
  - short: 표(남 60명 중 흡연 15, 여 40명 중 흡연 4)에서 P(흡연|남) ("0.25") / choice: P(A|B)와 P(B|A) 관계 / ox: 검사 정확도가 90%면 양성이 나온 사람의 90%는 병이 있다(X)
- **그림**: F1 교차표에서 한 줄만 잘라 보기(분모가 바뀌는 모습), F2 자연빈도 나무
- **영상 위치**: 베이즈 → 나이브 베이즈 연결 문단 바로 뒤에 dl-m33(머신러닝 영상, 공개됨)
- **원본 원고**: 03-2-conditional-probability-and-bayes(조건부확률 정의, 기저율 무시 오류, 베이즈 갱신). 실무 이탈 예측 예 → 타이타닉과 검사 양성.

## st-02-1 확률변수와 확률분포

- **목표**: 확률변수를 "결과에 숫자를 붙인 것"으로 이해하고, 확률분포를 표·막대그래프로 나타내고, pmf(딱 그 값)와 cdf(그 값 이하)를 구분할 수 있다.
- **전제 개념**: st-09-1 확률, 시뮬레이션.
- **알아야 할 개념**
  1. 확률변수 X: 결과 → 숫자 (동전 두 개 던져 앞면 수 X = 0, 1, 2)
  2. 확률분포: X가 가질 수 있는 값마다 확률을 적은 표 (합 = 1)
  3. 이산(셀 수 있는 값) vs 연속(재는 값) 확률변수
  4. pmf: P(X = k) "딱 k일 확률"
  5. cdf: P(X ≤ k) "k 이하일 확률" (계단처럼 쌓인다)
  6. 기댓값 = 값 × 확률의 합 (오래 반복했을 때의 평균)
  7. 실제 데이터의 분포 = 상대도수 (tips 인원 수)
  8. 연속형은 "딱 그 값"의 확률이 0, 구간의 넓이로 확률을 잰다 (밀도 곡선)
  9. scipy.stats의 공통 메서드 미리 보기: pmf/pdf, cdf, sf, ppf, rvs
- **배치**: S(확률변수 정의 + 동전 두 개) → **F1**(결과 4개 → X 값 3개로 묶이는 그림) → C(확률분포 표 직접 만들기) → R → C(시뮬레이션으로 확인) → S(pmf vs cdf) → **F2**(pmf 막대와 cdf 계단) → C(cumsum으로 cdf) → R → S(기댓값) → C(기댓값 계산 + 시뮬레이션 평균) → R → S(데이터의 분포) → C(tips size 상대도수) → R → C(size 기댓값 = 평균) → S(연속형과 밀도) → C(penguins 몸무게 구간 비율) → R → S(scipy.stats 메서드 표) → S(정리)
- **퀴즈 vs 코드**: **퀴즈 2문항**. choice: "불량 2개 이하일 확률"을 구하는 메서드(cdf) — 기존 문항을 여기로 옮김 / short: X가 0, 1, 2를 각각 확률 0.25, 0.5, 0.25로 가질 때 기댓값("1").
- **그림**: F1 결과 → 확률변수 값 매핑, F2 pmf 막대 vs cdf 계단
- **원본 원고**: 03-3-random-variable-and-distribution(확률변수, 이산·연속, pmf·pdf·cdf, 기댓값·분산).

## st-02-2 이항분포와 포아송분포

- **목표**: "n번 해서 k번 성공할 확률"은 이항, "일정 시간·공간에 k건 일어날 확률"은 포아송으로 계산할 수 있다.
- **전제 개념**: st-02-1 pmf·cdf.
- **알아야 할 개념**
  1. 베르누이 시행: 결과가 둘(성공·실패), 성공 확률 p
  2. 이항분포 B(n, p): 같은 시행 n번, 서로 독립, 성공 수 k
  3. 실데이터 연결: AI4I 고장률 p = 0.0339 → 설비 100대 중 고장 수
  4. pmf(딱 k), cdf(k 이하), sf(k 초과 = 1 − cdf) — "이상"과 "초과" 구분
  5. 평균 np, 분산 np(1−p)
  6. 포아송분포: 평균 λ만 알면 됨 (하루 고객 문의 수, 시간당 불량)
  7. 이항에서 n이 크고 p가 작으면 포아송과 거의 같다 (λ = np)
  8. 어떤 분포를 고를지 판단 표
- **배치**: S(베르누이) → C(ai4i 고장률) → S(이항분포 정의 + 조건) → **F1**(설비 100대 = 동전 100번 비유와 막대 분포) → C(binom.pmf(3)) → R → C(cdf(3)) → C(sf(5)) → R(이상 vs 초과 주의 표) → C(분포 막대 그래프) → C(mean, var) → R → **T**(p를 0.1로 바꾸면) → S(포아송) → C(poisson pmf: 하루 평균 4건) → C(cdf) → R → S(이항 ≈ 포아송) → C(두 분포 pmf 나란히) → R → S(분포 고르기 표) → S(정리)
- **퀴즈 vs 코드**: **퀴즈 2문항**. 기존 choice "pmf/cdf/sf/ppf" 중 sf 버전 새로 + choice "하루 평균 3건 들어오는 민원 수" 분포 고르기(포아송).
- **그림**: F1 이항분포 조건 4가지 체크리스트 + 막대 모양
- **원본 원고**: 03-3의 이산 분포 절. 기존 st-02-1 레슨의 이항·포아송 예제(불량 수)를 실데이터 고장률로 교체.

## st-02-3 정규분포와 표준화

- **목표**: 평균·표준편차로 정규분포를 정하고, 구간 확률(cdf)과 경계값(ppf)을 구할 수 있다.
- **전제 개념**: st-01-3 z점수, st-02-1 연속형 밀도.
- **알아야 할 개념**
  1. 정규분포: 평균을 중심으로 좌우 대칭인 종 모양, 평균 μ와 표준편차 σ 두 숫자로 결정
  2. 왜 자주 나오나: 작은 영향이 많이 더해진 값(키·측정 오차) — 중심극한정리 예고
  3. 68-95-99.7 규칙
  4. 표준정규분포와 z = (x − μ)/σ
  5. norm.cdf: x 이하 확률, 구간 확률 = cdf(b) − cdf(a)
  6. norm.ppf: 확률 → 경계값 (상위 5% 기준값)
  7. 실데이터가 정규에 가까운지 보기: 히스토그램에 정규 곡선 겹치기 (ai4i 공기 온도)
  8. 모든 데이터가 정규는 아니다 (titanic fare)
- **배치**: S(종 모양 정의) → **F1**(정규 곡선 + 68·95·99.7 띠) → C(평균·σ가 다른 곡선 두 개) → R → S(68-95-99.7) → C(시뮬레이션으로 ±1σ 비율) → R → S(표준화) → C(z 계산) → S(cdf로 확률) → C(norm.cdf) → C(구간 확률) → R → S(ppf) → C(ppf(0.95)) → R → S(실데이터) → C(ai4i air_temp 평균·σ) → C(히스토그램 + 정규 곡선) → R → C(정규 가정으로 계산한 비율 vs 실제 비율) → R → **T**(fare로 바꾸면 크게 어긋남) → S(정리)
- **퀴즈 vs 코드**: **퀴즈 2문항**. 기존 choice "평균과 표준편차로 정해지는 연속 분포" 유지 + short "평균 ± 2σ 안에 들어갈 확률은 약 몇 %?"("95").
- **그림**: F1 68-95-99.7 정규 곡선
- **연결 실습**: 유닛 13
- **원본 원고**: 03-3 연속 분포·정규분포 절.

## st-03-1 표본 뽑기와 편향

- **목표**: 무작위 추출이 왜 필요한지 설명하고, 편향된 방법으로 뽑은 표본이 얼마나 틀린 숫자를 만드는지 실데이터로 보일 수 있다.
- **전제 개념**: st-00-2 모집단·표본, 모수·통계량.
- **알아야 할 개념**
  1. 왜 전부 보지 않나: 시간·비용, 파괴 검사(라면 맛 검사 비유)
  2. 단순 무작위 추출: 모두에게 똑같은 기회 (`df.sample`)
  3. 편향(bias): 표본 숫자가 한쪽으로 꾸준히 어긋나는 것 — 표본을 키워도 안 고쳐진다
  4. 편향의 종류: 선택 편향, 무응답 편향, 생존자 편향(살아 돌아온 비행기 이야기)
  5. 층화 추출: 무리별 비율을 맞춰 뽑기
  6. 데이터가 많다고 편향이 사라지지 않는다
- **배치**: S(라면·국 비유) → **F1**(과녁: 편향 vs 흔들림) → C(타이타닉 = 우리의 모집단, 실제 생존율 0.384) → C(무작위 100명 생존율) → R → **T**(seed 바꾸기) → S(편향된 표본: 1등석 객실 근처에서만 인터뷰) → C(1등석에서만 100명) → R(0.63, 크게 어긋남) → C(편향된 표본 크기를 200으로 키워도) → R(여전히 어긋남) → S(편향 종류 3가지 + 생존자 편향 이야기) → S(층화 추출) → C(pclass 비율 맞춰 뽑기) → R → S(자주 하는 오해) → S(정리)
- **퀴즈 vs 코드**: **퀴즈 2문항**. choice: 학교 앞 학원가에서만 설문했을 때 생기는 문제(선택 편향) / ox: 표본을 10배로 늘리면 편향도 줄어든다(X).
- **그림**: F1 과녁 4칸(편향 작음·큼 × 흔들림 작음·큼)
- **원본 원고**: 04-1-sampling-and-bias(추출 방법, 편향 종류, 많은 데이터 ≠ 편향 없음).

## st-03-2 표본평균의 분포와 표준오차

- **목표**: 표본평균도 뽑을 때마다 흔들리는 값이며, 그 흔들림의 크기(표준오차)가 σ/√n이라는 것을 시뮬레이션으로 확인할 수 있다.
- **전제 개념**: st-03-1 무작위 표본, st-01-2 표준편차.
- **알아야 할 개념**
  1. 표본평균은 표본마다 다르다 (같은 반 5명씩 뽑아 평균 키)
  2. 표본분포: 표본평균을 아주 많이 모아 그린 분포
  3. 표본분포의 중심 = 모평균 (치우침 없음)
  4. 표준오차(SE) = 표본평균들의 표준편차 = σ/√n
  5. n을 4배로 → SE는 절반 (√ 관계)
  6. 표준편차(값들의 흩어짐) vs 표준오차(평균의 흔들림) 구분
- **배치**: S(반 평균 키 비유) → C(ai4i tool_wear 모평균·σ) → C(표본 30대 평균 한 번) → C(다섯 번) → R → S(표본분포) → **F1**(모집단 → 표본 여러 개 → 평균들 → 히스토그램) → C(1,000번 반복 평균의 평균·표준편차) → R(모평균과 거의 같음, 흩어짐 11.6) → S(표준오차 공식) → C(σ/√n 계산) → R(이론과 시뮬레이션 일치) → C(n = 10, 40, 160의 SE) → R(4배 → 절반) → **T**(n 바꾸기) → S(std vs SE 표) → C(표본 하나로 SE 추정: std(ddof=1)/√n, stats.sem) → S(정리)
- **퀴즈 vs 코드**: **퀴즈 2문항**. 기존 short-choice "σ=6, n=9 → SE" + ox "표본 크기 커지면 좁아진다" 유지.

## st-03-3 중심극한정리

## st-04-1 95% 신뢰구간의 뜻

- **목표**: 신뢰구간 = 점 하나 대신 "이 범위쯤"이라고 말하는 방법임을 알고, 95%가 "구간을 만드는 방법의 성공률"이라는 것을 시뮬레이션으로 설명할 수 있다.
- **전제 개념**: st-03-2 SE, st-02-3 ppf(1.96).
- **알아야 할 개념**
  1. 점추정(평균 하나)의 한계 → 구간추정(범위)
  2. 일기예보 비유: "내일 최고 기온 18~22도"
  3. 구간 = 추정값 ± (몇 배) × SE, 95%면 약 1.96배
  4. 95%의 뜻: 같은 방법으로 100번 표본을 뽑아 구간을 만들면 약 95개가 참값을 포함
  5. 흔한 오해: "참값이 이 구간에 있을 확률이 95%"(이미 만든 구간은 포함하거나 안 하거나)
  6. 신뢰수준 ↑ → 구간 넓어짐, n ↑ → 구간 좁아짐
- **배치**: S(점 vs 구간, 일기예보) → S(구간 만들기 공식 한 줄) → C(penguins 몸무게를 모집단으로: 참 평균) → C(표본 25마리로 구간 하나) → R → ::video{dl-m07} → S(100번 반복) → C(100개 구간 중 참값 포함 개수) → R(95개 근처) → C(구간 100개 그래프: 놓친 구간 빨간색) → **F1**(구간 막대들과 참값 선 개념도) → S(오해 바로잡기) → S(신뢰수준과 폭) → C(90·95·99% 배수 ppf) → C(구간 폭 비교) → R → **T**(n 바꾸기) → S(정리)
- **퀴즈 vs 코드**: **퀴즈 2문항**. choice: 95% 신뢰구간의 올바른 해석 / ox: 표본 수를 늘리면 구간이 좁아진다(O).
- **그림**: F1 구간 20개와 참값 선(1개가 빗나감)
- **영상 위치**: 첫 구간을 만든 직후 dl-m07(95% 신뢰구간의 의미, 준비 중)
- **원본 원고**: 04-3-confidence-interval 앞부분(의미, 오해, 폭을 정하는 요인).

## st-04-2 t분포로 구하는 평균 · 비율의 신뢰구간

- **목표**: 모표준편차를 모를 때 t분포로 평균의 신뢰구간을, 정규 근사로 비율의 신뢰구간을 계산하고 한 문장으로 보고할 수 있다.
- **전제 개념**: st-04-1 구간 = 추정 ± 배수 × SE.
- **알아야 할 개념**
  1. 현실에서는 σ를 모른다 → 표본 표준편차 s로 대신 → 불확실성이 하나 더 생김
  2. t분포: 정규보다 꼬리가 두꺼움, 자유도 n − 1, n이 크면 정규와 같아짐
  3. `stats.t.interval(0.95, df, loc, scale=SE)`
  4. 직접 계산과 함수 결과 비교
  5. 비율의 SE = √(p(1−p)/n), 비율 신뢰구간
  6. 그룹별 구간이 겹치는지 보기 (겹치면 결론 조심)
  7. 보고 문장 예: "평균 팁은 3.00달러(95% CI 2.82~3.17, n = 244)"
- **배치**: S(σ를 모른다) → **F1**(정규 vs t(자유도 4) 곡선, 꼬리 비교) → C(t.ppf vs norm.ppf: df 4, 29, 200) → R → C(tips 팁 평균·s·SE) → C(t.interval) → R → C(직접 계산으로 같은 값) → S(비율) → C(titanic 생존율 구간) → R → C(성별 생존율 구간) → R(겹치지 않음) → **T**(신뢰수준 바꾸기) → S(보고 문장) → S(정리)
- **퀴즈 vs 코드**: **퀴즈 2문항**. 기존 short "표본 12개 → 자유도 11", ox "99%가 95%보다 넓다" 유지.
- **그림**: F1 정규 vs t분포 꼬리
- **연결 실습**: 유닛 15
- **원본 원고**: 04-3 계산·보고 절.

## st-05-1 가설검정의 논리와 p-value

- **목표**: "차이가 없다고 가정했을 때 이런 결과가 얼마나 드문가"라는 가설검정의 논리를 시뮬레이션으로 설명하고, p-value로 판단할 수 있다.
- **전제 개념**: st-09-1 시뮬레이션, st-02-2 이항분포.
- **알아야 할 개념**
  1. 법정 비유: 무죄 추정(귀무가설) → 증거가 충분히 강하면 유죄(기각)
  2. 귀무가설 H0(차이·효과 없음) vs 대립가설 H1
  3. 동전이 공정한가? 100번 중 앞면 61번
  4. H0 아래 세계를 시뮬레이션: 공정한 동전 100번을 1만 번
  5. p-value = H0이 맞을 때 지금만큼(또는 더) 극단적인 결과가 나올 확률
  6. 유의수준 α(보통 0.05)와 판단 문장 "기각한다 / 기각하지 못한다"
  7. 양측 vs 단측
  8. scipy로 같은 계산: `stats.binomtest`
  9. p-value 오해 3가지: H0이 맞을 확률이 아니다 / 효과 크기가 아니다 / 기각 못함 ≠ 차이 없음 증명
  10. 실데이터: 순열 검정으로 tips 흡연자 vs 비흡연자 팁 비율
- **배치**: S(법정 비유) → S(H0·H1) → **F1**(검정 4단계 흐름) → S(동전 61번) → C(공정한 동전 100번 한 세트) → C(1만 세트 시뮬레이션) → C(61 이상 비율) → R → ::video{dl-m08} → S(p-value 정의 + 양측) → C(양측 p) → C(binomtest) → R → S(α와 판단 문장) → **T**(앞면 수를 55로) → R → S(오해 3가지) → S(순열 검정: 라벨 섞기) → C(흡연자 팁비율 평균 차이) → C(라벨 섞어 5,000번) → R → S(정리)
- **퀴즈 vs 코드**: **퀴즈 2문항**. 기존 ox "p < 0.05면 기각" 유지 + choice "p-value의 올바른 뜻".
- **그림**: F1 검정 4단계(가설 세우기 → 통계량 계산 → H0 세계에서 얼마나 드문지 → 판단)
- **영상 위치**: 시뮬레이션 비율 해석 직후 dl-m08(가설검정과 p-value, 준비 중)
- **원본 원고**: 05-1-hypothesis-pvalue(귀무·대립, p-value 정의, 오해, 판단 문장).

## st-05-2 1종 오류 · 2종 오류 · 검정력

- **목표**: 두 가지 오류를 구분하고, 표본 수·효과 크기가 검정력에 어떤 영향을 주는지 시뮬레이션으로 볼 수 있다.
- **전제 개념**: st-05-1 α, 기각.
- **알아야 할 개념**
  1. 판단 결과 2 × 2 표: 실제(차이 없음/있음) × 판단(기각/못함)
  2. 1종 오류(α): 없는 차이를 있다고 — 화재경보기가 괜히 울림
  3. 2종 오류(β): 있는 차이를 놓침 — 불이 났는데 안 울림
  4. 검정력 = 1 − β: 진짜 차이를 잡아낼 확률
  5. 시뮬레이션: H0이 참일 때 기각 비율 ≈ α
  6. 차이가 있을 때 기각 비율 = 검정력, n이 커지면 ↑
  7. α를 낮추면 1종은 줄지만 2종은 늘어남 (시소)
  8. 여러 번 검정하면 1종 오류가 쌓인다(다중비교) — st-08-2에서 다시
- **배치**: S(화재경보기 비유) → **F1**(2 × 2 판단표) → S(용어) → C(H0 참: 차이 없는 두 그룹 1,000번 t검정 → 기각 비율) → R(≈ 0.05) → C(차이 있음 n=20 → 기각 비율) → R(검정력 낮음) → ::video{dl-m21} → **F2**(H0·H1 분포 두 개, α·β 면적) → C(n = 20, 50, 100 검정력) → R → **T**(효과 크기 바꾸기) → S(α 시소) → C(α=0.01 일 때 검정력) → R → S(다중비교 예고) → C(검정 20번 중 하나라도 기각될 확률 1 − 0.95²⁰) → R(64%) → S(정리)
- **퀴즈 vs 코드**: **퀴즈 2문항**. choice: "실제로 효과가 없는 약을 효과 있다고 결론" = 1종 / ox: 표본 수를 늘리면 검정력이 높아진다(O).
- **그림**: F1 2 × 2 판단표, F2 두 분포 겹침과 α·β
- **영상 위치**: 검정력 시뮬레이션 직후 dl-m21(제1·2종 오류와 검정력, 준비 중) — 기존 st-05-1·st-08-1 두 곳에 있던 것을 이 레슨으로 모으고 st-08-2에는 다시 넣지 않음
- **원본 원고**: 05-2-type1-type2-power 전체.

## st-05-3 세 가지 t검정

- **목표**: 상황(기준값과 비교 / 서로 다른 두 그룹 / 같은 대상 전후)에 맞는 t검정을 고르고, 단측 대립가설을 쓸 수 있다.
- **전제 개념**: st-05-1 p-value, st-04-2 t분포.
- **알아야 할 개념**
  1. t 통계량 = (차이) ÷ (차이의 SE): "차이가 흔들림의 몇 배인가"
  2. 1표본 t검정: 평균이 기준값과 다른가 (`ttest_1samp`) — 펭귄 몸무게 평균이 4,000g인가
  3. 독립 2표본 t검정: 두 그룹 평균 비교, Welch(`equal_var=False`)를 기본으로 — tips 점심 vs 저녁 계산서
  4. 대응 t검정: 같은 대상을 두 번 잰 값(`ttest_rel`) — 같은 학생 시험 전후
  5. 대응 데이터를 독립으로 잘못 검정하면 차이를 놓친다
  6. 단측 검정: `alternative="greater"/"less"` — 방향을 미리 정했을 때만
  7. 고르는 순서도
- **배치**: S(t 통계량 비유: 신호 ÷ 잡음) → **F1**(어떤 t검정? 순서도) → S(1표본) → C(penguins 평균) → C(ttest_1samp 4000) → R → S(독립 2표본) → C(tips 점심 vs 저녁 평균) → C(ttest_ind Welch) → R → S(대응) → C(학생 8명 전후 점수 — 작은 예) → C(ttest_rel) → C(같은 데이터를 ttest_ind로) → R(대응을 무시하면 p가 커짐) → S(단측) → C(alternative="greater") → R(p 절반) → **T**(기준값 4000 → 4150) → S(정리)
- **퀴즈 vs 코드**: **퀴즈 2문항**. 기존 choice "같은 시편을 두 측정기로 → ttest_rel" 유지 + choice "남녀 두 그룹 키 비교 → ttest_ind".
- **그림**: F1 t검정 선택 순서도
- **연결 실습**: 유닛 16
- **원본 원고**: 05-3-t-test-and-chi-square의 t검정 절(종류·가정·Welch 권장).

## st-06-1 카이제곱 검정: 범주끼리 관련이 있을까

- **목표**: 두 범주형 변수의 교차표에서 "관련 없다면 기대되는 표"를 만들고 실제 표와 비교해 독립성을 검정할 수 있다.
- **전제 개념**: st-09-2 교차표·독립, st-05-1 p-value.
- **알아야 할 개념**
  1. 숫자 평균이 없는 데이터(범주 × 범주)는 t검정을 못 쓴다
  2. 관측도수(실제 표)
  3. 기대도수: "관련이 없다면" 행 합 × 열 합 ÷ 전체
  4. 카이제곱 통계량 = Σ (관측 − 기대)² / 기대 — 표 전체의 어긋남 점수
  5. 자유도 (행 − 1) × (열 − 1)
  6. `stats.chi2_contingency`로 한 번에
  7. 적합도 검정(`chisquare`): 한 변수가 기대 비율을 따르나 — 주사위가 공정한가
  8. 주의: 기대도수 5 미만 칸이 많으면 부정확, 관련 있음 ≠ 원인
- **배치**: S(범주 데이터) → C(sex × survived crosstab) → S(관련이 없다면?) → **F1**(관측표 vs 기대표 나란히) → C(기대도수 직접 계산) → R → S(어긋남 점수) → C(카이제곱 직접) → C(chi2_contingency) → R → S(자유도) → C(pclass × survived) → R(dof 2) → **T**(embarked로 바꾸기) → S(적합도 검정) → C(주사위 600번 결과 chisquare) → R → S(주의점) → S(정리)
- **퀴즈 vs 코드**: **퀴즈 2문항**. 기존 ox "자유도 (행−1)(열−1)" 유지 + short "행 합 40, 열 합 50, 전체 100일 때 기대도수"("20").
- **그림**: F1 관측표와 기대표
- **원본 원고**: 05-3의 카이제곱 절.

## st-06-2 분산분석(ANOVA)과 사후검정

- **목표**: 세 집단 이상의 평균을 한 번에 비교하고, 차이가 있으면 어느 쌍이 다른지 사후검정으로 찾을 수 있다.
- **전제 개념**: st-05-3 독립 t검정, st-05-2 다중비교.
- **알아야 할 개념**
  1. 왜 t검정을 여러 번 하면 안 되나 (3쌍 → 1종 오류 누적)
  2. ANOVA의 아이디어: 그룹 사이 흩어짐 vs 그룹 안 흩어짐 — F = 사이 ÷ 안
  3. 그림으로: 그룹 평균이 멀고 그룹이 좁으면 F가 크다
  4. `stats.f_oneway`: penguins 종별 몸무게 (F 342, 매우 유의)
  5. "차이 없음" 사례: tips 요일별 팁 (p = 0.17)
  6. ANOVA는 "어딘가 다르다"까지만 → 사후검정 Tukey HSD (`stats.tukey_hsd`)
  7. 가정: 독립, 그룹별 분산이 비슷, 정규에 가까움 — 어긋나면 Kruskal-Wallis
  8. 실무 해석: 차이가 유의해도 크기(평균 차이 g)를 함께
- **배치**: S(세 반 시험 비교 비유) → C(t검정 3번의 1종 오류 누적 1 − 0.95³) → S(ANOVA 아이디어) → **F1**(그룹 사이 vs 안 흩어짐, F 크고 작은 두 경우) → C(종별 몸무게 평균·std) → C(f_oneway) → R → C(F 직접 계산) → R → S(차이 없음 사례) → C(tips 요일별) → C(f_oneway) → R → S(사후검정) → C(tukey_hsd) → R(Adelie·Chinstrap은 차이 없음, Gentoo만 다름) → S(가정과 대안) → C(kruskal) → **T** → S(정리)
- **퀴즈 vs 코드**: **퀴즈 2문항**. 기존 choice "세 설비 평균 두께 → f_oneway" 유지 + ox "ANOVA가 유의하면 모든 그룹이 서로 다르다"(X).
- **그림**: F1 F비 개념도
- **연결 실습**: 유닛 32
- **원본 원고**: 07-2-anova(아이디어, 사후검정, 가정, 해석 실수).

## st-07-1 공분산과 상관계수

- **목표**: 두 변수가 함께 움직이는 방향과 강도를 공분산·상관계수로 말하고, 상관계수가 놓치는 것(곡선·이상치)을 그림으로 확인할 수 있다.
- **전제 개념**: st-01-2 편차·표준편차, st-01-3 z점수.
- **알아야 할 개념**
  1. 두 변수의 관계 = 산점도 (지느러미 길이 ↔ 몸무게)
  2. 공분산: 편차 × 편차의 평균 — 같은 방향이면 +, 반대면 −
  3. 공분산의 약점: 단위에 따라 크기가 변함 (mm → cm)
  4. 상관계수 r = 표준화한 공분산, −1 ~ 1
  5. r의 크기 감각 표 (0.1 약 / 0.5 중간 / 0.8 강)
  6. r은 직선 관계만 잰다: 곡선 관계 r ≈ 0
  7. 이상치 하나가 r을 바꾼다 → 스피어만(순위 상관)
  8. 상관 행렬 `df.corr()`
  9. 앤스컴 콰르텟: 숫자가 같아도 그림은 다르다 → 꼭 그려 보기
- **배치**: S(키와 몸무게 비유) → C(산점도 + 개수) → R → S(공분산) → **F1**(산점도 4분면: 편차 곱 +/−) → C(편차 곱 평균 직접 vs np.cov) → R → C(단위 바꾸면 공분산 변화) → R → S(상관계수) → C(np.corrcoef, pearsonr) → R(0.87) → S(크기 감각 표) → S(직선만 잰다) → C(y = x² 곡선 r) → R → S(이상치) → C(이상치 하나 추가 pearson vs spearman) → R → C(df.corr 숫자 열) → S(앤스컴) → C(앤스컴 4세트 평균·r 같음 + 그림) → R → S(정리: 상관 ≠ 인과는 st-10-1)
- **퀴즈 vs 코드**: **퀴즈 2문항**. 기존 ox "r 0.95면 원인"(X) 유지 + choice "r ≈ 0이면?" (직선 관계 없음, 곡선 관계는 있을 수 있음).
- **그림**: F1 4분면 편차 곱
- **원본 원고**: 06-1-covariance-and-correlation 전체.

## st-07-2 단순선형회귀: 최소제곱으로 직선 긋기

- **목표**: 데이터에 가장 잘 맞는 직선(최소제곱)을 구하고, 기울기·절편을 단위와 함께 해석하고, 예측값과 잔차를 계산할 수 있다.
- **전제 개념**: st-07-1 상관계수, 일차함수 y = a + bx (중학교 수학).
- **알아야 할 개념**
  1. 상관(함께 움직이는 정도) → 회귀(x로 y를 예측하는 식)
  2. 직선 ŷ = a + b·x: 절편 a, 기울기 b
  3. 잔차 = 실제 − 예측
  4. 최소제곱: 잔차 제곱의 합이 가장 작은 직선 (영상 dl-m22)
  5. 직선 몇 개를 직접 대 보고 잔차 제곱합 비교
  6. `stats.linregress` → slope, intercept
  7. 기울기 해석: "지느러미 1mm 길면 몸무게가 평균 약 50g 더 나간다" (단위!)
  8. 절편 해석의 함정: 지느러미 0mm 펭귄은 없다
  9. 기울기 = r × (sy/sx)
  10. 예측하기
- **배치**: S(상관 → 회귀) → **F1**(직선, 잔차 세로 막대, 잔차 제곱 사각형) → S(최소제곱) → ::video{dl-m22} → C(아무 직선 두 개의 잔차 제곱합) → R → **T**(기울기 바꿔 보기) → C(linregress) → R(기울기 49.7) → S(기울기 해석) → S(절편 함정) → C(기울기 = r·sy/sx 확인) → C(예측: 200mm, 220mm) → R → C(잔차 몇 개) → C(그래프: 점 + 직선) → S(정리)
- **퀴즈 vs 코드**: **퀴즈 2문항**. 기존 write "linregress 기울기 출력" 유지 + choice "기울기 49.7의 해석".
- **그림**: F1 최소제곱 개념도
- **영상 위치**: 최소제곱 설명 직후 dl-m22(공개, 유튜브 재생) — **기존 임베드 유지**
- **원본 원고**: 06-2-simple-linear-regression.

## st-07-3 회귀 결과 읽기와 진단

- **목표**: R²·기울기의 p-value·잔차 그래프를 읽어 "이 직선을 믿어도 되나"를 판단하고, 범위 밖 예측(외삽)을 피할 수 있다.
- **전제 개념**: st-07-2 기울기·잔차, st-05-1 p-value.
- **알아야 할 개념**
  1. R²: y의 흩어짐 중 직선이 설명하는 비율 (단순회귀에서는 r²)
  2. R² 직접 계산: 1 − 잔차 제곱합 / 전체 제곱합
  3. 기울기의 p-value: "기울기 = 0" 가설 검정, 기울기의 신뢰구간(stderr 이용)
  4. 잔차 그래프: 패턴이 없어야 좋다 — 곡선 패턴, 깔때기 패턴
  5. tips: 계산서 → 팁 회귀, 잔차가 금액이 클수록 커지는 깔때기
  6. 외삽 주의: 데이터 범위 밖 예측
  7. 회귀 결과 읽는 순서 체크리스트
  8. 다음 단계: 여러 변수는 다중회귀(머신러닝 ml-02)
- **배치**: S(믿어도 되나?) → C(linregress 결과 rvalue², pvalue, stderr) → S(R²) → **F1**(전체 흩어짐 vs 남은 흩어짐 막대) → C(R² 직접 계산) → R → S(기울기 p-value와 CI) → C(기울기 95% CI) → R → S(잔차 그래프) → **F2**(좋은 잔차 / 곡선 / 깔때기 3칸) → C(penguins 잔차 그래프) → R → C(tips 회귀 + 잔차) → R(깔때기) → S(외삽) → C(지느러미 범위 vs 300mm 예측) → R → S(체크리스트) → S(다중회귀 연결) → S(정리)
- **퀴즈 vs 코드**: **퀴즈 2문항**. choice: R² 0.76의 뜻 / ox: 잔차 그래프에 U자 패턴이 보이면 직선 모델이 적절하다(X).
- **그림**: F1 R² 막대 개념도, F2 잔차 패턴 3가지
- **연결 실습**: 유닛 33
- **원본 원고**: 06-3-regression-diagnostics(R², 잔차 진단, 이상치·영향점, 외삽).

## st-08-1 A/B 테스트의 구조와 두 비율 비교

- **목표**: 무작위 배정 실험(A/B 테스트)이 왜 공정한지 설명하고, 두 그룹 전환율 차이를 검정하고 신뢰구간으로 보고할 수 있다.
- **전제 개념**: st-03-1 편향, st-06-1 카이제곱, st-04-2 비율 신뢰구간.
- **알아야 할 개념**
  1. 비교 실험: 하나만 바꾸고 나머지는 같게 (급식 메뉴 두 가지)
  2. 무작위 배정: 그룹을 동전 던지기로 나누면 다른 차이가 고르게 섞인다
  3. 실험 전에 정할 것: 지표 하나(주 지표), 기간, 표본 수, 유의수준
  4. 두 비율 비교: 2 × 2 표 → `chi2_contingency` (또는 z검정)
  5. 차이의 신뢰구간
  6. 상대 차이 vs 절대 차이 (4% → 5% = +1%p, +25%)
  7. 실험 중 몰래 보기(peeking)의 위험 시뮬레이션
- **배치**: S(급식 비유) → **F1**(A/B 실험 흐름: 무작위 배정 → 두 그룹 → 지표 비교) → S(무작위 배정이 공정한 이유) → C(사용자 1,000명 나이 → 무작위로 나눠 평균 나이 비교) → R(비슷함) → S(실험 전에 정할 것) → C(결과 데이터: A 2,000명 중 80, B 2,000명 중 110) → C(전환율·차이) → R → C(chi2_contingency) → R → C(차이의 95% CI) → R → S(상대 vs 절대) → S(몰래 보기) → C(차이 없는 실험을 매일 들여다보기 시뮬레이션) → R(거짓 양성 급증) → S(정리)
- **퀴즈 vs 코드**: **퀴즈 2문항**. choice: 무작위 배정의 목적 / ox: 전환율 4% → 5%는 1% 상승이다 (X, 1%p·25%).
- **그림**: F1 A/B 실험 흐름
- **원본 원고**: 07-1-ab-test-basics(구조, 사전 설계, 주 지표, peeking).

## st-08-2 표본 수 설계와 실무 판단

- **목표**: 검출하고 싶은 차이로부터 필요한 표본 수를 계산하고, 결과를 "유의성 · 크기 · 비용"으로 판단할 수 있다.
- **전제 개념**: st-05-2 검정력, st-08-1 두 비율 비교.
- **알아야 할 개념**
  1. 표본 수를 미리 정하는 이유: 너무 적으면 놓치고, 너무 많으면 낭비
  2. 필요한 네 가지: 기준 전환율, 검출할 최소 차이, α, 검정력
  3. 두 비율 표본 수 공식(그룹당 n), 코드 함수로
  4. 차이를 절반으로 → n은 약 4배
  5. 시뮬레이션으로 검정력 확인
  6. 유의하다 ≠ 중요하다: 아주 큰 n에서 0.1%p 차이도 유의
  7. 효과 크기(차이·Cohen's h) 함께 보고
  8. 다중비교: 지표 여러 개를 보면 하나쯤은 유의 → 주 지표, 보정(본페로니)
  9. 의사결정 표: 유의·크기 조합별 행동
- **배치**: S(왜 미리) → S(네 가지 재료) → C(표본 수 함수 정의 + 4% → 5%) → R → C(4% → 4.5%) → R(약 4배) → **F1**(차이 vs 필요 표본 수 곡선) → **T**(기준 전환율·차이 바꾸기) → C(시뮬레이션 검정력 확인) → R(≈ 0.8) → S(유의 ≠ 중요) → C(n 200,000에서 0.1%p 차이 p-value) → R → S(효과 크기) → S(다중비교) → C(본페로니 기준) → S(의사결정 표) → S(정리)
- **퀴즈 vs 코드**: **퀴즈 2문항**. 기존 2문항(차이 절반 → 4배, 검정력 80%) 유지.
- **그림**: F1 검출 차이 vs 표본 수
- **연결 실습**: 유닛 34
- **원본 원고**: 07-3-practical-decision-making(유의성 vs 실무 중요성, 의사결정 표), 05-2 검정력 계산.

## st-10-1 상관과 인과, 심슨의 역설

- **목표**: 함께 움직이는 것과 원인을 구분하고(교란변수), 묶어서 볼 때와 나눠서 볼 때 결론이 뒤집히는 심슨의 역설을 실데이터로 확인할 수 있다.
- **전제 개념**: st-07-1 상관계수, st-09-2 조건부확률.
- **알아야 할 개념**
  1. 상관 ≠ 인과: 아이스크림과 물놀이 사고(더운 날씨)
  2. 교란변수(숨은 공통 원인), 역인과(소방차가 많을수록 피해가 크다), 우연(가짜 상관)
  3. 펭귄 부리: 전체로 보면 길이 ↔ 깊이 r = −0.23 (음의 상관)
  4. 종별로 나누면 모두 + (0.39 ~ 0.65) → 심슨의 역설
  5. 타이타닉: 등석이 생존과 요금 모두에 영향 (요금이 생존 원인?)
  6. 인과를 말하려면: 무작위 실험(st-08), 그게 안 되면 층별로 나눠 보기
  7. 체크리스트: 숨은 변수 · 방향 · 우연 · 선택 편향
- **배치**: S(아이스크림) → **F1**(교란변수 삼각형: 더위 → 아이스크림, 더위 → 사고) → S(세 가지 이유) → C(펭귄 전체 상관) → R(−0.23) → C(종별 상관) → R(모두 +) → C(종별 색 산점도 + 전체 직선) → R → **F2**(심슨의 역설 개념도) → S(왜 일어나나) → C(titanic fare ↔ survived 상관) → C(pclass별 나눠 보기) → R → **T**(다른 열 조합 바꾸기) → S(인과를 말하려면) → S(체크리스트) → S(정리)
- **퀴즈 vs 코드**: **퀴즈 3문항**. 판단력 문제라 상황형 퀴즈.
  - choice: 교란변수 찾기 / choice: 심슨의 역설이란 / ox: 무작위 배정 실험이면 교란변수 문제를 크게 줄일 수 있다(O)
- **그림**: F1 교란변수 삼각형, F2 심슨의 역설(그룹 안 + / 전체 −)
- **원본 원고**: 08-1-correlation-vs-causation 전체.

## st-10-2 통계 결과를 보고하는 법

- **목표**: 분석 결과를 "무엇을 봤나 · 얼마나 다른가 · 얼마나 확실한가 · 그래서 무엇을"의 네 부분으로 한 문단에 쓸 수 있다.
- **전제 개념**: 트랙 전체 (신뢰구간, p-value, 효과 크기).
- **알아야 할 개념**
  1. 나쁜 보고 vs 좋은 보고 비교 ("p=0.03, 유의함!" vs 전체 문장)
  2. 보고서에 꼭 들어갈 다섯 가지: 표본 수, 요약값(평균·중앙값), 효과 크기(차이), 신뢰구간, p-value
  3. 관측과 해석을 나눠 쓰기
  4. 한계 쓰기: 표본 구조, 기간, 인과 아님
  5. 숫자 반올림·단위·%p 표기
  6. 그래프 하나 고르기: 오차 막대(신뢰구간) 그래프
  7. 직접 해 보기: tips 흡연자 vs 비흡연자 팁 비율 보고 문단 만들기
- **배치**: S(나쁜 보고 예) → S(다섯 가지) → **F1**(보고 문단 4부분 틀) → C(tips 흡연 여부별 n·평균·중앙값) → C(차이 + Welch t검정) → C(차이의 95% CI) → R → C(보고 문장 f-string으로 자동 생성) → R → S(관측 vs 해석) → S(한계) → C(오차 막대 그래프) → R → S(표기 규칙 표) → S(트랙 마무리: 배운 것 한 장 정리) → S(정리)
- **퀴즈 vs 코드**: **퀴즈 2문항**. choice: 가장 좋은 보고 문장 / ox: p-value만 적으면 효과 크기는 적지 않아도 된다(X).
- **그림**: F1 보고 문단 틀
- **원본 원고**: 08-2-reporting-and-communication(보고 원칙, 관측/해석 분리, 한계 표기), 07-3 의사결정 문장.
