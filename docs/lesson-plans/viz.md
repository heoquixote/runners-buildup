# 데이터 시각화 트랙 레슨 기획안 (v2: 분석 목적별)

작성 기준은 [README.md](README.md). 기호: `S` 설명, `F` 그림, `C` 실행 셀, `T` 직접 해보기, `R` 결과 해석.

원본은 진성 님의 Python 기초 원고 7장(`docs/sources/python/07-4`, `07-6-matplotlib-basics`, `07-7-seaborn-plotly`)과 통계 원고(`stats/02-3-shape-and-outlier`)입니다.

## v2로 바꾼 이유

v1(PR #20)은 라이브러리별(matplotlib 4편, seaborn 4편)로 차트를 "그리는 법"을 정리했습니다. 진성 님 피드백: **비교 · 분포처럼 분석 목적별로 묶고, 목적마다 그릴 수 있는 그래프를 모두, 그리고 각 그래프의 해석 방법까지 빠짐없이** 다뤄야 한다.

그래서 v2는 이렇게 바꿉니다.

1. 라이브러리 레슨은 **코드 구조만** 남깁니다(DAY 01·02). 차트 종류는 모두 목적별 코스로 옮깁니다.
2. 목적별 코스 5개: **비교 · 추이 · 분포 · 관계와 상관 · 구성과 비율**. 각 코스 안에서 그 목적에 쓰는 차트를 matplotlib · seaborn 구분 없이 모두 다룹니다.
3. 차트마다 **해석 틀 4칸**을 똑같이 씁니다(아래). 레슨을 잘게 쪼개 한 레슨에 차트 2~4개만 둡니다.
4. 해석은 판단력이라 퀴즈가 효과적입니다. 레슨마다 "이 그래프를 이렇게 읽은 것이 맞나?" 판단 퀴즈를 1~3문항 둡니다(그래프 수치를 문장으로 주고 해석을 고르게).

## 차트 하나를 설명하는 틀 (모든 차트 공통)

| 칸 | 내용 |
| --- | --- |
| **무엇을 나타내나** | x축, y축, 막대·점·선·색 하나가 각각 무엇인지 |
| **이렇게 읽는다** | 순서대로 볼 것 3~5개 (예: 중심 → 퍼짐 → 모양 → 튀는 값) |

## DAY 03 비교 (da-12): "어느 쪽이 더 큰가?"

### da-12-1 막대 그래프 읽기

- **목표**: 막대 그래프의 길이를 읽고, 정렬 · 0 기준선 · 값 표시를 확인하며 "가장 큰 그룹, 차이의 크기"를 문장으로 말할 수 있다.
- **차트**: 세로 막대(`ax.bar`), 가로 막대(`ax.barh`), 개수 막대(`sns.countplot`)
- **해석 포인트**: 막대 = 범주 하나, 길이 = 값. 순서: 가장 큰 · 작은 막대 → 차이가 몇 배인가 → 비슷한 무리 → 축이 0에서 시작하나. 차이는 "몇 개 더"와 "몇 배"를 함께.
- **오독**: 축을 자른 막대(F: viz02), 개수 막대에서 "개수가 많다 = 비율이 높다" 착각, 정렬 안 된 막대에서 순위 잘못 읽기.
- **배치**: S(막대가 답하는 질문) → C(객실 등급별 승객 수) → S(무엇을 나타내나) → S(읽는 순서) → R(해석 문장) → S(0 기준선) → **F viz02** → C(축 자른 그림 vs 0부터) → S(가로·정렬) → C(barh 정렬) → R → S(값 표시) → C(bar_label) → S(countplot) → C → R(요일별 건수) → S(개수 vs 비율 오독) → C(등급별 인원 vs 생존율) → R → 정리 표
- **퀴즈 2**: choice(축이 90부터 시작한 막대 해석) / choice(개수가 많은 그룹이 비율도 높다고 할 수 있나)

### da-12-2 평균과 오차 막대 읽기

- **목표**: barplot의 막대가 평균이라는 것과, 오차 막대가 "평균이 얼마나 확실한가"를 뜻한다는 것을 알고, 겹치는 오차 막대를 성급하게 "차이 있음"으로 읽지 않는다.
- **차트**: `sns.barplot`(평균 + 신뢰구간), `errorbar="sd"`, `estimator="sum"`, `sns.pointplot`
- **해석 포인트**: 막대 높이 = 평균. 검은 선 = 95% 신뢰구간(같은 조사를 다시 하면 평균이 대략 이 범위). 선이 길다 = 데이터가 적거나 들쭉날쭉. 두 그룹의 선이 크게 겹치면 차이를 단정하기 어렵다. sd는 "데이터의 퍼짐", CI는 "평균의 흔들림"으로 뜻이 다르다.
- **오독**: 막대 높이를 합계로 읽기, 오차 막대를 최솟값~최댓값으로 읽기, 표본 수를 안 보고 비교하기.
- **배치**: S → C(요일별 평균 금액 barplot) → R(평균 숫자) → S(오차 막대) → **F viz14**(신뢰구간 겹침) → C(요일별 건수와 CI 길이) → R(금요일 19건, 선이 가장 김) → S(sd vs CI) → C(errorbar='sd') → R → S(합계와 평균) → C(estimator='sum') → R(토요일 합계 1위, 평균은 일요일) → S(pointplot) → C → R → 정리
- **퀴즈 2**: ox(막대 높이 = 합계 X) / choice(오차 막대가 크게 겹칠 때 맞는 해석)

### da-12-3 두 기준으로 나눠 비교하기

- **목표**: 그룹을 두 기준으로 나눈 그래프에서 "어느 기준의 차이가 더 큰가", "한 기준의 효과가 다른 기준에 따라 달라지는가(엇갈림)"를 읽을 수 있다.
- **차트**: 묶음 막대(hue), 점 그래프(pointplot hue: 평행 vs 엇갈림), 롤리팝·점 그래프(dot plot), 칸 나누기(catplot col)
- **해석 포인트**: 묶음 안 비교(같은 등급의 남녀) vs 묶음 사이 비교(등급끼리). 선이 평행하면 "효과가 일정", 기울기가 다르거나 엇갈리면 "조건에 따라 효과가 달라짐". 점 그래프는 막대보다 잉크가 적어 범주가 많을 때 순위 읽기에 좋다.
- **배치**: S → C(등급×성별 생존율 묶음 막대) → S(두 가지 비교 방향) → R → S(pointplot 평행·엇갈림) → **F viz15**(평행 vs 엇갈림) → C(요일×성별 팁) → R → S(점 그래프) → C(펭귄 섬×종 평균 몸무게 dot) → R → S(칸 나누기) → C(catplot col) → R → 정리
- **퀴즈 2**: choice(평행선 해석) / choice(묶음 막대에서 성별 차이 vs 등급 차이)

## DAY 04 추이 (da-13): "시간에 따라 어떻게 변하나?"

### da-13-1 선 그래프 읽기

- **목표**: 선 그래프에서 추세 · 계절성 · 불규칙 변동 · 급변(이상점)을 구분해 말할 수 있다.
- **차트**: `ax.plot`, `sns.lineplot`(월별 평균 + 띠)
- **해석 포인트**: x = 시간(순서가 있는 값), y = 값, 선의 기울기 = 변화 속도. 순서: 전체 방향(추세) → 반복 패턴(계절성) → 들쭉날쭉(변동) → 튀는 점. 시작값·끝값과 변화율을 숫자로.
- **오독**: 순서 없는 범주를 선으로 잇기, 점 사이 선을 실제 측정값으로 읽기, y축 범위에 따라 변화가 과장되는 것.
- **배치**: S → **F viz12**(선 그래프 패턴 4가지) → C(flights 전체 144개월) → R(추세+계절) → S(연 합계로 추세만) → C → R(1949 1,520 → 1960 5,714, 3.8배) → S(월별 평균으로 계절성만) → C(sns.lineplot x=month) → R(7·8월 351) → S(y축 범위 오독) → C(같은 선, ylim 두 가지) → R → 정리
- **퀴즈 2**

### da-13-2 추세를 또렷하게: 이동평균 · 로그 축 · 기준선

- **목표**: 들쭉날쭉한 선을 이동평균으로 다듬어 추세를 읽고, 로그 축으로 "증가 속도(비율)"를 읽고, 기준선과 비교해 해석할 수 있다.
- **차트**: `rolling().mean()` 선, `ax.set_yscale("log")`, `axhline` · `fill_between` 목표 범위
- **해석 포인트**: 이동평균 창이 클수록 매끄럽지만 늦게 반응. 로그 축에서 직선 = 일정한 비율로 증가. 기준선 위·아래 머무른 기간.
- **배치**: S → C(가상 일별 방문자 90일) → R(요일 들쭉날쭉) → S(이동평균) → C(7일 이동평균) → **T**(창 3·7·28) → R → S(로그 축) → C(flights 선형 vs 로그) → R(로그에서는 거의 직선 → 해마다 비슷한 비율로 성장) → S(기준선) → C(목표 범위 띠, 목표 미달 일수) → R → 정리
- **퀴즈 2**

### da-13-3 여러 시계열 비교하기

- **목표**: 여러 선 · 작은 여러 칸 · 달력 히트맵 중 알맞은 것으로 여러 시계열을 비교하고 읽을 수 있다.
- **차트**: 여러 선(hue), 작은 여러 칸(relplot col/col_wrap), 시작점 기준 지수화(100 기준), 달력형 히트맵(월×연도)
- **해석 포인트**: 선이 많으면 겹쳐서 못 읽음 → 칸 나누기. 크기가 다른 시계열은 첫 값을 100으로 맞춰 증가율 비교. 히트맵: 가로로 읽으면 연도별 변화, 세로로 읽으면 계절 패턴.
- **배치**: S → C(연도별 12개 선 hue) → R(겹침) → S(작은 여러 칸) → C(relplot col_wrap) → R → S(지수화) → C(1월 vs 7월 승객 100 기준) → R → S(달력 히트맵) → C(pivot heatmap) → R(가로·세로 읽기) → 정리
- **퀴즈 2**

## DAY 05 분포 (da-14): "값들이 어떻게 퍼져 있나?"

### da-14-1 히스토그램 읽기

- **목표**: 히스토그램에서 중심 · 퍼짐 · 모양(대칭 / 오른쪽 꼬리 / 왼쪽 꼬리 / 봉우리 두 개) · 이상치를 읽고, 평균과 중앙값 중 무엇이 대표값으로 맞는지 판단한다.
- **차트**: `ax.hist`, `sns.histplot`(bins, binwidth, hue, multiple, stat)
- **해석 포인트**: x = 값의 구간, y = 그 구간의 개수. 순서: 봉우리 위치(중심) → 폭(퍼짐) → 모양 → 꼬리·외딴 막대. 오른쪽 꼬리면 평균 > 중앙값.
- **오독**: 막대 그래프처럼 범주로 읽기, bins에 따라 달라지는 모양을 사실로 단정, 그룹 크기가 다른데 개수로 비교.
- **배치**: S → **F viz11**(모양 4가지) → C(펭귄 지느러미: 봉우리 두 개) → R → C(hue=species로 원인 확인) → R → C(titanic fare: 오른쪽 꼬리 + 평균·중앙값 선) → R(32.2 vs 14.5) → S(bins) → **T** → S(그룹 크기 다를 때) → C(stat density, common_norm False) → R → 정리
- **퀴즈 3**: choice(오른쪽 꼬리일 때 평균과 중앙값) / choice(봉우리 두 개의 가능한 원인) / ox(bins를 바꿔도 모양은 같다 X)

### da-14-2 밀도 곡선과 ECDF 읽기

- **목표**: KDE 곡선의 봉우리 · 겹침을 읽고, ECDF에서 "몇 % 이하", 중앙값, 그룹 간 차이를 읽는다.
- **차트**: `sns.kdeplot`(hue, fill, bw_adjust), `sns.ecdfplot`, `sns.rugplot`
- **해석 포인트**: KDE y축 값 자체는 해석하지 않는다(넓이가 1). 모양과 위치, 겹침 정도. ECDF: y=0.5와 만나는 x = 중앙값, 오른쪽에 있는 곡선 = 값이 큰 그룹, 가파른 구간 = 값이 몰린 구간.
- **오독**: KDE의 y값을 개수·확률로 읽기, 데이터 없는 범위까지 뻗은 꼬리(음수 나이)를 실제로 읽기.
- **배치**: S → C(kde hue) → R → S(y축 오독) → **T**(bw_adjust) → C(kde+rug) → S(ECDF) → C(ecdf hue + 0.5선) → R(중앙값 · 200mm 이하 56.8%) → S(가파름) → 정리
- **퀴즈 2**

### da-14-3 상자그림 읽기

- **목표**: 상자그림의 다섯 숫자와 이상치를 읽고, 상자 위치 · 길이 · 중앙값 위치로 그룹 분포를 비교한다.
- **차트**: `ax.boxplot`, `sns.boxplot`(x, hue)
- **해석 포인트**: 순서: 중앙값 위치 비교 → 상자 길이(IQR, 흩어짐) → 수염 길이·중앙값 위치로 치우침 → 이상치 개수·위치. 상자끼리 많이 겹치면 차이가 작음.
- **오독**: 가운데 선을 평균으로 읽기, 상자 크기를 데이터 개수로 읽기, 이상치 = 오류로 단정.
- **배치**: S → **F viz03** → C(fare 하나) → R(Q1 7.9 · 중앙값 14.5 · Q3 31.0) → S(치우침 읽기) → C(등급별 상자) → R → C(요일별 금액) → R → S(오독) → C(상자 크기 ≠ 개수: 요일별 건수) → R → 정리
- **퀴즈 3**

### da-14-4 바이올린 · 스트립 · 스웜 읽기

- **목표**: 바이올린의 폭(밀도)으로 봉우리를 읽고, 점 그래프로 실제 개수와 위치를 확인하며, 상자그림만으로 놓치는 것을 찾는다.
- **차트**: `sns.violinplot`(split, inner), `sns.stripplot`, `sns.swarmplot`, 상자 + 점 겹쳐 그리기
- **해석 포인트**: 바이올린 폭 = 그 값 근처 데이터 밀도. split으로 두 그룹 좌우 비교. 점 그래프로 표본 수 확인. 데이터가 적으면 바이올린 모양이 과장됨.
- **배치**: S → C(같은 데이터 상자 vs 바이올린) → R(봉우리 두 개가 상자에선 안 보임) → C(split) → R → S(점) → C(swarm) → R(금요일 19개) → C(상자+strip) → 정리 표(분포 차트 6종 비교)
- **퀴즈 2**

## DAY 06 관계와 상관 (da-15, 유닛 30): "두 값이 함께 움직이나?"

### da-15-1 산점도 읽기

- **목표**: 산점도에서 방향 · 강도 · 형태(직선/곡선) · 덩어리 · 이상점을 읽고 한 문장으로 관계를 설명한다.
- **차트**: `ax.scatter`, `sns.scatterplot`(hue, size, style, alpha)
- **해석 포인트**: 점 = 행 하나. 순서: 방향(양·음·없음) → 강도(얼마나 좁은 띠인가) → 형태 → 덩어리 → 이상점. "x가 클수록 y도 큰 경향" 문장 틀.
- **오독**: 겹친 점 때문에 밀도 오판(alpha), 덩어리를 하나의 관계로 읽기, 관계를 원인으로 읽기.
- **배치**: S → **F viz13**(산점도 패턴 6가지) → C(tips 금액-팁) → R → C(penguins 지느러미-몸무게) → R(더 좁은 띠 = 강함) → S(덩어리) → C(hue=species) → R → S(이상점) → C(팁 비율 튀는 점 표시) → R → S(겹침) → C(alpha) → 정리
- **퀴즈 2**

### da-15-2 추세선 읽기

- **목표**: 추세선의 기울기를 "x가 1 늘 때 y가 얼마 변하나"로 읽고, 신뢰 띠와 데이터 범위 밖 예측(외삽)의 위험을 안다.
- **차트**: `sns.regplot`, `sns.lmplot(hue=)`, `order=2`(곡선), `lowess` 대신 이동평균 비교 없음
- **해석 포인트**: 기울기 0.105 → "금액 1달러당 팁 약 10센트". 띠가 넓은 곳 = 데이터 적은 곳. 그룹별 기울기 차이. 곡선 관계에 직선을 그으면 잘못된 결론.
- **배치**: S → C(regplot + 기울기) → R → S(띠) → R → S(그룹별) → C(lmplot smoker) → R(0.137 vs 0.070) → S(곡선 관계) → C(직선 vs order=2, 가상 데이터) → R → S(외삽) → 정리
- **퀴즈 2**

### da-15-3 상관계수와 히트맵 읽기

- **목표**: 상관계수의 부호와 크기를 읽고, 히트맵에서 강한 쌍을 찾고, 같은 상관계수라도 모양이 다를 수 있음(앤스콤 4종)과 상관 ≠ 인과를 안다.
- **차트**: `df.corr()`, `sns.heatmap`(annot, vmin/vmax, cmap, mask)
- **해석 포인트**: 크기 기준(대략 0.1 약함 · 0.3 보통 · 0.5 이상 강함, 분야마다 다름). 대각선은 1, 위아래 대칭. 색 범위 고정. r은 직선 관계만 잰다.
- **배치**: S → **F viz09** → C(tips corr 숫자) → R → C(penguins heatmap) → R(0.87 · −0.47) → S(색 범위) → **T** → S(앤스콤 4종) → C(r 같고 모양 다른 4칸) → R → S(상관 ≠ 인과) → 정리
- **퀴즈 3**

### da-15-4 여러 변수 한 번에: pairplot · jointplot

- **목표**: pairplot 격자에서 칸 위치를 읽고, 대각선 분포와 칸별 관계를 해석하고, 그룹을 합쳤을 때 관계가 뒤집히는 현상(심슨 역설)을 찾아낸다.
- **차트**: `sns.pairplot(hue=)`, `sns.jointplot(kind=)`
- **배치**: S → C(pairplot) → S(격자 읽는 법: 행 = y, 열 = x, 대각선) → R → S(심슨 역설) → C(종별 상관) → R(−0.47 → +0.58~0.72) → S(jointplot) → C(kind='hex' / 'reg') → R → 정리 → 유닛 30 실습 안내
- **퀴즈 2**

## DAY 07 구성과 비율 (da-16): "전체 중 얼마를 차지하나?"

### da-16-1 파이 · 도넛 읽기

- **목표**: 파이 조각 = 전체 중 비율로 읽고, 파이가 잘 맞는 경우(조각 2~4개, 하나가 확실히 큼)와 아닌 경우를 판단한다.
- **차트**: `ax.pie`(autopct, startangle), 도넛(`wedgeprops`)
- **해석 포인트**: 합이 100%인 데이터에만. 가장 큰 조각의 비율과 "절반 넘나" 판단. 조각 비교는 퍼센트 숫자로.
- **오독**: 합이 100이 아닌 값(복수 응답)을 파이로, 비슷한 조각 크기 눈대중, 3D 파이.
- **배치**: S → C(승선 항구 pie) → R(72.4%) → S(도넛) → C → S(조각 많을 때) → C(9조각 pie vs 정렬 막대) → R → 정리
- **퀴즈 2**

### da-16-2 누적 막대와 100% 막대 읽기

- **목표**: 누적 막대에서 전체 크기와 구성을, 100% 막대에서 그룹별 비율 차이를 읽는다.
- **차트**: 누적 막대(`bottom=`, `df.plot(kind="bar", stacked=True)`), 100% 누적 막대(`crosstab(normalize="index")`), `sns.histplot(multiple="fill")`
- **해석 포인트**: 누적 막대: 전체 높이 비교는 정확, 맨 아래 조각만 비교 정확, 위 조각은 부정확. 100% 막대: 모든 막대 높이 같음 → 전체 크기 정보는 사라짐(개수 함께 표기).
- **배치**: S → C(등급별 생존·사망 누적) → R → S(위 조각 오독) → C(100%) → R(3등실 사망 76%) → S(크기 정보 사라짐) → C(막대 위 n 표시) → C(histplot fill: 지느러미 구간별 종 구성) → R → 정리
- **퀴즈 2**

### da-16-3 시간에 따른 구성: 누적 영역

- **목표**: 누적 영역 그래프로 시간에 따른 전체와 구성 변화를 읽고, 100% 누적 영역으로 비중 변화를 읽는다.
- **차트**: `ax.stackplot`, 100% stackplot
- **해석 포인트**: 맨 위 경계 = 전체, 띠 두께 = 그 부분의 크기. 100% 영역에서 띠 두께 변화 = 비중 변화. 아래 띠가 흔들리면 위 띠 모양이 따라 흔들려 착시.
- **배치**: S → C(flights 계절별 승객 누적 영역) → R → C(100% 영역) → R(여름 비중) → S(오독) → 정리 표(구성 차트 5종)
- **퀴즈 2**
