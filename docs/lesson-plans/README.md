# 레슨 기획안 작성 기준

레슨 페이지는 **기획안을 먼저 쓰고, 기획안대로 작성**합니다. 트랙마다 파일 하나(`ml.md`, `stats.md` …)에 페이지별 기획을 모읍니다.

## 대상

- 고등학생 ~ 대학교 1학년. 앞 단계 지식을 가정하지 않는다.
- 쉬운 말, 일상 비유, 단계별 설명. 수식은 꼭 필요할 때 한 줄만.

## 페이지 기획안 항목

1. **이 페이지의 한 문장 목표**: 다 읽은 학생이 할 수 있게 되는 것
2. **전제 개념**: 이 페이지 전에 알아야 하는 것. 앞 레슨에서 배웠으면 한 줄로 다시 짚는다.
3. **알아야 할 개념**: 순서대로. 하나의 개념 = 하나의 소제목
4. **배치 순서**: 아래 기호로 적는다.
   - `S` 설명 (비유 → 정의 → 왜 필요한지)
   - `F` 그림·도식
   - `C` 실행 셀 (읽고 실행만 하는 예제)
   - `T` 직접 해보기 셀 (값 하나를 바꿔 보며 결과 비교)
   - `R` 결과 해석 (실행 결과 숫자를 짚어 주는 설명)
5. **퀴즈 vs 코드 실습 판단**과 근거
6. **그림·도식 목록**
7. **데이터**와 **연결된 실습 문제**
8. **영상 위치**: 어떤 설명 바로 뒤에 어떤 모션 영상을 넣는지 (트랙 페이지에 따로 모으지 않는다)
9. **원본 원고**: `docs/sources/` 안의 진성 님 원고 중 무엇을 바탕으로 했는지, 무엇을 가져오고 무엇을 뺐는지

## 퀴즈 vs 코드 실습 판단 기준

| 배워야 하는 것 | 효과적인 방식 | 이유 |
| --- | --- | --- |
| 용어 구분, 상황 판단 ("이 상황엔 어떤 지표?") | 개념 퀴즈 (choice · ox) | 코드를 짜도 판단력은 늘지 않는다. 짧은 퀴즈가 오개념을 바로 잡는다. |
| 숫자 계산 원리 ("TP=6, FN=2면 재현율?") | short 퀴즈 | 공식을 한 번 손으로 계산해 봐야 기억에 남는다. |
| 순서·절차 (분할 → fit → 평가) | 코드 실습 (T 셀 + 실습 문제) | 순서는 직접 쳐 봐야 몸에 붙는다. |
| 설정값의 효과 (max_depth, k, 임계값) | T 셀 (값 바꿔 보기) | 값을 바꿔 결과가 변하는 것을 보는 게 설명보다 빠르다. |
| API 사용법 (Pipeline, ColumnTransformer) | 실습 문제 (빈칸 채우기·단계형) | 퀴즈로 이름을 맞히는 것은 쓸 줄 아는 것과 다르다. |

- 레슨 퀴즈는 **판단 · 오개념 확인용으로만**, 최대 3문항. 코드 실습으로 충분하면 퀴즈를 넣지 않고 '레슨 완료' 버튼으로 끝낸다.
- "출력 결과를 쓰세요" 문항은 만들지 않는다.

## 작성 규칙

- import / from 문은 코드 맨 위.
- 그래프 글자는 영어 (브라우저 파이썬에 한글 글꼴 없음).
- 실행 결과에 나온 숫자를 본문에서 그대로 짚는다. 결과와 본문이 어긋나면 안 된다.
- 앞 레슨에서 이미 가르친 내용은 다시 길게 가르치지 않고 "[평가지표](#/l/ml-03-1)에서 배운 재현율" 식으로 연결만 한다.
- 본문에서 다른 레슨 · 코스를 가리킬 때는 `ml-02-5`, `dl-04` 같은 **번호를 쓰지 않고 제목으로 풀어 쓴다.** 예: ~~`ml-02-5에서 배운`~~ → `[로지스틱 회귀: 확률로 분류하기](#/l/ml-02-5)에서 배운`. 코스는 코스 제목에 첫 레슨 링크를 건다. 제목 뒤 조사(은/는 · 을/를 · 과/와 · 으로/로)는 제목 끝 글자에 맞춘다. 그림 alt · caption에는 링크 없이 제목만 쓴다. 학생 화면에는 번호가 보이지 않으므로 번호는 의미가 없다.
- 영상은 `::video{ref="dl-mNN"}`로 관련 설명 바로 뒤에 넣는다. 아직 제작 전이면 화면에 표시되지 않고, `content/videos.js`에 `release_url`(유튜브 주소)이나 `youtube_id`를 넣으면 바로 재생된다.
- 그림은 `::figure{src="content/img/<track>/<name>.svg" alt="..." caption="..."}`로 넣는다.
- 본문 흐름에 꼭 필요하지는 않지만 알아 두면 좋은 지식(소수 계산 오차 같은 심화 · 배경 지식)은 전구 아이콘 팁 상자로 분리한다. 여는 줄 `:::tip 알아 두면 좋아요 · 제목`, 닫는 줄 `:::`. 안에는 문단 · 실행 셀 · 표를 그대로 쓸 수 있다.
