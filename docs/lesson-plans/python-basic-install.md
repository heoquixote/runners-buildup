### pb-00-2 Google Colab
- 개념: 노트북 = 셀(코드/텍스트) 묶음, 런타임 = 구글 서버의 파이썬
- 도식: Colab 화면 지도(① 파일 이름 ② + 코드 ③ 셀과 ▶ ④ 왼쪽 파일 패널 ⑤ 런타임 메뉴)
- 순서: 접속·로그인 → 새 노트 → 셀 실행(Shift+Enter) → 파일 올리기 / 구글 드라이브 연결 → 저장 위치
- 막힘: 회사 계정 차단, 연결 끊김·변수 사라짐, 업로드 파일 사라짐, 한글 그래프 깨짐, `!pip install`

### pb-00-3 Anaconda
- 개념: 배포판(파이썬 + 패키지 + Jupyter), Navigator · Anaconda Prompt · Jupyter의 관계
- 도식: 설치 옵션 화면(Just Me, 설치 경로, PATH 체크 해제), Jupyter 화면 지도
- 순서: 내려받기(Windows / macOS Apple 칩·Intel 구분) → 설치 → Jupyter 실행 → 새 노트북 → 실행
- 막힘: 한글 사용자 폴더 경로, `conda` 명령 없음, 브라우저가 안 열림(토큰 URL), 노트북 파일 위치, 조직 규모별 라이선스 → Miniconda/공식 설치

### pb-00-4 python.org + VS Code
- 개념: 인터프리터(python.org) + 편집기(VS Code) 역할 분리, 가상환경이 필요한 이유
- 도식: Windows 설치 첫 화면(PATH 체크), VS Code 화면 지도(① 탐색기 ② 확장 ③ 편집기 ④ ▶ 실행 ⑤ 터미널 ⑥ 인터프리터 선택)
- 순서: 파이썬 설치(Windows / macOS) → 버전 확인 → VS Code 설치 → 확장 2개 → 폴더 열고 hello.py 실행 → 가상환경 + pandas 설치
- 막힘: Microsoft Store가 열림(앱 실행 별칭), `pip` 인식 안 됨(`python -m pip`), PowerShell 실행 정책, macOS SSL 인증서, 설치했는데 ModuleNotFoundError(인터프리터 불일치)

## 실행 셀
