## 학습 목표

- 문자열을 만들고 결합하고 포매팅할 수 있습니다.
- `print()`와 `input()`의 역할을 설명할 수 있습니다.
- 사용자 입력이 왜 기본적으로 문자열로 들어오는지 이해할 수 있습니다.

## 사용 라이브러리

- 표준 라이브러리: 없음
- 외부 라이브러리: 없음

## 왜 문자열과 입출력이 중요한가

초보자는 Python을 숫자 계산 도구처럼 생각하기 쉽지만, 실제 프로그램은 대부분 `문자열`을 다룹니다.

- 사용자 이름
- 파일 경로
- 날짜
- 로그 메시지
- API 응답
- 리포트 문장

또한 프로그램은 입력을 받고 출력을 보여주면서 동작합니다. 문자열과 기본 입출력은 사실상 모든 프로그램의 공통 기반입니다.

## 문자열 만들기

문자열은 작은따옴표나 큰따옴표로 만들 수 있습니다.

```python
name = "Python"
city = 'Seoul'
```

둘의 기능 차이는 거의 없고, 팀이나 프로젝트의 스타일에 맞춰 일관되게 쓰는 것이 더 중요합니다.

## 문자열 연결과 반복

```python
first = "Learners"
second = "School"

print(first + " " + second)
print("-" * 20)
```

- `+`는 문자열 결합
- `*`는 문자열 반복

반복은 콘솔 출력 구분선이나 간단한 포맷팅에서 자주 사용됩니다.

## 문자열 인덱싱과 슬라이싱

문자열은 순서가 있는 데이터입니다.

```python
text = "Python"

print(text[0])   # P
print(text[1])   # y
print(text[-1])  # n
print(text[0:3]) # Pyt
```

이 기능은 코드 파싱, 파일명 처리, 접두어/접미어 분리 같은 작업에서 유용합니다.

## 자주 쓰는 문자열 메서드

```python
text = "  python data  "

print(text.strip())
print(text.upper())
print(text.lower())
print(text.replace("data", "sql"))
print(text.split())
```

### `strip()`

앞뒤 공백 제거

### `upper()`, `lower()`

대소문자 변환

### `replace()`

문자열 일부 치환

### `split()`

구분자를 기준으로 나누기

실무에서는 CSV 비슷한 문자열, 로그 라인, 사용자 입력 가공에 자주 씁니다.

## 문자열 포매팅

문자열 안에 값을 자연스럽게 넣는 방법입니다.

### f-string

가장 추천하는 방식입니다.

```python
name = "Jinseong"
score = 95

message = f"{name}님의 점수는 {score}점입니다."
print(message)
```

가독성이 좋고, 실무에서 가장 많이 사용됩니다.

### `format()`

```python
message = "{}님의 점수는 {}점입니다.".format(name, score)
print(message)
```

기존 코드에서 자주 보이지만, 새로 작성할 때는 보통 f-string이 더 읽기 쉽습니다.

## `print()` 함수

`print()`는 값을 화면에 보여주는 함수입니다.

```python
print("Hello")
print(10)
print(True)
```

### 여러 값 함께 출력

```python
name = "Python"
version = 3.12

print(name, version)
```

### `sep`와 `end`

```python
print("2026", "06", "23", sep="-")
print("Hello", end=" ")
print("Python")
```

- `sep`: 여러 값 사이 구분자
- `end`: 출력 끝에 붙일 문자

로그를 정돈하거나 한 줄 포맷을 만들 때 유용합니다.

## `input()` 함수

사용자 입력을 받는 함수입니다.

```python
name = input("이름을 입력하세요: ")
print(name)
```

중요한 점:

`input()`으로 받은 값은 항상 문자열입니다.

```python
age = input("나이를 입력하세요: ")
print(type(age))
```

그래서 숫자 계산에 쓰려면 형변환이 필요합니다.

```python
age = int(input("나이를 입력하세요: "))
print(age + 1)
```

## 왜 입력이 문자열로 들어올까

사용자가 키보드로 입력하는 정보는 컴퓨터 입장에서는 우선 `문자`입니다.

예를 들어 사용자가 `30`을 입력해도, 프로그램이 처음 받는 것은 `"30"`입니다. 이 값을 `정수 30`으로 쓸지, `문자열 "30"`으로 쓸지는 프로그램이 나중에 결정합니다.

이 원리를 이해하면 형변환이 왜 필요한지 자연스럽게 받아들일 수 있습니다.

## 문자열은 불변(immutable)이다

문자열은 한 번 만들어지면 내부 문자를 직접 바꿀 수 없습니다.

```python
text = "Python"
# text[0] = "J"  # 오류
```

대신 새 문자열을 만들어야 합니다.

```python
text = "J" + text[1:]
print(text)
```

이 개념은 이후 `리스트는 바뀌고 문자열은 안 바뀐다`는 차이를 이해하는 데 중요합니다.

## 실무에서 자주 만나는 문자열 문제

### 1. 공백 문제

```python
user_id = "  admin  "
print(user_id.strip())
```

입력 앞뒤 공백을 제거하지 않으면 비교나 조회가 실패할 수 있습니다.

### 2. 숫자 문자열 계산 문제

```python
price = input("가격을 입력하세요: ")
print(price + "100")
```

이렇게 하면 숫자 계산이 아니라 문자열 결합이 됩니다.

### 3. 줄바꿈과 포맷 문제

리포트나 로그를 출력할 때는 출력 형식이 곧 가독성입니다. `print()`를 단순 확인용으로만 보지 말고, 메시지를 설계하는 도구로 생각하는 것이 좋습니다.

## 간단한 예제

```python
name = input("이름: ")
sales = int(input("오늘 매출: "))

message = f"{name}님의 오늘 매출은 {sales:,}원입니다."
print(message)
```

이 예제에는 실제로 중요한 요소가 다 들어 있습니다.

- 입력 받기
- 문자열을 숫자로 변환하기
- f-string으로 문장 만들기
- 결과 출력하기

## 자주 하는 실수

- `input()` 결과를 숫자로 착각하는 것
- 문자열과 숫자를 바로 더하려는 것
- 공백이나 줄바꿈을 무시하는 것
- 긴 문자열을 무작정 `+`로 이어 붙여 가독성을 해치는 것

## 정리

이번 페이지의 핵심은 다음입니다.

- 문자열은 거의 모든 프로그램에서 등장합니다.
- `print()`는 보여주기, `input()`은 받기입니다.
- `input()` 결과는 항상 문자열이므로 필요하면 형변환해야 합니다.

문자열과 입출력에 익숙해지면 이후 파일 처리, 로그, 예외 메시지, API 응답 해석이 훨씬 쉬워집니다.
