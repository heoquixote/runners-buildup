## 이 장의 목적

Python 문법을 외우기 전에, `Python이 왜 쓰이는지`, `코드는 어떻게 실행되는지`, `학습 환경은 어떻게 구성해야 하는지`를 먼저 정리합니다.  
입문 단계에서 가장 많이 막히는 지점은 문법보다도 실행 환경과 실행 흐름을 이해하지 못하는 데 있습니다.

## 왜 이 장이 먼저 필요한가

많은 초보자가 `print()`부터 배우지만, 실무에서는 아래 질문이 먼저 잡혀야 합니다.

- Python은 어떤 문제에 강한가
- Notebook과 `.py` 스크립트는 무엇이 다른가
- 코드 실행은 어떤 순서로 일어나는가
- 설치는 했는데 왜 실행이 안 되는가

이 흐름이 없으면 에러 메시지를 읽어도 원인을 좁히기 어렵고, 환경이 바뀌었을 때 같은 코드가 왜 다르게 보이는지도 설명하기 어렵습니다.

## 이 장에서 다루는 흐름

1. Python을 배우는 이유와 활용 분야를 정리합니다.
2. 인터프리터와 실행 흐름을 이해합니다.
3. 로컬 개발 환경과 실습 방식의 차이를 정리합니다.

- 1-1. 왜 Python을 배워야 할까?
- 1-2. Python 코드는 어떻게 실행될까?
- 1-3. 개발 환경과 실행 방법
