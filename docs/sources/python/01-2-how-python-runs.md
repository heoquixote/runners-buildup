## 왜 실행 흐름을 이해해야 하는가

Python 입문자는 문법 자체보다 `왜 같은 코드가 환경마다 다르게 보이는지`에서 더 자주 혼란을 겪습니다.

예:

- Notebook에서는 되는데 `.py` 파일에서는 안 됨
- 아까 만든 변수가 지금은 없음
- 코드를 수정했는데 예상과 다르게 실행됨

이 문제의 핵심은 대부분 `실행 방식과 실행 순서`를 이해하지 못한 데서 시작됩니다.

## Python은 인터프리터 방식으로 동작한다

Python은 기본적으로 인터프리터가 코드를 읽고 실행하는 언어입니다.

쉽게 말하면:

1. 작성한 코드를 읽고
2. 문법이 맞는지 확인하고
3. 위에서 아래로 실행합니다

즉, Python은 보통 `작성 -> 저장 -> 실행 -> 결과 확인`의 흐름으로 사용됩니다.

## Python을 실행하는 대표적인 방식

### 1. REPL

터미널에서 한 줄씩 실행하는 방식입니다.

```python
>>> 2 + 3
5
```

장점:

- 빠르게 실험할 수 있음
- 문법 테스트에 좋음

한계:

- 긴 로직 관리가 어려움
- 재현성이 낮음

### 2. 스크립트 `.py`

파일 전체를 처음부터 끝까지 실행하는 방식입니다.

```python
print("start")
x = 10
print(x)
```

터미널에서:

```bash
python main.py
```

장점:

- 재현성이 높음
- 실무 코드의 기본 형태
- 버전 관리와 배포에 유리

### 3. Jupyter Notebook

셀 단위로 실행하는 방식입니다.

장점:

- 실험과 탐색에 좋음
- 데이터 분석 학습에 유리
- 결과를 바로 시각적으로 확인 가능

한계:

- 셀 실행 순서가 꼬이면 상태를 추적하기 어려움
- 스크립트처럼 항상 처음부터 재실행되는 것이 아님

## 왜 Notebook과 스크립트가 다르게 느껴질까

Notebook에서는 셀을 부분적으로 다시 실행할 수 있고, 이전 셀의 변수 상태가 남아 있습니다.

예를 들어:

```python
x = 10
```

를 먼저 실행해 두었다면, 아래 셀에서:

```python
print(x)
```

가 동작할 수 있습니다.

하지만 `.py` 파일은 매번 `처음부터 끝까지` 다시 실행합니다. 따라서 중간 셀만 따로 살아 있는 개념이 없습니다.

이 차이를 이해하지 못하면:

- Notebook에서는 되던 코드가 스크립트에서 실패하고
- `NameError`가 왜 났는지 헷갈리게 됩니다

## 실행 순서는 위에서 아래로

기본적으로 Python은 파일을 위에서 아래로 읽습니다.

```python
print(name)
name = "Python"
```

이 코드는 실패합니다. `name`이 정의되기 전에 사용되었기 때문입니다.

즉, 코드가 적혀 있는 순서 자체가 중요합니다.

## 함수는 정의와 실행이 다르다

```python
def greet():
    print("hello")

greet()
```

여기서:

- `def greet():`는 함수를 정의하는 단계
- `greet()`는 함수를 실제 실행하는 단계

초보자는 정의만 해놓고 왜 출력이 안 되는지 헷갈리기 쉽습니다. 함수를 만들어 두는 것과 호출하는 것은 별개입니다.

## 에러를 실행 흐름으로 읽는 방법

예를 들어 `NameError`가 났다면:

- 이 변수가 정말 먼저 정의되었는가
- Notebook이라면 이전 셀 상태에 의존한 것은 아닌가
- 함수 안과 밖의 스코프를 혼동한 것은 아닌가

를 먼저 확인해야 합니다.

`ImportError`라면:

- 해당 라이브러리가 설치되었는가
- 현재 실행 중인 Python 환경이 맞는가

를 점검하면 됩니다.

즉, 많은 에러는 문법보다 `실행 맥락`을 보면 더 빨리 풀립니다.

## `if __name__ == "__main__"` 패턴

Python 파일은 직접 실행할 수도 있고, 다른 파일에서 가져와 사용할 수도 있습니다.

```python
def main():
    print("프로그램 시작")


if __name__ == "__main__":
    main()
```

이 구조의 의미:

- 이 파일을 직접 실행하면 `main()` 실행
- 다른 파일에서 import하면 자동 실행되지 않음

실무에서는 매우 자주 쓰는 패턴입니다.

## 추천 학습 방식

입문 단계에서는 다음 흐름이 좋습니다.

1. REPL로 아주 작은 문법 실험
2. `.py` 파일로 전체 흐름 확인
3. 탐색형 분석은 Notebook 활용
4. 최종 검증은 스크립트 기준으로 다시 실행

이렇게 하면 편의성과 재현성을 둘 다 챙길 수 있습니다.

- 함수 정의와 호출을 같은 것으로 착각하는 것
