## 이 장의 목적

Python을 조금 쓰다 보면, 한 파일 안에 모든 코드를 넣는 방식이 금방 한계에 부딪힙니다.  
이 장에서는 코드를 여러 파일로 나누고, 재사용하고, 실행 환경까지 관리하는 기본 구조를 다룹니다.

## 왜 중요한가

Notebook 한 칸에서는 잘 돌아가던 코드가 파일이 여러 개가 되면 갑자기 복잡해집니다.  
이때 필요한 것이 `모듈`, `패키지`, `클래스`, `가상환경` 같은 구조화 도구입니다.
