## 이 장의 목적

이 장에서는 Python에서 가장 자주 사용하는 핵심 자료구조인 리스트, 튜플, 딕셔너리, 집합을 다룹니다.  
또한 `참조`, `가변/불변`, `복사`처럼 초보자가 가장 많이 헷갈리는 동작 원리도 함께 정리합니다.

## 왜 이 장이 중요한가

코드가 잘못되는 이유는 문법보다도 `데이터 구조를 잘못 선택했기 때문`인 경우가 많습니다.  
같은 값을 다루더라도 순서가 중요한지, 키로 찾아야 하는지, 중복을 제거해야 하는지에 따라 적절한 구조가 달라집니다.
