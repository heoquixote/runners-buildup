## 학습 목표

- `int()`, `float()`, `str()`, `bool()` 같은 형변환 함수를 이해할 수 있습니다.
- Python에서 어떤 값이 참처럼, 거짓처럼 평가되는지 설명할 수 있습니다.
- 형변환 실수로 생기는 대표적인 오류를 피할 수 있습니다.

## 사용 라이브러리

- 표준 라이브러리: 없음
- 외부 라이브러리: 없음

## 왜 형변환과 불리언 평가가 중요한가

실무 데이터는 항상 깔끔한 타입으로 들어오지 않습니다.

- 엑셀에서 읽은 숫자가 문자열일 수 있습니다.
- API 응답이 `"true"`처럼 문자열일 수 있습니다.
- 빈 값과 0이 같은 의미가 아닐 수도 있습니다.

이런 상황에서 형변환과 불리언 평가 규칙을 이해하지 못하면 조건문이 엉뚱하게 동작하고, 계산 결과도 틀어집니다.

## 형변환이란 무엇인가

형변환은 한 타입의 값을 다른 타입으로 바꾸는 것입니다.

```python
age_text = "30"
age = int(age_text)

price = "19.99"
price_float = float(price)
```

Python에서는 대표적으로 다음 변환을 많이 씁니다.

- `int()`
- `float()`
- `str()`
- `bool()`

## `int()`와 `float()`

### 문자열을 정수로 바꾸기

```python
count = int("10")
print(count + 5)
```

### 문자열을 실수로 바꾸기

```python
ratio = float("0.75")
print(ratio * 100)
```

### 주의할 점

```python
# int("3.14")  # 오류
```

`"3.14"`는 정수 문자열이 아니므로 바로 `int()`로 바꿀 수 없습니다.

필요하다면:

```python
value = int(float("3.14"))
```

처럼 중간에 실수 변환을 거칠 수 있습니다. 다만 이 경우 소수점 아래 정보는 사라집니다.

## `str()`

숫자나 불리언 값을 문자열로 바꿀 때 사용합니다.

```python
price = 15000
message = "가격은 " + str(price) + "원입니다."
print(message)
```

실무에서는 보통 f-string이 더 읽기 좋지만, `str()` 자체는 여전히 자주 쓰입니다.

## `bool()`

값을 참 또는 거짓으로 바꿉니다.

```python
print(bool(1))
print(bool(0))
print(bool("hello"))
print(bool(""))
```

기본 원리는 간단합니다.

- 비어 있거나 0에 가까운 값은 거짓
- 값이 있으면 참

하지만 여기서 초보자가 자주 헷갈립니다.

```python
print(bool("False"))
```

결과는 `False`가 아니라 `True`입니다. 이유는 `"False"`가 `비어 있지 않은 문자열`이기 때문입니다.

즉, 문자열 내용이 아니라 `문자열이 비어 있는지 아닌지`가 기준입니다.

## 자주 쓰는 형변환 패턴

### 사용자 입력 숫자로 바꾸기

```python
age = int(input("나이를 입력하세요: "))
```

### 숫자를 문자열로 바꿔 출력하기

```python
sales = 250000
print("오늘 매출: " + str(sales))
```

### 정수와 실수 섞어 다루기

```python
quantity = 3
unit_price = 19.99
total = quantity * unit_price
print(total)
```

Python은 이 경우 자동으로 실수형 계산을 수행합니다.

## 불리언 평가(truthiness)란 무엇인가

Python에서는 값이 꼭 `True`나 `False`가 아니어도 조건문 안에서 참/거짓처럼 평가됩니다.

```python
name = "Python"

if name:
    print("이름이 있습니다.")
```

여기서 `name`은 문자열이지만, 비어 있지 않으므로 참으로 평가됩니다.

## 거짓처럼 평가되는 대표 값

다음 값들은 조건문에서 보통 거짓처럼 평가됩니다.

- `0`
- `0.0`
- `""`
- `[]`
- `{}`
- `set()`
- `None`
- `False`

예:

```python
items = []

if not items:
    print("데이터가 비어 있습니다.")
```

실무에서 이 패턴은 매우 자주 쓰입니다.

## 참처럼 평가되는 대표 값

다음은 보통 참처럼 평가됩니다.

- 0이 아닌 숫자
- 비어 있지 않은 문자열
- 요소가 있는 리스트/딕셔너리/집합
- 대부분의 객체

```python
if [1, 2, 3]:
    print("리스트에 값이 있습니다.")
```

## `None`, `0`, `""`는 같은가

절대 같지 않습니다. 실무에서는 이 차이를 구분하는 것이 중요합니다.

- `None`: 값이 없음
- `0`: 숫자 0
- `""`: 빈 문자열

예를 들어 매출 컬럼에서:

- `None`은 데이터 누락
- `0`은 실제 매출 없음

일 수 있습니다. 둘을 같은 의미로 처리하면 분석 결과가 왜곡됩니다.

## 조건문에서 자주 쓰는 패턴

### 값이 있는지 확인

```python
email = "user@example.com"

if email:
    print("이메일이 있습니다.")
```

### 입력값이 비어 있는지 확인

```python
name = input("이름: ").strip()

if not name:
    print("이름이 비어 있습니다.")
```

### 숫자 변환 전 예외 가능성 고려

```python
value = "123"

if value:
    number = int(value)
```

## 실무에서 자주 하는 실수

### 1. `"False"`를 거짓으로 착각

```python
flag = "False"
if flag:
    print("실행됨")
```

실행됩니다. 문자열이 비어 있지 않기 때문입니다.

### 2. `int()` 변환 가능 여부를 확인하지 않음

```python
# int("12,000")  # 오류
# int("N/A")     # 오류
```

실무 데이터는 종종 쉼표, 공백, 특수문자를 포함합니다. 정제 없이 바로 변환하면 실패합니다.

### 3. `None`과 `0`을 같은 것으로 처리

분석이나 조건 판단에서 의미가 완전히 달라질 수 있습니다.

## 추천 예제

```python
raw_sales = input("오늘 매출을 입력하세요: ").strip()

if not raw_sales:
    print("매출값이 비어 있습니다.")
else:
    sales = int(raw_sales)
    is_high_sales = sales >= 100000
    print(f"입력된 매출: {sales}")
    print(f"목표 달성 여부: {is_high_sales}")
```

이 예제는 형변환, 빈 문자열 검사, 불리언 평가가 함께 어떻게 쓰이는지 보여줍니다.

## 정리

이번 페이지의 핵심은 다음입니다.

- 형변환은 데이터를 올바른 타입으로 맞추는 과정입니다.
- Python은 `True`, `False`뿐 아니라 다양한 값을 참/거짓처럼 평가합니다.
- `None`, 빈 문자열, 0은 겉으로 비슷해 보여도 의미가 다를 수 있습니다.

이 규칙을 이해하면 조건문, 입력 처리, 파일 읽기, 데이터 전처리에서 훨씬 안정적인 코드를 작성할 수 있습니다.
