## 이 장의 목적

이 장에서는 Python 기본 기능을 넘어, 별도 설치를 통해 확장되는 `외부 라이브러리`를 다룹니다.  
Python 생태계의 강점은 바로 이 확장성에 있기 때문에, `무엇을 언제 설치해야 하는가`를 이해하는 것이 중요합니다.

## 왜 이 장이 중요한가

표준 라이브러리만으로도 많은 작업이 가능하지만, API 호출, 대규모 테이블 처리, 시각화는 외부 라이브러리가 훨씬 효율적인 경우가 많습니다.  
다만 초보자는 `어디까지가 기본 제공인지` 헷갈리기 쉬우므로, 이 장에서 그 경계를 명확히 잡습니다.
