## 학습 목표

- 리스트와 튜플의 공통점과 차이를 설명할 수 있습니다.
- 순서가 있는 컬렉션이 필요한 상황을 이해할 수 있습니다.
- 변경 가능 여부가 설계에 어떤 영향을 주는지 설명할 수 있습니다.

## 사용 라이브러리

- 표준 라이브러리: 없음
- 외부 라이브러리: 없음

## 왜 리스트와 튜플이 중요한가

실무에서 데이터를 한 개만 다루는 경우는 드뭅니다. 보통은 여러 값을 묶어서 순서대로 처리해야 합니다.

- 여러 학생 점수
- 여러 파일 경로
- 여러 날짜
- 한 행의 여러 값

이때 가장 먼저 떠오르는 자료구조가 리스트와 튜플입니다.

## 리스트와 튜플의 공통점

둘 다 `순서가 있는 데이터 묶음`입니다.

```python
numbers = [10, 20, 30]
point = (3, 7)
```

공통적으로 가능한 일:

- 인덱스로 접근
- 슬라이싱
- 반복문 순회
- 길이 확인

```python
print(numbers[0])
print(point[1])
print(len(numbers))
```

## 리스트 `list`

리스트는 `변경 가능한` 순서형 자료구조입니다.

```python
fruits = ["apple", "banana", "orange"]
fruits.append("grape")
print(fruits)
```

### 리스트에서 자주 쓰는 메서드

```python
items = [1, 2, 3]

items.append(4)
items.extend([5, 6])
items.insert(1, 99)
items.remove(99)
last_item = items.pop()

print(items)
print(last_item)
```

자주 쓰는 메서드:

- `append()`: 맨 뒤에 추가
- `extend()`: 여러 값 이어 붙이기
- `insert()`: 특정 위치에 삽입
- `remove()`: 값 기준 삭제
- `pop()`: 위치 기준 제거 후 반환

### 리스트가 잘 맞는 상황

- 데이터가 계속 추가/삭제될 수 있을 때
- 순회하면서 가공할 때
- 결과를 누적할 때

예:

```python
sales = []
sales.append(12000)
sales.append(15000)
sales.append(18000)
```

## 튜플 `tuple`

튜플은 `변경 불가능한` 순서형 자료구조입니다.

```python
point = (10, 20)
```

튜플은 한 번 만들면 원소를 바꿀 수 없습니다.

```python
# point[0] = 99  # 오류
```

### 튜플이 잘 맞는 상황

- 값의 구조가 고정되어 있을 때
- 좌표처럼 의미가 정해진 묶음일 때
- 함수에서 여러 값을 반환할 때

예:

```python
position = (37.5, 127.0)
student = ("Kim", 95)
```

## 리스트와 튜플의 가장 큰 차이

핵심은 `변경 가능 여부`입니다.

- 리스트: 바꿀 수 있음
- 튜플: 바꿀 수 없음

이 차이는 단순 문법 차이가 아니라 `설계 의도`를 표현합니다.

예를 들어:

- 월별 매출 목록 -> 리스트
- RGB 색상 값 `(255, 255, 255)` -> 튜플

즉, 앞으로 바뀔 데이터인지 아닌지를 구조로 드러낼 수 있습니다.

## 인덱싱과 슬라이싱

```python
numbers = [10, 20, 30, 40, 50]

print(numbers[0])
print(numbers[-1])
print(numbers[1:4])
```

이 기능은 특정 구간의 데이터 추출, 최근 7일 데이터 자르기, 상위 일부 항목 확인 등에 자주 쓰입니다.

## 반복문과 함께 쓰기

```python
scores = [88, 92, 75, 100]

for score in scores:
    print(score)
```

리스트와 튜플은 반복문과 함께 사용할 때 진가가 드러납니다. 이후 배우는 `for`, `comprehension`, `map` 같은 개념과도 자연스럽게 이어집니다.

## 패킹과 언패킹

튜플은 여러 값을 한 번에 묶고 풀 때 특히 편리합니다.

```python
point = (3, 7)
x, y = point

print(x)
print(y)
```

함수 반환값에서도 자주 보게 됩니다.

```python
def get_min_max(numbers):
    return min(numbers), max(numbers)

low, high = get_min_max([3, 8, 1, 9])
```

## 실무에서 자주 하는 실수

### 1. 리스트 복사와 참조 공유 혼동

```python
a = [1, 2, 3]
b = a
```

이 경우 `b`는 복사본이 아니라 같은 리스트를 함께 가리킵니다. 이 내용은 `3-3`에서 더 자세히 다룹니다.

### 2. 튜플도 리스트처럼 수정하려고 함

튜플은 구조가 고정된 데이터를 위한 도구입니다. 수정이 필요하면 리스트를 써야 합니다.

### 3. 의미가 다른 값을 무작정 순서만으로 저장

예:

```python
data = ["Kim", 29, "Seoul", 5500]
```

이렇게만 두면 나중에 각 위치의 의미를 기억하기 어렵습니다. 구조가 복잡해지면 딕셔너리나 클래스가 더 나을 수 있습니다.

## 추천 예제

### 리스트 예제

```python
daily_sales = [120000, 98000, 150000, 110000]

total = 0
for sales in daily_sales:
    total += sales

print(total)
```

### 튜플 예제

```python
report_period = ("2026-06-01", "2026-06-30")
start_date, end_date = report_period

print(start_date)
print(end_date)
```

## 언제 무엇을 쓰면 좋은가

- 수정, 추가, 삭제가 필요하다 -> 리스트
- 고정된 구조의 값을 묶는다 -> 튜플
- 함수 반환값을 여러 개 돌려준다 -> 튜플
- 반복 처리 대상이 유동적이다 -> 리스트

## 정리

이번 페이지의 핵심은 다음입니다.

- 리스트와 튜플은 모두 순서형 자료구조입니다.
- 차이는 `변경 가능 여부`입니다.
- 자료구조 선택은 단순 취향이 아니라 데이터의 성격을 표현하는 결정입니다.

이 기준을 익혀 두면 이후 딕셔너리, 집합, 함수 반환값, 반복문을 더 자연스럽게 이해할 수 있습니다.
