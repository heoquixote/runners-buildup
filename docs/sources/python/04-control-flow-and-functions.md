## 이 장의 목적

이 장에서는 코드를 조건에 따라 나누고, 여러 번 반복하고, 재사용 가능한 단위로 묶는 방법을 다룹니다.  
기초 문법이 `한 줄을 읽는 능력`이라면, 이 장은 `작은 프로그램을 만드는 능력`으로 넘어가는 구간입니다.

## 왜 이 장이 중요한가

초보자는 같은 코드를 여러 번 복사해서 문제를 해결하기 쉽습니다.  
하지만 조건문, 반복문, 컴프리헨션, 함수를 익히면 같은 작업을 더 짧고 읽기 쉬운 구조로 바꿀 수 있습니다.
