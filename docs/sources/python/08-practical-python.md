## 이 장의 목적

이 장에서는 앞에서 배운 문법, 자료구조, 라이브러리, 패키지 관리 개념을 실제 업무 흐름으로 연결합니다.  
코드를 한 번 실행하는 수준을 넘어, 반복 실행하고 유지보수하는 감각을 만드는 장입니다.

## 왜 이 장이 중요한가

문법을 안다고 해서 바로 실무 코드가 되는 것은 아닙니다.  
실무에서는 입력 파일, 실패 상황, 반복 실행, 로그, 프로젝트 구조가 함께 움직입니다.

- 8-1. 자동화 스크립트 만들기
- 8-2. 디버깅과 에러 읽기
- 8-3. 프로젝트 구조와 좋은 코드 습관
