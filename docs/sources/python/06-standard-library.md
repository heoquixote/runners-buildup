## 이 장의 목적

이 장에서는 Python 설치만으로 바로 사용할 수 있는 `표준 라이브러리`를 다룹니다.  
초보자가 `이 기능도 따로 설치해야 하나요?`라는 혼란을 줄일 수 있도록, 기본 제공 기능만 따로 묶어 설명합니다.

## 왜 이 장이 중요한가

실무에서는 외부 라이브러리 없이도 상당수의 파일 처리, 경로 조작, 날짜 계산, CSV/JSON 입출력을 해결할 수 있습니다.  
즉, 외부 라이브러리를 배우기 전에 표준 라이브러리만으로 가능한 범위를 먼저 이해하는 편이 좋습니다.

## 세부 목차

- 6-1. 파일 입출력
- 6-2. 예외 처리
- 6-3. CSV와 JSON
- 6-4. datetime, math, random, os, pathlib
