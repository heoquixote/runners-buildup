## 학습 목표

- 변수와 값의 관계를 설명할 수 있습니다.
- 숫자형, 문자열, 불리언의 차이를 이해할 수 있습니다.
- 데이터 타입에 따라 가능한 연산이 달라진다는 점을 설명할 수 있습니다.

## 사용 라이브러리

- 표준 라이브러리: 없음
- 외부 라이브러리: 없음

## 왜 이 주제가 중요한가

Python을 처음 배울 때 변수는 단순히 `값을 저장하는 상자`처럼 설명되는 경우가 많습니다. 입문 단계에서는 이 비유가 도움이 되지만, 실제로는 `이름이 어떤 값을 가리키는 구조`에 더 가깝습니다.

이 개념을 정확히 이해해야 다음 주제들이 자연스럽게 연결됩니다.

- 자료구조를 다룰 때 왜 값이 바뀌는지
- 함수에 값을 넘길 때 무엇이 전달되는지
- 디버깅할 때 어떤 변수가 어떤 상태인지

## 변수란 무엇인가

변수는 `값에 붙이는 이름`입니다.

```python
name = "jinseong"
age = 30
is_student = False
```

위 코드는 다음 의미를 가집니다.

- `name`은 `"jinseong"`이라는 문자열을 가리킵니다.
- `age`는 `30`이라는 정수를 가리킵니다.
- `is_student`는 `False`라는 불리언 값을 가리킵니다.

중요한 점은 `변수 이름`과 `값`은 다르다는 것입니다. 변수 이름은 사람이 읽기 쉽도록 붙이는 식별자이고, 실제 연산은 값의 타입에 따라 동작합니다.

## 변수 이름 짓기 규칙

Python 변수명은 다음 규칙을 따릅니다.

- 영문자, 숫자, 밑줄(`_`)을 사용할 수 있습니다.
- 숫자로 시작할 수 없습니다.
- 공백을 넣을 수 없습니다.
- 예약어(`if`, `for`, `class` 등)는 사용할 수 없습니다.

```python
user_name = "heo"
score_2026 = 95
```

좋은 변수명은 `값의 의미`를 드러냅니다.

좋지 않은 예:

```python
a = 15000
x = "2026-06-23"
```

좋은 예:

```python
monthly_salary = 15000
report_date = "2026-06-23"
```

실무에서는 변수명이 곧 문서 역할을 합니다.

## 기본 데이터 타입

### 정수 `int`

소수점이 없는 숫자입니다.

```python
count = 10
temperature = -3
```

### 실수 `float`

소수점이 있는 숫자입니다.

```python
price = 19.99
ratio = 0.82
```

실수는 컴퓨터 내부 표현 방식 때문에 `정확히 떨어지는 값처럼 보이지 않을 수 있습니다`.

```python
print(0.1 + 0.2)
```

결과가 `0.30000000000000004`처럼 보일 수 있습니다. 금융 계산처럼 정밀도가 매우 중요한 경우는 별도 전략이 필요합니다.

### 문자열 `str`

문자를 다루는 타입입니다.

```python
city = "Seoul"
message = "Hello, Python"
```

문자열 안에 숫자가 들어 있어도 타입은 문자열입니다.

```python
age_text = "30"
```

이 값은 숫자처럼 보여도 계산에 바로 쓸 수 없습니다.

### 불리언 `bool`

참과 거짓을 나타냅니다.

```python
is_admin = True
has_error = False
```

조건문, 필터링, 검증 로직에서 핵심적으로 사용됩니다.

## 타입 확인하기

값의 타입이 헷갈릴 때는 `type()`으로 확인할 수 있습니다.

```python
name = "Python"
age = 30
height = 175.5
is_ready = True

print(type(name))
print(type(age))
print(type(height))
print(type(is_ready))
```

입문 단계에서 이 습관은 매우 중요합니다. 눈으로 보기엔 숫자 같아도 실제로는 문자열인 경우가 많기 때문입니다.

## 타입에 따라 가능한 연산이 다르다

```python
print(10 + 20)
print("10" + "20")
```

겉보기에는 비슷하지만 의미는 완전히 다릅니다.

- `10 + 20`은 숫자 계산이라 `30`
- `"10" + "20"`은 문자열 결합이라 `"1020"`

같은 `+` 연산자라도 타입에 따라 다르게 동작합니다. 이것이 바로 `데이터 타입이 중요한 이유`입니다.

## 실무에서 자주 마주치는 타입 문제

### 1. 숫자처럼 보이는 문자열

CSV나 엑셀 파일을 읽으면 `1000`이 숫자가 아니라 문자열로 들어오는 경우가 있습니다.

```python
sales = "1000"
tax = "100"
print(sales + tax)
```

이 코드는 `1100`이 아니라 `"1000100"`이 됩니다.

### 2. 불리언처럼 보이는 문자열

```python
active = "False"
print(type(active))
```

이 값은 문자열이지 불리언이 아닙니다. 따라서 조건문에서 기대와 다르게 동작할 수 있습니다.

### 3. 결측이나 비어 있는 값

실무 데이터에서는 값이 비어 있거나 `None`, `""`, `"N/A"`처럼 섞여 있는 경우가 많습니다. 이런 값들은 이후 형변환이나 연산에서 오류를 유발합니다.

## 학습할 때 추천하는 사고방식

변수를 볼 때는 다음 세 가지를 함께 생각하면 좋습니다.

1. 이 변수 이름은 무엇을 뜻하는가
2. 현재 이 변수 안의 값은 무엇인가
3. 그 값의 타입은 무엇인가

예를 들어:

```python
user_count = "12"
```

여기서 초보자는 `12명`이라는 의미만 보고 넘어가기 쉽지만, 실제로는:

- 이름: `user_count`
- 값: `"12"`
- 타입: 문자열

이라는 세 요소를 동시에 봐야 합니다.

## 간단한 예제

```python
product_name = "Notebook"
price = 45000
discount_rate = 0.1
is_sold_out = False

final_price = price * (1 - discount_rate)

print(product_name)
print(final_price)
print(is_sold_out)
```

이 예제는 실제 업무 코드의 축소판입니다.

- 텍스트는 문자열
- 금액은 숫자형
- 비율은 실수형
- 상태값은 불리언

서로 다른 타입이 함께 움직이면서 하나의 결과를 만듭니다.

## 자주 하는 실수

- 숫자처럼 보이는 문자열을 숫자로 착각하는 것
- 변수명을 너무 짧게 써서 의미를 잃는 것
- 타입을 확인하지 않고 연산부터 하는 것
- `True`, `False` 대신 `"True"`, `"False"` 문자열을 쓰는 것

## 정리

이번 페이지에서 꼭 가져가야 할 핵심은 세 가지입니다.

- 변수는 값을 가리키는 이름입니다.
- 값에는 타입이 있고, 타입에 따라 동작이 달라집니다.
- 실무 오류의 상당수는 타입을 잘못 이해한 상태에서 시작됩니다.

이 감각이 잡히면 다음 페이지의 연산자, 문자열 처리, 형변환, 조건문까지 훨씬 자연스럽게 연결됩니다.
