## 이 장의 목적

이 장에서는 Python 문장을 구성하는 가장 기초적인 요소인 변수, 기본 데이터 타입, 연산자, 문자열, 입력/출력, 형변환을 다룹니다.  
쉽게 말해 `Python 문장을 읽고 직접 쓸 수 있는 최소 문법 단위`를 정리하는 장입니다.

## 왜 이 장이 중요한가

자료구조나 함수로 넘어가기 전에 먼저 `값이 어떤 타입인지`, `연산이 어떻게 해석되는지`, `입력값이 어떤 형태로 들어오는지`를 이해해야 합니다.  
초보자가 자주 겪는 오류는 복잡한 알고리즘보다도 이런 기본 문법 오해에서 시작됩니다.

## 이 장에서 다루는 흐름

1. 변수와 기본 데이터 타입을 익힙니다.
2. 연산자와 표현식이 어떻게 평가되는지 이해합니다.
3. 문자열, 입력/출력, 형변환을 통해 실제 코드 흐름을 만듭니다.
