## 학습 목표

- Python이 널리 쓰이는 이유를 설명할 수 있습니다.
- Python이 특히 강한 작업과 상대적으로 덜 적합한 작업을 구분할 수 있습니다.
- 문법 학습을 넘어 문제 해결 관점에서 Python을 바라볼 수 있습니다.

## 왜 Python인가

Python은 `읽기 쉬운 문법`, `풍부한 생태계`, `자동화와 데이터 처리에 강한 확장성` 때문에 널리 쓰입니다.  
특히 데이터 분석 실무에서는 SQL로 데이터를 꺼내고, Python으로 가공하고, 시각화나 모델링으로 이어지는 흐름이 매우 자연스럽습니다.

## Python이 잘하는 일

- 반복 업무 자동화
- CSV, JSON, API 데이터 처리
- 데이터 분석과 시각화
- 머신러닝과 통계 분석
- 간단한 백엔드나 유틸리티 스크립트 작성

## 실무에서 언제 문제가 되는가

Python은 매우 유연하지만, 속도가 가장 중요한 저수준 시스템 개발에는 다른 언어가 더 적합할 수 있습니다.  
또한 Notebook 위주로만 학습하면 재사용 가능한 코드 구조를 만드는 데 늦게 막힐 수 있습니다.

## 대안은 무엇인가

- 빠른 웹 프론트엔드 상호작용: JavaScript
- 시스템 프로그래밍이나 고성능 처리: Rust, C++
- 통계 중심 학습: R
- 단순 집계와 조회: SQL

중요한 점은 `Python이 모든 문제의 정답`이 아니라, `업무 흐름을 가장 유연하게 연결해주는 좋은 기본 언어`라는 점입니다.
