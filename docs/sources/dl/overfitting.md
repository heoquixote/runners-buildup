# 과적합과 과소적합 (Overfitting)

## 정의
과적합은 학습 데이터의 잡음까지 외워 새 데이터에서 성능이 떨어지는 상태, 과소적합은 기본 패턴조차 잡지 못한 상태다. train 점수보다 validation/test와의 격차가 중요하며, 과소적합은 bias, 과적합은 variance 쪽 문제로 설명한다.

## 책별 관점
### [[machine-learning-basics|머신러닝 기초]]
- 과소적합은 train과 validation 모두 낮고, 과적합은 train은 높은데 validation이 낮다. [[raw/books/02-데이터 분석/머신러닝 기초/pages/09-1-overfitting-underfitting#과적합|머신러닝 기초 09-1]]
- bias가 크면 너무 단순해 구조를 못 잡고, variance가 크면 데이터가 조금만 바뀌어도 모델이 흔들린다. [[raw/books/02-데이터 분석/머신러닝 기초/pages/09-1-overfitting-underfitting#bias-variance를 아주 직관적으로 보기|머신러닝 기초 09-1]]
- train 점수만 보면 외운 정도와 일반화를 구분할 수 없다. [[raw/books/02-데이터 분석/머신러닝 기초/pages/09-1-overfitting-underfitting#train 점수만 보면 왜 위험한가|머신러닝 기초 09-1]]
- 줄이는 방향: 데이터 추가, feature 정리, 모델 단순화, 정규화, 교차검증, 조기 종료. [[raw/books/02-데이터 분석/머신러닝 기초/pages/09-1-overfitting-underfitting#줄이기 위한 기본 방향|머신러닝 기초 09-1]]
- 데이터 누수는 과적합처럼 보이기도 하지만 원인과 대응이 다르다. [[raw/books/02-데이터 분석/머신러닝 기초/pages/09-overfitting-validation-and-regularization#데이터 누수는 과적합처럼 보이기도 합니다|머신러닝 기초 09]]
- feature 수에 비해 표본이 적으면 과적합 위험이 크다. [[raw/books/02-데이터 분석/머신러닝 기초/pages/09-overfitting-validation-and-regularization#1. feature 수는 많은데 표본 수는 적은 경우|머신러닝 기초 09]]
- 결정트리는 깊어질수록 과적합되기 쉬워 max_depth, min_samples_leaf로 제어한다. [[raw/books/02-데이터 분석/머신러닝 기초/pages/10-1-decision-tree-basics#2. 깊어지면 과적합되기 쉽다|머신러닝 기초 10-1]]

### [[bigdata-analysis-engineer|빅데이터분석기사]]
- 과소적합은 모델이 너무 단순해 학습 성능도 나쁜 상태, 과대적합은 학습은 잘 맞히는데 검증이 나쁜 상태다. [[raw/books/05-자격증/빅데이터분석기사/pages/03-빅데이터-모델링/01-분석모형-설계/02-분석-환경-구축/02-데이터-분할#과대적합과 과소적합|빅데이터분석기사 3과목 1-2-2]]
- 대응: 과소적합이면 모델을 복잡하게·변수 추가·더 오래 학습, 과대적합이면 단순화·데이터 추가·정규화·조기 종료. 가장 확실한 것은 데이터 추가지만 가장 비싸다. [[raw/books/05-자격증/빅데이터분석기사/pages/03-빅데이터-모델링/01-분석모형-설계/02-분석-환경-구축/02-데이터-분할#진단과 대응|빅데이터분석기사 3과목 1-2-2]]
- 관측치 20개를 19차 다항식으로 맞추면 모든 점을 지나지만 새 값에서 엉뚱하게 예측한다. 대응은 복잡도를 줄이거나 데이터가 지탱할 양을 늘리는 두 갈래다. [[raw/books/05-자격증/빅데이터분석기사/pages/04-빅데이터-결과-해석/01-분석모형-평가-및-개선/02-분석모형-개선/01-과대적합-방지#과대적합이 생기는 자리|빅데이터분석기사 4과목 1-2-1]]
- 복잡도를 정하는 요소는 모형마다 다르다: 회귀는 변수 수·차수, 나무는 깊이, 신경망은 층·노드 수, SVM은 C. K-최근접이웃은 K가 작을수록 복잡해 방향이 반대다. [[raw/books/05-자격증/빅데이터분석기사/pages/04-빅데이터-결과-해석/01-분석모형-평가-및-개선/02-분석모형-개선/01-과대적합-방지#복잡도는 어디서 오는가|빅데이터분석기사 4과목 1-2-1]]
- 조기 종료는 검증 오차가 올라가기 시작하는 지점에서 학습을 멈추는 방법으로, 구조를 바꾸지 않고 학습 진행량으로 복잡도를 조절한다. [[raw/books/05-자격증/빅데이터분석기사/pages/04-빅데이터-결과-해석/01-분석모형-평가-및-개선/02-분석모형-개선/01-과대적합-방지#조기 종료|빅데이터분석기사 4과목 1-2-1]]
- 신경망에서는 가중치 규제, 에폭 제한, 학습률 감소가 함께 묶인다. 은닉층·노드 수나 에폭을 늘리면 과대적합이 심해진다. [[raw/books/05-자격증/빅데이터분석기사/pages/03-빅데이터-모델링/02-분석기법-적용/01-분석기법/04-인공신경망#과대적합 방지|빅데이터분석기사 3과목 2-1-4]]
- 방법 선택 순서: 데이터 추가가 가능하면 먼저, 비싸면 규제·단순화, 반복 학습 모형은 조기 종료, 변수가 많으면 L1, 상관이 강하면 엘라스틱넷, 이미지·텍스트는 증강과 드롭아웃. [[raw/books/05-자격증/빅데이터분석기사/pages/04-빅데이터-결과-해석/01-분석모형-평가-및-개선/02-분석모형-개선/01-과대적합-방지#방법을 고르는 순서|빅데이터분석기사 4과목 1-2-1]]
