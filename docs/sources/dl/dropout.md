# 드롭아웃 (Dropout)

## 정의
신경망 학습 때마다 일부 노드를 무작위로 꺼 두어 특정 노드에 의존하지 못하게 하는 과적합 방지 기법이다. 매번 조금씩 다른 신경망을 학습시키는 셈이 되어 예측할 때 여러 모형을 평균 낸 효과를 낸다.

## 책별 관점
### [[bigdata-analysis-engineer|빅데이터분석기사]]
- 특정 노드에만 의존하지 못하게 해, 여러 모형을 평균 낸 효과를 낸다. [[raw/books/05-자격증/빅데이터분석기사/pages/03-빅데이터-모델링/02-분석기법-적용/01-분석기법/04-인공신경망#과대적합 방지|빅데이터분석기사 3과목 2-1-4]]
- 드롭아웃이 효과적인 이유는 앙상블과 통한다. 노드를 매번 다르게 끄면 조금씩 다른 신경망 여러 개를 학습하는 셈이다. [[raw/books/05-자격증/빅데이터분석기사/pages/03-빅데이터-모델링/02-분석기법-적용/02-고급-분석기법/05-딥러닝-분석#과적합을 막는 장치|빅데이터분석기사 3과목 2-2-5]]
- 신경망의 복잡도(층·노드 수)를 줄이는 수단 중 하나로, 여러 경로로 나누어 학습하도록 유도한다. [[raw/books/05-자격증/빅데이터분석기사/pages/04-빅데이터-결과-해석/01-분석모형-평가-및-개선/02-분석모형-개선/01-과대적합-방지#드롭아웃|빅데이터분석기사 4과목 1-2-1]]
