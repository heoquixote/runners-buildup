# 트랜스포머 (Transformer)

## 정의
순서대로 훑는 대신 어텐션으로 문장의 모든 위치를 동시에 참조하는 신경망 구조이다. 각 단어가 다른 단어를 얼마나 참고할지 가중치로 정하며, 순서 정보는 위치 정보를 더해 보존한다. 병렬 처리로 큰 모델 학습이 가능해져 대규모 언어모델의 바탕이 되었다.
