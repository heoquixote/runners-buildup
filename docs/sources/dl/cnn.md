# 합성곱 신경망 (CNN)

## 정의
작은 필터를 이미지 위에서 이동시키며 지역적 특징을 추출하는 신경망이다. 같은 필터를 재사용해 학습할 값을 크게 줄이고, 인접 픽셀의 위치 관계를 유지하며, 같은 모양이 어디에 있든 반응한다.

## 책별 관점
### [[bigdata-analysis-engineer|빅데이터분석기사]]
- 이미지를 펼쳐 넣으면 입력이 폭발(100×100 컬러면 3만 개)하고 인접 픽셀 관계가 사라진다. CNN은 필터 이동으로 두 문제를 해결한다. [[raw/books/05-자격증/빅데이터분석기사/pages/03-빅데이터-모델링/02-분석기법-적용/01-분석기법/04-인공신경망#CNN이 이미지에 적합한 이유|빅데이터분석기사 3과목 2-1-4]]
- 앞쪽 층이 선과 모서리 같은 단순 패턴을 잡고 뒤로 갈수록 조합해 복잡한 형태를 만든다. [[raw/books/05-자격증/빅데이터분석기사/pages/03-빅데이터-모델링/02-분석기법-적용/02-고급-분석기법/05-딥러닝-분석#깊이가 바꾼 것|빅데이터분석기사 3과목 2-2-5]]
- CNN 해석에는 특징맵 시각화와, 이미지의 어느 부분을 보고 판단했는지 보여 주는 클래스 활성화 맵을 쓴다. [[raw/books/05-자격증/빅데이터분석기사/pages/04-빅데이터-결과-해석/02-분석결과-해석-및-활용/01-분석결과-해석/02-분석-모델별-시각화#딥러닝 모델|빅데이터분석기사 4과목 2-1-2]]
