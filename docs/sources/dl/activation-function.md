# 활성화 함수 (Activation Function)

## 정의
신경망 노드의 순입력을 비선형으로 변환해 다음 층으로 보내는 함수이다. 활성화 함수가 없으면 층을 아무리 쌓아도 하나의 선형식이 된다. 비선형을 만드는 역할과 출력을 필요한 형태로 맞추는 역할을 함께 한다.

## 책별 관점
### [[bigdata-analysis-engineer|빅데이터분석기사]]
- 함수들은 앞 함수의 문제 하나를 다음 함수가 다루는 순서로 발전했다: 시그모이드·tanh(기울기 소실) → ReLU(Dying ReLU) → Leaky ReLU, ELU, Maxout. [[raw/books/05-자격증/빅데이터분석기사/pages/03-빅데이터-모델링/02-분석기법-적용/01-분석기법/04-인공신경망#활성화 함수|빅데이터분석기사 3과목 2-1-4]]
- ReLU는 양수 구간 기울기가 항상 1이라 기울기 소실을 완화하고 연산이 빠르지만, 입력이 계속 음수인 노드는 다시 학습되지 않는다(Dying ReLU). [[raw/books/05-자격증/빅데이터분석기사/pages/03-빅데이터-모델링/02-분석기법-적용/01-분석기법/04-인공신경망#ReLU|빅데이터분석기사 3과목 2-1-4]]
- 소프트맥스는 여러 값을 지수화해 합으로 나눠 합이 1인 확률로 바꾸며 다중 분류 출력층 전용이다. [[raw/books/05-자격증/빅데이터분석기사/pages/03-빅데이터-모델링/02-분석기법-적용/01-분석기법/04-인공신경망#소프트맥스|빅데이터분석기사 3과목 2-1-4]]
- 위치별 선택: 은닉층은 ReLU(우려 시 Leaky ReLU·ELU, RNN 계열은 tanh), 출력층은 이진 분류 시그모이드, 다중 분류 소프트맥스, 회귀는 활성화 함수를 두지 않는다. [[raw/books/05-자격증/빅데이터분석기사/pages/03-빅데이터-모델링/02-분석기법-적용/01-분석기법/04-인공신경망#어디에 무엇을 쓰는가|빅데이터분석기사 3과목 2-1-4]]
