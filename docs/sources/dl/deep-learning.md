# 딥러닝 (Deep Learning)

## 정의
은닉층을 여러 개 쌓은 인공신경망으로 학습하는 방법이다. 깊이가 바꾼 핵심은 특징 추출을 사람이 설계하지 않고 모델이 데이터에서 학습한다는 점이며, 층이 쌓일수록 표현이 점점 추상화된다. 비정형 데이터와 대량 데이터에서 강점을 보인다.

## 책별 관점
### [[bigdata-analysis-engineer|빅데이터분석기사]]
- 기존 기계학습과 비교: 특징 추출을 모델이 학습, 데이터가 늘수록 계속 좋아짐, 비정형 데이터에 적합, GPU 등 대규모 연산 필요, 해석 가능성 낮음. [[raw/books/05-자격증/빅데이터분석기사/pages/03-빅데이터-모델링/02-분석기법-적용/02-고급-분석기법/05-딥러닝-분석#깊이가 바꾼 것|빅데이터분석기사 3과목 2-2-5]]
- 최근에야 가능해진 이유는 데이터 축적, GPU 병렬 연산, 학습 기법(ReLU·드롭아웃·배치 정규화) 세 조건이 함께 갖춰졌기 때문이다. [[raw/books/05-자격증/빅데이터분석기사/pages/03-빅데이터-모델링/02-분석기법-적용/02-고급-분석기법/05-딥러닝-분석#왜 최근에야 가능해졌는가|빅데이터분석기사 3과목 2-2-5]]
- 과적합을 막는 장치: 드롭아웃, 배치 정규화, 조기 종료, 데이터 증강, 가중치 규제. [[raw/books/05-자격증/빅데이터분석기사/pages/03-빅데이터-모델링/02-분석기법-적용/02-고급-분석기법/05-딥러닝-분석#과적합을 막는 장치|빅데이터분석기사 3과목 2-2-5]]
- 알고리즘: DNN(정형), CNN(이미지), RNN(순서), LSTM·GRU(긴 순서), 오토인코더(정답 없음), GAN(생성), 트랜스포머(어텐션으로 모든 위치 동시 참조). [[raw/books/05-자격증/빅데이터분석기사/pages/03-빅데이터-모델링/02-분석기법-적용/02-고급-분석기법/05-딥러닝-분석#딥러닝 분석 알고리즘|빅데이터분석기사 3과목 2-2-5]]
- 정형 데이터, 적은 데이터, 도메인 지식으로 특징을 잘 만들 수 있을 때, 판단 근거를 설명해야 할 때는 다른 기법이 낫다. [[raw/books/05-자격증/빅데이터분석기사/pages/03-빅데이터-모델링/02-분석기법-적용/02-고급-분석기법/05-딥러닝-분석#딥러닝을 쓸지 판단하기|빅데이터분석기사 3과목 2-2-5]]
- 딥러닝 시각화: 학습 곡선, 특징맵, 클래스 활성화 맵(눈밭을 보고 늑대를 판정한 사례), 어텐션 가중치, t-SNE·UMAP 임베딩 시각화. [[raw/books/05-자격증/빅데이터분석기사/pages/04-빅데이터-결과-해석/02-분석결과-해석-및-활용/01-분석결과-해석/02-분석-모델별-시각화#딥러닝 모델|빅데이터분석기사 4과목 2-1-2]]
- 딥러닝의 특징: 특징 추출 자동화, 대규모 데이터 요구, 높은 연산 비용(GPU), 비정형 데이터에 강함, 해석의 어려움. 다섯 가지는 특징을 사람이 설계하지 않는다는 하나의 선택에서 파생된다. [[raw/books/05-자격증/빅데이터분석기사/pages/01-빅데이터-분석-기획/01-빅데이터의-이해/02-빅데이터-기술-및-제도/03-빅데이터와-인공지능#딥러닝의 특징|1과목 1-2-3]]
- GAN은 진짜 같은 가짜를 만드는 생성자와 진위를 구분하는 판별자를 경쟁시켜 학습하는 비지도 방식이며, 생성하는 인공지능의 출발점이 되었다. [[raw/books/05-자격증/빅데이터분석기사/pages/01-빅데이터-분석-기획/01-빅데이터의-이해/02-빅데이터-기술-및-제도/03-빅데이터와-인공지능#비지도학습: 군집, 오토인코더, 생성적 적대 신경망|1과목 1-2-3]]
- 빅데이터는 딥러닝에 학습 재료를, 딥러닝은 빅데이터에 분석 수단을 준다. 그래서 신뢰성(Veracity)이 중요해진다. [[raw/books/05-자격증/빅데이터분석기사/pages/01-빅데이터-분석-기획/01-빅데이터의-이해/02-빅데이터-기술-및-제도/03-빅데이터와-인공지능#빅데이터와 인공지능의 관계|1과목 1-2-3]]
- 기술 동향으로 프레임워크 보급(TensorFlow·PyTorch), GAN, 오토인코더, XAI, AutoML, 거대 언어모델(LLM)이 제시된다. [[raw/books/05-자격증/빅데이터분석기사/pages/01-빅데이터-분석-기획/01-빅데이터의-이해/02-빅데이터-기술-및-제도/03-빅데이터와-인공지능#인공지능 기술 동향|1과목 1-2-3]]
