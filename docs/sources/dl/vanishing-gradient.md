# 기울기 소실 (Vanishing Gradient)

## 정의
역전파 과정에서 기울기가 층을 지날 때마다 곱해지며 작아져, 앞쪽 층이 사실상 학습되지 않는 문제이다. 깊은 신경망이 오래 학습되지 못한 원인이었고, ReLU 등이 이를 완화하면서 딥러닝이 가능해졌다.

## 책별 관점
### [[bigdata-analysis-engineer|빅데이터분석기사]]
- 시그모이드의 기울기는 최대 0.25라 층을 지날 때마다 값이 작아지고, 층이 열 개면 앞쪽에는 사실상 0이 도착한다. [[raw/books/05-자격증/빅데이터분석기사/pages/03-빅데이터-모델링/02-분석기법-적용/01-분석기법/04-인공신경망#기울기 소실 문제|빅데이터분석기사 3과목 2-1-4]]
- ReLU는 양수 구간 기울기가 1이라 곱해도 줄지 않아 문제를 완화했으며, 깊은 신경망 학습의 결정적 계기 중 하나다. [[raw/books/05-자격증/빅데이터분석기사/pages/03-빅데이터-모델링/02-분석기법-적용/01-분석기법/04-인공신경망#기울기 소실 문제|빅데이터분석기사 3과목 2-1-4]]
- RNN도 시점을 거슬러 올라갈 때 기울기가 작아져 긴 순서를 기억하지 못하며, LSTM이 문(gate)으로 이를 다룬다. [[raw/books/05-자격증/빅데이터분석기사/pages/03-빅데이터-모델링/02-분석기법-적용/01-분석기법/04-인공신경망#RNN과 LSTM|빅데이터분석기사 3과목 2-1-4]]
- 딥러닝이 최근에야 가능해진 조건 중 학습 기법(ReLU, 드롭아웃, 배치 정규화)이 깊은 층의 학습 문제를 풀었다. [[raw/books/05-자격증/빅데이터분석기사/pages/03-빅데이터-모델링/02-분석기법-적용/02-고급-분석기법/05-딥러닝-분석#왜 최근에야 가능해졌는가|빅데이터분석기사 3과목 2-2-5]]
