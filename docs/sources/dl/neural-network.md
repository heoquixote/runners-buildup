# 인공신경망 (Artificial Neural Network)

## 정의
여러 층의 단순한 계산(가중치 곱의 합, 편향, 활성화 함수)을 쌓아 복잡한 함수를 만드는 모델이다. 학습은 순전파, 손실 계산, 역전파, 가중치 갱신을 반복하며 가중치와 편향을 조정하는 일이다. 구조는 사람이 정하고 그 안의 숫자는 데이터가 정한다.

## 책별 관점
### [[bigdata-analysis-engineer|빅데이터분석기사]]
- 특징: 비선형 관계 표현, 특징의 자동 학습, 대규모 데이터 요구, 높은 연산 비용, 해석의 어려움. 모두 특징 설계를 모델에 맡긴 하나의 선택에서 파생된다. [[raw/books/05-자격증/빅데이터분석기사/pages/03-빅데이터-모델링/02-분석기법-적용/01-분석기법/04-인공신경망#인공신경망의 특징|빅데이터분석기사 3과목 2-1-4]]
- 단층 퍼셉트론은 직선 하나로 나뉘는 문제만 풀어 XOR을 풀지 못했고, 은닉층을 두어 입력을 다른 공간으로 옮기면서 해결되었다. [[raw/books/05-자격증/빅데이터분석기사/pages/03-빅데이터-모델링/02-분석기법-적용/01-분석기법/04-인공신경망#XOR 문제가 중요한 이유|빅데이터분석기사 3과목 2-1-4]]
- 노드 계산: 앞 층 출력×가중치의 합 → 편향 더하기(순입력) → 활성화 함수 적용. 계산 문제에서는 편향 누락, 활성화 함수 생략, 경계값 오독이 흔한 실수다. [[raw/books/05-자격증/빅데이터분석기사/pages/03-빅데이터-모델링/02-분석기법-적용/01-분석기법/04-인공신경망#출력값을 직접 계산해 보기|빅데이터분석기사 3과목 2-1-4]]
- 학습 흐름은 순전파 → 손실 계산 → 역전파 → 가중치 갱신이며 이를 반복하는 것이 경사하강법이다. [[raw/books/05-자격증/빅데이터분석기사/pages/03-빅데이터-모델링/02-분석기법-적용/01-분석기법/04-인공신경망#학습의 흐름|빅데이터분석기사 3과목 2-1-4]]
- 주요 설정값: 학습률(크면 발산, 작으면 느림), 에폭(적으면 덜 배우고 많으면 과적합), 배치 크기. [[raw/books/05-자격증/빅데이터분석기사/pages/03-빅데이터-모델링/02-분석기법-적용/01-분석기법/04-인공신경망#주요 설정값|빅데이터분석기사 3과목 2-1-4]]
- 정형 데이터에서는 신경망이 항상 최선이 아니며, 강점은 사람이 특징을 정의하기 어려운 비정형 데이터에서 드러난다. [[raw/books/05-자격증/빅데이터분석기사/pages/03-빅데이터-모델링/02-분석기법-적용/01-분석기법/04-인공신경망#인공신경망의 장단점|빅데이터분석기사 3과목 2-1-4]]
