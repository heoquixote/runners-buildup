# 순환 신경망 (RNN)

## 정의
이전 시점의 상태를 다음 계산에 넘겨 순서를 기억하는 신경망으로, 문장·시계열·음성처럼 순서가 의미를 갖는 데이터에 쓴다. 긴 순서에서 기울기 소실이 일어나는 한계를 LSTM이 기억과 망각을 조절하는 문(gate)으로 다룬다.

## 책별 관점
### [[bigdata-analysis-engineer|빅데이터분석기사]]
- RNN은 이전 시점의 결과를 다음 계산에 넘기지만, 시점을 거슬러 올라갈수록 기울기가 작아져 긴 순서를 기억하지 못한다. [[raw/books/05-자격증/빅데이터분석기사/pages/03-빅데이터-모델링/02-분석기법-적용/01-분석기법/04-인공신경망#RNN과 LSTM|빅데이터분석기사 3과목 2-1-4]]
- LSTM은 무엇을 기억하고 잊을지 결정하는 문을 두어 중요한 정보를 오래 유지한다. tanh는 RNN 계열 은닉층에서 아직 쓰인다. [[raw/books/05-자격증/빅데이터분석기사/pages/03-빅데이터-모델링/02-분석기법-적용/01-분석기법/04-인공신경망#RNN과 LSTM|빅데이터분석기사 3과목 2-1-4]]
- 트랜스포머는 RNN의 순차 처리(병렬화 불가)와 먼 거리 의존(관계가 희미해짐) 한계에서 출발했다. [[raw/books/05-자격증/빅데이터분석기사/pages/03-빅데이터-모델링/02-분석기법-적용/02-고급-분석기법/05-딥러닝-분석#트랜스포머|빅데이터분석기사 3과목 2-2-5]]
