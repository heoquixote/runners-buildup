## 학습 목표

- ROC-AUC와 PR-AUC의 의미를 설명할 수 있습니다.
- threshold와 독립적인 순위 지표가 왜 필요한지 이해할 수 있습니다.
- 클래스 불균형 상황에서 어떤 지표를 더 주의 깊게 볼지 판단할 수 있습니다.

## 초심자용 한 줄 요약

ROC-AUC와 PR-AUC는 `확률 점수가 양성과 음성을 얼마나 잘 구분해 순서를 매기는가`를 보는 지표입니다.

## 왜 AUC가 필요한가

precision과 recall은 threshold에 따라 바뀝니다.  
그런데 모델 자체의 순위화 능력을 먼저 보고 싶을 때가 있습니다.

예:

- threshold를 아직 못 정했다
- 여러 모델의 점수 분리 능력을 먼저 비교하고 싶다

이때 AUC 계열 지표가 유용합니다.

## ROC-AUC

ROC 곡선은 여러 threshold에서 아래 관계를 봅니다.

- TPR: `TP / (TP + FN)` = recall
- FPR: `FP / (FP + TN)`

ROC-AUC가 높다는 것은  
양성 샘플이 음성 샘플보다 더 높은 점수를 받는 경향이 강하다는 뜻입니다.

직관적으로:

- 0.5에 가까움 -> 무작위에 가까움
- 1.0에 가까움 -> 매우 잘 구분

## PR-AUC

PR 곡선은 여러 threshold에서 아래 관계를 봅니다.

- precision
- recall

즉, 양성을 얼마나 잘 찾으면서 헛경보를 얼마나 줄이는지에 더 직접적입니다.

## 언제 PR-AUC를 더 봐야 하나

양성 클래스가 매우 희귀한 문제에서는 PR-AUC가 더 민감합니다.

예:

- 사기 거래 탐지
- 희귀 질환 탐지
- 중대한 장애 탐지

이런 문제에서는 ROC-AUC가 꽤 높아 보여도  
실제 precision은 낮을 수 있습니다.

## 작은 감각 비교

### 클래스가 비교적 균형적인 경우

- ROC-AUC도 충분히 유용
- precision/recall과 함께 보면 좋음

### 양성이 매우 희귀한 경우

- PR-AUC를 더 주의 깊게 보기
- top-k precision 같은 운영형 지표도 함께 보기

## AUC가 높아도 끝이 아닌 이유

AUC는 `순위화 능력`을 잘 보여주지만 아래를 모두 해결하지는 않습니다.

- 어떤 threshold를 쓸지
- 확률이 보정(calibration)되어 있는지
- 실제 운영 비용을 얼마나 반영하는지

즉, AUC는 좋은 출발점이지만 최종 의사결정 지표는 아닐 수 있습니다.

## 실무에서 자주 하는 실수

### 1. ROC-AUC만 보고 불균형 문제를 낙관적으로 해석한다

양성이 희귀할수록 PR-AUC나 precision@k를 같이 봐야 할 수 있습니다.

### 2. AUC가 높으니 threshold는 아무렇게나 정한다

AUC와 threshold 정책은 별개입니다.

### 3. 점수 순위는 좋은데 확률 보정을 안 본다

캠페인 대상 수나 리스크 점수 해석이 필요한 경우 calibration도 중요할 수 있습니다.

## 정리

- ROC-AUC는 전반적 분리 능력, PR-AUC는 양성 탐지 품질에 더 민감합니다.
- 불균형 데이터에서는 PR-AUC를 더 주의 깊게 보는 편이 안전합니다.
- AUC는 모델 비교의 언어이지, 최종 운영 정책 전체를 대신하지는 않습니다.
