## 학습 목표

- SHAP과 PDP가 각각 무엇을 보여주는지 설명할 수 있습니다.
- 개별 예측 해석과 전체 평균 패턴 해석의 차이를 이해할 수 있습니다.
- SHAP, Feature Importance, Permutation Importance, PDP를 언제 각각 먼저 볼지 구분할 수 있습니다.
- 상관관계가 높은 변수에서 SHAP과 PDP 해석이 왜 조심스러운지 말할 수 있습니다.

## 초심자용 한 줄 요약

SHAP은 `이 예측이 왜 이렇게 나왔는지`를 더 잘 보여주고, PDP는 `이 변수가 커질수록 예측이 평균적으로 어떻게 바뀌는지`를 보여줍니다.

## 왜 SHAP과 PDP가 필요한가

Feature Importance나 Permutation Importance는  
어떤 변수가 `중요한가`를 먼저 보여줍니다.

하지만 실무에서는 거기서 한 단계 더 나아가 아래 질문이 나옵니다.

- 이 고객은 왜 이탈 위험이 높게 나왔나
- 이 변수는 커질수록 예측이 늘어나나, 줄어드나
- 특정 변수 효과가 직선처럼 움직이나, 어느 구간에서 꺾이나

이 질문에 답할 때 `SHAP`과 `PDP`가 자주 쓰입니다.

## SHAP은 무엇인가

SHAP은 각 예측값에 대해  
각 feature가 얼마나 예측을 밀어 올리거나 내렸는지 분해해서 보여주는 방식입니다.

초심자용으로는 아래처럼 이해하시면 됩니다.

- 기준점이 있다
- 각 feature가 기준점에서 예측을 얼마나 움직였는지 본다
- 그 합이 최종 예측이 된다

즉, `개별 예측 설명`에 특히 강합니다.

## SHAP으로 무엇을 볼 수 있나

### 1. 개별 고객 해석

예:

- 최근 로그인 감소가 위험도를 얼마나 올렸는가
- 문의 수 증가가 예측에 얼마나 기여했는가

### 2. 전체 데이터의 큰 패턴

요약 plot을 보면

- 어떤 변수가 전체적으로 자주 영향을 주는지
- 값이 커질수록 위험이 오르는지 내리는지

도 함께 볼 수 있습니다.

즉, SHAP은 `로컬 해석 + 글로벌 요약`을 같이 볼 수 있는 장점이 있습니다.

## 작은 코드 예시: SHAP

```python
import shap
from sklearn.ensemble import RandomForestClassifier

model = RandomForestClassifier(random_state=42)
model.fit(X_train, y_train)

explainer = shap.TreeExplainer(model)
shap_values = explainer.shap_values(X_test)
```

실무에서는 보통 아래 시각화를 많이 봅니다.

- summary plot
- bar plot
- force plot
- waterfall plot

## SHAP 해석에서 주의할 점

### 1. 인과관계가 아니다

SHAP 값이 크다고 해서  
그 변수를 바꾸면 실제 결과가 꼭 그렇게 바뀐다는 뜻은 아닙니다.

### 2. 상관 높은 변수에서는 기여 분배가 흔들릴 수 있다

비슷한 변수가 여러 개 있으면  
어느 변수에 공을 나눠 줄지가 애매할 수 있습니다.

### 3. 계산 비용이 들 수 있다

모델과 데이터 크기에 따라 꽤 무거울 수 있습니다.

## PDP는 무엇인가

PDP(Partial Dependence Plot)는  
한 변수를 변화시켰을 때 예측값이 평균적으로 어떻게 바뀌는지 보는 그래프입니다.

직관적으로는:

1. 다른 변수들은 평균적으로 고정된다고 생각한다
2. 관심 변수 값을 조금씩 바꿔본다
3. 예측값 평균이 어떻게 움직이는지 본다

즉, PDP는 `전체 평균 관점의 변수-예측 관계 곡선`입니다.

## PDP로 무엇을 볼 수 있나

- 값이 커질수록 예측이 증가하는가
- 어느 구간부터 효과가 약해지는가
- 비선형 관계가 있는가

예를 들어:

- `days_since_last_login`이 3일에서 10일로 늘어날 때 위험이 크게 오르다가
- 20일 이후에는 증가 폭이 완만해질 수 있습니다

이런 구조를 시각적으로 읽기 좋습니다.

## 작은 코드 예시: PDP

```python
from sklearn.inspection import PartialDependenceDisplay

PartialDependenceDisplay.from_estimator(
    model,
    X_train,
    features=["days_since_last_login"],
)
```

## PDP 해석에서 주의할 점

### 1. 평균 패턴이지 개별 고객 설명은 아니다

PDP는 전체 평균을 봅니다.  
특정 한 고객 예측이 왜 높았는지는 SHAP 쪽이 더 자연스럽습니다.

### 2. 상관 높은 변수에서는 비현실적 조합이 생길 수 있다

실제 데이터에는 거의 없는 조합을 평균에 섞어 볼 수 있어  
해석이 왜곡될 수 있습니다.

### 3. 상호작용이 강하면 단일 PDP만으로는 부족할 수 있다

변수 하나가 아니라 변수 조합이 함께 작동하는 경우가 많습니다.

## 무엇을 먼저 볼까

### Feature Importance

- 어떤 변수가 중요한지 빠르게 훑고 싶다

### Permutation Importance

- 실제 성능 관점에서 변수 의존도를 보고 싶다

### SHAP

- 개별 예측을 설명해야 한다
- 전체 패턴도 같이 보고 싶다

### PDP

- 변수 값이 바뀔 때 예측 곡선이 어떻게 움직이는지 보고 싶다

즉, 이 도구들은 경쟁 관계라기보다  
`질문이 다를 때 쓰는 서로 다른 렌즈`에 가깝습니다.

## 실무에서 자주 생기는 문제

### 1. SHAP 그림이 예뻐 보여서 의미를 과신하는 경우

설명 도구일 뿐, 실험 설계나 인과 추론을 대체하지는 않습니다.

### 2. PDP를 인과효과처럼 읽는 경우

평균적 연관 구조이지 정책 효과가 아닙니다.

### 3. 상관 높은 변수 구조를 무시하고 해석하는 경우

SHAP도 PDP도 둘 다 해석이 흔들릴 수 있습니다.

## 대안은 무엇인가

- 변수 중요도만 빠르게 보고 싶다 -> `Feature Importance`, `Permutation Importance`
- 개별 건 설명이 필요하다 -> `SHAP`
- 평균 관계 곡선을 보고 싶다 -> `PDP`
- 국소 패턴을 더 보고 싶다 -> ICE plot, local explanation 추가 검토

## 정리

- SHAP은 개별 예측이 왜 그렇게 나왔는지 설명하는 데 강합니다.
- PDP는 변수 값 변화에 따른 평균 예측 곡선을 읽는 데 유용합니다.
- Feature Importance, Permutation Importance, SHAP, PDP는 모두 모델 해석 도구이지만 답하는 질문이 서로 다릅니다.
- 상관 높은 변수와 인과관계 오해는 항상 조심해야 합니다.
