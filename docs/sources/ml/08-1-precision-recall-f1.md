## 학습 목표

- precision, recall, F1의 공식을 이해하고 설명할 수 있습니다.
- 세 지표가 어떤 오류 비용과 연결되는지 해석할 수 있습니다.
- 불균형 분류 문제에서 accuracy만 볼 때의 위험을 말할 수 있습니다.

## 초심자용 한 줄 요약

precision은 `양성이라고 말한 것의 정확성`, recall은 `실제 양성을 놓치지 않는 정도`, F1은 `둘의 균형`입니다.

## 공식부터 짧게 보기

- `precision = TP / (TP + FP)`
- `recall = TP / (TP + FN)`
- `F1 = 2 * precision * recall / (precision + recall)`

핵심은 공식을 외우는 것보다 각 분모가 무엇을 뜻하는지 이해하는 것입니다.

## precision은 무엇을 묻는가

`양성이라고 예측한 것들 중 실제 양성은 얼마나 되는가`

즉, 헛경보를 얼마나 줄였는지 봅니다.

precision이 중요한 예:

- 마케팅 타기팅
- 고가 수작업 검수 대상 선정
- 사기 조사 우선순위 큐

양성이라고 보낸 뒤 후속 비용이 크면 precision이 중요해집니다.

## recall은 무엇을 묻는가

`실제 양성 중에서 얼마나 놓치지 않았는가`

즉, 중요한 케이스를 얼마나 잘 잡았는지 봅니다.

recall이 중요한 예:

- 암 진단 보조
- 사기 거래 탐지
- 이탈 고객 사전 대응

놓침 비용이 크면 recall을 더 우선합니다.

## F1은 언제 유용한가

F1은 precision과 recall 둘 중 하나만 높아도 좋은 척하지 못하게 막는 지표입니다.

예:

- precision `0.95`, recall `0.20` -> F1 낮음
- precision `0.68`, recall `0.72` -> F1 상대적으로 안정적

즉, 한쪽으로 치우친 모델을 경계할 때 유용합니다.

## 작은 예시

이탈 예측 모델 두 개가 있다고 해보겠습니다.

### 모델 A

- precision `0.82`
- recall `0.35`

해석:

- 찍은 대상은 꽤 정확함
- 하지만 실제 이탈 고객을 많이 놓침

### 모델 B

- precision `0.58`
- recall `0.78`

해석:

- 더 많이 잡지만 헛경보도 늘어남

어느 모델이 좋은지는  
`쿠폰 비용`과 `이탈 손실 비용` 중 무엇이 더 큰지에 달려 있습니다.

## accuracy와 무엇이 다른가

양성 비율이 희귀한 문제에서는 accuracy가 높아도 무의미할 수 있습니다.

예:

- 실제 양성 비율 2%
- 모든 샘플을 음성으로 예측

이 경우 accuracy는 98%지만 recall은 0입니다.

즉, 양성을 잡는 것이 중요한 문제라면 accuracy만으로는 판단이 왜곡됩니다.

## 실무에서 언제 문제가 되는가

### 1. precision이 높다고 무조건 좋은 모델이라고 생각하는 경우

양성 예측을 너무 적게 하면 precision은 쉽게 올라갈 수 있습니다.

### 2. recall만 보고 FP 비용을 무시하는 경우

대상을 너무 많이 뽑아 후속 운영이 감당 안 될 수 있습니다.

### 3. F1을 만능 지표처럼 쓰는 경우

F1은 균형 지표일 뿐, 실제 비용 구조를 직접 반영하진 않습니다.

## 정리

- precision은 `양성 예측의 신뢰도`
- recall은 `실제 양성 포착률`
- F1은 `둘의 균형`

결국 어떤 지표를 우선할지는 모델 자체가 아니라 `실패 비용 구조`가 결정합니다.
