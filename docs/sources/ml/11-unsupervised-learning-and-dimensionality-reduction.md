## 비지도학습이란 무엇인가

지도학습은 `정답(label)`이 있는 상태에서 학습합니다.  
비지도학습은 정답 없이 데이터의 구조, 패턴, 유사성을 찾습니다.

대표 목적은 아래와 같습니다.

- 고객 세그먼트 찾기
- 유사 문서 묶기
- 데이터 압축
- 이상 패턴 탐색의 출발점 만들기

즉, 비지도학습은 종종 “예측 모델”보다 “탐색과 구조 이해”에 더 가깝습니다.

## 군집화: 비슷한 것끼리 묶기

군집화(clustering)는 유사한 데이터끼리 그룹을 만드는 작업입니다.

예:

- 구매 패턴이 비슷한 고객 묶기
- 비슷한 행동 로그 묶기
- 비슷한 상품 묶기

### K-Means의 기본 아이디어

K-Means는 미리 정한 `K`개의 중심점을 기준으로 데이터를 나눕니다.

직관적으로는:

1. 중심점을 임시로 놓습니다.
2. 각 데이터를 가장 가까운 중심에 배정합니다.
3. 각 그룹 중심을 다시 계산합니다.
4. 반복합니다.

즉, 같은 군집 안에서는 거리가 가깝고 군집끼리는 멀어지도록 만듭니다.

## K 값을 어떻게 정할까

초심자는 종종 K를 정답처럼 생각하지만, 현실에서는 탐색적 판단이 많습니다.

고려 요소:

- 비즈니스에서 필요한 세그먼트 수
- 군집 해석 가능성
- 엘보우 방법, 실루엣 점수 같은 참고 지표

중요한 것은 “수학적으로 완벽한 K”보다  
`업무에서 설명 가능하고 행동으로 옮길 수 있는 세그먼트인가`입니다.

## 차원축소: 많은 변수를 더 적게 요약하기

변수가 너무 많으면 시각화도 어렵고 노이즈도 커질 수 있습니다.  
차원축소는 여러 feature를 더 적은 축으로 요약하는 방법입니다.

대표적으로 PCA가 자주 사용됩니다.

## PCA의 기본 아이디어

PCA는 데이터 분산을 최대한 많이 보존하는 새로운 축을 찾습니다.

쉽게 말하면:

- 원래 컬럼을 그대로 쓰지 않고
- 데이터 차이가 가장 크게 드러나는 방향을 새 축으로 만듭니다

예를 들어 20개 변수를 2개 축으로 줄이면  
시각화나 요약 설명이 쉬워질 수 있습니다.

## explained variance를 어떻게 볼까

PCA에서는 `설명된 분산 비율`을 자주 봅니다.

- 첫 번째 주성분이 전체 변동의 얼마를 설명하는가
- 앞의 몇 개 축으로 충분히 정보가 유지되는가

예를 들어 앞의 3개 축이 85%를 설명한다면  
20개 변수를 3개 요약 축으로 보는 실용적 선택이 가능할 수 있습니다.

## 비지도학습이 특히 불리한 상황

비지도학습은 강력하지만 아래 상황에서는 특히 조심해야 합니다.

### 1. 정답이 꼭 필요한 문제

예를 들어 대출 승인 여부, 질병 판별처럼  
명확한 정답과 평가 기준이 필요한 문제는 지도학습이 더 직접적입니다.

### 2. 결과를 바로 정책으로 확정하려는 경우

군집 결과는 탐색적 구조일 뿐,  
그 자체가 곧 정답 정책이나 고객 등급 체계는 아닐 수 있습니다.

### 3. 잡음이 많고 feature 해석이 불안정한 경우

label이 없기 때문에 모델이 무엇을 잡아냈는지  
사람이 추가 해석과 검증을 해줘야 합니다.

### 4. 고차원 거리 자체가 불안정한 경우

군집화나 manifold 기법은 거리 개념에 민감할 수 있는데,  
고차원에서는 거리 감각 자체가 흐려질 수 있습니다.

즉, 비지도학습은 `자동 정답 생성기`보다  
`가설 생성기`에 더 가깝다고 보는 편이 안전합니다.

## 차원축소가 불리한 상황

### 1. 원래 변수 해석이 매우 중요한 경우

PCA, t-SNE, UMAP 결과 축은 원래 컬럼과 1:1로 대응하지 않기 때문에  
설명 책임이 큰 문제에서는 해석이 어려울 수 있습니다.

### 2. 정보 손실이 치명적인 경우

차원을 줄인다는 것은 일부 정보를 압축하거나 버린다는 뜻입니다.  
그래서 후속 모델 성능이나 의사결정 품질이 떨어질 수 있습니다.

### 3. 시각화용 임베딩을 거리나 점수처럼 해석하는 경우

t-SNE나 UMAP의 2차원 좌표는 시각화에 강하지만  
그 좌표계를 바로 원래 데이터의 절대 거리처럼 읽으면 위험할 수 있습니다.

## 작은 코드 예시

```python
from sklearn.cluster import KMeans
from sklearn.decomposition import PCA
from sklearn.preprocessing import StandardScaler

X_scaled = StandardScaler().fit_transform(X)

kmeans = KMeans(n_clusters=3, random_state=42)
clusters = kmeans.fit_predict(X_scaled)

pca = PCA(n_components=2)
X_pca = pca.fit_transform(X_scaled)

print(clusters[:5])
print(pca.explained_variance_ratio_)
```

이 코드에서 핵심은 아래 해석입니다.

- 스케일 차이가 크면 먼저 표준화가 필요할 수 있음
- cluster 번호 자체에는 본질적 의미가 없음
- PCA 축은 원래 변수 이름 그대로가 아니라 새로운 조합 축임

## 실무에서 언제 문제가 되는가

### 1. 군집 결과를 곧바로 진실로 받아들이는 경우

군집은 알고리즘이 만든 분할일 뿐, 절대적인 자연 법칙이 아닙니다.  
파라미터와 feature 선택에 따라 결과가 달라질 수 있습니다.

### 2. 스케일링 없이 거리 기반 알고리즘을 쓰는 경우

매출과 클릭 수처럼 단위 차이가 크면 큰 값 스케일 변수가 군집을 지배할 수 있습니다.

### 3. PCA 축을 원인 변수처럼 해석하는 경우

PCA는 설명을 위한 축 재구성이지, 직접적인 비즈니스 원인을 말해주지는 않습니다.

### 4. label이 없다는 사실을 잊고 성능처럼 말하는 경우

군집 결과는 지도학습 점수처럼 간단히 “정답률”로 말할 수 없는 경우가 많습니다.

## 대안은 무엇인가

상황에 따라 아래 대안도 있습니다.

- rule-based segmentation
- hierarchical clustering
- DBSCAN
- Gaussian Mixture
- t-SNE, UMAP 같은 시각화 중심 축소 기법

즉, 비지도학습은 `하나의 정답 찾기`보다 `데이터를 더 잘 읽기 위한 탐색 도구`로 보는 편이 좋습니다.
