## 학습 목표

- 선형회귀가 무엇을 학습하는지 설명할 수 있습니다.
- 계수와 절편의 의미를 해석할 수 있습니다.
- 손실 함수가 무엇을 벌주고 있는지 이해할 수 있습니다.

## 초심자용 한 줄 요약

선형회귀는 `입력 변수의 가중합으로 숫자를 설명하려는 모델`이며, 손실 함수는 `어떤 틀림을 더 크게 벌줄지`를 정하는 기준입니다.

## 선형회귀의 기본 식

가장 기본적인 형태는 아래와 같습니다.

`y = b0 + b1x1 + b2x2 + ... + bpxp`

- `y`: 예측값
- `b0`: 절편
- `b1 ... bp`: 각 feature의 계수

즉, 여러 입력 변수에 가중치를 곱해 더한 값으로 결과를 설명합니다.

## 계수는 어떻게 읽을까

예를 들어 집값 예측에서 아래와 같은 결과가 나왔다고 가정해보겠습니다.

`price = 5000 + 300 * area + 1200 * near_station`

단순 해석:

- `area`가 1 증가할 때 예측 가격은 평균적으로 300 증가
- `near_station = 1`이면 그렇지 않은 경우보다 평균적으로 1200 높음

물론 실제로는 변수 상관관계와 스케일을 함께 봐야 하지만,  
입문 단계에서는 `계수 = 방향과 크기의 힌트` 정도로 이해하면 좋습니다.

## 손실 함수는 왜 필요한가

회귀 모델은 예측값과 실제값 차이를 줄이려 합니다.  
이때 어떤 차이를 더 싫어할지 정해주는 것이 손실 함수입니다.

### MSE 기반 학습

`MSE = 평균(실제값 - 예측값)^2`

의미:

- 오차를 제곱해 큰 실수를 더 강하게 벌줍니다.
- 미분이 쉬워 최적화에 자주 사용됩니다.

### MAE 기반 관점

`MAE = 평균 |실제값 - 예측값|`

의미:

- 절대 오차를 직접 봅니다.
- 이상치 영향이 상대적으로 덜합니다.

실무적으로는 `무엇을 더 벌주고 싶은가`가 핵심입니다.

## 작은 예시

실제 매출이 `[100, 120, 500]`이고 예측이 `[110, 130, 420]`라고 해보겠습니다.

오차는 `[10, 10, 80]`입니다.

- MAE는 평균적으로 얼마나 빗나갔는가를 보여줍니다.
- MSE는 `80` 같은 큰 오차를 훨씬 더 강하게 반영합니다.

즉, 큰 실패가 치명적인 문제면 MSE 계열이 더 민감하게 반응합니다.

## 선형회귀가 잘 맞는 상황

- feature와 target 관계가 대체로 선형적이다
- 해석 가능성이 중요하다
- baseline이 필요하다
- 데이터가 아주 복잡하지 않다

특히 처음 회귀 문제를 풀 때는 선형회귀가 좋은 출발점입니다.

## 선형회귀의 한계

### 1. 비선형 관계에 약할 수 있다

실제 관계가 구부러져 있으면 설명력이 떨어질 수 있습니다.

### 2. 이상치에 민감할 수 있다

큰 오차가 학습 방향을 크게 흔들 수 있습니다.

### 3. feature 간 상관성이 높으면 계수 해석이 불안정할 수 있다

예를 들어 평수와 방 개수가 거의 함께 움직이면  
각 계수의 개별 해석이 흔들릴 수 있습니다.

## 대안은 무엇인가

상황에 따라 아래를 고려할 수 있습니다.

- Ridge, Lasso 같은 정규화 선형모델
- 트리 기반 회귀 모델
- 로그 변환 같은 타깃 변환
- 비선형 feature engineering

## 정리

- 선형회귀는 숫자 예측의 가장 기본적인 출발점입니다.
- 손실 함수는 `어떤 틀림을 더 싫어하는가`를 반영합니다.
- 성능뿐 아니라 해석 가능성과 baseline 가치도 큰 장점입니다.
