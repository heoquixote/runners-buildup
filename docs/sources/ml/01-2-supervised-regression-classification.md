## 학습 목표

- 지도학습과 비지도학습의 차이를 설명할 수 있습니다.
- 회귀와 분류를 예측값 형태로 구분할 수 있습니다.
- 문제를 처음 봤을 때 어떤 학습 유형인지 분류할 수 있습니다.

## 초심자용 한 줄 요약

머신러닝 문제를 볼 때 가장 먼저 할 일은 `정답이 있는가`, `예측값이 숫자인가 범주인가`를 구분하는 것입니다.

## 가장 먼저 보는 질문 2개

머신러닝 문제를 처음 보면 아래 두 질문부터 던지면 됩니다.

1. 정답(label)이 있는가
2. 예측 결과가 숫자인가, 범주인가

이 두 질문만으로도 상당수 문제를 빠르게 분류할 수 있습니다.

## 지도학습과 비지도학습

### 지도학습

정답(label)이 있는 데이터로 학습합니다.

예:

- 고객 이탈 여부 예측
- 내일 매출 예측
- 스팸 메일 분류

형태는 보통 아래와 같습니다.

`X -> y`

- `X`: feature
- `y`: label

### 비지도학습

정답 없이 데이터의 구조를 찾습니다.

예:

- 고객 세그먼트 찾기
- 유사 상품 묶기
- 이상 패턴 탐색 출발점 만들기

즉, 지도학습은 `정답 맞히기`, 비지도학습은 `구조 찾기`에 가깝습니다.

## 회귀와 분류

지도학습 안에서도 가장 먼저 나누는 축이 `회귀`와 `분류`입니다.

### 회귀

예측 결과가 연속형 숫자입니다.

예:

- 다음 달 매출
- 배송 시간
- 집값

즉, 답이 `3.2`, `152000`, `7.5일`처럼 숫자 크기 자체에 의미가 있습니다.

### 분류

예측 결과가 클래스입니다.

예:

- 이탈 / 유지
- 사기 / 정상
- 긍정 / 부정 / 중립

결과를 `0`과 `1`로 저장하더라도, 그 값이 단순 코드라면 분류입니다.

## 헷갈리기 쉬운 케이스

### 1. 숫자로 되어 있어도 분류일 수 있다

예를 들어 `y = 0, 1`이면 숫자처럼 보이지만

- 0: 정상
- 1: 이탈

처럼 의미가 클래스라면 분류입니다.

### 2. 점수 예측처럼 보여도 실제 액션은 분류일 수 있다

이탈 확률 `0.83`을 예측하더라도, 실제 업무에서는  
`0.7 이상이면 캠페인 대상`처럼 잘라서 쓰는 경우가 많습니다.

즉, 모델은 확률을 만들지만 비즈니스 의사결정은 분류처럼 동작할 수 있습니다.

## 작은 예시로 구분하기

### 예시 1. 부동산 가격 예측

- 정답 있음
- 결과가 숫자
- 정리: `지도학습 + 회귀`

### 예시 2. 카드 사기 탐지

- 정답 있음
- 결과가 사기/정상
- 정리: `지도학습 + 분류`

### 예시 3. 고객 세그먼트 만들기

- 정답 없음
- 유사한 고객을 묶고 싶음
- 정리: `비지도학습 + 군집화`

## 왜 이 구분이 중요한가

문제 유형이 다르면 아래가 모두 달라집니다.

- 모델 후보
- 평가 지표
- 데이터 준비 방식
- 예측 결과 해석 방식

예:

- 회귀: `MAE`, `RMSE`, `R2`
- 분류: `precision`, `recall`, `F1`, `ROC-AUC`
- 군집화: 실루엣 점수, 해석 가능성, 세그먼트 활용도

즉, 처음 구분을 잘못하면 뒤의 모든 선택이 흔들릴 수 있습니다.

## 실무에서 언제 문제가 되는가

### 1. label이 모호한데 분류를 바로 시작하는 경우

예를 들어 이탈 정의가 팀마다 다르면 모델부터 만들어도 해석이 흔들립니다.

### 2. 숫자를 예측하지만 실제 의사결정 비용 구조를 무시하는 경우

매출 예측에서 평균 오차는 괜찮아도 큰 과소예측이 치명적일 수 있습니다.

### 3. 비지도학습 결과를 정답처럼 믿는 경우

군집은 사람이 만든 해석 도구이지 절대적인 진실이 아닙니다.

## 정리

- 정답이 있으면 지도학습, 없으면 비지도학습입니다.
- 지도학습에서 숫자를 맞히면 회귀, 클래스를 맞히면 분류입니다.
- 이 구분은 모델 선택보다 먼저 해야 하는 가장 기초적인 설계입니다.
