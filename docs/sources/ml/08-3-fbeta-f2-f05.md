## 학습 목표

- `F-beta` 지표가 왜 필요한지 설명할 수 있습니다.
- `F1`, `F2`, `F0.5`의 차이를 이해할 수 있습니다.
- recall 우선 문제와 precision 우선 문제에서 어떤 F 지표를 더 볼지 판단할 수 있습니다.

## 초심자용 한 줄 요약

`F1`이 precision과 recall을 똑같이 본다면, `F2`는 recall 쪽을 더 보고, `F0.5`는 precision 쪽을 더 보는 지표입니다.

## 왜 F1만으로는 부족할까

`F1`은 precision과 recall의 균형을 보는 좋은 출발점입니다.  
하지만 실무에서는 두 지표를 항상 같은 비중으로 보지 않습니다.

예:

- 암 진단 보조: 놓치면 안 되므로 recall이 더 중요
- 마케팅 타기팅: 잘못 보내는 비용이 크므로 precision이 더 중요

이처럼 비용 구조가 한쪽으로 기울어져 있다면  
`F1`만 보면 그 우선순위가 충분히 드러나지 않을 수 있습니다.

## F-beta의 기본 개념

F-beta는 precision과 recall을 하나의 숫자로 묶되,  
`beta` 값을 통해 어느 쪽을 더 중요하게 볼지 조정한 지표입니다.

공식은 아래와 같습니다.

`F_beta = (1 + beta^2) * (precision * recall) / (beta^2 * precision + recall)`

여기서 중요한 해석은 다음과 같습니다.

- `beta = 1` -> `F1`, precision과 recall을 같은 비중으로 봄
- `beta > 1` -> recall에 더 큰 비중
- `beta < 1` -> precision에 더 큰 비중

즉, beta는 `우리가 어떤 종류의 실패를 더 싫어하는가`를 숫자로 표현하는 손잡이입니다.

## F2는 무엇을 뜻하나

`F2`는 recall에 더 많은 비중을 둡니다.

직관:

- 실제 양성을 놓치는 것이 더 비싸다
- FP가 조금 늘더라도 FN을 줄이는 편이 낫다

예:

- 질병 판별
- 사기 거래 탐지
- 중요한 장애 알림 탐지

이런 문제에서는 `precision이 조금 떨어져도 실제 양성을 더 많이 잡는가`가 중요하므로  
`F2`가 더 실무적인 비교 지표가 될 수 있습니다.

## F0.5는 무엇을 뜻하나

`F0.5`는 precision에 더 많은 비중을 둡니다.

직관:

- 양성이라고 예측한 대상의 정확성이 더 중요하다
- recall이 조금 낮아져도 FP를 줄이는 편이 낫다

예:

- 고비용 쿠폰 발송 대상 선정
- 수작업 검수 대상 선별
- 세일즈 리드 우선순위 추출

이런 문제에서는 `헛경보를 줄여서 운영 효율을 높이는가`가 중요하므로  
`F0.5`가 더 잘 맞을 수 있습니다.

## 작은 비교 예시

두 모델이 있다고 가정해보겠습니다.

### 모델 A

- precision `0.90`
- recall `0.45`

### 모델 B

- precision `0.68`
- recall `0.78`

이 상황에서:

- `F1`은 둘의 균형을 봅니다.
- `F2`는 recall이 높은 모델 B를 더 좋게 볼 가능성이 큽니다.
- `F0.5`는 precision이 높은 모델 A를 더 좋게 볼 가능성이 큽니다.

즉, 모델 순위가 지표 선택에 따라 달라질 수 있습니다.

## 언제 어떤 지표를 고를까

### F1이 적합한 경우

- precision과 recall을 비슷하게 중요하게 본다
- 어떤 방향으로 가중치를 둘지 아직 확실하지 않다
- baseline 비교 출발점이 필요하다

### F2가 적합한 경우

- FN 비용이 더 크다
- 양성을 놓치면 비즈니스 손실이 크다
- 더 넓게 잡고 이후 후처리로 거를 수 있다

### F0.5가 적합한 경우

- FP 비용이 더 크다
- 후속 액션이 비싸다
- 양성이라고 예측한 대상의 신뢰도가 중요하다

## 실무에서 자주 하는 실수

### 1. F1을 만능 지표처럼 쓴다

실패 비용 구조가 비대칭이면 `F1`은 중요한 차이를 가릴 수 있습니다.

### 2. F2나 F0.5를 썼지만 왜 그 값을 골랐는지 설명하지 못한다

지표 선택은 모델링 취향이 아니라 운영 정책과 연결되어야 합니다.

### 3. F 계열 지표 하나만 보고 confusion matrix를 안 본다

숫자 하나로 줄여도 실제 FP, FN 규모를 함께 봐야 합니다.

## scikit-learn 예시

```python
from sklearn.metrics import fbeta_score

f1 = fbeta_score(y_test, pred, beta=1)
f2 = fbeta_score(y_test, pred, beta=2)
f05 = fbeta_score(y_test, pred, beta=0.5)

print(f1, f2, f05)
```

이 코드를 볼 때 중요한 질문은 아래입니다.

- 왜 `beta=2`를 봐야 하는가
- 왜 `beta=0.5`를 봐야 하는가
- 이 선택이 실제 액션 비용과 맞는가

## 정리

- `F1`은 균형형 지표입니다.
- `F2`는 recall 우선, `F0.5`는 precision 우선 지표입니다.
- 결국 어떤 F 지표를 볼지는 `FP와 FN 중 무엇이 더 비싼가`에 따라 정해야 합니다.
