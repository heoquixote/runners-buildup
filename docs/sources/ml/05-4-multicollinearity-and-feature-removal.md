## 학습 목표

- 다중공선성이 무엇인지 설명할 수 있습니다.
- 왜 선형모델 계수 해석을 불안정하게 만드는지 이해할 수 있습니다.
- 상관계수, VIF 같은 점검 기준의 큰 그림을 설명할 수 있습니다.
- 변수를 무조건 제거하기보다 언제 유지할지까지 판단할 수 있습니다.

## 초심자용 한 줄 요약

다중공선성은 `비슷한 변수가 너무 많이 함께 들어와서 각 변수의 역할을 깔끔하게 나누기 어려운 상태`입니다.

## 다중공선성이란 무엇인가

다중공선성은 feature들 사이의 상관이 너무 높아  
서로 비슷한 정보를 많이 담고 있는 상태를 말합니다.

예:

- `age`와 `birth_year`
- `monthly_sales`와 `weekly_sales_sum`
- `total_orders`와 `recent_30d_orders`

즉, 모델 입장에서는 “비슷한 설명을 하는 변수 여러 개”가 함께 들어온 셈입니다.

## 왜 문제가 되나

예측 성능이 크게 나쁘지 않아도  
계수 해석은 매우 불안정해질 수 있습니다.

예:

- 이번 학습에서는 `age` 계수가 크게 나옴
- 다음 분할에서는 `birth_year` 쪽이 더 커짐

즉, 어떤 변수의 영향인지 분리해서 말하기 어려워집니다.

특히 아래 상황에서 더 중요합니다.

- 선형회귀
- 로지스틱 회귀
- 변수 계수 해석이 중요한 보고서

## 언제 덜 민감한가

트리 기반 모델은 선형계수처럼 직접 흔들리지는 않지만  
비슷한 변수가 많으면 중요도 해석이 분산되거나 불안정해질 수 있습니다.

즉, 다중공선성은 선형모델에서 더 직접적이지만  
트리모델에서도 완전히 무시할 문제는 아닙니다.

## 어떻게 점검할까

### 1. 상관계수 보기

가장 단순한 시작점입니다.

예:

- `corr > 0.8`
- `corr > 0.9`

같은 기준을 후보 신호로 볼 수 있습니다.

주의:

- 상관계수는 주로 2개 변수 관계를 봅니다.
- 여러 변수 조합 문제는 충분히 못 볼 수 있습니다.

### 2. VIF 보기

VIF(Variance Inflation Factor)는  
한 변수가 다른 변수들로 얼마나 잘 설명되는지 보는 지표입니다.

직관적으로는:

- VIF가 높다
- 다른 변수와 중복 정보가 많다
- 계수 분산이 커질 수 있다

실무에서는 `5` 또는 `10`을 경계선처럼 보는 경우가 많지만,  
절대 기준이라기보다 경고 신호로 이해하는 편이 좋습니다.

## 작은 코드 예시: 상관계수

```python
import pandas as pd

corr = X_train.corr(numeric_only=True)
print(corr)
```

## 작은 코드 예시: VIF

```python
import pandas as pd
from statsmodels.stats.outliers_influence import variance_inflation_factor

X_num = X_train[["age", "income", "recent_30d_orders"]].assign(const=1)

vif = pd.Series(
    [variance_inflation_factor(X_num.values, i) for i in range(X_num.shape[1] - 1)],
    index=X_num.columns[:-1],
)

print(vif)
```

## 변수를 무조건 제거해야 하나

항상 그렇지는 않습니다.

### 제거가 자연스러운 경우

- 거의 같은 의미의 변수다
- 운영 비용만 늘리고 정보 추가가 거의 없다
- 계수 해석이 핵심인 모델이다

### 유지가 자연스러운 경우

- 각각 다른 비즈니스 해석이 중요하다
- 트리모델 중심이라 계수 안정성이 핵심이 아니다
- 제거하면 현업 설명이 더 어려워진다

### 중간 대안

- 대표 변수 하나만 남긴다
- 차원축소 사용
- 정규화 회귀(Ridge, Lasso) 활용
- 파생변수 구조를 다시 단순화한다

## 실무에서 자주 생기는 문제

### 1. 파생변수를 많이 만든 뒤 중복을 점검하지 않는 경우

좋은 뜻으로 만든 컬럼이 사실상 같은 정보를 반복할 수 있습니다.

### 2. 상관계수만 보고 너무 기계적으로 제거하는 경우

도메인상 중요한 변수까지 빠질 수 있습니다.

### 3. 계수 부호가 자꾸 바뀌는데 원인을 못 찾는 경우

다중공선성이 숨어 있을 수 있습니다.

## 대안은 무엇인가

- 해석 가능한 선형모델이 중요하다 -> 상관계수 + VIF + 정규화 함께 검토
- 예측 성능이 우선이다 -> 제거보다 regularization이나 트리모델 비교
- 비슷한 변수 묶음이 많다 -> 대표 feature 설계로 단순화

## 정리

- 다중공선성은 비슷한 변수들이 함께 들어와 계수 해석을 흔드는 문제입니다.
- 상관계수와 VIF는 점검의 출발점입니다.
- 변수 제거는 기계적으로 하기보다 해석, 성능, 운영 비용을 같이 보고 결정해야 합니다.
